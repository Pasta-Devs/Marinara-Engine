# Halloween seasonal art

Decorations for the Halloween seasonal theme: the bats and pumpkins on Home (`styles/themes/seasonal-halloween.css`)
and the art in the Halloween greeting (`components/modals/SeasonalGreetingModal.tsx`).

Provenance: generated for Marinara Engine with AI image generation on 2026-10-19, for this theme: a cluster of
three smiling jack-o'-lanterns with autumn leaves, a single smiling jack-o'-lantern, and a cute purple cartoon bat, each
on a transparent background. Each picture was trimmed to its artwork, resized and saved as WebP (quality 82):

| File            | Size      | Used for                                   |
| --------------- | --------- | ------------------------------------------ |
| `pumpkins.webp` | 480 × 276 | Home, beside or below the hero             |
| `pumpkin.webp`  | 224 × 226 | The greeting window                        |
| `bat.webp`      | 160 × 100 | Home's flying bats and the greeting window |
