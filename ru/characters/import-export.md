# Импорт и экспорт карточек персонажей

Это руководство объясняет, как загрузить карточки персонажей в приложение Marinara Engine и как экспортировать собственных персонажей обратно. Здесь описаны поддерживаемые типы файлов, настройки в окне импорта и три формата экспорта.

Карточка персонажа – это один файл с одним персонажем: имя, описание, личность, приветствия и обычно картинка-аватар. Карточка позволяет переносить персонажа между Marinara Engine и другими приложениями для ролевых игр.

## Форматы импорта

Окно **Import Character** (импорт персонажа) принимает четыре типа файлов. Можно перетащить сразу несколько файлов, причем разных типов.

| Тип файла | Что это |
| --- | --- |
| **.json** | Обычная карточка персонажа в текстовом виде (Chara Card V2). |
| **.png** | Картинка-карточка персонажа: данные спрятаны внутри изображения. |
| **.charx** | Пакет Character Card V3 (CharX) – формат на основе zip, который использует RisuAI. |
| **.marinara** | Собственный экспорт приложения Marinara Engine (встречается и как `.marinara.json`). |

Файл **.marinara** сохраняет больше всего подробностей, потому что это родной формат приложения Marinara Engine. Остальные три приходят из SillyTavern, Chub, Risu и похожих программ.

## Импорт персонажа

Чтобы добавить в библиотеку одну или несколько карточек, выполните такие шаги.

1. Откройте панель **Characters** (персонажи).
2. Нажмите на панели инструментов кнопку **Import** (импорт). Это кнопка-иконка со стрелкой скачивания. Откроется окно **Import Character**.
3. Перетащите файлы в это окно или нажмите на него, чтобы выбрать их вручную. Вы увидите подсказку "Drop one or more files here or click to browse".
4. Задайте две настройки импорта (описаны ниже). Они действуют для всех файлов этой партии.
5. Дождитесь списка результатов. Каждый файл получает зеленую галочку со словом "Imported" и именем либо красную отметку с ошибкой.

### Выбор сохраняемых тегов

Настройка **Imported card tags** (теги импортированной карточки) определяет судьбу тегов на входящей карточке. Это называется режимом импорта тегов. Есть три варианта:

- **All tags**: сохранить все теги исходной карточки. Так работает по умолчанию.
- **No tags**: пропустить теги исходной карточки.
- **Existing only**: сохранить только те теги, которые уже есть в библиотеке.

### Выбор области действия скриптов регулярных выражений

Некоторые карточки идут вместе со скриптами регулярных выражений – небольшими правилами замены текста. Настройка **Imported regex scripts** (импортированные скрипты регулярных выражений) задает их область действия:

- **Character only**: скрипты работают только для этого персонажа. Так работает по умолчанию.
- **Global**: скрипты добавляются в раздел **Regexes** панели **Presets** и работают во всех чатах.

Выбирайте **Character only** – кроме тех случаев, когда правила точно нужны во всех чатах.

### Карточки со встроенным лорбуком

Лорбук – это набор фактов о вашем мире, к которым ИИ обращается во время чата. Если у карточки есть встроенный лорбук, импорт приостанавливается и открывается панель **Embedded lorebook found** (найден встроенный лорбук). В ней перечислены все файлы и число записей в каждом. Выберите один вариант для всей партии:

- **Import Lorebook**: дополнительно создать отдельный лорбук Marinara и привязать его к персонажу.
- **No Import**: оставить лорбук только внутри карточки.

### Импорт нескольких карточек сразу

То же окно **Import Character** справляется и с пакетным импортом. Выберите несколько файлов, и Marinara импортирует их по очереди. В списке результатов на каждый файл приходится одна строка, так вы увидите, какие карточки загрузились, а какие нет.

## Экспорт персонажа

Откройте персонажа в редакторе и нажмите на верхней панели инструментов кнопку **Export character** (экспорт персонажа). Окно **Export Character** предлагает три формата.

| Формат | Что получится | Когда подходит |
| --- | --- | --- |
| **Marinara Native** | Файл `.marinara.json` со всеми метаданными приложения Marinara Engine, спрайтами, изображениями галереи и привязанными лорбуками. | Перенос персонажа между установками Marinara Engine без потери подробностей. |
| **Compatible JSON** | Обычный файл JSON формата Chara Card V2 без обертки Marinara. | Отправка в другие приложения, которые читают карточки JSON. |
| **Compatible PNG Card** | Картинка формата Chara Card V2 с данными карточки внутри изображения. | Приложения и сайты, которым нужна карточка PNG: SillyTavern, Chub, Risu. |

Выбирайте **Marinara Native**, когда важно сохранить все. Один из форматов **Compatible** подойдет, если файл уходит в другую программу. Оба совместимых формата теряют дополнения, которые есть только в Marinara Engine, – например, спрайты и изображения галереи. Непустые поля **Backstory** (предыстория) и **Appearance** (внешность) добавляются к стандартному полю Description, чтобы другие программы для V2 сохранили эти сведения о персонаже. Эти поля удаляются из экспортируемых расширений, чтобы при повторном импорте не было дубликатов. Сохраненная карточка не меняется; **Marinara Native** оставляет поля раздельными.

## Экспорт нескольких персонажей сразу

Группу персонажей можно экспортировать одним файлом zip.

1. Откройте панель **Characters**.
2. Нажмите на панели инструментов кнопку **Select** (выбрать), чтобы перейти в режим выбора. Это кнопка-иконка с галочкой.
3. Отметьте нужных персонажей.
4. Нажмите кнопку **Export** на панели действий внизу. Marinara скачает архив с именем `marinara-characters.zip`.

Внутри архива лежит по одному файлу **Marinara Native** на каждого персонажа. Для пакетного экспорта форматы PNG и совместимый JSON недоступны, поэтому для них используйте экспорт по одному персонажу.

## Импорт целой папки SillyTavern

Выше описаны карточки, которые выбираются вручную. Чтобы перенести всю установку SillyTavern сразу, воспользуйтесь пакетным импортом папки. Он забирает персонажей, чаты, пресеты и лорбуки вместе. Найти его можно в панели **Settings** (настройки), на вкладке **Imports**. Подробное описание – в руководстве [Импорт данных из SillyTavern](../data/importing-from-sillytavern.md).
