# Импорт и экспорт карточек персонажей

Карточка персонажа – это один файл с одним персонажем: имя, описание, личность, приветствия и часто картинка-аватар. Импортируйте карточки, чтобы добавить персонажей из других приложений и с других сайтов. Экспортируйте своих персонажей, чтобы сохранить резервную копию или поделиться ими.

## Импорт персонажа

Перед началом: вам нужен файл карточки персонажа на вашем устройстве. Чтобы вместо этого найти карточки в интернете, см. [Card Browser](bot-browser.md).

1. Нажмите **Characters** (персонажи) на верхней панели. Если такой кнопки нет, сначала откройте **More** (еще).
2. Нажмите на панели инструментов **Import** (импорт) – иконку со стрелкой скачивания. Откроется окно **Import Character** (импорт персонажа).
3. Задайте настройки импорта, описанные ниже. Они действуют для всех файлов этой партии.
4. Перетащите файлы в это окно или коснитесь его либо нажмите на него, чтобы открыть окно выбора файлов на вашем устройстве. Можно выбрать несколько файлов, причем разных типов.
5. Дождитесь списка результатов. У каждого файла появится зеленая галочка либо красная отметка с ошибкой. Текст будет таким: `Imported "Name"`, `Imported "Name" with its embedded lorebook` или `Imported "Name" without creating the embedded lorebook`.
6. Найдите нового персонажа в **Characters**.

Marinara принимает четыре типа файлов:

| Тип файла | Что это |
| --- | --- |
| **.json** | Карточка, сохраненная в виде текста. Файлы экспорта Marinara (`.marinara.json`) – тоже файлы .json. |
| **.png** | Картинка-карточка: данные карточки спрятаны внутри изображения. |
| **.charx** | Пакет карточки, сохраненный как файл zip. |
| **.marinara** | Файл экспорта Marinara. |

Экспорт Marinara сохраняет больше всего подробностей. Остальные типы приходят из SillyTavern, Chub, Risu и похожих программ.

Если не получилось: прочитайте красное сообщение рядом с файлом. Остальные файлы партии все равно импортируются.

### Настройки импорта

| Настройка | Варианты |
| --- | --- |
| **Imported card tags** (теги импортированной карточки) | **All tags** (по умолчанию): сохранить все теги. |
| | **No tags**: пропустить их. |
| | **Existing only**: сохранить только теги, которые уже есть в вашей библиотеке. |
| **Imported regex scripts** (импортированные regex-скрипты) | **Character only** (по умолчанию): правила работают для этого персонажа. |
| | **Global**: правила попадают в **Presets → Regexes** (пресеты → регулярные выражения) и работают во всех чатах. |
| **Split description into fields** (разделить описание по полям) | По умолчанию выключено. Отметьте флажок, чтобы перенести помеченный текст о личности, внешности и тому подобном из **Description** (описание) в отдельные поля. |

Скрипты регулярных выражений – это небольшие правила замены текста. Оставьте **Character only**, если только вам не нужны эти правила везде. Разделение оставляет карточки рассказчика, мира и карточки с несколькими персонажами как есть.

### Карточки со встроенным лорбуком

Лорбук – это набор фактов о вашем мире, к которым ИИ обращается во время чата. Если в карточку встроен лорбук, импорт приостанавливается и показывает **Embedded lorebook found** (найден встроенный лорбук). Там перечислены все файлы и число записей в каждом. Выберите один вариант для всей партии:

- **Import Lorebook** дополнительно создает отдельный лорбук Marinara, привязанный к персонажу.
- **No Import** оставляет лорбук только внутри карточки.

### Импорт целой папки SillyTavern

Чтобы перенести всю установку SillyTavern, воспользуйтесь пакетным импортом в панели **Settings** (настройки), на вкладке **Imports** (импорт). Он переносит персонажей, чаты, пресеты и лорбуки вместе. См. [Импорт данных из SillyTavern](../data/importing-from-sillytavern.md).

## Экспорт персонажа

1. Откройте персонажа в редакторе.
2. Нажмите **Export character** (экспорт персонажа) в шапке. Откроется окно **Export Character**.
3. Выберите формат. Marinara скачает файл.

| Формат | Что получится | Когда подходит |
| --- | --- | --- |
| **Marinara Native** | Файл `.marinara.json` с метаданными Marinara, спрайтами, изображениями галереи и привязанными лорбуками. | Перенос персонажа между установками Marinara без потери подробностей. |
| **Compatible JSON** | Обычный файл карточки, который могут прочитать другие приложения. Дополнения, которые есть только в Marinara, например спрайты и изображения галереи, в него не попадают. | Другие приложения, которые читают карточки JSON. |
| **Compatible PNG Card** | Картинка-карточка с данными внутри изображения. В нее попадают ваши спрайты, но не изображения галереи. | Приложения и сайты, которым нужна карточка PNG, например SillyTavern, Chub и Risu. |

Оба формата **Compatible** добавляют непустые поля **Backstory** (предыстория) и **Appearance** (внешность) к стандартному полю **Description**, чтобы эти сведения сохранились в других приложениях. Сохраненная карточка не меняется.

Форматы **Marinara Native** и **Compatible PNG Card** сохраняют онбординг карточки (см. [Интерактивный онбординг](interactive-onboarding.md)), поэтому, когда кто-то импортирует карточку в Marinara, она по-прежнему задает свои вопросы. Формат **Compatible JSON** его не сохраняет.

## Экспорт нескольких персонажей сразу

1. Нажмите **Characters** на верхней панели (или сначала **More**, если этой кнопки не видно).
2. Нажмите на панели инструментов **Select** (выбрать) – иконку галочки – и отметьте нужных персонажей.
3. Нажмите **Export** (экспорт) на панели внизу. Marinara скачает `marinara-characters.zip`.

Внутри архива лежит по одному файлу **Marinara Native** на каждого персонажа. У пакетного экспорта нет вариантов PNG и JSON. Для них используйте экспорт одного персонажа. Другие способы выбрать персонажей описаны в руководстве [Порядок в библиотеке персонажей](library-organization.md#export-or-delete-many-characters).
