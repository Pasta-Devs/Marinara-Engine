# Персоны

Персона – это карточка персонажа, которая представляет вас в чате: ваше имя, описание и другие необязательные подробности. Marinara отправляет их в каждом промпте, чтобы ИИ знал, с кем разговаривает. Можно держать много персон и выбирать по одной для каждого чата. Как использовать персону, описано в руководстве [Выбор персоны в чате](choosing-your-persona.md).

## Создание персоны

1. Нажмите **Personas** (персоны) на верхней панели навигации. Если этой кнопки не видно, сначала откройте **More** (еще).
2. Нажмите **New** (создать). Откроется окно **Create Persona** (создать персону).
3. Введите имя в поле **Name** (имя). Это единственное обязательное поле.
4. Нажмите **Create**.

Персона создается с пустым описанием и открывается в редакторе персоны.

5. Откройте вкладку **Card** (карточка) и напишите **Description** (описание): ваше имя, внешность и то, как вы себя ведете.
6. Нажмите **Save** (сохранить) в заголовке.

Затем выберите ее в чате, где хотите ее использовать. См. [Выбор персоны в чате](choosing-your-persona.md).

## Что делает персона

Marinara отправляет вашу персону ИИ в каждом промпте. Выберите в чате **None** (нет), чтобы не отправлять персону. Без персоны ИИ называет вас "User".

Макрос `{{user}}` – это метка в тексте. Marinara заменяет ее именем персоны перед отправкой промпта. Если вашу персону зовут Alex, `{{user}}` превращается в Alex. См. [Макросы промптов](../prompts/macros.md).

## Панель Personas

Панель **Personas** – это ваша библиотека персон. Нажмите на строку, чтобы открыть эту персону в редакторе персоны.

| Элемент | Что делает |
| --- | --- |
| **Download** (скачать) | Открывает [Card Browser](bot-browser.md), где можно найти и персоны на PlotLight. |
| **Open Library** (открыть библиотеку) | Открывает библиотеку персон на всю страницу, с той же сеткой и предпросмотром, что и в библиотеке персонажей. |
| **New** | Создает персону. |
| **Import** (импортировать) | Открывает окно **Import Persona** (импорт персоны). |
| **Select** (выбрать) | Включает режим выбора для массового удаления и экспорта. |
| Поле поиска | Подсказка в поле: **Search personas/tags** (поиск персон/тегов). Ищет по имени, описанию, комментарию и тегам. О поиске по тегам см. [Поиск](library-organization.md#search). |
| Список сортировки | **Manual order** (ручной порядок), **A-Z**, **Z-A**, **Newest** (сначала новые), **Oldest** (сначала старые) или **Tokens** (примерный размер промпта). |
| **New Folder** (новая папка) | Создает папку. |
| **Tags** (теги) | Раскрывает список тегов для фильтрации. |

В режиме **Manual order** перетащите строку или нажмите <kbd>Alt</kbd>+<kbd>Up</kbd> либо <kbd>Alt</kbd>+<kbd>Down</kbd> на строке в фокусе. На сенсорном экране нажмите и удерживайте строку, чтобы взять ее. При наведении на строку появляются **Duplicate** (дублировать) и **Delete** (удалить). Если персон больше, чем помещается на одной странице, появляется кнопка **Load more** (загрузить еще). Пока персон нет, панель показывает **No personas yet**.

## Редактор персоны

При открытии персоны область чата заменяется редактором персоны на всю страницу. В его заголовке есть:

- Стрелка **Back** (назад).
- Плитка аватара. Нажмите на нее, чтобы загрузить картинку. Если настроено подключение для генерации изображений, картинку может создать и кнопка с волшебной палочкой.
- Поле имени и поле комментария для короткой пометки, например `Modern AU version`.
- Кнопка **Save**, которая выключена, пока вы ничего не изменили.
- **Export persona** (экспортировать персону), **Add persona as character** (добавить персону как персонажа), **Duplicate persona** (дублировать персону) и **Delete persona** (удалить персону).

При выходе из редактора изменения сначала сохраняются. Если сохранение не удается, редактор остается открытым с вашим черновиком.

Вкладки идут в таком порядке: **Metadata** (метаданные), **Card**, **Convo**, **Lorebook** (лорбук), **Sprites** (спрайты), **Gallery** (галерея), **Colors** (цвета) и **Stats** (характеристики). Каждая вкладка переносит к своему разделу одной длинной формы.

Редактор персоны работает так же, как [редактор персонажа](creating-and-editing-characters.md). Ниже описано, чем он отличается.

| Вкладка | Особенности для персоны |
| --- | --- |
| **Metadata** | Данные персоны и сведения для библиотеки. См. список под этой таблицей. |
| **Card** | См. раздел [Вкладка Card](#card-tab) ниже. |
| **Convo** | Поля, которые работают только в режиме Conversation. См. [Профили в режиме Conversation](../conversation/profiles.md). |
| **Lorebook** | Прикрепите записи лорбука, которые активируются, когда эта персона участвует в чате. См. [Обзор лорбуков](../lorebooks/overview.md). |
| **Sprites** | Рисунки в полный рост для Game и Roleplay. Есть **Facial Expressions** (выражения лица), **Full-body** (во весь рост) и **Clips** (клипы), а также **Upload Folder** (загрузить папку). См. [Спрайты персонажа](sprites.md). |
| **Gallery** | Эталонные изображения и видео, с кнопками **Upload Persona Images** (загрузить изображения персоны) и **Upload Persona Videos** (загрузить видео персоны). См. [Галереи персонажей и персон](galleries.md). |
| **Colors** | Цвета имени, речи и фона сообщения. См. [Цвета персонажа и характеристики RPG](colors-and-stats.md). |
| **Stats** | Полосы состояния и атрибуты RPG. См. раздел [Вкладка Stats](#stats-tab) ниже. |

На вкладке **Metadata** есть:

- **Persona ID** с кнопкой **Copy** (копировать).
- Обрезка аватара.
- **Name** и **Creator** (автор).
- **Phonetic name** (фонетическое имя) – используется, только когда синтез речи читает ваше имя.
- **Title / Comment** (заголовок / комментарий) – короткая пометка.
- **Version** (версия), по умолчанию `1.0`, с переключателем **Automatic versioning** (автоматическое версионирование).
- **Tags**.
- **Creator Notes** (заметки автора), которые никогда не отправляются ИИ.

<a id="card-tab"></a>

### Вкладка Card

На вкладке **Card** собраны поля, которые описывают вас для ИИ. Под каждым видна текущая оценка числа токенов.

| Поле | Что писать | Отправляется ИИ |
| --- | --- | --- |
| **Summary** (краткое описание) | Обзор для библиотеки и предпросмотра. | Нет |
| **Description** | Кто вы в целом и какая у вас роль. | В каждом промпте |
| **Personality** (личность) | Темперамент, поведение, речевые привычки. | Да |
| **Backstory** (предыстория) | История, происхождение, связи. | Да |
| **Appearance** (внешность) | Внешность, одежда, визуальные детали. | Да |
| **Scenario** (сценарий) | Ваша обычная ситуация в ролевых сценах. | Да |
| **Example Dialogue** (примеры диалога) | Образцы разговоров. Разделяйте их с помощью `<START>`. Используйте `{{user}}` для вашей персоны и `{{char}}` для другого персонажа. | Да |

**Image Appearance Override** (отдельное описание внешности для изображений) под полем **Appearance** работает так же, как у персонажей. См. [Вкладка Card](creating-and-editing-characters.md#card-tab). Текстовые поля поддерживают макросы.

Эти функции работают так же, как у персонажей, только их предмет – персона:

- Кнопка с волшебной палочкой над каждым полем пишет его за вас. См. [Генерация поля карточки с помощью палочки](creating-and-editing-characters.md#write-a-card-field-with-the-wand).
- **Add Alternative Field** (добавить альтернативное поле) под каждым полем дает выбранным чатам другую версию. Список **Active in** (активно в) показывает только чаты, которые используют эту персону, а назначения приостанавливаются, когда чат выбирает другую персону. См. [Альтернативное поле в выбранных чатах](creating-and-editing-characters.md#use-an-alternative-field-in-selected-chats).
- **Version history** (история версий) находится на вкладке **Metadata**. До первой правки там написано `Previous persona states will appear here after the next edit.` **Reset** (сбросить) удаляет все снимки и ставит версии значение 1.0. См. [История версий](creating-and-editing-characters.md#version-history).

<a id="stats-tab"></a>

### Вкладка Stats

Вкладка **Stats** состоит из двух отдельных блоков. Оба питают HUD – панель характеристик, которая показывается на экране во время чата.

- **Enable Persona Stats** (включить характеристики персоны) включает полосы состояния – шкалы потребностей, например голода и настроения. Новый набор начинается с полос Satiety, Energy, Hygiene и Mood, каждая на 100 из 100. Агент **Persona Stats** меняет их по ходу истории.
- **Enable RPG Attributes** (включить атрибуты RPG) включает Pools (полосы вроде HP и MP) и Attributes (числа вроде силы). Оба объяснены в руководстве [Цвета персонажа и характеристики RPG](colors-and-stats.md). Новый набор начинается с HP и MP на 100 из 100 и STR, DEX, CON, INT, WIS и CHA со значением 10. Они отправляются вместе с персоной для боя и Game Mode, а также для необязательных бросков. Агенты их не обновляют.

Блок **Game Mode Icon** (значок Game Mode) задает картинку вашего токена во время боя в Game Mode. См. [Значок Game Mode](colors-and-stats.md#game-mode-icon). Если установлен набор правил Game Mode (правила для игр в настольном стиле), блок **Ruleset sheets** (листы наборов правил) хранит вашу начальную сборку для него. См. [Листы наборов правил](colors-and-stats.md#ruleset-sheets). Заданные значения – это стартовые значения для новых чатов.

## Импорт и экспорт персон

Чтобы импортировать персону, нажмите **Import** в панели **Personas**. Окно **Import Persona** принимает файлы `.marinara` и `.json`, в том числе несколько сразу. Файл Marinara восстанавливает все подробности, спрайты и структуру галереи. Обычный файл JSON из другого инструмента сопоставляется поле за полем с новой персоной. Имя обязательно. Для каждого файла показывается отметка успеха или ошибки.

Чтобы экспортировать, нажмите **Export persona** в редакторе или воспользуйтесь **Export** (экспорт) в режиме выбора. Окно **Export Persona** (экспорт персоны) предлагает два формата:

| Формат | Что вы получаете |
| --- | --- |
| **Marinara Native** | Все подробности персоны Marinara, спрайты и прикрепленные лорбуки. Используйте его для переноса персоны между установками Marinara. |
| **Compatible JSON** | Только обычные поля персоны, для других инструментов. |

Массовый экспорт скачивает один архив zip, где на каждую персону приходится один файл.

## Дублирование и удаление персоны

Чтобы дублировать персону, нажмите **Duplicate** в строке или **Duplicate persona** в редакторе. Копия получает имя "{original name} (Copy)" и сохраняет все поля карточки, цвета, характеристики и поля Convo. Ни один чат не меняет свою персону.

Чтобы удалить персону, нажмите **Delete** в строке или **Delete persona** в редакторе, затем подтвердите. Отменить удаление нельзя. Чтобы удалить несколько, нажмите **Select**, отметьте персоны и нажмите **Delete** в полосе выбора. Если удалить что-то не удалось, эти персоны остаются отмеченными, и попытку можно повторить.

## Добавление персоны как персонажа

**Add persona as character** в заголовке редактора создает новую карточку среди ваших персонажей. В нее копируются имя, описание, личность, сценарий, предыстория, внешность, теги, автор, версия и аватар. Персона остается без изменений. Как редактировать новую карточку, описано в руководстве [Создание и редактирование персонажей](creating-and-editing-characters.md).
