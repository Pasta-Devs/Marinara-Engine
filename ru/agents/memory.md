# Memory Recall и сводки чата

Это руководство объясняет функцию **Memory Recall** (память чата, поиск по прошлым сообщениям), включаемую по желанию функцию **Advanced Memory Recall (Alpha)** (расширенная память чата, альфа-версия) для автоматического управления контекстом Roleplay, панель **Chat Summary** (сводка чата) и раздел **Automatic Summarization** (автоматические сводки) в Conversation.

## Две системы памяти

Любая модель ИИ читает за один раз лишь ограниченный объем текста. Этот предел называют контекстным окном. Когда чат становится длинным, самые старые сообщения выпадают из окна, и ИИ их забывает. В приложении Marinara Engine (далее – Marinara) есть две отдельные системы, которые решают эту проблему.

- **Memory Recall** ищет в старых сообщениях места, ближе всего связанные с тем, что вы только что написали, и незаметно возвращает их в промпт. Функция работает во всех режимах чата.
- Сводки сжимают старые сообщения в короткие пересказы, которые занимают в промпте место исходных сообщений. В чатах Roleplay за это отвечает панель **Chat Summary**, в чатах Conversation – раздел **Automatic Summarization**.

Чатам Game Mode доступна только функция **Memory Recall**. Ни одной из функций сводки в них нет.

Обе системы можно использовать одновременно. Они делают разную работу и друг другу не мешают.

## Настройка Memory Recall

**Memory Recall** находит подходящие фрагменты из более ранней части чата и вставляет их в промпт как воспоминания. Для этого нужен эмбеддинг – числовой отпечаток смысла сообщения. Marinara сравнивает отпечаток нового сообщения с сохраненными отпечатками прошлых сообщений и добавляет самые близкие совпадения.

### Включение Memory Recall

1. Откройте чат и нажмите кнопку **Chat Settings** (настройки чата) в заголовке чата.
2. Найдите раздел **Memory Recall** (у него значок мозга).
3. Включите переключатель **Enable Memory Recall**.

**Enable Memory Recall** – настройка отдельного чата. Значение по умолчанию зависит от режима:

- Включено в чатах Conversation.
- Включено в чатах Roleplay и Game, где есть активная сцена.
- Выключено во всех остальных чатах.

Если выключить переключатель, найденные воспоминания перестают попадать в промпт. Уже сохраненные данные при этом не удаляются.

### Источник эмбеддингов

Чтобы строить отпечатки смысла, функции **Memory Recall** нужен источник эмбеддингов. Он задается в подключении, а не в настройках чата. Подключение – это сохраненные настройки доступа к провайдеру ИИ.

1. Откройте панель **Connections** (подключения) и начните править подключение.
2. Найдите раздел **Semantic Search (Embeddings)**.
3. Введите название модели эмбеддингов в поле модели. Пример значения – `text-embedding-3-small`.
4. При необходимости укажите в поле **Embedding Endpoint URL** другой адрес.
5. При необходимости выберите в раскрывающемся списке **Embedding Connection** подключение, у которого можно позаимствовать ключ и адрес. Среди вариантов – **Same as this connection** и **Local Model (sidecar)**.

Некоторые провайдеры эмбеддинги не предлагают. Тогда Marinara выводит примечание с просьбой выбрать отдельное подключение для эмбеддингов: совместимое с OpenAI, подключение к Google или к встроенной модели Local Model.

Если подключение для эмбеддингов не задано вовсе, Marinara берет встроенную локальную модель эмбеддингов. Она скачивается один раз и работает на вашем компьютере, ключ API для нее не нужен. Подробнее о встроенной модели – в руководстве [Настройка модели Local Model](../connections/local-model.md).

Тот же параметр **Semantic Search (Embeddings)** отвечает и за семантический поиск в лорбуках, так что достаточно настроить его один раз – и работают обе функции.

### Окно **Memories for This Chat**

Чтобы посмотреть, что чат запомнил, откройте панель **Chat Settings**, перейдите в раздел **Memory Recall** и нажмите **Access memories for this chat**. Если Advanced Memory включена, просмотр остается внутри выдвижной панели Roleplay; иначе открывается окно **Memories for This Chat**.

В окне видно число сохраненных фрагментов памяти и примерную оценку в токенах. На карточке каждого фрагмента показаны охваченный диапазон дат, число сообщений, статус и время создания. Статус бывает таким:

- **Vectorized** – отпечаток построен и готов к поиску.
- **Waiting for vector** – отпечаток еще создается.
- **Embedding unavailable** – ни один источник эмбеддингов не смог его построить.

На панели инструментов есть значки экспорта воспоминаний, импорта, перестроения и полной очистки. У каждого фрагмента есть свой значок корзины, чтобы забыть только его.

- Значок корзины у фрагмента открывает окно **Forget Memory**. Подтвердите кнопкой **Forget**.
- Значок корзины для полной очистки открывает окно **Clear Memories**. Подтвердите кнопкой **Clear**. Так удаляются воспоминания, но сообщения чата остаются на месте.
- Значок обновления пересобирает все фрагменты памяти из текущих сообщений чата. Пользуйтесь им после смены модели эмбеддингов.
- Экспорт сохраняет файл `.marinara.json`. Импорт принимает файлы `.json` и `.marinara` и объединяет их с уже существующими воспоминаниями.

### Как ведет себя Memory Recall

Стоит помнить о нескольких моментах:

- Marinara сохраняет фрагменты памяти в фоне всегда, когда доступен источник эмбеддингов – даже при выключенном **Enable Memory Recall**. Переключатель отвечает только за то, попадают ли сохраненные воспоминания в промпт. Чтобы сохранение прекратилось, уберите источник эмбеддингов или время от времени очищайте воспоминания.
- Фрагмент создается, только когда накопится не менее 5 новых сообщений. Более мелкие порции ждут следующего ответа.
- Найденные фрагменты проходят проверку на схожесть и должны быть достаточно близки по смыслу. Слабые совпадения отбрасываются, поэтому поиск иногда не возвращает ничего, хотя воспоминания есть.
- На найденные воспоминания отводится небольшая доля промпта, так что добавляются лишь несколько самых подходящих.
- Если сменить модель эмбеддингов, когда воспоминания уже есть, старые фрагменты перестанут совпадать. Пересоберите их значком обновления.
- Удаление сообщений чата удаляет и его фрагменты памяти.

В некоторых контейнерных сборках, известных как Marinara Lite, функция **Memory Recall** выключена полностью. Там раздел **Memory Recall** вообще не появляется.

## Advanced Memory Recall (Alpha, Roleplay)

Откройте **Chat Settings → Memory Recall** и включите **Advanced Memory Recall (Alpha)**. Этот необязательный режим совместно управляет окном недавней истории, сводками для связности и подходящими старыми отрывками. На компьютере и телефоне настройки, ход подготовки и просмотр архива остаются внутри выдвижной панели Chat Settings.

### Настройка

- Выберите **maximum context** (максимальный контекст), который поддерживает модель чата. Лимит учитывает приблизительное число токенов промпта, инструменты, вложения, место для ответа и запас. Это оценка, а не точный подсчет токенизатором или ограничение расходов.
- Выберите **constant-summary budget** (бюджет постоянной сводки) в пределах этого лимита. Краткий снимок состояния для связности включается в каждый запрос один раз. Пока полный запрос помещается, недавние сообщения остаются несжатыми.
- **helper connection** (вспомогательное подключение) принимает небольшие решения о сценах. По умолчанию используется подключение агентов, а при его отсутствии – подключение чата. Первую обработку истории можно поручить основной или вспомогательной модели; выбранные модели видны до подготовки.
- Для сводок сцен и сжатия используются существующие модель и промпты **Summaries** (сводки). Advanced Memory работает независимо от общего переключателя Agents и не требует скачиваемого агента.
- Предпочтительный диапазон соседних сообщений по умолчанию составляет **3–10**. В зависимости от релевантности, доступа персонажа и свободного места сообщений может быть меньше, в том числе ни одного.

Для существующего группового чата Individual (индивидуальный режим) один раз подтвердите недостающие диапазоны знаний персонажей. Первая реплика персонажа не доказывает, что ему известно всё до нее. Выбирайте реального персонажа в качестве **Narrator** (рассказчик) только тогда, когда ему можно обходить ограничения участия. Явно скрытые сообщения и ручные маркеры начала по-прежнему ограничивают память. Диапазоны можно исправить позже; новым персонажам требуется отдельное подтверждение.

Подготовка обрабатывает старую историю порциями и показывает текущий этап рядом с хомячьим колесом Professor Mari. **Cancel** (отмена) сохраняет завершенную работу; **Resume** (продолжение) позволяет продолжить после закрытия панели или перезапуска сервера. Если вызов модели завершился ошибкой, ранее действительная память сохраняется, а интерфейс показывает ошибку для повторной попытки.

### Во время чата

Когда полный запрос достигает лимита, Advanced Memory сначала убирает необязательные воспоминания, затем переносит старые завершенные сцены в сводку для связности. Если одна незавершенная сцена слишком велика, старая часть временно сжимается в сводку, а сцена остается открытой. Исходные сообщения и ручные настройки начала и видимости сохраняются.

Архив может вернуть подходящие сводки сцен и точные реплики с исходными номерами сообщений и указанием говорящих. Учитываются сообщения и персон, и персонажей. При перегенерации старого ответа используются только источники до него, даже если ответ находится раньше текущего управляемого окна. После редактирования, смены свайпа, скрытия или удаления исходных сообщений затронутые производные воспоминания проверяются повторно перед использованием.

Откройте **Access memories for this chat** в той же панели, чтобы проверить источники сцен и доступ к ним, исправить сводки, отключить записи для поиска, перестроить индекс или выполнить экспорт и импорт. Исправления исходных ручных сводок сохраняются и делают недействительными зависимые сводки для связности. Отключение записи отличается от скрытия ее исходных сообщений: именно скрытие источников определяет доступные персонажу знания.

Пока Advanced включен, этот режим управляет поиском, поэтому переключатель Standard Recall не вставляет вторую копию. Он также заменяет обычное расписание автоматических сводок Roleplay для этого чата. Отключение Advanced Memory возвращает обычные настройки. Существующие лорбуки и скачиваемые агенты сохраняют собственные правила области действия; Advanced Memory не может сделать произвольный пользовательский или внешний контекст приватным.

### Размещение в пресете

Авторы пресетов могут размещать следующие обычные маркеры содержимого с помощью существующих настроек порядка секций, имени, роли и группы:

| Маркер | Содержимое |
| --- | --- |
| `chat_summary` | Ограниченный по объему снимок состояния для связности с учетом персонажа. |
| `current_scene_summary` | Временная сводка старой части текущей сцены. |
| `recalled_scenes` | Подходящие архивные сцены. |
| `recalled_messages` | Точные исторические отрывки с указанием говорящих и источников. |

Каждая часть следует формату пресета **XML**, **Markdown** или **None** (без форматирования) и содержит краткое объяснение своего назначения. Пустые части ничего не выводят. Размещение определяет первое включенное вхождение маркера; части без включенного маркера вставляются один раз перед историей, поэтому старые пресеты работают. Отрывки – это контекст, а не новые текущие сообщения или команды. Три новых маркера пусты, когда Advanced Memory выключена.

Предпросмотр промпта использует уже подготовленную память, не вызывая модель и не создавая эмбеддинги. Если нужна инициализация или сжатие, сначала выполните подготовку в панели. Отчет памяти показывает приблизительный размер контекста, выбранную границу и возвращенные источники; инспектор итогового промпта показывает, что действительно ушло модели.

### Ограничения и восстановление

Поиск выборочен, а сводки могут упускать нюансы. Храните важные исправления в исходной переписке или редакторе сводок. Ни одна система не восстановит то, что никогда не было записано. Если эмбеддинги недоступны, ограниченный поиск по словам и действительные сводки для связности остаются доступны; архив никогда не вставляется целиком. Если одни только обязательные инструкции, вложение или резерв ответа не помещаются, уменьшите эти данные или увеличьте лимит. Advanced Memory остановится, а не станет молча удалять инструкции.

## Chat Summary (Roleplay)

**Chat Summary** сжимает старые сообщения в короткие пересказы – записи сводки. Каждую запись пишет либо ИИ, либо вы сами, и каждую можно включить или выключить отдельно. Функция есть только в чатах Roleplay.

Чтобы ее открыть, нажмите кнопку **Chat Summary** (значок свитка) в заголовке чата Roleplay. Откроется всплывающая панель **Chat Summary**.

### Создание записи сводки

1. В блоке **Summary Scope** выберите **Last**, чтобы свести самые свежие сообщения, или **Range**, чтобы задать конкретный диапазон сообщений.
2. Нажмите кнопку **Generate**, и ИИ напишет запись по этому объему.
3. Либо нажмите кнопку **Write**, чтобы создать пустую запись и набрать пересказ самостоятельно.

Каждая запись в списке показывает заголовок, исходный диапазон или число сообщений и примерный размер в токенах. Запись можно включить или выключить, развернуть, изменить кнопкой **Edit** или удалить кнопкой **Delete**. Групповые кнопки **Show Inactive** и **Hide Inactive** показывают или скрывают неактивные записи, а **Activate All** и **Deactivate All** включают или выключают сразу все.

### Automatic Summaries

Панель **Automatic Summaries** обновляет сводки по ходу чата. Она есть только в чатах Roleplay.

- Включите переключатель **Enabled** внутри панели **Automatic Summaries**.
- Частоту задайте в поле **Every** – она измеряется в сообщениях пользователя. По умолчанию 5, диапазон – от 1 до 200.
- Кнопка **Backfill Summary** догоняет старый чат, у которого сводок никогда не было. Обработка идет порциями, и во время работы видна полоса прогресса. Нажмите кнопку **Stop**, чтобы прервать ее раньше.

### Шаблоны Summary Prompt

Панель **Summary Prompt** управляет инструкцией, по которой ИИ пишет сводку. Кнопка **Edit** меняет активный промпт. Кнопка **Templates** открывает менеджер шаблонов. Там кнопка **New template** сохраняет промпт под именем. У каждого сохраненного шаблона есть свои кнопки **Duplicate**, **Edit** и **Delete**.

Сохраненные шаблоны – общая настройка всего приложения. Правка или выбор шаблона в одном чате Roleplay меняет промпт сводки во всех чатах Roleplay.

### Подключение Summary Connection и размер ответа

Панель **Summary Connection** выбирает подключение, которое пишет сводки. По умолчанию там стоит **Agent default (falls back to chat connection)**. Это значит, что сначала используется подключение агента по умолчанию, а вторым – собственное подключение чата.

Поле **Maximum output size** задает предельную длину сгенерированной сводки. По умолчанию 4096 токенов, диапазон – от 1 до 32768.

### Параметры отображения

Элементы **Display** во всплывающей панели решают, как сообщения со сводкой выглядят на экране:

- **Hide summarised messages** – скрывает исходные сообщения, как только их накрывает сводка. По умолчанию выключено.
- **Recent message tail** – сколько самых новых сообщений остаются полностью видимыми даже при включенном скрытии. По умолчанию 10, принимается любое целое неотрицательное число. Значение 0 скрывает всю сведенную порцию. Чем больше значение, тем больше промпт и дороже обращение к модели.
- **Collapse hidden messages** – задает, как скрытые сообщения выглядят в тексте чата.

Если в чате включено подтверждение записи агентом (отдельная настройка в разделе **Agents**), сводки от ИИ ждут вашей проверки и только потом вступают в силу.

## Automatic Summarization (Conversation)

Чаты Conversation работают с другой системой – **Automatic Summarization**. Она подводит итог каждого календарного дня, а затем собирает завершенные недели дневных сводок в недельную сводку. Дальше в промпт уходят только недельные сводки, дневные сводки текущей недели и сегодняшние сообщения. Так каждый запрос остается небольшим.

Эта функция работает сама, и для чатов Conversation ее нельзя выключить.

### Открытие редактора

1. Откройте чат Conversation и нажмите кнопку **Chat Settings**.
2. Найдите раздел **Automatic Summarization** (у него значок календаря).
3. Нажмите кнопку **Edit Summaries** – откроется окно **Automatic Summarization**.

В окне сначала идут недельные записи, а за ними дни, еще не собранные в неделю. Разверните запись, чтобы изменить текст **Summary** и список **Key Details**, где можно добавлять и убирать строки.

### Настройки Day Rollover Hour и Recent Message Tail

Два параметра в разделе **Automatic Summarization** определяют, как делятся дни:

- **Day Rollover Hour** – час, с которого для сводок начинается новый день. По умолчанию 4 AM, выбрать можно любой час от 12 AM (полночь) до 11 AM. Сообщения, отправленные раньше этого часа, относятся к предыдущему дню. Выберите время, когда вы никогда не общаетесь, чтобы ночная сессия не разрезалась пополам.
- **Recent Message Tail** – сколько самых новых сообщений за сегодня остаются дословно даже после того, как попали в сводку. По умолчанию 10, принимается любое целое неотрицательное число. Чем больше значение, тем больше промпт и дороже обращение к модели.

Если изменить **Day Rollover Hour**, когда сводки уже есть, Marinara предупредит, что старые сводки строились по прежней настройке.

### Заполнение пропущенных дней

Иногда день остается без сводки – например, после импорта старого чата. В окне есть панель **Missing Summaries** с кнопкой **Backfill**: она повторяет попытку для недавних дней, у которых сводки нет. За один раз просматриваются до 14 дней назад.

Смена подключения или модели для сводок не переписывает уже существующие дневные и недельные записи.

## Устранение неполадок

### Memory Recall ничего не находит

- Проверьте, что источник эмбеддингов настроен. Если у фрагментов в окне **Memories for This Chat** стоит статус **Embedding unavailable**, настройте раздел **Semantic Search (Embeddings)** в подключении или обойдитесь встроенной локальной моделью. См. [Настройка модели Local Model](../connections/local-model.md).
- Если у фрагментов стоит **Waiting for vector**, дайте им время. Отпечатки строятся после ответов.
- Поиск добавляет только те воспоминания, что тесно связаны с вашим последним сообщением. Если похожего нет, не добавляется ничего. Это нормально.
- Если модель эмбеддингов менялась недавно, нажмите значок обновления в окне **Memories for This Chat**, чтобы старые фрагменты подошли новой модели.

### Сводки не генерируются

- Проверьте, что у чата есть рабочее текстовое подключение. **Chat Summary** берет подключение из панели **Summary Connection**, а **Automatic Summarization** – вычисленное подключение для сводок. Если не работает ни одно, генерация пропускается.
- Если в чате включено подтверждение записи агентом, сводки от ИИ сначала ждут вашего одобрения.
- Неудачная сводка автоматически повторяется через паузу. Если дело застряло, запустите вручную **Backfill Summary** (Roleplay) или **Backfill** (Conversation).
