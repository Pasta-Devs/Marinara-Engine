# Одобрение записей агентов и редактор Agent Suite

Агенты могут записывать данные в ваш чат: записи лорбука, сводки и правки карточек персонажей. Это руководство показывает, как проверять такие записи до сохранения и как просматривать и исправлять то, что агенты сохранили, в редакторе **Agent Suite** (набор агентов).

## Проверка записей агентов до сохранения

По умолчанию часть записей агентов сохраняется сама. Переключатель **Review Agent Outputs** (проверять результаты агентов) заставляет каждую из них ждать вашего одобрения.

1. Откройте чат и нажмите **Chat Settings** (настройки чата).
2. Прокрутите до раздела **Agents** (агенты).
3. В чате Roleplay откройте **Trackers Control** (управление трекерами). В Game пропустите этот шаг.
4. Включите **Review Agent Outputs**.

Когда переключатель включен, обновления лорбука, обновления сводки и другие проверяемые результаты агентов-писателей ждут вас. Когда он выключен, обновления лорбука и сводки могут сохраняться автоматически.

Правки карточки персонажа всегда сначала запрашивают одобрение, даже если **Review Agent Outputs** выключен. Эту проверку отключить нельзя.

### Проверка обновления лорбука или сводки

Когда агент предлагает запись, открывается окно с заголовком **Review Lorebook Update** или **Review Summary Update**. В нем видно имя агента и поле **Proposed Text** (предложенный текст), которое можно отредактировать. Для записей в лорбук окно также напоминает держать каждую запись под заголовком `###`.

- **Accept** (принять) сохраняет текст вместе с вашими правками.
- **Regenerate** (сгенерировать заново) запускает заново только этого агента, чтобы получить новое предложение.
- **Discard** (отклонить) отбрасывает предложение без сохранения.

Если ждут еще предложения, окно показывает, сколько их. Когда вы закончите с текущим, оно откроется снова для следующего.

Агент со способностью **Create character cards** (создавать карточки персонажей) также может предложить новую карточку персонажа. Открывается окно проверки с текстом карточки. Пока вы не примете ее, ничего не сохраняется.

### Проверка обновления карточки персонажа

Агент **Card Evolution Auditor** предлагает правки карточки персонажа, исходя из того, что произошло в ролевой игре. В режиме Conversation встроенный инструмент `update_about_me` тоже может предложить изменение публичного раздела About Me. Ни один из них не меняет карточку сам. Оба открывают окно **Review Character Card Updates**.

Для каждой предложенной правки окно показывает поле карточки, которое она затрагивает, короткую причину, если агент ее указал, блок **Before** с текущим текстом и поле **After**, которое можно отредактировать.

- **Approve** (одобрить) применяет правки. Число на кнопке показывает, сколько правок будет применено. Номер версии персонажа растет, а в историю версий добавляется запись.
- **Regenerate** запускает агента заново для новых предложений.
- **Reject** (отклонить) убирает их, не меняя карточку.

Если карточка изменилась после того, как агент составил предложение, правка помечается как устаревшая и становится бледной. Тогда появляется кнопка **Override stale** (применить устаревшие) с числом устаревших правок. Нажимайте ее, только если этот текст все равно нужен. Marinara попросит подтверждение, а затем добавит устаревший текст в поле, а не заменит текст, который больше не совпадает.

## Просмотр и правка данных агентов

Редактор **Agent Suite** показывает все, что сохранили агенты этого чата: данные трекеров, например текущую сцену, присутствующих персонажей и характеристики персоны, а также сохраненные результаты собственных агентов. С его помощью можно исправить неверное имя, поправить характеристику или навести порядок в беспорядочном тексте.

1. Откройте **Chat Settings** и прокрутите до **Agents**.
2. Нажмите **Agent Suite**.
3. Выберите агента в списке слева.

Справа появляются редактируемые блоки, разбитые максимум на три группы: **Stored Memory** (сохраненная память), **Tracker Data** (данные трекера, только для агентов-трекеров) и **Recent Outputs** (последние результаты, только для собственных агентов). У агентов, которые ничего не отслеживают, есть только **Stored Memory**.

Каждый блок – это редактор текста или JSON. Блоки JSON показывают номера строк и сразу сообщают о неправильном JSON. Кнопка **Save** (сохранить) неактивна, пока JSON не разбирается. Чтобы искать по всем данным трекеров или править их как поля, нажмите **Open in State Editor** в заголовке **Tracker Data**. См. [State Editor](../roleplay/hud-and-trackers.md#the-state-editor).

Изменив блок, нажмите **Save**, чтобы сохранить его, или **Reset** (сбросить), чтобы вернуть сохраненное значение.

### Переписывание блока с помощью ИИ

1. Нажмите **AI Edit** (правка с помощью ИИ) на блоке.
2. Чтобы изменить только часть, сначала выделите этот текст. Без выделения переписывается весь блок.
3. Введите инструкцию, например "исправь искаженные имена персонажей, ее зовут Mira".
4. Необязательно: нажмите **Add Context** (добавить контекст), чтобы приложить карточки персонажей или записи лорбука, – так ИИ поймет, что означают эти данные.
5. Выберите подключение (сервис ИИ и модель), которое выполнит переписывание.
6. Нажмите **Rewrite** (переписать).

Результат попадает в блок как несохраненный черновик. Проверьте его, затем нажмите **Save** или **Reset**.

- Пока агенты этого чата еще работают, сохранение ждет их завершения.
- **Clear memory** (очистить память) появляется в **Stored Memory**, только когда у агента есть сохраненные данные. Кнопка сразу удаляет все, что этот агент сохранил для этого чата, и отменить это нельзя. Marinara сначала попросит подтверждение.
- У агента **Narrative Director** сохраненные спойлеры скрыты. Чтобы посмотреть и отредактировать их, нажмите **Reveal spoilers** (показать спойлеры).

## Просмотр сохраненных вставок в промпт

Перед генерацией ответа некоторые агенты-писатели добавляют текст в промпт. Так обычно работают **Prose Guardian**, **Narrative Director** и собственные агенты вставки. Панель **Cached prompt injections** (сохраненные вставки в промпт) показывает этот текст для самого последнего ответа. Она нужна для разбора проблем.

Перед началом: включите **Debug mode** (режим отладки), см. [Обзор агентов](agents-overview.md#tell-whether-an-agent-ran). В чате Roleplay откройте вкладку **Injections** (вставки) в **Agent activity** (активность агентов). См. [Agent activity](../roleplay/getting-started.md#agent-activity).

Каждую вставку можно развернуть, чтобы прочитать и отредактировать текст, нажать значок **Save**, чтобы сохранить правку, или нажать значок **Re-run** (запустить заново), чтобы этот агент написал новую.

Вставки **Knowledge Retrieval** и **Knowledge Router** здесь заново запустить нельзя. Правки и повторные запуски вступают в силу, только если вы сгенерируете тот же ответ заново. Повторный запуск использует историю чата на тот момент, а не более новые сообщения.
