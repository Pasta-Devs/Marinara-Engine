# Одобрение записей агентов и редактор Agent Suite

В этом руководстве вы узнаете, как проверять то, что агенты записывают во время чата, и как этим управлять. Агенты – это небольшие помощники на базе ИИ, которые работают рядом с ответами. Здесь разобраны переключатель **Review Agent Outputs** (проверять результаты агентов), два окна проверки, редактор **Agent Suite** (набор агентов) и панель **Cached prompt injections** (сохраненные вставки в промпт).

## Переключатель **Review Agent Outputs**

Некоторые агенты записывают в чат новые данные. Агент Lorebook может добавить записи в лорбук – набор фактов о вашем мире. Агент сводки может сохранить сводку чата. По умолчанию часть таких записей сохраняется автоматически. Переключатель **Review Agent Outputs** дает возможность сначала проверить каждую запись.

Где найти переключатель:

1. Откройте чат, для которого нужен контроль.
2. Откройте **Chat Settings** (настройки чата).
3. Прокрутите до раздела **Agents**.
4. Включите переключатель **Review Agent Outputs**.

Когда **Review Agent Outputs** включен, обновления лорбука, обновления сводки и другие проверяемые записи агентов ждут вашего одобрения и только потом сохраняются. Когда он выключен, обновления лорбука и сводки могут сохраняться автоматически.

Изменения карточки персонажа – особый случай. Они всегда запрашивают одобрение, даже если **Review Agent Outputs** выключен. Эту защиту отключить нельзя.

## Окно подтверждения записей агента

Когда переключатель **Review Agent Outputs** включен и агент предлагает запись в лорбук или сводку, открывается окно проверки. Его заголовок – **Review Lorebook Update** или **Review Summary Update**, в зависимости от типа записи.

В окне видно:

- Имя агента, который сделал предложение.
- Поле **Proposed Text** с текстом, который можно отредактировать перед сохранением.
- Для записей в лорбук – короткое напоминание держать каждую запись под заголовком `###`.

Внизу окна три варианта действий:

- **Accept** (принять): сохраняет текст в чат вместе со всеми правками.
- **Regenerate** (сгенерировать заново): запускает заново только этого агента, чтобы получить новое предложение.
- **Discard** (отклонить): выбрасывает предложение без сохранения.

Если в очереди ждет несколько предложений, окно показывает, сколько их осталось. После обработки текущего оно открывается снова для следующего.

## Проверка изменений карточки персонажа

Агент **Card Evolution Auditor** предлагает правки полей карточки персонажа, исходя из того, что произошло во время игры в режиме Roleplay. Встроенный инструмент `update_about_me` режима Conversation тоже может предложить изменение публичного раздела About Me. Ни один из этих путей не меняет карточку сам: оба открывают окно **Review Character Card Updates**, и решение остается за вами.

Окно перечисляет все предложенные правки. Для каждой правки видно:

- Поле карточки, которое она затрагивает (например, описание, личность или внешность).
- Короткую причину изменения, если агент ее указал.
- Блок **Before** с текущим текстом.
- Поле **After** с новым текстом. Этот текст можно отредактировать до одобрения.

Доступные действия:

- **Approve** (одобрить): применяет правки. Число на кнопке показывает, сколько правок будет применено. После одобрения номер версии персонажа растет, а в историю версий добавляется запись.
- **Regenerate**: запускает агента заново для нового набора предложений.
- **Reject** (отклонить): убирает предложения, не меняя карточку.

Бывает, что карточка изменилась уже после того, как агент составил предложение. Тогда приложение помечает правку как устаревшую (**stale**) и делает ее бледной. Если устаревшие правки есть, появляется кнопка **Override stale** с их числом. Нажимайте ее только тогда, когда этот текст все равно нужен. Приложение сначала попросит подтверждение. Затем устаревший текст добавляется в поле, а не заменяет текст, который больше не совпадает.

## Редактор **Agent Suite** и переписывание с помощью ИИ

Редактор **Agent Suite** показывает все, что сохранили агенты этого чата, и позволяет это менять. Сюда входят данные трекеров – текущая сцена, присутствующие персонажи, характеристики персоны. Сюда же входят сохраненные результаты ваших собственных агентов. Неверное имя, ошибочную характеристику или мешанину в сохраненном тексте можно исправить руками или с помощью ИИ.

Как его открыть:

1. Откройте **Chat Settings**.
2. Прокрутите до раздела **Agents**.
3. Нажмите кнопку **Agent Suite**.

Слева – список агентов, активных в этом чате. Выберите одного, чтобы увидеть его данные. Справа появляются редактируемые блоки. Они сгруппированы в **Stored Memory** (сохраненная память), **Tracker Data** (данные трекера, только для трекеров) и **Recent Outputs** (последние результаты, только для собственных агентов). У агентов, которые ничего не отслеживают, есть только **Stored Memory**.

Каждый блок – это редактор текста или формата JSON. После правки блока:

- Нажмите кнопку **Save** (сохранить), чтобы сохранить изменение.
- Нажмите кнопку **Reset** (сбросить), чтобы отменить несохраненную правку и вернуть прежнее значение.

Другой вариант: блок может переписать ИИ.

1. Нажмите кнопку **AI Edit** (правка с помощью ИИ) на нужном блоке.
2. Чтобы изменить только часть текста, сначала выделите ее в редакторе. Без выделения переписывается весь блок.
3. Введите инструкцию, например "исправь искаженные имена персонажей, ее зовут Mira".
4. По желанию: нажмите кнопку **Add Context** (добавить контекст), чтобы приложить карточки персонажей или записи лорбука. Так ИИ лучше поймет, о чем эти данные.
5. Выберите подключение – провайдера ИИ и модель, которые выполнят переписывание.
6. Нажмите кнопку **Rewrite** (переписать).

Новый текст попадает в блок как несохраненный черновик. Проверьте его и нажмите **Save**, чтобы оставить, или **Reset**, чтобы отбросить.

Несколько замечаний:

- Если агенты этого чата еще работают, сохранение приостановлено до их завершения.
- В разделе **Stored Memory** есть одна кнопка **Clear memory** (очистить память). Она появляется только тогда, когда у агента есть сохраненные данные. Кнопка сразу удаляет все, что этот агент сохранил для этого чата, и отменить это нельзя. Приложение сначала попросит подтверждение.
- У агента **Narrative Director** сохраненные спойлеры скрыты. Чтобы посмотреть и отредактировать их, нажмите **Reveal spoilers** (показать спойлеры).

## Панель **Cached prompt injections**

Перед тем как сгенерировать ответ, некоторые агенты добавляют текст в промпт – в текст, который Marinara отправляет ИИ. Так обычно работают **Prose Guardian**, **Narrative Director** и собственные агенты вставки. Панель **Cached prompt injections** показывает этот добавленный текст и нужна для разбора проблем. Она находится на вкладке **Injections** (вставки) раздела **Agent activity** (активность агентов) в чате Roleplay. Вкладка видна, когда включен **Debug mode** (режим отладки). См. [Активность агентов](../roleplay/getting-started.md#agent-activity). Она относится к самому последнему ответу.

Для каждой сохраненной вставки доступно:

- Развернуть ее, чтобы прочитать и отредактировать текст.
- Нажать значок **Save**, чтобы сохранить правку.
- Нажать значок **Re-run**, чтобы этот агент написал вставку заново.

Вставки агентов **Knowledge Retrieval** и **Knowledge Router** из этой панели заново запустить нельзя. Правки и повторные запуски вступают в силу только тогда, когда вы генерируете тот же ответ заново. Повторный запуск использует историю чата на тот момент, а не более новые сообщения.
