# Создание своих агентов

В этом руководстве вы узнаете, как собрать своего агента в приложении Marinara Engine. Агент – это небольшой помощник ИИ, который работает автоматически рядом с чатом. Здесь показано, как задать фазу, возможности, тип результата, ключевые слова активации, инструменты и промпт. В конце разобран один полный пример.

Если про агентов вы читаете впервые, начните с руководства [Агенты: помощники ИИ в чатах](agents-overview.md), а потом возвращайтесь сюда.

## Когда нужен свой агент

Marinara Engine предлагает много официальных агентов, готовых к скачиванию. Прежде чем собирать своего агента, посмотрите [Справочник агентов для скачивания](built-in-agents.md) и открытый репозиторий пакетов [Pasta-Devs/Marinara-Agents](https://github.com/Pasta-Devs/Marinara-Agents). Возможно, нужный агент уже есть в каталоге, а официальные манифесты служат рабочими примерами пакета.

Свой агент нужен тогда, когда встроенные не покрывают задачу. Веские причины:

- Нужен помощник с собственными инструкциями и манерой речи.
- Нужно вставлять определенную заметку в каждый промпт.
- Нужно переписывать каждый ответ в определенном стиле.
- Нужно, чтобы агент вызывал ваш собственный инструмент.

Если установленный официальный агент близок к задуманному, лучше скопировать его. В панели **Agents** (агенты) наведите курсор на карточку и нажмите кнопку **Copy agent**. Так получится редактируемая копия.

## Перед началом

До сборки важны два факта:

1. Агенты настраиваются для каждого чата, а не для персонажа. Собранный в библиотеке агент сам по себе не работает. Его нужно добавить в чат и включить переключатель **Enable Agents** (включить агентов) в панели **Chat Settings** (настройки чата).
2. Свои агенты работают во всех режимах чата: Roleplay, Game Mode и Conversation. Официальные пакеты доступны только в поддерживаемых режимах, а свои агенты остаются доступны везде.

## Создание своего агента

Чтобы собрать нового агента с нуля, выполните эти шаги.

1. Откройте панель **Agents**.
2. Нажмите кнопку **New** (иконка плюса) в верхней части.
3. Редактор агента откроется на всю страницу с пустой заготовкой.
4. Введите название в поле заголовка сверху, например `Weather Reporter`.
5. Заполните поля **Description** (описание) и **Author** (автор), чтобы потом вспомнить назначение агента.
6. Выберите **Pipeline Phase** (фаза конвейера) – о ней ниже.
7. Включите нужные возможности в разделе **Custom Agent Abilities** (возможности своего агента).
8. Выберите **Result Type** (тип результата), подходящий тому, что агент должен выдавать.
9. Впишите инструкции агента в поле **Prompt Template** (шаблон промпта).
10. Нажмите кнопку **Save** (сохранить) в верхней панели. Должен появиться зеленый значок **Saved**.

Новый агент теперь виден в разделе **Custom Agents** панели **Agents**. Чтобы его использовать, откройте чат, перейдите в **Chat Settings**, включите **Enable Agents** и добавьте агента из раздела **Custom Agents** там же.

## Pipeline Phase

Параметр **Pipeline Phase** задает, когда агент работает. Выберите одну из трех кнопок:

- **Pre-Generation**: работает до ответа ИИ. Может добавить контекст или изменить промпт.
- **Parallel**: работает одновременно с ответом. Готовый ответ такому агенту не виден.
- **Post-Processing**: работает после того, как ответ готов. Может прочитать ответ, а для некоторых типов результата – и отредактировать его.

Некоторые типы результата задают фазу принудительно. При выборе **Text Rewrite** фаза переключается на **Post-Processing**. При выборе **Prompt Patch** – на **Pre-Generation**. Иначе такая работа просто не имеет смысла.

У своих агентов в фазе **Post-Processing** появляется раздел **Turn Data Access** (доступ к данным хода). В нем два необязательных переключателя: **Pre-generation injections** и **Parallel agent results**. Включите их, чтобы агент видел результаты других агентов за тот же ход. Оставьте выключенными, чтобы агент работал изолированно.

## Custom Agent Abilities

Раздел **Custom Agent Abilities** – это возможности, которые включаются вручную. Пока переключатель выключен, возможность заблокирована. Благодаря этому свой агент по умолчанию безопасен. Доступны такие возможности:

| Возможность | Что агент может делать |
|---|---|
| **Create lorebooks** | Создать новый лорбук от имени агента, если для его записей о мире не указан целевой лорбук. |
| **Edit lorebooks** | Писать записи лорбука и выдавать результаты обновления лорбука. |
| **Edit messages** | Заменять текст сгенерированного сообщения переписанным или добавлять к нему варианты продолжения. |
| **Edit trackers** | Обновлять состояние трекеров: игры, персонажа, персоны или своего трекера. |
| **Frontend styling** | Применять временный визуальный эффект во время генерации. |
| **Change chat backgrounds** | Менять фон, выбранный для чата, и сохранять этот выбор. |
| **Change character sprites** | Менять выражения лица персонажа и персоны, которые видны в чате. |
| **Control media playback** | Управлять воспроизведением Spotify, YouTube или локальной музыки. |
| **Control haptic devices** | Отправлять ограниченные команды на подключенное тактильное устройство. |
| **Edit About Me details** | Менять текст **About Me** для конкретного чата. Изменения в публичной карточке по-прежнему требуют отдельного подтверждения. |
| **Image generation** | Запускать генерацию изображений по промпту для картинки. |
| **Vectors/embeddings** | Использовать контекст векторов или эмбеддингов. Векторы – это способ искать текст по смыслу. |
| **Main prompt edits** | Редактировать промпт, который уходит основной модели ИИ. |

Лорбук – это набор заметок о мире, которые ИИ может подтянуть в сцену. Трекер – это живая панель, где хранятся факты: характеристики, настроение или место.

Если включить **Edit lorebooks**, появится раздел **Lorebook Writer**. Включите **Allow lorebook entry writes** и выберите один лорбук в раскрывающемся списке **Target lorebook**. Писать агент сможет только в этот лорбук.

## Result Type

Параметр **Result Type** сообщает Marinara, как читать вывод агента. Большинство типов результата ожидают ответ в формате JSON. JSON – это простой текстовый формат с фигурными скобками и кавычками. Каждому типу результата нужна соответствующая возможность из таблицы выше.

| Тип результата | Что делает | Нужная возможность |
|---|---|---|
| **Context Injection** | Добавляет текст до генерации или записывает заметку после нее. | Не нужна |
| **Text Rewrite** | Работает после ответа и заменяет текст сообщения. | **Edit messages** |
| **Lorebook Update** | Создает или обновляет записи лорбука. | **Edit lorebooks** |
| **Character Tracker** | Обновляет трекер персонажей (кто присутствует в сцене). | **Edit trackers** |
| **Persona Stats** | Обновляет характеристики, статус и инвентарь персоны. | **Edit trackers** |
| **Custom Tracker** | Заменяет поля вашего собственного трекера. | **Edit trackers** |
| **Game State** | Обновляет игровые данные вроде состояния мира. | **Edit trackers** |
| **Image Prompt** | Просит генератор изображений нарисовать сцену. | **Image generation** |
| **Prompt Patch** | Добавляет разделы промпта, ставит их в начало или заменяет. | **Main prompt edits** |
| **Frontend Style** | Применяет временный эффект оформления. | **Frontend styling** |
| **Background Change** | Выбирает доступный фон чата и сохраняет выбор. | **Change chat backgrounds** |
| **Sprite Change** | Меняет выражения лица персонажа и персоны, которые видны в чате. | **Change character sprites** |
| **Spotify Control** | Управляет воспроизведением Spotify. | **Control media playback** |
| **YouTube Control** | Управляет воспроизведением YouTube. | **Control media playback** |
| **Local Music Control** | Управляет воспроизведением из вашей локальной коллекции музыки. | **Control media playback** |
| **Haptic Command** | Отправляет ограниченную команду на подключенное тактильное устройство. | **Control haptic devices** |
| **About Me Update** | Обновляет текст **About Me** для чата и предлагает публичные правки. | **Edit About Me details** |
| **Interactive Choices** | Добавляет варианты продолжения к сгенерированному сообщению. | **Edit messages** |

Проще всего начать с **Context Injection**. Здесь не нужен ни один переключатель возможностей, а формат вывода ничем не ограничен. Этот тип подходит, когда агент должен просто добавить короткую заметку в промпт или записать сводку.

Если тип результата серый и недоступен, значит нужная возможность еще не включена. Включите соответствующий переключатель в разделе **Custom Agent Abilities** – и тип результата станет доступен.

### Настройки графических агентов для отдельного чата

У агента с возможностью **Image generation** на карточке в разделе **Chat Settings → Agents → Custom Agents** появляются два дополнительных элемента управления рядом с выбором шаблона промпта, доступным каждому пользовательскому агенту:

- **Image Connection** — переопределяет подключение для генерации изображений только в этом чате. Оставьте **Agent default**, чтобы использовать подключение из собственных настроек агента. Выбранный для чата **Image Style** также применяется к изображениям пользовательского агента, поэтому в разных чатах один агент может создавать разные изображения без дублирования.
- **Camera button** — немедленно создает изображение этим агентом, не ожидая его ключевых слов активации. Промпт по-прежнему пишет сам агент; если его шаблон решит не создавать промпт, вместо изображения появится уведомление об ошибке.

## Activation Keywords

По умолчанию свой агент работает в обычном для него ритме. Раздел **Activation Keywords** (ключевые слова активации) позволяет пропускать агента, пока сцена ему не подходит. Так экономятся токены и деньги. Токен – это небольшой кусочек текста, который считает ИИ.

Порядок настройки:

1. В разделе **Activation Keywords** впишите по одному ключевому слову или фразе в строку. Например:

```
tavern
secret door
moonlit ritual
```

2. В поле **Scan Depth** укажите, сколько последних сообщений просматривать. По умолчанию 5. Максимум 200.
3. Теперь агент работает только тогда, когда хотя бы одно ключевое слово встречается в этих последних сообщениях.

Оставьте поле ключевых слов пустым, чтобы агент работал каждый раз в обычном ритме.

## Подключение инструментов (Function Calling)

Агент может вызывать инструменты. Инструмент – это функция, которую ИИ запускает, чтобы что-то получить или изменить, а затем прочитать результат. Это же называют вызовом функций.

Чтобы подключить инструменты, откройте раздел **Tools / Function Calling** и включите или выключите каждый из них. В списке есть встроенные инструменты и те, что вы сделали сами. О сборке собственного инструмента читайте в руководстве [Собственные инструменты и вызов функций](../extending/custom-tools.md).

Инструменты работают только тогда, когда сам чат это разрешает. В панели **Chat Settings** откройте раздел **Function Calling** и включите **Enable Tool Use**. Без этой настройки чата инструменты агента остаются выключенными, даже если включить их здесь.

Импортированные файлы агентов не дают доступа к инструментам. После импорта агента проверьте его промпт и настройки, а затем сами выберите инструменты, которые ему нужны.

## Named prompt options

Один агент может хранить несколько вариантов промпта – за это отвечает возможность **Named prompt options** (именованные варианты промпта). Отдельный чат выбирает один вариант, и править агента для всех чатов не приходится.

Чтобы добавить вариант:

1. В разделе **Prompt Template** найдите **Named prompt options**.
2. Нажмите кнопку **Add option**.
3. Дайте варианту название и короткое описание.
4. Впишите полный текст промпта для этого варианта.

Когда агента добавляют в чат, там появляется раскрывающийся список **Prompt Mode** с вашими именованными вариантами. Если вариантов нет, меню чата показывает только промпт по умолчанию.

## Другие настройки, которые можно изменить

Часть настроек у своих агентов такая же, как у встроенных:

- **Connection Override**: выберите для этого агента другое подключение ИИ. Например, более дешевую модель для фоновой работы. Оставьте поле пустым, чтобы использовать подключение чата.
- **Agent Budget**: задайте **Context Size** (сколько последних сообщений читает агент, по умолчанию 5). Там же задается **Max Output Tokens** – запас места для вывода, по умолчанию 4096, в диапазоне от 128 до 32768.
- **Add as Prompt Section**: включите этот переключатель, чтобы последний вывод агента стал разделом, который можно вставить в пресет промпта.

Макросы вроде `{{user}}` и `{{char}}` работают внутри поля **Prompt Template**. Полный список – в руководстве [Макросы промптов](../prompts/macros.md).

## Разобранный пример

Ниже полностью готовый свой агент, который переписывает каждый ответ на британский английский.

Настройка в редакторе:

1. Назовите его `British English Editor`.
2. В разделе **Custom Agent Abilities** включите **Edit messages**.
3. В разделе **Result Type** выберите **Text Rewrite**. Фаза сама переключится на **Post-Processing**.
4. Вставьте это в поле **Prompt Template**:

```
You are a copy editor. Rewrite the latest reply into British English.
Change spelling and vocabulary only. Do not change the meaning, tone, or events.
Return JSON with an "editedText" field holding the full rewritten reply,
and a "changes" array of short notes describing what you changed.
```

5. Нажмите кнопку **Save**.
6. Откройте чат в режиме Roleplay, перейдите в **Chat Settings**, включите **Enable Agents** и добавьте `British English Editor` из раздела **Custom Agents**.

После каждого ответа агент возвращает такой JSON:

```
{"editedText":"The colour of the harbour caught her eye.","changes":[{"description":"color to colour, harbor to harbour"}]}
```

Marinara читает `editedText` и подставляет его в ответ. Сообщение отображается на британском английском. Заметки из `changes` показываются как короткая сводка того, что агент поправил.

## Импорт и экспорт агентов

Своего агента можно передать другим в виде файла.

Чтобы экспортировать агента из редактора, нажмите кнопку **Export agent** (иконка загрузки) в верхней панели. Промпт и настройки агента сохранятся как пакет. Описания своих инструментов в пакеты агентов не входят никогда.

Чтобы экспортировать сразу несколько агентов, нажмите **Select agents** в панели **Agents**, отметьте нужных и экспортируйте группу.

Импорт внешних агентов по умолчанию заблокирован. Сначала откройте **Settings → Advanced → Danger Zone** и включите **Allow custom Agent imports**. Этому переключателю не нужны правки в `.env`. Он влияет только на агентов из файлов, папок и своих репозиториев: агенты, созданные в Marinara, и официальные агенты, установленные через **Download Agents**, остаются доступны как обычно.

Для импорта откройте панель **Agents** и нажмите **Import agents** для одного файла или **Import agent folder**, чтобы выбрать целую папку. Перед сохранением Marinara показывает список запрашиваемых прав. Одобряйте только те возможности, которые агенту действительно нужны; неотмеченные остаются заблокированными. Каждый импорт файла получает новый собственный идентификатор, поэтому импортированный агент не может заменить проверенного агента с тем же внутренним типом.

Для безопасности Marinara игнорирует вложенные функции, стирает выбор инструментов из импортированных настроек, очищает временный CSS перед применением и проверяет одобренные возможности, прежде чем импортированный агент сможет менять сообщения, трекеры, лорбуки, фоны, спрайты, медиа, тактильные устройства, данные **About Me**, промпты или сгенерированные изображения. Доверенные функции импортируйте отдельно из раздела **Function Calls**, проверяйте их и только потом сами подключайте к агенту. Если выключить переключатель в **Danger Zone** обратно, внешние импортированные агенты перестанут работать; на своих и официальных агентов это не влияет.
