# Профили стиля изображений

Профиль стиля – это многоразовый "фирменный стиль", который дополняет каждый промпт изображения перед тем, как Marinara отправит его вашему сервису изображений. С ним аватары, портреты, селфи, фоны, иллюстрации и спрайты выглядят единообразно. Это руководство показывает, как выбрать, изменить и проверить профиль.

## Что такое профиль стиля

Любое создаваемое изображение начинается с текстового промпта: аватары, портреты, селфи в режиме Conversation, фоны сцен, иллюстрации и спрайты. Профиль стиля – это сохраненный набор правил, которые Marinara добавляет к этому промпту. Профиль может добавить положительные слова (что нужно получить), отрицательные слова (чего нужно избежать) и предпочтительную форму записи промпта. Один профиль выбирается как стандартный для всего приложения. Для отдельного чата или отдельной модели изображений его можно заменить.

Чтобы найти редактор, откройте **Settings → Generations → Image Generation** (настройки → генерации → генерация изображений) и прокрутите до раздела **Style Profiles** (профили стиля).

## Встроенные профили

В Marinara есть 10 встроенных профилей стиля. По умолчанию выбран **Auto**. Любой из них можно изменить, а встроенный профиль – в любой момент вернуть к исходным значениям.

Термины, которые встретятся ниже:

- SDXL – это Stable Diffusion XL, популярная открытая модель изображений, которую можно запускать на своем компьютере или через облачный сервис.
- Checkpoint – это один файл обученной модели изображений. Здесь в качестве примеров упоминаются Illustrious, Pony и NovelAI.
- Danbooru – это большой сайт с аниме-изображениями. Его короткие теги через запятую, например "1girl, long hair, smile", стали привычным способом писать промпты для аниме-моделей.

Встроенные профили:

- **Off**: никакого фирменного стиля не добавляет. Промпт уходит почти в том виде, в котором его набрали.
- **Auto**: выводит единый вид из персонажа, игры, сцены и выбранной модели изображений. Это профиль по умолчанию.
- **Anime**: общие теги в аниме-стиле для чистого рисунка персонажей.
- **Danbooru / Illustrious**: теги в стиле Danbooru для аниме-checkpoint на базе SDXL – Illustrious, Pony, NovelAI.
- **Realistic SDXL**: реализм обычными фразами для моделей SDXL.
- **Photorealistic**: промпт в фотографической манере с достоверной кожей, светом и материалами.
- **Cinematic**: драматичный свет и выразительная композиция для ключевых кадров.
- **Digital Painting**: мазок концепт-арта и продуманный свет.
- **Painterly Fantasy**: мягкая живописная фэнтезийная иллюстрация.
- **Z-Image Turbo Narrative**: короткая проза для моделей Z-Image Turbo, которые хорошо понимают обычные предложения.

## Смена общего стиля

Профиль по умолчанию действует на все изображения, пока его не заменит выбор чата или модели изображений.

1. Откройте **Settings → Generations → Image Generation → Style Profiles**.
2. Раскройте список **Default style** (стиль по умолчанию).
3. Выберите профиль.

Выбор сохраняется сразу, и новые изображения используют его.

## Копия профиля и его настройка

Встроенный профиль можно править прямо на месте или с помощью **Clone** (создать копию) сохранить оригинал и собрать свой.

1. Раскройте список **Editing** (редактируемый профиль) и выберите профиль, наиболее близкий к нужному.
2. Нажмите **Clone**. Marinara делает копию, открывает ее для правки и сразу назначает стилем по умолчанию для всего приложения.
3. В поле **Name** (название) впишите узнаваемое имя.
4. Выберите значение **Prompt grammar** (грамматика промпта) – о нем в следующем разделе.
5. Заполните поле **Style text** (текст стиля) обычным описанием нужного вида. Когда промпт изображения пишет ИИ (так работают агент Illustrator, селфи и Noodle), он следует вашему тексту стиля, а не копирует его. Для других изображений, например аватаров, текст стиля может добавляться как есть.
6. Добавьте **Positive tags** (нужные слова) и **Negative tags** (слова, которых нужно избежать).
7. Раскройте раздел **Per-image tags** (теги по типам изображений) и добавьте отдельные теги для каждого типа изображения: аватар, портрет, селфи, фон, иллюстрация, спрайт.
8. На шаге 2 копия стала стилем по умолчанию для всего приложения. Чтобы вернуть эту роль другому профилю, раскройте список **Default style** и выберите нужный.

Профилями помогают управлять две кнопки:

- **Reset** (сбросить) работает только для встроенных профилей. Она возвращает встроенный профиль к исходным значениям.
- **Delete** (удалить) работает только для созданных вами профилей и только пока профилей больше одного.

## Режимы грамматики промпта

**Prompt grammar** сообщает Marinara, в каком виде модель изображений лучше читает промпт. Выберите режим под свою модель.

- **Hybrid**: смесь предложений и тегов. Безопасный универсальный выбор.
- **Danbooru tags**: короткие теги через запятую в стиле Danbooru. Лучший вариант для аниме-checkpoint на базе SDXL – Illustrious, Pony, NovelAI.
- **Tags**: короткие ключевые слова через запятую, без соглашений Danbooru.
- **Natural language**: обычные предложения. Лучший вариант для моделей, понимающих прозу: DALL-E и модели Z-Image Turbo.

## Раздел Test bench

**Test bench** (тестовый стенд) внутри редактора Style Profiles показывает, что именно отправит Marinara, и при этом настоящее изображение не создается.

1. Выберите **Image kind** (тип изображения) – например, portrait или background.
2. Наберите примерный промпт в поле **Sample input** (пример ввода).
3. Прочитайте содержимое полей **Final positive prompt** (итоговый положительный промпт) и **Final negative prompt** (итоговый отрицательный промпт).

Test bench также выводит короткую заметку об очистке. Если менять нечего, там написано "No cleanup needed for this sample." Если промпт изменен, заметка сообщает, сколько повторов и неуместных фрагментов удалено.

## Как Marinara очищает промпт

Перед отправкой любого запроса на изображение Marinara собирает промпт с учетом активного профиля. При сборке:

- удаляются почти одинаковые теги, например повторяющийся тег качества;
- простые отрицательные фразы вроде "avoid text" или "no watermark" переносятся в отрицательный промпт;
- для фонов, иллюстраций и селфи ваши формулировки сохраняются, а для портретов, аватаров и спрайтов текст сводится к коротким визуальным тегам, которые Marinara распознает;
- добавляются теги профиля для того типа изображения, который создается.

## Пример до и после

Допустим, вы выбрали профиль **Danbooru / Illustrious**, задали **Image kind** portrait и набрали в поле **Sample input**:

```
masterpiece, masterpiece, red-haired knight, no watermark
```

Тогда Test bench покажет такой **Final positive prompt**:

```
detailed eyes, solo, upper body, portrait, looking at viewer, anime screencap, masterpiece, best quality, absurdres
```

Произошло три вещи:

- Фраза "no watermark" ушла из положительного промпта в **Final negative prompt**. Заметка об очистке учитывает это изменение.
- Профиль добавил свои теги стиля, свои теги для портрета и свои теги качества. Слово "masterpiece" в результате пришло из тегов профиля, а не из набранного текста.
- Набранный текст был сведен к главному. Для портретов сохраняются только фрагменты, которые распознаются как ясные визуальные приметы. Фраза "red-haired knight" к ним не относится, поэтому она отброшена.

Если слова о персонаже исчезают для портрета, аватара или спрайта, попробуйте тип изображения **illustration**. Для него ваши формулировки сохраняются.

## Порядок приоритета: чат, подключение, общий стиль

Marinara может взять профиль стиля из трех мест. Побеждает самый частный выбор.

1. Профиль, выбранный для текущего чата или игры.
2. Профиль стиля, заданный у модели изображений в разделе **Local image defaults** (стандартные настройки локальных изображений) ее редактора.
3. Общий **Default style** в **Settings**.

Раздел **Local image defaults** появляется только для AUTOMATIC1111 / SD Web UI, ComfyUI и NovelAI. Для всех остальных сервисов выбор переходит к общему **Default style**. Чтобы задать профиль для отдельной модели, откройте модель изображений, раскройте **Local image defaults** и выберите профиль в списке профилей стиля. Оставьте **Use global default** (использовать общее значение по умолчанию), чтобы следовать общему выбору. Если Marinara может угадать подходящий профиль по названию модели, появляется кнопка "Use ...", которая применяет его одним нажатием.
