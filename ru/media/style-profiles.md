# Профили стиля изображений

В этом руководстве вы узнаете, что такое профили стиля изображений в приложении Marinara Engine. Профиль стиля – это многоразовый "фирменный стиль", который дополняет каждый промпт изображения (текст, который Marinara отправляет ИИ) перед отправкой провайдеру генерации изображений. Так аватары, портреты, селфи, фоны, иллюстрации и спрайты выглядят одинаково.

## Что такое профиль стиля

Marinara Engine генерирует изображения разного назначения: аватары персонажей и персон, портреты, селфи в режиме Conversation, фоны сцен, иллюстрации внутри сцены и спрайты персонажей. Любое из этих изображений начинается с текстового промпта.

Профиль стиля – это сохраненный набор правил, которые Marinara добавляет к этому тексту. Профиль может добавить положительные слова (что нужно получить), отрицательные слова (чего нужно избежать) и предпочтительную форму записи промпта. Благодаря этому все изображения держатся одного вида, и одни и те же слова о стиле не приходится набирать заново.

Один профиль выбирается как стандартный для всего приложения. Для отдельного чата или отдельного подключения для изображений его можно заменить. Обо всем этом – ниже.

Редактор открывается так.

1. Откройте панель **Settings** (настройки).
2. Перейдите на вкладку **Generations** (генерация).
3. Найдите раздел **Image Generation** (генерация изображений).
4. Прокрутите до раздела **Style Profiles** (профили стиля).

## Встроенные профили

Marinara поставляется с 10 встроенными профилями стиля. По умолчанию выбран **Auto**. Любой из них можно изменить, а встроенный профиль – в любой момент вернуть к исходным значениям.

Несколько терминов, которые встретятся ниже:

- SDXL – это Stable Diffusion XL, популярная открытая модель изображений. Ее запускают на своем компьютере или через облачный сервис.
- Checkpoint – это один файл обученной модели изображений. Разные файлы checkpoint скачивают ради разной манеры рисунка. В профилях упоминаются Illustrious, Pony и NovelAI.
- Danbooru – это большой сайт с аниме-изображениями. Его короткие теги через запятую (например, "1girl, long hair, smile") стали привычным способом писать промпты для аниме-моделей.

Встроенные профили:

- **Off**: никакого фирменного стиля не добавляет. Промпт уходит почти в том виде, в котором его набрали.
- **Auto**: выводит единый вид из персонажа, игры, сцены и выбранной модели изображений. Это профиль по умолчанию.
- **Anime**: общие теги в аниме-стиле для чистого рисунка персонажей.
- **Danbooru / Illustrious**: теги в стиле Danbooru для аниме-checkpoint на базе SDXL – Illustrious, Pony, NovelAI.
- **Realistic SDXL**: реализм обычными фразами для моделей SDXL.
- **Photorealistic**: промпт в фотографической манере с достоверной кожей, светом и материалами.
- **Cinematic**: драматичный свет и выразительная композиция для ключевых кадров.
- **Digital Painting**: мазок концепт-арта и продуманный свет.
- **Painterly Fantasy**: мягкая живописная фэнтезийная иллюстрация.
- **Z-Image Turbo Narrative**: короткая проза для моделей Z-Image Turbo, которые хорошо понимают обычные предложения.

## Смена общего стиля

Общий профиль по умолчанию действует на все создаваемые изображения, пока его не заменит выбор чата или подключения. Меняется он так.

1. Откройте панель **Settings**, вкладку **Generations**, раздел **Image Generation**, затем **Style Profiles**.
2. Раскройте список **Default style** (стиль по умолчанию).
3. Выберите профиль для всего приложения.

Выбор сохраняется сразу. Новые изображения используют выбранный профиль.

## Копия профиля и его настройка

Встроенный профиль можно править прямо на месте, но кнопка **Clone** (создать копию) позволяет сохранить оригинал и собрать свою версию. Свой профиль создается так.

1. Раскройте список **Editing** (редактируемый профиль) и выберите профиль, наиболее близкий к нужному.
2. Нажмите кнопку **Clone**. Marinara делает копию, открывает ее для правки и сразу назначает стилем по умолчанию для всего приложения.
3. В поле **Name** (название) впишите узнаваемое имя.
4. Выберите значение в списке **Prompt grammar** (грамматика промпта) – о нем в следующем разделе.
5. Заполните поле **Style text** (текст стиля) обычным описанием нужного вида. Когда промпт изображения пишет ИИ (так работают агент Illustrator, селфи и Noodle), он следует вашему тексту стиля, а не копирует его. Для других изображений, например аватаров, текст стиля может добавляться как есть.
6. Добавьте **Positive tags** (нужные слова) и **Negative tags** (слова, которых нужно избежать).
7. Раскройте раздел **Per-image tags** (теги по типам изображений) и добавьте отдельные теги для каждого типа: аватар, портрет, селфи, фон, иллюстрация, спрайт.
8. На шаге 2 копия стала стилем по умолчанию для всего приложения. Чтобы вернуть эту роль другому профилю, раскройте список **Default style** и выберите нужный.

Профилями управляют две кнопки:

- **Reset** (сбросить) работает только для встроенных профилей. Она возвращает встроенный профиль к исходным значениям.
- **Delete** (удалить) работает только для созданных вами профилей и только пока профилей больше одного.

## Режимы грамматики промпта

Список **Prompt grammar** сообщает Marinara, в каком виде модель изображений лучше читает промпт. Выберите режим под свою модель. Режимов четыре.

- **Hybrid**: смесь предложений и тегов. Безопасный универсальный выбор.
- **Danbooru tags**: короткие теги через запятую в стиле Danbooru. Лучший вариант для аниме-checkpoint на базе SDXL – Illustrious, Pony, NovelAI.
- **Tags**: короткие ключевые слова через запятую, без соглашений Danbooru.
- **Natural language**: обычные предложения. Лучший вариант для моделей, понимающих прозу: DALL-E и модели Z-Image Turbo.

## Раздел Test bench

Раздел **Test bench** (тестовый стенд) показывает, что именно отправит Marinara, и при этом настоящее изображение не создается. Он находится внутри редактора Style Profiles. Пользоваться им нужно так.

1. Выберите значение в списке **Image kind** (тип изображения) – например, portrait или background.
2. Наберите примерный промпт в поле **Sample input** (пример ввода).
3. Прочитайте содержимое полей **Final positive prompt** (итоговый положительный промпт) и **Final negative prompt** (итоговый отрицательный промпт).

Раздел Test bench также выводит короткую заметку об очистке. Если менять нечего, там написано "No cleanup needed for this sample." Если промпт изменен, заметка сообщает, сколько повторов и неуместных фрагментов удалено.

## Как Marinara очищает промпт

Перед отправкой любого запроса на изображение Marinara собирает промпт с учетом активного профиля. При сборке происходит несколько вещей:

- Почти одинаковые теги удаляются – например, повторяющийся тег качества.
- Простые отрицательные фразы (вроде "avoid text" или "no watermark") переносятся в отрицательный промпт.
- Для фонов, иллюстраций и селфи ваши формулировки сохраняются. Для портретов, аватаров и спрайтов текст сводится к коротким визуальным тегам, которые Marinara распознает.
- Добавляются теги профиля для того типа изображения, который создается.

## Пример до и после

Допустим, выбран профиль **Danbooru / Illustrious**, в списке **Image kind** стоит portrait, а в поле **Sample input** набрано:

```
masterpiece, masterpiece, red-haired knight, no watermark
```

Тогда в поле **Final positive prompt** появится:

```
detailed eyes, solo, upper body, portrait, looking at viewer, anime screencap, masterpiece, best quality, absurdres
```

Произошло три вещи:

- Фраза "no watermark" ушла из положительного промпта в поле **Final negative prompt**. Заметка об очистке учитывает это изменение.
- Профиль добавил свои теги стиля, свои теги для портрета и свои теги качества. Слово "masterpiece" в результате пришло из тегов профиля, а не из набранного текста.
- Набранный текст был сведен к главному. Для портретов сохраняются только фрагменты, которые распознаются как ясные визуальные приметы. Фраза "red-haired knight" к ним не относится, поэтому она отброшена.

Если слова о персонаже исчезают для портрета, аватара или спрайта, попробуйте тип изображения **illustration**. Для него формулировки сохраняются как есть.

## Порядок приоритета: чат, подключение, общий стиль

Marinara берет профиль стиля из трех мест. Побеждает самый частный выбор. Порядок такой:

1. Профиль, прямо выбранный для текущего чата или игры.
2. Профиль из списка **Style Profile** (профиль стиля) у подключения для изображений – в разделе **Local Image Defaults** редактора подключений.
3. Общий стиль из списка **Default style** в панели **Settings**.

Раздел **Local Image Defaults** (локальные настройки изображений) появляется только у локальных подключений Stable Diffusion: AUTOMATIC1111 / SD Web UI, ComfyUI и NovelAI. Для остальных провайдеров выбор сразу переходит к общему стилю из списка **Default style**. Чтобы задать профиль для отдельного подключения, откройте подключение, раскройте раздел **Local Image Defaults** и выберите профиль в списке **Style Profile**. Значение **Use global default** оставляет в силе общий выбор. Если Marinara может угадать подходящий профиль по названию модели у подключения, появляется кнопка "Use ...", которая применяет этот профиль одним нажатием.
