# Анимированные выражения лица

Анимированные выражения лица – это короткие зацикленные анимации, которые служат спрайтами-портретами персонажа. Спрайт – это фигура персонажа, которую Marinara показывает на экране во время чата. Обычный спрайт выражения лица – это статичная картинка, например радостное лицо. Анимированное выражение лица играет вместо нее и сохраняется как GIF – файл изображения, который сам проигрывает короткую анимацию по кругу.

Marinara создает его в два шага. Она просит аккаунт **Video Generation** (генерация видео) сделать короткий ролик с этим выражением лица, а затем превращает ролик в зацикленный GIF на вашем компьютере. После сохранения он работает как любой другой спрайт. Скачиваемый агент **Expression Engine** показывает его, когда сцене нужна эта эмоция. См. [Спрайты персонажа](../characters/sprites.md) и [Справочник агентов для скачивания](../agents/built-in-agents.md).

<a id="before-you-start"></a>

## Перед началом

Понадобятся две вещи.

1. Аккаунт для видео. Как его добавить, описано в руководстве [Генерация видео сцены](scene-video.md).
2. ffmpeg на компьютере, где работает Marinara. ffmpeg – это бесплатный медиаинструмент, который превращает ролик в GIF.

Если ffmpeg нет, генерация сразу завершается ошибкой с таким сообщением:

```text
Animated expression GIF conversion requires ffmpeg. Install ffmpeg and make it available on PATH, or set FFMPEG_PATH.
```

Установите ffmpeg так, чтобы система его находила, или укажите в переменной окружения `FFMPEG_PATH` полный путь к программе ffmpeg. Переменная окружения – это настройка, которую вы задаете серверу перед запуском.

## Генерация анимированных выражений лица

Используется то же окно, что и для статичных спрайтов.

1. Откройте **Character Editor** (редактор персонажа) для персонажа или **Persona Editor** (редактор персоны) для персоны.
2. Откройте вкладку **Sprites**, затем категорию **Facial Expressions**.
3. Нажмите **Generate Sprite**. Откроется окно **Generate Sprites**.
4. Установите флажок **Generate animated portraits**. Окно переключится в режим анимации. Выбор аккаунта для изображений сменяется выбором аккаунта для видео, элементы управления сеткой для листов спрайтов исчезают, а Marinara делает по одному выражению лица за раз.
5. Выберите аккаунт для видео.
6. Заполните **Appearance Description** (описание внешности), чтобы сервис знал, как выглядит персонаж.
7. Выберите выражения лица, которые нужно сгенерировать.
8. Нажмите **Generate Animated Portrait** для одного выражения лица или **Generate Animated Portraits** для нескольких.

Пока идет генерация, отображается "Generating animated portrait GIFs...". Когда она закончится, просмотрите результаты и нажмите кнопку сохранения, чтобы добавить их к персонажу или персоне. Если одно выражение лица не получилось, Marinara сохраняет готовые и выводит список неудачных, чтобы можно было повторить попытку.

Анимированные выражения лица генерируются дольше статичных спрайтов, потому что делаются по одному. Начните с нескольких.

Если в **Settings → Generations → Overall Generations** (настройки → генерации → общие настройки генерации) включено **Expose media prompts before sending** (показывать промпты медиа перед отправкой), Marinara останавливается, чтобы вы могли прочитать и отредактировать каждый промпт до отправки в сервис.

## Длительность и форма

Каждое анимированное выражение лица – это вертикальный портретный ролик 9:16, и изменить это нельзя. Чтобы изменить длительность ролика, откройте **Settings → Generations**, найдите **Video Generation** и задайте **Animated expression length** (длительность анимированного выражения). По умолчанию – 3 секунды. Диапазон – от 1 до 8 секунд. Marinara сохраняет небольшой зацикленный GIF шириной 512 пикселей. Чем короче ролик, тем меньше файл и плотнее цикл.

<a id="backgrounds-are-not-removed"></a>

## Фон не удаляется

У статичных спрайтов фон можно убрать, чтобы персонаж как будто парил над сценой. Анимированные выражения лица пропускают эту очистку. В режиме анимации флажок **Prefer clean transparent-style background** лишь добавляет подсказку в промпт для видео. В пояснении к нему сказано: "GIF transparency is not guaranteed." Шаг проверки сообщает, что для GIF очистка фона, нарезка листа и обрезка кадров пропускаются. У анимированного выражения лица фон может остаться видимым. Для более чистого вида попросите однотонный фон в **Appearance Description**.

## Устранение неполадок

- **Генерация завершается ошибкой с сообщением про ffmpeg**: установите ffmpeg или задайте `FFMPEG_PATH`. См. [Перед началом](#before-you-start).
- **В списке выбора написано, что аккаунтов для видео не найдено**: сначала добавьте такой аккаунт. См. [Генерация видео сцены](scene-video.md).
- **Кнопка Generate Sprite неактивна**: на некоторых устройствах, например при некоторых установках на Android и в Termux, Marinara не может загрузить свою библиотеку изображений. Тогда выключается вся генерация спрайтов, включая анимированные выражения лица.
- **Сохраненный GIF по-прежнему показывает фон**: это ожидаемо. См. [Фон не удаляется](#backgrounds-are-not-removed).
