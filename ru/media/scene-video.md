# Генерация видео сцены

Видео сцены – это короткий ролик MP4 о сцене. Он может анимировать картинку из галереи: картинка становится первым кадром, а ИИ добавляет движение. В Roleplay его можно создать и только по истории. В этом руководстве описано, как настроить видеосервис, создавать ролики из галереи и в Game Mode и менять настройки видео.

Видео сцены работают в чатах Roleplay и Game Mode. Чаты Conversation вместо этого отправляют видеосообщения. Смотрите [Видеосообщения](../conversation/selfies.md#video-messages).

Game Mode и **Animate illustration** (анимировать иллюстрацию) всегда начинают с картинки, поэтому сначала сгенерируйте или загрузите ее. В Roleplay команда `/video` и кнопка **Video** (видео) в галерее следуют настройке **First frame** (первый кадр) агента Illustrator. Если First frame не выбран, картинка им не нужна.

Для видео сцены используется отдельный тип аккаунта – **Video Generation** (генерация видео), а не обычная генерация изображений. Готовые ролики сохраняются вместе с чатом и показываются в галерее, где их можно закрепить, скачать или просмотреть.

## Настройка видеосервиса

1. Нажмите **Connections** (подключения) на верхней панели, затем **Add** (добавить). Откроется окно **Add account** (добавить аккаунт).
2. Выберите сервис в разделе **Images & video** (изображения и видео). Сервисы перечислены ниже.
3. Вставьте ключ API облачного сервиса. Локальному ComfyUI ключ не нужен. SwarmUI нужен Swarm Auth Token (токен авторизации SwarmUI), только если ваш сервер требует аккаунт.
4. Нажмите **Connect** (подключиться), затем выберите модель или оставьте модель по умолчанию. У NanoGPT модели по умолчанию нет, поэтому выберите ее из списка. Для ComfyUI не указывайте модель, если только рабочий процесс не использует `%model%`. Для SwarmUI модель указывать не обязательно.
5. Откройте видеомодель и нажмите **Test video** (проверить видео), чтобы проверить ее.

Каждый сервис подставляет адрес по умолчанию и, где это применимо, модель по умолчанию. У NanoGPT модели по умолчанию нет, поэтому выберите ее сами.

| Видеосервис | Модель по умолчанию | Примечания |
| --- | --- | --- |
| **Google AI Studio** | `gemini-omni-flash-preview` | Запускает модели Gemini Omni и Veo через Gemini API. |
| **xAI Imagine** | `grok-imagine-video-1.5` | Видео Grok Imagine через xAI Videos API. |
| **OpenRouter Video** | `google/veo-3.1` | Можно вписать любой ID видеомодели OpenRouter. |
| **NanoGPT** | нет, выберите сами | Видеомодели через NanoGPT. |
| **Atlas Cloud** | `google/veo3.1/text-to-video` | Размещенные модели text-to-video и image-to-video. |
| **Seedance 2.0** | `seedance-2-0` | Режимы по тексту, по первому кадру, по первому и последнему кадру. |
| **ComfyUI** | задается рабочим процессом | Локальные WAN и другие видеопроцессы в формате API. |
| **SwarmUI** | задается рабочим процессом | Видеопроцессы ComfyUI через ваш сервер SwarmUI. |

**Google AI Studio** охватывает два семейства. **Gemini Omni** использует `gemini-omni-flash-preview`. **Google Veo** использует `veo-3.1-generate-preview`. Какое из них запустится, зависит от выбранной модели.

Для **ComfyUI** укажите `http://127.0.0.1:8188` и вставьте видеопроцесс в формате API в поле **ComfyUI workflow (required)**. Это поле обязательно. Подстановки и выходные узлы описаны в руководстве [Настройка рабочего процесса ComfyUI](comfyui.md#comfyui-video-workflows).

Для **SwarmUI** Marinara подставляет `http://127.0.0.1:7801`. Вставьте видеопроцесс в формате API в поле **ComfyUI workflow (required)**. Это поле обязательно. SwarmUI не поддерживает подстановки `%reference_image_name%`, поэтому используйте `%reference_image%`. Если ваш сервер требует аккаунт, вставьте Swarm Auth Token в поле **API key** (ключ API).

### Видеомодель по умолчанию

Чтобы видеомодель использовалась, когда у чата нет своей, задайте задачу **Video** в разделе **Defaults** (по умолчанию) вверху панели **Connections**. В Chat Settings она показывается как **Default video provider** (провайдер видео по умолчанию). Если нет ни модели чата, ни модели по умолчанию, действия с видео предупреждают, что модель нужно выбрать.

### Инструкции для промптов видео

У каждой видеомодели есть поле **Video prompting instructions** (инструкции для промптов видео). Объясните в нем ИИ, который пишет ваши промпты видео, чего ждет ваша видеомодель: например, движений камеры, определенной длины промпта или звука. Эти инструкции направляют анимации галереи в Roleplay, видеосообщения Conversation и **Image-aware shot planning** (планирование кадров с учетом изображения) агента Storyboard. Если ИИ скопирует в промпт целое предложение из этих инструкций, Marinara удалит это предложение. Видео сцен в Game Mode, клипы звонков и анимированные выражения пишут свои промпты отдельно и не учитывают это поле.

### Параметры видео по умолчанию для каждой модели

У видеомодели есть панель **Video defaults** (параметры видео по умолчанию) для длины ролика, соотношения сторон и разрешения по умолчанию. Эти значения важнее общей для приложения запасной длины.

Длина по умолчанию, диапазон, соотношение сторон и разрешение для каждого сервиса:

- Gemini Omni: 10 с, от 1 до 60 с, 16:9, разрешение по умолчанию у провайдера.
- Google Veo: 8 с, 4, 6 или 8 с, 16:9, 720p.
- xAI Imagine: 10 с, от 1 до 15 с, 16:9, 720p.
- OpenRouter Video: 10 с, от 1 до 60 с, 16:9, 720p.
- Atlas Cloud: 8 с, от 1 до 60 с, 16:9, 720p.
- Seedance 2.0: 5 с, от 4 до 15 с, 16:9, 720p.
- ComfyUI и SwarmUI: 5 с, от 1 до 60 с, 16:9, 720p.

У Gemini Omni нет поля разрешения, а длина вписывается в текст промпта. Google Veo всегда берет 8 секунд при анимации референсного изображения, потому что ему нужно 8 секунд, чтобы свести первый и последний кадры.

### Референсные кадры Seedance

Seedance должен получить референсное изображение по публичной веб-ссылке. У локального сервера Marinara ее нет, поэтому в обычной локальной установке понадобится один дополнительный шаг.

1. Откройте модель Seedance.
2. Включите **Upload Seedance reference frames temporarily** (временно загружать референсные кадры Seedance). Кадр отправляется на временную публичную ссылку.
3. Необязательно: задайте **Temporary link lifetime** (срок жизни временной ссылки). По умолчанию – 12 часов.

Если у сервера Marinara уже есть публичный адрес, вместо этого можно задать переменную окружения. Смотрите [Настройки сервера: справочник](../CONFIGURATION.md).

## Создание видео из галереи

В чатах Roleplay и Game Mode видео сцены можно создавать из галереи. Откройте **Chat Settings** (настройки чата) и разверните **Gallery** (галерея). В галерее есть вкладки **Images** (изображения) и **Videos** (видео), каждая со счетчиком.

### В Roleplay

Кнопка **Video** в строке действий вверху галереи создает ролик по последнему ответу, как и команда `/video`. Добавьте описание после `/video`, чтобы указать, что должно быть в ролике.

- **First frame**: следует настройке **First frame** агента Illustrator. Это новая картинка Illustrator по последнему ответу (сначала рисуется, затем анимируется), аватар или спрайт персонажа либо отсутствие картинки. Если ничего не выбрано, ролик создается только по истории.
- **Аватар**: ролик начинается с того, кого ваше описание называет первым, в том числе с вашей персоны. Достаточно части имени с заглавной буквы, которой нет ни у кого другого ("Lena" для "Dr. Lena Kowalski"). Если никто не назван, ролик начинается с персонажа чата.
- **Просмотр**: если включено **Expose media prompts before sending** (показывать промпты медиа перед отправкой), сначала можно просмотреть и отредактировать промпт ролика.
- **Контекст**: ИИ читает столько же последних сообщений, сколько Illustrator для картинки (**Context Size** агента Illustrator в разделе **Agent Budget** на его экране настройки).
- **Без картинки**: когда ролик начинается без картинки или с аватара, ИИ сам описывает сцену. Его инструкции – **Roleplay Clip Director** в **Settings → Generations → Video Generation Prompt Overrides** (настройки → генерации → переопределения промптов генерации видео).

Готовый ролик проигрывается прямо в чате, под последним ответом, даже если картинка взята из более раннего ответа. Ролики не открываются сами по себе в плавающем окне. Чтобы вывести ролик в плавающее окно, нажмите **Pin video to chat** (закрепить видео в чате) на вкладке **Videos**. Кнопка **X** на ролике убирает его из сообщения. В галерее он остается.

### В Game Mode

1. Проверьте, что на вкладке **Images** есть хотя бы одна картинка. Используйте **Illustrate** (проиллюстрировать) или загрузите картинку.
2. Нажмите **Video** в строке действий вверху галереи.
3. Если включено **Expose media prompts before sending** (**Settings → Generations → Overall Generations**), просмотрите или измените промпт и нажмите **Generate** (создать). Отмена не запускает запрос.
4. На кнопке появляется **Generating...**, а баннер сообщает, что идет генерация видео.
5. По завершении ролик появляется на вкладке **Videos**.

Если картинки нет, Marinara сообщает: "Add or generate a gallery image before generating a scene video." Создайте или загрузите картинку и повторите попытку.

### Анимация одной картинки

1. Откройте вкладку **Images**.
2. Наведите указатель на картинку.
3. Нажмите **Animate illustration** (иконка кинопленки).

Если просмотр промпта включен, окно показывает точный собранный промпт, длительность, соотношение сторон и разрешение для этой картинки. Ваша правка действует только на этот ролик. В Roleplay ИИ, планирующий движение, читает столько же последних сообщений, сколько Illustrator, заканчивая ответом, к которому относится картинка. Его многоразовые инструкции – **Roleplay Gallery Animation Director** в **Settings → Generations → Video Generation Prompt Overrides**.

Каждый ролик на вкладке **Videos** проигрывается на месте и показывает свою длину и название модели. Используйте **Pin video to chat** или **Download scene video** (скачать видео сцены). Пока роликов нет, на вкладке написано **No videos yet**.

## Выбор сервиса

Все восемь сервисов делают короткие ролики из вашего изображения.

- **Google AI Studio (Gemini Omni)**: длина до 60 секунд, вписывается в промпт.
- **Google AI Studio (Veo)**: высокое качество, строго 4, 6 или 8 секунд. При анимации изображения берет 8.
- **xAI Imagine**: от 1 до 15 секунд, лимит длины промпта короче, чем у остальных.
- **OpenRouter Video**: от 1 до 60 секунд, с любой видеомоделью, которую поддерживает ваш аккаунт.
- **NanoGPT**: от 1 до 60 секунд, модели по умолчанию нет.
- **Atlas Cloud**: загружает актуальный видеокаталог Atlas Cloud. Сначала идут модели image-to-video, для каждой указана начальная цена за секунду готового видео. Если загрузить каталог не удалось, Marinara предлагает начальные модели Veo 3.1 и Seedance 2.0. Можно ввести точный идентификатор модели. Ограничения модели при этом сохраняются.
- **Seedance 2.0**: от 4 до 15 секунд, с режимами по первому кадру и по первому и последнему кадру. Нужна публичная ссылка на референсное изображение.
- **ComfyUI**: локальная генерация через ваш рабочий процесс в формате API. Marinara загружает референсное изображение напрямую, если рабочий процесс использует `%reference_image_name%`.
- **SwarmUI**: локальная генерация через ваш рабочий процесс и сервер SwarmUI. Референсное изображение передается через `%reference_image%`.

Задачи с видео идут долго. Сервис запускает задачу, а Marinara ждет и проверяет, пока ролик не будет готов. На один ролик может уйти несколько минут. Большим локальным моделям WAN может не хватить стандартных 30 минут. Увеличьте `VIDEO_GEN_TIMEOUT_MS` и перезапустите Marinara.

### Различия между моделями Atlas Cloud

Не все модели Atlas Cloud принимают одни и те же настройки. Перед каждым запросом Marinara читает опубликованную схему входных данных модели с `static.atlascloud.ai` и подстраивает под нее ваши значения по умолчанию.

- Исходная картинка отправляется в то поле изображения, которое использует модель.
- Длина ролика меняется на ближайшую из тех, что предлагает модель. Модель, которая допускает только 5 или 10 секунд, превращает значение по умолчанию 8 секунд в 10.
- Разрешение меняется на ближайший уровень, который предлагает модель. Модели, которым нужен размер в пикселях, получают ближайшее `width*height` для ваших соотношения сторон и разрешения.
- Настройка, которой у модели нет, пропускается, и применяется значение модели по умолчанию.

Журнал сервера перечисляет каждое измененное значение в строке, начинающейся с `[video-gen/atlas-cloud] fitted request`. Если схему не удалось прочитать, Marinara отправляет тот же общий запрос, что и раньше.

Для видео сцены выбирайте модель image-to-video. У модели text-to-video нет поля изображения. Она игнорирует вашу картинку и создает не связанный с ней ролик по промпту, о чем сообщает журнал сервера. **Test video** отправляет простой градиент в качестве первого кадра, если модели нужно изображение, поэтому модели image-to-video тоже могут пройти проверку.

У многих моделей Atlas Cloud есть собственные входные поля, например `negative_prompt`, `seed`, `generate_audio`, `shot_type`, `enable_prompt_expansion` или списки LoRA.

1. Откройте модель Atlas Cloud и выберите или введите модель.
2. Разверните **Video defaults**, затем **Atlas Cloud setup** (настройка Atlas Cloud).
3. Найдите **Model options** (параметры модели) под настройками длины, соотношения сторон и разрешения.

Вверху **Model options** перечислены длины, разрешения, размеры кадра и соотношения сторон, которые принимает модель. Для модели text-to-video там также показано предупреждение. Каждый параметр носит название и описание, которые ему дал Atlas Cloud, и изначально стоит на **Model default** (значение модели по умолчанию), а само значение указано в скобках. Параметр, оставленный на **Model default**, не отправляется. Измените параметр, чтобы отправлять свое значение с каждым видео этой модели, включая **Test video**. Поля списков и объектов, например LoRA, принимают JSON.

Выбор сохраняется отдельно для каждой модели. **Reset model options** (сбросить параметры модели) очищает его для текущей модели. Нажмите **Save** (сохранить), чтобы сохранить изменения. Если сохраненный параметр больше не подходит модели, Marinara пропускает его и называет в строке журнала.

## Создание видео в Game Assets

В Game Mode есть второе место для создания видео сцены – **Game Assets** (игровые ресурсы). Нажмите его кнопку с папкой справа вверху чата. На компьютере открывается окно, а на телефоне – панель на всю ширину. Если вы перенесли его в Chat Settings, откройте там раздел **Game Assets**.

1. Откройте **Game Assets**.
2. Нажмите **Generate video** (создать видео; "Generate a scene video from the latest illustration").
3. Когда новый ролик готов, он проигрывается там же.

**Generate video** остается неактивной, пока у игры нет и видеомодели, и иллюстрации сцены. При слишком раннем нажатии можно увидеть "Choose a Video Generation connection in Game Settings first." (задайте для игры видеомодель) или "Generate a scene illustration before generating a scene video." Если ролик не получился, панель показывает "Scene video generation failed." Повторите попытку, а при повторных сбоях проверьте ключ.

## Выбор видеомодели для чата

Каждый чат выбирает свою видеомодель в **Chat Settings → Agents → Scene Videos** (настройки чата → агенты → видео сцен).

- В **Roleplay** показывается карточка **Scene Videos** ("Generate manual MP4 scene videos from gallery images"). В ней один элемент управления – список видеомоделей.
- В **Game Mode** показывается карточка **Scene Videos** ("Generate MP4 scene videos from game illustrations") с большим числом элементов управления. Список видеомоделей выбирает модель. **Game Video Prompt** (промпт видео Game) – шаблон, который решает, как анимируется картинка. Встроенный вариант по умолчанию – **Cinematic Scene Video**. **Edit Video Prompt Presets** (изменить пресеты промптов видео) добавляет и правит ваши собственные копии для этого чата.

**Game Video Prompt** управляет видео, запущенными вручную из галереи и Game Assets в Game Mode. Анимации галереи в Roleplay вместо него используют **Roleplay Gallery Animation Director**. У агента Storyboard есть собственный шаблон **Storyboard Video Prompt** по умолчанию. Каждый чат может заменить его в **Chat Settings → Agents → Storyboards**. Сброс возвращает шаблон агента Storyboard по умолчанию.

При создании чата Game Mode в мастере настройки есть выбор видеомодели на шаге **Features** (возможности), после того как вы включите визуальную генерацию.

## Настройки генерации видео

Часть настроек видео по умолчанию действует для всего приложения. Откройте **Settings → Generations** и найдите **Video Generation** ("Set default clip lengths and edit reusable video prompts for Game, Gallery, and Calls").

- **Scene video fallback length** (запасная длина видео сцены): применяется только тогда, когда у выбранной видеомодели нет своей длины. По умолчанию 10 секунд. Диапазон – от 1 до 60.
- **Video Generation Prompt Overrides**: здесь правятся многоразовые шаблоны промптов видео. **Roleplay Gallery Animation Director** задает инструкции, которые отправляются модели Prompt Model перед созданием ролика галереи в Roleplay. Его переменная `${durationSeconds}` заменяется на длину ролика.
- **Videos per reply** (видео на ответ): сколько видеосообщений персонажи Conversation могут отправить в одном ответе и сколько роликов Illustrator добавляет к одному ответу Roleplay. По умолчанию 3. Диапазон – от 1 до 10. Каждый персонаж Conversation отправляет не более одного. Настройка нужна для групповых чатов и для просьб о нескольких видео сразу. Увеличьте значение, чтобы больше персонажей могли отправить ролик. Уменьшите, чтобы сэкономить запросы. Ролики сверх лимита пропускаются. `/video` и кнопка **Video** в галерее не учитываются.
- **Animated expression length** (длительность анимированного выражения) относится к анимированным спрайтам портретов. Смотрите [Анимированные выражения лица](animated-expressions.md).

## Раскадровки

Скачиваемый агент Storyboard собирает упорядоченные ключевые кадры и ролики в Roleplay и Game Mode. Когда анимация включена, Marinara анимирует каждый удачный ключевой кадр выбранной видеомоделью и шаблоном **Storyboard Video Prompt** самого агента. Смотрите [Руководство по агенту Storyboard](../game/storyboard.md).

## Устранение неполадок

### "Choose a Video Generation connection"

У чата нет видеомодели. Откройте **Chat Settings → Agents → Scene Videos** и выберите ее. Если список пуст, добавьте модель в **Connections**.

### "Add or generate a gallery image before generating a scene video"

Для Game Mode и **Animate illustration** нужна существующая картинка. Roleplay может создать ролик только по истории, если первый кадр не выбран. Используйте **Illustrate**, загрузите картинку или нажмите **Animate illustration** на той, что уже есть.

### Видео делается очень долго

Это нормально. Google, xAI, OpenRouter, NanoGPT, Atlas Cloud и Seedance запускают задачу, а Marinara ждет ее завершения. На один ролик может уйти несколько минут.

### Seedance не может прочитать референсное изображение

Seedance нужна публичная ссылка на картинку. На локальном сервере включите **Upload Seedance reference frames temporarily** в модели Seedance. Смотрите [Референсные кадры Seedance](#seedance-reference-frames).

### Запрос видео срывается снова и снова

Проверьте, что у аккаунта действующий ключ API и есть доступ к видео. Откройте аккаунт в **Connections** и сверьте ключ и модель. Серверные тайм-ауты описаны в руководстве [Настройки сервера: справочник](../CONFIGURATION.md).
