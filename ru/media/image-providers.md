# Провайдеры генерации изображений и их настройка

Это руководство объясняет, как подключить сервис генерации изображений к приложению Marinara Engine. Здесь же перечислено, что требуется каждому из 17 сервисов. На генерации изображений работают иллюстрации сцен, селфи, фоны сцен, а также сгенерированные аватары, портреты и спрайты.

Генерация изображений настраивается как особый вид подключения. Как только одно подключение для изображений работает, его могут использовать все функции приложения, связанные с картинками.

## Как добавить подключение для генерации изображений

**API key** (ключ API) – это секретный пароль от провайдера, который дает приложению Marinara доступ к вашему аккаунту. **Base URL** (базовый адрес) – это веб-адрес интерфейса сервиса. Правильный **Base URL** приложение Marinara подставляет само, когда вы выбираете сервис.

Чтобы добавить подключение для изображений, выполните следующие шаги.

1. Откройте панель **Connections** (подключения).
2. Нажмите кнопку **New** (создать), чтобы открыть окно **Create Connection**.
3. Введите название, затем выберите провайдера **Image Generation**.
4. В редакторе подключения выберите сервис в сетке **Service**.
5. Вставьте ключ в поле **API Key**, если сервису нужен ключ. Бесплатным и локальным сервисам он не нужен.
6. Выберите модель в списке **Model** или впишите идентификатор модели вручную. У части сервисов есть кнопка **Fetch Models from API** (получить список моделей), которая загружает актуальный список.
7. Нажмите кнопку **Save** (сохранить).
8. Нажмите кнопку **Test Image** (проверить генерацию), чтобы убедиться в работоспособности. Marinara сгенерирует небольшое тестовое изображение.

Если кнопка **Test Image** вернула картинку, подключение готово. Если проверка не прошла, проверьте ключ API и **Base URL**.

## OpenAI (DALL-E)

Облачный сервис, стандартный **Base URL** – `https://api.openai.com/v1`. Нужен ключ API от аккаунта OpenAI. Доступны модели DALL-E и GPT Image. Принимает до 16 референсных изображений.

## Stability AI

Облачный сервис, стандартный **Base URL** – `https://api.stability.ai/v2beta`. Нужен ключ API сервиса Stability AI. Доступны модели Stable Diffusion и Stable Image.

## Together AI

Облачный сервис, стандартный **Base URL** – `https://api.together.xyz/v1`. Нужен ключ API сервиса Together AI. Доступны модели FLUX и другие открытые модели изображений.

## NovelAI

Облачный сервис, стандартный **Base URL** – `https://image.novelai.net`. Нужен ключ API сервиса NovelAI. Сервис специализируется на рисунках в стиле аниме. Для моделей V4, V4.5 и V5 Marinara отправляет нативные промпты персонажей с их позициями в раскадровках и сценах Illustrator с несколькими персонажами. Часть новых возможностей, например точные референсные изображения, работает только на модели версии V4.5.

## OpenRouter Images

Облачный сервис, стандартный **Base URL** – `https://openrouter.ai/api/v1`. Нужен ключ API сервиса OpenRouter. Модели изображений доступны через чат-интерфейс OpenRouter, поэтому конкретный набор моделей зависит от аккаунта.

## xAI / Grok Imagine

Облачный сервис, стандартный **Base URL** – `https://api.x.ai/v1`. Нужен ключ API сервиса xAI. Изображения генерирует Grok Imagine.

## Venice.ai

Облачный сервис, стандартный **Base URL** – `https://api.venice.ai/api/v1`. Нужен ключ API сервиса Venice. Нажмите **Fetch Models from API**, чтобы загрузить модели изображений, доступные вашему аккаунту. Marinara обращается к собственному интерфейсу изображений Venice, отключает необязательное размытие в безопасном режиме Venice и сама приводит запрошенные размеры к тому формату, который понимает модель: пиксели, соотношение сторон или уровень разрешения. Ограничения самого провайдера или модели все равно могут отклонить запрос.

## Z.AI

Облачный сервис, стандартный **Base URL** – `https://api.z.ai/api/paas/v4`. Нужен обычный ключ API сервиса Z.AI. Ключи тарифа GLM Coding Plan и адрес `/api/coding/paas/v4` для генерации изображений не подходят. Нажмите **Fetch Models from API** и выберите модель **GLM-Image** или **CogView 4**. Marinara приводит запрошенное соотношение сторон к размеру, который поддерживает выбранная модель, отправляет запрос в собственный интерфейс изображений Z.AI и скачивает временную ссылку с результатом в локальное хранилище. Первая версия работает только с генерацией по тексту и не отправляет референсные изображения.

## Atlas Cloud

Облачный сервис, стандартный **Base URL** – `https://api.atlascloud.ai/api/v1`. Нужен ключ API сервиса Atlas Cloud. Marinara предлагает небольшой стартовый набор: Nano Banana, Gemini Flash Image и FLUX 1.1 Pro. Можно вписать и точный идентификатор другой модели изображений Atlas Cloud. Задачи выполняются асинхронно: Marinara запускает генерацию и опрашивает Atlas Cloud, пока изображение не будет готово. Обычные настройки генерации по тексту сопоставляются автоматически. Референсные изображения отправляются тем моделям, которые заявляют поддержку image-to-image, edit или Kontext. Схемы моделей Atlas различаются, поэтому при выборе другого идентификатора сверяйтесь с документацией Atlas Cloud по этой модели.

## NanoGPT

Облачный сервис, стандартный **Base URL** – `https://nano-gpt.com/api/v1`. Нужен ключ API сервиса NanoGPT. NanoGPT работает как агрегатор, поэтому список моделей загружается кнопкой **Fetch Models from API**.

## Block Entropy

Облачный сервис, стандартный **Base URL** – `https://api.blockentropy.ai`. Нужен ключ API. Отдельного обработчика для Block Entropy в приложении Marinara нет, поэтому запросы уходят в формате, совместимом с OpenAI. Реальная совместимость не подтверждена, так что перед серьезной работой проверьте сервис кнопкой **Test Image**.

## RunPod Serverless (ComfyUI)

Облачный сервис, стандартный **Base URL** – `https://api.runpod.ai/v2`. Он выполняет рабочий процесс ComfyUI на бессерверной точке RunPod. Нужны три вещи: ключ API сервиса RunPod в поле **API Key**, значение **RunPod Endpoint ID** и рабочий процесс **ComfyUI Workflow** в формате JSON. Смотрите раздел про рабочий процесс ComfyUI ниже.

## Pollinations

Бесплатный облачный сервис, стандартный **Base URL** – `https://image.pollinations.ai`. Ни аккаунта, ни ключа API не требуется. Это самый быстрый способ попробовать генерацию изображений.

## Stable Horde

Бесплатный облачный сервис, стандартный **Base URL** – `https://stablehorde.net/api/v2`. Это сеть из компьютеров добровольцев. Ключ API указывать не обязательно. Бесплатный ключ дает более высокий приоритет в очереди.

## SD Web UI (AUTOMATIC1111 / Forge)

Локальный сервис, стандартный **Base URL** – `http://localhost:7860`. Обращается к программе Stable Diffusion Web UI, запущенной на вашем компьютере. Эту программу нужно запустить с включенным программным интерфейсом. Ключ API не нужен.

## ComfyUI

Локальный сервис, стандартный **Base URL** – `http://127.0.0.1:8188`. Обращается к серверу ComfyUI, запущенному на вашем компьютере. Поддерживает свой рабочий процесс – о нем ниже. Ключ API не нужен.

## Draw Things

Локальный сервис, стандартный **Base URL** – `http://localhost:7860`. Обращается к приложению Draw Things на macOS или iOS. Marinara работает с ним так же, как с сервером AUTOMATIC1111. Ключ API не нужен.

## Локальные сервисы в вашей сети

Слово `localhost` (его же называют петлевым адресом) означает тот самый компьютер, на котором работает Marinara. Локальные серверы изображений на этом же компьютере работают без дополнительной настройки.

Если сервер изображений запущен на другом компьютере домашней сети, в настройках сервера нужно разрешить адреса локальной сети. Как это сделать, описано в руководстве [Настройки сервера: справочник](../CONFIGURATION.md).

Иногда провайдер возвращает не сами данные изображения, а ссылку. Публичные адреса CDN приложение Marinara скачивает через обычные проверки безопасности исходящих запросов. Ссылку на частный или петлевой адрес Marinara принимает только тогда, когда протокол, имя узла и порт в точности совпадают с настроенным провайдером изображений. Переадресация с этого частного адреса не может увести на другую локальную службу. Если локальный прокси хранит результаты на другом частном адресе, настройте его так, чтобы файлы отдавались с того же адреса, что и интерфейс изображений.

## Рабочий процесс ComfyUI в формате JSON и RunPod

Для сервисов **ComfyUI** и **RunPod Serverless (ComfyUI)** появляется поле **ComfyUI Workflow**. Вставьте в него рабочий процесс в формате JSON, экспортированный из ComfyUI командой **Save (API Format)**, **Export (API)** или **Export to API** – название зависит от версии интерфейса. Для **ComfyUI** поле помечено как необязательное, для **RunPod Serverless (ComfyUI)** – как обязательное.

Marinara подставляет значения в рабочий процесс через специальные подстановки. Расставьте эти текстовые подстановки в тех местах, куда должно попасть значение.

- `%prompt%` и `%negative_prompt%` – промпты, то есть текст, который Marinara отправляет модели.
- `%width%`, `%height%` и `%seed%` – размер изображения и зерно, то есть начальное число генератора.
- `%model%`, `%steps%`, `%cfg%`, `%sampler%`, `%scheduler%` и `%denoise%` – настройки генерации.
- `%reference_image%` и от `%reference_image_01%` до `%reference_image_04%` – вставка данных референсных изображений.
- `%reference_image_name%` и от `%reference_image_name_01%` до `%reference_image_name_04%` – загрузка референсных изображений и вставка их имен файлов для узла LoadImage в локальном ComfyUI.

Главная подстановка – `%prompt%`. Если ее нет, редактор выдает предупреждение. Для **ComfyUI** пустое поле означает встроенный рабочий процесс по умолчанию. Для **RunPod Serverless (ComfyUI)** рабочий процесс обязателен, потому что у точки подключения нет своего варианта по умолчанию. Оба принимают до 4 референсных изображений в виде данных base64. Подстановки с именами загруженных файлов доступны только для локального ComfyUI.

Полный порядок экспорта, примеры JSON, правила кавычек вокруг подстановок, настройка референсных изображений, отдельные рабочие процессы для персонажей, доступ по локальной сети и разбор проблем – в руководстве [Настройка рабочего процесса ComfyUI](comfyui.md).

## Панель Local Image Defaults для подключения

Если выбран сервис **SD Web UI (AUTOMATIC1111 / Forge)**, **ComfyUI**, **NovelAI** или **Draw Things**, у подключения появляется панель **Local Image Defaults** (стандартные настройки локальных изображений). Для **Draw Things** панель показывает те же поля и те же значения, что и для **SD Web UI (AUTOMATIC1111 / Forge)**. Эти настройки действуют только тогда, когда изображение генерирует именно это подключение. Кнопка **Reset** (сбросить) возвращает встроенные значения.

У всех четырех сервисов есть поле **Seed**. Значение -1 оставляет каждое изображение случайным. Любое другое число заставляет использовать одно и то же зерно каждый раз.

Остальные поля зависят от сервиса.

| Сервис | Поле | По умолчанию |
| --- | --- | --- |
| AUTOMATIC1111 / Forge | Steps | 20 |
| AUTOMATIC1111 / Forge | CFG Scale | 7 |
| AUTOMATIC1111 / Forge | Sampler | Euler a |
| AUTOMATIC1111 / Forge | Img2Img Denoise | 0.6 |
| ComfyUI | Steps | 20 |
| ComfyUI | CFG Scale | 7 |
| ComfyUI | Sampler | euler_ancestral |
| ComfyUI | Scheduler | normal |
| ComfyUI | Denoise | 1 |
| NovelAI | Steps | 28 |
| NovelAI | Prompt Guidance | 6 |
| NovelAI | Sampler | k_euler_ancestral |
| NovelAI | Noise Schedule | karras |

У каждого сервиса есть также текстовые поля **Prompt Prefix** и **Negative Prefix**. Написанный там текст добавляется в начало каждого промпта этого подключения. У AUTOMATIC1111 / Forge и ComfyUI есть поле **Clip Skip**. У AUTOMATIC1111 / Forge дополнительно появляется переключатель **Restore faces**. У ComfyUI появляется переключатель **Upload a 1x1 placeholder when no reference image is provided**. Он важен только для своих рабочих процессов с подстановками референсных изображений. У NovelAI добавляются поля **Guidance Rescale** и **UC Preset**.

## Поддержка референсных изображений разная у разных провайдеров

Референсное изображение – это готовая картинка, которую вы отправляете вместе с промптом. Она помогает сохранить в новом изображении лицо персонажа или стиль рисунка. Провайдеры принимают разное количество таких картинок.

| Провайдер | Референсные изображения |
| --- | --- |
| OpenAI (DALL-E) | До 16 |
| NovelAI | До 16, только на модели V4.5 |
| xAI / Grok Imagine | До 3 |
| Venice.ai | Не поддерживаются при генерации по тексту |
| Z.AI | Не поддерживаются в текущей интеграции – только генерация по тексту |
| Atlas Cloud | Первое изображение, для подходящих идентификаторов моделей image-to-image, edit или Kontext |
| NanoGPT | До 3 |
| Stability AI | Только первое изображение, в режиме image to image |
| OpenRouter Images | Поддерживаются, без жесткого предела |
| ComfyUI и RunPod Serverless (ComfyUI) | До 4, через подстановки в рабочем процессе |
| Together AI, Pollinations, Stable Horde | Не поддерживаются |

Точные референсные изображения NovelAI работают только на модели версии V4.5, например `nai-diffusion-4-5-full`. Сервис NovelAI еще не выпустил Precise Reference для V5. При запросе референсов на другой модели Marinara генерирует изображение без них и записывает предупреждение в лог сервера.

## Очередь запросов на генерацию изображений

Переключатель **Queue image generation requests** находится в **Settings** (настройки), далее **Generations**, далее **Image Generation**. По умолчанию он включен.

Когда он включен, Marinara отправляет задачи на изображения по одной. Оставьте его включенным для сервисов, которые не принимают два запроса одновременно. Выключайте только в том случае, если сервис справляется с множеством одновременных запросов, а вы хотите получить результат быстрее.
