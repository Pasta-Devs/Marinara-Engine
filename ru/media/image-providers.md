# Провайдеры генерации изображений и их настройка

Это руководство объясняет, как подключить сервис генерации изображений к приложению Marinara Engine. Здесь же перечислено, что требуется каждому сервису. На генерации изображений работают иллюстрации сцен, селфи, фоны сцен, а также сгенерированные аватары, портреты и спрайты.

Генерация изображений настраивается как особый вид подключения. Как только одно подключение для изображений работает, его могут использовать все функции приложения, связанные с картинками.

## Как добавить подключение для генерации изображений

**API key** (ключ API) – это секретный пароль от провайдера, который дает приложению Marinara доступ к вашему аккаунту. **Base URL** (базовый адрес) – это веб-адрес интерфейса сервиса. Правильный **Base URL** приложение Marinara подставляет само, когда вы выбираете сервис.

Чтобы добавить подключение для изображений, выполните следующие шаги.

1. Откройте панель **Connections** (подключения).
2. Нажмите кнопку **New** (создать), чтобы открыть окно **Create Connection**.
3. Введите название, затем выберите провайдера **Image Generation**.
4. В редакторе подключения выберите сервис в сетке **Service**.
5. Вставьте ключ в поле **API Key**, если сервису нужен ключ. Бесплатным и локальным сервисам он не нужен.
6. Выберите модель в списке **Model** или впишите идентификатор модели вручную. У части сервисов есть кнопка **Fetch Models from API** (получить список моделей), которая загружает актуальный список.
7. Нажмите кнопку **Save** (сохранить).
8. Нажмите кнопку **Test Image** (проверить генерацию), чтобы убедиться в работоспособности. Marinara сгенерирует небольшое тестовое изображение.

Если кнопка **Test Image** вернула картинку, подключение готово. Если проверка не прошла, проверьте ключ API и **Base URL**.

## OpenAI (DALL-E)

Облачный сервис, стандартный **Base URL** – `https://api.openai.com/v1`. Нужен ключ API от аккаунта OpenAI. Доступны модели DALL-E и GPT Image. Модели GPT Image принимают до 16 референсных изображений, модели DALL-E – ни одного.

## ChatGPT (Codex login)

Облачный сервис, который вместо ключа API использует ваш тариф ChatGPT, поэтому для изображений не нужны кредиты API OpenAI. На компьютере, где работает сервер Marinara, установите программу Codex CLI и один раз выполните `codex login`. Это тот же вход, который использует подключение для чата **OpenAI (ChatGPT)**. Пошаговая инструкция – в руководстве [Подключения по подписке Claude, ChatGPT и Grok](../connections/subscription-clis.md#openai-chatgpt). Ни ключ API, ни **Base URL** указывать не нужно. Marinara сама подставляет модель `gpt-image-2` – ту же, которую для изображений использует сам Codex.

**Test Connection** (проверить подключение) проверяет только, может ли Marinara прочитать ваш вход в Codex. **Test Image** генерирует настоящее изображение и расходует ваши лимиты на изображения в ChatGPT. Если есть референсные изображения, Marinara отправляет запрос на редактирование и прикладывает к нему до 16 из них. ChatGPT может вернуть изображение не того размера в пикселях, который был запрошен, поэтому Marinara дополнительно указывает нужное соотношение сторон в промпте.

Этот сервис обращается к интерфейсу изображений ChatGPT, которым пользуется Codex, а не к публичному API OpenAI, поэтому OpenAI может изменить этот интерфейс без предупреждения.

## Stability AI

Облачный сервис, стандартный **Base URL** – `https://api.stability.ai/v2beta`. Нужен ключ API сервиса Stability AI. Доступны модели Stable Diffusion и Stable Image.

## Together AI

Облачный сервис, стандартный **Base URL** – `https://api.together.xyz/v1`. Нужен ключ API сервиса Together AI. Доступны модели FLUX и другие открытые модели изображений.

## Arli AI

Облачный сервис, стандартный **Base URL** – `https://api.arliai.com/v1`. Нужен ключ API сервиса Arli AI. Запускает размещенные модели Stable Diffusion. Поле **Model** обязательно, поэтому впишите название нужной модели изображений Arli AI. Использует те же поля **Local Image Defaults** (стандартные настройки локальных изображений), что и **SD Web UI (AUTOMATIC1111 / Forge)**, – о них ниже. Если вы отправляете референсные изображения, Marinara берет первое из них как исходную картинку (image to image).

Сервис **Arli AI** здесь предназначен только для изображений. Для чат-моделей Arli AI используйте провайдер чата **Arli AI**; см. [Поддерживаемые провайдеры ИИ](../connections/providers-reference.md#arli-ai).

## NovelAI

Облачный сервис, стандартный **Base URL** – `https://image.novelai.net`. Нужен ключ API сервиса NovelAI. Сервис специализируется на рисунках в стиле аниме. Для моделей V4, V4.5 и V5 Marinara отправляет нативные промпты персонажей с их позициями в раскадровках и сценах Illustrator с несколькими персонажами. Часть новых возможностей, например точные референсные изображения, работает только на модели версии V4.5.

## OpenRouter Images

Облачный сервис, стандартный **Base URL** – `https://openrouter.ai/api/v1`. Нужен ключ API сервиса OpenRouter. Модели изображений доступны через чат-интерфейс OpenRouter, поэтому конкретный набор моделей зависит от аккаунта.

## xAI / Grok Imagine

Облачный сервис, стандартный **Base URL** – `https://api.x.ai/v1`. Нужен ключ API сервиса xAI. Изображения генерирует Grok Imagine.

## Venice.ai

Облачный сервис, стандартный **Base URL** – `https://api.venice.ai/api/v1`. Нужен ключ API сервиса Venice. Нажмите **Fetch Models from API**, чтобы загрузить модели изображений, доступные вашему аккаунту. Marinara обращается к собственному интерфейсу изображений Venice, отключает необязательное размытие в безопасном режиме Venice и сама приводит запрошенные размеры к тому формату, который понимает модель: пиксели, соотношение сторон или уровень разрешения. Ограничения самого провайдера или модели все равно могут отклонить запрос.

## Z.AI

Облачный сервис, стандартный **Base URL** – `https://api.z.ai/api/paas/v4`. Нужен обычный ключ API сервиса Z.AI. Ключи тарифа GLM Coding Plan и адрес `/api/coding/paas/v4` для генерации изображений не подходят. Нажмите **Fetch Models from API** и выберите модель **GLM-Image** или **CogView 4**. Marinara приводит запрошенное соотношение сторон к размеру, который поддерживает выбранная модель, отправляет запрос в собственный интерфейс изображений Z.AI и скачивает временную ссылку с результатом в локальное хранилище. Первая версия работает только с генерацией по тексту и не отправляет референсные изображения.

## Atlas Cloud

Облачный сервис с адресом Base URL по умолчанию `https://api.atlascloud.ai/api/v1`. Требуется ключ API Atlas Cloud. **Fetch Models** (Загрузить модели) получает актуальный каталог моделей Atlas Cloud для генерации изображений из текста и на основе изображения. Если каталог недоступен, Marinara показывает небольшой начальный список: Nano Banana, Gemini Flash Image и FLUX 1.1 Pro. Вы всегда можете ввести точный идентификатор модели изображений Atlas Cloud. Задания выполняются асинхронно: Marinara запускает генерацию и опрашивает Atlas Cloud, пока изображение не будет готово. Обычные настройки генерации из текста сопоставляются автоматически; референсные изображения отправляются моделям, чьи идентификаторы указывают на поддержку image-to-image, редактирования или Kontext. Схемы моделей могут различаться, поэтому при вводе другого идентификатора сверяйтесь с документацией выбранной модели в Atlas Cloud.

## fal.ai

Облачный сервис со стандартным **Base URL** `https://fal.run`. Создайте ключ API на [fal.ai](https://fal.ai/dashboard/keys), затем выберите **fal.ai** в сетке сервисов изображений. Начальный список **Model** содержит `fal-ai/flux/schnell` и `fal-ai/flux/dev`; можно ввести ID другой конечной точки генерации по тексту с совместимой схемой входа и выхода. **Test Connection** (проверить подключение) проверяет только конфигурацию. **Test Image** отправляет реальный запрос генерации и расходует ваши кредиты fal.ai.

Marinara отправляет промпт и запрошенные размеры, затем скачивает первое возвращенное изображение в существующий процесс обработки изображений. Негативные промпты добавляются как текстовые инструкции. Используйте **Custom Parameters** (пользовательские параметры) для настроек конкретной модели, например `seed`, `num_inference_steps` или `image_size`. Интеграция использует синхронные запросы генерации по тексту; она не отправляет референсные изображения и не возобновляет прерванные задания. Проверьте допустимые входные данные на странице API выбранной модели или собственного эндпоинта, например в [справочнике API flux/schnell](https://fal.ai/models/fal-ai/flux/schnell/api).

## SpicyAPI

Облачный сервис со стандартным **Base URL** `https://api.spicyapi.ai/api/v1`. Создайте ключ API в [консоли SpicyAPI](https://spicyapi.ai/console/keys), затем выберите **SpicyAPI** в сетке сервисов изображений. Marinara подставляет модель `alibaba/z-image-spicy-pro/text-to-image`. Нажмите **Fetch Models from API**, чтобы загрузить все модели SpicyAPI для генерации по тексту и для редактирования, или введите ID модели, например `bytedance/seedream-5.0-pro/text-to-image`. **Test Connection** проверяет ваш ключ, читая список моделей, поэтому ничего не стоит. **Test Image** создает настоящее изображение и расходует ваш баланс SpicyAPI.

Выбирайте сервис **SpicyAPI**. Не используйте **OpenAI (DALL-E)** или подключение **Custom (OAI-Compatible)** с адресом SpicyAPI. Адрес SpicyAPI в стиле OpenAI работает только с текстом, поэтому через них изображения не создать.

У каждой модели SpicyAPI свои настройки. Marinara спрашивает у SpicyAPI, какие из них принимает выбранная модель, и отправляет только их. Она выбирает самый близкий вариант из тех, что предлагает модель, например соотношение сторон, ширину и высоту или фиксированный размер. Если у модели нет поля для негативного промпта, негативный промпт добавляется в конец промпта как текст. Для других настроек модели, например `seed`, `resolution` или `loras`, используйте **Custom Parameters**.

SpicyAPI выполняет каждое изображение как задание. Marinara ждет завершения задания, проверяет его еще раз, если оно длится дольше примерно минуты, а затем скачивает результат. Если соединение обрывается, Marinara подхватывает то же задание, а не платит за новое. Модели редактирования (ID которых заканчиваются на `/edit`) получают ваши референсные изображения. SpicyAPI принимает референсные изображения размером до 1 МБ каждое и до 2 МБ на запрос, поэтому Marinara уменьшает изображения побольше и не отправляет лишние, которые не помещаются.

## NanoGPT

Облачный сервис, стандартный **Base URL** – `https://nano-gpt.com/api/v1`. Нужен ключ API сервиса NanoGPT. NanoGPT работает как агрегатор, поэтому список моделей загружается кнопкой **Fetch Models from API**.

## Block Entropy

Облачный сервис, стандартный **Base URL** – `https://api.blockentropy.ai`. Нужен ключ API. Отдельного обработчика для Block Entropy в приложении Marinara нет, поэтому запросы уходят в формате, совместимом с OpenAI. Реальная совместимость не подтверждена, так что перед серьезной работой проверьте сервис кнопкой **Test Image**.

## RunPod Serverless (ComfyUI)

Облачный сервис, стандартный **Base URL** – `https://api.runpod.ai/v2`. Он выполняет рабочий процесс ComfyUI на бессерверной точке RunPod. Нужны три вещи: ключ API сервиса RunPod в поле **API Key**, значение **RunPod Endpoint ID** и рабочий процесс **ComfyUI Workflow** в формате JSON. Смотрите раздел про рабочий процесс ComfyUI ниже.

## Pollinations

Бесплатный облачный сервис, стандартный **Base URL** – `https://image.pollinations.ai`. Ни аккаунта, ни ключа API не требуется. Это самый быстрый способ попробовать генерацию изображений.

## Stable Horde

Бесплатный облачный сервис, стандартный **Base URL** – `https://stablehorde.net/api/v2`. Это сеть из компьютеров добровольцев. Ключ API указывать не обязательно. Бесплатный ключ дает более высокий приоритет в очереди.

## SD Web UI (AUTOMATIC1111 / Forge)

Локальный сервис, стандартный **Base URL** – `http://localhost:7860`. Обращается к программе Stable Diffusion Web UI, запущенной на вашем компьютере. Эту программу нужно запустить с включенным программным интерфейсом. Ключ API не нужен.

## ComfyUI

Локальный сервис, стандартный **Base URL** – `http://127.0.0.1:8188`. Обращается к серверу ComfyUI, запущенному на вашем компьютере. Поддерживает свой рабочий процесс – о нем ниже. Ключ API не нужен.

## SwarmUI

Локальный сервис, стандартный **Base URL** – `http://127.0.0.1:7801`. Обращается к серверу SwarmUI, который умеет распределять работу ComfyUI по собственной очереди. Для локального сервера без аккаунтов ключ API не нужен. Если ваш сервер SwarmUI требует аккаунт, вставьте Swarm Auth Token (токен авторизации SwarmUI) в поле **API Key**. **Fetch Models from API** показывает модели на вашем сервере SwarmUI.

Поле **ComfyUI Workflow** для SwarmUI необязательно. Оставьте его пустым, чтобы использовать собственные настройки изображений SwarmUI, или вставьте рабочий процесс – о нем ниже. Включите **Save images in SwarmUI** (сохранять изображения в SwarmUI) в **Local Image Defaults**, чтобы каждое изображение также сохранялось в папке вывода SwarmUI. Marinara в любом случае хранит свою копию.

## Draw Things

Локальный сервис, стандартный **Base URL** – `http://localhost:7860`. Обращается к приложению Draw Things на macOS или iOS. Marinara работает с ним так же, как с сервером AUTOMATIC1111. Ключ API не нужен.

## Локальные сервисы в вашей сети

Слово `localhost` (его же называют петлевым адресом) означает тот самый компьютер, на котором работает Marinara. Локальные серверы изображений на этом же компьютере работают без дополнительной настройки.

Если сервер изображений запущен на другом компьютере домашней сети, в настройках сервера нужно разрешить адреса локальной сети. Как это сделать, описано в руководстве [Настройки сервера: справочник](../CONFIGURATION.md).

Иногда провайдер возвращает не сами данные изображения, а ссылку. Публичные адреса CDN приложение Marinara скачивает через обычные проверки безопасности исходящих запросов. Ссылку на частный или петлевой адрес Marinara принимает только тогда, когда протокол, имя узла и порт в точности совпадают с настроенным провайдером изображений. Переадресация с этого частного адреса не может увести на другую локальную службу. Если локальный прокси хранит результаты на другом частном адресе, настройте его так, чтобы файлы отдавались с того же адреса, что и интерфейс изображений.

## Рабочий процесс ComfyUI в формате JSON и RunPod

Для сервисов **ComfyUI**, **SwarmUI** и **RunPod Serverless (ComfyUI)** появляется поле **ComfyUI Workflow**. Вставьте в него рабочий процесс в формате JSON, экспортированный из ComfyUI командой **Save (API Format)**, **Export (API)** или **Export to API** – название зависит от версии интерфейса. Для **ComfyUI** и **SwarmUI** поле помечено как необязательное, для **RunPod Serverless (ComfyUI)** – как обязательное.

Marinara подставляет значения в рабочий процесс через специальные подстановки. Расставьте эти текстовые подстановки в тех местах, куда должно попасть значение.

- `%prompt%` и `%negative_prompt%` – промпты, то есть текст, который Marinara отправляет модели.
- `%width%`, `%height%` и `%seed%` – размер изображения и зерно, то есть начальное число генератора.
- `%model%`, `%steps%`, `%cfg%`, `%sampler%`, `%scheduler%` и `%denoise%` – настройки генерации.
- `%reference_image%` и от `%reference_image_01%` до `%reference_image_04%` – вставка данных референсных изображений.
- `%reference_image_name%` и от `%reference_image_name_01%` до `%reference_image_name_04%` – загрузка референсных изображений и вставка их имен файлов для узла LoadImage в локальном ComfyUI.

Главная подстановка – `%prompt%`. Если ее нет, редактор выдает предупреждение. Для **ComfyUI** пустое поле означает встроенный рабочий процесс по умолчанию. Для **SwarmUI** пустое поле означает собственные настройки изображений SwarmUI. Для **RunPod Serverless (ComfyUI)** рабочий процесс обязателен, потому что у точки подключения нет своего варианта по умолчанию. Все три принимают до 4 референсных изображений в виде данных base64. Подстановки с именами загруженных файлов доступны только для локального ComfyUI.

Полный порядок экспорта, примеры JSON, правила кавычек вокруг подстановок, настройка референсных изображений, отдельные рабочие процессы для персонажей, доступ по локальной сети и разбор проблем – в руководстве [Настройка рабочего процесса ComfyUI](comfyui.md).

## Панель Local Image Defaults для подключения

Если выбран сервис **SD Web UI (AUTOMATIC1111 / Forge)**, **ComfyUI**, **NovelAI**, **Draw Things**, **Arli AI**, **SwarmUI** или **RunPod Serverless (ComfyUI)**, у подключения появляется панель **Local Image Defaults**. Для **Draw Things** и **Arli AI** панель показывает те же поля и те же значения, что и для **SD Web UI (AUTOMATIC1111 / Forge)**. Для **SwarmUI** и **RunPod Serverless (ComfyUI)** она показывает те же поля и значения, что и для **ComfyUI**. Эти настройки действуют только тогда, когда изображение генерирует именно это подключение. Кнопка **Reset** (сбросить) возвращает встроенные значения.

У всех этих сервисов есть поле **Seed**. Значение -1 оставляет каждое изображение случайным. Любое другое число заставляет использовать одно и то же зерно каждый раз.

Остальные поля зависят от сервиса.

| Сервис | Поле | По умолчанию |
| --- | --- | --- |
| AUTOMATIC1111 / Forge | Steps | 20 |
| AUTOMATIC1111 / Forge | CFG Scale | 7 |
| AUTOMATIC1111 / Forge | Sampler | Euler a |
| AUTOMATIC1111 / Forge | Img2Img Denoise | 0.6 |
| ComfyUI | Steps | 20 |
| ComfyUI | CFG Scale | 7 |
| ComfyUI | Sampler | euler_ancestral |
| ComfyUI | Scheduler | normal |

| NovelAI | Steps | 28 |

У каждого сервиса есть также текстовые поля **Prompt Prefix** и **Negative Prefix**. Написанный там текст добавляется в начало каждого промпта этого подключения. У AUTOMATIC1111 / Forge и ComfyUI есть поле **Clip Skip**. У AUTOMATIC1111 / Forge дополнительно появляется переключатель **Restore faces**. У ComfyUI появляется переключатель **Upload a 1x1 placeholder when no reference image is provided**. Он важен только для своих рабочих процессов с подстановками референсных изображений. У NovelAI добавляются поля **Guidance Rescale** и **UC Preset**.

## Поддержка референсных изображений разная у разных провайдеров

Референсное изображение – это готовая картинка, которую вы отправляете вместе с промптом. Она помогает сохранить в новом изображении лицо персонажа или стиль рисунка. Провайдеры принимают разное количество таких картинок.

| Провайдер | Референсные изображения |
| --- | --- |
| OpenAI (DALL-E) | До 16, только модели GPT Image |
| ChatGPT (Codex login) | До 16 |
| NovelAI | До 16, только на модели V4.5 |
| xAI / Grok Imagine | До 3 |
| Venice.ai | Не поддерживаются при генерации по тексту |
| Z.AI | Не поддерживаются в текущей интеграции – только генерация по тексту |
| Atlas Cloud | Первое изображение, для подходящих идентификаторов моделей image-to-image, edit или Kontext |
| SpicyAPI | Только модели редактирования, в пределах лимита модели; слишком большие изображения уменьшаются до допустимого размера |
| NanoGPT | До 3 |
| Stability AI | Только первое изображение, в режиме image to image |
| Arli AI | Только первое изображение, в режиме image to image |
| SD Web UI (AUTOMATIC1111 / Forge) и Draw Things | Только первое изображение, в режиме image to image |
| OpenRouter Images | Поддерживаются, без жесткого предела |
| ComfyUI и RunPod Serverless (ComfyUI) | До 4, через подстановки в рабочем процессе |
| SwarmUI | До 4 |
| Together AI, Pollinations, Stable Horde, fal.ai | Не поддерживаются |

Точные референсные изображения NovelAI работают только на модели версии V4.5, например `nai-diffusion-4-5-full`. Сервис NovelAI еще не выпустил Precise Reference для V5. При запросе референсов на другой модели Marinara генерирует изображение без них и записывает предупреждение в лог сервера.

## Очередь запросов на генерацию медиа

Переключатель **Queue media generation requests** (ставить запросы генерации медиа в очередь) находится в **Settings** (настройки), далее **Generations**, далее **Overall Generations**. По умолчанию он включен.

Когда он включен, Marinara отправляет задачи на изображения каждому аккаунту провайдера изображений по одной, а задачи на видео каждому аккаунту провайдера видео тоже по одной, в отдельных очередях. Изображение и видео для одного и того же аккаунта могут выполняться одновременно. Это действует независимо от того, какая функция их запрашивает: Illustrator, трекеры, команды, галерея, ресурсы Game и скачанные агенты вроде Slurp. Два подключения с одинаковыми адресом и ключом API используют общую соответствующую очередь. Разные аккаунты и провайдеры по-прежнему работают одновременно. Для NovelAI между задачами также делается короткая пауза. Когда NovelAI отвечает, что занят, Marinara ждет и дважды пробует снова, вместо того чтобы завершить изображение ошибкой.

Оставьте его включенным для сервисов, которые не принимают два запроса одновременно. Выключайте только в том случае, если сервис справляется с множеством одновременных запросов, а вы хотите получить результат быстрее.
