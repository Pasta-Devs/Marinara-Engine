# Провайдеры генерации изображений и их настройка

На генерации изображений работают иллюстрации сцен, селфи, фоны сцен, а также сгенерированные аватары, портреты и спрайты. Это руководство показывает, как добавить сервис изображений и что нужно каждому сервису. Как только одна модель изображений заработает, ее смогут использовать все функции приложения, связанные с изображениями.

## Добавление сервиса изображений

Ключ API – это секретный код, который выдает сервис, чтобы Marinara могла пользоваться вашим аккаунтом. Веб-адрес каждого сервиса Marinara подставляет сама, поэтому вводить его приходится редко.

1. Нажмите **Connections** (подключения) на верхней панели, затем **Add** (добавить). Откроется окно **Add account** (добавить аккаунт).
2. Найдите сервис. В списке есть раздел **Images & video** (изображения и видео), а поле **Search providers** (искать провайдеров) помогает найти нужный сервис.
3. Вставьте ключ в поле **API key** (ключ API). Бесплатным и локальным сервисам он не нужен. Для сервера, который вы запускаете сами, заполните поле адреса.
4. Нажмите **Connect** (подключиться). Marinara проверяет аккаунт.
5. Выберите модель изображений в списке или введите идентификатор модели. Это и есть ваша модель изображений. Она появится под аккаунтом в панели **Connections**.
6. Откройте модель изображений и нажмите **Test image** (проверить изображение). Marinara создаст небольшое тестовое изображение.
7. Чтобы приложение использовало эту модель для изображений, задайте ее для задачи **Images** (изображения) в блоке **Defaults** (по умолчанию) вверху панели **Connections**.

Чтобы добавить к аккаунту еще одну модель изображений, откройте его меню **⋯** и нажмите **Add image model** (добавить модель изображений). Окно целиком описано в руководстве [Подключение к провайдеру ИИ](../connections/connecting-to-a-provider.md).

Если не получилось: **Test image** не проходит, когда неверен ключ или адрес. Сначала проверьте и то и другое. **Test provider** (проверить провайдера) проверяет только, может ли Marinara связаться с сервисом. **Test image** создает настоящее изображение и может расходовать кредиты.

## Как получить изображение в чате

Когда модель изображений задана для задачи **Images**, изображение можно запросить в чате.

1. Добавьте агента Illustrator в чат Roleplay. См. [Агент Illustrator](illustrator-agent.md).
2. Откройте **Chat Settings** (настройки чата), разверните **Gallery** (галерея) и нажмите **Illustrate** (проиллюстрировать).
3. Дождитесь, пока закончится **Generating...**. Изображение появится в галерее.

В чате Roleplay можно также воспользоваться командой `/illustrate`. См. [Справочник слеш-команд](../chats/slash-commands.md).

## Выбор сервиса

Адрес каждого сервиса Marinara подставляет сама. Облачным сервисам нужен аккаунт, а большинству из них – еще и ключ API. Бесплатным сервисам ключ не нужен. Локальные сервисы запускают программу генерации изображений на вашем компьютере.

**Самый простой старт:** выберите **Pollinations**. Этот сервис бесплатный, и ему не нужны ни аккаунт, ни ключ. Если захотите изображения получше, позже выберите сервис посильнее.

| Сервис | Ключ API | Где работает |
| --- | --- | --- |
| OpenAI (DALL-E) | Да | Облако |
| ChatGPT (Codex login) | Нет, используется `codex login` | Облако |
| Stability AI | Да | Облако |
| Together AI | Да | Облако |
| Arli AI | Да | Облако |
| NovelAI | Да | Облако |
| OpenRouter Images | Да | Облако |
| xAI / Grok Imagine | Да | Облако |
| Venice.ai | Да | Облако |
| Z.AI | Да | Облако |
| Atlas Cloud | Да | Облако |
| fal.ai | Да | Облако |
| SpicyAPI | Да | Облако |
| NanoGPT | Да | Облако |
| Block Entropy | Да | Облако |
| RunPod Serverless (ComfyUI) | Да | Облако |
| Pollinations | Нет | Бесплатное облако |
| Stable Horde | Необязательно | Бесплатное облако |
| SD Web UI (AUTOMATIC1111 / Forge) | Нет | Локально |
| ComfyUI | Нет | Локально |
| SwarmUI | Необязательно | Локально |
| Draw Things | Нет | Локально |

Заметки о простых сервисах:

- **OpenAI (DALL-E)**: предлагает модели DALL-E и GPT Image.
- **Stability AI**: модели Stable Diffusion и Stable Image.
- **Together AI**: FLUX и другие открытые модели изображений.
- **OpenRouter Images**: обращается к моделям изображений через чат-интерфейс OpenRouter, поэтому набор моделей зависит от аккаунта.
- **xAI / Grok Imagine**: использует Grok Imagine.
- **NanoGPT**: агрегатор, поэтому пользуйтесь его списком моделей.
- **Pollinations**: самый быстрый способ попробовать генерацию изображений. Аккаунт не нужен.
- **Stable Horde**: сеть из компьютеров добровольцев. Бесплатный ключ дает более высокий приоритет в очереди.
- **SD Web UI** и **Draw Things**: запускайте программу с включенным программным интерфейсом. Marinara работает с Draw Things так же, как с сервером AUTOMATIC1111 (приложение работает на macOS или iOS).
- **Block Entropy**: отдельного обработчика для него в Marinara нет, поэтому запросы уходят в формате, совместимом с OpenAI. Совместимость не подтверждена. Прежде чем полагаться на сервис, проверьте его кнопкой **Test image**.

## Сервисы с особой настройкой

### ChatGPT (Codex login)

Этот сервис вместо ключа API использует ваш тариф ChatGPT, поэтому для изображений не нужны кредиты API OpenAI.

1. На компьютере, где работает Marinara, установите Codex CLI и один раз выполните `codex login`. Это тот же вход, который использует аккаунт ChatGPT для чата. См. [Подключения по подписке Claude, ChatGPT и Grok](../connections/subscription-clis.md#openai-chatgpt).
2. Выберите сервис. Ни ключ, ни адрес заполнять не нужно. Marinara сама подставляет модель `gpt-image-2` – ту, которую Codex использует для изображений.

**Test provider** проверяет только, может ли Marinara прочитать ваш вход в Codex. **Test image** создает настоящее изображение и расходует ваши лимиты на изображения в ChatGPT. Если есть референсные изображения, Marinara отправляет запрос на редактирование и прикладывает до 16 из них. ChatGPT может вернуть изображение другого размера в пикселях, поэтому Marinara дополнительно указывает нужное соотношение сторон в промпте. Этот сервис обращается к эндпоинту изображений ChatGPT, которым пользуется Codex, а не к публичному API OpenAI, поэтому OpenAI может изменить его без предупреждения.

### Arli AI

Сервис запускает размещенные модели Stable Diffusion. Модель обязательна, поэтому впишите название нужной модели изображений Arli AI. Он использует те же поля **Local Image Defaults** (стандартные настройки локальных изображений), что и SD Web UI (см. [Local Image Defaults](#local-image-defaults-per-connection)). Первое референсное изображение используется как исходная картинка. Этот сервис предназначен только для изображений. О чат-моделях Arli AI читайте в руководстве [Поддерживаемые провайдеры ИИ](../connections/providers-reference.md#arli-ai).

### NovelAI

NovelAI специализируется на рисунках в стиле аниме. Для моделей V4, V4.5 и V5 Marinara отправляет нативные промпты для каждого персонажа с их позициями в раскадровках и сценах Illustrator с несколькими персонажами. Точные референсные изображения работают только на модели V4.5.

### Venice.ai

Marinara обращается к собственному эндпоинту изображений Venice, отключает необязательное размытие безопасного режима Venice и приводит запрошенные размеры к формату размеров каждой модели. Собственные правила Venice или ограничения модели все равно могут отклонить запрос.

### Z.AI

Используйте обычный ключ API сервиса Z.AI. Ключи тарифа GLM Coding Plan и адрес `/api/coding/paas/v4` для изображений не подходят. Выберите **GLM-Image** или **CogView 4**. Marinara приводит соотношение сторон к размеру, который поддерживает модель, и скачивает временный результат в локальное хранилище. Сервис работает только с генерацией по тексту и не отправляет референсные изображения.

### Atlas Cloud

Marinara загружает актуальный каталог Atlas Cloud для генерации изображений по тексту и на основе изображения. Если загрузить его не удается, она показывает начальный список (Nano Banana, Gemini Flash Image, FLUX 1.1 Pro). Точный идентификатор модели всегда можно ввести вручную. Задания выполняются асинхронно, поэтому Marinara запускает задание и опрашивает сервис, пока изображение не будет готово. Референсные изображения отправляются моделям, чьи идентификаторы указывают на поддержку image-to-image, редактирования или Kontext. Схемы моделей Atlas различаются, поэтому для других идентификаторов сверяйтесь с документацией модели в Atlas Cloud.

### fal.ai

Создайте ключ API на [fal.ai](https://fal.ai/dashboard/keys). В начальном списке есть `fal-ai/flux/schnell` и `fal-ai/flux/dev`. Можно ввести ID другого эндпоинта генерации по тексту с совместимыми входом и выходом. **Test provider** проверяет только настройку. **Test image** отправляет настоящий запрос и расходует кредиты fal.ai.

Marinara отправляет промпт и размеры и скачивает первое возвращенное изображение. Негативные промпты добавляются как текст. Для настроек модели, например `seed`, `num_inference_steps` или `image_size`, используйте **Custom Parameters** (свои параметры). Сервис использует синхронные запросы генерации по тексту, не отправляет референсные изображения и не возобновляет прерванные задания. См. [справочник API](https://fal.ai/models/fal-ai/flux/schnell/api) модели.

### SpicyAPI

Создайте ключ в [консоли SpicyAPI](https://spicyapi.ai/console/keys) и выберите **SpicyAPI**. Marinara подставляет модель `alibaba/z-image-spicy-pro/text-to-image`. Можно ввести другой ID, например `bytedance/seedream-5.0-pro/text-to-image`. **Test provider** читает список моделей, поэтому ничего не стоит. **Test image** создает настоящее изображение и расходует ваш баланс.

Выбирайте именно сервис **SpicyAPI**. Не используйте **OpenAI (DALL-E)** или совместимый с OpenAI аккаунт с адресом SpicyAPI. Адрес SpicyAPI в стиле OpenAI работает только с текстом.

У каждой модели свои настройки. Marinara спрашивает у SpicyAPI, какие из них принимает модель, и отправляет только их, выбирая самый близкий из предложенных вариантов (соотношение сторон, ширина и высота или фиксированный размер). Если у модели нет поля для негативного промпта, негативный промпт добавляется в конец промпта. Для других настроек, например `seed`, `resolution` или `loras`, используйте **Custom Parameters**.

Каждое изображение – это задание. Marinara ждет, примерно через минуту проверяет его снова, затем скачивает результат. Если соединение обрывается, Marinara подхватывает то же задание, а не платит за новое. Модели редактирования (ID которых заканчиваются на `/edit`) получают ваши референсные изображения. SpicyAPI принимает до 1 МБ на изображение и до 2 МБ на запрос, поэтому Marinara уменьшает изображения побольше и не отправляет лишние, которые не помещаются.

### SwarmUI

SwarmUI умеет распределять работу ComfyUI по собственной очереди. Локальному серверу без аккаунтов ключ не нужен. Если ваш сервер требует аккаунт, вставьте Swarm Auth Token (токен авторизации SwarmUI) в поле **API key**. Список моделей показывает модели на вашем сервере SwarmUI.

Поле **ComfyUI workflow (optional)** (рабочий процесс ComfyUI, необязательно) можно оставить пустым. Оставьте его пустым, чтобы использовать собственные настройки изображений SwarmUI, или вставьте рабочий процесс (см. ниже). Включите **Save images in SwarmUI** (сохранять изображения в SwarmUI) в **Local Image Defaults**, чтобы каждое изображение также сохранялось в папке вывода SwarmUI. Marinara в любом случае хранит свою копию.

### Локальные сервисы в вашей сети

`localhost` означает компьютер, на котором работает Marinara. Локальные серверы изображений на этом компьютере работают без дополнительной настройки. Если сервер запущен на другом компьютере вашей сети, разрешите адреса локальной сети в настройках сервера. См. [Настройки сервера: справочник](../CONFIGURATION.md).

Если сервис возвращает не данные изображения, а ссылку, публичные адреса CDN Marinara скачивает через обычные проверки исходящих запросов. Ссылку на частный или петлевой адрес Marinara принимает только тогда, когда протокол, имя узла и порт в точности совпадают с настроенным сервисом изображений. Переадресация с этого адреса не может увести на другую локальную службу. Если локальный прокси хранит результаты на другом частном адресе, настройте его так, чтобы эти файлы отдавались с того же адреса, что и его API изображений.

## Рабочий процесс ComfyUI в формате JSON и RunPod

Для **ComfyUI**, **SwarmUI** и **RunPod Serverless (ComfyUI)** появляется поле **ComfyUI workflow (optional)** или **(required)**. Вставьте в него рабочий процесс в формате JSON, экспортированный из ComfyUI командой **Save (API Format)**, **Export (API)** или **Export to API** – в зависимости от версии ComfyUI. Для ComfyUI и SwarmUI поле необязательно, а для RunPod обязательно: RunPod нужны ваш токен API RunPod в качестве ключа API, **RunPod endpoint ID** (идентификатор эндпоинта RunPod) и рабочий процесс.

Расставьте в рабочем процессе эти текстовые метки там, куда Marinara должна подставить значение:

- `%prompt%` и `%negative_prompt%` – для промптов.
- `%width%`, `%height%` и `%seed%` – для размера и зерна.
- `%model%`, `%steps%`, `%cfg%`, `%sampler%`, `%scheduler%` и `%denoise%` – для настроек генерации.
- `%reference_image%` и от `%reference_image_01%` до `%reference_image_04%` – для данных референсных изображений.
- `%reference_image_name%` и от `%reference_image_name_01%` до `%reference_image_name_04%` – чтобы загрузить референсные изображения и подставить имена их файлов для узла LoadImage в локальном ComfyUI.

Важнее всего `%prompt%`. Если его нет, редактор предупреждает об этом. Для ComfyUI пустое поле означает встроенный рабочий процесс по умолчанию. Для SwarmUI – собственные настройки SwarmUI. У RunPod варианта по умолчанию нет, поэтому рабочий процесс обязателен. Все три принимают до 4 референсных изображений в сыром base64. Подстановки с загрузкой имен файлов работают только для локального ComfyUI.

Полный порядок экспорта, примеры, правила кавычек, референсные изображения, отдельные рабочие процессы для персонажей, доступ по сети и устранение неполадок описаны в руководстве [Настройка рабочего процесса ComfyUI](comfyui.md).

## Панель Local Image Defaults для подключения

Панель **Local image defaults** появляется у модели изображений для сервисов **SD Web UI (AUTOMATIC1111 / Forge)**, **ComfyUI**, **NovelAI**, **Draw Things**, **Arli AI**, **SwarmUI** и **RunPod Serverless (ComfyUI)**. Draw Things и Arli AI показывают поля SD Web UI. SwarmUI и RunPod показывают поля ComfyUI. Эти настройки действуют только тогда, когда изображение создает эта модель. **Reset** (сбросить) возвращает встроенные значения.

У каждого сервиса есть поле **Seed** (зерно). Значение -1 оставляет каждое изображение случайным. Любое другое число каждый раз использует это же зерно. Остальные поля зависят от сервиса.

| Сервис | Поле | По умолчанию |
| --- | --- | --- |
| AUTOMATIC1111 / Forge | Steps | 20 |
| AUTOMATIC1111 / Forge | CFG scale | 7 |
| AUTOMATIC1111 / Forge | Sampler | Euler a |
| AUTOMATIC1111 / Forge | Img2img denoise | 0.6 |
| ComfyUI | Steps | 20 |
| ComfyUI | CFG scale | 7 |
| ComfyUI | Sampler | euler_ancestral |
| ComfyUI | Scheduler | normal |
| ComfyUI | Denoise | 1 |
| NovelAI | Steps | 28 |
| NovelAI | Prompt guidance | 6 |
| NovelAI | Sampler | k_euler_ancestral |
| NovelAI | Noise schedule | karras |

У каждого сервиса есть также поля **Prompt prefix** (префикс промпта) и **Negative prefix** (негативный префикс). Текст из них добавляется в начало каждого промпта этой модели. У AUTOMATIC1111 / Forge и ComfyUI есть поле **Clip skip**. AUTOMATIC1111 / Forge добавляет переключатель **Restore faces** (восстанавливать лица). ComfyUI добавляет переключатель, который загружает заглушку 1x1, если референсное изображение не передано. Он важен только для своих рабочих процессов с подстановками референсов. NovelAI добавляет **Guidance rescale** и **UC preset**.

## Поддержка референсных изображений зависит от сервиса

Референсное изображение – это готовая картинка, которую вы отправляете вместе с промптом, чтобы в новом изображении сохранились лицо персонажа или стиль рисунка.

| Сервис | Референсные изображения |
| --- | --- |
| OpenAI (DALL-E) | До 16, только модели GPT Image |
| ChatGPT (Codex login) | До 16 |
| NovelAI | До 16, только на модели V4.5 |
| xAI / Grok Imagine | До 3 |
| NanoGPT | До 3 |
| ComfyUI, RunPod Serverless (ComfyUI), SwarmUI | До 4, через подстановки в рабочем процессе |
| Stability AI, Arli AI, SD Web UI, Draw Things | Только первое изображение, в режиме image to image |
| Atlas Cloud | Первое изображение, для подходящих идентификаторов моделей image-to-image, edit или Kontext |
| SpicyAPI | Только модели редактирования, в пределах лимита модели, с уменьшением до допустимого размера |
| OpenRouter Images | Поддерживаются, без жесткого предела |
| Venice.ai, Z.AI | Не поддерживаются при генерации по тексту |
| Together AI, Pollinations, Stable Horde, fal.ai | Не поддерживаются |

Точные референсы NovelAI работают только на модели V4.5, например `nai-diffusion-4-5-full`. NovelAI еще не выпустил Precise Reference для V5. Если запросить референсы на другой модели, Marinara создаст изображение без них и запишет предупреждение в журнал сервера.

## Очередь запросов на генерацию медиа

Переключатель **Queue media generation requests** (ставить запросы генерации медиа в очередь) находится в **Settings → Generations → Overall Generations** (настройки → генерации → общие настройки генерации). По умолчанию он включен.

Когда он включен, Marinara отправляет задачи на изображения каждому аккаунту изображений по одной, а задачи на видео каждому аккаунту видео тоже по одной, в отдельных очередях. Изображение и видео для одного и того же аккаунта могут выполняться одновременно. Это действует для всех функций, которые их запрашивают: Illustrator, трекеры, команды, галерея, ресурсы Game и скачанные агенты вроде Slurp. Две модели с одинаковыми адресом и ключом API используют общую очередь. Разные аккаунты по-прежнему работают одновременно. Для NovelAI между задачами также делается короткая пауза, а когда NovelAI отвечает, что занят, Marinara ждет и пробует еще два раза.

Оставьте его включенным для сервисов, которые отклоняют два запроса одновременно. Выключайте его, только если ваш сервис справляется с множеством запросов сразу, а вам нужна скорость.
