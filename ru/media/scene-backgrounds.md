# Фоны сцены и галерея

Это руководство объясняет, как работают фоны сцены – картинки, которые ИИ создает для вас из **Gallery** (галерея), – и как устроена сама галерея. Есть еще два близких руководства: [Фоны чата](../appearance/chat-backgrounds.md) рассказывает о библиотеке загруженных картинок, которые вы выбираете вручную, а [Фоны в режиме Roleplay](../roleplay/backgrounds.md) – об агенте, который сам подбирает фон на каждом ходу.

## Где работают фоны сцены

Фоны сцены работают в режимах Roleplay и Game Mode. В режиме Conversation они недоступны. При попытке сгенерировать фон в режиме Conversation приложение показывает такое сообщение:

```
Scene background generation is available in Roleplay and Game modes.
```

Для генерации фона нужно подключение **Image Generation** (генерация изображений). Если его еще нет, сначала настройте его. См. [Провайдеры генерации изображений и их настройка](image-providers.md).

## Генерация и применение фона из галереи

**Gallery** хранит изображения и видео чата. Это раздел **Chat Settings** (настройки чата): откройте Chat Settings и разверните **Gallery**. На компьютере раздел можно вынести в отдельное окно (см. [Обзор настроек чата](../chats/chat-settings.md#popping-a-section-out-into-its-own-window)). Кнопка **Background** (фон) создает фон для текущей сцены.

Как сгенерировать фон:

1. Откройте раздел **Gallery** в **Chat Settings**.
2. Нажмите кнопку **Background**.
3. Пока изображение создается, надпись на кнопке меняется на **Generating...**.
4. Появляется сообщение о статусе: "AI background generation is running. The new background will be applied when it finishes."
5. По завершении новое изображение сразу применяется к текущей сцене. Это подтверждает сообщение "Background generated."

Фон строится по текущей сцене. В игре учитываются жанр, антураж, локация, погода и время суток. Готовые фоны берут размер холста **Backgrounds**, по умолчанию это 1280 на 720 пикселей. Размер меняется в панели **Settings** (настройки), затем **Generations**, затем **Image Generation**.

### Если подключение для изображений не выбрано

Если Marinara не находит подходящее подключение для изображений, генерация прерывается таким сообщением:

```
Choose an image generation connection for the Illustrator agent, or mark one as the default image connection.
```

Чтобы это исправить, откройте панель **Connections** (подключения), разверните раздел **Defaults** и выберите подключение в разделе **Images**. Другой вариант – задать отдельное подключение для изображений у агента **Illustrator**.

## Раздел Gallery

В панели **Gallery** две вкладки: **Images** и **Videos**. Рядом с названием каждой вкладки видно число элементов. Вкладка **Videos** доступна только тогда, когда для чата включены видео сцены.

Кнопки действий сверху раздела появляются только тогда, когда соответствующая возможность применима к чату:

- **Illustrate**: запускает агента Illustrator и создает одно изображение сцены. См. [Агент Illustrator](illustrator-agent.md).
- **Selfie**: создает селфи персонажа в режиме Conversation.
- **Background**: генерирует фон сцены и сразу применяет его, как описано выше.
- **Video**: делает видео сцены по последней иллюстрации.
- **Create storyboard**: создает ключевые кадры для последнего хода режима Game Mode или для завершенного эпизода режима Roleplay, когда включена раскадровка.
- **Browse Images**: открывает браузер сохраненных изображений, откуда их можно вставить.
- **View storyboard**: открывает последнюю раскадровку режима Game Mode.

Под кнопками находится область **Upload Images** для перетаскивания файлов. Перенесите на нее картинки, чтобы добавить свои изображения в галерею этого чата.

### Действия с отдельным изображением

Наведите указатель на любое изображение на вкладке **Images** (на телефоне – коснитесь его), чтобы увидеть доступные действия:

- Открыть изображение в полном размере (**Open gallery image**).
- **Pin to chat**: закрепляет изображение в чате.
- **Download image**: сохраняет изображение на устройство.
- **Animate illustration**: превращает это изображение в видео сцены.
- **Copy prompt**: копирует сохраненный промпт изображения. Если промпт не сохранен, кнопка показывает **No prompt saved** и не работает.
- **Delete gallery image**: удаляет изображение после подтверждения.

## Проверка промпта перед отправкой

Промпт можно посмотреть и изменить до того, как Marinara отправит запрос на фон провайдеру изображений.

1. Откройте панель **Settings**, затем **Generations**, затем **Image Generation**.
2. Включите переключатель **Expose media prompts before sending**.

Когда эта настройка включена, перед каждым запросом открывается окно **Review Image Prompt**. Пояснение в нем читается так: "Edit the prompt below before Marinara sends the image request to your provider."

В этом окне можно:

- Изменить текст промпта и негативный промпт.
- Посмотреть тип и размер изображения, а также счетчик символов, который обновляется на ходу.
- Нажать кнопку **Cancel**, чтобы отменить отправку, или **Generate**, чтобы отправить запрос.

Если хотя бы одно поле промпта пустое, кнопка **Generate** не работает и появляется примечание: "Every image request needs a prompt." Текст отправляется точно в том виде, в котором вы его набрали.

## Управление сохраненными фонами

Каждый сгенерированный фон сцены попадает в библиотеку фонов. В эту же библиотеку можно добавлять свои изображения. Для загрузки подходят файлы JPG, PNG, GIF, WebP и AVIF размером до 20 МБ каждый.

Фоны, которые вы добавили, можно переименовывать, помечать тегами и удалять. Теги пишутся строчными буквами и допускают буквы, цифры, пробелы, дефисы и подчеркивания – до 40 символов каждый. Рядом с вашими фонами показываются встроенные игровые фоны, но их нельзя переименовать, отметить тегом или удалить.

Библиотека управляется из настроек оформления – там же выбирается фон для отдельного чата или фон по умолчанию. Про всю библиотеку, окно выбора и настройку **Background Blur** читайте в руководстве [Фоны чата](../appearance/chat-backgrounds.md).
