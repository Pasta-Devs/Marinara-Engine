# Настройка синтеза речи (TTS)

В этом руководстве вы узнаете, как настроить синтез речи в приложении Marinara Engine, чтобы сообщения и игровое повествование звучали вслух. Синтез речи (TTS) превращает написанный текст чата в звучащую речь. Здесь описан выбор провайдера голоса, подбор голосов, автовоспроизведение и кнопки воспроизведения у каждого сообщения.

## Где находятся настройки TTS

Почти все настройки TTS собраны в одном месте. Откройте панель **Connections** (подключения) и найдите карточку **Text to Speech**. По умолчанию карточка свернута – нажмите на ее заголовок, чтобы раскрыть.

Запросы TTS приложение отправляет через собственный сервер. Ключ API провайдера хранится на сервере в зашифрованном виде. После сохранения в поле видна маскировка – ряд точек вместо настоящего ключа. Настоящий ключ никогда не возвращается в браузер.

Включение TTS само по себе ничего не озвучивает. Оно лишь показывает кнопку **Speak** (озвучить) у каждого сообщения и настройки **Auto-play** (автовоспроизведение). Что и когда читать, вы решаете сами.

В тех же настройках воспроизведения можно включить **Skip text inside HTML and custom tags** (пропускать текст внутри HTML- и пользовательских тегов), **Skip fenced code blocks** (пропускать огражденные блоки кода) или **Skip text inside square brackets** (пропускать текст в квадратных скобках). Блоки кода пропускаются по умолчанию, остальные два фильтра изначально выключены. Фильтр тегов удаляет заключенный в них текст, например скрытый блок `<simulation>...</simulation>`, но сохраняет теги говорящих для выбора голосов. Фильтры действуют при ручном и автоматическом воспроизведении, включая повествование Game и определение говорящих в Roleplay.

## Шаг 1: включите TTS и выберите Source

1. Откройте панель **Connections** и раскройте карточку **Text to Speech**.
2. Нажмите переключатель в заголовке карточки, чтобы включить TTS. Наведите на него курсор, и появится всплывающая подсказка: **Enable TTS** в выключенном состоянии и **Disable TTS** во включенном.
3. Откройте раскрывающийся список **Source** (источник) и выберите провайдера.

**Source** – это служба, которая создает звук. Доступны четыре варианта:

- **OpenAI-compatible**: OpenAI или любой сервер, повторяющий формат TTS от OpenAI.
- **ElevenLabs**: голосовая служба ElevenLabs.
- **PocketTTS**: бесплатный голосовой сервер, который запускается на вашем компьютере.
- **xAI Voice**: голосовая служба xAI.

По умолчанию выбран источник **OpenAI-compatible**. Marinara хранит отдельный профиль настроек для каждого источника: зашифрованный ключ API, адрес, модель, голоса и параметры провайдера. При переключении источника возвращаются его прежние настройки, а еще не настроенный источник начинает со стандартных значений.

## Шаг 2: укажите Base URL, API Key и Model

Каждому источнику нужен веб-адрес, а почти всем – еще и ключ API. Ключ API – это секретный код от провайдера, который подтверждает, что запрос исходит от вас.

1. Проверьте поле **Base URL** (базовый адрес). Для каждого источника подставляется разумное значение по умолчанию, они собраны в таблице ниже. Меняйте его только при работе через прокси или со своим сервером.
2. Вставьте ключ провайдера в поле **API Key** (ключ API). Чтобы сохранить прежний ключ, не трогайте точки маскировки. Чтобы удалить сохраненный ключ, очистите поле.
3. Проверьте поле **Model** (модель). Для каждого источника подставляется модель по умолчанию. Можно вписать название другой модели, которую поддерживает провайдер.

Приложение подставляет такие значения по умолчанию:

| Source            | Base URL по умолчанию     | Модель по умолчанию    | Голос, который подставляется сразу |
| ----------------- | ------------------------- | ---------------------- | ------------------------------- |
| OpenAI-compatible | https://api.openai.com/v1 | tts-1                  | alloy                           |
| ElevenLabs        | https://api.elevenlabs.io | eleven_multilingual_v2 | нет (нужно выбрать самостоятельно) |
| PocketTTS         | http://localhost:49112    | pocket-tts             | alba                            |
| xAI Voice         | https://api.x.ai/v1       | grok-tts               | eve                             |

Для **ElevenLabs** поле **Model** загружает речевые модели, доступные через ваше подключение, и всегда показывает список целиком. Выбирайте обычную речевую модель. Идентификаторы моделей с фрагментом `ttv` относятся к конструированию голоса, а не к речи, и читать текст вслух они не умеют. При случайном выборе такой модели воспроизведение прерывается ошибкой с просьбой указать речевую модель.

### PocketTTS – это отдельная программа

PocketTTS не входит в состав приложения Marinara Engine. Marinara обращается к серверу [PocketTTS OpenAI-compatible server](https://github.com/teddybear082/pocket-tts-openai_streaming_server), который отдает и речь, и список голосов – именно это нужно приложению. Установите и запустите этот сервер по его инструкции: Marinara не скачивает его и не управляет им.

Совместимый сервер по умолчанию работает по адресу `http://localhost:49112`. Оставьте это значение в поле **Base URL**, если не меняли порт сервера. Ранее вписанные собственные адреса PocketTTS сохраняются как есть.

## Шаг 3: выберите голос (Voice Option)

Настройка **Voice Option** (выбор голоса) определяет, как голоса распределяются между персонажами:

- **One voice for all characters**: все говорят одним голосом. Это значение по умолчанию.
- **Selected per character**: выбранным персонажам вы назначаете отдельные голоса.

### Один голос для всех персонажей

Выберите голос в поле **All Characters Voice**. Для PocketTTS в раскрывающемся списке показаны голоса, которые вернул ваш сервер, а рядом остается текстовое поле для своего идентификатора голоса, адреса или пути.

Чтобы загрузить настоящий список голосов от провайдера, заполните данные подключения и нажмите кнопку **Refresh voices** (обновить голоса) с иконкой круговой стрелки. Сделать это можно еще до включения воспроизведения. Обновление сначала сохраняет карточку, поэтому только что введенный ключ API работает сразу. До подключения приложение показывает короткий встроенный запасной список, чтобы поле не было пустым. Если провайдер вернул ошибку, приложение показывает ее, а не выдает запасной список за успешное обновление.

Для **ElevenLabs** голос выбрать обязательно. Marinara постранично загружает библиотеку аккаунта: личные, рабочие, сохраненные и стандартные голоса. В окне выбора есть поле поиска, а когда библиотека длиннее панели, полоса прокрутки видна постоянно. Там же указано, сколько голосов загружено. Изначально в окне стоит "Select an ElevenLabs voice", и до выбора настоящего голоса воспроизведение заблокировано.

### Отдельный голос для выбранных персонажей

1. Установите **Voice Option** в значение **Selected per character**.
2. Появляется таблица **Character Voices** со столбцами **Character** и **Voice**.
3. Нажмите кнопку **Add character voice** (добавить голос персонажа), чтобы добавить строку.
4. Выберите персонажа в левом раскрывающемся списке и голос в правом.
5. Повторите для каждого персонажа, которому нужен свой голос.

Кнопка **Refresh** в блоке Character Voices перезагружает ту же библиотеку провайдера, не возвращая вас к режиму одного голоса. Сначала нужно создать персонажей. Если их еще нет, приложение просит добавить персонажей на вкладке Characters, а уже потом назначать голоса. Персонажи без личного голоса говорят общим голосом. См. [Создание и редактирование персонажей](../characters/creating-and-editing-characters.md).

## Блок **Narrator Voice**

Повествование – это текст, который не произносит ни один персонаж: описание сцены или реплики ведущего игры. Ему можно дать отдельный голос.

1. В блоке **Narrator Voice** (голос рассказчика) включите **Use separate narrator voice**.
2. Выберите голос в появившемся списке.

Этот голос звучит, когда автор реплики – Narrator, GM, Game Master или System. Так работают сообщения в режимах Roleplay и Conversation. Сюда же относятся строки повествования в Game Mode без указанного автора. При работе с ElevenLabs голос рассказчика лучше выбрать здесь. Если оставить поле пустым, повествование получает запасной голос только при заданном общем голосе.

## Блок **Random NPC Voices** (только Game Mode)

Эта возможность выдает свободные голоса второстепенным игровым персонажам. Она работает только в Game Mode и только для персонажей NPC (неигровых персонажей), за которыми следит Game Mode. В Roleplay и Conversation она ничего не делает.

1. В блоке **Random NPC Voices** включите **Use default voices for random NPCs**.
2. Появляются две сетки флажков: **Male NPC defaults** и **Female NPC defaults**.
3. Отметьте голоса, из которых будет выбирать каждый набор.

Отслеживаемый персонаж NPC без личного голоса получает устойчивый вариант из подходящего набора. В течение сессии голос такого персонажа не меняется. Если персонажу NPC назначен собственный голос, он всегда сохраняется. Когда приложение не может определить, какие голоса мужские, а какие женские, каждый набор берет голоса из полного списка.

## Настройки **Audio Format** и **Speed**

Настройка **Audio Format** (формат звука) переключает **MP3** (по умолчанию) и **WAV**. Выбирайте WAV для локальных или собственных серверов, которые не умеют отдавать MP3. Два замечания:

- Для ElevenLabs настройка **Audio Format** скрыта: этот провайдер всегда работает с MP3.
- Для xAI Voice настройка видна, но ни на что не влияет. xAI Voice всегда возвращает MP3.

Ползунок **Speed** (скорость) задает, как быстро говорит голос. Допустимый диапазон зависит от источника:

- OpenAI-compatible и PocketTTS: от 0.25 до 4.0 обычной скорости.
- ElevenLabs: от 0.7 до 1.2.
- xAI Voice: от 0.7 до 1.5.

Если сохраненная скорость выходит за диапазон текущего источника, при озвучивании приложение подтягивает ее к ближайшему допустимому значению.

Только для **ElevenLabs** появляются две дополнительные настройки. **Language** (язык) жестко задает язык речи, а можно оставить значение **Auto detect**. **Stability** (стабильность) регулирует речь между более выразительной и более ровной.

## **Auto-play**: автоматическое чтение сообщений

Под заголовком **Auto-play** каждый переключатель отвечает за один вид новых сообщений: приложение читает их сразу после генерации. Все они работают только при включенном **Enable TTS**. Изначально все переключатели выключены.

- **Roleplay messages**: читает новые ответы в Roleplay.
- **Conversation messages**: читает новые ответы в Conversation Mode.
- **Game narration**: читает новое повествование и реплики боя в Game Mode.
- **Progressive playback**: если в ответе несколько строк, первая начинает звучать сразу, не дожидаясь остального текста.
- **Only read dialogues**: читает только реплики в кавычках или с пометкой речи и пропускает обычное повествование.

Автовоспроизведение срабатывает один раз – на самом новом ответе, в момент его завершения. Старые сообщения не перечитываются, когда вы открываете чат заново или прокручиваете его.

## Озвучивание одного сообщения

При включенном TTS в панели инструментов под каждым сообщением персонажа или рассказчика появляется кнопка **Speak** с иконкой микрофона. Она читает именно это сообщение по требованию.

- Нажмите кнопку **Speak**, чтобы прослушать сообщение. Пока звук загружается, кнопка показывает состояние ожидания.
- Нажмите ее еще раз во время воспроизведения, чтобы остановиться. Пока сообщение звучит, всплывающая подсказка читается **Stop speaking**.
- Сообщение без читаемого текста, например с одной картинкой, показывает **No dialogue to speak** и остается недоступным.

Во время озвучивания появляются еще две кнопки. **Pause speaking** и **Resume speaking** приостанавливают и продолжают воспроизведение. **Restart speaking** запускает сообщение с начала.

Кнопка с иконкой громкоговорителя открывает ползунок **Line volume** от 0 до 100 процентов, по умолчанию 50. Эта громкость сохраняется отдельной настройкой. Она не связана ни с микшером Game Mode, ни с громкостью звонков в Conversation, поэтому изменение одного значения не влияет на остальные.

## Блок **Cached clips**

Сгенерированный звук приложение сохраняет в браузере, чтобы не создавать одну и ту же реплику дважды. Панель **Cached clips** показывает текущее количество записей и общий размер.

Нажмите кнопку **Export cached TTS clips** (экспортировать сохраненные записи) с иконкой скачивания, чтобы сохранить все записи на устройство отдельными звуковыми файлами. Самые старые записи удаляются автоматически. Кнопки ручной очистки в приложении нет, поэтому для полной очистки удалите данные браузера.

## TTS в разных режимах чата

Одна и та же настройка TTS работает во всех режимах, но у каждого есть свои дополнения:

- Roleplay использует переключатель автовоспроизведения **Roleplay messages** и кнопки **Speak** у сообщений. См. [Режим Roleplay: начало работы](../roleplay/getting-started.md).
- Conversation Mode использует переключатель **Conversation messages** и те же кнопки **Speak**. Голосовые звонки – более крупная возможность, ей посвящено руководство [Аудио- и видеозвонки в режиме Conversation](../conversation/calls.md).
- Game Mode использует переключатель **Game narration**. Кроме того, у Game Mode есть свой звуковой микшер с каналом **TTS** рядом с **Master**, **Music**, **Sound Effects** и **Ambient**. Этот канал задает общую громкость речи в игре и начинается со 100 процентов. См. [Game Mode: начало работы](../game/getting-started.md).

## Поле **Phonetic name** (произношение в звонках)

Если имя персонажа или персоны написано так, что голос произносит его неверно, добавьте **Phonetic name** – запись произношения. В редакторе **Character Editor** это поле стоит рядом с полем **Name** персонажа. В редакторе **Persona Editor** оно находится среди основных сведений. Впишите, как имя должно звучать.

Эта замена используется только во время аудио- и видеозвонков в Conversation. Обычная кнопка **Speak** у сообщений, автовоспроизведение в чате и повествование в Game Mode это поле не читают.

## Устранение неполадок

- Ничего не звучит: проверьте, что переключатель **Enable TTS** включен. Затем проверьте нужный переключатель **Auto-play** для этого режима или воспользуйтесь кнопкой **Speak** у сообщения. Кнопка **Speak** и настройки автовоспроизведения появляются только после включения TTS.
- В раскрывающемся списке нет голосов: сохраните карточку при включенном TTS и верном ключе API, затем нажмите кнопку **Refresh voices**. Для PocketTTS дополнительно проверьте, что совместимый сервер отвечает по адресу `<Base URL>/v1/voices`.
- ElevenLabs не говорит: проверьте, что выбран настоящий голос, а не подсказка "Select an ElevenLabs voice". Еще проверьте, что в поле **Model** указана речевая модель, а не модель конструирования голоса с фрагментом `ttv` в идентификаторе.
- Собственный сервер TTS по локальному адресу заблокирован: включите на сервере настройку `TTS_LOCAL_URLS_ENABLED`. Так приложение получает доступ к локальному или частному адресу для серверов в формате OpenAI-compatible или ElevenLabs. Для PocketTTS эта настройка не нужна. См. [Настройки сервера: справочник](../CONFIGURATION.md).
- Быстрая проверка настроек: нажмите в карточке кнопку **Preview**, чтобы прослушать короткий пример с текущими настройками.
