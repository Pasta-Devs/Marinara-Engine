# Частые вопросы

Здесь собраны вопросы, которые о приложении Marinara Engine задают чаще всего. Ответы разбиты по темам. В каждом есть ссылка на подробное руководство.

## Как открыть Marinara Engine с телефона или другого устройства?

Marinara Engine работает как локальный сервер на одном компьютере, а открывается в браузере. Этот ответ – про доступ с телефона, планшета или другого компьютера в той же сети.

Скрипты запуска (`start.sh`, `start.bat` и `start-termux.sh`) уже привязывают сервер ко всем сетевым интерфейсам (`0.0.0.0`). Другие устройства видят сервер в сети, но по умолчанию их отсекает контроль доступа. Пока доступ не настроен на компьютере-хосте, удаленное устройство видит только страницу **Access blocked** (доступ заблокирован) с инструкцией по настройке.

Порядок действий:

1. Оставьте Marinara запущенным на компьютере-хосте.
2. На компьютере-хосте настройте контроль доступа: Basic Auth (имя пользователя и пароль) или список разрешенных адресов (перечень адресов доверенных устройств). Руководство [Удаленный доступ](REMOTE_ACCESS.md) разбирает каждый вариант, включая обход для полностью доверенных частных сетей.
3. Узнайте локальный IP-адрес компьютера-хоста. В Windows выполните эту команду и посмотрите значение **IPv4 Address** (адрес IPv4):

```
ipconfig
```

В macOS или Linux выполните эту команду:

```
hostname -I
```

4. На другом устройстве откройте браузер и перейдите по адресу хоста с номером порта. Порт по умолчанию – `7860`:

```
http://192.168.1.42:7860
```

Вместо `192.168.1.42` подставьте IP-адрес своего хоста.

5. Если браузер запросит имя пользователя и пароль Basic Auth, введите их. Если вместо этого открылась страница **Access blocked**, сначала завершите шаг 2 на хосте.

В обычной настольной установке на том же компьютере (`127.0.0.1`) пароль не нужен. В установках Android под управлением APK для localhost добавлен закрытый вход, чтобы другое приложение Android не могло выдать себя за Marinara, но оболочка Android создает и использует эти учетные данные автоматически. Другие устройства заблокированы, пока не настроен контроль доступа (Basic Auth или список разрешенных адресов). Оба варианта описаны в руководстве [Удаленный доступ](REMOTE_ACCESS.md).

Если устройства находятся в разных сетях, поможет инструмент вроде Tailscale. Tailscale выдает каждому устройству постоянный частный адрес. После этого можно подключаться откуда угодно, не открывая Marinara в публичный интернет. Не удается подключиться – смотрите [Устранение неполадок](TROUBLESHOOTING.md).

## Есть ли мобильное приложение Marinara?

Отдельного мобильного приложения нет. На телефоне и планшете открывается то же веб-приложение в браузере. Большинство мобильных браузеров предлагают пункт **Add to Home Screen** (добавить на главный экран) или **Install App** (установить приложение) – после этого страница выглядит как настоящее приложение, без адресной строки. Это называется PWA (Progressive Web App – сайт, который можно установить как приложение).

На Android можно [скачать последнюю версию APK напрямую](https://github.com/Pasta-Devs/Marinara-Engine/releases/latest/download/marinara-engine-android.apk). Тогда Marinara работает прямо на телефоне через Termux. Для установки не нужны ключ подписи, пароль или секрет локального доступа; о системных запросах разрешений читайте в [Руководстве по установке на Android (Termux)](installation/android-termux.md). Для iPhone и iPad есть [Руководство по приложению PWA для iOS / iPadOS](installation/ios-pwa.md).

Оболочка Android автоматически входит при открытии сервера Termux под управлением APK. Закрытые учетные данные видны только тем, кто намеренно открывает сервер в другом браузере на том же телефоне: перейдите на `/android-login`, выполните в Termux команду `cat ~/.marinara-engine/android-secret` и вставьте показанное значение. Локальная CLI `mari` автоматически читает тот же секрет, которым управляет скрипт запуска. При ручной установке Termux действуют обычные правила доступа через localhost и сеть.

## Что за три режима чата?

В приложении Marinara три режима чата, и они показаны вкладками, когда открыт список чатов:

- **Conversation**: чат в стиле переписки или личных сообщений, как будто вы пишете персонажу в мессенджере.
- **Roleplay**: сцена истории с погружением, с описаниями от рассказчика, аватарами персонажей и картинками персонажей по желанию.
- **Game Mode**: текстовое приключение, которое ведет Game Master (ведущий игры), с изображениями сцен и видео по желанию.

У каждого режима есть свое вводное руководство. Начните с нужного режима, а затем изучите подробные руководства по нему.

## Как сменить часовой пояс для расписаний в режиме Conversation?

Откройте чат Conversation и выберите **Schedule timezone** (часовой пояс расписаний) в панели **Chat Settings** (настройки чата) – либо укажите пояс сразу при создании расписаний в мастере настройки Conversation. Сначала Marinara берет часовой пояс с устройства, но можно выбрать любой поддерживаемый пояс IANA или вернуть значение устройства пунктом **Use device**. Это одна общая настройка для всех чатов Conversation, включая автономные сообщения на стороне сервера, и она синхронизируется с другими устройствами, подключенными к тому же серверу Marinara.

## Нужен ли ключ API, чтобы пользоваться приложением Marinara?

Почти всегда да. **Подключение** – это сохраненные настройки доступа к одному сервису ИИ: какой провайдер, какая модель и чем вы там авторизуетесь. **Ключ API** – это секретный код, похожий на пароль. Его выдает провайдер ИИ, чтобы Marinara могла обращаться к этому провайдеру от вашего имени.

Без хотя бы одного подключения чат не начать. Чтобы создать подключение, откройте панель **Connections** (подключения), нажмите кнопку **New** (создать), выберите провайдера, вставьте ключ в поле **API Key** и выберите модель. Весь процесс по шагам разобран в руководстве [Подключение к провайдеру ИИ](connections/connecting-to-a-provider.md).

Несколько провайдеров обходятся без ключа API. Варианты по подписке (Claude, ChatGPT и Grok) авторизуются через программу в командной строке, а встроенная модель Local Model работает на вашем компьютере вообще без ключа.

## Какие провайдеры ИИ поддерживаются?

Marinara поддерживает много провайдеров. На каждое подключение выбирается один.

Для текста в чатах и ролевых играх доступны **OpenAI**, **OpenAI (ChatGPT)**, **Anthropic**, **Claude (Subscription)**, **Grok CLI (Subscription)**, **Google Gemini**, **Google Vertex AI**, **Mistral**, **Cohere**, **OpenRouter**, **NanoGPT**, **xAI / Grok**, а также **Custom (OAI-Compatible)** для локальных моделей и моделей на своем сервере, например Ollama, LM Studio и KoboldCpp.

Для генерации изображений есть **OpenAI (DALL-E)**, **Stability AI**, **Together AI**, **NovelAI**, **OpenRouter Images**, **xAI / Grok Imagine**, **Venice.ai**, **Atlas Cloud**, **Pollinations**, **Stable Horde**, **SD Web UI (AUTOMATIC1111 / Forge)**, **ComfyUI**, **RunPod Serverless (ComfyUI)**, **Draw Things**, **NanoGPT** и **Block Entropy**.

Для генерации видео доступны **Google AI Studio**, **xAI Imagine**, **OpenRouter Video**, **Atlas Cloud**, **Seedance 2.0** и локальные схемы работы **ComfyUI** в формате API.

Подключений можно сохранить сколько угодно и назначить каждому чату свое. Смотрите [Подключение к провайдеру ИИ](connections/connecting-to-a-provider.md).

## Marinara платная?

Само приложение Marinara бесплатно и работает на вашем компьютере. Платить нужно только выбранному провайдеру ИИ по его тарифам, а они зависят от провайдера и модели.

Кое-что можно попробовать бесплатно. Генерация изображений через **Pollinations** обходится без ключа. **Stable Horde** бесплатен, а ключ нужен только для более высокого приоритета. Встроенная модель **Local Model** работает на вашем компьютере без ключа. Варианты по подписке (Claude, ChatGPT и Grok) используют платный тариф, который у вас, возможно, уже есть, вместо ключа API с оплатой за запросы.

## Мои ключи API в безопасности?

Да. Marinara шифрует каждый ключ API алгоритмом AES-256 перед записью на диск. При экспорте подключений и профилей секретные значения вырезаются. С полной резервной копией иначе: в ней лежат зашифрованные записи и, если он есть, файл ключа шифрования, которым они открываются. Поэтому архивы ZIP с полной резервной копией никому не показывайте.

Импорт профиля намеренно не переносит секретные значения, так что после импорта профиля каждый ключ API придется ввести заново – в том числе когда вы применяете **Import Profile** (импорт профиля) к архиву ZIP с полной резервной копией. Восстановление папки с данными вручную сохраняет зашифрованные ключи, если вместе с ней восстановлен и подходящий файл ключа шифрования.

## Что такое карточка персонажа?

**Карточка персонажа** – это сохраненный профиль персонажа ИИ: имя, аватар, характер, предыстория и приветствие. Карточки создаются и правятся в редакторе **Character Editor** (редактор персонажей). Еще можно импортировать карточки, сделанные в других приложениях. Смотрите [Создание и редактирование персонажей](characters/creating-and-editing-characters.md).

## Что такое лорбук и как применить один лорбук к нескольким персонажам?

**Лорбук** – это набор записей о вашем мире. Каждая запись добавляет факты в промпт только тогда, когда в чате появляются ее ключевые слова. Так экономятся токены, а мир остается непротиворечивым. Область действия лорбука задается тремя способами. Выберите подходящий:

1. Привяжите его к персонажам или персонам. В редакторе лорбука заполните поле **Linked Characters** (связанные персонажи) или **Linked Personas** (связанные персоны). После этого лорбук включается в любом чате, где есть связанный персонаж или используется связанная персона. Оба поля принимают несколько значений, так что добавьте всех нужных персонажей.
2. Прикрепите его к одному чату. Откройте панель **Chat Settings**, найдите раздел **Lorebooks** (лорбуки) и нажмите кнопку **Add Lorebook** (добавить лорбук). Так стоит делать, когда факты нужны только в одном конкретном чате.
3. Отфильтруйте отдельные записи по персонажам. Внутри общего лорбука каждую запись можно отметить так, чтобы она срабатывала лишь при определенных персонажах. Это удобно для большого лорбука о мире, где часть записей относится к конкретным персонажам.

Полное описание возможности – в руководстве [Обзор лорбуков](lorebooks/overview.md).

## Что такое агент?

**Агент** – это необязательный помощник на базе ИИ, который работает во время чата и решает одну узкую задачу. Например: следит за текущей сценой, оценивает качество текста, добавляет карты или звонки, ведет настольную игру в режиме Conversation. После свежей установки необязательных агентов нет. Откройте панель **Agents** (агенты), нажмите кнопку **Download Agents** (скачать агентов), прочитайте описание нужного пункта и установите его. Затем включайте совместимых агентов для каждого чата в панели **Chat Settings**. Когда у установленного официального пакета появляется совместимое обновление, Marinara спрашивает разрешение перед скачиванием. Ответ **No** оставляет текущую версию, а кнопка **Update** (обновить) остается в Download Agents на будущее. Если хост недоступен или проверка не прошла, установленная версия продолжает работать. Через каталог пакет можно и полностью удалить. Смотрите [Агенты](agents/agents-overview.md) и публичный [репозиторий Marinara-Agents](https://github.com/Pasta-Devs/Marinara-Agents).

## Как настроить Noodle?

Noodle – это встроенная в Marinara вымышленная социальная сеть для ваших персонажей, работающая локально. Откройте вкладку **Noodle**, а в ней раздел **Settings** (настройки). Пригласите персонажей или папки с персонажами, выберите подключение для генерации в разделе **Refresh** (обновление), затем нажмите **Refresh now** (обновить сейчас), чтобы создать первые записи. Еще можно задать расписание автоматических обновлений, генерацию изображений, случайных пользователей и перенос в ваши чаты.

Подробные руководства: [Noodle: встроенная социальная лента](noodle/overview.md) и [Настройки Noodle и перенос в чаты](noodle/settings.md).

## Почему персонаж не помнит, что было раньше?

Модели ИИ удерживают лишь ограниченный объем текста, поэтому в длинных чатах старые сообщения выпадают из виду. Помогают две системы памяти:

- **Memory Recall** ищет по прежним сообщениям и незаметно возвращает в промпт самое подходящее. Включается в панели **Chat Settings**, раздел **Memory Recall**.
- Сводки сжимают старые сообщения в короткий пересказ. В чатах Roleplay за это отвечает **Chat Summary**, в чатах Conversation – **Automatic Summarization**.

Настройка и подробности – в руководстве [Memory Recall и сводки чата](agents/memory.md).

## Как сделать резервную копию данных?

Откройте панель **Settings**, перейдите на вкладку **Advanced** (дополнительно), найдите раздел **Backup & Export** и нажмите кнопку **Download Backup** (скачать резервную копию). Так сохраняется один архив `.zip` с вашими данными и загруженными файлами. Чтобы восстановить его потом, выберите **Import Profile (JSON/ZIP)** в панели **Settings** на вкладке **Imports** и укажите тот же файл `.zip`.

В том же разделе включается автоматическое резервное копирование по кругу – ежедневное, еженедельное или ежемесячное. Архив ZIP с полной резервной копией может содержать зашифрованные записи и файл ключа, которым они открываются, так что никому их не показывайте. При этом **Import Profile** по-прежнему оставляет секреты провайдеров пустыми, поэтому после импорта введите ключи заново. Полное руководство: [Резервное копирование и восстановление](data/backup-and-restore.md).

## Как работают расширения и можно ли импортировать сторонний код?

По умолчанию черновик личного расширения создает только Professor Mari, и только для вас. Черновик сразу выключен, а перед запуском нужно просмотреть его код и подтвердить точный хеш SHA-256.

Код для браузера по умолчанию выполняется в отдельном Worker внутри iframe с непрозрачным источником. Кроме узкого набора возможностей – запись в журнал, приватное хранилище, таймеры, очистка и декларативный интерфейс – он получает непрозрачные идентификаторы активного чата и его персонажей. Так расширения вроде Notepad хранят состояние для конкретного чата. Расширение для браузера может отдельно запросить ограниченные снимки данных: только карточки персонажей, участвующих в этом чате, и/или выбранную для него персону. Эти разрешения показываются при подтверждении точного хеша. Без них соответствующих записей просто нет. Расширения в песочнице никогда не получают сообщения, библиотеки персонажей и персон целиком, необъявленные поля, метаданные чата, доступ к DOM, доступ к сети и API изменения данных. Серверный код выполняется в отдельном процессе в песочнице операционной системы – на поддерживаемых хостах macOS и Linux – и контекст чата из браузера ему не передается.

Импорт сторонних расширений по умолчанию скрыт. Сначала администратор хоста должен указать `ENABLE_EXTERNAL_EXTENSIONS=true` в файле `.env`, а затем нужно принять предупреждение в разделе **Settings → Advanced → Danger Zone**. Пока не открыты оба защитных барьера, внешние записи – включая сохраненные вручную и пришедшие с импортом профиля – не видны, их нельзя подтвердить и нельзя выполнить.

Внешнее расширение может запросить разрешение **Full page access** (полный доступ к странице), если для совместимости со старым кодом действительно нужен DOM приложения Marinara. Песочницы здесь нет: подтвержденный код выполняется прямо на странице Marinara. Он получает доступ к содержимому страницы, хранилищу браузера, сетевым API и текущей сессии того же источника. Черновики Professor Mari такое разрешение запросить не могут. Включайте его только после проверки той самой версии кода, которой вы доверяете. Если после выключения остались незарегистрированные изменения, перезагрузите страницу. Смотрите [Личные расширения](extending/personal-extensions.md).

## Где хранятся мои данные?

Все лежит на том компьютере, где работает Marinara, в папке `data` внутри установки. Персонажи, чаты, персоны, лорбуки, пресеты и настройки сохраняются там же. В облако ничего не уходит. Смотрите [Где Marinara хранит ваши данные](data/where-data-is-stored.md).

## Потеряются ли данные при обновлении?

Нет. После обновления приложения Marinara персонажи, чаты и настройки остаются на месте. И все же перед крупным обновлением стоит сделать резервную копию – на всякий случай. Порядок обновления для каждой платформы описан в руководстве [Обновление](UPGRADING.md).

## Что умеет Professor Mari?

Professor Mari – это встроенный ассистент на главном экране. Открывается кнопкой **Ask Professor Mari** (спросить Professor Mari). Ассистент объясняет, как устроено приложение, и помогает с настройкой. По просьбе обычными словами Professor Mari также создает и правит ваши данные: персонажей, персоны, лорбуки, пресеты промптов (сохраненные шаблоны инструкций) и новые чаты.

Над полем ввода появляются плашки с готовыми ответами – они ведут через многошаговое создание и правки, чтобы не приходилось набирать каждую деталь вручную.

Когда ассистент меняет ваши данные, появляется карточка проверки с кнопками **Keep** (оставить) и **Restore** (вернуть), так что любую правку можно отменить. Это помощник, а не замена этим руководствам там, где важна конкретная версия. Полный список возможностей – в руководстве [Professor Mari](home/professor-mari.md).

Professor Mari также правит обычные исходные файлы приложения Marinara. А вот файлы зависимостей, скрипты запуска, установщики и схемы работы CI ждут отдельной проверки. Если для правки нужна публичная библиотека npm, Marinara показывает точную выбранную версию и контрольную сумму из реестра, а затем устанавливает ее с отключенными служебными скриптами.

Примечание: на обычном удаленном адресе действиям Professor Mari по изменению данных нужны и Basic Auth, и секрет администратора. На доверенных или разрешенных сетевых маршрутах работают обходы, описанные в руководстве [Удаленный доступ](REMOTE_ACCESS.md).

## Что такое агент Storyboard и как им пользоваться в режиме Game Mode?

Скачиваемый агент **Storyboard** превращает готовый текст истории в упорядоченную последовательность ключевых кадров и умеет анимировать каждый кадр в короткий клип. В режиме **Game Mode** он строит раскадровку по одному законченному ходу рассказа от Game Master. Кадры видны в плавающей панели просмотра или прямо как фон игры. В режиме **Roleplay** он собирает недавно завершенные обмены репликами в эпизод прямо в чате.

Чтобы включить его в режиме Game Mode, установите агента **Storyboard** через **Agents > Download Agents**. Откройте игру и перейдите в **Chat Settings > Agents**. Включите переключатели **Enable Agents** (включить агентов) и **Enable Storyboards** (включить раскадровки). Затем задайте подключение для изображений – в самой игре или в общих настройках агента Storyboard. Завершите ход рассказа от Game Master, откройте раздел **Gallery** (галерея) и нажмите **Create storyboard** (создать раскадровку). Кнопка **View storyboard** (посмотреть раскадровку) открывает панель просмотра заново.

Чтобы раскадровки в игре собирались автоматически, включите **Automatic Storyboard Illustrations** (автоматические иллюстрации раскадровки). Для клипов дополнительно включите **Automatic Storyboard Animations** (автоматическая анимация раскадровки) и выберите подключение для генерации видео. Стиль подачи **Storyboard Optimized** в мастере создания игры влияет только на текст рассказа от Game Master: он не устанавливает и не включает агента. Настройка в режимах Game Mode и Roleplay, промпты, панели просмотра, судьба прежних настроек и разбор проблем описаны здесь: [Руководство по агенту Storyboard](game/storyboard.md).

## Могут ли персонажи говорить вслух во время звонка?

Да, в режиме **Conversation**. Аудио- и видеозвонки есть только в этом режиме. Чтобы услышать голос персонажа, сначала настройте раздел **Text to Speech** (синтез речи) в панели **Connections**.

Если вы хотите отвечать в микрофон, а встроенное в браузер распознавание речи работает ненадежно, сначала установите агента **Calls** через **Agents > Download Agents**. Затем откройте панель **Connections**, раскройте карточку **Local Model**, найдите пункт **Local Speech Model**, выберите **Whisper Tiny (Multilingual)** или **Whisper Base (Multilingual)** и нажмите кнопку **Download Whisper**. При удалении агента Calls скачанные файлы Whisper тоже удаляются и место на диске освобождается. Полная настройка звонков описана в руководстве [Аудио- и видеозвонки в режиме Conversation](conversation/calls.md).

## Умеет ли Marinara генерировать изображения?

Да. Добавьте подключение для генерации изображений – например **Pollinations** (ключ не нужен) или платного провайдера. После этого Marinara создает аватары персонажей, картинки сцен, селфи и ключевые кадры агента Storyboard в режимах Roleplay и Game Mode. Как добавить подключение, описано в руководстве [Подключение к провайдеру ИИ](connections/connecting-to-a-provider.md).

## Как читать документацию внутри приложения?

С каждой установкой поставляется полный набор руководств. Читать их можно не выходя из приложения:

- На главном экране нажмите кнопку **Documentation** (документация) в нижней части, рядом с **Replay Tutorial**.
- В разделе частых вопросов на главном экране откройте вопрос о документации и нажмите кнопку **Open Documentation** (открыть документацию).

Обе кнопки открывают один и тот же встроенный просмотрщик. Он показывает список всех руководств и отображает их прямо в приложении Marinara.
