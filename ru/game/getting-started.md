# Game Mode: начало работы

Режим Game Mode превращает приложение Marinara Engine в одиночную ролевую игру, которой управляет Game Master (ведущий игры) на базе ИИ. С этим руководством вы начнете игру, сыграете первый ход и найдете элементы управления.

Game Mode – один из трех режимов чата (Conversation, Roleplay и Game Mode). Game Master (GM) – это ИИ, который описывает мир, играет за каждого встреченного персонажа и решает, что произойдет дальше, как Dungeon Master в настольной игре. Marinara следит за картой, вашим отрядом, неигровыми персонажами (NPC), предметами, квестами, временем в мире и погодой. Долгую игру можно разбить на несколько **сессий**, как игровые вечера одной кампании.

Использовать все механики необязательно. Можно обойтись без боя и кубиков и играть ради истории.

## Перед началом

Нужно всего одно – аккаунт ИИ для Game Master. Если вы еще не добавили аккаунт, смотрите [Подключение к провайдеру ИИ](../connections/connecting-to-a-provider.md).

Все остальное необязательно и по умолчанию выключено. Это можно добавить позже:

- **Изображения.** Агент **Illustrator** рисует портреты персонажей NPC, фоны локаций и изображения сцен. Скачайте его в **Agents → Agent Organizer** (агенты → организатор агентов). Ему нужен аккаунт для изображений. Без него у вас все равно будут история, отслеживание состояния и бой, но визуальные области останутся пустыми.
- **Эффекты сцены от встроенной модели.** Marinara может запускать небольшую модель прямо на вашем компьютере, чтобы бесплатно подбирать фоны и музыку. Как только вы ее скачаете, она становится вариантом по умолчанию для **Scene effects model** (модель эффектов сцены). До тех пор по умолчанию стоит **Skip - use inline tags from GM** (пропустить, использовать теги из текста GM). Смотрите [Настройка встроенной модели](../connections/local-model.md).
- **Раскадровки.** Скачайте агента Storyboard, а затем включите его для игры. Смотрите [Руководство по агенту Storyboard](storyboard.md).
- **Видео.** Аккаунт для видео нужен только для видео сцен и анимированных раскадровок.
- **Музыка.** Агент **Music DJ** включает музыку из Spotify или из локальной папки с музыкой.

## Начало игры

1. В боковой панели чатов откройте вкладку **GM** и нажмите кнопку **+** (**New Game**). Или нажмите **Game** на главном экране. Откроется мастер настройки. Смотрите [Управление списком чатов](../chats/managing-chats.md).
2. На первом шаге выберите **Model** (модель), которая ведет GM. Выберите аккаунт, который вы добавили раньше. Если список пуст, сначала добавьте аккаунт. Для генерации мира берите сильную платную модель (см. раздел [Выбор модели](#choosing-a-model)).
3. На каждом шаге нажимайте **Next** (далее). У всех остальных полей есть значения по умолчанию, поэтому мастер можно пройти, ничего не меняя.
4. На последнем шаге нажмите **Create world** (создать мир). Пока Marinara строит ваш мир, на кнопке видно **Generating World…**. Это один большой запрос к вашей модели, поэтому дождитесь его завершения.
5. Когда мир готов, на экране игры появляется **Start Game** (начать игру). Нажмите эту кнопку. Затем GM пишет первое сообщение.

Если свои виджеты HUD включены (по умолчанию это так), под **Start Game** есть кнопка **Review Starting Widgets** (проверить начальные виджеты). Ее можно пропустить или сначала изменить с ее помощью начальные виджеты. Смотрите [Game Mode: виджеты панели HUD](hud-widgets.md).

> **Совет:** если вы только начинаете с Game Mode, оставьте **Game Master Mode** (режим ведущего игры) на **Standalone GM**. Marinara соберет для вас ехидного рассказчика.

Если не получилось, смотрите раздел [Генерация мира падает с ошибкой JSON или 422](#world-generation-fails-with-a-json-or-422-error).

### Мастер настройки

| Шаг | Что вы задаете |
| --- | --- |
| **Connection** (подключение) | **Game Name** (название игры), **Model**, которая ведет GM, и необязательную **Scene effects model**. Карточка **Game Mode** (режим игры) пока показывает только **VN** (см. раздел [VN или Overworld](#vn-or-overworld)). |
| **World** (мир) | Жанр, мир, тон, сложность, возрастную категорию и язык. **Combat Preference** (предпочтительный вид боя) – **Turn-Based** или **Tactical**. Каждая новая игра использует классы **MRPG** (Marinara RPG; см. [Классы MRPG](mrpg-classes.md)). Когда установлен набор правил, появляется выбор **Rules** (правила), см. раздел [Выбор правил](#choose-rules). |
| **Party** (отряд) | Вашу персону (персонажа, за которого вы играете), **Game Master Mode**, участников отряда и **GM intro message** (см. раздел [Вступительное сообщение GM](#the-gm-intro-message)). |
| **Goals** (цели) | Чего вы хотите от приключения. |
| **Lorebooks** (лорбуки) | Лорбуки, которые GM считает каноном. Лорбук – это набор фактов о мире. Смотрите [Лорбуки](../lorebooks/overview.md). |
| **Features** (возможности) | **Enable Agents** (включить агентов), затем карточку для каждого скачанного агента (**Illustrator**, **Music DJ**, **Lorebook Keeper**), а также **Custom HUD Widgets** (свои виджеты панели HUD), **Quick Time Events** (события на скорость реакции) и **Start Muted** (начать без звука). |
| **GM** | Стиль подачи и **GM Prompt** (промпт GM). |

Идеи, которые предлагаются под полями мира и целей, меняются при каждом открытии мастера. В игре Tactical GM пишет краткое описание каждого боя, а Marinara строит по нему поле боя. Смотрите [Бой](combat.md#tactical-battles-and-terrain).

На шаге **World** есть также настройки боя для боссов. **GM directs bosses** (GM управляет боссами) по умолчанию включено. С этой настройкой GM решает, как ходят боссы, через ваше подключение GM, и это может занять немного времени. Обычные противники решают сами, если только не включено **GM directs bosses** и набор правил игры не отдает противников Game Master (см. раздел [Текст Game Master](../extending/ruleset-sheets.md#game-master-text)). Пока **GM directs bosses** включено, **Game Master also plays named and brilliant opponents** (Game Master играет также за именных и выдающихся противников; по умолчанию включено) позволяет GM играть еще и за именных персонажей и очень умных врагов. Еще две настройки видны всегда: **Companions fight on their own** (спутники сражаются сами; по умолчанию включено, выключите, чтобы играть за весь отряд самостоятельно) и **Let cruel opponents strike the fallen** (разрешить жестоким противникам добивать павших; по умолчанию выключено). Смотрите [Бой](combat.md).

Если скачан агент **Hierarchical Maps** (теперь он называется World Maps, см. [World Maps](../agents/hierarchical-maps.md)) и включено **Enable Agents**, на шаге **Features** можно также набросать **Hierarchical world map** (иерархическая карта мира), использовать сохраненный шаблон карты или связать общий мир.

| Game Presentation | Standard | См. ниже. |

<a id="choose-rules"></a>

### Выбор правил

Поле **Rules** появляется только для новой игры и только если установлен хотя бы один набор правил. **Marinara's own rules** (собственные правила Marinara) – вариант по умолчанию: встроенные проверки d20 и лист с шестью характеристиками. Набор правил, например **5e (SRD 5.1)**, заменяет их проверками и листом персонажа своей настольной системы, а также может проводить бои по собственным правилам. Мастер настройки показывает, что охватывает каждый набор правил. После создания игры выбор фиксируется. Смотрите [Игра с набором правил](rulesets.md).

<a id="the-gm-intro-message"></a>

### Вступительное сообщение GM

**GM intro message** (на шаге **Party**) решает, как начинается игра:

- **None** (нет; по умолчанию): GM открывает игру так, как считает нужным.
- **Defined** (задано): введите первое сообщение точно так, как оно должно читаться. Игра открывается этим текстом, а повторная генерация дает тот же текст.
- **Guided** (направлено): опишите, как должно пройти начало, например где оно происходит и кто там есть. GM пишет начало по этому описанию.

Текст может содержать до 8000 символов. В нем не может быть двойных фигурных скобок, а в тексте **Guided** – еще и квадратных скобок. Поле сообщает, когда текст использовать нельзя. История мира может задать собственное вступление. Тогда поле показывает его как заблокированное, и изменить его нельзя.

### Стиль подачи Storyboard Optimized

На шаге **GM** для **Game Presentation** (оформление Game) можно выбрать **Standard** (стандартный) или **Storyboard Optimized** (оптимизировано для раскадровки). **Storyboard Optimized** использует промпт Storyboard Game Prompt, который превращает ходы GM в визуальные сцены, готовые к съемке. Он не скачивает и не включает агента Storyboard, не включает генерацию изображений или видео и не меняет ваши аккаунты. После создания игры настройте все это в **Chat Settings → Agents → Storyboards** (настройки чата → агенты → раскадровки).

Редактор **GM Prompt** показывает предпросмотр промпта для выбранного стиля подачи. Если не менять текст, встроенный пресет остается выбранным. Если его изменить, ваш текст заменяет пресет.

Альтернативный аниме-вариант с одним кадром остается доступным и после настройки: выберите **Anime Episode Director** для Animation Planner и **Anime Game Video** для Storyboard Video Prompt.

## Первый ход

Напишите, что делает или говорит ваш персонаж, и отправьте сообщение. GM отвечает, обновляет мир и может попросить бросить кубики или начать бой.

Кнопка с речевым облачком рядом с кнопкой прикрепления файлов (ее всплывающая подсказка – **Choose who to address**, то есть выбор адресата) задает, кому уйдет сообщение:

| Режим | Что делает |
| --- | --- |
| По умолчанию | Сообщение уходит в сцену как действие или реплика. GM и ваш отряд отвечают внутри истории. |
| **Talk to Party** (говорить с отрядом) | Добавляет метку `[To the party]` и обращается к вашим спутникам. Показывается, только когда отряд не пуст. |
| **Talk to GM** (говорить с GM) | Добавляет метку `[To the GM]` и задает вопрос GM вне роли, например "Знает ли мой персонаж о храме?" |

Активный режим отмечен в меню значком **On**. Чтобы выключить его, нажмите тот же пункт еще раз.

<a id="the-games-controls"></a>

## Элементы управления игрой

На компьютере элементы управления открываются кнопками справа вверху чата. На телефоне ищите их в перемещаемом меню **Chat tools** (инструменты чата) с тремя точками.

| Элемент управления | Что в нем |
| --- | --- |
| **Game controls** (управление игрой, игровой контроллер) | **Retry turn**, **Retry scene analysis**, **Retry Music DJ** (когда музыку включает Music DJ) и **Retry assets image generation**. Для раскадровки на фоне игры также повтор, воспроизведение и пауза и отключение звука. **Show the scene** (показать сцену), **Show the overworld** (показать глобальную карту) и **Show the map** (показать карту) переключают виды в играх, где они есть. **Edit game data** (править данные игры) позволяет вручную исправить сохраненные данные (см. раздел [Ручная правка данных игры](sessions-and-saves.md#editing-game-data-by-hand)). **Checkpoints** (контрольные точки) возвращает к более раннему моменту (см. раздел [Как игра сохраняется](sessions-and-saves.md#how-your-game-saves)). |
| **Session** (сессия, перо) | История сессий, журнал и управление сессией. Смотрите [Game Mode: сессии и сохранения](sessions-and-saves.md). |
| **Volume** (громкость, динамик) | Громкость **Master**, **Music**, **Sound Effects**, **TTS** и **Ambient**. |
| **Game Assets** (игровые ресурсы, папка) | Медиафайлы сцены и Asset Browser. Смотрите [Игровые ресурсы](game-assets.md). |
| **Connected chat** (связанный чат) | Показывается, когда игра связана с Conversation. Смотрите [Связанные чаты](../chats/connected-chats.md#switching-between-connected-chats). |

Выберите инструмент, чтобы открыть его в перемещаемом окне на компьютере или в панели на всю ширину на телефоне. На компьютере перетаскивайте кнопку инструмента, чтобы переместить ее. На телефоне перемещайте меню с тремя точками или разблокируйте его, чтобы изменить порядок инструментов внутри. Смотрите [Окна управления и их кнопки](../chats/chat-settings.md#control-windows-and-their-buttons).

Элемент управления можно также держать внутри **Chat Settings**. Откройте окно элемента и выберите **Put back in Chat Settings** (вернуть в настройки чата). Тогда он появится там как раскрываемый раздел, а его кнопка выноса снова сделает его окном. Каждая игра сохраняет ваш выбор. **Reset View** (сбросить вид) восстанавливает исходное расположение.

**Character Profiles** (профили персонажей) и на компьютере, и на телефоне остается вне Chat tools. Перетащите кнопку с портретом куда хотите, а затем откройте ее, чтобы выбрать участника отряда и посмотреть или изменить его лист персонажа. На телефоне у **Map** (карта) тоже есть собственная перемещаемая кнопка. Обе следуют стилю виджетов вашего чата, сохраняют свое положение для этой игры и могут быть заблокированы из своего открытого окна.

<a id="choosing-a-model"></a>

## Выбор модели

Генерация мира – самая тяжелая часть режима Game Mode. Модель должна выдать один длинный документ JSON строгого формата (это текстовый формат, который должен быть точным, иначе игра не сможет его прочитать) без пропущенных полей. Модель, которая хорошо справляется с обычным чатом, все равно может не пройти этот шаг.

- Для генерации мира берите сильную современную модель топового уровня на платном аккаунте. По состоянию на 2026 год игроки сообщают о хороших результатах с флагманскими линейками крупных провайдеров, например Anthropic Claude, OpenAI GPT и Google Gemini. Названия моделей часто меняются, поэтому считайте это примерами, а не окончательным списком.
- Самые дешевые из рекомендуемых нами моделей – DeepSeek V4 Flash и Claude Haiku 5.5, обе проверены в игре по состоянию на 31 октября 2026 года.
- Для следующих ходов иногда можно взять модель подешевле, потому что ходам нужно повествование, а не строгий JSON. Если GM забывает персонажей NPC или противоречит сказанному раньше, вернитесь к более сильной модели.
- Для генерации мира избегайте бесплатных моделей и моделей с автоматической маршрутизацией. Они могут направить запрос на небольшую модель, которая не выдаст корректный JSON. Небольшие модели с открытыми весами обычно тоже не справляются.

Полный справочник по параметрам – в руководстве [Параметры генерации](../prompts/generation-parameters.md).

## Во что обходится ход

Game Mode делает три вида запросов к ИИ:

1. **Генерация мира.** Один раз, когда вы нажимаете **Start Game**. Один большой запрос, который возвращает описание мира, стартовую карту, персонажей NPC, листы отряда и виджеты.
2. **Игровые ходы.** Каждое сообщение собирает новый промпт с текущим состоянием. GM описывает происходящее и обновляет мир. Расчеты раундов боя делает движок, а не модель, поэтому результаты остаются честными.
3. **Сводки сессий.** Когда вы завершаете сессию, GM пишет пересказ и заметки о преемственности. Когда вы начинаете следующую, он пишет короткое связующее сообщение. Старые сессии сжимаются в сводки, чтобы длинные кампании помещались в модель.

<a id="optional-tool-planning-and-lore-searches"></a>

## Необязательное планирование инструментов и поиск по лору

Во время игры откройте **Chat Settings → Function Calling** (настройки чата → вызов функций).

- **Let the GM search lore** (разрешить GM поиск по лору) позволяет GM искать факты в лорбуках по смыслу. Сначала включите векторизацию для лорбуков и векторизуйте их записи. Поиск учитывает включенные книги, папки и переключатели записей для конкретного чата. Он использует ваш аккаунт для эмбеддингов и может добавить запрос к модели. В чатах Game этот переключатель нужен для поиска в лорбуках, даже если включено **Enable Tool Use** (разрешить использование инструментов). Пока он выключен, `search_lorebook` недоступен в списке выбора инструментов.
- **Game tool provider** (провайдер инструментов игры) по умолчанию стоит на **Same as narrator** (как у рассказчика), что сохраняет обычный цикл инструментов (до четырех раундов инструментов за ход). Если выбрать другой аккаунт, перед повествованием выполняется один отдельный запрос планирования. Эта модель выбирает инструменты, а рассказчик получает их результаты в виде текста. Это стоит одного дополнительного запроса за ход на этом аккаунте. Более дешевая модель может снизить стоимость, но выбрать другие инструменты. Один проход планирования не может запустить второй поиск по цепочке.
- **Finish rolled turns in one request** (завершать ходы с бросками одним запросом) по умолчанию включено и экономит запрос на ходах с бросками кубиков. Смотрите [Game Mode: броски кубиков и проверки навыков](dice-and-skill-checks.md#finishing-a-rolled-turn-in-one-request).

Аккаунты по подписке Claude и Grok не поддерживают нативные вызовы инструментов. Элементы управления объясняют это и остаются отключенными, пока не выбран поддерживаемый **Game tool provider**. Текстовые команды и теги бросков продолжают работать. Если отдельный аккаунт отсутствует или его запрос завершается ошибкой, ход сообщает об ошибке, а не ведет повествование без работы инструментов.

Если локальные модели делят ограниченную память GPU, откройте **Chat Settings → Agents** и включите **Run Game tasks one at a time** (выполнять задачи Game по одной). Тогда повествование, агенты и медиа сцены ждут друг друга в пределах этого чата игры. По умолчанию настройка выключена и не резервирует GPU от других чатов или приложений.

## Включение агентов

Агенты – это необязательные помощники на базе ИИ, которые работают рядом с GM. Они делают дополнительные запросы, поэтому увеличивают затраты. Чтобы задействовать их, откройте во время игры **Chat Settings → Agents** и включите **Enable Agents**. В режиме Game Mode полезны два агента:

- **Game Session Keeper** помогает сохранять преемственность между сессиями.
- **Music DJ** подбирает фоновую музыку.

**Review Agent Outputs** (проверять результаты агентов) позволяет проверить, что выдал агент. Смотрите [Агенты: помощники ИИ в чатах](../agents/agents-overview.md).

## Устранение неполадок

<a id="world-generation-fails-with-a-json-or-422-error"></a>

### Генерация мира падает с ошибкой JSON или 422

Скорее всего, модель не смогла выдать полный JSON. Попробуйте по порядку.

1. Проверьте, какую модель использует GM. Если это бесплатная модель или модель с автоматической маршрутизацией, переключитесь на сильную платную.
2. Повторите попытку. Некоторые сбои случаются однократно.
3. Сократите длинное поле мира или предпочтений. Длинный ввод оставляет меньше места для JSON.

Если обращение почти сработало, Marinara предлагает окно **Repair JSON** (починить JSON) с сырым выводом модели в редакторе с нумерацией строк. Строка статуса сообщает, корректен ли JSON, или показывает ошибку разбора. Нажмите **Format** (форматировать), чтобы привести корректный JSON в порядок, затем **Apply Repaired JSON** (применить исправленный JSON), чтобы использовать ваше исправление и не платить за повторную попытку. **Repair JSON** появляется также для сводок сессий и других структурированных обращений. Другие решения – в руководстве [Устранение неполадок в приложении Marinara Engine](../TROUBLESHOOTING.md).

### GM бодро рассказывает, хотя выбран мрачный тон

Некоторые модели остаются жизнерадостными. Добавьте четкую инструкцию в поле предпочтений мастера настройки, например "держи повествование мрачным, не смягчай провалы". Или переключитесь на модель, чей стандартный голос подходит к тону.

## Overworld

Разделы ниже описывают игры **Overworld**, которые пока недоступны. Читайте их, только если на вашем сервере они включены.

<a id="vn-or-overworld"></a>

### VN или Overworld

Новая игра идет в одном из двух режимов игры, который выбирается на первом шаге и сохраняется для всех ее сессий:

- **Overworld** – это мир, созданный под заданный вами мир игры, по которому вы ходите на глобальной карте (overworld), с городами, местами для исследования и подземельями. Для него нужны набор мира и сам мир. Пока вы не выберете набор, берется набор для вашего первого жанра (High fantasy, если у жанра своего набора нет), и для него случайно создается мир.
- **VN** – это Game Mode в том виде, в каком он был всегда, с подачей как у визуальной новеллы: сцена за сценой, с картой сцены и боями, без набора мира, мира, глобальной карты, городов и карт подземелий.

Overworld заблокирован, пока тот, кто держит сервер, не задаст `MARINARA_OVERWORLD_GAMES`. Пока он заблокирован, его карточка неактивна, с пометкой "Overworld games, with a setting kit and a generated world, are not ready yet. New games start as VN games." Тогда каждая новая игра – это игра VN, а варианты набора мира и мира не появляются. Игра, созданная до появления этого выбора, продолжает идти так же, как шла: с миром это игра Overworld, без мира – игра VN.

<a id="choosing-a-setting-kit"></a>

### Выбор набора мира

**Setting kit** (набор мира) дает GM слова, которыми описывается ваш вид мира: названия мест и размеры поселений, виды групп, способы путешествовать, названия года и дня, то, как народы называют себя, деньги и товары, стихии, места сражений и семейство изображений и музыки, которое он использует (см. раздел [Игровые ресурсы](game-assets.md#a-settings-own-art-and-music)). Он также указывает, какие виды перемен допускает мир, например соперничество, преступность, войны или катастрофы, и как быстро мир меняется. Выключенный вид никогда не появляется, поэтому ссора может остаться ссорой.

Наборов восемь: высокое фэнтези, уся и сянься, наши дни, современная мистика, 1920-е, киберпунк, космическая опера и постапокалипсис. Набор "наши дни" по умолчанию мягкий: без преступности, конфликтов и катастроф, в медленном темпе.

- Если выбрать набор раньше жанра, задается подходящий ему жанр. Жанр, который вы выбрали сами, остается.
- **Write it for my setting** (переписать под мой мир) просит вашу модель GM переписать набор под ваши жанр, мир и тон. Если результат не складывается в целое, модель просят еще раз, сообщив причины. Если и это не помогает, мастер говорит, что было не так, и оставляет прежний набор.
- **Change its words** (изменить его слова) открывает для правки каждое слово набора. Вводите список в одну строку через запятую. Набор с проблемой, например с пустым названием или без поселений, сообщает, что не так, и игра не может начаться, пока это не исправлено.
- **Download this kit** (скачать этот набор) сохраняет файл `.worldkit.json`, чтобы им поделиться. **Import a kit file** (импортировать файл набора) загружает такой файл обратно.

Игра сохраняет набор, с которым ее создали, и файл общей настройки тоже переносит его. Experience может поставляться с собственным пакетом карт (набор мира, готовые карты и тайлы). Когда этот Experience включен, настройка показывает его набор как уже заданный и, если он поставляет карты, поле **Map** для выбора. Если выключить Experience, ваши варианты возвращаются.

<a id="making-a-world"></a>

### Создание мира

Когда набор выбран, **Your world** (ваш мир) еще до начала игры раскладывает мир словами набора: регионы, поселения всех размеров, то, чем известно каждое место, и пути между ними (дороги, реки, морские пути, прыжковые трассы) со временем в пути в днях.

Мир создается из **World seed** (зерно мира). Одно и то же зерно, набор и описание всегда дают один и тот же мир. **Roll** (бросить заново) дает другой мир, а ввод прежнего числа возвращает прежний. Предпросмотр показывает маленькую карту земли и поселений, место, где начинает отряд, и список поселений по регионам.

- **Start from this lore** (начать с этого лора) читает отмеченные лорбуки и берет из них указанные там места и датированные события, сохраняя их ровно так, как написано. **Build around the lore** (строить вокруг лора) заполняет мир вокруг них. **Only the lore's places** (только места из лора) ничего, кроме них, не создает.
- **Write the world's brief** (написать описание мира) просит у вашей модели GM настоящее время, главные места, группы, вокруг которых крутится настоящее (чего хочет каждая, ее союзники и соперники), и имена для мест и людей в звучании, свойственном каждому народу. Места из лора сохраняются, что бы ни написала модель. Все, что не подходит к набору, отбрасывается и подсчитывается. **Change the brief** (изменить описание) открывает его слова для правки, включая личные и родовые имена каждого народа. Без описания места нумеруются, а людей называют по их занятию.

**У мира есть прошлое.** До начала игры мир прогоняется вперед год за годом от своего основания. Поселения растут, группы основываются, получают и теряют лидеров, сближаются и ссорятся друг с другом. Там, где они есть в мире, разбойники, войны и голод оставляют свои следы. Серьезная перемена наступает только после того, как она назревала, и только в тех видах, которые разрешает набор. Датированные события из вашего лора или описания происходят тогда и там, где сказано. Одно и то же зерно и описание дают одно и то же прошлое.

**Что знает GM.** GM всегда знает, где находится отряд, куда он может пойти и сколько времени занимает каждый путь. Ему сообщают самые заметные события прошлого, кто правит текущим местом и историю этого места. О любом другом месте или группе он может спросить и получит ответ на следующем ходу. Место, куда идет отряд, он называет меткой места. Место из списка мира сохраняет размер, который дал ему мир. Место, которого нет в списке мира, например ферма, сохраняет имя, которое дал ему GM. В каждом поселении есть жители, которых зерно определяет, когда приходит отряд: у каждого имя из его культуры, занятие, подходящее месту, характер, манера речи и внешность. Когда GM называет кого-то полным именем, этот человек попадает в число отслеживаемых персонажей.

**Сделанное отрядом остается сделанным.** Когда отряд помогает группе или мешает ей, меняет отношение двух групп друг к другу, захватывает или разоряет место или ставит кого-то во главе группы, GM записывает это в своем ответе. Каждое изменение сверяется с миром. Изменение того вида, который в наборе выключен, или изменение, называющее место или группу, которых в мире нет, отклоняется. С этого момента GM получает мир таким, каким его оставила история. Место, добавленное историей, – это место, куда может пойти отряд. Свайп, повторная генерация или удаленное сообщение отменяют изменение вместе с его ответом.

**Мир живет и без отряда.** Когда GM сообщает, что проходит время, мир делает шаги по неделе за раз и только в тех видах перемен, которые есть в наборе. Катастрофы никогда не случаются сами: описать катастрофу может только GM, и если ее вид выключен, это отклоняется. Там, где находится отряд, ничего не решается. Новости распространяются: GM узнает о далекой перемене, когда пройдут дни, которые занимает дорога. Дела отряда значат тем больше, чем он известнее.

**Ручные правки.** В редакторе мира можно переименовывать или перемещать места, раскрашивать землю, добавлять места и людей, рисовать тактическое поле боя места (см. раздел [Бой](combat.md#tactical-battles-and-terrain)) и планировать город (см. раздел [Город](map-time-weather.md#the-town)). Все части игры сразу видят правки. Переименованное место по-прежнему откликается на старое имя. Правки меняют мир с этого момента и никогда – его прошлое. Город сохраняет свою планировку, поэтому места и люди, которых вы добавляете, занимают его следующие свободные участки и дома.

**Файлы мира.** **Download this world** (скачать этот мир) в разделе **Your world** сохраняет мир, который вы создаете, а **Download the world** (скачать мир) на вкладке World игры сохраняет мир этой игры с ручными правками как файл `.world.json`. **Import a world file** (импортировать файл мира) рядом с набором мира загружает такой файл в настройку новой игры: выбирает набор из файла и создает его мир. **Your worlds** (ваши миры) делает то же самое с миром из вашей библиотеки. Файл может также нести историю мира: события и сцены, которые написал его автор. Сцены истории появляются в повествовании перед ответом GM ровно так, как написаны, а ее цели квестов перечисляются в разделе **Story** (история) на вкладке World журнала. Как написать историю, описано в руководстве [Создание сюжетных сценариев Game Mode](../extending/writing-story-scripts.md). Ручные правки и история принадлежат тому зерну и описанию, поэтому при изменении любого из них они отбрасываются. Файл, который не удается прочитать, отклоняется, и мастер объясняет почему. Если содержимое файла не подходит к набору, часть его отбрасывается, и мастер сообщает, что именно.

**Мир позже и его сохранение.** Игре, созданной без мира, можно позже дать мир на вкладке **World** журнала кнопкой **Make a world for this game** (создать мир для этой игры). Мир начинает действовать со следующего хода, а прошлые ходы, карта и люди остаются. Пока Overworld RPG заблокирован, кнопка неактивна. Игра сохраняет свой мир таким, каким он был создан, поэтому новая сессия, ветка и экспортированный чат сохраняют тот же мир. Мир, созданный более ранней версией генератора, продолжает игру, но править его больше нельзя.

Игра с миром открывается на **глобальной карте** (overworld) – пиксельной карте, где вы ведете отряд между поселениями и входите в города. Смотрите [Глобальная карта](map-time-weather.md#the-overworld).
