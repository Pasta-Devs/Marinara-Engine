# Игровые ресурсы: музыка, звук, спрайты и фоны

Игровые ресурсы – это медиафайлы, которые режим Game Mode проигрывает и показывает: музыка, звук, изображения персонажей и фоны сцен. В этом руководстве описано, как пользоваться стартовым набором, загружать свои файлы в **Asset Browser** (браузер ресурсов), ограничивать ресурсы, доступные игре, и генерировать звуковые эффекты и музыку.

Режим Game Mode читает библиотеку сам. Музыку, окружающий звук и фоны он подбирает по сцене, поэтому назначать ресурсы вручную во время игры не нужно.

| Категория | Что это |
| --- | --- |
| **Music** (музыка) | Фоновые треки, которые меняются вместе со сценой. |
| **Ambient** (окружающий звук) | Зацикленные звуки среды, например природы, города или помещения. |
| **Sound Effects** (звуковые эффекты, SFX) | Короткие звуки для меню, боя и исследования. |
| **Sprites** (спрайты) | Изображения персонажей и предметов на экране. |
| **Backgrounds** (фоны) | Изображения сцены за текстом истории. |

## Стартовый набор

Marinara устанавливает бесплатную стартовую библиотеку при первом запуске сервера и обновляет ее при следующих запусках, если встроенный набор изменился. В нее входят:

- Пять треков **Music** для разных настроений сцены.
- Зацикленные записи **Ambient** в папках `nature`, `urban` и `interior`.
- Звуки **Sound Effects** для меню, боя и исследования.

Папки **Backgrounds** и **Sprites** в Asset Browser изначально пустые. Спрайтов персонажей в комплекте нет, поэтому добавьте изображения, которые подходят вашим играм. Для фонов режим Game Mode также берет изображения из собственной библиотеки фонов приложения. При новой установке в ней 13 стартовых изображений и простой `Black.jpg`, и игры могут использовать их без загрузки. Если в этой папке уже были изображения, восстанавливается только `Black.jpg`. Сгенерированные изображения сцен и ваши загрузки добавляются к ним.

Все встроенные аудиофайлы распространяются по лицензии CC0 (общественное достояние, можно использовать свободно). Сведения об авторстве каждого файла лежат в файле `CREDITS.md`, который поставляется вместе с ресурсами на диске. В приложении он не показывается.

Встроенные файлы и папки защищены. Удалить или переместить их в **Asset Browser** нельзя, но переименовать или скопировать можно.

## Открытие Asset Browser

**Asset Browser** – это файловый менеджер для игровых ресурсов. Откройте его из **Settings** (настройки):

1. Откройте **Settings**.
2. Перейдите на вкладку **Imports** (импорт).
3. Найдите **Game Assets** (игровые ресурсы) и нажмите **Asset Browser**.

Или откройте его из игры:

1. Откройте чат Game Mode.
2. Нажмите или коснитесь кнопки **Game Assets** (значок папки) справа вверху чата. На компьютере и телефоне ее можно перетащить в другое место.

Кнопка появляется только в чатах Game Mode. Она открывает **Game Assets** с **Asset Browser** внутри: перемещаемое окно на компьютере или панель на всю ширину на телефоне. Если вы перенесли его командой **Put back in Chat Settings** (вернуть в настройки чата), вместо этого откройте раздел **Game Assets** в Chat Settings.

На панели инструментов есть навигационная цепочка, начинающаяся с **Game Assets**, переключатель **Grid view** (сетка) и **List view** (список), а также **Upload** (загрузить), **New** (создать), **Rescan** (пересканировать), **Open in system folder** (открыть в системной папке) и поле **Search in folder** (поиск в папке). На широких экранах слева есть дерево папок для перехода между категориями.

## Загрузка своих ресурсов

Marinara проверяет каждую загрузку по правилам из раздела [Типы и размеры файлов](#file-types-and-sizes). Используйте любой из двух способов.

### Загрузка из Asset Browser

1. Откройте **Asset Browser**.
2. Откройте одну из пяти папок-категорий или вложенную папку внутри нее.
3. Нажмите **Upload** и выберите файлы либо перетащите файлы в область файлов.

Нужно находиться внутри папки-категории. Если перетащить файлы на верхнем уровне, приложение попросит сначала открыть такую папку.

### Загрузка из Settings

1. Откройте **Settings** и перейдите на вкладку **Imports**.
2. В разделе **Game Assets** выберите категорию в **Type** (тип): **Music**, **Ambient**, **Sound Effects**, **Sprites** или **Backgrounds**.
3. Укажите место назначения в **Folder** (папка) или оставьте значение по умолчанию.
4. Нажмите **Choose Files** (выбрать файлы) и выберите файлы.
5. Нажмите **Upload to Server** (загрузить на сервер).

Если не получилось, сообщение об ошибке перечисляет допустимые типы файлов для этой категории. Для музыки проверьте путь к папке (см. [Правило для папок с музыкой](#the-music-folder-rule)).

Значения **Folder** по умолчанию:

| Тип | Папка по умолчанию |
| --- | --- |
| **Music** | `exploration/fantasy/calm` |
| **Ambient** | `nature` |
| **Sound Effects** | `exploration` |
| **Sprites** | `generic-fantasy` |
| **Backgrounds** | `custom` |

<a id="file-types-and-sizes"></a>

### Типы и размеры файлов

| Категория | Допустимые типы файлов |
| --- | --- |
| Music, Ambient, Sound Effects | MP3, OGG, WAV, FLAC, M4A, AAC, WebM |
| Sprites | PNG, JPG, JPEG, GIF, WebP, AVIF, SVG |
| Backgrounds | PNG, JPG, JPEG, GIF, WebP, AVIF |

Аудиофайлы и изображения могут весить до 50 МБ каждый. Текстовые файлы – до 10 МБ.

<a id="the-music-folder-rule"></a>

### Правило для папок с музыкой

Каждый музыкальный трек должен лежать по трехуровневому пути `state/genre/intensity`, например `exploration/fantasy/calm`. Если путь не совпадает, загрузка не проходит. По этой структуре режим Game Mode понимает, когда играть каждый трек.

- Состояние: `exploration`, `dialogue`, `combat`, `travel_rest`.
- Жанр: `fantasy`, `horror`, `romance`, `mystery`, `scifi`, `modern`, `slice_of_life`, `adventure`, `drama`, `custom` или семейство мира (см. ниже), например `wuxia`.
- Интенсивность: `calm`, `tense`, `intense`.

На папки окружающего звука, звуковых эффектов, спрайтов и фонов такое правило не распространяется. Их вложенные папки можно называть как угодно.

## Наведение порядка в ресурсах

Чтобы увидеть действия с файлом или папкой, щелкните по нему правой кнопкой на компьютере или откройте его меню "...".

| Действие с файлом | Что оно делает |
| --- | --- |
| **Rename** (переименовать) | Не срабатывает, если такое имя в этой папке уже занято. |
| **Move** (переместить), **Copy** (скопировать) | Отправляет файл в другую папку через выбор папки. |
| **Delete** (удалить), **Download** (скачать) | Удаляет файл или сохраняет его на ваше устройство. |

| Действие с папкой | Что оно делает |
| --- | --- |
| **Create subfolder** (создать вложенную папку) | Создает внутри нее новую папку. |
| **Open in system folder** | Показывает папку в файловом менеджере компьютера. |
| **Delete folder** (удалить папку) | Если внутри есть файлы, сначала отметьте **Delete everything inside** (удалить все внутри). |

**New** на панели инструментов создает **New folder** (новая папка), **New text file** (новый текстовый файл) или **New markdown file** (новый файл markdown) в текущей папке. Чтобы работать сразу с несколькими файлами, поставьте их флажки. Полоса показывает, сколько файлов выбрано, и содержит **Select all** (выбрать все), **Move**, **Copy** и **Delete**. Большие папки загружаются частями с кнопкой **Load more** (показать еще).

У каждой папки может быть короткая заметка. Нажмите на текст описания или на подсказку **Add description...**, чтобы ее написать. У пяти папок-категорий описания фиксированные.

### Пересканирование после изменений извне

Marinara ведет внутренний список ресурсов, чтобы режим Game Mode быстро их находил. Загрузки через приложение обновляют его автоматически. Если вы копируете файлы в папку игровых ресурсов на компьютере в обход приложения, нажмите **Rescan**, чтобы приложение перечитало папку. **Rescan** есть на панели инструментов **Asset Browser** и в разделе **Game Assets** в **Settings**.

### Открытие папки на компьютере

**Open in system folder** работает, только когда вы используете приложение на том же компьютере, где работает сервер. На телефоне, планшете или другом компьютере приложение сообщит, что системные папки можно открыть только с устройства, на котором работает Marinara.

## Выбор ресурсов, доступных игре

Чат Game Mode может использовать только часть ваших папок с ресурсами, например чтобы веселая музыка не звучала в игре ужасов.

1. Во время настройки раскройте **Adjust Game Assets for this Game** (настроить игровые ресурсы для этой игры) на шаге **Features** (возможности). Для уже созданной игры откройте ее окно **Game Assets**.
2. Нажмите кнопку **Game assets**. Надпись на ней сменится на **Selecting**.
3. Небольшим переключателем состояния на каждой папке включите ее или исключите.

Полоса показывает "All folders included" или число исключенных папок. **Reset to all** (вернуть все) снова включает все папки. Выбор сохраняется только для этого чата. Он меняет папки, из которых режим Game Mode может выбирать, и не удаляет и не скрывает ни одного файла.

<a id="a-settings-own-art-and-music"></a>

### Собственные изображения и музыка мира

У игры, начатой с набором мира, есть семейство изображений, которое показано в разделе **Art and music** (изображения и музыка), когда вы меняете слова набора: `fantasy`, `scifi`, `modern`, `wuxia`, `jazz_age`, `wasteland` или одно из собственных семейств набора. Игра использует папки, названные по ее семейству, и все папки, не названные ни по какому семейству, а папки других семейств пропускает. Игра в киберпанке никогда не играет фэнтезийную боевую музыку и не показывает зачарованный лес. Если ничего из ее семейства или общих папок не подходит, не играет ничего, а не трек другого семейства. Игра без набора мира использует все папки.

- **Музыка**: положите треки мира в `music/<state>/<family>/<intensity>`, например `combat/wuxia/intense`. Они играют раньше общих треков.
- **Фоны**: `backgrounds/<family>`. Фоны, сгенерированные в игре с набором мира, тоже сохраняются туда.
- **Звуки боя**: звук в `sfx/combat/<family>` с тем же названием, что и встроенный, например `sword-swing`, заменяет его в играх этого семейства. Встроенные звуки боя фэнтезийные, поэтому бои других семейств идут в тишине, пока вы не добавите их собственные звуки.

Встроенные стартовые фоны считаются общими, кроме фэнтезийных (`ancient_library`, `castle_cliff`, `enchanted_forest`) и современного `city_night`. Набор мира, сохраненный до появления семейств изображений, продолжает работать: набор, созданный из стартового, использует семейство этого стартового набора, а любой другой использует все папки, пока вы не выберете семейство в **Art and music**. Полоса выбора, описанная выше, называет семейство открытой игры.

<a id="generated-sound-effects-and-music"></a>

## Генерируемые звуковые эффекты и музыка

Режим Game Mode может генерировать звуковые эффекты и музыку через аккаунт **Music & Sound Effects** (музыка и звуковые эффекты). Выберите ElevenLabs, SunoAPI или свой совместимый сервер. Каждый новый звук или трек использует аккаунт этого сервиса. Встроенное аудио остается доступным без генерации.

**Перед началом:** вам нужен аккаунт **Music & Sound Effects**. В окне **Add account** (добавить аккаунт) для него нет плитки. Такие аккаунты появляются после обновления или импорта: **Import a backup** (импортировать резервную копию) в разделе **Connections** (подключения). См. [настройку провайдера и ограничения](../connections/providers-reference.md#music--sound-effects).

1. В **Connections** откройте модель аккаунта через **Edit model** (изменить модель).
2. Выберите сервис, введите его ключ и выберите модели музыки и звуковых эффектов. Для музыки SunoAPI также нужен общедоступный HTTPS-адрес обратного вызова. Своему серверу нужны пути его эндпоинтов.
3. Включите **Sound-effect generation** (генерация звуковых эффектов), **Music generation** (генерация музыки) или обе настройки.
4. Сохраните аккаунт. См. [настройку провайдера и ограничения](../connections/providers-reference.md#music--sound-effects).

Затем включите генерацию при создании игры:

1. На шаге **Features** мастера настройки найдите карточку **Game Audio** (звук в игре).
2. В поле выбора аккаунта выберите свой аккаунт или оставьте **Use the default Music & Sound Effects account** (использовать аккаунт музыки и звуковых эффектов по умолчанию).
3. Оставьте **Sound effects** (звуковые эффекты) и **Music** включенными или выключите то, что вам не нужно.

Для каждого переключателя в выбранном аккаунте должна быть включена соответствующая возможность. Речевой аккаунт Audio для генерации не используется.

Во время игры:

- **Sound effects.** После ходов GM Marinara запрашивает у сервиса короткие звуки, подходящие к сцене.
- **Music.** Marinara сочиняет по одному инструментальному треку длиной около двух минут для каждого места, которое посещает отряд, и для каждого вида боя, например боя с боссом. Каждый трек создается один раз и потом используется повторно. Трек нового места начинает звучать при одной из следующих смен сцены, чтобы музыка не врывалась посреди сцены. Трек боя плавно включается, как только он готов.

Сгенерированные звуки и треки сохраняются вместе с игровыми ресурсами, поэтому один и тот же звук не создается дважды. Если музыку в игре играет **Music DJ**, режим Game Mode музыку не генерирует.

## Своя папка с музыкой для Music DJ

**Music DJ** – это агент-помощник, который умеет играть музыку во время игры. В режиме Custom он проигрывает треки из выбранной вами папки. Когда вы включаете **Music DJ** для чата, в его настройках появляется **Apply to** (применить к). Этот параметр сохраняет папку для этого чата, для единственного персонажа чата или для всех чатов. Надпись **In use:** показывает папку, из которой играет музыка в чате. При варианте **All chats (default)** (все чаты, по умолчанию) источник **Game Assets** принимает путь внутри игровых ресурсов, например `music` или `music/combat`. Чтобы задать чату или персонажу свою папку, см. [Отдельная папка для чата или персонажа](../media/music.md#use-a-different-folder-for-a-chat-or-character).

В полном редакторе **Music DJ** есть раздел **Custom Music Library** (своя музыкальная библиотека). **Use Game Assets music folder** (использовать папку музыки Game Assets) выбирает между двумя режимами:

- Включено: поле **Game Assets music folder** (папка музыки Game Assets) читает папку внутри игровых ресурсов. **Open Folder** (открыть папку) открывает ее на компьютере сервера.
- Выключено: **Default music folder on this device** (папка с музыкой по умолчанию на этом устройстве) играет музыку из любой папки на компьютере, где работает сервер. Нажмите **Select Folder** (выбрать папку) или вставьте путь.

Для выбора папки за пределами приложения нужен привилегированный доступ. На том же компьютере, где работает сервер, это работает без дополнительной настройки. С другого устройства или через удаленный доступ сначала настройте доступ администратора. См. [Удаленный доступ](../REMOTE_ACCESS.md). Об остальных возможностях музыкального плеера см. [Music DJ](../media/music.md).
