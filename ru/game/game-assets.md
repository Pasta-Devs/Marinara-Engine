# Игровые ресурсы: музыка, звук, спрайты и фоны

В этом руководстве описана библиотека игровых ресурсов, из которой режим Game Mode берет музыку, звук, изображения персонажей и фоны сцен. Вы узнаете про встроенный стартовый набор, файловый менеджер **Asset Browser** (браузер ресурсов), загрузку своих файлов, выбор ресурсов, доступных каждой игре, а также звуковые эффекты и музыку, которые режим Game Mode может сгенерировать для вас.

## Что такое игровые ресурсы

Игровые ресурсы – это медиафайлы, которые режим Game Mode проигрывает и показывает во время сессии. Marinara Engine делит их на пять категорий:

- **Music** (музыка): фоновые музыкальные треки, которые меняются вместе со сценой.
- **Ambient** (окружающий звук): зацикленные звуки среды – природа, город или помещение.
- **Sound Effects** (звуковые эффекты, они же SFX): короткие звуки для меню, боя и исследования.
- **Sprites** (спрайты): изображения персонажей и предметов на экране.
- **Backgrounds** (фоны): изображения сцены за текстом истории.

Режим Game Mode читает эту библиотеку сам. Музыку, окружающий звук и фоны он подбирает автоматически по сцене, поэтому назначать ресурсы вручную во время игры не нужно.

## Встроенный стартовый набор

Marinara устанавливает бесплатную стартовую библиотеку при первом запуске сервера. При следующих запусках эти файлы обновляются, если встроенный набор изменился. В стартовый набор входят:

- Пять треков **Music** – по одному на каждое из нескольких настроений сцены.
- Набор зацикленных записей **Ambient** в папках природы, города и помещений.
- Звуки **Sound Effects** для меню, боя и исследования.

Файлов **Backgrounds** в комплекте нет. Папки фонов изначально пустые. Они заполняются только после загрузки изображений или когда режим Game Mode сам генерирует изображения сцены.
Файлов **Sprites** с изображениями персонажей в комплекте тоже нет. Добавляйте только те изображения персонажей, которые подходят вашим играм.

Все встроенные файлы распространяются по лицензии CC0: они находятся в общественном достоянии, и использовать их можно свободно. Полные сведения об авторстве каждого файла лежат в текстовом файле `CREDITS.md`, который поставляется вместе с ресурсами на диске. В приложении он не показывается.

Встроенные файлы и папки защищены. Удалить или переместить их из панели **Asset Browser** нельзя, поэтому стартовая библиотека остается целой. Переименовать или скопировать их по-прежнему можно.

## Открытие панели Asset Browser

Панель **Asset Browser** – это файловый менеджер для игровых ресурсов. Открыть ее можно двумя способами.

Из панели **Settings** (настройки):

1. Откройте панель **Settings**.
2. Перейдите на вкладку **Imports**.
3. Найдите раздел **Game Assets**.
4. Нажмите кнопку **Asset Browser**.

Из игры:

1. Откройте чат в режиме Game Mode.
2. Нажмите **Game Assets** (кнопку с папкой). Изначально она находится справа вверху чата. На компьютере и телефоне ее можно перетащить на другое место.

Кнопка есть только в чатах Game Mode. Она открывает **Game Assets** с **Asset Browser** внутри: перемещаемое окно на компьютере или панель на всю ширину на телефоне.

Если вы перенесли окно командой **Put back in Chat Settings** (вернуть в настройки чата), откройте раздел **Game Assets** в Chat Settings.

На верхней панели инструментов есть навигационная цепочка, которая начинается с **Game Assets**. Рядом с ней – переключатель между **Grid view** (сетка) и **List view** (список), кнопка **Upload** (загрузить) и кнопка **New** (создать). Там же кнопка **Rescan** (пересканировать), кнопка **Open in system folder** (открыть в системной папке) и поле **Search in folder** (поиск в папке). На широких экранах слева есть дерево папок для перехода между категориями.

## Загрузка своих ресурсов

Загрузить ресурсы можно двумя способами. Выбирайте тот, который удобнее.

### Загрузка через панель Asset Browser

1. Откройте панель **Asset Browser**.
2. Войдите в одну из пяти папок-категорий или во вложенную папку внутри нее.
3. Нажмите кнопку **Upload** и выберите файлы либо перетащите файлы в область файлов.

Сначала нужно оказаться внутри папки-категории. Если перетащить файлы на верхнем уровне, приложение попросит сначала открыть папку-категорию.

### Загрузка из панели Settings

1. Откройте панель **Settings** и перейдите на вкладку **Imports**.
2. Найдите раздел **Game Assets**.
3. Выберите категорию в меню **Type**: **Music**, **Ambient**, **Sound Effects**, **Sprites** или **Backgrounds**.
4. Укажите место назначения в поле **Folder** или оставьте предложенное значение по умолчанию.
5. Нажмите кнопку **Choose Files** и выберите файлы.
6. Нажмите кнопку **Upload to Server**.

Каждое значение **Type** подставляет в поле **Folder** разумный путь по умолчанию. Вот эти значения:

- **Music**: `exploration/fantasy/calm`
- **Ambient**: `nature`
- **Sound Effects**: `exploration`
- **Sprites**: `generic-fantasy`
- **Backgrounds**: `custom`

### Правила по типам и размеру файлов

Сервер проверяет по этим правилам каждую загрузку. Они действуют для обоих способов загрузки.

| Категория                     | Допустимые типы файлов               |
| ----------------------------- | ------------------------------------ |
| Music, Ambient, Sound Effects | MP3, OGG, WAV, FLAC, M4A, AAC, WebM  |
| Sprites                       | PNG, JPG, JPEG, GIF, WebP, AVIF, SVG |
| Backgrounds                   | PNG, JPG, JPEG, GIF, WebP, AVIF      |

Аудиофайлы и изображения могут весить до 50 МБ каждый. Текстовые файлы – до 10 МБ. Типы файлов, которые не подходят категории, сервер отклоняет. В сообщении об ошибке перечислены допустимые типы.

### Правило для папок с музыкой

Для музыки действует строгая структура папок. Каждый музыкальный трек должен лежать по трехуровневому пути `state/genre/intensity`, например `exploration/fantasy/calm`. Если путь не совпадает, загрузка не проходит.

Допустимые значения:

- Состояние: `exploration`, `dialogue`, `combat`, `travel_rest`.
- Жанр: `fantasy`, `horror`, `romance`, `mystery`, `scifi`, `modern`, `slice_of_life`, `adventure`, `drama`, `custom` или семейство мира (см. ниже), например `wuxia`.
- Интенсивность: `calm`, `tense`, `intense`.

Именно по этой структуре режим Game Mode понимает, когда играть каждый трек. На папки окружающего звука, звуковых эффектов, спрайтов и фонов это правило не распространяется. Их вложенные папки можно называть как угодно.

### Собственные изображения и музыка мира

У игры, начатой с набором мира, есть семейство изображений, которое показано в разделе **Art and music** (изображения и музыка), когда вы меняете слова набора: `fantasy`, `scifi`, `modern`, `wuxia`, `jazz_age`, `wasteland` или одно из собственных семейств набора. Игра использует папки, названные по ее семейству, и все папки, не названные ни по какому семейству, а папки других семейств не трогает, поэтому игра в киберпанке никогда не играет фэнтезийную боевую музыку и не показывает зачарованный лес. Если ничего из собственного семейства или общих папок не подходит, не играет ничего, а не трек другого семейства.

- **Музыка**: положите треки мира в `music/<state>/<family>/<intensity>`, например `combat/wuxia/intense`. Они играют раньше общих треков.
- **Фоны**: `backgrounds/<family>`. Фоны, сгенерированные во время игры с набором мира, тоже сохраняются туда.
- **Звуки боя**: звук в `sfx/combat/<family>` с тем же названием, что и встроенный, например `sword-swing`, заменяет его в играх этого семейства. Встроенные звуки боя фэнтезийные, поэтому бои другого семейства идут в тишине, пока вы не добавите его собственные.

Встроенные стартовые фоны считаются общими, кроме фэнтезийных (`ancient_library`, `castle_cliff`, `enchanted_forest`) и современного `city_night`. Игра без набора мира использует все папки, как раньше. Набор мира, сохраненный до появления семейств изображений, продолжает работать: набор, созданный из стартового, использует семейство этого стартового набора, а любой другой использует все папки, пока вы не выберете семейство в **Art and music**. Полоса выбора, описанная в разделе [Выбор ресурсов, доступных игре](#choosing-which-assets-a-game-can-use), называет семейство открытой игры.

## Наведение порядка в ресурсах

Панель **Asset Browser** помогает держать файлы в порядке. Чтобы увидеть доступные действия, щелкните по файлу или папке правой кнопкой на компьютере либо откройте меню "..." рядом с ними.

Действия с файлом:

- **Rename** (переименовать): дать файлу новое имя. Переименование не проходит, если такое имя в папке уже занято.
- **Move** (переместить) и **Copy** (скопировать): отправить файл в другую папку через выбор папки.
- **Delete** (удалить): убрать файл.
- **Download** (скачать): сохранить файл на устройство.

Действия с папкой:

- **Create subfolder** (создать вложенную папку): создать новую папку внутри.
- **Open in system folder**: показать папку в файловом менеджере компьютера.
- **Delete folder** (удалить папку): убрать папку. Если внутри еще есть файлы, сначала нужно поставить флажок **Delete everything inside** (удалить все внутри).

Кнопка **New** на панели инструментов тоже создает элементы в текущей папке. Она предлагает **New folder**, **New text file** и **New markdown file**.

Чтобы работать сразу с несколькими файлами, используйте флажки на каждом файле. Полоса показывает, сколько файлов выбрано, и содержит кнопки **Select all** (выбрать все), **Move**, **Copy** и **Delete**. Большие папки показывают содержимое частями, а под ним есть кнопка **Load more** (показать еще).

К каждой папке можно добавить короткую заметку. Нажмите на текст описания папки или на подсказку **Add description...**, чтобы написать его. У пяти папок-категорий описания фиксированные, изменить их нельзя.

Помните, что встроенные файлы стартового набора защищены. Их можно переименовать или скопировать, но не переместить и не удалить.

## Пересканирование после изменений извне

Marinara ведет внутренний список ресурсов, чтобы режим Game Mode находил их быстро. При загрузке через приложение этот список обновляется сам.

Если скопировать файлы в папку игровых ресурсов напрямую на компьютере, минуя приложение, оно заметит это не сразу. Нажмите кнопку **Rescan**, чтобы приложение перечитало папку и подхватило новые файлы. Кнопка **Rescan** есть и на панели инструментов **Asset Browser**, и в разделе **Game Assets** в панели **Settings**.

<a id="choosing-which-assets-a-game-can-use"></a>

## Выбор ресурсов, доступных игре

Каждый чат режима Game Mode может ограничиться лишь частью папок с ресурсами. Это удобно, например, когда в игре ужасов не должна звучать веселая музыка.

Во время настройки раскройте пункт **Adjust Game Assets for this Game** на шаге **Features**. В уже созданной игре откройте окно **Game Assets**.

Дальше:

1. Нажмите кнопку **Game assets**. Пока режим активен, на ней написано **Selecting**.
2. Небольшим переключателем состояния на каждой папке включите ее в набор или исключите.

Полоса показывает "All folders included" или число исключенных папок, а кнопка **Reset to all** возвращает все папки обратно. Этот выбор сохраняется только для одного чата. Он меняет набор папок, из которых режим Game Mode берет файлы, но ничего не удаляет и не скрывает. За пределами этого чата режима Game Mode он не действует.

<a id="generated-sound-effects-and-music"></a>

## Генерируемые звуковые эффекты и музыка

Режим Game Mode также умеет создавать для ваших сцен новые звуковые эффекты и музыку с помощью ElevenLabs – сервиса ИИ для работы со звуком. Нужен ключ API ElevenLabs. Каждый новый звук или трек – это отдельный запрос к ElevenLabs от вашего аккаунта.

Сначала настройте аудиоподключение:

1. Откройте панель **Connections** (подключения) и создайте подключение с провайдером **Audio**.
2. В списке **Audio Source** (источник звука) выберите **ElevenLabs**, затем вставьте свой ключ API ElevenLabs.
3. Включите **Game sound effects** (звуковые эффекты в игре), **Game music** (музыка в игре) или оба переключателя. Эти переключатели появляются только для источника **ElevenLabs**.
4. Сохраните подключение.

Затем включите эту функцию при создании игры:

1. На шаге **Features** мастера настройки найдите карточку **Game Audio** (звук в игре).
2. В поле **Audio Connection** (аудиоподключение) выберите свое подключение ElevenLabs или оставьте **Use the default audio connection** (использовать аудиоподключение по умолчанию).
3. Оставьте **Sound effects** (звуковые эффекты) и **Music** (музыка) включенными или выключите то, что вам не нужно.

**Sound effects** и **Music** нельзя включить, пока выбранное подключение не является подключением ElevenLabs с включенным соответствующим переключателем. Об этом сообщает карточка.

Во время игры:

- **Sound effects**: после ходов GM Marinara запрашивает у ElevenLabs короткие звуковые эффекты, подходящие к сцене.
- **Music**: Marinara сочиняет по одному инструментальному треку длиной около двух минут для каждого места, которое посещает отряд, и для каждого типа боя, например боя с боссом. Каждый трек создается только один раз, а потом используется повторно. Трек нового места начинает звучать при одной из следующих смен сцены, чтобы музыка не обрывала сцену на середине. Трек боя плавно включается, как только он готов.

Сгенерированные звуки и треки сохраняются вместе с игровыми ресурсами, поэтому один и тот же звук не создается дважды. Если музыку в игре играет агент **Music DJ**, режим Game Mode музыку не генерирует.

## Своя папка с музыкой для Music DJ

**Music DJ** – это агент-помощник, который умеет играть музыку во время игры. В режиме Custom он проигрывает треки из выбранной вами папки. Задать эту папку можно в двух местах.

Когда вы включаете агента **Music DJ** для чата, форма настройки следует источнику, сохраненному в агенте Music DJ. Вариант **Game Assets** показывает путь внутри игровых ресурсов, например `music` или `music/combat`. Вариант **Folder on this device** показывает сохраненный путь на устройстве сервера и кнопку **Choose Folder** (выбрать папку).

В полном редакторе агента **Music DJ** есть раздел **Custom Music Library**. Переключатель **Use Game Assets music folder** выбирает между двумя режимами:

- Переключатель включен: в поле **Game Assets music folder** указывается папка внутри игровых ресурсов, например `music` или `music/combat`. Кнопка **Open Folder** открывает эту папку на машине сервера.
- Переключатель выключен: поле **Music folder on this device** позволяет режиму Custom играть музыку из любой папки на компьютере, где работает сервер. Нажмите кнопку **Select Folder**, чтобы открыть системный выбор папки, или вставьте путь к папке в это поле.

Для выбора папки за пределами приложения нужен привилегированный доступ. На том же компьютере, где работает сервер, это работает без дополнительной настройки. С другого устройства или через удаленный доступ сначала нужно настроить доступ администратора. О том, как его включить, читайте в руководстве [Удаленный доступ](../REMOTE_ACCESS.md). Все остальное о музыкальном плеере описано в руководстве [Music DJ](../media/music.md).

## Открытие папки на компьютере

Кнопка **Open in system folder** открывает выбранную папку с ресурсами в обычном файловом менеджере компьютера. Это работает только тогда, когда приложение открыто на том же компьютере, где работает сервер. На телефоне, планшете или другом компьютере приложение сообщит, что системные папки открываются только на устройстве, где работает Marinara.
