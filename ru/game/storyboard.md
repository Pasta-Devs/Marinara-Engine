# Руководство по агенту Storyboard

Агент **Storyboard** скачивается отдельно и превращает завершенный текст истории в упорядоченные картинки ключевых кадров, а при желании – и в короткие клипы, созданные из этих картинок. Он работает в режимах Game Mode и Roleplay. Чаты Conversation его не используют.

Пакет Storyboard дает промпты планирования, значения по умолчанию и настройки для отдельного чата. Marinara отвечает за генерацию медиа, сохраняет результаты в панели **Gallery** (галерея) и показывает их в чате или в панели просмотра Game. Это руководство сначала описывает Game Mode. Работа в Roleplay описана дальше, в разделе [Раскадровка в режиме Roleplay](#roleplay-storyboards). Об остальных возможностях Roleplay см. руководство [Режим Roleplay: начало работы](../roleplay/getting-started.md).

- **Game Mode** берет один завершенный ход с повествованием GM (ведущего игры). В нем есть отдельные переключатели **Automatic Storyboard Illustrations** (автоматические иллюстрации раскадровки) и **Automatic Storyboard Animations** (автоматическая анимация раскадровки), а **Gallery → Create storyboard** (галерея → создать раскадровку) работает для последнего хода GM. Раскадровка показывается в плавающей панели просмотра или как фон Game, синхронно с повествованием, а для неподвижных кадров и анимации используются отдельные планировщики.
- **Roleplay** берет завершенные сообщения после последнего удачного эпизода. Варианты автоматики – **Manual only** (только вручную), **Still images** (неподвижные картинки) или **Animations** (анимация), а **Gallery → Create storyboard** работает с последним завершенным ответом ассистента. Раскадровка показывается прямо в чате, под ответом, которым заканчивается эпизод, а для планирования используются контракт эпизода, визуальный стиль, необязательное дополнение для анимации и контракт вывода.

В обоих режимах картинки ключевых кадров сохраняются в Gallery на вкладке **Images** (изображения), а клипы – на вкладке **Videos** (видео).

## Установка агента

1. Откройте панель **Agents** (агенты) значком Sparkles.
2. Выберите **Agent Organizer** (организатор агентов).
3. Откройте **Storyboard** и нажмите **Install** (установить).
4. Откройте чат Game или Roleplay, затем откройте **Chat Settings → Agents** (настройки чата → агенты).
5. Включите **Enable Agents** (включить агентов), затем включите **Enable Storyboards** (включить раскадровки) в карточке Storyboard.

Установка делает агента доступным, но не включает его во всех чатах. Перезапускать Marinara не нужно.

Если не получилось и Storyboard нет в Chat Settings, проверьте, что пакет установлен, чат работает в режиме Game или Roleplay, а версия пакета работает с вашей версией Marinara.

## Раскадровка в режиме Game Mode

В режиме Game Mode агент Storyboard берет источником истории ровно один завершенный ход с повествованием GM. Он убирает скрытые командные теги GM, планирует упорядоченные кадры и привязывает каждый кадр к отрезку читаемых частей хода. Панель просмотра меняет кадры по мере того, как читатель продвигается по этим частям.

### Создание раскадровки в игре

**Перед началом:** игре нужен аккаунт для изображений (собственный аккаунт игры или аккаунт из общих настроек Storyboard). См. руководство [Провайдеры генерации изображений и их настройка](../media/image-providers.md).

1. Установите Storyboard и откройте чат Game Mode.
2. Откройте **Chat Settings → Agents**, включите **Enable Agents**, а затем **Enable Storyboards**.
3. Дождитесь конца хода с повествованием GM.
4. Откройте **Chat Settings → Gallery** и нажмите **Create storyboard**.

Чтобы снова открыть закрытую панель просмотра, нажмите **View storyboard** (посмотреть раскадровку) в Gallery. Ручная генерация следует текущей настройке анимации: когда включено **Automatic Storyboard Animations**, ручная раскадровка тоже запрашивает клипы.

Если не получилось, см. раздел [Устранение неполадок](#troubleshooting).

### Автоматическая раскадровка в Game Mode

В карточке Storyboard два переключателя:

- **Automatic Storyboard Illustrations** создает неподвижные ключевые кадры после завершенного хода GM.
- **Automatic Storyboard Animations** дополнительно создает клип для каждого ключевого кадра. Включение анимации включает и иллюстрации, а выключение иллюстраций выключает анимацию.

Автоматическая генерация работает, только пока агент включен для этой игры, и не создает раскадровку заново для хода, у которого она уже есть. Если для последнего хода нужна еще одна, воспользуйтесь ручным действием в Gallery.

Если в настройках генерации включено **Expose media prompts before sending** (показывать промпты медиа перед отправкой), ручная раскадровка в игре может показать собранные промпты картинок для проверки. Автоматические раскадровки пропускают проверку, чтобы игра не останавливалась.

### Настройки игры

Откройте **Chat Settings → Agents → Storyboards**.

| Настройка | По умолчанию у агента | Чем управляет |
| --- | --- | --- |
| **Enable Storyboards** | Выключено в каждом чате | Включает установленного агента для этой игры. |
| **Automatic Storyboard Illustrations** | Берется из Automatic generation | Неподвижные ключевые кадры после каждого хода GM. |
| **Automatic Storyboard Animations** | Берется из Automatic generation | Клипы MP4 для каждого ключевого кадра. |
| **Keyframes per Turn** | 3 (от 1 до 200) | Желаемое число кадров. Короткий ход может дать меньше. |
| **Animation Clip Duration** | 5 секунд (от 1 до 15) | Запрашиваемая длительность каждого клипа. Сервис может ее урезать. |
| **Viewer Display** | Floating | Перетаскиваемая панель просмотра или фон Game на весь экран. |
| **Illustration Planner** | Still Keyframes | Планирует законченные неподвижные иллюстрации. |
| **Animation Planner** | Comic Page Animation | Планирует первые кадры, пригодные для анимации, и указания по движению. |
| **Use Storyboard Template** | Включено | Применяет выбранный итоговый шаблон оформления иллюстрации. |
| **Storyboard Illustration Prompt** | Game Scene Illustration | Оформляет запланированный кадр для сервиса изображений. |
| **Storyboard Video Prompt** | Cinematic Scene Video | Оформляет первый кадр и план движения для сервиса видео. |

Пакет дает и планировщики для NovelAI, комиксов, манги, аниме и LTX. Выбор планировщика анимации сам по себе видео не включает. По-прежнему нужны **Automatic Storyboard Animations** и аккаунт для видео.

Любой чат может переопределить значения агента по умолчанию. Унаследованные значения Chat Settings помечает как **Using agent default**, а после того, как вы переопределите значение, рядом появляется кнопка сброса.

### Как строится раскадровка в игре

В Game Mode для неподвижных кадров и для анимации есть отдельные планировщики.

```text
completed GM narration
  -> still or animation planner
  -> Storyboard Illustration Prompt
  -> image account
  -> optional Storyboard Video Prompt
  -> video account
```

Планировщик выбирает моменты истории и расставляет их по порядку. Промпт иллюстрации – это шаблон оформления для сервиса, а не еще один планировщик. Когда анимация включена, планировщик анимации выдает точное описание первого кадра и указание по движению, а промпт видео превращает это указание в итоговый запрос.

### Панель просмотра в игре

- **Floating viewer** (плавающая панель просмотра) – это панель поверх игры, которую можно перетаскивать и менять ее размер. Она следует за местом чтения в повествовании и показывает соответствующий кадр. Готовое видео проигрывается, а пока его нет, показывается картинка кадра. Закрытие скрывает панель для текущего хода. Чтобы открыть ее снова, используйте **Gallery → View storyboard**.
- **Game background** (фон игры) помещает активный кадр за остальную часть экрана. Пока этот режим включен, он заменяет создаваемый фон сцены, поэтому **Generate background** (создать фон) недоступна. Фоновые клипы проигрываются один раз и остаются на последнем кадре.

Для повтора, воспроизведения и паузы и отключения звука откройте **Game controls** (управление игрой). Это кнопка с геймпадом рядом с правым верхним углом чата. На компьютере она открывается как окно, а на телефоне – как панель. Если вы перенесли ее в Chat Settings, откройте там раздел **Game controls**.

### Storyboard Optimized – это не переключатель агента

Стиль подачи **Storyboard Optimized** (оптимизировано для раскадровки) в мастере настройки меняет промпт повествования GM так, чтобы в ходах были более сильные визуальные опоры, которые можно показать в кадре. Он не устанавливает и не включает Storyboard, не включает автоматическую генерацию медиа и не выбирает аккаунты для изображений и видео. Агент работает и со стилем **Standard** (стандартный), и со стилем **Storyboard Optimized**. Установите и включите агента отдельно.

### Рецепты для Game Mode

Каждый рецепт сочетает цепочку Storyboard с остальными настройками игры и сервиса. Примените названную цепочку, если ваш пакет ее предлагает, или выберите перечисленные значения вручную.

#### Раскадровки-комиксы через Google

Цепочка: **Illustration Planner** – Still Keyframes, **Animation Planner** – Comic Page Animation, **Storyboard Illustration Prompt** – Game Scene Illustration, **Storyboard Video Prompt** – Comic Page Video, **Use Storyboard Template** – включено.

Что проверить в игре:

- **Illustrator**: включено (шаг Features мастера настройки)
- Аккаунт для изображений: Google/Nano Banana, **Image Style** (стиль изображений): Default; сохраните художественный стиль, созданный при настройке
- **Automatic Storyboard Illustrations**: включено
- **Automatic Storyboard Animations**: выключено
- **Keyframes per Turn**: 3
- Аккаунт для видео: None

Так получаются обычные раскадровки из неподвижных кадров. Сохраненная цепочка анимации Comic Page применяется, только если позже вы выберете аккаунт для видео и включите **Automatic Storyboard Animations**.

#### Прямые теги NovelAI

Цепочка: **Illustration Planner** – NovelAI Keyframes. Для **Storyboard Illustration Prompt** создайте свой вариант, промпт которого содержит только текст ниже. Включите **Use Storyboard Template**. Animation Planner и Video Prompt оставьте без изменений.

```text
${scenePrompt}
```

Что проверить в игре:

- **Image Style**: Danbooru; уберите прозаический текст из поля **Style text** (текст стиля) в профиле Danbooru
- **Use Campaign Art Style**: выключено
- **Attach Card Appearance**: выключено
- **Send Avatar References**: выключено
- **Use NovelAI Character Prompts**: выключено
- **Queue media generation requests**: включено
- Подстройте под задачу положительные и отрицательные теги, а также теги иллюстрации

Сквозной шаблон отправляет компактные теги NovelAI от планировщика, не оборачивая их в обычный прозаический шаблон оформления.

#### Локальная связка Krea 2 + LTX 2.3

Цепочка: **Illustration Planner** – Still Keyframes как запасной вариант только для неподвижных кадров, **Animation Planner** – LTX Simple Image-to-Video, **Storyboard Illustration Prompt** – Storyboard First Frame, **Storyboard Video Prompt** – Narration Passthrough, **Use Storyboard Template** – включено.

На видеокарте с 8 ГБ видеопамяти начните с одного ключевого кадра в 480p. Когда это заработает, переходите к трем ключевым кадрам и большим размерам. Аккаунт ComfyUI, подстановки и полная проверка описаны в руководстве [Раскадровки LTX 2.3 в Game Mode](ltx-2-3-storyboards.md).

## Раскадровка в режиме Roleplay

В режиме Roleplay раскадровка собирает завершенные обмены сообщениями в визуальный эпизод, который показывается под ответом ассистента, завершающим этот эпизод.

### Создание раскадровки в Roleplay

1. Установите Storyboard и включите его для чата Roleplay.
2. В **Chat Settings → Agents → Storyboards** выберите **Prompt connection** (подключение для промпта) и **Image model** (модель изображений) или оставьте в них **Use global default** (использовать общее значение по умолчанию), если общая настройка завершена.
3. Выберите **Automatic mode** (автоматический режим):
   - **Manual only**: автоматических эпизодов нет. **Create storyboard** делает эпизод из неподвижных кадров по запросу.
   - **Still images**: автоматически создает эпизод с иллюстрациями.
   - **Animations**: автоматически создает картинки ключевых кадров и клип для каждого кадра. Нужен аккаунт для видео.
4. Задайте **Messages per episode** (сообщений на эпизод) и **Keyframes per episode** (ключевых кадров на эпизод).
5. Дождитесь конца нового ответа ассистента или откройте **Chat Settings → Gallery** и нажмите **Create storyboard**.

Чтобы переключаться между кадрами в раскадровке из нескольких ключевых кадров, используйте стрелки. Анимированный кадр показывает свой клип прямо в чате, а пока клип готовится или недоступен, показывает свою картинку.

### Как работает интервал эпизодов

Интервал – это число новых сообщений пользователя и ассистента, которое должно накопиться между удачными автоматическими раскадровками. Считаются обе роли, а новые сообщения попадают в эпизод по порядку. По умолчанию стоит 1, поэтому следующий завершенный ответ ассистента может сразу создать эпизод. Большее значение позволяет накопиться большему количеству диалога и действия. Исходный текст ограничен последними 20 сообщениями и 12 000 символов, поэтому длинный чат не может создать безразмерный запрос на планирование.

Счетчик сдвигается вперед только после того, как раскадровка сохранена полностью или частично, поэтому неудачный эпизод не расходует исходный материал. Открытие существующего чата не подтягивает старые ответы. Автоматическая генерация ждет нового завершенного ответа ассистента.

### Библиотека промптов Roleplay

Roleplay собирает один запрос к планировщику из четырех выбранных промптов:

| Настройка | По умолчанию | Назначение |
| --- | --- | --- |
| **Episode contract** | Completed Roleplay Episode | Выбирает моменты, подтвержденные исходным текстом, и сохраняет их в порядке сообщений. |
| **Visual style** | Normal / Anime | Облик каждого ключевого кадра. Другие варианты: NovelAI, Comic, Colored Manga, B&W Manga. |
| **Animation addon** | Simple Storyboard Motion | Используется только для клипов. Добавляет одно выполнимое действие, поведение камеры, реплики и звуки из исходного текста, окружение и остановку в конце. |
| **Output contract** | Roleplay Keyframe JSON | Структурированные поля ключевого кадра, которые возвращает планировщик. |

Затем **Storyboard Illustration Prompt** оформляет каждый первый кадр для сервиса изображений, а когда клипы включены, **Storyboard Video Prompt** оформляет план движения. Чтобы изменить эти промпты, откройте свернутую **Prompt library** (библиотека промптов) в Stage 1. Нажмите **Add option** (добавить вариант), чтобы создать свой промпт, затем переименуйте его, добавьте краткое описание и измените текст. Встроенным вариантам можно вернуть значения по умолчанию. Правка визуального стиля Roleplay не меняет планировщики Game Mode.

### Storyboard и Illustrator вместе

Storyboard не зависит от Illustrator, и ручные действия Illustrator остаются доступными. Когда раскадровка Roleplay стоит на **Still images** или **Animations**, Marinara пропускает обычную автоматическую картинку Illustrator для этого ответа, чтобы два агента не создавали конкурирующие медиа. **Manual only** оставляет работу Illustrator без изменений.

## Настройки агента Storyboard

Откройте панель **Agents**, выберите **Storyboard** и откройте его настройки. Эти значения действуют по умолчанию для чатов без собственных переопределений.

| Настройка | По умолчанию | Назначение |
| --- | --- | --- |
| Agent connection | Выбранный вами аккаунт агента | Планирует раскадровку с помощью модели. |
| **Image model** | **Use the chat image connection** | Создает каждый ключевой кадр. Аккаунт для изображений нужен хотя бы на одном уровне цепочки запасных вариантов. |
| **Video connection** | **Use the chat video connection** | Создает клипы, когда анимация включена. |
| **Automatic generation** | Still images | Начальное поведение автоматики для чатов, где агент только что включен. |
| **Keyframes per turn** | 3 (от 1 до 200) | Желаемое число упорядоченных кадров. |
| **Clip seconds** | 5 (от 1 до 15) | Запрашиваемая длительность каждого клипа. |
| **Viewer display** | Floating viewer | Вид панели просмотра Game по умолчанию. Roleplay всегда показывает раскадровки прямо в чате. |
| **Default Roleplay episode interval** | 1 (от 1 до 100) | Сколько нового материала Roleplay нужно между автоматическими эпизодами. |
| **Attach Card Appearance** | Включено | Добавляет в промпты картинок внешность распознанных персонажей. Карточка или персона с включенным **Image Appearance Override** (отдельное описание внешности для изображений) дает этот текст вместо своего поля **Appearance**. |
| **Send Avatar References** | Включено | Отправляет аватары распознанных персонажей и персон, когда сервис изображений принимает образцы. |
| **Use the final image template** | Включено | Оформляет запланированный кадр перед отправкой в сервис изображений. В чате Game это **Use Storyboard Template**. |
| **Use NovelAI character prompts** | Включено | Собственные промпты NovelAI для каждого персонажа, только в поддерживаемых официальных аккаунтах NovelAI V4 и V4.5. Другие сервисы используют общий путь промпта. |

Для Game Mode в библиотеке две линии планирования, и какая из них работает, зависит от того, создает игра неподвижные кадры или клипы: **Still planner** (по умолчанию Still Keyframes) и **Animation planner** (по умолчанию Comic Page Animation). Текст планировщиков правится в общих настройках агента, а каждый чат Game выбирает из вариантов в собственных настройках.

После планирования общие шаблоны оформления собирают итоговые запросы: **Default image prompt** (Game Scene Illustration) и **Default video prompt** (Cinematic Scene Video). У каждого пронумерованного этапа своя свернутая **Prompt library**: Stage 2 – для шаблонов оформления изображений, Stage 3 – для планировщиков движения с учетом изображения, Stage 4 – для сквозных шаблонов оформления видео. Среди вариантов для изображений есть также **Storyboard Illustration** и **Storyboard First Frame**. Среди вариантов для видео – **Anime Game Video**, **Comic Page Video** и **Narration Passthrough**. Чаты Game и Roleplay могут выбрать разные шаблоны оформления.

**Image-aware shot planning** (планирование кадров с учетом изображения) на Stage 3 также следует полю **Video prompting instructions** (инструкции для промптов видео) аккаунта для видео. Укажите в этом поле редактора аккаунта, чего ждет ваша видеомодель, например формулировок для камеры, длины промпта или звуковых подсказок.

В разных режимах аккаунты выбираются немного по-разному. В Roleplay в каждом чате есть отдельные списки для промпта, изображений и видео, а **Use global default** наследует настройки Storyboard. Game Mode берет собственные аккаунты для планирования, изображений и видео, если они заданы, а иначе – значения агента по умолчанию. Для неподвижных кадров нужен аккаунт для изображений. Для анимации нужны удачная картинка ключевого кадра и аккаунт для видео.

## Промпты картинок и узнаваемость персонажей

Планировщик решает, какие моменты показать, и описывает визуальное содержание каждого кадра. Итоговый шаблон картинки добавляет структуру для сервиса, внешность распознанных персонажей, работу с образцами, контекст места, художественное направление кампании и указания к картинке.

Если планировщик уже возвращает ровно тот синтаксис, который должен получить сервис изображений, используйте сквозной шаблон вроде `${scenePrompt}`. Выключайте **Use the final image template**, только если намеренно хотите обойти шаблон оформления. Обязательные указания к картинке действуют все равно.

Чтобы персонажи выглядели стабильнее:

- Держите поля Appearance в карточках персонажей конкретными и актуальными.
- Не выключайте **Attach Card Appearance**, если только планировщик сам не повторяет нужные детали.
- Держите **Send Avatar References** включенным, когда сервис принимает образцы, а аватары соответствуют нужному облику.
- Лучше держать в кадре немного персонажей, которых хорошо видно. Storyboard включает только распознанных видимых персонажей и персон, а не всех в чате.

## Стоимость и производительность

Каждый ключевой кадр – это отдельная задача на изображение. Анимированные раскадровки добавляют по одной задаче на видео на каждый удачный ключевой кадр, поэтому анимированная раскадровка из трех кадров может дать три запроса на изображения и три запроса на видео. Проверяя новый сервис или локальную установку, начните с неподвижных картинок и одного ключевого кадра. Увеличивайте число кадров, длину клипов и интервал автоматики только после того, как заработает базовый путь.

## Игры из старой системы раскадровки

В существующих чатах Game могут храниться настройки из старого встроенного интерфейса раскадровки. При установке пакета Marinara сохраняет их как переопределения для чата, поэтому старая игра может вести себя не так, как задают текущие значения агента по умолчанию. Откройте **Chat Settings → Agents → Storyboards** и нажмите кнопку сброса у каждого поля, которое должно снова следовать значению агента по умолчанию. Эти настройки – только данные для переноса. Для генерации пакет по-прежнему должен быть установлен и включен для игры.

## Устранение неполадок

### Кнопка Create storyboard есть, но генерация не удается

- Включите для чата **Enable Agents** и **Enable Storyboards**.
- Выберите рабочий аккаунт для генерации изображений в карточке Storyboard в Roleplay, в настройках игры или в общих настройках Storyboard.
- Дождитесь конца ответа ассистента или GM и попробуйте снова.

### В Roleplay не появился автоматический эпизод

- Выберите **Still images** или **Animations**, а не **Manual only**.
- Дождитесь нового завершенного ответа ассистента. Открытие чата не подтягивает старые сообщения.
- Проверьте **Messages per episode**. Должно накопиться достаточно новых сообщений пользователя и ассистента.
- Неудачный запуск не сдвигает счетчик, поэтому поищите в журнале сервера исходную ошибку сервиса или разбора ответа.

### Картинки появляются, а видео нет

- В Roleplay выберите **Animations**. В Game Mode включите **Automatic Storyboard Animations**.
- Выберите аккаунт Video Generation, который принимает картинку на вход и делает из нее видео.
- Проверьте вкладку **Videos** в Gallery. Клип может появиться позже картинки своего ключевого кадра.
- Если после сбоя модели планирование ушло в запасной путь, Marinara может сохранить запасные картинки и пропустить видео для этого запуска.

### Раскадровка неполная или зависла

Возможно, задача у сервиса не выполнилась, вышла за тайм-аут или уперлась в ограничение частоты запросов или содержимого. Если сервис работает, но медленно, увеличьте `IMAGE_GEN_TIMEOUT_MS` или `VIDEO_GEN_TIMEOUT_MS` в `.env` и перезапустите Marinara, потому что эти значения читаются при запуске. См. [Настройки сервера: справочник](../CONFIGURATION.md).

Включите режим отладки и поищите в журнале сервера `storyboard`, чтобы увидеть работу планировщика, собранный промпт картинки, выбор образцов и промпт видео. Отладочный журнал может содержать личный текст чата, поэтому перед отправкой кому-либо его нужно почистить.
