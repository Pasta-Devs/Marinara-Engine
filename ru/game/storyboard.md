# Руководство по агенту Storyboard

Агент **Storyboard** скачивается отдельно и превращает завершенный текст истории в упорядоченные картинки ключевых кадров, а при желании – и в короткие клипы на их основе. Он работает в режимах **Roleplay** и **Game Mode**. В чатах Conversation раскадровка не используется.

Так раскадровка работает сейчас – через агента. Пакет Storyboard дает промпты планирования (промпт – это текст, который Marinara отправляет ИИ), значения по умолчанию и настройки для отдельного чата. Marinara Engine отвечает за встроенную часть: генерирует медиа, сохраняет их в панели **Gallery** (галерея) и показывает в чате или в панели просмотра игры.

## Roleplay и Game Mode: краткое сравнение

| | Roleplay | Game Mode |
| --- | --- | --- |
| Источник истории | Завершенные сообщения пользователя и ответы ИИ после прошлого удачного эпизода | Один завершенный ход с повествованием GM (ведущего игры) |
| Варианты автоматики | **Manual only**, **Still images** или **Animations** | Отдельные переключатели **Automatic Storyboard Illustrations** и **Automatic Storyboard Animations** |
| Ручное действие | **Gallery > Create storyboard** для последнего завершенного ответа ИИ | **Gallery > Create storyboard** для последнего завершенного хода GM |
| Показ | Прямо в чате, под ответом ИИ, которым заканчивается эпизод | Плавающая панель просмотра или фон игры, синхронно с повествованием |
| Промпты планирования | Контракт эпизода, визуальный стиль, необязательное дополнение для анимации и контракт вывода | Отдельные планировщики для неподвижных кадров и для анимации |
| Общие итоговые промпты | Промпт картинки для иллюстрации и промпт видео для анимации | Промпт картинки для иллюстрации и промпт видео для анимации |

В обоих режимах картинки ключевых кадров сохраняются в панели **Gallery**, на вкладке **Images**, а клипы – на вкладке **Videos**.

## Установка агента

1. Откройте панель **Agents** (агенты) значком с искрами.
2. Перейдите в раздел **Download Agents**.
3. Откройте карточку **Storyboard** и нажмите кнопку **Install**.
4. Откройте чат в режиме Roleplay или Game Mode, затем перейдите в **Chat Settings > Agents** (настройки чата, раздел агентов).
5. Включите переключатель **Enable Agents**, а затем переключатель **Enable Storyboards** в карточке **Storyboard**.

После установки пакет доступен подходящим чатам, но сам собой ни в одном чате не включается. Перезапускать Marinara после установки текущей версии пакета не нужно.

Если агент Storyboard не появился в панели **Chat Settings**, проверьте, что пакет установлен, а чат работает в режиме Roleplay или Game Mode.

## Настройки агента Storyboard

Откройте панель **Agents**, выберите агента **Storyboard** и откройте его настройки. Эти значения действуют по умолчанию во всех чатах, где нет собственных переопределений.

### Значения по умолчанию для генерации и медиа

| Настройка | По умолчанию | Назначение |
| --- | --- | --- |
| Agent connection | Выбранное подключение для агентов | Планирует раскадровку силами модели ИИ |
| **Image connection** | Use the Game image connection | Генерирует каждый ключевой кадр; подключение для генерации изображений обязательно хотя бы на одном уровне цепочки |
| **Video connection** | Use the Game video connection | Генерирует клипы, когда включена анимация |
| **Automatic generation** | Still images | Задает исходное поведение автоматики для чатов, где агент только что включен |
| **Keyframes per turn** | 3, диапазон 1-6 | Задает желаемое число упорядоченных кадров |
| **Clip seconds** | 5, диапазон 1-15 | Задает запрашиваемую длительность каждого клипа |
| **Viewer display** | Floating viewer | Задает вид панели просмотра в Game Mode; в Roleplay раскадровка всегда показывается прямо в чате |
| **Default Roleplay episode interval** | 1, диапазон 1-100 | Задает, сколько нового материала копится в Roleplay между автоматическими эпизодами |
| **Attach Card Appearance** | On | Добавляет в промпты картинок описание внешности распознанных персонажей |
| **Send Avatar References** | On | Отправляет аватары распознанных персонажей и персоны (персонажа, за которого играете вы), если провайдер изображений принимает образцы |
| **Use the final image template** | On | Оформляет запланированный кадр перед отправкой провайдеру изображений |
| **Use NovelAI character prompts** | On | Использует собственный механизм промптов NovelAI для каждого персонажа в поддерживаемых официальных подключениях NovelAI V4/V4.5 |

### Библиотека промптов для Game Mode

В игровой библиотеке две разные линии планирования. Какая из них работает, зависит от того, что делает игра: неподвижные кадры или клипы.

| Настройка | По умолчанию | Назначение |
| --- | --- | --- |
| **Still planner** | Still Keyframes | Разбивает один завершенный ход GM на законченные моменты для неподвижных картинок |
| **Animation planner** | Comic Page Animation | Создает первые кадры, пригодные для анимации, и указания по движению с учетом длительности |

В пакете есть и другие планировщики: NovelAI, комикс, цветная манга, черно-белая манга, эпизод аниме и варианты под LTX. Текст промпта любого планировщика правится в общих настройках агента. Игровой чат выбирает из вариантов для неподвижных кадров и для анимации в **Chat Settings > Agents > Storyboards**.

### Библиотека промптов для Roleplay

В режиме Roleplay четыре выбранных промпта собираются в один запрос к планировщику.

| Настройка | По умолчанию | Назначение |
| --- | --- | --- |
| **Episode contract** | Completed Roleplay Episode | Выбирает завершенные моменты, подтвержденные исходным текстом, и сохраняет порядок сообщений |
| **Visual style** | Normal / Anime | Задает визуальную подачу каждого ключевого кадра |
| **Animation addon** | Simple Storyboard Motion | Добавляет движение, работу камеры, реплики и звуки из исходного текста, окружение и остановку в конце – только для клипов |
| **Output contract** | Roleplay Keyframe JSON | Задает структуру полей ключевого кадра, которые возвращает планировщик |

Откройте свернутую **Prompt library** (библиотеку промптов) в Stage 1, чтобы редактировать эти полные коллекции. Кнопка **Add option** добавляет свой промпт: его можно переименовать, снабдить кратким описанием и написать текст. Встроенным вариантам можно вернуть значения из пакета.

### Общие шаблоны оформления для провайдеров

После того как любой из режимов спланировал кадры, общие шаблоны оформления собирают итоговые запросы к провайдерам.

| Настройка | По умолчанию | Назначение |
| --- | --- | --- |
| **Default image prompt** | Game Scene Illustration | Оформляет каждый запланированный ключевой кадр для провайдера изображений |
| **Default video prompt** | Cinematic Scene Video | Оформляет картинку первого кадра и план движения для провайдера видео |

У каждого пронумерованного этапа своя свернутая **Prompt library**: Stage 2 содержит форматтеры изображений, Stage 3 — планировщики движения с учетом изображения, Stage 4 — форматтеры передачи промпта видео. Среди встроенных вариантов для картинок есть также **Storyboard Illustration** и **Storyboard First Frame**. Для видео доступны **Anime Game Video**, **Comic Page Video** и **Narration Passthrough**. Чаты Game Mode и Roleplay могут выбрать разные шаблоны оформления, и общий набор промптов при этом не меняется.

### Общие значения по умолчанию и переопределения в чате

Любой чат может переопределить значения агента. Унаследованные значения панель **Chat Settings** помечает как **Using agent default**, а после создания переопределения рядом появляется кнопка сброса.

Приоритет подключений в режимах слегка различается:

- В Roleplay есть отдельные списки для промпта, изображений и видео в каждом чате. Вариант **Use global default** берет значение из общих настроек агента Storyboard.
- Game Mode сначала берет собственные игровые подключения для планирования, изображений и видео, если они заданы, и только потом – значения агента Storyboard по умолчанию.

Для неподвижных кадров нужно подключение для генерации изображений. Для анимации нужны и удачно созданная картинка ключевого кадра, и подключение для генерации видео.

## Раскадровка в режиме Roleplay

В режиме Roleplay завершенные обмены репликами собираются в один визуальный эпизод, который появляется под ответом ИИ, завершающим этот эпизод.

### Быстрый старт

1. Установите агента **Storyboard** и включите его для чата в режиме Roleplay.
2. В **Chat Settings > Agents > Storyboards** выберите подключения в полях **Prompt connection** и **Image connection** либо оставьте **Use global default**, если общие настройки уже заполнены.
3. Выберите значение в списке **Automatic mode**:
   - **Manual only**: автоматических эпизодов нет; кнопка **Create storyboard** делает эпизод из неподвижных кадров по требованию.
   - **Still images**: эпизод с иллюстрациями создается автоматически.
   - **Animations**: автоматически создаются картинки ключевых кадров и клип для каждого кадра; нужно подключение для генерации видео.
4. Задайте значения в полях **Messages per episode** и **Keyframes per episode**.
5. Дождитесь конца нового ответа ИИ либо откройте панель **Gallery** и нажмите кнопку **Create storyboard**.

Переключаться между кадрами в раскадровке из нескольких кадров помогают стрелки. Анимированный кадр проигрывает свой клип прямо в чате, а пока клип готовится или недоступен, показывает картинку.

### Как работает интервал эпизодов

Интервал задает, сколько новых сообщений пользователя и ответов ИИ копится между удачными автоматическими раскадровками. Счетчик двигают обе стороны, а новые сообщения попадают в эпизод в хронологическом порядке.

По умолчанию стоит 1, поэтому эпизод может появиться сразу после следующего завершенного ответа ИИ. Большее значение дает диалогу и действию накопиться. Исходный текст ограничен последними 20 сообщениями и 12 000 символов, чтобы старый или очень длинный чат не создал безразмерный запрос к планировщику.

Точка отсчета сдвигается только после того, как раскадровка сохранена полностью или частично. Неудачный эпизод исходный материал не тратит. Открытие уже существующего чата не подтягивает старые ответы: автоматическая генерация ждет нового завершенного ответа ИИ.

### Цепочка промптов в режиме Roleplay

До общих шаблонов оформления в режиме Roleplay работают четыре слоя планирования:

1. **Episode contract** выбирает завершенные моменты истории, подтвержденные исходным текстом, и привязывает их к переданным сообщениям.
2. **Visual style** задает подачу: Normal/Anime, NovelAI, Comic, Colored Manga или B&W Manga.
3. **Animation addon** подключается только для анимированных раскадровок. Он описывает одно выполнимое действие, поведение камеры, реплики и звуки из исходного текста, окружение и остановку в конце.
4. **Output contract** задает структуру результата с ключевыми кадрами, который возвращает планировщик.

Затем **Storyboard Illustration Prompt** оформляет каждый запланированный первый кадр для провайдера изображений. Когда включены клипы, **Storyboard Video Prompt** оформляет план движения для провайдера видео.

Библиотека промптов Roleplay отделена от библиотеки планировщиков Game Mode. Правка визуального стиля в Roleplay не меняет игровые планировщики неподвижных кадров и анимации.

### Совместная работа агентов Storyboard и Illustrator

Storyboard и Illustrator – это разные агенты. Ручные действия агента Illustrator и остальные его материалы остаются доступными. Если в Roleplay для раскадровки выбрано **Still images** или **Animations**, Marinara не создает для этого завершенного ответа обычную автоматическую картинку агента Illustrator. Так два агента не делают конкурирующих материалов к одному ответу. Вариант **Manual only** обычную работу агента Illustrator не меняет.

## Раскадровка в режиме Game Mode

В режиме Game Mode источником истории служит ровно один завершенный ход с повествованием GM. Marinara убирает скрытые командные теги GM, планирует упорядоченные кадры и привязывает каждый кадр к своему отрезку читаемого текста хода. Панель просмотра меняет кадры по мере чтения этих отрезков.

### Быстрый старт

1. Установите агента **Storyboard**.
2. Создайте или откройте чат в режиме Game Mode.
3. Перейдите в **Chat Settings > Agents**, включите переключатель **Enable Agents**, а затем переключатель **Enable Storyboards**.
4. Проверьте, что у игры есть подключение для генерации изображений либо что его дают общие настройки агента Storyboard.
5. Дождитесь конца хода с повествованием GM.
6. Откройте панель **Gallery** и нажмите кнопку **Create storyboard**.

Закрытую панель просмотра можно вернуть кнопкой **View storyboard** в панели **Gallery**. Ручная генерация подчиняется текущей настройке анимации: когда включен переключатель **Automatic Storyboard Animations**, ручная раскадровка тоже запрашивает клипы.

### Автоматическая раскадровка в Game Mode

В карточке **Storyboard** два переключателя автоматики:

- **Automatic Storyboard Illustrations** создает неподвижные ключевые кадры после завершенного хода GM.
- **Automatic Storyboard Animations** дополнительно создает клип для каждого ключевого кадра. Включение анимации включает и иллюстрации, а выключение иллюстраций выключает анимацию.

Автоматическая генерация работает только тогда, когда агент Storyboard включен для этой игры. Второй раскадровки для хода, у которого она уже есть, приложение тоже не делает. Если раскадровка для последнего хода нужна еще раз, воспользуйтесь ручным действием в панели **Gallery**.

Если в настройках генерации включен переключатель **Expose image prompts before sending**, ручная раскадровка в игре может показать собранные промпты картинок для проверки. Автоматические раскадровки идут без окна проверки, чтобы игра не останавливалась.

### Настройки в чате Game Mode

Перейдите в **Chat Settings > Agents > Storyboards**.

| Настройка | По умолчанию у агента | Чем управляет |
| --- | --- | --- |
| **Enable Storyboards** | Off в каждом чате | Включает установленного агента для этой игры |
| **Automatic Storyboard Illustrations** | Берется из **Automatic generation** | Неподвижные ключевые кадры после каждого завершенного хода GM |
| **Automatic Storyboard Animations** | Берется из **Automatic generation** | Клипы MP4 для каждого ключевого кадра |
| **Keyframes per Turn** | 3, диапазон 1-6 | Желаемое число кадров; для короткого хода их может выйти меньше |
| **Animation Clip Duration** | 5 секунд, диапазон 1-15 | Запрашиваемая длительность каждого клипа; провайдер может ее урезать |
| **Viewer Display** | Floating | Перетаскиваемая панель просмотра или фон всей игры |
| **Still Planner** | Still Keyframes | Планирует законченные неподвижные иллюстрации |
| **Animation Planner** | Comic Page Animation | Планирует первые кадры, пригодные для анимации, и указания по движению |
| **Use Storyboard Template** | On | Применяет выбранный итоговый шаблон оформления иллюстрации |
| **Storyboard Illustration Prompt** | Game Scene Illustration | Оформляет запланированный кадр для провайдера изображений |
| **Storyboard Video Prompt** | Cinematic Scene Video | Оформляет первый кадр и план движения для провайдера видео |

В пакете есть и другие планировщики: NovelAI, комикс, манга, аниме и варианты под LTX. Сам по себе выбор планировщика анимации генерацию видео не включает: по-прежнему нужны переключатель **Automatic Storyboard Animations** и подключение для генерации видео.

### Цепочка промптов в режиме Game Mode

В режиме Game Mode планировщики для неподвижных и для анимированных результатов раздельные:

```text
completed GM narration
  -> Still Planner or Animation Planner
  -> Storyboard Illustration Prompt
  -> image connection
  -> optional Storyboard Video Prompt
  -> video connection
```

Планировщик выбирает моменты истории и расставляет их по порядку. Промпт иллюстрации – это шаблон оформления для провайдера, а не еще один планировщик истории. Когда включена анимация, планировщик анимации выдает и точное описание первого кадра, и указание по движению. Промпт видео превращает это указание в итоговый запрос.

### Обновленные рецепты для Game Mode

Каждый рецепт соединяет готовую цепочку раскадровки из пакета с остальными настройками игры и провайдера. Если пакет предлагает нужную цепочку, примените ее; если нет – выставьте перечисленные значения вручную.

#### Раскадровка-комикс через Google

Цепочка, которую задает пакет:

- **Illustration Planner**: Still Keyframes
- **Animation Planner**: Comic Page Animation
- **Storyboard Illustration Prompt**: Game Scene Illustration
- **Storyboard Video Prompt**: Comic Page Video
- **Use Storyboard Template**: On

Что проверить в настройках игры:

- **Visual Generation**: On
- **Image Connection**: Google/Nano Banana
- **Image Style**: Default
- Оставьте художественный стиль, созданный мастером настройки.
- **Automatic Storyboard Illustrations**: On
- **Automatic Storyboard Animations**: Off
- **Keyframes per Turn**: 3
- **Video Connection**: None

Так получаются обычные раскадровки из неподвижных кадров. Сохраненная цепочка анимации Comic Page заработает только после того, как вы выберете подключение для генерации видео и включите переключатель **Automatic Storyboard Animations**.

#### Прямые теги NovelAI

Цепочка, которую задает пакет:

- **Illustration Planner**: NovelAI Keyframes
- **Storyboard Illustration Prompt**: создайте свой вариант, текст промпта которого состоит только из строки:

  ```text
  ${scenePrompt}
  ```

- **Use Storyboard Template**: On
- Оставьте Animation Planner и Storyboard Video Prompt без изменений.

Что проверить в настройках игры:

- **Image Style**: Danbooru
- **Use Campaign Art Style**: Off
- **Attach Card Appearance**: Off
- **Send Avatar References**: Off
- **Use NovelAI Character Prompts**: Off
- **Queue media generation requests**: On
- Уберите прозаический текст из поля **Style Text** в профиле Danbooru.
- Подстройте под задачу положительные и отрицательные теги, а также теги иллюстрации.

Свой сквозной шаблон отправляет компактные теги NovelAI прямо от планировщика и не оборачивает их в обычный прозаический шаблон оформления иллюстрации.

#### Локальная связка Krea 2 + LTX 2.3

Цепочка, которую задает пакет:

- **Illustration Planner**: Still Keyframes как запасной вариант только для неподвижных кадров
- **Animation Planner**: LTX Simple Image-to-Video
- **Storyboard Illustration Prompt**: Storyboard First Frame
- **Storyboard Video Prompt**: Narration Passthrough
- **Use Storyboard Template**: On

На видеокарте с 8 ГБ видеопамяти начните с одного ключевого кадра в 480p. Когда он получится, переходите к трем кадрам и большему разрешению. Подключение ComfyUI, подстановки и полный порядок проверки описаны в руководстве [Раскадровки LTX 2.3 в Game Mode](ltx-2-3-storyboards.md).

### Стиль подачи Storyboard Optimized – это не переключатель агента

Стиль подачи **Storyboard Optimized** в мастере настройки игры меняет промпт повествования GM так, чтобы в ходах было больше ярких деталей, которые можно показать в кадре. Он не устанавливает и не включает агента Storyboard, не включает автоматическую генерацию медиа и не выбирает подключения для изображений и видео.

Агент Storyboard работает с обоими стилями подачи – Standard и Storyboard Optimized. Установить и включить агента нужно отдельно.

### Панель просмотра в игре

**Floating viewer** – это панель поверх игры: ее можно перетаскивать и менять ее размер. Она следит за местом чтения в повествовании GM и показывает соответствующий кадр. Готовое видео проигрывается, а пока его нет, виден сам кадр.

**Game background** помещает активный кадр за игровые элементы управления. Пока этот режим включен, он заменяет обычный создаваемый фон сцены, поэтому кнопка **Generate background** недоступна. Фоновый клип проигрывается один раз и остается на последнем кадре; в игровых элементах управления есть повтор, воспроизведение и пауза, а также отключение звука.

Закрытие плавающей панели скрывает ее только для текущего хода. Вернуть ее можно через **Gallery > View storyboard**.

## Промпты картинок и узнаваемость персонажей

У выбранного планировщика и у итогового промпта картинки разные задачи:

- Планировщик решает, какие моменты показать, и описывает содержание каждого кадра.
- Итоговый шаблон картинки добавляет структуру для провайдера, внешность распознанных персонажей, работу с образцами, контекст места, художественное направление кампании и указания к картинке.

Если планировщик уже возвращает промпт ровно в том виде, какой нужен провайдеру изображений, возьмите сквозной шаблон вроде `${scenePrompt}`. Переключатель **Use the final image template** выключайте только тогда, когда осознанно хотите обойти выбранный шаблон оформления. Обязательные указания к картинке действуют в любом случае.

Чтобы персонажи выглядели стабильнее:

- Держите поля Appearance в карточках персонажей конкретными и актуальными.
- Не выключайте **Attach Card Appearance**, если только выбранный планировщик сам не повторяет все нужные детали внешности.
- Держите **Send Avatar References** включенным, когда провайдер принимает образцы, а аватары соответствуют задуманному облику.
- Лучше держать в кадре немного персонажей и следить, чтобы они были хорошо видны. Агент Storyboard берет образцы только для распознанных видимых персонажей и персоны, а не для всех персонажей чата.

Переключатель **Use NovelAI character prompts** влияет только на запросы через поддерживаемые официальные подключения NovelAI V4/V4.5. Остальные провайдеры получают промпт по общему пути, даже когда переключатель включен.

## Стоимость и производительность

Каждый ключевой кадр – это отдельное задание на изображение. Анимированная раскадровка добавляет по одному заданию на видео для каждого удачного кадра. Поэтому анимированная раскадровка из трех кадров дает три запроса на изображения и три запроса на видео.

Проверяя нового провайдера или локальный процесс, начните с неподвижных картинок и одного ключевого кадра. Увеличивайте число кадров, длительность клипов и частоту автоматических запусков только после того, как базовый путь заработает надежно.

## Игры, начатые в старой системе раскадровки

Сейчас Storyboard – это агент, который скачивается отдельно. При этом в старых игровых чатах могут храниться явные настройки из прежнего встроенного интерфейса раскадровки. При установке пакета Marinara сохраняет эти значения как переопределения для чата и не выбрасывает рабочие настройки игры.

Поэтому старая игра может вести себя не так, как задают текущие значения агента по умолчанию. Перейдите в **Chat Settings > Agents > Storyboards** и нажмите кнопку сброса у каждого поля, которое должно снова наследовать значение агента Storyboard.

Старые настройки – это данные для переноса, а не вторая реализация раскадровки. Чтобы генерация работала сейчас, пакет Storyboard должен быть установлен и включен для этой игры.

## Устранение неполадок

### Агента Storyboard нет в панели Chat Settings

- Установите агента **Storyboard** в разделе **Agents > Download Agents**.
- Работайте в чате Roleplay или Game Mode: режим Conversation не поддерживается.
- Проверьте, что версия пакета совместима с установленной версией движка.

### Кнопка Create storyboard есть, но генерация не удается

- Включите для чата переключатели **Enable Agents** и **Enable Storyboards**.
- Выберите рабочее подключение для генерации изображений: в карточке Storyboard в режиме Roleplay, в настройках игры или в общих настройках агента.
- Дождитесь конца ответа ИИ или хода GM и попробуйте снова.

### В Roleplay не появился автоматический эпизод

- Выберите **Still images** или **Animations**, а не **Manual only**.
- Дождитесь нового завершенного ответа ИИ. Открытие чата старые сообщения не подтягивает.
- Проверьте поле **Messages per episode**. После прошлой удачной раскадровки должно накопиться достаточно новых сообщений пользователя и ответов ИИ.
- Неудачный запуск точку отсчета не сдвигает, поэтому поищите в журнале сервера исходную ошибку провайдера или разбора ответа.

### Картинки появляются, а видео нет

- В Roleplay выберите **Animations**. В Game Mode включите переключатель **Automatic Storyboard Animations**.
- Выберите подключение Video Generation.
- Проверьте, что это подключение принимает картинку на вход и делает из нее видео.
- Загляните в панель **Gallery**, на вкладку **Videos**. Клип может появиться позже своей картинки.
- Если после сбоя модели ИИ планирование ушло в запасной путь, Marinara может сохранить запасные картинки и пропустить видео для этого запуска.

### Раскадровка неполная или зависла

Скорее всего, одно или несколько заданий у провайдера не выполнились, вышли за тайм-аут либо уперлись в ограничение частоты запросов или в фильтр содержимого. Тайм-аут – это время, которое сервер ждет медленную задачу. Если провайдер работает, но отвечает медленно, увеличьте `IMAGE_GEN_TIMEOUT_MS` или `VIDEO_GEN_TIMEOUT_MS` в файле `.env`, а затем перезапустите Marinara: эти значения читаются при старте.

Включите режим отладки и поищите в журнале сервера строку `storyboard`: так видно работу планировщика, собранный промпт картинки, выбор образцов и промпт видео. В отладочном журнале может быть личный текст чата и промпты, поэтому перед отправкой кому-либо его нужно почистить.
