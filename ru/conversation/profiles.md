# Профили в режиме Conversation (отображаемое имя, About Me, поведение)

У каждого персонажа и каждой персоны есть небольшой профиль, как в приложении для переписки, для режима Conversation: отображаемое имя, биография "about me" и указание о поведении. Эти поля никогда не используются в режимах Roleplay и Game Mode.

Это не профиль настроек (сохраненный набор параметров чата, см. [Профили настроек](../chats/settings-profiles.md)). Режим вам еще незнаком? Сначала прочитайте [Режим Conversation: начало работы](getting-started.md). Персона – это карточка персонажа, которая представляет вас.

## Где находятся эти поля

Поля находятся на вкладке **Convo**.

1. Откройте персонажа в **Character Editor** (редактор персонажа) или персону в **Persona Editor** (редактор персоны). Для этого откройте панель **Characters** на боковой панели или панель **Personas** по значку человека на верхней панели правой боковой панели, затем нажмите на карточку (см. [Создание и редактирование персонажей](../characters/creating-and-editing-characters.md) и [Персоны: создание и редактирование](../characters/personas.md)).
2. Нажмите на вкладку **Convo**.

На вкладке есть **Convo Display Name**, **About Me** и **Convo Behavior**. У персонажа там также есть **Weekly schedule** (с **Edit schedule** или **Create schedule**, см. [расписания](schedules.md)) и **Image generation instructions** – необязательные указания для селфи этого персонажа (см. [Селфи](selfies.md)).

## Отображаемое имя

**Convo Display Name** – это имя, которое показывается в чатах Conversation. Оставьте поле пустым, чтобы использовать имя с карточки. Уже отправленные сообщения обновляются сразу.

У персонажей также есть **Declare this name on the card in the prompt**. Когда флажок включен, Marinara добавляет к тексту карточки в промпте строку вроде "Conversation display name: X" (текст, который Marinara отправляет модели), чтобы модель знала, какая карточка под каким именем. Сначала нужно задать отображаемое имя.

## Как написать About Me

**About Me** – это короткая биография: строка или две, эмодзи, шутка или ничего. Marinara добавляет в промпт **About Me** каждого присутствующего персонажа и каждой персоны на каждом ходу, чтобы модель знала, как каждый себя подает. Вам для этого ничего делать не нужно.

Чтобы заполнить поле:

- Напишите текст сами. Кнопка эмодзи на панели инструментов вставляет эмодзи. **Revert** (отменить) возвращает текст, который был до текущей правки.
- У сохраненного персонажа нажмите кнопку с волшебной палочкой (**Generate About Me from this card**).
- Попросите **Professor Mari** на главном экране, например `Write Luna's About Me as a cryptic one-line bio.` Она читает сохраненный профиль, пишет биографию голосом этого человека и сохраняет ее. Вы можете оставить или откатить ее изменение в обычной проверке.

Если не получилось: кнопки с волшебной палочкой нет у карточки, которая еще не сохранена. Сначала сохраните карточку.

## Convo Behavior

**Convo Behavior** – это указание о том, как персонаж или персона ведет себя в режиме Conversation, например: отвечать коротко и строчными буквами, писать как живой человек. Инструкции post-history – это текст промпта, который стоит после недавней истории чата. Если вы не пишете свои промпты, оставьте вариант по умолчанию. Параметр **Insertion** (вставка) задает, куда в промпте попадает указание:

| Вариант | Куда попадает указание |
| --- | --- |
| **Constant — after the card** (по умолчанию) | Всегда, сразу после текста карточки. |
| **Constant — before the card** | Всегда, прямо перед текстом карточки. |
| **Append to post-history** | В конец инструкций post-history. |
| **Prepend to post-history** | В начало инструкций post-history. |
| **Replace post-history** | Вместо инструкций post-history. |
| **Only where {{convo_behavior}} is placed** | Только там, где вы поставили макрос в своем промпте. |

## About Me для одного чата

**About Me** на карточке используется везде по умолчанию. Для одного чата можно задать другую биографию.

1. В чате Conversation нажмите на аватар или имя персонажа или персоны. Рядом откроется карточка профиля (на телефоне она выезжает снизу).
2. Прочитайте карточку. На ней видны аватар, имя и текущее **About Me**. Значок показывает **Default** или **Chat-specific**. У персонажей также виден статус **Online**, **Away**, **Busy** или **Offline**.
3. Нажмите **Edit**.
4. Напишите биографию для этого чата. Доступен выбор эмодзи со вкладкой **Custom emojis**.
5. Нажмите **Save**. Вы увидите сообщение "Chat-specific about me saved".

**Cancel** закрывает режим правки без сохранения. **Revert** отменяет несохраненные изменения. **Clear** убирает существующее переопределение и возвращает значение с карточки. Сохранение пустой биографии тоже убирает его.

## Пусть персонаж меняет свое About Me сам

Это дополнительная возможность. Инструмент `update_about_me` позволяет персонажу править свою биографию во время чата. По умолчанию он выключен. Чтобы использовать его, откройте **Chat Settings → Function Calling**, включите **Enable Tool Use**, затем добавьте инструмент `update_about_me`.

Персонаж выбирает один из двух вариантов:

- Public меняет настоящую биографию, которая видна во всех чатах. Сначала вы ее одобряете.
- Chat меняет биографию, которая видна только в текущем чате.

## Макросы для своих промптов

Чтобы профили дошли до модели, макросы не нужны. Используйте их, только чтобы поставить значение в точное место своего промпта. Вне режима Conversation каждый из них пуст. См. [Макросы промптов](../prompts/macros.md).

| Макрос | Значение |
| --- | --- |
| `{{convo_display}}` | Отображаемое имя отвечающего персонажа. |
| `{{char_about}}` | Действующее **About Me** персонажа. |
| `{{persona_about}}` | Действующее **About Me** персоны. |
| `{{convo_behavior}}` | **Convo Behavior** персонажа. |
