# Селфи

В этом руководстве вы узнаете, как работают селфи в режиме Conversation. Селфи – это изображение, которое персонаж генерирует сам и отправляет в чат, как фотографию в мессенджере. Здесь описано, как включить селфи, как их настроить и как попросить снимок вручную.

## Что такое селфи

Селфи – это возможность режима Conversation. Персонаж может отправить сгенерированное изображение самого себя прямо во время обычного чата. Это не то же самое, что картинки сцен в режимах Roleplay и Game Mode. Селфи придуманы именно для той атмосферы мессенджера, которую дает режим Conversation.

Селфи работают через генерацию изображений. Каждое отправленное персонажем селфи расходует один запрос генерации изображения у выбранного подключения. Поэтому селфи выключены, пока вы их не настроите.

Селфи добавляет дополнительный пакет **Illustrator**. Установите пакет Illustrator в разделе **Agents → Download Agents** (скачать агентов), прежде чем переходить к настройке.

## Как включить селфи

Настройки селфи находятся в блоке **Illustrator Settings** (настройки Illustrator) в разделе **Agents** чата режима Conversation. **Commands** (команды) – это скрытые действия, которые персонаж может выполнить сам: например, отправить селфи или включить песню. Элементы управления командами появляются в разделе **Agents**, когда установлен пакет, который такие команды добавляет.

Чтобы включить селфи:

1. Откройте чат в режиме Conversation.
2. Откройте панель **Chat Settings** (настройки чата, значок с ползунками).
3. Найдите раздел **Agents**.
4. Включите в нем главный переключатель **Commands**. Пока он выключен, персонажи не могут выполнять скрытые действия.
5. Найдите блок **Illustrator Settings**.
6. Включите переключатель **Generated Selfies** (генерация селфи).

После включения **Generated Selfies** под переключателем появляются настройки селфи. Там будут поля для подключения, модели промпта, стиля и референсных изображений. Кнопки **Resolution** (разрешение) появляются только после выбора значения в поле **Selfie Connection**.

## Настройки селфи

Когда селфи включены, задайте их вид и выберите сервис, который их рисует. Все эти настройки собраны в блоке **Illustrator Settings** по пути **Chat Settings → Agents**. Они действуют только для текущего чата.

### Selfie Connection

Поле **Selfie Connection** (подключение для селфи) задает сервис генерации изображений, который рисует картинку. По умолчанию стоит значение **None (selfies disabled)** – сервис пока не выбран. Укажите здесь одно из настроенных подключений для изображений.

Пока в поле **Selfie Connection** ничего не выбрано, персонажи не могут отправлять селфи. Надпись "Choose a Selfie Connection to let characters generate selfie images" означает, что подключение все еще не задано.

О том, как добавить подключение для изображений, читайте в руководстве [Провайдеры генерации изображений и их настройка](../media/image-providers.md).

### Prompt Model

Поле **Prompt Model** (модель промпта) задает текстовую модель, которая пишет описание селфи. По этому описанию подключение для изображений рисует картинку. По умолчанию стоит значение **Main chat model** – та же модель, что уже работает в чате. Если описание должна писать другая модель, выберите другое текстовое подключение.

### Image Style

Поле **Image Style** (стиль изображения) задает профиль стиля для селфи. Профиль стиля – это сохраненный набор слов о художественном стиле, например "anime" или "realistic photo". По умолчанию стоит значение **Use default style from Style Profiles in Advanced settings**, то есть используется глобальный стиль по умолчанию.

Подробнее о стилях – в руководстве [Профили стиля изображений](../media/style-profiles.md).

### Send Avatar References

Переключатель **Send Avatar References** (отправлять аватар как референс) по умолчанию выключен. Когда он включен, Marinara отправляет сервису изображений аватар или спрайт персонажа как референсное изображение. Так селфи получается похожим на персонажа. Это работает, только если провайдер изображений поддерживает референсные изображения.

### Attach Card Appearance

Переключатель **Attach Card Appearance** (добавлять внешность из карточки) по умолчанию выключен. Когда он включен, Marinara добавляет в описание селфи текст о внешности из карточки персонажа. Так модель получает больше подробностей о том, как выглядит персонаж.

### Resolution

Поле **Resolution** задает размер изображения селфи. Кнопки **Resolution** появляются только после выбора значения в поле **Selfie Connection**. Нажмите одну из кнопок с готовым размером. По умолчанию это **896x1152** – вытянутый вертикальный формат, который подходит большинству селфи.

Доступные размеры:

| Разрешение | Формат                     |
| ---------- | -------------------------- |
| 512x512    | Квадрат                    |
| 512x768    | Вертикальный               |
| 768x768    | Квадрат                    |
| 768x1024   | Вертикальный               |
| 896x1152   | Вертикальный (по умолчанию) |
| 1024x1024  | Квадрат                    |

## Как персонаж отправляет селфи

После настройки персонаж сам решает отправить селфи во время чата. Никакую команду вводить не нужно. Персонаж выбирает момент, а Marinara генерирует картинку и публикует ее в чате.

Ответ модели использует `[selfie]`, при желании с контекстом:

```text
Here is a picture from my walk!
[selfie: context="standing beside the river at sunset"]
```

Также работают `[selfie: "standing beside the river"]` и `[selfie: standing beside the river]`. Регистр не важен, поэтому `[SELFIE:xxxxx.]` – допустимый синтаксис. Это команда режима Conversation, а не запуск генерации изображения в Roleplay или Game Mode. Если маркер остался в сообщении как текст, возможно, выбран другой режим или выключена настройка **Commands**. Убедитесь, что Illustrator установлен, **Generated Selfies** включено и выбрано **Selfie Connection**. Если генерация начинается, но завершается ошибкой, проверьте сообщение об ошибке подключения или провайдера изображений. Изменение регистра маркера ее не исправит.

## Как попросить селфи вручную

Другой вариант: запросить селфи самостоятельно, не дожидаясь персонажа.

1. Откройте **Chat Settings** (настройки чата) и разверните раздел **Gallery** (галерея).
2. Нажмите кнопку **Selfie** (иконка фотоаппарата).
3. Если в чате несколько персонажей, выберите в списке рядом с кнопкой, кто должен сделать селфи.
4. Если в разделе **Settings** (настройки), **Generations**, **Image Generation** включен параметр **Expose media prompts before sending**, проверьте или отредактируйте итоговый собранный промпт селфи и нажмите кнопку **Generate**. Если отменить проверку, запрос на изображение не отправляется.
5. Подождите, пока на кнопке показана надпись **Generating...**.

Когда селфи готово, появляется сообщение "Selfie generated." и картинка в чате. Ручной запрос тоже идет через выбранное подключение **Selfie Connection**, поэтому он тоже расходует один запрос генерации изображения.
