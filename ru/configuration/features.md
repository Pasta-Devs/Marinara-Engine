# Переключатели функций

Некоторые варианты поведения сервера необязательны. Включайте их в **Settings > Advanced > Features** (настройки > дополнительные > функции). Все переключатели изначально выключены, поэтому сервер, где никто не открывает раздел, работает как прежде.

Изменения применяются сразу, без перезапуска сервера или обновления страницы.

<a id="overview"></a>

## Обзор

| Переключатель | Ключ настройки | По умолчанию | Переменная окружения |
| --- | --- | --- | --- |
| **Stable lorebook picks** (стабильный выбор лорбука) | `stableLorebookGroupPicks` | Выкл. | `LOREBOOK_STABLE_GROUP_WINNERS` |
| **Retry failed provider calls** (повторять неудачные вызовы провайдера) | `providerRetry` | Выкл. | `PROVIDER_RETRY_TRANSIENT_ERRORS` |
| **Lorebook activation stats** (статистика активаций лорбука) | `usageAndActivationStats` | Выкл. | нет |
| **Recover deleted chat messages** (восстанавливать удаленные сообщения чата) | `messageTrash` | Выкл. | нет |

Поиск `features` в настройках открывает этот раздел.

<a id="where-the-settings-are-stored"></a>

## Где хранятся настройки

Все переключатели сохраняются вместе в настройке приложения `features`, JSON-объекте логических значений. Записываются только отличия от значений по умолчанию. Отсутствующий ключ, пустой объект или нечитаемое значение означают исходное состояние: всё выключено.

Сервер держит копию в памяти, поэтому проверка не добавляет чтений в частых операциях вроде вызовов провайдера и сканирования лорбуков. Сохранение в Settings или любая запись строки `features` сразу обновляет копию.

API: `GET` и `PUT /api/app-settings/features`. `PUT` заменяет объект целиком и отвергает неизвестные ключи и нелогические значения.

<a id="switches"></a>

## Переключатели

<a id="stable-lorebook-picks"></a>

### Стабильный выбор лорбука

Ключ: `stableLorebookGroupPicks`. Переменная окружения: `LOREBOOK_STABLE_GROUP_WINNERS`.

Вкл.: группа включения лорбука сохраняет одного победителя в чате, пока совпадающие кандидаты не меняются. В других чатах и наборах кандидатов выбор может отличаться.

Выкл.: победитель разыгрывается заново при каждой генерации.

<a id="retry-failed-provider-calls"></a>

### Повтор неудачных вызовов провайдера

Ключ: `providerRetry`. Переменная окружения: `PROVIDER_RETRY_TRANSIENT_ERRORS`.

Вкл.: отказ или недоступность соединения либо ошибка шлюза 502/503 повторяется до двух раз с короткой случайно изменяемой паузой, только до получения любого текста. 504 и оборванное соединение никогда не повторяются. Если у подключения есть fallback, он пробуется сразу вместо повторов.

Выкл.: как и прежде, повторяются только запросы, ограниченные по частоте.

<a id="lorebook-activation-stats"></a>

### Статистика активаций лорбука

Ключ: `usageAndActivationStats`. Переменной окружения нет.

Вкл.: после успешного сохранения ответа Marinara записывает, какие записи лорбука активировались, чтобы в редакторе лорбука записи можно было сортировать и фильтровать по использованию. Фрагменты, дописанные через **Continue** (продолжить), не добавляют записей об активации.

Выкл.: ничего не записывается, а редактор лорбука скрывает статистику активаций.

<a id="recover-deleted-chat-messages"></a>

### Восстановление удаленных сообщений чата

Ключ: `messageTrash`. Переменной окружения нет.

Вкл.: удаленные сообщения чата попадают на вкладку **Trash** (корзина) в поиске по чату. Вернуть их можно там кнопкой **Restore** (восстановить) в течение 30 дней; после этого они удаляются навсегда. Сообщения Game и удаления при откате по-прежнему необратимы.

Выкл.: удаленные сообщения удаляются сразу.

<a id="precedence"></a>

## Приоритет

1. **Переменная окружения.** Если задана, она выше сохраненного переключателя как при включении, так и при выключении. Settings показывает заблокированный переключатель с именем переменной. Пустое значение считается отсутствующим.
2. **Сохраненный переключатель.** Значение из Settings > Advanced > Features.
3. **По умолчанию.** Выкл.

| Переменная | Управляет | Значения |
| --- | --- | --- |
| `LOREBOOK_STABLE_GROUP_WINNERS` | Стабильным выбором лорбука | `true`, `1`, `yes` или `on` включают. Любое другое значение выключает. |
| `PROVIDER_RETRY_TRANSIENT_ERRORS` | Повторами вызовов провайдера | `true`, `1`, `yes` или `on` включают. Любое другое значение выключает. |

Переменные читаются при каждой проверке, поэтому изменение `.env` не требует перезапуска.

<a id="for-developers"></a>

## Для разработчиков

Реестр: `packages/shared/src/schemas/feature-settings.schema.ts`, имена переключателей и значения по умолчанию. Добавьте переключатель в `FEATURE_SWITCH_NAMES`, `FEATURE_SWITCH_DEFAULTS` и `featureSettingsSchema`, подпись и справку в `settings.features.<key>` английского каталога, а затем запись в `SERVER_SWITCHES` файла `packages/client/src/components/panels/settings/FeatureSwitchesSettings.tsx`, чтобы он появился в Settings. На сервере проверяйте через `isFeatureEnabled("<key>")` из `packages/server/src/services/features/feature-settings.ts`. В клиенте используйте `useFeatureEnabled("<key>")` из `packages/client/src/hooks/use-feature-settings.ts`.
