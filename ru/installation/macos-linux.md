# Установка на macOS и Linux

Установите Marinara Engine на компьютер Mac или Linux и запустите ее скриптом запуска `start.sh`. После этого Marinara работает на вашем собственном компьютере.

## Что нужно заранее

Понадобятся два инструмента:

- **Node.js** версии 24, 25 или 26. Node.js запускает Marinara. Рекомендуемый выпуск LTS (Long Term Support, долгосрочная поддержка) – версия 24.
- **Git**. Git скачивает Marinara и получает обновления.

Устанавливать pnpm (инструмент, который устанавливает составные части приложения) не нужно. Скрипт запуска сам настроит нужную версию.

### Установка Node.js и Git на macOS

С Homebrew одна команда ставит оба инструмента:

```bash
brew install node git
```

Без Homebrew скачайте установщик Node.js с сайта [nodejs.org](https://nodejs.org). Затем установите Git вместе с инструментами командной строки Xcode:

```bash
xcode-select --install
```

### Установка Node.js и Git на Linux

Используйте менеджер пакетов своего дистрибутива. В Ubuntu и Debian штатная версия Node.js часто старее 24-й, поэтому сначала подключите выпуск NodeSource:

```bash
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo bash -
sudo apt install -y nodejs git
```

В Fedora:

```bash
sudo dnf install -y nodejs git
```

В Arch:

```bash
sudo pacman -S nodejs npm git
```

### Проверка инструментов

```bash
node -v
git --version
```

Команда `node -v` должна показать `v24` или выше. Если любая из команд отвечает "command not found", инструмент установлен неправильно.

## Установка и запуск Marinara

1. Откройте терминал – окно, в котором вводятся команды. На Mac нажмите <kbd>Cmd</kbd>+<kbd>Space</kbd>, введите Terminal и нажмите Enter. В Linux откройте свое приложение терминала.
2. Скачайте Marinara.

   ```bash
   git clone https://github.com/Pasta-Devs/Marinara-Engine.git
   ```

3. Перейдите в новую папку.

   ```bash
   cd Marinara-Engine
   ```

4. Запустите Marinara скриптом запуска – скриптом, который настраивает и запускает ее.

   ```bash
   ./start.sh
   ```

Первый запуск занимает несколько минут, потому что все скачивается и собирается. Терминал показывает ход работы, а затем `Press Ctrl+C to stop`. Marinara открывается в браузере по адресу `http://127.0.0.1:7860`. Если браузер не открылся, перейдите по этому адресу сами.

Если не получилось:

- `permission denied`: выполните `chmod +x start.sh`, затем снова `./start.sh`.
- `[ERROR] Node.js 24 LTS or newer is required`: версия Node.js слишком старая. Установите более новую версию, затем снова выполните `./start.sh`.

## Запуск и остановка Marinara

- **Повторный запуск:** выполните `./start.sh` из папки Marinara. Если Marinara уже работает, скрипт снова открывает ее в браузере.
- **Остановка:** нажмите <kbd>Ctrl</kbd>+<kbd>C</kbd> в терминале.

При каждом выполнении `./start.sh` в папке, скачанной через Git, скрипт запуска:

1. Проверяет, есть ли более новая версия, и обновляется, если находит ее.
2. Проверяет Node.js и нужную версию pnpm.
3. Устанавливает недостающие части и пересобирает приложение, если код изменился.
4. Запускает сервер и открывает браузер.

## Настройки скрипта запуска

Настройки скрипта запуска хранятся в файле `.env` в папке Marinara. Файл `.env` – это обычный текстовый файл, по одной настройке в строке. Чтобы скрипт запуска не открывал браузер, добавьте такую строку:

```bash
AUTO_OPEN_BROWSER=false
```

`PORT` задает порт – число после двоеточия в адресе (по умолчанию 7860). Скрипт запуска разрешает другим устройствам в вашей локальной сети обращаться к Marinara, но она блокирует их, пока вы не зададите вход. См. [Удаленный доступ](../REMOTE_ACCESS.md).

## Обновление Marinara

Команда `./start.sh` сначала обновляет Marinara. Чаты, персонажи и настройки остаются на месте. Если вы сами меняли код, скрипт запуска откладывает ваши изменения и возвращает их после обновления. О пропуске обновления, кнопке **Apply Update** (применить обновление) в приложении и командах для обновления вручную читайте в руководстве [Обновление приложения Marinara Engine](../UPGRADING.md#macos-and-linux).

## Ручная настройка без скрипта запуска

Большинству лучше подойдет скрипт запуска. Чтобы выполнить каждый шаг самостоятельно, нужен pnpm. В Node.js 24 есть Corepack – инструмент, который включает pnpm. В Node.js 25 его нет.

1. В Node.js 24 включите pnpm:

   ```bash
   corepack enable pnpm
   ```

   В Node.js 25 или 26 сначала установите Corepack:

   ```bash
   npm install --global corepack
   corepack enable pnpm
   ```

2. Скачайте Marinara.

   ```bash
   git clone https://github.com/Pasta-Devs/Marinara-Engine.git
   ```

3. Перейдите в ее папку.

   ```bash
   cd Marinara-Engine
   ```

4. Установите части приложения, соберите его и запустите сервер.

   ```bash
   pnpm install --force
   pnpm build
   pnpm start
   ```

5. Откройте `http://127.0.0.1:7860`.

С `pnpm start` сервер слушает только ваш собственный компьютер. Чтобы разрешить подключение другим устройствам, добавьте `HOST=0.0.0.0` в `.env` и перезапустите сервер.

## Дополнительно: инструмент удаления фона

Marinara запрашивает прозрачный фон для генерируемых спрайтов (изображений персонажей) и сама очищает однотонный фон. В качестве запасного варианта для детализированных пейзажей или теней можно установить дополнительный инструмент удаления фона на основе ИИ. Он создает venv для Python (отдельную папку для пакетов Python) и скачивает большие файлы: PyTorch (библиотеку машинного обучения) и модели U2Net (файлы, которые находят на изображении главный объект).

1. На macOS лучше всего работает Python 3.11. Сначала установите его. Подходят версии Python с 3.9 по 3.11.

   ```bash
   brew install python@3.11
   ```

2. Из папки Marinara выполните:

   ```bash
   pnpm backgroundremover:install
   ```

Чтобы скрипт запуска установил инструмент при следующем запуске, добавьте в `.env` эту строку:

```bash
BACKGROUNDREMOVER_AUTO_INSTALL=true
```

## Если что-то не работает

На некоторых системах Linux установка завершается ошибкой, в тексте которой есть `ERR_PNPM_ENAMETOOLONG` (слишком длинные пути к файлам). Удалите недособранные папки и снова запустите скрипт запуска:

```bash
rm -rf node_modules .pnpm .pnpm-store
./start.sh
```

Другие решения описаны в руководстве [Устранение неполадок в приложении Marinara Engine](../TROUBLESHOOTING.md).
