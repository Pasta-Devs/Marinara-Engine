# Установка на macOS и Linux

В этом руководстве вы узнаете, как установить и запустить Marinara Engine на macOS или Linux. Вы установите два обязательных инструмента, запустите приложение через скрипт для командной строки и научитесь обновлять его в дальнейшем. Marinara Engine (дальше – просто Marinara) работает целиком на вашем компьютере.

## Что нужно заранее

До начала работы установите два бесплатных инструмента:

- **Node.js**: программа, которая запускает Marinara. Нужна версия 24, 25 или 26 (рекомендуется версия 24, это выпуск LTS).
- **Git**: инструмент, который скачивает Marinara и получает обновления.

Устанавливать pnpm самостоятельно не нужно. pnpm – это менеджер пакетов, через который Marinara получает свои части. Скрипт запуска сам поставит нужную версию pnpm.

### Установка на macOS

Проще всего через Homebrew. Одна команда ставит сразу оба инструмента:

```bash
brew install node git
```

Без Homebrew скачайте установщик Node.js с https://nodejs.org. Затем поставьте Git вместе с инструментами командной строки Xcode:

```bash
xcode-select --install
```

### Установка на Linux

Возьмите менеджер пакетов своего дистрибутива. В Ubuntu и Debian штатная версия Node.js часто ниже 24-й. Сначала подключите более новый выпуск NodeSource:

```bash
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo bash -
```

Затем установите Node.js и Git:

```bash
sudo apt install -y nodejs git
```

В Fedora:

```bash
sudo dnf install -y nodejs git
```

В Arch:

```bash
sudo pacman -S nodejs npm git
```

### Проверка инструментов

Проверьте, что оба инструмента готовы. Выполните эту команду:

```bash
node -v
```

В ответе должно быть `v24` или число выше. Затем выполните эту команду:

```bash
git --version
```

В ответе должна быть версия вида `git version 2.40` или выше. Если любая из команд отвечает "command not found", инструмент установлен неправильно.

## Быстрый старт через скрипт запуска

Скрипт запуска `start.sh` – рекомендуемый способ работы с Marinara. Он ставит все необходимое, собирает приложение и открывает его в браузере.

1. Скачайте Marinara. Выполните эту команду:

```bash
git clone https://github.com/Pasta-Devs/Marinara-Engine.git
```

2. Перейдите в новую папку. Выполните эту команду:

```bash
cd Marinara-Engine
```

3. Сделайте скрипт запуска исполняемым. Выполните эту команду:

```bash
chmod +x start.sh
```

4. Запустите Marinara. Выполните эту команду:

```bash
./start.sh
```

Первый запуск занимает несколько минут: все скачивается и собирается. По завершении Marinara открывается в браузере по адресу http://127.0.0.1:7860. Число 7860 – порт по умолчанию, то есть та дверца, через которую приложение работает на вашем компьютере.

Если браузер не открылся сам, откройте его и перейдите по тому же адресу.

### Что скрипт запуска делает каждый раз

При каждом выполнении `./start.sh` в папке, скачанной через Git, скрипт запуска:

1. Проверяет, есть ли более новая версия, и обновляет себя, если находит ее.
2. Убеждается, что Node.js и нужная версия pnpm готовы.
3. Устанавливает недостающие части.
4. Пересобирает приложение, если код изменился.
5. Подготавливает локальное хранилище для ваших данных.
6. Запускает сервер и открывает приложение в браузере.

### Как отключить автоматическое открытие браузера

По умолчанию скрипт запуска сам открывает браузер. Чтобы этого не происходило, создайте в папке Marinara файл `.env` и добавьте в него такую строку:

```bash
AUTO_OPEN_BROWSER=false
```

Файл `.env` – это обычный текстовый файл с настройками, по одной в строке. Простой стартовый `.env` выглядит так:

```bash
PORT=7860
AUTO_OPEN_BROWSER=true
```

Переменная `PORT` задает порт адреса (по умолчанию 7860). Кроме того, скрипт запуска по умолчанию разрешает другим устройствам в вашей сети LAN обращаться к серверу. LAN – это локальная сеть, сеть вашего дома или офиса. При этом Marinara блокирует такие устройства, пока не настроен пароль или другой способ доступа. Как это сделать, показано в руководстве [Удаленный доступ: вход и список разрешенных адресов](../REMOTE_ACCESS.md).

## Установка вручную

Большинству лучше подойдет скрипт запуска, описанный выше. Если вы хотите выполнить каждый шаг сами, используйте команды ниже. Для установки вручную нужен доступный pnpm. В Node.js 24 есть Corepack, а в Node.js 25 его нет.

1. В Node.js 24 включите pnpm через Corepack:

```bash
corepack enable pnpm
```

В Node.js 25 и 26 сначала установите отдельный пакет Corepack, а затем включите pnpm:

```bash
npm install --global corepack
corepack enable pnpm
```

2. Скачайте Marinara. Выполните эту команду:

```bash
git clone https://github.com/Pasta-Devs/Marinara-Engine.git
```

3. Перейдите в папку. Выполните эту команду:

```bash
cd Marinara-Engine
```

4. Установите части приложения. Выполните эту команду:

```bash
pnpm install --force
```

5. Соберите приложение. Выполните эту команду:

```bash
pnpm build
```

6. Запустите сервер. Выполните эту команду:

```bash
pnpm start
```

Теперь откройте в браузере http://127.0.0.1:7860. С командой `pnpm start` сервер по умолчанию слушает только ваш компьютер. Все работает локально, а хранилище данных готовится при первом запуске.

### Если установка на Linux не удалась

Некоторые системы Linux не принимают очень длинные пути к файлам во время установки. Если вы видите ошибку с текстом `ERR_PNPM_ENAMETOOLONG`, удалите недособранные папки и начните заново со скрипта запуска. Выполните эту команду:

```bash
rm -rf node_modules .pnpm .pnpm-store
```

Затем выполните эту команду:

```bash
./start.sh
```

## Дополнительный инструмент удаления фона

Marinara умеет убирать фон с картинок-спрайтов персонажей. Спрайт – это картинка персонажа, которая используется в режимах Roleplay и Game Mode. Родная прозрачность и встроенная адаптивная очистка краев работают и без этого скачивания. Дополнительный инструмент удаления фона на основе ИИ нужен только как запасной вариант для спрайтов, снятых на подробном фоне, с тенями или другой неоднородной картинкой позади. Учтите: он скачивает большие файлы.

Дополнительный инструмент – это программа на Python. При установке создается venv для Python (виртуальное окружение, отдельная папка с пакетами Python). Также скачивается PyTorch, библиотека машинного обучения. И наконец, скачиваются модели U2Net – файлы, которые находят на картинке главный объект.

Чтобы установить инструмент один раз, выполните эту команду из папки Marinara:

```bash
pnpm backgroundremover:install
```

На macOS надежнее всего работает Python версии 3.11. Сначала установите его через Homebrew:

```bash
brew install python@3.11
```

Затем снова выполните команду установки:

```bash
pnpm backgroundremover:install
```

Чтобы скрипт запуска установил этот инструмент сам при следующем запуске, добавьте в файл `.env` такую строку:

```bash
BACKGROUNDREMOVER_AUTO_INSTALL=true
```

## Обновление

Когда вы запускаете Marinara командой `./start.sh` в папке, скачанной через Git, скрипт запуска проверяет наличие более новой версии. Он обновляет себя автоматически перед стартом. Чаты, персонажи и настройки сохраняются.

Команда `./start.sh --skip-update` пропускает одну проверку. Чтобы установленная версия Engine сохранялась между запусками, добавьте в `.env` строку `AUTO_UPDATE_ENABLED=false`. Проверить наличие обновлений и обновиться вручную по-прежнему можно через **Settings → Advanced → Updates** или командами Git.

Проверить обновления можно и внутри приложения. Откройте панель **Settings** (настройки), перейдите на вкладку **Advanced** и найдите раздел **Updates**. Нажмите кнопку **Check for Updates**, чтобы узнать, есть ли более новый выпуск. Кнопка **Apply Update** по умолчанию выключена. Чтобы включить ее, задайте несколько серверных параметров. Затем сохраните секрет администратора в разделе **Settings**, **Advanced**, **Admin Access**. Если вы не включаете эту кнопку, для обновления достаточно перезапустить приложение командой `./start.sh`.

Полный порядок обновления, включая создание резервной копии и переключение каналов выпуска, описан в руководстве по обновлению по ссылке ниже.

## Ключевые термины

- **pnpm**: менеджер пакетов, через который Marinara скачивает и упорядочивает свои части.
- **Corepack**: вспомогательный инструмент в составе Node.js, который включает pnpm.
- **LAN**: локальная сеть, частная сеть вашего дома или офиса.
- **.env**: обычный текстовый файл с настройками в папке Marinara, по одной настройке в строке.
- **venv**: виртуальное окружение Python, отдельная папка с пакетами Python.
- **PyTorch**: библиотека машинного обучения, которую использует дополнительный инструмент удаления фона.
- **U2Net**: файлы модели, по которым инструмент удаления фона находит на картинке главный объект.
