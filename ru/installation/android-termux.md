# Руководство по установке на Android (Termux)

В этом руководстве вы узнаете, как запустить Marinara Engine на телефоне или планшете с Android. Приложение Marinara работает внутри Termux – это бесплатное окружение Linux для Android. Настроить можно двумя способами: просто, через приложение для Android, или вручную, в терминале Termux.

## Что такое Termux и F-Droid

Termux – это бесплатное приложение, которое дает телефону небольшую систему Linux и командную строку. Приложению Marinara Engine оно необходимо, потому что Marinara – это сервер Linux, а не обычное приложение для Android.

F-Droid – это бесплатный магазин приложений для Android с открытым исходным кодом. Автоматическая настройка Marinara скачивает стабильную версию Termux из F-Droid. У Termux есть и отдельная экспериментальная версия в Google Play; если она уже установлена, Marinara распознает ее официальную подпись, но для этого руководства рекомендуется F-Droid.

Termux из F-Droid ставится по этой ссылке: [Termux в F-Droid](https://f-droid.org/en/packages/com.termux/). Не смешивайте Termux или его плагины из разных источников: их подписи должны совпадать. Подробности для каждого источника есть в [официальных инструкциях по установке Termux](https://github.com/termux/termux-app#installation).

## Установка через приложение для Android (APK)

Самый простой путь – приложение Marinara Engine для Android. APK – это установочный файл приложения для Android. Само приложение небольшое и играет роль помощника: оно настраивает Termux, а затем открывает Marinara, как только локальный сервер запустится. Всю настоящую работу по-прежнему делает Termux, поэтому Android попросит подтвердить несколько системных запросов. Для установки готового APK не нужны ключ подписи, пароль, секрет локального доступа или изменение `CSRF_TRUSTED_ORIGINS`. Приложение автоматически создает и передает закрытые учетные данные для localhost. Не добавляйте `null` в `CSRF_TRUSTED_ORIGINS`: оно намеренно считается незаданным и не требуется для обмена APK.

1. Нажмите [Скачать последнюю версию APK для Android](https://github.com/Pasta-Devs/Marinara-Engine/releases/latest/download/marinara-engine-android.apk).
2. Установите APK и откройте приложение.
3. Нажмите кнопку **Install / Start Marinara**.
4. Если Termux еще не установлен, подтвердите запросы установки от Android, чтобы приложение скачало и установило Termux из F-Droid.
5. Когда Android спросит, выдайте разрешение **Run commands in Termux environment** (запуск команд в окружении Termux).
6. Если Termux блокирует настройку, приложение копирует за вас команду `allow-external-apps`. Вставьте эту команду в Termux один раз, а затем снова нажмите кнопку **Install / Start Marinara**.
7. Дождитесь, пока Termux установит зависимости и соберет Marinara. Первая сборка занимает несколько минут.
8. Когда Termux закончит работу, вернитесь в приложение Marinara Engine. Как только локальный сервер будет готов, приложение подключится и войдет автоматически.

Если нужен значок на домашнем экране, который открывает Marinara как обычное приложение, это же приложение для Android его и дает. Оно лишь обертка вокруг сервера в Termux, поэтому сервер сначала нужно настроить. Обойти запросы установки и разрешений от Android оно не может, но настраивать какой-либо установочный секрет Marinara не просит.

## Установка вручную в Termux

Если приложением пользоваться не хочется, Marinara можно установить вручную. Откройте Termux и вставьте одну команду:

```
pkg update -y && pkg install -y git nodejs-lts && ([ -d "$HOME/Marinara-Engine/.git" ] || git clone https://github.com/Pasta-Devs/Marinara-Engine.git "$HOME/Marinara-Engine") && cd "$HOME/Marinara-Engine" && chmod +x start-termux.sh && ./start-termux.sh
```

Эта одна команда делает пять вещей:

1. Обновляет пакеты Termux.
2. Устанавливает Git и Node.js. Marinara поддерживает версии Node.js 24, 25 и 26.
3. Скачивает Marinara Engine, если приложение еще не установлено.
4. Делает скрипт запуска (файл `start-termux.sh`) исполняемым.
5. Выполняет скрипт запуска первый раз.

Скрипт запуска устанавливает зависимости приложения, собирает Marinara прямо на устройстве и поднимает локальный сервер. Он же обновит Node.js, если установленная версия слишком старая. Первый запуск идет медленно из-за сборки. Дальше все работает намного быстрее.

Когда все закончится, откройте в браузере на Android этот адрес:

```
http://127.0.0.1:7860
```

Marinara слушает порт, заданный переменной `PORT` (это сетевой порт, который использует приложение). По умолчанию – 7860. Если задан другой `PORT`, используйте его номер.

Совет: чтобы получить значок, как у обычного приложения, откройте меню браузера и выберите пункт, который добавляет Marinara на домашний экран. Название этого пункта в разных браузерах отличается.

## Повторный запуск Marinara

После первой настройки установку повторять не нужно. Откройте Termux и выполните:

```
cd Marinara-Engine
./start-termux.sh
```

Скрипт запуска проверяет обновления, а затем запускает Marinara. Чтобы запустить текущую копию без обращения к GitHub, добавьте `--skip-update`:

```
cd Marinara-Engine
./start-termux.sh --skip-update
```

При обновлении зависимостей скрипт запуска также удаляет из локального кеша pnpm пакеты, которые больше нигде не используются. Так старые релизы не накапливают на телефоне несколько гигабайт; чатов, настроек и других пользовательских данных приложения Marinara это не касается.

## Доступ с другого устройства

По умолчанию скрипт запуска делает Marinara доступным в локальной сети. То есть открыть приложение может ноутбук или другой телефон в той же сети Wi-Fi. Пошаговые указания, как найти нужный адрес, есть в разделе [Частые вопросы](../FAQ.md).

## Обновление

При каждом выполнении скрипта запуска (`./start-termux.sh`) он проверяет на GitHub, нет ли более новой версии, и обновляется перед стартом. Так что самый простой способ оставаться на свежей версии – просто запускать Marinara как обычно.

Чтобы запустить установленную копию без обновления, используйте флаг пропуска:

```
./start-termux.sh --skip-update
```

Чтобы установленная версия Engine сохранялась между запусками, добавьте `AUTO_UPDATE_ENABLED=false` в файл `.env` проекта. Команды обновления вручную и раздел **Settings → Advanced → Updates** это не отключает.

Обновления можно проверить и внутри приложения. Откройте панель **Settings** (настройки), перейдите на вкладку **Advanced** и откройте раздел **Updates**. Нажмите кнопку **Check for Updates**, чтобы узнать, вышел ли более новый релиз. Кнопка **Apply Update** в приложении по умолчанию выключена и требует настройки. Как ее включить и использовать, описано в разделе [Обновление приложения Marinara Engine](../UPGRADING.md).
