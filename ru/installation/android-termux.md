# Руководство по установке на Android (Termux)

Запустите Marinara Engine на телефоне или планшете с Android. Marinara работает внутри Termux. Termux – это бесплатное приложение, которое дает телефону небольшую систему Linux. Настроить все можно через приложение Marinara для Android (это проще всего) или вручную в Termux.

## О Termux и F-Droid

Marinara – это сервер Linux, а не обычное приложение для Android, поэтому для работы ей нужен Termux. F-Droid – это бесплатный магазин приложений с открытым исходным кодом. При настройке приложение для Android скачивает стабильную сборку Termux из F-Droid. У Termux есть и экспериментальная сборка в Google Play. Если она уже установлена, Marinara ее принимает, но это руководство рекомендует F-Droid.

Установите Termux со страницы [Termux в F-Droid](https://f-droid.org/en/packages/com.termux/). Не смешивайте Termux и его приложения-плагины из разных источников: их подписи должны совпадать. См. [официальные инструкции по установке Termux](https://github.com/termux/termux-app#installation).

## Установка через приложение для Android

Приложение Marinara Engine для Android настраивает Termux, а затем открывает Marinara, когда локальный сервер запущен. По ходу дела Android попросит подтвердить несколько системных запросов.

1. Нажмите [Скачать последнюю версию APK для Android](https://github.com/Pasta-Devs/Marinara-Engine/releases/latest/download/marinara-engine-android.apk). APK – это установочный файл приложения для Android.
2. Установите APK и откройте приложение.
3. Нажмите кнопку **Install / Start Marinara**.
4. Если Termux не установлен, подтвердите запросы установки от Android, в том числе разрешите этому приложению устанавливать приложения. Так оно сможет установить Termux из F-Droid.
5. Когда Android спросит, выдайте разрешение **Run commands in Termux environment** (запуск команд в окружении Termux).
6. Если Termux блокирует настройку, приложение копирует команду `allow-external-apps` и открывает Termux. Нажмите и удерживайте экран Termux, выберите **Paste** (вставить), нажмите Enter, затем вернитесь назад и снова нажмите **Install / Start Marinara**.
7. Дождитесь, пока Termux установит зависимости (компоненты, которые нужны приложению) и соберет Marinara. На экране Termux прокручивается текст. Первая сборка занимает несколько минут.
8. Когда Termux закончит работу, вернитесь в приложение Marinara Engine. Как только сервер будет готов, приложение само подключится и выполнит вход, и вы увидите главный экран Marinara.

Чтобы вместо этого пользоваться браузером, выберите **Open in browser** (открыть в браузере) на экране запуска приложения. Приложение запоминает выбор, и в браузере вход тоже выполняется автоматически.

Если не сработало, сначала разберитесь с запросом, который заблокировал настройку, а затем снова нажмите **Install / Start Marinara**. Если приложение не может открыть localhost, обновите APK и нажмите **Install / Start Marinara**. См. [справку по входу в localhost на Android](../TROUBLESHOOTING.md#android-localhost-opens-the-login-page-or-returns-401503).

Приложению не нужны ключ подписи, пароль или изменение `CSRF_TRUSTED_ORIGINS`. Оно само создает закрытые учетные данные для localhost. Не добавляйте `null` в `CSRF_TRUSTED_ORIGINS`.

## Установка вручную в Termux

Этот способ подойдет, если приложение вам не нужно. Откройте Termux, затем нажмите и удерживайте экран и выберите **Paste**, чтобы вставить эту команду (скопируйте ее целиком):

```bash
pkg upgrade -y && pkg install -y git nodejs-lts && \
([ -d "$HOME/Marinara-Engine/.git" ] || \
  git clone https://github.com/Pasta-Devs/Marinara-Engine.git "$HOME/Marinara-Engine") && \
cd "$HOME/Marinara-Engine" && chmod +x start-termux.sh && ./start-termux.sh
```

По порядку эта команда:

1. Обновляет все пакеты Termux. Более новая версия Node.js не может запуститься со старыми библиотеками Termux, поэтому Termux нужно обновить полностью. Если появится вопрос, сохранить ли файл конфигурации, нажмите Enter, чтобы оставить свой.
2. Устанавливает Git и Node.js. Marinara поддерживает Node.js 24, 25 и 26.
3. Скачивает Marinara, если она еще не скачана.
4. Делает скрипт запуска (`start-termux.sh`) исполняемым и запускает его.

Скрипт запуска устанавливает зависимости, собирает Marinara прямо на устройстве и поднимает локальный сервер. Если ваша версия Node.js слишком старая, он ее обновит. Первый запуск идет медленно, а на экране Termux прокручивается текст. Последующие запуски проходят быстрее.

Когда скрипт сообщит, что сервер запущен, откройте этот адрес в браузере на Android:

```text
http://127.0.0.1:7860
```

Если вы задали другой `PORT`, используйте этот номер. Чтобы получить значок, как у обычного приложения, выберите в меню браузера пункт, который добавляет страницу на домашний экран. Название пункта в разных браузерах отличается.

## Запуск и остановка Marinara

При установке через приложение откройте его и нажмите **Install / Start Marinara**, если сервер остановлен. Чтобы переключаться между приложением и браузером, выберите **Open in browser** на экране запуска, затем **Retry connection** (повторить подключение). Изнутри приложения на экран запуска можно вернуться через **Settings → General → App Behavior → Open Android launcher (app or browser)** (настройки → общие → поведение приложения → открыть экран запуска Android (приложение или браузер)).

При ручной установке откройте Termux и выполните:

```bash
cd Marinara-Engine
./start-termux.sh
```

Чтобы остановить сервер, нажмите <kbd>Ctrl</kbd>+<kbd>C</kbd> в Termux.

## Обновление Marinara

При каждом выполнении `./start-termux.sh` скрипт запуска проверяет на GitHub, нет ли более новой версии, и обновляется перед стартом. Чтобы запустить Marinara без обновления, добавьте `--skip-update`. Другие варианты и шаги обновления APK описаны в руководстве [Обновление приложения Marinara Engine](../UPGRADING.md#android-termux).

Во время обновлений скрипт запуска также удаляет неиспользуемые пакеты из своего локального кеша pnpm. Так старые выпуски не занимают несколько гигабайт места на устройстве. Ваших чатов и настроек это не касается.

## Открытие Marinara с другого устройства

Скрипт запуска позволяет другим устройствам в вашей сети Wi-Fi подключаться к Marinara, но блокирует их, пока вы не зададите вход. См. [Частые вопросы](../FAQ.md#how-do-i-access-marinara-engine-from-my-phone-or-another-device) и [Удаленный доступ](../REMOTE_ACCESS.md).

Если другое устройство не может войти после обновления, см. [Нет доступа после обновления](../REMOTE_ACCESS.md#locked-out-after-updating). В Termux эта команда удаляет вход в приложение и завершает сеансы во всех браузерах:

```bash
cd "$HOME/Marinara-Engine" && node scripts/reset-login.mjs
```
