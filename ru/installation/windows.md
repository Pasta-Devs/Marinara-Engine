# Руководство по установке на Windows

Установите Marinara Engine на компьютер с Windows с помощью установщика (меньше всего шагов) или из исходного кода. После этого Marinara работает на вашем собственном компьютере.

## Что нужно заранее

Понадобятся Windows 10 или Windows 11 (64 бита), несколько гигабайт свободного места на диске и подключение к интернету на время установки. Установщик рекомендует около 2,5 ГБ свободного места.

Также нужны две программы:

- **Node.js** версии 24, 25 или 26. Node.js запускает приложение. Рекомендуемый выпуск LTS (Long Term Support, долгосрочная поддержка) – версия 24.
- **Git**. Git скачивает код и позволяет Marinara обновляться самой.

Если вы пользуетесь установщиком, ставить их заранее не нужно: он сам получит обе программы. При установке из исходного кода их ставят вручную. Устанавливать pnpm (инструмент, который устанавливает составные части приложения) не нужно. Его настраивают установщик и `start.bat`.

## Установка с помощью установщика для Windows

1. Откройте [страницу выпусков Marinara Engine](https://github.com/Pasta-Devs/Marinara-Engine/releases).
2. Скачайте последний установщик для Windows. Его имя – `Marinara-Engine-Installer-` и номер версии.
3. Запустите установщик. Если Windows показывает "Windows protected your PC", выберите **More info** (подробнее), затем **Run anyway** (выполнить в любом случае), но только для файла со страницы выпусков.
4. Следуйте указаниям на экране. Если Node.js или Git нет, разрешите установщику их поставить.
5. Выберите папку установки или оставьте папку по умолчанию (`%LOCALAPPDATA%\Marinara-Engine`).
6. Подождите, пока установщик скачает и соберет приложение. Список хода установки показывает каждый шаг. Это занимает несколько минут.
7. Когда установщик сообщит, что установка завершена, дважды щелкните ярлык **Marinara Engine** на рабочем столе.

Откроется окно консоли (черное текстовое окно) и покажет ход запуска. Затем браузер откроет Marinara. Если этого не произошло, перейдите по адресу `http://127.0.0.1:7860`.

Установщик создает Git-копию последнего стабильного выпуска, поэтому Marinara может обновляться сама при каждом запуске.

> **Совет:** некоторые антивирусы помечают установщик как подозрительный, потому что он скачивает Node.js и Git. Запускайте установщик, только если вы скачали его со страницы выпусков по ссылке выше.

## Запуск и остановка Marinara

- **Запуск:** дважды щелкните ярлык на рабочем столе или пункт в меню "Пуск". При установке из исходного кода запустите `start.bat` в папке Marinara.
- **Остановка:** ярлык открывает окно консоли. Нажмите в нем <kbd>Ctrl</kbd>+<kbd>C</kbd>.

Если Marinara уже работает, ярлык снова открывает ее в браузере.

## Установка из исходного кода

Этот способ подойдет, если вы предпочитаете вводить команды сами или хотите тестовую версию (staging).

1. Установите [Node.js](https://nodejs.org/en/download) и [Git for Windows](https://git-scm.com/download/win).
2. Откройте новое окно Command Prompt (текстовое окно, в котором вводятся команды).
3. Проверьте обе программы. Команда `node -v` должна показать версию 24, 25 или 26.

   ```bat
   node -v
   git --version
   ```

   Если команда не найдена, закройте и снова откройте Command Prompt или переустановите недостающую программу.

4. Скачайте код.

   ```bat
   git clone https://github.com/Pasta-Devs/Marinara-Engine.git
   ```

5. Перейдите в его папку.

   ```bat
   cd Marinara-Engine
   ```

6. Необязательно: перейдите на версию staging до первого запуска. Чтобы остаться на стабильной версии, пропустите этот шаг. Перед работой со staging сделайте резервную копию данных.

   ```bat
   git checkout staging
   ```

   После этого скрипт запуска при обновлениях оставляет вас на staging.

7. Запустите скрипт запуска – скрипт, который настраивает и запускает Marinara.

   ```bat
   start.bat
   ```

Первый запуск занимает несколько минут, потому что все устанавливается и собирается. Окно консоли показывает ход работы. Когда все будет готово, браузер откроет Marinara. Чтобы запустить ее позже, снова выполните `start.bat` из той же папки.

Если не получилось: сообщение `[ERROR] Node.js 24 LTS or newer is required` означает, что версия Node.js слишком старая. Установите Node.js 24 или новее с сайта [nodejs.org](https://nodejs.org), затем снова запустите `start.bat`.

### Ручная настройка без скрипта запуска

Для этого способа нужна команда `pnpm`. Выполняйте команды внутри папки `Marinara-Engine`.

1. Один раз установите pnpm.

   ```bat
   npm install -g pnpm
   ```

2. Установите зависимости (части, которые нужны приложению), соберите приложение и запустите сервер.

   ```bat
   pnpm install --force
   pnpm build
   pnpm start
   ```

3. Откройте `http://127.0.0.1:7860`.

С `pnpm start` к Marinara можно обратиться только с этого компьютера. Чтобы разрешить подключение другим устройствам, создайте в папке `Marinara-Engine` файл с именем `.env`, добавьте в него эту строку и перезапустите сервер.

```env
HOST=0.0.0.0
```

## Открытие Marinara с другого устройства

Установщик, его ярлык и `start.bat` позволяют другим устройствам в вашей сети обращаться к Marinara, но она блокирует их, пока вы не зададите вход. Порядок действий описан в руководстве [Удаленный доступ](../REMOTE_ACCESS.md) и в [Частых вопросах](../FAQ.md#how-do-i-access-marinara-engine-from-my-phone-or-another-device).

## Обновление Marinara

При каждом запуске Marinara ярлыком или через `start.bat` скрипт запуска проверяет обновления, устанавливает их, пересобирает приложение и запускает его. Чаты, персонажи и настройки остаются на месте. Если вы сами меняли код, скрипт запуска откладывает ваши изменения и возвращает их после обновления. Если это не удается, он оставляет текущую версию и выводит сообщение. О кнопке **Apply Update** (применить обновление) в приложении, пропуске обновления и командах для обновления вручную читайте в руководстве [Обновление приложения Marinara Engine](../UPGRADING.md#windows).

## Где лежат данные и как удалить приложение

Данные лежат в папке `packages\server\data` внутри папки Marinara. Чтобы удалить приложение, откройте пункт **Uninstall Marinara Engine** (удалить Marinara Engine) в меню "Пуск". Программа удаления спросит, удалить ли и ваши данные. Выберите **No** (нет), чтобы сохранить их для повторной установки. См. [Резервное копирование и восстановление Marinara](../data/backup-and-restore.md).

## Дополнительно: удаление фона у спрайтов средствами ИИ

Marinara запрашивает прозрачный фон для генерируемых спрайтов и сама очищает однотонный фон. В качестве запасного варианта для детализированных пейзажей можно установить дополнительный инструмент `backgroundremover`. Он скачивает большие файлы машинного обучения, поэтому по умолчанию выключен.

1. Установите Python 3.11 с сайта [python.org](https://www.python.org/downloads/windows/). Подходят версии Python с 3.9 по 3.11.
2. Выполните эту команду из папки `Marinara-Engine`.

   ```bat
   pnpm backgroundremover:install
   ```

Команда создает отдельную папку Python (venv) внутри папки с данными. Marinara использует ее автоматически.

Чтобы `start.bat` установил инструмент при следующем запуске, добавьте эту строку в файл `.env`:

```env
BACKGROUNDREMOVER_AUTO_INSTALL=true
```

## Если что-то не работает

Проверьте, что версия Node.js – 24, 25 или 26 и что Git установлен. Другие решения описаны в руководстве [Устранение неполадок в приложении Marinara Engine](../TROUBLESHOOTING.md).
