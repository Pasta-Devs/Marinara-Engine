# Зеркалирование сообщений в Discord

Это руководство объясняет, как работает зеркалирование сообщений в Discord в приложении Marinara Engine. Зеркало копирует сообщения чата в канал Discord – в одну сторону, прямо по ходу переписки. Оно работает в режимах Conversation, Roleplay и Game Mode.

## Что делает зеркало

Зеркалирование сообщений в Discord – это односторонняя передача. Marinara отправляет сообщения в канал Discord. Обратно, из Discord в Marinara, сообщения не приходят. Это не двусторонний бот для Discord.

Зеркало работает через вебхук Discord. Вебхук – это специальный адрес URL, по которому одно приложение может публиковать сообщения в канале Discord.

Зеркало настраивается отдельно для каждого чата. У каждого чата свой адрес вебхука. Чтобы включить зеркало в одном чате, достаточно вставить туда адрес. В остальных чатах зеркало остается выключенным, пока вы не вставите адрес в каждом из них.

## Создание адреса вебхука Discord

Вебхук создается в Discord, а не в приложении Marinara Engine. Для этого нужны права на управление тем каналом Discord, который вы хотите использовать.

1. Откройте свой сервер Discord и выберите канал, где должны появляться сообщения.
2. Откройте настройки этого канала, затем раздел **Integrations** (интеграции), затем **Webhooks** (вебхуки).
3. Создайте новый вебхук и скопируйте его адрес.

Адрес вебхука Discord выглядит так:

```
https://discord.com/api/webhooks/123456789012345678/AbCdEf-example-token
```

Никому не показывайте этот адрес. Публиковать сообщения в вашем канале Discord может любой, у кого он есть.

## Включение зеркала

Настройка вебхука находится в настройках каждого чата, в разделе **Connected Chats** (связанные чаты). Поле ввода подписано **Discord Mirror** (зеркалирование в Discord), а его подсказка в поле читается `https://discord.com/api/webhooks/...`.

1. Откройте чат, который нужно зеркалировать.
2. Откройте панель **Chat Settings** (настройки чата).
3. Найдите раздел **Connected Chats**.
4. Вставьте адрес вебхука в поле ввода в нижней части этого раздела.

Теперь зеркало для этого чата включено. Чтобы выключить его, очистите поле ввода.

Если адрес не подходит под формат вебхука Discord, под полем появляется красная надпись "Invalid webhook URL format". Исправьте адрес, и настройка сохранится. При сохранении Marinara проверяет адрес еще раз, уже на сервере.

Адрес вебхука остается в этой установке Marinara. Экспорт чатов, экспортированные профили настроек и файлы **Export Profile** (экспортировать профиль) его не содержат, и импорт любого из них никогда не включает зеркало. Чтобы зеркалировать чат, перенесенный в другую установку, вставьте адрес там заново. Профиль настроек, сохраненный в этой установке, по-прежнему задает зеркало, когда вы его применяете.

## Что отправляется

Marinara зеркалирует ваши сообщения и ответы ИИ по мере их генерации.

- Имя отправителя: ваши сообщения идут под именем активной персоны, а сообщения ИИ – под именем персонажа.
- В режиме Game Mode повествование отправляется под именем "Narrator". Ходы участников отряда и персонажей NPC (неигровых персонажей) идут под именем "Party". Если в игре включен вариант **Character GM**, ответы Game Master (ведущего игры) идут под именем этого персонажа.
- Картинки не отправляются. Discord показывает только имя отправителя и текст.
- Длинные сообщения: Discord ограничивает каждое сообщение 2000 символами. Сообщение длиннее 1997 символов сокращается, а его копия в Discord заканчивается на "...".
- Упоминания вида @everyone или @here внутри текста никого не уведомляют в вашем канале Discord.

## Что не отправляется

- Ответы, сгенерированные заново, и свайпы (альтернативные варианты ответа) повторно не зеркалируются. В Discord уходит только первый ответ на каждый ход.
- Сообщения, написанные за вас, не зеркалируются. Impersonate – это функция, при которой ИИ пишет сообщение вместо вас.
- Если отправка в Discord не удалась, Marinara не показывает ошибку и не повторяет попытку. Сбой фиксируется только в журнале сервера.

## Ограничение частоты отправки

Discord ограничивает частоту публикаций для приложений. Marinara отправляет не более одного сообщения примерно раз в 1,2 секунды на каждый вебхук – это около 50 сообщений в минуту. Остальные сообщения ждут в очереди и уходят по порядку. Если Discord просит Marinara сбавить темп, приложение выжидает паузу и затем продолжает отправку.
