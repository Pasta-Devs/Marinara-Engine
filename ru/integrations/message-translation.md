# Перевод сообщений

Marinara Engine умеет переводить сообщения чата с одного языка на другой. В этом руководстве вы узнаете о четырех провайдерах перевода, о переключателях автоматического перевода, о кнопке перевода у отдельного сообщения и об ограничениях каждого провайдера.

Перевод настраивается отдельно для каждого чата. У каждого чата свой провайдер, свои языки и свои ключи. Чтобы начинать новые чаты с теми же настройками, сохраните их как [настройки перевода по умолчанию](#translator-defaults-for-new-chats).

## Где находятся настройки перевода

1. Откройте чат в любом режиме (Conversation, Roleplay или Game).
2. Откройте панель **Chat Settings** (настройки чата) для этого чата.
3. Найдите раздел **Translation** (перевод).

Все описанные ниже настройки провайдера и переключатели находятся в разделе **Translation**.

## Выбор провайдера

В раскрывающемся списке **Provider** (провайдер) четыре варианта:

| Провайдер | Что нужно | Примечания |
|---|---|---|
| **Google Translate** | Ничего | Вариант по умолчанию. Бесплатно, ключ не нужен. Не больше 5000 символов на запрос. |
| **DeepL API** | Ключ API DeepL | Качество выше. Подходят и бесплатные, и платные ключи. |
| **DeepLX (self-hosted)** | Адрес сервера DeepLX | Для сервера DeepLX, который вы поднимаете сами. |
| **AI (via connection)** | Подключение к ИИ | Переводит силами одного из подключенных провайдеров ИИ. |

**Google Translate** выбран по умолчанию и не требует настройки. Другой провайдер стоит выбирать только ради возможностей, описанных ниже.

### Поля **Model Language** и **My Language**

Языки задают два поля. В обоих по умолчанию стоит `en` (английский).

- **Model Language** (язык модели): ваши собственные сообщения переводятся на этот язык, прежде чем их прочитает ИИ. Его используют **Translate My Messages** (переводить мои сообщения) и **Translate draft** (перевести черновик).
- **My Language** (мой язык): ответы ИИ переводятся на этот язык. Его используют **Auto-Translate Responses** (автоматический перевод ответов) и кнопка **Translate** (перевести) у каждого сообщения.

Формат зависит от провайдера:

- Для **Google Translate**, **DeepL API** и **DeepLX (self-hosted)** введите короткий код языка. Примеры: `en`, `ja`, `es`, `de`, `fr`, `zh`, `ko`.
- Для **AI (via connection)** введите название языка. Примеры: `English`, `Japanese`, `Spanish`.

### Настройка DeepL API

Если выбран вариант **DeepL API**, появляется поле **DeepL API Key** (ключ API DeepL). Вставьте сюда ключ от аккаунта DeepL. Ключи DeepL выглядят так:

```
xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx:fx
```

Ключ, который заканчивается на `:fx`, – это ключ бесплатного тарифа. Marinara отправляет его в бесплатную службу DeepL. Любой другой ключ считается платным.

### Настройка DeepLX

DeepLX – это бесплатный сервер перевода, который вы поднимаете у себя сами. Если выбран вариант **DeepLX (self-hosted)**, появляется поле **DeepLX URL** (адрес сервера DeepLX). Укажите в нем адрес сервера DeepLX, например:

```
http://localhost:1188
```

Если сервер DeepLX работает на этом же компьютере или в локальной сети, его адрес – локальный. Из соображений безопасности Marinara по умолчанию блокирует запросы к локальным адресам. Чтобы их разрешить, добавьте эту строку в файл `.env` и сохраните файл:

```
DEEPLX_LOCAL_URLS_ENABLED=true
```

Файл `.env` – это файл настроек сервера. Где его найти, объясняет [Настройки сервера: справочник](../CONFIGURATION.md). Перезапускать сервер не нужно: изменение подхватывается за несколько секунд.

Серверу DeepLX с публичным адресом в интернете эта настройка не нужна. По умолчанию блокируются только локальные адреса и адреса частных сетей.

### Настройка перевода через ИИ

Если выбран вариант **AI (via connection)**, Marinara переводит текст силами одного из подключенных провайдеров ИИ. Появляются три дополнительных поля.

В раскрывающемся списке **Connection** (подключение) выбирается подключение, которое будет переводить. Это поле обязательно. Если оставить его пустым, перевод завершится ошибкой с сообщением "Connection ID is required for AI translation". Подключение – это сохраненные настройки доступа к провайдеру ИИ. Как создать подключение, описано в руководстве по подключениям ниже.

Поля **Outgoing Message Prompt** (промпт для исходящих сообщений) и **Incoming Response Prompt** (промпт для входящих ответов) содержат промпты – указания, которые Marinara отправляет ИИ, когда он переводит ваши сообщения и ответы ИИ. В обоих уже стоит встроенный текст по умолчанию, и каждый можно изменить для этого чата. `{{targetLanguage}}` в промпте превращается в **Model Language** или **My Language**. После изменения промпта появляется кнопка **Restore** (восстановить), которая возвращает встроенный текст. Промпт по умолчанию:

```
You are a translator. Translate the given text accurately into {{targetLanguage}}, preserving formatting, markdown, and any special characters like *asterisks* for actions. Output ONLY the translated text, nothing else -- no explanations, no extra commentary.
```

## Переключатели автоматического перевода

Под настройками провайдера расположены четыре переключателя. Все четыре по умолчанию выключены.

Переключатель **Auto-Translate Responses** переводит каждый ответ ИИ сразу после генерации. В режиме Game Mode Marinara сначала убирает из повествования теги, предназначенные только для Game Master (ведущего игры), и лишь затем переводит текст.

Переключатель **Translate My Messages** переводит ваше сообщение на **Model Language** прямо перед отправкой ИИ. Перевод заменяет набранный текст. Если перевод не удался, Marinara отправляет исходный текст и показывает сообщение об ошибке.

Переключатель **Show Draft Translate Button** (показывать кнопку перевода черновика) добавляет кнопку **Translate draft** рядом с кнопкой **Send**. Так можно перевести сообщение и проверить или поправить результат до отправки. Это ручная замена переключателя **Translate My Messages**, который переводит текст в момент отправки, не давая ничего проверить.

Переключатель **Show Only Translation** (показывать только перевод) показывает перевод переведенного сообщения вместо оригинала, а не оригинал и перевод вместе.

В режиме **Conversation** всегда можно перевести неотправленный черновик через кнопку со смайликом у поля ввода → **Tools → Translate draft** (инструменты → перевести черновик), на компьютере или телефоне. Включать **Show Draft Translate Button** или автоматический перевод не требуется. Действие использует настройки перевода исходящих сообщений этого чата и заменяет черновик для проверки; сообщение не отправляется. При ошибке перевода черновик остается неизменным.

## Настройки перевода по умолчанию для новых чатов

Под переключателями **Save translator defaults** (сохранить настройки перевода по умолчанию) сохраняет настройки перевода этого чата для новых чатов во всех режимах. Настройки из мастера настройки и из профиля настроек имеют приоритет. Существующие чаты сохраняют свои настройки. **Forget saved defaults** (забыть сохраненные настройки по умолчанию) удаляет их. [Noodle](../noodle/settings.md#translation) использует те же настройки по умолчанию.

Ключ API DeepL и адрес DeepLX остаются в этой установке Marinara. Экспорт чатов, экспортированные профили настроек и файлы **Export Profile** (экспорт профиля) их не включают, а импорт любого из них никогда их не задает. После переноса чата в другую установку введите их заново.

## Кнопка **Translate** у каждого сообщения

У каждого сообщения в чате – и у вашего, и у ответа ИИ – есть кнопка **Translate** в панели действий, которая появляется при наведении. Кнопка отмечена значком с языками. Она работает сама по себе, и переключатели выше для нее не нужны.

1. Наведите курсор на сообщение, чтобы показалась панель действий.
2. Нажмите кнопку **Translate**.
3. Перевод появляется под сообщением или, при включенном **Show Only Translation**, вместо него.
4. Нажмите ту же кнопку снова, чтобы скрыть перевод. Всплывающая подсказка теперь читается **Hide translation**.

Такой перевод сохраняется вместе с сообщением. Он остается после обновления страницы и не пропадает, если переключиться на другой чат и вернуться назад.

Кнопка у сообщения использует тот же провайдер и **My Language**, что заданы в разделе **Translation**.

## Ограничения провайдеров

Учитывайте эти ограничения при выборе провайдера.

- **Google Translate** отклоняет текст длиннее 5000 символов. Появляется ошибка "Text too long for Google Translate (max 5000 characters). Use DeepL or AI provider for longer texts." Для более длинного текста переключитесь на DeepL или на ИИ.
- **DeepL API**, **DeepLX (self-hosted)** и **AI (via connection)** принимают текст подлиннее – до серверного предела 50000 символов на запрос.
- **Google Translate**, **DeepL API** и **DeepLX (self-hosted)** прерывают работу и показывают ошибку, если перевод занимает больше 15 секунд.
- **AI (via connection)** работает по правилам выбранного подключения: со своей моделью и своим тайм-аутом (сколько сервер ждет медленную задачу), а не по пределу в 15 секунд.
- **DeepLX (self-hosted)** с локальным адресом заблокирован, пока не задана строка `DEEPLX_LOCAL_URLS_ENABLED=true`, как описано выше.
