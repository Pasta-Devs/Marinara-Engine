# Подключения по подписке Claude, ChatGPT и Grok

Три сервиса позволяют общаться в чате по тарифу, за который вы уже платите, без ключа API: **Claude (Subscription)**, **OpenAI (ChatGPT)** и **Grok CLI (Subscription)**. Вы устанавливаете небольшую программу для командной строки (CLI) и один раз входите в аккаунт. Затем Marinara Engine повторно использует этот вход. В Marinara ничего вставлять не нужно.

Какой тариф нужен:

- **Claude (Subscription)**: Anthropic Pro или Max либо другой тариф, который принимает Claude Code.
- **OpenAI (ChatGPT)**: аккаунт ChatGPT. Лимиты использования зависят от тарифа.
- **Grok CLI (Subscription)**: SuperGrok или X Premium+.

## Добавление аккаунта по подписке

Перед началом учтите: программа CLI должна быть установлена, а вход в нее выполнен на том компьютере, где работает сервер Marinara. Это не телефон и не браузер, в котором вы открываете Marinara. Если Marinara работает на другом компьютере или в Docker, выполните шаги 1 и 2 там. Командам `npm` нужен Node.js. Он у вас есть, если вы устанавливали Marinara из исходного кода. См. [Установка Marinara Engine](../INSTALLATION.md).

1. Откройте терминал на компьютере, где работает Marinara. Терминал – это окно, в котором вводят команды. В Windows откройте PowerShell. В macOS откройте Terminal.
2. Выполните команду установки для своего сервиса, затем его команду входа. Программа показывает собственные шаги входа, обычно это веб-страница, на которой нужно войти.

| Сервис | Установка | Вход |
| --- | --- | --- |
| Claude | `npm i -g @anthropic-ai/claude-code` | `claude login` |
| ChatGPT | `npm i -g @openai/codex` | `codex login` |
| Grok | см. ниже | `grok login` |

Для Grok приложение показывает такую команду установки. Если в вашей системе она не работает, следуйте собственным инструкциям x.ai для Grok CLI.

```bash
curl -fsSL https://x.ai/cli/install.sh | bash
```

3. В Marinara нажмите **Connections** (подключения) на верхней панели, затем **Add** (добавить).
4. В разделе **Chat** (чат) нажмите на свой сервис. У этих сервисов есть пометка **Sign in** (вход).
5. Окно сообщает **Sign in first** и называет команду. Поля для ключа нет. Нажмите **Connect** (подключиться). Marinara проверяет вход. Надпись **Connected** означает, что все работает.
6. Выберите модель в списке, затем нажмите **Done** (готово). Для Grok CLI модель можно не указывать, тогда используется модель CLI по умолчанию (см. [Grok CLI (Subscription)](#grok-cli-subscription)).

Для проверки отправьте сообщение в чате. Если пришел ответ, все работает.

Если не получилось:

- **Marinara could not use the login on this computer.** Программа CLI не установлена или вход в нее не выполнен на компьютере с Marinara. Выполните там команду входа, затем нажмите **Try again** (попробовать снова).

## Claude (Subscription)

Дальнейшие разделы описывают необязательные настройки. Для чата они не нужны.

Этот сервис использует ваш тариф Claude через Claude Code. В редакторе модели (**Edit model**) у него есть три дополнительных элемента: кеширование промптов, **Fast mode** (быстрый режим) и **Diagnose model routing** (диагностика маршрутизации модели).

### Расширенное кеширование токенов

Кеширование промптов позволяет Claude повторно использовать начало вашего промпта, поэтому повторные запросы расходуют меньше лимита. Настройка **Prompt caching → Extended token caching (1 hour)** запрашивает кеш на один час, что помогает, когда вы делаете паузы между сообщениями. Нужна версия Claude Code 2.1.242 или новее. Marinara отправляет эту настройку вместе с запросом и не меняет ваши сохраненные настройки Claude.

Когда настройка выключена, Claude использует собственное значение по умолчанию для вашего аккаунта. См. [кеширование промптов в Claude Code](https://code.claude.com/docs/en/prompt-caching).

### Быстрый режим

Настройка **Fast mode → Use Claude Code fast-mode routing** по умолчанию выключена. Оставьте ее выключенной. Она запрашивает у Claude Code более быстрый класс модели, но, как сообщает приложение, у текущих моделей такого класса больше нет, поэтому включение ничего полезного не дает и может добавить лишнюю нагрузку. Если вы попытаетесь ее включить, появится окно с заголовком **Turn on fast mode?** Нажмите **Keep it off** (оставить выключенным).

### Диагностика маршрутизации модели

Используйте **Diagnose model routing**, когда вы запросили крупную модель, например Opus, но подозреваете, что получили модель поменьше.

1. Выберите модель. Пока модель не задана, кнопка недоступна.
2. Нажмите **Diagnose model routing**. Сначала Marinara сохраняет несохраненные изменения.
3. Посмотрите на результат. Marinara отправляет настоящий промпт через ваш вход в Claude Code и сообщает, за какую модель списали оплату с вашего аккаунта.

## OpenAI (ChatGPT)

Этот сервис использует ваш аккаунт ChatGPT через Codex CLI. Marinara читает локальный файл входа Codex и обновляет сессию, когда это возможно.

Чтобы задать, как долго Codex думает перед ответом, откройте **Edit model** (изменить модель), включите **Use custom defaults for this model** (использовать свои значения по умолчанию для этой модели) и выберите уровень **Reasoning Effort** (глубина рассуждений). Изначально выбран вариант **Default** (по умолчанию), который сохраняет собственный уровень Codex для модели. Чат может выбрать свой уровень в разделе **Advanced Parameters** (дополнительные параметры). Уровень из пресета на него не влияет. Модель Codex, которая используется как запасная, следует только собственному уровню, а агенты на этой модели используют уровень модели. Доступные уровни совпадают с теми, что есть у выбранной модели.

## Grok CLI (Subscription)

Этот сервис запускает Grok CLI на компьютере с Marinara. От других сервисов он отличается двумя вещами:

- Он не поддерживает стриминг. Ответ появляется целиком, а не слово за словом.
- Его контекстное окно по умолчанию – 32 000 токенов. Токены – это небольшие кусочки текста, которые считают модели. Большие промпты могут упереться в собственный лимит хода CLI, поэтому значение по умолчанию невелико. В модели можно задать большее значение **Max Context Window** (максимальное контекстное окно).

В редакторе модели вариант **Use the Grok CLI default** (использовать модель Grok CLI по умолчанию) оставляет модель пустой, чтобы CLI выбрал ее сам. Редактор называет `grok-composer-2.5-fast` обычно самой безопасной моделью для ролевой игры, потому что Marinara запускает CLI без интерфейса, с выключенными собственными инструментами Grok, памятью, веб-поиском, планами и субагентами.

## Расход по тарифу

Аккаунты Claude (Subscription) и OpenAI (ChatGPT) могут показывать, какую часть лимитов тарифа вы израсходовали.

1. Нажмите **⋯** в строке аккаунта, выберите **Edit account** (изменить аккаунт) и откройте **Usage and balance** (расход и баланс).
2. Если чтение извне выключено, нажмите **Turn on** (включить).
3. Включите **Show the usage meter on the card** (показывать индикатор расхода на карточке) и сохраните.

Для каждого окна лимита показывается полоса с израсходованным процентом и временем сброса, например `58% · resets in 2h`. Те же полосы появляются в выборе подключения чата и в настройках **Connection** (подключение) чата, пока этот аккаунт активен. Для **Shuffle** (перемешивание) они не появляются.

- Полосы учитывают все использование вашего тарифа, а не только Marinara. Для Claude это включает Claude Code и claude.ai. Для ChatGPT – любое использование Codex, например Codex CLI. У чатов на chatgpt.com свои лимиты, и они не учитываются.
- Сервисы сообщают процент для каждого окна, без числа токенов.
- При чтении Marinara запрашивает у CLI на компьютере с Marinara те же данные, что показывает его собственная команда расхода. Модели при этом не отправляется ни одного сообщения, и тариф не расходуется. Кнопка обновления читает данные заново.
- Тариф только с одним окном показывает одну полосу.
- Claude Code помечает свои данные о расходе как экспериментальные. Если новая версия их изменит, вместо неверного числа полосы покажут ошибку и кнопку повторной попытки.

## Ограничения этих сервисов

- Им нужен платный тариф (или подходящий тариф ChatGPT) и выполненный вход в CLI на компьютере с Marinara.
- Ни один из них не дает эмбеддингов. Семантическому поиску по лорбукам и функции Memory Recall нужен отдельный аккаунт для эмбеддингов.
- Для **Send test message** (отправить тестовое сообщение) сначала нужно выбрать модель, кроме Grok CLI.
