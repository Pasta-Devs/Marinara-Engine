# Подключения по подписке Claude, ChatGPT и Grok

В этом руководстве речь о трех подключениях, которые вместо ключа API используют вход в аккаунт: **Claude (Subscription)**, **OpenAI (ChatGPT)** и **Grok CLI (Subscription)**. Схема простая: вы устанавливаете небольшую программу для командной строки, один раз входите в аккаунт, а Marinara Engine использует этот аккаунт для чата. Программа для командной строки (CLI) запускается вводом команды в окне терминала.

## Что такое подключения по подписке

Большинству подключений в приложении Marinara Engine нужен ключ API. Ключ API – это секретная строка, похожая на пароль. Ее вставляют в подключение, чтобы сервис ИИ мог списывать оплату с вашего аккаунта.

Эти три подключения работают иначе. Вместо ключа API они используют локальный вход в аккаунт. Вы входите в программу CLI на своей машине, а Marinara повторно использует этот вход. В приложение Marinara ничего вставлять не нужно.

Подключение по подписке подходит тогда, когда ваш аккаунт уже дает доступ через одну из этих программ CLI:

- **Claude (Subscription)** использует подписку Anthropic **Pro** или **Max**.
- **OpenAI (ChatGPT)** использует аккаунт ChatGPT.
- **Grok CLI (Subscription)** использует аккаунт **SuperGrok** или **X Premium+**.

## Что нужно подготовить

Требования к аккаунту зависят от провайдера.

- **Claude (Subscription)**: нужен тарифный план Claude, который поддерживает вход по подписке в Claude Code.
- **OpenAI (ChatGPT)**: подходят и бесплатный, и платные тарифные планы ChatGPT. Лимиты использования зависят от плана.
- **Grok CLI (Subscription)**: нужен аккаунт SuperGrok или X Premium+.

Для всех трех провайдеров программа CLI должна быть установлена, и вход в аккаунт выполнен на той же машине, где работает сервер Marinara. Это не браузер и не телефон, с которых вы открываете Marinara. Marinara запускает программу CLI локально, поэтому вход должен быть выполнен именно на сервере.

Если Marinara работает на вашем собственном компьютере, то этот компьютер и есть сервер. Если приложение работает на другой машине или в контейнере Docker, установите программу CLI и войдите в аккаунт там.

## Claude (Subscription)

Понадобится подписка Anthropic Pro или Max. Это тот же вход, который используют Visual Studio Code и другие инструменты Anthropic.

1. На машине, где работает Marinara, установите программу Claude Code CLI:

```
npm i -g @anthropic-ai/claude-code
```

2. Один раз войдите в аккаунт:

```
claude auth login
```

3. В приложении Marinara откройте панель **Connections** (подключения) и нажмите кнопку **New** (создать).
4. В окне **Create Connection** введите название, выберите провайдера **Claude (Subscription)** и нажмите кнопку **Create**.
5. Обратите внимание: в редакторе нет полей **API Key** и **Base URL**. Информационная панель подтверждает, что они не нужны.
6. Выберите модель Claude – например, из семейства Opus или Sonnet – в раскрывающемся списке **Model**.
7. Нажмите кнопку **Save**, затем кнопку **Send Test Message** (отправить тестовое сообщение). Короткий ответ означает, что вход работает.

Подключения Claude по подписке работают только с текстовым чатом. У этого подключения есть два дополнительных элемента, **Fast Mode** и **Diagnose Model Routing**; о них ниже.

## OpenAI (ChatGPT)

Понадобится аккаунт ChatGPT. Marinara направляет чат через вход в программу Codex CLI.

1. На машине, где работает Marinara, установите программу Codex CLI:

```
npm i -g @openai/codex
```

2. Один раз войдите в аккаунт:

```
codex login
```

3. В приложении Marinara откройте панель **Connections** и нажмите кнопку **New**.
4. В окне **Create Connection** введите название, выберите провайдера **OpenAI (ChatGPT)** и нажмите кнопку **Create**.
5. Выберите модель в раскрывающемся списке **Model**. Список берется из сессии ChatGPT, если она доступна. Если нет, используется встроенный список.
6. Нажмите кнопку **Save**, затем кнопку **Send Test Message** и проверьте, что ответ пришел.

Marinara читает локальный файл входа Codex и обновляет сессию, когда это возможно.

## Grok CLI (Subscription)

Понадобится аккаунт SuperGrok или X Premium+.

1. На машине, где работает Marinara, установите программу Grok CLI:

```
curl -fsSL https://x.ai/cli/install.sh | bash
```

2. Один раз войдите в аккаунт:

```
grok login
```

3. В приложении Marinara откройте панель **Connections** и нажмите кнопку **New**.
4. В окне **Create Connection** введите название, выберите провайдера **Grok CLI (Subscription)** и нажмите кнопку **Create**.
5. Выберите модель или оставьте поле **Model** пустым, чтобы использовать модель CLI по умолчанию. Для режима Roleplay безопаснее всего обычно `grok-composer-2.5-fast`.
6. Нажмите кнопку **Save**, затем кнопку **Send Test Message**. Это подключение проходит проверку даже без выбранной модели.

У программы Grok CLI две особенности. Стриминга здесь нет, поэтому ответ появляется целиком, а не слово за словом. Контекстное окно по умолчанию – 32000 токенов, меньше, чем у других провайдеров. Причина в том, что очень большие промпты могут упереться в собственный лимит хода программы CLI.

Чтобы загрузить модели Grok, нажмите кнопку **Fetch Models from Grok CLI** в разделе **Model**.

## Срок хранения кеша промптов Claude

В редакторе подключения Claude настройка **Prompt Caching → Extended token caching (1 hour)** запрашивает кеш на один час, чтобы можно было делать более долгие паузы между сообщениями. Нужна версия Claude Code **2.1.242 или новее**. Приложение Marinara передает настройку для этого запроса, не меняя сохраненные настройки Claude.

Если переключатель выключен, основные диалоги и запросы Agent SDK используют настройки Claude по умолчанию: сейчас это один час для использования подписки в пределах тарифа и пять минут для дополнительного использования, кредитов или оплаты через API. Собственные субагенты Claude Code используют пять минут без отдельной настройки; некоторые вспомогательные запросы, управляемые сервером, могут использовать один час. Переменные окружения CLI, переопределяющие это значение, по-прежнему имеют приоритет. См. [кеширование промптов в Claude Code](https://code.claude.com/docs/en/prompt-caching).

Логи отладки разделяют записи в кеш на пять минут и на один час по данным об использовании, которые сообщает SDK. Эквивалентная стоимость рассчитывается по стандартным множителям цены токенов API, а не по счету за подписку. Если SDK не сообщает разбивку записей по сроку хранения, оценка остается неизвестной.

## Почему здесь нет поля для ключа API

У всех трех провайдеров по подписке поля **API Key** и **Base URL** скрыты. Так и задумано. Вход хранится внутри программы CLI на машине с сервером, поэтому в приложении Marinara вводить нечего.

Если провайдер выбран по ошибке и поля для ключа не видно, вернитесь к нужному провайдеру в списке провайдеров. Для провайдеров с ключом API поле появляется снова.

## Fast Mode (только Claude)

В редакторе **Claude (Subscription)** есть раздел **Fast Mode** с одним переключателем, **Use Claude Code fast-mode routing**. По умолчанию он выключен.

Оставьте его выключенным. Само приложение говорит, что сейчас эта функция ничего не делает. Она запрашивает у Claude Code более быстрый класс модели, но у текущих моделей Claude такого класса больше нет. Включение ничего не даст и может добавить лишнюю нагрузку. Переключатель остается в интерфейсе только на случай, если Anthropic вернет эту функцию.

При попытке включить переключатель появляется окно подтверждения с заголовком **YOU DON'T WANT THIS SETTING ON!** Выберите **Keep it off**.

## Diagnose Model Routing (только Claude)

В редакторе **Claude (Subscription)** есть кнопка **Diagnose Model Routing** в области проверок. Она нужна, когда вы запросили одну модель Claude, но подозреваете, что отвечает более простая.

1. Выберите модель и нажмите кнопку **Save**. Пока модель не выбрана, кнопка недоступна.
2. Нажмите кнопку **Diagnose Model Routing**.
3. Посмотрите на результат. Marinara отправляет настоящий промпт через ваш вход в Claude Code. После этого приложение сообщает, за какую модель фактически списали оплату с аккаунта.

Так обнаруживается тихая замена на более простую модель, когда вы запрашиваете что-то крупное вроде Opus, а получаете Sonnet или Haiku.

## О чем стоит знать заранее

- Этим подключениям нужны платная подписка и выполненный вход в программу CLI на машине с сервером.
- Эмбеддинги недоступны ни в одном из трех. Для семантического поиска по лорбукам и для **Memory Recall** нужно отдельное подключение с эмбеддингами.
- **Claude (Subscription)** работает только с текстовым чатом.
- **Grok CLI (Subscription)** не поддерживает стриминг и стартует с меньшим контекстным окном.
- Кнопке **Send Test Message** сначала нужна выбранная модель – кроме Grok CLI, где проверка работает и без нее.
