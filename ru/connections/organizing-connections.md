# Порядок в подключениях

Это руководство объясняет, как держать сохраненные подключения в порядке в приложении Marinara Engine. Речь пойдет о папках подключений, поиске и сортировке, копировании и удалении, случайном наборе, панели Quick Connection Switcher, а также об экспорте и импорте подключений. Подключение – это сохраненные настройки, по которым Marinara обращается к одному сервису ИИ.

Все это делается в панели **Connections** (подключения). Откройте ее – сохраненные подключения выстроятся в список строк. В каждой строке видно название подключения, а под ним – провайдер и модель.

## Папки подключений

Папки подключений нужны, чтобы группировать подключения по смыслу. Например, все локальные модели – в одну папку, все платные провайдеры – в другую.

Чтобы создать папку, выполните эти шаги:

1. Нажмите кнопку **New Folder** (новая папка) над списком подключений.
2. Появляется новая папка с названием "unnamed".
3. Сразу переименуйте ее, чтобы отличать от остальных (см. ниже).

Чтобы переименовать папку, дважды щелкните по строке папки или дважды коснитесь ее на сенсорном экране. Другой вариант: выделите строку папки и нажмите клавишу **F2**. Введите новое название и нажмите Enter.

Чтобы положить подключение в папку, перетащите строку подключения на эту папку. Чтобы вынуть подключение обратно, перетащите его на область под папками. Во время перетаскивания видна подсказка **Drop here to move out of folder**.

На сенсорном экране нажмите и удерживайте строку, чтобы взять ее, затем перетащите. Обычный свайп по-прежнему прокручивает список.

Чтобы свернуть или развернуть папку, щелкните по ее строке один раз. Небольшое число в строке папки показывает, сколько подключений внутри.

Чтобы удалить папку, нажмите значок корзины в строке папки. Если внутри еще есть подключения, Marinara просит подтверждение в окне **Delete Folder**. Пустая папка удаляется сразу, без запроса подтверждения. Удаление папки не удаляет подключения внутри. Они просто возвращаются в область вне папок.

## Поиск и сортировка

Поле **Search connections** фильтрует список по мере ввода. Совпадения ищутся по названию подключения, провайдеру, модели, базовому адресу URL, сервису изображений или видео и модели эмбеддингов. Когда ничего не найдено, появляется надпись "No connections match your search".

Раскрывающийся список **Sort order** рядом с полем поиска меняет порядок строк. В нем пять вариантов:

| Вариант | Что делает |
|---|---|
| **Custom** | Свой порядок, заданный перетаскиванием. |
| **A-Z** | Сортировка по названию, по алфавиту (A-Z). |
| **Z-A** | Сортировка по названию, в обратном алфавитном порядке (Z-A). |
| **Newest** | Сначала самые новые подключения. |
| **Oldest** | Сначала самые старые подключения. |

Чтобы задать свой порядок, перетаскивайте строки подключений вверх или вниз. При перетаскивании сортировка сама переключается на **Custom**. Выделенную строку можно также перемещать клавишами Alt+Up или Alt+Down.

## Копирование и удаление

Наведите курсор на строку подключения, и в ней появятся кнопки действий. На сенсорном экране они видны сразу.

Чтобы скопировать подключение, нажмите кнопку **Duplicate** (создать копию) со значком копирования. Создается полная копия, включая сохраненный ключ API – секретный код, похожий на пароль. Копия сразу открывается в редакторе, и ее можно переименовать. Подтверждение не запрашивается.

Чтобы удалить одно подключение, нажмите в его строке кнопку **Delete** (удалить) со значком корзины. Marinara показывает окно **Delete Connection**, в котором написано: Delete "your connection name"? This cannot be undone. Для подтверждения нажмите кнопку **Delete**.

Чтобы удалить или экспортировать сразу несколько подключений, нажмите кнопку **Select** (выбрать) сверху панели. Включается режим выбора. Отметьте нужные подключения, а затем нажмите кнопку **Export** или **Delete** на панели действий снизу. Перед массовым удалением появляется окно **Delete Connections**.

## Случайный набор и панель Quick Connection Switcher

Благодаря случайному набору чат берет для каждого ответа другое подключение. Это удобно, когда запросы нужно распределить между несколькими провайдерами или моделями.

Чтобы добавить подключение в случайный набор, нажмите в его строке значок перемешивания. Всплывающая подсказка читается **Add to random pool**. Когда подключение уже в наборе, подсказка меняется на **In random pool (click to remove)**. Повторное нажатие значка убирает подключение из набора.

Чтобы чат работал со случайным набором, откройте панель **Chat Settings** (настройки чата), найдите раздел **Connection** и выберите в раскрывающемся списке пункт **🎲 Random**. В режиме Game Mode этот список называется **GM / Party Model**. После этого каждый ответ берет из набора случайное подключение.

Если выбранное для ответа подключение дает сбой, а для **Main** (основное) задано запасное подключение, ответ пишет запасное. Уведомление называет подключение, которое дало сбой, его модель и короткую причину, например "key rejected", "rate limited" или "not found", чтобы было понятно, какое подключение из набора нужно исправить. У ответа остается маленькая пометка **Fallback**; нажмите на нее или наведите на нее указатель, чтобы снова увидеть ту же строку.

Панель **Quick Connection Switcher** (быстрое переключение подключения) еще быстрее меняет подключение для текущего чата, а заодно и его модель. Нажмите значок ссылки в области ввода сообщения, чтобы ее открыть. Слева в ней показаны подключения, а справа – колонка **Models** (модели) выбранного подключения:

- Нажмите подключение, и текущий чат сразу начнет работать через него. Меню остается открытым, чтобы следом можно было выбрать одну из его моделей.
- Нажмите модель, чтобы использовать ее. Модель сохраняется в этом подключении, подключение выбирается для чата, если еще не было выбрано, и меню закрывается. Галочка отмечает модель, которую подключение использует сейчас. Как и в редакторе подключения, выбор модели из списка также обновляет размер контекста подключения и его лимит вывода, если провайдер их сообщает.
- Введите текст в поле **Search or enter model ID…**, чтобы отфильтровать список. Нажатие Enter выбирает модель, идентификатор или название которой вы ввели, либо единственную модель, оставшуюся в списке. Чтобы использовать модель, которой нет в списке, введите ее точный идентификатор: нажмите Enter, когда в списке ему ничего не соответствует, или нажмите строку **Use "…"**.
- Нажмите звездочку рядом с моделью, чтобы закрепить ее. Закрепленные модели остаются вверху, в группе **Pinned** (закрепленные), даже если вы ввели их вручную. Повторное нажатие звездочки снимает закрепление.
- Когда вы впервые открываете модели подключения, Marinara загружает список у провайдера и сохраняет его вместе с подключением, поэтому в следующие разы список появляется сразу. Нажмите кнопку обновления рядом с полем поиска, чтобы загрузить список заново, например когда провайдер добавил новые модели. Смена ключа API, базового адреса URL или провайдера подключения тоже загружает свежий список.
- Если у провайдера нет списка моделей или он недоступен, меню об этом сообщает, и идентификатор модели все равно можно ввести вручную.
- Нажмите кнопку с кубиком сверху меню, чтобы включить или выключить случайный набор для этого чата.
- Пока случайный набор включен, нажатие на подключение вместо этого добавляет его в набор или убирает оттуда. Галочка показывает, какие подключения входят в набор. Колонка **Models** при этом скрыта, потому что у набора нет одного определенного подключения.

На телефоне коснитесь стрелки-шеврона рядом с полем сообщения и откройте вкладку **Connections**. Коснитесь подключения, чтобы переключить на него чат; меню при этом закрывается. Чтобы выбрать модель, коснитесь вместо этого стрелки в правом конце строки подключения. Его модели откроются в том же меню, а чат переключится, только когда вы выберете одну из них. Чтобы вернуться к списку подключений, коснитесь стрелки назад.

**Смена модели действует везде, где используется это подключение.** Надпись внизу меню, "Model changes are saved to this connection.", означает, что агенты, вспомогательные функции и другие чаты с тем же подключением тоже переходят на новую модель. Другие настройки моделей в подключении, например модель эмбеддингов или подключение для описания изображений, не меняются. Если другая модель нужна только для одной задачи, скопируйте подключение и измените копию.

## Экспорт и импорт подключений

Подключения можно экспортировать в файл, чтобы сделать резервную копию или перенести их в другую установку, а позже импортировать обратно.

**Ключи API никогда не попадают в экспорт.** После импорта подключений откройте каждое из них и введите ключ API заново. Закрепленные модели в экспорт входят, а сохраненный список моделей – нет, поэтому он загружается заново, когда вы впервые открываете модели подключения.

Чтобы экспортировать одно подключение, откройте его в редакторе и нажмите кнопку **Export** (экспортировать) со значком загрузки. Для нескольких сразу включите в панели режим **Select** и нажмите **Export** на панели действий. Перед началом скачивания Marinara показывает окно **Export Connection Data** с предупреждением: This will export your connection data, WITHOUT your provided API Key. Remember to never share those with others! После этого нажмите кнопку **Export**, чтобы продолжить.

Одно подключение скачивается как файл `.connection.json`. Несколько подключений скачиваются вместе как файл `marinara-connections.zip`.

Чтобы импортировать подключения, нажмите кнопку **Import** (импортировать) сверху панели Connections. Открывается окно **Import Connections**. Перетащите в него один или несколько файлов `.json` либо нажмите на окно и выберите их на устройстве. В окне есть напоминание: Imported connections never include API keys. Add each key again after import. После импорта у каждого нового подключения ключ API остается пустым, пока вы его не заполните.
