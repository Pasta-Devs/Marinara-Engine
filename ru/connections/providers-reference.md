# Поддерживаемые провайдеры ИИ

Эта страница – справочник по основным сервисам, к которым может подключиться Marinara Engine: где взять ключ API, какой адрес используется по умолчанию и какие у сервиса особенности. Пошаговое добавление аккаунта описано в руководстве [Подключение к провайдеру ИИ](connecting-to-a-provider.md) – начните с него.

Сервис выбирается в окне **Add account** (добавить аккаунт), в разделе, который соответствует его назначению: **Chat** (чат), **Images & video** (изображения и видео), **Voice** (голос) или **Decisions** (решения). На плитке указано то же название, что и ниже. Адрес – это веб-адрес, на который Marinara отправляет запросы. В редакторе аккаунта он называется **Address** (адрес), а в редакторе модели – **Base URL** (базовый адрес). Для известных сервисов Marinara заполняет его сама. Меняйте его только для прокси или сервера, который вы запускаете сами.

Модели часто меняются, поэтому на этой странице они не перечислены. После подключения список моделей загружается в окне выбора. Чтобы загрузить его заново, нажмите **Refresh model list** (обновить список моделей) в окне выбора.

## Сервисы чата

Эти сервисы используют ключ API, кроме трех сервисов по подписке, которые используют вход в аккаунт на вашем компьютере.

| Сервис | Где взять ключ |
| --- | --- |
| LinkAPI | `linkapi.ai` |
| OpenAI | `platform.openai.com/api-keys` |
| Anthropic | `console.anthropic.com/settings/keys` |
| Google Gemini | `aistudio.google.com/apikey` |
| Google Vertex AI | `cloud.google.com/vertex-ai/docs/authentication` (руководство по учетным данным) |
| Mistral | `console.mistral.ai/api-keys` |
| Cohere | `dashboard.cohere.com/api-keys` |
| OpenRouter | `openrouter.ai/keys` |
| NanoGPT | `nano-gpt.com/api` |
| xAI / Grok | `console.x.ai` |
| Arli AI | `www.arliai.com/account` |
| Z.AI | `z.ai/manage-apikey/apikey-list` |
| DeepSeek | `platform.deepseek.com/api_keys` |
| OpenAI-compatible, Claude (Subscription), OpenAI (ChatGPT), Grok CLI (Subscription) | Страницы ключа нет. См. примечания ниже. |

Адреса по умолчанию, которые Marinara заполняет за вас:

- LinkAPI: `https://linkapi.ai/v1` (OpenAI-совместимый шлюз со своим ключом)
- OpenAI: `https://api.openai.com/v1`
- Anthropic: `https://api.anthropic.com/v1`
- Google Gemini: `https://generativelanguage.googleapis.com/v1beta`
- Google Vertex AI:
  `https://us-central1-aiplatform.googleapis.com/v1/projects/YOUR_PROJECT_ID/locations/us-central1`
- Mistral: `https://api.mistral.ai/v1`
- Cohere: `https://api.cohere.ai/compatibility/v1`
- OpenRouter: `https://openrouter.ai/api/v1`
- NanoGPT: `https://nano-gpt.com/api/v1`
- xAI / Grok: `https://api.x.ai/v1`
- Arli AI: `https://api.arliai.com/v1`
- Z.AI: `https://api.z.ai/api/paas/v4`
- DeepSeek: `https://api.deepseek.com/v1`
- OpenAI-compatible и сервисы по подписке: нет. Адрес вводите вы, или он не нужен.

Все страницы ключей начинаются с `https://`.

У трех сервисов по подписке поля **API key** (ключ API) и адреса скрыты. Эмбеддингов они не предлагают. Как их установить и войти в аккаунт, описано в руководстве [Подключения по подписке Claude, ChatGPT и Grok](subscription-clis.md). Там же рассказано об использовании тарифа.

Агрегатор – это сервис, в котором один ключ открывает доступ к моделям многих компаний. OpenRouter и NanoGPT – агрегаторы. Шлюз – то же самое, но для прокси, который вы запускаете сами или арендуете.

## Особенности сервисов

### OpenAI

**OpenAI** предоставляет модели GPT. Для изображений DALL-E добавьте **OpenAI** и выберите модели **Image** (изображения) в том же аккаунте. То же относится к другим сервисам, которые создают изображения с тем же ключом.

### Anthropic

**Anthropic** предоставляет модели Claude. Кеширование промптов позволяет сервису повторно использовать начало вашего промпта, что может снизить стоимость длинных чатов. Включите его настройкой **Enable prompt caching** (включить кеширование промптов) в редакторе модели. **Anthropic** не предлагает эмбеддингов (см. [Эмбеддинги](#embeddings)).

### Google Gemini и Google Vertex AI

**Google Gemini** предоставляет модели Gemini через Google AI Studio. Это более простой из двух вариантов Google. В обоих вариантах Google Marinara отключает настраиваемые фильтры безопасности Google, кроме категорий, которые вы сами задали в **Custom Parameters** (свои параметры). Базовая защита Google, например защита детей, по-прежнему действует.

**Google Vertex AI** предоставляет Gemini через проект Google Cloud, и настраивать его сложнее. Отредактируйте адрес и замените `YOUR_PROJECT_ID` на идентификатор своего проекта. Если регион не `us-central1`, поменяйте и его. Поле **API key** принимает любой из следующих вариантов, а Marinara сама определяет, что вы вставили:

1. Ключ сервисного аккаунта в формате JSON (файл, который выдает Google Cloud и в котором указан сервисный аккаунт).
2. Токен доступа OAuth, например полученный командой `gcloud auth print-access-token`.
3. Ключ Vertex API.

**Gemini 4 Argon** работает только в локациях `global`, `us` и `eu`, а не в отдельном регионе вроде `us-central1`. Так сказано в примечании в коде Marinara, которое следует документации Google. Чтобы использовать эту модель, задайте адрес `https://aiplatform.googleapis.com/v1/projects/YOUR_PROJECT_ID/locations/global`. С другой локацией Google возвращает ошибку, и Marinara ее показывает.

### Cohere

**Cohere** использует свой эндпоинт, совместимый с OpenAI. Если вставить старый адрес Cohere v2, Marinara сама переключит его на совместимый эндпоинт.

### OpenRouter

**OpenRouter** – агрегатор с двумя дополнительными настройками в редакторе модели:

- **Preferred provider** (предпочитаемый провайдер) принудительно направляет запросы на один указанный сервис. Название должно совпадать с тем, что указано на странице моделей OpenRouter. Оставьте поле пустым, чтобы маршрут выбирался автоматически.
- **Enable prompt caching** отправляет подсказки о кешировании для моделей Claude, которые идут через OpenRouter. Большинство других моделей кешируют сами.

### NanoGPT

**NanoGPT** – агрегатор без встроенного списка моделей. После подключения окно выбора загружает модели, доступные вашему аккаунту. Marinara читает подробный каталог NanoGPT и отмечает, какие модели входят в вашу подписку:

| Значок | Значение |
| --- | --- |
| Зеленый `1x` | Входит в подписку, по обычному тарифу. |
| Большее значение, например `2x` | Входит в подписку, но каждый входной токен расходует столько токенов вашей квоты. |
| **Paid** (платная) | Не входит в подписку. Использование списывается с платного баланса. |
| Нет значка | У NanoGPT не было данных о подписке для этой модели. |

#### Использование подписки

Если у вас есть подписка NanoGPT, аккаунт может показывать текущую квоту.

1. Нажмите **⋯** в строке аккаунта, выберите **Edit account** (изменить аккаунт) и откройте **Usage and balance** (расход и баланс).
2. Если чтение извне выключено, нажмите **Turn on** (включить). Чтобы добавить ключ управления, нажмите **Add a usage-only key** (добавить ключ только для расхода), вставьте его и нажмите **Show usage** (показать расход).
3. Включите **Show the usage meter on the card** (показывать индикатор расхода на карточке) и сохраните.

Индикатор показывает недельную и дневную квоты входных токенов: сколько осталось и когда каждая сбрасывается, например `42M remaining · resets in 4d`. Квота, которую NanoGPT не может сообщить, показывается как неизвестная, а не как неиспользованная. Неактивная подписка явно обозначается, а не рисуется как полная. Кнопка обновления читает данные заново.

Для чтения расхода подходят два вида учетных данных:

- **Management key** (ключ управления; рекомендуется). Создайте его по адресу `https://nano-gpt.com/settings#management-api-tokens` только для чтения расхода. Он может читать квоты, но не может запускать модели или тратить ваш баланс. Marinara хранит его зашифрованным и отправляет только на эндпоинт управления NanoGPT.
- **Ваш ключ API** используется, если ключ управления не сохранен. Это работает, но тогда квота читается ключом, который может тратить ваш баланс.

Тот же индикатор показывается под полосой контекста в окне выбора подключения чата и в настройках **Connection** (подключение) чата. Он появляется, только если модель чата – модель NanoGPT с включенным индикатором, и не появляется для **Shuffle** (перемешивание).

### xAI / Grok

**xAI / Grok** предоставляет модели Grok. У Grok 4.6 и 4.7 контекстное окно на 500 000 токенов и рассуждение до уровня **Extra high** (очень высокий). Они поддерживают инструменты чата, включая **Web Search** (поиск в интернете), поэтому результаты поиска могут учитываться в готовом ответе.

### Arli AI

**Arli AI** – облачный сервис чата без встроенного списка моделей. После подключения окно выбора загружает его модели. Для изображений Arli AI добавьте **Arli AI** и выберите модели **Image** в том же аккаунте.

### Z.AI

**Z.AI** предоставляет модели GLM (GLM 5.3, GLM 5.3 Flash и более ранние) через собственный API. Модели GLM 5.2 и 5.3 принимают уровень рассуждений **Maximum** (максимальный). Адрес по умолчанию ведет к эндпоинту с оплатой по факту использования. Coding Plan сервиса Z.AI использует другой эндпоинт, поэтому ключ Coding Plan здесь может не работать.

### DeepSeek

**DeepSeek** предоставляет `deepseek-flash` и `deepseek-v4-pro`. По умолчанию DeepSeek рассуждает. Его **Reasoning Effort** (глубина рассуждений) использует собственные уровни DeepSeek, а **Off** (выключено) отключает рассуждение для этого запроса. Запрос со средним уровнем DeepSeek выполняет как High. Рассуждения показываются в ответе обычным блоком размышлений.

Некоторые параметры к DeepSeek не относятся, поэтому панель их не показывает: **Verbosity** (подробность), **Top K** и штрафы выведены из употребления и игнорируются. **Temperature** (температура) и **Top P** составляют пару, потому что DeepSeek использует только один из них. При выключенном рассуждении вы видите **Temperature**, а при включенном – **Top P**.

Подключайте DeepSeek через его собственную плитку, а не указывая адрес DeepSeek в **OpenAI**. Сервис OpenAI рассчитан на модели OpenAI, поэтому для модели DeepSeek он скрывает элементы управления генерацией и почти не отправляет ваших настроек.

### OpenAI-compatible

**OpenAI-compatible** подключает сервер или прокси, который принимает формат запросов OpenAI, например Ollama, LM Studio или KoboldCpp. В окне **Add account** он называется **OpenAI-compatible address** (OpenAI-совместимый адрес). Для большинства локальных серверов ключ можно оставить пустым. Адрес вы вводите сами. См. [Подключение локальной модели или модели на своем сервере](local-self-hosted.md). О небольшой модели, которую Marinara запускает сама, читайте в руководстве [Настройка встроенной модели](local-model.md).

## Изображения и видео

В разделе **Images & video** у каждой плитки свой адрес и свое правило насчет того, нужен ли ключ. Плитки: Stability AI, Together AI, NovelAI, Venice.ai, Atlas Cloud, fal.ai, SpicyAPI, Pollinations, Stable Horde, Seedance 2.0, а также локальные серверы: ComfyUI, SD Web UI (AUTOMATIC1111 / Forge), SwarmUI, RunPod Serverless (ComfyUI), Draw Things и Block Entropy. Draw Things, ComfyUI, SwarmUI, SD Web UI и RunPod помечены **Self-hosted** (на своем сервере).

Модели изображений и видео от OpenAI, OpenRouter, xAI, NanoGPT, Arli AI, Z.AI и Google берутся из вашего аккаунта чата для этого сервиса. Добавьте аккаунт чата, затем выберите в нем модели **Image** или **Video** (видео).

См. [Провайдеры генерации изображений и их настройка](../media/image-providers.md) и [Генерация видео сцены](../media/scene-video.md).

## Decision

В разделе **Decisions** есть плитки **TypeSafe** (адрес по умолчанию `https://api.typesafe.ai`), **Own decision server** (собственный сервер решений) и **Built-in model (decisions)** (встроенная модель для решений). Сервисы чата, которые используют формат чата OpenAI, тоже могут отвечать на решения, но только с моделью, которая возвращает логарифмы вероятностей (оценки для каждого возможного ответа). Модель решений отвечает "да" или "нет" на вопросы о вашем чате. См. [Модели решений](decision-models.md).

## Audio

В разделе **Voice** аудиосервис озвучивает голоса персонажей и повествование. Выберите **Audio source** (источник звука):

| Источник | Что это |
| --- | --- |
| ElevenLabs | Голоса персонажей и повествование. |
| OpenAI-compatible | OpenAI или любой сервер, повторяющий формат речи OpenAI. |
| PocketTTS | Бесплатный голосовой сервер, который вы запускаете на своем компьютере. |
| xAI Voice | Голосовой сервис xAI. |

Каждый источник подставляет адрес и модель по умолчанию. **Default voice** (голос по умолчанию) – это голос, который используется, когда не задано ничего более конкретного, например голос отдельного персонажа. **Request timeout (seconds)** (тайм-аут запроса в секундах) – это время, которое Marinara ждет одну озвученную реплику. Для медленного голосового сервера увеличьте его.

Чтобы выбрать речевой аккаунт, который Marinara использует по умолчанию, нажмите на строку **Voice (Text to Speech)** (голос, синтез речи) в блоке **Jobs** (задачи). Чтобы читать сообщения вслух через такой аккаунт, выберите его как **Source** (источник) в карточке **Text to Speech** (синтез речи). См. [Настройка синтеза речи (TTS)](../media/tts-setup.md) и [Использование аудиоподключения](../media/tts-setup.md#use-an-audio-connection).

## Музыка и звуковые эффекты

Этот тип аккаунта создает инструментальную музыку и звуковые эффекты отдельно от речи. В окне **Add account** для него нет плитки. Такие аккаунты появляются после обновления (см. ниже) или импорта. Аккаунт редактируется в **Edit model** (изменить модель): там выбирается его сервис и включается **Music generation** (генерация музыки), **Sound-effect generation** (генерация звуковых эффектов) или обе настройки. При настройке Game такой аккаунт выбирается в поле **Music & Sound Effects account** (аккаунт музыки и звуковых эффектов), и вариант по умолчанию там – **Use the default Music & Sound Effects account** (использовать аккаунт музыки и звуковых эффектов по умолчанию).

Сервисы:

- **ElevenLabs**: адрес по умолчанию `https://api.elevenlabs.io`. Нужен ключ ElevenLabs. Для музыки и звуковых эффектов есть отдельные поля моделей.
- **SunoAPI**: адрес по умолчанию `https://apibox.erweima.ai`. Нужны ключ с [sunoapi.org](https://sunoapi.org/) и, если музыка включена, общедоступный HTTPS-адрес в поле **SunoAPI music callback URL** (адрес обратного вызова музыки SunoAPI). Это собственный сервис SunoAPI, а не вход в подписку Suno.
- **Custom compatible server** (свой совместимый сервер): адрес вашего сервера. Нужны явно заданный путь эндпоинта музыки или звуковых эффектов и поддерживаемый формат запроса. См. [контракты совместимого аудиосервера](../media/tts-setup.md#game-music-and-sound-effects-on-a-compatible-audio-server).

Примечания:

- SunoAPI нужен адрес обратного вызова, хотя Marinara сама проверяет готовность трека. Адрес указываете вы. Marinara его не создает.
- Промпт стиля музыки может содержать до 1 000 символов. Промпт звукового эффекта – до 500.
- Каждый запрос может стоить денег у вашего провайдера. См. [API музыки](https://docs.sunoapi.org/suno-api/generate-music) и [API звуковых эффектов](https://docs.sunoapi.org/suno-api/generate-sounds). Звуковые эффекты SunoAPI не проверялись с платным аккаунтом.

При обновлении для каждого аккаунта Audio с включенной генерацией создается отдельный аккаунт Music & Sound Effects. Старые отдельные настройки ElevenLabs в Game могут создать свой, поэтому таких аккаунтов может оказаться несколько. Речевые аккаунты и назначения голосов не меняются, и сохраненные ID аккаунтов Game тоже не меняются. Генерация работает, только если соответствующий перенесенный аккаунт доступен и в нем включена настройка музыки или звуковых эффектов. Иначе выберите другой подходящий аккаунт. Удаленный перенесенный аккаунт не создается заново при перезапуске. Эндпоинты, восстановленные из профиля, остаются недоступными, пока вы не проверите и не сохраните их локально.

Включайте генерацию звука отдельно для каждой игры или включите **Sound effects** (звуковые эффекты) в настройках команд Roleplay, чтобы использовать `[sound: description]`. У Gacha Forge есть собственная настройка генерации звука. Готовые звуки Game доступны и при выключенной генерации.

## Эмбеддинги

Эмбеддинги превращают текст в списки чисел, чтобы Marinara могла находить связанный текст. На них работают семантический поиск в лорбуках и Memory Recall. У большинства сервисов чата в редакторе модели, в разделе **Semantic search (embeddings)** (семантический поиск), можно задать модель эмбеддингов и необязательный **Embedding endpoint URL** (адрес эндпоинта эмбеддингов).

**Anthropic**, **Claude (Subscription)**, **OpenAI (ChatGPT)** и **Grok CLI (Subscription)** не умеют создавать эмбеддинги. Для них выберите другой аккаунт в раскрывающемся списке **Embedding provider** (провайдер эмбеддингов), например OpenAI-совместимый, **Google Gemini** или **Built-in model** (встроенная модель).

Чтобы использовать один источник эмбеддингов для всех аккаунтов без собственных настроек эмбеддингов, нажмите на строку **Embeddings** (эмбеддинги) в блоке **Jobs**. **Marinara's own search** (собственный поиск Marinara) оставляет встроенную модель эмбеддингов. Собственная модель эмбеддингов аккаунта или его **Embedding provider** по-прежнему имеют приоритет. После изменения заново векторизуйте свои лорбуки и воспоминания. См.
