# Поддерживаемые провайдеры ИИ

В этом руководстве собраны все провайдеры ИИ, к которым может подключиться Marinara Engine. Для каждого указано, где взять ключ API, какой базовый адрес используется по умолчанию и на какие особенности стоит обратить внимание. Ключ API – это секретный код, похожий на пароль. Провайдер выдает его, чтобы Marinara могла обращаться к сервису ИИ от имени вашего аккаунта.

Общий порядок создания подключения описан в руководстве [Подключение к провайдеру ИИ](connecting-to-a-provider.md) – начните с него. Эта страница нужна как справочник: по ней удобно искать подробности об одном конкретном провайдере.

## Как читать эту страницу

Провайдер выбирается при создании подключения в панели **Connections** (подключения). В окне **Create Connection** (создание подключения) у каждого провайдера есть кнопка **Provider** с тем самым названием, которое указано ниже.

Большинство провайдеров на этой странице – облачные сервисы, которые размещают ИИ у себя. Вы регистрируетесь у провайдера, копируете ключ API и вставляете его в поле **API Key** (ключ API). Три провайдера с подпиской вместо ключа используют локальный вход в аккаунт – об этом сказано в их разделах.

Два понятия встречаются постоянно:

- Базовый адрес (Base URL): веб-адрес, на который Marinara отправляет запросы. Большинство провайдеров подставляют его сами. Менять его нужно только для локальных или нестандартных серверов.
- Модель: конкретная модель ИИ, которую вы выбираете после провайдера. Список доступных моделей часто меняется, поэтому здесь он не приводится. Актуальный набор покажет раскрывающийся список **Model** (модель) или кнопка **Fetch Models from API** (получить список моделей) в редакторе подключения.

## OpenAI

- Где взять ключ: `https://platform.openai.com/api-keys`
- Базовый адрес по умолчанию: `https://api.openai.com/v1`

Провайдер **OpenAI** предоставляет модели семейства GPT. После вставки ключа выберите модель из раскрывающегося списка или нажмите кнопку **Fetch Models from API**, чтобы загрузить актуальный набор. Это подключение работает только с чат-моделями. Для изображений DALL-E используйте провайдер **Image Generation** и его сервис **OpenAI (DALL-E)**.

## Anthropic

- Где взять ключ: `https://console.anthropic.com/settings/keys`
- Базовый адрес по умолчанию: `https://api.anthropic.com/v1`

Провайдер **Anthropic** предоставляет модели Claude. Он поддерживает кеширование промптов, что снижает стоимость длинных чатов. Включается это переключателем **Enable prompt caching** (включить кеширование промптов) в редакторе подключения.

Эмбеддингов провайдер **Anthropic** не предлагает. Эмбеддинг – это числовое представление текста, благодаря которому Marinara ищет по лорбукам и памяти. Для таких функций создайте отдельное подключение для эмбеддингов (см. раздел про эмбеддинги ниже).

## Google Gemini

- Где взять ключ: `https://aistudio.google.com/apikey`
- Базовый адрес по умолчанию: `https://generativelanguage.googleapis.com/v1beta`

Провайдер **Google Gemini** дает доступ к моделям Gemini через Google AI Studio. Из двух вариантов Google этот – более простой.

Marinara отключает настраиваемые фильтры безопасности Google в обоих вариантах Google, кроме категорий, которые вы сами задали в **Custom Parameters** (свои параметры), но базовая защита Google, например защита детей, по-прежнему действует.

## Google Vertex AI

- Документация по учетным данным: `https://cloud.google.com/vertex-ai/docs/authentication`
- Базовый адрес по умолчанию: `https://us-central1-aiplatform.googleapis.com/v1/projects/YOUR_PROJECT_ID/locations/us-central1`

Провайдер **Google Vertex AI** дает доступ к моделям Gemini через проект Google Cloud. Настраивать его сложнее, чем **Google Gemini**. Поле **Base URL** (базовый адрес) придется отредактировать: замените `YOUR_PROJECT_ID` на реальный идентификатор проекта. Регион тоже поменяйте, если он отличается от `us-central1`.

Поле **API Key** принимает любой из трех видов учетных данных, а Marinara сама определяет, что именно вставлено:

1. Ключ сервисного аккаунта в формате JSON.
2. Токен доступа OAuth, например полученный командой `gcloud auth print-access-token`.
3. Ключ Vertex API.

**Gemini 4 Argon** работает только в локациях `global`, `us` и `eu`, а не в отдельном регионе вроде `us-central1`. Чтобы использовать эту модель, задайте в поле **Base URL** адрес `https://aiplatform.googleapis.com/v1/projects/YOUR_PROJECT_ID/locations/global`. С любой другой локацией Google возвращает ошибку, и Marinara ее показывает.

Модель Argon может отвечать по несколько минут – через любой из двух вариантов Google. Если ответы в чате прерываются по тайм-ауту, увеличьте `CHAT_GENERATION_TIMEOUT_MS`. Если по тайм-ауту прерываются вызовы агентов, увеличьте `AGENT_CALL_TIMEOUT_MS` (смотрите [Настройки сервера: справочник](../CONFIGURATION.md)). Google советует закладывать не меньше 15 минут, то есть `900000`.

- Базовый адрес по умолчанию: `https://api.mistral.ai/v1`

Провайдер **Mistral** предоставляет модели семейства Mistral. Кроме ключа API ничего настраивать не нужно.

## Cohere

- Где взять ключ: `https://dashboard.cohere.com/api-keys`
- Базовый адрес по умолчанию: `https://api.cohere.ai/compatibility/v1`

Провайдер **Cohere** по умолчанию работает через свой эндпоинт, совместимый с OpenAI. Эндпоинт – это адрес, по которому сервис принимает запросы. Если вставить старый адрес Cohere v2, Marinara сама переключит его на совместимый эндпоинт. Запросы при этом продолжают работать.

## OpenRouter

- Где взять ключ: `https://openrouter.ai/keys`
- Базовый адрес по умолчанию: `https://openrouter.ai/api/v1`

Провайдер **OpenRouter** – это агрегатор: один ключ открывает доступ к множеству моделей разных компаний. В редакторе подключения он добавляет две дополнительные настройки:

- **Preferred Provider** (предпочитаемый провайдер): текстовое поле, которое заставляет **OpenRouter** направлять запросы на один конкретный сервис. Название должно совпадать с тем, что указано на странице моделей OpenRouter. Оставьте поле пустым, чтобы маршрут выбирался автоматически.
- **Enable prompt caching**: отправляет подсказки о кешировании для моделей Claude, идущих через **OpenRouter**. Остальные модели в **OpenRouter** обычно кешируют сами, и эта настройка им не нужна.

## NanoGPT

- Где взять ключ: `https://nano-gpt.com/api`
- Базовый адрес по умолчанию: `https://nano-gpt.com/api/v1`

Провайдер **NanoGPT** – тоже агрегатор. Встроенного списка моделей у него нет, поэтому раскрывающийся список **Model** сначала пуст. Вставьте ключ и нажмите кнопку **Fetch Models from API**, чтобы загрузить модели, доступные вашему аккаунту.

Marinara читает подробный каталог моделей NanoGPT, поэтому список показывает, какие модели входят в вашу подписку и какие расходуют больше её квоты:

- У включённой в подписку модели отображается значок **множителя входных токенов**: зелёный `1x` при обычном расходе или большее значение, например `2x`, если каждый отправленный токен расходует столько входных токенов квоты. У модели, *не входящей* в подписку, отображается **Paid** (платная), поскольку её использование списывается с платного баланса. Отсутствие значка означает, что для модели не было данных о подписке.

### Использование подписки

Если у вас есть подписка NanoGPT, это подключение может показывать её текущую квоту:

1. Включите **Show subscription usage** (показывать использование подписки) в редакторе подключения и сохраните.
2. При желании сначала вставьте **Management Token** (токен управления).

Виджет обращается к endpoint использования NanoGPT и показывает недельную и дневную квоты входных токенов. Для чтения подходят два вида учётных данных:

- **Management Token** (рекомендуется): создайте его по адресу `https://nano-gpt.com/settings#management-api-tokens` с областью доступа **Usage only** (только использование). Он может читать квоты, но не запускать модели и не расходовать баланс, поэтому это более безопасный выбор для отображения расхода. Marinara хранит его зашифрованным и отправляет только на endpoint управления NanoGPT.
- **Ваш API-ключ**: используется автоматически, если токен управления не сохранён. Это работает, но квоты читаются с помощью тех же учётных данных, которые позволяют расходовать баланс.

Квота, которую NanoGPT сейчас не может сообщить, отображается как **неизвестная**, а не как неиспользованная. Неактивная подписка явно обозначается, вместо того чтобы показывать весь объём как доступный. Кнопка обновления позволяет обновить виджет по запросу.

Тот же индикатор находится под индикатором контекста в списке выбора подключения чата и в его настройках **Connection** (подключение), поэтому квоту можно отслеживать, не выходя из чата. Он следует за активным подключением: появляется только для NanoGPT с включённым **Show subscription usage** и не появляется для **Random**, где нет единственного подключения для запроса. В списке он оформлен как полоса контекста над ним и читается так же: использованный объём относительно недельной квоты, например `8.9M / 60M tokens`.

## xAI / Grok

- Где взять ключ: `https://console.x.ai`
- Базовый адрес по умолчанию: `https://api.x.ai/v1`

Провайдер **xAI / Grok** предоставляет модели Grok. При выборе этого провайдера в окне **Create Connection** Marinara подставляет модель Grok 4.5. Потом модель можно сменить. Grok 4.6 и 4.7 предлагают контекстное окно на 500 000 токенов и рассуждение до уровня **Maximum** (`xhigh`). Они поддерживают существующие инструменты чата, включая **Web Search** (поиск в интернете), поэтому результаты поиска могут учитываться в готовом ответе.

## Arli AI

- Где взять ключ: `https://www.arliai.com/account`
- Базовый адрес по умолчанию: `https://api.arliai.com/v1`

Провайдер **Arli AI** – облачный сервис для чата. Встроенного списка моделей у него нет, поэтому раскрывающийся список **Model** сначала пуст. Вставив ключ, нажмите **Fetch Models from API**, чтобы загрузить актуальные модели. Для изображений Arli AI используйте провайдер **Image Generation** и его сервис **Arli AI**.

## Z.AI

- Где взять ключ: `https://z.ai/manage-apikey/apikey-list`
- Базовый адрес по умолчанию: `https://api.z.ai/api/paas/v4`

**Z.AI** предоставляет модели GLM (GLM 5.3, GLM 5.3 Flash и более ранние) через собственный API. В списке **Model** показаны актуальные модели GLM, а **Fetch Models from API** обновляет его для вашей учетной записи. Модели GLM 5.3 всегда используют рассуждение: настройка **Reasoning Effort** (глубина рассуждений) в пресете преобразуется в один из трех уровней, которые принимает Z.AI: **Low** (низкий), **High** (высокий) и **Maximum** (максимальный). Если оставить настройку незаданной, используется значение Z.AI по умолчанию – **Maximum**. Базовый адрес по умолчанию ведет к эндпоинту с оплатой по факту использования. Coding Plan сервиса Z.AI использует другой эндпоинт, который по правилам провайдера предназначен только для инструментов из его списка, поэтому не стоит ожидать, что ключ этого плана здесь заработает.

## DeepSeek

- Где взять ключ: `https://platform.deepseek.com/api_keys`
- Базовый адрес по умолчанию: `https://api.deepseek.com/v1`

Провайдер **DeepSeek** предоставляет собственные чат-модели: `deepseek-flash` и `deepseek-v4-pro`. После вставки ключа они появляются в раскрывающемся списке **Model**, а **Fetch Models from API** обновляет этот список для вашего аккаунта.

По умолчанию модели DeepSeek используют рассуждение. Настройка **Reasoning Effort** здесь использует собственные уровни сервиса DeepSeek – **Low**, **High** и **Maximum**, а **Off** (выключено) отключает рассуждение для этого запроса. Уровня **Medium** нет: запрос со средним уровнем сервис DeepSeek выполняет как High, поэтому Marinara предлагает High, а не вторую кнопку, которая делала бы то же самое. Рассуждения появляются в ответе там же, где обычно показываются размышления модели.

Некоторые настройки в панели параметров к провайдеру DeepSeek не относятся, поэтому панель их не показывает, вместо того чтобы делать вид, что они работают. Среди них **Verbosity** (подробность), **Top K** и штрафы за повторы: сервис DeepSeek отказался от этих параметров и игнорирует их. **Temperature** (температура) и **Top P** составляют пару: сервис DeepSeek использует только один из них, в зависимости от того, включено ли рассуждение. Поэтому при выключенном рассуждении вы видите **Temperature**, а при включенном – **Top P**.

Подключайте сервис DeepSeek через этот провайдер, а не указывайте адрес DeepSeek в провайдере **OpenAI**. Провайдер **OpenAI** рассчитан на собственные модели OpenAI, поэтому с моделью DeepSeek он скрывает элементы управления генерацией и не отправляет почти ни одной из ваших настроек.

## Claude (Subscription)

- Ключ API: не нужен. Вместо него – вход в локальную программу.

Программа работает на том же компьютере, где запущен сервер Marinara, и войти в аккаунт нужно один раз. Поля **API Key** и **Base URL** для этого провайдера скрыты. Эмбеддингов он не предлагает (см. раздел про эмбеддинги ниже).

Как установить программу и войти в аккаунт, описано в руководстве [Подключения по подписке Claude, ChatGPT и Grok](subscription-clis.md).

## OpenAI (ChatGPT)

## Custom (OAI-Compatible)

- Базовый адрес по умолчанию: нет, его нужно ввести самостоятельно.

Выберите **Custom (OAI-Compatible)**, чтобы подключить локальный или собственный сервер моделей – например, Ollama, LM Studio или KoboldCpp. Этот вариант подходит и для любого прокси, который понимает формат чата OpenAI. Поле **API Key** для большинства локальных серверов можно оставить пустым. В поле **Base URL** укажите адрес своего сервера.

Пошаговая настройка и описание переключателя **Treat as local/custom endpoint** (считать эндпоинт локальным или своим) есть в руководстве [Подключение локальной модели или модели на своем сервере](local-self-hosted.md). О небольшой модели, встроенной в Marinara, читайте в руководстве [Настройка модели Local Model](local-model.md).

## Image Generation

**Image Generation** – особый провайдер. После его выбора нужно указать еще и **Service** (сервис) – тот сервис генерации изображений, который выполняет работу. У каждого сервиса свой базовый адрес по умолчанию и свое правило насчет того, нужен ли ключ API. Среди сервисов есть платные облачные API: **OpenAI (DALL-E)**, **Stability AI**, **NovelAI** и **Z.AI**. Есть и бесплатные варианты – **Pollinations** и **Stable Horde**. Локальные серверы вроде **ComfyUI** и **SD Web UI (AUTOMATIC1111 / Forge)** тоже работают.

Полный список сервисов генерации изображений, их настройка и параметры генерации собраны в руководстве [Провайдеры генерации изображений и их настройка](../media/image-providers.md).

## Video Generation

**Video Generation** – тоже особый провайдер, со своим списком **Video Service** (сервис генерации видео). Marinara использует его для коротких видеороликов сцен в формате MP4. Доступны сервисы **Google AI Studio**, **xAI Imagine**, **OpenRouter Video**, **NanoGPT**, **Atlas Cloud**, **Seedance 2.0**, **ComfyUI** и **SwarmUI**. Облачным сервисам нужен ключ API. **ComfyUI** и **SwarmUI** работают на вашем компьютере и обычно его не требуют.

Полная настройка и ограничения каждого сервиса видео описаны в руководстве [Генерация видео сцены](../media/scene-video.md).

## Decision

- Базовый адрес по умолчанию: `https://api.typesafe.ai` для источника **TypeSafe**.

**Decision** – необязательный особый провайдер для модели, которая отвечает "да" или "нет" на вопросы о вашем чате. Например, она может решить, нужно ли запускать собственного агента. Ее ответы управляют работой Marinara и не публикуются в чате. После выбора провайдера укажите источник: **TypeSafe**, **OpenRouter**, **Custom System One endpoint** (собственный эндпоинт System One) или **OpenAI-compatible chat model** (OpenAI-совместимая модель чата). Облачным источникам нужен ключ API.

Что делает модель решений, как ее выбрать и как полностью настроить, описано в руководстве [Модели решений](decision-models.md).

## Audio

**Audio** – особый провайдер для голосов и сгенерированного звука. После его выбора укажите **Audio Source** (источник звука):

- **ElevenLabs**: речь, звуковые эффекты и музыка.
- **OpenAI-compatible**: OpenAI или любой сервер, повторяющий формат речи OpenAI.
- **PocketTTS**: бесплатный голосовой сервер, который запускается на вашем компьютере.
- **xAI Voice**: голосовая служба xAI.

Каждый источник подставляет базовый адрес и модель по умолчанию. **Default Voice** (голос по умолчанию) – это голос, который используется, когда не задано ничего более конкретного, например голос отдельного персонажа. Чтобы выбрать аудиоподключение, которое Marinara использует по умолчанию, откройте панель **Connections**, раскройте раздел **Defaults** (по умолчанию) и выберите его в списке **Audio**.

С источником **ElevenLabs** появляются еще два переключателя: **Game sound effects** (звуковые эффекты в игре) и **Game music** (музыка в игре). С ними режим Game Mode может создавать звуковые эффекты и музыку через это подключение. См. [Генерируемые звуковые эффекты и музыка](../game/game-assets.md#generated-sound-effects-and-music). О голосах и чтении сообщений вслух читайте в руководстве [Настройка синтеза речи (TTS)](../media/tts-setup.md).

## Эмбеддинги

На эмбеддингах работают семантический поиск по лорбукам и **Memory Recall**. Они превращают текст в числовые представления, по которым Marinara находит связанные записи. У большинства чат-провайдеров в редакторе подключения можно задать **Embedding Model** (модель эмбеддингов) и, при необходимости, **Embedding Endpoint URL** (адрес эндпоинта для эмбеддингов).

Некоторые провайдеры эмбеддинги не создают: их нет у **Anthropic**, **Claude (Subscription)**, **OpenAI (ChatGPT)** и **Grok CLI (Subscription)**. В таком случае через раскрывающийся список **Embedding Connection** (подключение для эмбеддингов) возьмите другое подключение: совместимое с OpenAI, подключение к **Google Gemini** или к встроенной модели **Local Model**.
