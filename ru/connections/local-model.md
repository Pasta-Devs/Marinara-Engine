# Настройка модели Local Model

Это руководство рассказывает о встроенной модели **Local Model** – небольшой модели ИИ, которую приложение Marinara Engine скачивает и запускает на вашем компьютере. Ключ API и аккаунт в интернете для нее не нужны. Здесь вы узнаете, как ее настроить, что делает раздел **Runtime Settings** (настройки среды выполнения) и как модель Local Model обслуживает помощников: трекеры, эффекты сцен в режиме Game Mode и расшифровку звонков без интернета.

## Что такое Local Model

**Local Model** – это компактная языковая модель (Gemma), которая работает целиком на вашем компьютере. Ключ API – это секретный код, с которым Marinara обращается к онлайн-сервису ИИ. Модели Local Model ключ API не нужен, потому что ничего не покидает ваш компьютер.

Модель Local Model намеренно сделана маленькой. Ее дело – фоновая вспомогательная работа, а не основной чат или ролевая игра. Marinara поручает ей следующее:

- Трекеры (агенты, которые следят за состоянием) в режиме Roleplay.
- Эффекты сцен в режиме Game Mode: фоны, музыку, погоду.
- Эмбеддинги лорбуков (числовые представления текста) для семантического поиска.
- Расшифровку речи с микрофона в звонках режима Conversation – через отдельную речевую модель.
- Ответы на вопросы активации и утверждения решений, если выбрать его моделью решений. См. [Модели решений](decision-models.md).

В окне настройки она называется **Local AI Model**. В раскрывающихся списках подключений – **Local Model (sidecar)**. Это одна и та же возможность.

Не используйте модель Local Model для основного чата, ролевой игры, повествования Game Master (ведущий игры) и правок ассистента Professor Mari. Для этого она слишком мала, и результат выйдет слабым. Здесь выбирайте более сильное подключение. См. [Подключение к провайдеру ИИ](connecting-to-a-provider.md).

## Как открыть карточку Local Model

Модель Local Model живет в панели **Connections** (подключения).

1. Откройте панель **Connections**.
2. Найдите карточку с названием **Local Model**.
3. Нажмите на карточку или на кнопку с шестеренкой **Open local model settings**.

Кнопка с шестеренкой открывает полное окно настройки **Local AI Model**. Пока ни одна модель не скачана, на карточке есть еще кнопка **Download now** и кнопка **Choose model options**. Обе открывают то же окно настройки.

В окне настройки видно предупреждение **Local Model is for helpers, not main roleplay**. Оно повторяет, что модель предназначена только для вспомогательных задач.

## Поддержка оборудования и операционных систем

Модель Local Model скачивает среду выполнения (программу, которая запускает модель) и файл модели. На компьютере должно хватить свободного места на диске и оперативной памяти (RAM) для того и другого.

Возможности зависят от операционной системы:

- **Windows (64-bit) и Linux (64-bit)**: доступен полный выбор в списке **Runtime Target**, так что можно указать семейство видеокарты (GPU) или работу только на процессоре (CPU).
- **Windows on ARM и Linux on ARM**: набор вариантов урезан, в основном работа на CPU.
- **macOS on Apple Silicon**: Marinara использует среду выполнения MLX, настроенную под чипы Apple. Своя модель задается репозиторием HuggingFace, а не отдельным файлом.
- **macOS on Intel и Android**: фактически только CPU.

В установках "Lite" модель Local Model недоступна. Установка Lite – это облегченная сборка без локальной среды выполнения, чтобы занимать меньше места. В такой сборке карточки Local Model нет.

## Первая настройка

Сначала установите среду выполнения, потом выберите модель.

1. Откройте окно настройки **Local AI Model**.
2. Нажмите кнопку **Install Runtime**. На Apple Silicon она называется **Install MLX Runtime**.
3. Дождитесь конца установки среды выполнения. Ход скачивания показывает полоса прогресса.
4. Выберите модель по инструкции из раздела **Скачивание модели** ниже.
5. Дождитесь конца скачивания модели.
6. Когда статус покажет **Ready**, нажмите кнопку **Done**.

Если закончить настройку прямо сейчас не выходит, нажмите кнопку **Skip for Now**. Когда модель уже есть, эта кнопка называется **Close**.

Установка и переустановка среды выполнения – защищенное действие. В установках Windows "в один клик" оно разрешено сразу. На macOS, Linux и в контейнере Docker его может потребоваться разрешить вручную. См. раздел **Устранение неполадок** ниже.

Marinara скачивает только те версии llama.cpp, MLX и uv, которые одобрены для установленной версии приложения Marinara Engine. Перед распаковкой и запуском она сверяет точный размер файла и контрольную сумму SHA-256. Набор зависимостей Python для среды MLX тоже закреплен по версиям и проверяется по хешу, а проверенный исходный код mlx-lm ставится без подтягивания лишних пакетов. Поэтому среда выполнения обновляется вместе с проверенными обновлениями Marinara, а не подтягивается молча из сборки "latest" основного проекта.

## Скачивание модели

Окно настройки предлагает два способа получить модель.

### Готовые пресеты

В разделе **Curated Gemma 4 Presets** выбирается один из двух готовых вариантов. На оборудовании других производителей они идут в формате GGUF:

| Пресет | Размер скачивания | Память при работе |
| --- | --- | --- |
| Q8 (Best Quality) | около 5.4 ГБ | около 5.8 ГБ |
| Q4_K_M (Smaller, Faster) | около 3.2 ГБ | около 3.6 ГБ |

Вариант Q8 помечен как **Recommended**. Он дает лучшее качество. Вариант Q4_K_M меньше и быстрее, а памяти ему нужно меньше.

На Apple Silicon вместо них предлагаются пресеты MLX. 8-битному пресету MLX нужно около 5.9 ГБ на скачивание и около 7.5 ГБ памяти. 4-битному – около 3.6 ГБ на скачивание и около 4.8 ГБ памяти.

Чтобы скачать пресет:

1. Выделите нужный пресет.
2. Нажмите кнопку **Use Curated Preset**. Если модель уже установлена, кнопка называется **Switch to Curated Preset**.

### Своя модель

В разделе **Use Your Own Model From HuggingFace** можно подключить собственную модель с HuggingFace – публичного сайта, где выкладывают модели.

1. Введите название репозитория в поле. Формат – `owner/repo`.
2. Нажмите кнопку **List Models**. На Apple Silicon она называется **Validate Repo**.
3. На оборудовании других производителей выберите конкретный файл в раскрывающемся списке, затем нажмите кнопку **Download Selected GGUF**.
4. На Apple Silicon, когда репозиторий проверен, нажмите кнопку **Use Validated MLX Repo**.

Marinara хранит на диске только один файл модели Local Model. Перед скачиванием новой модели старая удаляется. Отдельной кнопки удаления для основной модели Local Model нет. Чтобы от нее избавиться, скачайте поверх другую модель.

## Справочник по разделу Runtime Settings

Откройте раздел **Runtime Settings** в окне настройки, чтобы отрегулировать работу модели. Поля сохраняются по-разному:

- Раскрывающиеся списки и переключатель **Native Tool Calls** сохраняются сразу после изменения.
- Поля **Context Window**, **Max Response Tokens**, **Temperature**, **Top P** и **Top K** вступают в силу только после нажатия кнопки **Apply Settings**.
- У поля **Physical Batch Size** своя кнопка **Apply**. Отдельная кнопка есть и у поля с числом слоев, которое появляется, когда в списке **GPU Offload** выбрано **Custom GPU layers**.

| Параметр | По умолчанию | За что отвечает |
| --- | --- | --- |
| Runtime Target | Auto detect | Под какое семейство GPU Marinara ставит среду выполнения |
| GPU Offload | Auto offload | Какая часть работы уходит на GPU |
| Native Tool Calls | On | Разрешает модели вызывать инструменты и функции |
| Pooling Type | None | Способ расчета эмбеддингов для поиска по лорбукам |
| Physical Batch Size | 512 | Размер пакета для запросов эмбеддингов лорбуков |
| Context Window | 8192 | Сколько текста модель читает за один раз |
| Max Response Tokens | 4096 | Какой длины ответ модель может написать |
| Temperature | 0.3 | Насколько случайны ответы |
| Top P | 0.95 | Ограничение выборки при подборе слов |
| Top K | 64 | Ограничение выборки при подборе слов |

Пояснения к самым неочевидным полям:

- Поля **Runtime Target** и **GPU Offload** есть только в среде выполнения GGUF. На Apple Silicon ускоритель выбирает MLX.
- Поля **Pooling Type** и **Physical Batch Size** тоже есть только в среде выполнения GGUF, под заголовком **Embedding Endpoint**. Они настраивают лишь эмбеддинги лорбуков и не меняют обычные ответы в чате.
- По умолчанию в поле **Pooling Type** стоит **None**. Переключите его на **Mean**, если модель Local Model считает эмбеддинги лорбуков.
- Поле **Physical Batch Size** задает, сколько текста эндпоинт эмбеддингов берет в один пакет. Увеличьте значение, если длинные записи лорбука не векторизуются. Приложение советует 1024 для Gemma.
- Переключатель **Native Tool Calls** должен быть включен, иначе инструменты не работают. Предупреждение сообщает, что без него ассистент Professor Mari и свои агенты не смогут запускать инструменты в локальной модели. В среде выполнения MLX этого параметра нет.
- Поле **Max Response Tokens** ограничивает обычные ответы в чате и ответы агентов. Анализ сцены в режиме Game Mode оно не ограничивает: там свой внутренний предел.

## Кнопка Send Test Message

Кнопка **Send Test Message** проверяет, работает ли среда выполнения. Она находится в разделе Runtime. Пока модель не скачана и среда выполнения не установлена, кнопка выключена.

1. Нажмите кнопку **Send Test Message**.
2. Дождитесь блока с результатом.
3. При успехе появляется блок **Local Test Message Succeeded** со временем ответа.
4. При ошибке появляется блок **Local Test Message Failed** с текстом ошибки.

Проверка использует фиксированный промпт (текст, который Marinara отправляет ИИ). Значение **Temperature** и настройки токенов она не учитывает, поэтому честно показывает, отвечает ли модель.

## Модель Local Model для вспомогательных задач

Как только модель скачана, на карточке Local Model появляются два переключателя:

- **Use for tracker agents (roleplay)** – по умолчанию выключен.
- **Use for game scene analysis** – по умолчанию включен.

Эти два переключателя решают, держит ли Marinara модель Local Model запущенной в фоне. Когда оба выключены, среда выполнения сама не стартует. Стоит включить любой из них – и Marinara запускает локальный сервер автоматически. Первый запуск после включения занимает немного времени.

На карточке есть еще кнопка **Use local model for all tracker agents**. Одним нажатием она переводит на модель Local Model все встроенные трекеры. Строка ниже показывает, сколько трекеров уже работает через локальную модель, например "3/7 built-in tracker agents currently point at the local model." Меняется только модель, а сами агенты при этом не включаются. О том, как их включить, читайте в руководстве [Memory Recall и сводки чата](../agents/memory.md) и в руководстве по своему режиму.

В режиме Game Mode работу со сценой тоже можно отдать модели Local Model. В настройке игры раскрывающийся список **Scene Effects Connection** предлагает вариант **Local Model (Gemma)**. При его выборе включается переключатель **Use for game scene analysis**. См. [Game Mode: начало работы](../game/getting-started.md).

### Модель Local Model для эмбеддингов лорбуков

Модель Local Model может обслуживать семантический поиск по лорбукам. В настройках векторизации лорбука выберите подключение **Local Model (sidecar)**. Для этого сначала нужен включенный переключатель **Use for tracker agents (roleplay)** или **Use for game scene analysis**. Если оба выключены, запрос завершается ошибкой: сообщение говорит, что локальную модель нужно включить для трекеров или анализа сцены игры. Этот путь работает через среду выполнения GGUF и недоступен на MLX для Apple Silicon. См. [Семантический поиск в лорбуках](../lorebooks/semantic-search.md).

## Модель Local Model как подключение для чата

Как только модель скачана, Local Model появляется внизу большинства списков подключений. Она показана как **Local Model (sidecar)** или как **Local Model** с названием модели в скобках, если название известно.

При выборе для обычного чата появляется предупреждение. В нем написано, что модель Local Model крошечная и рассчитана на вспомогательные задачи. Там же сказано, что ответы в основном чате и в ролевой игре могут быть медленными, короткими или слабыми. Это не настоящее сохраненное подключение, поэтому значения по умолчанию для него не сохранить.

Выбор в чате запускает локальный сервер по требованию, даже когда оба вспомогательных переключателя выключены. В списке основной модели режима Game Mode ее нет. Режим Game Mode обращается к модели Local Model только через **Scene Effects Connection**.

## Модель Local Speech Model для звонков

**Local Speech Model** – это дополнительная модель агента Calls, которая расшифровывает речь с микрофона без интернета. Она обслуживает звонки режима Conversation, когда голос расшифровывается на вашем компьютере. Это модель Whisper – модель распознавания речи, которая превращает произнесенные слова в текст.

Сначала установите агента **Calls** через **Agents > Download Agents**. После этого моделью Whisper можно управлять на карточке **Local Model** в панели Connections, под заголовком **Local Speech Model**. Пока агент Calls не установлен, заголовок и элементы скачивания скрыты.

Предлагаются два варианта:

- **Whisper Tiny (Multilingual)**: около 180 МБ на скачивание, около 350 МБ памяти. Лучший первый выбор для телефонов и старых компьютеров.
- **Whisper Base (Multilingual)**: около 320 МБ на скачивание, около 650 МБ памяти. Точнее разбирает невнятную речь, но запускается дольше.

Как ее настроить:

1. Откройте карточку **Local Model** и разверните ее.
2. Под заголовком **Local Speech Model** выберите модель в раскрывающемся списке.
3. Нажмите кнопку **Download Whisper**.
4. Когда появится статус **Ready**, настройка закончена.

Чтобы удалить только выбранную модель, нажмите кнопку с корзиной **Delete Local Whisper**. При удалении агента Calls все скачанные модели Whisper и сохраненный выбор удаляются сами, освобождая место на диске. Если установить Calls заново, элементы **Local Speech Model** вернутся и модель Whisper можно будет скачать снова.

Запись вашего голоса не покидает компьютер. В выбранное подключение для чата уходит только расшифрованный текст. Чтобы задействовать модель в звонке, в настройке режима звукового входа выберите вариант Local Whisper. См. [Аудио- и видеозвонки в режиме Conversation](../conversation/calls.md).

## Устранение неполадок

**"Sidecar runtime install is disabled."** Установка и переустановка среды выполнения – защищенное действие. В установках Windows "в один клик" оно разрешено сразу. На macOS, Linux и в контейнере Docker есть два выхода. Первый – прописать `SIDECAR_RUNTIME_INSTALL_ENABLED=true` в файле `.env` на сервере, например:

```
SIDECAR_RUNTIME_INSTALL_ENABLED=true
```

Второй – один раз ввести секрет Admin Access в **Settings -> Advanced -> Admin Access** и повторить попытку. См. [Настройки сервера: справочник](../CONFIGURATION.md).

**Среда выполнения не запустилась.** В окне настройки появляется блок **Local runtime failed to start** с текстом ошибки и путем к файлу журнала. Нажмите кнопку **Retry Startup**. Если не помогло, нажмите кнопку **Reinstall Runtime** или попробуйте другое значение **Runtime Target**. Кнопка **Continue Without Local AI** позволяет работать в Marinara без модели Local Model. На карточке в панели Connections та же проблема показана как **Local runtime unavailable**.

**При скачивании среды выполнения не совпал размер или контрольная сумма SHA-256.** Marinara отбрасывает такой файл еще до распаковки. Сначала обновите Marinara, затем повторите попытку – так одобренный список версий среды выполнения и скачанный файл совпадут. Если на той же версии ошибка повторяется, не распаковывайте и не запускайте архив вручную: сообщите сопровождающим значение **Runtime Target** и текст ошибки.

**Поиск по лорбуку сообщает, что локальная модель не включена.** Включите на карточке Local Model переключатель **Use for tracker agents (roleplay)** или **Use for game scene analysis**, затем повторите векторизацию.

**В режиме Game Mode появилось уведомление "Local scene helper failed to start."** Нажмите в нем кнопку **Open Local AI Model**, чтобы повторить попытку, сменить модель или отключить локальный анализ сцены.

Больше подсказок собрано в руководстве [Устранение неполадок в приложении Marinara Engine](../TROUBLESHOOTING.md).
