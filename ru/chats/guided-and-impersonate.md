# Направляемая генерация и Impersonate

В этом руководстве описаны два способа направлять чат в приложении Marinara Engine. Направляемая генерация задает ИИ направление для следующего ответа, но видимое сообщение при этом не появляется. Impersonate поручает ИИ написать ваш ответ за вас. Здесь же разобрано меню **Quick replies** (быстрые ответы), которое ставит оба действия рядом с кнопкой **Send**.

## Направляемая генерация

Направляемая генерация – это способ сказать ИИ, куда повести следующий ответ. Указание идет от вас, а не от персонажа. Оно задает направление ответу, но обычным сообщением в чате не становится.

### Направление ответа командой /guided

Основной способ направить ответ – слеш-команда `/guided`.

1. Введите в поле сообщения `/guided`, а после него – направление.
2. Нажмите Enter или кнопку **Send** (отправить).
3. ИИ генерирует следующий ответ и ведет его в заданную вами сторону.

Например, такое направление подталкивает следующий ответ к признанию:

```
/guided make him admit he is lying
```

У команды есть короткие псевдонимы. Вместо `/guided` можно ввести `/narrator`, `/narrate` или `/nar`.

В групповом чате направление можно адресовать одному персонажу. Введите `/guided respond for <character> <direction>`. На месте `<character>` укажите имя персонажа, на месте `<direction>` – само направление. Например:

```
/guided respond for Alice make her admit she is lying
```

### Направление при повторной генерации

Ответ можно направить и в момент, когда вы генерируете его заново. Тогда направлением один раз послужит текст, набранный в поле сообщения.

1. Откройте панель **Settings** (настройки), затем **Advanced** (дополнительно), затем **Message Tools** (инструменты сообщений).
2. Включите переключатель **Guide swipes/regens with chat input**. По умолчанию он выключен.
3. Вернитесь в чат и наберите направление в поле сообщения, но не отправляйте его.
4. Нажмите **Regenerate** (сгенерировать заново) на сообщении ИИ.

Когда переключатель включен и в поле есть текст, всплывающая подсказка кнопки **Regenerate** меняется на **Regenerate (guided)**. ИИ делает новую версию ответа, взяв набранный текст как направление.

### Просмотр раздела Stored guidance

Если ответ создавался с направлением, Marinara сохраняет это направление, чтобы его можно было посмотреть позже. На сообщении появляется действие **Stored guidance** (сохраненное направление) с иконкой свитка.

1. Нажмите иконку **Stored guidance** на сообщении ИИ.
2. Откроется окно **Stored guidance** с тем направлением, из которого получился ответ.

Окно подписывает направление по его источнику:

- **/guided**: направление пришло из команды `/guided`.
- **Guided regenerate**: направление пришло из нажатия **Regenerate** с направлением.
- **Game start**: направление пришло из настройки режима Game Mode.

Для направлений из `/guided` и из повторной генерации есть кнопка **Copy /guided**: она копирует направление обратно в виде готовой команды `/guided`. Ее можно вставить в другой чат и повторить тот же ход.

## Impersonate

Impersonate поручает ИИ написать ваше следующее сообщение за вас – голосом вашей персоны. Персона – это персонаж, за которого играете вы; в чат он подставляется как `{{user}}`. О том, как ее настроить, читайте в руководстве [Персоны: создание и редактирование](../characters/personas.md).

Impersonate работает только в чатах Roleplay. В чатах Conversation и Game Mode он недоступен. При попытке использовать его в чате Conversation появляется сообщение "Impersonate is not available in Conversation mode."

### Использование /impersonate

1. Введите в поле сообщения `/impersonate`. После команды можно добавить направление, но это не обязательно.
2. Нажмите Enter или кнопку **Send**.
3. ИИ пишет сообщение от лица вашей персоны и отправляет его в чат.

Например, так ИИ напишет вашим голосом сообщение с вопросом о погоде:

```
/impersonate ask about the weather
```

У команды есть короткий псевдоним. Вместо `/impersonate` можно ввести `/imp`.

Сообщение, написанное через Impersonate, можно переделать. Действие **Regenerate** работает и на сообщениях пользователя, созданных через Impersonate, так что вы получите другую версию.

### Настройки Impersonate

У Impersonate есть раздел настроек, который действует на каждый запуск `/impersonate` во всех чатах. Открывается он из настроек отдельного чата.

1. Откройте панель **Chat Settings** (настройки чата) для чата Roleplay.
2. Найдите раздел **Impersonate**.

В разделе собраны такие элементы:

- **Prompt Template**: необязательное указание, которое отправляется модели при каждом запуске Impersonate. Оставьте поле пустым, чтобы использовать промпт самого чата, а если у чата его нет – встроенный промпт по умолчанию. Поддерживаются макросы `{{user}}`, `{{persona_description}}` и `{{impersonate_direction}}`. Макрос – это заготовка, которую Marinara заменяет настоящим текстом перед отправкой. Нажмите кнопку **Built-in default**, чтобы прочитать текст по умолчанию. Кнопка **Reset** (сбросить) убирает заданный вами шаблон и очищает поле.
- **Preset**: отдельный пресет промпта только для ответов Impersonate. Пресет – это сохраненный набор настроек промпта. Смотрите руководство [Редактор пресетов и управление промптами](../prompts/presets.md). По умолчанию выбрано **Use chat default**. Пресеты действуют только в режиме Roleplay.
- **Connection**: направляет ответы Impersonate через отдельное подключение – например, к более дешевой или быстрой модели. Подключение – это сохраненные настройки доступа к провайдеру ИИ. Смотрите руководство [Подключение к провайдеру ИИ](../connections/connecting-to-a-provider.md). По умолчанию выбрано **Use chat default**. Еще можно выбрать **Random**.
- **Skip agents**: когда включено, Marinara пропускает работу агентов (трекеров, маршрутизаторов лорбуков и похожих помощников) во время Impersonate. Так Impersonate остается быстрым и не меняет состояние мира. По умолчанию выключено. Смотрите руководство [Агенты](../agents/agents-overview.md).
- **Use CYOA as direction**: когда включено, нажатие на вариант CYOA передает его как направление для Impersonate, а не отправляет обычным сообщением. CYOA – это "выбери свое приключение": набор вариантов под ответом, на которые в некоторых чатах можно нажать. По умолчанию этот переключатель выключен.

### Свой промпт для Impersonate

Промпт для Impersonate можно задать и для одного отдельного чата – слеш-командой.

1. Введите `/impersonate_prompt`, а после него – промпт в кавычках.
2. Нажмите Enter.

Например:

```
/impersonate_prompt "You will now play as my OC:"
```

Чтобы убрать промпт этого чата и вернуться к промпту по умолчанию, введите:

```
/impersonate_prompt reset
```

У команды есть короткий псевдоним – `/imp_prompt`.

## Меню Quick replies

Меню **Quick replies** добавляет дополнительные действия отправки рядом с обычной кнопкой **Send**. Так направляемая генерация и Impersonate доступны в одно нажатие, без слеш-команд.

Какие действия показывать, вы выбираете в настройках.

1. Откройте панель **Settings**, затем **Advanced**, затем **Message Tools**.
2. Включите переключатель **Quick replies**. По умолчанию он выключен.
3. Разверните его и отметьте, какие действия показывать. После включения меню все три действия включены по умолчанию.

Действий три:

- **Post only**: добавляет набранное сообщение в чат, не вызывая ответ ИИ. Это также можно сделать слеш-командой `/send <message>`.
- **Guide reply**: отправляет набранный текст как направление `/guided`, а не как обычное сообщение.
- **Impersonate**: генерирует ответ от лица вашей персоны, а набранный текст берет как направление. В чатах Conversation это действие скрыто, потому что Impersonate там не работает.

Если включено только одно действие, его кнопка стоит прямо рядом с **Send**. Если включено больше одного, они сворачиваются в небольшое меню. Чтобы открыть его, нажмите кнопку с тремя точками (она подписана **Quick replies**).
