# Направляемая генерация и Impersonate

Два способа направлять чат. Направляемая генерация задает следующему ответу направление и не публикует видимого сообщения. Impersonate поручает модели написать ваш собственный ответ. Меню Quick replies ставит оба действия рядом с **Send** (отправить).

## Направление ответа командой /guided

Ваше направление – это указание вне роли. Оно влияет на ответ, но не появляется в чате как сообщение.

1. Введите в поле сообщения `/guided` и свое направление.
2. Нажмите <kbd>Enter</kbd> или **Send**.

Модель пишет следующий ответ, следуя вашему направлению. Например:

```text
/guided make him admit he is lying
```

Вместо `/guided` можно ввести `/narrator`, `/narrate` или `/nar`. В групповом чате направление можно адресовать одному персонажу с помощью `respond as`, `reply as` или `respond for`:

```text
/guided respond as Alice make her admit she is lying
```

## Направление при повторной генерации

Здесь текст из поля сообщения один раз используется как направление для повторной генерации.

1. Откройте **Settings → Advanced → Message Tools** (настройки → дополнительно → инструменты сообщений) и включите **Guide swipes/regens with chat input** (направлять свайпы и повторные генерации текстом из поля ввода). По умолчанию он выключен.
2. В чате наберите направление в поле сообщения, но не отправляйте его.
3. Нажмите **Regenerate** (сгенерировать заново) на сообщении ИИ. Когда в поле есть текст, кнопка подписана **Regenerate (guided)**.

После этого направление остается в поле, так что его можно поправить и сгенерировать ответ еще раз. Чтобы поле вместо этого очищалось, выключите **Keep guidance after regenerating** (сохранять направление после повторной генерации) в **Settings → General → Input & Editing** (общие → ввод и правка).

Если не получилось: кнопка должна быть подписана **Regenerate (guided)**. Если на ней написано только **Regenerate**, настройка выключена или поле пустое.

## Просмотр Stored guidance

Marinara сохраняет направление, которое задало ответ.

1. Нажмите иконку **Stored guidance** (сохраненное направление) со свитком на сообщении ИИ.
2. Окно **Stored guidance** покажет направление.

Окно подписывает, откуда пришло направление: **/guided**, **Guided regenerate** или **Game start** (настройка Game Mode). Для направлений из `/guided` и из направляемой повторной генерации кнопка **Copy /guided** (скопировать как /guided) копирует готовую команду `/guided`, которую можно вставить в другой чат.

## Ваш ответ через Impersonate

Impersonate поручает модели написать ваше следующее сообщение голосом вашей персоны. Персона – это персонаж, за которого играете вы; она обозначается как `{{user}}`. См. [Персоны](../characters/personas.md).

Перед началом: Impersonate работает только в чатах Roleplay. В Conversation появляется сообщение "Impersonate is not available in Conversation mode." В Game он тоже недоступен.

1. Введите в поле сообщения `/impersonate`. При желании добавьте после команды направление.
2. Нажмите <kbd>Enter</kbd> или **Send**.

Модель публикует сообщение пользователя от лица вашей персоны. Например, эта команда пишет сообщение с вопросом о погоде:

```text
/impersonate ask about the weather
```

Короткий псевдоним – `/imp`. **Regenerate** работает и на сообщении, которое написал Impersonate, так что можно получить другую версию.

### Настройки Impersonate

Эти настройки действуют на каждый запуск `/impersonate` во всех ваших чатах. Откройте **Chat Settings** (настройки чата) в чате Roleplay и найдите раздел **Impersonate**. Как открыть панель, см. [Обзор панели Chat Settings](chat-settings.md).

| Элемент | Что делает |
| --- | --- |
| **Prompt Template** (шаблон промпта) | Необязательное указание, которое отправляется при каждом запуске Impersonate. Если оно пустое, используется собственный промпт чата или встроенный промпт по умолчанию. Поддерживаются `{{user}}`, `{{persona_description}}` и `{{impersonate_direction}}` – заготовки, которые Marinara заменяет настоящим текстом. Выберите **Built-in default** (встроенный по умолчанию), чтобы прочитать текст по умолчанию, **Copy built-in default to edit** (скопировать встроенный для правки), чтобы начать с его копии, **Save as** (сохранить как), чтобы сохранить шаблон под своим названием, и **Delete template** (удалить шаблон), чтобы удалить шаблон. |
| **Preset** (пресет) | Пресет промпта только для ответов Impersonate. По умолчанию: **Use chat default** (как в чате). См. [Редактор пресетов и управление промптами](../prompts/presets.md). |
| **Connection** (подключение) | Модель для ответов Impersonate, например более дешевая или быстрая. По умолчанию: **Use chat default**. Можно также выбрать **Random**. См. [Подключение к провайдеру ИИ](../connections/connecting-to-a-provider.md). |
| **Skip agents** (пропускать агентов) | Пропускает работу агентов (трекеров, маршрутизаторов лорбуков и похожих помощников) во время Impersonate. Так Impersonate работает быстро и не меняет состояние мира. По умолчанию выключено. См. [Агенты](../agents/agents-overview.md). |
| **Use CYOA as direction** (использовать CYOA как направление) | Нажатие на вариант CYOA (choose your own adventure, "выбери свое приключение") делает его направлением для Impersonate, а не публикует его. По умолчанию выключено. Если в **Settings → General → Input & Editing** включено **Add CYOA choices to the message box instead of sending them** (добавлять варианты CYOA в поле сообщения, а не отправлять их), нажатие только добавляет текст в поле сообщения, и эта настройка ни на что не влияет. |

### Свой промпт для одного чата

1. Введите `/impersonate_prompt` и свой промпт в кавычках.
2. Нажмите <kbd>Enter</kbd>.

```text
/impersonate_prompt "You will now play as my OC:"
```

Чтобы вернуться к промпту по умолчанию, введите `/impersonate_prompt reset`. Псевдоним – `/imp_prompt`.

## Кнопки Quick replies рядом с Send

Quick replies добавляют альтернативы кнопке **Send**, доступные в одно нажатие, так что слеш-команду набирать не нужно.

1. Откройте **Settings → General → Input & Editing**.
2. Включите **Quick replies** (быстрые ответы). По умолчанию он выключен.
3. Разверните его и выберите, какие действия показывать. После включения все три действия по умолчанию включены.

| Действие | Что делает |
| --- | --- |
| **Post only** (только опубликовать) | Добавляет набранное сообщение в чат без ответа. Команда `/send <message>` делает то же самое. |
| **Guide reply** (направить ответ) | Отправляет набранный текст как направление `/guided`. |
| **Impersonate** | Генерирует ответ от лица вашей персоны, используя набранный текст как направление. В чатах Conversation это действие скрыто. |

Если включено одно действие, его кнопка стоит рядом с **Send**. Если больше одного, они сворачиваются в кнопку с тремя точками (**Quick replies**), которая открывает меню.
