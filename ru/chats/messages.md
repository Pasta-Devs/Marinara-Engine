# Действия с сообщением: редактирование, удаление, свайпы, повторная генерация

У каждого сообщения – и вашего, и ответа ИИ – есть панель действий. С ее помощью отдельное сообщение можно отредактировать, удалить, сгенерировать заново, скрыть или создать от него ветку.

Панель появляется, когда вы касаетесь сообщения на телефоне или планшете либо наводите на него курсор на компьютере.

## Панель действий сообщения

Чаще всего нужны такие кнопки:

- **Edit** (редактировать) меняет текст сообщения.
- **Regenerate** (сгенерировать заново) просит модель написать новую версию ответа ИИ. Каждая такая версия называется свайпом.
- **Delete** (удалить) удаляет сообщение.

Кнопки показаны иконками. Их подписи приведены ниже. Некоторые кнопки появляются только в определенных ситуациях.

| Кнопка | Что делает |
| --- | --- |
| **Copy** (копировать) | Копирует текст сообщения. |
| **Edit** | Открывает сообщение для редактирования. |
| **Regenerate** | Создает новый свайп (еще одну версию ответа). Только на сообщениях ИИ, а также на ваших сообщениях в Roleplay и на ваших сообщениях от Impersonate в Conversation. |
| **Delete** | Удаляет сообщение. |
| **Translate** (перевести) / **Hide translation** (скрыть перевод) | Переводит сообщение на ваш язык, а затем скрывает перевод. |
| **Add reaction** (добавить реакцию) | Открывает выбор эмодзи. Только в Conversation. |
| **Hide from AI** (скрыть от ИИ) / **Unhide from AI** (показать ИИ снова) | Перестает отправлять это сообщение модели или возобновляет отправку. В групповом чате Roleplay открывает выбор персонажей. |
| **Bookmark, pin or note** (закладка, закрепление или заметка) | Добавляет сообщение в закладки, закрепляет его, чтобы оно оставалось в промпте и за пределом истории (до 10 на чат), или добавляет **Private note** (личную заметку). Модель никогда не видит заметку, если вы не включите **Show the note to the narrator character** (показывать заметку персонажу-рассказчику); это работает в чатах с одним персонажем и в групповых чатах с отдельными ответами. |
| **Branch from here** (создать ветку отсюда) | Копирует чат до этого сообщения в новую ветку. Нет в чатах сцен. |
| **Clone from here** (клонировать отсюда) | Копирует чат сцены до этого сообщения в новый чат Roleplay. Только в чатах сцен. |
| **Peek prompt** (посмотреть промпт) | Показывает точный промпт для этого ответа. Только на последнем сообщении ИИ. |
| **Stored guidance** (сохраненное направление) | Показывает направление, которое задало этот ответ. Только для ответов, созданных по направлению или через Impersonate. |
| **View model thoughts** (посмотреть размышления модели) | Открывает скрытые рассуждения модели. Только если модель вернула рассуждения. |
| **Show original before rewrite** (показать текст до правки) / **Show rewritten version** (показать исправленный вариант) | Переключает между исходным и переписанным текстом, когда агент (помощник, который работает рядом с ответами) переписал сообщение. |
| **Mark as new start** (отметить как новое начало) | Только в Roleplay. Начинает память модели об этом чате с этого сообщения, когда включена функция Advanced Memory (долговременная память Marinara). См. [Advanced Memory](../agents/memory.md). |
| **Pause speaking** (приостановить озвучку) / **Resume speaking** (продолжить озвучку) / **Restart speaking** (озвучить заново) | Управляют озвучкой, когда синтез речи Text to Speech (голос читает сообщения вслух) включен и идет озвучка. |

Подробнее: [Peek Prompt](peek-prompt.md), [Ветки чата](branches.md), [Сцены](../roleplay/scenes.md) (чат сцены – это короткий чат Roleplay, ответвленный от другого чата), [Перевод сообщений](../integrations/message-translation.md), [Настройка синтеза речи (TTS)](../media/tts-setup.md), [Направляемая генерация и Impersonate](guided-and-impersonate.md), [личные заметки](../roleplay/getting-started.md#your-private-notes).

## Редактирование сообщения

1. Нажмите **Edit** на сообщении. Текст превратится в поле для правки.
2. Измените текст.
3. Нажмите **Save** (сохранить) или <kbd>Ctrl</kbd>+<kbd>Enter</kbd> (<kbd>Cmd</kbd>+<kbd>Enter</kbd> на Mac).
4. Чтобы выйти без сохранения, нажмите **Cancel** (отменить) или <kbd>Esc</kbd>.

Две настройки в **Settings → General → Input & Editing** (настройки → общие → ввод и правка) позволяют начать правку быстрее. Обе включены по умолчанию.

- **Up Arrow edits last message** (стрелка вверх редактирует последнее сообщение): нажмите <kbd>Up</kbd>, когда поле ввода пустое.
- **Double-click edits messages** (двойной щелчок редактирует сообщения): дважды щелкните или дважды коснитесь сообщения Roleplay.

## Удаление сообщения

1. Нажмите **Delete** на сообщении. Откроется окно **Delete message** (удаление сообщения).
2. Выберите один из вариантов.

| Вариант | Что делает |
| --- | --- |
| **Delete only this swipe (1/3)** | Убирает свайп, который вы сейчас видите. Показывается, только если свайпов больше одного. |
| **Delete all other swipes** | Оставляет свайп, который вы сейчас видите, и убирает остальные. Показывается, только если свайпов больше одного. |
| **Delete this message** | Убирает сообщение вместе со всеми его свайпами. |
| **Delete more** | Выделяет это сообщение и все сообщения ниже и открывает панель выделения. |
| **Cancel** | Закрывает окно. |

На панели выделения нажимайте сообщения, чтобы добавить их. **Select all messages above** (выделить все сообщения выше) и **Select all messages below** (выделить все сообщения ниже) расширяют выделение, **Unselect all** (снять все выделение) очищает его, а **Delete selected** (удалить выделенные) удаляет то, что осталось выделенным. Панель показывает, сколько сообщений выделено.

Системные сообщения, например строка "joined the chat", удаляются одним нажатием, без окна.

## Свайпы: альтернативные ответы

Свайп – это одна из версий ответа ИИ. В одном сообщении их может быть несколько, поэтому ответы можно сравнить и оставить тот, который нравится. Когда у сообщения два свайпа или больше, на нем появляется элемент управления свайпами. Он показывает активный свайп и общее число, например "2/4".

- **Previous swipe** (предыдущий свайп) и **Next swipe** (следующий свайп) переключают свайпы назад и вперед.
- Числовое поле переходит к нужному свайпу. Введите номер и нажмите <kbd>Enter</kbd>. Подпись поля – **Jump to swipe 1-N**.
- На самом новом свайпе кнопка "вперед" превращается в **Generate next swipe** (сгенерировать следующий свайп) и создает новый свайп.

Последний свайп удалить нельзя. Приложение сообщает "Cannot delete the last remaining swipe". Вместо этого используйте **Delete this message**.

## Повторная генерация, продолжение и повторная отправка

Эти три действия похожи, но делают разное.

| Действие | Результат |
| --- | --- |
| **Regenerate** | Новый свайп. Исходный сохраняется. На сенсорном экране приложение сначала спрашивает "Regenerate this message as a new swipe?". Когда направление задано, кнопка называется **Regenerate (guided)**. |
| `/continue` | Дописывает текст в то же сообщение, без нового свайпа. |
| **Send** с пустым полем | Новый ответ с нуля. |

### Продолжение ответа

Введите `/continue` (или `/cont`) в поле ввода и отправьте. Модель продолжит с того места, где остановился ее последний ответ.

```text
/continue
```

Marinara вставляет перед новым текстом пустую строку. Чтобы текст примыкал прямо к последнему символу, выключите **Settings → General → Responses → Add a new line before /continue text** (ответы → добавлять новую строку перед текстом /continue).

### Повтор пустой отправкой

Если последнее сообщение ваше, а поле ввода пустое, **Send** (отправить) не отправляет, а повторяет запрос. В Roleplay нажатие **Send** с пустым полем также начинает новый ход, даже если ИИ уже ответил. К предыдущему ответу оно никогда ничего не добавляет. См. [Отправка сообщений и стриминг](sending-and-streaming.md#retry-without-retyping).

## Как скрыть сообщение от ИИ

Нажмите **Hide from AI**, чтобы сообщение не попадало в промпт на следующих ходах. Вам оно по-прежнему видно, с меткой **Hidden from AI**. Нажмите **Unhide from AI**, чтобы снова его отправлять.

В групповом чате Roleplay кнопка **Hide from AI** открывает выбор аватаров. Выберите аватар группы, чтобы скрыть сообщение от всех, или одного либо нескольких персонажей, чтобы скрыть его только от них. Значок перечеркнутого глаза на сообщении показывает, кому оно не видно. В чате с одним персонажем кнопка сразу скрывает сообщение или снова показывает его.

Если скрыть сообщение от одного персонажа, он все равно получит шепот внутри этого сообщения, но не остальной текст. Скрытие от всех убирает и шепот. См. [Шепот и секреты](../roleplay/getting-started.md#whispers-and-secrets).

Чтобы скрыть диапазон сообщений, используйте `/hide` и `/unhide`. См. [Справочник слеш-команд](slash-commands.md). Нумерация сообщений начинается с 1 на первом сообщении.

Если в Advanced Memory включена опция **Decide who sees new messages** (решать, кто видит новые сообщения), в групповом чате, где персонажи отвечают по очереди, новые сообщения автоматически скрываются от отсутствующих персонажей. Ваш собственный выбор всегда важнее. См. [Кто видит новые сообщения](../agents/memory.md#deciding-who-sees-new-messages).

## Переключатели отображения сообщений

Они находятся в **Settings → Advanced → Message Tools** (дополнительно → инструменты сообщений).

| Переключатель | По умолчанию | Что показывает |
| --- | --- | --- |
| **Show message numbers** | выключено | Номер на каждом сообщении – те же номера, которые используют `/goto`, `/hide` и `/unhide`. |
| **Show token usage on messages** | выключено | Токены промпта и ответа для каждого ответа ИИ (токены – небольшие кусочки текста, которые считает модель), а также попадания в кеш и время ответа, если эти данные доступны. |
| **Show model name on messages** | выключено | Модель, которая написала каждый ответ. |
| **Show "older messages not sent" note** | включено | Пометку под ответом, например "1109 older messages not sent", когда старые сообщения не поместились в промпт. Пометки об обрезанном или пустом ответе показываются всегда. |
