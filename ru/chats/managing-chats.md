# Управление списком чатов

В панели **Chats** (чаты) слева хранятся все ваши чаты. В ней можно создавать, искать, сортировать, упорядочивать и удалять чаты.

## Список чатов и вкладки режимов

В верхней части панели расположены три вкладки режимов. На каждой вкладке видны только чаты этого режима.

| Вкладка | Режим |
| --- | --- |
| **CONVO** | Conversation: чат в стиле мессенджера. |
| **RP** | Roleplay: сцена с персонажами и отслеживанием состояния мира. |
| **GM** | Game: одиночная ролевая игра под управлением ИИ. |

В каждой строке видны название чата и аватары его персонажей. В чатах Conversation цветная точка на аватаре показывает статус персонажа. Красный значок – число непрочитанных сообщений. Строка с маленькой иконкой ветки и числом – это чат с несколькими ветками, собранными в одну строку. См. [Ветки чата](branches.md).

## Создание чата

Перед началом: добавьте хотя бы один аккаунт в **Connections** (подключения). См. [Подключение к провайдеру ИИ](../connections/connecting-to-a-provider.md).

1. Нажмите вкладку нужного режима.
2. Нажмите кнопку **+** в верхней части панели. Ее подпись – **New Conversation**, **New Roleplay** или **New Game**, в зависимости от вкладки.

Marinara создает и открывает чат. Рядом с ним открываются **Chat Settings** (настройки чата) и мастер настройки. Чат получает название **New Conversation**, **New Roleplay** или **New Game**. Если вы сохранили для Conversation или Roleplay профиль настроек по умолчанию, отмеченный звездочкой, Marinara применяет его к новому чату. См. [Профили настроек](settings-profiles.md).

Если не получилось: когда нет ни одного сохраненного аккаунта, вместо чата открывается окно **Add account** (добавить аккаунт). Выберите сервис, нажмите **Connect** (подключиться), затем выберите модель. Все шаги описаны в руководстве [Подключение к провайдеру ИИ](../connections/connecting-to-a-provider.md).

## Импорт чата

Можно импортировать историю чата в файле `.jsonl` из SillyTavern или Marinara.

1. Нажмите вкладку режима, в котором должен появиться чат.
2. Нажмите кнопку **Import** (импорт) в верхней части панели. Ее подпись – **Import SillyTavern or Marinara chat JSONL**.
3. Выберите файл `.jsonl`.

Marinara создает чат, открывает его и показывает **Imported N messages**. О форматах экспорта и массовом экспорте см. [Экспорт и импорт чатов](export-import.md).

Если не получилось: внизу экрана появляется небольшое сообщение **Import failed** с причиной. Принимаются только файлы `.jsonl`.

## Переименование чата

Название чата видите только вы. Оно не отправляется модели.

1. Откройте чат, затем откройте **Chat Settings**.
2. В **Chat Name** (название чата) нажмите на текущее название.
3. Введите новое название и нажмите <kbd>Enter</kbd> или галочку.

Как открыть панель, см. [Обзор панели Chat Settings](chat-settings.md).

## Удаление чата

1. Нажмите кнопку с корзиной в строке чата. На компьютере она появляется, когда вы наводите курсор на строку.
2. В окне **Delete Chat** (удаление чата) нажмите **Delete** (удалить).

Удаление необратимо. Оно также останавливает ответ, который еще пишется для этого чата.

Если у чата несколько веток, окно сообщает, сколько их, и предлагает два варианта:

- **Delete This Branch Only** (удалить только эту ветку) удаляет ветку, на которой вы нажали кнопку.
- **Delete All N branches** (удалить все N веток) удаляет все ветки группы.

Чтобы управлять ветками, не удаляя чат, см. [Ветки чата](branches.md).

За эти окна отвечает общая настройка приложения **Confirm before deleting** (подтверждать удаление). По умолчанию она включена. Она находится в **Settings → General** (настройки → общие).

## Папки для чатов

Папки группируют чаты внутри одной вкладки режима.

1. Откройте вкладку, на которой есть хотя бы один чат. Только тогда под вкладками появляется **New Folder** (создать папку).
2. Нажмите **New Folder**. Папка получит название **unnamed** (следующие – **unnamed 2**, **unnamed 3**).

| Что нужно | Как это сделать |
| --- | --- |
| Переименовать папку | Дважды щелкните или дважды коснитесь ее либо выделите ее и нажмите <kbd>F2</kbd>. Пустое название игнорируется. |
| Удалить папку | Нажмите кнопку с корзиной в строке папки. Если в папке есть чаты, появляется окно **Delete Folder** (удаление папки). Чаты переходят на верхний уровень и не удаляются. |
| Изменить порядок папок | Перетащите папку вверх или вниз. Меню сортировки переключится на **Custom** (свой порядок). |
| Переместить чат в папку | Перетащите строку чата на папку. На сенсорном экране сначала нажмите на чат и удерживайте примерно полсекунды. |
| Вынуть чат из папки | Перетащите его на пустое место под папками. |

Если выделено несколько чатов, перетаскивание одного перемещает все выделенные. Чаты вне папок показываются под папками.

## Поиск, сортировка и фильтр

### Поиск чата по названию

На каждой вкладке есть поле поиска. Подсказка в поле – **Search conversations**, **Search roleplays** или **Search games**. Введите слово. Поиск идет по названиям чатов, тегам и именам персонажей, но не по тексту сообщений.

### Поиск сообщения во всех чатах

1. Нажмите **Search all chats** (искать во всех чатах) – кнопку рядом с меню сортировки.
2. Введите слова для поиска.

Поиск идет по всем чатам, и его можно отфильтровать по режиму, персонажу, отправителю и дате.

В меню сортировки (**Sort chats**) есть такие варианты:

| Вариант | Порядок |
| --- | --- |
| **Custom** | Ваш порядок папок. |
| **Manual order** (ручной порядок) | Чаты в том порядке, в который вы их перетащили. С клавиатуры выделите чат и нажмите <kbd>Alt</kbd>+<kbd>Up</kbd> или <kbd>Alt</kbd>+<kbd>Down</kbd>. |
| **Recent** (недавние) | Сначала чаты с самой недавней активностью. Это вариант по умолчанию. |
| **Newest** | Сначала чаты, созданные позже всех. |
| **Oldest** | Сначала самые старые чаты. |
| **A-Z** и **Z-A** | По названию. |

Если хотя бы у одного чата на вкладке есть тег, появляется плашка **Tags (N)**. Нажмите ее, чтобы раскрыть теги, затем нажмите тег, чтобы оставить только чаты с ним. Нажмите **Clear** (очистить), чтобы снять фильтр. Добавить чату тег в этой панели нельзя.

Список показывает по 100 чатов за раз. Нажмите **Load more** (загрузить еще), чтобы увидеть следующую порцию.

## Выделение нескольких чатов

1. Нажмите кнопку с галочкой **Select chats** (выбрать чаты) в верхней части панели.
2. Нажмите на каждый нужный чат. Вместо того чтобы открывать чат, строка показывает флажок.
3. Используйте панель внизу – она показывает, сколько чатов выделено.

**Export** (экспорт) скачивает выделенные чаты одним файлом `.zip` с файлами `.jsonl`. **Delete** просит подтвердить удаление в окне **Delete Chats**, а затем удаляет их. Чтобы выйти из режима выделения, снова нажмите кнопку с галочкой. Переключение вкладки тоже снимает выделение.

## Недавние чаты на главном экране

На главном экране есть виджет **Recent chats** (недавние чаты) с вашими последними чатами. У каждого показаны название, значок режима и последнее сообщение. Нажмите чат, чтобы открыть его. Если чатов нет, в виджете написано **Your chats will show here**. См. [Виджеты главного экрана](../home/welcome.md#home-widgets).
