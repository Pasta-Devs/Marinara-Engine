# Импорт и экспорт лорбуков

Импортируйте лорбуки, чтобы перенести факты о мире из файлов, и экспортируйте их, чтобы поделиться ими или сохранить резервную копию. Это руководство описывает одиночные файлы, несколько файлов сразу и четыре формата экспорта. Лорбук – это набор заметок с ключевыми словами, которые Marinara добавляет в промпт, когда появляется подходящее слово. В других программах эта возможность называется World Info.

## Что можно импортировать

Marinara сама определяет тип файла. Оба вида – это файлы `.json`, и для импорта не нужны ни аккаунт, ни ключ API.

- Лорбук, экспортированный из Marinara. В нем сохраняются все поля и все папки.
- Файл World Info из другой программы, например World Info из SillyTavern или формат "character-book" из карточек персонажей V2. Marinara сопоставляет его поля со своими.

## Импорт лорбука

1. Откройте панель **Lorebooks** (лорбуки).
2. Нажмите иконку со стрелкой скачивания в верхнем ряду, среднюю из трех иконок. Ее всплывающая подсказка – **Import** (импорт). Иконка с плюсом – **New** (создать), а иконка с галочкой – **Select** (выбрать).
3. В окне **Import Lorebook** (импорт лорбука) коснитесь области с надписью **Drop one or more lorebook files here or click to browse** или нажмите на нее и выберите файлы `.json`. На компьютере файлы можно также перетащить на эту область. Можно выбрать сразу несколько и смешивать файлы Marinara и World Info.
4. Дождитесь результатов. Для каждого файла появляется зеленая галочка с надписью **Imported lorebook** или красная отметка с ошибкой. Если файлов несколько, итоговая строка показывает, сколько прошло успешно, а сколько с ошибкой.
5. Нажмите **Close** (закрыть). Новые лорбуки появятся в панели **Lorebooks**.

Датой создания Marinara оставляет дату из самого файла.

Если не получилось: прочитайте ошибку рядом с файлом. Файл, который не является лорбуком или поврежден, не импортируется, а остальные файлы импортируются.

## После импорта

С ключевыми словами импортированный лорбук работает сразу. Если вы пользуетесь семантическим поиском, заново постройте его векторы. См. [Семантический поиск в лорбуках](semantic-search.md).

## Экспорт лорбука

1. В панели **Lorebooks** нажмите на лорбук, чтобы открыть его.
2. Нажмите иконку экспорта в заголовке редактора, справа вверху. Ее всплывающая подсказка – **Export lorebook** (экспорт лорбука).
3. В окне **Export Lorebook** выберите формат. Браузер скачает файл.

| Формат | Что вы получаете | Для чего |
| --- | --- | --- |
| **Marinara Native** | Все поля записей и папки. Имя файла заканчивается на `.marinara.json`. | Перенос лорбука в другую установку Marinara. |
| **Compatible JSON** | Файл World Info без папок, имя заканчивается на `.json`. Часть деталей, которые есть только в Marinara, теряется. | Другие программы для ролевых игр. |
| **Markdown** | По одному заголовку `## Name` на запись со строкой `Keys:`. | Чтение и правка в текстовом редакторе. |
| **CSV** | Таблица со столбцами name, keys, content, folder, enabled, constant и probability. | Правка многих записей в табличном редакторе. |

## Экспорт нескольких лорбуков сразу

1. В панели **Lorebooks** нажмите иконку с галочкой (**Select**).
2. Отметьте каждый нужный лорбук.
3. Нажмите **Export** (экспорт) на панели внизу.

Браузер скачает `marinara-lorebooks.zip`. Массовый экспорт всегда использует **Marinara Native**, поэтому при импорте все вернется.

## Импорт записей из Markdown или CSV

В лорбук можно добавить записи из текстового файла Markdown или CSV, например из файла, который вы отредактировали после экспорта.

1. Откройте лорбук и нажмите **Import entries from Markdown or CSV** (импортировать записи из Markdown или CSV) в заголовке редактора.
2. В окне **Import entries** (импорт записей) нажмите **Choose file** (выбрать файл) или вставьте текст в поле.
3. Проверьте **Format** (формат). Marinara угадывает его по тексту.
4. Прочитайте предпросмотр. Для Markdown используйте по одному заголовку `## Name` на запись, необязательную строку `Keys: a, b`, затем текст. Для CSV используйте строку заголовков с name, keys и content и необязательными столбцами folder, enabled, constant и probability. Предпросмотр показывает, сколько записей готово, и перечисляет ошибки и предупреждения по строкам.
5. В **Import into** (куда импортировать) выберите **This lorebook** (этот лорбук) или **New lorebook** (новый лорбук). Для нового введите название в **New lorebook name** (название нового лорбука).
6. В **When an entry name already exists** (если запись с таким названием уже есть) выберите **Skip the imported entry** (пропустить импортируемую запись), **Import as a renamed copy** (импортировать как переименованную копию) или **Overwrite the existing entry** (перезаписать существующую запись).
7. Нажмите кнопку **Import**, на которой показано число записей.

Всплывающее уведомление сообщит, сколько записей добавлено, перезаписано и пропущено.

Если не получилось: кнопка остается неактивной, когда в файле есть ошибка, которая затрагивает весь файл, например нет обязательных столбцов, или когда нет ни одной корректной записи. Исправьте строки, которые перечисляет предпросмотр.
