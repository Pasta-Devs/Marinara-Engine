# Привязка лорбуков к персонажам и персонам

Привяжите лорбук к персонажу или персоне, и он будет включаться сам в нужных чатах. Лорбук можно также встроить в карточку персонажа и настроить лорбуки для одного чата. Если вы только начинаете, прочитайте [Обзор лорбуков](overview.md).

## Привязка или встраивание

| Возможность | Привязка (Assign) | Встраивание (Embed) |
| --- | --- | --- |
| Что происходит | Персонаж или персона ссылается на лорбук из вашей библиотеки. | Лорбук записывается в карточку персонажа. |
| Когда включается | В чатах с этим персонажем или персоной. | Так же, и при этом путешествует вместе с карточкой. |
| Экспортируется вместе с карточкой | Нет | Да |
| Доступно для | Персонажей и персон | Только персонажей |

Чаще всего нужна привязка. Встраивайте лорбук, только если собираетесь поделиться карточкой вместе с ним.

## Вкладка Lorebook в редакторе

Вкладка **Lorebook** (лорбук) есть и в редакторе персонажа, и в редакторе персоны.

1. Откройте персонажа или персону для редактирования.
2. Перейдите на вкладку **Lorebook**. В разделе **Lorebooks** (лорбуки) две кнопки: **New** (создать) и **Assign Lorebook** (привязать лорбук).

**New** создает лорбук, уже привязанный к этому персонажу или персоне, с категорией **Character**. **Assign Lorebook** привязывает лорбук, который у вас уже есть.

## Привязка существующего лорбука

Перед началом: окно выбора показывает только лорбуки, у которых **Category** (категория) – **Character**, и для персон тоже. Если лорбука нет в списке, откройте его, поставьте на вкладке **Overview** (обзор) в поле **Category** значение **Character** и попробуйте снова.

1. На вкладке **Lorebook** нажмите **Assign Lorebook**.
2. Введите часть названия в поле поиска.
3. Нажмите на лорбук. Появится галочка.
4. Оставьте в **Scope** (область действия) значение **All chats with** с именем или измените его (см. ниже).
5. Нажмите **Assign** (привязать).

Теперь лорбук виден в списке привязанных. Кнопка **Scope** в его строке меняет область действия, а иконка корзины убирает привязку. Нажмите на название, чтобы открыть лорбук.

Глобальный лорбук нельзя одновременно привязать. См. [Обзор лорбуков](overview.md).

### Scope

**Scope** решает, в каких чатах можно использовать привязанный лорбук. Рассматриваются только чаты с этим персонажем или с этой персоной.

| Scope | Результат |
| --- | --- |
| **All chats with** (имя) | Значение по умолчанию. Лорбук включается в каждом таком чате. |
| **Disabled for all chats** | Привязка остается, но лорбук не включается никогда. Так его можно приостановить. |
| **Specific chats** | Только чаты, которые вы отметили в списке. Чтобы сохранить, отметьте хотя бы один. |

Чтобы поменять область действия позже, нажмите **Scope** в строке, измените ее и снова нажмите **Assign**.

## Встраивание лорбука в карточку персонажа

Перед началом: сначала привяжите лорбук к персонажу (см. выше).

1. Откройте персонажа и перейдите на вкладку **Lorebook**.
2. В строке лорбука нажмите **Embed into card** (встроить в карточку).

В строке появится значок **Embedded**, и теперь записи экспортируются вместе с карточкой.

Карточка хранит один встроенный лорбук. Если он уже есть, кнопка **Embed into card** неактивна, а ее всплывающая подсказка предлагает сначала убрать текущий встроенный лорбук.

После правки привязанного лорбука нажмите **Refresh** (обновить) в его строке, чтобы перезаписать встроенную копию из текущих записей.

### Управление встроенным лорбуком

Когда в карточке есть встроенный лорбук, под списком привязанных появляются такие элементы и список его записей только для чтения.

- **Import Embedded Lorebook** (импортировать встроенный лорбук) превращает записи из карточки в обычный лорбук в вашей библиотеке, привязанный обратно к персонажу. Когда привязанная копия уже есть, кнопка называется **Reimport Embedded Lorebook**.
- **Edit Embedded Lorebook** (редактировать встроенный лорбук) открывает этот привязанный лорбук. Ваши правки сами переносятся в копию в карточке.
- **Remove from card** (убрать из карточки) удаляет встроенную копию. Отдельно привязанный лорбук остается на месте.

Многие карточки, импортированные из других программ, приходят со встроенным лорбуком. Нажмите **Import Embedded Lorebook**, чтобы получить редактируемую версию.

## Раздел Lorebooks в панели Chat Settings

У каждого чата свои настройки лорбуков.

1. Откройте чат.
2. Откройте **Chat Settings** (настройки чата).
3. Найдите раздел **Lorebooks**. Значок показывает, сколько лорбуков активно.

У каждого активного лорбука есть значок, который объясняет, почему он включен.

| Значок | Значение |
| --- | --- |
| **Chat** | Вы добавили его в этот чат. |
| **Global** | Это глобальный лорбук. |
| **Character** | Он привязан к персонажу из этого чата. |
| **Persona** | Он привязан к персоне этого чата. |

Набор активных лорбуков можно изменить только для этого чата.

- **Add Lorebook** (добавить лорбук) добавляет лорбук в этот чат. У него виден значок **Chat**.
- Иконка корзины (**Remove from chat**, убрать из чата) убирает лорбук, который вы добавили.
- Иконка зачеркнутого глаза (**Disable in this chat**, выключить в этом чате) скрывает здесь автоматический лорбук, не снимая привязку. Тогда его название зачеркнуто и стоит значок **Disabled**.
- Иконка глаза (**Enable in this chat**, включить в этом чате) снова включает его.

### Lorebook Token Budget

**Lorebook Token Budget** (лимит токенов лорбуков) ограничивает, сколько токенов текста из лорбуков может добавить этот чат. По умолчанию – 8192, а 0 означает без ограничений. Он действует поверх собственного **Token Budget** (лимит токенов) каждого лорбука. См. [Лимиты токенов и рекурсия в лорбуках](token-budgets.md).
