# Установка Marinara Engine

Это руководство помогает выбрать подходящий способ установки приложения Marinara Engine для вашего устройства. Marinara работает на вашей собственной машине, поэтому чаты и данные остаются локально. Для каждой платформы есть отдельная пошаговая инструкция – ссылки собраны в таблице.

## Выбор платформы

Выберите руководство для того устройства, на котором должна работать Marinara.

| Платформа | Руководство по установке |
|---|---|
| Windows | [Руководство по установке на Windows](installation/windows.md) |
| macOS или Linux | [Установка на macOS и Linux](installation/macos-linux.md) |
| Docker или Podman | [Запуск в контейнере (Docker / Podman)](installation/containers.md) |
| Телефон или планшет на Android | [Скачать APK](https://github.com/Pasta-Devs/Marinara-Engine/releases/latest/download/marinara-engine-android.apk) · [Руководство по установке на Android](installation/android-termux.md) |
| iPhone или iPad | [Руководство по приложению PWA для iOS / iPadOS](installation/ios-pwa.md) |

Что стоит знать до выбора:

- На **iPhone или iPad** приложение Marinara не запускает сервер само. Сервер работает на компьютере, домашнем сервере или устройстве Android. После этого вы открываете его в браузере Safari на iPhone или iPad. Об этом рассказано в руководстве по iOS.
- На **Android** приложение Marinara работает внутри **Termux**. Termux – это бесплатное приложение, которое дает Android небольшое окружение Linux. Нажмите прямую ссылку на APK, подтвердите обязательные запросы установки Android и разрешений Termux, а приложение само настроит закрытые учетные данные для localhost. Установщик никогда не просит учетные данные подписи Android или этот локальный секрет.

## Что выбрать

Если вы только начинаете и хотите обойтись минимумом настройки, подойдет один из этих вариантов:

- На **Windows** используйте **Windows installer** (установщик для Windows). Он сам все скачивает и настраивает, а еще добавляет ярлык на рабочий стол.
- На **Android** используйте ссылку **Скачать APK** выше. Откройте скачанный файл, затем нажмите в приложении **Install / Start Marinara**.
- На **macOS**, **Linux** или домашнем сервере используйте **Docker**. Приложение запускается одной командой. В образе уже есть Node.js, все зависимости и собранная копия приложения. Устанавливать Node.js и собирать приложение вручную не нужно.

Если терминал вам привычен и вы, возможно, захотите менять код, запускайте приложение из исходного кода. "Запуск из исходного кода" означает, что вы скачиваете код и собираете приложение у себя на машине. Этот путь описан в руководствах по **Windows**, **macOS и Linux** и **Android (Termux)**.

## Минимальные системные требования

- Нужен компьютер или устройство, которое может работать как сервер: Windows, macOS, Linux или Android.
- Для запуска из исходного кода нужны **Node.js** версии 24 и **Git**. Node.js запускает приложение, а Git скачивает и обновляет код. Ссылки на оба файла есть в руководствах по платформам.
- Установке через **Docker** или **Podman** Node.js не нужен. Рекомендуемый вариант с Compose все же использует Git, чтобы скачать файлы проекта. Об этом рассказано в руководстве по контейнерам.
- По умолчанию приложение работает на вашей собственной машине по этому адресу:

```text
http://127.0.0.1:7860
```

- Адрес `127.0.0.1` означает ваш собственный компьютер, а `7860` – это стандартный порт. Чтобы открыть Marinara с телефона или другого устройства в вашей сети, посмотрите про доступ по локальной сети в руководстве [Частые вопросы](FAQ.md).

## Что делать после установки

Когда приложение Marinara запущено и открыто в браузере, прочитайте [Начало работы с приложением Marinara Engine](home/welcome.md). Там разобраны первые шаги: как добавить подключение, создать или импортировать персонажа и начать чат.

Как обновлять установленное приложение позже, описано в руководстве [Обновление приложения Marinara Engine](UPGRADING.md).
