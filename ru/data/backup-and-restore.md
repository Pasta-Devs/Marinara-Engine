# Резервное копирование и восстановление Marinara

Сохраните копию данных Marinara Engine, чтобы потом вернуть ее обратно. Это пригодится перед обновлением, переездом на новое устройство или [сбросом данных](clearing-data.md).

## Какой способ выбрать

| Вариант | Что создает | Для чего нужен |
| --- | --- | --- |
| **Download Backup** | Файл `.zip` со всеми вашими данными и файлами. | Одна полная копия всего. |
| **Export Profile** | Файл поменьше с данными вашего аккаунта (персонажи, чаты, лорбуки и другое). | Копия без секретов или файлы для других инструментов. |

`.zip` – это один файл, в котором лежит много файлов. Оба варианта находятся в разделе **Settings → Advanced → Backup & Export** (настройки → расширенные → резервная копия и экспорт). Восстановление находится в разделе **Settings → Imports → Profile & Marinara** (импорт → профиль и Marinara).

**Перед началом.** На компьютере, где запущена Marinara, эти инструменты работают сразу. С телефона, планшета или любого другого устройства сначала задайте на сервере секрет администратора и введите то же значение в **Settings → Advanced → Admin Access**. Секрет администратора – это пароль в файле `.env` сервера, параметр `ADMIN_SECRET`. См. раздел "Privileged APIs (ADMIN_SECRET)" в [справочнике настроек сервера](../CONFIGURATION.md) и руководство [Удаленный доступ](../REMOTE_ACCESS.md).

## Скачивание резервной копии

1. Откройте **Settings → Advanced**.
2. В разделе **Backup & Export** нажмите **Download Backup**. Пока идет работа, на кнопке видно **Creating backup…**.
3. Сохраните файл, когда браузер предложит, или найдите его в папке загрузок.

В файле `.zip` лежат:

- ваши сохраненные текстовые данные (персонажи, чаты, лорбуки, пресеты, подключения, настройки);
- загруженные и созданные вами файлы: аватары, спрайты, фоны, изображения галереи, шрифты, свои эмодзи и стикеры, а также свой звук уведомления;
- файл `.encryption-key`, если он есть;
- заметка `RESTORE.txt` о том, как восстановить файлы вручную (см. [Восстановление вручную](#restore-by-hand)).

Названия папок см. в руководстве [Где Marinara хранит ваши данные](where-data-is-stored.md).

> **Предупреждение:** в резервной копии лежат ваши сохраненные ключи API и файл `.encryption-key`, который их открывает. Никому не передавайте ее. Храните ее в закрытом месте.

На Android папка данных приложения недоступна, поэтому **Download Backup** – единственный способ вынести копию с устройства.

Если не получилось: при сообщении "Backup preparation timed out after one hour." повторите попытку. Если с другого устройства скачать не удается, проверьте **Admin Access** (см. выше).

## Автоматические резервные копии

Marinara может сама делать полную копию по расписанию на компьютере, где она запущена.

1. Откройте **Settings → Advanced → Backup & Export**.
2. Включите **Automatic backups**.
3. Выберите **Daily**, **Weekly** или **Monthly**.
4. Задайте **Automatic backups kept** от 1 до 9999.

Первую копию Marinara создает вскоре после включения. После каждого запуска она хранит заданное число самых новых копий и удаляет более старые автоматические. Копии, которые вы сделали кнопкой **Download Backup**, она никогда не удаляет.

Автоматические копии лежат в папке `backups/` внутри папки данных. Самая новая называется `marinara-automatic-backup.zip`. У более старых в имени есть дата и время. Формат тот же, что у **Download Backup**.

Каждому запуску нужно свободное место еще для одного полного архива, потому что старый архив остается, пока не будет готов новый. Если места не хватает, Marinara пропускает запуск и показывает причину рядом с настройкой. Когда место освободится, она повторит попытку.

> **Совет:** держите вторую копию вне папки данных. Если диск выйдет из строя или приложение будет стерто, автоматические копии тоже пропадут.

## Экспорт профиля

1. Откройте **Settings → Advanced → Backup & Export**.
2. Нажмите **Export Profile**. Откроется окно с тем же названием.
3. Выберите формат.
4. Браузер скачает файл.

- **Marinara Native** сохраняет ваших персонажей, персоны, чаты, лорбуки, пресеты, агентов, темы и код Personal Extension, а также медиафайлы. Ключи API, ссылки вебхуков и некоторые настройки чатов не восстанавливаются (см. [Снова введите ключи](#enter-your-keys-again)). Такой файл можно восстановить в Marinara.
- **Compatible JSON** создает `.zip` из простых файлов персонажей, персон и лорбуков для других инструментов. В Marinara его восстановить нельзя.

Профиль в родном формате скачивается как `marinara-profile.json`. Если он слишком большой, Marinara предлагает вместо него файл ZIP. Нажмите **Export ZIP**, чтобы скачать `marinara-profile.zip`.

Профиль в родном формате хранит код Personal Extension, но не то, включено ли расширение и одобрено ли оно. Каждое восстановленное расширение приходит выключенным. Проверьте его заново в **Settings → Addons**.

## Восстановление через Import Profile

**Import Profile** загружает файл профиля или архив из **Download Backup** (`.zip`).

1. Откройте **Settings → Imports**.
2. В разделе **Profile & Marinara** нажмите **Import Profile (JSON/ZIP)**.
3. Выберите `marinara-profile.json`, `marinara-profile.zip` или `.zip` резервной копии. Пока идет проверка, на кнопке видно **Scanning Profile...**.
4. Прочитайте окно **Import Profile**. В нем перечислено то, что нашла Marinara, и есть предупреждения, которые нужно прочитать до импорта.
5. Нажмите **Import** или **Cancel**, чтобы остановиться. На кнопке видно **Importing Profile...**, рядом идет полоса прогресса. Когда импорт закончится, сообщение сообщит, что профиль импортирован.

Если не получилось:

- Если вы не открыли Marinara по адресу `localhost`, `127.0.0.1` или `[::1]`, для импорта профиля нужен HTTPS. Ошибка выглядит так: "Profile import requires HTTPS outside local development." Откройте Marinara по адресу HTTPS.
- Если в `.zip` не хватает части медиафайлов, импорт все равно доходит до конца. Предупреждение перечисляет то, чего нет, а Marinara импортирует остальное.

Если вы дважды импортируете один и тот же профиль, Marinara обновляет ваши элементы и не создает копии. Профили из куда более старых версий могут создать дубликаты.

## Снова введите ключи

**Import Profile** никогда не возвращает ключи API и ссылки вебхуков, даже из архива **Download Backup** `.zip`. Ключ API – это секретный код, который вам выдает сервис. В файле профиля и в профиле внутри резервной копии эти значения пусты. Поэтому после импорта на новом компьютере введите их снова:

1. Откройте **Connections** (подключения) на верхней панели.
2. Откройте каждый используемый аккаунт, введите его ключ API и сохраните. См. [Подключение к провайдеру ИИ](../connections/connecting-to-a-provider.md).
3. Введите ссылку вебхука в каждом своем инструменте, где она нужна.

Некоторые настройки с адресами или ключами (Discord, DeepL, Intiface) тоже не возвращаются. Введите их снова в **Chat Settings** (настройки чата) каждого чата.

Импорт никогда не стирает ключи, которые уже есть в этой же установке.

## Перенос на новый компьютер

1. Установите Marinara на новом компьютере и запустите ее. См. [Установка](../INSTALLATION.md).
2. Откройте **Settings → Imports → Profile & Marinara** и нажмите **Import Profile (JSON/ZIP)**.
3. Выберите архив **Download Backup** или файл профиля, затем нажмите **Import**.
4. Введите ключи API снова, как описано выше.

Ключ из резервной копии помогает, только если вы копируете всю папку данных вручную, как ниже.

## Восстановление вручную

Используйте это, только если **Import Profile** применить нельзя. Внутри `.zip` лежит одна папка, например `marinara-backup-...`, с заметкой `RESTORE.txt`.

1. Остановите Marinara.
2. Распакуйте резервную копию.
3. Скопируйте папки и файл `.encryption-key` из распакованной папки в вашу папку данных. См. [Где Marinara хранит ваши данные](where-data-is-stored.md).
4. Запустите Marinara.

Храните файл `.encryption-key` рядом с папкой `storage`, иначе сохраненные ключи API нельзя будет прочитать.

Список **Existing backups** в разделе **Backup & Export** обычно пуст. Он вам не нужен.
