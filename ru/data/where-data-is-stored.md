# Где Marinara хранит ваши данные

В этом руководстве вы узнаете, где приложение Marinara Engine хранит данные на вашем компьютере. Речь пойдет об основной папке данных, о папке `storage` и папках с ресурсами внутри нее, а также о файле с ключом шифрования, который защищает сохраненные ключи API.

Marinara Engine (далее – Marinara) работает на вашем собственном компьютере. Сохраненные персонажи, чаты и настройки остаются только на нем. Но помните: при генерации ответа Marinara все равно отправляет содержимое чата провайдеру ИИ, к которому вы подключились.

## Папка данных (DATA_DIR)

Все, что вы создаете в приложении Marinara, лежит в одной папке на компьютере, где запущен сервер. Она называется папкой данных. На нее указывает переменная окружения `DATA_DIR`. Переменная окружения – это значение, которое задается на сервере вне приложения. В панели **Settings** (настройки) вы его не найдете.

По умолчанию папка данных – это папка `data`, которую Marinara создает рядом с файлами сервера. Если Marinara запущена в официальном контейнере Docker, папка данных находится по пути `/app/data` внутри контейнера.

Если непонятно, где находится папка данных, посмотрите журнал сервера при запуске. При старте Marinara выводит строку, которая начинается с `[storage] DATA_DIR=`, а за ней идет полный путь к папке данных.

Папку данных можно перенести в другое место, задав `DATA_DIR` самостоятельно. Как это сделать, см. [Настройки сервера: справочник](../CONFIGURATION.md). Новое значение `DATA_DIR` вступает в силу только после перезапуска Marinara.

## Папка `storage` и папки с ресурсами

Внутри папки данных все разделено на папку `storage` и несколько папок с ресурсами.

В папке `storage` лежат текстовые данные: персонажи, чаты, сообщения, лорбуки, пресеты и подключения. Marinara сохраняет каждую таблицу в небольших файлах, сгруппированных по владельцу, например сообщения одного чата или записи одного лорбука. Поэтому изменение одного элемента не требует перезаписывать постоянно растущий общий JSON-файл. При однократном обновлении старого хранилища Marinara сохраняет исходные файлы таблиц рядом с новыми папками с суффиксом `.pre-shard`.

Изображения, звук и другие медиафайлы лежат в отдельных папках, каждая из которых названа по своему содержимому. Основные папки с ресурсами:

| Папка | Что в ней лежит |
| --- | --- |
| `avatars` | Аватары персонажей и персон |
| `sprites` | Спрайты персонажей |
| `backgrounds` | Загруженные вами фоны чата |
| `gallery` | Изображения галереи |
| `fonts` | Добавленные вами шрифты |
| `knowledge-sources` | Файлы, загруженные для агентов знаний |
| `game-assets` | Ресурсы режима Game Mode |
| `custom-emojis` | Собственные изображения эмодзи |
| `custom-stickers` | Собственные изображения стикеров |

Более подробное техническое описание того, как работает папка `storage`, разработчики найдут в руководстве [Файловое хранилище](../development/file-storage.md).

## Файл с ключом шифрования

Marinara шифрует сохраненные ключи API, чтобы они не лежали открытым текстом. Ключ, которым выполняется это шифрование, хранится в файле `.encryption-key` внутри папки данных.

Этот файл важен при переносе и восстановлении данных. Допустим, вы скопировали папку данных на новый компьютер, а файл `.encryption-key` оставили на старом. Тогда Marinara больше не сможет расшифровать сохраненные ключи API, и их придется вводить заново. Всегда держите этот файл вместе с остальными данными.

В некоторых продвинутых конфигурациях ключ передается через переменную окружения `ENCRYPTION_KEY`, а не через файл. Если используется эта переменная, храните ее значение в надежном месте отдельно. Тогда файла `.encryption-key` для копирования просто нет. Подробности – в руководстве [Настройки сервера: справочник](../CONFIGURATION.md).

## Где мои данные на Android

На Android папка данных сервера обычно лежит в хранилище приложения, куда без прав root не попасть. Поэтому просто скопировать ее с телефона не получится.

Чтобы получить копию данных на Android, нажмите кнопку **Download Backup** (скачать резервную копию). Она находится в панели **Settings**, на вкладке **Advanced**, в разделе **Backup & Export**. Так создается один архив ZIP с вашими данными. Файл `.encryption-key` тоже попадает в архив, если он есть. Это самый надежный способ сохранить данные с телефона.

Этот же раздел может хранить от 1 до 9999 сменяющих друг друга автоматических архивов – ежедневных, еженедельных или ежемесячных – в папке `backups/` внутри
папки данных. Самый свежий называется `marinara-automatic-backup.zip`, а у сохраненных более старых автоматических архивов в имени стоит отметка времени.
Этот предел действует только на автоматические резервные копии. Важные копии храните еще и вне хранилища приложения, потому что
при удалении или сбросе приложения могут пропасть и текущие данные, и локальные автоматические копии.

Полные шаги резервного копирования и восстановления на всех платформах описаны здесь: [Резервное копирование и восстановление Marinara](backup-and-restore.md).
