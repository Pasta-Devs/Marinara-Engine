# Где Marinara хранит ваши данные

Найдите папку, в которой Marinara Engine хранит ваши данные, и узнайте, что нужно сохранить при переносе или копировании.

Marinara работает на вашем компьютере и сохраняет на нем ваших персонажей, чаты и настройки. Когда вы генерируете ответ, Marinara все равно отправляет содержимое чата провайдеру ИИ, к которому вы подключились.

## Как найти папку данных

Все, что вы создаете, лежит в одной папке на компьютере, где работает сервер. Это папка данных. Ее параметр – `DATA_DIR`, значение, которое вы задаете серверу до запуска (переменная окружения). В **Settings** (настройки) его нет.

- По умолчанию это папка `data` рядом с файлами сервера.
- В официальном контейнере Docker это `/app/data`.
- Чтобы увидеть точный путь, посмотрите на окно, в котором вы запустили Marinara (терминал или консоль). При запуске Marinara выводит строку, которая начинается с `[storage] DATA_DIR=`, а за ней идет путь. Если вы не можете найти это окно, поищите папку `data` внутри папки Marinara.

Чтобы перенести папку, задайте `DATA_DIR` и перезапустите Marinara. См. [справочник настроек сервера](../CONFIGURATION.md).

## Что внутри

Ваши текстовые данные лежат в папке `storage`: персонажи, чаты, сообщения, лорбуки, пресеты и подключения. Marinara сохраняет их во множестве небольших файлов. После обновления со старой структуры в `storage/tables/` могут остаться старые копии с именами, которые заканчиваются на `.pre-shard`. Marinara их никогда не удаляет. Когда все заработает, вы можете удалить их сами, чтобы освободить место.

Ваши изображения, звук и другие файлы лежат в отдельных папках рядом с `storage`. Названия папок такие:

| Папка | Что в ней лежит |
| --- | --- |
| `avatars` | Аватары персонажей и персон |
| `sprites` | Спрайты персонажей |
| `avatar-models` | Файлы для агентов **2D Avatars** и **3D Avatars**, например картинки PNGTuber и 3D-модели |
| `backgrounds` | Загруженные вами фоны чата |
| `gallery` | Изображения галереи |
| `fonts` | Добавленные вами шрифты |
| `knowledge-sources` | Файлы, загруженные для агентов знаний |
| `game-assets` | Ресурсы режима Game Mode |
| `game-scene-videos` | Видео сцен режима Game Mode |
| `conversation-call-character-videos` | Видео персонажей для звонков Conversation |
| `custom-emojis` | Собственные изображения эмодзи |
| `custom-stickers` | Собственные изображения стикеров |
| `notification-sounds` | Ваш собственный звук уведомления |
| `long-term-memory` | Данные агента долговременной памяти |
| `lorebooks/images`, `prompts/images`, `agents/images`, `connections/images` | Изображения, прикрепленные к лорбукам, пресетам, агентам и аккаунтам |

В папке данных также лежат `backups/` (ваши [автоматические резервные копии](backup-and-restore.md#automatic-backups)) и файл ключа шифрования. **Download Backup** включает каждую папку из таблицы, `storage` и файл ключа. Разработчики могут прочитать руководство [Файловое хранилище](../development/file-storage.md).

## Сохраните файл с ключом шифрования

Marinara шифрует ваши сохраненные ключи API. Ключом для этого служит файл `.encryption-key` в папке данных.

Если вы скопируете данные на новый компьютер без этого файла, Marinara не сможет прочитать сохраненные ключи API. Вам придется ввести их заново. Копируйте его вместе с остальной папкой данных.

В некоторых конфигурациях ключ передается через переменную окружения `ENCRYPTION_KEY`. Тогда файла для копирования нет. Храните это значение в надежном месте отдельно. См. [справочник настроек сервера](../CONFIGURATION.md).

## Копирование данных с Android

На Android папка данных лежит в хранилище приложения, куда без прав root не попасть, поэтому скопировать ее нельзя. Используйте **Settings → Advanced → Backup & Export → Download Backup** (настройки → расширенные → резервная копия и экспорт → скачать резервную копию). Файл `.zip` включает `.encryption-key`, если он есть. См. [Резервное копирование и восстановление Marinara](backup-and-restore.md).

Автоматические резервные копии сохраняются в том же хранилище приложения. Удаление или сброс приложения может стереть их вместе с живыми данными, поэтому держите копию в другом месте.
