# Импорт данных из SillyTavern

Перенесите данные SillyTavern в Marinara Engine. Импортируйте файлы по одному или просканируйте всю папку SillyTavern и импортируйте все сразу.

## Что можно перенести

| Данные SillyTavern | В Marinara |
| --- | --- |
| Персонажи | Персонажи |
| Чаты и групповые чаты | Чаты |
| Пресеты | Пресеты (сохраненный набор настроек генерации) |
| World Info | Лорбуки (заметки, которые ИИ читает, когда встречаются определенные слова) |
| Фоны | Фоны чатов |
| Персоны | Персоны (профиль, который представляет вас) |

## Быстрый импорт отдельных файлов

1. Откройте **Settings → Imports** (настройки → импорт).
2. В разделе **SillyTavern Import** нажмите кнопку для вашего типа файла.
3. Выберите файл.

| Кнопка | Файл |
| --- | --- |
| **Import Character (JSON/PNG)** | Карточка персонажа `.json` или `.png`. |
| **Import Chat (JSONL)** | Журнал чата `.jsonl` (одна запись JSON на строку – формат, в котором SillyTavern сохраняет чаты). |
| **Import Preset (JSON)** | Пресет `.json`. |
| **Import Lorebook (JSON)** | Файл World Info `.json`. |

У кнопок нет параметров. Импорт персонажа сохраняет все теги источника и ограничивает скрипты регулярных выражений этим персонажем. Скрипт регулярного выражения – это правило поиска и замены текста. Чтобы выбрать эти параметры, используйте **Import** в панели Characters. См. [Импорт и экспорт карточек персонажей](../characters/import-export.md).

Если в карточке персонажа есть лорбук, браузер спросит, нужно ли импортировать его как отдельный лорбук. Нажмите **OK**, чтобы сохранить его как лорбук для повторного использования, или **Cancel**, чтобы импортировать только персонажа.

**Import Chat (JSONL)** создает чат Roleplay, если файл не указывает другой режим, и открывает его.

### Импорт чата в выбранный режим

Чтобы выбрать режим, используйте кнопку импорта над списком чатов. Ее всплывающая подсказка – **Import SillyTavern or Marinara chat JSONL**. Чат импортируется в режим, вкладка которого открыта (Conversation, Roleplay или Game). См. [Экспорт и импорт чатов](../chats/export-import.md).

## Импорт папки SillyTavern

Перед началом: мастер настройки читает файлы на компьютере сервера. Если SillyTavern стоит на другом компьютере, сначала скопируйте его папку (ту, в которую вы установили SillyTavern) на компьютер с Marinara. На компьютере с Marinara мастер работает сразу. С другого устройства задайте секрет администратора и введите его в **Settings → Advanced → Admin Access**. См. [Резервное копирование и восстановление Marinara](backup-and-restore.md) и раздел "Privileged APIs (ADMIN_SECRET)" в [справочнике настроек сервера](../CONFIGURATION.md).

1. Откройте **Settings → Imports → SillyTavern Import**.
2. Нажмите **Import from SillyTavern Folder**.
3. Выберите папку SillyTavern. Укажите основную папку, обычно ту, в которой лежит папка `data/` или `public/`. Есть такие способы:
   - Нажмите **Browse** и выберите папку.
   - Если окна выбора папки нет (удаленный сервер), открывается встроенный обзор папок. Он показывает только папки внутри домашней папки пользователя, от имени которого работает сервер. Нажмите **Select This Folder**.
   - Введите путь в поле **SillyTavern Folder Path**, например `/path/to/SillyTavern`. Введенный путь работает, только если настройка сервера `IMPORT_ALLOWED_ROOTS` перечисляет папку, которая его содержит.
4. Нажмите **Scan Folder**. Marinara покажет, сколько элементов нашла в каждой категории.
5. На экране **Choose exactly what to import** отметьте нужные элементы. У каждой категории есть кнопки **All** и **None** и переключатель **Show** или **Hide** для отдельных элементов.
6. Нажмите **Import Selected**. Полоса прогресса показывает текущий элемент и счетчик по каждой категории.
7. Когда появится **Import complete!**, прочитайте счетчик по каждой категории и нажмите **Done**.

Большинство элементов отмечено заранее. Стандартные пресеты SillyTavern, такие как `deterministic`, `neutral` и пресеты `universal-*`, Marinara оставляет без флажка, и плашка сообщает об этом. Не отмечайте их, если вам не нужны их копии.

Если при сканировании нашлись персонажи, появляются еще два параметра:

**Imported character tags** (по умолчанию **All tags**):

- **All tags** сохраняет теги источника.
- **No tags** пропускает их.
- **Existing only** сохраняет только теги, которые у вас уже есть.

**Imported regex scripts** (по умолчанию **Character only**):

- **Character only** применяет скрипты к каждому персонажу.
- **Global** добавляет их в **Presets → Regexes** для всех чатов.

Если не получилось:

- "Could not find SillyTavern data directory." означает, что Marinara не может прочитать эту папку. Выберите основную папку SillyTavern.
- "folderPath is not allowed" означает, что сервер отклонил путь. Нажмите **Browse** и выберите папку. Владелец сервера может ограничить папки для импорта настройкой `IMPORT_ALLOWED_ROOTS`. Если она задана, даже выбранная папка должна лежать внутри одной из этих папок. Спросите того, кто держит сервер, или см. [справочник настроек сервера](../CONFIGURATION.md).
- Если один элемент не импортируется, Marinara пропускает его, продолжает работу и перечисляет его в предупреждениях на последнем шаге, например `Character "Foo": error message`.

## Что происходит с вашими данными

- Файлы чатов одного персонажа импортируются как ветки одного чата. Ветка – это копия чата, которую вы продолжаете отдельно.
- Групповые чаты импортируются как чаты Roleplay.
- Импортированные элементы сохраняют дату последнего изменения исходного файла, а не дату импорта.

## Что не переносится

Мастер настройки читает только категории из первой таблицы. Другие данные SillyTavern, например общие настройки приложения и быстрые ответы, не импортируются.
