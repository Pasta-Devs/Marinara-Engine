# Сражения (Roleplay)

Сражение дает сцене Roleplay пошаговый экран боя с полосами здоровья, списками противников и отряда и журналом боя. Это необязательная возможность. Чат без нее работает как раньше. В режиме Game Mode есть своя, отдельная система боя: см. [Game Mode: бой](../game/combat.md).

## Включение боя

Агент – это помощник, который работает рядом с ответами. Агент **Combat** (бой) добавляет возможность сражений. По умолчанию он выключен, поэтому его включают отдельно в каждом чате.

1. Откройте чат. Откройте **Chat Settings** (настройки чата) кнопкой с ползунками в чате.
2. Перейдите в **Agents** (агенты).
3. Включите **Enable Agents** (включить агентов), если этот переключатель выключен.
4. Добавьте агента **Combat** из списков под переключателем.

Теперь над полем ввода сообщения появляется кнопка **Encounter** (сражение) со скрещенными мечами. Ее всплывающая подсказка: **Start Combat Encounter**.

Если не получилось: если кнопки нет, агент **Combat** в этом чате не активен. Как работают агенты, см. в руководстве [Агенты: помощники ИИ в чатах](../agents/agents-overview.md).

## Начало сражения

1. Нажмите **Encounter**. Откроется окно **Configure Combat Narrative**. Оно задает стиль изложения, которым пишет ИИ.
2. Выберите стиль для **Combat Narration** (пока идет бой) и для **Summary Narration** (сводка, которая попадает в чат, когда бой заканчивается). В обеих группах одни и те же четыре настройки, они перечислены ниже. Значения по умолчанию подходят, поэтому можно сразу нажать **Begin Combat** (начать бой).
3. Необязательно: выберите **Spellbook** (книга заклинаний). Книга заклинаний – это лорбук (сохраненный набор фактов о мире), где перечислены заклинания и способности, доступные в бою. Если вы ее не используете, оставьте **None** (нет).
4. Нажмите **Begin Combat**. Нажмите **Cancel** (отмена), чтобы закрыть окно без боя.

Пока ИИ создает противников, ваш отряд, их атаки и предметы, вы видите "Initializing combat encounter...". Это может занять несколько секунд.

| Настройка стиля | Варианты |
| --- | --- |
| Время | **Present Tense** (настоящее), **Past Tense** (прошедшее) |
| Лицо | **First Person** (первое), **Second Person** (второе), **Third Person** (третье) |
| Повествование | **Omniscient**: рассказчик знает всё. **Limited**: рассказчик знает то, что знает один персонаж. |
| Точка зрения | Текстовое поле: чьими глазами показана сцена. Оставьте его пустым, чтобы рассказчик был нейтральным. |

## Ваш ход

Экран **Combat Encounter** состоит из четырех частей:

- **Enemies**: карточки с полосой здоровья и эффектами состояния.
- **Party**: ваша сторона. Ваш собственный персонаж отмечен как **(You)**.
- **Combat Log**: запись каждого хода.
- **Your Actions**: ваши кнопки.

В свой ход выберите атаку в **Attacks**, примените предмет из **Items** или впишите произвольное действие в **Custom Action** и отправьте его, например "Бросаю песок в глаза стражнику".

Когда действию нужна цель, открывается окно **Select Target** (выбор цели). Выберите одного противника или союзника либо **All Enemies** (все противники) для удара по площади. Действия, которые работают только по площади, пропускают этот шаг.

Пока ИИ просчитывает ход, вы видите "Processing action...", а ваши кнопки заблокированы. Они разблокируются, когда ход завершится.

Если не получилось: если ИИ вернет данные, которые приложение не может прочитать, появится экран **Combat Error**. Нажмите **Close Encounter** (закрыть сражение), чтобы безопасно выйти из боя, затем начните новый.

## Завершение сражения

- **Conclude** (завершить) в верхней панели заканчивает бой досрочно. Окно просит подтверждения, затем в чат пишется сводка боя.
- Кнопка **X** в верхней панели закрывает бой и отбрасывает его после окна подтверждения с заголовком **End Combat**. Сводка не пишется.
- Когда одна из сторон побеждает, на плашке появляется **VICTORY**, **DEFEAT**, **FLED** или **INTERRUPTED**. В чат пишется сводка в вашем стиле **Summary Narration**. Когда она готова, нажмите **Close Combat Window** (закрыть окно боя).

Если сводку создать не удалось, кнопка называется **Close Anyway** (все равно закрыть). Нажмите ее, чтобы вернуться к сцене без сводки.

## Чем это отличается от боя в режиме Game Mode

- Сражение в режиме Roleplay вы начинаете сами кнопкой **Encounter**. В режиме Game Mode бой начинает Game Master (ведущий игры), когда этого требует история.
- Бою в режиме Roleplay нужен агент **Combat**. Бою в режиме Game Mode он не нужен.
- У двух систем разные экраны боя.
