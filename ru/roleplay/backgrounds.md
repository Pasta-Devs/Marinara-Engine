# Фоны в режиме Roleplay

Чат Roleplay показывает изображение сцены во весь экран позади ваших сообщений. Можно поручить выбор агенту **Background** (фон), который подбирает изображение после каждого ответа, создать новое вручную или закрепить одно изображение за отдельным чатом. Когда изображение меняется, Marinara плавно переходит от старого к новому.

Генерация изображений не обязательна. Без аккаунта для генерации изображений фон – однотонный цвет, а чат работает как текстовый.

## Фон для одного чата

Так можно оставить одно изображение позади открытого чата, вместо того чтобы доверять выбор агенту. Это меняет только этот чат.

1. Откройте чат. Затем откройте **Settings → Appearance** (настройки → оформление) и найдите **Backgrounds** (фоны).
2. В блоке **Chat Background** (фон чата) выберите загруженное изображение или один из фонов ваших игровых ресурсов.

Изображение появится позади ваших сообщений. Чтобы вернуть фон по умолчанию, нажмите **Remove** (удалить) рядом с **Chat Background**.

Изображений еще нет? Сначала загрузите одно. См. [Фоны чата](../appearance/chat-backgrounds.md).

## Подбор фона агентом Background

Агент **Background** – это помощник, который работает рядом с ответами. После каждого ответа он читает текущую сцену и выбирает самое подходящее изображение из всех ваших фонов. Он выбирает только существующие изображения. Новые автоматически создает агент **Illustrator**.

1. Откройте чат Roleplay.
2. Откройте **Chat Settings** (настройки чата) кнопкой с ползунками в чате.
3. Откройте **Agents** (агенты) и включите **Enable Agents** (включить агентов).
4. Добавьте агента **Background**.

Теперь фон меняется сам, когда история переходит из одного места в другое.

Если не получилось: когда фонов только один или два, агент продолжает выбирать их. Добавьте в библиотеку больше фонов. См. [Фоны чата](../appearance/chat-backgrounds.md).

## Создание фона вручную

Marinara собирает промпт для изображения по данным сцены (жанр, мир, место, погода и время) и создает новый фон.

Перед началом: установите агента **Illustrator** и задайте для него аккаунт для генерации изображений либо отметьте один аккаунт для генерации изображений как используемый по умолчанию. См. [Подключение к провайдеру ИИ](../connections/connecting-to-a-provider.md). Добавлять Illustrator в чат не нужно.

1. Откройте **Chat Settings** кнопкой с ползунками в чате и разверните **Gallery** (галерея).
2. Нажмите **Background**. Пока идет работа, на кнопке написано **Generating...**, а в галерее видно "Illustrator is generating a background image for this scene."
3. Дождитесь окончания. Новое изображение добавляется в библиотеку фонов и применяется к сцене.

Ручная генерация использует аккаунт для изображений агента Illustrator, а затем ваш аккаунт для генерации изображений по умолчанию. Она работает в режимах Roleplay и Game, но не в Conversation.

Если не получилось: сообщение "Choose an image generation connection for the Illustrator agent, or mark one as the default image connection." означает, что Marinara не нашла аккаунт для изображений. Задайте его и попробуйте снова. Если кнопки **Background** нет, Illustrator не установлен.

## Библиотека и размытие

Изображения, из которых идет выбор, лежат в том же разделе **Backgrounds**. Импорт, теги, переименование, удаление, ползунок **Background Blur** (размытие фона) и фон по умолчанию для новых чатов Roleplay описаны в руководстве [Фоны чата](../appearance/chat-backgrounds.md).
