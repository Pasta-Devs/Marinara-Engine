# Фоны в режиме Roleplay

В этом руководстве описан фон сцены в режиме Roleplay: агент **Background** (фон), который подбирает фон после каждого ответа, создание фона вручную и закрепление одного фона за отдельным чатом. Библиотека загруженных фонов и ее настройки описаны в руководстве [Фоны чата](../appearance/chat-backgrounds.md), а изображения сцен, созданные ИИ в панели **Gallery** (галерея), – в руководстве [Фоны сцены](../media/scene-backgrounds.md).

## Фон сцены

В режиме Roleplay за сообщениями видна сцена во всю ширину экрана. При смене фона Marinara плавно растворяет старое изображение и проявляет новое, поэтому переход выглядит мягко, а не рывком.

Генерация изображений для этого не нужна. Если подключение для генерации изображений не настроено, вместо фона показывается однотонный цвет. Чат при этом работает как обычный текстовый чат.

## Агент **Background**

Агент **Background** – необязательный помощник, который сам подбирает фон сцены. Он запускается после каждого ответа. Агент читает текущую сцену и выбирает самое подходящее изображение из всех доступных фонов. Папки в библиотеке нужны только для порядка в панели **Settings** (настройки) и никогда не скрывают от агента ни один вариант. Агент выбирает только существующие изображения; автоматической генерацией фонов занимается агент **Illustrator**.

По умолчанию агент **Background** выключен. Чтобы его включить:

1. Откройте чат в режиме Roleplay.
2. Откройте **Chat Settings** (настройки чата) кнопкой в чате. Если вы ее не перемещали, она находится справа вверху.
3. Перейдите в раздел **Agents** (агенты).
4. Включите агента **Background**.

После этого фон сцены меняется сам, когда история переходит из одного места в другое.

## Создание фона вручную

Новый фон можно сделать и самостоятельно, без агента. Marinara собирает промпт для изображения (промпт – это текст, который Marinara отправляет ИИ) по данным сцены: жанру, антуражу, текущему месту, погоде и времени. Затем создается новый фон.

1. Откройте **Chat Settings** и разверните раздел **Gallery**.
2. Нажмите кнопку **Background**.
3. Дождитесь, пока кнопка закончит работу. Во время генерации на ней написано **Generating...**.

Пока идет генерация, видно примечание: "AI background generation is running. The new background will be applied when it finishes." Новое изображение добавляется в библиотеку фонов и применяется к сцене.

Ручная генерация использует подключение для изображений агента **Illustrator**, а если его нет – подключение для генерации изображений по умолчанию. Агенту **Background** подключение не нужно: он только выбирает изображения, которые уже есть в библиотеке. Если Marinara не находит подключение, генерация завершается с сообщением: "Choose an image generation connection for the Illustrator agent, or mark one as the default image connection."

Генерация фона сцены работает только в режимах Roleplay и Game Mode. В режиме Conversation она недоступна.

## Фон для одного чата

За открытым чатом можно закрепить конкретный фон, вместо того чтобы доверять выбор агенту.

1. Откройте панель **Settings**.
2. Перейдите на вкладку **Appearance** (оформление).
3. Найдите раздел **Backgrounds** (фоны).
4. В блоке **Chat Background** выберите загруженное изображение или фон из игровых ресурсов.

Чтобы вернуть фон по умолчанию, нажмите кнопку **Remove** рядом с **Chat Background**.

## Библиотека фонов и размытие

Изображения, из которых идет выбор, лежат в том же разделе **Backgrounds** в панели **Settings** на вкладке **Appearance**. Библиотеку полностью описывает руководство [Фоны чата](../appearance/chat-backgrounds.md): импорт изображений, теги, переименование, удаление, ползунок **Background Blur** и выбор фона по умолчанию для новых чатов в режиме Roleplay.
