# Prompt Overrides для изображений и видео

Prompt Overrides – это редакторы шаблонов, по которым Marinara составляет промпты для моделей изображений и видео. С их помощью можно изменить, как модели описываются портреты, селфи, спрайты, изображения сцен, раскадровки или видеоклипы.

На промпт, который уходит в вашу чат-модель, они не влияют. Для этого используйте пресет. См. [Редактор пресетов и управление промптами](presets.md) и [Параметры генерации](generation-parameters.md).

Спрайт – это изображение персонажа, например выражение лица или поза. Раскадровка – это набор кадров с иллюстрациями по одному ходу в режиме Game Mode или по завершенному эпизоду в режиме Roleplay.

Перед началом: Prompt Overrides важны только для функций, которые генерируют изображения или видео, а для них сначала нужен аккаунт генерации изображений или видео. Без него шаблон не используется никогда. См. [Провайдеры генерации изображений и их настройка](../media/image-providers.md) и [Генерация видео сцены](../media/scene-video.md).

## Где найти редакторы

1. Откройте **Settings** (настройки).
2. Нажмите вкладку **Generations** (генерации).
3. Прокрутите до раздела **Prompt Overrides** ("Reusable image and video prompt templates").

Там находятся два редактора. Нажмите на название, чтобы раскрыть редактор.

| Редактор | Какие шаблоны охватывает |
| --- | --- |
| **Video Generation Prompt Overrides** | Видео сцен в режиме Game и в галерее, видеосообщения в режиме Conversation, клипы персонажа во время звонка в режиме Conversation, анимированные портреты с выражением лица. |
| **Image Generation Prompt Overrides** | Селфи в режиме Conversation, портреты персонажей NPC в режиме Game, изображения сцен, промпты раскадровки, шаблон **Noodle Post Image** и другие сборщики изображений. |

## Изменение шаблона

1. Откройте редактор.
2. Выберите шаблон в списке **Registered prompt** (зарегистрированный промпт). Состав списка зависит от редактора.
3. Посмотрите на плашку статуса рядом со списком и прочитайте короткое описание под ним.
4. В блоке **Available variables** (доступные переменные) нажмите на плашку переменной, чтобы вставить ее. Переменные выглядят как `${charName}`.
5. Отредактируйте текст в поле **Template** (шаблон).
6. Проверьте поле **Rendered preview** (предпросмотр). Оно подставляет в ваш шаблон примерные значения.
7. Исправьте предупреждение **Unknown variables**, если оно есть. Имя, которого нет в списке **Available variables**, не подставляется.
8. Нажмите **Save** (сохранить).

Появится сообщение "Prompt override saved", а плашка сменится на **Custom active**.

| Плашка статуса | Значение |
| --- | --- |
| **Default** | Свой шаблон не сохранен. |
| **Custom active** | Используется ваш сохраненный шаблон. |
| **Custom paused** | Ваш шаблон сохранен, но выключен. |

## Как сохранить шаблон, но не применять его

Выключите переключатель **Apply this override** (применять это переопределение) под предпросмотром. Подсказка к нему гласит: "Turn this off to keep the template saved without using it." Marinara продолжает использовать встроенный шаблон, а плашка показывает **Custom paused**.

## Возврат к встроенному шаблону

Нажмите **Reset to Default** (сбросить к значениям по умолчанию). Если переопределение сохранено, Marinara попросит подтвердить действие. Плашка возвращается к **Default**.
