# Редактор пресетов и управление промптами

Пресет – это сохраненный чертеж промпта, то есть текста, который Marinara отправляет модели для каждого ответа. Он решает, что входит в промпт и в каком порядке: ваши инструкции, карточка персонажа, ваша персона, история чата, записи лорбука и многое другое. Соберите пресет в **Preset Editor** (редактор пресетов), а затем назначьте его чату.

Пресеты собирают промпт в чатах **Roleplay**. Чаты **Conversation** и **Game** вместо этого используют одно поле промпта (см. [Чаты Conversation и Game](#conversation-and-game-chats)). Пресетам не нужен ключ API, но чтобы отправить промпт, все равно нужен работающий аккаунт. См. [Подключение к провайдеру ИИ](../connections/connecting-to-a-provider.md).

## Назначение пресета чату

Пока чат не использует пресет, тот ничего не делает. В чате **Roleplay** подойдет любой из двух способов. Чтобы выбрать готовый пресет, назначьте его. Как сделать свой, см. [Создание пресета](#create-a-preset).

Из панели **Presets** (пресеты):

1. Откройте чат.
2. В панели **Presets** найдите строку пресета. На компьютере наведите курсор на строку, чтобы появились ее кнопки.
3. Нажмите кнопку с галочкой **Assign to chat** (назначить чату). Галочка показывает, что пресет используется. Нажмите ее еще раз, чтобы снять назначение.

Из **Chat Settings** (настройки чата):

1. Откройте чат, затем **Chat Settings**.
2. Найдите **Prompt Preset** (пресет промпта) и выберите пресет в раскрывающемся списке.

Если у пресета есть переменные, откроется окно **Configure Preset Variables**. См. [Переменные пресета](preset-variables.md). При переходе на другой пресет ранее выбранные значения переменных сбрасываются.

<a id="create-a-preset"></a>

## Создание пресета

1. Откройте панель **Presets** на боковой панели.
2. Нажмите **New** (значок плюса). Откроется окно **Create Preset**.
3. Впишите **Name** (название). Это поле обязательное. По желанию добавьте **Description** (описание).
4. Нажмите **Create**. Пресет откроется в **Preset Editor**.
5. Соберите промпт на вкладке **Sections**.
6. Нажмите **Save** в правом верхнем углу.

Редактор не сохраняет ничего сам. Нажимайте **Save** после каждого изменения. Если вы уходите с несохраненными правками, предупреждение предлагает **Keep editing**, **Discard** и **Save & close**.

Чтобы экспортировать пресет, нажмите значок стрелки вверх на верхней панели (всплывающая подсказка **Export preset**). Если есть несохраненные правки, Marinara сначала попросит их сохранить. Чтобы удалить пресет, нажмите значок корзины.

## Панель Presets

**Prompts** – раздел для пресетов. Другие разделы – **Regexes** и **Functions**. Кнопки сверху – **New**, **Import** (загрузить файл `.json`) и **Select** (экспортировать или удалить сразу несколько).

- **Search presets** фильтрует список.
- Меню сортировки предлагает **Manual order** (ручной порядок), **A-Z**, **Z-A**, **Newest** и **Oldest**. В режиме **Manual order** перетащите строку или нажмите <kbd>Alt</kbd>+<kbd>Up</kbd> либо <kbd>Alt</kbd>+<kbd>Down</kbd> на строке в фокусе. На сенсорном экране нажмите и удерживайте строку, чтобы взять ее.
- **New Folder** (новая папка) группирует пресеты. Перетащите пресет на папку, а чтобы переименовать папку, нажмите или коснитесь ее дважды.

В каждой строке видны название, формат обертки, число разделов и автор. Значок **DEFAULT** отмечает пресет по умолчанию, помеченный звездочкой. Нажмите строку, чтобы открыть пресет.

## Вкладки Preset Editor

| Вкладка | Что на ней |
| --- | --- |
| **Overview** | Название, описание, формат обертки и автор. |
| **Sections** | Структура промпта, собранная из блоков и маркеров. |
| **Prompts** | Промпты режимов для чатов Conversation и Game. |
| **Parameters** (параметры) | Начальные настройки генерации. См. [Параметры генерации](generation-parameters.md). |
| **Regex** | Скрипты регулярных выражений, привязанные к этому пресету, и **Scoped regex default** (ограниченный regex по умолчанию). См. [Скрипты регулярных выражений](../extending/regex-scripts.md). |

### Вкладка Overview

- **Name** – заголовок в панели **Presets**.
- **Description** – краткое описание.
- **Wrap Format** управляет тем, как оформляются разделы (см. [Форматы обертки](#wrap-formats)).
- **Author** – необязательное имя создателя, полезное, когда вы делитесь пресетом.

Две карточки только для чтения показывают счетчики **Sections** и **Groups**.

### Вкладка Prompts

- **Conversation Mode** – текстовое поле для промпта Conversation этого пресета. Оставьте его пустым, чтобы использовать встроенный промпт.
- **Roleplay Mode** здесь не редактируется. Roleplay использует промпт, собранный из ваших **Sections**.
- **Game Mode** – текстовое поле для промпта Game этого пресета. Оставьте его пустым, чтобы использовать встроенный промпт.

Встроенный **Marinara's Universal Preset** (универсальный пресет Marinara) задает текст промпта, но не параметры генерации. Его старые сохраненные настройки выборки, рассуждений, форматирования и токенов игнорируются, а вместо них действуют настройки вашего аккаунта, переопределения чата и значения приложения по умолчанию. Чтобы его настроить, создайте редактируемую копию.

## Разделы и маркеры

На вкладке **Sections** вы собираете промпт. Разделы собираются сверху вниз.

1. Нажмите **Add Section** (добавить раздел).
2. Выберите **Prompt Block** или маркер.

**Prompt Block** – это текст, который вы пишете сами: системные инструкции, правила тона, все, что должно быть в каждом промпте. У маркера нет своего текста. Marinara заполняет его актуальным содержимым чата, когда отправляет промпт.

| Маркер | Что вставляет |
| --- | --- |
| **Character Info** | Данные карточки активного персонажа. |
| **Persona** | Данные вашей активной персоны. |
| **Chat History** | Сообщения чата. |
| **Chat Summary** | Собранную сводку чата. |
| **Dialogue Examples** | Примеры реплик персонажа. |
| **Lorebook Marker (All)** | Все активные записи лорбуков. |
| **Lorebook Marker (Before)** | Записи лорбука, которые должны идти до. |
| **Lorebook Marker (After)** | Записи лорбука, которые должны идти после. |

В строке маркера показан значок **MARKER**. В большинство маркеров нельзя ничего вписать. Используйте **Lorebook Marker (All)**, если не хотите разделять записи лорбука на те, что идут до, и те, что идут после.

Три более редких маркера:

- **Current Scene Summary** и **Recalled Scenes** размещают сводки, которые создает Advanced Memory Recall. Без маркера **Recalled Scenes** они появляются перед историей чата. См. [Память](../agents/memory.md).
- **ID Macro Cards** размещает карточки персонажей, которые вы подтягиваете в промпт, вписывая ID карточки персонажа в двойных фигурных скобках. Без этого маркера они идут на место по умолчанию. См. [Макросы промптов](macros.md).

Без включенного маркера **Dialogue Examples** непустые примеры реплик добавляются в **Character Info** после сценария, в формате обертки пресета. Добавьте маркер, чтобы выбрать место вставки. Дважды Marinara их никогда не добавляет.

Если в чате есть активные лорбуки, а в пресете нет маркера лорбука, предупреждение говорит: "Add a lorebook marker when this preset should receive active lorebook entries." Добавьте маркер, чтобы записи дошли до модели. См. [Обзор лорбуков](../lorebooks/overview.md).

Если у вас есть свои агенты с включенным параметром "inject as section", в меню добавления появляется **Agent Sections**. Каждый такой раздел вставляет последний результат этого агента, а вокруг него можно дописать собственные инструкции.

### Изменение раздела

1. Нажмите название раздела или его стрелку, чтобы развернуть его.
2. Измените его **Name** или роль (**System**, **User** или **Assistant**).
3. У **Prompt Block** отредактируйте **Content** (содержимое). Оно поддерживает [макросы](macros.md).
4. Нажмите **Save** в правом верхнем углу.

Элементы управления в строке:

- **Duplicate** (дублировать) копирует раздел.
- Значок глаза включает или выключает его.
- **Delete** (удалить) удаляет его.
- Чтобы изменить порядок, перетащите раздел за ручку, воспользуйтесь стрелками вверх и вниз или долго нажмите на сенсорном экране.

### Группы

Группа объединяет несколько разделов в один контейнер.

1. На вкладке **Sections** нажмите **Groups**, затем **New Group**.
2. Нажмите название группы, чтобы переименовать ее.
3. Разверните раздел и выберите группу в его раскрывающемся списке **Group**.

С **XML** группа становится одним родительским тегом. С **MARKDOWN** она становится одним заголовком. Удаление группы не удаляет ее разделы. Они только выходят из группы.

### Позиция и глубина

У каждого раздела в его редакторе есть настройка **Position** (позиция).

- **Ordered (in sequence)** ставит раздел туда, где он находится в списке. Это обычный вариант.
- **Depth (from end of chat)** ставит раздел на заданное число сообщений выше конца чата, по числу в **Depth** (глубина). Глубина 0 означает место после последнего сообщения. Используйте это для напоминаний, которые модель должна видеть рядом с самыми новыми сообщениями.

<a id="wrap-formats"></a>

## Форматы обертки

**Wrap Format** на вкладке **Overview** задает, во что заворачивается каждый раздел.

| Формат | Результат |
| --- | --- |
| **XML** | Каждый раздел стоит в тегах. Группы становятся родительскими тегами. Это вариант по умолчанию. |
| **MARKDOWN** | Каждый раздел получает заголовок. Группы становятся заголовками более высокого уровня. |
| **NONE** | Без обертки. Содержимое отправляется так, как написано. |

XML подходит большинству моделей. Пробуйте остальные, только если модель отвечает лучше без тегов.

Чтобы отправить один **Prompt Block** без его тега или заголовка, разверните его и включите **Send without wrapper** (отправлять без обертки). Тег группы все еще может его окружать, поэтому уберите блок из группы, чтобы он ушел совсем без обертки. Маркеры всегда сохраняют свою обертку, а переключатель скрыт, когда выбран формат **NONE**.

<a id="conversation-and-game-chats"></a>

## Чаты Conversation и Game

Эти чаты не собирают промпт из разделов **Sections**. Они используют один промпт режима. В **Chat Settings** в разделе **Prompt Preset** есть раскрывающийся список **Prompt source** (источник промпта) с вашими пресетами. Изначально в нем выбрано **Default conversation prompt** или **Default game prompt**, а если пресетов нет, он показывает **No presets available**. В панели **Presets** кнопка назначения показывает "Prompt presets are not available in conversation mode."

Под списком значок показывает, откуда берется промпт.

| Значок | Значение |
| --- | --- |
| **Default** | Встроенный промпт. |
| **Preset** | Промпт выбранного пресета. |
| **Style** | Промпт выбранного стиля промпта GM. Только в чатах Game. |
| **Custom** | Правка только для этого чата. Она имеет приоритет над всеми остальными. |

Текстовое поле показывает используемый промпт. Отредактируйте его, чтобы создать копию только для этого чата. Если ваш текст в точности совпадает с пресетом или промптом по умолчанию, Marinara считает его неизмененным. Пока есть своя правка, появляется значок сброса (всплывающая подсказка **Reset to default prompt**).

В чатах Game есть еще два элемента. **GM prompt style** (стиль промпта GM) заменяет только промпт Game, а правка для этого чата по-прежнему имеет приоритет. **Extra instructions** (дополнительные инструкции) добавляет текст к промпту Game, до 2000 символов, например "Write in the style of Terry Pratchett."

<a id="decision-blocks-and-prompt-caching"></a>

## Блоки решений и кеширование промпта

Раздел может содержать блок решения `{{#if decision:"..."}}`, чтобы эта часть отправлялась, только когда утверждение о чате истинно. См. [Вопрос к модели решений](conditional-prompts.md#asking-the-decision-model).

Блоки решений, которые часто меняются, ставьте ближе к концу промпта, например в инструкции после истории. Измененная ветка может помешать провайдеру повторно использовать промпт начиная с этого места, поэтому ранняя правка лишает большей части экономии от кеша. Более ранняя неизмененная часть все равно может использоваться повторно. Оставляйте решение в начале, только если его ответ меняется редко. См. [Кеширование промпта](conditional-prompts.md#prompt-caching).

Утверждения в выключенных разделах и группах никогда не запрашиваются и не учитываются в **Decision statements per turn** (утверждения решений за один ответ).

## Как проверить, что получил ИИ

**Peek Prompt** показывает полностью собранный промпт для сообщения. Это самый быстрый способ разобраться в странном ответе. См. [Peek Prompt: посмотреть, что получила модель ИИ](../chats/peek-prompt.md).
