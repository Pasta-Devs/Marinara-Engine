# Макросы промптов

Это руководство объясняет макросы промптов в приложении Marinara Engine. Макрос – это короткий тег вида `{{tag}}`, который Marinara заменяет на текущее значение. Значение подставляется в момент сборки промпта – например, ваше имя или сегодняшняя дата. Здесь перечислены все встроенные макросы, места, где их можно писать, и типичные ошибки.

## Что такое макросы и где они работают

Макрос – это текст в двойных фигурных скобках, например `{{user}}` или `{{char}}`. Собирая текст для отправки ИИ, Marinara находит такие теги и подставляет вместо каждого его текущее значение. Отдельного переключателя для макросов нет. Любое поле, которое их поддерживает, всегда их раскрывает.

У встроенных тегов регистр в названии макроса не важен: работают и `{{user}}`, и `{{USER}}`.

Писать макросы можно во многих местах приложения:

- Поля персонажа в панели **Character Editor** (редактор персонажа): Description, Personality, Backstory, Appearance, Scenario, Example Dialogue, System Prompt, Post-History Instructions и поле **Depth Prompt**.
- Поля персоны в панели **Persona Editor** (редактор персоны) – те же поля карточки.
- Поля Description и Content в записи лорбука.
- Разделы промпта в панели **Preset Editor** (редактор пресетов).
- Поля Find, Replace и Trim в скрипте регулярного выражения.
- Шаблоны промптов агентов.
- Поле ввода сообщения. Напишите в сообщении `{{roll:1d20}}` – макрос раскроется перед отправкой.

Значение макроса может содержать другой макрос, и Marinara раскроет его тоже.

## Перед началом

Ничего настраивать не нужно. Встроенные макросы работают сразу, без ключа API и без отдельного подключения. Ключ API – это секретный код, похожий на пароль, который позволяет Marinara обращаться к провайдеру ИИ. Макросы же обрабатываются внутри приложения Marinara сами по себе.

Но две возможности зависят от других частей приложения:

- Переменные пресета (универсальный тег `{{NAME}}`) работают только с тем пресетом промпта, где они заданы. См. [Переменные пресета](preset-variables.md).
- Макрос агента `{{agent::TYPE}}` показывает текст только после того, как соответствующий агент отработал и выдал результат.

## Макросы личности, персонажа и персоны

Эти макросы подставляют имена и поля карточки того, кто пишет, и персонажа, который отвечает. Пользователь – это вы или ваша активная персона, то есть персонаж, за которого играете вы. Персонаж – это бот, который отвечает.

| Макрос | Во что раскрывается |
| --- | --- |
| `{{user}}` / `{{userName}}` | Текущее отображаемое имя (или имя персоны). Если персона не выбрана, подставляется `User`. |
| `{{userNamePhonetic}}` | Поле Phonetic name у персоны, а если оно пустое – `{{user}}`. |
| `{{char}}` / `{{charName}}` | Имя текущего персонажа. По умолчанию `Character`. |
| `{{<21-character-card-ID>}}` | Шаблон записи для имени другой карточки персонажа. Замените текст в угловых скобках на точный ID этой карточки из 21 символа. |
| `{{persona-21-character-card-ID}}` | Шаблон записи для имени другой персоны. Замените текст после `persona-` на точный ID её карточки из 21 символа, чтобы добавить контекст этой карточки. |
| `{{charNamePhonetic}}` | Поле Phonetic name у персонажа, а если оно пустое – `{{char}}`. |
| `{{characters}}` | Все персонажи чата через запятую. |
| `{{group}}` | Все остальные активные персонажи группового чата, кроме того, кто отвечает сейчас. Персона в этот список персонажей не входит. |
| `{{persona}}` | Поля Description, Personality, Backstory, Appearance и Scenario персоны, каждое с новой строки. |
| `{{personaDescription}}` | Поле Description персоны. |
| `{{personaPersonality}}` | Поле Personality персоны. |
| `{{personaBackstory}}` | Поле Backstory персоны. |
| `{{personaAppearance}}` | Поле Appearance персоны. |
| `{{personaScenario}}` | Поле Scenario персоны. |

Макросы полей персонажа читают карточку текущего персонажа:

| Макрос | Поле карточки персонажа |
| --- | --- |
| `{{description}}` | Description |
| `{{personality}}` | Personality |
| `{{backstory}}` | Backstory |
| `{{appearance}}` | Appearance |
| `{{scenario}}` | Scenario |
| `{{example}}` | Example Dialogue |
| `{{charSysInfo}}` | System Prompt |
| `{{charPostHistory}}` | Post-History Instructions |

В чате с одним персонажем они берут данные этого персонажа. В групповом чате – по умолчанию данные первого персонажа. Чтобы повторить текст для каждого персонажа, поместите его в групповой блок в квадратных скобках. О групповых блоках см. [Условные промпты](conditional-prompts.md).

`{{group}}` следует за персонажем, который отвечает сейчас, в том числе при отдельных генерациях внутри группы. Например, если в группе Roleplay есть Powers That Be, Maukie и Pantalone, а отвечает Pantalone, то `{{group}}` раскроется в `Powers That Be, Maukie`. Карточка персонажа остается в этом списке даже тогда, когда ее имя совпадает с `{{user}}`.

У поля Phonetic name две задачи. Оно задает, как имя произносит синтез речи. Оно же наполняет `{{charNamePhonetic}}` и `{{userNamePhonetic}}`. Поле есть и в **Character Editor**, и в **Persona Editor**.

Чтобы сослаться на персонажа, которого нет в текущем чате, скопируйте ID его карточки и поставьте его прямо внутри двойных фигурных скобок, например `{{V1StGXR8_Z5jdHi6B-myT}}`. Marinara заменяет макрос на имя карточки и добавляет в системный промпт контекст персонажа из указанной карточки. Приветствия и содержимое поля **Example Dialogue** этой карточки не подставляются. Включенные лорбуки, привязанные к этой карточке, по-прежнему подчиняются своим обычным правилам ключевых слов, записей **Constant**, фильтров, вероятности и лимита токенов.

Чтобы сослаться на неактивную персону, добавьте `persona-` перед скопированным ID, например `{{persona-P1StGXR8_Z5jdHi6B-myT}}`. Marinara заменит макрос на имя персоны и добавит её поля Description, Personality, Appearance, Backstory и Scenario в ID Macro Cards. Привязанные лорбуки по-прежнему подчиняются обычным правилам активации.

## Макросы режима Conversation

Эти четыре макроса работают только в режиме Conversation. Во всех остальных режимах они всегда раскрываются в пустоту – даже если один и тот же текст карточки или пресета используется в нескольких режимах.

| Макрос | Во что раскрывается |
| --- | --- |
| `{{convo_display}}` | Поле **Convo Display Name** персонажа, а если оно пустое – имя из карточки. |
| `{{char_about}}` | Текущее поле **About Me** персонажа: значение, заданное для конкретного чата, иначе значение из карточки. |
| `{{persona_about}}` | Текущее поле About Me персоны. |
| `{{convo_behavior}}` | Текст **Convo Behavior** персонажа, но только если в настройке вставки выбрано размещение по этому макросу. |

Эти поля редактируются на вкладке **Convo** в панелях **Character Editor** и **Persona Editor**. Полная настройка описана в руководстве [Профили в режиме Conversation (отображаемое имя, "about me", поведение)](../conversation/profiles.md).

## Макросы размещения в режиме Conversation

Режим Conversation сам вставляет в промпт несколько блоков. Эти макросы позволяют пресету **перенести** блок туда, где стоит макрос. Тогда Marinara выводит блок на месте макроса и **пропускает** автоматическую вставку, поэтому содержимое не дублируется. У каждого макроса есть один или несколько синонимов, и все они работают одинаково.

| Макрос (и синонимы) | Что размещает |
| --- | --- |
| `{{context}}`, `{{status}}` | Блок контекста / статуса чата. |
| `{{commands}}`, `{{commandList}}` | Напоминание о доступных командах. |
| `{{reactRules}}`, `{{emojiReact}}` | Правила **реакций** своими эмодзи. |
| `{{replyRules}}` | Правила **ответов** своими эмодзи и стикерами. |
| `{{memories}}`, `{{memoryRecall}}` | Блок **Memory Recall** (память чата). |
| `{{lorebook}}`, `{{lore}}` | Вставки из лорбуков. |

Всё это действует только в режиме Conversation. Если в чате один персонаж, то ручная расстановка описаний участников через `{{char_about}}` / `{{persona_about}}` (см. выше) работает так же: Marinara пропускает свой автоматический блок "about me" об участниках, и описания не вставляются дважды. В групповых чатах автоматический блок участников остается, потому что каждый из этих двух макросов охватывает только одного участника и не должен скрывать описания остальных.

## Макросы контекста

Эти макросы описывают текущий чат и текущий запрос.

| Макрос | Во что раскрывается |
| --- | --- |
| `{{input}}` | Последнее сообщение пользователя, доступное промпту. |
| `{{model}}` | Название текущей модели, если модель выбрана. |
| `{{chatId}}` | Идентификатор текущего чата. |
| `{{lastGenerationType}}` | Метка причины, по которой генерируется этот ответ. |
| `{{idle_duration}}` | Сколько времени прошло с последней активности в чате, в виде текста `8 minutes` или `1 hour 5 minutes`. |
| `{{gameStoryboardKeyframeCount}}` | Текущий ориентир **Keyframes per Turn** (ключевых кадров за ход) в режиме Game Mode, от 1 до 6. По умолчанию `3`. |
| `{{agent::TYPE}}` | Сохраненный результат агента указанного типа. |

`{{lastGenerationType}}` раскрывается в простую метку. В приложении встречаются, например, значения `normal`, `continue`, `regenerate`, `impersonate`, `guided`, `autonomous`, `turn_game`, `preview`, `game_setup`, `lorebook_scan` и `retry_agents`. Список может пополняться, поэтому считайте его примерами, а не закрытым перечнем.

`{{gameStoryboardKeyframeCount}}` передается в промпты GM в режиме Game Mode, включая встроенный **Storyboard Game Prompt**. Это ориентир для повествования, а не требование выдать ровно столько абзацев. Планировщик раскадровки при этом вернет меньше кадров, если в ходе слишком мало отдельных визуальных моментов.

Макрос `{{agent::TYPE}}` вставляет сохраненный результат агента – фонового помощника, который заполняет, например, трекер сцены. Проще всего добавить его в панели **Preset Editor**: нажмите кнопку **Add Section** (добавить раздел), раскройте группу **Agent Sections** и выберите агента. Marinara создаст раздел, в котором уже стоит нужный тег `{{agent::TYPE}}`. Этот макрос раскрывается последним, поэтому текст агента не может вставить в промпт новые макросы.

## Макросы outlet в лорбуках

`{{outlet::name}}` вставляет содержимое тех записей лорбука, у которых в поле **Position** выбрано **Outlet**, а поле **Outlet name** в точности совпадает с `name`. Регистр в названии outlet важен: например, `{{outlet::character_rules}}` не подходит к точке вставки outlet с названием `Character_Rules`.

Записи outlet активируются по обычным правилам лорбука. Активна ли запись для текущей генерации, решают ключевые слова, режим Constant, вероятность, фильтры, тайминг, ограничения на число записей и лимит токенов. Активные записи с одинаковым названием outlet идут в порядке поля **Order**, каждая с новой строки. Вставляются они только в месте макроса и не добавляются дополнительно на обычной позиции лорбука.

Макросы outlet можно использовать в разделах промпта в режимах Conversation, Roleplay и Game Mode. Макрос работает даже тогда, когда стоит перед маркером лорбука в пресете, а если пресет использует только записи outlet, маркер лорбука ему вообще не нужен. Неизвестная или неактивная точка вставки outlet раскрывается в пустоту. Запись outlet не раскрывает другой макрос outlet, поэтому вложенной рекурсии здесь не бывает.

## Макросы времени

Все макросы времени берут один и тот же момент за одно раскрытие, поэтому никогда не расходятся между собой. Часовой пояс берется из браузера.

| Макрос | Во что раскрывается |
| --- | --- |
| `{{date}}` | Текущая дата в формате `YYYY-MM-DD`. |
| `{{time}}` | Текущее время как `HH:MM` по 24-часовой шкале. |
| `{{datetime}}` / `{{isotime}}` | Полная отметка времени со смещением часового пояса. Оба названия означают одно и то же. |
| `{{weekday}}` | Название дня недели, например `Monday`. |
| `{{timezone}}` | Название часового пояса, например `Europe/Warsaw`. |

## Макросы случайности и кубиков

Эти макросы добавляют в промпт элемент случайности. Для чисел и выбора вариантов используйте макрос `{{random}}`, для кубиков – макрос `{{roll}}`.

| Макрос | Что делает |
| --- | --- |
| `{{random}}` | Случайное целое число от 0 до 100. |
| `{{random:X:Y}}` | Случайное целое число от X до Y включительно. |
| `{{random::A::B::C}}` | Случайно выбирает один вариант, а затем раскрывает макросы только внутри выбранного. |
| `{{random::A@2::B@0.5}}` | Случайный выбор с весами. Правила весов – ниже. |
| `{{roll:XdY}}` | Сумма броска кубиков. Например, `{{roll:2d6}}` бросает два шестигранных кубика и складывает результат. |

Простой пример случайного выбора, который можно скопировать:

```text
{{random::The door creaks open.::A bell rings.::Someone laughs nearby.}}
```

### Выбор с весами

Чтобы задать вероятность варианта, добавьте в его конец `@число`. Это относительный вес: чем он больше, тем чаще выпадает вариант.

```text
{{random::Common event@1::Rare event@0.25}}
```

В этом примере суммарный вес равен 1.25, поэтому вероятности такие:

| Вариант | Вес | Вероятность |
| --- | --- | --- |
| Common event | 1 | 80% |
| Rare event | 0.25 | 20% |

Правила весов:

- Отсутствующий вес считается равным 1.
- Вес может быть дробным – например, 0.5 или 0.01.
- Вес 0 оставляет вариант в списке, но выбрать его невозможно.
- Если у всех вариантов вес 0, макрос раскрывается в пустоту.
- Весом считается только `@число` в самом конце. Символ `@` в другом месте – скажем, в адресе электронной почты – остается как есть.

## Динамические переменные

Переменные позволяют одной части промпта сохранить значение, а более поздней – его прочитать.

| Макрос | Что делает |
| --- | --- |
| `{{setvar::name::value}}` | Сохраняет значение и не оставляет в тексте ничего. |
| `{{getvar::name}}` | Читает сохраненное значение (пустота, если оно не задавалось). |
| `{{addvar::name::value}}` | Складывает значения, если оба числовые; иначе дописывает текст. |
| `{{addnumvar::name::value}}` | Расширение Marinara, которое всегда выполняет числовое сложение. Отсутствующее или недопустимое значение считается нулём, переполнение игнорируется. |
| `{{incvar::name}}` | Прибавляет 1 к числовой переменной и вставляет новое значение. |
| `{{decvar::name}}` | Вычитает 1 из числовой переменной и вставляет новое значение. |

При сборке промпта переменные раскрываются слева направо и сохраняются в текущем чате. Значение, заданное раньше – например, в записи лорбука, которая идет первой, – можно прочитать позже в том же промпте. Как и локальные переменные в SillyTavern, оно сохраняется между следующими ходами и после перезапуска, но не попадает в другие чаты.

Любой тег `{{NAME}}`, которого нет среди встроенных макросов, считается переменной пресета и ищется по имени. Если переменной с таким именем нет, тег остается в тексте точно в том виде, в каком его написали. О том, как задавать такие переменные, см. [Переменные пресета](preset-variables.md).

## Макросы форматирования

Эти макросы меняют текст вокруг себя.

| Макрос | Что делает |
| --- | --- |
| `{{newline}}` / `{{\n}}` | Вставляет перенос строки. |
| `{{trim}}` | Убирает себя и обрезает пробелы вокруг этого места. |
| `{{trimStart}}` | Обрезает пробелы в начале окружающего текста. |
| `{{trimEnd}}` | Обрезает пробелы в конце окружающего текста. |
| `{{uppercase}}...{{/uppercase}}` | Переводит текст внутри в ВЕРХНИЙ РЕГИСТР. |
| `{{lowercase}}...{{/lowercase}}` | Переводит текст внутри в нижний регистр. |
| `{{noop}}` | Удаляется из результата. Удобен как безвредная заглушка во время правки. |
| `{{// comment}}` | Заметка автора, которая удаляется из результата. |
| `{{banned "text"}}` | Удаляется из результата. Ничего не фильтрует и не блокирует. |

## Как оставить двойные скобки в тексте

Экранирующего символа для макросов нет. Чтобы двойные скобки остались в тексте, возьмите название, которое Marinara не знает. Любой неизвестный тег `{{name}}` остается точно таким, как его написали, – при условии, что переменной пресета с таким же именем нет. Если нужна личная заметка, которая никогда не попадет к ИИ, используйте `{{// like this}}`.

## Окно **Macro reference** и команда /macros

В углу каждого поля с поддержкой макросов есть две небольшие кнопки:

- Кнопка **Expand editor** (развернуть редактор) открывает для этого поля окно побольше.
- Кнопка **Macro reference** (справочник макросов) открывает окно **Macro reference** со списком всех встроенных макросов по категориям и с точным синтаксисом каждого. Список формируется из того же источника, что использует движок, поэтому он всегда точный.

Другой вариант: написать в поле ввода `/macros` (короткая форма `/macro` тоже работает). Команда выводит полный список макросов прямо в чат – удобная шпаргалка.

Условные блоки умеют объединять сравнения через `||` (ИЛИ), `&&` (И) и круглые скобки. Для перечисления равных значений есть краткая форма `{{#if character == "Maukie" || "Pantalone"}}`. О приоритете операторов, примерах для групповых чатов и полном списке операторов см. [Условные промпты](conditional-prompts.md).

## Частые ошибки

- Не пишите переменные внутри блока `{{random::...}}`. Макрос `{{setvar}}` внутри варианта срабатывает для всех вариантов до того, как сделан выбор, а не только для выбранного.
- Не используйте локальную переменную как глобальную. Значения, заданные через `{{setvar}}`, сохраняются только в текущем чате; у каждого другого чата своё значение.
- `{{prompt}}` – не макрос. Если всё сообщение состоит из `{{prompt}}`, Marinara не отправит его, а откроет просмотр **Peek Prompt**. См. [Peek Prompt](../chats/peek-prompt.md).
- Свои инструменты (раздел **Custom Tools**) не работают с текстом `{{macro}}`. Не вставляйте `{{roll:1d20}}` в поле инструмента в расчете на раскрытие.
- Шаблон промпта **Impersonate** принимает лишь несколько подстановок, а не весь список макросов. Названия там тоже другие, поэтому макрос, который работает в карточке, здесь может не сработать.
- Очень большой или глубоко вложенный результат макроса обрезается без предупреждения. Ошибки не будет, поэтому не давайте раскрытиям разрастаться.
