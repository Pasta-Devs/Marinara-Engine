# Android (Termux) इंस्टॉलेशन गाइड

इस गाइड में बताया गया है कि Marinara Engine को Android फ़ोन या टैबलेट पर कैसे चलाएँ। Marinara, Termux के अंदर चलता है, जो Android के लिए एक मुफ़्त Linux माहौल है। सेटअप का आसान रास्ता Android ऐप है, और चाहें तो Termux टर्मिनल में हाथ से भी कर सकते हैं।

## Termux और F-Droid क्या हैं

Termux एक मुफ़्त ऐप है जो आपके फ़ोन में एक छोटा Linux सिस्टम और कमांड लाइन जोड़ देता है। Marinara Engine को इसकी ज़रूरत इसलिए है, क्योंकि Marinara एक Linux सर्वर है, कोई नेटिव Android ऐप नहीं।

F-Droid, Android के लिए एक मुफ़्त और ओपन-सोर्स ऐप स्टोर है। Marinara का अपने-आप होने वाला सेटअप Termux का स्थिर F-Droid बिल्ड डाउनलोड करता है। Termux का अलग प्रयोगात्मक Google Play बिल्ड भी है; वह पहले से इंस्टॉल हो तो Marinara उसके आधिकारिक साइनर को पहचानता है, लेकिन इस गाइड में F-Droid ही सुझाया गया तरीका है।

Termux को F-Droid से यहाँ इंस्टॉल करें: [Termux on F-Droid](https://f-droid.org/en/packages/com.termux/)। Termux या उसके प्लगइन ऐप अलग-अलग सोर्स से न मिलाएँ, क्योंकि उनके सिग्नेचर मेल खाने चाहिए। हर सोर्स की जानकारी के लिए [Termux के आधिकारिक इंस्टॉलेशन नोट](https://github.com/termux/termux-app#installation) देखें।

## Android ऐप (APK) से इंस्टॉल करना

सबसे आसान रास्ता Marinara Engine का Android ऐप है। APK यानी Android ऐप की इंस्टॉल फ़ाइल। यह ऐप एक छोटा सहायक है: यह आपके लिए Termux सेट करता है, और लोकल सर्वर चालू होते ही Marinara खोल देता है। असली काम फिर भी Termux ही करता है, इसलिए Android आपसे कुछ सिस्टम अनुमतियाँ माँगेगा। तैयार APK इंस्टॉल करने के लिए साइनिंग की, पासवर्ड, लोकल एक्सेस सीक्रेट या `CSRF_TRUSTED_ORIGINS` बदलने की ज़रूरत नहीं है। ऐप अपना निजी localhost क्रेडेंशियल अपने-आप बनाकर अदला-बदली करता है। `CSRF_TRUSTED_ORIGINS` में `null` न जोड़ें; इसे जान-बूझकर सेट न किया हुआ माना जाता है और APK हैंडशेक को इसकी ज़रूरत नहीं है।

1. [नया Android APK डाउनलोड करें](https://github.com/Pasta-Devs/Marinara-Engine/releases/latest/download/marinara-engine-android.apk) पर टैप करें।
2. APK इंस्टॉल करें, फिर ऐप खोलें।
3. **Install / Start Marinara** पर टैप करें।
4. अगर Termux अभी इंस्टॉल नहीं है, तो Android के इंस्टॉल प्रॉम्प्ट को मंज़ूरी दें ताकि ऐप Termux को F-Droid से डाउनलोड करके इंस्टॉल कर सके।
5. Android पूछे तो **Run commands in Termux environment** अनुमति दें।
6. अगर Termux सेटअप रोक देता है, तो ऐप आपके लिए एक `allow-external-apps` कमांड कॉपी कर देता है। उस कमांड को Termux में एक बार पेस्ट करें, फिर दोबारा **Install / Start Marinara** पर टैप करें।
7. Termux के डिपेंडेंसी इंस्टॉल करने और Marinara बनाने तक इंतज़ार करें। पहली बार बनने में कुछ मिनट लगते हैं।
8. Termux का काम पूरा होने पर Marinara Engine ऐप में लौटें। लोकल सर्वर तैयार होते ही ऐप अपने-आप कनेक्ट होकर साइन इन करता है।

अगर होम स्क्रीन पर ऐसा आइकन चाहिए जो Marinara को आम ऐप की तरह खोले, तो वह भी यही Android ऐप देता है। यह Termux सर्वर के ऊपर एक रैपर है, इसलिए सर्वर पहले सेट होना ज़रूरी है। यह Android के इंस्टॉल और अनुमति वाले प्रॉम्प्ट को छोड़ नहीं सकता, लेकिन आपसे Marinara का कोई इंस्टॉलेशन सीक्रेट सेट करने को नहीं कहता।

## Termux में हाथ से इंस्टॉल करना

ऐप इस्तेमाल नहीं करना चाहते तो Marinara को हाथ से भी इंस्टॉल कर सकते हैं। Termux खोलें और यह एक कमांड पेस्ट करें:

```
pkg update -y && pkg install -y git nodejs-lts && ([ -d "$HOME/Marinara-Engine/.git" ] || git clone https://github.com/Pasta-Devs/Marinara-Engine.git "$HOME/Marinara-Engine") && cd "$HOME/Marinara-Engine" && chmod +x start-termux.sh && ./start-termux.sh
```

यह एक कमांड पाँच काम करती है:

1. Termux के पैकेज अपडेट करती है।
2. Git और Node.js इंस्टॉल करती है। Marinara, Node.js के वर्ज़न 24, 25 और 26 के साथ चलता है।
3. Marinara Engine को डाउनलोड करती है, बशर्ते वह पहले से इंस्टॉल न हो।
4. लॉन्चर (`start-termux.sh` स्क्रिप्ट) को चलने लायक बनाती है।
5. लॉन्चर को पहली बार चलाती है।

लॉन्चर ऐप की डिपेंडेंसी इंस्टॉल करता है, Marinara को आपके डिवाइस पर बनाता है और लोकल सर्वर चालू करता है। आपका Node.js वर्ज़न बहुत पुराना हो तो उसे भी अपग्रेड कर देता है। पहली बार चलने में समय लगता है, क्योंकि तब ऐप बनता है। बाद की बार यह कहीं ज़्यादा तेज़ रहता है।

काम पूरा होने पर अपने Android ब्राउज़र में यह पता खोलें:

```
http://127.0.0.1:7860
```

Marinara उसी पोर्ट पर सुनता है जो `PORT` में सेट है (वह नेटवर्क पोर्ट जिसे ऐप इस्तेमाल करता है)। डिफ़ॉल्ट 7860 है। अगर आपने कोई दूसरा `PORT` सेट किया है, तो वही नंबर लगाएँ।

सुझाव: ऐप जैसा आइकन पाने के लिए ब्राउज़र का मेन्यू खोलें और वह विकल्प चुनें जो Marinara को होम स्क्रीन पर जोड़ता है। इस विकल्प का नाम हर ब्राउज़र में अलग होता है।

## Marinara को दोबारा चालू करना

पहले सेटअप के बाद इंस्टॉल दोहराने की ज़रूरत नहीं। Termux खोलें और यह चलाएँ:

```
cd Marinara-Engine
./start-termux.sh
```

लॉन्चर पहले अपडेट देखता है, फिर Marinara चालू करता है। GitHub देखे बिना अपनी मौजूदा कॉपी चलानी हो तो `--skip-update` जोड़ें:

```
cd Marinara-Engine
./start-termux.sh --skip-update
```

डिपेंडेंसी अपडेट के दौरान लॉन्चर अपने लोकल pnpm कैश से गैर-ज़रूरी पैकेज भी हटा देता है। इससे पुराने रिलीज़ जमा होकर फ़ोन में कई गीगाबाइट नहीं घेरते; Marinara की चैट, सेटिंग्स और बाकी यूज़र डेटा को यह छूता तक नहीं।

## दूसरे डिवाइस से पहुँच

डिफ़ॉल्ट रूप से लॉन्चर Marinara को आपके लोकल नेटवर्क पर उपलब्ध कर देता है। यानी उसी Wi-Fi से जुड़ा लैपटॉप या दूसरा फ़ोन इसे खोल सकता है। सही पता ढूँढने के स्टेप-दर-स्टेप निर्देश [अक्सर पूछे जाने वाले सवाल](../FAQ.md) में देखें।

## अपडेट करना

हर बार लॉन्चर (`./start-termux.sh`) चलाने पर वह GitHub पर नया वर्ज़न देखता है और चालू होने से पहले अपडेट कर देता है। इसलिए अपडेट रहने का सबसे आसान तरीका यही है कि Marinara को सामान्य रूप से चालू करें।

अपनी इंस्टॉल की हुई कॉपी बिना अपडेट के चलानी हो तो स्किप फ़्लैग लगाएँ:

```
./start-termux.sh --skip-update
```

हर बार चालू करने पर इंस्टॉल किया गया Engine वर्ज़न वही बनाए रखना हो, तो प्रोजेक्ट की `.env` में `AUTO_UPDATE_ENABLED=false` जोड़ें। इससे मैन्युअल अपडेट कमांड या **Settings → Advanced → Updates** बंद नहीं होते।

अपडेट ऐप के अंदर से भी देख सकते हैं। **Settings** (सेटिंग्स) खोलें, **Advanced** टैब पर जाएँ और **Updates** सेक्शन खोलें। नया रिलीज़ आया है या नहीं, यह देखने के लिए **Check for Updates** पर क्लिक करें। ऐप के अंदर वाला **Apply Update** बटन डिफ़ॉल्ट रूप से बंद रहता है और उसके लिए सेटअप चाहिए। इसे चालू करने और इस्तेमाल करने का तरीका [Marinara Engine को अपडेट करना](../UPGRADING.md) में देखें।
