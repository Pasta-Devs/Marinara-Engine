# macOS / Linux इंस्टॉलेशन गाइड

इस गाइड में बताया गया है कि macOS या Linux पर Marinara Engine कैसे इंस्टॉल करें और कैसे चलाएँ। इसमें दो ज़रूरी टूल इंस्टॉल करने हैं, फिर शेल लॉन्चर से ऐप चालू करना है, और आगे अपडेट करने का तरीका भी यहीं मिलेगा। Marinara Engine (आगे सिर्फ़ Marinara) पूरी तरह आपके अपने कंप्यूटर पर चलता है।

## पहले से क्या चाहिए

शुरू करने से पहले दो मुफ़्त टूल इंस्टॉल होने चाहिए:

- **Node.js**: वह प्रोग्राम जो Marinara को चलाता है। वर्ज़न 24, 25 या 26 इंस्टॉल करें (24 वाला LTS रिलीज़ सुझाया जाता है)।
- **Git**: वह टूल जो Marinara को डाउनलोड करता है और अपडेट लाता है।

pnpm खुद इंस्टॉल करने की ज़रूरत नहीं है। pnpm वह पैकेज मैनेजर है जिससे Marinara अपने हिस्से डाउनलोड करता है। शेल लॉन्चर सही pnpm वर्ज़न अपने आप इंस्टॉल कर देता है।

### macOS पर इंस्टॉल करना

सबसे आसान रास्ता Homebrew है। यह एक कमांड दोनों टूल इंस्टॉल कर देती है:

```bash
brew install node git
```

Homebrew इस्तेमाल नहीं करते, तो Node.js का इंस्टॉलर https://nodejs.org से डाउनलोड करें। इसके बाद Git को Xcode कमांड लाइन टूल्स के साथ इंस्टॉल करें:

```bash
xcode-select --install
```

### Linux पर इंस्टॉल करना

अपने डिस्ट्रिब्यूशन का पैकेज मैनेजर इस्तेमाल करें। Ubuntu या Debian पर डिफ़ॉल्ट Node.js अक्सर वर्ज़न 24 से पुराना होता है। पहले नया NodeSource रिलीज़ जोड़ें:

```bash
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo bash -
```

फिर Node.js और Git इंस्टॉल करें:

```bash
sudo apt install -y nodejs git
```

Fedora पर:

```bash
sudo dnf install -y nodejs git
```

Arch पर:

```bash
sudo pacman -S nodejs npm git
```

### टूल की जाँच

जाँच लें कि दोनों टूल तैयार हैं। यह कमांड चलाएँ:

```bash
node -v
```

`v24` या उससे बड़ा नंबर दिखना चाहिए। इसके बाद यह कमांड चलाएँ:

```bash
git --version
```

`git version 2.40` जैसा या उससे नया वर्ज़न दिखना चाहिए। किसी भी कमांड पर "command not found" आए, तो वह टूल ठीक से इंस्टॉल नहीं हुआ है।

## लॉन्चर से झटपट शुरुआत

Marinara को चलाने का सुझाया हुआ तरीका लॉन्चर स्क्रिप्ट `start.sh` है। यह सब कुछ इंस्टॉल करती है, ऐप बनाती है और उसे आपके ब्राउज़र में खोल देती है।

1. Marinara डाउनलोड करें। यह कमांड चलाएँ:

```bash
git clone https://github.com/Pasta-Devs/Marinara-Engine.git
```

2. नए फ़ोल्डर में जाएँ। यह कमांड चलाएँ:

```bash
cd Marinara-Engine
```

3. लॉन्चर को चलने लायक बनाएँ। यह कमांड चलाएँ:

```bash
chmod +x start.sh
```

4. Marinara चालू करें। यह कमांड चलाएँ:

```bash
./start.sh
```

पहली बार में कुछ मिनट लगते हैं, क्योंकि तब सब कुछ डाउनलोड और तैयार होता है। काम पूरा होते ही Marinara आपके ब्राउज़र में http://127.0.0.1:7860 पर खुल जाता है। 7860 डिफ़ॉल्ट पोर्ट है, यानी वह दरवाज़ा जिससे ऐप आपके कंप्यूटर पर बात करता है।

ब्राउज़र अपने आप न खुले, तो उसे खुद खोलें और वही पता डालें।

### लॉन्चर हर बार क्या करता है

Git डाउनलोड से `./start.sh` चलाने पर लॉन्चर हर बार यह करता है:

1. नया वर्ज़न देखता है और मिलने पर खुद को अपडेट कर लेता है।
2. जाँचता है कि Node.js और सही pnpm वर्ज़न तैयार हैं।
3. जो हिस्से गायब हैं, उन्हें इंस्टॉल करता है।
4. कोड बदला हो तो ऐप दोबारा बनाता है।
5. आपके डेटा के लिए लोकल स्टोरेज तैयार करता है।
6. सर्वर चालू करता है और ऐप को ब्राउज़र में खोलता है।

### ब्राउज़र का अपने आप खुलना बंद करना

डिफ़ॉल्ट रूप से लॉन्चर आपका ब्राउज़र खोल देता है। इसे बंद करने के लिए Marinara फ़ोल्डर में `.env` नाम की फ़ाइल बनाएँ और उसमें यह पंक्ति जोड़ें:

```bash
AUTO_OPEN_BROWSER=false
```

`.env` एक सादी टेक्स्ट फ़ाइल है जिसमें आपकी सेटिंग्स रहती हैं, हर पंक्ति में एक। शुरुआती छोटी `.env` कुछ ऐसी दिखती है:

```bash
PORT=7860
AUTO_OPEN_BROWSER=true
```

`PORT` पते का पोर्ट तय करता है (डिफ़ॉल्ट 7860)। डिफ़ॉल्ट रूप से लॉन्चर आपके LAN के दूसरे डिवाइस को भी सर्वर तक पहुँचने देता है। LAN यानी लोकल एरिया नेटवर्क, आपके घर या ऑफ़िस का नेटवर्क। फिर भी Marinara उन डिवाइस को तब तक रोके रखता है, जब तक आप पासवर्ड या कोई दूसरा एक्सेस विकल्प सेट नहीं कर देते। इसका तरीका [रिमोट एक्सेस: लॉगिन और IP अलाउलिस्ट](../REMOTE_ACCESS.md) गाइड में दिया गया है।

## मैन्युअल सेटअप

ज़्यादातर लोगों के लिए ऊपर वाला लॉन्चर ही ठीक है। हर स्टेप खुद चलाना चाहें, तो इसकी जगह ये कमांड चलाएँ। मैन्युअल सेटअप के लिए pnpm मौजूद होना चाहिए। Node.js 24 में Corepack शामिल है, Node.js 25 में नहीं।

1. Node.js 24 पर pnpm को Corepack से चालू करें:

```bash
corepack enable pnpm
```

Node.js 25 या 26 पर पहले अलग से Corepack पैकेज इंस्टॉल करें, फिर pnpm चालू करें:

```bash
npm install --global corepack
corepack enable pnpm
```

2. Marinara डाउनलोड करें। यह कमांड चलाएँ:

```bash
git clone https://github.com/Pasta-Devs/Marinara-Engine.git
```

3. फ़ोल्डर में जाएँ। यह कमांड चलाएँ:

```bash
cd Marinara-Engine
```

4. हिस्से इंस्टॉल करें। यह कमांड चलाएँ:

```bash
pnpm install --force
```

5. ऐप बनाएँ। यह कमांड चलाएँ:

```bash
pnpm build
```

6. सर्वर चालू करें। यह कमांड चलाएँ:

```bash
pnpm start
```

अब अपने ब्राउज़र में http://127.0.0.1:7860 खोलें। `pnpm start` के साथ सर्वर डिफ़ॉल्ट रूप से सिर्फ़ आपके अपने कंप्यूटर पर सुनता है। सब कुछ लोकल चलता है, और पहली बार चालू करने पर आपका डेटा स्टोरेज तैयार हो जाता है।

### Linux पर इंस्टॉल न हो तो

कुछ Linux सिस्टम इंस्टॉल के दौरान बहुत लंबे फ़ाइल पथ स्वीकार नहीं करते। `ERR_PNPM_ENAMETOOLONG` वाली एरर दिखे, तो अधूरे फ़ोल्डर हटा दें और लॉन्चर से दोबारा शुरू करें। यह कमांड चलाएँ:

```bash
rm -rf node_modules .pnpm .pnpm-store
```

फिर यह कमांड चलाएँ:

```bash
./start.sh
```

## वैकल्पिक बैकग्राउंड रिमूवर

Marinara कैरेक्टर की स्प्राइट इमेज से बैकग्राउंड हटा सकता है। स्प्राइट यानी Roleplay और Game Mode में दिखने वाली कैरेक्टर की तस्वीर। नेटिव ट्रांसपेरेंसी और बिल्ट-इन अडैप्टिव मैट क्लीनअप इस डाउनलोड के बिना भी काम करते हैं। अलग से AI रिमूवर तभी इंस्टॉल करें, जब बारीक नज़ारे, परछाइयों या ऐसे ही भरे-पूरे बैकग्राउंड वाली स्प्राइट के लिए एक और सहारा चाहिए हो; यह बड़ी फ़ाइलें डाउनलोड करता है।

यह अतिरिक्त टूल एक Python प्रोग्राम है। इसे इंस्टॉल करने पर एक Python venv बनता है (वर्चुअल एनवायरनमेंट, यानी अलग फ़ोल्डर जिसमें Python पैकेज रहते हैं)। साथ ही PyTorch डाउनलोड होता है, जो मशीन लर्निंग की लाइब्रेरी है। आखिर में U2Net मॉडल डाउनलोड होते हैं, यानी वे फ़ाइलें जो इमेज में मुख्य विषय पहचानती हैं।

इसे एक बार इंस्टॉल करने के लिए Marinara फ़ोल्डर से यह कमांड चलाएँ:

```bash
pnpm backgroundremover:install
```

macOS पर Python का वर्ज़न 3.11 सबसे भरोसेमंद रहता है। पहले उसे Homebrew से इंस्टॉल करें:

```bash
brew install python@3.11
```

इसके बाद इंस्टॉल वाली कमांड दोबारा चलाएँ:

```bash
pnpm backgroundremover:install
```

अगली बार चालू करने पर लॉन्चर यह टूल खुद इंस्टॉल कर दे, इसके लिए अपनी `.env` फ़ाइल में यह पंक्ति जोड़ें:

```bash
BACKGROUNDREMOVER_AUTO_INSTALL=true
```

## अपडेट करना

Git डाउनलोड से `./start.sh` के ज़रिए Marinara चालू करने पर लॉन्चर नया वर्ज़न देखता है। शुरू होने से पहले वह खुद को अपने आप अपडेट कर लेता है। आपकी चैट, कैरेक्टर और सेटिंग्स वैसी ही रहती हैं।

एक बार की जाँच छोड़नी हो तो `./start.sh --skip-update` चलाएँ। इंस्टॉल किया हुआ Engine वर्ज़न हर बार वही बनाए रखना हो, तो `.env` में `AUTO_UPDATE_ENABLED=false` जोड़ें। जाँच या अपडेट फिर भी **Settings → Advanced → Updates** से या Git कमांड से खुद कर सकते हैं।

ऐप के अंदर से भी जाँच सकते हैं। **Settings** (सेटिंग्स) खोलें, **Advanced** टैब पर जाएँ और **Updates** सेक्शन देखें। नया रिलीज़ आया है या नहीं, यह देखने के लिए **Check for Updates** पर क्लिक करें। **Apply Update** बटन डिफ़ॉल्ट रूप से बंद रहता है। उसे चालू करने के लिए सर्वर के कुछ विकल्प सेट करने पड़ते हैं। इसके बाद **Settings**, **Advanced**, **Admin Access** में एक एडमिन सीक्रेट सेव करें। इसे चालू न करना हो, तो अपडेट के लिए बस `./start.sh` से दोबारा चालू कर लें।

अपडेट के पूरे स्टेप, पहले बैकअप लेने का तरीका और रिलीज़ चैनल बदलने की जानकारी नीचे दी गई अपडेट गाइड में है।

## मुख्य शब्द

- **pnpm**: वह पैकेज मैनेजर जिससे Marinara अपने हिस्से डाउनलोड करके व्यवस्थित रखता है।
- **Corepack**: Node.js के साथ आने वाला हेल्पर, जो pnpm को चालू करता है।
- **LAN**: लोकल एरिया नेटवर्क, यानी आपके घर या ऑफ़िस का निजी नेटवर्क।
- **.env**: Marinara फ़ोल्डर में रखी सादी टेक्स्ट सेटिंग्स फ़ाइल, हर पंक्ति में एक सेटिंग।
- **venv**: Python का वर्चुअल एनवायरनमेंट, यानी अलग फ़ोल्डर जिसमें Python पैकेज रहते हैं।
- **PyTorch**: मशीन लर्निंग की लाइब्रेरी, जिसे वैकल्पिक बैकग्राउंड रिमूवर इस्तेमाल करता है।
- **U2Net**: वे मॉडल फ़ाइलें, जिनसे बैकग्राउंड रिमूवर इमेज में मुख्य विषय पहचानता है।
