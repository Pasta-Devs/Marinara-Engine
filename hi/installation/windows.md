# Windows इंस्टॉलेशन गाइड

Marinara Engine को Windows PC पर इंस्टॉलर से (सबसे कम स्टेप) या सोर्स से इंस्टॉल करें। इसके बाद Marinara आपके अपने PC पर चलता है।

## शुरू करने से पहले

आपको Windows 10 या Windows 11 (64-बिट), कुछ गीगाबाइट खाली डिस्क स्पेस और इंस्टॉल के लिए इंटरनेट कनेक्शन चाहिए। इंस्टॉलर लगभग 2.5 GB खाली जगह रखने की सलाह देता है।

आपको दो टूल भी चाहिए:

- **Node.js** 24, 25 या 26। Node.js ऐप को चलाता है। वर्ज़न 24 सुझाया गया LTS (Long Term Support) रिलीज़ है।
- **Git**। Git कोड डाउनलोड करता है और Marinara को खुद अपडेट होने देता है।

इंस्टॉलर इस्तेमाल करते हैं, तो इन्हें इंस्टॉल करने की ज़रूरत नहीं: वह दोनों खुद ले आता है। सोर्स से इंस्टॉल करते हैं, तो इन्हें खुद इंस्टॉल करना होगा। pnpm (वह टूल जो ऐप के हिस्से इंस्टॉल करता है) इंस्टॉल करने की ज़रूरत नहीं है। इंस्टॉलर और `start.bat` उसे सेट कर देते हैं।

## Windows इंस्टॉलर से इंस्टॉल करना

1. [Marinara Engine का रिलीज़ पेज](https://github.com/Pasta-Devs/Marinara-Engine/releases) खोलें।
2. सबसे नया Windows इंस्टॉलर डाउनलोड करें। उसका नाम `Marinara-Engine-Installer-` और उसके बाद वर्ज़न होता है।
3. इंस्टॉलर चलाएँ। Windows "Windows protected your PC" दिखाए, तो **More info** चुनें, फिर **Run anyway**, लेकिन सिर्फ़ तब जब फ़ाइल रिलीज़ पेज से ली गई हो।
4. स्क्रीन पर आने वाले निर्देशों का पालन करें। Node.js या Git न हो, तो इंस्टॉलर को उसे इंस्टॉल करने दें।
5. इंस्टॉल फ़ोल्डर चुनें, या डिफ़ॉल्ट (`%LOCALAPPDATA%\Marinara-Engine`) रहने दें।
6. इंस्टॉलर के ऐप डाउनलोड करने और बनाने तक इंतज़ार करें। प्रोग्रेस की एक लिस्ट हर स्टेप दिखाती है। इसमें कुछ मिनट लगते हैं।
7. जब वह बताए कि इंस्टॉलेशन पूरी हो गई है, तो डेस्कटॉप पर **Marinara Engine** शॉर्टकट पर डबल-क्लिक करें।

एक कंसोल विंडो (काली टेक्स्ट विंडो) खुलती है और प्रोग्रेस दिखाती है। फिर आपका ब्राउज़र Marinara खोल देता है। न खोले, तो `http://127.0.0.1:7860` पर जाएँ।

इंस्टॉलर सबसे नए स्थिर रिलीज़ की Git कॉपी बनाता है, ताकि Marinara हर बार खुलने पर खुद को अपडेट कर सके।

> **Tip:** कुछ एंटीवायरस टूल इंस्टॉलर पर निशान लगा देते हैं, क्योंकि वह Node.js और Git डाउनलोड करता है। इंस्टॉलर तभी चलाएँ जब आपने उसे ऊपर दिए रिलीज़ पेज से लिया हो।

## Marinara शुरू और बंद करना

- **शुरू करें:** डेस्कटॉप शॉर्टकट या Start Menu की एंट्री पर डबल-क्लिक करें। सोर्स से इंस्टॉल किया हो, तो Marinara फ़ोल्डर में `start.bat` चलाएँ।
- **बंद करें:** शॉर्टकट एक कंसोल विंडो खोलता है। उसमें <kbd>Ctrl</kbd>+<kbd>C</kbd> दबाएँ।

Marinara पहले से चल रहा हो, तो शॉर्टकट उसे आपके ब्राउज़र में दोबारा खोल देता है।

## सोर्स से इंस्टॉल करना

यह तरीका तब अपनाएँ जब कमांड खुद चलाना पसंद हो, या staging (टेस्टर) वर्ज़न चाहिए हो।

1. [Node.js](https://nodejs.org/en/download) और [Git for Windows](https://git-scm.com/download/win) इंस्टॉल करें।
2. एक नई Command Prompt विंडो खोलें (वह टेक्स्ट विंडो जिसमें कमांड टाइप करते हैं)।
3. दोनों टूल जाँचें। `node -v` पर वर्ज़न 24, 25 या 26 दिखना चाहिए।

   ```bat
   node -v
   git --version
   ```

   कोई कमांड न मिले, तो Command Prompt बंद करके दोबारा खोलें, या जो टूल छूट गया है उसे फिर से इंस्टॉल करें।

4. कोड डाउनलोड करें।

   ```bat
   git clone https://github.com/Pasta-Devs/Marinara-Engine.git
   ```

5. उसका फ़ोल्डर खोलें।

   ```bat
   cd Marinara-Engine
   ```

6. वैकल्पिक: पहली बार चलाने से पहले staging वर्ज़न पर जाएँ। स्थिर वर्ज़न पर रहना हो, तो यह स्टेप छोड़ दें। staging इस्तेमाल करने से पहले अपना डेटा बैकअप कर लें।

   ```bat
   git checkout staging
   ```

   इसके बाद लॉन्चर अपडेट करते समय आपको staging पर ही रखता है।

7. लॉन्चर चलाएँ, यानी वह स्क्रिप्ट जो Marinara को सेट करके शुरू करती है।

   ```bat
   start.bat
   ```

पहली बार चलाने में कुछ मिनट लगते हैं, क्योंकि तभी सब कुछ इंस्टॉल और बिल्ड होता है। एक कंसोल विंडो प्रोग्रेस दिखाती है। तैयार होते ही आपका ब्राउज़र Marinara खोल देता है। बाद में दोबारा शुरू करने के लिए उसी फ़ोल्डर से `start.bat` चलाएँ।

अगर यह काम नहीं किया: `[ERROR] Node.js 24 LTS or newer is required` का मतलब है कि आपका Node.js बहुत पुराना है। [nodejs.org](https://nodejs.org) से Node.js 24 या उससे नया वर्ज़न इंस्टॉल करें, फिर `start.bat` दोबारा चलाएँ।

### लॉन्चर के बिना मैन्युअल सेटअप

इस रास्ते के लिए `pnpm` कमांड चाहिए। ये कमांड `Marinara-Engine` फ़ोल्डर के अंदर से चलाएँ।

1. pnpm एक बार इंस्टॉल करें।

   ```bat
   npm install -g pnpm
   ```

2. डिपेंडेंसी (ऐप को चाहिए होने वाले हिस्से) इंस्टॉल करें, ऐप बनाएँ और सर्वर शुरू करें।

   ```bat
   pnpm install --force
   pnpm build
   pnpm start
   ```

3. `http://127.0.0.1:7860` खोलें।

`pnpm start` के साथ सिर्फ़ यही PC Marinara तक पहुँच सकता है। दूसरे डिवाइस को जुड़ने देने के लिए `Marinara-Engine` फ़ोल्डर में `.env` नाम की फ़ाइल बनाएँ, उसमें यह पंक्ति जोड़ें और सर्वर रीस्टार्ट करें।

```env
HOST=0.0.0.0
```

## Marinara को दूसरे डिवाइस से खोलना

इंस्टॉलर, उसका शॉर्टकट और `start.bat` आपके नेटवर्क के दूसरे डिवाइस को Marinara तक पहुँचने देते हैं, लेकिन जब तक आप लॉगिन सेट न करें, Marinara उन्हें रोके रखता है। स्टेप के लिए देखें [रिमोट एक्सेस](../REMOTE_ACCESS.md) और [FAQ](../FAQ.md#how-do-i-access-marinara-engine-from-my-phone-or-another-device)।

## Marinara अपडेट करना

हर बार शॉर्टकट या `start.bat` से Marinara शुरू करने पर लॉन्चर अपडेट जाँचता है, उन्हें इंस्टॉल करता है, ऐप फिर से बनाता है और उसे शुरू करता है। आपकी चैट, कैरेक्टर और सेटिंग्स अपनी जगह बनी रहती हैं। अगर आपने कोड में खुद बदलाव किए हैं, तो लॉन्चर उन्हें अलग रख देता है और अपडेट के बाद वापस लगा देता है। ऐसा न हो पाए, तो वह आपका मौजूदा वर्ज़न ही रहने देता है और एक नोट दिखाता है। ऐप के अंदर वाले **Apply Update** (अपडेट लागू करें) बटन, अपडेट छोड़ने और मैन्युअल कमांड के लिए देखें [Marinara Engine को अपडेट करना](../UPGRADING.md#windows)।

## अपना डेटा ढूँढना या अनइंस्टॉल करना

आपका डेटा Marinara फ़ोल्डर के अंदर `packages\server\data` फ़ोल्डर में है। अनइंस्टॉल करने के लिए Start Menu की **Uninstall Marinara Engine** एंट्री खोलें। अनइंस्टॉलर पूछता है कि आपका डेटा भी डिलीट करना है या नहीं। बाद में दोबारा इंस्टॉल करने के लिए डेटा रखना हो, तो **No** चुनें। देखें [Marinara का बैकअप और रिस्टोर](../data/backup-and-restore.md)।

## वैकल्पिक: AI से स्प्राइट का बैकग्राउंड हटाना

Marinara जेनरेट किए गए स्प्राइट के लिए पारदर्शी बैकग्राउंड माँगता है और सादे बैकग्राउंड खुद साफ़ कर देता है। बारीक नज़ारों के लिए एक फ़ॉलबैक के तौर पर आप वैकल्पिक `backgroundremover` टूल इंस्टॉल कर सकते हैं। यह मशीन लर्निंग की बड़ी फ़ाइलें डाउनलोड करता है, इसलिए डिफ़ॉल्ट रूप से बंद रहता है।

1. [python.org](https://www.python.org/downloads/windows/) से Python 3.11 इंस्टॉल करें। Python 3.9 से 3.11 तक काम करता है।
2. `Marinara-Engine` फ़ोल्डर से यह कमांड चलाएँ।

   ```bat
   pnpm backgroundremover:install
   ```

इससे आपके डेटा फ़ोल्डर के नीचे एक निजी Python फ़ोल्डर (venv) बन जाता है। Marinara उसे अपने आप इस्तेमाल करता है।

अगली बार खुलने पर `start.bat` से इसे इंस्टॉल करवाने के लिए अपनी `.env` फ़ाइल में यह पंक्ति जोड़ें:

```env
BACKGROUNDREMOVER_AUTO_INSTALL=true
```
