# इमेज और वीडियो के लिए प्रॉम्प्ट ओवरराइड

Prompt Overrides (प्रॉम्प्ट ओवरराइड) उन टेम्पलेट के एडिटर हैं जिनसे Marinara इमेज और वीडियो मॉडल के लिए प्रॉम्प्ट लिखता है। पोर्ट्रेट, सेल्फ़ी, स्प्राइट, सीन आर्ट, स्टोरीबोर्ड या वीडियो क्लिप का विवरण मॉडल को कैसे दिया जाए, यह बदलने के लिए इनमें से किसी एक का इस्तेमाल करें।

ये आपके चैट मॉडल को भेजा जाने वाला प्रॉम्प्ट नहीं बदलते। उसके लिए प्रीसेट इस्तेमाल करें। देखें [Preset Editor और प्रॉम्प्ट मैनेजर](presets.md) और [जेनरेशन पैरामीटर](generation-parameters.md)।

स्प्राइट यानी कैरेक्टर के आर्टवर्क का एक टुकड़ा, जैसे कोई एक्सप्रेशन या पोज़। स्टोरीबोर्ड यानी चित्रों वाले फ़्रेम का सेट, जो Game Mode के किसी टर्न या पूरे हो चुके Roleplay एपिसोड से बनता है।

शुरू करने से पहले: Prompt Overrides सिर्फ़ उन सुविधाओं के लिए मायने रखते हैं जो इमेज या वीडियो जेनरेट करती हैं, और उन सुविधाओं के लिए पहले इमेज या वीडियो जेनरेशन का अकाउंट चाहिए। उसके बिना टेम्पलेट कभी इस्तेमाल नहीं होता। देखें [इमेज जेनरेशन प्रोवाइडर और सेटअप](../media/image-providers.md) और [सीन वीडियो जेनरेशन](../media/scene-video.md)।

## एडिटर ढूँढना

1. **Settings** (सेटिंग्स) खोलें।
2. **Generations** टैब पर क्लिक करें।
3. **Prompt Overrides** ("Reusable image and video prompt templates") तक स्क्रॉल करें।

वहाँ दो एडिटर हैं। किसी एडिटर को खोलने के लिए उसके शीर्षक पर क्लिक करें।

| एडिटर | इसमें आने वाले टेम्पलेट |
| --- | --- |
| **Video Generation Prompt Overrides** | Game और Gallery के सीन वीडियो, Conversation के वीडियो संदेश, Conversation Call के कैरेक्टर क्लिप, एनिमेटेड एक्सप्रेशन पोर्ट्रेट |
| **Image Generation Prompt Overrides** | Conversation की सेल्फ़ी, Game के NPC पोर्ट्रेट, सीन आर्ट, स्टोरीबोर्ड प्रॉम्प्ट, **Noodle Post Image** टेम्पलेट और बाकी इमेज बिल्डर |

## टेम्पलेट में बदलाव करना

1. कोई एडिटर खोलें।
2. **Registered prompt** से कोई टेम्पलेट चुनें। लिस्ट एडिटर पर निर्भर करती है।
3. उसके बगल वाली स्टेटस पिल देखें, और ड्रॉपडाउन के नीचे लिखा छोटा विवरण पढ़ें।
4. **Available variables** के नीचे किसी वेरिएबल चिप पर क्लिक करके उसे जोड़ें। वेरिएबल `${charName}` जैसे दिखते हैं।
5. **Template** बॉक्स में टेक्स्ट बदलें।
6. **Rendered preview** देखें। यह आपके टेम्पलेट को नमूना वैल्यू से भर देता है।
7. कोई **Unknown variables** चेतावनी हो, तो उसे ठीक करें। जो नाम **Available variables** लिस्ट में नहीं है, वह भरा नहीं जाता।
8. **Save** पर क्लिक करें।

आपको "Prompt override saved" दिखता है, और पिल बदलकर **Custom active** हो जाती है।

| स्टेटस पिल | मतलब |
| --- | --- |
| **Default** | कोई कस्टम टेम्पलेट सेव नहीं है। |
| **Custom active** | आपका सेव किया टेम्पलेट इस्तेमाल हो रहा है। |
| **Custom paused** | आपका टेम्पलेट सेव है, पर बंद है। |

## टेम्पलेट सेव रखना, पर इस्तेमाल न करना

प्रीव्यू के नीचे **Apply this override** बंद करें। इसके हेल्प टेक्स्ट में लिखा है "Turn this off to keep the template saved without using it." Marinara बिल्ट-इन टेम्पलेट ही इस्तेमाल करता रहता है, और पिल पर **Custom paused** लिखा दिखता है।

## बिल्ट-इन टेम्पलेट पर लौटना

**Reset to Default** पर क्लिक करें। कोई ओवरराइड सेव हो, तो Marinara पुष्टि माँगता है। पिल फिर से **Default** दिखाने लगती है।
