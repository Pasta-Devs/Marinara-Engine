# Claude, ChatGPT और Grok के सब्सक्रिप्शन कनेक्शन

इस गाइड में उन तीन कनेक्शन के बारे में बताया गया है जो API कुंजी की जगह अकाउंट से लॉगिन करते हैं: **Claude (Subscription)**, **OpenAI (ChatGPT)** और **Grok CLI (Subscription)**। इसके लिए एक छोटा कमांड लाइन टूल इंस्टॉल करें, एक बार लॉगिन करें, और Marinara Engine उसी अकाउंट से चैट चलाता है। कमांड लाइन टूल (CLI) यानी ऐसा प्रोग्राम जो टर्मिनल विंडो में कमांड टाइप करके चलाया जाता है।

## सब्सक्रिप्शन कनेक्शन क्या हैं

Marinara Engine के ज़्यादातर कनेक्शन API कुंजी से चलते हैं। API कुंजी पासवर्ड जैसा एक गुप्त कोड है, जिसे कनेक्शन में पेस्ट किया जाता है ताकि AI सेवा आपके अकाउंट पर बिल लगा सके।

ये तीन कनेक्शन अलग तरह से काम करते हैं। इनमें API कुंजी की जगह लोकल लॉगिन चलता है। आप अपनी ही मशीन पर CLI में साइन इन करते हैं, और Marinara उसी लॉगिन को दोबारा इस्तेमाल करता है। Marinara में कुछ भी पेस्ट नहीं करना पड़ता।

सब्सक्रिप्शन कनेक्शन तब चुनें जब आपके अकाउंट में इनमें से किसी CLI के ज़रिए एक्सेस शामिल हो:

- **Claude (Subscription)** आपके Anthropic **Pro** या **Max** सब्सक्रिप्शन से चलता है।
- **OpenAI (ChatGPT)** आपके ChatGPT अकाउंट से चलता है।
- **Grok CLI (Subscription)** आपके **SuperGrok** या **X Premium+** अकाउंट से चलता है।

## पहले क्या चाहिए

अकाउंट की शर्त हर प्रोवाइडर की अलग है।

- **Claude (Subscription)** के लिए ऐसा Claude प्लान चाहिए जो Claude Code के सब्सक्रिप्शन लॉगिन में सपोर्टेड हो।
- **OpenAI (ChatGPT)** योग्य Free और पेड, दोनों तरह के ChatGPT प्लान पर चलता है। इस्तेमाल की सीमाएँ प्लान के हिसाब से बदलती हैं।
- **Grok CLI (Subscription)** के लिए SuperGrok या X Premium+ चाहिए।

तीनों प्रोवाइडर के लिए CLI उसी मशीन पर इंस्टॉल और लॉगिन होना चाहिए जिस पर Marinara सर्वर चलता है। यह वह ब्राउज़र या फ़ोन नहीं है जिस पर आप Marinara देखते हैं। Marinara उस CLI को लोकल स्तर पर चलाता है, इसलिए लॉगिन सर्वर के साथ ही होना ज़रूरी है।

अगर Marinara आपके अपने कंप्यूटर पर चलता है, तो वही कंप्यूटर सर्वर है। किसी दूसरी मशीन पर या Docker में चलाने की सूरत में CLI वहीं इंस्टॉल करें और वहीं लॉगिन करें।

## Claude (Subscription)

इसके लिए Anthropic का Pro या Max सब्सक्रिप्शन चाहिए। यह वही साइन-इन है जो Visual Studio Code और Anthropic के दूसरे टूल इस्तेमाल करते हैं।

1. जिस मशीन पर Marinara चल रहा है, वहाँ Claude Code CLI इंस्टॉल करें:

```
npm i -g @anthropic-ai/claude-code
```

2. एक बार साइन इन करें:

```
claude auth login
```

3. Marinara में **Connections** (कनेक्शन) पैनल खोलें और **New** पर क्लिक करें।
4. **Create Connection** विंडो में नाम टाइप करें, **Claude (Subscription)** प्रोवाइडर चुनें, फिर **Create** पर क्लिक करें।
5. एडिटर में ध्यान दें कि यहाँ **API Key** या **Base URL** फ़ील्ड है ही नहीं। एक इन्फ़ो पैनल बताता है कि इनकी ज़रूरत नहीं है।
6. **Model** ड्रॉपडाउन से कोई Claude मॉडल चुनें, जैसे कोई Opus या Sonnet मॉडल।
7. **Save** पर क्लिक करें, फिर **Send Test Message** पर क्लिक करें। छोटा सा जवाब आ जाए तो लॉगिन काम कर रहा है।

Claude के सब्सक्रिप्शन कनेक्शन सिर्फ़ टेक्स्ट चैट सपोर्ट करते हैं। इस कनेक्शन में दो अतिरिक्त कंट्रोल हैं, **Fast Mode** और **Diagnose Model Routing**, जिनके बारे में नीचे बताया गया है।

## OpenAI (ChatGPT)

इसके लिए ChatGPT अकाउंट चाहिए। Marinara चैट को Codex CLI के लॉगिन से होकर भेजता है।

1. जिस मशीन पर Marinara चल रहा है, वहाँ Codex CLI इंस्टॉल करें:

```
npm i -g @openai/codex
```

2. एक बार साइन इन करें:

```
codex login
```

3. Marinara में **Connections** पैनल खोलें और **New** पर क्लिक करें।
4. **Create Connection** विंडो में नाम टाइप करें, **OpenAI (ChatGPT)** प्रोवाइडर चुनें, फिर **Create** पर क्लिक करें।
5. **Model** ड्रॉपडाउन से कोई मॉडल चुनें। यह लिस्ट मुमकिन हो तो आपके ChatGPT सेशन से आती है, वरना ऐप में पहले से मौजूद लिस्ट दिखती है।
6. **Save** पर क्लिक करें, फिर **Send Test Message** पर क्लिक करके जवाब आना पक्का करें।

Marinara आपकी लोकल Codex लॉगिन फ़ाइल पढ़ता है और जब मुमकिन हो, सेशन को रिफ़्रेश कर देता है।

## Grok CLI (Subscription)

इसके लिए SuperGrok या X Premium+ अकाउंट चाहिए।

1. जिस मशीन पर Marinara चल रहा है, वहाँ Grok CLI इंस्टॉल करें:

```
curl -fsSL https://x.ai/cli/install.sh | bash
```

2. एक बार साइन इन करें:

```
grok login
```

3. Marinara में **Connections** पैनल खोलें और **New** पर क्लिक करें।
4. **Create Connection** विंडो में नाम टाइप करें, **Grok CLI (Subscription)** प्रोवाइडर चुनें, फिर **Create** पर क्लिक करें।
5. कोई मॉडल चुनें, या CLI का डिफ़ॉल्ट चलाने के लिए **Model** फ़ील्ड खाली छोड़ दें। Roleplay के लिए सबसे सुरक्षित मॉडल आम तौर पर `grok-composer-2.5-fast` रहता है।
6. **Save** पर क्लिक करें, फिर **Send Test Message** पर क्लिक करें। यह कनेक्शन बिना मॉडल सेट किए भी टेस्ट चला सकता है।

Grok CLI की दो बातें खास हैं। यह स्ट्रीमिंग नहीं करता, इसलिए जवाब शब्द-दर-शब्द बनने के बजाय एक ही बार में पूरा दिखता है। इसकी कॉन्टेक्स्ट विंडो डिफ़ॉल्ट रूप से 32000 टोकन की है, जो बाकी प्रोवाइडर से कम है, क्योंकि बहुत बड़े प्रॉम्प्ट CLI की अपनी टर्न सीमा से टकरा सकते हैं।

Grok के मॉडल लोड करने के लिए **Model** सेक्शन में मौजूद **Fetch Models from Grok CLI** बटन इस्तेमाल करें।

## Claude के प्रॉम्प्ट कैश की अवधि

Claude कनेक्शन एडिटर में **Prompt Caching → Extended token caching (1 hour)** मैसेज के बीच लंबे विराम के लिए 1 घंटे का कैश माँगता है। इसके लिए Claude Code **2.1.242 या नया** ज़रूरी है। Marinara सेव की गई Claude सेटिंग बदले बिना उस रिक्वेस्ट के लिए यह सेटिंग भेजता है।

इसे बंद रखने पर मुख्य बातचीत और Agent SDK अनुरोधों के लिए Claude की डिफ़ॉल्ट सेटिंग लागू रहती है: फ़िलहाल प्लान की सीमा के अंदर सब्सक्रिप्शन इस्तेमाल के लिए 1 घंटा और अतिरिक्त इस्तेमाल, क्रेडिट या API बिलिंग के लिए 5 मिनट। Claude Code के अपने सबएजेंट अलग से कॉन्फ़िगर न किए जाने पर 5 मिनट इस्तेमाल करते हैं; सर्वर द्वारा नियंत्रित कुछ सहायक अनुरोध 1 घंटा इस्तेमाल कर सकते हैं। इस मान को बदलने वाले मौजूदा CLI एनवायरनमेंट वेरिएबल को अब भी प्राथमिकता मिलती है। [Claude Code की प्रॉम्प्ट कैशिंग](https://code.claude.com/docs/en/prompt-caching) देखें।

डिबग लॉग SDK से मिले इस्तेमाल के आँकड़ों के आधार पर 5 मिनट और 1 घंटे के कैश राइट अलग दिखाते हैं। लागत का अनुमान API टोकन दरों के सामान्य गुणकों से निकलता है, आपके सब्सक्रिप्शन बिल से नहीं। अगर SDK कैश अवधि के हिसाब से राइट का ब्योरा नहीं देता, तो अनुमान अज्ञात रहता है।

## API कुंजी वाली फ़ील्ड क्यों नहीं दिखती

तीनों सब्सक्रिप्शन प्रोवाइडर में **API Key** और **Base URL** फ़ील्ड छिपी रहती हैं। ऐसा जान-बूझकर किया गया है। आपका लॉगिन सर्वर मशीन पर CLI के अंदर रहता है, इसलिए Marinara में टाइप करने के लिए कुछ बचता ही नहीं।

अगर गलती से गलत प्रोवाइडर चुन लिया और कुंजी वाली फ़ील्ड नहीं दिख रही, तो प्रोवाइडर ग्रिड में वापस अपने असली प्रोवाइडर पर चले जाएँ। API वाले प्रोवाइडर में कुंजी की फ़ील्ड फिर से आ जाती है।

## Fast Mode (सिर्फ़ Claude में)

**Claude (Subscription)** के एडिटर में **Fast Mode** सेक्शन होता है, जिसमें एक ही टॉगल है, **Use Claude Code fast-mode routing**। यह डिफ़ॉल्ट रूप से बंद रहता है।

इसे बंद ही रहने दें। ऐप खुद बताता है कि फ़िलहाल इस सुविधा से कुछ नहीं होता। यह Claude Code से तेज़ मॉडल टियर माँगता है, पर मौजूदा Claude मॉडल में ऐसा टियर रह ही नहीं गया। इसे चालू करने से कोई फ़ायदा नहीं होता और थोड़ा अतिरिक्त बोझ पड़ सकता है। यह टॉगल UI में सिर्फ़ इसलिए बना हुआ है कि Anthropic कभी यह सुविधा लौटा दे।

इसे चालू करने की कोशिश करने पर **YOU DON'T WANT THIS SETTING ON!** नाम की एक पुष्टि विंडो आती है। वहाँ **Keep it off** चुनें।

## Diagnose Model Routing (सिर्फ़ Claude में)

**Claude (Subscription)** के एडिटर में टेस्ट वाले हिस्से में **Diagnose Model Routing** बटन होता है। इसे तब इस्तेमाल करें जब आपने एक Claude मॉडल माँगा हो, पर शक हो कि जवाब किसी छोटे मॉडल से आया है।

1. कोई मॉडल चुनें और **Save** पर क्लिक करें। मॉडल चुने बिना यह बटन काम नहीं करता।
2. **Diagnose Model Routing** पर क्लिक करें।
3. नतीजा पढ़ें। Marinara आपके Claude Code लॉगिन से होकर एक असली प्रॉम्प्ट भेजता है। फिर बताता है कि आपके अकाउंट पर असल में किस मॉडल का बिल लगा।

इससे चुपचाप हुआ डाउनग्रेड पकड़ में आता है, यानी वह हालत जब आप Opus जैसा बड़ा मॉडल माँगते हैं और चुपके से Sonnet या Haiku मिल जाता है।

## जो सीमाएँ जान लेनी चाहिए

- इन कनेक्शन के लिए पेड सब्सक्रिप्शन चाहिए, और सर्वर मशीन पर CLI लॉगिन होना चाहिए।
- तीनों में से किसी पर भी एम्बेडिंग नहीं मिलती। लोरबुक की सिमैंटिक सर्च और मेमोरी रिकॉल के लिए एम्बेडिंग वाला अलग कनेक्शन चाहिए।
- **Claude (Subscription)** सिर्फ़ टेक्स्ट चैट सपोर्ट करता है।
- **Grok CLI (Subscription)** स्ट्रीमिंग नहीं करता और छोटी कॉन्टेक्स्ट विंडो से शुरू होता है।
- **Send Test Message** के लिए पहले मॉडल चुनना ज़रूरी है, सिर्फ़ Grok CLI इसका अपवाद है, जो बिना मॉडल के भी टेस्ट कर सकता है।
