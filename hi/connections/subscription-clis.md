# Claude, ChatGPT और Grok के सब्सक्रिप्शन कनेक्शन

तीन सेवाएँ आपको API कुंजी की जगह उस प्लान से चैट करने देती हैं जिसके पैसे आप पहले से दे रहे हैं: **Claude (Subscription)**, **OpenAI (ChatGPT)** और **Grok CLI (Subscription)**। आप एक छोटा कमांड लाइन टूल (CLI) इंस्टॉल करते हैं और एक बार साइन इन करते हैं। इसके बाद Marinara Engine उसी साइन-इन को दोबारा इस्तेमाल करता है। Marinara में कुछ भी पेस्ट नहीं करना पड़ता।

आपको यह प्लान चाहिए:

- **Claude (Subscription)**: Anthropic Pro या Max, या कोई दूसरा प्लान जिसे Claude Code मानता हो।
- **OpenAI (ChatGPT)**: एक ChatGPT अकाउंट। इस्तेमाल की सीमाएँ प्लान पर निर्भर करती हैं।
- **Grok CLI (Subscription)**: SuperGrok या X Premium+।

## सब्सक्रिप्शन अकाउंट जोड़ें

शुरू करने से पहले जान लें कि CLI उसी कंप्यूटर पर इंस्टॉल और साइन इन होना चाहिए जिस पर Marinara सर्वर चलता है। यह वह फ़ोन या ब्राउज़र नहीं है जिस पर आप Marinara देखते हैं। अगर Marinara किसी दूसरे कंप्यूटर पर या Docker में चलता है, तो स्टेप 1 और 2 वहीं करें। `npm` कमांड के लिए Node.js चाहिए। अगर आपने Marinara सोर्स से इंस्टॉल किया है, तो यह आपके पास पहले से है। देखें [इंस्टॉलेशन](../INSTALLATION.md)।

1. Marinara चलाने वाले कंप्यूटर पर एक टर्मिनल खोलें। टर्मिनल वह विंडो है जिसमें आप कमांड टाइप करते हैं। Windows पर PowerShell खोलें। macOS पर Terminal खोलें।
2. अपनी सेवा की इंस्टॉल कमांड चलाएँ, फिर उसकी साइन-इन कमांड चलाएँ। टूल साइन इन के अपने स्टेप दिखाता है, आम तौर पर एक वेब पेज जहाँ आप साइन इन करते हैं।

| सेवा | इंस्टॉल | साइन इन |
| --- | --- | --- |
| Claude | `npm i -g @anthropic-ai/claude-code` | `claude login` |
| ChatGPT | `npm i -g @openai/codex` | `codex login` |
| Grok | नीचे देखें | `grok login` |

Grok के लिए ऐप यह इंस्टॉल कमांड दिखाता है। अगर यह आपके सिस्टम पर न चले, तो Grok CLI के लिए x.ai के अपने निर्देश अपनाएँ।

```bash
curl -fsSL https://x.ai/cli/install.sh | bash
```

3. Marinara में टॉप बार में **Connections** (कनेक्शन) पर क्लिक करें, फिर **Add** (जोड़ें) पर क्लिक करें।
4. **Chat** (चैट) के नीचे अपनी सेवा पर क्लिक करें। इन सेवाओं पर **Sign in** का टैग होता है।
5. विंडो में **Sign in first** लिखा होता है और कमांड का नाम बताया जाता है। इसमें कुंजी की फ़ील्ड नहीं होती। **Connect** (कनेक्ट करें) पर क्लिक करें। Marinara लॉगिन की जाँच करता है। **Connected** का मतलब है कि यह काम कर रहा है।
6. लिस्ट से एक मॉडल चुनें, फिर **Done** (हो गया) पर क्लिक करें। Grok CLI के लिए आप मॉडल खाली भी छोड़ सकते हैं, तब CLI का अपना डिफ़ॉल्ट इस्तेमाल होता है (देखें [Grok CLI (Subscription)](#grok-cli-subscription))।

पक्का करने के लिए किसी चैट में संदेश भेजें। जवाब आए, तो यह काम कर रहा है।

अगर यह काम नहीं किया:

- **Marinara could not use the login on this computer.** Marinara वाले कंप्यूटर पर CLI इंस्टॉल नहीं है या उसमें साइन इन नहीं किया गया है। वहाँ साइन-इन कमांड चलाएँ, फिर **Try again** (फिर कोशिश करें) पर क्लिक करें।

## Claude (Subscription)

यहाँ से आगे के सेक्शन वैकल्पिक सेटिंग्स के बारे में हैं। चैट करने के लिए इनकी ज़रूरत नहीं है।

यह सेवा Claude Code के ज़रिए आपका Claude प्लान इस्तेमाल करती है। मॉडल एडिटर (**Edit model**) में इसके तीन अतिरिक्त कंट्रोल हैं: प्रॉम्प्ट कैशिंग, **Fast mode** (फ़ास्ट मोड) और **Diagnose model routing** (मॉडल रूटिंग की जाँच करें)।

### Extended token caching

प्रॉम्प्ट कैशिंग से Claude आपके प्रॉम्प्ट की शुरुआत दोबारा इस्तेमाल कर पाता है, इसलिए बार-बार की रिक्वेस्ट आपकी सीमा का कम हिस्सा खर्च करती हैं। **Prompt caching → Extended token caching (1 hour)** एक घंटे का कैश माँगता है, जो संदेशों के बीच रुकने पर काम आता है। इसके लिए Claude Code 2.1.242 या उसके बाद का वर्ज़न चाहिए। Marinara यह सेटिंग रिक्वेस्ट के साथ भेजता है और आपकी सेव की हुई Claude सेटिंग्स नहीं बदलता।

यह बंद हो, तो Claude आपके अकाउंट के लिए अपना डिफ़ॉल्ट इस्तेमाल करता है। देखें [Claude Code की प्रॉम्प्ट कैशिंग](https://code.claude.com/docs/en/prompt-caching)।

### Fast mode

**Fast mode → Use Claude Code fast-mode routing** डिफ़ॉल्ट रूप से बंद रहता है। इसे बंद ही रहने दें। यह Claude Code से तेज़ मॉडल टियर माँगता है, पर ऐप के मुताबिक मौजूदा मॉडल अब ऐसा टियर नहीं देते, इसलिए इसे चालू करने से कोई फ़ायदा नहीं होता और थोड़ा अतिरिक्त बोझ पड़ सकता है। इसे चालू करने की कोशिश करने पर **Turn on fast mode?** नाम की एक डायलॉग विंडो आती है। **Keep it off** (बंद ही रहने दें) पर क्लिक करें।

### Diagnose model routing

जब आपने Opus जैसा बड़ा मॉडल माँगा हो, पर शक हो कि आपको कोई छोटा मॉडल मिला है, तब **Diagnose model routing** इस्तेमाल करें।

1. कोई मॉडल चुनें। मॉडल सेट होने तक बटन बंद रहता है।
2. **Diagnose model routing** पर क्लिक करें। Marinara पहले बिना सेव किए बदलाव सेव कर लेता है।
3. नतीजा पढ़ें। Marinara आपके Claude Code साइन-इन से होकर एक असली प्रॉम्प्ट भेजता है और बताता है कि आपके अकाउंट पर किस मॉडल का बिल लगा।

## OpenAI (ChatGPT)

यह सेवा Codex CLI के ज़रिए आपका ChatGPT अकाउंट इस्तेमाल करती है। Marinara लोकल Codex लॉगिन फ़ाइल पढ़ता है और जब मुमकिन हो, सेशन को रिफ़्रेश कर देता है।

Codex जवाब देने से पहले कितनी देर सोचे, यह सेट करने के लिए **Edit model** (मॉडल एडिट करें) खोलें, **Use custom defaults for this model** (इस मॉडल के लिए कस्टम डिफ़ॉल्ट इस्तेमाल करें) चालू करें और कोई **Reasoning Effort** (रीज़निंग एफ़र्ट) चुनें। यह **Default** (डिफ़ॉल्ट) से शुरू होता है, जो उस मॉडल के लिए Codex का अपना स्तर रखता है। कोई चैट **Advanced Parameters** (एडवांस्ड पैरामीटर) में अपना अलग स्तर चुन सकती है। प्रीसेट का स्तर इसे नहीं बदलता। फ़ॉलबैक के तौर पर इस्तेमाल हुआ Codex मॉडल सिर्फ़ अपना ही स्तर मानता है, और इस मॉडल पर चलने वाले एजेंट मॉडल का स्तर इस्तेमाल करते हैं। आपको जो स्तर दिखते हैं, वे आपके चुने हुए मॉडल के लिए उपलब्ध स्तरों से मेल खाते हैं।

## Grok CLI (Subscription)

यह सेवा Marinara वाले कंप्यूटर पर Grok CLI चलाती है। दो बातें दूसरी सेवाओं से अलग हैं:

- यह स्ट्रीम नहीं करती। जवाब शब्द-दर-शब्द आने के बजाय एक ही बार में पूरा दिखता है।
- इसकी कॉन्टेक्स्ट विंडो डिफ़ॉल्ट रूप से 32,000 टोकन की होती है। टोकन टेक्स्ट के छोटे टुकड़े हैं जिन्हें मॉडल गिनते हैं। बड़े प्रॉम्प्ट CLI की अपनी टर्न सीमा से टकरा सकते हैं, इसलिए डिफ़ॉल्ट कम रखा गया है। मॉडल पर आप बड़ी **Max Context Window** (अधिकतम कॉन्टेक्स्ट विंडो) सेट कर सकते हैं।

मॉडल एडिटर में **Use the Grok CLI default** (Grok CLI का डिफ़ॉल्ट इस्तेमाल करें) मॉडल खाली छोड़ देता है, ताकि CLI अपना मॉडल खुद चुने। एडिटर बताता है कि रोलप्ले के लिए आम तौर पर सबसे सुरक्षित मॉडल `grok-composer-2.5-fast` है, क्योंकि Marinara CLI को हेडलेस मोड में चलाता है, और Grok के अपने टूल, मेमोरी फ़ीचर, वेब सर्च, प्लान और सबएजेंट बंद रहते हैं।

## प्लान का उपयोग

Claude (Subscription) और OpenAI (ChatGPT) अकाउंट दिखा सकते हैं कि आपने अपने प्लान की सीमाओं का कितना हिस्सा इस्तेमाल कर लिया है।

1. अकाउंट की पंक्ति पर **⋯** पर क्लिक करें, **Edit account** (अकाउंट एडिट करें) चुनें और **Usage and balance** (उपयोग और बैलेंस) खोलें।
2. अगर बाहर से उपयोग पढ़ना बंद है, तो **Turn on** (चालू करें) पर क्लिक करें।
3. **Show the usage meter on the card** (कार्ड पर उपयोग का मीटर दिखाएँ) चालू करें, फिर सेव करें।

हर सीमा-विंडो को एक बार मिलता है, जिसमें इस्तेमाल का प्रतिशत और रीसेट होने का समय दिखता है, जैसे `58% · resets in 2h`। जब तक यह अकाउंट सक्रिय है, यही बार चैट के कनेक्शन पिकर में और चैट की **Connection** (कनेक्शन) सेटिंग्स में भी दिखते हैं। **Shuffle** के लिए ये नहीं दिखते।

- बार आपके प्लान पर हुआ सब कुछ गिनते हैं, सिर्फ़ Marinara नहीं। Claude के लिए इसमें Claude Code और claude.ai शामिल हैं। ChatGPT के लिए इसमें Codex का सारा इस्तेमाल शामिल है, जैसे Codex CLI। chatgpt.com की चैट की अपनी सीमाएँ हैं और वे इसमें शामिल नहीं हैं।
- सेवाएँ हर विंडो का प्रतिशत बताती हैं, टोकन की गिनती नहीं।
- हर रीडिंग में Marinara वाले कंप्यूटर के CLI से वही डेटा माँगा जाता है जो उसकी अपनी उपयोग वाली कमांड दिखाती है। यह किसी मॉडल को कोई संदेश नहीं भेजती और आपके प्लान का कुछ भी इस्तेमाल नहीं करती। रिफ़्रेश बटन इसे दोबारा पढ़ता है।
- जिस प्लान में सिर्फ़ एक विंडो हो, उसमें एक ही बार दिखता है।
- Claude Code अपने उपयोग-डेटा को प्रयोगात्मक बताता है। अगर कोई नया वर्ज़न इसे बदल दे, तो बार गलत संख्या की जगह एक एरर और दोबारा कोशिश करने का बटन दिखाते हैं।

## इन सेवाओं की सीमाएँ

- इनके लिए पेड प्लान (या योग्य ChatGPT प्लान) चाहिए, और Marinara वाले कंप्यूटर पर CLI में साइन इन होना चाहिए।
- इनमें से कोई भी एम्बेडिंग नहीं देती। लोरबुक की सिमैंटिक सर्च और मेमोरी रिकॉल के लिए एम्बेडिंग वाला अलग अकाउंट चाहिए।
- **Send test message** (टेस्ट संदेश भेजें) के लिए पहले मॉडल चुनना ज़रूरी है, Grok CLI को छोड़कर।
