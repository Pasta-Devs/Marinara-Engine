# Marinara आपका डेटा कहाँ सेव करता है

वह फ़ोल्डर ढूँढें जिसमें Marinara Engine आपका डेटा रखता है, और जानें कि उसे ले जाते या कॉपी करते समय कौन से हिस्से रखने हैं।

Marinara आपके अपने कंप्यूटर पर चलता है और आपके कैरेक्टर, चैट और सेटिंग्स वहीं सेव करता है। जवाब जेनरेट करते समय Marinara आपकी चैट का कंटेंट फिर भी उस AI सेवा को भेजता है जिससे आपने कनेक्ट किया है।

## डेटा फ़ोल्डर ढूँढना

आपका बनाया सब कुछ सर्वर चलाने वाले कंप्यूटर के एक ही फ़ोल्डर में रहता है। यही डेटा फ़ोल्डर है। इसकी सेटिंग `DATA_DIR` है, जो ऐसी वैल्यू है जो आप सर्वर शुरू होने से पहले उसे देते हैं (एक एनवायरनमेंट वेरिएबल)। यह **Settings** (सेटिंग्स) में नहीं है।

- डिफ़ॉल्ट रूप से यह सर्वर की फ़ाइलों के बगल में `data` नाम का फ़ोल्डर होता है।
- आधिकारिक Docker कंटेनर में यह `/app/data` है।
- सही पाथ देखने के लिए उस विंडो को देखें जहाँ आपने Marinara शुरू किया था (टर्मिनल या कंसोल)। शुरू होते समय वह `[storage] DATA_DIR=` से शुरू होने वाली एक लाइन छापता है, जिसके बाद पाथ होता है। वह विंडो न मिले तो Marinara फ़ोल्डर के अंदर `data` नाम का फ़ोल्डर ढूँढें।

फ़ोल्डर को दूसरी जगह ले जाने के लिए `DATA_DIR` सेट करें और Marinara रीस्टार्ट करें। [सर्वर कॉन्फ़िगरेशन रेफ़रेंस](../CONFIGURATION.md) देखें।

## अंदर क्या रहता है

आपका टेक्स्ट डेटा `storage` फ़ोल्डर में रहता है: कैरेक्टर, चैट, संदेश, लोरबुक, प्रीसेट और कनेक्शन। Marinara इसे कई छोटी फ़ाइलों के रूप में सेव करता है। पुराने लेआउट से अपग्रेड करने के बाद `storage/tables/` में आपको ऐसी पुरानी कॉपियाँ दिख सकती हैं जिनके नाम `.pre-shard` पर खत्म होते हैं। Marinara उन्हें कभी नहीं हटाता। सब कुछ ठीक चलने लगे तो जगह खाली करने के लिए आप उन्हें खुद हटा सकते हैं।

आपकी इमेज, ऑडियो और दूसरी फ़ाइलें `storage` के बगल के अपने-अपने फ़ोल्डरों में रहती हैं। फ़ोल्डर के नाम ये हैं:

| फ़ोल्डर | उसमें क्या रहता है |
| --- | --- |
| `avatars` | कैरेक्टर और पर्सोना के अवतार |
| `sprites` | कैरेक्टर की स्प्राइट आर्ट |
| `avatar-models` | **2D Avatars** और **3D Avatars** एजेंट की फ़ाइलें, जैसे PNGTuber की तस्वीरें और 3D मॉडल |
| `backgrounds` | आपकी अपलोड की हुई चैट बैकग्राउंड |
| `gallery` | गैलरी की इमेज |
| `fonts` | आपके जोड़े हुए कस्टम फ़ॉन्ट |
| `knowledge-sources` | नॉलेज एजेंट के लिए आपकी अपलोड की हुई फ़ाइलें |
| `game-assets` | Game Mode के असेट |
| `game-scene-videos` | Game Mode के सीन के वीडियो |
| `conversation-call-character-videos` | Conversation कॉल के लिए कैरेक्टर के वीडियो |
| `custom-emojis` | कस्टम इमोजी की इमेज |
| `custom-stickers` | कस्टम स्टिकर की इमेज |
| `notification-sounds` | आपकी अपनी नोटिफ़िकेशन आवाज़ |
| `long-term-memory` | लंबी अवधि की मेमोरी वाले एजेंट का डेटा |
| `lorebooks/images`, `prompts/images`, `agents/images`, `connections/images` | लोरबुक, प्रीसेट, एजेंट और अकाउंट से जुड़ी इमेज |

डेटा फ़ोल्डर में `backups/` ([ऑटोमैटिक बैकअप](backup-and-restore.md#automatic-backups)) और एन्क्रिप्शन की फ़ाइल भी रहती है। **Download Backup** में टेबल का हर फ़ोल्डर, `storage` और कुंजी फ़ाइल शामिल रहती है। डेवलपर [फ़ाइल-नेटिव स्टोरेज](../development/file-storage.md) पढ़ सकते हैं।

## एन्क्रिप्शन कुंजी फ़ाइल सँभालकर रखें

Marinara आपकी सेव की हुई API कुंजियाँ एन्क्रिप्ट करता है। इसकी कुंजी डेटा फ़ोल्डर की `.encryption-key` फ़ाइल है।

यह फ़ाइल लिए बिना डेटा नए कंप्यूटर पर कॉपी करेंगे तो Marinara आपकी सेव की हुई API कुंजियाँ पढ़ नहीं पाएगा। तब आपको उन्हें दोबारा डालना पड़ेगा। इसे बाकी डेटा फ़ोल्डर के साथ ही कॉपी करें।

कुछ सेटअप कुंजी `ENCRYPTION_KEY` एनवायरनमेंट वेरिएबल से देते हैं। तब कॉपी करने के लिए कोई फ़ाइल नहीं होती। उस वैल्यू को अलग से सुरक्षित रखें। [सर्वर कॉन्फ़िगरेशन रेफ़रेंस](../CONFIGURATION.md) देखें।

## Android से अपना डेटा कॉपी करना

Android पर डेटा फ़ोल्डर ऐप के स्टोरेज में होता है, जहाँ root एक्सेस के बिना नहीं पहुँचा जा सकता, इसलिए आप उसे कॉपी नहीं कर सकते। **Settings → Advanced → Backup & Export → Download Backup** (सेटिंग्स → एडवांस्ड → बैकअप और एक्सपोर्ट → बैकअप डाउनलोड) इस्तेमाल करें। `.zip` में `.encryption-key` फ़ाइल भी रहती है, अगर वह मौजूद हो। [Marinara का बैकअप और रिस्टोर](backup-and-restore.md) देखें।

ऑटोमैटिक बैकअप उसी ऐप स्टोरेज में सेव होते हैं। ऐप अनइंस्टॉल या रीसेट करने पर वे लाइव डेटा के साथ हट सकते हैं, इसलिए एक कॉपी कहीं और रखें।
