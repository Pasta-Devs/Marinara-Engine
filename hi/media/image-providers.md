# इमेज जेनरेशन प्रोवाइडर और सेटअप

इस गाइड में बताया गया है कि Marinara Engine से किसी इमेज जेनरेशन सेवा को कैसे जोड़ें। साथ ही यह भी कि 17 में से हर सेवा को क्या चाहिए। इमेज जेनरेशन से सीन के चित्र, सेल्फ़ी, सीन बैकग्राउंड और जेनरेट किए गए अवतार, पोर्ट्रेट और स्प्राइट बनते हैं।

इमेज जेनरेशन एक खास तरह के कनेक्शन के रूप में सेट होता है। एक बार कोई इमेज कनेक्शन काम करने लगे, तो ऐप का हर इमेज फ़ीचर उसे इस्तेमाल कर सकता है।

## इमेज जेनरेशन कनेक्शन कैसे जोड़ें

**API कुंजी** यानी प्रोवाइडर से मिला एक गुप्त पासवर्ड, जिससे Marinara आपके अकाउंट को इस्तेमाल कर पाता है। **Base URL** यानी उस सेवा के ऐप्लिकेशन इंटरफ़ेस का वेब पता। सेवा चुनते ही Marinara सही Base URL अपने आप भर देता है।

इमेज कनेक्शन जोड़ने के लिए ये स्टेप अपनाएँ।

1. **Connections** (कनेक्शन) पैनल खोलें।
2. **Create Connection** विंडो खोलने के लिए **New** पर क्लिक करें।
3. नाम डालें, फिर **Image Generation** प्रोवाइडर चुनें।
4. कनेक्शन एडिटर में ग्रिड से कोई **Service** चुनें।
5. अगर उस सेवा को कुंजी चाहिए तो **API Key** पेस्ट करें। मुफ़्त और लोकल सेवाओं को कुंजी नहीं चाहिए।
6. लिस्ट से कोई **Model** चुनें, या मॉडल ID टाइप करें। कुछ सेवाओं में मौजूदा लिस्ट लोड करने के लिए **Fetch Models from API** मिलता है।
7. **Save** पर क्लिक करें।
8. सब ठीक चल रहा है, यह पक्का करने के लिए **Test Image** पर क्लिक करें। Marinara एक छोटी टेस्ट इमेज जेनरेट करता है।

अगर **Test Image** से तस्वीर आ जाए, तो कनेक्शन तैयार है। न आए तो API कुंजी और Base URL जाँच लें।

## सेवा कैसे चुनें

17 सेवाएँ तीन समूहों में बँटी हैं। क्लाउड सेवाओं के लिए API कुंजी और अकाउंट चाहिए। मुफ़्त सेवाओं के लिए कोई कुंजी नहीं चाहिए। लोकल सेवाएँ इमेज सॉफ़्टवेयर आपके अपने कंप्यूटर पर चलाती हैं।

नीचे की तालिका में हर सेवा एक नज़र में दी गई है। ब्योरा और खास बातें आगे हर सेवा के अलग सेक्शन में हैं।

## OpenAI (DALL-E)

क्लाउड सेवा, जिसका डिफ़ॉल्ट Base URL `https://api.openai.com/v1` है। इसके लिए आपके OpenAI अकाउंट की API कुंजी चाहिए। इसमें DALL-E और GPT Image मॉडल मिलते हैं। यह ज़्यादा से ज़्यादा 16 रेफ़रेंस इमेज लेती है।

## Stability AI

क्लाउड सेवा, जिसका डिफ़ॉल्ट Base URL `https://api.stability.ai/v2beta` है। इसके लिए Stability AI की API कुंजी चाहिए। इसमें Stable Diffusion और Stable Image मॉडल मिलते हैं।

## Together AI

क्लाउड सेवा, जिसका डिफ़ॉल्ट Base URL `https://api.together.xyz/v1` है। इसके लिए Together AI की API कुंजी चाहिए। इसमें FLUX और दूसरे ओपन इमेज मॉडल मिलते हैं।

## NovelAI

क्लाउड सेवा, जिसका डिफ़ॉल्ट Base URL `https://image.novelai.net` है। इसके लिए NovelAI की API कुंजी चाहिए। इसका ज़ोर एनिमे स्टाइल आर्ट पर है। V4, V4.5 और V5 मॉडल पर Marinara कई कैरेक्टरों वाले स्टोरीबोर्ड और Illustrator सीन के लिए हर कैरेक्टर की जगह के साथ उसका प्रॉम्प्ट NovelAI के अपने फ़ॉर्मैट में भेजता है। कुछ नए फ़ीचर, जैसे सटीक रेफ़रेंस इमेज, सिर्फ़ V4.5 मॉडल पर चलते हैं।

## OpenRouter Images

क्लाउड सेवा, जिसका डिफ़ॉल्ट Base URL `https://openrouter.ai/api/v1` है। इसके लिए OpenRouter की API कुंजी चाहिए। यह इमेज मॉडल तक OpenRouter के चैट इंटरफ़ेस से पहुँचती है, इसलिए कौन से मॉडल मिलेंगे यह हर अकाउंट पर अलग होता है।

## xAI / Grok Imagine

क्लाउड सेवा, जिसका डिफ़ॉल्ट Base URL `https://api.x.ai/v1` है। इसके लिए xAI की API कुंजी चाहिए। इमेज जेनरेशन के लिए यह Grok Imagine इस्तेमाल करती है।

## Venice.ai

क्लाउड सेवा, जिसका डिफ़ॉल्ट Base URL `https://api.venice.ai/api/v1` है। इसके लिए Venice की API कुंजी चाहिए। अपने अकाउंट पर उपलब्ध इमेज मॉडल लोड करने के लिए **Fetch Models from API** इस्तेमाल करें। Marinara, Venice का नेटिव इमेज एंडपॉइंट इस्तेमाल करता है, Venice का वैकल्पिक safe-mode ब्लर बंद कर देता है, और माँगे गए डाइमेंशन को हर मॉडल के पिक्सेल, आस्पेक्ट रेशियो या रेज़ोल्यूशन टियर वाले साइज़ फ़ॉर्मैट में अपने आप बदल देता है। फिर भी प्रोवाइडर की नीति या मॉडल की सीमाएँ किसी रिक्वेस्ट को ठुकरा सकती हैं।

## Z.AI

क्लाउड सेवा, जिसका डिफ़ॉल्ट Base URL `https://api.z.ai/api/paas/v4` है। इसके लिए सामान्य Z.AI API कुंजी चाहिए। GLM Coding Plan वाली कुंजियाँ और `/api/coding/paas/v4` एंडपॉइंट इमेज जेनरेशन के लिए काम नहीं करते। **GLM-Image** या **CogView 4** चुनने के लिए **Fetch Models from API** इस्तेमाल करें। Marinara, माँगे गए आस्पेक्ट रेशियो को चुने हुए मॉडल के किसी समर्थित साइज़ में बदलता है, रिक्वेस्ट Z.AI के नेटिव इमेज एंडपॉइंट पर भेजता है, और नतीजे के अस्थायी URL को लोकल स्टोरेज में डाउनलोड कर लेता है। यह पहला वर्ज़न सिर्फ़ टेक्स्ट टू इमेज है और रेफ़रेंस इमेज नहीं भेजता।

## Atlas Cloud

क्लाउड सेवा, जिसका डिफ़ॉल्ट Base URL `https://api.atlascloud.ai/api/v1` है। इसके लिए Atlas Cloud की API कुंजी चाहिए। Marinara, Nano Banana, Gemini Flash Image और FLUX 1.1 Pro के लिए एक छोटा शुरुआती कैटलॉग देता है, और चाहें तो Atlas Cloud का कोई दूसरा इमेज मॉडल ID हूबहू टाइप कर सकते हैं। जॉब असिंक्रोनस चलते हैं, इसलिए Marinara जेनरेशन शुरू करता है और इमेज तैयार होने तक Atlas Cloud से लगातार पूछता रहता है। आम टेक्स्ट टू इमेज कंट्रोल अपने आप मैप हो जाते हैं। जिन मॉडल ID में image-to-image, edit या Kontext व्यवहार बताया गया हो, उनके लिए रेफ़रेंस इमेज भेजी जाती हैं। Atlas के मॉडल स्कीमा अलग-अलग हो सकते हैं, इसलिए कोई दूसरा मॉडल ID इस्तेमाल करते समय उस मॉडल की Atlas Cloud डॉक्यूमेंटेशन देख लें।

## NanoGPT

क्लाउड सेवा, जिसका डिफ़ॉल्ट Base URL `https://nano-gpt.com/api/v1` है। इसके लिए NanoGPT की API कुंजी चाहिए। NanoGPT कई सेवाओं को एक जगह लाता है, इसलिए इसकी मॉडल लिस्ट लोड करने के लिए **Fetch Models from API** इस्तेमाल करें।

## Block Entropy

क्लाउड सेवा, जिसका डिफ़ॉल्ट Base URL `https://api.blockentropy.ai` है। इसके लिए API कुंजी चाहिए। Marinara में Block Entropy के लिए अलग हैंडलर नहीं है, इसलिए वह रिक्वेस्ट OpenAI के अनुकूल फ़ॉर्मैट में भेजता है। असल में यह कितनी अनुकूल है, इसकी पुष्टि नहीं हुई है, इसलिए इस पर भरोसा करने से पहले **Test Image** से जाँच लें।

## RunPod Serverless (ComfyUI)

क्लाउड सेवा, जिसका डिफ़ॉल्ट Base URL `https://api.runpod.ai/v2` है। यह RunPod के सर्वरलेस एंडपॉइंट पर ComfyUI वर्कफ़्लो चलाती है। इसके लिए तीन चीज़ें चाहिए: **API Key** के तौर पर आपका RunPod API टोकन, एक **RunPod Endpoint ID**, और एक **ComfyUI Workflow** JSON। नीचे ComfyUI वर्कफ़्लो वाला सेक्शन देखें।

## Pollinations

मुफ़्त क्लाउड सेवा, जिसका डिफ़ॉल्ट Base URL `https://image.pollinations.ai` है। इसके लिए न अकाउंट चाहिए, न API कुंजी। इमेज जेनरेशन आज़माने का यह सबसे तेज़ तरीका है।

## Stable Horde

मुफ़्त क्लाउड सेवा, जिसका डिफ़ॉल्ट Base URL `https://stablehorde.net/api/v2` है। यह क्राउडसोर्स नेटवर्क है। API कुंजी वैकल्पिक है। मुफ़्त कुंजी लेने पर कतार में ज़्यादा प्राथमिकता मिलती है।

## SD Web UI (AUTOMATIC1111 / Forge)

लोकल सेवा, जिसका डिफ़ॉल्ट Base URL `http://localhost:7860` है। यह आपके अपने कंप्यूटर पर चल रहे Stable Diffusion Web UI से बात करती है। उस सॉफ़्टवेयर को उसके ऐप्लिकेशन इंटरफ़ेस के साथ चालू करना ज़रूरी है। API कुंजी की ज़रूरत नहीं।

## ComfyUI

लोकल सेवा, जिसका डिफ़ॉल्ट Base URL `http://127.0.0.1:8188` है। यह आपके अपने कंप्यूटर पर चल रहे ComfyUI सर्वर से बात करती है। इसमें अपना वर्कफ़्लो भी दिया जा सकता है, जिसका ब्योरा नीचे है। API कुंजी की ज़रूरत नहीं।

## Draw Things

लोकल सेवा, जिसका डिफ़ॉल्ट Base URL `http://localhost:7860` है। यह macOS या iOS पर Draw Things ऐप से बात करती है। Marinara इसे AUTOMATIC1111 सर्वर की तरह ही मानता है। API कुंजी की ज़रूरत नहीं।

## आपके नेटवर्क पर चलने वाली लोकल सेवाएँ

`localhost` शब्द (जिसे loopback भी कहते हैं) का मतलब है वही कंप्यूटर, जिस पर Marinara चलता है। उसी कंप्यूटर पर चल रहे लोकल इमेज सर्वर बिना किसी अतिरिक्त सेटअप के काम करते हैं।

अगर इमेज सर्वर आपके घरेलू नेटवर्क के किसी दूसरे कंप्यूटर पर चलता है, तो सर्वर कॉन्फ़िगरेशन में लोकल नेटवर्क पते की छूट देनी पड़ेगी। यह कैसे करना है, इसके लिए [सर्वर कॉन्फ़िगरेशन रेफ़रेंस](../CONFIGURATION.md) देखें।

जब कोई प्रोवाइडर इमेज बाइट के बजाय URL लौटाता है, तो Marinara सार्वजनिक CDN URL को अपनी सामान्य आउटबाउंड रिक्वेस्ट सुरक्षा जाँचों से गुज़ारकर डाउनलोड करता है। प्राइवेट या loopback वाला रिज़ल्ट URL तभी माना जाता है, जब उसका scheme, होस्टनेम और पोर्ट सेट किए गए इमेज प्रोवाइडर से हूबहू मिलते हों। उस प्राइवेट ऑरिजिन से आने वाले रीडायरेक्ट किसी दूसरी लोकल सेवा पर नहीं जा सकते। अगर कोई लोकल प्रॉक्सी नतीजे किसी दूसरे प्राइवेट ऑरिजिन पर रखती है, तो प्रॉक्सी को ऐसे सेट करें कि वे फ़ाइलें उसी ऑरिजिन से मिलें, जिस पर उसका इमेज API है।

## ComfyUI वर्कफ़्लो JSON और RunPod

**ComfyUI** और **RunPod Serverless (ComfyUI)** के लिए एक **ComfyUI Workflow** फ़ील्ड दिखती है। ComfyUI से एक्सपोर्ट किया हुआ वर्कफ़्लो JSON उसमें पेस्ट करें। फ़्रंटएंड के वर्ज़न के हिसाब से एक्सपोर्ट का विकल्प **Save (API Format)**, **Export (API)** या **Export to API** होता है। **ComfyUI** में इस फ़ील्ड पर Optional लिखा रहता है और **RunPod Serverless (ComfyUI)** में Required।

Marinara आपके वर्कफ़्लो को प्लेसहोल्डर के ज़रिए भरता है। वर्कफ़्लो में जहाँ वैल्यू आनी चाहिए, वहाँ ये टेक्स्ट मार्कर लगाएँ।

- प्रॉम्प्ट के लिए `%prompt%` और `%negative_prompt%`।
- इमेज के साइज़ और सीड के लिए `%width%`, `%height%` और `%seed%`।
- जेनरेशन सेटिंग्स के लिए `%model%`, `%steps%`, `%cfg%`, `%sampler%`, `%scheduler%` और `%denoise%`।
- रेफ़रेंस इमेज का डेटा जोड़ने के लिए `%reference_image%` और `%reference_image_01%` से `%reference_image_04%` तक।
- रेफ़रेंस इमेज अपलोड करके उनके फ़ाइल नाम लोकल ComfyUI के LoadImage नोड में जोड़ने के लिए `%reference_image_name%` और `%reference_image_name_01%` से `%reference_image_name_04%` तक।

सबसे अहम प्लेसहोल्डर `%prompt%` है। यह छूट जाए तो एडिटर चेतावनी देता है। **ComfyUI** में फ़ील्ड खाली छोड़ने पर बिल्ट-इन डिफ़ॉल्ट वर्कफ़्लो चलता है। **RunPod Serverless (ComfyUI)** में वर्कफ़्लो देना ज़रूरी है, क्योंकि एंडपॉइंट पर कोई डिफ़ॉल्ट नहीं होता। दोनों ज़्यादा से ज़्यादा 4 कच्ची base64 रेफ़रेंस इमेज लेते हैं, और फ़ाइल नाम अपलोड वाले प्लेसहोल्डर सिर्फ़ लोकल ComfyUI में मिलते हैं।

एक्सपोर्ट की पूरी प्रक्रिया, JSON के उदाहरण, प्लेसहोल्डर पर उद्धरण-चिह्न के नियम, रेफ़रेंस इमेज का सेटअप, किसी खास कैरेक्टर के वर्कफ़्लो, LAN एक्सेस और समस्याओं के हल के लिए [ComfyUI वर्कफ़्लो सेटअप](comfyui.md) देखें।

## हर कनेक्शन के लिए Local Image Defaults

जब सेवा **SD Web UI (AUTOMATIC1111 / Forge)**, **ComfyUI**, **NovelAI** या **Draw Things** हो, तो कनेक्शन पर **Local Image Defaults** पैनल दिखता है। **Draw Things** के लिए इस पैनल में वही फ़ील्ड और वही डिफ़ॉल्ट होते हैं जो **SD Web UI (AUTOMATIC1111 / Forge)** के लिए हैं। ये सेटिंग्स सिर्फ़ तब लगती हैं, जब यही कनेक्शन कोई इमेज जेनरेट करता है। **Reset** बटन से बिल्ट-इन वैल्यू वापस आ जाती हैं।

इन चारों सेवाओं में **Seed** फ़ील्ड दिखती है। -1 रखने पर हर इमेज रैंडम रहती है। कोई और नंबर डालने पर हर बार वही सीड दोबारा इस्तेमाल होता है।

बाकी फ़ील्ड सेवा के हिसाब से बदलती हैं।

| सेवा | फ़ील्ड | डिफ़ॉल्ट |
| --- | --- | --- |
| AUTOMATIC1111 / Forge | Steps | 20 |
| AUTOMATIC1111 / Forge | CFG Scale | 7 |
| AUTOMATIC1111 / Forge | Sampler | Euler a |
| AUTOMATIC1111 / Forge | Img2Img Denoise | 0.6 |
| ComfyUI | Steps | 20 |
| ComfyUI | CFG Scale | 7 |
| ComfyUI | Sampler | euler_ancestral |
| ComfyUI | Scheduler | normal |
| ComfyUI | Denoise | 1 |
| NovelAI | Steps | 28 |
| NovelAI | Prompt Guidance | 6 |
| NovelAI | Sampler | k_euler_ancestral |
| NovelAI | Noise Schedule | karras |

हर सेवा में **Prompt Prefix** और **Negative Prefix** टेक्स्ट फ़ील्ड भी होती हैं। इनमें लिखा टेक्स्ट इस कनेक्शन के हर प्रॉम्प्ट की शुरुआत में जुड़ जाता है। AUTOMATIC1111 / Forge और ComfyUI, दोनों में **Clip Skip** फ़ील्ड है। AUTOMATIC1111 / Forge में एक **Restore faces** टॉगल और मिलता है। ComfyUI में **Upload a 1x1 placeholder when no reference image is provided** नाम का टॉगल जुड़ता है। यह सिर्फ़ उन कस्टम वर्कफ़्लो के लिए मायने रखता है, जिनमें रेफ़रेंस इमेज के प्लेसहोल्डर हों। NovelAI में **Guidance Rescale** और **UC Preset** फ़ील्ड और जुड़ती हैं।

## रेफ़रेंस इमेज का सपोर्ट हर प्रोवाइडर पर अलग है

**रेफ़रेंस इमेज** यानी कोई पहले से मौजूद तस्वीर, जिसे प्रॉम्प्ट के साथ भेजा जाता है। इससे नई इमेज में कैरेक्टर का चेहरा या आर्ट स्टाइल बना रहता है। कौन प्रोवाइडर कितनी इमेज लेता है, यह हर जगह अलग है।

| प्रोवाइडर | रेफ़रेंस इमेज |
| --- | --- |
| OpenAI (DALL-E) | ज़्यादा से ज़्यादा 16 |
| NovelAI | ज़्यादा से ज़्यादा 16, सिर्फ़ V4.5 मॉडल पर |
| xAI / Grok Imagine | ज़्यादा से ज़्यादा 3 |
| Venice.ai | टेक्स्ट टू इमेज जेनरेशन में सपोर्ट नहीं |
| Z.AI | मौजूदा टेक्स्ट टू इमेज इंटीग्रेशन में सपोर्ट नहीं |
| Atlas Cloud | image-to-image, edit या Kontext वाले अनुकूल मॉडल ID के लिए पहली इमेज |
| NanoGPT | ज़्यादा से ज़्यादा 3 |
| Stability AI | सिर्फ़ पहली इमेज, image to image के तौर पर |
| OpenRouter Images | सपोर्ट है, कोई तय सीमा नहीं |
| ComfyUI और RunPod Serverless (ComfyUI) | ज़्यादा से ज़्यादा 4, वर्कफ़्लो प्लेसहोल्डर से |
| Together AI, Pollinations, Stable Horde | सपोर्ट नहीं |

NovelAI की सटीक रेफ़रेंस इमेज सिर्फ़ V4.5 मॉडल पर चलती हैं, जैसे `nai-diffusion-4-5-full`। NovelAI ने अभी V5 के लिए Precise Reference जारी नहीं किया है। किसी दूसरे मॉडल पर रेफ़रेंस माँगने पर Marinara उनके बिना इमेज बनाता है और सर्वर लॉग में चेतावनी दर्ज करता है।

## Queue image generation requests टॉगल

**Queue image generation requests** टॉगल **Settings** (सेटिंग्स), फिर **Generations**, फिर **Image Generation** में मिलता है। यह डिफ़ॉल्ट रूप से चालू रहता है।

चालू होने पर Marinara इमेज जॉब एक बार में एक ही भेजता है। जो सेवाएँ एक साथ दो रिक्वेस्ट नहीं लेतीं, उनके लिए इसे चालू रखें। इसे तभी बंद करें, जब आपकी सेवा एक साथ कई रिक्वेस्ट संभाल लेती हो और नतीजे जल्दी चाहिए हों।
