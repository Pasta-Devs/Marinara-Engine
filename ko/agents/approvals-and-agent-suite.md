# 에이전트 승인과 Agent Suite

이 가이드에서는 채팅 중에 에이전트(답변과 나란히 자동으로 실행되는 작은 AI 기능)가 무엇을 쓰는지 확인하고 통제하는 방법을 설명합니다. **Review Agent Outputs**(에이전트 출력 검토) 토글, 두 가지 검토 창, **Agent Suite**(에이전트 모음) 편집기, **Cached prompt injections**(캐시된 프롬프트 삽입) 패널을 다룹니다.

## Review Agent Outputs

일부 에이전트는 채팅에 새 데이터를 기록하려고 합니다. 로어북 에이전트는 로어북 항목을 추가할 수 있고, 요약 에이전트는 채팅 요약을 저장할 수 있습니다. 기본값에서는 이런 기록 중 일부가 자동으로 저장됩니다. **Review Agent Outputs** 토글을 켜면 기록 하나하나를 먼저 확인할 수 있습니다.

토글은 다음 위치에 있습니다.

1. 통제하려는 채팅을 여세요.
2. **Chat Settings**(채팅 설정)를 여세요.
3. **Agents**(에이전트) 섹션까지 스크롤하세요.
4. **Review Agent Outputs**를 켜세요.

**Review Agent Outputs**가 켜져 있으면 로어북 업데이트, 요약 업데이트를 비롯해 검토 대상인 쓰기 에이전트의 출력이 승인을 받을 때까지 저장되지 않고 대기합니다. 꺼져 있으면 로어북과 요약 업데이트가 자동으로 저장될 수 있습니다.

캐릭터 카드 편집은 예외입니다. **Review Agent Outputs**가 꺼져 있어도 항상 먼저 승인을 요청합니다. 이 안전 장치는 끌 수 없습니다.

## 에이전트 쓰기 승인 창

**Review Agent Outputs**가 켜진 상태에서 에이전트가 로어북이나 요약 기록을 제안하면 검토 창이 열립니다. 기록 종류에 따라 창 제목은 **Review Lorebook Update**(로어북 업데이트 검토) 또는 **Review Summary Update**(요약 업데이트 검토)가 됩니다.

창에는 다음 내용이 표시됩니다.

- 제안을 낸 에이전트의 이름.
- 저장하기 전에 직접 고칠 수 있는 **Proposed Text**(제안된 텍스트) 입력란.
- 로어북 기록일 때는 각 항목을 `###` 제목 아래에 두라는 짧은 안내.

창 아래쪽에서는 세 가지 중에 고를 수 있습니다.

- **Accept**(수락): 고친 내용까지 반영해서 텍스트를 채팅에 저장합니다.
- **Regenerate**(재생성): 해당 에이전트 하나만 다시 실행해서 새 제안을 받습니다.
- **Discard**(변경 취소): 제안을 저장하지 않고 버립니다.

대기 중인 제안이 둘 이상이면 아직 몇 개가 남았는지 창에 표시됩니다. 지금 것을 처리하고 나면 다음 제안으로 창이 다시 열립니다.

## 캐릭터 카드 업데이트 검토

**Card Evolution Auditor** 에이전트는 롤플레이에서 벌어진 일을 바탕으로 캐릭터 카드 필드를 어떻게 고칠지 제안할 수 있습니다. Conversation 모드에 내장된 `update_about_me` 도구도 공개 About Me 변경을 제안할 수 있습니다. 어느 쪽도 카드를 마음대로 고치지는 않습니다. 둘 다 **Review Character Card Updates**(캐릭터 카드 업데이트 검토) 창을 열어 판단을 맡깁니다.

이 창에는 제안된 편집이 하나씩 나열됩니다. 편집마다 다음 내용을 볼 수 있습니다.

- 대상이 되는 카드 필드(예: description, personality, appearance).
- 에이전트가 이유를 밝혔다면 그 짧은 설명.
- 현재 텍스트를 보여 주는 **Before**(변경 전) 영역.
- 새 텍스트가 들어 있는 **After**(변경 후) 입력란. 승인하기 전에 이 텍스트를 고칠 수 있습니다.

사용할 수 있는 동작은 다음과 같습니다.

- **Approve**(승인): 편집을 적용합니다. 버튼의 숫자는 적용될 편집 개수입니다. 승인하면 캐릭터의 버전 번호가 올라가고 버전 기록 항목이 저장됩니다.
- **Regenerate**: 에이전트를 다시 실행해서 제안을 새로 받습니다.
- **Reject**(거부): 카드를 그대로 두고 제안을 닫습니다.

에이전트가 제안을 만든 뒤에 카드가 바뀌는 경우도 있습니다. 그러면 앱이 해당 편집에 **stale**(오래됨) 표시를 붙이고 흐리게 보여 줍니다. 오래됨으로 표시된 편집이 하나라도 있으면 개수가 적힌 **Override stale**(오래된 항목 덮어쓰기) 버튼이 나타납니다. 그 텍스트를 그래도 반영하고 싶을 때만 쓰세요. 앱이 먼저 확인을 요청합니다. 이후에는 이미 달라진 텍스트를 덮어쓰는 대신, 오래됨으로 표시된 텍스트를 해당 필드에 덧붙입니다.

## Agent Suite 편집기와 AI 다시 쓰기

**Agent Suite**에서는 이 채팅의 에이전트들이 저장해 둔 내용을 전부 보고 고칠 수 있습니다. 트래커 데이터(현재 장면, 등장 중인 캐릭터, 페르소나 능력치 등)와 사용자 지정 에이전트가 저장한 출력이 모두 여기에 들어갑니다. 잘못된 이름을 바로잡거나 능력치를 고치거나 엉킨 저장 텍스트를 정리하는 작업을 직접 할 수도 있고 AI에 맡길 수도 있습니다.

여는 방법은 다음과 같습니다.

1. **Chat Settings**(채팅 설정)를 여세요.
2. **Agents** 섹션까지 스크롤하세요.
3. **Agent Suite**를 클릭하세요.

왼쪽에는 이 채팅에서 활동 중인 에이전트 목록이 있습니다. 하나를 고르면 그 에이전트가 저장한 내용이 나옵니다. 오른쪽에는 고칠 수 있는 블록이 표시되며, **Stored Memory**(저장된 기억), **Tracker Data**(트래커 데이터, 트래커 에이전트만 해당), **Recent Outputs**(최근 출력, 사용자 지정 에이전트만 해당)로 묶여 있습니다. 데이터를 추적하지 않는 에이전트는 **Stored Memory**만 표시합니다.

각 블록은 텍스트 편집기이거나 JSON 편집기입니다. 블록을 고친 뒤에는 이렇게 하세요.

- **Save**(저장)를 클릭하면 고친 내용이 유지됩니다.
- **Reset**(초기화)을 클릭하면 저장하지 않은 변경을 되돌리고 저장된 값으로 돌아갑니다.

블록을 AI에 맡겨 다시 쓰게 할 수도 있습니다.

1. 바꾸려는 블록에서 **AI Edit**(AI 편집)를 클릭하세요.
2. 일부만 바꾸려면 편집기에서 그 부분을 먼저 선택하세요. 아무것도 선택하지 않으면 블록 전체를 다시 씁니다.
3. 지시를 입력하세요. 예를 들면 "깨진 캐릭터 이름을 고치세요. 그 캐릭터의 이름은 Mira입니다."처럼 씁니다.
4. 선택 사항: **Add Context**(컨텍스트 추가)를 클릭해서 캐릭터 카드나 로어북 항목을 붙일 수 있습니다. 데이터가 무슨 뜻인지 AI가 이해하는 데 도움이 됩니다.
5. 다시 쓰기를 맡길 연결(AI 제공자와 모델)을 고르세요.
6. **Rewrite**(재작성)를 클릭하세요.

다시 쓴 텍스트는 저장되지 않은 초안 상태로 블록에 들어갑니다. 내용을 확인하고 **Save**를 클릭해서 남기거나 **Reset**을 클릭해서 버리세요.

몇 가지 유의할 점이 있습니다.

- 이 채팅의 에이전트가 아직 실행 중이면 실행이 끝날 때까지 저장이 보류됩니다.
- **Stored Memory** 섹션에는 **Clear memory**(기억 지우기) 버튼이 하나 있습니다. 이 버튼은 에이전트가 저장한 데이터가 있을 때만 나타납니다. 해당 에이전트가 이 채팅에 저장한 내용을 한 번에 모두 삭제하며, 되돌릴 수 없습니다. 앱이 먼저 확인을 요청합니다.
- **Narrative Director**는 저장된 스포일러를 가려 둡니다. **Reveal spoilers**(스포일러 보기)를 눌러야 내용을 보고 고칠 수 있습니다.

## Cached prompt injections 패널

답변이 생성되기 전에 일부 쓰기 에이전트가 프롬프트에 텍스트를 덧붙입니다. **Prose Guardian**, **Narrative Director**, 사용자 지정 주입 에이전트에서 흔히 일어나는 일입니다. **Cached prompt injections** 패널은 그렇게 덧붙은 텍스트를 확인하는 문제 해결용 화면입니다. Roleplay 채팅의 **Agent activity**(에이전트 활동)에 있는 **Injections**(삽입) 탭에서 확인할 수 있습니다. 이 탭은 **Debug mode**(디버그 모드)가 켜져 있을 때 나타납니다. [에이전트 활동](../roleplay/getting-started.md#agent-activity)을 참고하세요. 가장 최근 답변을 대상으로 합니다.

캐시된 주입마다 다음 작업을 할 수 있습니다.

- 펼쳐서 텍스트를 읽고 고치기.
- **Save** 아이콘을 클릭해 고친 내용 저장하기.
- **Re-run**(다시 실행) 아이콘을 클릭해 그 에이전트 하나만 주입을 새로 쓰게 하기.

**Knowledge Retrieval**과 **Knowledge Router**의 주입은 이 패널에서 다시 실행할 수 없습니다. 고친 내용과 다시 실행한 결과는 같은 답변을 재생성해야 반영됩니다. 다시 실행할 때는 그 시점의 원래 채팅 기록을 사용하며, 이후에 추가된 메시지는 쓰지 않습니다.
