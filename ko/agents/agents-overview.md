# 에이전트: 채팅을 도와주는 AI

이 가이드에서는 Marinara Engine의 에이전트가 무엇인지, 어떻게 다운로드하고 언제 실행되며 채팅에서 어떻게 켜는지 설명합니다. **Agents**(에이전트) 패널, 공식 카탈로그, 채팅별 설정, 에이전트가 실행됐는지 확인하는 방법을 다룹니다. 공식 카탈로그 전체는 문서 끝의 관련 가이드를 참고하세요.

## 에이전트란

에이전트는 채팅 답변 앞뒤에서 자동으로 실행되는 작은 AI 기능입니다. 캐릭터와 대화하는 동안 정해진 한 가지 일을 맡아 처리합니다. 예를 들어 어떤 에이전트는 시간과 날씨를 기록하거나 캐릭터의 표정을 고릅니다. 반복되는 표현을 지우려고 답변을 다시 쓰는 에이전트도 있습니다. 중요한 장면의 이미지를 생성하는 에이전트도 있습니다.

에이전트는 캐릭터가 아니라 채팅 단위로 켭니다. 캐릭터 카드에는 에이전트 스위치가 없습니다. 같은 캐릭터로 만든 채팅 두 개가 서로 완전히 다른 에이전트를 실행할 수도 있습니다. 어떤 에이전트를 실행할지는 각 채팅의 설정에서 고릅니다.

Marinara Engine을 새로 설치하면 선택형 에이전트는 하나도 들어 있지 않습니다. 기본 앱과 Termux 설치 용량을 줄이기 위해서입니다. v2.3.0 이상의 공식 카탈로그에는 클릭 한 번으로 설치하는 패키지 33개가 있습니다. Writer Agents 6개, Tracker Agents 9개, Misc Agents 18개이며 Long-Term Memory, Maps, Calls, Inventory Tracker와 Conversation 게임 6종이 모두 포함됩니다. 소스와 매니페스트, 다운로드할 수 있는 아티팩트, 저장소 단위 카탈로그는 [Pasta-Devs/Marinara-Agents](https://github.com/Pasta-Devs/Marinara-Agents)에 공개돼 있습니다. 에이전트별 자세한 안내는 [다운로드 가능한 에이전트 레퍼런스](built-in-agents.md)를 참고하세요. 직접 만들려면 [사용자 지정 에이전트 만들기](custom-agents.md)를 참고하세요.

## 실행 시점 3가지

모든 에이전트는 답변을 기준으로 세 지점 중 한 곳에서 실행됩니다. 이 지점을 에이전트의 **pipeline phase**(파이프라인 단계)라고 합니다. 에이전트 편집기에서 지정하며, 기본 제공 에이전트에는 이미 알맞은 기본값이 들어 있습니다.

- **Pre-Generation**(생성 전): AI가 답변을 쓰기 전에 실행됩니다. 프롬프트에 필요한 컨텍스트를 먼저 넣을 수 있습니다. 지식을 찾아오는 에이전트가 여기서 실행됩니다.
- **Parallel**(병렬): 답변과 동시에 실행됩니다. 답변을 기다리지 않고, 답변을 바꾸지도 못합니다. 실시간 관객 반응 에이전트가 여기서 실행됩니다.
- **Post-Processing**(후처리): 답변이 끝난 뒤에 실행됩니다. 답변을 읽을 수 있고, 다시 쓰는 에이전트라면 답변을 수정할 수도 있습니다. 대부분의 트래커와 문장 정리 에이전트, 이미지 에이전트가 여기서 실행됩니다.

## Agents 패널

오른쪽 패널 탭(Sparkles 아이콘)에서 **Agents** 패널을 여세요. 여기서 에이전트를 둘러보고, 만들고, 정리합니다. 이 패널은 보관함입니다. 개별 채팅에서 에이전트를 켜고 끄는 스위치가 아닙니다.

위쪽의 **Download Agents**(에이전트 다운로드)를 클릭하면 전체 화면으로 공식 카탈로그가 열립니다. 데스크톱과 모바일 모두에서 쓸 수 있습니다. 항목을 선택하면 설명, 지원하는 기능 종류, 다운로드 용량, 권한, 버전 호환성, 문서를 볼 수 있습니다. **Install**(설치)을 클릭하면 추가됩니다. 이미 설치한 패키지는 같은 화면에서 바로 수동으로 업데이트하거나 **Uninstall**(제거)할 수 있습니다. 또한 Marinara는 서버가 시작될 때 설치된 공식 패키지를 모두 확인해서, 각 패키지가 동작을 시작하기 전에 호환되는 최신 카탈로그 버전으로 올립니다. 호스트 서버가 오프라인이거나 업데이트를 검증할 수 없을 때는 패키지가 현재 버전 그대로 계속 동작합니다.

앱 안의 카탈로그는 공개된 [Marinara-Agents 저장소](https://github.com/Pasta-Devs/Marinara-Agents)를 기반으로 합니다. 모든 패키지와 아티팩트를 저장소에서 직접 확인할 수 있지만, 보통은 **Download Agents**를 통해 설치하는 편이 좋습니다. 그래야 Marinara가 호환성, 권한, 해시, 아카이브 내용, 재시작 필요 여부를 검증합니다.

카탈로그에는 공식 채팅 에이전트, World Maps, Conversation의 음성 및 영상 통화, 선택형 Conversation 게임이 모두 들어 있습니다. 설치한 에이전트는 **Writer Agents**(작가 에이전트), **Tracker Agents**(추적 에이전트), **Misc Agents**(기타 에이전트)로 묶이고, 직접 만든 에이전트는 **Custom Agents**(커스텀 에이전트) 항목에 모입니다. 카탈로그 패키지를 제거하면 그 코드와 설정이 Engine에서 지워지지만 채팅 메시지와 기록은 그대로 남습니다. 직접 만든 에이전트를 삭제하면 완전히 사라집니다.

이런 기능이 기본 포함돼 있던 Engine 버전에서 업데이트하면 Marinara가 해당 패키지를 한 번 다운로드하고, 기존 채팅의 선택 상태와 에이전트 설정, 저장된 실행 데이터, 기록을 그대로 유지합니다. 이 이관 과정에서 카탈로그에 연결하지 못하면 아무것도 버리지 않고 다음 시작 때 다시 시도합니다.

시작할 때 이뤄지는 자동 업데이트가 선택하지 않은 패키지를 설치하는 일은 없습니다. 데스크톱, Docker, Android/Termux 설치본은 각자의 로컬 서버에 저장된 패키지를 업데이트합니다. iOS, iPadOS를 비롯한 브라우저 클라이언트는 접속한 Marinara 서버가 설치하고 업데이트한 패키지를 사용합니다.

## 채팅에서 에이전트 켜기

에이전트는 각 채팅 안의 **Chat Settings**(채팅 설정) 패널에서 켭니다.

1. 원하는 채팅을 여세요.
2. 톱니바퀴 아이콘을 눌러 **Chat Settings**를 여세요.
3. **Agents** 섹션을 찾으세요.
4. **Enable Agents**(에이전트 활성화)를 켜세요. 전체 스위치입니다. 꺼져 있으면 이 채팅에서는 어떤 에이전트도 실행되지 않습니다.
5. 스위치 아래 목록에서 원하는 에이전트를 추가하거나, 필요 없는 에이전트를 빼세요.

추가한 에이전트는 활성 목록에 표시되고, 항목마다 작은 제거 버튼이 붙습니다.

**Agents** 섹션에는 다음 설정도 있습니다.

- **Review Agent Outputs**(에이전트 출력 검토): 켜면 로어북, 요약, 캐릭터 카드 변경 사항이 저장되기 전에 승인을 기다립니다. 끄면 로어북과 요약 변경은 저절로 저장되지만, 캐릭터 카드 수정은 여전히 먼저 확인을 거칩니다. [에이전트 승인과 Agent Suite](approvals-and-agent-suite.md)를 참고하세요.
- **Manual Trackers**(트래커 작동 설정, Roleplay 채팅 전용): 켜면 트래커 에이전트가 답변마다 실행되지 않습니다. HUD의 버튼을 눌러 직접 실행합니다. HUD는 heads-up display의 약자로, Roleplay 화면 위에 겹쳐 표시되는 정보 막대입니다.
- **Agent Suite**(에이전트 모음): 이 채팅에서 에이전트가 저장해 둔 내용을 모두 읽고 수정할 수 있는 뷰어를 엽니다.

### 비용 경고

에이전트를 쓰면 토큰과 모델 호출이 추가로 발생합니다. 에이전트마다 자체 지시문이 붙고, 대개 모델 호출도 따로 일어납니다. 같은 연결을 쓰는 에이전트는 가능하면 Marinara가 한 번의 호출로 묶습니다. 에이전트 목록 위에는 현재 구성의 부담을 어림해 보여 주는 표시가 있습니다. 추가된 에이전트 지시문이 대략 몇 토큰인지, 턴마다 호출이 몇 번 더 일어나는지 알려 줍니다.

부담이 커지면 이 표시가 주황색으로 바뀌고 경고 아이콘이 붙습니다. 턴당 실제 비용은 표시된 값보다 큽니다. 호출할 때마다 채팅 기록과 캐릭터 정보가 함께 전송되기 때문입니다. 경고가 보이면 필요 없는 에이전트를 빼거나, 일부를 더 저렴한 연결이나 로컬 연결로 옮기세요.

## 모드별 기본 에이전트

새로 설치한 직후에는 선택형 에이전트가 설치돼 있지도, 활성화돼 있지도 않습니다. 각 채팅 모드에는 설치한 패키지 중 호환되는 것만 표시됩니다.

- **Roleplay**: 카탈로그에서 Roleplay 에이전트를 설치한 다음 Chat Settings에서 추가하세요. World Maps도 다른 지원 에이전트와 똑같이 목록에 나타납니다.
- **Conversation**: 카탈로그에서 Calls나 개별 테이블 게임을 설치하세요. 게임은 게임 선택기에 나타나고 각자의 슬래시 명령어를 등록합니다. Calls는 전용 툴바와 Chat Settings 설정을 추가합니다.
- **Game Mode**: Game Mode와 호환되는 에이전트를 설치했다면 게임을 만들 때 선택하거나 나중에 추가할 수 있습니다. World Maps는 그 게임에서 활성화된 경우에만 지도 작업 공간과 세계 지도 화면을 제공합니다.

호환되는 에이전트는 언제든지 추가하거나 뺄 수 있습니다.

## 에이전트가 실행됐는지 확인하기

어떤 에이전트는 눈에 보이는 변화를 바로 만들고, 어떤 에이전트는 조용히 일합니다. 실행 여부는 다음과 같이 확인합니다.

- 트래커 에이전트는 HUD와 트래커 패널에 내용을 씁니다. 시간, 장소, 기분, 능력치가 바뀌었다면 트래커 에이전트가 실행된 것입니다.
- 에이전트가 작업하는 동안 화면에 떠 있는 상태 표시에 짧은 진행 메시지가 나옵니다. 실행되는 모습을 실시간으로 볼 수 있습니다.
- **Prose Guardian**과 **Continuity Checker** 에이전트는 답변 텍스트 자체를 고칩니다. 답변이 다듬어지거나 바로잡혔다면 이 에이전트가 실행된 것입니다.
- 전체 과정을 추적하려면 **Settings**(설정) > **Advanced**(고급) > **Message Tools**(메시지 도구)에서 **Debug mode**(디버그 모드)를 켜세요. 에이전트마다 프롬프트와 응답이 서버 콘솔에 기록됩니다. 에이전트별 호출 횟수와 토큰, 소요 시간을 보여 주는 **Agent Debug** 오버레이도 함께 표시됩니다.

실행될 줄 알았던 에이전트가 동작하지 않았나요? **Enable Agents**가 켜져 있는지 확인하세요. 그 에이전트가 이 채팅에서 활성 상태인지 확인하세요. 현재 채팅 모드가 그 에이전트를 지원하는지 확인하세요.
