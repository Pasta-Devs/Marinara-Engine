# 에이전트: 채팅을 도와주는 AI

에이전트는 기본 채팅 답변 앞뒤에서 실행되는 작은 AI 도우미입니다. 어떤 에이전트는 시간과 날씨를 기록하고, 어떤 에이전트는 캐릭터의 표정을 고르고, 또 어떤 에이전트는 중요한 장면의 이미지를 그립니다. 이 가이드에서는 에이전트를 설치하고, 채팅에서 켜고, 실행됐는지 확인하는 방법을 설명합니다.

## 에이전트란

에이전트는 캐릭터가 아니라 채팅 단위로 켭니다. 같은 캐릭터로 만든 채팅 두 개가 서로 다른 에이전트를 실행할 수 있습니다.

새로 설치한 상태에는 선택형 에이전트가 하나도 없습니다. 공식 패키지를 한 번의 클릭으로 설치하는 스토어인 **Agent Organizer**에서 설치하세요. 소스와 카탈로그는 [Pasta-Devs/Marinara-Agents](https://github.com/Pasta-Devs/Marinara-Agents)에 공개되어 있습니다. Marinara가 호환성, 권한, 파일 해시를 확인할 수 있도록 **Agent Organizer**를 통해 설치하세요. 에이전트별로 하는 일은 [다운로드 가능한 에이전트 레퍼런스](built-in-agents.md)를, 직접 만드는 방법은 [사용자 지정 에이전트 만들기](custom-agents.md)를 참고하세요.

## 채팅에 에이전트 추가하기

시작하기 전에: 먼저 에이전트를 설치하세요. **Agents**(에이전트) 패널(오른쪽 탭의 Sparkles 아이콘)을 열고 **Agent Organizer**를 클릭한 다음, 에이전트 페이지를 열고 **Get**(받기)을 클릭하세요. [에이전트 설치와 업데이트](#install-and-update-agents)를 참고하세요.

1. 채팅을 여세요.
2. **Chat Settings**(채팅 설정)를 열고 **Agents** 섹션을 찾으세요.
3. **Enable Agents**(에이전트 활성화)를 켜세요. 전체 스위치이므로, 꺼져 있으면 이 채팅에서는 어떤 에이전트도 실행되지 않습니다.
4. **Add Agent**(에이전트 추가)를 클릭하고 에이전트가 속한 그룹(**Writer Agents**(작성 에이전트)나 **Misc Agents**(기타 에이전트) 등)을 연 다음 에이전트를 고르세요.

추가한 에이전트는 활성 상태로 표시되며, 항목마다 작은 제거 버튼이 붙습니다. 에이전트는 언제든 추가하거나 뺄 수 있습니다.

> **참고:** 각 채팅 모드에는 그 모드에서 동작하는 에이전트만 표시됩니다. Conversation(대화)에서는 설치한 게임이 게임 선택기에 나타나고 **Calls**가 툴바 컨트롤을 추가합니다. Game Mode(게임 모드)에서는 게임을 만들 때 에이전트를 고르거나 나중에 추가하세요.

에이전트가 실행되지 않았다면 **Enable Agents**가 켜져 있는지, 그 에이전트가 이 채팅에서 활성 상태인지, 에이전트의 모드가 채팅과 맞는지 확인하세요.

### Agents 섹션의 다른 컨트롤

다음 컨트롤도 같은 **Agents** 섹션에 있습니다.

- **Agent Menus**(에이전트 메뉴, Roleplay 전용): 에이전트 이름을 클릭하면 그 에이전트의 설정으로 이동합니다.
- **Trackers Control**(트래커 제어, Roleplay 전용): 아래의 트래커 옵션이 들어 있는 카드로, 처음에는 닫혀 있습니다.
- **Agent Suite**(에이전트 모음): 이 채팅에서 에이전트가 저장한 내용을 읽고 수정할 수 있는 뷰어를 엽니다.
- **Review Agent Outputs**(에이전트 출력 검토): 로어북, 요약, 캐릭터 카드 변경 사항이 승인을 기다리게 합니다. Roleplay에서는 **Trackers Control** 안에 있습니다. [에이전트 승인과 Agent Suite](approvals-and-agent-suite.md)를 참고하세요.

**Trackers Control** 안의 옵션은 다음과 같습니다.

- **Attach chat summaries**(채팅 요약 첨부): 기본값은 꺼짐입니다. 저장된 채팅 요약을 재시도를 포함한 에이전트 요청에 추가합니다. 기본 답변에서 요약을 빼거나 요약 생성을 멈추지는 않습니다. 기본 프롬프트 전체에 접근할 수 있는 에이전트는 여전히 그 안의 요약을 읽을 수 있습니다.
- **Attach Lorebooks to Trackers**(로어북을 트래커에 연결): 트래커 에이전트도 기본 답변에 쓰인 로어북 항목을 받습니다. 채팅에 트래커 에이전트가 있으면 나타납니다.
- **Individual tracker schedule**(개별 트래커 스케줄): 트래커가 답변마다 실행되지 않게 합니다. 대신 HUD(Roleplay 화면 위에 겹쳐 표시되는 상태 오버레이)에서 직접 실행합니다.

### 한 에이전트에 참조 로어북 주기

1. **Chat Settings**에서 **Agents**를 연 다음 그 에이전트의 설정을 여세요.
2. **Attach lorebook for the specific agent**(특정 에이전트용 로어북 연결)를 켜세요. 처음에는 꺼져 있습니다.
3. **Reference lorebook**(참조 로어북)에서 책을 고르세요.

이 선택은 이 채팅의 해당 에이전트에만 적용됩니다. 일치하는 항목은 일반 로어북 트리거 규칙을 따르며, 수동 재시도를 포함해 이 에이전트에 전달됩니다. 이 설정은 기본 답변이나 관계없는 에이전트에 그 책을 추가하지 않지만, 함께 실행되는 에이전트도 같은 항목을 볼 수 있습니다. 삭제되었거나 사용할 수 없는 책은 아무것도 제공하지 않습니다.

## 에이전트가 실행되는 시점

각 에이전트는 답변 앞뒤의 한 지점에서 실행되며, 이 지점을 **pipeline phase**(파이프라인 단계)라고 합니다. 기본 제공 에이전트마다 기본값이 있으며, 에이전트 편집기에서 바꿀 수 있습니다.

| 단계 | 실행 시점 | 예 |
|---|---|---|
| **Pre-Generation**(생성 전) | 답변 전. 프롬프트에 컨텍스트를 더할 수 있습니다. | 지식 조회 |
| **Parallel**(병렬) | 답변과 동시. 답변을 바꿀 수 없습니다. | 실시간 관객 반응 |
| **Post-Processing**(후처리) | 답변 후. 답변을 읽을 수 있고, 다시 쓰는 에이전트는 답변을 수정할 수 있습니다. | 대부분의 트래커, 문장 정리, 이미지 |

<a id="tell-whether-an-agent-ran"></a>

## 에이전트가 실행됐는지 확인하기

- 트래커 에이전트는 HUD와 트래커 패널에 내용을 씁니다. 시간, 장소, 기분, 능력치가 바뀌었다면 트래커가 실행된 것입니다.
- **Chat Settings**의 **Agent activity**(에이전트 활동)에는 에이전트가 남긴 짧은 메모가 나열됩니다. 에이전트가 작업하는 동안에는 아이콘이 돌아가고, 하나라도 실패하면 아이콘에 점이 표시됩니다. [에이전트 활동](../roleplay/getting-started.md#agent-activity)을 참고하세요.
- **Prose Guardian**과 **Continuity Checker**는 답변 텍스트를 바꿉니다. 답변이 다듬어지거나 바로잡혔다면 이 에이전트가 실행된 것입니다.
- 전체 과정을 추적하려면 **Settings → Advanced → Message Tools**(설정 → 고급 → 메시지 도구)에서 **Debug mode**(디버그 모드)를 켜세요. 에이전트마다 프롬프트와 응답이 서버 콘솔에 기록되고, 에이전트 디버그 항목은 브라우저 콘솔에도 나타납니다. 캐시된 프롬프트 주입은 **Agent activity**의 **Injections**(삽입) 탭에 표시됩니다.

## 비용 살피기

에이전트마다 자체 지시문이 붙고, 대개 모델 호출도 따로 일어납니다. 같은 연결을 쓰는 에이전트는 가능하면 Marinara가 한 번의 호출로 묶습니다.

에이전트 목록 위의 표시는 턴마다 추가되는 토큰과 호출 수를 어림해 보여 줍니다. 자세한 내용은 표시 옆의 도움말 아이콘을 탭하세요. 부담이 크면 이 표시가 주황색으로 바뀌고 경고 아이콘이 붙습니다. 호출할 때마다 채팅 기록과 캐릭터 정보가 함께 전송되므로 실제 비용은 표시보다 큽니다.

경고가 보이면 필요 없는 에이전트를 빼거나 일부를 더 저렴한 연결이나 로컬 연결로 옮기세요. 연결에 저장한 **Reasoning Effort**(추론 강도)는 그 연결을 쓰는 에이전트에도 적용됩니다. [에이전트용 파라미터](../prompts/generation-parameters.md#parameters-for-agents)를 참고하세요.

## 에이전트 설치와 업데이트

**Agents** 패널(오른쪽 탭의 Sparkles 아이콘)을 열고 **Agent Organizer**를 클릭하세요. 데스크톱과 모바일 모두에서 쓸 수 있습니다.

- **Home**(홈)에는 추천 에이전트와 섹션별 목록이 표시됩니다. 섹션은 **Apps**(앱), **Chat games**(채팅 게임), **Trackers**(트래커), **Writing help**(글쓰기 도움)입니다.
- **Updates**(업데이트)에는 설치한 에이전트 중 새 버전이 있는 항목이 나열됩니다. **Installed**(설치됨)에는 설치한 모든 항목이 버전, 용량과 함께 나열됩니다.
- 검색과 모드 필터로 모든 목록을 좁힐 수 있습니다.
- 에이전트를 선택하면 설명, 다운로드 용량, 권한, 호환성, **Version history**(버전 기록)를 볼 수 있습니다. 설치하려면 **Get**을 클릭하세요. **⋯** 메뉴에는 **Uninstall**(제거)이 있습니다.
- 제목 옆의 **⋯** 메뉴에는 **Update all**(모두 업데이트), **Install all**(모두 설치), **Refresh catalog**(카탈로그 새로고침), **Uninstall all**(모두 제거)이 있습니다.

설치한 에이전트는 **Apps**, **Writer Agents**, **Tracker Agents**(추적 에이전트), **Misc Agents**로 묶이고, 직접 만든 에이전트는 **Custom Agents**(커스텀 에이전트)에 모입니다. **Apps**는 Noodle과 Slurp처럼 전용 Home 탭이 있는 패키지입니다. 채팅에 추가하지 않고 단독으로 사용합니다.

**Rules**(규칙)로 표시된 패키지는 에이전트가 아닙니다. 5e (SRD 5.1) 같은 Game Mode 규칙 집합을 추가하며, 게임을 만들 때 **Rules**(룰)에서 고릅니다. [규칙 집합으로 플레이하기](../game/rulesets.md)를 참고하세요. 5e 패키지는 미리보기 버전이므로 `staging` 브랜치의 Engine에서만 목록에 나타납니다.

패키지를 제거하면 코드와 설정은 지워지지만 채팅 메시지와 기록은 남습니다. 직접 만든 에이전트를 삭제하면 완전히 사라집니다.

### 에이전트 업데이트하기

설치한 패키지에 호환되는 새 버전이 있으면 **Agent updates available**(에이전트 업데이트 있음) 창이 열립니다. 창에는 업데이트마다 버전과 재시작 필요 여부가 표시됩니다.

1. 건너뛰려는 업데이트의 체크 상자를 해제하세요. 모든 업데이트는 처음에 선택되어 있습니다.
2. 패키지가 노트를 공개했다면 **What's new**(새로운 기능)를 읽어 보세요. **More**(더보기)를 누르면 긴 노트 전체가 표시됩니다. 점 표시는 눈에 띄는 변경 사항을 나타냅니다.
3. **Update all**을 클릭하세요. 일부를 해제했다면 **Update 2 of 3**(3개 중 2개 업데이트)를 클릭하세요. 각 행에는 **Updated**(업데이트됨)나 **Failed**(실패)가 표시됩니다. 실패한 행에는 이유와 **Retry**(재시도)가 표시됩니다.
4. 업데이트에 재시작이 필요하면 **Restart now**(지금 재시작)를 클릭하거나 나중에 Marinara를 다시 시작하세요.

현재 버전을 유지하려면 **Not now**(나중에)를 클릭하세요. 건너뛴 버전에 대해서는 Marinara가 다시 묻지 않습니다. **Agent Organizer**에서 언제든 업데이트할 수 있습니다. 설치한 패키지는 카탈로그에 연결할 수 없을 때도 현재 버전으로 계속 동작합니다. **See in Agent Organizer**(Agent Organizer에서 보기)는 에이전트 페이지를 엽니다.

업데이트는 직접 설치한 패키지에만 적용됩니다. 패키지는 Marinara 서버에 있으므로 브라우저 클라이언트는 서버에 설치된 패키지를 사용합니다.

이런 기능이 기본 포함되어 있던 Engine 버전에서 업그레이드하면 Marinara가 해당 패키지를 한 번 다운로드하고, 채팅의 선택 상태와 설정, 기록을 그대로 유지합니다. 카탈로그에 연결하지 못하면 다음 시작 때 다시 시도합니다.
