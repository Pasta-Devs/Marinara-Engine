# 채팅 분기

이 가이드에서는 Marinara Engine의 채팅 분기를 설명합니다. 분기가 무엇이고 어떻게 만드는지, 이어서 분기를 전환하고 이름을 바꾸고 삭제하고 내보내고 가져오는 방법까지 다룹니다. 분기를 쓰면 원래 채팅을 잃지 않고 다른 전개를 시험해 볼 수 있습니다.

## 분기란

분기는 지정한 지점까지의 기록을 공유하는 채팅 사본입니다. 원래 채팅을 그대로 남겨 둔 채 다른 방향으로 이야기를 풀어 보고 싶을 때 사용합니다.

같은 채팅에서 갈라진 분기는 모두 하나로 묶입니다. 채팅 목록에서는 분기가 여러 개인 채팅도 한 줄로만 표시되고, 그 옆에 분기 개수가 작게 붙습니다. 분기를 열고 서로 전환하는 조작은 **Chat Settings**(채팅 설정)의 **Chat Branches**(채팅 분기) 섹션에서 합니다(아래 참고).

분기마다 표시 이름을 따로 지정할 수 있어서 "friendly ending", "dark ending"처럼 이름표를 달아 둘 수 있습니다. 이 표시 이름은 바탕이 되는 채팅 이름과는 별개입니다.

분기 계보에는 바로 위의 원본 채팅과 분기가 갈라진 메시지가 기록됩니다. 원본 메시지 ID와 복사된 메시지 ID를 둘 다 보관하기 때문에, 복사된 메시지에 새 ID가 부여되어도 연동 기능이 분기 지점을 알아낼 수 있습니다. 분기에서 다시 분기를 만들면 맨 처음 원본이 아니라 그 분기가 바로 위 부모로 기록됩니다. 예전에 만든 분기나 가져온 형제 분기는 표시 이름은 유지하지만 계보 정보는 없습니다.

## 여기서부터 분기 만들기

채팅 안의 어느 메시지에서나 분기를 만들 수 있습니다.

1. 메시지 위에 마우스를 올리거나(모바일에서는 메시지를 탭해서) 메시지 동작 막대를 표시하세요.
2. **Branch from here**(여기서 분기 생성) 버튼을 클릭하세요. 작은 분기 모양 아이콘이 그려져 있습니다.

Marinara는 그 메시지까지를 포함해 채팅을 복사해서 새 분기를 만듭니다. 새 분기는 다음과 같습니다.

- 모드, 캐릭터, 페르소나, 프롬프트 프리셋, 연결은 원본 채팅과 같습니다.
- 모든 메시지를 복사합니다. 스와이프(같은 답변의 다른 안)와 어느 스와이프가 활성 상태였는지도 함께 복사합니다. 스와이프의 동작 방식은 [메시지 조작: 편집, 삭제, 스와이프, 재생성](messages.md) 가이드를 참고하세요.
- 복사된 메시지에 연결된 트래커와 게임 상태 스냅샷도 복사하므로 Roleplay와 Game Mode 채팅은 상태를 그대로 유지합니다.
- 표시 이름은 **New Branch**로 시작합니다. 이름은 나중에 바꿀 수 있습니다(아래 참고).
- 원본 채팅과 같은 채팅 폴더에 남습니다.

빈 채팅은 메시지 기준점이 null입니다. 부모 채팅을 삭제해도 자식 채팅에 기록된 계보는 달라지지 않습니다. 다만 분기 묶음 전체를 삭제하면 그 묶음의 채팅이 모두 지워집니다.

일간 요약과 주간 요약은 넘어오지 않습니다. 저장된 메시지 범위가 복사된 분기 안에 온전히 들어가는 롤링 요약만 넘어오며, 분기의 새 메시지 ID에 맞춰 다시 연결됩니다. 원본 범위가 분기 지점을 넘어가는 요약이나 메시지 정보가 없는 예전 형식의 요약은 제외됩니다. 새 분기는 그런 요약을 처음부터 다시 만듭니다.

장면 채팅에서는 분기를 만들 수 없습니다. 장면 채팅에는 **Branch from here** 버튼이 나타나지 않고, 대신 **Clone from here**(여기서 복제) 동작이 따로 있습니다. 동작 방식은 [장면: Roleplay 분기](../roleplay/scenes.md)를 참고하세요.

## Chat Branches 섹션

**Chat Settings**를 열고 **Chat Name** 아래의 **Chat Branches** 섹션을 펼치세요. 헤더에 현재 분기 개수가 표시됩니다. 컴퓨터에서는 별도 창으로 꺼낼 수 있습니다([채팅 설정 개요](chat-settings.md#popping-a-section-out-into-its-own-window) 참고).

이 섹션에는 현재 채팅의 모든 분기가 나열되며, 지금 보고 있는 분기가 맨 위에 옵니다. 각 줄에는 분기 표시 이름과 마지막 수정 시각이 나옵니다.

### 다른 분기로 전환하기

분기 줄을 클릭하면 그 분기가 열리고 채팅 화면이 선택한 분기로 바뀝니다.

### 분기 이름 바꾸기

1. **Chat Branches** 섹션을 여세요.
2. 이름을 바꿀 분기 줄에서 연필(이름 바꾸기) 버튼을 클릭하세요.
3. "Set a display name for this chat branch."라는 안내와 함께 **Rename Branch**(분기 이름 변경) 창이 열립니다.
4. 새 이름을 입력하고 **Rename**(이름 바꾸기) 버튼으로 확정하세요.

이름을 비워 두거나 원래 이름 그대로 두면 아무 일도 일어나지 않습니다.

### 분기 삭제하기

1. **Chat Branches** 섹션을 여세요.
2. 분기 줄에서 휴지통(삭제) 버튼을 클릭하세요.
3. **Delete Branch**(분기 삭제) 창이 열리고 "Delete this branch? Messages will be lost."라고 묻습니다.
4. **Delete**(삭제) 버튼으로 확정하세요.

분기를 삭제하면 그 분기와 그 안의 메시지만 지워집니다. 다른 분기는 그대로 남습니다.

### 모든 분기 삭제하기

분기가 둘 이상인 채팅에서는 섹션 아래쪽에 **Delete All Branches**(모든 분기 삭제) 버튼이 나타납니다. 이 버튼은 "Delete all N branches? This cannot be undone."라고 묻고, **Delete All**(전체 삭제) 버튼으로 확정하면 묶음 안의 분기가 한 번에 모두 지워집니다.

채팅 목록에서 시작할 수도 있습니다. 분기가 있는 채팅을 목록의 휴지통 아이콘으로 삭제하면 **Delete Chat**(채팅 삭제) 창이 열려 무엇을 지울지 묻습니다. 여기에는 **Delete This Branch Only**(이 분기만 삭제) 버튼과 **Delete All N Branches** 버튼이 있습니다. 목록에서 삭제하는 방법은 [채팅 목록 관리](managing-chats.md)에서 더 자세히 다룹니다.

## 분기 내보내기

**Chat Branches** 섹션 위쪽에는 내보내기 버튼이 있습니다. 지금 보고 있는 분기를 내보냅니다.

- **JSONL**: 분기를 JSONL 파일로 다운로드합니다. JSONL은 한 줄에 메시지 하나를 담는 텍스트 형식이며 SillyTavern과 호환됩니다.
- **Text**: 분기를 일반 텍스트 대본으로 다운로드합니다.

여러 채팅을 한꺼번에 내보내려면 [채팅 내보내기와 가져오기](export-import.md)를 참고하세요. 모델의 추론 과정을 내보내기에 포함하는 선택지도 그 가이드에서 설명합니다.

## JSONL 파일을 새 분기로 가져오기

저장해 둔 채팅 기록을 지금 열려 있는 채팅의 새 분기로 불러올 수 있습니다.

1. **Chat Branches** 섹션을 여세요.
2. **Import**(가져오기) 버튼을 클릭하세요.
3. SillyTavern이나 Marinara에서 내보낸 JSONL 파일(`.jsonl`)을 고르세요.

Marinara는 그 파일을 현재 채팅 묶음의 새 분기로 추가합니다. "Imported N messages as a new branch"와 같은 메시지가 나타나고, 앱이 새 분기로 전환합니다.
