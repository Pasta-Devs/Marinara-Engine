# 설정 프로필

설정 프로필은 다시 쓸 수 있는 채팅 설정을 이름 붙여 묶어 둔 것입니다. 연결, 프롬프트 프리셋, 에이전트, 도구, 번역, 기억 회상, 고급 매개변수 등을 담습니다. 같은 옵션을 다시 설정하는 대신 프로필을 다른 채팅에 적용하세요.

프로필은 **Chat Settings**(채팅 설정) 맨 위에 있습니다. Conversation(대화)과 Roleplay(롤플레이)에서 쓸 수 있습니다. Game 채팅에는 프로필 컨트롤이 표시되지 않습니다.

**프롬프트 프리셋**은 다릅니다. 프롬프트 프리셋은 시스템 프롬프트의 구조와 생성 값을 정하며, Presets 패널에서 편집합니다. [Preset Editor와 프롬프트 관리](../prompts/presets.md)를 참고하세요. 설정 프로필은 그보다 넓은 묶음이며, 프롬프트 프리셋을 항목 하나로 담을 수 있습니다.

## 프로필 적용하기

1. 바꾸려는 채팅을 연 다음 **Chat Settings**를 여세요. [채팅 설정 개요](chat-settings.md)를 참고하세요.
2. **Profile**(프로필) 드롭다운을 여세요. 라벨은 **Apply a settings profile to this chat**(이 채팅에 설정 프로필 적용)입니다.
3. 이름을 보고 프로필을 고르세요.

채팅이 곧바로 바뀝니다. 프로필이 **Hide summarised messages**(요약된 메시지 숨기기)를 켜거나 끄면, 채팅의 요약된 메시지도 그 순간 모델에게서 숨겨지거나 다시 보입니다.

작동하지 않는 경우: 채팅의 값이 저장된 어느 프로필과도 맞지 않으면 드롭다운에 **Custom settings profile**(사용자 지정 설정 프로필)이 표시됩니다. 적용한 프로필이 삭제되었다면 **Missing profile - choose a profile**(프로필 없음 - 프로필을 선택하세요)이 표시됩니다. 다른 프로필을 고르세요.

## 프로필 만들기와 편집하기

1. 드롭다운 옆의 **New**(새로 만들기)를 탭하세요("New profile from this chat's settings", 이 채팅의 설정으로 새 프로필 만들기). 이 채팅의 설정이 슬롯에 들어 있는 프로필 빌더가 열립니다. 저장된 프로필을 바꾸려면 프로필을 선택하고 **Edit**(편집)를 클릭하세요. Default 프로필은 편집할 수 없습니다.
2. **Profile name**(프로필 이름)을 입력하세요.
3. 슬롯을 채우세요(아래 목록 참고).
4. **Save and choose chats…**(저장하고 채팅 선택…)를 탭하세요.
5. 새 채팅에 이 프로필을 쓰려면 **Make this the default**(기본값으로 지정)를 체크하세요. 목록은 **New conversation chats**(새 대화 채팅) 또는 **New roleplay chats**(새 롤플레이 채팅)로 시작합니다.
6. 지금 이 프로필을 적용할 기존 채팅을 체크하세요.
7. **Apply to N chats**(채팅 N개에 적용)를 탭하거나, 아무것도 체크하지 않았다면 **Save**(저장)를 탭하세요.

빌더는 슬롯을 **Chat**(채팅), **Story**(스토리), **Pictures**(이미지), **Behind the scenes**(무대 뒤)로 묶습니다. 슬롯은 다음과 같습니다.

- **Connection**(연결), **Prompt preset**(프롬프트 프리셋), **Parameters**(매개변수)
- **Agents**(에이전트), **Tools**(도구), **Memory & summary**(기억 및 요약)
- **Persona**(페르소나), **Lorebooks**(로어북), **Background**(배경)
- **Image style**(이미지 스타일), **Translation**(번역)

슬롯을 채우는 방법은 다음과 같습니다.

- 각 슬롯의 목록에서 항목을 고르세요. **Agents**, **Tools**, **Lorebooks**는 여러 개를 고를 수 있습니다. **Tools**의 체크박스로 도구를 하나씩 켜거나 끄세요. 항목 하나만 받는 슬롯을 비우려면 **None**(없음)을 고르세요.
- 컴퓨터의 에이전트 목록과 로어북 목록에서는 <kbd>Ctrl</kbd>(macOS에서는 <kbd>Command</kbd>)을 누른 채로 여러 항목을 고르세요. 휴대폰에서는 선택 컨트롤을 쓰세요. **Clear selection**(선택 해제)은 목록을 비웁니다.
- 컴퓨터에서는 편집기를 연 채로 라이브러리 사이드바를 열고, 항목을 해당 필드로 끌어다 놓을 수 있습니다.
- **Parameters**, **Memory & summary**, **Translation**은 프로필에 해당 설정이 들어 있는지만 보여 줍니다. Chat Settings에서 바꾼 다음 프로필에 저장하세요.

새 채팅 마법사의 **Use a Profile**(프로필 사용) 단계에도 목록 맨 위에 **New profile…**(새 프로필…)이 있고, 저장된 프로필 옆에 **Edit**가 있습니다. 저장하면 마법사가 그 프로필을 선택합니다.

## 채팅 설정을 프로필에 저장하기

채팅에서 프로필을 갱신하려면 프로필을 적용하고, 채팅을 바꾼 다음, 드롭다운 아래의 아이콘 줄을 사용하세요.

| 버튼 | 라벨 | 결과 |
|---|---|---|
| Save | **Save current chat settings into this profile**(현재 채팅 설정을 이 프로필에 저장) | 프로필에 저장된 값을 대체합니다. |
| Rename | **Rename profile**(프로필 이름 바꾸기) | 이름을 바꿉니다. |
| Import | **Import settings profile (.json)**(설정 프로필 가져오기, .json) | 프로필 파일을 불러옵니다. |
| Export | **Export settings profile (.json)**(설정 프로필 내보내기, .json) | 프로필을 다운로드합니다. |
| Delete | **Delete profile**(프로필 삭제) | 프로필을 완전히 삭제합니다. |

### 프로필을 쓰는 다른 채팅 갱신하기

채팅마다 프로필 설정의 사본을 따로 가지므로, 프로필을 저장해도 그것만으로 다른 채팅이 바뀌지는 않습니다. 같은 모드의 다른 채팅이 그 프로필을 쓰고 있으면 **Other chats use this profile**(다른 채팅도 이 프로필을 사용합니다) 대화 상자가 묻습니다.

- **Save to this profile only**(이 프로필에만 저장)는 프로필만 저장하고 다른 채팅은 그대로 둡니다.
- **Save and update N other chats**(저장하고 다른 채팅 N개 업데이트)는 프로필의 Chat Settings를 그 채팅들에도 복사합니다. 그 채팅들에서 직접 바꾼 해당 설정은 대체되며, 저장하는 채팅에서 기본값으로 둔 설정은 그 채팅들에서도 기본값으로 돌아갑니다.

프로필을 쓰는 다른 채팅이 없으면 **Save**는 묻지 않고 바로 저장합니다. 멀티플레이어 방은 이 방식으로 갱신되지 않습니다.

## 기본 프로필 정하기

드롭다운 옆의 별은 그 모드의 새 채팅에 자동으로 쓰일 프로필을 표시합니다. 기본 프로필은 모드마다 하나만 지정할 수 있습니다. 라벨은 **Mark this profile as default for new chats in this mode**(이 모드의 새 채팅에서 이 프로필을 기본 프로필로 지정), **This profile is the default for new chats in this mode**(이 프로필은 이 모드의 새 채팅에서 기본값으로 사용됩니다), **Select a profile to mark it as default**(기본 프로필로 지정할 프로필을 선택하세요)입니다. 빌더에서 **Make this the default**를 체크해도 됩니다.

## 프로필 가져오기와 내보내기

**Export settings profile (.json)**은 백업으로 보관하거나 공유할 수 있는 `.marinara-settings-profile.json` 파일을 다운로드합니다. **Import settings profile (.json)**은 호환되는 파일로 새 프로필을 만들며, 기존 프로필을 덮어쓰지 않습니다. 예전에 내보낸 파일도 가져올 수 있습니다. 가져오기에 실패하면 **Import failed**(가져오기 실패)가 표시됩니다.

프로필에는 설정만 저장되며, 제공자의 시크릿은 들어가지 않습니다. 내보내거나 가져온 프로필에는 Discord 미러 웹훅, DeepLX 주소, DeepL 키, Intiface 주소도 빠집니다. 이 설치에서 저장한 프로필에는 그대로 남습니다. 내보낸 파일에는 페르소나와 로어북이 빠집니다. 이 항목들은 이 설치에만 있기 때문입니다.

## Default 프로필

Conversation과 Roleplay에는 각각 기본 제공 **Default** 프로필이 있습니다. 이 프로필을 적용하면 프로필이 관리하는 설정이 그 모드의 Marinara 기본값으로 돌아갑니다. 이름을 바꾸거나 덮어쓰거나 삭제할 수 없습니다. 비활성화된 컨트롤에는 **Cannot save into the Default profile**(기본 프로필에는 저장할 수 없습니다), **Cannot rename the Default profile**(기본 프로필은 이름을 바꿀 수 없습니다), **Cannot delete the Default profile**(기본 프로필은 삭제할 수 없습니다)이 표시됩니다.

## 즐겨찾는 창 배치

Chat Settings 제목 표시줄의 **Reset View**(보기 초기화) 옆 별은 새 채팅에 쓸 즐겨찾는 창 배치를 저장합니다. **Profile** 드롭다운 옆의 별은 그와 달리 기본 프로필을 고릅니다. 사용 순서는 [새 채팅의 배치 고르기](chat-settings.md#choosing-a-layout-for-new-chats)를 참고하세요.

새 채팅이 저장된 배치가 있는 기본 프로필을 쓰면, 그 배치가 즐겨찾는 배치보다 우선합니다. 저장된 배치가 없는 프로필은 즐겨찾는 배치에서 온 배치를 포함해 채팅의 배치를 유지합니다. 그래도 프로필은 자체 배치 안내 설정(이 설정이 없는 예전 프로필은 안내를 표시합니다)과 자체 Scoped Regex Scripts 방식을 적용하며, 방식이 없으면 프롬프트 프리셋의 기본값을 사용합니다.

## 프로필에 담기는 것

프로필에는 채팅이 모델과 주고받는 방식이 저장됩니다.

- 연결
- 프롬프트 프리셋(Conversation에서는 프롬프트 소스라고 부릅니다)
- 에이전트와 도구
- 번역, Memory Recall(기억 회상), 고급 매개변수
- 창과 버튼 배치: 위치, 크기, 고정, 잠금, Chat Settings 안에 있거나 밖으로 꺼낸 도구, 열린 컨트롤 창, 컴퓨터와 휴대폰의 버튼 위치입니다. **Default**처럼 저장된 배치가 없는 프로필은 채팅의 배치를 그대로 둡니다.
- 배치 안내를 숨겼는지 여부. **Default**나 이 선택이 없는 예전 프로필을 적용하면 안내가 다시 나타납니다.
- 그 밖의 재사용 가능한 채팅 옵션

프로필에는 **시작 선택 항목**도 담을 수 있습니다. 페르소나, 켤 로어북, 배경입니다.

- 프로필을 적용하면 선택 항목이 채팅에 복사됩니다. 프로필에서 비워 둔 항목은 채팅의 기존 선택이 유지됩니다.
- 프로필의 다른 설정은 여전히 채팅의 설정을 대체합니다.
- 선택 항목은 연결되지 않습니다. 나중에 채팅에서 바꾼 내용은 그 채팅에만 남습니다.
- **Save current chat settings into this profile**은 프로필 자체의 페르소나, 로어북, 배경을 유지합니다. 배경이 없는 프로필은 저장할 때 채팅의 배경을 가져옵니다.
- 다른 채팅을 갱신해도 그 채팅의 페르소나, 로어북, 배경은 절대 바뀌지 않습니다.

프로필은 채팅이 가진 콘텐츠인 캐릭터, 스프라이트, 요약, 태그, 장면 프롬프트를 대체하지 않습니다. 채팅 기록도 담지 않으며, 매크로 변수, 끈 캐릭터, 멀티플레이어 방 같은 진행 중인 상태도 담지 않습니다.

### Save and update가 복사하는 항목

**Save and update**는 다음 항목을 다른 채팅에 복사합니다.

- 생성 및 컨텍스트 옵션
- 그룹 채팅 옵션
- 기능 및 명령 스위치
- 에이전트와 그 옵션
- 기억 및 요약 설정
- 번역
- 창 배치

그 밖의 모든 것은 각 채팅이 가진 그대로 남습니다.

- 연결, 프롬프트 프리셋, 사용자 지정 프롬프트
- 이야기와 캐릭터
- 로어북과 배경
- 메모와 진행 상황
- 그 채팅의 내레이터만 쓸 수 있는 Roleplay 명령
- Noodle이 그 채팅의 메시지를 쓸 수 있는지 여부

고급 매개변수와 이미지 캡션(켜짐 여부와 이미지를 설명하는 연결)은 그 연결에 맞춰 설정되므로, 프로필의 연결을 쓰는 채팅에서만 바뀝니다. 캐릭터 스케줄은 저장하는 채팅에서 켜거나 끈 경우에만 바뀝니다. Knowledge Retrieval, Knowledge Router, Lorebook Keeper, Expression Engine은 프롬프트 템플릿과 함께 각 채팅에서 켜고 끈 상태 그대로 유지됩니다. 이 기능들이 쓰는 소스, 로어북, 스프라이트는 각 채팅이 직접 고릅니다.
