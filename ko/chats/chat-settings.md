# 채팅 설정 개요

**Chat Settings**(채팅 설정)에서 현재 채팅의 연결, 캐릭터, 에이전트와 다른 설정을 고릅니다. 메시지 검색, 요약, 분기, 갤러리도 여기에 있습니다.

대부분의 설정은 현재 채팅에만 적용됩니다. 창 배치도 채팅마다 따로 저장됩니다. 다만 **Tracker Panel**(트래커 패널)을 켜거나 끄는 설정은 다른 Roleplay 채팅에도 적용됩니다.

이 업데이트 후 처음 채팅에 들어가면 버튼과 창을 배치하는 방법을 짧은 영상으로 보여 줍니다. 기존 사용자도 컴퓨터와 휴대폰에서 이 안내를 볼 수 있습니다. 안내를 마치려면 **Got it**(알겠습니다)을 선택하세요. 이후 다른 채팅에 들어가거나 페이지를 새로고침해도 다시 나타나지 않습니다.

## Chat Settings 열기

1. 채팅을 여세요.
2. **Chat Settings** 버튼(슬라이더 아이콘)을 클릭하거나 탭하세요. 처음에는 앱 상단 바 아래, 채팅 오른쪽 위에 있습니다.
3. 섹션 제목을 누르면 내용이 펼쳐집니다. 이런 섹션을 **드로어**라고도 합니다. 제목을 다시 누르면 접힙니다.

새 채팅을 만들면 Chat Settings가 자동으로 열립니다. 닫으려면 **X**를 누르거나 슬라이더 버튼을 다시 누르세요.

업데이트 전에 만든 채팅에서는 익숙한 도구 아이콘이 이동 가능한 버튼으로 남습니다. 기존 설치를 업데이트하면, 이미 즐겨찾는 배치를 고르지 않은 모드에서는 익숙한 배치가 새 채팅의 즐겨찾는 배치로도 저장됩니다. 도구의 버튼으로 창을 열고 **Put back in Chat Settings**(채팅 설정으로 되돌리기)를 선택하면 Chat Settings 안에 넣을 수 있습니다. 컴퓨터의 Roleplay 트래커는 **Trackers**(트래커) 창 하나로 모입니다. 이전에 저장한 배치는 그대로 유지됩니다.

슬라이더 버튼을 편한 곳으로 끌어 옮기세요. 드래그하면 가까운 채팅 버튼과 나란히 맞춰집니다. 컴퓨터에서는 Alt를 누른 채 자유롭게 배치할 수 있습니다. 채팅마다 버튼 위치를 기억합니다. 버튼의 작은 점은 에이전트가 작업 중이라는 뜻입니다.

Roleplay에서 슬라이더 버튼 옆의 짧은 안내는 한 번만 닫으면 됩니다. **X**로 닫으면 다른 채팅에서도 숨겨지며 새로고침해도 나타나지 않습니다.

컴퓨터에서는 배치 안내 옆의 **X**(**Hide these tips for this chat**, 이 채팅에서 안내 숨기기)를 누르면 해당 채팅에서 안내가 계속 숨겨집니다. 새로고침하거나 Reset View를 사용해도 유지됩니다. 새 채팅에도 적용하려면 즐겨찾는 배치의 별 버튼이나 설정 프로필로 이 선택을 저장하세요.

## 채팅 창의 모양 바꾸기

**Settings → Appearance → App**(설정 → 모양 → 앱)을 열고 **App Style** 아래쪽의 **Chat widget style**(채팅 위젯 스타일)을 찾으세요. **Default**는 Marinara의 기존 모양을 유지합니다. **Dottore**는 시안색 장식, 기술적인 느낌의 글꼴과 잘린 모서리를 사용합니다. **Mari**는 분홍색과 금색, 이야기책 같은 글꼴과 아치형 프레임을 사용합니다. 두 스타일 모두 라이트 모드와 다크 모드에 맞춰 바뀌며, 세 채팅 모드의 이동 버튼, 창, 펼치는 섹션에 적용됩니다.

프리셋 아래의 **Font**(글꼴)와 **Shape**(모양)로 각각을 바꿀 수 있습니다. Marinara에 설치한 글꼴도 목록에 나타납니다. 프리셋을 다시 선택하면 두 선택이 초기화되고, **Default**는 기본 모양으로 돌아갑니다. 창 위치나 저장한 채팅 배치는 바뀌지 않습니다. 이 선택은 앱 환경설정에 저장되며 같은 서버에 연결된 브라우저 사이에서 동기화됩니다.

## 창 이동, 고정, 잠금

컴퓨터에서 Chat Settings는 채팅 위에 떠 있는 창으로 열립니다. 내용은 창 크기에 맞춰집니다. 버튼으로 창을 처음 열면 버튼 아래에 나타나며 채팅 영역 안에 들어오도록 위치가 조정됩니다. 저장한 위치가 있으면 그곳에서 열립니다.

- **이동**: 제목 표시줄을 끌어 옮기세요. 키보드로 제목 표시줄에 포커스를 맞춘 뒤 방향키를 눌러도 됩니다. Shift를 함께 누르면 더 크게 이동합니다.
- **크기 변경**: 창 가장자리나 모서리를 끌어당기세요. 오른쪽 아래 크기 조절 손잡이에 포커스를 맞추고 방향키를 써도 됩니다.
- **Pin**(고정)은 다른 곳을 클릭해도 창을 열어 둡니다. 고정한 창은 새로고침 후에도 다시 열립니다. 먼저 닫거나 최소화했다면 그 상태를 유지합니다. 고정하지 않은 창은 밖을 클릭하거나 Escape를 누르면 닫힙니다. 단, 입력란에서 글을 쓰거나 열린 메뉴를 사용하는 동안에는 닫히지 않습니다.
- **Lock**(잠금)은 창 이동과 크기 변경을 막고 버튼 위치도 잠급니다. 버튼으로 창을 여는 것은 가능합니다. 창이나 버튼을 다시 옮기려면 창의 잠금을 해제하세요.
- **Close**(닫기, **X**)는 창을 숨깁니다.

브라우저 크기를 바꾸거나 사이드바를 열어도 창은 채팅 영역 안에 머뭅니다.

휴대폰에서는 Chat Settings가 화면 너비의 패널로 열립니다. 입력할 때는 키보드 위 공간에 맞춰집니다.

## 도움말, 트래커, Reset View

제목 표시줄에는 다음 버튼도 있습니다.

- **Help**(도움말, 제목 옆의 **?**)는 채팅의 각 컨트롤을 설명합니다. 휴대폰에서는 채팅이 보이도록 먼저 Chat Settings를 닫습니다. 강조된 **Chat Settings** 버튼을 탭하면 Reset View, 즐겨찾는 배치, Roleplay Tracker Panel, 잠금/해제, 닫기, 섹션 꺼내기의 아이콘 설명이 나옵니다. 안내 안에서 스크롤하면 전체 목록을 읽을 수 있습니다. **Settings → General → App Behavior → Hide chat Help button**(설정 → 일반 → 앱 동작 → 채팅 도움말 버튼 숨기기)에서 Help 버튼을 숨길 수 있습니다.
- **Reset View**(화면 배치 초기화, 원형 화살표)는 확인을 받은 뒤 현재 채팅의 초기 배치로 돌아갑니다. 꺼낸 섹션을 원래 위치로 돌려놓고 창 크기, 위치, 고정, 잠금을 기본값으로 되돌립니다.
- **Favorite layout**(즐겨찾는 배치, Reset View 옆의 별)은 이 모드의 새 채팅에 쓸 배치를 저장합니다. [새 채팅의 배치 고르기](#choosing-a-layout-for-new-chats)를 참고하세요.
- **Tracker Panel**(주사위)은 에이전트나 Advanced Memory를 사용하는 Roleplay 채팅에서 패널을 켜고 끕니다. 컴퓨터에서는 채팅 옆에 패널이 나타나고, 휴대폰에서는 이동 가능한 버튼으로 패널을 엽니다. **Settings → Appearance**(설정 → 모양)의 Tracker Panel 설정도 함께 바뀝니다.

Tracker Panel이 숨겨져 있으면 컴퓨터에서는 [Trackers 창](../roleplay/hud-and-trackers.md#the-trackers-window)으로 트래커를 볼 수 있습니다. 메시지 옆 공간이 부족하면 처음에는 작은 **Trackers** 버튼이 나타납니다. 창을 닫으면 그 버튼으로 돌아갑니다. Tracker Panel을 다시 보려면 Chat Settings 제목 표시줄의 주사위를 누르세요.

## 섹션을 별도 창으로 꺼내기

섹션을 따로 열어 두려면 **?** 옆의 화살표가 있는 사각형, **Pop out**(별도 창으로 열기) 버튼을 누르세요. 섹션에 별도 창이 생기며, 되돌리기 전까지 Chat Settings 안에서는 사라집니다.

컴퓨터에서는 섹션 제목을 Chat Settings 밖으로 끌어 꺼낼 수도 있습니다. 새 창은 처음에는 고정되지 않으므로 다른 곳을 클릭하면 버튼으로 최소화됩니다. 채팅을 사용하는 동안 계속 열어 두려면 고정하세요. Chat Settings처럼 이동하거나 크기를 바꾸거나 잠글 수 있습니다.

- **Close**(**X**)는 섹션을 작은 아이콘 버튼으로 최소화합니다. 버튼을 원하는 곳으로 옮긴 뒤 누르면 창이 마지막 위치에서 열립니다.
- **Put back in Chat Settings**(**X** 옆의 굽은 화살표)는 섹션을 Chat Settings 안으로 되돌립니다. 창을 Chat Settings 위로 끌어 놓아도 됩니다.
- 고정하지 않은 섹션은 다른 곳을 클릭하거나 Escape를 누르면 버튼으로 최소화됩니다. 입력란에서 글을 쓰거나 열린 메뉴를 사용하는 동안에는 유지됩니다.

휴대폰에서 섹션을 꺼내면 Chat Settings가 닫히고 채팅에 이동 가능한 버튼이 생깁니다. 버튼을 탭하면 섹션이 패널로 열립니다. 패널을 닫으면 버튼으로 돌아가며, **Put back in Chat Settings**를 누르면 섹션을 원래 위치로 되돌립니다.

Trackers 창의 트래커도 같은 방식으로 꺼낼 수 있습니다. 이때 되돌리는 버튼의 이름은 **Put back in Trackers**(트래커로 되돌리기)입니다.

## 컨트롤 창과 버튼

Game의 **Game controls**, **Session**, **Volume**, **Game Assets**와 **Connected chat**, 설치한 패키지의 컨트롤은 작은 전용 창을 엽니다.

버튼은 처음에 채팅 오른쪽 위에 있습니다. 클릭하거나 탭하면 창이 열리고, 창을 닫으면 버튼으로 돌아갑니다. 휴대폰에서는 화면 너비의 패널로 열립니다.

도구를 Chat Settings 안에 두려면 창을 열고 **Put back in Chat Settings**를 선택하세요. 펼치고 접을 수 있는 섹션으로 들어갑니다. 섹션의 별도 창 버튼으로 다시 꺼낼 수 있으며, 컴퓨터에서는 제목을 밖으로 끌어도 됩니다. **Reset View**는 도구를 초기 버튼 형태로 되돌립니다.

버튼을 끌어 위치를 바꾸세요. 드래그하면 가까운 버튼과 나란히 맞춰집니다. 컴퓨터에서는 Alt를 눌러 자유롭게 배치하거나, 버튼에 포커스를 맞추고 방향키로 옮길 수 있습니다. Conversation의 **Calls**는 일반 버튼으로 유지됩니다.

## 채팅마다 저장되는 창 배치

채팅은 창 크기와 위치, 고정과 잠금, 꺼낸 섹션, 버튼 위치를 기억합니다. 휴대폰 버튼 위치는 컴퓨터와 별도로 저장됩니다. 채팅을 바꾸면 그 채팅의 배치가 복원됩니다.

[설정 프로필](#settings-profiles)로 배치를 저장해 다른 채팅에서 쓸 수 있습니다. **Reset View**는 현재 채팅의 초기 배치로 돌아갑니다.

## 새 채팅의 배치 고르기

**Reset View** 옆의 별 버튼을 누르면 현재 배치를 같은 모드의 새 채팅에 기본으로 적용합니다. Conversation, Roleplay, Game은 각각 즐겨찾는 배치를 따로 저장합니다.

업데이트 후에는 익숙한 도구 버튼 배치에 세 모드 모두 이미 별이 붙어 있습니다. 새 채팅은 즐겨찾는 배치를 바꾸거나 지울 때까지 이 배치를 사용합니다. 새로 설치했다면 도구는 Chat Settings 안에 있고 즐겨찾는 배치는 없습니다. 나중에 예전 채팅을 가져와도 그 채팅의 도구를 쓸 수 있지만, 새 채팅의 기본 배치는 바뀌지 않습니다.

1. 창과 버튼을 원하는 곳에 놓으세요. 도구를 Chat Settings 안에 두거나 필요에 따라 꺼내세요.
2. 새 채팅에서도 배치 안내를 숨기려면 안내를 닫으세요.
3. **Reset View** 옆의 별을 누르세요. 현재 배치와 안내 표시 여부가 저장한 즐겨찾는 배치와 같으면 별이 채워집니다.

즐겨찾는 배치에는 창과 버튼의 위치와 크기, 고정, 잠금, 도구를 안에 둘지 밖에 둘지, 안내 표시 여부가 저장됩니다. 캐릭터, 연결, AI 설정, 메시지는 해당 채팅에 남습니다.

즐겨찾는 배치를 바꾸려면 배치를 수정하고 별을 다시 누르세요. 사용을 중단하려면 채워진 별을 누르세요. 이후 새 채팅은 기본 배치를 사용합니다. 저장, 변경, 삭제는 그 이후에 만든 채팅에만 영향을 주며 기존 채팅은 자기 배치를 유지합니다.

자체 배치가 저장된 설정 프로필을 적용하면 프로필 배치가 즐겨찾는 배치보다 우선합니다. 저장된 배치가 없는 프로필은 즐겨찾는 배치를 그대로 둡니다. 안내 표시 여부는 프로필에 저장된 선택을 따릅니다.

## Chat Name

**Chat Name**(채팅 제목) 섹션에는 채팅 목록에 표시되는 이름이 들어 있습니다. 이 이름은 본인에게만 보입니다. AI에는 전달되지 않으며, 주고받는 내용에도 전혀 영향을 주지 않습니다.

1. **Chat Name** 섹션에서 현재 이름을 클릭하세요.
2. 이름이 입력란으로 바뀝니다.
3. 새 이름을 입력하세요.
4. Enter를 누르거나 체크 표시 버튼을 클릭해 확정하세요.

## Connection

**Connection**(연결) 섹션에서는 이 채팅에서 어떤 AI 제공자와 모델이 답할지 정합니다. 연결은 API 키와 선택한 모델까지 포함해 AI 제공자에 접속하는 데 필요한 정보를 한데 저장해 둔 것입니다. API 키는 해당 제공자의 계정을 Marinara Engine이 쓸 수 있게 해 주는 비밀번호 같은 비밀 문자열입니다.

드롭다운에서 저장해 둔 연결을 고르세요. **Random**을 고를 수도 있습니다. 이때는 무작위 목록에 넣어 둔 연결 중에서 매번 다른 연결을 고릅니다.

연결을 처음부터 만드는 방법은 [AI 제공자에 연결하기](../connections/connecting-to-a-provider.md)를 참고하세요.

## 설정 프로필

패널 맨 위에는 **Profile**(프로필) 컨트롤이 있습니다. 설정 프로필은 채팅 설정을 한 묶음으로 저장해 두고 다른 채팅에서 다시 쓸 수 있게 한 것입니다. 드롭다운에서 프로필을 고르면 현재 채팅에 적용됩니다.

프로필에는 이 채팅의 연결, 프롬프트 프리셋, 에이전트, 도구, 번역, 기억 기능, 고급 매개변수, 창 배치를 비롯한 설정이 함께 담깁니다. 캐릭터, 페르소나, 로어북, 스프라이트, 요약, 태그, 장면 프롬프트는 프로필이 건드리지 않습니다. 이 항목들은 채팅 자체에 묶여 있습니다. **Default**처럼 저장된 배치가 없는 프로필은 채팅의 창 배치를 그대로 둡니다.

이 줄에는 글자 없이 작은 아이콘 버튼만 늘어서 있습니다. 버튼에 마우스를 올리면 툴팁에 이름이 나타납니다.

- 디스크 아이콘(**Save current chat settings into this profile**)은 현재 채팅의 설정을 선택한 프로필에 써 넣습니다.
- 연필 아이콘(**Rename profile**)은 선택한 프로필의 이름을 바꿉니다.
- 파일 더하기 아이콘(**Save current chat settings as a new profile**)은 현재 채팅의 설정을 새 프로필로 저장합니다.
- 아래쪽 화살표 아이콘(**Import settings profile (.json)**)은 `.json` 파일에서 프로필을 불러옵니다.
- 위쪽 화살표 아이콘(**Export settings profile (.json)**)은 선택한 프로필을 `.json` 파일로 저장합니다.
- 휴지통 아이콘(**Delete profile**)은 선택한 프로필을 삭제합니다.

드롭다운 옆에는 별 버튼이 있습니다. 이 버튼을 클릭하면 그 프로필이 해당 모드의 새 채팅에 쓰이는 기본값이 됩니다. 그 모드에서 새 채팅을 만들면 Marinara가 별을 붙인 프로필을 알아서 적용합니다. 기본값으로 지정할 수 있는 프로필은 모드마다 하나뿐입니다.

이 기능을 지원하는 모드에는 기본 제공 **Default** 프로필이 있습니다. **Default** 프로필은 이름을 바꾸거나, 설정을 써 넣거나, 삭제할 수 없습니다. 이 프로필을 적용하면 프로필이 관리하는 설정이 앱 기본값으로 되돌아갑니다.

프로필 컨트롤은 Game Mode에는 나타나지 않습니다.

Marinara는 **preset**이라는 말을 프롬프트 프리셋에만 씁니다. 프롬프트 프리셋은 시스템 프롬프트의 구조와 생성 파라미터를 정하고, 설정 프로필은 위에 적은 재사용 가능한 채팅 설정을 한데 묶습니다. 자세한 규칙은 [설정 프로필](settings-profiles.md)을 참고하세요.

## 채팅 변수

**Chat Variables**(채팅 변수) 섹션에서는 텍스트에 이름을 붙이고 그 이름을 중괄호 두 개로 감싸 재사용할 수 있습니다. `char1`이라는 변수에 `Mary` 값을 넣은 다음 메시지에 `{{char1}} walks in.`을 입력하면 AI는 "Mary walks in."으로 읽습니다.

각 행에는 **name**(이름)과 **value**(값)이 있습니다. 이름에는 영문자, 숫자, 밑줄을 쓸 수 있으며 영문자나 밑줄로 시작해야 합니다. 정확히 21자인 이름은 캐릭터 참조용으로 예약되어 있습니다. `char`나 `user` 같은 기본 제공 매크로 이름은 사용할 수 없습니다. 기본 제공 매크로가 항상 우선하기 때문입니다. Enter를 누르거나 필드 밖을 클릭하면 저장됩니다. 휴지통 버튼은 변수를 삭제합니다.

다음 세 가지를 알아 두세요.

- 메시지에는 입력한 태그가 그대로 표시됩니다. 값은 AI만 봅니다. 따라서 나중에 값을 바꾸면 그 태그를 사용한 이전 턴에도 모두 반영됩니다.
- 변수는 이 채팅에만 속합니다. 다른 채팅에는 별도 목록이 있으며 현재 목록은 앱을 다시 시작해도 유지됩니다.
- `{{setvar}}`와 같은 저장소를 사용합니다. 프롬프트 섹션이나 로어북 항목이 설정한 값도 여기에서 편집할 수 있는 행으로 표시됩니다. 같은 이름을 사용하는 항목은 직접 입력한 값을 덮어씁니다.

중괄호 두 개 안에 쓸 수 있는 다른 내용은 [프롬프트 매크로](../prompts/macros.md)를 참고하세요.

## Chat Settings의 채팅 도구

채팅 도구도 Chat Settings의 섹션으로 들어 있습니다. 어떤 도구가 보이는지는 채팅 모드에 따라 다릅니다.

- **Search messages**(메시지 검색)는 설정 프로필 아래, 위쪽에 있는 펼칠 수 있는 섹션입니다. 단어를 입력하거나 `#` 뒤에 메시지 번호를 붙여 검색하세요. **Bookmarks**(북마크)와 **Trash**(휴지통) 탭에는 북마크한 메시지와 삭제한 메시지가 표시됩니다. 다른 섹션처럼 별도 창으로 꺼낼 수 있습니다. Game 채팅에는 없습니다.
- **Chat Name** 아래의 **Chat Branches**(채팅 분기)에서 분기를 전환하고 이름을 바꾸고 내보내고 가져옵니다. [채팅 분기](branches.md)를 참고하세요.
- **Lorebooks** 아래의 **Chat Summary**(채팅 요약)에서 Roleplay 채팅의 요약을 읽고 만듭니다. [Memory Recall과 채팅 요약](../agents/memory.md#chat-summary-roleplay)을 참고하세요.
- **Chat Summary** 아래의 **Active Context**(활성 컨텍스트)는 이 채팅에서 사용 중인 로어북과 컨텍스트를 보여 줍니다. [토큰 예산과 재귀](../lorebooks/token-budgets.md#seeing-skipped-entries-in-active-context)를 참고하세요.
- 에이전트나 Advanced Memory를 쓰는 Roleplay 채팅에서는 **Agents** 바로 아래의 **Agent activity**(에이전트 활동)가 에이전트의 작업 결과를 보여 줍니다. 트래커 재실행, 에이전트 재시도와 중지, 트래커 비우기도 할 수 있습니다. [에이전트 활동](../roleplay/getting-started.md#agent-activity)을 참고하세요.
- **Agents** 아래의 **Author's Notes**(작가 노트)에는 Roleplay 채팅의 매 턴마다 AI가 읽는 노트를 넣습니다. [Author's Notes](../roleplay/getting-started.md#authors-notes)를 참고하세요.
- **Gallery**(갤러리)에는 채팅의 이미지와 동영상이 있습니다. [장면 배경과 Gallery](../media/scene-backgrounds.md)를 참고하세요.

## 패널의 다른 섹션

**Chat Settings** 패널에는 채팅별로 동작하는 기능도 여럿 모여 있습니다. 기능마다 별도의 가이드가 있습니다.

- **Persona**(페르소나)에서는 이 채팅에서 맡을 역할을 정합니다. Conversation(대화)과 Roleplay(롤플레이) 채팅에 나타납니다. [채팅에서 페르소나 선택하기](../characters/choosing-your-persona.md)를 참고하세요.
- **Characters**(캐릭터)에서는 Conversation과 Roleplay 채팅의 캐릭터를 관리합니다. 캐릭터가 둘 이상인 채팅은 [그룹 채팅과 여럿이 나누는 대화](group-chats.md)를 참고하세요.
- **Party**(파티)는 Game 채팅에만 나타납니다. **Persona**와 **Characters** 섹션을 대신해 두 가지를 한곳에 모아 놓은 섹션입니다.
- **Lorebooks**(로어북)에서는 이 채팅에 세계 설정을 붙입니다. [로어북 개요](../lorebooks/overview.md)를 참고하세요.
- **Agents**(에이전트)에서는 이 채팅에 쓸 AI 에이전트를 켭니다. [에이전트: 채팅을 도와주는 AI](../agents/agents-overview.md)를 참고하세요.
- **Translation**(번역)에서는 메시지 자동 번역을 설정합니다. [메시지 번역](../integrations/message-translation.md)을 참고하세요.
- **Advanced Parameters**(고급 매개변수)에서는 temperature나 최대 토큰 수 같은 생성 설정을 이 채팅에서만 다르게 지정합니다. [생성 파라미터](../prompts/generation-parameters.md)를 참고하세요.

어떤 섹션이 보이는지는 채팅 모드에 따라 다릅니다. Roleplay, Conversation, Game 채팅에만 나타나는 섹션도 있습니다.
