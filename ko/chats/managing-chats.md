# 채팅 목록 관리

왼쪽의 **Chats**(채팅) 패널에는 모든 채팅이 모여 있습니다. 이 패널에서 채팅을 시작하고, 찾고, 정렬하고, 정리하고, 삭제할 수 있습니다.

## 채팅 목록과 모드 탭

패널 위쪽에는 모드 탭이 3개 있습니다. 각 탭에는 그 모드의 채팅만 표시됩니다.

| 탭 | 모드 |
| --- | --- |
| **CONVO** | Conversation(대화): 메신저처럼 주고받는 채팅입니다. |
| **RP** | Roleplay(롤플레이): 캐릭터와 세계 상태를 함께 따라가는 장면입니다. |
| **GM** | Game: AI가 진행하는 1인용 RPG입니다. |

각 줄에는 채팅 이름과 참여 캐릭터의 아바타가 표시됩니다. Conversation 채팅에서는 아바타에 붙은 색점으로 그 캐릭터의 상태를 알 수 있습니다. 빨간 배지는 읽지 않은 메시지 개수입니다. 작은 분기 아이콘과 숫자가 붙은 줄은 분기가 여러 개인 채팅을 한 줄로 묶은 것입니다. [채팅 분기](branches.md)를 참고하세요.

## 채팅 시작하기

시작하기 전에: **Connections**(연결)에서 계정을 하나 이상 추가하세요. [AI 제공자에 연결하기](../connections/connecting-to-a-provider.md)를 참고하세요.

1. 원하는 모드의 탭을 클릭하세요.
2. 패널 위쪽의 **+** 버튼을 탭하세요. 버튼의 라벨은 탭에 따라 **New Conversation**(새 대화), **New Roleplay**(새 롤플레이), **New Game**(새 게임) 중 하나입니다.

Marinara가 채팅을 만들고 엽니다. 그 옆에 **Chat Settings**(채팅 설정)와 설정 마법사가 함께 열립니다. 채팅의 처음 이름은 **New Conversation**, **New Roleplay**, **New Game** 중 하나입니다. Conversation이나 Roleplay용 기본 설정 프로필을 별표로 저장해 두었다면 Marinara가 새 채팅에 그 프로필을 적용합니다. [설정 프로필](settings-profiles.md)을 참고하세요.

작동하지 않는 경우: 저장된 계정이 없으면 채팅 대신 **Add account**(계정 추가) 창이 열립니다. 서비스를 고르고 **Connect**(연결)를 클릭한 다음 모델을 고르세요. 전체 단계는 [AI 제공자에 연결하기](../connections/connecting-to-a-provider.md)에 있습니다.

## 채팅 가져오기

SillyTavern이나 Marinara의 `.jsonl` 채팅 기록을 가져올 수 있습니다.

1. 가져온 채팅이 들어갈 모드의 탭을 클릭하세요.
2. 패널 위쪽의 **Import**(가져오기) 버튼을 탭하세요. 버튼의 라벨은 **Import SillyTavern or Marinara chat JSONL**입니다.
3. `.jsonl` 파일을 고르세요.

Marinara가 채팅을 만들어 열고 **Imported N messages**(메시지 N개를 가져왔습니다)를 표시합니다. 내보내기 형식과 일괄 내보내기는 [채팅 내보내기와 가져오기](export-import.md)를 참고하세요.

작동하지 않는 경우: 화면 아래쪽에 **Import failed**(가져오기 실패)라는 짧은 메시지가 이유와 함께 표시됩니다. `.jsonl` 파일만 가져올 수 있습니다.

## 채팅 이름 바꾸기

채팅 이름은 나에게만 보입니다. 모델에는 전달되지 않습니다.

1. 채팅을 연 다음 **Chat Settings**를 여세요.
2. **Chat Name**(채팅 제목)에서 현재 이름을 클릭하세요.
3. 새 이름을 입력한 뒤 <kbd>Enter</kbd>를 누르거나 체크 표시를 클릭하세요.

패널을 여는 방법은 [채팅 설정](chat-settings.md)을 참고하세요.

## 채팅 삭제하기

1. 채팅 줄의 휴지통 버튼을 탭하세요. 컴퓨터에서는 줄에 마우스를 올리면 버튼이 나타납니다.
2. **Delete Chat**(채팅 삭제) 창에서 **Delete**(삭제)를 클릭하세요.

삭제는 되돌릴 수 없습니다. 그 채팅에서 아직 작성 중이던 답변도 함께 멈춥니다.

채팅에 분기가 여러 개 있으면 창에 분기 개수가 표시되고, 두 가지 선택지가 나옵니다.

- **Delete This Branch Only**(이 분기만 삭제)는 클릭한 분기를 지웁니다.
- **Delete All N branches**는 묶음 안의 모든 분기를 지웁니다.

채팅을 지우지 않고 분기를 관리하려면 [채팅 분기](branches.md)를 참고하세요.

이 확인 창은 앱 전체 설정인 **Confirm before deleting**(삭제 전 확인하기)이 제어합니다. 기본값은 켜짐입니다. **Settings → General**(설정 → 일반)에 있습니다.

## 채팅 폴더

폴더는 한 모드 탭 안에서 채팅을 묶습니다.

1. 채팅이 하나 이상 있는 탭을 여세요. 그래야만 탭 아래에 **New Folder**(새 폴더)가 나타납니다.
2. **New Folder**를 클릭하세요. 폴더 이름은 **unnamed**가 됩니다(그다음은 **unnamed 2**, **unnamed 3**).

| 하려는 일 | 방법 |
| --- | --- |
| 폴더 이름 바꾸기 | 폴더를 더블 클릭하거나 두 번 탭하세요. 또는 폴더에 포커스를 두고 <kbd>F2</kbd>를 누르세요. 빈 이름은 무시됩니다. |
| 폴더 삭제 | 폴더 줄의 휴지통 버튼을 클릭하세요. 폴더에 채팅이 들어 있으면 **Delete Folder**(폴더 삭제) 창이 나타납니다. 채팅은 최상위로 옮겨지며 삭제되지 않습니다. |
| 폴더 순서 바꾸기 | 폴더를 위아래로 끌어 놓으세요. 정렬 메뉴가 **Custom**(사용자 지정)으로 바뀝니다. |
| 채팅을 폴더에 넣기 | 채팅 줄을 폴더 위로 끌어 놓으세요. 터치 화면에서는 먼저 채팅을 0.5초 정도 길게 누르세요. |
| 채팅을 폴더에서 빼기 | 채팅을 폴더 아래의 빈 영역으로 끌어 놓으세요. |

채팅을 여러 개 선택한 상태에서 하나를 끌면 선택한 채팅 전체가 함께 이동합니다. 폴더에 들어 있지 않은 채팅은 폴더 아래에 나열됩니다.

## 검색, 정렬, 필터

### 이름으로 채팅 찾기

탭마다 검색란이 있습니다. 플레이스홀더는 탭에 따라 **Search conversations**(대화 검색...), **Search roleplays**(롤플레이 검색...), **Search games**(게임 검색...) 중 하나입니다. 단어를 입력하세요. 채팅 이름, 태그, 캐릭터 이름과 일치하는 채팅을 찾으며, 메시지 본문은 검색하지 않습니다.

### 모든 채팅에서 메시지 찾기

1. 정렬 메뉴 옆의 버튼인 **Search all chats**(모든 채팅 검색)를 탭하세요.
2. 찾을 단어를 입력하세요.

모든 채팅을 검색하며, 모드, 캐릭터, 보낸 사람, 날짜로 거를 수 있습니다.

정렬 메뉴(**Sort chats**)에는 다음 선택지가 있습니다.

| 선택지 | 순서 |
| --- | --- |
| **Custom** | 내가 정한 폴더 순서입니다. |
| **Manual order**(수동 정렬) | 채팅을 끌어 놓은 순서입니다. 키보드에서는 채팅에 포커스를 두고 <kbd>Alt</kbd>+<kbd>Up</kbd>이나 <kbd>Alt</kbd>+<kbd>Down</kbd>을 누르세요. |
| **Recent**(최근) | 최근에 활동한 채팅이 먼저 옵니다. 기본값입니다. |
| **Newest**(최신순) | 최근에 만든 채팅이 먼저 옵니다. |
| **Oldest**(오래된순) | 가장 오래된 채팅이 먼저 옵니다. |
| **A-Z**와 **Z-A** | 이름순입니다. |

탭 안의 채팅 중 하나라도 태그가 있으면 **Tags (N)**(태그(N)) 칩이 나타납니다. 칩을 클릭해 태그를 펼친 다음 태그를 클릭하면 그 태그가 붙은 채팅만 표시됩니다. 필터를 없애려면 **Clear**(지우기)를 클릭하세요. 이 패널에서는 채팅에 태그를 추가할 수 없습니다.

목록에는 한 번에 채팅이 100개씩 표시됩니다. 다음 묶음을 보려면 **Load more**(더 보기)를 클릭하세요.

## 채팅 여러 개 선택하기

1. 패널 위쪽의 체크 표시 버튼(**Select chats**)을 클릭하세요.
2. 원하는 채팅을 하나씩 클릭하세요. 채팅이 열리지 않고 줄에 체크박스가 표시됩니다.
3. 아래쪽 막대를 쓰세요. 막대에는 선택한 채팅 개수가 표시됩니다.

**Export**(내보내기)는 선택한 채팅을 `.jsonl` 파일들이 담긴 `.zip` 파일 하나로 다운로드합니다. **Delete**는 **Delete Chats**(채팅 삭제) 창에서 확인을 받은 뒤 채팅을 지웁니다. 선택 모드를 끝내려면 체크 표시 버튼을 다시 클릭하세요. 탭을 바꿔도 선택이 해제됩니다.

## 홈 화면의 최근 채팅

홈 화면에는 가장 최근 채팅을 보여 주는 **Recent chats**(최근 채팅) 위젯이 있습니다. 채팅마다 이름, 모드 배지, 마지막 메시지가 표시됩니다. 채팅을 클릭하면 그 채팅이 열립니다. 채팅이 하나도 없으면 위젯에 **Your chats will show here**(채팅이 여기에 표시됩니다)라고 표시됩니다. [홈 위젯](../home/welcome.md#home-widgets)을 참고하세요.
