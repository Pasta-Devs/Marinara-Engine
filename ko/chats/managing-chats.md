# 채팅 목록 관리

이 가이드에서는 Marinara Engine의 채팅 목록을 설명합니다. 모드 탭 3가지와 함께 채팅을 만들고, 가져오고, 이름을 바꾸고, 삭제하고, 정리하고, 검색하고, 여러 개를 한꺼번에 관리하는 방법을 다룹니다. 홈 화면의 최근 채팅 줄도 함께 설명합니다.

## 채팅 목록과 모드 탭

채팅은 왼쪽 사이드바인 **Chats**(채팅) 패널에 모여 있습니다. 패널 위쪽에는 모드 탭이 3개 있습니다.

- **CONVO**는 Conversation(대화)입니다. 메신저처럼 주고받는 일반 채팅입니다.
- **RP**는 Roleplay(롤플레이)입니다. 캐릭터와 세계 상태를 함께 따라가는 몰입형 장면입니다.
- **GM**은 Game입니다. AI가 진행하는 1인용 RPG입니다.

각 탭에는 그 모드의 채팅만 표시됩니다. 탭을 클릭하면 목록이 바뀝니다.

목록의 각 줄에는 채팅 이름과 참여 캐릭터의 아바타가 표시됩니다. Conversation 채팅에서는 아바타에 붙은 작은 색점으로 캐릭터별 상태를 알 수 있습니다. 줄에 빨간 배지가 보이면 읽지 않은 메시지 개수입니다.

일부 줄에는 숫자가 붙은 작은 분기 아이콘이 표시됩니다. 그 채팅에 분기가 둘 이상 있고, 분기들이 한 줄로 묶여 있다는 뜻입니다. 분기가 무엇인지는 [채팅 분기](branches.md)에서 확인하세요.

## 새 채팅 만들기

1. 원하는 모드 탭을 고르세요(**CONVO**, **RP**, **GM**).
2. 패널 위쪽의 **+** 버튼을 클릭하세요. 툴팁은 현재 탭에 따라 **New Conversation**(새 대화), **New Roleplay**(새 롤플레이), **New Game**(새 게임) 중 하나로 표시됩니다.
3. 채팅이 만들어지면서 바로 열리고, 설정을 마칠 수 있도록 **Chat Settings**(채팅 설정) 패널과 설정 마법사가 함께 열립니다.

새 채팅의 이름은 **New Conversation**, **New Roleplay**, **New Game** 중 하나입니다. 이름은 나중에 바꿀 수 있습니다(아래 채팅 이름 바꾸기 참고).

채팅을 열려면 연결이 하나 이상 필요합니다. 연결은 Marinara를 AI 제공자에 이어 주는 정보입니다. 아직 연결이 없으면 채팅 대신 **Set Up**(설정) 창이 나타나 먼저 연결을 고르라고 안내합니다. 연결이 하나도 없으면 **No connections found**와 함께 **Open Connections**(연결 열기) 버튼이 표시됩니다. 연결을 만드는 방법은 [AI 제공자에 연결하기](../connections/connecting-to-a-provider.md)에서 확인하세요.

그 모드의 기본 설정 프로필을 별표로 지정해 두었다면 Marinara가 새 채팅에 자동으로 적용합니다. [채팅 설정 개요](chat-settings.md)를 참고하세요.

## 채팅 가져오기

SillyTavern이나 Marinara에서 `.jsonl` 파일로 저장한 채팅 기록을 가져올 수 있습니다.

1. 가져온 채팅을 넣을 모드 탭을 고르세요.
2. 패널 위쪽의 **Import**(가져오기) 버튼을 클릭하세요. 툴팁은 **Import SillyTavern or Marinara chat JSONL**입니다.
3. `.jsonl` 파일을 고르세요.

Marinara가 현재 탭의 모드로 새 채팅을 만들고 바로 엽니다. **Imported N messages** 메시지가 표시되며, 여기서 N은 가져온 메시지 개수입니다.

대량 가져오기와 내보내기 형식을 포함해 채팅을 가져오고 내보내는 모든 방법은 [채팅 내보내기와 가져오기](export-import.md)에서 확인하세요.

## 채팅 이름 바꾸기

채팅 이름은 화면에만 보입니다. AI에 전달되지 않으므로 대화 내용에는 영향을 주지 않습니다.

1. 채팅을 여세요.
2. 채팅 안의 버튼으로 **Chat Settings**(채팅 설정)를 여세요.
3. **Chat Name**(채팅 제목) 항목에서 현재 이름을 클릭하면 입력란으로 바뀝니다.
4. 새 이름을 입력한 뒤 Enter를 누르거나 체크 버튼을 클릭하세요.

Chat Settings 패널에 대한 자세한 내용은 [채팅 설정 개요](chat-settings.md)에서 확인하세요.

## 채팅 삭제하기

채팅 하나를 삭제하려면 그 줄에 마우스를 올린 뒤 휴지통 버튼을 클릭하세요. 모바일에서는 휴지통 버튼이 항상 표시됩니다. **Delete Chat**(채팅 삭제) 창이 열리고 "Delete this chat?"라고 묻습니다. **Delete**(삭제)를 클릭하면 삭제됩니다.

삭제한 채팅은 되돌릴 수 없습니다. 그 채팅에서 생성 중이던 답변도 함께 중단됩니다.

### 분기 선택 창

삭제하려는 채팅에 분기가 둘 이상 있으면 다른 창이 대신 열립니다. 제목은 **Delete Chat**이고, 이 채팅에 분기가 여러 개라는 안내와 함께 두 가지 선택지를 제시합니다.

- **Delete This Branch Only**(이 분기만 삭제)는 클릭한 분기만 삭제합니다.
- **Delete All N Branches**는 묶여 있는 분기를 모두 삭제하며, 여기서 N은 분기 개수입니다.

채팅 전체를 지우지 않고 분기를 관리하는 방법은 [채팅 분기](branches.md)에서 확인하세요.

### 삭제 확인 창 켜고 끄기

이런 확인 창을 표시할지는 앱 전체 설정인 **Confirm before deleting**(삭제 전 확인하기)이 결정합니다. 기본값은 켜짐이며, **Settings**(설정)의 **General**(일반) 탭에 있습니다. 설정 자체의 도움말도 켜 둘 것을 권합니다.

## 채팅 폴더

각 모드 탭 안에서 채팅을 폴더로 묶을 수 있습니다.

1. 현재 탭에 채팅이 하나 이상 있어야 합니다. 그래야 목록 위에 **New Folder**(새 폴더) 버튼이 나타납니다.
2. **New Folder**를 클릭하세요. 폴더가 **unnamed**라는 이름으로 만들어집니다(같은 이름이 이미 있으면 **unnamed 2**, **unnamed 3** 식으로 이어집니다).

폴더 이름을 바꾸려면 폴더를 더블 클릭하거나 두 번 탭하거나, 폴더를 선택한 상태에서 F2를 누르세요. 이름을 비워 두면 변경이 무시됩니다.

폴더를 삭제하려면 폴더 줄의 휴지통 버튼을 클릭하세요. **Delete Folder**(폴더 삭제) 창에서 삭제를 확인합니다. 폴더를 삭제해도 안에 있던 채팅은 사라지지 않고 최상위로 다시 올라옵니다.

폴더 순서를 바꾸려면 손잡이를 잡고 위아래로 끌어 놓으세요.

채팅을 폴더에 넣으려면 채팅 줄을 폴더 위로 끌어 놓으세요. 채팅을 모든 폴더 밖으로 빼려면 폴더 아래의 빈 영역으로 끌어 놓으세요. 터치 화면에서는 채팅을 0.5초 정도 길게 누르면 끌기가 시작됩니다. 채팅을 여러 개 선택한 상태에서 그중 하나를 끌면 선택한 전체가 함께 이동합니다.

어느 폴더에도 들어 있지 않은 채팅은 폴더 아래에 일반 목록으로 표시됩니다.

## 검색, 정렬, 태그 필터

모드 탭마다 목록 위에 검색란이 따로 있습니다. 안내 문구는 탭에 따라 **Search conversations...**, **Search roleplays...**, **Search games...**로 바뀝니다. 검색은 채팅 이름, 태그, 참여 캐릭터 이름을 대상으로 합니다. 메시지 본문은 검색하지 않습니다.

검색란 옆에는 툴팁이 **Sort chats**인 정렬 메뉴가 있습니다. 선택지는 4가지입니다.

- **Newest**는 기본값이며, 최근에 활동한 채팅을 먼저 보여 줍니다.
- **Oldest**는 활동한 지 오래된 채팅을 먼저 보여 줍니다.
- **A-Z**는 이름을 A부터 Z 순으로 정렬합니다.
- **Z-A**는 이름을 Z부터 A 순으로 정렬합니다.

탭 안의 채팅 중 하나라도 태그가 있으면 태그 필터 줄이 나타납니다. **Tags**(태그) 칩을 클릭하면 태그 목록이 펼쳐집니다. 태그를 클릭하면 그 태그가 붙은 채팅만 표시됩니다. 필터를 없애려면 **Clear**(지우기)를 클릭하세요. 태그가 많을 때는 **+N more** 칩으로 나머지를 볼 수 있습니다.

참고: 이 화면은 이미 붙어 있는 태그로 거르기만 합니다. 여기에는 채팅에 태그를 추가하는 버튼이 없습니다.

목록에는 한 번에 최대 100개의 채팅이 표시됩니다. 그보다 많으면 아래쪽에 **Load more**(더 불러오기) 버튼이 나타나고, 클릭하면 다음 묶음이 이어서 표시됩니다.

## 채팅 여러 개 선택하기

여러 채팅을 한꺼번에 처리할 수 있습니다.

1. 패널 위쪽의 **Select chats**(채팅 선택) 버튼(체크 아이콘)을 클릭하세요.
2. 원하는 채팅을 차례로 클릭하세요. 이때는 채팅이 열리지 않고 각 줄의 체크박스가 켜집니다.
3. 아래쪽 막대에 선택한 채팅 개수와 버튼 2개가 표시됩니다.

**Export**(내보내기) 버튼은 선택한 채팅을 하나의 `.zip` 파일로 묶어 다운로드합니다. **Delete** 버튼은 선택한 채팅을 삭제합니다. 삭제 전에는 **Delete Chats** 확인 창이 먼저 표시됩니다.

아무 작업도 하지 않고 선택 모드를 끝내려면 선택 버튼을 다시 클릭하세요. 탭을 바꿔도 선택이 해제됩니다.

## 홈 화면의 Recent Chats

홈 화면에는 최근에 활동한 채팅 3개를 모아 보여 주는 **Recent Chats**(최근 채팅) 줄이 있습니다. 각 채팅은 아바타, 모드 배지, 채팅 이름이 담긴 작은 칩으로 표시됩니다. 칩을 클릭하면 그 채팅이 열립니다. 아직 채팅이 하나도 없으면 **No chats yet**이라고 표시됩니다.
