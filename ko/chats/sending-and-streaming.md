# 메시지 보내기와 스트리밍

메시지를 입력해 보내면 답변이 나타납니다. 이 가이드에서는 메시지 보내기, 첨부 파일, 스트리밍, 답변 멈추기, 다시 시도, 오류 읽는 법을 설명합니다.

## 메시지 보내기

시작하기 전에: 채팅에 모델이 지정되어 있어야 합니다. [AI 제공자에 연결하기](../connections/connecting-to-a-provider.md)를 참고하세요.

1. 채팅 아래쪽의 입력 막대에 글을 입력하세요.
2. **Send**(전송)를 클릭하거나, 해당 채팅 모드에서 **Send on Enter**(엔터 키로 전송)가 켜져 있다면 <kbd>Enter</kbd>를 누르세요.

보낸 메시지가 나타나고, 이어서 답변이 스트리밍됩니다. 한 채팅에서 동시에 생성할 수 있는 답변은 하나뿐입니다. 답변이 스트리밍되는 동안 **Send**는 정지 버튼으로 바뀝니다.

작동하지 않는 경우: 채팅에 모델이 설정되어 있지 않으면 답변이 바로 실패하고, 설정된 연결이 없다는 메시지가 나타납니다. [채팅 설정](chat-settings.md)에서 모델을 고르세요.

### Send on Enter

**Settings → General → Input & Editing**(설정 → 일반 → 입력 및 편집)에 있습니다. 채팅 모드마다 토글이 하나씩 있습니다.

| 채팅 모드 | 기본값 | 꺼져 있을 때 |
| --- | --- | --- |
| Roleplay | 꺼짐 | <kbd>Enter</kbd>를 누르면 줄이 바뀝니다. **Send**를 클릭하세요. |
| Conversations | 켜짐 | <kbd>Ctrl</kbd>+<kbd>Enter</kbd>(Mac에서는 <kbd>Cmd</kbd>+<kbd>Enter</kbd>)로 보냅니다. |
| Game | 켜짐 | <kbd>Ctrl</kbd>+<kbd>Enter</kbd>(Mac에서는 <kbd>Cmd</kbd>+<kbd>Enter</kbd>)로 보냅니다. |

Roleplay(롤플레이)는 메시지가 길고 줄바꿈이 자주 필요해서 기본값이 꺼짐입니다. Professor Mari에게는 별도의 토글인 **Enter sends to Professor Mari**(Enter로 Professor Mari에게 전송)가 **Settings → General → Search and Professor Mari settings**(설정 → 일반 → 검색 및 Professor Mari 설정)에 있습니다.

## 이미지와 파일 첨부

1. 입력 막대의 클립 아이콘을 탭하세요.
2. 파일을 고르세요. 입력란 위에 작은 칩으로 표시됩니다.
3. 평소처럼 보내세요.

Marinara는 이미지, PDF 파일, 일반 텍스트 파일(`.txt`, `.md`, `.markdown`, `.json`, `.jsonl`, `.csv`, `.log`, `.xml`, `.yaml`, `.yml`)을 받습니다. 파일 하나의 크기는 20 MB 이하여야 합니다. 이보다 큰 파일이나 지원하지 않는 형식은 안내와 함께 거부됩니다.

모델이 비전 기능을 지원해야만 이미지를 볼 수 있습니다. 텍스트만 처리하는 모델이라면 **Chat Settings → Advanced Parameters**(채팅 설정 → 고급 매개변수)에서 **Image captioning**(이미지 캡셔닝)을 켜세요. 기본값은 꺼짐입니다. 그러면 Marinara가 직접 고른 모델로 각 이미지를 글로 설명하고, 이미지 대신 그 설명을 보냅니다.

## 메시지 안에 갤러리 이미지 표시하기

첨부 파일은 모델이 보는 용도입니다. 갤러리 링크는 메시지 본문 안에 이미지를 표시해 직접 볼 수 있게 합니다. 메시지는 Markdown 이미지 문법을 지원하며, Marinara는 `card://` 링크를 갤러리 파일로 해석합니다.

```text
![a caption](card://characters/<character-id>/gallery/<filename>.png)
```

Roleplay에서는 채팅의 에셋 브라우저가 링크를 대신 넣어 줄 수 있습니다. 메시지, 인사말, 예시 대화에 직접 붙여 넣어도 됩니다.

캐릭터 자신의 갤러리에는 휴대 가능한 `card://self/gallery/<filename>` 형식을 쓰세요. 캐릭터를 내보냈다가 가져온 뒤에도 계속 작동합니다. 갤러리의 **Copy image reference**(이미지 참조 복사) 버튼이 이 형식을 만듭니다. [캐릭터 갤러리](../characters/galleries.md#reuse-a-gallery-image-in-messages-and-greetings)를 참고하세요.

## 답변 스트리밍

스트리밍은 답변을 한꺼번에 보여 주지 않고 단어 단위로 보여 줍니다. 이 설정은 **Settings → General → Responses**(설정 → 일반 → 응답)에 있습니다.

| 설정 | 기본값 | 하는 일 |
| --- | --- | --- |
| **Enable streaming**(스트리밍 활성화) | 켜짐 | 답변을 쓰이는 대로 보여 줍니다. 끄면 모델이 다 쓴 뒤에 답변 전체가 나타납니다. |
| **Streaming speed**(스트리밍 속도) | 50 | 1에서 100까지의 슬라이더입니다. 값이 낮을수록 타자기 효과가 느려집니다. 모델이 글을 쓰는 속도는 바뀌지 않습니다. |
| **Trim incomplete sentences from the response**(응답에서 완성되지 않은 문장 제거) | 꺼짐 | 답변을 저장하기 전에 끝의 미완성 문장을 지웁니다. 온전히 끝난 답변과 명령문 형태의 마무리는 그대로 둡니다. |

## 입력 중 표시와 진행 표시

첫 단어가 도착하기 전에는 캐릭터 이름과 함께 움직이는 점 세 개가 보입니다. 그룹 채팅에서는 답변하는 모든 캐릭터의 이름이 표시됩니다. 서버가 프롬프트를 준비하는 동안에는 진행 문구가 아래 라벨을 차례로 보여 줍니다. 일부 단계는 채팅에서 해당 기능을 쓸 때만 실행되므로, 모든 문구가 보이지는 않을 수 있습니다.

- **Preparing context...**
- **Building prompt...**
- **Scanning lorebooks...**
- **Recalling memories...**
- **Running agents...**
- **Retrieving knowledge...**
- **Generating...**

캐릭터의 상태가 바쁨이나 자리 비움이면 점 대신 대기 표시가 나타납니다. 캐릭터가 응답할 수 있게 되면 답변이 시작됩니다.

## 모델의 생각 보기

일부 모델은 "thinking"이라고 부르는 숨은 추론 과정을 함께 돌려줍니다. 답변에 추론이 있으면 메시지에 뇌 모양 아이콘인 **View model thoughts**(모델의 생각 보기)가 나타납니다. 클릭하면 추론 내용을 읽을 수 있습니다.

이 기능이 작동하려면 모델이 추론 내용을 돌려줘야 합니다. 일부 모델은 추론을 평범한 텍스트 태그로 감쌉니다. 그런 모델이라면 생성 설정에서 **Thinking Tags**(추론 태그)를 지정해 Marinara가 추론과 답변을 나눌 수 있게 하세요. [생성 파라미터](../prompts/generation-parameters.md)를 참고하세요.

## 답변 멈추기

정지 버튼을 클릭하세요. 답변이 스트리밍되는 동안에는 **Send** 버튼이 정지 버튼입니다. 이미 들어온 텍스트는 대개 남습니다. 직접 멈춘 경우에는 오류가 표시되지 않습니다.

## 다시 입력하지 않고 재시도하기

마지막 메시지가 내가 보낸 것이고 AI가 답하지 않았다면, 입력란을 비워 둔 채 **Send**를 클릭하세요(또는 <kbd>Enter</kbd>를 누르세요). Marinara는 같은 메시지를 다시 올리지 않고 새 답변을 시작합니다. Conversation(대화)에서는 이 상태일 때 버튼에 원형 화살표가 표시됩니다. 입력란에 쓰다 만 글이 있으면 **Send**는 그 글을 보냅니다.

Roleplay에서는 AI가 이미 답한 뒤에도 빈 **Send**로 완전히 새로운 답변을 시작합니다. 앞 답변에 덧붙이지는 않습니다. 앞 답변을 늘리려면 `/continue`를 쓰세요. [메시지 조작](messages.md)을 참고하세요.

## 생성 오류가 떴을 때

답변이 실패하면 화면 아래쪽에 토스트(짧은 팝업 메시지)가 약 15초 동안 표시됩니다. 내용은 복사할 수 있습니다. 일부 오류는 Marinara가 다음에 할 일로 바꿔서 알려 줍니다.

| 원인 | 토스트가 알려 주는 내용 |
| --- | --- |
| 모델이 지원하지 않는 파라미터를 거부함 | **Chat Settings → Advanced Parameters**를 열고 그 파라미터의 **Send**를 끄세요. |
| 모델이 요구하는 파라미터가 꺼져 있음 | 같은 곳에서 **Send**를 다시 켜세요. |
| 답변이 비어 있는 채로 돌아옴 | 메시지를 다시 보내세요. |
| 이미 답변을 생성하고 있음 | 기다리거나 정지 버튼으로 멈추세요. |
| 설정된 연결이 없음 | 채팅에 연결을 설정하세요. |

오류가 계속되면 [문제 해결](../TROUBLESHOOTING.md)을 참고하세요.

## 느린 연결과 모바일 탭

긴 답변은 시간이 걸릴 수 있습니다. 언제든 멈출 수 있습니다. 휴대폰에서는 다른 곳으로 전환하면 브라우저가 채팅 탭을 잠시 멈출 수 있습니다. 그때 답변이 스트리밍 중이었다면 Marinara는 **Finishing in background...**를 표시한 뒤 서버에서 답변이 끝났는지 확인합니다. 답변이 나타나지 않으면 잠시 뒤에 채팅을 새로 고치세요.
