# 채팅 내보내기와 가져오기

이 가이드에서는 채팅을 파일로 저장하는 방법, 읽기 좋은 스토리로 공유하는 방법, Marinara나 SillyTavern(다른 롤플레이 채팅 앱)의 채팅 파일을 다시 불러오는 방법을 설명합니다. 채팅은 하나만, 채팅의 일부만, 또는 여러 개를 한 번에 내보낼 수 있습니다.

<a id="file-formats-you-will-see"></a>

## 채팅 파일 형식

| 형식 | 설명 | 다시 가져올 수 있나요? |
| --- | --- | --- |
| **JSONL** | JSON Lines를 뜻하며, 메시지 하나를 한 줄에 저장하는 일반 텍스트 파일입니다. 기본 형식입니다. | 예 |
| **Text**(텍스트) | 읽기 좋은 `.txt` 대화 기록입니다. | 아니요 |
| **Markdown**(마크다운) | 읽기 좋은 `.md` 파일입니다. 채팅 이름과 채팅에 담긴 날짜 범위로 시작하고, 이어서 각 메시지를 화자 이름 아래에 보여 줍니다. | 아니요 |
| **Story**(스토리) | 화자마다 이름과 아바타를 보여 주는, 스타일이 적용된 `.html` 웹 페이지입니다. 브라우저에서 열어 읽거나 공유하거나 인쇄하세요. | 아니요 |

**Markdown**과 **Story** 파일에는 시스템 메시지와 사용자에게 숨긴 메시지가 들어가지 않습니다. 채팅 가져오기는 `.jsonl` 파일만 받으므로, 나중에 채팅을 다시 가져오려면 **JSONL**로 내보내세요.

**JSONL** 파일에는 채팅에 저장된 주소 몇 가지가 빠집니다. Discord 미러 웹훅, DeepLX 주소, DeepL 키, Intiface 주소입니다. 가져올 때도 이 값들은 절대 들어오지 않습니다. 이 기능을 쓴다면 가져온 채팅의 **Chat Settings**(채팅 설정)에서 다시 입력하세요.

## 채팅 하나 내보내기

1. 채팅을 여세요.
2. **Chat Settings**를 열고 **Chat Name**(채팅 제목) 아래의 **Chat Branches**(채팅 분기)를 펼치세요. 채팅에 분기가 하나뿐이어도 내보내기 버튼은 이 섹션에 있습니다.
3. **JSONL**, **Text**, **Markdown**, **Story** 중 하나를 탭하세요.

브라우저가 파일을 다운로드합니다. 파일에는 지금 보고 있는 분기와 그 메시지가 들어 있습니다.

<a id="export-part-of-a-chat"></a>

## 채팅 일부 내보내기

일부 메시지만 저장하려면 **Export a range**(범위 지정 내보내기)를 사용하세요. Game 채팅에서는 쓸 수 없습니다.

1. **Chat Branches**에서 **Export a range**를 클릭하세요.
2. 첫 메시지를 클릭한 다음 마지막 메시지를 클릭하세요. "Select the first and last message to export."라는 안내 문구가 표시됩니다.
3. **Export selected**(선택한 메시지 내보내기)를 클릭하세요.
4. **Export messages**(메시지 내보내기) 창에서 메시지 개수와 첫 메시지, 마지막 메시지를 확인한 다음 **Text**, **Markdown**, **JSONL**, **Story** 중 하나를 고르세요.

Marinara는 고른 첫 메시지부터 마지막 메시지까지 모든 메시지를 내보냅니다. 내보내지 않고 멈추려면 **Cancel**(취소)을 클릭하세요.

## 여러 채팅 한 번에 내보내기

1. 왼쪽 사이드바에서 원하는 모드의 탭을 클릭하세요. **CONVO**, **RP**, **GM** 중 하나입니다. 각 탭은 그 탭에 속한 채팅만 내보냅니다.
2. 목록 위쪽의 **Select chats**(채팅 선택)를 클릭하세요.
3. 원하는 채팅을 하나씩 클릭하세요. 아래쪽 막대에 "3 selected"처럼 선택한 개수가 표시됩니다.
4. 막대에서 **Export**(내보내기)를 클릭하세요.

브라우저가 채팅 하나당 JSONL 대화 기록 하나가 담긴 `.zip` 파일을 다운로드합니다. 여러 채팅을 한 번에 내보낼 때는 항상 **JSONL**을 씁니다. [채팅 목록 관리](managing-chats.md#selecting-multiple-chats)를 참고하세요.

## 새 채팅으로 가져오기

Marinara에서 저장했거나 SillyTavern에서 내보낸 `.jsonl` 파일로 새 채팅을 만듭니다.

1. 왼쪽 사이드바에서 원하는 모드의 탭을 클릭하세요. 가져온 채팅은 파일에 적힌 모드가 아니라 지금 열어 둔 탭의 모드를 따릅니다.
2. **+** 버튼 옆의 **Import**(가져오기) 버튼을 클릭하세요. 라벨은 **Import SillyTavern or Marinara chat JSONL**입니다.
3. `.jsonl` 파일을 고르세요.

"Imported N messages"라는 메시지가 나타나고, Marinara가 새 채팅을 엽니다. SillyTavern 파일에 대한 더 자세한 내용은 [SillyTavern에서 가져오기](../data/importing-from-sillytavern.md)를 참고하세요.

작동하지 않는 경우: 화면 아래쪽에 **Import failed**(가져오기 실패)라는 작은 메시지가 이유와 함께 나타납니다. 파일 이름이 `.jsonl`로 끝나는지 확인하세요.

## 새 분기로 가져오기

`.jsonl` 파일을 이미 있는 채팅에 새 분기로 불러옵니다. [채팅 분기](branches.md)를 참고하세요.

1. 분기를 추가할 채팅을 여세요.
2. **Chat Settings**를 열고 **Chat Branches**를 펼친 다음 **Import**를 클릭하세요.
3. `.jsonl` 파일을 고르세요.

"Imported N messages as a new branch"라는 메시지가 나타납니다. 새 분기는 열려 있는 채팅의 캐릭터, 페르소나, 연결, 프롬프트 프리셋을 그대로 씁니다.

## 내보내기에 추론과 비공개 메모 포함하기

숨은 텍스트를 내보내기 파일에 넣을지는 설정 두 개로 정합니다. 둘 다 **Settings → Advanced → Message Tools**(설정 → 고급 → 메시지 도구)에 있는 토글이며, 둘 다 기본값은 꺼짐입니다. 채팅 하나를 내보낼 때와 `.zip`으로 내보낼 때 모두 적용됩니다.

| 설정 | 켜면 |
| --- | --- |
| **Include reasoning in exports**(내보내기에 추론 포함) | 모델이 저장한 사고 과정을 모든 형식에 넣습니다. **Markdown**과 **Story** 파일에서는 메시지 아래의 접을 수 있는 **Thinking** 섹션에 들어갑니다. |
| **Include private notes in exports**(내보내기에 비공개 메모 포함) | 내 비공개 메시지 메모를 **JSONL**과 **Text** 내보내기에 넣습니다. |

> **경고:** 대화 기록을 공유하기 전에는 둘 다 꺼 두세요. 숨은 추론 내용과 비공개 메모에는 보낼 생각이 없던 내용이 들어 있을 수 있습니다.
