# 채팅 내보내기와 가져오기

이 가이드에서는 채팅을 파일로 저장하는 방법과 저장해 둔 채팅을 다시 Marinara Engine으로 불러오는 방법을 설명합니다. 채팅은 하나만 내보낼 수도 있고 여러 개를 한 번에 내보낼 수도 있습니다. Marinara에서 저장한 채팅 파일은 물론, SillyTavern(다른 롤플레이 채팅 앱)에서 내보낸 파일도 가져올 수 있습니다.

## 채팅 파일 형식

Marinara는 두 가지 채팅 파일 형식을 사용합니다.

- **JSONL**: JSONL은 JSON Lines를 뜻합니다. 메시지 하나를 한 줄에 저장하는 일반 텍스트 파일입니다. 내보내기 기본값이며, 나중에 Marinara로 다시 가져올 수 있습니다.
- **Text**: 사람이 읽기 좋은 `.txt` 대화 기록입니다. 읽고 공유하기는 편하지만 Marinara로 다시 가져올 수는 없습니다. 다른 사람에게 채팅 내용을 보여 줄 때만 **Text**를 쓰세요.

채팅 가져오기는 `.jsonl` 파일만 받습니다. 나중에 다시 가져올 생각이라면 **Text**가 아니라 **JSONL**로 내보내세요.

## 채팅 하나 내보내기

채팅 하나를 파일로 내보내려면 **Chat Settings**(채팅 설정)의 **Chat Branches**(채팅 분기) 섹션을 사용합니다. 한 채팅의 기록을 내보내는 가장 빠른 방법입니다.

1. 내보낼 채팅을 여세요.
2. **Chat Settings**를 열고 **Chat Name** 아래의 **Chat Branches** 섹션을 펼치세요.
3. JSONL 파일로 저장하려면 **JSONL**을, 읽기 쉬운 텍스트 파일로 저장하려면 **Text**를 클릭하세요.
4. 브라우저가 파일을 다운로드합니다.

지금 열려 있는 채팅이 메시지까지 함께 저장됩니다.

## 여러 채팅 한 번에 내보내기

채팅 여러 개를 선택해서 `.zip` 파일 하나로 한꺼번에 다운로드할 수 있습니다.

1. 왼쪽 사이드바에서 채팅 목록을 여세요.
2. 원하는 모드 탭을 고르세요. **CONVO**(Conversation), **RP**(Roleplay), **GM**(Game) 중에서 고를 수 있습니다. 각 탭은 그 탭에 속한 채팅만 내보냅니다.
3. 채팅 목록 위쪽의 **Select chats**(채팅 선택) 버튼을 클릭하세요.
4. 포함할 채팅을 하나씩 클릭하세요. 클릭한 채팅마다 체크박스가 켜집니다.
5. 아래쪽에 선택한 개수를 알려 주는 막대가 나타납니다. 예를 들면 "3 selected"처럼 표시됩니다.
6. 그 막대에서 **Export**(내보내기)를 클릭하세요.
7. 브라우저가 JSONL 대화 기록이 담긴 `.zip` 파일을 다운로드합니다. 채팅 하나당 파일 하나입니다.

여러 채팅을 한 번에 내보낼 때는 항상 **JSONL** 형식을 씁니다. 같은 막대의 **Delete**(삭제)는 선택한 채팅을 지울 때만 클릭하세요.

## 새 채팅으로 가져오기

`.jsonl` 파일로 채팅을 새로 만드는 방법입니다. Marinara에서 저장한 채팅 파일이나 SillyTavern에서 내보낸 파일을 가져올 때 사용합니다.

1. 왼쪽 사이드바에서 채팅 목록을 여세요.
2. 원하는 모드 탭을 고르세요. **CONVO**, **RP**, **GM** 중에서 고를 수 있습니다. Marinara는 지금 열려 있는 탭에 가져온 채팅을 만듭니다.
3. 목록 위쪽의 **New**(새로 만들기) 버튼 옆에 있는 가져오기 버튼을 클릭하세요. 툴팁에 **Import SillyTavern or Marinara chat JSONL**이라고 표시됩니다.
4. 파일 선택 창에서 `.jsonl` 파일을 고르세요.
5. "Imported N messages"라는 메시지가 나타나고, Marinara가 새로 만든 채팅으로 이동합니다.

새 채팅을 Roleplay 모드로 만들고 싶다면 가져오기 전에 **RP** 탭을 여세요. 모드를 정하는 것은 파일이 아니라 열려 있는 탭입니다.

## 새 분기로 가져오기

`.jsonl` 파일을 기존 채팅에 새 분기로 불러올 수도 있습니다. 분기는 따로 저장된 채팅 사본이라, 원래 채팅과 별개로 이야기를 이어 갈 수 있습니다. 분기에 대한 자세한 내용은 [채팅 분기](branches.md)를 참고하세요.

1. 분기를 추가할 채팅을 여세요.
2. **Chat Settings**를 열고 **Chat Branches** 섹션을 펼치세요.
3. 그 섹션에서 **Import**(가져오기)를 클릭하세요.
4. `.jsonl` 파일을 고르세요.
5. "Imported N messages as a new branch"라는 메시지가 나타납니다.

새 분기는 열려 있는 채팅에 추가됩니다. 캐릭터, 페르소나, 연결, 프롬프트 프리셋은 열려 있는 채팅의 것을 그대로 씁니다.

## 내보내기에 추론 내용 포함하기

일부 모델은 답변과 함께 겉으로 드러나지 않는 사고 과정이나 추론 내용을 저장합니다. 이 숨은 내용을 내보내기 파일에 넣을지는 설정 하나로 정합니다.

해당 설정은 **Include reasoning in exports**(내보내기에 추론 포함)입니다. **Settings**(설정)의 **Advanced**(고급) 탭에서 **Message Tools**(메시지 도구) 섹션에 있습니다. 토글이며 기본값은 **off**입니다.

- **off**이면 저장된 사고 과정과 추론 내용을 **JSONL**과 **Text** 채팅 내보내기 양쪽 모두에서 뺍니다.
- **on**이면 숨은 사고 과정과 추론 내용을 두 형식 모두에 넣습니다.

이 설정은 채팅 하나를 내보낼 때와 `.zip`으로 여러 개를 내보낼 때 모두 적용됩니다.

대화 기록을 다른 사람과 공유할 때는 **Include reasoning in exports**를 꺼 두세요. 숨은 추론 내용에는 함께 보낼 생각이 없던 메모가 들어 있을 수 있습니다. 혼자 볼 기록을 온전히 남기고 싶을 때만 켜세요.
