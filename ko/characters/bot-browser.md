# Card Browser: 캐릭터 찾아서 가져오기

이 가이드에서는 Marinara Engine의 **Card Browser**(카드 브라우저)를 설명합니다. 공개 사이트에서 캐릭터 카드를 찾아 라이브러리로 가져오는 기본 내장 도구입니다. 지원하는 소스, 검색과 필터 사용법, 소스별 성인 콘텐츠 처리 방식을 다룹니다. 캐릭터를 가져오거나 파일로 저장하는 방법도 함께 설명합니다. 예전 버전에서는 이 탭 이름이 **Bot Browser** 또는 **Browser**였습니다.

캐릭터 카드는 캐릭터 한 명의 이름, 성격, 인사말을 비롯한 정보를 담은 파일입니다. 원래대로라면 웹사이트에서 카드를 다운로드한 다음 Marinara에 업로드해야 합니다. **Card Browser**는 이 두 단계를 한자리에서 대신 처리합니다.

## Card Browser란

**Card Browser**는 Marinara 안에서 여러 공개 캐릭터 카드 사이트를 검색합니다. 지원하는 소스는 **ChubAI**, **JannyAI**, **Pygmalion**, **Wyvern**, **DataCat** 5곳입니다. **CharacterTavern**도 목록에는 그대로 있지만 지금은 둘러볼 수 없습니다([CharacterTavern](#charactertavern) 참고). 소스를 골라 검색하고, 결과를 필터링하고, 캐릭터의 상세 정보를 미리 볼 수 있습니다. 그런 다음 그 캐릭터를 라이브러리로 가져오거나 PNG 파일로 저장하면 됩니다. 기본값 그대로 두면 캐릭터 카드를 둘러보고 가져오는 데 계정도 API 키도 필요하지 않습니다.

## Card Browser 열기

**Card Browser**를 여는 방법은 두 가지입니다.

1. 상단 바에서 **Card Browser** 아이콘을 클릭하세요. 오른쪽 패널 버튼들이 늘어선 줄에 있습니다.
2. 또는 오른쪽 사이드바에서 **Card Browser** 패널을 연 다음, 패널 위쪽의 **Download Cards**(카드 다운로드) 버튼을 클릭하세요.

어느 쪽이든 콘텐츠 영역 전체가 **Card Browser** 전체 화면으로 바뀝니다. 이 화면은 채팅 영역을 대신 차지합니다. 작은 팝업 창이 아닙니다.

나가려면 **Card Browser** 헤더 왼쪽 위의 뒤로 화살표 버튼을 클릭하세요. 들어오기 전 화면으로 돌아갑니다.

**Card Browser**는 앱이 켜져 있는 동안 상태를 유지합니다. 닫았다가 다시 열어도 마지막 검색어, 필터, 선택했던 캐릭터가 그대로 남아 있습니다. 앱 전체를 새로 고치면 초기화됩니다.

## 소스 고르기

헤더의 소스 버튼을 클릭하세요. 현재 소스 이름과 작은 화살표가 표시되어 있습니다. 클릭하면 소스가 **ChubAI**, **JannyAI**, **CharacterTavern**, **Pygmalion**, **Wyvern**, **DataCat** 순서로 들어 있는 메뉴가 열립니다. **CharacterTavern**에는 **Unavailable**(사용할 수 없음) 표시가 붙어 있습니다.

**Card Browser**를 처음 열면 **ChubAI**가 선택되어 있습니다. 소스를 바꾸면 검색어, 태그, 필터가 모두 지워집니다. 성인 콘텐츠 설정과 로그인 상태는 소스마다 따로 기억하므로, 한 소스에서 바꾼 설정이 다른 소스에 영향을 주지 않습니다.

이름과 관련해 한 가지만 짚어 둡니다. 메뉴에는 **ChubAI**로 적혀 있지만, 캐릭터 상세 화면의 외부 링크는 **View on Chub**으로 표시됩니다. 사이트가 스스로를 부르는 이름이 그렇기 때문입니다. 나머지 소스는 두 곳의 이름이 같습니다.

## CharacterTavern

CharacterTavern이 웹사이트를 개편하면서 Marinara가 카드를 검색하고 다운로드할 때 쓰던 연결을 더 이상 제공하지 않습니다. **CharacterTavern**을 고르면 **Card Browser**에 검색 결과 대신 짧은 안내가 표시됩니다. CharacterTavern이 API 접근을 제공하게 되면 둘러보기 기능이 다시 돌아올 수 있습니다.

그때까지는 다음과 같이 CharacterTavern 캐릭터를 직접 Marinara로 가져올 수 있습니다.

1. 안내에서 **Open CharacterTavern**(CharacterTavern 열기)을 클릭하세요. 새 탭에서 사이트가 열립니다.
2. character-tavern.com에서 캐릭터 카드 파일을 다운로드하세요.
3. 안내에서 **Import Character**(캐릭터 가져오기)를 클릭하고 다운로드한 파일을 고르세요. [캐릭터 카드 가져오기와 내보내기](import-export.md)를 참고하세요.

CharacterTavern에서 이미 가져온 캐릭터는 라이브러리에 그대로 남아 있습니다.

## 검색, 정렬, 페이지 이동

**Search characters...** 입력란에 입력하면 검색됩니다. Enter 키를 누를 필요는 없습니다. 입력을 멈추고 잠깐(약 0.5초) 지나면 Marinara가 알아서 검색합니다. 입력란을 비우거나 필터를 바꿔도 다시 검색합니다.

검색 입력란 옆에는 정렬 드롭다운이 있습니다. 선택지는 소스마다 다르고, 기본 정렬 방식도 소스마다 다릅니다.

| 소스      | 기본 정렬       |
| --------- | --------------- |
| ChubAI    | Most Downloaded |
| JannyAI   | Newest          |
| Pygmalion | Downloads       |
| Wyvern    | Popular         |
| DataCat   | Relevance       |

현재 검색을 다시 실행하려면 **Refresh**(새로고침) 버튼(원형 화살표 아이콘)을 클릭하세요.

결과 아래에는 **Previous**(이전) 버튼과 **Next**(다음) 버튼이 있고, **Page 2** 같은 페이지 표시가 함께 나옵니다. 소스가 정확한 전체 개수를 알려 주지 못할 때는 현재 페이지 번호만 표시됩니다.

**DataCat**에는 주의할 점이 하나 있습니다. **Fresh** 정렬은 태그 필터와 검색어가 모두 없을 때만 최신 결과를 보여 줍니다. 검색어를 입력하거나 태그를 고르는 순간 **DataCat**은 일반 관련도 결과로 되돌아갑니다.

## 태그로 필터링하기

툴바의 **Tags**(태그) 버튼을 클릭하면 태그 패널이 열립니다.

- **Search tags...** 입력란에 입력하면 태그 목록이 좁혀집니다.
- 태그 옆의 초록색 체크를 클릭하면 그 태그를 포함하고, 빨간색 빼기를 클릭하면 제외합니다. 하나의 태그를 포함과 제외에 동시에 넣을 수는 없습니다.
- 포함한 태그는 초록색 칩으로, 제외한 태그는 빨간색 칩으로 표시됩니다. 칩을 클릭하면 해제됩니다.
- **Clear**(지우기) 버튼을 누르면 적용 중인 태그가 모두 사라집니다.

대부분의 소스에서 태그 목록은 최근 검색 결과에 들어 있던 캐릭터를 바탕으로 만들어집니다. 첫 검색 전에는 패널에 **Tags will appear after searching**이라고 표시됩니다. 원하는 태그가 목록에 없으면 이름을 직접 입력하세요. 버튼이 두 개 나타나서 필터로 추가하거나 결과에서 차단할 수 있습니다.

**DataCat**은 방식이 다릅니다. 태그 목록이 워낙 방대해서 인기 태그를 처음부터 바로 불러옵니다. 그 밖의 태그 이름은 직접 입력하면 됩니다.

## 추가 필터

일부 소스는 툴바에 **Filters**(필터) 버튼을 함께 표시합니다. 제공할 필터가 있는 소스에서만 나타나므로 **DataCat**에서는 보이지 않습니다. 작은 배지에 적용 중인 필터 개수가 표시됩니다.

필터 패널에는 다음 항목이 들어갈 수 있습니다.

- **Lorebook**, **Alt Greetings** 같은 콘텐츠 체크박스. 해당 기능을 가진 캐릭터만 남깁니다. 로어북은 캐릭터가 함께 지니고 다닐 수 있는 추가 배경 설정을 모아 둔 것입니다.
- **Sort Direction**(정렬). **ChubAI**와 **Pygmalion**에서 **Descending** 또는 **Ascending**을 고를 수 있습니다.
- **Min Tokens**(최소 토큰)와 **Max Output Tokens**(최대 출력 토큰) 숫자 입력란. 결과를 크기로 제한합니다. 비워 두면 소스의 기본값을 씁니다.
- **JannyAI**에는 **Show Low Quality** 토글이 있습니다. 기본값은 꺼짐이라 **JannyAI**가 저품질로 표시한 캐릭터가 숨겨집니다. 함께 보려면 켜세요.

**Wyvern** 관련 참고 사항입니다. **Lorebook**과 **Alt Greetings** 체크박스, **Min Tokens**와 **Max Output Tokens** 입력란이 표시되기는 하지만, 어느 것도 **Wyvern** 결과를 바꾸지 않습니다. **Wyvern**에서 결과를 좁히려면 대신 정렬 드롭다운과 태그를 쓰세요.

## 소스별 성인 콘텐츠(NSFW)

앱에서 성인 콘텐츠는 **NSFW**로 표시됩니다. 툴바에는 **NSFW** 체크박스가 하나뿐이지만 소스마다 처리 방식이 다릅니다. 질문이 가장 많은 부분이니 꼼꼼히 읽어 주세요.

- **ChubAI**와 **JannyAI**: **NSFW** 체크박스가 곧바로 작동합니다. 로그인이 필요 없습니다. 기본값은 꺼짐입니다.
- **Pygmalion**: 로그인하기 전까지 **NSFW** 체크박스가 비활성화되어 있습니다. 툴팁이 먼저 로그인하라고 안내합니다. 로그인한 뒤에는 앱이 Pygmalion 계정 설정을 그대로 따릅니다. 그때부터 체크박스에는 **NSFW depends on your account settings**라고 표시됩니다. 로그인 후에는 켜고 끄는 스위치가 따로 없습니다.
- **Wyvern**: **NSFW** 체크박스가 항상 비활성화되어 있습니다. **Use "🔞 Popular NSFW" sort for NSFW content**라는 안내가 표시됩니다. **Wyvern**에서 성인 콘텐츠를 보려면 정렬 드롭다운에서 **🔞 Popular NSFW**를 고르세요.
- **DataCat**: 모든 캐릭터에 성인 태그가 붙어 있어 체크박스가 켜진 상태로 고정됩니다. **DataCat**을 처음 고르면 **DataCat is NSFW only** 제목의 창이 뜹니다. 둘러보려면 **Continue to DataCat**을, 돌아가려면 **Don't continue to DataCat**을 클릭하세요.

성인 캐릭터는 썸네일 모서리에 작고 빨간 **NSFW** 배지가 붙습니다.

## Pygmalion 로그인하기

**Pygmalion**은 성인 콘텐츠를 로그인 뒤에 숨겨 둡니다. 일반 공개 캐릭터를 보는 데는 로그인이 필요 없습니다. 로그인은 성인 콘텐츠를 여는 용도뿐입니다.

로그인하려면 툴바의 **Log In**(로그인) 버튼을 클릭하세요. 로그인 창이 열립니다. 내 Pygmalion 계정에서 복사해 온 값을 붙여넣는 방식입니다. Marinara는 비밀번호를 묻지 않습니다.

**Pygmalion**은 창 제목이 **Pygmalion Authentication**이고 **Auth Token**(인증 토큰)을 입력받습니다.

1. pygmalion.chat에 접속해 계정에 로그인하세요.
2. 브라우저의 개발자 도구를 여세요. 대부분의 브라우저에서는 F12 키를 누르면 열립니다. 개발자 도구는 브라우저에 기본으로 들어 있는 고급 사용자용 패널입니다.
3. **Application** 탭을 열고 **Local Storage**로 이동하세요.
4. `authn`이라는 이름의 항목을 찾아 그 값을 복사하세요.
5. 복사한 값을 Marinara의 **Auth Token** 입력란에 붙여넣으세요.
6. **Save & Connect**(저장 & 접속)를 클릭하세요. NSFW 콘텐츠가 활성화되었다는 메시지가 표시됩니다.

창에는 이 단계를 다시 안내하는 도움말 영역과 pygmalion.chat을 여는 **Website** 링크가 있습니다. 로그아웃하려면 로그인 창을 다시 열고 **Log Out**(로그아웃)을 클릭하세요.

중요한 점이 있습니다. 이 로그인 정보는 서버 메모리에만 들어 있습니다. 파일로 저장되는 일은 없습니다. Marinara 서버를 다시 시작하면 로그아웃되므로 토큰을 다시 붙여넣어야 합니다. 이때 Marinara가 다시 로그인하라는 메시지를 표시합니다.

## 가져오기 전에 캐릭터 살펴보기

결과 카드를 클릭하면 상세 화면이 열립니다. 돌아가려면 **Back to results**(뒤로 돌아가기)를 클릭하세요.

상세 화면에는 캐릭터의 아바타, 이름, 제작자, 짧은 소개 문구, 그리고 최대 20개의 태그 칩이 표시됩니다. 캐릭터의 원본 페이지를 새 탭에서 여는 **View on** 링크도 있습니다.

그 아래에는 캐릭터의 상세 정보가 이어집니다. 소스가 정보를 제공할 때만 표시됩니다. 이 영역은 **Creator's Notes**, **Personality**, **Scenario**, **First Message**, **Alternate Greetings** 같은 제목으로 나뉩니다. 캐릭터가 로어북을 지니고 있으면 호박색 **Has embedded lorebook** 배지가 붙습니다.

소스에 따라 상세 정보를 늘 돌려주지는 않습니다. 아무것도 불러오지 못하면, 기본 정보만으로도 캐릭터를 가져올 수 있다는 안내가 표시됩니다.

## 캐릭터 가져오기 또는 다운로드하기

상세 화면에는 버튼이 두 개 있습니다. **Import**(가져오기)는 캐릭터를 Marinara 라이브러리에 추가합니다. **Download as PNG**(PNG 다운로드)는 라이브러리에 추가하지 않고 기기에 파일로만 저장합니다.

캐릭터 카드를 라이브러리로 가져오는 방법은 다음과 같습니다.

1. 캐릭터의 상세 화면을 여세요.
2. **Imported tags**(가져온 태그) 옵션을 고르세요(아래 표 참고).
3. **Import**를 클릭하세요. 처리하는 동안 버튼에 **Importing...**이 표시됩니다.
4. 완료 메시지가 뜰 때까지 기다리세요. 캐릭터를 가져왔다는 메시지가 표시됩니다.
5. 채팅을 시작하기 전에 **Characters**(캐릭터) 패널을 열어 가져온 캐릭터를 확인하세요.

가져온 캐릭터는 다른 캐릭터와 똑같이 작동합니다. 실제로 대화하려면 작동하는 제공자 연결이 따로 필요합니다. [AI 제공자에 연결하기](../connections/connecting-to-a-provider.md)를 참고하세요.

### 함께 가져올 태그

아바타 옆의 **Imported tags** 패널에서 캐릭터와 함께 딸려 올 태그를 정합니다. 기본값은 **All tags**입니다.

| 옵션          | 동작                                         |
| ------------- | -------------------------------------------- |
| All tags      | 소스의 태그를 그대로 가져옵니다.             |
| No tags       | 소스의 태그를 가져오지 않습니다.             |
| Existing only | Marinara에서 이미 쓰고 있는 태그만 남깁니다. |

### 내장 로어북 확인 창

캐릭터가 로어북을 내장하고 있으면 가져올 때 브라우저의 작은 확인 창이 뜹니다. 그 로어북을 별도의 독립 Marinara 로어북으로도 저장할지 묻는 창입니다. **OK**를 클릭하면 캐릭터에 붙은 사본과 함께 별도 로어북이 만들어집니다. **Cancel**을 클릭하면 로어북은 캐릭터에만 붙은 채로 남습니다.

### PNG 파일로 다운로드하기

**Download as PNG**를 클릭하면 캐릭터가 표준 PNG 캐릭터 카드 파일로 저장됩니다. 처리하는 동안 버튼에 **Building PNG...**가 표시됩니다. 모든 소스에서 쓸 수 있습니다. 저장된 파일은 캐릭터 이름을 따서 `Some_Character.png` 같은 이름이 됩니다. 이 파일은 다른 사람과 공유하거나 나중에 다른 앱으로 가져올 수 있습니다.

JSON과 PNG는 같은 캐릭터 데이터를 담는 대표적인 두 가지 형식입니다. JSON은 일반 텍스트 형식입니다. PNG 카드는 캐릭터 데이터를 안에 품고 있는 이미지 파일입니다. 둘 다 캐릭터 전체를 담습니다.

## 가져온 캐릭터 목록

오른쪽 사이드바의 **Card Browser** 패널에는 **Card Browser**로 가져온 캐릭터만 따로 모아 둡니다. 직접 만들었거나 다른 방법으로 가져온 캐릭터는 여기에 나오지 않습니다. 물론 전부 **Characters** 라이브러리 본체에는 그대로 있습니다.

- **Download Cards** 버튼을 누르면 **Card Browser** 전체 화면이 열립니다.
- **Search imported...** 입력란으로 이 목록을 걸러 볼 수 있습니다.
- 정렬 드롭다운에는 **A-Z**, **Z-A**, **Newest**, **Oldest**가 있습니다.
- 목록의 행을 오른쪽 클릭하거나 행에 있는 버튼을 쓰면 **Quick Start Roleplay**와 **Quick Start Conversation**이 나옵니다. 해당 캐릭터와의 새 채팅이 바로 열립니다. 이 자리에서 캐릭터를 목록에서 삭제할 수도 있습니다.

## 문제 해결

**JannyAI 검색이나 상세 정보가 Cloudflare 오류로 실패합니다.** 자동화된 요청을 막는 사이트가 있습니다. 같은 브라우저에서 jannyai.com에 한 번 접속해 확인 절차를 통과한 다음, Marinara로 돌아와 다시 검색하세요.

**Pygmalion 로그인이 갑자기 풀렸습니다.** Marinara 서버를 다시 시작하면 이 로그인 정보가 지워집니다. **Log In** 창을 다시 열고 토큰을 한 번 더 붙여넣으세요.

**CharacterTavern에는 안내만 표시됩니다.** 정상입니다. CharacterTavern 카드를 파일로 가져오는 방법은 [CharacterTavern](#charactertavern)을 참고하세요.

**검색이 실패하거나 소스가 아예 작동하지 않습니다.** 공개 사이트는 언제든 페이지 구조를 바꾸거나 접근을 막을 수 있습니다. 시간을 두고 다시 시도해 보세요. 특정 소스에서 계속 실패한다면 그 사이트에서 캐릭터를 직접 열어 카드를 다운로드한 뒤, 일반적인 가져오기 방법으로 넣으세요. [캐릭터 카드 가져오기와 내보내기](import-export.md)를 참고하세요.
