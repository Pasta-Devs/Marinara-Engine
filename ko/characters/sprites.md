# 캐릭터 스프라이트(표정과 전신)

이 가이드에서는 스프라이트라고 부르는 캐릭터 그림을 추가하는 방법과 AI로 생성하는 방법을 설명합니다. 배경을 정리하는 방법, 스프라이트가 화면에 어떻게 나타날지 조절하는 방법도 함께 다룹니다. 스프라이트는 Roleplay Mode와 Game Mode에서 동작합니다.

## 스프라이트란

스프라이트는 서 있는 자세의 캐릭터 그림입니다. Marinara Engine이 채팅 장면 위에 띄워서 보여 주는 캐릭터 그림을 말합니다. Marinara는 두 가지 스프라이트를 사용합니다.

- **Facial Expressions**(표정): 기쁨, 슬픔, 분노처럼 감정마다 다른 얼굴 그림입니다.
- **Full-body**(전신): 대기, 걷기, 전투 자세처럼 포즈마다 다른 전신 그림입니다.

스프라이트는 **Roleplay Mode**와 **Game Mode**에서만 화면에 나타납니다. Conversation 모드의 일반 채팅에는 스프라이트 그림이 표시되지 않습니다. 업로드 자체는 어느 모드에서든 할 수 있습니다. 스프라이트는 캐릭터에 딸려 있어서 어떤 채팅에서 쓰든 그대로 유지되기 때문입니다.

스프라이트는 캐릭터마다 따로 추가합니다. 채팅에서 나를 대신하는 캐릭터인 페르소나에도 추가할 수 있습니다. 페르소나 편집기에도 아래에서 설명하는 **Sprites**(스프라이트) 탭이 똑같이 있습니다.

## Sprites 탭 위치

스프라이트 관리는 캐릭터 편집기(또는 페르소나 편집기) 안에서 합니다.

1. 편집할 캐릭터를 여세요.
2. 편집기에서 **Sprites** 탭을 클릭하세요.
3. 탭 위쪽에서 **Facial Expressions**, **Full-body**, **Clips**(클립) 중 하나를 고르세요.

이 가이드에서 설명하는 것은 **Facial Expressions**와 **Full-body**입니다. **Clips**는 음성 통화와 영상 통화를 위한 별개의 기능입니다. 클립에 대해서는 [Conversation 음성 통화와 영상 통화](../conversation/calls.md)를 참고하세요.

## 직접 만든 스프라이트 업로드하기

이미 가지고 있는 그림을 그대로 올릴 수 있습니다. Marinara는 흔히 쓰는 이미지 파일을 지원합니다. 배경이 투명한 PNG 파일이 가장 좋습니다. 캐릭터 주변의 빈 영역이 비치면서 장면 위에 자연스럽게 얹히기 때문입니다.

### 스프라이트 한 장 올리기

1. **Sprites** 탭을 열고 **Facial Expressions** 또는 **Full-body**를 고르세요.
2. **Add Sprite**(스프라이트 추가) 상자의 입력란에 이름을 입력하세요. 표정에는 "Expression name (e.g. happy, sad, angry)", 포즈에는 "Pose name (e.g. idle, walk, battle_stance)"라는 안내 문구가 표시됩니다.
3. **Upload**(업로드)를 클릭하고 이미지 파일 하나를 고르세요.

새 스프라이트가 입력한 이름과 함께 아래 격자에 나타납니다.

### 자주 쓰는 표정 빠르게 추가하기

**Facial Expressions**에서는 **Quick add**(빠른 추가) 줄에 아직 쓰지 않은 표정 이름이 happy, angry처럼 추천으로 표시됩니다. 하나를 클릭하면 그 이름이 미리 채워진 상태로 파일 선택 창이 열립니다. 이름을 직접 입력하지 않아도 됩니다.

### 폴더째 한 번에 올리기

폴더에 스프라이트가 많이 들어 있다면 한 번에 전부 가져올 수 있습니다.

1. 이미지 파일 이름을 표정이나 포즈 이름으로 지으세요. 예를 들어 파일 이름을 `admiration.png`로 두면 admiration이라는 표정이 만들어집니다.
2. **Add Sprite** 상자에서 **Upload Folder**(폴더 업로드)를 클릭하세요.
3. 이미지가 들어 있는 폴더를 고르세요.

확장자를 뺀 파일 이름이 그대로 스프라이트 이름이 됩니다. 진행 중에는 "Uploading X/Y sprites"라는 진행 표시가 나타납니다.

같은 표정의 여러 변형을 만들려면 밑줄 앞부분을 같은 이름으로 맞추세요. 예를 들어 `happy_01.png`와 `happy_blush.png`는 둘 다 happy의 변형으로 처리됩니다.

### 스프라이트 관리하기

격자에 있는 스프라이트 카드 위에 마우스를 올리면 다음 기능이 나타납니다.

- **Frame**(프레임): 캐릭터가 원하는 위치에 오도록 이미지를 잘라 냅니다.
- **Download**(다운로드): 스프라이트 파일을 컴퓨터에 저장합니다.
- **Replace**(교체): 같은 이름 위에 새 이미지를 올립니다.
- **Delete**(삭제): 해당 스프라이트를 지웁니다.

삭제할 때는 "Delete sprite for"와 이름이 함께 표시되는 확인 메시지가 나타납니다. 스프라이트가 두 개 이상 표시되어 있으면 같은 창에서 **Delete All Expressions**나 **Delete All Full-Body**도 선택할 수 있습니다.

## AI로 스프라이트 생성하기

이미지 연결을 설정해 두었다면 Marinara가 스프라이트를 대신 그려 줍니다. 연결은 Marinara와 AI 서비스를 이어 주는 정보입니다. 스프라이트를 생성하려면 이미지 연결이 필요하고, 움직이는 스프라이트를 만들려면 동영상 연결이 필요합니다. 설정 방법은 [AI 제공자에 연결하기](../connections/connecting-to-a-provider.md)를 참고하세요.

먼저 **Add Sprite** 상자에서 **Generate Sprite**(스프라이트 생성)를 클릭하세요. **Generate Sprites** 창이 열립니다. 창 위쪽에서 **Expressions (Portrait)**(표정(인물)) 또는 **Full-body** 중 어느 쪽을 만들지 고릅니다.

창의 항목을 채우세요.

1. 드롭다운에서 **Image Generation Connection**(이미지 생성 연결)을 고르세요.
2. 특정한 그림체에 맞추고 싶다면 **Reference Images**(참조 이미지)를 최대 4장까지 추가하세요. 체크박스를 켜서 현재 아바타를 참조로 쓸 수도 있습니다.
3. 캐릭터의 생김새를 **Appearance Description**(외형 설명)에 적으세요. 이 항목은 필수입니다.
4. 필요하면 **Transparent sprite background**(투명 스프라이트 배경)를 켜세요. Marinara는 먼저 PNG 자체의 투명도를 요청합니다. 제공자가 알파 채널을 돌려주지 못하면 **Appearance Description**에 적힌 색과 가장 적게 겹치는 진한 초록, 마젠타, 청록 중 하나를 배경색으로 골라 쓴 뒤 그 색을 자동으로 제거합니다.
5. **Expression Count**(표정 수, 전신은 **Pose Count**(포즈 수))로 몇 장을 만들지 정한 다음, 어떤 표정이나 포즈를 채울지 고르세요.
6. **Generate**(생성) 버튼을 클릭하세요.

이미지가 도착하면 결과를 검토합니다. 각 이미지를 켜거나 끄고, 이름을 바꾸고, 저장하기 전에 잘라 낼 수 있습니다. 마음에 들면 선택한 이미지를 캐릭터의 스프라이트 목록에 저장하세요.

**Full-body**에서는 캐릭터에 이미 얼굴 표정이 있다면 **Match existing expression sprites**(기존 얼굴 표정 스프라이트에 맞추기)를 체크할 수 있습니다. 이미 있는 표정 이름마다 그에 맞는 전신 포즈가 만들어집니다.

AI 생성에서 알아 둘 점이 두 가지 있습니다.

- 앱에 표시되는 안내와 달리 생성에는 몇 분이 걸리기도 합니다. 느린 AI 서비스일수록 더 걸립니다. 처음부터 다시 시작하지 말고 기다리세요.
- 일부 Android 설치본을 비롯한 몇몇 기기에서는 AI 스프라이트 생성과 배경 정리를 쓸 수 없습니다. 이때는 버튼이 비활성화되고 Marinara가 그 이유를 화면에 표시합니다.

### 움직이는 얼굴 스프라이트

**Expressions (Portrait)**에는 **Generate animated portraits**(애니메이션 초상화 생성)라는 체크박스가 있습니다. 이 항목을 켜면 정지 이미지 대신 짧은 동영상 클립을 만든 다음, 각 클립을 반복 재생되는 GIF 스프라이트로 바꿉니다. GIF는 짧은 애니메이션이 재생되는 이미지 파일입니다. 움직이는 얼굴 스프라이트는 이미지 연결이 아니라 동영상 연결을 사용합니다.

## 스프라이트 배경 정리하기

스프라이트는 캐릭터만 보이고 배경이 비칠 때 가장 보기 좋습니다. 생성된 정지 스프라이트는 제공자가 지원하는 경우 PNG 자체의 투명도를 사용합니다. 그렇지 않을 때는 Marinara가 단색 배경을 가장자리까지 부드럽게 제거하고, 머리카락과 옷감처럼 반투명한 픽셀에 남은 배경색까지 씻어 냅니다. 예전 방식인 흰색 배경 스프라이트도 그대로 지원합니다.

### 한 장씩 직접 정리하기

격자에서 스프라이트 그림을 클릭하면 정리 편집기가 열립니다. 여기에서 배경을 지우고, 지운 부분을 다시 칠하고, 어두운 배경과 밝은 배경, 체크무늬 배경에 얹어 결과를 확인할 수 있습니다. 실행 취소와 원본 되돌리기도 되고, 끝나면 변경 내용을 적용합니다.

### 여러 장 한꺼번에 정리하기

**Clean Backgrounds**(배경 정리) 버튼은 지금 격자에 표시된 모든 스프라이트에서 배경을 제거합니다.

1. **Cleanup strength**(정리 강도) 슬라이더를 설정하세요. Soft에서 Aggressive까지 0에서 100까지이며 기본값은 35입니다. 값이 클수록 배경을 더 많이 지우지만 캐릭터까지 깎일 수 있습니다.
2. **Clean Backgrounds**를 클릭하고 확인하세요.

일괄 정리가 끝나면 Marinara가 안전용 사본을 남겨 둡니다. "Last cleanup has a restore point"라는 문구와 **Undo Cleanup**(정리 취소) 버튼이 표시됩니다. 이 버튼을 클릭하면 영향을 받은 스프라이트가 전부 원래대로 돌아갑니다.

배경 정리는 PNG, JPG, JPEG, WEBP, AVIF 이미지에서 동작합니다. GIF와 SVG 파일에서는 동작하지 않습니다.

자동 정리는 이미지를 먼저 살펴본 뒤 처리 방식을 고릅니다. 단색 배경과 예전 방식의 흰색 배경은 내장된 빠른 방식이 먼저 처리합니다. 가장자리가 실제로는 균일하지 않다면, 선택 사항인 AI 배경 제거 기능이 설치되어 있을 때 Marinara가 그것을 대신 사용할 수 있습니다. 배경이 복잡한 장면이나 캐릭터 색이 배경과 거의 같은 그림에는 직접 정리 편집기를 쓰는 편이 가장 안전합니다.

## 스프라이트 내보내기

캐릭터의 스프라이트를 zip 파일로 컴퓨터에 저장할 수 있습니다. zip은 여러 파일을 하나로 묶어 담는 파일 형식입니다.

1. **Sprites** 탭을 여세요.
2. **Add Sprite** 상자에서 **Export**(내보내기)를 클릭하세요.
3. 지금 선택한 카테고리만 내보내려면 **Expressions only** 또는 **Full-body only**를, 전부 내보내려면 **All sprites**를 고르세요.

캐릭터 이름이 붙은 폴더 하나가 다운로드되고, 그 안에 스프라이트 이미지 파일이 들어 있습니다.

## 채팅에서 스프라이트가 표시되는 방식

스프라이트를 올리는 것은 절반에 불과합니다. 채팅 중에 언제 어떻게 나타날지도 정해야 합니다. 이 설정은 캐릭터 편집기가 아니라 채팅 설정에서 합니다.

### Roleplay Mode

**Roleplay Mode**에서는 선택 사항인 **Expression Engine**(표정 엔진) 에이전트가 스프라이트 표시를 담당합니다. **Agents → Agent Organizer (에이전트 관리)**에서 다운로드한 다음 채팅에 추가하세요. 이 에이전트는 메시지마다 분위기를 읽고 어울리는 표정 스프라이트를 고릅니다. 자세한 내용은 [다운로드 가능한 에이전트 레퍼런스](../agents/built-in-agents.md)를 확인하세요.

Roleplay 채팅에서 스프라이트가 나타나려면 다음 조건이 모두 충족되어야 합니다.

- 해당 채팅에서 **Expression Engine** 에이전트가 활성화되어 있어야 합니다.
- 캐릭터 하나 이상 또는 활성 페르소나가 스프라이트 소유자로 지정되어 있어야 합니다.
- 스프라이트 소스가 하나 이상 켜져 있어야 합니다.

채팅 설정을 열고 **Expression Engine** 에이전트 카드를 찾으세요. 여기에서 스프라이트 표시 방식을 조절합니다.

- **Sprite Source**(스프라이트 소스): **Expressions**, **Full-body** 또는 둘 다를 고릅니다. 기본값은 둘 다 켜짐이며, 최소 하나는 켜 두어야 합니다.
- **Expression Avatars**(감정 아바타): 화면에 겹쳐 띄우는 대신, 메시지 옆의 작은 아바타를 어울리는 표정 스프라이트로 바꿉니다. 기본값은 꺼짐이며 Roleplay Mode 전용입니다.

### Game Mode

**Game Mode**에서는 말하거나 싸우는 캐릭터의 전신 스프라이트가 자동으로 표시됩니다. Expression Engine 에이전트는 필요하지 않습니다. 해당 캐릭터의 전신 스프라이트만 올려 두면 됩니다. Game Mode 전반의 설정은 [Game Mode: 시작하기](../game/getting-started.md)를 참고하세요.

### 스프라이트 이동과 크기 조절(Arrange 모드)

스프라이트 소유자를 지정하면 **Expression Engine** 에이전트 카드에 **Sprite Layout**(스프라이트 배치) 항목이 나타납니다.

- **Arrange**(배치)를 클릭하면 끌기 모드로 들어가고, 각 스프라이트를 원하는 위치로 끌어다 놓을 수 있습니다. 끝나면 **Done**(완료)을 클릭하세요.
- **Reset**(초기화)은 직접 지정한 위치를 지우고 자동 배치로 되돌립니다.
- **Default Side**(기본 위치)는 새 스프라이트를 **Left**와 **Right** 중 어느 쪽에 붙일지 정합니다. 기본값은 Left입니다. 방향을 바꾸면 현재 배치가 좌우로 뒤집힙니다.
- 슬라이더 4개로 크기와 불투명도를 조절합니다. **Expression Size**(표정 크기)와 **Full-body Size**(전신 크기)는 5%에서 200%까지, **Expression Opacity**(표정 불투명도)와 **Full-body Opacity**(전신 불투명도)는 15%에서 100%까지이며 모두 100%에서 시작합니다.

## 영상 통화 클립

**Sprites** 탭의 **Clips**는 다른 기능입니다. Conversation 모드의 음성 통화나 영상 통화에서 캐릭터의 카메라 화면 역할을 하는 짧은 반복 동영상을 만듭니다. 통화 기능에 속하므로 별도 문서에서 설명합니다. [Conversation 음성 통화와 영상 통화](../conversation/calls.md)를 참고하세요.
