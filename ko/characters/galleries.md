# 캐릭터와 페르소나 갤러리

이 가이드에서는 캐릭터 편집기와 페르소나 편집기 안에 있는 **Gallery**(갤러리) 탭을 설명합니다. 캐릭터나 페르소나에 계속 붙어 있는 이미지와 동영상을 추가하는 방법을 다룹니다. 갤러리 이미지를 사용자 지정 이모지나 스티커로 지정하는 방법도 함께 살펴봅니다.

## Gallery 탭

모든 캐릭터와 모든 페르소나에는 각자의 **Gallery** 탭이 있습니다. **Character Editor**(캐릭터 편집기)에서 캐릭터를 열거나 **Persona Editor**(페르소나 편집기)에서 페르소나를 연 다음, 카메라 아이콘이 있는 **Gallery** 탭을 클릭하세요.

Gallery 안에는 하위 탭이 두 개 있습니다.

- **Images**(이미지): 이 캐릭터나 페르소나용으로 업로드한 그림입니다.
- **Videos**(동영상): 업로드한 동영상과 함께, 이 캐릭터와 연결된 장면 동영상 및 영상 통화 클립이 들어갑니다.

캐릭터의 갤러리는 **Character Gallery**(캐릭터 갤러리), 페르소나의 갤러리는 **Persona Gallery**(페르소나 갤러리)라는 이름으로 표시됩니다. 동작 방식은 둘 다 같습니다.

## 채팅 갤러리와 다른 점

Gallery 이미지는 캐릭터나 페르소나에 속하며, 특정 채팅에 속하지 않습니다. 채팅을 삭제해도 이 갤러리 이미지는 그대로 남습니다. 설정 자료용 시트, 의상 변형, 가져온 캐릭터 이미지 묶음은 Gallery에 넣으세요.

채팅에도 자체 갤러리가 있지만 성격이 다릅니다. 그쪽에는 해당 채팅에만 해당하는 삽화와 메시지에 생성된 첨부 이미지가 들어갑니다. 잠깐 쓰고 마는 장면 그림은 채팅 갤러리에, 오래 두고 쓸 캐릭터 그림은 캐릭터나 페르소나의 Gallery에 보관하세요.

## 이미지 추가하기

1. 캐릭터 편집기나 페르소나 편집기를 여세요.
2. **Gallery** 탭을 클릭하세요.
3. **Images** 하위 탭이 선택되어 있는지 확인하세요.
4. 이미지 파일을 **Upload Character Images**(캐릭터 이미지 업로드) 영역으로 끌어다 놓거나, 그 영역을 클릭해 파일을 고르세요. 페르소나에서는 이 영역의 이름이 **Upload Persona Images**입니다.
5. 업로드가 끝날 때까지 기다리세요. 새로 추가된 갤러리 이미지가 아래 격자에 나타납니다.

JPG, PNG, GIF, WebP, AVIF처럼 흔히 쓰는 이미지 형식을 업로드할 수 있습니다. 이미지를 클릭하면 더 크게 볼 수 있습니다. 각 이미지 타일에는 다운로드 버튼과 삭제 버튼도 있습니다.

## 동영상 추가하기

1. **Gallery** 탭을 클릭하세요.
2. **Videos** 하위 탭을 선택하세요.
3. 동영상 파일을 **Upload Character Videos**(캐릭터 동영상 업로드) 영역으로 끌어다 놓거나, 그 영역을 클릭해 파일을 고르세요. 페르소나에서는 이 영역의 이름이 **Upload Persona Videos**입니다.
4. 업로드가 끝날 때까지 기다리세요.

지원하는 동영상 형식은 MP4, WebM, MOV입니다. **Videos** 하위 탭에는 이 캐릭터와의 채팅에서 생성한 장면 동영상과 영상 통화 클립도 함께 표시됩니다. 최신 항목이 위로 오도록 정렬됩니다.

## 갤러리 이미지를 사용자 지정 이모지나 스티커로 지정하기

갤러리 이미지는 **Conversation Mode**(대화 모드, 메신저 형태의 채팅 모드)에서 쓸 사용자 지정 이모지나 스티커로 바꿀 수 있습니다. 사용자 지정 이모지는 `:name:`으로 적는 작은 인라인 이미지이고, 스티커는 `sticker:name:`으로 적는 큼직한 블록 이미지입니다. 둘 다 Conversation Mode 채팅에서만 동작합니다.

이미지를 지정하는 방법은 다음과 같습니다.

1. **Gallery** 탭을 열고 **Images** 하위 탭을 선택하세요.
2. 원하는 이미지를 찾으세요. 왼쪽 위 모서리에 작은 태그 버튼이 있고, 툴팁으로 **Tag as emoji or sticker**(이모지 또는 스티커로 태그 지정)가 표시됩니다.
3. 태그 버튼을 클릭하세요. **Make emoji**와 **Make sticker**가 있는 메뉴가 열립니다.
4. **Make emoji** 또는 **Make sticker**를 클릭하세요.
5. **Custom Emoji** 또는 **Custom Sticker** 창에서 이름을 입력하고 확인하세요.

이름에는 소문자, 숫자, 밑줄만 쓸 수 있고 최대 32자입니다. 나머지 문자는 Marinara Engine이 알아서 변환합니다. 예를 들어 "Big Grin"은 `big_grin`이 됩니다.

크기 제한은 갤러리가 아니라 어떤 종류로 지정하는지에 따라 정해집니다. 이모지 이미지는 256 x 256 픽셀을 넘으면 안 되고, 스티커 이미지는 512 x 512 픽셀을 넘으면 안 됩니다. 이미지가 너무 크면 오류 메시지가 나타나고 지정이 적용되지 않습니다.

### 지정한 이미지 관리하기

이미지를 한 번 지정하고 나면 이미지 위의 버튼에 정해 둔 이름이 표시됩니다. 그 버튼을 클릭하면 추가 선택지가 있는 메뉴가 열립니다.

- **Rename**(이름 바꾸기): 이름을 바꿉니다.
- **Switch to sticker** 또는 **Switch to emoji**(이모지로 전환): 종류를 바꿉니다. 바꿀 때 새 종류의 크기 제한을 다시 확인합니다. 256 x 256 픽셀보다 큰 스티커 이미지는 이모지가 되기에는 너무 큽니다. 이 경우 오류가 나타나고 종류는 그대로 유지됩니다.
- **Remove emoji** 또는 **Remove sticker**(스티커 해제): 지정을 해제합니다. Gallery에서 이미지가 삭제되지는 않습니다.

### 이렇게 지정한 이모지와 스티커가 통하는 범위

갤러리에서 지정한 이모지나 스티커는 그 캐릭터 또는 페르소나 하나에만 적용됩니다. 해당 캐릭터나 페르소나가 참여한 Conversation Mode 채팅에서만 동작합니다. 메시지 입력 막대에 있는 전체 공용 이모지 및 스티커 목록과는 별개입니다.

갤러리 이름이 전체 공용 목록의 이름과 겹치면 그 채팅에서는 갤러리 쪽이 우선합니다. 이름이 겹치는지는 따로 검사하지 않습니다. 예상 밖의 결과를 피하려면 이미지마다 겹치지 않는 이름을 붙이세요.

## 갤러리 이미지를 메시지와 인사말에서 다시 사용하기

캐릭터 갤러리의 이미지는 인사말, 예시 메시지, 캐릭터가 보내는 메시지 등 채팅 본문 안에 표시할 수 있습니다. 갤러리 이미지 위에 마우스를 올리고 **Copy image reference**(링크 아이콘)를 클릭하면 캐릭터가 말하는 곳 어디든 붙여 넣을 수 있는 짧은 Markdown이 복사됩니다.

```text
![sunset selfie](card://self/gallery/k3m2xq7.png)
```

규칙은 하나입니다. **`self`는 해당 메시지를 말하는 캐릭터를 뜻합니다.** 메시지를 렌더링할 때 Marinara가 `self`를 그 캐릭터로 바꾸고 갤러리 이미지를 표시합니다.

캐릭터 카드의 **First Message**, **Alternate Greetings**, **Example Dialogue**, Roleplay와 Conversation에서 캐릭터가 보내는 모든 메시지, 그룹 채팅에서 작동합니다. 여러 화자가 포함된 답변에서는 `self`를 화자별로 해석합니다. 화자의 갤러리에 파일이 없으면 다른 채팅 캐릭터의 갤러리에서 찾습니다.

직접 작성한 메시지에는 말하는 캐릭터가 없으므로 작동하지 않으며, 시스템 메시지는 Markdown 이미지를 렌더링하지 않습니다. 직접 캐릭터 이미지를 게시하려면 완전한 `card://characters/<id>/...` 형식을 쓰는 채팅 에셋 브라우저를 사용하세요. 페르소나 갤러리는 `card://personas/<id>/gallery/<file>` 형식을 사용합니다.

두 캐릭터가 같은 파일 이름의 이미지를 갖고 있으면 화자의 이미지가 항상 우선합니다. 화자에게 파일이 없을 때는 채팅 캐릭터 순서에서 처음 일치하는 파일을 사용합니다. 특정 버전이 필요하면 파일 이름을 다르게 지정하세요.

### 완전한 링크 대신 `self`를 쓰는 이유

완전한 링크에는 캐릭터의 내부 id(`card://characters/<id>/gallery/<file>`)가 포함되며, 캐릭터를 가져올 때마다 id가 새로 생성되므로 공유하면 링크가 깨집니다. `self` 형식에는 id나 서버 주소가 없습니다. **네이티브 JSON 내보내기와 가져오기** 후에도 작동하며, 갤러리 이미지는 파일 이름을 유지한 채 내보내기에 포함됩니다.

한 가지 제한은 **PNG 카드 내보내기에 갤러리가 포함되지 않는다는 점**입니다. 갤러리 참조를 쓰는 캐릭터는 네이티브 `.json` 내보내기로 공유하세요.
