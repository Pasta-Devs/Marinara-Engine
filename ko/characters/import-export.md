# 캐릭터 카드 가져오기와 내보내기

이 가이드에서는 캐릭터 카드를 Marinara Engine으로 가져오는 방법과, 직접 만든 캐릭터를 다시 내보내는 방법을 설명합니다. Marinara가 받아들이는 파일 형식, 가져오기 창에서 고르는 선택지, 내보내기 형식 3가지를 다룹니다.

캐릭터 카드는 캐릭터 한 명의 정보를 담은 파일 하나입니다. 이름, 설명, 성격, 인사말이 들어가고 아바타 이미지가 함께 담기는 경우도 많습니다. 카드가 있으면 Marinara와 다른 롤플레이 앱 사이에서 캐릭터를 옮길 수 있습니다.

## 가져올 수 있는 형식

**Import Character**(캐릭터 가져오기) 창은 파일 형식 4가지를 받습니다. 여러 파일을 한 번에 끌어다 놓을 수 있고, 형식이 서로 달라도 됩니다.

| 파일 형식 | 설명 |
| --- | --- |
| **.json** | 텍스트 형태의 일반 캐릭터 카드입니다(Chara Card V2). |
| **.png** | 카드 데이터가 그림 안에 숨겨진 캐릭터 카드 이미지입니다. |
| **.charx** | RisuAI가 쓰는 zip 기반 형식인 Character Card V3 패키지(CharX)입니다. |
| **.marinara** | Marinara 자체 내보내기 파일입니다(`.marinara.json`으로 보이기도 합니다). |

**.marinara** 파일은 Marinara 고유 형식이라 정보를 가장 많이 그대로 담습니다. 나머지 3가지는 SillyTavern, Chub, Risu 같은 도구에서 나온 형식입니다.

## 캐릭터 가져오기

카드 하나 또는 여러 개를 라이브러리에 추가하는 절차입니다.

1. **Characters**(캐릭터) 패널을 여세요.
2. 툴바에서 **Import** 버튼을 클릭하세요. 다운로드 화살표가 그려진 아이콘 버튼입니다. **Import Character** 창이 열립니다.
3. 창 위로 파일을 끌어다 놓거나, 창을 클릭해서 파일을 찾으세요. "Drop one or more files here or click to browse"라는 문구가 보입니다.
4. 가져오기 옵션 2가지를 설정하세요(아래에서 설명합니다). 이 설정은 이번에 가져오는 파일 전체에 적용됩니다.
5. 결과 목록이 나올 때까지 기다리세요. 파일마다 초록색 체크와 함께 "Imported"와 이름이 표시되거나, 빨간색 표시와 함께 오류가 나타납니다.

### 유지할 태그 고르기

**Imported card tags**(가져온 카드 태그) 옵션은 가져오는 카드에 달린 태그를 어떻게 처리할지 정합니다. 태그 가져오기 방식이라고 부릅니다. 선택지는 3가지입니다.

- **All tags**: 원본 카드의 태그를 전부 유지합니다. 기본값입니다.
- **No tags**: 원본 태그를 가져오지 않습니다.
- **Existing only**: 라이브러리에 이미 있는 태그만 유지합니다.

### 정규식 스크립트의 적용 범위 고르기

정규식 스크립트가 함께 들어 있는 카드도 있습니다. 텍스트를 찾아 바꾸는 작은 규칙입니다. 적용 범위는 **Imported regex scripts**(가져온 정규식 스크립트) 옵션으로 정합니다.

- **Character only**: 이 캐릭터에서만 스크립트가 작동합니다. 기본값입니다.
- **Global**: 스크립트를 **Presets**(프리셋)의 **Regexes**(정규식) 섹션에 추가해 모든 채팅에서 작동하게 합니다.

규칙을 모든 채팅에 적용할 생각이 아니라면 **Character only**를 고르세요.

### 로어북이 들어 있는 카드

로어북은 AI가 채팅 도중 찾아볼 수 있도록 세계 설정을 모아 둔 것입니다. 가져오려는 카드에 로어북이 내장되어 있으면 가져오기가 잠시 멈추고 **Embedded lorebook found**(내장 로어북을 찾음) 패널이 나타납니다. 파일 목록과 함께 항목이 몇 개인지 보여 줍니다. 이번에 가져오는 파일 전체에 적용할 선택지 하나를 고르세요.

- **Import Lorebook**(로어북 가져오기): 캐릭터에 연결된 독립 Marinara 로어북도 함께 만듭니다.
- **No Import**(가져오지 않음): 로어북을 카드 안에만 둡니다.

### 카드 여러 개 한꺼번에 가져오기

같은 **Import Character** 창에서 일괄 가져오기도 할 수 있습니다. 파일을 여러 개 선택하면 Marinara가 하나씩 차례대로 가져옵니다. 결과 목록에는 파일마다 한 줄씩 표시되므로 어떤 카드가 성공하고 어떤 카드가 실패했는지 확인할 수 있습니다.

## 캐릭터 내보내기

편집기에서 캐릭터를 연 다음 위쪽 툴바의 **Export character**(캐릭터 내보내기)를 클릭하세요. **Export Character** 창에서 형식 3가지를 고를 수 있습니다.

| 형식 | 저장되는 내용 | 적합한 상황 |
| --- | --- | --- |
| **Marinara Native** | Marinara 메타데이터, 스프라이트, 갤러리 이미지, 연결된 로어북까지 유지하는 `.marinara.json` 파일입니다. | Marinara 설치 환경 사이에서 캐릭터를 정보 손실 없이 옮길 때 |
| **Compatible JSON** | Marinara 전용 정보를 뺀 순수 Chara Card V2 JSON입니다. | JSON 카드를 읽는 다른 앱에 공유할 때 |
| **Compatible PNG Card** | 카드 데이터를 그림 안에 담은 Chara Card V2 이미지입니다. | SillyTavern, Chub, Risu처럼 PNG 카드를 쓰는 앱과 사이트 |

전부 그대로 유지하고 싶다면 **Marinara Native**를 고르세요. 파일을 다른 도구로 넘길 때는 **Compatible** 형식 중 하나를 고르세요. 호환 형식 2가지는 스프라이트나 갤러리 이미지처럼 Marinara에만 있는 부가 정보를 버립니다. 비어 있지 않은 **Backstory**(배경 이야기)와 **Appearance**(외모) 필드는 표준 Description에 덧붙여 다른 V2 지원 도구에서도 캐릭터 정보를 유지합니다. 다시 가져올 때 중복되지 않도록 이 필드들은 내보내는 확장 정보에서 제거합니다. 저장된 카드는 바뀌지 않으며 **Marinara Native**는 별도 필드를 유지합니다.

## 캐릭터 여러 개 한꺼번에 내보내기

여러 캐릭터를 zip 파일 하나로 묶어 내보낼 수 있습니다.

1. **Characters** 패널을 여세요.
2. 툴바에서 **Select**(선택) 버튼을 클릭해 선택 모드로 들어가세요. 체크 표시가 그려진 아이콘 버튼입니다.
3. 내보낼 캐릭터에 체크하세요.
4. 아래쪽 작업 막대에서 **Export**(내보내기)를 클릭하세요. Marinara가 `marinara-characters.zip`이라는 이름의 zip 파일을 다운로드합니다.

zip 안에는 캐릭터마다 **Marinara Native** 파일이 하나씩 들어 있습니다. 일괄 내보내기에는 PNG나 호환 JSON 선택지가 없으므로, 그 형식이 필요하면 캐릭터를 하나씩 내보내세요.

## SillyTavern 폴더 통째로 가져오기

여기까지는 직접 고른 카드를 가져오는 방법입니다. SillyTavern 설치본 전체를 한 번에 옮기려면 폴더 일괄 가져오기 기능을 쓰세요. 캐릭터, 채팅, 프리셋, 로어북을 한꺼번에 가져옵니다. 이 기능은 **Settings**(설정)의 **Imports**(가져오기) 탭에 있습니다. 자세한 절차는 [SillyTavern에서 가져오기](../data/importing-from-sillytavern.md)를 참고하세요.
