# 이미지 스타일 프로필

스타일 프로필은 여러 번 재사용하는 "우리 집 화풍"으로, Marinara가 이미지 서비스에 보내기 전에 모든 이미지 프롬프트를 이 화풍에 맞춰 다듬습니다. 아바타, 초상화, 셀카, 배경, 일러스트, 스프라이트의 그림체를 하나로 맞추고 싶을 때 사용합니다. 이 가이드에서는 스타일 프로필을 고르고, 편집하고, 테스트하는 방법을 설명합니다.

## 스타일 프로필이란

아바타, 초상화, Conversation(대화) 셀카, 장면 배경, 일러스트, 스프라이트까지, 생성되는 이미지는 모두 텍스트 프롬프트에서 출발합니다. 스타일 프로필은 Marinara가 그 프롬프트에 덧붙이는 규칙을 저장해 둔 것입니다. 긍정 단어(넣고 싶은 것), 부정 단어(피하고 싶은 것), 선호하는 프롬프트 형식을 더할 수 있습니다. 프로필 하나를 앱 전체의 기본값으로 고릅니다. 특정 채팅이나 특정 이미지 모델에서만 다른 프로필로 덮어쓸 수도 있습니다.

편집기를 찾으려면 **Settings → Generations → Image Generation**(설정 → 생성 → 이미지 생성)을 열고 **Style Profiles**(스타일 프로필)까지 스크롤하세요.

## 기본 제공 프로필

Marinara에는 기본 제공 스타일 프로필이 10가지 있습니다. 기본값은 **Auto**입니다. 어느 프로필이든 편집할 수 있고, 기본 제공 프로필은 언제든 처음 값으로 되돌릴 수 있습니다.

아래에서 쓰는 용어는 다음과 같습니다.

- SDXL은 Stable Diffusion XL로, 내 컴퓨터에서 돌리거나 클라우드 서비스로 이용할 수 있는 널리 쓰이는 공개 이미지 모델입니다.
- 체크포인트는 학습을 마친 이미지 모델 파일 하나를 뜻합니다. 여기서 이름이 나오는 Illustrious, Pony, NovelAI가 그 예입니다.
- Danbooru는 대형 애니메이션 이미지 사이트입니다. "1girl, long hair, smile"처럼 쉼표로 구분한 이 사이트의 짧은 태그가 애니메이션 이미지 모델에 프롬프트를 넣는 일반적인 방식으로 자리 잡았습니다.

기본 제공 프로필은 다음과 같습니다.

- **Off**: 화풍을 전혀 덧붙이지 않습니다. 입력한 프롬프트가 거의 그대로 전달됩니다.
- **Auto**: 캐릭터, 게임, 장면, 선택한 이미지 모델을 보고 일관된 그림체를 추론합니다. 기본 프로필입니다.
- **Anime**: 깔끔한 캐릭터 그림을 위한 일반적인 애니메이션풍 태그입니다.
- **Danbooru / Illustrious**: Illustrious, Pony, NovelAI 같은 SDXL 애니메이션 체크포인트를 겨냥한 Danbooru 방식 태그입니다.
- **Realistic SDXL**: SDXL 모델용 자연어 사실주의 표현입니다.
- **Photorealistic**: 피부, 조명, 재질을 사실적으로 살리는 사진풍 프롬프트입니다.
- **Cinematic**: 키 비주얼에 어울리는 극적인 조명과 강한 구도입니다.
- **Digital Painting**: 콘셉트 아트 특유의 붓 터치와 설계된 조명입니다.
- **Painterly Fantasy**: 부드러운 회화풍 판타지 일러스트입니다.
- **Z-Image Turbo Narrative**: 평범한 문장을 잘 이해하는 Z-Image Turbo 계열 모델을 위한 짧은 산문입니다.

## 전체 화풍 바꾸기

기본 프로필은 채팅이나 이미지 모델이 따로 덮어쓰지 않는 한 모든 이미지에 적용됩니다.

1. **Settings → Generations → Image Generation → Style Profiles**를 여세요.
2. **Default style**(기본 스타일) 목록을 여세요.
3. 프로필을 고르세요.

선택은 곧바로 저장되며, 새 이미지에 적용됩니다.

## 프로필 복제하고 손보기

기본 제공 프로필을 그 자리에서 고칠 수도 있고, **Clone**(복제)으로 원본을 남겨 둔 채 나만의 프로필을 만들 수도 있습니다.

1. **Editing**(편집 중) 드롭다운을 열고 원하는 결과에 가장 가까운 프로필을 고르세요.
2. **Clone**을 클릭하세요. Marinara가 사본을 만들어 편집 대상으로 선택하고, 동시에 그 사본을 앱 전체의 기본 스타일로 지정합니다.
3. **Name**(이름) 입력란에 알아보기 쉬운 이름을 넣으세요.
4. **Prompt grammar**(프롬프트 문법)를 고르세요. 자세한 설명은 다음 절에 있습니다.
5. **Style text**(스타일 텍스트)에 원하는 그림체를 평범한 문장으로 적으세요. Illustrator, 셀카, Noodle처럼 AI가 이미지 프롬프트를 쓰는 경우에는 Style text를 그대로 복사하지 않고 그 내용을 따릅니다. 아바타 같은 다른 이미지에는 Style text가 적힌 그대로 추가될 수 있습니다.
6. **Positive tags**(긍정 프롬프트, 넣을 단어)와 **Negative tags**(네거티브 태그, 피할 단어)를 추가하세요.
7. **Per-image tags**(이미지별 태그) 섹션을 열어 이미지 종류별(아바타, 초상화, 셀카, 배경, 일러스트, 스프라이트) 추가 태그를 넣으세요.
8. 2단계에서 사본이 이미 앱 전체 기본값이 되었습니다. 그 역할을 다른 프로필에 돌려주려면 **Default style**을 열고 원하는 프로필을 고르세요.

프로필 관리에 쓰는 버튼이 두 개 있습니다.

- **Reset**(초기화)은 기본 제공 프로필에만 동작합니다. 해당 프로필을 처음 값으로 되돌립니다.
- **Delete**(삭제)는 직접 만든 프로필에만, 그리고 프로필이 두 개 이상 있을 때만 동작합니다.

## 프롬프트 문법 모드

**Prompt grammar**는 이미지 모델이 프롬프트를 어떤 형태로 읽기를 원하는지 Marinara에 알려 줍니다. 모델에 맞는 모드를 고르세요.

- **Hybrid**: 문장과 태그를 섞어 씁니다. 무난한 범용 선택지입니다.
- **Danbooru tags**: 쉼표로 구분한 짧은 Danbooru 방식 태그입니다. Illustrious, Pony, NovelAI 같은 애니메이션 SDXL 체크포인트에 가장 잘 맞습니다.
- **Tags**(태그): 쉼표로 구분한 짧은 키워드로, Danbooru 관례는 따르지 않습니다.
- **Natural language**: 평범한 문장입니다. DALL-E나 Z-Image Turbo 계열처럼 산문을 읽어 내는 모델에 가장 잘 맞습니다.

## Test bench 활용

Style Profiles 편집기 안의 **Test bench**(테스트 벤치)는 실제 이미지를 만들지 않고 Marinara가 보낼 내용을 그대로 미리 보여 줍니다.

1. **Image kind**(이미지 종류)를 고르세요. 예를 들어 초상화나 배경입니다.
2. **Sample input**(입력 예시)에 대략적인 프롬프트를 입력하세요.
3. **Final positive prompt**(최종 긍정 프롬프트)와 **Final negative prompt**(최종 부정 프롬프트) 상자를 읽어 보세요.

Test bench는 정리 결과도 짧게 알려 줍니다. 바꾼 것이 없으면 "No cleanup needed for this sample."이라고 표시하고, 프롬프트를 손봤으면 중복되거나 자리를 잘못 잡은 조각을 몇 개 정리했는지 알려 줍니다.

## Marinara가 프롬프트를 정리하는 방식

Marinara는 이미지 요청을 보내기 전에 활성 프로필로 프롬프트를 컴파일합니다. 컴파일러가 하는 일은 다음과 같습니다.

- 반복된 품질 태그처럼 거의 같은 태그를 제거합니다.
- "avoid text"나 "no watermark" 같은 단순한 부정 표현을 부정 프롬프트로 옮깁니다.
- 배경, 일러스트, 셀카 이미지에서는 입력한 표현을 그대로 살리지만, 초상화, 아바타, 스프라이트 이미지에서는 입력한 말을 알아볼 수 있는 짧은 시각 태그로 압축합니다.
- 만들려는 이미지 종류에 맞는 프로필의 이미지별 태그를 덧붙입니다.

## 적용 전후 예시

**Danbooru / Illustrious** 프로필을 고르고, **Image kind**를 초상화로 설정한 다음, **Sample input**에 이렇게 입력했다고 가정합니다.

```
masterpiece, masterpiece, red-haired knight, no watermark
```

그러면 Test bench의 **Final positive prompt**에 다음이 표시됩니다.

```
detailed eyes, solo, upper body, portrait, looking at viewer, anime screencap, masterpiece, best quality, absurdres
```

세 가지 일이 일어났습니다.

- "no watermark"가 긍정 프롬프트에서 빠져 **Final negative prompt**로 옮겨졌습니다. 정리 안내문은 이 변경도 정리 횟수에 포함합니다.
- 프로필이 자체 화풍 태그, 초상화용 이미지별 태그, 품질 태그를 덧붙였습니다. 결과에 보이는 "masterpiece"는 입력한 단어가 아니라 프로필 자체의 태그에서 온 것입니다.
- 입력한 단어는 압축되었습니다. 초상화 이미지에서는 컴파일러가 분명한 시각 단서로 알아본 조각만 남깁니다. "red-haired knight"는 여기에 해당하지 않아 빠졌습니다.

초상화, 아바타, 스프라이트에서 지정한 대상 단어가 사라진다면 이미지 종류를 **illustration**으로 바꿔 보세요. 이 종류는 입력한 표현을 그대로 살립니다.

## 우선순위: 채팅, 연결, 그다음 전역

Marinara는 세 곳에서 스타일 프로필을 가져올 수 있습니다. 가장 구체적으로 지정한 쪽이 우선합니다.

1. 현재 채팅이나 게임에 지정한 프로필.
2. 이미지 모델에 설정한 스타일 프로필. 모델 편집기의 **Local image defaults**(로컬 이미지 기본값) 안에 있습니다.
3. **Settings**의 전역 **Default style**.

**Local image defaults** 섹션은 AUTOMATIC1111 / SD Web UI, ComfyUI, NovelAI에서만 나타납니다. 그 밖의 서비스에서는 선택이 전역 **Default style**로 넘어갑니다. 모델별 프로필을 지정하려면 이미지 모델을 열고 **Local image defaults**를 펼친 다음 스타일 프로필 목록에서 프로필을 고르세요. 전역 선택을 따르려면 **Use global default**(전역 기본값 사용)로 두세요. 모델 이름으로 적절한 프로필을 짐작할 수 있으면 Marinara가 한 번에 그 프로필을 적용하는 "Use ..." 버튼을 표시합니다.
