# Haptic Feedback 설정

이 가이드에서는 Marinara Engine에서 AI 캐릭터가 연결된 햅틱 기기를 조작하도록 설정하는 방법을 설명합니다. 보조 앱 설치, 채팅에 **Haptic Feedback** 에이전트 추가, 기기 연결, 조절할 수 있는 촉감 설정까지 다룹니다.

## 햅틱 피드백이란

햅틱 피드백은 채팅 도중 AI 캐릭터가 연결된 햅틱 기기(성인용 토이)에 촉감 신호를 보내는 기능입니다. Marinara Engine이 기기와 직접 통신하지는 않습니다. 대신 **Intiface Central**이라는 무료 연동 앱에 명령을 보내고, 그 앱이 기기를 제어합니다.

**Intiface Central**은 **Buttplug.io**라는 기기 프로토콜을 사용합니다. 여러 토이와 다른 앱들이 함께 지원하는 개방형 표준입니다. **Intiface Central**을 한 번 설치해서 기기를 페어링해 두면, Marinara가 로컬 네트워크 주소로 그 앱에 접속합니다.

햅틱 피드백은 채팅에 추가할 수 있는 AI 기능인 **Agents**(에이전트) 중 하나로 만들어져 있습니다. Conversation(대화), Roleplay(롤플레이), Game(게임) 모드에서 작동합니다.

## 시작하기 전에

햅틱 피드백을 켜기 전에 세 가지를 준비해야 합니다.

1. 공식 웹사이트에서 **Intiface Central**을 설치하세요. 브라우저에서 아래 주소를 여세요.

```
https://intiface.com/central/
```

2. **Intiface Central**을 열고 서버를 시작하세요. 앱 안에 있는 서버 시작 버튼을 찾으면 됩니다.
3. 앱이 기기를 인식할 수 있도록 **Intiface Central** 안에서 기기를 페어링하거나 연결하세요.

**Intiface Central**이 실행 중이 아니거나 서버가 시작되지 않았다면 Marinara는 촉감 신호를 하나도 보낼 수 없습니다.

## Haptic Feedback 에이전트 추가하기

햅틱 피드백은 다른 에이전트와 똑같이 채팅 설정에서 추가합니다.

1. Conversation, Roleplay 또는 Game 채팅을 여세요.
2. 해당 채팅의 **Chat Settings**(채팅 설정)를 여세요.
3. **Agents** 섹션으로 이동하세요.
4. 채팅에 **Haptic Feedback** 에이전트를 추가하세요.
5. **Agents** 목록에 새로 나타난 **Haptic Feedback** 카드를 찾으세요.

카드 위쪽에 있는 **Haptic Feedback** 토글을 켜세요. 꺼져 있을 때는 설명에 "Allow this agent to send touch cues during the chat."이라고 표시되고, 켜져 있을 때는 "Touch cues are enabled for this chat."으로 바뀝니다. 이 토글은 기본값이 꺼짐입니다.

토글을 켜면 AI가 글을 쓰는 동안 숨은 촉감 신호를 보낼 수 있습니다. 이 신호는 채팅에 텍스트로 나타나지 않으며, 연결된 모든 기기에 전달됩니다.

## 연결, 검색, 기기 확인

**Haptic Feedback** 카드를 열면 Marinara가 저장해 둔 주소로 **Intiface Central**에 자동 연결을 시도합니다. 직접 연결할 수도 있습니다.

카드에는 색깔 점이 있는 상태 줄이 표시됩니다. 초록색 점은 연결됨, 빨간색 점은 연결되지 않음을 뜻합니다. 그 옆의 버튼은 연결이 끊긴 상태에서는 **Connect**(연결), 연결된 상태에서는 **Disconnect**(연결 해제)로 표시됩니다.

직접 연결하려면 **Connect**를 클릭하세요. 연결에 성공하면 상태 줄에 "Connected"와 서버 주소가 표시됩니다.

실패하면 연결할 수 없다는 메시지가 나타납니다. **Intiface Central**이 실행 중이고 서버가 시작되었는지 확인하라는 안내이며, 메시지 안에 **Intiface Central** 웹사이트 링크가 함께 들어 있습니다.

연결되면 카드에 찾은 기기 수가 표시됩니다. 연결된 기기가 없으면 "No devices found", 있으면 기기 수가 나옵니다. 다시 검색하려면 **Scan for devices**(기기 검색)를 클릭하세요. 검색이 진행되는 동안 버튼은 "Scanning..."으로 바뀝니다. 카드에는 기기마다 이름과 지원하는 동작(진동, 회전 등)이 함께 표시됩니다.

Marinara는 Haptic Agent에 Intiface의 정확한 이름, 기능에서 판별한 장난감 유형, 지원 동작도 전달합니다. 따라서 모든 장난감을 진동기로 가정하지 않고 올바른 기기와 동작을 선택할 수 있습니다.

## 지원 동작과 패턴

Marinara는 연결된 기기에 대해 Intiface가 보고하는 모든 출력 유형을 사용합니다. 진동, 회전, 왕복 운동, 수축, 팽창, 선형 위치, 온도, 분사, 조명을 지원합니다. 선형 위치는 스트로크, 밀기, 펌프 동작 기기를 제어하고 팽창은 공기압 펌프 기기를 제어합니다.

에이전트는 정지 이외의 동작에 **Steady**, **Tap**, **Pulse**, **Wave**, **Ramp**, **Impact** 패턴을 적용할 수 있습니다. 위치 패턴은 실제 이동 목표를 번갈아 지정하므로 펌프나 스트로크 패턴이 여러 움직임을 한꺼번에 보내지 않고 시간에 따라 실행됩니다.

### Intiface URL 입력란

**Intiface URL** 입력란에는 **Intiface Central** 서버의 네트워크 주소를 넣습니다. 두 앱이 통신하는 데 쓰는 로컬 주소인 WebSocket 주소입니다. 기본값은 아래와 같습니다.

```
ws://127.0.0.1:12345
```

주소 `127.0.0.1`은 "같은 컴퓨터"라는 뜻입니다. 입력란을 비워 두면 Marinara가 서버 기본값을 사용합니다. 또한 Marinara는 입력한 주소를 브라우저에 기억해 두기 때문에 여러 채팅과 기기에서 그대로 재사용됩니다.

Marinara를 Docker로 실행하거나 다른 기기의 브라우저에서 Marinara를 열면 `127.0.0.1`로는 **Intiface Central**에 닿지 않습니다. 이럴 때는 **Intiface Central**이 돌아가고 있는 컴퓨터의 주소를 입력하세요. 아래 예시와 같은 형태이며, 숫자 부분은 그 컴퓨터의 실제 주소로 바꾸면 됩니다.

```
ws://192.168.1.50:12345
```

## 촉감 강도

모든 채팅 모드에서 **Haptic Feedback** 카드에 세 가지 선택지를 가진 **Touch sensitivity**(터치 감도) 컨트롤이 표시됩니다. 감도는 에이전트가 부드럽거나 강한 출력을 얼마나 쉽게 고를지 안내하며 엄격한 상한을 두지 않습니다. 현재 동작에 필요하면 어느 선택지든 기기의 전체 `0.0-1.0` 강도 범위를 사용할 수 있습니다.

세 선택지는 에이전트의 반응 방식을 안내합니다.

| 선택지 | 느낌 | 비고 |
|---|---|---|
| **Subtle** | 더 부드러운 피드백을 선호합니다 | 전체 범위를 계속 사용할 수 있습니다 |
| **Standard** | 대부분의 장면에 어울리는 균형 잡힌 피드백 | 기본값이며 전체 범위를 사용할 수 있습니다 |
| **Intense** | 강한 피드백을 더 쉽게 선택합니다 | 최대 출력을 사용할 수 있습니다 |

기본으로 **Standard**가 선택되어 있습니다. 장면에 맞는 반응 방식을 고르세요. Marinara는 모든 명령을 Intiface의 물리적 `0.0-1.0` 범위에 맞춰 계속 검증합니다.

## 우발적인 접촉

강도 컨트롤 아래에는 모든 채팅 모드에 나타나는 **Incidental contact**(우발적 접촉) 토글이 있습니다. 설명에는 "Tiny taps for accidental brushes and bumps."라고 적혀 있습니다. 이 토글은 기본값이 꺼짐입니다.

꺼져 있으면 AI는 이야기 속의 사소한 우발적 접촉을 무시하고, 의도적이거나 확실한 접촉에만 신호를 보냅니다. 스치거나 부딪히는 장면에서도 짧은 신호를 받고 싶다면 켜세요.

## 다른 기기에서 사용하기

기본적으로 Marinara는 Marinara 서버가 돌아가는 컴퓨터에서 보낸 햅틱 명령만 받아들입니다. 기기 제어를 로컬에 묶어 두어 사생활을 지키기 위해서입니다.

그래서 휴대폰이나 다른 기기에서 Marinara를 열면 햅틱 피드백이 작동하지 않습니다. 그 기기가 다른 곳에서 실행 중인 Marinara 서버에 접속하는 경우가 여기에 해당합니다. 서버 설정을 바꾸지 않는 한 연결, 검색, 명령 전송이 모두 거부됩니다.

다른 기기에서 햅틱을 제어하려면 `HAPTICS_ALLOW_REMOTE`라는 서버 설정을 켜세요. 그리고 Basic Auth나 관리자 시크릿 같은 접근 보호도 함께 설정해야 합니다. 설정 항목은 [서버 설정 참고 문서](../CONFIGURATION.md)를, 접근 보호는 [원격 접근: Basic Auth와 IP 허용 목록](../REMOTE_ACCESS.md)을 참고하세요. 관리자 접근 정보는 **Settings**(설정)의 **Advanced**(고급) 영역에 있는 **Admin Access**(관리자 접근) 항목에서 입력합니다.

## 잘 작동하지 않을 때

AI가 기기를 전혀 작동시키지 못한다면 다음을 순서대로 확인하세요.

1. **Intiface Central**이 열려 있고 서버가 시작되었는지 확인하세요.
2. 기기가 페어링되어 있고, **Scan for devices**를 클릭한 뒤 기기 목록에 나타나는지 확인하세요.
3. 상태 점이 초록색이고 **Haptic Feedback** 토글이 켜져 있는지 확인하세요.
4. 휴대폰이나 원격 기기에서 쓰고 있다면 위의 원격 접근 안내를 다시 확인하세요.

**Intiface Central**이 연결되지 않았거나 기기가 하나도 연결되어 있지 않으면 Marinara는 AI의 촉감 신호를 조용히 건너뜁니다. 채팅에는 오류가 표시되지 않습니다.
