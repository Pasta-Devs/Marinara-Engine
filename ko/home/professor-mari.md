# Professor Mari, 앱 안의 어시스턴트

Professor Mari는 홈 화면에 들어 있는 Marinara Engine의 기본 어시스턴트입니다. 이 가이드에서는 어디에서 찾는지, 무엇을 할 수 있는지, 변경한 내용을 어떻게 되돌릴 수 있게 해 두는지, 자주 생기는 문제는 어떻게 푸는지 설명합니다.

## Professor Mari가 있는 곳

Professor Mari는 홈 화면에 있습니다. 홈 화면은 채팅을 하나도 열지 않았을 때 보이는 화면입니다.

픽셀 아트 그림과 **Professor Mari** 제목이 붙은 카드를 찾으세요. 그 아래 상태 줄로 지금 상태를 알 수 있습니다. 대기 중이면 **Ready to help**, 작업 중이면 **Working on it...**라고 표시됩니다. **Ask Professor Mari**(Professor Mari에게 묻기) 버튼을 클릭하면 전체 채팅 창이 열립니다.

말은 평소 쓰는 말투 그대로 걸면 됩니다. 입력 상자에 메시지를 쓰고 Enter를 누르면 전송됩니다. Shift와 Enter를 함께 누르면 줄바꿈이 들어갑니다.

Professor Mari에게 첫 메시지를 보내면 **Hello World** 업적이 열립니다.

## 할 수 있는 일

Professor Mari는 단순한 질문 상자가 아닙니다. 앱을 설명해 주고, 초기 설정을 도와주고, 부탁하면 이것저것 만들어 줍니다.

다음과 같은 일을 부탁할 수 있습니다.

- 무언가를 바꾸기 전에 그 설정이나 모드, 개념이 무엇인지 설명 듣기.
- 캐릭터 만들기와 편집하기. 캐릭터는 AI에게 이름과 성격, 말투를 부여하는 카드입니다.
- 페르소나 만들기와 편집하기. 페르소나는 채팅에서 직접 연기하는 정체성, 즉 이야기 속의 "나"입니다.
- 로어북 만들기와 편집하기. 로어북은 필요한 순간에 AI가 끌어다 쓰는 세계 설정 메모 모음입니다.
- 테마, 에이전트, 프롬프트 프리셋, Personal Extension(개인 확장) 초안 만들기와 편집하기. 기본으로 들어 있는 확장 제작자는 Professor Mari뿐입니다. Professor Mari가 만든 초안은 비활성 상태로 남습니다. 샌드박스 안의 코드를 직접 살펴보고, 요청된 캐릭터 카드나 페르소나 활성 권한을 검토한 다음, **Settings**(설정) > **Addons**(애드온)에서 정확한 해시를 승인해야 켜집니다.
- 프롬프트 프리셋의 한 부분만 그 자리에서 편집하기. Professor Mari는 프리셋에 들어 있는 개별 섹션, 프롬프트 그룹, 선택 변수를 목록으로 보여 주고, 그중 하나를 전문 그대로 읽어 준 다음, 그 부분만 더하거나 바꾸거나 지울 수 있습니다. 예를 들어 특정 섹션에 한 줄을 덧붙이는 식입니다. 프리셋 전체를 새로 만들거나 통째로 갈아 끼우지 않아도 됩니다.
- 공식 다운로드 에이전트와 기능 패키지 33개를 비교하고, 각각 어떤 모드를 지원하는지 설명하고, 목적에 맞는 것을 추천받기. Professor Mari는 카탈로그에 있는 것과 실제로 설치된 것을 구분하고, 필요하면 **Agents → Download Agents**로 안내하며, 패키지 원본과 전체 카탈로그가 [Pasta-Devs/Marinara-Agents](https://github.com/Pasta-Devs/Marinara-Agents)에 있다는 것도 알고 있습니다.
- 아바타, 스프라이트, 배경 같은 이미지 생성하기와 지정하기. 스프라이트는 채팅 중에 표시되는 캐릭터 이미지로, 초상화나 전신 포즈 같은 그림입니다.
- 캐릭터나 세계관을 조사할 수 있도록 공개된 Fandom 위키 문서 찾아보기.
- 채팅 입력란 위에 뜨는 빠른 답장 제안 칩을 따라 여러 단계로 이어지는 생성이나 편집 진행하기. 칩은 대상 종류에 따라 색이 다릅니다.

Professor Mari는 편집하기 전에 대상을 먼저 읽고, 요청이 모호하면 빠진 내용을 되묻습니다. 이미지 작업을 맡기려면 동작하는 이미지 생성 연결이 미리 설정되어 있어야 합니다. 연결까지 대신 만들어 주지는 않습니다.

## 안내 제안 칩

Professor Mari 채팅이 비어 있을 때는 **Create a Character**, **Create a Lorebook**, **Create a Persona** 같은 시작 칩이 나타나 자주 하는 작업을 바로 시작하게 해 줍니다. 안내를 따라 생성이나 편집을 진행하는 동안에는 칩이 다음 단계에 맞게 바뀝니다. 칩을 클릭하면 입력란에 초안이 채워지고, 보내기 전에 그 초안을 고칠 수 있습니다.

안내 흐름은 긴 양식을 한 번에 내밀지 않고 한 번에 하나씩만 묻습니다.

## 앱 자체의 파일 읽기와 고치기

Professor Mari는 Marinara의 프로그램 파일 내부를 들여다보고, 고치고, 샌드박스 안에서 명령을 실행할 수 있습니다. 실제로 강력한 기능이므로 어디까지 허용되는지 분명히 알아 두는 편이 좋습니다.

신뢰 경계를 쉬운 말로 정리하면 다음과 같습니다.

- 파일 도구는 Marinara가 설치된 폴더 안에서만 동작합니다. 셸 명령은 작업 공간과 필요한 시스템 프로그램을 읽을 수 있지만, 그 밖의 개인 파일은 읽지 못합니다.
- `.env` 같은 환경 비밀 파일과 Git 내부 파일은 파일 도구로도, 셸로도 열 수 없습니다.
- 캐릭터와 채팅이 저장되는 데이터 폴더에는 직접 쓰지 못합니다. 대신 아래에서 설명하는 검토 절차를 거칩니다.
- 셸 명령은 네트워크에 접근하지 못하고, 서버의 비밀 값도 물려받지 않으며, 평범한 작업 공간 파일과 전용 임시 폴더에만 쓸 수 있습니다.
- Professor Mari는 일반 소스 파일을 계속 직접 고칠 수 있습니다. 의존성 매니페스트, 잠금 파일, 런처, 설치 프로그램, CI 워크플로를 건드리는 변경은 대기 상태로 쌓이고, Marinara가 적용하기 전에 화면에 보여 줍니다.
- 소스 변경에 공개 npm 라이브러리가 필요하면 Professor Mari가 특정 패키지를 지정해 요청합니다. Marinara는 `latest`를 정확한 버전으로 확정하고, 레지스트리 무결성 값을 검토 카드에 보여 주며, 승인한 뒤에만 설치합니다. 패키지 라이프사이클 스크립트는 계속 비활성 상태입니다.
- Marinara가 macOS나 Linux의 셸 샌드박스를 제공하지 못하는 환경에서는 셸 명령이 비활성화됩니다. 더 안전한 구조화된 파일 도구와 앱 데이터 도구는 그대로 쓸 수 있습니다.
- 실행한 명령은 짧은 시간이 지나면 스스로 멈추므로, 멈춰 버린 명령이 끝없이 돌아가는 일은 없습니다.

대부분은 이 기능을 쓸 일이 없습니다. 앱에 문제가 생겼을 때 앱 자체를 점검하거나 고칠 수 있도록 마련해 둔 기능입니다.

## 연결 고르기

Professor Mari가 생각하려면 연결이 필요합니다. 연결은 API 키를 써서 Marinara를 AI 제공자와 이어 주는 정보입니다. API 키는 제공자가 발급하는 비밀 문자열입니다.

클립 아이콘 옆의 링크 아이콘을 클릭하면 **Connections**(연결) 드롭다운이 열립니다. 설정해 둔 텍스트 생성 연결 중에서 아무거나 고르세요. 내장 로컬 모델을 다운로드했다면 **Local Model (sidecar)**로 여기에 함께 나타납니다. 앱이 모델 이름을 알고 있으면 괄호 안에 그 이름이 대신 들어갑니다. 어떤 연결을 골랐는지는 브라우저에 기억됩니다.

아직 연결이 하나도 없으면 드롭다운에 **Add a connection**(연결 추가)만 표시됩니다. 연결 없이 메시지를 보내려고 하면 **Connections** 패널이 대신 열립니다. 이런 팝업 메시지(토스트라고 부릅니다)도 함께 뜹니다.

> You haven't set up a connection yet! Click the link icon beside the paperclip to select one.

연결을 처음부터 설정하는 방법은 문서 끝에 링크된 연결 가이드에서 볼 수 있습니다.

## 파일 첨부하기

**Attach files**(파일 첨부)라고 표시된 클립 버튼을 클릭하면 메시지에 파일을 붙일 수 있습니다.

이미지, PDF 파일, 그리고 `.txt`, `.md`, `.json`, `.csv`, `.log` 같은 흔한 텍스트 파일을 받습니다. 파일 하나당 최대 20 MB입니다. 첨부한 파일은 보내기 전까지 메시지 상자 위에 칩으로 표시되고, 거기에서 뺄 수 있습니다.

이미지를 읽게 하려면 선택한 연결의 모델이 이미지 입력을 지원해야 합니다.

## 변경한 내용 검토하기

이미 있는 항목을 Professor Mari가 편집할 때는 변경을 곧바로 저장한 다음 검토 카드를 띄웁니다. 결과가 마음에 들지 않으면 이 카드로 되돌리면 됩니다.

카드 제목은 **Review Mari's changes**(Mari의 변경 사항 검토)입니다. 무슨 작업을 했고 어떤 데이터를 건드렸는지 보여 주며, 버튼이 2개 있습니다.

- **Keep**(유지)은 변경을 확정합니다. "Kept Mari's workspace change." 메시지가 나타납니다.
- **Restore**(복원)는 직전에 저장된 버전을 되돌립니다. "Restored the previous app data snapshot." 메시지가 나타납니다.

몇 가지 알아 둘 점이 있습니다.

- 새로 만든 캐릭터나 로어북처럼 완전히 새로운 항목에는 보통 이 단계가 없습니다. 덮어쓴 것이 없으니 되돌릴 것도 없기 때문입니다.
- 검토 카드는 답하지 않고 두면 10분 뒤에 저절로 사라집니다.
- 캐릭터와 페르소나는 각자의 편집기 안에 자체 버전 기록도 남깁니다. 두 번째 안전장치로 거기에서 예전 버전을 되돌릴 수 있습니다.

위험도가 더 높은 변경 2가지는 먼저 적용하지 않고 기다립니다.

- **Sensitive file changes**(민감한 파일 변경)는 경로와 적용될 내용을 보여 주고 **Apply change**(변경 적용)와 **Discard**(변경 취소) 버튼을 함께 띄웁니다. 의존성 파일, 런처, 설치 프로그램, CI 워크플로가 여기에 해당합니다. 일반적인 TypeScript, React, CSS, 프롬프트, 라우트, 문서 편집은 이런 추가 관문 없이 그대로 진행됩니다.
- **Dependencies**(의존성)는 정확한 공개 npm 패키지, 버전, 대상 작업 공간, 의존성 종류, 레지스트리 무결성, 선언된 직접 의존성을 보여 주고 **Install**(설치)과 **Not now**(나중에) 버튼을 함께 띄웁니다. `npm`, `pnpm`, `yarn`, `pip` 같은 설치 명령은 캐시를 이용한 설치까지 포함해 셸 안에서 모두 막혀 있습니다.

라이브러리를 승인한다는 것은 나중에 Marinara가 그 코드를 불러오거나 실행할 때 그것을 믿겠다는 뜻입니다. 라이프사이클 스크립트를 꺼 두면 설치 시점의 실행은 막을 수 있지만, 그것만으로 라이브러리가 실행 중에도 무해해지지는 않습니다.

## 사용자 지정 스킬

스킬은 Professor Mari가 특정 종류의 요청을 처리하는 방식을 바꾸려고 직접 작성하는 짧은 안내 문서입니다.

채팅 헤더의 **Skills**(스킬) 버튼을 클릭하면 **Professor Mari Skills**(Professor Mari 스킬) 패널이 열립니다. 이 패널에서 할 수 있는 일은 다음과 같습니다.

- **New**(새로 만들기)를 클릭해 템플릿에서 스킬 만들기.
- **Upload**(업로드)를 클릭해 `.md`나 `.txt` 파일에서 스킬 추가하기.
- 스킬을 하나씩 켜고 끄기. 꺼 둔 스킬도 사라지지는 않지만 쓰이지 않습니다.
- 스킬을 선택해 **Name**(이름), **Description**(설명), **Instructions**(지침)를 편집한 뒤 **Save**(저장) 클릭하기. **Delete**(삭제)를 클릭하면 삭제됩니다.

스킬이 하나도 없으면 패널에 **No custom skills yet**이라고 표시됩니다.

## 저장된 기억

Professor Mari는 평소 지키는 작업 방식을 기억해 둘 수 있습니다. 채팅을 새로 시작할 때마다 같은 말을 되풀이하지 않아도 됩니다. 로어북이나 캐릭터 카드를 어떤 형식으로 정리하는지, 이름은 어떤 규칙으로 붙이는지, Professor Mari가 어떻게 행동하기를 바라는지 같은 것입니다.

기억을 남기는 방법은 두 가지입니다.

- **말로 알려 주기.** "로어북 항목의 키는 항상 캐릭터 이름과 별명으로 잡아 줘"처럼 말하면 됩니다. Professor Mari가 그 내용을 저장하고, 정확한 문구가 담긴 **Keep/Restore** 검토 카드를 보여 줍니다. 새로 저장된 기억은 **비활성화**(꺼짐) 상태로 시작하므로, 직접 켜기 전까지는 아무것도 달라지지 않습니다. 카드에는 세 번째 버튼 **Keep & Enable**(유지하고 활성화)이 있어서, 저장과 동시에 바로 켤 수도 있습니다.
- **직접 추가하기.** 채팅 헤더의 **Memories**(기억) 버튼을 클릭하면 **Memories** 패널이 열립니다. 여기에서 기억을 만들고, 편집하고, 켜거나 끄고, 삭제할 수 있습니다. **Upload**로 `.md` 파일이나 텍스트 파일을 올려 그 내용을 기억으로 만들 수도 있습니다.

기억을 저장하거나 고치는 것은 **직접 부탁했을 때뿐**입니다. 읽어 들인 캐릭터나 로어북, 파일에 그렇게 하라고 적혀 있어도 따르지 않습니다.

기억을 어떻게 쓰는지, 그리고 왜 부담이 적은지는 다음과 같습니다.

- Professor Mari는 매 턴 *켜져 있는* 기억의 짧은 **색인**만 봅니다. 제목과 한 줄 설명뿐이라 비용이 거의 들지 않습니다. 지금 하는 작업에 관련된 기억이 있으면 그때 전문을 찾아 읽고 그대로 따릅니다. 항상 들어가는 것은 짧은 색인뿐이라, 기억이 늘어나도 프롬프트는 작게 유지됩니다. 예외는 **Persistent**(항상 적용)로 표시한 기억입니다(아래 참고). 이 기억은 매 턴 전문이 주입되므로 개수는 적게, 길이는 짧게 유지하세요. 꺼 둔 기억은 지워지지 않고 무시될 뿐이므로, 잠시 꺼서 다른 방식을 시도해 보고 나중에 다시 켤 수 있습니다.
- 저장된 기억은 기본 동작과 부딪힐 때 **기본 동작보다 우선합니다**. 예를 들어 "어떻게 하는지 물으면 그냥 해 줘"라는 기억이 있으면, 먼저 확인하고 넘어가는 평소 습관 대신 묻지 않고 바로 편집하는 쪽으로 돌아갑니다.
- *매* 턴 적용되어야 하는 드문 지시는 **Persistent**로 만들면 그 전문이 Professor Mari의 프롬프트에 항상 들어갑니다. 이런 기억은 하나하나가 언제나 프롬프트를 차지하므로 개수는 적게, 길이는 짧게 유지하고, 항상 참이어야 하는 행동을 적을 때만 쓰세요.

기억을 관리하려면 **Memories** 패널을 쓰거나, 그냥 이렇게 물어보세요. "뭘 기억하고 있어?", "로어북 서식 기억에 제목도 넣어 줘", "그건 잊어버려."

## 채팅 기록과 Restart

Professor Mari는 자기만의 채팅을 따로 보관합니다. 이 채팅은 평소의 채팅 목록에 나타나지 않습니다.

헤더의 **Chats**(채팅) 버튼을 클릭하면 저장해 둔 Professor Mari 채팅이 열립니다. 패널에는 "Restart saves the current chat here."라고 적혀 있습니다. 저장된 채팅을 클릭해 열거나, 이름을 바꾸거나, 삭제할 수 있습니다.

**Restart**(재시작) 버튼을 클릭하면 Professor Mari와 채팅을 처음부터 새로 시작합니다. Restart는 현재 채팅을 먼저 **Chats** 목록에 저장합니다. 메시지 상자에 `/restart`를 입력해도 똑같이 동작합니다. "Professor Mari's previous chat was saved." 메시지가 나타납니다.

작업 중일 때는 헤더에 **Stop**(중지) 버튼이 나타납니다. 클릭하면 진행 중인 작업이 취소됩니다.

## 떠다니는 채팅 버블

채팅 창을 열어 둔 채 다른 페이지로 이동하면 Professor Mari가 작은 버블 형태로 따라올 수 있습니다.

휴대폰이나 좁은 화면에서는 드래그해서 옮길 수 있는 작고 둥근 아바타로 바뀝니다. 탭하면 전체 채팅이 다시 열립니다. 넓은 화면에서는 드래그할 수 있는 작은 **Ask Professor Mari** 창이 나타납니다. 어느 쪽에나 이번 세션 동안 버블을 숨기는 버튼이 함께 있습니다.

## 채팅과 별개인 FAQ

채팅 카드 옆에는 **FAQ** 패널이 놓여 있습니다. 여기에는 질문과 답변이 미리 정해진 형태로 적혀 있습니다. AI 채팅이 아닙니다.

**Search FAQ** 입력란에 검색어를 입력하면 질문이 걸러집니다. 질문마다 **Setup**, **Connections**, **Game Mode**처럼 색이 있는 분류 태그가 붙습니다. 질문을 탭하면 답변이 펼쳐집니다.

FAQ는 앱에 미리 적어 둔 내용이라 지금 어떻게 설정해 두었는지까지는 알지 못합니다. 내 데이터나 현재 상태에 대해 묻고 싶을 때는 채팅을 쓰세요.

## 한계와 안전

Professor Mari는 문서 전체를 대신하는 존재가 아니라 옆에서 돕는 기능입니다. 다음 한계를 기억해 두세요.

- 내장된 지식이 지금 쓰는 앱 버전과 정확히 일치한다고는 보장하지 못합니다. 버전에 따라 달라지거나 최근에 바뀐 내용이라면 가이드와 릴리스 노트를 먼저 믿으세요.
- 새 콘텐츠를 만드는 일은 덮어쓰는 것이 없어서 대체로 안전합니다. 이미 있는 콘텐츠를 편집할 때는 더 조심해야 합니다.
- 검토를 거친 의존성이라도 결국 서드파티 코드이고, 그것을 불러오는 Marinara 코드와 똑같은 실행 권한을 갖습니다. 승인 카드에 표시되는 패키지 이름, 정확한 버전, 용도, 무결성 값을 확인하세요.
- 편집을 맡길 때는 어떤 항목의 어떤 필드를 바꿀지 정확히 밝히세요. "이 캐릭터를 통째로 다시 써 줘"보다 "Luna의 인사말을 짧게 줄이고 성격은 그대로 둬"가 훨씬 안전합니다.
- 여러 단계에 걸친 생성 작업에서는 모든 필드를 한 번에 넘기려 하지 말고, 제안 칩을 따라 한 번에 하나씩 답하세요.
- 작업을 끝냈다고 하는데 앱에 반영되지 않았다면 앱 쪽을 믿으세요. 해당 패널에서 직접 마무리하면 됩니다.
- 같은 컴퓨터가 아니라 다른 기기에서 Marinara에 접속했다면, 편집 동작에는 원격 접근 설정이 필요합니다. 원격 접근 가이드를 참고하세요.

## 문제 해결

- 답이 아예 없을 때: 링크 아이콘에서 연결이 선택되어 있는지 확인하세요. 설정된 연결이 없으면 **Connections** 패널을 열어 하나 추가하세요.
- "You haven't set up a connection yet" 팝업 메시지가 뜰 때: 링크 아이콘 드롭다운에서 연결을 고르거나, 연결을 먼저 추가하세요.
- 첨부한 이미지를 읽지 못할 때: 모델이 이미지 입력을 지원해야 합니다. 이미지를 볼 수 있는 모델의 연결로 바꾸세요.
- Fandom 검색이 실패할 때: Fandom은 외부 웹사이트라 인터넷 연결이 필요합니다.
- 권한 오류가 나면서 동작이 막힐 때: 같은 컴퓨터가 아니라 네트워크를 거쳐 Marinara에 접속하고 있다는 뜻입니다. 원격 접근을 먼저 설정하세요.
