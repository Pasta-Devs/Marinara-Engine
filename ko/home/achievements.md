# 업적

업적은 Marinara Engine을 쓰다 보면 열리는 장식용 배지입니다. 예를 들어 채팅을 만들거나 커뮤니티 링크를 방문하면 열립니다. 업적은 앱의 동작을 바꾸지 않습니다. 이 가이드에서는 업적을 찾는 곳, 전체 목록, 끄는 방법을 설명합니다.

## Achievements 창 열기

1. 홈 화면으로 이동하세요.
2. **Achievements**(업적) 북마크(트로피 아이콘)를 클릭하세요. 휴대폰에서는 먼저 탭 왼쪽의 북마크 버튼을 탭하세요.

**Achievements** 창이 열립니다. 맨 위에는 **12 of 24 achievements unlocked in this profile.** 같은 요약이 있습니다. 프로필은 저장된 Marinara 데이터 한 묶음입니다. 그 아래에는 카드가 격자로 늘어섭니다.

- 잠긴 카드에는 **?????**와 자물쇠 아이콘이 표시됩니다. 열기 전까지는 내용을 읽을 수 없습니다.
- 열린 카드에는 **unlocked**(잠금 해제됨) 태그가 표시됩니다.
- 목표치가 있는 카드에는 **Progress**(진행 상황) 줄과 막대도 표시됩니다.

홈에 **Achievements** 위젯을 추가할 수도 있습니다. 북마크에서 **Widgets**(위젯)를 클릭하고 위젯을 켜세요. 위젯에는 **12 of 24 unlocked** 같은 개수와 **Last obtained**(최근 획득) 업적, **Closest next**(다음 업적까지) 업적이 표시됩니다. 불러오는 동안에는 **Checking the collection...**(컬렉션 확인 중...)이 표시됩니다. 위젯을 클릭하면 창이 열립니다. [홈 위젯](welcome.md#home-widgets)을 참고하세요.

작동하지 않는 경우: 북마크, 위젯, 창은 **Achievements** 설정이 켜져 있을 때만 표시됩니다. [업적 켜고 끄기](#turn-achievements-on-or-off)를 참고하세요.

진행 상황은 사용 중인 프로필에 저장됩니다. 다른 프로필이나 새 설치에서는 아무것도 열리지 않은 상태로 시작합니다. 열린 업적은 전체 백업에 저장됩니다.

## 업적 24가지

업적은 모두 24가지이며 **Milestone**(마일스톤), **Community**(커뮤니티), **Creation**(창작), **Collection**(컬렉션) 네 카테고리로 나뉩니다. **Creation**과 **Collection** 업적에는 **I**, **II**, **III** 세 단계가 있으며, 각각 5, 25, 100에서 열립니다. 두 번째 단계에 도달하면 배지 제목이 **Hoarder II**처럼 표시될 수 있습니다.

| 업적 | 카테고리 | 여는 방법 |
| --- | --- | --- |
| **Diligent Student** | Milestone | 첫 실행 튜토리얼을 끝내거나 건너뜁니다. |
| **Hello World** | Milestone | Professor Mari에게 첫 메시지를 보냅니다. |
| **Please Handle With Care** | Milestone | Professor Mari의 그림을 화면 여기저기로 끌어 옮깁니다. |
| **One Of Us** | Community | **Discord** 북마크나 **Community** 위젯의 **Discord** 링크를 클릭합니다. |
| **Based Backer** | Community | 북마크나 **Community** 위젯에서 **Support**(지원)를 클릭합니다(Ko-fi가 열립니다). |
| **Backseat Appreciator** | Community | 북마크나 **Community** 위젯에서 **Credits**(크레딧)를 클릭합니다. |
| **Who Needs IRL Friends** | Creation | Conversation 채팅을 만듭니다(5, 25, 100). |
| **They Feel Real To Me** | Creation | Roleplay 채팅을 만듭니다(5, 25, 100). |
| **I Have No Other Hobbies** | Creation | Game 채팅을 만듭니다(5, 25, 100). |
| **Hoarder** | Collection | 캐릭터를 모읍니다(5, 25, 100). |
| **The World's A Stage** | Collection | 로어북을 모읍니다(5, 25, 100). |
| **I Am A Gamer** | Collection | 페르소나를 모읍니다(5, 25, 100). |

- 페르소나는 채팅에서 나를 나타내는 캐릭터 카드입니다. 로어북은 키워드가 나올 때 AI가 읽는 세계 설정 모음입니다.
- **Collection**은 가져오거나 다운로드한 항목을 포함해 라이브러리에 있는 해당 종류를 모두 셉니다. **Hoarder**에서는 기본 제공 캐릭터인 Professor Mari를 절대 세지 않습니다.
- 커뮤니티 업적은 링크를 방문하기만 해도 충분합니다. 해당 사이트에 가입할 필요는 없습니다.

## 에이전트의 업적

설치한 에이전트는 자체 업적을 추가할 수 있습니다. 이 업적은 같은 창에서 기본 제공 업적 뒤에 **From Noodle**(Noodle에서 제공) 같은 제목 아래로 표시됩니다. 같은 규칙을 따르며, 에이전트는 자체 배지 그림을 보여 줄 수 있습니다.

에이전트를 제거하면 해당 섹션이 사라지지만 열린 기록은 유지됩니다. 다시 설치하면 다시 열린 상태로 표시됩니다. 맨 위의 개수에는 설치한 에이전트의 업적도 포함됩니다.

## 업적 켜고 끄기

1. **Settings → General**(설정 → 일반)을 여세요.
2. **App Behavior**(앱 동작) 섹션에서 **Achievements** 토글을 켜거나 끄세요. 기본값은 켜짐입니다.

- 켜짐: 북마크와 창을 쓸 수 있고, 업적이 열리면 팝업이 나타납니다.
- 꺼짐: 북마크, 위젯, 팝업이 숨겨집니다. 앱은 백그라운드에서 계속 기록을 남기므로, 다시 켜도 잃는 것은 없습니다.

## 업적이 열리는 방식

Marinara는 채팅 만들기나 북마크 클릭처럼 기록 대상 동작이 일어날 때와 창을 열 때 개수를 확인합니다.

- 어떤 동작으로 배지가 열리고 설정이 켜져 있으면, **Achievement unlocked**(업적 잠금 해제됨)라는 제목의 팝업에 **Hoarder II** 같은 배지 이름이 표시됩니다.
- 창을 열면 이미 다른 방법으로 조건을 채운 배지가 열릴 수 있습니다. 이런 업적은 조용히 처리되어 팝업 없이 카드만 열린 상태로 표시됩니다.
- 한 번 열린 배지는 나중에 채팅, 캐릭터, 로어북, 페르소나를 지워도 열린 상태로 남습니다.
- 열린 카드의 **Progress** 막대는 현재 개수를 보여 주므로, 배지를 얻었는데도 카드에 **2 / 5**처럼 표시될 수 있습니다. 정상입니다.

업적을 초기화하는 버튼은 없습니다.
