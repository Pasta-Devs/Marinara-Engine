# Game Mode: 세션과 저장 데이터

Game Mode(게임 모드)는 TRPG 모임 하루하루처럼 모험을 번호가 붙은 세션으로 나눕니다. 이 가이드에서는 세션을 끝내고 시작하는 방법, 지난 세션을 읽는 방법, 설정을 공유하는 방법, 저장된 데이터를 직접 고치는 방법, 이전 시점으로 되돌아가는 방법을 설명합니다.

첫 세션은 **Session 1**입니다. 이 세션을 끝내고 다시 시작하면 **Session 2**가 만들어지고, 이후로도 같은 방식입니다. 세션을 끝내면 게임 마스터(GM, 게임을 진행하는 AI)가 나중에 다시 읽을 수 있는 요약을 씁니다.

## 저장하고 이어 하기

저장 버튼은 없습니다. 게임은 플레이하는 동안 알아서 저장됩니다.

1. 잠시 멈추려면 탭이나 앱을 닫으세요.
2. 이어 하려면 같은 게임 채팅을 여세요. 멈춘 곳으로 돌아갑니다.
3. 한 챕터를 마무리하려면 세션을 끝내세요([세션 끝내기](#end-a-session) 참고).

이전 시점으로 되돌아가려면 [게임이 저장되는 방식](#how-your-game-saves)을 참고하세요.

<a id="opening-session"></a>

## Session 열기

**Session**(세션)에서 세션을 끝내고, 새 세션을 시작하고, 지난 기록을 읽습니다.

1. Game Mode 채팅을 여세요.
2. 채팅 오른쪽 위 근처에 있는 **Session** 버튼(깃펜 아이콘)을 클릭하거나 탭하세요. 버튼은 다른 곳으로 끌어 옮길 수 있습니다([컨트롤 창과 버튼](../chats/chat-settings.md#control-windows-and-their-buttons) 참고).
3. **Session**이 컴퓨터에서는 창으로, 휴대폰에서는 화면 너비의 패널로 열립니다. 첫 줄에는 현재 세션 번호와 상태가 표시됩니다.
4. **Session History**(세션 기록)와 **Journal**(일지) 두 개의 탭이 있습니다. 세션 조작은 **Session History** 탭에서 합니다.

**Put back in Chat Settings**(채팅 설정에 되돌려 놓기)로 이 창을 옮겼다면 대신 Chat Settings 안의 **Session** 섹션을 여세요.

<a id="end-a-session"></a>

## 세션 끝내기

한 챕터를 마무리하고 GM에게 요약을 맡기고 싶을 때 세션을 끝내세요.

1. **Session**을 열고 **Session History**에 머무르세요.
2. 맨 위에서 **Session N (Current)**로 표시된 현재 세션을 찾으세요.
3. 그 줄에서 **End Session**(세션 종료) 버튼(작은 사각형 아이콘)을 클릭하세요. 그 줄에는 작은 아이콘 버튼이 여러 개 있으므로 포인터를 올려 툴팁을 확인하세요. **End Session**이라는 제목의 팝업 창이 확인을 요청합니다.
4. 선택 사항: **What do you want to happen in the next session (optional)?**(다음 세션에서 어떤 일이 일어나길 원하나요(선택 사항)?)에 메모를 입력하세요(최대 5,000자). GM이 이야기를 이끌게 하려면 비워 두세요.
5. 팝업 창에서 **End Session**을 클릭하세요. 그만두려면 **Cancel**(취소)을 클릭하세요.

GM이 요약을 쓰는 동안 팝업 창 제목이 **Ending Session**(세션 종료 중)으로 바뀝니다. 끝날 때까지 이 화면에서 기다리세요. 그러면 세션이 종료 상태로 표시되고 기록에 나타납니다.

작동하지 않는 경우: GM 모델에 접속할 수 있는지 확인하세요. 요약은 모델 요청이므로 다른 요청처럼 실패할 수 있습니다. 다시 시도하고 [Marinara Engine 문제 해결](../TROUBLESHOOTING.md)을 참고하세요.

## 새 세션 시작하기

세션이 종료되면 그 줄의 같은 버튼이 **New Session**(새 세션 시작)으로 바뀝니다.

1. **Session**을 열고 **Session History**로 이동하세요.
2. 현재 세션 줄에서 **New Session** 버튼(재생 아이콘)을 클릭하세요.

GM은 직전 요약과 세션을 끝낼 때 적어 둔 메모를 바탕으로 이야기를 이어 갑니다. 생성된 세계가 있는 게임에서는 세계가 멈췄던 지점부터 이어집니다. 흘러간 날짜, 파티의 행적과 평판, 이야기에 추가된 장소와 집단, 파티가 다녀간 곳이 그대로 이어집니다.

## 지난 세션 읽기

**Session History**에는 종료된 세션이 최신순으로 나열됩니다. 아직 끝낸 세션이 없으면 **No completed sessions yet**(아직 완료된 세션이 없습니다)이 표시됩니다. 각 줄에는 세션 번호, 날짜, 기록된 발견의 개수가 표시됩니다. 줄을 클릭하면 펼쳐집니다. 다음 필드가 표시될 수 있습니다.

| 필드 | 담긴 내용 |
| --- | --- |
| **Summary**(요약) | 세션에서 벌어진 일. |
| **Resume Point**(재개 지점) | 다음 세션이 이어질 지점. |
| **Party Dynamics**(파티 관계) | 파티원들 사이의 관계. |
| **Key Discoveries**(주요 발견) | 중요한 사실, 반전, 밝혀진 내용. |
| **Character Moments**(캐릭터 모먼트) | 돋보인 장면. |
| **Little Details To Recall**(기억할 작은 세부 정보) | 사소한 습관, 약속, 자잘한 세부 정보. |
| **NPC Updates**(NPC 업데이트) | NPC(플레이어가 아닌 캐릭터로, GM이 조종하는 인물)의 변화. |
| **Next Session Request**(다음 세션 요청) | 세션을 끝낼 때 남긴 메모. |
| **Stats Snapshot**(스탯 스냅샷), **Party Status**(파티 상태) | 저장된 수치와 파티 상태. |

### 세션 다시 보기

다시 보기는 읽기 전용입니다. GM을 호출하지 않고, 메시지를 만들지 않으며, 인벤토리나 스탯을 바꾸거나 일지를 갱신하거나 체크포인트를 복원하지도 않습니다.

1. 종료된 세션을 펼치세요.
2. **Replay Session**(세션 재생)을 클릭하세요.
3. **Next**(다음)와 **Next turn**(다음 턴)을 눌러 원래의 서술과 대사를 차례로 넘겨 보세요.
4. 선택지에서는 원래 골랐던 항목 하나만 활성화됩니다. 그 항목을 클릭하면 기록된 경로를 따라 계속 진행합니다.
5. 다 봤으면 위쪽의 닫기 버튼이나 **Return to current session**(현재 세션으로 돌아가기)을 클릭하세요.

다시 보기 기능이 생기기 전의 세션도 저장된 텍스트, 연출, 선택지, 에셋으로 다시 볼 수 있습니다. 예전 턴에는 당시 저장되지 않은 장면 연출이 빠져 있을 수 있습니다.

### 지난 세션 편집하기

이후 세션이 내용을 제대로 기억하도록 종료된 세션의 기록을 고치세요.

1. 세션을 펼치세요.
2. **Edit Details**(세부 정보 편집)를 클릭하세요.
3. 원하는 필드를 고친 다음 **Save Details**(세부사항 저장)를 클릭하세요. 고친 내용을 버리려면 **Cancel**을 클릭하세요.

펼친 세션에는 버튼이 두 개 더 있습니다.

- **Regenerate**(재생성)는 AI 결론을 다시 실행합니다. 요약과 나머지 모든 필드를 다시 쓰므로 **Edit Details**로 고친 내용은 사라집니다.
- **Update Plot Arcs**(플롯 아크 업데이트)는 그 세션에서 일어난 일을 바탕으로 GM의 숨은 이야기 계획을 갱신하도록 AI에 요청합니다. 이 계획은 **Show Spoilers**(스포일러 보기) 화면의 **Story Arc**(스토리 아크), **Plot Twists**(반전), **Party Arcs**(파티 아크)입니다.

**Regenerate Lorebook**(로어북 재생성)은 가장 최근에 종료한 세션에만, 그리고 Lorebook Keeper 기능이 켜져 있을 때만 나타납니다. 로어북은 AI가 떠올릴 수 있는 세계 설정의 모음입니다.

## 게임을 만든 설정 공유하기

Game Mode는 새 캠페인을 만들 때 사용한 설정의 스냅샷을 보관합니다. 먼저 플레이해 보고, 조합이 괜찮으면 공유하세요.

1. 캠페인을 열고 **Session**을 여세요.
2. **Session History**에서 **Initial Game Setup**(초기 게임 설정)을 펼치세요.
3. 저장된 모험, 출연 캐릭터, 모델, 프롬프트, 생성 파라미터, 비주얼, 스토리보드, 월드 도구 설정을 확인하세요.
4. **Copy setup**(설정 복사)을 클릭하면 텍스트가 복사되고, **Download setup**(설정 다운로드)을 클릭하면 텍스트 파일로 저장됩니다.

> **경고:** 텍스트에는 길게 적어 둔 플레이어 선호 사항과 사용자 지정 GM 지침이 들어갑니다. 올리기 전에 읽어 보세요. 인증 정보, 서버 URL, API 키, 로컬 데이터베이스 ID는 절대 포함되지 않습니다.

캐릭터 카드, 페르소나, 로어북, 모델, 계정은 이름만 적히고 함께 담기지 않으므로, 다른 플레이어는 같은 역할을 하는 항목을 각자 갖춰야 합니다. 스냅샷 기능이 생기기 전에 만든 캠페인은 저장된 적 없는 설정을 되살릴 수 없으므로, **Initial Game Setup**은 믿을 수 있는 스냅샷이 있을 때만 표시됩니다.

## GM의 숨은 기록 보기

현재 세션 줄의 눈 아이콘인 **Show Spoilers**는 현재 세션에 대한 GM의 비공개 기록을 보여 줍니다. 읽으면 이야기의 반전이 미리 밝혀질 수 있습니다.

1. **Session**을 열고 **Session History**로 이동하세요.
2. 현재 세션 줄에서 **Show Spoilers** 버튼(눈 아이콘)을 클릭하세요.

이 화면에는 **World Overview**(세계 개요), **Story Arc**, **Plot Twists**, **Party Arcs**, 그리고 저장된 **Maps**(지도), **NPCs**, **Character Cards**(캐릭터 카드)가 표시될 수 있습니다. 다시 숨기려면 같은 버튼을 클릭하세요. 이때 버튼 이름은 **Hide Spoilers**(스포일러 가리기)로 바뀌어 있습니다.

이 기록을 바꾸려면 **Edit Spoilers**(스포일러 편집)를 클릭하고 텍스트를 고친 다음 **Save Spoilers**(스포일러 저장)를 클릭하세요. 일부 필드는 구조화된 텍스트 형식인 JSON입니다. 형식이 어긋난 JSON은 저장되지 않으므로, 형식을 아는 경우에만 고치세요.

<a id="editing-game-data-by-hand"></a>

## 게임 데이터 직접 고치기

GM이 NPC의 평판을 잘못 매기거나 퀘스트를 계속 열어 두는 등 무언가를 잘못 처리했다면, 저장된 데이터를 직접 고칠 수 있습니다.

1. **Game controls**(게임 컨트롤)를 열고 **Edit game data**(게임 데이터 편집)를 선택하세요. 휴대폰에서는 **Game controls**가 점 세 개짜리 **Chat tools**(채팅 도구) 메뉴 안에 있습니다.
2. **Game Data**(게임 데이터) 창이 열립니다. 경고에는 "Hand edits can break a game. Every change is checked before it saves, and names can't change here."라고 적혀 있습니다.
3. 목록에서 섹션을 고르세요(휴대폰에서는 칩 한 줄). 검색창은 모든 섹션에서 값을 한꺼번에 찾습니다.
4. **Fields**(필드)에서 값을 바꾸거나, 원본 데이터를 보려면 **JSON**으로 전환하세요.
5. **Review changes**(변경 사항 검토)를 클릭해 정확히 무엇이 바뀌는지 확인한 다음 **Save changes**(변경 사항 저장)를 클릭하세요.

> **경고:** 직접 편집하면 게임이 손상될 수 있습니다. Marinara는 저장할 때마다 먼저 **Before a State Editor save**(상태 편집기 저장 전)로 표시된 체크포인트를 남기려고 시도합니다([게임이 저장되는 방식](#how-your-game-saves) 참고). 편집이 잘못되면 그 체크포인트를 불러와 되돌리세요. 첫 턴이 아직 저장되지 않은 막 시작한 게임에는 아직 체크포인트로 남길 내용이 없습니다.

작동하지 않는 경우: 편집기가 이유를 알려 주고 초안을 그대로 두므로 고칠 수 있습니다. 편집하는 동안 게임이 같은 데이터를 바꿨다면 게임의 변경을 되돌리지 않도록 저장이 거부됩니다. **Reload**(다시 불러오기)는 게임 쪽 버전을 보여 주고 초안을 버립니다.

바꿀 수 있는 섹션은 **Party Cards**(파티 카드), **Party Sheet**(파티 시트), **NPCs**, **Journal**, **Player Notes**(플레이어 노트), **Inventory**(인벤토리), **Story**(스토리), **Session Summaries**(세션 요약), **World Edits**(세계 편집), **Story Script**(스토리 스크립트), **HUD Widgets**(HUD 위젯)입니다. 섹션은 게임에 그 데이터가 있을 때만 표시되므로, 세계가 없는 게임에는 **World Edits**가 없습니다. **World**(세계), **Maps & Position**(지도 및 위치), **Time, Weather & Morale**(시간, 날씨 및 사기), **Combat**(전투), **Settings**(설정) 같은 섹션에는 **Read-only**(읽기 전용) 표시가 붙습니다. 읽고 검색할 수는 있지만 이 데이터는 게임이 직접 관리합니다. 프롬프트, 이미지, 음악, 주사위 선호 설정은 **Chat Settings**(채팅 설정)에서 바꿉니다.

검사는 다음 규칙을 지킵니다.

- 카드, NPC, 파티, 가방은 이름으로 서로를 찾기 때문에 이름은 바꿀 수 없습니다. 여기서 파티원을 추가하거나 뺄 수도 없습니다.
- NPC의 평판은 -100에서 100 사이입니다.
- **Inventory**에서는 아이템의 수량, 별칭, 소지자, 그리고 착용, 조율, 켜짐 여부를 바꿀 수 있습니다. 묶음을 빼면 그 묶음이 삭제되고, id 없이 묶음을 추가하면 아이템이 추가됩니다.
- **Session Summaries**에서는 세션의 텍스트만 바꿀 수 있습니다.
- **World Edits**에는 이름을 바꾼 장소나 추가한 인물처럼 세계 위에 직접 가한 편집이 들어 있습니다. 세계 자체는 절대 바뀌지 않습니다.

이 창은 Roleplay(롤플레이)의 State Editor와 같은 방식으로 작동합니다. [State Editor](../roleplay/hud-and-trackers.md#the-state-editor)를 참고하세요.

<a id="how-your-game-saves"></a>

## 게임이 저장되는 방식

Game Mode는 자동으로 저장합니다. 세계, 파티, 지도, 인벤토리, 게임 속 시간, 세션 요약은 저장 버튼 없이 플레이하는 동안 보관됩니다.

Marinara는 세션 시작 시점, 세션 종료 시점, 전투가 시작되거나 끝나는 시점, 새로운 장소에 도착한 시점, 그리고 일정한 간격마다 체크포인트도 자동으로 기록합니다. 종류별로 최신 5개를 보관하고 오래된 것은 정리합니다. Game Data 편집기도 저장할 때마다 먼저 체크포인트를 남기려고 시도합니다.

되돌아가려면 다음과 같이 하세요.

1. **Game controls → Checkpoints**(게임 컨트롤 → 체크포인트)를 여세요. 최신순으로 나열됩니다.
2. 원하는 시점의 **Load**(불러오기)를 클릭하세요.

**Load**는 게임을 그 시점으로 되돌립니다. 트래커, 지도, **World Edits**, 이야기, 파티 카드와 시트, NPC, 일지, 내 메모, 인벤토리, 세션 요약, GM의 이야기 계획, HUD 위젯, 시간, 날씨, 사기가 모두 되돌아갑니다. 게임이 되돌아간 지점에는 시스템 메시지가 표시됩니다. 설정은 그대로 유지됩니다. **Delete**(삭제)는 체크포인트를 영구히 지웁니다.

잘못된 턴 하나만 되돌리려면 **Game controls**의 **Retry turn**(턴 재시도)을 사용하거나, 스와이프해 답변의 다른 버전으로 넘기세요.

데이터 사본을 직접 보관하려면 [Marinara 백업과 복원](../data/backup-and-restore.md)을 참고하세요.
