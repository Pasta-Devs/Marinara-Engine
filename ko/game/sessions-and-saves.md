# Game Mode: 세션과 저장 데이터

이 가이드에서는 Marinara Engine이 여러 플레이 세션에 걸쳐 Game Mode(게임 모드)의 진행 상황을 어떻게 관리하는지 설명합니다. 세션을 끝내고 새로 시작하는 방법, **Session History**(세션 기록)에서 지난 세션을 읽는 방법을 다룹니다. **Show Spoilers**(스포일러 보기) 화면과 게임 데이터가 저장되는 방식도 함께 설명합니다.

## 세션이란

Game Mode는 모험을 번호가 붙은 세션으로 나눕니다. 세션은 한 번에 쭉 이어서 플레이한 구간으로, TRPG 모임 하루치와 비슷합니다. 각 세션은 게임 마스터(GM, 게임을 진행하는 AI)가 서술합니다. 세션을 끝내면 GM이 요약을 써 주고, 나중에 다시 읽어 볼 수 있습니다.

첫 세션은 **Session 1**입니다. 이 세션을 끝내고 다시 시작하면 **Session 2**가 만들어지고, 이후로도 같은 방식입니다.

## Session 열기

**Session**(세션)에서 세션을 끝내고, 새 세션을 시작하고, 지난 기록을 읽습니다.

1. 게임 화면이 보이도록 Game Mode 채팅을 새로 시작하거나 기존 채팅을 여세요.
2. **Session** 버튼(깃펜 아이콘)을 클릭하거나 탭하세요. 처음에는 채팅 오른쪽 위 근처에 있으며 다른 곳으로 끌어 옮길 수 있습니다([컨트롤 창과 버튼](../chats/chat-settings.md#control-windows-and-their-buttons) 참고).
3. **Session**이 컴퓨터에서는 창으로, 휴대폰에서는 화면 너비의 패널로 열립니다. 첫 줄에는 **Session**과 함께 현재 세션 번호와 상태가 표시됩니다.
4. **Session History**와 **Journal**(일지) 두 개의 탭이 있습니다. 세션 조작과 설정 공유는 **Session History** 탭에서 합니다.

**Put back in Chat Settings**(채팅 설정으로 되돌리기)로 창을 옮겼다면 Chat Settings 안의 **Session** 섹션을 여세요.

## 게임을 만든 설정 공유하기

Game Mode는 새 캠페인을 만들 때 사용한 설정을 변경 불가능한 스냅샷으로 보관합니다. 덕분에 시작 전에 모든 항목을 일일이 적어 둘 필요가 없습니다. 먼저 플레이해 보고 조합이 괜찮다 싶을 때 나중에 공유하면 됩니다.

1. 공유하려는 Game Mode 캠페인을 여세요.
2. **Session**(깃펜 아이콘 버튼)을 여세요.
3. **Session History** 탭에 그대로 머문 채로 **Initial Game Setup**(초기 게임 설정)을 펼치세요.
4. 저장된 모험, 출연 캐릭터, 모델, 프롬프트, 실제로 적용된 생성 파라미터, 비주얼, 스토리보드, 월드 도구 설정을 확인하세요.
5. **Copy setup**(설정 복사)을 클릭하면 텍스트가 클립보드에 복사되고, **Download .txt**를 클릭하면 공유용 텍스트 파일로 저장됩니다.

복사된 텍스트에는 길게 적어 둔 플레이어 선호 사항과 사용자 지정 GM 지침도 들어갑니다. 이런 항목에 사적인 내용이 있다면 공개하기 전에 먼저 읽어 보세요. 연결 인증 정보, 서버 URL, API 키, 로컬 데이터베이스 ID는 절대 포함되지 않습니다. 캐릭터 카드, 페르소나, 로어북, 모델, 제공자 계정은 참고용으로 이름만 적히고 파일에 함께 담기지는 않습니다. 그래서 설정을 받은 사람은 같은 역할을 하는 항목을 각자 갖추거나 직접 골라야 합니다.

설정 스냅샷 기능이 추가되기 전에 만든 캠페인은 애초에 저장된 적 없는 선호 사항을 되살릴 수 없습니다. 그래서 **Initial Game Setup**은 믿을 수 있는 생성 스냅샷이 있을 때만 표시됩니다.

## 세션 끝내기

지금까지의 이야기를 한 챕터로 마무리하고 GM에게 요약을 맡기고 싶을 때 세션을 끝내세요.

1. **Session**을 열고 **Session History** 탭에 머무르세요.
2. 맨 위에 현재 세션이 **Session N (Current)**로 표시됩니다.
3. 그 줄에서 **End Session**(세션 종료) 버튼(**Show Spoilers** 옆의 작은 사각형 아이콘)을 클릭하세요.
4. **End Session** 창이 열리고 확인을 요청합니다.
5. 원한다면 **What do you want to happen in the next session (optional)?** 입력란에 내용을 적으세요. 최대 5000자까지 입력할 수 있습니다.
6. GM이 알아서 이야기를 이끌게 하려면 이 입력란을 비워 두세요.
7. 창에서 **End Session**을 클릭하면 확정되고, **Cancel**(취소)을 클릭하면 취소됩니다.

확정하면 요약 생성이 시작됩니다. 끝날 때까지 이 화면에서 기다리세요. 처리 중에는 창 제목이 **Ending Session**으로 바뀝니다. 완료되면 그 세션이 종료 상태로 표시되고 기록에 남습니다.

## 새 세션 시작하기

현재 세션이 종료되면 같은 자리의 버튼이 **New Session**(새 세션)으로 바뀝니다.

1. **Session**을 열고 **Session History** 탭으로 이동하세요.
2. 현재 세션 줄에서 **New Session** 버튼(재생 아이콘)을 클릭하세요.
3. GM이 이야기를 이어 갑니다. 직전 세션의 요약과 세션을 끝낼 때 적어 둔 다음 세션 요청을 함께 참고합니다.

## 지난 세션 읽기

**Session History** 탭에는 종료된 세션이 최신순으로 나열됩니다. 아직 끝낸 세션이 하나도 없으면 **No completed sessions yet**이라고 표시됩니다.

각 줄에는 세션 번호, 날짜, 기록된 발견의 개수가 보입니다. 줄을 클릭하면 펼쳐집니다. 펼친 세션에는 다음 필드가 표시될 수 있습니다.

- **Summary**(요약): 세션에서 벌어진 일.
- **Resume Point**(재개 지점): 다음 세션이 이어질 지점.
- **Party Dynamics**(파티 관계): 파티원들 사이의 관계.
- **Key Discoveries**(주요 발견): 중요한 사실, 반전, 밝혀진 내용.
- **Character Moments**(캐릭터 모먼트): 캐릭터가 돋보인 장면.
- **Little Details To Recall**(기억할 작은 세부 정보): 사소한 습관, 약속, 자잘한 세부 정보.
- **NPC Updates**(NPC 업데이트): NPC(플레이어가 아닌 캐릭터로, GM이 조종합니다)의 변화.
- **Next Session Request**(다음 세션 요청): 세션을 끝낼 때 남긴 메모.
- **Stats Snapshot**(스탯 스냅샷)과 **Party Status**(파티 상태): 저장된 수치와 파티 상태.

### 완료한 세션 다시 보기

완료된 세션은 캠페인을 바꾸지 않고 다시 볼 수 있습니다.

1. **Session History**에서 종료된 세션을 펼치세요.
2. **Replay Session**(세션 재생)을 클릭하세요.
3. **Next**(다음)와 **Next turn**(다음 턴)을 눌러 원래의 서술과 대사를 차례로 넘겨 보세요.
4. 다시 보기가 선택지에 이르면 원래 세션에서 골랐던 항목 하나만 활성화됩니다. 그 항목을 클릭하면 기록된 경로를 따라 계속 진행합니다.
5. 다 봤으면 화면 위쪽의 닫기 버튼이나 **Return to current session**(현재 세션으로 돌아가기)을 클릭하세요.

다시 보기는 읽기 전용입니다. GM을 호출하지 않고, 메시지를 만들지 않으며, 인벤토리나 스탯을 바꾸거나 일지에 반영하거나 체크포인트를 복원하지도 않습니다. 다시 보기 기능이 생기기 전에 만든 세션도 저장해 둔 텍스트, 인라인 연출, 선택지, 사용 가능한 에셋은 그대로 활용합니다. 다만 예전 턴에는 그 턴을 플레이할 당시 저장되지 않은 장면 연출이 빠져 있을 수 있습니다.

### 지난 세션 편집하기

종료된 세션의 기록은 직접 손볼 수 있습니다. 이후 세션이 내용을 제대로 기억하게 하려면 이렇게 고치세요.

1. 바꾸려는 세션을 펼치세요.
2. **Edit Details**(세부 정보 편집)를 클릭하세요.
3. 원하는 필드를 고친 다음 **Save Details**(세부사항 저장)를 클릭하세요. 고친 내용을 버리려면 **Cancel**을 클릭하세요.

펼친 세션에는 버튼이 두 개 더 있습니다.

- **Regenerate**(재생성): 그 세션의 AI 결론을 다시 만듭니다. 요약을 비롯해 항목의 모든 필드가 새로 쓰이므로 **Edit Details**로 고친 내용은 사라집니다.
- **Update Plot Arcs**(플롯 아크 업데이트): 그 세션에서 일어난 일을 반영해 GM의 숨은 이야기 계획을 다시 정리하도록 AI에 요청합니다. 이 계획은 **Show Spoilers** 화면에 보이는 **Story Arc**(스토리 아크), **Plot Twists**(반전), **Party Arcs**(파티 아크)입니다.

**Regenerate Lorebook**(로어북 재생성) 버튼은 가장 최근에 종료한 세션에만, 그리고 선택 기능인 Lorebook Keeper를 켜 두었을 때만 나타납니다. 로어북은 AI가 꺼내 쓸 수 있도록 세계 설정을 모아 둔 것입니다.

## Show Spoilers 화면

**Show Spoilers**를 누르면 현재 세션에 대한 GM의 숨은 기록이 드러납니다. 평소 플레이 중에는 보이지 않는 내용입니다. 읽으면 이야기의 반전이 미리 밝혀질 수 있습니다.

1. **Session**을 열고 **Session History** 탭으로 이동하세요.
2. 현재 세션 줄에서 **Show Spoilers**(눈 아이콘)를 클릭하세요.
3. GM의 비공개 상태가 표시됩니다.

이 화면에는 다음 항목이 표시될 수 있습니다.

- **World Overview**(세계 개요): 세계관의 큰 그림.
- **Story Arc**: 계획해 둔 이야기의 방향.
- **Plot Twists**: GM이 아껴 두고 있는 반전.
- **Party Arcs**: 파티원을 위해 준비한 여정.
- **Maps**(지도), **NPCs**, **Character Cards**(캐릭터 카드): 저장된 게임 데이터.

기록을 다시 감추려면 같은 버튼을 클릭하세요. 이때 버튼 이름은 **Hide Spoilers**(스포일러 가리기)로 바뀌어 있습니다.

이 비밀 내용은 직접 고칠 수도 있습니다. 게임 마스터용 치트 패널처럼 쓰는 셈입니다. **Edit Spoilers**(스포일러 편집)를 클릭해 내용을 바꾼 다음 **Save Spoilers**(스포일러 저장)를 클릭하세요. 일부 필드는 구조화된 텍스트 형식인 JSON으로 표시됩니다. 형식이 어긋난 JSON은 저장되지 않으니, JSON 필드는 형식을 아는 경우에만 고치세요.

## 게임이 저장되는 방식

Game Mode는 진행 상황을 자동으로 저장합니다. 저장 버튼을 누를 필요가 없습니다. 세계, 파티, 지도, 인벤토리, 게임 속 시간, 세션 요약은 플레이하는 동안 알아서 보관됩니다.

앱은 뒤에서 체크포인트도 자동으로 남깁니다. 세션 시작 시점, 세션 종료 시점, 전투가 시작되거나 끝나는 시점에 체크포인트를 기록합니다. 다만 지금은 이 체크포인트를 앱에서 살펴보거나 복원할 화면이 없습니다. 그러니 예전 체크포인트를 불러와 턴을 되돌리는 방법에 기대지 마세요.

데이터 사본을 직접 보관하려면 앱의 백업 도구를 사용하세요. [Marinara 백업과 복원](../data/backup-and-restore.md)을 참고하세요.
