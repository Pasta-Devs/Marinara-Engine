# Game Mode: HUD 위젯

HUD 위젯은 게임 화면 좌우 가장자리에 붙는 작은 패널입니다. 체력 막대, 소지금 카운터, 동료의 호감도 같은 것을 추적합니다. HUD는 heads-up display의 약자입니다. 위젯은 게임마다 따로 있으며, Roleplay(롤플레이)의 HUD 트래커와는 별개입니다([Roleplay HUD와 트래커](../roleplay/hud-and-trackers.md) 참고).

한 게임에는 위젯을 전부 합쳐 최대 4개까지 둘 수 있으며, 왼쪽과 오른쪽에 원하는 대로 나눌 수 있습니다. 위젯은 해당 게임에서 **Custom HUD Widgets**(커스텀 HUD 위젯)가 켜져 있을 때만 쓰입니다. 이 옵션은 설정 마법사에서 기본으로 켜져 있습니다. 그러면 게임 마스터(GM)가 세계를 만들면서 시작 위젯 세트를 설계합니다.

## 위젯 종류

GM은 위젯을 만들 때마다 종류를 고릅니다. 위젯을 직접 만들 때는 종류를 직접 고를 수 있습니다.

| 위젯 종류 | 표시 내용 |
| --- | --- |
| **Progress Bar**(진행 막대) | 최댓값 대비 현재 값을 보여 주는 가로 막대입니다. 체력이나 기력에 알맞습니다. |
| **Gauge**(게이지) | 최댓값 대비 현재 값을 보여 주는 반원형 계기판입니다. |
| **Relationship Meter**(관계도 막대) | 단계 표시와 이름이 붙은 막대입니다. NPC의 호감도나 유대감에 알맞습니다. |
| **Counter**(카운터) | 소지금, 경과 일수, 처치 수처럼 큰 숫자 하나를 보여 줍니다. |
| **Stat Block**(스탯 블록) | 이름과 값이 짝을 이루는 작은 표입니다. STR, DEX 같은 능력치나 상태를 나타내는 단어에 알맞습니다. |
| **List**(목록) | 진행 중인 목표처럼 짧은 항목을 글머리 기호로 나열합니다. |
| **Inventory Grid**(인벤토리 격자) | 아이템 칸을 격자로 배열합니다. 분류 탭과 아이템 개수도 넣을 수 있습니다. |
| **Timer**(타이머) | 분과 초로 표시하는 카운트다운 시계입니다. 실시간으로 줄어들게 할 수 있습니다. |

## 게임 시작 전에 위젯 검토하기

사용자 지정 위젯이 있으면 게임 화면의 **Start Game**(게임 시작) 아래에 **Review Starting Widgets**(시작 위젯 검토) 버튼이 있습니다. 이 버튼을 클릭하면 시작하기 전에 **Review Starting Widgets** 창이 열립니다. 창에는 시작 위젯이 모두 나열되므로, 게임에 확정되기 전에 손볼 수 있습니다.

1. 위젯의 **Edit**(편집)를 눌러 시작 값을 바꾸거나 **Stat Block**의 필드 이름을 바꾸세요.
2. 필요 없는 위젯은 **Remove**(제거)를 눌러 없애세요.
3. **Start Game**을 눌러 보이는 그대로의 위젯으로 게임을 시작하세요. 시작하지 않고 창을 닫으려면 **Back**(뒤로)을 누르세요.

진행 중인 게임에서 새 세션을 시작할 때도 비슷한 창인 **Prepare Next Session Widgets**(다음 세션 위젯 준비)가 나타납니다. 이 창에는 **Start Game** 대신 **Start Next Session**(다음 세션 시작)이, **Back** 대신 **Cancel**(취소)이 있습니다.

## 플레이 중에 위젯 고치기

GM은 이야기 전개에 맞춰 위젯 값을 갱신합니다. 갱신을 빠뜨렸다면 위젯을 직접 고치세요.

1. 화면 왼쪽이나 오른쪽 가장자리에서 위젯 패널을 찾으세요.
2. 위젯 머리글의 연필(**Edit**) 버튼을 클릭하세요.
3. 편집 창에서 값을 바꾸세요. 예를 들어 막대라면 **Maximum value**(최대값)를 바꿉니다.
4. **Save Changes**(변경 사항 저장)를 클릭하세요.

위젯 머리글을 클릭하면 본문이 접히거나 펼쳐집니다.

## 패널 옮기기와 고정하기

위젯 패널은 기본적으로 제자리에 고정되어 있습니다. 패널마다 머리글에 자물쇠 아이콘이 있습니다.

1. 자물쇠 아이콘을 클릭해 고정을 푸세요. 옅은 테두리가 생기면 옮길 수 있는 상태입니다.
2. 패널을 원하는 자리로 끌어다 놓으세요.
3. 자물쇠 아이콘을 다시 클릭해 고정하세요.

패널을 기본 자리로 되돌리려면 자물쇠 아이콘을 더블 클릭하거나, 아이콘에 초점이 있는 상태에서 <kbd>R</kbd>을 누르세요. 각 패널은 게임별로 위치와 고정 상태를 기억합니다. 배치는 다른 게임으로 이어지지 않습니다.

휴대폰에서는 위젯이 패널 대신 작은 알약 모양으로 표시됩니다. 알약을 탭하면 해당 위젯이 열리고, X를 탭하면 닫힙니다.

## 직접 위젯 만들기

GM에게 맡기지 않고 위젯을 직접 설계할 수도 있습니다. 수동 편집기는 다음 두 곳 중 하나에서 여세요.

- 설정 마법사: **Custom HUD Widgets**를 켠 다음 **Build Widget Setup**(위젯 설정 빌드)을 켜세요. 아래에 편집기가 나타납니다.
- 진행 중인 게임: **Chat Settings**(채팅 설정)를 연 다음 **Widgets**(위젯) 섹션을 여세요.

1. 드롭다운에서 위젯 종류를 고르고 **Add**(추가)를 누르세요.
2. **Icon**(아이콘), **Label**(레이블), **Type**(타입), **Side**(위치), **Accent**(강조)를 지정하세요. **Icon**은 짧은 기호나 이모지, **Side**는 **Left HUD**(왼쪽 HUD) 또는 **Right HUD**(오른쪽 HUD), **Accent**는 색입니다.
3. 그 종류의 필드를 채우세요. 막대는 **Value**(값)와 **Max**(최대), 카운터는 **Count**(개수), 인벤토리 격자는 **Slots**(슬롯)와 **Contents**(내용), 타이머는 **Seconds**(초)와 **Running**(실행 중)을 씁니다.
4. **Chat Settings**에서는 **Save Widgets**(위젯 저장)를 눌러 변경 내용을 적용하세요. **Reset**(초기화)은 저장하지 않은 편집 내용을 되돌립니다.

편집기에는 허용된 4개 중 몇 개를 썼는지 표시됩니다.

## 가져오기와 내보내기로 위젯 주고받기

위젯 배치를 파일로 저장해 두었다가 다른 게임에 불러올 수 있습니다. 설정 마법사와 **Chat Settings**의 **Widgets** 섹션 양쪽에 이 버튼이 있습니다.

1. **Export Widgets**(위젯 내보내기)를 눌러 위젯을 JSON 파일(일반 텍스트로 된 데이터 형식)로 다운로드하세요.
2. 다른 게임에서 **Import Widgets**(위젯 가져오기)를 누르고 그 파일을 고르세요.
3. **Chat Settings**에서는 **Save Widgets**를 눌러 불러온 위젯을 적용하세요.
