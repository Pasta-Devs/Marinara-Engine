# Game Mode: MRPG 클래스

새 Experience로 만든 게임을 포함해 모든 새 게임은 **MRPG**(Marinara RPG) 클래스로 플레이합니다. 파티원마다 클래스가 있고, 파티가 이긴 전투에서 레벨을 올리며, 성장하면서 새 클래스를 잠금 해제합니다. 이 페이지는 클래스 선택, 스탯의 의미, 레벨과 승급 방식, 캐릭터 시트를 설명하는 플레이어용 가이드입니다.

다음 두 종류의 게임에서는 MRPG 클래스를 사용하지 않습니다.

- **Legacy 게임.** MRPG 클래스가 생기기 전에 만든 게임은 전환하기로 할 때까지 **Legacy** 시트를 유지합니다. [Legacy 게임을 MRPG로 전환하기](#move-a-legacy-game-to-mrpg)를 참고하세요.
- **규칙 집합 게임.** 5e (SRD 5.1)처럼 규칙 집합으로 플레이하는 게임은 규칙 집합 자체의 시트를 사용합니다. [규칙 집합으로 플레이하기](rulesets.md)를 참고하세요.

MRPG 클래스에서 전투가 진행되는 방식은 [MRPG 게임의 전투](combat.md#battles-in-an-mrpg-game)를 참고하세요.

<a id="how-it-works"></a>

## 작동 방식

- 캐릭터마다 8가지 **트리** 중 2가지를 훈련합니다. 하나는 직접 고르는 **주 트리**이고, 다른 하나는 성향으로 열리는 **자매 트리**입니다.
- 게임을 시작할 때 주 트리의 기본 클래스로 레벨 1에서 시작합니다.
- 전투에서 이기면 경험치를 얻습니다. 캐릭터의 스탯은 **활성 클래스**에서 나오며, 그 클래스의 레벨이 오를수록 상승합니다.
- 클래스 레벨 10에서는 고급 클래스로, 클래스 레벨 20에서는 마스터 클래스로 승급할 수 있습니다. 레벨은 30에서 멈춥니다.
- 전투 밖에서는 잠금 해제한 어떤 클래스로든 바꿀 수 있고, 훈련한 다른 클래스의 스킬을 최대 4개까지 가져갈 수 있습니다.

<a id="the-eight-trees"></a>

## 8가지 트리

| 트리 | 열 | 전투 방식 | 다음 성향의 자매 트리 |
| --- | --- | --- | --- |
| **Blade** | 전열 | 적과 정면으로 맞서는 무기 전사입니다. | Reckless |
| **Guard** | 전열 | 아군이 받을 공격을 대신 맞고 적이 자신에게 오게 하는 방패병입니다. | Protective, Honourable |
| **Scout** | 전열 | 공격하고, 피하고, 훔치는 빠른 기회주의자입니다. | Opportunistic, Cowardly |
| **Marksman** | 후열 | 대상에 맞춰 탄약을 바꾸는 궁수입니다. | Patient, Cautious |
| **Channeler** | 후열 | 불, 얼음, 번개, 바람, 나무, 땅, 물, 금속을 다루는 마법사입니다. | Arrogant, Methodical |
| **Hexer** | 후열 | 적을 약화하고 HP를 흡수하는 저주술사입니다. | Cruel |
| **Mender** | 후열 | 파티를 쓰러지지 않게 지키고 질병과 상태를 치료하는 치유사입니다. | Supportive |
| **Herald** | 후열 | 명령을 내리고 파티를 강하게 만드는 노래를 부르는 전투 지휘관입니다. | Coordinated, Disciplined |

여러 트리를 고루 갖춘 파티가 가장 유리합니다. 후열을 근접 공격하면 피해가 절반이므로, 후열 트리는 전열이 전선을 지켜 주어야 합니다([열](combat.md#rows) 참고).

<a id="classes-in-each-tree"></a>

### 트리별 클래스

트리마다 클래스가 7개 있습니다. 기본 클래스는 클래스 레벨 10에서 고급 클래스 2개 중 하나로 승급하고, 각 고급 클래스는 클래스 레벨 20에서 마스터 클래스로 승급합니다. 마지막 열의 세 번째 계통은 **Pure** 캐릭터에게만 열립니다. 성향이 자체 주 트리를 다시 가리켜 자매 트리가 없고 그 트리 하나만 훈련하는 캐릭터입니다.

| 트리 | 기본 클래스 | 고급(10) → 마스터(20) | Pure 전용 |
| --- | --- | --- | --- |
| Blade | Blade | Duelist → Headsman; Bloodsworn → Cleaver | Weaponmaster → Paragon of Arms |
| Guard | Guard | Sentinel → Stonewall; Warden → Elder Warden | Aegis → Bulwark |
| Scout | Scout | Rogue → Phantom; Skirmisher → Harrier | Shade → Shroud |
| Marksman | Marksman | Sharpshooter → Farshot; Tracker → Huntsmaster | Artillerist → Siegebreaker |
| Channeler | Channeler | Elementalist → Stormcaller; Rune Scholar → Runelord | Astral Adept → Starweaver |
| Hexer | Hexer | Witch → Carrion Lord; Dreamcaller → Dreamweaver | Nullifier → Void Sovereign |
| Mender | Mender | Cleric → Saint; Apothecary → Panacean | Lifebinder → Lightbearer |
| Herald | Herald | Cantor → Maestro; Field Captain → Marshal | Standard-Bearer → Lodestar |

캐릭터 시트의 **Classes**(클래스) 탭에는 모든 클래스의 설명과 각 스킬을 배우는 클래스 레벨이 표시됩니다.

<a id="choose-a-characters-trees"></a>

## 캐릭터의 트리 고르기

**주 트리.** 게임을 시작하기 전에 라이브러리 캐릭터나 페르소나의 **Stats**(스탯) 탭에 있는 **Game Mode**(게임 모드) 섹션에서 고르세요([카드의 MRPG 선택 사항](../characters/colors-and-stats.md#mrpg-picks-on-a-card) 참고). **Auto**(자동)로 두면 캐릭터의 설명에서 트리를 가져오고, 게임 안에서는 클래스와 능력도 함께 읽습니다. 카드에 트리가 하나도 언급되지 않은 캐릭터는 Blade로 시작합니다. 캐릭터가 첫 경험치를 얻기 전까지는 게임 안에서도 시트의 **Classes** 탭에 있는 **Main tree**(주 트리)에서 바꿀 수 있습니다.

**강한 스탯과 약한 스탯.** 같은 카드 섹션에서 캐릭터가 **Strong in**(강한 능력치)인 스탯을 최대 2개, **Weak in**(약한 능력치)인 스탯을 1개 고를 수 있습니다. 게임마다 각 캐릭터의 숨겨진 성장률을 새로 굴리며, 이 선택은 그 굴림에 영향을 줍니다. 숫자를 직접 정하지는 않습니다.

**자매 트리.** 게임이 캐릭터의 게임 카드를 만들 때 Game Master는 Description(설명)과 성격에서 전투에 임하는 방식인 성향을 읽습니다. 그 성향으로 위 표의 자매 트리가 열립니다. 특정 자매 트리를 원한다면 그 성향을 염두에 두고 Description을 작성하세요. 시트에는 자매 트리 옆에 성향이 표시됩니다. 예를 들면 "from Cautious"입니다. 나중에 이야기에서 캐릭터의 성향이 바뀔 수 있지만 자매 트리는 시작할 때 정해진 그대로 유지됩니다.

Reckless Blade처럼 성향으로 자체 주 트리가 열리는 캐릭터는 **Pure**입니다. 트리 하나만 훈련하며 그 트리의 Pure 전용 계통이 열립니다.

<a id="what-the-stats-mean"></a>

## 스탯의 의미

| 스탯 | 하는 일 |
| --- | --- |
| **HP** | 체력입니다. 0이 되면 쓰러집니다. 전투의 HP 막대는 이 스탯보다 크며 레벨과 함께 늘어납니다. |
| **Strength** (Str) | 무기 피해입니다. Stamina도 올립니다. |
| **Magic** (Mag) | 주문과 지팡이, 완드, 포커스의 피해 및 치유 위력입니다. MP도 정합니다. |
| **Skill** (Skl) | 명중률과 치명타입니다. |
| **Speed** (Spd) | 캐릭터가 행동하는 빈도와 회피 능력입니다. Stamina도 올립니다. |
| **Defense** (Def) | 무기와 그 밖의 물리 공격으로 받는 피해를 줄입니다. |
| **Resistance** (Res) | 마법으로 받는 피해를 줄입니다. |
| **Luck** (Lck) | 명중률과 회피를 조금 올리고 치명타를 막는 데 도움을 줍니다. |

스킬에는 다음 두 자원을 사용합니다.

- **MP**는 마법에 사용합니다. Magic의 2배에 8을 더한 값이며, 전투 중에는 회복되지 않습니다.
- **Stamina** (ST)는 그 밖의 모든 스킬에 사용합니다. Strength에 Speed의 절반과 10을 더한 값이며, 턴마다 일부가 회복되고 방어한 턴에는 더 많이 회복됩니다.

전투 밖 스킬 판정에도 같은 스탯을 사용합니다. [스킬 판정](#skill-checks)을 참고하세요.

<a id="levels-and-experience"></a>

## 레벨과 경험치

**경험치.** 전투에서 이기면 항복하거나 달아난 적을 포함해 파티가 물리친 적마다 경험치를 얻습니다. 절반은 전투에 참가한 모두에게 똑같이 나누고, 나머지 절반은 피해, 치유, 지원 등 각자 기여한 만큼 나눕니다. 캐릭터보다 레벨이 낮은 적은 경험치를 적게 주고 높은 적은 더 많이 주며, 파티 평균보다 레벨이 낮은 캐릭터는 경험치를 절반만큼 더 얻습니다. 패배하거나 달아난 전투에서는 경험치를 얻지 못합니다.

**캐릭터 레벨.** 경험치 100마다 레벨이 하나 오르며 최대 30까지입니다. 전투 화면의 종료 패널인 **What the party gained**(파티가 얻은 것)에는 경험치, 오른 레벨, 상승한 스탯이 표시됩니다.

**클래스 레벨.** 활성 클래스는 같은 경험치를 자체 클래스 레벨에 받습니다. 클래스 레벨이 캐릭터 레벨의 절반보다 낮으면 경험치를 2배로 받아 늦게 시작한 클래스가 따라잡을 수 있습니다. 캐릭터의 스탯은 활성 클래스와 그 클래스 레벨에서 나옵니다. 클래스 레벨이 오를 때마다 클래스의 성장률과 캐릭터의 숨겨진 적성에 따라 모든 스탯의 상승 여부를 굴리며, 매번 적어도 2가지 스탯이 오릅니다.

따라서 새로 시작한 클래스의 전투 능력은 레벨 1 수준입니다. 감당할 수 있는 전투 사이에 새 클래스로 바꾸고, 지금까지 키운 힘이 필요할 때는 다시 돌아가세요.

**승급.** 클래스 레벨 10이 되면 고급 클래스가 열리고, 클래스 레벨 20이 되면 마스터 클래스가 열립니다. 종료 패널에는 **A promotion is open**(승급 가능)이 표시됩니다. **Classes** 탭에서 **Promote to**(승급 대상)와 클래스 이름을 눌러 승급하세요. 승급한 클래스는 승급 전 클래스의 클래스 레벨에서 시작하고 일회성 스탯 보너스를 더하며, 남는 가져오기 슬롯을 그 클래스가 거쳐 온 클래스의 액티브 스킬로 채웁니다.

성장률은 숨겨져 있습니다. **Debug**(디버그)를 켜면 **Status**(상태) 탭에 각 스탯이 오를 정확한 확률이 표시됩니다.

<a id="switch-classes-and-carry-skills"></a>

## 클래스 바꾸기와 스킬 가져오기

클래스는 전투 밖에서 **Classes** 탭을 통해 바꿉니다. 클래스를 고르면 스킬과 전환할 때 잃는 것이 표시됩니다. 그런 다음 아직 훈련하지 않은 클래스라면 **Take up**(시작하기), 전에 훈련한 클래스라면 도달한 클래스 레벨로 돌아가는 **Switch to**(전환)를 고르세요.

캐릭터는 활성 클래스의 스킬과 훈련한 다른 클래스에서 **가져온** 스킬을 최대 4개까지 사용합니다. **Skills**(스킬) 탭의 **Carry from other classes**(다른 클래스에서 가져오기)에서 고르세요. 가져온 스킬은 캐릭터 자체 스탯으로 사용합니다. Guard의 Cover처럼 트리 전체에 속하는 스킬도 있으며, 그 트리의 모든 클래스는 슬롯을 쓰지 않고 해당 스킬을 유지합니다. 클래스를 바꾸면 사용하던 스킬을 잃게 될 때는 시트에서 먼저 경고하므로 가져올 수 있습니다.

<a id="the-character-sheet"></a>

## 캐릭터 시트

**Character Profiles**(캐릭터 프로필)에서 파티원의 시트를 여세요. 다음 4개 탭이 있습니다.

- **Status**: 레벨, 경험치, 활성 클래스, 장비를 포함한 스탯, 전투를 시작할 때의 HP, MP, Stamina입니다. **Row**(열)는 Turn-Based 전투에서 전열과 후열 중 어디에 설지 정하며, 클래스마다 기본 열이 있습니다.
- **Classes**: 두 트리와 그 안의 모든 클래스, 잠금 해제된 항목, 각 클래스의 요구 사항, 승급입니다.
- **Skills**: 활성 클래스의 스킬과 가져온 스킬 및 비용입니다.
- **Gear**(장비): **Weapon**(무기), **Armour**(방어구), **Accessory**(장신구) 슬롯 2개입니다. 파티가 지니고 있고 해당 클래스가 쓸 수 있는 장비로 채웁니다. 각 장비는 착용하기 전에 스탯을 표시합니다. 무기나 방어구 슬롯이 비어 있으면 해당 레벨에서 클래스의 표준 장비로 싸웁니다.

무기에 따라 공격에 쓰는 스탯이 달라집니다. 지팡이, 완드, 포커스는 Magic으로 Resistance를 공격하고, 그 밖의 무기는 Strength로 Defense를 공격합니다.

**길들인 동료.** Tracker는 전투에서 약해진 야수를 길들일 수 있습니다. 길들인 야수는 **Status** 탭에 표시되는 동료가 되며 최대 8마리까지 둘 수 있습니다. 활성 동료는 Tracker나 Huntsmaster 클래스가 활성 상태일 때 자신이 가장 강한 스탯을 올리며, 레벨이 높고 elite인 야수일수록 더 많이 올립니다. 마구간이 가득 차면 새 동료를 두기 위해 하나를 풀어 주세요. 동료는 전투 밖에서 바꿉니다.

**영구 사망.** 마법사의 **World** 단계에 있는 설정 옵션인 **Permadeath**(영구 사망, 기본 꺼짐)를 켜면 전투에서 쓰러진 파티원을 전투가 끝나기 전에 구하지 못했을 때 영원히 잃습니다. 꺼져 있으면 쓰러진 파티원은 전투 뒤 다시 일어납니다.

<a id="skill-checks"></a>

## 스킬 판정

전투 밖 판정은 캐릭터의 활성 클래스가 부여하는 MRPG 스탯을 읽습니다. Stealth는 Speed, Persuasion은 Luck처럼 스킬마다 스탯 하나를 사용합니다. 전체 목록과 각 스탯이 주는 보너스는 [주사위와 스킬 판정](dice-and-skill-checks.md#how-the-result-is-decided)을 참고하세요.

## 새 파티원과 공유 게임

**진행 중인 게임에 합류하는 캐릭터.** 게임이 시작된 뒤 합류한 동료는 Game Master가 부여한 레벨로 들어옵니다. 대부분 낮은 레벨에서 시작하며, 노련한 전사는 파티와 비슷한 레벨에서 시작할 수 있습니다. Game Master는 빠르게 따라잡을 원석 같은 재능에 일부 스탯의 빠른 성장을 주거나, 이미 제법 능숙한 캐릭터에 더 좋은 시작 스탯을 줄 수도 있습니다. Game Master가 아무 설명도 하지 않은 새 파티원은 레벨 1에서 시작합니다.

**공유 게임의 게스트.** 게스트마다 방에 참가할 때 이름, 설명, Game Master에게 전할 **캐릭터 콘셉트**, 카드와 같은 **Game Mode** 선택 사항(시작 트리, 강한 스탯, 약한 스탯)을 입력해 자신의 캐릭터를 만듭니다. 자신의 페르소나 하나를 고르면 그 내용으로 이 항목들이 채워집니다. 캐릭터 콘셉트에는 캐릭터가 어떤 인물인지, 이야기 속에 어떻게 등장하기를 바라는지 Game Master에게 알릴 내용을 적으세요. Game Master는 캐릭터를 이야기에 어우러지게 하고 자매 트리를 고릅니다.

- **새 게임.** 호스트와 게스트 모두 레벨 1에서 시작합니다.
- **진행 중인 게임.** Game Master는 다른 새 파티원과 마찬가지로 게스트의 시작 레벨, 성장률, 스탯도 정합니다.
- **돌아온 게스트.** 게스트가 떠나도 캐릭터는 레벨, 장비, 길들인 야수와 함께 게임에 남습니다. 플레이어가 없는 동안 캐릭터는 전투에 참여하지 않고 경험치도 얻지 않으며 장면에서도 제외됩니다. 게스트가 돌아오면 떠날 때의 레벨로 같은 캐릭터를 플레이합니다.

각 플레이어의 스킬 판정은 자신의 캐릭터 스탯을 읽습니다.

<a id="move-a-legacy-game-to-mrpg"></a>

## Legacy 게임을 MRPG로 전환하기

Legacy 게임은 원하는 동안 계속 Legacy 시트를 유지합니다. 전환하려면 **Journal**(일지)을 열고 **All**(전체) 탭에서 **MRPG classes**(MRPG 클래스) 카드를 찾으세요. **Upgrade**(업그레이드)를 선택하세요.

카드는 파티원마다 다음을 표시합니다.

- **클래스.** 라이브러리 카드에서 고른 트리, 또는 Legacy 클래스에서 가져온 시작 트리입니다. 바꿀 수 있습니다.
- **자매 트리.** 성향으로 열리는 트리입니다. 아직 성향이 없는 캐릭터는 업그레이드할 때 Description(설명)에서 성향을 가져옵니다.
- **장비.** 캐릭터가 지닌 각 Legacy 무기와 방어구, 그리고 변환될 MRPG 장비입니다. 그대로 둘 장비는 체크박스를 해제하세요.

**Upgrade the party**(파티 업그레이드)로 확정하면 다음과 같이 처리됩니다.

- 모든 파티원은 시작 클래스의 최고 수준인 레벨 10에서 시작하며, 레벨이 오를 때와 같은 방식으로 각 레벨의 스탯을 굴립니다. 첫 승급이 즉시 열립니다.
- 카드의 클래스가 MRPG 클래스로 바뀝니다. Legacy 클래스와 능력은 카드의 **Before the upgrade**(업그레이드 전) 메모로 옮겨져 이야기가 계속 그 내용을 알 수 있습니다. Legacy 스탯도 카드에 남지만 판정과 전투에서는 더 이상 사용하지 않습니다.
- 전환을 승인한 무기와 방어구는 각각 대응하는 MRPG 장비가 되고 이름을 유지하며, 클래스가 착용할 수 있으면 착용합니다.

> **경고:** 업그레이드는 되돌릴 수 없습니다. MRPG 클래스로 전환한 게임은 Legacy 시트로 돌아갈 수 없습니다.

전투 중에는 업그레이드가 제공되지 않습니다. 먼저 전투를 끝내세요. 규칙 집합으로 플레이하는 게임은 업그레이드할 수 없으며 규칙 집합의 시트를 유지합니다.
