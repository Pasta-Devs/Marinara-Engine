# Game Mode: MRPG 클래스

새 Experience로 만든 게임을 포함해 모든 새 게임은 **MRPG**(Marinara RPG) 클래스로 플레이합니다. 파티원마다 클래스가 있고, 전투에서 레벨을 올리며, 성장하면서 새 클래스를 잠금 해제합니다. MRPG 클래스가 생기기 전에 만든 게임은 전환하기로 할 때까지 **Legacy** 시트를 유지합니다([Legacy 게임을 MRPG로 전환하기](#move-a-legacy-game-to-mrpg) 참고).

5e (SRD 5.1)처럼 규칙 집합으로 플레이하는 게임은 규칙 집합 자체의 시트를 사용하며, MRPG 클래스가 적용되지 않습니다.

<a id="classes-and-trees"></a>

## 클래스와 트리

트리는 **Blade**, **Guard**, **Scout**, **Marksman**, **Channeler**, **Hexer**, **Mender**, **Herald**까지 8가지입니다. 캐릭터마다 그중 2가지를 훈련합니다.

- **주 트리.** 시트에서 고릅니다. 라이브러리 캐릭터나 페르소나 카드의 **Game Mode**(게임 모드) 섹션에서 고를 수 있습니다. 고르지 않으면 캐릭터의 클래스와 능력에서 가져옵니다.
- **보조 트리.** 캐릭터가 게임을 시작할 때의 성향으로 열립니다. 성향이 자체 주 트리를 가리키는 캐릭터는 그 트리 하나만 훈련하며, 한 트리만 고수하는 캐릭터에게만 열리는 클래스에 도달할 수 있습니다.

각 트리는 기본 클래스에서 시작합니다. 클래스 레벨 10과 20에서 승급하며, 레벨은 30에서 멈춥니다. 캐릭터는 훈련한 다른 클래스의 스킬을 최대 4개까지 가져갈 수 있습니다. 클래스는 전투 밖에서 캐릭터 시트를 통해 바꿉니다. 능력치는 활성 클래스를 따릅니다.

<a id="the-character-sheet"></a>

## 캐릭터 시트

파티 목록에서 파티원의 시트를 여세요. **Status**(상태), **Classes**(클래스), **Skills**(스킬), **Gear**(장비) 탭이 있습니다. 성장률은 숨겨져 있습니다. **Debug**(디버그)를 켜면 정확한 성장률이 표시됩니다.

파티가 전투에서 이기면 파티원의 레벨이 오릅니다. 패배하거나 도망친 전투에서는 경험치를 얻지 못합니다. 설정 옵션인 **Permadeath**(영구 사망)를 켜면 전투에서 쓰러진 파티원을 전투가 끝나기 전에 구하지 못했을 때 영원히 잃습니다.

<a id="skill-checks"></a>

## 스킬 판정

전투 밖 판정은 캐릭터의 MRPG 능력치를 읽습니다. 각 스킬이 어떤 능력치를 쓰는지는 [주사위와 스킬 판정](dice-and-skill-checks.md#how-the-result-is-decided)을 참고하세요.

<a id="newcomers-to-the-party"></a>

## 새 파티원

게임이 시작된 뒤 합류한 캐릭터는 Game Master가 부여한 레벨로 들어옵니다. 대부분의 새 파티원은 낮은 레벨에서 시작하며, 노련한 전사는 파티와 비슷한 레벨에서 시작할 수 있습니다. Game Master는 새 파티원에게 다음 특성을 줄 수도 있습니다.

- 일부 능력치의 **빠른 성장**. 빠르게 따라잡을 원석 같은 재능에 사용합니다.
- **더 좋은 시작 능력치**. 이미 제법 능숙한 캐릭터에 사용합니다.

캐릭터가 합류할 때 Game Master가 이를 결정합니다. 아무 설명이 없는 새 파티원은 레벨 1에서 시작합니다.

<a id="playing-with-others"></a>

## 다른 사람과 플레이하기

공유 게임에서는 게스트마다 방에 참가할 때 이름, 설명, Game Master에게 전할 **캐릭터 콘셉트**, 페르소나와 같은 **Game Mode** 선택 사항(시작 트리, 강한 능력치, 약한 능력치)을 입력해 자신의 캐릭터를 만듭니다. 자신의 페르소나 하나를 고르면 그 내용으로 이 항목들이 채워집니다. 캐릭터 콘셉트에는 캐릭터가 어떤 인물인지, 이야기 속에 어떻게 등장하기를 바라는지 Game Master에게 알릴 내용을 적습니다.

그런 다음 Game Master는 캐릭터를 이야기에 어우러지게 하고 자매 트리를 고릅니다.

- **새 게임.** 호스트와 게스트 모두 레벨 1에서 시작합니다.
- **이미 진행 중인 게임.** Game Master는 게스트의 시작 레벨도 정하고, 다른 [새 파티원](#newcomers-to-the-party)과 마찬가지로 빠른 성장이나 더 좋은 능력치를 줄 수 있습니다.
- **돌아온 게스트.** 게스트가 떠나도 캐릭터는 레벨, 장비, 길들인 야수와 함께 게임에 남습니다. 플레이어가 없는 동안 캐릭터는 전투에 참여하지 않고 경험치도 얻지 않으며, Game Master도 장면에서 제외합니다. 게스트가 돌아오면 떠날 때의 레벨로 같은 캐릭터를 플레이합니다.

<a id="move-a-legacy-game-to-mrpg"></a>

## Legacy 게임을 MRPG로 전환하기

Legacy 게임은 원하는 동안 계속 Legacy 시트를 유지합니다. 전환하려면 **Journal**(일지)을 열고 **All**(전체) 탭에서 **MRPG classes**(MRPG 클래스) 카드를 찾으세요. **Upgrade**(업그레이드)를 선택하세요.

카드는 파티원마다 다음을 표시합니다.

- **클래스.** 라이브러리 카드에서 고른 트리, 또는 Legacy 클래스에서 가져온 시작 트리입니다. 바꿀 수 있습니다.
- **자매 트리.** 성향으로 열리는 보조 트리입니다. 아직 성향이 없는 캐릭터는 업그레이드할 때 Description(설명)에서 성향을 가져옵니다.
- **장비.** 캐릭터가 지닌 각 Legacy 무기와 방어구, 그리고 변환될 MRPG 장비입니다. 그대로 둘 장비는 체크박스를 해제하세요.

**Upgrade the party**(파티 업그레이드)로 확정하면 다음과 같이 처리됩니다.

- 모든 파티원은 시작 클래스의 최고 수준인 레벨 10에서 시작하며, 레벨이 오를 때와 같은 방식으로 각 레벨의 능력치를 굴립니다.
- 카드의 클래스가 MRPG 클래스로 바뀝니다. Legacy 클래스와 능력은 카드의 **Before the upgrade**(업그레이드 전) 메모로 옮겨져 이야기가 계속 그 내용을 알 수 있습니다. Legacy 능력치도 카드에 남습니다.
- 전환을 승인한 무기와 방어구는 각각 대응하는 MRPG 장비가 되고 이름을 유지하며, 클래스가 착용할 수 있으면 착용합니다.

> **경고:** 업그레이드는 되돌릴 수 없습니다. MRPG 클래스로 전환한 게임은 Legacy 시트로 돌아갈 수 없습니다.

전투 중에는 업그레이드가 제공되지 않습니다. 먼저 전투를 끝내세요. 규칙 집합으로 플레이하는 게임은 업그레이드할 수 없으며 규칙 집합의 시트를 유지합니다.
