# 게임 에셋: 음악, 소리, 스프라이트, 배경

이 가이드에서는 Game Mode(게임 모드)가 음악, 소리, 캐릭터 그림, 장면 배경에 사용하는 게임 에셋 라이브러리를 설명합니다. 기본으로 들어 있는 시작용 모음, 파일 관리 도구인 **Asset Browser**(에셋 브라우저), 직접 만든 파일 업로드, 게임별로 사용할 에셋 고르기까지 다룹니다.

## 게임 에셋이란

게임 에셋은 세션이 진행되는 동안 Game Mode가 재생하고 화면에 보여 주는 미디어 파일입니다. Marinara Engine은 이를 다섯 가지로 나눕니다.

- **Music**(음악): 장면에 따라 바뀌는 배경 음악입니다.
- **Ambient**(앰비언트): 자연, 도시, 실내 소리처럼 계속 반복되는 환경음입니다.
- **Sound Effects**(효과음, SFX라고도 합니다): 메뉴, 전투, 탐험에 쓰는 짧은 소리입니다.
- **Sprites**(스프라이트): 화면에 표시되는 캐릭터와 사물 그림입니다.
- **Backgrounds**(배경): 이야기 뒤에 깔리는 장면 이미지입니다.

Game Mode는 이 라이브러리를 스스로 읽습니다. 장면에 맞춰 음악, 환경음, 배경을 알아서 고르므로 플레이 도중 에셋을 일일이 지정하지 않아도 됩니다.

## 기본 제공되는 시작용 모음

Marinara는 서버를 처음 시작할 때 무료 시작용 라이브러리를 설치합니다. 이후 실행에서도 기본 모음이 바뀌었으면 파일을 업데이트합니다. 시작용 모음에는 다음이 들어 있습니다.

- 서로 다른 장면 분위기에 하나씩 대응하는 **Music** 트랙 5개.
- 자연, 도시, 실내 폴더로 나뉜 **Ambient** 반복 음원 모음.
- 메뉴, 전투, 탐험용 **Sound Effects**.

**Backgrounds**는 기본 제공되지 않습니다. 배경 폴더는 비어 있는 상태로 시작합니다. 이미지를 업로드하거나 Game Mode가 장면 그림을 생성해야 채워집니다.
캐릭터 **Sprites**도 기본 제공되지 않습니다. 직접 만드는 게임에 어울리는 캐릭터 그림만 추가하세요.

기본 제공 파일은 모두 CC0 라이선스입니다. 즉, 퍼블릭 도메인이라 자유롭게 쓸 수 있습니다. 파일별 상세 출처는 에셋과 함께 디스크에 저장되는 `CREDITS.md` 텍스트 파일에 들어 있습니다. 앱 안에서는 표시되지 않습니다.

기본 제공 파일과 폴더는 보호됩니다. **Asset Browser**에서 삭제하거나 옮길 수 없으므로 시작용 라이브러리는 그대로 유지됩니다. 이름 변경과 복사는 가능합니다.

## Asset Browser 열기

**Asset Browser**는 게임 에셋을 다루는 파일 관리 도구입니다. 여는 방법은 두 가지입니다.

**Settings**(설정)에서 여는 방법:

1. **Settings**를 여세요.
2. **Imports**(가져오기) 탭으로 이동하세요.
3. **Game Assets**(게임 에셋) 섹션을 찾으세요.
4. **Asset Browser** 버튼을 클릭하세요.

게임에서 여는 방법:

1. Game Mode 채팅을 여세요.
2. **Game Assets** 버튼(폴더 아이콘)을 클릭하거나 탭하세요. 처음에는 채팅 오른쪽 위 근처에 있습니다. 컴퓨터와 휴대폰 모두에서 다른 곳으로 끌어 옮길 수 있습니다.

버튼은 Game Mode 채팅에만 나타납니다. **Asset Browser**가 들어 있는 **Game Assets**를 열며, 컴퓨터에서는 이동 가능한 창으로, 휴대폰에서는 화면 너비의 패널로 표시됩니다.

**Put back in Chat Settings**(채팅 설정으로 되돌리기)로 옮겼다면 Chat Settings 안의 **Game Assets** 섹션을 여세요.

위쪽 툴바에는 **Game Assets**에서 시작하는 경로 표시가 있습니다. 그 옆으로 **Grid view**(격자 보기)와 **List view**(목록 보기) 전환, **Upload**(업로드) 버튼, **New**(새로 만들기) 버튼이 있습니다. **Rescan**(다시 스캔) 버튼, **Open in system folder**(시스템 폴더에서 열기) 버튼, **Search in folder** 입력란도 함께 있습니다. 화면이 넓으면 왼쪽 폴더 트리로 카테고리 사이를 바로 오갈 수 있습니다.

## 직접 만든 에셋 업로드하기

업로드하는 방법은 두 가지입니다. 편한 쪽을 쓰면 됩니다.

### Asset Browser에서 업로드

1. **Asset Browser**를 여세요.
2. 다섯 카테고리 폴더 중 하나, 또는 그 안의 하위 폴더로 들어가세요.
3. **Upload**를 클릭해 파일을 고르거나, 파일 영역으로 파일을 끌어다 놓으세요.

먼저 카테고리 폴더 안으로 들어가야 합니다. 최상위에서 파일을 놓으면 카테고리 폴더를 연 뒤 업로드하라는 안내가 나옵니다.

### Settings에서 업로드

1. **Settings**를 열고 **Imports** 탭으로 이동하세요.
2. **Game Assets** 섹션을 찾으세요.
3. **Type**(타입) 메뉴에서 **Music**, **Ambient**, **Sound Effects**, **Sprites**, **Backgrounds** 중 하나를 고르세요.
4. **Folder**(폴더) 입력란에 저장 위치를 지정하거나, 제안된 기본값을 그대로 두세요.
5. **Choose Files**(파일 선택)를 클릭해 파일을 고르세요.
6. **Upload to Server**(서버 업로드)를 클릭하세요.

**Type**을 고르면 **Folder** 입력란이 알맞은 기본값으로 채워집니다. 기본값은 다음과 같습니다.

- **Music**: `exploration/fantasy/calm`
- **Ambient**: `nature`
- **Sound Effects**: `exploration`
- **Sprites**: `generic-fantasy`
- **Backgrounds**: `custom`

### 파일 형식과 크기 규칙

서버는 업로드되는 모든 파일을 아래 규칙으로 검사합니다. 두 가지 업로드 방법 모두에 적용됩니다.

| 카테고리                          | 허용 파일 형식                       |
| --------------------------------- | ------------------------------------ |
| Music, Ambient, Sound Effects     | MP3, OGG, WAV, FLAC, M4A, AAC, WebM  |
| Sprites                           | PNG, JPG, JPEG, GIF, WebP, AVIF, SVG |
| Backgrounds                       | PNG, JPG, JPEG, GIF, WebP, AVIF      |

오디오와 이미지 파일은 각각 50 MB까지, 텍스트 파일은 10 MB까지 올릴 수 있습니다. 카테고리에 맞지 않는 형식은 서버가 거부합니다. 오류 메시지에 허용 형식이 표시됩니다.

### 음악 폴더 규칙

음악은 폴더 구조가 엄격합니다. 모든 음악 트랙은 `state/genre/intensity` 형태의 3단계 경로에 있어야 합니다. 예를 들면 `exploration/fantasy/calm`입니다. 경로가 맞지 않으면 업로드가 실패합니다.

사용할 수 있는 값은 다음과 같습니다.

- State: `exploration`, `dialogue`, `combat`, `travel_rest`.
- Genre: `fantasy`, `horror`, `romance`, `mystery`, `scifi`, `modern`, `slice_of_life`, `adventure`, `drama`, `custom`.
- Intensity: `calm`, `tense`, `intense`.

Game Mode는 이 구조를 보고 각 트랙을 언제 재생할지 판단합니다. 앰비언트, 효과음, 스프라이트, 배경 폴더에는 이 규칙이 없습니다. 하위 폴더 이름은 자유롭게 지어도 됩니다.

## 에셋 정리하기

**Asset Browser**를 쓰면 파일을 깔끔하게 정리할 수 있습니다. 데스크톱에서는 파일이나 폴더를 오른쪽 클릭하거나 "..." 메뉴를 열면 사용할 수 있는 작업이 나옵니다.

파일에 쓸 수 있는 작업:

- **Rename**(이름 바꾸기): 파일 이름을 새로 붙입니다. 같은 폴더에 이미 있는 이름이면 실패합니다.
- **Move**(이동)와 **Copy**(복사): 폴더 선택기로 다른 폴더에 파일을 보냅니다.
- **Delete**(삭제): 파일을 삭제합니다.
- **Download**(다운로드): 파일을 기기에 저장합니다.

폴더에 쓸 수 있는 작업:

- **Create subfolder**(하위 폴더 만들기): 그 안에 새 폴더를 만듭니다.
- **Open in system folder**: 컴퓨터의 파일 관리자에서 그 폴더를 엽니다.
- **Delete folder**(폴더 삭제): 폴더를 삭제합니다. 안에 파일이 남아 있으면 먼저 **Delete everything inside**(내부 항목 모두 삭제)를 선택해야 합니다.

툴바의 **New** 버튼으로도 현재 폴더에 항목을 만들 수 있습니다. **New folder**(새 폴더), **New text file**(새 텍스트 파일), **New markdown file**(새 Markdown 파일) 중에서 고를 수 있습니다.

여러 파일을 한 번에 처리하려면 각 파일의 체크박스를 쓰세요. 선택한 파일 개수를 알려 주는 막대와 함께 **Select all**(모두 선택), **Move**, **Copy**, **Delete** 버튼이 나타납니다. 항목이 많은 폴더는 일부만 먼저 보여 주고 **Load more**(더 불러오기) 버튼으로 나머지를 불러옵니다.

폴더마다 짧은 설명을 달 수 있습니다. 폴더 설명 문구나 **Add description...** 안내를 클릭해 입력하세요. 다섯 개 카테고리 폴더의 설명은 고정되어 있어 바꿀 수 없습니다.

기본 제공 시작용 파일은 보호된다는 점을 기억하세요. 이름 변경과 복사는 되지만 이동과 삭제는 되지 않습니다.

## 앱 밖에서 파일을 바꾼 뒤 다시 스캔하기

Marinara는 Game Mode가 에셋을 빠르게 찾을 수 있도록 내부 목록을 관리합니다. 앱에서 업로드하면 이 목록은 자동으로 업데이트됩니다.

앱을 거치지 않고 컴퓨터에서 게임 에셋 폴더에 파일을 직접 복사하면 앱이 곧바로 알아채지 못합니다. 이때는 **Rescan** 버튼을 클릭해 폴더를 다시 읽고 새 파일을 인식하게 하세요. **Rescan**은 **Asset Browser** 툴바와 **Settings**의 **Game Assets** 섹션 양쪽에 있습니다.

## 게임마다 사용할 에셋 고르기

Game Mode 채팅은 저장된 에셋 폴더 중 일부만 쓰도록 제한할 수 있습니다. 예를 들어 호러 게임에서 밝은 음악을 빼고 싶을 때 유용합니다.

설정 중에는 **Features** 단계에서 **Adjust Game Assets for this Game**(이 게임의 게임 에셋 조정)을 펼치세요. 이미 만든 게임이라면 그 게임의 **Game Assets** 창을 여세요.

그다음 순서는 다음과 같습니다.

1. **Game assets** 버튼을 클릭하세요. 활성 상태에서는 표시가 **Selecting**으로 바뀝니다.
2. 각 폴더에 있는 작은 상태 컨트롤로 포함할지 제외할지 지정하세요.

막대에는 "All folders included" 또는 제외된 폴더 개수가 표시되며, 전부 다시 포함하는 **Reset to all**(전체로 초기화) 버튼도 있습니다. 이 선택은 해당 채팅에만 저장됩니다. Game Mode가 고를 수 있는 폴더 범위만 달라질 뿐, 파일이 삭제되거나 숨겨지지는 않습니다. 그 Game Mode 채팅 밖에는 아무 영향도 주지 않습니다.

## Music DJ용 사용자 지정 음악 폴더

**Music DJ**는 게임 중에 음악을 틀어 주는 보조 에이전트입니다. Custom 모드로 동작할 때는 지정한 폴더의 트랙을 재생합니다. 이 폴더는 두 곳에서 지정할 수 있습니다.

채팅에서 **Music DJ**를 활성화하면 설정 양식이 Music DJ 에이전트에 저장된 소스를 따라갑니다. **Game Assets**에는 `music`이나 `music/combat`처럼 게임 에셋 안의 경로가 표시됩니다. **Folder on this device**에는 저장된 서버 기기 경로와 **Choose Folder**(폴더 선택) 버튼이 표시됩니다.

**Music DJ** 전체 편집기에는 **Custom Music Library**(사용자 지정 음악 라이브러리) 섹션이 있습니다. 이 섹션의 **Use Game Assets music folder**(게임 에셋 음악 폴더 사용) 스위치로 두 가지 방식 중 하나를 고릅니다.

- 스위치 켜기: **Game Assets music folder**(게임 에셋 음악 폴더) 입력란이 `music`이나 `music/combat`처럼 게임 에셋 안의 폴더를 읽습니다. **Open Folder**(폴더 열기) 버튼을 누르면 서버 컴퓨터에서 그 폴더가 열립니다.
- 스위치 끄기: **Music folder on this device**(이 기기의 음악 폴더) 입력란을 쓰면 Custom 모드가 서버를 실행하는 컴퓨터의 어느 폴더에서든 음악을 재생할 수 있습니다. **Select Folder**를 클릭해 시스템 폴더 선택기를 열거나, 폴더 경로를 입력란에 붙여넣으세요.

앱 밖의 폴더를 고르려면 관리자 권한이 필요합니다. 서버와 같은 컴퓨터에서는 추가 설정 없이 바로 됩니다. 다른 기기나 원격 접근으로 쓸 때는 먼저 관리자 접근을 설정해야 합니다. 설정 방법은 [원격 접근](../REMOTE_ACCESS.md)을 참고하세요. 음악 플레이어에 관한 나머지 내용은 [Music DJ](../media/music.md)에 있습니다.

## 컴퓨터에서 폴더 열기

**Open in system folder** 버튼을 누르면 선택한 에셋 폴더가 컴퓨터의 기본 파일 관리자에서 열립니다. 이 기능은 서버를 실행하는 컴퓨터에서 앱을 쓸 때만 동작합니다. 휴대폰, 태블릿, 다른 컴퓨터에서는 Marinara를 실행 중인 기기에서만 시스템 폴더를 열 수 있다는 안내가 표시됩니다.
