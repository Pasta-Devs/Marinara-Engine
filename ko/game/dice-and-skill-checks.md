# Game Mode: 주사위와 스킬 판정

이 가이드에서는 Marinara Engine의 Game Mode(게임 모드)에서 주사위를 굴리는 방법을 설명합니다. 빠른 주사위 메뉴, 사용자 지정 주사위 표기법, 사용자 지정 굴림에 걸린 제한을 다룹니다. 게임 마스터(GM)가 DC를 기준으로 스킬 판정을 진행하는 방식도 함께 설명합니다.

## 주사위 굴리기

Game Mode 채팅의 메시지 입력 바에는 주사위 버튼이 있습니다. 마우스를 올리면 **Roll dice**(주사위 굴리기) 툴팁이 나타납니다. 버튼을 클릭하면 빠른 주사위 메뉴가 열립니다.

메뉴에는 한 번의 클릭으로 굴릴 수 있는 프리셋 8가지가 있습니다.

| 프리셋 | 굴리는 주사위 |
|---|---|
| d20 | 20면체 주사위 1개 |
| d6 | 6면체 주사위 1개 |
| 2d6 | 6면체 주사위 2개 |
| d10 | 10면체 주사위 1개 |
| d100 | 100면체 주사위 1개 |
| d4 | 4면체 주사위 1개 |
| d8 | 8면체 주사위 1개 |
| d12 | 12면체 주사위 1개 |

빠르게 한 번 굴리려면 다음과 같이 하세요.

1. Game Mode 채팅에서 메시지 입력 바를 여세요.
2. 주사위 버튼을 클릭하세요.
3. 프리셋 8가지 중 하나를 클릭하세요. 예를 들어 **d20**입니다.
4. 입력 바에 `🎲 d20` 같은 작은 칩이 나타납니다.

굴림은 곧바로 전송되지 않고 대기열에 들어갑니다. 대기 중인 굴림을 빼려면 칩의 지우기 버튼을 클릭하세요. 툴팁은 **Clear queued roll**(대기 중인 주사위 굴림 지우기)입니다.

주사위 계산은 다음 메시지를 보낼 때 실행됩니다. 앱이 결과를 메시지 끝에 태그로 붙입니다. 보너스 없이 주사위 1개만 굴리면 다음과 같은 모양입니다.

```
[dice: d20 = 14]
```

주사위를 2개 이상 굴리거나 보너스가 붙으면 세부 내역까지 함께 표시됩니다.

```
[dice: 3d8+2 = 18 (4, 6, 6 +2)]
```

게임 마스터는 이 태그를 읽고 결과에 맞춰 이야기를 풀어 갑니다.

게임 마스터가 한 턴에 여러 번 주사위를 굴리면 각 주사위 카드가 대기열에 따로 들어갑니다. 카드를 닫으면 다음 카드가 표시됩니다. 모든 굴림은 해당 턴의 활성 스와이프(대체 응답)에 저장되며 새로고침 후에도 **Logs**(로그)에 남습니다. 턴을 이어 쓰면 이전 굴림이 유지되고, 다시 생성하면 새 스와이프에 별도 굴림 묶음이 생깁니다.

게임 마스터는 서술에서 `[dice: 3d8+2]`로 굴림을 요청할 수도 있습니다. 엔진이 실제 숫자를 정하고 같은 애니메이션 카드를 표시합니다. Claude와 Grok 구독을 포함해 텍스트만 지원하는 연결에서도 작동합니다. 표기법과 한도는 주사위 메뉴와 같습니다.

## 사용자 지정 주사위 표기법

주사위 메뉴에는 직접 굴림을 적어 넣는 입력란도 있습니다. 표준 `NdM` 표기법을 씁니다. `N`은 굴릴 주사위 개수이고, `M`은 주사위 한 개의 면 수입니다. 끝에 보너스나 페널티를 붙일 수 있습니다.

입력란의 안내 문구에는 `3d8+2` 예시가 보입니다. 8면체 주사위 3개를 굴려 합계에 2를 더한다는 뜻입니다.

사용자 지정 굴림을 쓰려면 다음과 같이 하세요.

1. 주사위 버튼을 클릭해 메뉴를 여세요.
2. 입력란에 표기법을 입력하세요. 예를 들어 `2d6+1`입니다.
3. Enter를 누르거나, 입력란 옆의 작은 종이비행기(보내기) 버튼을 클릭하세요.
4. 굴림이 칩으로 대기열에 올라가 전송할 준비가 됩니다.

입력할 수 있는 예를 몇 가지 더 들면 다음과 같습니다.

- `d20`은 20면체 주사위 1개를 굴립니다.
- `4d8-1`은 8면체 주사위 4개를 굴리고 1을 뺍니다.
- `2d6+3`은 6면체 주사위 2개를 굴리고 3을 더합니다.

넘을 수 없는 한도가 두 가지 있습니다. 한 번에 최대 100개의 주사위를 굴릴 수 있고, 각 주사위는 최대 1000면입니다. 이를 넘는 요청은 거부하는 대신 한도에 맞게 줄입니다. 결과 카드에는 조정된 표기법이 표시되므로 `500d6`을 입력하면 실제로 굴린 100개를 나타내는 `100d6` 카드가 표시됩니다. 입력이 올바른 주사위 표기법, 즉 `NdM`이나 `d20` 같은 단독 `dM`이 아니면 굴림이 실패하고 필요한 형식을 안내하는 오류가 표시됩니다.

## 스킬 판정

스킬 판정은 몰래 숨어들기, 단서 찾기, NPC(플레이어가 아닌 캐릭터) 설득처럼 위험이 따르는 행동의 성공 여부를 가립니다. 스킬 판정은 직접 시작할 수 없습니다. 게임 마스터가 이야기를 풀어 가다가 판정을 요구합니다. 그러면 앱이 결과 배너와 함께 d20 굴림 애니메이션을 보여 줍니다.

텍스트로 요청한 판정은 행동 시도부터 시작합니다. 엔진이 주사위 결과를 결정한 뒤 실제 결과를 담아 모델에 한 번 더 요청하므로 게임 마스터가 같은 턴 안에서 결과 서술을 마칠 수 있습니다. 굴리기 전에 결과를 추측한 초안도 바로잡습니다. 추가 요청은 프롬프트를 다시 보내므로 입력 및 출력 토큰을 더 사용합니다. 요청에 실패하면 턴에 확정된 결과만 남기고 추측하거나 미완성인 결과 서술은 저장하지 않습니다. 채팅을 새로고침한 뒤에도 해당 턴에 안내와 **Regenerate turn**(턴 재생성) 버튼이 남습니다.

**Chat Settings → Function Calling**(채팅 설정 → 함수 호출)에서 **Narrate dice outcomes immediately**(주사위 결과 즉시 서술)를 끄면 추가 요청 없이 실제 결과를 다음 턴에 사용하도록 유지합니다. 이 설정은 기본적으로 켜져 있습니다. 실제 굴림이 발생하지 않은 요청은 추가 서술 요청을 실행하지 않습니다.

두 번째 요청 없이 같은 턴에 결과를 남기는 세 번째 선택지도 있습니다. 아래 [주사위를 굴리는 턴을 한 요청으로 마치기](#finishing-a-rolled-turn-in-one-request)를 참고하세요.

주사위 도구를 지원하는 연결에서는 게임 마스터가 생성 중에 실제 굴림 결과를 받을 수 있습니다. 도구가 반환되면 즉시 카드가 나타나고, 완료된 판정은 다시 굴리지 않고 그 결과를 기록합니다. 해결된 스킬 판정마다 별도 배너가 생기며 대기 중인 주사위 카드 뒤에 표시됩니다.

배너에는 스킬 이름과 목표 숫자가 표시됩니다. 예를 들어 **Stealth Check** 옆에 **DC 15**가 붙는 식입니다. DC는 Difficulty Class의 약자로, 굴림 결과가 도달하거나 넘어서야 하는 숫자입니다.

### 결과를 정하는 방식

판정에서는 20면체 주사위 1개를 굴리고 수정치 2가지를 더합니다.

- 스킬 수정치. 게임이 캐릭터별로 관리하는 스킬 레벨에서 가져옵니다. 아직 그 스킬의 레벨이 없으면 이 수정치는 0입니다.
- 능력치 수정치. 그 스킬을 관장하는 능력치에서 가져옵니다.

주사위 값에 두 수정치를 더한 값이 합계입니다. 합계가 DC에 도달하거나 넘어서면 판정에 성공하고, 모자라면 실패합니다. 스킬마다 관장 능력치는 자동으로 정해집니다. 예를 들어 Stealth는 Dexterity, Perception은 Wisdom, Persuasion은 Charisma를 씁니다. 앱이 알지 못하는 스킬은 Intelligence를 씁니다.

### 대성공과 대실패

다음 두 굴림은 계산 결과보다 우선합니다.

- 주사위 눈 자체가 20이 나오면(natural 20) **CRITICAL SUCCESS**입니다. DC가 아무리 높아도 항상 성공합니다.
- 주사위 눈 자체가 1이 나오면(natural 1) **CRITICAL FAILURE**입니다. 수정치가 아무리 커도 항상 실패합니다.

배너에는 **CRITICAL SUCCESS**, **SUCCESS**, **FAILURE**, **CRITICAL FAILURE** 4가지 결과 중 하나가 표시됩니다.

### 다른 주사위 시스템

게임 마스터는 `[skill_check: skill="Endurance" dc="12" dice="3d6+2"]`처럼 다른 표기법을 지정할 수 있습니다. 이런 판정은 캐릭터 시트의 d20 보정치 대신 표기법에 있는 고정 보정치를 사용하며 합계가 DC에 도달하면 성공합니다. 자연 1과 자연 20 규칙은 위에서 설명한 표준 d20 판정에만 적용됩니다.

성공 수를 세는 주사위 풀은 주사위별 기준값과 필요한 성공 횟수를 모두 지정해야 합니다. `[skill_check: skill="Intimidation" dc="4" dice="6d10" resolution="successes" threshold="6"]`은 d10 여섯 개를 굴려 6 이상이 나온 주사위를 각각 한 번 세고, 성공이 네 번 이상이면 통과합니다. 엔진은 빠진 기준값을 추측하지 않으며 폭발 주사위, botch 규칙 또는 다른 특수 풀 규칙을 구현하지 않습니다. 유효한 기준값이 없는 풀은 미해결 상태로 남고 모델이 지어낸 숫자는 제거됩니다.

이것은 **규칙 집합이 없는** 게임의 풀이며 그대로입니다. 주사위 풀 규칙 집합을 가진 게임은 엔진이 실제 규칙을 보유하는 다른 방식입니다. 아래 [규칙 집합을 사용하는 게임](#games-that-use-a-ruleset)을 참고하세요.

`4d6kh3`, `3d6!`, `4dF`처럼 지원하지 않는 요청은 굴리지 않습니다. 엔진은 지원하지 않는 표기법을 로그에 기록하고 판정 레코드에서 지어낸 숫자를 제거합니다. 이 결과들은 미정으로 남으며, 엔진은 알리지 않고 다른 주사위 시스템으로 대체하지 않습니다.

### 어드밴티지와 디스어드밴티지

게임 마스터는 어드밴티지나 디스어드밴티지를 붙여 판정을 요구할 수 있습니다. 한 판정에 두 가지가 동시에 적용되는 일은 없습니다.

- 어드밴티지가 붙으면 앱이 20면체 주사위 2개를 굴려 높은 쪽을 씁니다.
- 디스어드밴티지가 붙으면 앱이 주사위 2개를 굴려 낮은 쪽을 씁니다.

게임 마스터가 둘 다 동시에 요청하면 앱은 의도를 추측하지 않고 해당 판정을 그대로 두므로 배너가 표시되지 않습니다.

둘 중 하나가 적용되면 배너의 DC 옆에 그 상태가 표시되고, 어느 주사위를 썼는지도 함께 표시됩니다.

### 주사위 미리 굴려 두기

판정이 시작되기 전에 주사위 메뉴에서 `d20`을 미리 대기열에 올려 둘 수 있습니다. 이렇게 하면 스킬 판정이 주사위를 새로 굴리지 않고 미리 굴려 둔 숫자를 씁니다. 스킬 수정치와 능력치 수정치는 그 위에 그대로 더해집니다.

## 규칙 집합을 사용하는 게임

게임은 Marinara 자체 규칙 대신 5e (SRD 5.1) 같은 규칙 집합을 사용할 수 있습니다. 규칙 집합은 그 게임에 속하며 그대로 유지됩니다. 게임을 만들 때 설정 마법사의 **Rules**(규칙)에서 고릅니다([규칙 선택](getting-started.md#choosing-rules) 참고). 규칙 집합이 없는 게임은 위의 설명대로 동작합니다.

규칙 집합이 있는 게임에서는 다음과 같이 동작합니다.

- Game Master는 여전히 기술이나 내성 이름과 난이도만 정합니다. 내장 난이도 대신 규칙 집합의 난이도 단계가 전달됩니다. 난이도는 그 단계의 범위까지 설정할 수 있으며 Marinara 자체 규칙의 1~40을 넘을 수도 있습니다. 다만 저장된 턴에 아직 남은 판정을 굴리는 대체 경로는 규칙 집합 게임에서도 1~40을 유지합니다.
- Engine은 규칙 집합의 주사위를 굴리고 캐릭터의 **규칙 집합 시트**에서 수정치를 더합니다. 규칙 집합이 선언한 구성 요소를 사용합니다. 기술이나 내성이 능력치를 지정하면 그 능력치 수정치, 훈련 수준에 따른 보너스(숙련 보너스의 배수, 고정값 또는 둘 다), 시트에 입력한 추가 보너스가 포함됩니다. 내장 기술 보너스와 능력치는 사용하지 않습니다.
- 동료의 판정도 가능합니다. Game Master가 태그에 `who="Name"`을 더하면 Engine은 그 캐릭터의 시트를 씁니다. `who`가 없으면 플레이어를 판정합니다. 시트가 아직 없는 동료는 규칙 집합의 기본값을 모두 가진 빈 시트로 굴립니다. 파티에서 찾을 수 없거나 둘이 공유하는 이름이면 수정치 없이 굴립니다. 예외는 플레이어 자신의 캐릭터 이름입니다. 동료와 이름이 같아도 플레이어와 플레이어 시트를 뜻합니다. Engine은 다른 사람의 시트를 빌리지 않습니다.
- 자연 주사위 결과는 규칙 집합을 따릅니다. 5e (SRD 5.1)에서는 판정과 내성에 자연 20이나 자연 1의 특수 효과가 없으므로, 자연 20도 난이도에 못 미치면 실패합니다. 의도적으로 Marinara 자체 규칙과 다릅니다.
- Game Master가 직접 쓴 숫자는 신뢰하지 않습니다. 완성된 것처럼 보이는 태그라도 수정치가 시트와 다르거나, 주사위 개수나 크기가 규칙 집합과 다르거나, 채택한 주사위가 굴림 모드가 고르는 것과 다르거나, 규칙 집합에 없는 자연 주사위 효과를 주장하면 다시 굴려 교체합니다.
- 판정 전에 직접 굴린 주사위는 규칙 집합이 d20 하나를 굴릴 때만 씁니다. 2d6이나 풀 같은 다른 주사위를 사용하는 규칙 집합은 이를 무시하고 평소대로 굴립니다.
- Game Master는 태그에 `with="Ability"`를 더해 기술이나 내성의 일반적인 능력치 대신 다른 능력치를 쓸 수 있습니다. 규칙 집합이 선언한 능력치만 유효하며, 나머지는 무시하고 본래 능력치를 유지합니다.
- 굴림 자리표시자에는 규칙 집합의 능력치, 기술, 내성과 숙련 보너스가 있을 경우 `PROF`를 쓸 수 있습니다.
- 규칙 집합 패키지가 없거나 게임 생성 당시보다 오래되었으면 판정은 숫자 없이 저장되고 미해결로 남습니다. 다른 시스템의 규칙으로 굴리지 않습니다.
- 실패한 주사위를 다시 굴리는 부적처럼 시트의 요소가 굴림을 바꾸면 Game Master가 판정에 그 이름을 적고 Engine이 나머지를 처리합니다. 비용을 차감하고 효과를 적용한 뒤 굴립니다. 선택하지 않았거나 비용을 지불할 수 없는 부적은 효과도 비용도 없습니다.
- 규칙 집합이 자원을 써서 굴림을 안정시키도록 허용하면 Game Master가 판정 자체에 명시하고 Engine이 한 번에 처리합니다. 점수를 차감하고 얻은 효과를 더한 뒤 굴립니다. 풀이 부족하면 아무것도 쓰지 않고 원래 굴림을 합니다. 기록에는 요청량이 아니라 실제 지불한 양이 표시됩니다.
- 규칙 집합에 부상 트랙이 있고 페널티를 굴림에 적용한다고 정했다면, 다칠수록 모든 판정이 어려워집니다. 풀 규칙은 그만큼 주사위를 빼되 규칙 집합의 최소 풀보다 작아지지 않습니다. 일부 시스템의 최소값은 0입니다. 주사위 합산 규칙은 고정 페널티를 적용합니다. 어느 쪽이든 판정에 적용량이 표시되어 주사위가 줄어든 이유를 알 수 있습니다. [규칙 집합 시트](party-and-npcs.md#the-ruleset-sheet)를 참고하세요.
- Game Master는 각 캐릭터의 자원, 상태, 휴식도 시트에 반영하며, Engine은 시트가 허용하지 않는 변경을 거부합니다. [규칙 집합 시트](party-and-npcs.md#the-ruleset-sheet)를 참고하세요.

### 주사위 풀을 굴리는 규칙 집합

일부 시스템은 굴림에 보너스를 더하지 않습니다. 대신 시트 숫자만큼 주사위를 던져 충분히 높은 눈이 나온 개수를 셉니다. 이런 규칙 집합도 만들 수 있으며 게임이 조금 다르게 동작합니다.

- **시트 숫자는 주사위 개수입니다.** 평점 3과 전문 기술 2라면 다섯 개를 던집니다. 편집기와 Game Master가 읽는 시트 모두 "+5" 대신 "5 dice"로 표시합니다.
- **난이도는 성공 개수입니다.** 어려운 일은 합계 15 대신 성공 세 개를 요구합니다. 규칙 집합의 난이도 단계가 각 단계의 필요 개수를 정합니다.
- **Engine이 굴리고 셉니다.** 어떤 눈이 성공인지, 높은 눈이 추가 주사위를 굴리거나 두 개로 세어지는지, 낮은 눈이 성공을 상쇄하는지, 대실패나 뛰어난 성공의 조건은 모두 규칙 집합에서 옵니다. 주사위 카드에는 던진 주사위를 모두 표시하고 목표에 도달한 것과 아닌 것을 구분하며, 필요 성공 수와 실제 성공 수를 보여 줍니다. 큰 풀은 축소하지 않고 여러 줄로 나누며, 실제로 합산하지 않은 총합을 표시하지 않습니다.
- **Game Master는 개별 판정을 조정할 수 있습니다.** 규칙 집합이 허용하면 주사위별 목표를 높이거나 낮추고 상황에 따라 주사위를 더하거나 뺍니다. 둘 다 규칙 집합의 선언 범위로 제한됩니다.
- **Game Master는 숫자를 제공하지 않습니다.** 서술에 적은 풀 결과는 항상 Engine의 실제 굴림으로 교체합니다. 이점과 판정 전에 직접 굴린 주사위는 적용되지 않습니다.
- **Game Master에게 크기별 주사위 하나씩 보여 주기는 이 판정에 적용되지 않습니다.** 보여 주는 주사위는 20면체입니다. 풀 판정은 Engine이 결과를 미리 보여 주지 않고 굴리며 다른 비공개 굴림처럼 서술합니다.

## 주사위를 굴리는 턴을 한 요청으로 마치기

기본적으로 주사위를 굴리는 턴은 초안 작성과 실제 숫자로 결과를 다시 쓰는 데 모델 요청 두 번을 씁니다. **Chat Settings → Function Calling**(채팅 설정 → 함수 호출)의 **Finish rolled turns in one request**(굴림 턴을 한 요청으로 완료)는 두 번째 요청을 없앱니다. 기본값은 꺼짐이며 켠 채팅에만 적용됩니다.

Game Master가 숫자가 나오기 전에 문장을 확정하므로 가능합니다. 무엇이 일어날지 정하기 전에 굴림을 보지 못해 받은 눈에 맞게 결과를 조정할 수 없습니다. 엔진이 나중에 굴리고 엔진의 기록을 저장합니다.

켜져 있는 동안 Game Master는 결과의 성격에 맞춰 다음 세 형식 중 하나로 판정을 작성하도록 요청받습니다.

**결과가 두 갈래면 양쪽을 모두 씁니다.** 숫자 없는 판정 뒤에 성공 문장과 실패 문장을 담은 블록을 씁니다. 엔진이 굴린 뒤 선택된 쪽을 남기고 다른 쪽은 턴을 읽기 전에 지웁니다. 먼저 굴린 것처럼 하나의 결과만 보입니다.

**결과가 숫자뿐이면 자리표시자를 쓰고 계속합니다.** 피해, 회복, 금액, 기간, 개수, 거리 등에 Game Master가 문장 중간에 `[[roll: 2d6+3]]`를 쓰고 엔진이 숫자로 바꿉니다. `[[roll: 1d8+STR]]`처럼 시트 수정치를 지정하면 엔진이 직접 더합니다. 이 형식은 읽을 시트가 있는 게임에서만 제공하며, 해석할 수 없는 이름은 0으로 처리하지 않고 거부합니다. 자리표시자에서 나온 숫자 위에 포인터를 올리면 주사위 내역이 보이고 각각 **Logs**(로그)에도 별도 굴림 행으로 나옵니다.

**숫자 자체가 세 가지 이상의 결말을 골라야 하면 값을 요청하고 멈춥니다.** Game Master가 기존에 쓰는 숫자 없는 간단한 판정이나 `[dice:]` 요청과 같습니다. 엔진이 굴리고 기록하며 결과 서술 없이 턴이 끝납니다. 다음 턴 시작에 Game Master가 그 숫자의 의미를 서술합니다. **Narrate dice outcomes immediately**(주사위 결과 즉시 서술)를 끈 것과 같습니다.

이 형식에 맞지 않는 판정도 같은 방식으로 대체 처리하므로 해결되지 않은 채 방치하거나 결과를 지어내지 않습니다.

켜기 전에 알아둘 점이 있습니다.

- **켜져 있는 동안 Narrate dice outcomes immediately는 사용하지 않습니다.** 설명과 함께 비활성 상태로 보입니다. 저장된 값은 그대로이므로 한 요청 주사위를 끄면 이전 설정으로 돌아옵니다.
- **기존 턴은 바뀌지 않습니다.** 켠 뒤 생성하는 턴에만 영향을 주며 이미 저장된 기록은 그대로 읽힙니다.
- **두 경우에는 여전히 요청이 여러 번 필요할 수 있습니다.** **Enable Tool Use**(도구 사용 활성화)가 켜져 있고 목록에 주사위 도구가 있으면 Game Master가 여전히 호출할 수 있으며, 도구 호출은 추가 한 왕복을 씁니다. 또한 **Game tool connection**(게임 도구 연결)이 **Same as narrator**(내레이터와 동일)가 아니면 항상 별도 계획 요청을 합니다. 둘 다 이 설정이 제거하는 결과 재작성과는 별개입니다.
- **굴릴 수 없으면 알려 줍니다.** 읽을 수 없는 숫자는 지어낸 값 대신 짧은 안내로 바꾸며, 해석할 수 없는 분기는 굴림 기록만 남기고 양쪽 문장을 버립니다. 어느 경우든 **Logs**에 생략한 내용을 설명하는 행을 남깁니다.
- **턴을 작성하는 동안** 자리표시자와 분기 블록은 스트리밍에서 보류하므로 숫자가 나타났다 바뀌는 모습은 보이지 않습니다. 턴이 끝나면 완성된 문장이 나옵니다.

### Game Master에게 크기별 주사위 하나씩 보여 주기

그 아래에 **Let the Game Master see one die of each size**(Game Master에게 크기별 주사위 하나씩 보여 주기)가 있으며 기본값은 꺼짐입니다. 성공 여유치, 명중 부위 표, 반응 굴림처럼 숫자 자체가 세 가지 이상의 결말을 골라야 해서 두 비공개 형식으로 처리할 수 없는 경우를 위한 설정입니다. 사용하지 않으면 그런 판정은 턴을 끝내고 다음 턴 시작에 서술해야 합니다.

켜면 엔진이 턴 전에 표준 크기의 주사위를 하나씩 굴리고 각 크기의 다음 값을 Game Master에게 보여 줍니다. Game Master는 하나를 쓰고 같은 처리에서 그 의미를 서술할 수 있습니다.

**이 절충점은 충분히 이해해야 합니다.** Game Master는 무엇을 얼마나 어렵게 판정할지 정하기 전에 숫자를 봅니다. 따라서 비공개 형식에서는 불가능한 결과 조정이 가능합니다. 받은 눈이 통과하는 난이도를 고르거나, 나쁜 숫자를 가지고 있는 동안 판정 자체를 피할 수 있습니다. 엔진은 난이도가 이야기와 맞는지 판단할 수 없어 이를 감지하지 못합니다. Game Master가 주사위를 봤다는 사실을 모르는 플레이어는 의심스러울 만큼 영웅적인 진행을 행운으로 받아들일 수 있습니다.

엔진이 Game Master의 협조 없이 강제하는 것은 다음과 같습니다.

- **값은 순서대로 나오며 두 번 쓰지 않습니다.** 엔진이 큐를 유지하고 턴의 주장과 무관하게 다음 값을 줍니다.
- **기록의 모든 숫자는 엔진의 것입니다.** 굴림, 수정치, 합계, 결과를 큐와 캐릭터 시트에서 다시 계산합니다. Game Master가 쓴 숫자가 다르면 교체하고 **Logs**에 남깁니다.
- **난이도는 제한됩니다.** 이전의 작성된 판정과 달리 1~40으로 제한합니다. 규칙 집합 게임은 해당 난이도 단계의 범위까지 허용합니다.
- **다시 요청해도 운이 나아지지 않습니다.** 같은 턴의 스와이프, 재생성, 이어 쓰기는 모두 같은 값을 사용하므로 좋은 눈이 나올 때까지 다시 굴릴 수 없습니다.
- **각 크기의 다음 값만 보여 줍니다.** **Values shown per size**(크기별 표시 개수)의 기본값은 1입니다. 한 턴에서 같은 크기를 이후에 굴리는 경우는 미리 보여 주지 않고 다음 턴에 서술합니다.
- **쓰지 않은 주사위는 일정 턴 뒤 다시 굴립니다.** **Rethrow after idle turns**(미사용 턴 후 다시 굴리기)의 기본값은 3입니다. 이 기능이 없으면 Game Master가 해당 크기를 피하는 동안 낮은 값이 채팅 끝까지 큐 맨 앞에 남을 수 있습니다. 0으로 설정하면 다시 굴리기를 끄고 그 동작으로 돌아갑니다.
- **큐보다 많은 굴림을 요청해도 새 굴림이 생기지 않습니다.** 판정의 질문은 남기고 숫자는 모두 지우며 다음 턴에 서술합니다. **Logs**에는 어느 턴에서 일어났는지 남깁니다.
