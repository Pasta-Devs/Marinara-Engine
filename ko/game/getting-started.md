# Game Mode: 시작하기

Game Mode(게임 모드)는 Marinara Engine을 AI 게임 마스터가 진행하는 1인용 롤플레잉 게임으로 바꿔 줍니다. 이 가이드에서는 Game Mode가 어떤 모드이고 시작하기 전에 무엇이 필요한지 설명합니다. 이어서 설정 마법사를 차례대로 살펴보고 각 게임 기능이 어디에 있는지 안내합니다. 한 번 읽고 게임을 시작한 다음, 더 깊은 내용은 문서 끝의 링크를 따라가세요.

## Game Mode란

Game Mode는 Marinara의 채팅 모드 중 하나입니다. 나머지는 Conversation(대화)과 Roleplay(롤플레이)입니다.

Game Mode에서는 AI 게임 마스터(GM)가 이야기를 진행합니다. 게임 마스터는 세계를 서술하고, 만나는 캐릭터를 모두 연기하고, 다음에 무슨 일이 일어날지 정하는 AI입니다. 테이블톱 게임의 던전 마스터와 같은 역할입니다.

엔진은 턴이 이어지는 동안 게임 상태를 대신 추적합니다. 지도, 파티, 플레이어가 아닌 캐릭터(NPC), 아이템, 퀘스트, 게임 속 시간, 날씨가 여기에 들어갑니다. 게임은 여러 턴에 걸쳐 진행됩니다. 긴 게임은 여러 **세션**으로 나눌 수 있습니다. 테이블톱 모임이 캠페인을 여러 날에 나눠 진행하는 것과 같습니다. 캠페인은 이어지는 이야기 전체를 가리킵니다.

모든 규칙 요소를 다 써야 하는 것은 아닙니다. 전투와 주사위를 건너뛰고 이야기와 그림 위주로 Game Mode를 즐기는 사람도 있습니다. RPG 시스템은 필요할 때만 꺼내 쓰면 됩니다.

## 시작하기 전에

게임을 시작하는 데 꼭 필요한 것은 하나뿐입니다. GM이 사용할 AI 제공자 연결입니다. 연결은 Marinara를 AI 제공자에 이어 주어 글을 생성할 수 있게 해 줍니다. 아직 만들어 두지 않았다면 [AI 제공자에 연결하기](../connections/connecting-to-a-provider.md)를 참고하세요.

나머지는 모두 선택 사항이고 기본값은 꺼짐입니다. 다음 기능은 나중에 추가해도 됩니다.

- **이미지 생성.** Game Mode의 화면은 배경과 캐릭터 그림이 들어가는 구성입니다. 이 자리를 채우려면 이미지 생성 연결이 필요합니다. 설정 마법사의 **Visual Generation**(비주얼 생성) 설정은 기본이 꺼짐이라 직접 켜야 합니다. 켜지 않아도 이야기, 상태 추적, 전투는 그대로 쓸 수 있고 그림 영역만 비어 있습니다.
- **장면 효과용 Local Model.** Marinara는 사용 중인 컴퓨터에서 작은 모델을 직접 돌릴 수 있습니다. 화면에는 **Local Model (Gemma)**로 표시됩니다. 이 모델이 추가 비용 없이 배경과 음악을 제안합니다. 설정 마법사의 기본 선택이기도 합니다. [Local Model 설정](../connections/local-model.md)을 참고하세요.
- **Storyboard 에이전트.** **Agents > Download Agents**에서 설치한 다음, 정지 이미지나 움직이는 스토리보드를 쓰려면 게임을 다 만든 뒤 **Chat Settings > Agents**에서 활성화하세요.
- **동영상 생성 연결.** 장면 동영상이나 움직이는 스토리보드를 쓸 때만 필요합니다.
- **음악.** **Music DJ** 에이전트가 게임 음악을 재생할 수 있습니다. Spotify나 로컬 음악 폴더가 필요하며 기본은 꺼짐입니다.

## 설정 마법사

Game Mode 채팅을 만들면 **설정 마법사**가 열립니다. 단계는 7개입니다. 반드시 입력해야 하는 항목은 첫 단계의 GM 연결뿐이고, 나머지는 모두 무난한 기본값이 들어 있습니다. 마법사를 빠르게 넘기고 나머지는 Marinara에 맡겨도 됩니다.

7단계는 다음과 같습니다.

1. **Connection.** **Game Mode**를 **Overworld RPG**와 **Classic**(클래식) 중에서 고르세요. Overworld RPG는 아직 준비되지 않아서 지금은 새 게임이 **Classic**으로 시작합니다. [Classic 또는 Overworld RPG](#classic-or-overworld-rpg)를 참고하세요. 게임 이름을 정하고, GM 연결을 고르고, 필요하면 장면 효과 연결도 지정하세요. 장면 효과의 기본값은 **Local Model (Gemma)**입니다.
2. **World.** 장르, 배경, 분위기, 난이도, 콘텐츠 등급과 언어를 설정하세요. 배경 아래, 그리고 나중에 목표 아래에 제시되는 아이디어는 여러 종류의 세계관에서 오며, 마법사를 열 때마다 새로 섞입니다. **Combat Preference**(전투 방식)에서 **Classic**(메뉴 전투) 또는 **Tactical**(격자 전투)을 선택하세요. Tactical 게임에서는 전장 시드, 크기, 지형 지침도 선택적으로 지정할 수 있습니다. Game Mode 규칙 집합이 설치되어 있으면 아래에 **Rules**(규칙)가 나타납니다. **Marinara's own rules**(Marinara 자체 규칙)를 유지하거나 규칙 집합을 고르세요. [규칙 선택](#choosing-rules)을 참고하세요. Overworld RPG에서는 그 아래에 **Setting kit**(세계관 키트)와 **Your world**(내 세계)가 있습니다. [세계관 키트 고르기](#choosing-a-setting-kit)와 [세계 만들기](#making-a-world)를 참고하세요.
3. **Party.** 직접 연기할 페르소나와 **Game Master Mode**(GM 모드), 함께할 파티원을 고르세요. **GM intro message**(GM 소개 메시지)는 게임의 첫 메시지를 정합니다. [GM 소개 메시지](#the-gm-intro-message)를 참고하세요.
4. **Goals.** 이 모험에서 무엇을 기대하는지 GM에게 알려 주세요.
5. **Lorebooks.** GM이 사실로 다뤄야 할 로어북을 연결하세요. 로어북은 세계 설정을 모아 둔 것입니다. [로어북](../lorebooks/overview.md)을 참고하세요.
6. **Features.** Visual Generation, Music DJ, HUD 위젯 같은 선택 기능을 켜세요. 설치해서 쓰는 에이전트는 게임을 만든 뒤 **Chat Settings**에서 활성화할 수 있습니다.
7. **GM.** 연출 방식을 고르고, 세계가 만들어지기 전에 GM 고급 지시문을 검토하세요.

다 마쳤으면 **Start Game**(게임 시작)을 클릭하세요.

Tactical 게임에서 전장 옵션을 비워 두면 GM이 장면에 맞는 개요를 선택하고 엔진이 전장을 생성합니다. 고정 시드는 조우 입력이 같을 때 생성 결과를 재현합니다. 지형 지침으로 무너진 벽이나 숲속 공터 같은 요소를 GM에게 요청할 수 있습니다. 이동 규칙, 지형 보너스와 생성 실패는 [Game Mode: 전투](combat.md#tactical-battles-and-terrain)를 참고하세요.

<a id="classic-or-overworld-rpg"></a>

### Classic 또는 Overworld RPG

새 게임은 두 가지 Game Mode 중 하나로 진행됩니다. 첫 단계에서 고르며, 그 게임의 모든 세션에 유지됩니다.

- **Overworld RPG**(준비가 끝나면 기본값): 내 세계관에 맞춰 만든 세계를 오버월드 지도 위에서 걸어 다니며, 방문할 마을, 탐험할 장소, 내려갈 던전이 있습니다. 세계관 키트와 세계가 필요합니다. 키트를 고르기 전까지는 첫 번째 장르에 맞는 키트가 쓰이고(맞는 키트가 없는 장르는 High fantasy), 그 키트로 세계가 무작위로 만들어집니다.
- **Classic**: 예전부터 있던 그대로의 Game Mode입니다. 이야기는 장면 단위로 진행되며 장면 지도와 전투가 있고, 세계관 키트, 세계, 오버월드, 마을, 던전 지도는 없습니다.

이 선택지가 생기기 전에 만든 게임은 이전과 같이 진행됩니다. 세계가 있으면 Overworld 게임, 없으면 Classic 게임입니다.

Overworld RPG는 아직 마무리 중입니다. 준비가 끝날 때까지 이 카드는 흐리게 표시되고 "Overworld games, with a setting kit and a generated world, are not ready yet. New games start as Classic games."라는 안내가 붙습니다. 그동안 새 게임은 모두 Classic이며, 아래의 세계관 키트와 세계 선택은 나타나지 않습니다. 아래 내용은 Overworld RPG 게임에 대한 설명입니다.

<a id="choosing-rules"></a>

### 규칙 선택

**Rules**(규칙)는 규칙 집합이 하나 이상 설치된 경우 새 게임을 만들 때만 표시됩니다. **Combat Preference**와는 별개입니다. 하나는 판정과 캐릭터 시트의 작동 방식을, 다른 하나는 전투의 표시 방식을 정합니다.

- **Marinara's own rules**(Marinara 자체 규칙)가 기본값이며, 내장 d20 판정과 능력치 6개의 시트를 사용합니다.
- **5e (SRD 5.1)** 같은 규칙 집합에는 지원 범위의 짧은 설명과 전투 방식을 설명하는 한 줄이 표시됩니다. 전투를 자체 해결하는 규칙 집합은 그 사실을 명시합니다. 시트만 빌려주는 규칙 집합은 시트 자체의 체력, 에너지, 능력을 사용해 Marinara의 전투를 진행한다고 안내합니다. 둘 다 하지 않는 규칙 집합은 Marinara의 전투를 진행한다고 안내하고, 선택한 **Combat Preference**를 표시합니다.

규칙 집합이 전투를 자체 해결하면 전투 화면도 그 규칙 집합을 따릅니다. 메뉴에는 캐릭터 자신의 공격과 능력이 나오며 각 항목에 자체 행동 예산과 풀에서 무엇을 쓰는지 표시됩니다. 아래 패널에는 턴 순서, 라운드, 규칙 집합 이름을 쓰는 모든 참가자의 상태와 각 예산의 잔량이 나옵니다. 로그에는 "Juno attacks Rust jackal with Road axe: 8 (5 + 3) + 3 = 11 against Guard 6, a hit."처럼 실제 계산이 출력됩니다. 행동은 적용되는 순간 캐릭터 시트에 기록되므로 전투 중 탭을 닫아도 결과를 잃지 않으며, Game Master는 이후 숫자가 이미 확정되었다는 안내를 받습니다. 규칙 집합이 전장 한 칸의 자체 거리도 정하면 **Combat Preference**가 전투 표시 방식을 결정합니다. **Classic**은 위치 없이 진행하고, **Tactical**은 생성된 보드에서 이동하고 자체 단위로 근접 거리와 사거리를 재며 칸에 범위 형태를 겨눕니다. [전투](combat.md#games-whose-ruleset-resolves-its-own-fights)를 참고하세요. 거리를 정하지 않은 규칙 집합은 이 설정을 보존하지만 사용하지 않습니다.

규칙 집합은 게임을 만들 때 정해지며 해당 게임에 계속 유지됩니다. 나중에 바꾸거나 추가할 수 없습니다.

일부 규칙 집합은 **layers**(레이어)를 제공합니다. Low magic이나 Hard winter 같은 이름 붙은 변형으로, 규칙 집합 아래에 스위치로 표시되며 각각 무엇을 하는지 한 줄 설명이 붙습니다. 레이어는 난이도를 더 가혹하게 만들거나, 캐릭터 시트의 선택지를 좁히거나, 시트 편집기의 선택 목록에서 미리 만들어 둔 항목 일부를 빼거나, 설정 단계에서 만드는 세계를 포함해 Game Master에게 추가 지시를 줄 수 있습니다. 서로 함께 쓸 수 없는 레이어도 있으며, 그럴 때는 마법사가 고를 수 없는 쪽을 비활성화합니다. 레이어는 규칙 집합과 똑같이 게임이 시작되면 고정되며, 레이어가 빼는 항목을 이미 쓰고 있는 시트는 그 항목을 그대로 유지합니다.

규칙 집합을 얻는 곳은 두 가지입니다. 공식 규칙 집합은 **Download Agents**(에이전트 다운로드)에서 설치하며, 그곳에 **Rules** 표시가 붙어 있습니다. 커뮤니티 규칙 집합은 파일이나 제작자의 GitHub 저장소에서 가져오며, `local/ember-roads`나 `alice/v20`처럼 출처별로 분류됩니다. 가져오기에는 에이전트를 가져올 때와 같은 **Allow custom Agent imports**(사용자 지정 에이전트 가져오기 허용) 스위치가 쓰입니다. 이 스위치가 꺼져 있는 동안 가져온 규칙 집합은 새 게임에서 빠지지만, 이미 그 규칙 집합을 쓰는 게임은 계속 작동합니다. 가져온 규칙 집합을 쓰는 게임은 항상 게임을 만들 때의 정확한 버전으로 진행됩니다. 직접 만들려면 [Game Mode 규칙 집합 작성하기](../extending/writing-rulesets.md)를 참고하세요.

규칙 집합을 고르면 **Party** 단계의 선택 항목 아래에 페르소나와 파티원이 나열되고, 그 규칙 집합 기준으로 누가 **Has a sheet**(시트 있음)이고 누가 **Starts on a blank sheet**(빈 시트로 시작함)인지 알려 줍니다. 시트는 캐릭터나 페르소나 편집기의 **Stats**(스탯)에서 추가합니다([규칙 집합 시트](../characters/colors-and-stats.md#ruleset-sheets) 참고). 게임은 세계를 생성할 때 각 시트의 사본을 가져갑니다. 게임 안에서 바꾼 내용은 캐릭터나 페르소나에 반영되지 않습니다. 시트가 없는 파티원은 모든 값이 규칙 집합의 기본값인 빈 시트를 받습니다. 세계 생성이 점수를 지어내는 일은 없습니다.

공유된 설정 파일은 규칙 집합을 기억합니다. 그런 파일을 가져왔는데 해당 규칙 집합이 없거나 더 오래된 버전만 있다면, 마법사가 어떤 규칙 집합이었는지 알려 줍니다. 그 규칙 집합을 설치해 고르지 않는 한 게임은 Marinara 자체 규칙을 사용합니다.

<a id="choosing-a-setting-kit"></a>

### 세계관 키트 고르기

**Setting kit**는 내 세계가 어떤 말로 쓰이는지 Game Master에게 알려 줍니다. 장소를 무엇이라 부르고 정착지가 얼마나 커질 수 있는지, 어떤 종류의 집단이 있는지, 장소가 무엇으로 유명할 수 있는지, 사람들이 어떻게 이동하는지, 한 해와 하루를 무엇이라 부르는지, 그 세계의 민족이 스스로를 어떻게 이름 짓는지, 이긴 전투에서 무엇이 떨어지는지, 돈과 그 세계에서 파는 일상 물건, 원소, 전투가 벌어지는 장소, 그리고 어떤 계열의 아트, 음악, 소리를 쓰는지가 들어 있습니다([게임 에셋](game-assets.md#a-settings-own-art-and-music) 참고). 경쟁, 범죄, 전쟁, 재해처럼 세계에 어떤 종류의 변화가 있는지, 그리고 세계가 스스로 얼마나 빨리 바뀌는지도 정합니다. 꺼진 종류는 배경 사건으로 끌려 들어오지 않고 장면이 그쪽으로 번지지도 않으므로, 말다툼은 말다툼으로 남을 수 있습니다.

세계관 키트는 새 Overworld RPG 게임에만 제공되며, 이런 게임에는 항상 키트가 있습니다. 키트를 고르기 전까지는 첫 번째 장르에 맞는 키트가 쓰입니다. 시작용 키트는 8가지입니다. 하이 판타지, 무협과 선협, 현대, 현대 초자연, 1920년대, 사이버펑크, 스페이스 오페라, 포스트 아포칼립스입니다. 현대 키트는 기본적으로 잔잔합니다. 범죄, 분쟁, 재난이 없고 변화가 느려서 일상물에 어울립니다.

장르를 고르기 전에 키트를 고르면 그 키트에 맞는 장르가 설정됩니다. 예를 들어 사이버펑크 키트는 **Cyberpunk**, 무협과 선협 키트는 **Wuxia**를 설정하며, 그 뒤로 배경과 목표 아이디어도 키트 고유의 것부터 제시됩니다. 직접 고른 장르는 그대로 유지됩니다.

키트를 고른 뒤 **Write it for my setting**(내 배경에 맞게 다시 쓰기)을 누르면 Game Master 연결이 고른 장르, 배경, 분위기에 맞춰 키트를 다시 씁니다. 모델이 쓴 결과가 앞뒤가 맞지 않으면 이유와 함께 한 번 더 요청하고, 그래도 안 되면 마법사가 무엇이 잘못됐는지 알려 주고 원래 키트를 유지합니다. **Change its words**(용어 바꾸기)를 누르면 키트의 모든 용어를 편집할 수 있습니다. 목록은 한 줄에 쉼표로 구분해 입력합니다. 이름이 비어 있거나 정착지가 없는 것처럼 문제가 있는 키트는 무엇이 잘못됐는지 표시하며, 고칠 때까지 게임을 시작할 수 없습니다.

게임은 만들 때의 키트를 계속 유지합니다. Game Master는 매 턴 키트를 읽고, 세계 생성도 키트의 용어를 사용합니다. 공유된 설정 파일에도 키트가 함께 들어갑니다.

Experience는 자체 **map pack**(지도 팩)을 함께 배포할 수 있습니다. 지도 팩에는 세계관 키트, 미리 만든 지도, 자체 타일이 들어 있습니다. 그 Experience를 켜면 설정 화면에 키트가 이미 정해진 것으로 표시되고(고를 키트가 없습니다), 지도가 들어 있다면 고를 수 있는 **Map**(지도)도 나타납니다. 게임은 그 지도에서 진행되며 Experience의 타일로 그려집니다. Experience를 끄면 직접 고른 선택이 돌아옵니다.

**Download this kit**(이 키트 다운로드)는 키트를 공유용 파일(`.worldkit.json`)로 저장하고, **Import a kit file**(키트 파일 가져오기)은 그런 파일을 다시 읽어 들입니다. **Import a world file**(세계 파일 가져오기)은 세계 하나를 통째로 가져옵니다(아래 참고).

### 세계 만들기

세계관 키트를 고르면 **Your world**가 게임이 시작되기 전에 키트의 용어로 세계 전체를 펼쳐 놓습니다. 지역, 키트의 단계에 있는 모든 크기의 정착지, 각 장소가 무엇으로 유명한지, 그리고 그 사이를 잇는 길(도로, 강, 항로, 점프 항로)과 각 여정에 걸리는 날짜가 들어 있습니다. 새 Overworld RPG 게임에는 모두 세계가 있으며, 바꿀 수 있는 시드로 무작위로 만들어집니다.

세계는 **World seed**(월드 시드)로 만들어집니다. 시드, 키트, 브리프가 같으면 언제나 같은 세계가 만들어지므로, **Roll**(다시 굴리기)을 누르면 다른 세계가 나오고 숫자를 다시 입력하면 그 세계가 돌아옵니다. 그 아래의 미리보기는 게임에서 플레이할 세계입니다. 땅과 정착지를 그린 작은 지도, 파티의 시작 위치, 지역별 전체 정착지 목록이 표시됩니다.

- **Start from this lore**(이 로어에서 시작)는 체크한 로어북에서 로어가 밝힌 장소와 날짜가 있는 사건을 읽어 들입니다. 각각은 로어에 적힌 그대로, 출처 항목과 함께 유지됩니다. **Build around the lore**(로어를 중심으로 만들기)는 그 주위로 세계를 채우고, **Only the lore's places**(로어의 장소만)는 그 밖에 아무것도 만들지 않습니다.
- **Write the world's brief**(세계 브리프 작성)는 나머지를 Game Master 연결에 요청합니다. 게임이 시작될 때의 현재 상황, 주요 장소, 현재 상황의 중심에 있는 집단(각 집단이 원하는 것과 동맹, 경쟁자), 그리고 세계가 만들어 내는 장소와 사람의 이름을 키트의 각 민족 고유의 소리와 순서에 맞춰 받습니다. 모델이 무엇을 쓰든 로어의 장소는 유지되며, 키트에 맞지 않는 내용은 빠지고 그 수가 집계됩니다. 모델이 거듭 쓰는 몇몇 이름도 마찬가지입니다. **Change the brief**(브리프 바꾸기)를 누르면 각 민족의 이름과 성을 포함해 브리프의 내용을 편집할 수 있습니다.

브리프가 없으면 세계는 키트와 로어의 장소만으로 이루어지며, 세계가 만들어 낸 장소에는 브리프가 이름을 붙일 때까지 번호가 매겨집니다.

세계에는 과거도 있습니다. 게임이 시작되기 전에 세계 자체의 엔진이 건국 시점부터 한 해씩 세계를 진행시킵니다. 모든 정착지가 세워져 지금의 크기로 자라고, 브리프의 집단이 근거지에 세워져 지도자를 얻고 잃으며 서로 가까워졌다 멀어집니다. 세계에 그런 요소가 있다면 도적, 전쟁, 기근이 흔적을 남기고 일부 장소는 그 때문에 사라집니다. 심각한 변화는 한동안 조짐이 쌓인 뒤에만 일어나며(전쟁 전의 긴장, 기근 전의 가뭄), 키트가 허용하는 종류의 변화만 사용합니다. 잔잔한 세계는 과거도 잔잔합니다. 로어가 밝히거나 브리프가 지목한 날짜가 있는 사건은 그 시점과 장소에서 일어납니다. 시드와 브리프가 같으면 언제나 같은 과거가 만들어집니다.

Game Master는 과거의 가장 두드러진 사건, 파티가 있는 장소를 어느 집단이 차지하고 있고 누가 그 집단을 이끄는지, 그리고 그 장소의 과거를 전달받습니다. 다른 장소나 집단에 대해서는 질문할 수 있으며, 다음 턴에 답을 받습니다.

모든 정착지에는 주민이 있으며, 파티가 도착할 때 시드로 정해집니다. 큰 장소일수록 주민이 많고, 각 주민은 자기 문화의 이름 목록에서 온 이름, 그 장소가 유명한 분야에 맞는 직업, 성향, 관심사, 말투와 외모를 갖습니다. 다른 곳에서 온 주민도 있습니다. Game Master에게는 현재 장소에서 파티가 아직 만나지 않은 주민 몇 명이 제시되며, 새로운 인물이 장면에 들어올 때 그중 한 명을 등장시킵니다. Game Master가 전체 이름으로 부른 인물은 하는 일과 외모와 함께 게임이 추적하는 캐릭터에 추가되므로, 이름이 같은 두 사람도 구분됩니다. 브리프의 이름 목록이 없으면 주민은 직업으로 불립니다.

플레이 중에 Game Master는 파티가 어디에 있는지, 거기서 어디로 갈 수 있는지, 각 길에 시간이 얼마나 걸리는지 항상 알고 있습니다. 파티가 가는 곳은 장소 태그로 지정합니다. 세계 목록에 있는 장소는 세계가 정한 크기를 유지합니다. 시장이 있는 규칙 집합에서는 시장 단계에서도 그에 맞는 크기를 받으므로, 세계의 수도가 시장에서 가장 큰 장소가 됩니다. 농가나 야영지처럼 세계 목록에 없는 장소는 Game Master가 붙인 이름을 유지합니다. 게임이 시작되면 세계의 과거는 고정됩니다. 배치도 직접 가한 편집(아래 참고)을 제외하면 고정됩니다. 공유된 설정 파일에는 처음 만들어진 그대로의 세계가 들어갑니다.

파티가 세계에 한 일은 그대로 남습니다. 파티가 집단을 돕거나 방해하고, 두 집단을 친구나 적으로 만들고, 집단의 편을 들거나 배신하고, 장소를 발전시키거나 훼손하고, 집단을 위해 장소를 차지하고, 집단을 무너뜨리고, 누군가를 집단의 우두머리로 앉히거나, 장소를 폐허로 만들면 Game Master가 응답에 그 사실을 기록합니다. 이야기가 새로 들여온 장소나 집단을 기록할 때와 같습니다. 각 변경은 세계와 대조해 확인합니다. 아늑한 현대 세계의 전쟁처럼 키트가 꺼 둔 종류의 변화나, 세계에 없는 장소나 집단을 지목한 변화는 거부됩니다. 그 뒤로 Game Master는 이야기가 남긴 상태의 세계를 전달받습니다. 그 장소의 형편, 장소를 차지한 집단과 그 지도자, 파티가 그곳에서 한 일, 파티가 상대한 각 집단과의 관계, 플레이가 시작된 뒤 바뀐 내용입니다. 이야기가 추가한 장소는 파티가 갈 수 있는 장소입니다. 변경은 그것을 만든 응답에 속하므로, 스와이프나 재생성, 메시지 삭제를 하면 그 응답과 함께 변경도 취소됩니다.

세계는 파티가 없어도 흘러갑니다. Game Master가 시간이 흐른다고 말하면(여행, 하룻밤 휴식, 긴 기다림) 세계는 한 주씩 스스로 진행되며, 키트에 있는 종류의 변화만 일어납니다. 형편이 좋아지거나 나빠지고, 새로 온 사람들이 정착하고, 집단이 가까워지거나 경쟁 관계가 되고, 우두머리가 물러납니다. 세계에 그런 요소가 있다면 어려운 시기의 장소에 문제가 생기고, 두 집단 사이의 긴장이 한 계절 동안 쌓인 뒤 전쟁으로 번질 수도 있습니다. 재앙은 결코 저절로 일어나지 않습니다. 재앙은 Game Master만 서술할 수 있으며, 파티 밖의 다른 사건과 마찬가지로 그 종류가 꺼져 있으면 거부됩니다. 파티가 있는 곳에서는 아무것도 미리 정해지지 않습니다. 그곳에서 일어나려는 일은 장면에서 펼쳐지도록 남겨 둡니다. 소식은 퍼져 나갑니다. Game Master는 길에 걸리는 날짜가 지난 뒤에야 먼 곳의 변화를 소문으로 듣고, 가까운 곳에서 무르익는 일은 직접 보므로 파티가 끼어들 수 있습니다. Game Master가 무르익는 전쟁을 멈춰 둘 수 있는 것은 그 전쟁이 세계에 맞지 않거나, 파티가 막을 현실적인 기회도 없이 게임을 망칠 때뿐입니다. 파티의 행동은 파티가 유명해질수록 더 큰 영향을 줍니다. 낯선 이의 도움은 별로 바꾸지 못하지만, 유명한 파티의 도움은 많은 것을 바꿉니다.

세계는 **hand edits**(직접 가한 편집)도 유지할 수 있습니다. 세계 편집기, 즉 만들어진 세계를 바꾸는 도구로 가한 변경입니다. 장소의 이름을 바꾸거나 옮기고, 땅을 칠하고, 장소와 사람을 추가할 수 있습니다. 장소의 전술 전장을 칠하거나([전투](combat.md#tactical-battles-and-terrain) 참고) 마을을 직접 배치할 수도 있습니다([마을](map-time-weather.md#the-town) 참고). 편집 내용은 Game Master, 오버월드, 마을, World 탭 등 게임의 모든 부분에 즉시 반영됩니다. 이름을 바꾼 장소도 예전 이름으로 계속 찾을 수 있으며, Game Master는 그곳의 예전 이름을 전달받습니다.

직접 가한 편집은 지금부터의 세계를 바꿀 뿐, 과거는 절대 바꾸지 않습니다. 세계의 역사와 세계가 스스로 만든 변화는 그대로 남습니다. 추가한 정착지는 추가한 그대로 유지됩니다. 마을은 배치를 유지하므로, 추가한 장소와 사람은 다음 빈 건물 부지와 다음 빈 집에 들어갑니다.

세계는 파일로 옮길 수 있습니다. **Your world** 아래의 **Download this world**(이 세계 다운로드)는 만들고 있는 세계를 저장하고, 게임의 World 탭에 있는 **Download the world**(세계 다운로드)는 그 게임의 세계를 직접 가한 편집까지 모두 포함해 `.world.json` 파일로 저장합니다. 세계관 키트 옆의 **Import a world file**은 그런 파일을 새 게임 설정으로 읽어 들입니다. 파일의 세계관 키트를 고르고, 직접 가한 편집까지 포함해 그 세계를 만듭니다. **Your worlds**(내 세계 목록)는 Pixelforge 같은 제작 도구로 게임 밖에서 만든 세계처럼 라이브러리에 보관한 세계로 같은 일을 합니다.

세계 파일에는 세계의 **스토리**, 즉 제작자가 그 세계를 위해 쓴 사건과 장면도 담을 수 있습니다. 스토리는 세계와 함께 들어오며 같은 조건으로 유지됩니다. 플레이 중에 스토리의 장면은 Game Master의 응답 앞에 쓰인 그대로 서술에 나타납니다. 스토리가 퀘스트 목표를 보여 주면 그 목표가 일지의 World 탭에서 **Story**(스토리) 아래에 나열됩니다. 스토리를 직접 쓰려면 [Game Mode 스토리 스크립트 작성하기](../extending/writing-story-scripts.md)를 참고하세요.

직접 가한 편집과 스토리는 그 시드와 브리프에 맞춰 만들어졌으므로, 둘 중 하나라도 바꾸면 빠집니다. 읽을 수 없는 파일은 거부되며 마법사가 이유를 알려 줍니다. 세계 파일에는 만들어진 그대로의 세계도 들어 있으므로, 다른 버전의 세계 생성기로 만든 세계도 만들어진 그대로 열립니다. 그 정보가 없는 예전 파일은 거부됩니다. 파일의 내용 중 세계관 키트에 맞지 않는 것은 빠지며, 마법사가 무엇이 빠졌는지 알려 줍니다.

Game Mode 선택지가 생기기 전에 세계 없이 만든 게임에는, 원할 때만 나중에 세계를 줄 수 있습니다. 일지의 **World** 탭에 있는 **Make a world for this game**(이 게임의 세계 만들기)을 누르면 새 게임과 같은 세계관 키트와 세계 선택지가 나옵니다. 세계는 다음 턴부터 시작되며, 게임의 지난 턴, 지도, 인물은 그대로 남습니다. Overworld RPG가 준비되지 않은 동안에는 이 버튼이 흐리게 표시되고 설정 화면과 같은 안내가 붙습니다.

게임은 만들어진 그대로의 세계를 유지합니다. 장소, 인물, 마을, 역사는 게임이 시작될 때와 직접 가한 편집을 저장할 때마다 게임과 함께 저장되므로, 세계를 만드는 방식을 바꾸는 업데이트가 나와도 이미 플레이 중인 세계는 바뀌지 않습니다. 새 세션, 분기, 내보낸 채팅도 같은 세계를 유지하며, 이전 세션에서 세계가 흘러간 과정(형편, 통치자, 전쟁)도 실제로 펼쳐진 그대로 남습니다. 이전 버전의 세계 생성기로 만든 세계는 만들어진 그대로 계속 플레이할 수 있지만 더는 편집할 수 없습니다.

세계가 있는 게임은 **오버월드**에서 열립니다. 오버월드는 세계를 픽셀 지도로 그린 것으로, 세계의 길을 따라 파티를 정착지에서 정착지로 걷게 하고 파티가 있는 마을에 들어갈 수 있습니다. 장면 보기로는 바로 전환할 수 있습니다. [오버월드](map-time-weather.md#the-overworld)를 참고하세요.

<a id="the-gm-intro-message"></a>

### GM 소개 메시지

**Party** 단계의 **GM intro message**는 게임이 어떻게 시작될지 정합니다.

- **None**(없음, 기본값): Game Master가 알아서 게임을 시작합니다.
- **Defined**(직접 지정): 첫 메시지를 보여 줄 그대로 입력하세요. 게임은 정확히 이 메시지로 시작하며, 재생성해도 같은 텍스트가 나옵니다.
- **Guided**(지침 기반): 시작 장소, 그곳에 있는 인물, 처음 일어나는 일처럼 시작 장면이 어떻게 흘러가야 하는지 설명하세요. Game Master가 그 설명을 바탕으로 시작 장면을 씁니다.

텍스트는 최대 8,000자까지 쓸 수 있습니다. 이중 중괄호는 쓸 수 없고, **Guided** 텍스트에는 대괄호도 쓸 수 없습니다. 쓸 수 없는 텍스트라면 입력란에 그 사실이 표시됩니다. 세계의 스토리가 자체 시작 메시지를 가져올 수도 있습니다. 스토리가 이를 잠그면 입력란에 "Set by this Experience and locked, so the game opens as its creator meant."라는 안내와 함께 표시되며 바꿀 수 없습니다.

### 알아 두면 좋은 기본값

아래는 **World**(월드), **Party**(파티), **Features** 단계의 처음 값입니다. 전부 바꿀 수 있습니다.

| 설정 | 기본값 | 비고 |
|---|---|---|
| Genre | Fantasy | 여러 개 선택 가능하며, 직접 입력한 항목도 추가할 수 있습니다. 세계관 키트를 먼저 고르면 키트가 자체 장르를 설정합니다 |
| Tone | Heroic | 여러 개 선택 가능합니다 |
| Difficulty | Normal | Casual, Normal, Hard, Brutal 중에서 고릅니다. 높일수록 전투가 가혹해집니다 |
| Content Rating | SFW | SFW 또는 NSFW입니다. NSFW는 성인용 내용을 허용할 뿐 강제하지 않습니다 |
| Language | English | 게임 속 모든 글이 이 언어로 작성됩니다 |
| Game Master Mode | Standalone GM | Standalone GM은 GM을 대신 만들어 주고, Character GM은 가지고 있는 캐릭터 카드를 GM으로 씁니다 |
| Visual Generation | Off | 이미지를 쓰려면 켜세요. 이미지 생성 연결이 필요합니다 |
| Game Presentation | Standard | **Storyboard Optimized**는 Storyboard Game Prompt로 GM 서술을 다듬을 뿐, Storyboard 에이전트를 설치하거나 활성화하지는 않습니다 |
| Music DJ | Off | Spotify나 로컬 음악 폴더가 필요합니다 |
| Custom HUD Widgets | On | 새로 만든 세계에 맞춰 AI가 만든 상태 위젯을 씁니다 |
| Start Muted | Off | 소리를 끈 상태로 게임을 시작합니다 |

Game Mode가 처음이라면 **Game Master Mode**를 **Standalone GM**에 그대로 두세요. Marinara가 공정하면서 살짝 능청스러운 GM을 만들어 주므로, 직접 GM 카드를 쓰기 전에 이 모드의 감을 잡을 수 있습니다.

GM 턴을 영상으로 찍을 수 있는 시각적 장면 단위로 쓰게 하려면 마지막 단계에서 **Storyboard Optimized**(스토리보드 최적화)를 고르세요. 이 선택은 GM 서술에 쓰이는 내장 프리셋 **Storyboard Game Prompt**를 지정합니다. Storyboard 에이전트를 설치하거나 활성화하지 않고, 이미지 생성이나 동영상 생성을 켜 주지도 않으며, 골라 둔 연결이나 에이전트의 플래너와 포맷터 기본값도 바꾸지 않습니다. 게임을 만든 뒤에 Storyboard를 따로 설치하고 활성화한 다음, **Chat Settings > Agents > Storyboards**에서 키프레임, 플래너, 이미지, 동영상 설정을 지정하세요.

설정을 마친 뒤에도 애니메이션풍 단일 컷 조합을 그대로 쓸 수 있습니다. Animation Planner에는 **Anime Episode Director**를, Storyboard Video Prompt에는 **Anime Game Video**를 고르세요.

**GM Prompt**(GM 프롬프트) 편집기는 선택한 연출에 실제로 적용되는 프롬프트를 미리 보여 줍니다. **Storyboard Optimized**를 고른 상태에서 편집기를 열면 키프레임 개수 매크로까지 포함한 Storyboard Game Prompt가 나타납니다. 그 텍스트를 그대로 두면 내장 프리셋이 계속 선택된 상태로 남고, 손을 대면 연출 프리셋을 덮어쓰는 사용자 지정 프롬프트가 만들어집니다.

## AI 호출의 3가지 종류

Game Mode는 서로 다른 3가지 AI 호출을 씁니다. 이 구분을 알아 두면 비용과 오류가 어디에서 생기는지 파악하기 쉽습니다.

1. **월드 생성.** **Start Game**을 클릭할 때 한 번만 실행됩니다. GM 연결이 JSON이라는 형식으로 크고 짜임새 있는 문서 하나를 돌려줍니다. 이 문서에는 월드 개요, 시작 지도, NPC, 파티의 게임 시트, 화면에 표시될 위젯이 담깁니다. JSON은 규칙이 엄격한 텍스트 형식이라 AI가 형식을 정확히 지켜야 하며, 그러지 않으면 게임이 읽어 들이지 못합니다. 가장 까다로운 단계이고, 그래서 모델 선택이 여기서 가장 중요합니다.
2. **게임 턴.** 메시지를 보낼 때마다 현재 상태를 담은 프롬프트가 새로 만들어집니다. 그러면 GM이 이야기를 서술하고 세계를 갱신합니다. 전투 라운드 계산은 모델이 아니라 엔진이 하므로 결과가 공정하고 일관되게 유지됩니다.
3. **세션 요약.** 세션을 끝내면 GM이 짜임새 있는 요약과 연속성 메모를 작성합니다. 새 세션을 시작하면 다음 이야기가 자연스럽게 이어지도록 짧은 연결 메시지를 씁니다. 지난 세션은 요약으로 압축되므로 캠페인이 길어져도 모델이 감당할 수 있습니다.

## 말할 대상 모드: 지금 누구에게 말하는지

입력창에는 파일 첨부 버튼 옆에 작은 말풍선 버튼이 있습니다. 툴팁은 **Choose who to address**(말할 대상 선택)입니다. 이 버튼으로 메시지를 누구에게 보낼지 정하며, 상태는 3가지입니다.

- 기본값에서는 메시지가 장면 안으로 들어갑니다. 게임 속 평범한 행동이나 대사가 되며, GM과 파티가 이야기 안에서 반응합니다.
- **Talk to Party**(파티에게 말하기)는 `[To the party]` 표시를 붙여 동료들에게 직접 말을 겁니다. "여기서는 어떻게 할까?" 같은 전술 논의에 쓰세요. 이 항목은 파티가 비어 있지 않을 때만 나타납니다.
- **Talk to GM**(GM에게 말하기)은 `[To the GM]` 표시를 붙여 GM에게 캐릭터 밖에서 말을 겁니다. "내 캐릭터가 그 신전을 알고 있나요?" 같은 질문이나 진행 속도를 조절해 달라는 요청에 쓰세요.

메뉴에서 지금 켜져 있는 모드에는 **On** 표시가 붙습니다. **Talk to Party**나 **Talk to GM**을 끄려면 같은 메뉴 항목을 다시 클릭하세요. 그러면 메시지는 다시 장면 안으로 들어갑니다.

<a id="optional-tool-planning-and-lore-searches"></a>

## 선택적 도구 계획과 로어 검색

플레이 중 **Chat Settings → Function Calling**(채팅 설정 → 함수 호출)을 여세요. **Let the GM search lore**(GM의 로어 검색 허용)를 사용하면 다른 선택적 도구를 모두 켜지 않고도 GM이 의미를 기준으로 정보를 찾을 수 있습니다. 먼저 해당 로어북의 벡터화를 켜고 항목을 벡터화하세요. 검색은 활성화한 로어북과 폴더, 채팅별 항목 스위치를 따릅니다. 설정한 임베딩 연결을 사용하며 모델의 후속 요청이 추가될 수 있습니다.

Game 채팅에서 도구로 로어북을 검색하려면 **Enable Tool Use**가 켜져 있어도 **Let the GM search lore**가 필요합니다. 이 설정이 꺼져 있으면 도구 선택 목록에서 `search_lorebook`을 사용할 수 없습니다. 이미 선택한 항목은 설명과 함께 계속 표시되므로, 항목을 제거하거나 로어 검색을 다시 켤 수 있습니다.

**Game tool connection**(게임 도구 연결)의 기본값은 **Same as narrator**(서술자와 동일)로, 일반 도구 반복 흐름을 유지합니다. 다른 연결을 선택하면 서술 전에 별도의 계획 요청을 한 번 실행합니다. 그 모델이 도구를 선택하고 서술자는 실제 결과를 텍스트로 받습니다. 추가 요청 비용은 선택한 연결에 청구됩니다. 저렴한 모델로 도구 비용을 줄일 수 있지만 다른 도구를 고를 수도 있습니다. 이 단일 계획 단계는 첫 결과를 바탕으로 두 번째 검색을 이어서 실행할 수 없습니다. 서술자가 여러 차례 도구를 사용하며 판단하게 하려면 **Same as narrator**를 사용하세요(한 턴에 최대 4차례까지이며, 그 뒤에는 그때까지 얻은 결과로 서술합니다).

Claude와 Grok 구독 연결은 네이티브 도구 호출을 지원하지 않습니다. 관련 컨트롤에 설명이 표시되며 지원되는 Game 도구 연결을 선택할 때까지 비활성화됩니다. 텍스트 명령과 주사위 태그는 계속 작동합니다. 별도 연결이 없거나 요청에 실패하면 요청한 도구 작업을 조용히 생략하고 서술하는 대신 해당 턴에 실패를 알립니다.

**Finish rolled turns in one request**(굴림 턴을 한 요청으로 완료)는 위의 두 번째 호출을 바꿉니다. 보통 주사위를 굴리는 턴은 초안과 실제 숫자로 다시 쓰기에 두 요청이 필요합니다. 켜면 Game Master가 결과를 미리 보지 않고 쓰고 엔진이 나중에 숫자를 채워 한 요청으로 끝납니다. 기본값은 꺼짐입니다. 다만 **Enable Tool Use**가 켜진 상태의 주사위 도구 호출과, 항상 자체 계획 요청을 하는 별도 **Game tool connection**은 여전히 추가 요청을 만듭니다. [Game Mode: 주사위와 기술 판정](dice-and-skill-checks.md#finishing-a-rolled-turn-in-one-request)을 참고하세요.

로컬 모델이 제한된 GPU 메모리를 공유한다면 **Chat Settings → Agents**를 열고 **Run Game tasks one at a time**(Game 작업을 하나씩 실행)을 켜세요. 해당 Game 채팅 안에서 서술, 에이전트, 장면 미디어가 서로의 완료를 기다립니다. 이 옵션은 처음에는 꺼져 있으며, 다른 채팅이나 애플리케이션에 대해 GPU를 독점 예약하지 않습니다. 기존 취소 기능은 실행 중과 대기 중에도 사용할 수 있습니다.

## 에이전트 켜기

에이전트는 GM과 함께 돌아가는 선택형 AI입니다. 게임에서 쓰려면 진행 중에 **Chat Settings**(채팅 설정)를 열고 **Agents**(에이전트) 섹션으로 가서 **Enable Agents**(에이전트 활성화)를 켜세요. 에이전트는 호출을 추가로 하므로 비용이 늘어납니다.

Game Mode에서 알아 두면 좋은 에이전트는 2가지입니다.

- **Game Session Keeper**는 세션이 이어질 때 흐름이 끊기지 않도록 돕습니다.
- **Music DJ**는 배경 음악을 고릅니다. Spotify나 로컬 음악 폴더가 필요합니다.

Game Mode에서는 **Review Agent Outputs**(에이전트 출력 검토)도 쓸 수 있어서 에이전트가 만들어 낸 결과를 확인할 수 있습니다. 에이전트 전반은 [에이전트: 채팅을 도와주는 AI](../agents/agents-overview.md)에서 다룹니다.

## 모델 고르기

Game Mode에서 가장 어려운 부분은 월드 생성입니다. 빠진 필드 하나 없이 길고 엄격한 JSON 문서를 모델에게 요구하기 때문입니다. 평범한 채팅은 잘 해내는 모델도 이 단계에서는 실패할 수 있습니다.

월드 생성에는 유료 연결로 쓰는 최신 최상위 모델을 권합니다. 2026년 기준으로 주요 제공자의 최상위 등급 모델에서 결과가 좋았다는 보고가 많습니다. Anthropic Claude, OpenAI GPT, Google Gemini가 그 예입니다. 구체적인 모델 이름은 자주 바뀌므로 고정된 목록이 아니라 예시로만 봐 주세요.

이후의 게임 턴에는 더 저렴한 모델로 낮춰도 될 때가 있습니다. 턴에서는 엄격한 JSON이 아니라 서술을 요구하기 때문입니다. GM이 NPC를 잊거나 앞선 설정과 어긋나기 시작하면 다시 더 강한 모델로 올리세요.

월드 생성에는 무료 모델이나 자동 라우팅 모델을 피하세요. 월드 생성용 JSON을 만들지 못하는 작은 모델로 연결될 수 있습니다. 크기가 작은 오픈 웨이트 모델도 대개 이 단계에서 실패합니다.

파라미터 전체 설명은 [생성 파라미터](../prompts/generation-parameters.md)에서 확인하세요.

## 게임 컨트롤

컴퓨터에서는 채팅 오른쪽 위 근처의 버튼으로 게임 컨트롤을 엽니다. 휴대폰에서는 이동할 수 있는 점 세 개짜리 **Chat tools**(채팅 도구) 메뉴에서 찾으세요.

- **Game controls**(게임 컨트롤, 게임 컨트롤러 아이콘):
  - **Retry turn**(턴 재시도), **Retry scene analysis**(장면 분석 재시도), Music DJ가 게임 음악을 재생할 때의 **Retry Music DJ**(Music DJ 재시도), **Retry assets image generation**(에셋 이미지 생성 재시도)이 있습니다.
  - 게임 배경에서 스토리보드가 재생 중이면 다시 재생, 재생/일시정지, 음소거도 있습니다.
  - 세계가 있는 게임에서는 **Show the scene**(장면 보기)과 **Show the overworld**(오버월드 보기)로 보기를 전환하고, **Show the map**(지도 보기)으로 열려 있는 던전, 동굴, 정거장 지도로 돌아갑니다.
  - **Edit game data**(게임 데이터 편집)는 게임의 저장 데이터를 직접 고치고([게임 데이터 직접 고치기](sessions-and-saves.md#editing-game-data-by-hand) 참고), **Checkpoints**(체크포인트)는 게임을 이전 시점으로 되돌립니다([게임이 저장되는 방식](sessions-and-saves.md#how-your-game-saves) 참고).
- **Session**(세션, 깃펜): 세션 기록, 일지, 세션 조작입니다. [Game Mode: 세션과 저장 데이터](sessions-and-saves.md)를 참고하세요.
- **Volume**(음량, 스피커): **Master**, **Music**, **Sound Effects**, **TTS**, **Ambient** 음량입니다.
- **Game Assets**(게임 에셋, 폴더): 장면 미디어와 Asset Browser입니다. [게임 에셋](game-assets.md)을 참고하세요.
- **Connected chat**(연결된 채팅): 게임이 Conversation에 연결되어 있을 때 나타납니다. [연결된 채팅](../chats/connected-chats.md#switching-between-connected-chats)을 참고하세요.

도구를 고르면 컴퓨터에서는 이동할 수 있는 창으로, 휴대폰에서는 화면 너비의 패널로 컨트롤이 열립니다. 컴퓨터에서는 버튼을 끌어 옮길 수 있습니다. 휴대폰에서는 점 세 개 메뉴를 옮기거나, 잠금을 풀어 메뉴 안의 도구 순서를 바꿀 수 있습니다. 창이나 패널을 닫은 뒤에도 같은 자리에서 도구를 다시 열 수 있습니다. [컨트롤 창과 버튼](../chats/chat-settings.md#control-windows-and-their-buttons)을 참고하세요.

이 컨트롤을 **Chat Settings** 안에 둘 수도 있습니다. 컨트롤 창을 열고 **Put back in Chat Settings**(채팅 설정으로 되돌리기)를 선택하면 그곳에 펼칠 수 있는 섹션으로 들어갑니다. 섹션의 별도 창 버튼으로 다시 별도 창으로 꺼낼 수 있습니다. 게임마다 이 선택을 저장하며, **Reset View**는 처음 배치로 되돌립니다. 컴퓨터에서는 버튼, 휴대폰에서는 Chat tools 항목입니다.

**Character Profiles**(캐릭터 프로필)는 컴퓨터와 휴대폰 모두에서 Chat tools 밖에 따로 있습니다. 초상화 버튼을 원하는 곳으로 끌어 놓고, 열어서 파티원을 고른 다음 그 캐릭터 시트를 보거나 편집하세요. 휴대폰에서는 **Map**에도 이동할 수 있는 버튼이 따로 있습니다. 둘 다 채팅 위젯 스타일을 따르고, 이 게임에서의 위치를 저장하며, 열린 창에서 잠글 수 있습니다. 데스크톱 지도는 기존 지도 패널 컨트롤을 그대로 유지합니다.

## 문제 해결

### 월드 생성이 JSON 오류나 422 오류로 실패합니다

가장 흔한 원인은 모델이 짜임새 있는 JSON을 끝까지 만들어 내지 못한 것입니다. 다음을 순서대로 시도하세요.

1. GM이 어떤 연결을 쓰고 있는지 확인하세요. 무료 모델이나 자동 라우팅 모델을 가리키고 있다면 성능이 좋은 유료 모델로 바꾸세요.
2. 다시 시도하세요. 일회성 실패도 있어서 같은 설정으로 두 번째에 성공하기도 합니다.
3. 무대나 선호 사항 입력란이 너무 길다면 줄이세요. 입력이 길수록 모델이 JSON 출력에 쓸 여유가 줄어듭니다.

호출이 거의 성공했는데 JSON이 조금 어긋난 정도라면 Marinara가 **Repair JSON**(JSON 수정) 창을 띄웁니다. 이 창은 모델의 원본 출력을 줄 번호가 붙은 편집기로 보여 줍니다. 상태 줄에서 JSON이 유효한지, 아니면 어떤 구문 오류가 있는지 알려 줍니다. 유효한 JSON을 보기 좋게 정리하려면 **Format**(형식 정리)을 클릭하세요. 그런 다음 **Apply Repaired JSON**(수정한 JSON 적용)을 클릭하면 전체를 다시 생성하는 비용 없이 고친 내용을 쓸 수 있습니다. **Repair JSON**은 세션 요약을 비롯한 다른 구조화 호출에서도 나타납니다.

증상별 해결 방법은 [Marinara Engine 문제 해결](../TROUBLESHOOTING.md)에서 더 볼 수 있습니다.

### 어두운 톤을 골랐는데 GM이 밝게 서술합니다

톤과 상관없이 밝은 어조를 유지하는 모델이 있습니다. 방법은 2가지입니다. 마법사의 선호 사항 입력란에 "서술을 음울하게 유지하고 실패를 미화하지 마세요."처럼 분명한 지시를 적으세요. 아니면 원하는 톤에 맞는 기본 어조를 가진 모델로 바꾸세요.
