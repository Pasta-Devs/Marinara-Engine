# 사용자 지정 이모지, 스티커, GIF

이 가이드에서는 내가 올린 사용자 지정 이모지와 스티커, GIF 검색, 그리고 캐릭터가 응답에서 쓸 수 있는 사용자 지정 이모지와 스티커를 정하는 방법을 설명합니다. 이 도구들은 Conversation Mode에서만 작동합니다. Roleplay와 Game Mode에는 기본 이모지 선택기만 있습니다.

## 이 도구가 있는 곳

Conversation 채팅에서 메시지 입력란 옆의 동그란 웃는 얼굴 버튼 **Emoji, GIFs & stickers**(이모지, GIF 및 스티커)를 클릭하세요. 입력란 위에 패널이 열립니다(휴대폰에서는 키보드 위의 시트입니다). 탭은 다음과 같습니다.

- **Emoji**(이모지): 표준 이모지 격자와, 업로드한 이미지가 모이는 별표 모양의 **Custom emojis**(사용자 지정 이모지) 탭입니다.
- **GIFs**: 실시간 GIF 검색입니다.
- **Kaomoji**(카오모지): `(^_^)` 같은 텍스트 얼굴입니다.
- **Stickers**(스티커): 업로드한 스티커입니다.

다른 입력 도구를 켜 두면 **Tools**(도구) 탭도 나타납니다.

## 사용자 지정 이모지 업로드하기

사용자 지정 이모지는 한 번 업로드해 두고 어느 Conversation 채팅에서나 쓰는 작은 이미지입니다. 직접 쓰는 메시지에서는 숏코드로 씁니다. 숏코드는 `:kekw:`처럼 콜론 사이에 이름을 넣은 것입니다.

1. 패널을 열고 **Emoji**로 이동한 다음 별표 모양의 **Custom emojis** 탭으로 이동하세요.
2. **Upload**(업로드)를 클릭하고 이미지 파일을 하나 이상 고르세요.
3. **Name this emoji**(이 이모지 이름 지정) 창에서 이름을 입력하고 **Add**(추가)를 클릭하세요.

이모지가 **Custom emojis** 격자에 나타납니다.

규칙은 다음과 같습니다.

- 이름은 1자에서 32자까지이며 영문 소문자, 숫자, 밑줄만 쓸 수 있습니다. 다른 문자는 앱이 알아서 바꿉니다.
- 이미지는 최대 256 x 256 픽셀입니다. 움직이는 GIF 파일도 채팅에서 그대로 재생됩니다.
- 이름은 겹치면 안 됩니다. 이미 있는 이름이면 `An emoji named ":name:" already exists.`라고 표시됩니다.

작동하지 않는 경우: 위 규칙에 맞게 이름과 이미지 크기를 확인하세요.

## 사용자 지정 이모지 사용하기

**Custom emojis** 격자에서 타일을 클릭하세요. 숏코드가 메시지에 들어가며, 메시지가 전송되지는 않습니다. 저장된 그대로 소문자로 숏코드를 직접 입력해도 됩니다.

Conversation 채팅에서 숏코드는 글줄 안의 작은 이미지로 표시됩니다. 이모지 숏코드만 있는 메시지는 더 크게 표시됩니다. 이름이 더 이상 없으면, 예를 들어 이모지를 삭제한 뒤에는 메시지에 일반 텍스트 `:kekw:`가 표시됩니다.

## 이름 바꾸기, 삭제, 내보내기, 가져오기

**Custom emojis** 탭 맨 위의 **Edit**(편집)를 클릭하면 편집 모드가 켜집니다.

- 타일을 클릭하면 **Rename emoji**(이모지 이름 변경)가 열립니다. 그다음 **Rename**(이름 바꾸기)을 클릭하세요.
- 타일의 휴지통 배지를 클릭하면 삭제합니다. **Delete emoji**(이모지 삭제)는 이 이모지를 쓴 메시지에 대신 텍스트가 표시된다고 경고합니다.
- **Export**(내보내기)를 클릭하면 사용자 지정 이모지를 모두 `marinara-custom-emojis.json`으로 다운로드합니다. 이미지는 파일 안에 들어 있습니다.
- **Import**(가져오기)를 클릭하면 내보낸 파일을 불러옵니다. 이름이나 크기 규칙에 어긋나거나 기존 이름과 겹치는 이모지는 건너뜁니다.

## 사용자 지정 스티커

스티커는 한 줄을 차지하며 따로 표시되는 더 큰 이미지입니다. 보통은 **Stickers** 탭에서 클릭해서 쓰며, 이때 삽입되는 텍스트는 `sticker:name:`입니다. **Stickers** 탭에서 **Upload**를 클릭하고, 이모지와 마찬가지로 **Edit**, **Export**, **Import**를 쓰세요. 다른 점은 다음과 같습니다.

- 업로드 창 이름은 **Name this sticker**(이 스티커 이름 지정)입니다.
- 가장 큰 이미지는 512 x 512 픽셀입니다(이모지는 256 x 256 픽셀).
- 내보내기 파일은 `marinara-custom-stickers.json`입니다.

스티커를 보내려면 타일을 클릭하세요. **Send sticker** 창에서 다음 중 하나를 고를 수 있습니다.

- **Send & reply**: 스티커를 하나의 메시지로 올리고 캐릭터가 답하게 합니다.
- **Add to message**: `sticker:name:` 텍스트를 메시지에 넣어 계속 입력할 수 있게 합니다.

## GIF 검색하기

**GIFs** 탭은 온라인 GIF 라이브러리인 Giphy를 검색합니다. 검색창에 입력하거나 인기 목록을 둘러본 다음, GIF를 클릭해 보내세요.

**시작하기 전에:** GIF 검색에는 무료 Giphy API 키가 필요합니다. 키는 Giphy 서비스를 Marinara가 쓸 수 있게 해 주는 비밀 코드입니다. 키가 없으면 이 탭에는 설정 카드가 표시됩니다. 키를 설정하려면 Marinara의 일반 텍스트 설정 파일인 `.env` 파일을 편집해야 합니다. 이 파일은 Marinara 프로젝트 폴더에 있고, Docker에서는 `/app/data/.env`입니다([.env 파일 편집하기](../CONFIGURATION.md#edit-the-env-file) 참고).

1. `https://developers.giphy.com/dashboard/`에서 Giphy 개발자 대시보드를 여세요.
2. 웹 앱용 API 키를 만들고 복사하세요.
3. 텍스트 편집기에서 `.env` 파일을 여세요.
4. 맨 끝에 다음 줄을 추가하되, `your_key_here` 대신 내 키를 넣고 파일을 저장하세요.

   ```text
   GIPHY_API_KEY=your_key_here
   ```

5. Marinara를 다시 시작하세요. 평소에 시작하던 방식으로 중지했다가 다시 시작한다는 뜻입니다([설치](../INSTALLATION.md) 참고).

GIF 결과는 Giphy의 성인 등급을 씁니다. 앱에서는 이 등급을 바꿀 수 없으므로 결과에 성인용 GIF가 포함될 수 있습니다. 안전한 결과만 주는 GIF 소스는 없습니다.

## 갤러리 이미지를 이모지나 스티커로 태그하기

Character Gallery나 Persona Gallery에 있는 이미지는 어느 것이든 이모지나 스티커가 될 수 있습니다. 그 캐릭터나 페르소나가 들어간 채팅에서만 작동합니다.

1. **Character Editor**나 **Persona Editor**를 여세요.
2. **Gallery**(갤러리) 탭을 연 다음 **Images** 하위 탭을 여세요.
3. 이미지 위에 마우스를 올리고 왼쪽 위 모서리의 태그 버튼을 클릭하세요.
4. **Make emoji** 또는 **Make sticker**를 고르세요.
5. **Custom Emoji** 또는 **Custom Sticker** 창에서 이름을 입력하세요.

태그 버튼에 이제 이름이 표시됩니다. 같은 크기 제한이 적용되며, 너무 큰 이미지는 빨간 오류가 표시됩니다. 나중에 바꾸려면 태그 버튼을 다시 클릭하세요. **Rename**, **Switch to sticker** 같은 전환 옵션, **Remove emoji** 같은 해제 옵션이 있습니다. 이미지는 일반 갤러리 이미지로도 그대로 남습니다.

## 선택 설정

Marinara는 응답하는 캐릭터에게 어떤 사용자 지정 이모지와 스티커를 써도 되는지 알려 줍니다. 고르는 방식을 바꾸려면 **Custom emojis** 탭이나 **Stickers** 탭 맨 위의 톱니바퀴 **Selection preferences**(선택 설정)를 클릭하세요. 두 탭 모두 같은 설정을 열며, 설정은 채팅마다 저장됩니다.

- **Semantic**(기본값): 최근 대화에 가장 잘 맞는 것을 제시합니다. 내 컴퓨터의 작은 모델을 쓰며, 쓸 수 없으면 무작위로 고릅니다.
- **Random**: 응답마다 무작위 세트를 제시합니다.
- **Tool-call**: 응답마다 모델이 어울리는 것을 고릅니다. **Select a model...**에서 모델을 고르세요. 아무것도 정하지 않았거나 실패하면 **Semantic**을 씁니다. 그룹 채팅에서 여러 캐릭터가 응답할 때는 건너뜁니다.

**Max offered (each)**(각 항목별 최대 제안 수)는 한 번에 제시하는 이모지 이름 수와 스티커 이름 수입니다. 기본값은 20이며 1에서 100까지입니다.

## 반응은 주 사용자 지정 이모지만 사용합니다

사용자 지정 이모지로 메시지에 반응할 수 있지만, **Custom emojis** 탭에 업로드한 이모지만 쓸 수 있습니다. 갤러리에서 태그한 이모지, 스티커, GIF는 반응으로 쓸 수 없습니다. [반응과 알림](getting-started.md#react-and-get-notified)을 참고하세요.
