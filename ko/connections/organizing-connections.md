# 연결 정리하기

이 가이드에서는 Marinara Engine에 저장해 둔 연결을 깔끔하게 관리하는 방법을 설명합니다. 연결 폴더, 검색과 정렬, 복제와 삭제, 랜덤 풀, **Quick Connection Switcher**(빠른 연결 전환기), 연결 내보내기와 가져오기를 다룹니다. 연결은 Marinara가 AI 서비스 한 곳에 접속하는 데 필요한 정보를 한데 저장해 둔 것입니다.

이 작업은 모두 **Connections**(연결) 패널에서 합니다. 패널을 열면 저장해 둔 연결이 행 목록으로 표시됩니다. 각 행에는 연결 이름이 있고, 그 아래에 제공자와 모델이 함께 표시됩니다.

## 연결 폴더

연결 폴더는 성격이 비슷한 연결을 묶어 두는 데 씁니다. 예를 들어 로컬 모델은 한 폴더에, 유료 제공자는 다른 폴더에 모아 둘 수 있습니다.

폴더를 만들려면 다음 단계를 따르세요.

1. 연결 목록 위에 있는 **New Folder**(새 폴더) 버튼을 클릭하세요.
2. "unnamed"라는 이름의 새 폴더가 생깁니다.
3. 구분하기 쉽도록 바로 이름을 바꾸세요(아래 참고).

폴더 이름을 바꾸려면 폴더 행을 더블 클릭하세요. 터치 화면에서는 두 번 탭하면 됩니다. 폴더 행을 선택한 뒤 **F2** 키를 눌러도 됩니다. 새 이름을 입력하고 Enter를 누르세요.

연결을 폴더에 넣으려면 연결 행을 끌어서 폴더 위에 놓으세요. 다시 빼내려면 폴더 아래쪽 영역으로 끌어다 놓으세요. 끌고 가는 동안 **Drop here to move out of folder**라는 안내가 표시됩니다.

터치스크린에서는 행을 길게 눌러 집어 든 다음 끄세요. 평소처럼 스와이프하면 목록이 스크롤됩니다.

폴더를 접거나 펴려면 폴더 행을 한 번 클릭하세요. 폴더 행에 표시되는 작은 숫자는 안에 들어 있는 연결 개수입니다.

폴더를 삭제하려면 폴더 행의 휴지통 아이콘을 클릭하세요. 폴더 안에 연결이 남아 있으면 Marinara가 **Delete Folder**(폴더 삭제) 창을 띄워 확인을 요청합니다. 빈 폴더는 확인 없이 바로 삭제됩니다. 폴더를 삭제해도 안에 있던 연결은 사라지지 않습니다. 그 연결들은 폴더에 넣지 않은 영역으로 돌아갑니다.

## 검색과 정렬

**Search connections** 입력란에 입력하면 목록이 바로 걸러집니다. 연결 이름, 제공자, 모델, 기본 URL, 이미지 또는 동영상 서비스, 임베딩 모델이 검색 대상입니다. 일치하는 항목이 없으면 "No connections match your search"가 표시됩니다.

검색 입력란 옆의 **Sort order**(정렬 순서) 드롭다운으로 목록 순서를 바꿉니다. 선택지는 5가지입니다.

| 선택지 | 동작 |
|---|---|
| **Custom** | 끌어다 놓아 직접 정한 순서입니다. |
| **A-Z** | 이름 기준 오름차순으로 정렬합니다. |
| **Z-A** | 이름 기준 내림차순으로 정렬합니다. |
| **Newest** | 최근에 만든 연결이 위로 옵니다. |
| **Oldest** | 오래된 연결이 위로 옵니다. |

순서를 직접 정하려면 연결 행을 위아래로 끌어다 놓으세요. 연결을 끌면 정렬이 자동으로 **Custom**으로 바뀝니다. 포커스가 있는 행은 Alt+Up이나 Alt+Down으로도 옮길 수 있습니다.

## 복제와 삭제

연결 행에 마우스를 올리면 동작 버튼이 나타납니다. 터치 화면에서는 행에 그대로 표시됩니다.

연결을 복제하려면 **Duplicate**(복제) 버튼(복사 아이콘)을 클릭하세요. 저장된 API 키까지 포함해 전부 복사됩니다. 복사본은 편집기에서 열리므로 바로 이름을 바꿀 수 있습니다. 확인 단계는 없습니다.

연결 하나를 삭제하려면 그 행의 **Delete**(삭제) 버튼(휴지통 아이콘)을 클릭하세요. Marinara가 **Delete Connection**(연결 삭제) 창을 띄우고 다음 문구를 보여 줍니다: Delete "your connection name"? This cannot be undone. **Delete**를 클릭하면 삭제됩니다.

여러 연결을 한 번에 삭제하거나 내보내려면 패널 위쪽의 **Select**(선택) 버튼을 클릭하세요. 선택 모드가 켜집니다. 원하는 연결을 탭한 다음, 아래쪽 동작 막대의 **Export**(내보내기) 또는 **Delete** 버튼을 사용하세요. 여러 개를 한 번에 삭제할 때는 실행 전에 **Delete Connections** 창이 뜹니다.

## 랜덤 풀과 Quick Connection Switcher

랜덤 풀을 쓰면 채팅이 답변을 생성할 때마다 다른 연결을 골라 씁니다. 요청을 여러 제공자나 모델에 나눠 보내고 싶을 때 유용합니다.

연결을 랜덤 풀에 넣으려면 해당 행의 셔플 아이콘을 클릭하세요. 툴팁에는 **Add to random pool**이라고 표시됩니다. 풀에 들어가면 툴팁이 **In random pool (click to remove)**로 바뀝니다. 아이콘을 다시 클릭하면 풀에서 빠집니다.

채팅에서 랜덤 풀을 쓰려면 **Chat Settings**(채팅 설정)를 열고 **Connection** 섹션에서 드롭다운의 **🎲 Random**을 선택하세요. Game Mode(게임 모드)에서는 이 드롭다운의 이름이 **GM / Party Model**입니다. 이렇게 하면 답변마다 풀에서 연결이 무작위로 선택됩니다.

답변에 선택된 연결이 실패했고 **Main**(메인)에 대체 연결을 설정해 두었다면, 대체 연결이 대신 답변을 씁니다. 알림에는 실패한 연결, 그 모델, 그리고 "key rejected", "rate limited", "not found" 같은 짧은 이유가 표시되므로 풀의 어떤 연결을 고쳐야 하는지 알 수 있습니다. 답변에는 작은 **Fallback**(폴백) 라벨이 남으며, 이 라벨을 탭하거나 마우스를 올리면 같은 내용을 다시 볼 수 있습니다.

**Quick Connection Switcher**(빠른 연결 전환기)는 지금 보고 있는 채팅의 연결과 그 모델을 더 빠르게 바꾸는 방법입니다. 채팅 입력 영역의 링크 아이콘을 클릭하면 열립니다. 왼쪽에는 연결 목록이, 오른쪽에는 선택한 연결의 **Models**(모델) 목록이 나타납니다.

- 연결을 클릭하면 현재 채팅에 바로 적용됩니다. 메뉴는 열린 채로 남으므로 이어서 그 연결의 모델을 고를 수 있습니다.
- 모델을 클릭하면 그 모델을 사용합니다. 모델은 해당 연결에 저장되고, 그 연결이 아직 채팅에 선택되어 있지 않았다면 함께 선택되며, 메뉴가 닫힙니다. 연결이 지금 사용하는 모델에는 체크 표시가 붙습니다. 연결 편집기에서와 마찬가지로, 목록에 있는 모델을 고르면 제공자가 알려 주는 경우 연결의 컨텍스트 크기와 출력 한도도 함께 바뀝니다.
- **Search or enter model ID…**(검색 또는 모델 ID 입력…) 입력란에 입력하면 목록이 좁혀집니다. Enter를 누르면 입력한 ID나 이름과 일치하는 모델, 또는 목록에 하나만 남은 모델이 선택됩니다. 목록에 없는 모델을 쓰려면 정확한 ID를 입력한 다음, 목록에 일치하는 항목이 없을 때 Enter를 누르거나 **Use "…"**("…" 사용) 행을 클릭하세요.
- 모델 옆의 별을 클릭하면 그 모델이 고정됩니다. 고정한 모델은 직접 입력한 모델까지 포함해 **Pinned**(고정됨) 아래 맨 위에 계속 표시됩니다. 별을 다시 클릭하면 고정이 해제됩니다.
- 연결의 모델을 처음 열면 Marinara가 제공자에게서 목록을 불러와 연결과 함께 저장하므로, 다음부터는 바로 표시됩니다. 제공자가 새 모델을 추가했을 때처럼 목록을 다시 불러오려면 검색 입력란 옆의 새로고침 버튼을 클릭하세요. 연결의 API 키, 기본 URL, 제공자를 바꿔도 새 목록을 불러옵니다.
- 제공자에 모델 목록이 없거나 제공자에 접속할 수 없으면 메뉴에 그렇다고 표시됩니다. 이때도 모델 ID는 직접 입력할 수 있습니다.
- 메뉴 위쪽의 주사위 버튼을 클릭하면 이 채팅의 랜덤 풀을 켜거나 끕니다.
- 랜덤 풀이 켜져 있는 동안에는 연결을 클릭할 때 적용되는 대신 풀에 추가되거나 풀에서 빠집니다. 풀에 들어 있는 연결에는 체크 표시가 붙습니다. 풀에는 연결이 하나로 정해져 있지 않으므로 **Models** 열은 숨겨집니다.

휴대폰에서는 메시지 입력란 옆의 꺾쇠 화살표를 탭한 다음 **Connections**(연결) 탭을 여세요. 연결을 탭하면 채팅이 그 연결로 바뀌고 메뉴가 닫힙니다. 모델을 고르려면 대신 연결 행 오른쪽 끝의 화살표를 탭하세요. 같은 메뉴에 그 연결의 모델이 열리며, 모델을 골라야만 채팅이 바뀝니다. 연결 목록으로 돌아가려면 뒤로 화살표를 탭하세요.

**모델 변경은 그 연결을 쓰는 모든 곳에 적용됩니다.** 메뉴 아래쪽의 안내 문구 "모델 변경 사항은 이 연결에 저장됩니다."는 같은 연결을 쓰는 에이전트, 보조 기능, 다른 채팅도 새 모델로 바뀐다는 뜻입니다. 임베딩 모델이나 캡션 연결처럼 연결에 있는 다른 모델 설정은 바뀌지 않습니다. 한 가지 용도에만 다른 모델을 쓰고 싶다면 연결을 복제한 다음 복사본을 바꾸세요.

## 연결 내보내기와 가져오기

연결을 파일로 내보내 백업하거나 다른 설치 환경으로 옮긴 뒤, 나중에 가져올 수 있습니다.

**내보내기 파일에는 API 키가 절대 포함되지 않습니다.** 연결을 가져온 다음에는 하나씩 열어서 API 키를 다시 입력해야 합니다. 고정한 모델은 포함되지만 저장된 모델 목록은 포함되지 않으므로, 연결의 모델을 처음 열 때 목록을 다시 불러옵니다.

연결 하나를 내보내려면 편집기에서 연결을 열고 **Export** 버튼(업로드 아이콘)을 클릭하세요. 여러 개를 한 번에 내보내려면 패널에서 **Select** 모드를 켜고 동작 막대의 **Export**를 클릭하세요. 다운로드가 시작되기 전에 Marinara가 **Export Connection Data**(연결 데이터 내보내기) 창을 띄우고 다음과 같이 경고합니다: This will export your connection data, WITHOUT your provided API Key. Remember to never share those with others! **Export**를 클릭하면 계속 진행됩니다.

연결 하나는 `.connection.json` 파일로 다운로드됩니다. 여러 연결은 `marinara-connections.zip` 파일 하나로 묶여 다운로드됩니다.

연결을 가져오려면 Connections 패널 위쪽의 **Import**(가져오기) 버튼을 클릭하세요. **Import Connections**(연결 가져오기) 창이 열립니다. `.json` 파일을 하나 이상 끌어다 놓거나, 창을 클릭해 파일을 찾아 선택하세요. 창에는 다음과 같은 안내가 있습니다: Imported connections never include API keys. Add each key again after import. 가져오기가 끝나면 새로 추가된 연결의 API 키는 직접 입력하기 전까지 비어 있습니다.
