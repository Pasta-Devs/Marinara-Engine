# 연결 정리하기

이 가이드에서는 **Connections**(연결) 패널에서 계정과 모델을 깔끔하게 관리하는 방법을 설명합니다. 접기, 별표, 옮기기, 제거, 폴더, Shuffle, 내보내기를 다룹니다. 계정을 추가하는 방법은 [AI 제공자에 연결하기](connecting-to-a-provider.md)를 참고하세요.

## 계정 목록

패널의 **Jobs**(작업) 상자 아래에 내 계정 목록이 표시됩니다. 계정마다 사진, 이름, 모델 개수, 주소가 표시됩니다. 모델 행에는 모델의 사진과 이름, 그리고 배지가 표시됩니다. 배지는 그 모델이 맡은 작업(**Main**(메인), **Agents**(에이전트), **Images**(이미지)), **Custom settings**(사용자 지정 설정), 가격, 또는 구독에 포함된 모델이면 **Plan**(플랜)입니다. **Built-in model**(내장 모델) 카드는 **Jobs** 상자 아래에 있습니다. [내장 모델 설정](local-model.md)을 참고하세요.

계정 행을 클릭하면 그 계정의 모델이 접히고, 다시 클릭하면 펼쳐집니다. Marinara는 어떤 계정을 접어 두었는지 기억합니다. 패널 위쪽의 **More actions**(추가 작업, 점 3개)에는 다음 항목이 있습니다.

| 항목 | 역할 |
| --- | --- |
| **Fold all accounts**(모든 계정 접기), **Open all accounts**(모든 계정 펼치기) | 모든 계정을 접거나 펼칩니다. |
| **Show only Off or Needs key**(꺼짐 또는 키 필요만 표시) | 확인이 필요한 계정만 표시합니다. |
| **Show cost badges**(비용 배지 표시) | 모델마다 가격을 표시합니다. |
| **Group by folder**(폴더별로 묶기), **Group by account**(계정별로 묶기) | 모델을 묶는 방식을 바꿉니다. [폴더](#folders)를 참고하세요. |
| **Import account**(연결 가져오기), **Export all accounts**(모든 계정 내보내기) | [내보내기와 가져오기](#export-and-import)를 참고하세요. |

패널이 넓으면 정렬 드롭다운이 **Search models and accounts**(모델 및 계정 검색) 옆에 있습니다. 패널이 좁으면 정렬은 **More actions** 안에 있습니다. 정렬 선택지는 **Custom**(사용자 지정), **A–Z**, **Z–A**, **Newest**(최신순), **Oldest**(오래된순)입니다. **Search models and accounts**에 입력하면 입력하는 대로 목록이 걸러집니다.

NanoGPT나 프록시처럼 여러 제작사의 모델에 닿는 계정도 있습니다. 이런 계정의 모델은 **via NanoGPT** 같은 머리글 아래에 묶여 표시됩니다.

### 계정 동작

계정 행의 **⋯**을 클릭하세요.

| 동작 | 역할 |
| --- | --- |
| **Edit account**(계정 편집) | 계정 설정을 엽니다. **Name**(이름), **Address**(주소), **API key**(API 키), **Use this account**(이 계정 사용)가 있습니다. |
| **Replace key**(키 교체) | 새 키를 붙여넣습니다. 이전 키가 다른 계정에도 있으면 Marinara가 그 계정도 함께 갱신할지 묻습니다. |
| **Test**(테스트) | 키를 확인하고 결과를 보여 줍니다. |
| **Add model**(모델 추가) | 계정의 모델 목록을 엽니다. 이미지도 만드는 서비스에는 **Add image model**(이미지 모델 추가)도 표시됩니다. |
| **Select models**(모델 선택) | 여러 모델을 한 번에 옮기거나 삭제할 수 있습니다. |
| **Duplicate**(복제) | 계정의 사본을 그 모델의 사본과 함께 추가합니다. |
| **Turn off**(끄기) / **Turn on**(켜기) | Marinara가 그 계정을 쓰지 않게 하거나 다시 쓰게 합니다. |
| **Delete account**(계정 삭제) | 아래를 참고하세요. |

계정을 삭제하려면 **Delete account**를 클릭하세요. Marinara가 확인을 요청하고, 그 계정의 모델을 쓰는 채팅, 에이전트, 모델, 작업을 **Used by**(사용처) 아래에 보여 줍니다. **Delete with its N models**(모델 N개와 함께 삭제)를 클릭하면 계정과 그 모델이 제거됩니다. 그러면 해당 채팅과 작업에는 다른 모델이 필요합니다. 제거할 수 없는 모델이 있으면 편집기가 **This account still has models. Remove these first:**(이 계정에 아직 모델이 있습니다. 먼저 다음 모델을 제거하세요:) 아래에 그 모델을 보여 줍니다. 각 모델을 열어 제거하세요.

**Edit account**에서 **Test account**(계정 테스트)는 키를 확인하고, **Usage and balance**(사용량 및 잔액)는 요금제 사용량을 보여 주며, **More options**(추가 옵션)에는 **Requests per minute**(분당 요청 수)과 **Parallel requests**(병렬 요청 수)가 있습니다.

### 제공자 아이콘

계정마다 서비스의 아이콘이 표시됩니다. 아이콘은 Marinara에 들어 있으며, 인터넷에서 불러오는 일은 없습니다. 사용자 지정 주소는 주소나 이름에 Ollama, LM Studio, KoboldCpp, Bifrost, LiteLLM 같은 알려진 서버나 게이트웨이가 들어 있으면 그 아이콘을 보여 줍니다. 그렇지 않으면 이름의 첫 글자를 보여 줍니다. 직접 고르려면 계정의 사진을 클릭한 다음 서비스 로고를 고르거나, 이미지를 업로드하거나, 글자를 쓰세요.

## 별표한 모델

별표는 빨리 찾고 싶은 모델에 붙입니다. 별표한 모델은 모든 모델 선택 창의 위쪽 **Starred**(별표) 아래에 표시됩니다. **Jobs** 상자의 **Model for**(용도별 모델) 창, **Model for this chat**(이 채팅의 모델), 그리고 **Chat Settings**(채팅 설정)와 에이전트 편집기의 모델 필드가 여기에 해당합니다.

모델에 별표를 하려면 계정의 **Add model** 목록에서 그 모델의 별을 클릭하거나, 모델의 **⋯** 메뉴에서 **Star**(별표)를 고르세요. 모델에 작업을 맡겨도 그 모델이 저장됩니다.

별표를 해제하려면 별을 다시 클릭하세요. Marinara가 모델을 제거하고 몇 초 동안 **Undo**(되돌리기)를 보여 줍니다. 채팅이 그 모델을 쓰고 있거나, 모델이 **Jobs**에서 역할을 맡고 있거나, 자기 설정이 있거나, 계정의 마지막 모델이면 별표만 빠지고 모델은 남습니다. 메시지에 그 이유가 표시됩니다.

## 모델 동작

모델 행의 **⋯**을 클릭하세요.

| 동작 | 역할 |
| --- | --- |
| **Make default for…**(기본값으로 지정…) | 모델에 작업을 맡깁니다. **Jobs** 상자에서 고르는 것과 같습니다. |
| **Edit model**(모델 편집) | 모델 설정을 엽니다. 모델 행을 클릭해도 같습니다. |
| **Move to account…**(계정으로 이동…) | 모델을 다른 계정으로 옮깁니다. 그러면 모델은 그 계정의 키를 씁니다. |
| **Folder**(폴더) | 모델을 폴더에 넣습니다. |
| **Duplicate** | 같은 설정으로 전체 사본을 만듭니다. |
| **Add to Shuffle**(셔플에 추가) / **Remove from Shuffle**(셔플에서 제거) | [Shuffle](#shuffle)을 참고하세요. |
| **Change picture**(사진 변경) | 사진 선택지를 엽니다. |
| **Remove**(제거) | 확인을 거친 뒤 모델을 삭제합니다. 확인 창에 그 모델을 쓰는 항목이 표시됩니다. |

모델을 옮기면 이름, 사진, 작업, 채팅이 함께 옮겨지고, 서비스 옵션은 초기화됩니다.

컴퓨터에서는 모델 행을 채팅 위로 끌어다 놓아 그 채팅에서 그 모델을 쓸 수 있습니다.

<a id="folders"></a>

## 폴더

폴더는 **RP**나 **Work**처럼 모델을 묶어 줍니다. 폴더를 보려면 **More actions**에서 **Group by folder**를 고르세요. 모델 하나는 폴더 하나에 들어갑니다.

1. 모델의 **⋯**을 클릭하고 **Folder**를 고르세요.
2. 폴더를 고르거나, **New folder…**(새 폴더…)를 클릭하고 이름을 입력한 다음 **Create**(만들기)를 클릭하세요.

폴더에는 아이콘과 색을 지정할 수 있습니다. 폴더 이름을 바꾸거나 폴더를 삭제하려면 폴더의 **⋯** 메뉴를 여세요. 폴더를 삭제해도 그 안의 모델은 **Not in a folder**(폴더 없음) 아래에 남습니다.

## Shuffle

Shuffle을 쓰면 채팅이 답변을 쓸 때마다 다른 모델을 고릅니다. 요청을 여러 서비스나 모델에 나눠 보내고 싶을 때 쓰세요.

1. 풀에 넣을 모델마다 **⋯**을 클릭하고 **Add to Shuffle**을 고르세요.
2. 채팅에서 채팅 입력란의 **Model for this chat**이나 **Chat Settings → Connection → Model**(채팅 설정 → 연결 → 모델)을 열고 **Shuffle**(셔플)을 고르세요.

그러면 답변마다 내 Shuffle 풀에서 모델이 무작위로 선택됩니다.

답변에 선택된 모델이 실패했고 **Main**에 **If it fails**(실패하면) 모델이 있다면, 그 모델이 대신 답변을 씁니다. 알림에는 실패한 모델과 "key rejected", "rate limited", "not found" 같은 짧은 이유가 표시됩니다. 답변에는 작은 **Fallback**(대체) 라벨이 남습니다. 이 라벨을 탭하거나 마우스를 올리면 같은 내용을 다시 볼 수 있습니다.

**Model for this chat**에서 고른 모델은 그 채팅에만 적용됩니다. 새 채팅의 모델을 바꾸려면 **Jobs** 상자에서 **Main**을 설정하세요.

## 내보내기와 가져오기

계정을 파일로 내보내 백업하거나 다른 설치본으로 옮긴 뒤, 나중에 가져올 수 있습니다.

> **경고:** 내보내기 파일에는 API 키가 절대 포함되지 않습니다. 가져온 다음에는 계정을 하나씩 열어서 키를 다시 입력하세요. 키는 절대 다른 사람과 공유하지 마세요.

- **모델 하나 내보내기:** **Edit model**로 모델을 열고 **Export model**(연결 내보내기)을 클릭하세요.
- **전부 내보내기:** **More actions**를 열고 **Export all accounts**를 고르세요. Marinara가 파일에 키가 없다는 점을 알려 줍니다. **Export**(내보내기)를 클릭하세요.
- **가져오기:** **More actions**를 열고 **Import account**를 고르세요. 파일(`.json`, `.jsonl`, `.zip`)을 하나 이상 창에 끌어다 놓거나, 창을 클릭해 파일을 찾으세요. 내보낸 `marinara-connections.zip`도 가져올 수 있습니다. 가져온 계정의 키는 직접 입력하기 전까지 비어 있습니다.

모델 하나는 `.connection.json` 파일로 다운로드됩니다. 여러 개는 `marinara-connections.zip` 하나로 묶여 다운로드됩니다. 별표는 포함됩니다. 서비스의 모델 카탈로그는 포함되지 않으므로, 계정의 모델을 처음 열 때 다시 불러옵니다.
