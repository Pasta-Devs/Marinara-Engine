# 연결 정리하기

이 가이드에서는 Marinara Engine의 계정과 모델을 깔끔하게 관리하는 방법을 설명합니다. 계정 목록, 별표한 모델, 모델 옮기기와 제거, 폴더, Shuffle, 내보내기와 가져오기를 다룹니다. 계정은 AI 제공자 하나에 쓰는 키, 로그인 또는 주소 하나이고, 모델은 그 계정에서 저장해 둔 AI 모델 하나입니다. 계정을 추가하는 방법은 [AI 제공자에 연결하기](connecting-to-a-provider.md)를 참고하세요.

## 계정 목록

**Connections**(연결) 패널의 **Jobs**(작업) 상자 아래에 내 계정 목록이 표시됩니다. 계정마다 사진, 이름, 모델 개수, 주소가 표시됩니다. 모델 행에는 모델의 사진과 이름, 그리고 배지가 표시됩니다. 배지는 그 모델이 맡은 작업(**Main**(메인), **Agents**(에이전트), **Images**(이미지)), **Custom settings**(사용자 지정 설정), 가격, 또는 구독에 포함된 모델이면 **Plan**(플랜)입니다.

계정 행을 클릭하면 그 계정의 모델이 접히고, 다시 클릭하면 펼쳐집니다. Marinara는 어떤 계정을 접어 두었는지 기억합니다. 패널 위쪽의 **More actions**(추가 작업)에는 **Fold all accounts**(모든 계정 접기)와 **Open all accounts**(모든 계정 펼치기), **Show only Off or Needs key**(꺼짐 또는 키 필요만 표시), **Show cost badges**(비용 배지 표시)가 있습니다. 패널이 넓으면 정렬 드롭다운이 **Search models and accounts**(모델 및 계정 검색) 옆에 있습니다. 패널이 좁으면 정렬 순서는 **More actions** 안에 있습니다.

프록시나 LinkAPI처럼 여러 모델 제작사에 닿는 게이트웨이 계정은 모델을 **via NanoGPT** 같은 **via** 머리글 아래에 그 제작사의 아이콘과 함께 묶어 보여 줍니다.

Jobs 상자 아래의 **Built-in model**(내장 모델) 카드에는 내 컴퓨터에서 실행되는 모델과 그 상태가 표시됩니다. [Local Model 설정](local-model.md)을 참고하세요.

### 계정 동작

계정 행의 **⋯**을 클릭하세요.

- **Edit account**(계정 편집)는 계정 설정을 엽니다. **Name**(이름), **API key**(API 키), **Address**(주소), **Usage and limits**(사용량 및 한도), **Use this account**(이 계정 사용)가 있습니다.
- **Replace key**(키 교체)로 새 키를 붙여넣습니다.
- **Test**(테스트)는 키를 확인하고 결과를 보여 줍니다.
- **Add model**(모델 추가)은 계정의 모델 목록을 엽니다. 이미지도 만드는 제공자에는 **Add image model**(이미지 모델 추가)도 표시됩니다.
- **Select models**(모델 선택)로 여러 모델을 한 번에 옮기거나 삭제할 수 있습니다.
- **Duplicate**(복제)는 계정의 사본을 그 모델의 사본과 함께 추가합니다.
- **Turn off**(끄기)를 누르면 다시 **Turn on**(켜기)을 누를 때까지 Marinara가 그 계정을 쓰지 않습니다.
- **Delete account**(계정 삭제). Marinara가 먼저 그 계정의 모델을 아직 쓰고 있는 작업, 채팅, 에이전트를 보여 줍니다.

### 제공자 아이콘

계정마다 제공자의 아이콘이 표시됩니다. 아이콘은 Marinara에 들어 있으므로 Marinara가 인터넷에서 불러오는 일은 없습니다. 사용자 지정 주소는 주소나 이름에 알려진 서버나 게이트웨이가 들어 있으면 그 아이콘을 보여 줍니다. 예를 들면 Ollama, LM Studio, KoboldCpp, Bifrost, LiteLLM입니다. 그렇지 않으면 이름의 첫 글자를 보여 줍니다. 계정의 사진을 클릭하면 직접 고를 수 있습니다.

## 별표한 모델

별표는 가까이 두고 쓰고 싶은 모델에 붙입니다. 별표한 모델은 모든 모델 선택 창의 위쪽 **Starred**(별표) 아래에 표시됩니다. **Jobs** 상자의 **Model for**(용도별 모델) 창, 채팅의 **Model for this chat**(이 채팅의 모델), 그리고 **Chat Settings**(채팅 설정)와 에이전트 편집기의 모델 필드가 여기에 해당합니다.

모델에 별표를 하려면 계정의 **Add model** 목록에서 그 모델의 별을 클릭하거나, 모델의 **⋯** 메뉴에서 **Star**(별표)를 고르세요. 모델에 작업을 맡겨도 그 모델이 저장됩니다.

별표를 해제하려면 별을 다시 클릭하세요. Marinara가 모델을 제거하고 몇 초 동안 **Undo**(되돌리기)를 보여 줍니다. 모델이 아직 **Jobs**에서 역할을 맡고 있거나, 자기 설정이 있거나, 계정의 마지막 모델이면 별표만 빠지고 모델은 남습니다. 메시지에 그 이유가 표시됩니다.

## 모델 동작

모델 행의 **⋯**을 클릭하세요.

- **Make default for…**(기본값으로 지정…)는 모델에 작업을 맡깁니다. **Jobs** 상자에서 고르는 것과 같습니다.
- **Edit model**(모델 편집)은 모델 설정을 엽니다. 모델 행을 클릭해도 같습니다.
- **Move to account…**(계정으로 이동…)는 모델을 같은 제공자의 다른 계정이나 새 계정으로 옮깁니다. 그러면 모델은 그 계정의 키와 카탈로그를 씁니다. 그 모델을 쓰는 채팅은 계속 작동합니다.
- **Folder**(폴더)는 모델을 폴더에 넣습니다. 폴더는 **More actions**에서 **Group by folder**(폴더별로 묶기)를 고르면 표시됩니다.
- **Duplicate**는 묻지 않고 같은 설정으로 전체 사본을 만듭니다.
- **Add to Shuffle**(셔플에 추가) 또는 **Remove from Shuffle**(셔플에서 제거).
- **Change picture**(사진 변경).
- **Remove**(제거)는 확인을 거친 뒤 모델을 삭제합니다.

컴퓨터에서는 모델 행을 채팅 위로 끌어다 놓아 그 채팅에서 그 모델을 쓸 수 있습니다.

## 검색

패널 위쪽의 **Search models and accounts**에 입력하면 목록이 바로 걸러집니다. 일치하는 항목이 없으면 패널에 그렇다고 표시됩니다.

## Shuffle

Shuffle을 쓰면 채팅이 답변을 쓸 때마다 다른 모델을 골라 씁니다. 요청을 여러 제공자나 모델에 나눠 보내고 싶을 때 유용합니다.

모델을 Shuffle에 넣으려면 그 모델의 **⋯** 메뉴에서 **Add to Shuffle**을 고르세요. 채팅에서 Shuffle을 쓰려면 채팅 입력란이나 **Chat Settings → Connection → Model**(채팅 설정 → 연결 → 모델)에서 **Model for this chat**을 열고 **Shuffle**(셔플)을 고르세요. 그러면 답변마다 내 Shuffle에서 모델이 무작위로 선택됩니다.

답변에 선택된 모델이 실패했고 **Main**에 **If it fails**(실패하면) 모델이 있다면, 그 모델이 대신 답변을 씁니다. 알림에는 실패한 모델과 "key rejected", "rate limited", "not found" 같은 짧은 이유가 표시되므로 어떤 모델을 고쳐야 하는지 알 수 있습니다. 답변에는 작은 **Fallback**(폴백) 라벨이 남으며, 이 라벨을 탭하거나 마우스를 올리면 같은 내용을 다시 볼 수 있습니다.

**Model for this chat**에서 고른 모델은 그 채팅에만 적용됩니다. 새 채팅의 모델을 바꾸려면 **Jobs** 상자에서 **Main**을 설정하세요.

## 내보내기와 가져오기

계정을 파일로 내보내 백업하거나 다른 설치 환경으로 옮긴 뒤, 나중에 가져올 수 있습니다.

**내보내기 파일에는 API 키가 절대 포함되지 않습니다.** 가져온 다음에는 계정을 하나씩 열어서 키를 다시 입력하세요. 별표는 포함되지만 제공자의 카탈로그는 포함되지 않으므로, 계정의 모델을 처음 열 때 카탈로그를 다시 불러옵니다.

모델 하나를 내보내려면 **Edit model**로 모델을 열고 **Export**(내보내기) 버튼(업로드 아이콘)을 클릭하세요. 전부 내보내려면 **More actions**를 열고 **Export all accounts**(모든 계정 내보내기)를 고르세요. 다운로드가 시작되기 전에 Marinara가 파일에 키가 없다는 점을 알려 줍니다.

모델 하나는 `.connection.json` 파일로 다운로드됩니다. 여러 개는 `marinara-connections.zip` 파일 하나로 묶여 다운로드됩니다.

가져오려면 **More actions**를 열고 **Import account**(연결 가져오기)를 고르세요. `.json` 파일을 하나 이상 창에 끌어다 놓거나, 창을 클릭해 파일을 찾아 선택하세요. 가져온 계정의 키는 직접 입력하기 전까지 비어 있습니다.
