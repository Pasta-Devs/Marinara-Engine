# 프리셋 변수

이 가이드에서는 **Preset Variables**(프리셋 변수)를 설명합니다. 프롬프트 프리셋 안에 미리 심어 두는, 작은 입력 양식 같은 선택지입니다. 프리셋을 만든 사람이 선택지를 한 번 정해 두면, 그 프리셋을 채팅에 지정할 때 누구나 원하는 옵션을 고를 수 있습니다. 프리셋 변수를 선택 블록이라고 부르기도 합니다.

## 프리셋 변수란

프롬프트 프리셋은 AI에 보낼 글의 뼈대를 저장해 두고 여러 번 재사용하는 틀입니다. 프리셋 변수는 이 틀에 이름표가 붙은 선택지를 하나 더합니다. 선택지에 이름을 붙이고, 질문을 쓰고, 고를 수 있는 옵션을 나열하면 됩니다.

프롬프트 섹션 안에는 변수 이름을 `{{tone}}`처럼 중괄호 두 겹으로 감싸서 넣습니다. AI가 답변을 생성할 때 Marinara Engine이 `{{tone}}`을 사용자가 고른 옵션 값으로 바꿉니다. 덕분에 프롬프트 글을 고치지 않고도 프리셋 하나로 서로 다른 동작을 만들어 낼 수 있습니다.

프리셋 변수는 프롬프트 프리셋 안에 들어 있으므로, 프롬프트 프리셋을 쓰는 채팅 모드에서만 동작합니다. Conversation(대화) 모드에는 적용되지 않습니다. 이 모드는 섹션으로 나뉜 프리셋 대신 프롬프트 글 전체를 통째로 대체하는 방식이라, 변수가 채워 넣을 자리 자체가 없습니다. 프리셋 자체를 알아보려면 [Preset Editor와 프롬프트 관리](presets.md)를 참고하세요.

## 프리셋 변수의 3가지 종류

변수의 동작은 옵션 개수와 토글 2개로 정해집니다. 옵션이 여러 개인 변수는 기본적으로 단일 선택입니다. 즉, 사용자는 옵션을 정확히 하나만 고르고 화면에는 라디오 버튼으로 표시됩니다. 이 기본 동작 위에 이름이 붙은 종류가 3가지 있습니다.

**Boolean Toggle**(불리언 토글). 옵션이 딱 하나뿐인 변수는 켜기/끄기 스위치가 됩니다. 사용자가 켜면 그 옵션 값이 삽입되고, 끄면 아무것도 삽입되지 않습니다. 편집기에서는 이런 변수에 **Boolean Toggle** 라벨이 붙습니다.

**Multi-Select**(다중 선택). **Multi-Select** 토글을 켜면 사용자가 옵션을 여러 개 고를 수 있습니다. 선택한 값들은 기본적으로 구분자로 이어 붙입니다. 구분자는 짧은 입력란이며 기본값은 쉼표와 공백입니다. 예를 들어 Romance, Fantasy, Action 옵션을 `, `로 이어 붙이면 "Romance, Fantasy, Action"이라는 글이 됩니다.

**Random Pick**(무작위 선택). 단일 선택 변수에서는 새 채팅마다 Marinara가 옵션 하나를 무작위로 미리 선택합니다. 확인 전에 바꿀 수 있으며, 저장된 선택은 직접 수정할 때까지 유지됩니다. **Multi-Select**를 켜면 생성할 때마다 선택한 옵션 중 하나를 앱이 무작위로 고릅니다. 변화를 주고 싶을 때 유용합니다. 후보 묶음을 정해 두면 답변마다 그 안에서 하나가 뽑힙니다.

## 프리셋 변수 추가하기

변수는 프리셋을 편집하는 중에 추가합니다. 다음 단계를 따르세요.

1. **Presets**(프리셋) 패널을 열고 프리셋을 클릭해 **Preset Editor**(프리셋 편집기)를 여세요.
2. **Sections**(섹션) 탭으로 이동한 다음 맨 아래의 **Preset Variables** 패널까지 스크롤하세요.
3. **Add Variable**(변수 추가)를 클릭하세요. 새 변수 카드가 나타납니다. 카드를 클릭하면 편집기가 펼쳐집니다.
4. **Variable Name**(변수 이름)을 정하세요. 영문자, 숫자, 밑줄만 쓸 수 있습니다. 중괄호 안에 넣는 이름이 바로 이 이름입니다(`{{variable_name}}`).
5. **Question (shown to user)**(질문(사용자에게 표시))를 채우세요. 값을 고를 때 사용자가 읽는 질문입니다.
6. **Options**(옵션) 목록을 편집하세요. 옵션마다 **Label**(사용자에게 보이는 이름)과 **Value**(프롬프트에 삽입되는 글)가 있습니다. 값을 비워 두면 아무것도 삽입되지 않습니다.
7. **Presentation**(표시 방식)에서 표시 형태를 고르세요. **Auto**, 버튼형(**Radios** 또는 **Checkboxes**), 간결형(**Dropdown** 또는 **Listbox**) 중에서 선택합니다. **Alphabetical option display**(옵션을 가나다순으로 표시)를 켜면 옵션이 라벨 순으로 정렬됩니다.
8. 변경 사항은 자동으로 저장됩니다. 편집기 아래쪽에는 "Changes auto-save. Press Escape to close."라고 표시됩니다. 다 마쳤으면 Escape를 누르거나 **Done**(완료)을 클릭하세요.

변수를 실제로 쓰려면 프롬프트 섹션 내용 안에 변수 이름을 중괄호로 감싸 넣으세요. 예를 들어 섹션에 `{{tone}}`을 넣고, **Gentle** 옵션과 **Harsh** 옵션을 가진 `tone` 변수를 만드는 식입니다. 사용자가 Harsh를 고르면 그 섹션에는 Harsh의 값이 들어갑니다.

변수에는 옵션이 항상 하나 이상 남아 있어야 합니다. 마지막 옵션을 지우려고 하면 Marinara가 그 옵션을 지우지 않고 남겨 둡니다.

## Configure Preset Variables 창

변수가 들어 있는 프리셋을 채팅에 지정하면 **Configure Preset Variables**(프리셋 변수 구성) 창이 자동으로 열립니다. 안내 문구는 "This preset has configurable variables. Select option(s) for each to customize your experience."입니다.

각 변수에는 질문, 대응하는 토큰(`{{tone}}` 같은 것), 그리고 해당할 때만 붙는 작은 배지(**Boolean toggle**, **Multi-select**, **Random pick**)가 함께 표시됩니다. 모든 변수에 값을 하나씩 고르세요.

- **Save as default**(기본값으로 저장)는 고른 값을 프리셋에 되돌려 저장해, 다음번에 미리 채워지도록 합니다.
- **Skip**(건너뛰기)은 선택을 저장하지 않고 창을 닫습니다.
- **Confirm Choices**(선택 적용)는 고른 값을 저장합니다. 단일 선택 변수가 하나라도 비어 있으면 이 버튼은 비활성화 상태로 남습니다. **Boolean toggle** 변수와 **Multi-select** 변수는 아무것도 고르지 않아도 버튼을 막지 않습니다.

다른 프리셋으로 바꾸면 현재 프리셋에서 고른 변수 값은 모두 지워집니다.

## 나중에 선택 바꾸기

고른 값을 바꾸겠다고 프리셋을 처음부터 다시 열 필요는 없습니다. 선택한 프리셋에 변수가 있으면 채팅 설정 패널의 **Prompt Preset**(프롬프트 프리셋) 섹션에 **Edit preset variables**(프리셋 변수 편집) 연필 버튼이 나타납니다. 이 버튼을 클릭하면 지금까지 고른 값이 채워진 상태로 **Configure Preset Variables** 창이 다시 열립니다.

## 남은 {{NAME}} 자리 표시자 처리

Marinara는 `{{user}}`, `{{char}}` 같은 기본 내장 매크로를 먼저 처리합니다. 그러고도 남은 `{{NAME}}` 형태의 자리 표시자(영문자, 숫자, 밑줄만 해당)는 프리셋 변수와 대조합니다.

이름이 정확히 일치하는 변수가 있으면 자리 표시자는 선택된 값으로 바뀝니다. 일치하는 변수가 없으면 `{{NAME}}` 글자가 입력한 그대로 남습니다. 알 수 없는 자리 표시자가 오류를 내지 않고 결과물에 그대로 나타나는 이유입니다. 매크로 전체 목록은 [프롬프트 매크로](macros.md)를 참고하세요.
