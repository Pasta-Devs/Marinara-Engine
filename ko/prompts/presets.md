# Preset Editor와 프롬프트 관리

이 가이드에서는 Marinara Engine의 프롬프트 프리셋을 설명합니다. 프리셋이 어떤 기능인지, **Preset Editor**(프리셋 편집기)에서 어떻게 만드는지, 채팅에 어떻게 지정하는지 알 수 있습니다. 프리셋은 Marinara가 AI에 보내는 글의 구조를 결정합니다.

## 프리셋이란

프리셋은 여러 번 재사용하는 설계도입니다. Marinara가 AI에 어떤 정보를 어떤 순서로 보낼지 프리셋이 정합니다. 직접 작성한 시스템 지시, 캐릭터 카드, 페르소나, 채팅 기록, 로어북 항목 등이 여기에 들어갑니다.

프리셋은 **Roleplay**(롤플레이)와 **Game** 채팅의 프롬프트를 구성합니다. **Conversation**(대화) 모드는 방식이 달라서 프롬프트 입력란 하나만 사용합니다. 아래 "Conversation 모드와 Game 모드의 차이"를 참고하세요.

프리셋에는 API 키도 계정도 필요하지 않습니다. 프롬프트를 어떻게 조립할지만 정해 둔 것이기 때문입니다. 프롬프트를 실제로 보내려면 정상 동작하는 연결이 따로 있어야 합니다. [AI 제공자에 연결하기](../connections/connecting-to-a-provider.md)를 참고하세요.

## Preset Editor 열기

프롬프트 프리셋은 앱 왼쪽 **Presets**(프리셋) 패널의 **Prompts**(프롬프트) 섹션에 있습니다. 이 패널의 나머지 섹션은 **Regexes**(정규식)와 **Functions**(기능)입니다.

패널 위쪽에는 버튼이 세 개 있습니다.

- **New**(플러스 아이콘): 새 프리셋을 만듭니다.
- **Import**(다운로드 아이콘): `.json` 파일에서 프리셋을 불러옵니다.
- **Select**(체크 아이콘): 여러 프리셋을 한 번에 내보내거나 삭제하도록 고릅니다.

버튼 아래에는 **Search presets** 입력란과 **A-Z**, **Z-A**, **Newest**, **Oldest** 정렬 메뉴가 있습니다. **New Folder**(새 폴더) 버튼으로 프리셋을 폴더로 묶을 수 있습니다. 프리셋을 폴더 위로 끌어다 놓으면 옮겨집니다. 폴더 이름은 더블 클릭하거나 두 번 탭해서 바꿉니다.

프리셋 행에는 이름, 래핑 형식, 섹션 개수, 작성자가 표시됩니다. 별표로 지정한 기본 프리셋에는 **DEFAULT** 배지가 붙습니다. 프리셋 행을 클릭하면 **Preset Editor**에서 열립니다.

## 프리셋 만들기와 편집하기

새 프리셋은 다음 순서로 만듭니다.

1. **Presets** 패널을 여세요.
2. **New** 버튼을 클릭하세요. **Create Preset**(프리셋 만들기) 창이 열립니다.
3. **Name**(이름)을 입력하세요. 필수 입력란입니다.
4. 나중에 용도를 알아보기 쉽도록 **Description**(설명)을 적어 두세요. 선택 사항입니다.
5. **Create**(만들기)를 클릭하세요. 새 프리셋이 **Preset Editor**에서 열립니다.
6. **Sections**(섹션) 탭에서 프롬프트를 구성하세요(아래에서 설명합니다).
7. 다 만들었으면 오른쪽 위의 **Save**(저장)를 클릭하세요.

편집기는 저절로 저장하지 않습니다. **Save**를 클릭해야 변경 내용이 남습니다. 저장하지 않은 편집 내용이 있는 채로 나가려고 하면 **Keep editing**(계속 편집), **Discard**(변경 취소), **Save & close**(저장 & 닫기) 버튼이 있는 경고가 나타납니다.

프리셋을 내보내려면 프리셋을 연 다음 위쪽 막대의 내보내기 버튼(위쪽 화살표 아이콘)을 클릭하세요. 저장하지 않은 편집 내용이 있으면 Marinara가 먼저 저장할지 확인합니다. 프리셋을 삭제할 때는 위쪽 막대의 휴지통 아이콘을 사용하세요.

## Overview, Sections, Prompts 탭

**Preset Editor**에는 탭이 세 개 있습니다.

- **Overview**(개요): 프리셋 이름, 설명, 래핑 형식, 작성자.
- **Sections**: 블록과 마커로 짜는 실제 프롬프트 구조.
- **Prompts**: Conversation 채팅과 Game 채팅이 쓰는 모드 프롬프트.

### Overview 탭

**Overview** 탭에는 입력란이 네 개 있습니다. **Name**은 **Presets** 패널에 표시되는 이름입니다. **Description**은 프리셋을 짧게 요약한 설명입니다. **Wrap Format**(감싸기 형식)은 섹션을 어떤 형식으로 감쌀지 정합니다("래핑 형식" 참고). **Author**(작성자)는 선택 사항인 제작자 이름으로, 프리셋을 공유할 때 쓸모가 있습니다. 읽기 전용 카드 두 개에는 **Sections**와 **Groups**(그룹) 개수가 나옵니다.

### Prompts 탭

**Prompts** 탭에는 모드 프롬프트가 있습니다.

- **Conversation Mode**: 이 프리셋의 Conversation 프롬프트로 쓰이는 텍스트 상자입니다. 비워 두면 Marinara에 내장된 conversation 프롬프트를 사용합니다.
- **Roleplay Mode**: 여기서는 편집할 수 없습니다. Roleplay는 **Sections**에서 조립한 프롬프트를 사용합니다.
- **Game Mode**: 이 프리셋의 Game 프롬프트로 쓰이는 텍스트 상자입니다. 비워 두면 Marinara에 내장된 game 프롬프트를 사용합니다.

## 섹션과 마커

프롬프트는 **Sections** 탭에서 만듭니다. 모든 섹션이 AI에 보내는 최종 텍스트의 일부가 됩니다. 섹션은 위에서 아래 순서로 조립됩니다.

**Add Section**(섹션 추가)을 클릭하면 추가 메뉴가 열립니다. 여기서 두 종류의 섹션을 고를 수 있습니다.

**Prompt Block**(프롬프트 블록)은 직접 글을 쓰는 자유 입력 섹션입니다. 시스템 지시, 어조 규칙처럼 모든 프롬프트에 넣고 싶은 문구를 여기에 씁니다.

**마커**는 내용이 자동으로 채워지는 섹션입니다. 마커 자체에는 글이 없습니다. 대신 Marinara가 보내는 시점에 현재 채팅의 실제 내용으로 채웁니다. 마커 종류는 아래 표와 같습니다.

| 마커 | 삽입되는 내용 |
|---|---|
| **Character Info** | 현재 캐릭터 카드의 세부 정보. |
| **Persona**(페르소나) | 현재 페르소나의 세부 정보. |
| **Chat History**(채팅 히스토리) | 진행 중인 채팅 메시지. |
| **Chat Summary**(채팅 요약) | 이 채팅에서 만들어진 채팅 요약. |
| **Dialogue Examples** | 캐릭터의 예시 대화. |
| **Lorebook Marker (All)** | 활성 로어북 항목 전체. |
| **Lorebook Marker (Before)** | 앞에 삽입하도록 설정한 로어북 항목. |
| **Lorebook Marker (After)** | 뒤에 삽입하도록 설정한 로어북 항목. |

마커인 섹션의 행에는 **MARKER** 배지가 붙습니다. 펼치면 마커 종류를 알려 주는 안내가 나옵니다. 대부분의 마커에는 내용을 직접 입력할 수 없습니다. Marinara가 대신 만들어 주기 때문입니다.

프리셋에 활성화된 **Dialogue Examples** 마커가 없으면, 비어 있지 않은 예시 대화가 **Character Info**의 Scenario 뒤에 덧붙습니다. 이때 프리셋의 XML, Markdown 형식이나 감싸지 않은 형식을 그대로 따릅니다. 위치를 직접 정하고 싶을 때 Dialogue Examples 마커를 추가하세요. Marinara가 예시 대화를 두 번 넣는 일은 없습니다.

채팅에 활성 로어북이 있는데 프리셋에 로어북 마커가 없으면 경고가 나타납니다. 내용은 다음과 같습니다: "Add a lorebook marker when this preset should receive active lorebook entries." 항목이 AI까지 전달되도록 로어북 마커를 추가하세요. [로어북 개요](../lorebooks/overview.md)를 참고하세요.

"inject as section" 옵션을 켠 사용자 지정 에이전트를 만들어 두었다면 추가 메뉴에 **Agent Sections**(에이전트 섹션) 그룹이 나타납니다. 각 에이전트 섹션은 해당 에이전트의 최신 출력을 프롬프트에 넣습니다. 그 앞뒤로 직접 지시를 덧붙일 수도 있습니다.

섹션 행 오른쪽에는 조작 버튼이 있습니다. **Duplicate**(복제)는 섹션을 복사합니다. 눈 아이콘은 섹션을 활성화하거나 비활성화합니다. **Delete**(삭제)는 섹션을 삭제합니다. 순서를 바꿀 때는 손잡이를 끌거나, 위아래 화살표를 쓰거나, 터치 화면에서 길게 누르세요.

섹션 이름이나 꺾쇠 아이콘을 클릭해 섹션을 펼치면 편집할 수 있습니다. **Name**과 역할(**System**, **User**, **Assistant**)을 바꿀 수 있습니다. **Prompt Block**은 **Content**(내용)도 편집할 수 있습니다. 내용 상자에서는 매크로를 쓸 수 있습니다. [프롬프트 매크로](macros.md)를 참고하세요.

## 그룹과 섹션 위치

### 그룹

그룹은 여러 섹션을 하나의 컨테이너로 묶습니다. 이렇게 하면 관련 있는 섹션들이 최종 프롬프트에서도 한데 모입니다.

1. **Sections** 탭 도구 모음에서 **Groups** 버튼을 클릭하세요.
2. **New Group**(새 그룹)을 클릭하세요. "New Group"이라는 이름의 그룹이 생깁니다.
3. 그룹 이름을 클릭해 원하는 이름으로 바꾸세요.
4. 섹션을 펼치고 **Group**(그룹) 드롭다운에서 그 그룹을 고르세요.

래핑 형식이 **XML**이면 그룹은 섹션들을 감싸는 부모 태그 하나가 됩니다. **Markdown**이면 그룹은 제목 하나가 됩니다. 그룹을 삭제해도 안에 있던 섹션은 지워지지 않습니다. 그룹에서 빠질 뿐입니다.

### 위치와 깊이

섹션을 펼치면 **Position**(위치) 설정이 있습니다.

- **Ordered (in sequence)**: 목록에 놓인 자리에 그대로 들어갑니다. 보통은 이 방식을 씁니다.
- **Depth (from end of chat)**: 채팅 끝에서 지정한 메시지 수만큼 위쪽에 들어갑니다. 이 방식을 고르면 **Depth**(깊이) 숫자 입력이 나타납니다. 깊이가 0이면 마지막 메시지 뒤에 들어갑니다.

짧은 문체 지침처럼 AI가 최신 메시지 가까이에서 봐야 하는 당부에는 **Depth**를 쓰세요.

## 래핑 형식

**Overview** 탭의 **Wrap Format**은 프롬프트를 조립할 때 각 섹션을 어떻게 감쌀지 정합니다. 버튼은 세 가지입니다.

- **XML**: 각 섹션을 태그로 감쌉니다. 예를 들어 내용 둘레에 이름 태그가 붙습니다. 그룹은 부모 태그가 됩니다. 기본값입니다.
- **MARKDOWN**: 각 섹션을 제목으로 감쌉니다. 그룹은 한 단계 위의 제목이 됩니다.
- **NONE**: 아무것도 감싸지 않습니다. 섹션 내용이 쓴 그대로 전달됩니다.

대부분의 모델에는 XML이 무난한 기본값입니다. 태그가 없을 때 모델 반응이 더 나아 보일 때만 **MARKDOWN**이나 **NONE**을 시도해 보세요.

## 채팅에 프리셋 지정하기

프리셋은 채팅에 지정해야 비로소 동작합니다. **Roleplay** 채팅에서는 두 가지 방법이 있습니다.

**Presets** 패널에서 지정하기:

1. 바꾸려는 채팅을 여세요.
2. **Presets** 패널에서 프리셋 행 위에 마우스를 올리세요.
3. 체크 표시가 있는 **Assign to chat**(채팅에 할당) 버튼을 클릭하세요. 한 번 더 클릭하면 지정이 해제됩니다.

**Chat Settings**(채팅 설정)에서 지정하기:

1. 채팅을 여세요.
2. **Chat Settings**(톱니바퀴)를 여세요.
3. **Prompt Preset**(프롬프트 프리셋) 섹션을 찾으세요.
4. 드롭다운에서 프리셋을 고르세요.

프리셋에 변수가 있으면 지정할 때 **Configure Preset Variables**(프리셋 변수 구성) 창이 열립니다. 거기서 원하는 값을 채우세요. [프리셋 변수](preset-variables.md)를 참고하세요. 다른 프리셋으로 바꾸면 앞서 고른 변수 값은 모두 지워집니다.

**Conversation** 모드에서는 패널로 프롬프트 프리셋을 지정할 수 없습니다. Conversation 채팅에서 지정 버튼을 클릭하면 "Prompt presets are not available in conversation mode."라는 메시지가 나타납니다. Conversation 채팅과 Game 채팅이 프리셋을 쓰는 방식은 다음 절을 참고하세요.

## Conversation 모드와 Game 모드의 차이

**Conversation** 채팅과 **Game** 채팅은 Sections로 프롬프트를 조립하지 않습니다. 대신 모드 프롬프트 하나를 쓰며, 이 프롬프트는 채팅마다 따로 덮어쓸 수 있습니다.

이 두 모드에서는 **Chat Settings**의 **Prompt Preset** 섹션에 **Prompt source**(프롬프트 소스) 드롭다운이 나옵니다. 드롭다운에는 저장된 프리셋이 나열됩니다. 기본값은 "Default conversation prompt" 또는 "Default game prompt"입니다. 프리셋이 하나도 없으면 "No presets available"이라고 표시됩니다.

드롭다운 아래에는 상태 행이 있습니다. 다음 세 가지 중 하나가 표시됩니다.

- **Default**: 내장 모드 프롬프트를 사용합니다.
- **Preset**: 고른 프리셋에서 프롬프트를 가져옵니다.
- **Custom**: 이 채팅에만 적용되는 내용을 직접 입력했습니다.

**Edit Prompt**(프롬프트 편집)를 클릭하면 이 채팅에만 쓸 프롬프트를 입력할 수 있습니다. 편집기는 **Edit Conversation Prompt**(대화 프롬프트 편집) 또는 **Edit Game Prompt**(게임 프롬프트 편집)로 열립니다. 입력한 내용이 프리셋이나 기본값과 완전히 같으면 Marinara는 사용자 지정이 아닌 것으로 처리합니다. 사용자 지정 내용이 한 번 생기면 그것을 지우는 **Reset to default prompt**(기본 프롬프트로 초기화) 버튼이 나타납니다.

Game 채팅에는 **Extra instructions**(추가 지침) 상자도 있습니다. 여기에 쓴 글은 Game 프롬프트에 덧붙습니다. 길이는 2000자까지입니다. 지시 예시로는 "Write in the style of Terry Pratchett."이 있습니다.

## 판정 블록과 프롬프트 캐시

섹션에 `{{#if decision:"..."}}` 판정 블록을 넣으면 채팅에 관한 문장이 참인 턴에만 프리셋의 해당 부분을 보냅니다. [Decision 모델에 묻기](conditional-prompts.md#asking-the-decision-model)를 참고하세요.

**변하는 판정 블록은 프롬프트 뒤에 놓으세요.** 예를 들어 기록 뒤 지침에 배치합니다. 분기가 바뀌면 제공자가 그 지점 이후의 프롬프트를 재사용하지 못할 수 있으므로 앞부분의 변경은 캐시 절감 효과 대부분을 없앨 수 있습니다. 더 앞의 변하지 않은 접두부는 여전히 해당할 수 있으며 전체 프롬프트가 반드시 새 입력으로 과금되는 것은 아닙니다. 답이 거의 바뀌지 않고 지침이 앞에 있어야 할 때만 앞부분에 두세요. 제공자별 상세 정보는 [프롬프트 캐시](conditional-prompts.md#prompt-caching)를 참고하세요.

비활성 섹션과 그룹의 문장은 묻지 않으며 **Decision statements per turn**(턴당 판정문 수)에 포함하지 않습니다.

## AI가 받은 내용 확인하기

어떤 프리셋과 섹션이 실제로 AI에 전달되었는지 확인하려면 **Peek Prompt**(프롬프트 미리보기)를 쓰세요. 해당 메시지에 대해 조립이 끝난 프롬프트 전체를 보여 줍니다. 이상한 응답의 원인을 찾는 가장 빠른 방법입니다. [Peek Prompt: AI가 받은 내용 확인하기](../chats/peek-prompt.md)를 참고하세요.
