# 채팅 배경

이 가이드에서는 Marinara Engine의 배경 라이브러리를 설명합니다. 직접 올린 이미지 중에서 골라 채팅 뒤에 깔아 두는 기능입니다. 매 턴 장면에 맞는 배경을 알아서 골라 주는 **Background** 에이전트는 [Roleplay 배경](../roleplay/backgrounds.md)을 참고하세요. Gallery에서 AI로 만드는 장면 배경은 [장면 배경과 Gallery](../media/scene-backgrounds.md)에서 다룹니다.

## 배경 설정 위치

배경 관리는 한 곳에서 합니다. **Settings**(설정)를 열고 **Appearance**(모양) 탭의 **Backgrounds**(배경) 섹션으로 이동하세요.

**Backgrounds** 섹션은 세 부분으로 나뉩니다.

1. 지금 열려 있는 채팅에 쓸 이미지를 고르는 **Chat Background**(채팅 배경화면) 선택 영역
2. **Background Blur**(배경 흐림) 슬라이더
3. 이미지를 가져오고, 정리하고, 검색하고, 태그를 달고, 이름을 바꾸고, 다운로드하고, 삭제하는 배경 라이브러리

채팅 배경은 Roleplay와 Game Mode 채팅에서만 보입니다. Conversation 모드는 대신 그라데이션을 쓰며, 이는 **Conversation Theme**(대화 테마) 섹션에서 지정합니다. 자세한 내용은 [모양 설정](appearance-settings.md)을 참고하세요.

## 배경 라이브러리

라이브러리에는 고를 수 있는 이미지가 모두 들어 있습니다. 직접 올린 이미지와 Marinara에 기본 포함된 이미지가 함께 표시됩니다. 각 이미지에는 구분용 라벨이 작게 붙습니다.

- **Library**: 직접 올린 이미지입니다. 이름 변경, 태그, 삭제가 가능합니다.
- **Game asset**: Marinara에 기본 포함된 이미지입니다. 읽기 전용이라 이름 변경, 태그, 삭제를 할 수 없습니다.

### 배경 가져오기

1. 라이브러리 맨 위의 **Import Backgrounds**(배경 등록) 영역을 찾으세요.
2. 이미지 파일을 하나 이상 그 영역으로 끌어다 놓거나, 영역을 클릭해서 파일을 고르세요.
3. 업로드가 끝날 때까지 기다리세요. 진행 중에는 영역에 **Importing...**이 표시됩니다.
4. 새로 올린 이미지가 아래 격자에 **Library** 라벨과 함께 나타납니다.

여러 파일을 한 번에 가져올 수 있습니다. 각 파일은 JPG, PNG, GIF, WebP, AVIF 중 하나의 이미지 형식이어야 하며, 파일당 최대 20 MB까지 허용합니다.

Marinara는 파일 이름이 아니라 실제 내용을 확인합니다. 이미지가 아닌 파일의 확장자만 `.png`로 바꿔서 올리면 업로드가 거부됩니다.

### 현재 채팅의 배경 고르기

1. **Settings**를 열고 **Appearance**, **Backgrounds** 순으로 이동하세요.
2. 격자에서 원하는 썸네일을 클릭하세요.
3. 선택한 이미지에 체크 표시가 붙고, 열려 있는 채팅의 배경이 됩니다.
4. 기본값으로 되돌리려면 선택된 썸네일을 다시 클릭하거나, **Chat Background** 옆의 **Remove**(제거) 버튼을 클릭하세요.

### 라이브러리 검색

라이브러리 위의 **Search backgrounds** 입력란으로 이름, 태그, 출처를 기준으로 걸러낼 수 있습니다. 개수 표시줄에는 조건에 맞는 이미지가 몇 개인지 "3 of 20 backgrounds"처럼 나옵니다. 검색 입력란의 작은 X를 클릭하면 검색어가 지워집니다.

검색창 옆의 선택 항목으로 배경을 **A-Z**, **Z-A**, **Newest**, **Oldest** 순으로 정렬합니다. 태그 필터를 모두 해제하려면 **All**을 선택하고, 태그로 걸러내려면 **Tags**(태그)를 펼쳐 태그를 하나 이상 선택하세요. 여러 태그를 선택하면 그중 하나만 달려 있어도 해당 배경이 표시됩니다.

### 배경을 폴더로 정리하기

폴더는 실제 이미지 파일을 옮기거나 숨기지 않고 라이브러리만 정리합니다.

1. **New Folder**(새 폴더)를 클릭하세요. Marinara가 겹치지 않는 이름으로 폴더를 만듭니다.
2. 폴더 이름을 더블 클릭하거나 두 번 탭해서 이름을 바꾸세요. 폴더를 선택한 뒤 F2를 눌러도 됩니다.
3. 컴퓨터에서는 배경 줄을 폴더로 끌어다 놓으세요. 휴대폰이나 태블릿에서는 줄을 길게 누른 다음 끌어다 놓으세요.
4. 배경을 폴더에서 빼려면 미분류 영역으로 다시 끌어다 놓으세요.

폴더와 폴더 배정 정보는 서버에 저장되고 백업에도 포함됩니다. 폴더를 삭제하면 안에 있던 배경이 미분류 목록으로 돌아갈 뿐, 이미지가 삭제되지는 않습니다. 검색과 태그 필터는 폴더 안에 있는 항목도 자동으로 찾아서 보여 줍니다.

**Background** 에이전트는 폴더에 들어 있는 배경까지 모두 그대로 인식합니다. 폴더는 **Settings** 안에서의 정리에만 영향을 줍니다.

### 배경 이름 바꾸기

이름은 **Library** 라벨이 붙은 이미지만 바꿀 수 있습니다.

1. 이미지 줄에 마우스를 올린 뒤 연필 아이콘(**Rename**, 이름 바꾸기)을 클릭하세요.
2. 새 이름을 입력하세요. 확장자는 입력하지 않아도 됩니다.
3. **Save**(저장)를 클릭하세요.

### 배경에 태그 달기

태그를 쓰면 직접 올린 이미지를 묶어서 찾기 편합니다. 태그는 **Library** 라벨이 붙은 이미지에만 달 수 있습니다.

1. 이미지 줄에서 태그 아이콘(**Edit tags**, 태그 편집)을 클릭하세요.
2. **Add tag...** 입력란에 태그를 입력하세요. 입력하는 동안 Marinara가 전에 쓴 태그를 추천합니다.
3. Enter를 누르거나 **Add**(추가)를 클릭하세요.
4. 태그를 빼려면 그 태그를 클릭하세요. 태그 편집이 열려 있는 동안에는 각 태그가 X가 붙은 버튼으로 표시됩니다.

### 배경 다운로드하기

기본 포함 이미지를 포함해 모든 배경을 다운로드할 수 있습니다. 이미지 줄에 마우스를 올린 뒤 다운로드 아이콘(**Download background**, 배경 다운로드)을 클릭하세요. 이미지는 원래 파일 이름 그대로 저장됩니다. iPhone이나 iPad에서는 공유 시트가 열리며, 여기서 이미지를 저장할 수 있습니다. 공유 시트가 열리지 않으면 표시되는 메시지에서 **Save file**(파일 저장)을 탭하세요.

### 배경 삭제하기

삭제는 **Library** 라벨이 붙은 이미지만 가능합니다. 이미지 줄에 마우스를 올려 휴지통 아이콘을 클릭하고 삭제를 확인하세요. 삭제한 이미지가 현재 채팅 배경이거나 Roleplay 기본 배경이었다면 Marinara가 기본 포함 이미지로 알아서 되돌립니다.

## Roleplay 기본 배경 지정하기

Roleplay 기본 배경은 새 Roleplay 채팅이 자체 배경을 고르기 전까지 처음 쓰는 이미지입니다. 한 번 지정해 두면 이후의 모든 새 Roleplay 채팅에 적용됩니다.

1. **Backgrounds** 섹션의 격자에서 원하는 이미지를 찾으세요.
2. 그 이미지 줄의 핀 아이콘(**Set as default for new Roleplay chats**, 새 롤플레이 채팅의 기본값으로 설정)을 클릭하세요.
3. 핀 버튼이 강조된 상태로 유지되고 썸네일에 **Default**(기본값) 라벨이 나타납니다. 이제 새 Roleplay 채팅은 이 이미지로 시작합니다.

이미지 왼쪽 위의 별은 이미지를 즐겨찾기에 추가합니다. 기본 배경은 바뀌지 않습니다.

되돌리려면 현재 기본 이미지의 핀을 다시 클릭하세요. 격자 위쪽의 **Reset Roleplay default**(롤플레이 기본값 초기화) 버튼을 클릭해도 됩니다. 이 버튼은 기본 배경이 기본 포함 이미지와 다를 때만 나타납니다.

## Background Blur

**Background Blur**는 채팅 뒤의 배경 이미지를 흐리게 만들어 글자를 읽기 쉽게 합니다. Roleplay와 Game Mode 배경에 적용됩니다.

1. **Backgrounds** 섹션에서 **Background Blur** 슬라이더를 찾으세요.
2. 0에서 24까지 조절하세요. 값이 클수록 더 흐려집니다.
3. 배경을 선명하게 두려면 0으로 설정하세요. 0에서는 값이 **Off**로 표시됩니다.

기본값은 0(**Off**)입니다.

## 직접 올린 이미지와 기본 포함 배경의 관계

라이브러리는 직접 올린 이미지와 기본 포함 **Game asset** 이미지를 하나의 격자에 함께 보여 줍니다. 고르는 방법도 같습니다. 다만 **Game asset** 이미지는 읽기 전용이라 이름 변경, 태그, 삭제 버튼이 나타나지 않습니다.

Gallery에서 AI로 만든 장면 배경도 같은 라이브러리에 저장되므로 나중에 다시 쓸 수 있습니다. [장면 배경과 Gallery](../media/scene-backgrounds.md)를 참고하세요.

## 배경 선택이 저장되는 위치

채팅에 어떤 배경이 나올지는 세 가지 설정이 결정하며, 저장 방식은 서로 다릅니다.

- 채팅마다 고른 **Chat Background**는 해당 채팅과 함께 서버에 저장됩니다. 어느 기기에서 그 채팅을 열어도 그대로 따라옵니다.
- 배경 폴더와 폴더 배정 정보는 서버에 저장되며, 다른 기기에서도 라이브러리와 함께 그대로 보입니다.
- Roleplay 기본 배경과 **Background Blur**는 기기별로 저장됩니다. 브라우저나 기기 사이에서 동기화되지 않습니다. 동기화 방식 전체는 [모양 설정](appearance-settings.md)에서 설명합니다.

## 자동 배경과 AI 생성 배경

이 가이드에서는 직접 골라 쓰는 라이브러리를 설명합니다. 배경을 알아서 처리해 주는 기능도 두 가지 있습니다.

- **Background** 에이전트는 Roleplay 채팅에서 매 턴 라이브러리에 있는 배경 중 장면에 맞는 것을 스스로 고릅니다. [Roleplay 배경](../roleplay/backgrounds.md)을 참고하세요.
- Gallery는 현재 장면을 바탕으로 완전히 새로운 장면 배경을 AI로 생성합니다. [장면 배경과 Gallery](../media/scene-backgrounds.md)를 참고하세요.
