# 전투 인카운터(Roleplay)

이 가이드에서는 Roleplay의 전투 인카운터를 설명합니다. 전투 인카운터는 Roleplay 장면에 체력 막대, 적과 파티 목록, 전투 로그를 갖춘 턴제 전투 화면을 더합니다. 선택 기능이며, 이 기능을 쓰지 않는 채팅은 지금까지와 똑같이 동작합니다. Game Mode에는 이와 별개인 자체 전투가 있습니다. [Game Mode: 전투](../game/combat.md)를 참고하세요.

## 전투 켜기

에이전트는 답변과 나란히 실행되는 도우미입니다. **Combat**(전투) 에이전트는 전투 기능을 더합니다. 기본값은 꺼짐이므로 채팅마다 켜야 합니다.

1. 채팅을 여세요. 채팅 안의 슬라이더 버튼으로 **Chat Settings**(채팅 설정)를 여세요.
2. **Agents**(에이전트)로 이동하세요.
3. **Enable Agents**(에이전트 활성화)가 꺼져 있으면 켜세요.
4. 스위치 아래 목록에서 **Combat** 에이전트를 추가하세요.

이제 메시지 입력란 위에 **Encounter**(전투) 버튼(교차한 검)이 나타납니다. 툴팁은 **Start Combat Encounter**(전투 인카운터 시작)입니다.

작동하지 않는 경우: 버튼이 없으면 이 채팅에서 **Combat** 에이전트가 활성화되지 않은 것입니다. 에이전트의 동작 방식은 [에이전트: 채팅을 도와주는 AI](../agents/agents-overview.md)를 참고하세요.

## 인카운터 시작하기

1. **Encounter**를 클릭하세요. **Configure Combat Narrative**(전투 나레이션 설정) 상자가 열립니다. AI가 사용할 서술 문체를 정하는 곳입니다.
2. **Combat Narration**(전투 나레이션)과 **Summary Narration**(요약 나레이션)의 문체를 고르세요. 앞의 것은 전투가 진행되는 동안, 뒤의 것은 전투가 끝났을 때 채팅에 기록되는 요약에 쓰입니다. 두 그룹에는 아래에 정리한 4가지 설정이 똑같이 들어 있습니다. 기본값으로도 잘 작동하므로 바로 **Begin Combat**(전투 시작)을 클릭해도 됩니다.
3. 선택 사항: **Spellbook**(스펠북)을 고르세요. 스펠북은 전투에서 쓸 수 있는 주문과 능력을 적어 둔 로어북(세계 설정을 모아 저장해 둔 것)입니다. 스펠북을 쓰지 않는다면 **None**(없음)으로 두세요.
4. **Begin Combat**을 클릭하세요. 전투 없이 상자를 닫으려면 **Cancel**(취소)을 클릭하세요.

AI가 적과 내 파티, 각자의 공격과 아이템을 만드는 동안 "Initializing combat encounter..."가 표시됩니다. 몇 초 정도 걸릴 수 있습니다.

| 문체 설정 | 선택지 |
| --- | --- |
| 시제 | **Present Tense**(현재 시제), **Past Tense**(과거 시제) |
| 인칭 | **First Person**(1인칭), **Second Person**(2인칭), **Third Person**(3인칭) |
| 서술 방식 | **Omniscient**(전지적): 모든 것을 압니다. **Limited**(제한된): 한 캐릭터가 아는 것만 압니다. |
| 시점 | 누구의 눈으로 장면을 서술할지 적는 입력란입니다. 비워 두면 중립적인 내레이터가 서술합니다. |

## 내 턴 진행하기

**Combat Encounter**(전투 인카운터) 화면은 네 부분으로 이루어져 있습니다.

- **Enemies**(적): 체력 막대와 상태 효과가 표시되는 카드입니다.
- **Party**(파티): 내 쪽 진영입니다. 내 캐릭터에는 **(You)** 표시가 붙습니다.
- **Combat Log**(전투 로그): 턴마다 남는 기록입니다.
- **Your Actions**(액션): 내가 쓰는 버튼입니다.

내 턴에는 **Attacks**(공격)에서 공격을 고르거나, **Items**(아이템)에서 아이템을 사용하거나, **Custom Action**(커스텀 액션)에 자유 행동을 입력해 보내세요. 예를 들어 "경비병의 눈에 모래를 뿌린다"처럼 입력할 수 있습니다.

행동에 대상이 필요하면 **Select Target**(타겟 선택) 창이 열립니다. 적이나 아군을 하나 고르거나, 광역 공격이라면 **All Enemies**(모든 적)를 고르세요. 광역 전용 행동은 이 단계를 건너뜁니다.

AI가 턴을 처리하는 동안에는 "Processing action..."이 표시되고 버튼이 잠깁니다. 턴이 끝나면 다시 풀립니다.

작동하지 않는 경우: AI가 앱이 읽을 수 없는 데이터를 반환하면 **Combat Error**(전투 오류) 화면이 나타납니다. **Close Encounter**(인카운터 닫기)를 클릭해 전투에서 안전하게 빠져나온 다음 새 인카운터를 시작하세요.

## 인카운터 끝내기

- 상단 막대의 **Conclude**(마무리)는 전투를 일찍 끝냅니다. 확인 상자가 나타난 다음 전투 요약이 채팅에 기록됩니다.
- 상단 막대의 **X**는 **End Combat**(끝내기)이라는 제목의 확인 상자를 거친 다음 전투를 닫고 버립니다. 요약은 기록되지 않습니다.
- 한쪽이 이기면 배너에 **VICTORY**, **DEFEAT**, **FLED**, **INTERRUPTED** 중 하나가 표시됩니다. 내가 고른 **Summary Narration** 문체로 요약이 채팅에 기록됩니다. 요약이 준비되면 **Close Combat Window**(전투 창 닫기)를 클릭하세요.

요약이 실패하면 버튼이 **Close Anyway**(그래도 닫기)로 바뀝니다. 이 버튼을 클릭하면 요약 없이 장면으로 돌아갑니다.

## Game Mode 전투와의 차이

- Roleplay 인카운터는 **Encounter**로 직접 시작합니다. Game Mode에서는 이야기에 필요할 때 Game Master가 전투를 시작합니다.
- Roleplay 전투에는 **Combat** 에이전트가 필요합니다. Game Mode 전투에는 필요하지 않습니다.
- 두 시스템은 서로 다른 전투 화면을 씁니다.
