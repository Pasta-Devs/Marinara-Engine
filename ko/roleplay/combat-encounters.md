# 전투 인카운터(Roleplay)

이 가이드에서는 Roleplay 모드의 전투 인카운터를 설명합니다. **Combat**(전투) 에이전트를 켜고 전투를 시작해 Encounter 창에서 진행하는 방법을 알 수 있습니다. Game Mode의 전투와 무엇이 다른지도 함께 정리했습니다.

전투 인카운터는 Roleplay의 선택 기능입니다. 체력 막대, 적과 파티 목록, 전투 기록을 갖춘 턴제 전투 화면을 장면에 더해 줍니다. 이 기능을 켜지 않으면 Roleplay 채팅은 지금까지와 똑같이 동작합니다.

## Combat 에이전트 켜기

에이전트는 메시지가 생성될 때 자동으로 실행되는 도우미 기능입니다. **Combat** 에이전트는 Roleplay 채팅에 전투 기능을 더합니다. 기본값은 꺼짐이므로 채팅마다 직접 켜야 합니다.

1. 전투를 추가할 채팅을 여세요.
2. **Chat Settings**(채팅 설정)를 여세요. 채팅 안의 **Chat Settings** 버튼은 직접 옮기지 않았다면 오른쪽 위에 있습니다.
3. **Agents**(에이전트) 섹션을 여세요.
4. **Enable Agents**(에이전트 활성화)가 꺼져 있으면 켜세요.
5. 채팅에 **Combat** 에이전트를 추가하세요.

이제 메시지 입력란 위 동작 줄에 **Encounter**(인카운터) 버튼(교차한 검 아이콘)이 보입니다. 툴팁은 **Start Combat Encounter**(전투 인카운터 시작)입니다. 이 버튼이 보이지 않는다면 해당 채팅에서 **Combat** 에이전트가 활성화되지 않은 것입니다.

Agents 패널과 에이전트의 동작 방식은 [에이전트: 채팅을 도와주는 AI](../agents/agents-overview.md)에서 자세히 설명합니다.

## 인카운터 시작하기

**Encounter** 버튼을 클릭하면 설정 상자가 열립니다. 이 상자의 제목은 **Configure Combat Narrative**(전투 나레이션 설정)입니다. 전투 중과 전투 후에 AI가 사용할 서술 문체를 정하는 곳입니다.

설정 상자에는 문체 그룹이 2개 있습니다.

- **Combat Narration**: 전투가 진행되는 동안 쓰이는 문체입니다.
- **Summary Narration**: 전투가 끝났을 때 채팅에 기록되는 요약의 문체입니다.

두 그룹 모두 아래 4가지 항목이 똑같이 들어 있습니다.

- 시제: **Present Tense** 또는 **Past Tense**.
- 인칭: **First Person**, **Second Person**, **Third Person**.
- 서술 시점: **Omniscient**(나레이터가 모든 것을 압니다) 또는 **Limited**(나레이터가 한 캐릭터가 아는 것만 압니다).
- 시점 입력란: 누구의 눈으로 장면을 서술할지 적습니다. 비워 두면 중립적인 나레이터 어조를 유지합니다.

문체 그룹 아래에는 선택 사항인 **Spellbook**(스펠북) 드롭다운이 있습니다. 스펠북은 전투에서 쓸 수 있는 주문과 능력을 적어 둔 특수한 로어북입니다. 로어북은 세계 설정 항목을 모아 둔 것입니다. 스펠북을 연결하면 AI가 캐릭터의 주문 목록을 파악합니다. 스펠북을 쓰지 않는다면 **None** 그대로 두세요.

준비가 끝났으면 **Begin Combat**(전투 시작)을 클릭하세요. 전투를 시작하지 않고 설정을 닫으려면 **Cancel**(취소)을 클릭하세요.

**Begin Combat**을 클릭하면 AI가 전투를 구성하는 동안 "Initializing combat encounter..."가 표시됩니다. 이때 적, 파티, 각자의 공격과 아이템이 만들어집니다. 몇 초 정도 걸립니다.

## 인카운터 진행하기(Encounter 창)

전체 전투 화면인 Encounter 창의 제목은 **Combat Encounter**(전투 인카운터)입니다. 다음 영역으로 이루어져 있습니다.

- **Enemies**(적): 적 카드가 격자로 놓입니다. 카드마다 체력 막대와 상태 효과가 표시됩니다.
- **Party**(파티): 아군 쪽 진영입니다. 직접 조작하는 캐릭터에는 **(You)** 표시가 붙습니다.
- **Combat Log**(전투 로그): 턴마다 무슨 일이 일어났는지 이어서 기록합니다.
- **Your Actions**(액션): 자기 턴에 사용하는 버튼입니다.

**Your Actions**에서 할 수 있는 일은 다음과 같습니다.

- **Attacks**(공격) 중 하나를 고릅니다.
- **Items**(아이템) 중 하나를 사용합니다.
- **Custom Action**(커스텀 액션) 입력란에 자유 행동을 적어 보냅니다. 버튼으로 표현되지 않는 행동, 예를 들어 "경비병의 눈에 모래를 뿌린다" 같은 행동에 사용합니다.

공격이나 아이템에 대상이 필요하면 **Select Target**(타겟 선택) 상자가 열립니다. 적이나 아군을 하나 고르거나, 모든 적을 한 번에 때리는 광역 공격이라면 **All Enemies**(모든 적)를 고르세요. 광역 전용 행동은 단일 대상 선택을 건너뜁니다.

AI가 턴을 처리하는 동안에는 화면에 "Processing action..."이 표시되고 버튼이 잠깁니다. 턴이 끝나면 다시 풀립니다.

AI가 앱에서 읽을 수 없는 데이터를 반환하면, 앱이 깨지는 대신 **Combat Error**(전투 오류) 화면이 나타납니다. 이 화면에서 **Close Encounter**(인카운터 닫기)를 클릭하면 전투에서 안전하게 빠져나갑니다.

## 인카운터 끝내기

전투를 일찍 끝내는 방법은 2가지이고, 여기에 한쪽이 이겨서 자연스럽게 끝나는 경우가 더해집니다.

- 상단 막대의 **Conclude**(마무리)를 클릭하면 전투를 일찍 끝냅니다. 먼저 확인 상자가 나타납니다. 이후 앱이 전투 요약을 채팅에 기록합니다.
- 상단 막대의 **X** 버튼을 클릭하면 전투를 닫고 버립니다. **End Combat**(끝내기)이라는 제목의 확인 상자가 먼저 나타납니다. 이 경우에는 요약을 기록하지 않습니다.

전투가 자연스럽게 끝나면 결과 배너로 **VICTORY**, **DEFEAT**, **FLED**, **INTERRUPTED** 중 하나가 나타납니다. 이어서 앱이 앞서 고른 **Summary Narration** 문체로 전투 요약 메시지를 채팅에 기록합니다. 요약이 준비되면 **Close Combat Window**(전투 창 닫기)를 클릭해 장면으로 돌아가세요.

요약 생성에 실패하면 버튼이 **Close Anyway**(그래도 닫기)로 바뀝니다. 이 버튼을 클릭하면 요약 없이 장면으로 돌아갑니다.

## Game Mode 전투와의 차이

전투 인카운터는 Roleplay 모드를 위한 가볍고 독립적인 전투 계층입니다. Game Mode에는 자체 전투 시스템이 따로 들어 있습니다.

주요 차이는 다음과 같습니다.

- Roleplay의 인카운터는 **Encounter** 버튼으로 직접 시작합니다. Game Mode에서는 이야기의 흐름에 따라 AI 게임 마스터(GM)가 전투를 시작합니다.
- Roleplay 전투에는 **Combat** 에이전트가 켜져 있어야 합니다. Game Mode 전투는 **Combat** 에이전트를 쓰지 않으며 없어도 동작합니다.
- 두 시스템은 서로 다른 전투 화면을 쓰고 데이터를 공유하지 않습니다.

Game Mode의 전투 시스템은 [Game Mode: 전투](../game/combat.md)에서 설명합니다.
