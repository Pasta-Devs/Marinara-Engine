# Roleplay HUD와 트래커

HUD(heads-up display)는 Roleplay(롤플레이) 채팅에서 이야기의 실시간 세부 정보를 보여 줍니다. 시간, 날씨, 등장 캐릭터, 내 능력치, 소지품, 퀘스트입니다. 어떤 값이든 직접 고칠 수 있고, 값을 잠가 AI가 더 이상 바꾸지 못하게 하거나, 필요할 때 트래커를 다시 실행할 수 있습니다.

값은 트래커 에이전트가 만들어 냅니다. 에이전트는 답변과 나란히 실행되는 보조 기능입니다. 트래커 에이전트는 이야기를 지켜보다가 메시지마다 HUD의 한 부분을 갱신합니다. 위젯은 해당 에이전트가 그 채팅에서 켜져 있을 때만 나타납니다.

## HUD 켜기

1. 채팅 안의 슬라이더 버튼으로 **Chat Settings**(채팅 설정)를 여세요.
2. **Agents**(에이전트)로 이동해 **Enable Agents**(에이전트 활성화)를 켜세요.
3. 스위치 아래 목록에서 에이전트를 추가하세요. 기본 HUD라면 먼저 **World State**를 추가하세요. 더 많이 보려면 **Persona Stats**, **Character Tracker**, **Quest Tracker**를 추가하세요.
4. 메시지를 보내세요.

답변이 끝나면 트래커가 나타납니다. 휴대폰에서는 **World State** 버튼이 보입니다. 컴퓨터에서는 **Tracker Panel**(트래커 패널)이나 **Trackers**(트래커) 창이 보입니다(아래 참고). 어떤 에이전트가 어떤 위젯을 채우는지는 위젯 표에 정리되어 있습니다.

작동하지 않는 경우: 켜진 트래커 에이전트가 없으면 HUD에 위젯이 나타나지 않습니다. **Enable Agents**가 켜져 있는지 확인하세요.

## HUD가 나타나는 곳

휴대폰에서는 이동 가능한 **World State**와 **Player & Tracker**(플레이어 및 트래커) 버튼이 트래커입니다. 버튼을 탭하면 패널이 열리고, **X**를 탭하면 닫힙니다. World State에 정보가 생기면 그 버튼에 위치, 날짜, 시간, 날씨, 온도를 담은 작은 배너가 표시됩니다. 버튼은 원하는 곳으로 끌어 옮기세요. 채팅이 버튼 위치를 기억합니다. 버튼은 **Settings → Appearance → App**(설정 → 모양 → 앱)의 **Chat widget style**(채팅 위젯 스타일)을 따릅니다.

컴퓨터에서는 같은 트래커가 두 곳 중 한 곳에 나타납니다.

- **Tracker Panel**: 메시지 옆의 측면 패널입니다. 기본적으로 켜져 있습니다. **Chat Settings** 제목 표시줄의 주사위 버튼으로 켜고 끕니다.
- **Trackers** 창: Tracker Panel이 꺼져 있을 때 트래커를 담는 이동 가능한 창입니다.

한 번에 둘 중 하나만 사용합니다. [Tracker Panel](#the-tracker-panel)과 [Trackers 창](#the-trackers-window)을 참고하세요.

## HUD 위젯

| 위젯 | 필요한 에이전트 | 표시 내용 |
| --- | --- | --- |
| **World State**(세계 상태) | World State | 장소, 날짜, 시간, 날씨, 온도, 그리고 직접 만든 세계 필드 |
| **Persona Stats**(페르소나 스탯) | Persona Stats | 내 페르소나의 상태 막대와 상태 문구 |
| **Present Characters**(등장 캐릭터) | Character Tracker | 장면에 있는 캐릭터와 그 기분, 겉모습, 사용자 지정 필드 |
| **Inventory**(인벤토리) | Persona Stats | 지니고 있는 물품과 수량 |
| **Inventory Tracker**(인벤토리 트래커) | Inventory Tracker | 화폐, 착용 중인 장비, 지니고 다니는 물품을 나눈 목록 |
| **Active Quests**(진행 중인 퀘스트) | Quest Tracker | 현재 목표 |
| **Custom Tracker**(커스텀 트래커) | Custom Tracker | 카운터나 화폐처럼 직접 이름을 붙인 필드 |

**Inventory** 위젯은 **Persona Stats** 에이전트가 채우므로, 그 에이전트를 켜면 두 위젯이 함께 나옵니다. **Inventory Tracker**는 별개입니다. 항목을 **Currencies**(화폐), **Equipped**(장착됨), **Inventory** 세 그룹으로 관리하며, 착용 중인 장비를 두 번 나열하지 않습니다.

항목은 저마다 작은 알약 모양으로 표시됩니다. 수량은 2 이상일 때만 `×4`처럼 표시됩니다. 수량이 1인 항목을 바꾸려면 추가 모드나 잠금 모드를 켜세요. 둘 다 모든 항목에 수량 조절 칸을 표시합니다. 추가 모드는 Tracker Panel 머리글의 **+** 버튼입니다. [잠금 모드](#lock-mode)는 아래에서 설명합니다.

**Present Characters**는 캐릭터 이모지를 최대 3개까지 보여 주고 나머지는 "+N"으로 셉니다. **Inventory**와 **Custom Tracker**는 항목을 하나씩 번갈아 보여 줍니다.

## 트래커 값 수정하기

모든 필드를 수정할 수 있으므로 AI가 잘못 적은 값을 바로잡을 수 있습니다. 수정한 내용은 곧바로 저장됩니다. 다음 답변은 수정한 값에서 시작하며, 값을 수정한 답변을 재생성하거나 스와이프할 때도 마찬가지입니다.

1. 트래커를 여세요. 휴대폰에서는 버튼을 탭하고, 컴퓨터에서는 Tracker Panel이나 Trackers 창에서 해당 섹션을 여세요.
2. 값을 클릭하고 새 값을 입력하세요.

- **World State**: **Location**(장소), **Date**(날짜), **Time**(시간), **Weather**(날씨), **Temperature**(온도), 그리고 사용자 지정 세계 필드.
- **Persona Stats**: **Status**(상태) 문구, 그리고 현재 값과 최대 값을 가진 이름 붙은 막대. 막대를 추가하거나 삭제할 수 있습니다.
- **Present Characters**: 캐릭터를 추가하거나 삭제하세요. 캐릭터마다 이모지, 이름, **Mood**(기분), **Look**(외형), **Outfit**(복장), **Thinks**(생각, 속마음), 사용자 지정 필드를 수정합니다. 캐릭터마다 아바타를 업로드할 수 있습니다. **Auto**(자동) 버튼은 "Auto-generate avatars"(아바타 자동 생성)를 켜거나 끕니다.
- **Inventory**: 물품을 추가하거나 삭제하세요. 이름과 수량을 수정합니다.
- **Inventory Tracker**: **Currencies**, **Equipped**, **Inventory** 아래에서 항목을 추가하거나 삭제하세요. 물품을 다른 그룹으로 옮기려면 삭제한 뒤 그 그룹에 추가하세요.
- **Active Quests**: 퀘스트를 추가하거나 삭제하세요. 퀘스트마다 체크박스가 달린 목표가 있습니다.
- **Custom Tracker**: 이름과 값 필드를 추가, 삭제, 수정하세요.

여러 값을 한꺼번에 고치려면 [State Editor](#the-state-editor)를 사용하세요.

<a id="lock-mode"></a>

## 잠금 모드

트래커 에이전트는 턴이 끝날 때마다 HUD 값을 덮어씁니다. 잠금 모드를 쓰면 값을 고정할 수 있습니다. 필드가 잠겨 있으면 다음 자동 실행이 그 필드를 건드리지 않습니다. 값이 계속 엉뚱하게 바뀔 때 쓰세요.

1. 트래커를 여세요.
2. 트래커 위쪽의 잠금 토글을 클릭하세요(툴팁 **Enter lock mode**(잠금 모드 시작)). 수정 가능한 값마다 옆에 작은 잠금 버튼이 나타납니다.
3. 값 옆의 잠금 버튼을 클릭하세요(툴팁 **Lock field**(필드 잠금)). 잠긴 필드에는 표시가 붙습니다.

잠금을 풀려면 같은 버튼을 다시 클릭하세요(**Unlock field**(필드 잠금 해제)). 잠금 모드에서 나가려면 위쪽 토글을 다시 클릭하세요(**Exit lock mode**(잠금 모드 종료)). 잠금 모드는 HUD 전체에 함께 적용되므로, 트래커 한 곳에서 켜면 모든 곳에 잠금 버튼이 나타납니다.

## 트래커 다시 실행하기

다음 메시지를 기다리지 않고 트래커를 바로 갱신하려면 트래커 안의 원형 화살표 버튼을 클릭하세요. 가장 최근 턴에 대해 그 트래커만 다시 실행합니다. 툴팁에는 **Re-run world state tracker only**(월드 트래커만 재실행)처럼 트래커 이름이 들어갑니다.

요청할 때만 트래커가 실행되게 하려면 **Chat Settings → Agents → Trackers Control**(채팅 설정 → 에이전트 → 트래커 제어)을 열고 **Individual tracker schedule**(개별 트래커 스케줄)에서 그 트래커를 켜세요. 수동 트래커는 답변마다 실행되지 않습니다. 예전 **Manual Trackers** 스위치를 켜 두었던 채팅에서는 그곳의 트래커가 모두 켜진 상태로 표시됩니다.

수동 트래커가 하나라도 있으면 새로고침 버튼이 나타납니다. 휴대폰에서는 HUD 줄에, 컴퓨터에서는 Trackers 창 제목 옆에 있습니다. 이 버튼을 클릭하면 현재 턴에 대해 수동 트래커를 실행합니다.

모든 트래커를 다시 실행하고, 실패한 에이전트를 재시도하고, **Clear Trackers**(트래커 비우기)를 쓰는 곳은 **Agent activity**(에이전트 활동)입니다. [에이전트 활동](getting-started.md#agent-activity)을 참고하세요.

> **경고:** **Clear Trackers**는 그 채팅에서 기록한 세계 상태를 모두 지우며 되돌릴 수 없습니다.

<a id="the-trackers-window"></a>

## Trackers 창

컴퓨터에서는 Tracker Panel이 꺼져 있으면 트래커가 **Trackers** 창을 씁니다. 메시지 옆에 공간이 있으면 왼쪽에 창이 열립니다. 공간이 없으면 채팅 왼쪽 위의 작은 **Trackers** 버튼으로 시작합니다. 버튼을 클릭해 창을 여세요. 저장된 배치가 있는 채팅은 그 배치를 유지합니다.

제목 표시줄을 끌어 창을 옮기고 가장자리를 끌어 크기를 바꾸세요. 오른쪽 위 버튼은 다음과 같습니다.

- **Pin**(고정): 다른 곳을 클릭해도 창을 열어 둡니다. 처음에는 고정되어 있습니다.
- **Lock**(잠금): 창 이동과 크기 변경을 막고 버튼 위치도 고정합니다. 버튼으로 창을 여는 것은 그대로 됩니다.
- **Close**(닫기): 창을 이동 가능한 **Trackers** 버튼으로 줄입니다.

Chat Settings의 **Reset View**(보기 초기화)는 저장된 배치를 지우고 공간에 맞춰 처음 표시할 창이나 버튼을 고릅니다.

트래커마다 접을 수 있는 섹션이 있습니다. 헤더를 클릭하면 작은 미리보기로 접히고, 다시 클릭하면 열립니다. Marinara는 어떤 섹션을 접었는지 기억합니다.

트래커 하나를 별도 창으로 띄우려면 화살표 옆의 별도 창 버튼을 클릭하거나 제목을 Trackers 창 밖으로 끌어내세요. 새 창은 고정되지 않은 상태로 시작합니다. 계속 열어 두려면 고정하세요. **X**를 누르면 트래커 아이콘이 있는 작은 버튼으로 줄어듭니다. **World State**는 대신 배너로 줄어들며, 휴대폰과 같은 위치, 날짜, 시간, 날씨를 보여 주므로 채팅 위쪽 가운데처럼 원하는 곳으로 끌어다 놓을 수 있습니다. 되돌리려면 **Put back in Trackers**(트래커에 되돌려 놓기, **X** 왼쪽의 굽은 화살표)를 클릭하거나 Trackers 창 위로 끌어다 놓으세요. 채팅마다 어떤 트래커를 어디에 꺼내 두었는지 기억합니다.

<a id="the-tracker-panel"></a>

## Tracker Panel

**Tracker Panel**은 같은 데이터를 보여 주는 더 큰 측면 패널입니다. 캐릭터 초상화와 속마음도 보여 줍니다.

1. **Chat Settings**를 여세요.
2. 제목 표시줄에서 고정과 잠금 옆에 있는 **Tracker Panel** 버튼(주사위)을 클릭하세요. 패널이 켜져 있는 동안 버튼이 강조됩니다.
3. 다시 클릭하면 패널이 숨겨집니다. 그러면 컴퓨터에서는 트래커가 Trackers 창에 표시됩니다.

컴퓨터에서는 패널이 **Desktop size**(데스크톱 크기)에서 정한 너비까지 메시지 옆에 맞춰 들어갑니다. 채팅 사이드바를 열었을 때처럼 창이 둘 다 담기에 좁으면 메시지와 메시지 입력란이 조금 좁아집니다. 휴대폰이나 태블릿에서 켜면 끌어 옮길 수 있는 Tracker Panel 버튼이 생깁니다. 탭하면 패널이 열리고, 다시 탭하면 닫힙니다. 패널이나 다른 화면이 채팅을 가리는 동안에는 채팅의 이동 가능한 버튼이 숨겨지며, 같은 자리에 다시 나타납니다.

### 트래커 필드 사용자 지정하기

패널 머리글의 버튼으로 트래커 구조를 바꿉니다.

- **+**는 추가 모드로 들어갑니다. World 섹션에는 **Add world field**(월드 필드 추가)가, 등장 캐릭터 카드마다 **Add custom field**(사용자 지정 필드 추가)가 생깁니다. 필드 이름은 일반 모드에서도 계속 보입니다.
- 휴지통 아이콘은 삭제 모드로 들어갑니다. 여기서 사용자 지정 세계 필드나 캐릭터 필드를 지웁니다. 필드를 지우면 그 필드의 잠금도 함께 사라집니다.
- 자물쇠 아이콘은 잠금 모드로 들어갑니다. 사용자 지정 필드도 기본 필드와 똑같이 잠깁니다.
- 사선이 그어진 눈 아이콘은 숨김 모드로 들어갑니다. 캐릭터 카드에서 **Mood**, **Look**, **Outfit**, **Thoughts**(생각) 중 하나를 고르세요. 숨긴 필드는 Tracker Panel과 HUD에서 사라지고, 값이 비워지며, 에이전트가 다시 채우지 않도록 잠긴 상태로 남습니다. 숨김 모드로 다시 들어가면 빈 필드로 다시 표시할 수 있습니다.

에이전트는 사용자 지정 필드의 값을 갱신합니다. 직접 만든 필드를 지우지는 않습니다.

### 새 초상화 만들기

Character Tracker에 이미지 연결이 있으면 캐릭터의 큰 카드에서 새 초상화를 만들 수 있습니다. 작은 카드에서는 **Feature character card**(캐릭터 카드 강조)를 클릭해 큰 카드를 여세요. Trackers 창에는 항상 큰 카드가 표시됩니다. 초상화에 마우스를 올린 뒤 눈 버튼을 클릭하면 **Look**을 바탕으로, 셔츠 버튼을 클릭하면 **Look**과 **Outfit**을 바탕으로 초상화를 만듭니다. 셔츠 버튼은 캐릭터에게 복장이 있을 때만 나타납니다. 기존 초상화는 새 초상화가 준비될 때까지 그대로 남습니다. 만들기에 실패하면 기존 초상화가 유지됩니다. 카드 아바타나 표정 스프라이트로 표시되는 캐릭터에게는 이 버튼이 없습니다.

### Tracker Panel 설정

**Settings → Appearance**를 열고 **Roleplay**(롤플레이) 그룹을 연 다음 **Tracker Panel** 섹션을 찾으세요.

| 설정 | 하는 일 |
| --- | --- |
| **Tracker Panel** | 켜고 끄는 스위치로, 주사위가 바꾸는 것과 같은 설정입니다. 기본적으로 켜져 있습니다. 켜져 있으면 라벨에 "Shown in the Roleplay HUD"(롤플레이 HUD에 표시됨)라고 표시됩니다. |
| **Dock Tracker Panel to edge**(트래커 패널을 가장자리에 고정) | 패널을 화면 가장자리에 붙이고, 근처의 채팅 컨트롤이 패널과 겹치지 않게 합니다. |
| **Use expression sprites for tracker portraits**(트래커 초상화에 얼굴 표정 스프라이트 사용) | 표정 스프라이트가 있으면 일반 아바타 대신 캐릭터의 현재 표정 스프라이트를 씁니다. [캐릭터 스프라이트](../characters/sprites.md)를 참고하세요. |
| **Panel background**(패널 배경) | 패널의 색상이나 그라데이션입니다. |
| **Desktop size** | 패널 너비입니다. **Compact**, **Standard**, **Expanded** 중에서 고릅니다. |
| **Thought display mode**(추론 표시 모드) | **Docked**는 캐릭터 카드 안에 속마음을 엽니다. **Floating**은 초상화 옆에 말풍선으로 엽니다. |
| **Always show Docked thoughts**(고정된 생각 항상 표시) | **Docked**일 때 주요 캐릭터의 속마음을 버튼 뒤에 숨기지 않고 항상 보이게 합니다. |
| **Stat display mode**(스탯 표시 모드) | 스탯을 막대나 원형 게이지로 보여 줍니다. |
| **Temperature unit**(온도 단위) | **°C**(기본값) 또는 **°F**입니다. 표시만 바뀌고 저장된 값은 바뀌지 않습니다. |

## State Editor

**State Editor**(상태 편집기)는 현재 턴의 모든 트래커를 한 창에 보여 주므로, 트래커를 하나씩 열지 않고도 값을 찾아 고칠 수 있습니다. 휴대폰에서도 작동합니다.

다음 중 한 곳에서 여세요.

- Tracker Panel 머리글의 톱니바퀴(**Tracker panel settings**(트래커 패널 설정))를 누른 다음 **{ }** 버튼(**Open in State Editor**(상태 편집기에서 열기)).
- **Trackers** 창의 제목 표시줄이나 별도 창으로 꺼낸 트래커의 제목 표시줄에 있는 **{ }** 버튼.
- 휴대폰에서는 **World State**와 **Player & Tracker** 패널의 **{ }** 버튼.
- **Agent Suite**(에이전트 모음)의 **Tracker Data**(트래커 데이터) 아래에 있는 **Open in State Editor** 링크.

편집기는 열기 전에 있던 트래커의 섹션에서 열립니다. 예를 들어 World State는 **Scene**(장면)에서 열립니다.

- **턴 줄**: 검색창 아래에 있습니다. 편집 중인 메시지와 스와이프를 알려 줍니다. 예를 들어 "Editing message #12 · swipe 2 of 3"입니다. **Latest**(최신)는 가장 최근 턴을 표시합니다. 스와이프마다 상태가 따로 있으므로, 다른 스와이프를 편집하려면 먼저 스와이프를 바꾸세요.
- **섹션**: **Scene**, **Present Characters**, **Persona Stats**, **Inventory Tracker**, **Custom Tracker Fields**(커스텀 트래커 필드), **Active Quests**입니다. 휴대폰에서는 편집기 위의 칩으로 나타납니다. 점은 바뀐 섹션을 표시합니다.
- **검색**: `mood`처럼 키나 값을 입력하세요. 결과를 클릭하면 그곳으로 이동합니다.
- **Fields**(필드): 각 섹션은 **Fields**로 열리며, 텍스트, 숫자, 켜기/끄기 값을 입력하는 상자가 있습니다.
- **No value**(값 없음): 빈 필드에는 **Text**(텍스트), **Number**(숫자), **On/off**(켜기/끄기) 중에서 고르는 선택지가 표시됩니다.
- **Add item**(항목 추가): 바로 위 항목을 복사해 항목을 추가합니다.
- **Add**(추가): 섹션이나 빈 카드에 이름 붙은 필드를 추가합니다.
- **×**: 항목을 삭제하거나 값을 비웁니다.
- **JSON**: 원본 데이터를 편집합니다. **Format**(서식 정리)은 JSON을 깔끔하게 정리합니다. JSON이 깨진 섹션은 고칠 때까지 저장할 수 없습니다.
- **Revert**(되돌리기): 한 섹션에서 바꾼 내용을 취소합니다.

캐릭터와 퀘스트는 이야기에 속하므로 여기서 카드를 추가할 수 없습니다. 캐릭터의 스탯처럼 카드 안의 목록은 편집할 수 있습니다.

저장하려면 다음과 같이 하세요.

1. **Review changes**(변경 사항 검토)를 클릭해 바뀐 내용을 줄 단위로 확인하세요.
2. **Save changes**(변경 사항 저장)를 클릭하세요. 편집하던 턴에 모든 섹션을 한꺼번에 기록합니다.

그때까지 초안은 창 안에 남고, 창을 닫으면 초안을 버리기 전에 확인을 묻습니다.

작동하지 않는 경우: 편집하는 동안 이야기가 진행되었다면 편집기는 그것을 덮어쓰지 않습니다. 새 답변이나 스와이프가 생기거나, 바꾼 섹션을 트래커가 갱신하면 저장이 거부되고 **Reload**(다시 불러오기) 버튼이 나타납니다. **Reload**는 가장 최신 상태를 보여 주고 초안을 버립니다.
