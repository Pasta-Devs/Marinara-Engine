# Roleplay HUD와 트래커

이 가이드에서는 Roleplay(롤플레이)의 HUD와 거기에 표시되는 작은 트래커 위젯을 설명합니다. 값을 수정하고 고정하는 방법, 그리고 더 큰 Tracker Panel이 어떻게 동작하는지 알 수 있습니다. Marinara Engine의 Roleplay 모드에 해당하는 내용입니다.

## HUD란

HUD(heads-up display)는 채팅 영역 위쪽에 놓인 작은 아이콘 위젯의 줄, 즉 채팅 위쪽 정보 막대입니다. 위젯 하나가 시간, 능력치, 현재 등장 캐릭터처럼 이야기의 현재 상태를 한 가지씩 보여 줍니다. 이야기가 진행되면 Marinara가 이 값들을 알아서 최신 상태로 유지합니다.

값은 트래커 에이전트가 만들어 냅니다. 에이전트는 뒤에서 조용히 돌아가는 작은 AI 조력자입니다. 트래커 에이전트는 각각 이야기를 지켜보다가 메시지가 오갈 때마다 HUD의 한 부분을 갱신합니다. 따로 요청하지 않아도 됩니다.

위젯은 해당 트래커 에이전트가 그 채팅에서 켜져 있을 때만 나타납니다. 에이전트는 **Chat Settings**(채팅 설정)의 **Agents**(에이전트) 항목에서 켜고 끕니다. 트래커 에이전트가 하나도 켜져 있지 않으면 HUD에는 **Agents & Actions**(에이전트와 액션) 버튼만 남고 위젯은 보이지 않습니다.

## HUD 위젯

트래커 위젯은 7가지입니다. 각각 자기 에이전트가 활성화되어야 나타납니다.

| 위젯                   | 필요한 에이전트   | 표시 내용                                                                        |
| ---------------------- | ----------------- | -------------------------------------------------------------------------------- |
| **World State**(세계 상태)        | World State       | 장소, 날짜, 시간, 날씨, 온도, 그리고 직접 만든 세계 필드                         |
| **Persona Stats**(페르소나 스탯)      | Persona Stats     | 페르소나의 상태 막대와 상태 문구                                                 |
| **Present Characters**(등장 캐릭터) | Character Tracker | 장면에 있는 캐릭터와 그 기분, 겉모습, 캐릭터별 사용자 지정 필드                  |
| **Inventory**          | Persona Stats     | 지니고 있는 물품과 수량                                                          |
| **Inventory Tracker**  | Inventory Tracker | 화폐, 착용 중인 장비, 지니고 다니는 물품을 나눈 목록                              |
| **Active Quests**(진행 중인 퀘스트)      | Quest Tracker     | 현재 목표                                                                        |
| **Custom Tracker**(커스텀 트래커)     | Custom Tracker    | 카운터나 화폐처럼 직접 이름을 붙인 필드                                          |

**Inventory**(인벤토리) 위젯은 **Persona Stats** 위젯과 같은 **Persona Stats** 에이전트가 움직인다는 점에 유의하세요. **Persona Stats**를 켜면 두 위젯이 함께 나옵니다.

별도의 **Inventory Tracker**는 Persona Stats의 소지품과 다릅니다. 이름과 수량만 담은 간결한 항목을 **Currencies**, **Equipped**, **Inventory** 세 그룹으로 관리하고, 착용 중인 장비가 지니고 다니는 물품에도 겹쳐 나오지 않게 합니다.

항목은 저마다 작은 알약 모양으로 표시됩니다. 알약은 패널 너비를 따라 늘어서다가 다음 줄로 넘어가므로, 물품이 많아져도 세로로 길게 늘어지지 않고 읽기 좋은 상태를 유지합니다. 수량은 2 이상일 때만 이름 뒤에 `×4` 형태로 붙고, 하나뿐인 물품은 이름만 나옵니다. 패널이 좁으면 알약이 한 줄에 하나씩 쌓입니다.

지금 1인 수량을 바꾸려면 추가 모드나 잠금 모드를 켜세요. 둘 다 모든 항목에 수량 조절 칸을 드러냅니다.

**Present Characters** 위젯은 캐릭터 이모지를 최대 3개까지 보여 주고, 그보다 많으면 "+N" 형태로 나머지 수를 표시합니다. **Inventory**와 **Custom Tracker** 위젯은 항목을 하나씩 번갈아 보여 줍니다.

## 팝오버에서 값 수정하기

위젯을 클릭하면 팝오버가 열립니다. 팝오버는 화면 위에 떠 있는 작은 패널입니다. 안에 있는 모든 필드를 수정할 수 있어서 AI가 잘못 적은 값을 바로잡을 수 있습니다. 수정한 내용은 곧바로 저장됩니다.

팝오버별로 수정할 수 있는 항목은 다음과 같습니다.

- **World State**: **Location**(장소), **Date**(날짜), **Time**(시간), **Weather**(날씨), **Temperature**(온도), 그리고 사용자 지정 세계 필드 행.
- **Persona Stats**: **Status**(상태) 문구, 그리고 현재 값과 최대 값을 가진 이름 붙은 상태 막대. 막대는 추가하거나 삭제할 수 있습니다.
- **Present Characters**: 캐릭터를 추가하거나 삭제하고, 캐릭터마다 이모지, 이름, **Mood**(기분), **Look**(외형), **Outfit**(복장), **Thinks**(속마음), 사용자 지정 필드 값을 수정합니다. 캐릭터별로 아바타를 업로드할 수도 있습니다. **Auto** 버튼을 누르면 "Auto-generate avatars: ON"과 "Auto-generate avatars: OFF"가 번갈아 전환됩니다.
- **Inventory**: 물품을 추가하거나 삭제하고, 물품마다 이름과 수량을 수정합니다.
- **Inventory Tracker**: **Currencies**, **Equipped**, **Inventory** 아래에서 항목을 추가하거나 삭제하고, 항목마다 이름과 수량을 수정합니다. 물품을 다른 그룹으로 옮기는 일은 아직 한 번에 되지 않으므로, 한 그룹에서 삭제한 뒤 다른 그룹에 추가하세요.
- **Active Quests**: 퀘스트를 추가하거나 삭제합니다. 퀘스트마다 이름 붙은 목표가 있고 완료 체크박스가 달려 있습니다.
- **Custom Tracker**: 이름과 값 필드를 추가, 삭제, 수정합니다.

## 잠금 모드

트래커 에이전트는 턴이 끝날 때마다 HUD 값을 덮어씁니다. 대개는 편리하지만, 특정 값이 계속 엉뚱하게 바뀌어서 직접 고정해 두고 싶을 때가 있습니다. 그럴 때 잠금 모드를 씁니다.

필드를 잠가 두면 다음 자동 트래커 실행이 그 필드를 건드리지 않습니다. 잠긴 필드에는 표시가 붙어서 한눈에 알아볼 수 있습니다.

필드를 잠그는 방법은 다음과 같습니다.

1. 위젯의 팝오버를 여세요.
2. 팝오버 위쪽에 있는 잠금 토글을 클릭하세요. 툴팁은 **Enter lock mode**(잠금 모드 시작)입니다.
3. 이제 수정 가능한 값마다 작은 잠금 버튼이 나타납니다.
4. 고정하려는 값 옆의 잠금 버튼을 클릭하세요. 툴팁은 **Lock field**(필드 잠금)입니다.

잠금을 풀려면 같은 버튼을 다시 클릭하세요(툴팁 **Unlock field**(필드 잠금 해제)). 잠금 모드에서 나가려면 위쪽 토글을 다시 클릭하세요(툴팁 **Exit lock mode**(잠금 모드 종료)). 잠금 모드는 HUD 전체에 함께 적용되므로, 팝오버 한 곳에서 켜면 모든 곳에 잠금 버튼이 나타납니다.

## 트래커 다시 실행하기

다음 메시지를 기다리지 않고 트래커를 바로 갱신할 수도 있습니다.

팝오버 안에는 작은 새로고침(원형 화살표) 버튼이 있습니다. 이 버튼을 클릭하면 가장 최근 턴에 대해 그 트래커 하나만 다시 실행합니다. 툴팁에는 **Re-run world state tracker only**(월드 트래커만 재실행), **Re-run quest tracker only**(퀘스트 트래커만 재실행)처럼 대상 트래커 이름이 들어갑니다.

**Chat Settings → Agents**의 **Manual Trackers**(트래커 작동 설정)를 켜면 활성화된 모든 트래커가 수동 실행으로 바뀝니다. 이 스위치를 끈 채로 **Individual tracker schedule**(개별 트래커 스케줄)에서 원하는 에이전트만 수동으로 지정할 수도 있습니다. 수동 트래커가 하나라도 있으면 HUD 줄에 새로고침 버튼이 나타나고, 이 버튼을 클릭하면 현재 턴에 대해 수동 트래커 묶음을 실행합니다. 트래커 팝오버 안의 새로고침 버튼은 여전히 해당 트래커만 바로 실행합니다.

HUD 줄 맨 앞의 반짝임 아이콘을 클릭하면 **Agents & Actions** 메뉴가 열립니다. 여기에서 모든 트래커를 다시 실행하고, 실패한 에이전트를 재시도하고, **Clear Trackers**(트래커 비우기)로 그 채팅에 기록된 세계 상태를 전부 지울 수 있습니다. **Clear Trackers**는 되돌릴 수 없으니 신중하게 사용하세요.

## Tracker Panel

**Tracker Panel**(트래커 패널)은 작은 HUD 위젯과 같은 트래커 데이터를 보여 주는 더 큰 측면 패널입니다. 트래커 카드를 넉넉한 공간에 펼쳐 주고, 초상화와 속마음 기능이 추가로 붙습니다. 설정은 **Settings**(설정)의 **Appearance**(모양) 탭에 있는 **Tracker Panel** 항목에서 합니다.

패널 머리글의 컨트롤로 트래커 구조 자체도 손볼 수 있습니다.

- **+**를 클릭하면 추가 모드로 들어갑니다. World 구역에는 **Add world field**(월드 필드 추가)가, 등장 캐릭터 카드마다 **Add custom field**(사용자 지정 필드 추가)가 생깁니다. 필드 이름은 일반 모드에서도 계속 보이므로 값의 의미를 항상 알 수 있습니다.
- 휴지통 아이콘을 클릭하면 삭제 모드로 들어가고, 사용자 지정 세계 필드나 캐릭터 필드를 지울 수 있습니다. 필드를 지우면 그 필드에 저장된 잠금 설정도 함께 사라집니다.
- 자물쇠 아이콘을 클릭하면 잠금 모드로 들어갑니다. 사용자 지정 필드 값도 기본 트래커 값과 똑같이 잠금이 동작합니다.
- 눈에 사선이 그어진 아이콘을 클릭하면 숨김 모드로 들어가고, 캐릭터 카드에서 **Mood**, **Look**, **Outfit**, **Thoughts**(생각) 중 원하는 항목을 고를 수 있습니다. 숨긴 필드는 Tracker Panel과 Roleplay HUD에서 사라지고, 값이 비워지며, 잠긴 상태로 남아 트래커 에이전트가 다시 채우지 않습니다. 숨김 모드로 다시 들어가면 숨긴 필드를 빈 필드 상태로 되돌릴 수 있습니다.

사용자 지정 필드 이름은 구조를 정하는 역할을 하며 트래커가 여러 번 실행되어도 그대로 유지됩니다. 이야기에서 값이 달라지면 트래커 에이전트가 값을 갱신하고, 에이전트 출력에서 빠진 항목이 있어도 직접 만든 필드가 지워지지는 않습니다.

관련 설정은 다음과 같습니다.

- **Tracker Panel**: 패널 전체를 켜고 끄는 토글입니다. 기본값은 켜짐입니다. 켜져 있으면 라벨에 "Shown in the Roleplay HUD"라고 표시됩니다.
- **Replace tracker HUD icons**(트래커 HUD 아이콘 교체): 작은 아이콘 줄을 숨겨서 패널을 화면 가장자리에 붙일 수 있게 합니다. **Agents & Actions** 버튼은 그대로 남습니다.
- **Use expression sprites for tracker portraits**(트래커 초상화에 얼굴 표정 스프라이트 사용): 표정 스프라이트(캐릭터의 현재 감정 초상화)가 있으면 트래커 초상화에 일반 아바타 대신 그 스프라이트를 씁니다. 표정 스프라이트는 [캐릭터 스프라이트](../characters/sprites.md)에서 설명합니다.
- **Panel background**(패널 배경): 패널 배경으로 쓸 색상이나 그라데이션을 고르는 선택기입니다.
- **Desktop size**(데스크톱 크기): 패널 너비를 고릅니다. 선택지는 **Compact**, **Standard**, **Expanded**입니다.
- **Thought display mode**(추론 표시 모드): 캐릭터의 속마음을 어떻게 보여 줄지 고릅니다. **Docked**는 캐릭터 카드 안에 펼치고, **Floating**은 초상화 옆에 말풍선으로 띄웁니다.
- **Always show Docked thoughts**(고정된 생각 항상 표시): **Thought display mode**가 **Docked**일 때, 주요 캐릭터의 속마음을 버튼 뒤에 숨기지 않고 항상 보이게 합니다.
- **Temperature unit**(온도 단위): 온도 표시를 **Celsius**와 **Fahrenheit** 중에서 고릅니다. 기본값은 Celsius입니다. 표시 방식만 바뀌고 저장된 세계 상태 값은 그대로입니다.

## HUD를 채우는 에이전트

HUD 위젯은 모두 턴이 끝난 뒤 실행되는 트래커 에이전트가 채웁니다. 어떤 에이전트가 어떤 위젯을 담당하는지는 이 가이드 앞부분의 위젯 표에 정리되어 있습니다.

페르소나나 캐릭터가 처음에 어떤 상태 막대와 RPG 능력치를 갖고 시작할지는 캐릭터 편집기나 페르소나 편집기의 **Stats**(스탯) 탭에서 정합니다. 그 뒤로는 이야기가 흘러가는 대로 트래커 에이전트가 값을 조정합니다.
