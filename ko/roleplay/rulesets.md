# Roleplay: 규칙 집합으로 플레이하기

Roleplay 채팅은 Game Mode가 쓰는 것과 같은 종류의 탁상용 규칙 집합으로 플레이할 수 있습니다. 불확실한 일이 생기면 내레이터가 판정을 요청하고, Marinara가 캐릭터 시트로 주사위를 굴리며, 답변은 굴림이 무엇을 결정했는지 알려 줍니다. Game Mode 게임을 시작하지 않고 roleplay에서 진짜 주사위와 캐릭터 시트를 쓰고 싶을 때 사용하세요.

Game Mode용으로 설치한 규칙 집합은 5e (SRD 5.1)처럼 무엇이든 작동하며, 캐릭터 편집기와 페르소나 편집기에서 그 규칙 집합용으로 이미 만든 시트도 함께 쓸 수 있습니다.

## 채팅에 규칙 집합 켜기

시작하기 전에: 규칙 집합을 설치하세요. [규칙 집합 구하기](../game/rulesets.md#get-a-ruleset)를 참고하세요.

1. Roleplay 채팅을 엽니다.
2. **Chat Settings**(채팅 설정)를 열고 **Ruleset**(규칙 집합) 섹션을 찾습니다.
3. 목록에서 규칙 집합을 고릅니다. 설치한 규칙 집합이 표시됩니다.
4. Marinara가 채팅의 각 멤버에게 시트를 주고 몇 개를 추가했는지 알려 줍니다. 각 멤버는 규칙 집합 아래에 표시됩니다.

각 멤버는 캐릭터 편집기나 페르소나 편집기에 있는, 그 규칙 집합용 자기 시트의 사본을 받습니다([규칙 집합 시트](../characters/colors-and-stats.md#ruleset-sheets) 참고). 시트가 없는 멤버는 목록에 **blank sheet**(빈 시트)로 표시되는 빈 시트를 받아 채팅에서 직접 채웁니다. 페르소나가 가장 먼저 옵니다. 채팅에서 바꾼 내용은 채팅에만 남고 캐릭터나 페르소나로 돌아가지 않습니다.

작동하지 않았다면: 가져온 규칙 집합은 **Allow custom Agent imports**(사용자 지정 에이전트 가져오기 허용)가 켜져 있어야 합니다. [규칙 집합 구하기](../game/rulesets.md#get-a-ruleset)를 참고하세요.

### 빈 시트 채우기

1. **Ruleset** 섹션에서 멤버 옆의 **Build sheet**(시트 만들기)를 클릭하세요.
2. 캐릭터 시트가 시트 편집기에서 열립니다. 규칙 집합에 단계별 빌더가 있으면 Game Mode와 캐릭터 편집기에서처럼 먼저 그곳에서 열립니다.
3. 선택을 마치고 **Save sheet**(시트 저장)를 클릭하세요.

### 새 멤버의 시트 추가하기

나중에 캐릭터가 채팅에 들어오면 **Add missing sheets**(빠진 시트 추가)를 클릭하세요. 이미 시트가 있는 멤버는 그대로 유지됩니다.

### 시트 제거하기

내레이터 카드처럼 시트가 없어야 하는 멤버는 시트를 잃게 할 수 있습니다.

1. **Ruleset** 섹션에서 멤버 옆의 휴지통 아이콘을 클릭하세요.
2. **Remove sheet**(시트 제거)를 클릭하세요.

채팅은 이를 기억하므로 **Add missing sheets**와 규칙 집합의 새 버전도 그 멤버를 빼놓습니다. 다시 시트를 주려면 **No sheet:**(시트 없음) 뒤에 있는 그 멤버의 버튼, 예를 들어 **Give Mira a sheet**(Mira에게 시트 주기)를 클릭하세요.

### 규칙 집합 바꾸기 또는 끄기

- **None**(없음)을 고르면 규칙 집합으로 플레이하지 않습니다. 시트는 유지되므로 같은 규칙 집합을 다시 고르면 멈춘 곳에서 이어집니다.
- 다른 규칙 집합을 고르면 모든 시트가 처음부터 시작합니다. 한 규칙 집합에 맞춘 시트는 다른 규칙 집합에서는 의미가 없기 때문입니다.

## 플레이 중의 판정

턴은 평소처럼 씁니다. 결과가 중요한 불확실한 행동을 캐릭터가 시도하면, 내레이터는 결과를 정하는 대신 판정을 씁니다. Marinara가 시트에서 그것을 굴리고, 그다음 내레이터가 굴림이 무엇을 결정했는지 씁니다.

완성된 메시지는 판정이 일어난 자리에 주사위 카드를 보여 주며, 기술, 난이도, 주사위와 **Success**(성공) 또는 **Failure**(실패)가 표시됩니다. 정말로 실패할 수 없는 평범한 행동에는 판정이 붙지 않습니다.

> **팁:** 일부 모델은 판정을 요청하라는 지시를 무시하고 결과를 스스로 정합니다. 판정이 전혀 나오지 않으면 채팅의 **Connection**(연결)에 더 강한 모델을 써 보세요.

**Impersonate**(유저 사칭) 턴에는 판정을 굴리지 않습니다. 멀티플레이어 방은 규칙 집합으로 플레이할 수 없습니다.

## 캐릭터 시트 사용하기

**Ruleset** 섹션에서 멤버 옆의 **Open sheet**(시트 열기)를 클릭하세요. 시트는 Game Mode가 보여 주는 것과 같습니다. Tracker Panel 위쪽의 두루마리 버튼은 페르소나의 시트를 엽니다.

- 체력이나 스트레스 같은 풀이나 트랙 옆의 **−**와 **+**를 클릭하면 값을 바꿀 수 있습니다. 변경은 현재 메시지와 함께 저장되므로 스와이프와 분기를 따라갑니다.
- 점수, 기술 등급, 필드와 목록을 바꾸려면 **Edit ruleset sheet**(규칙 집합 시트 편집)를 클릭한 뒤 **Save sheet**(시트 저장)를 클릭하세요.

내레이터는 매 턴 시트를 읽고 답변 안의 시트 명령으로 시트를 바꾸며, Marinara가 이를 적용하고 메시지에서는 숨깁니다. 휴식하려면 턴에 "우리는 긴 휴식을 취한다"처럼 말하세요. 내레이터가 휴식을 기록하고, 시트는 규칙 집합의 휴식이 회복하는 것을 되찾습니다. 시트에서 **Rest**(휴식)를 클릭할 수도 있습니다.

## 직접 규칙 집합 만들기

규칙 집합 빌더는 판정을 굴리는 방식, 시트에 들어가는 항목, 내레이터에게 알려 줄 내용을 양식으로 받아 작은 규칙 집합을 만듭니다. Marinara에 없는 시스템에 사용하세요. 직접 만든 규칙 집합은 Roleplay와 Game Mode에서 설치한 규칙 집합처럼 작동합니다.

시작하기 전에: 빌더는 가져오기와 같은 방식으로 규칙 집합을 저장하므로 **Allow custom Agent imports**를 켜세요. [규칙 집합 구하기](../game/rulesets.md#get-a-ruleset)를 참고하세요.

1. **Chat Settings → Ruleset**에서 **New ruleset…**(새 규칙 집합…)을 클릭하세요.
2. **Name**(이름)을 입력하세요.
3. **Dice**(주사위) 아래에서 판정을 굴리는 방식을 고르세요(아래 표 참고). 하나를 고르면 시작 능력치, 풀, 트랙이 채워지며, 이 값은 바꿀 수 있습니다.
4. **Difficulties**(난이도), **Stats**(능력치), **Skills**(기술)와 양식의 나머지 부분을 바꾸세요. 대부분의 섹션은 제목 아래의 한 줄로 무엇을 하는지 설명합니다.
5. **Create ruleset**(규칙 집합 만들기)을 클릭하세요.

Marinara가 규칙 집합을 저장합니다. 규칙 집합이 없는 채팅에서는 새 규칙 집합을 켜기도 합니다. 이미 규칙 집합이 있는 채팅은 그 규칙 집합과 시트를 유지합니다. 바꾸려면 목록에서 새 규칙 집합을 고르세요.

설치한 규칙 집합이 고른 방식으로 이미 굴린다면 **Dice** 섹션에 그 규칙 집합의 이름이 나옵니다. 규칙 집합마다 모든 캐릭터에 시트가 따로 생기므로, 캐릭터마다 시트를 하나로 유지하려면 다른 규칙 집합을 만들지 말고 그 규칙 집합으로 플레이하거나 그 규칙 집합을 편집하세요.

| 주사위 | 판정을 굴리는 방식 |
| --- | --- |
| **d20 + modifier**(d20 + 수정치) | d20 하나에 능력치와 기술을 더해 난이도 숫자를 상대로 굴립니다. |
| **2d6 bands**(2d6 구간) | 2d6에 능력치를 더합니다. 10 이상은 강한 성공, 7~9는 약한 성공, 6 이하는 실패입니다. |
| **Dice pool**(주사위 풀) | 능력치와 기술 1점마다 주사위를 하나씩 던집니다. 목표 숫자에 도달한 주사위는 모두 셉니다. d6과 d10 중 하나와 목표 숫자는 직접 고릅니다. |
| **Highest d6**(가장 높은 d6) | 1점마다 d6을 하나씩 던져 가장 높은 눈을 남깁니다. 6은 완전한 성공, 4나 5는 부분 성공, 6이 두 개면 대성공입니다. |
| **Percentile**(백분율) | d100 하나를 굴립니다. 기술의 숫자 이하가 나오면 판정에 성공합니다. |
| **Hope and Fear**(희망과 공포) | d12 두 개에 능력치를 더합니다. 더 높은 주사위가 결과에 희망이 따르는지 공포가 따르는지 알려 줍니다. |
| **No dice**(주사위 없음) | 아무것도 던지지 않습니다. 능력치와 기술을 더해 난이도와 비교합니다. |

### 직접 만든 규칙 집합 바꾸기

1. 채팅에 그 규칙 집합을 켜세요.
2. **Chat Settings → Ruleset**에서 **Edit ruleset**(규칙 집합 편집)을 클릭하세요.
3. 변경을 마치고 **Save new version**(새 버전 저장)을 클릭하세요.

채팅은 새 버전으로 옮겨 가며 모든 시트를 유지합니다. 능력치, 기술, 풀, 목록 열의 이름을 바꿔도 각 캐릭터가 그 안에 가진 값은 유지됩니다. 같은 규칙 집합을 쓰는 다른 채팅은 그 채팅에서 **Add missing sheets**를 클릭하면 새 버전으로 옮겨 갑니다.

**Edit ruleset**은 직접 만들었거나 파일에서 가져온 규칙 집합을 양식에 전부 담을 수 있을 때 나타납니다. 빌더가 만든 규칙 집합이나, 양식이 보여 주는 것만 쓰는 직접 작성한 파일이 해당합니다. 패키지나 저장소에서 온 규칙 집합에는 나타나지 않습니다. 빌더는 전투 규칙이나 주석처럼 그 밖의 내용이 있는 규칙 집합은 절대 열지 않으므로, 보여 주지 않는 내용을 빠뜨릴 수 없습니다. 또한 최신 버전으로 플레이하는 채팅에서만 나타납니다. 이전 버전을 쓰는 채팅에서는 먼저 **Add missing sheets**를 클릭하세요.

### 시트 배치하기

| 양식에서 | 시트에서 |
| --- | --- |
| 행 순서 | 능력치, 기술, 풀, 트랙, 필드, 목록 탭이 양식의 순서대로 표시됩니다. 행을 옮기려면 손잡이를 잡고 끌거나, 손잡이에 포커스를 둔 채 위아래 화살표 키를 누르세요. |
| 능력치나 기술의 **Group**(그룹) | 그룹이 같은 능력치나 기술은 한 제목 아래에 표시됩니다. |
| **Skill ranks**(기술 등급) | 시트에서 기술마다 고르는 등급과 각 등급이 더하는 값입니다. d20이나 2d6 굴림에서는 합계에 더하는 값, 풀에서는 주사위, 백분율에서는 점수입니다. |
| **Show ranks on the sheet as** | 시트에서 훈련된 각 기술과 내성 옆에 표시할 내용입니다. **Check value (+2)**, **Rank name**, **Dots (●●○)**, **Roman numerals (II)**, **Rank number (2)** 중에서 고릅니다. 판정과 내레이터가 받는 시트 사본은 그대로입니다. |
| **Practice meter**(연습 미터) | 훈련된 각 기술이 다음 등급까지 얼마나 왔는지 0부터 99%까지 보여 줍니다. 이야기 속에서 연습하면 올라가고, 등급이 오르면 처음부터 다시 시작합니다. 시트에서 바로잡을 수 있습니다. **No meter for:**(미터 제외) 아래에서 그룹에 체크 표시를 하면 그 그룹의 기술이 빠집니다. |
| 풀이나 트랙의 **Number**(숫자), **Bar**(막대) 또는 **Dots**(점) | 숫자만 표시하거나, 숫자 옆에 채우기 막대를 두거나, 값까지 채워진 점을 한 줄로 표시하며 점 하나가 1입니다. 점이 20개를 넘으면 막대로 표시됩니다. |
| **Lists**(목록) | 목록마다 탭이 하나씩 생기며, 다른 탭 이름을 입력하지 않으면 탭 이름은 목록 이름을 따릅니다. 탭 이름이 같은 목록은 한 탭을 함께 씁니다. |
| 목록의 열 | 모든 행에는 이름이 있고, 여기에 직접 추가한 열이 더해집니다. 열은 **Text**(텍스트), **Number** 또는 **Checkbox**(체크박스)입니다. 첫 번째 체크박스 열은 각 이름 옆에 체크 표시로 나타납니다. |

### 내레이터에게 규칙 알려 주기

**Prompts**(프롬프트) 섹션에는 규칙 집합에 관해 내레이터에게 알려 줄 내용이 들어갑니다. **Checks**(판정)와 **Keeping the sheets**(시트 관리)에는 기본값이 표시되며, 둘 중 하나를 비워 두면 그 기본값을 씁니다. 줄바꿈은 공백으로 바뀝니다. 이름과 프롬프트에는 대괄호나 이중 중괄호를 넣을 수 없습니다. 내레이터의 태그와 매크로가 이를 쓰기 때문입니다.

| 상자 | 용도 |
| --- | --- |
| **Checks** | 언제 판정을 요청하고 기술과 난이도를 어떻게 고를지입니다. |
| **Keeping the sheets** | 플레이 중 시트가 어떻게 바뀌는지입니다. |
| **Rules reference**(규칙 참고 자료) | 하우스 룰과 그 밖에 내레이터가 항상 앞에 두어야 할 모든 것입니다. |
| **World (Game Mode)**(월드, 게임 모드) | 이 규칙 집합으로 Game Mode 게임을 만들 때 한 번 읽으며, 그 게임의 세계를 규칙에 맞춥니다. |

## 문제 해결

| 증상 | 해결 방법 |
| --- | --- |
| **This chat's ruleset is not installed here, so its checks and sheets are paused.** | 규칙 집합을 다시 설치하거나 다른 것을 고르세요. |
| 내레이터가 판정을 전혀 요청하지 않습니다. | 채팅에 더 강한 모델을 쓰세요. 일부 모델은 판정 지시를 건너뜁니다. |
| 새 캐릭터에 시트가 없습니다. | **Add missing sheets**를 클릭하세요. |
