# Roleplay: 규칙 집합으로 플레이하기

Roleplay 채팅은 Game Mode가 쓰는 것과 같은 종류의 탁상용 규칙 집합으로 플레이할 수 있습니다. 불확실한 일이 생기면 내레이터가 판정을 요청하고, Marinara가 캐릭터 시트로 주사위를 굴리며, 답변은 굴림이 무엇을 결정했는지 알려 줍니다. Game Mode 게임을 시작하지 않고 roleplay에서 진짜 주사위와 캐릭터 시트를 쓰고 싶을 때 사용하세요.

Game Mode용으로 설치한 규칙 집합은 5e (SRD 5.1)처럼 무엇이든 작동하며, 캐릭터 편집기와 페르소나 편집기에서 그 규칙 집합용으로 이미 만든 시트도 함께 쓸 수 있습니다.

## 채팅에 규칙 집합 켜기

시작하기 전에: 규칙 집합을 설치하세요. [규칙 집합 구하기](../game/rulesets.md#get-a-ruleset)를 참고하세요.

1. Roleplay 채팅을 엽니다.
2. **Chat Settings**(채팅 설정)를 열고 **Ruleset**(규칙 집합) 섹션을 찾습니다.
3. 목록에서 규칙 집합을 고릅니다. 설치한 규칙 집합이 표시됩니다.
4. Marinara가 채팅의 각 멤버에게 시트를 주고 몇 개를 추가했는지 알려 줍니다. 각 멤버는 규칙 집합 아래에 표시됩니다.

각 멤버는 캐릭터 편집기나 페르소나 편집기에 있는, 그 규칙 집합용 자기 시트의 사본을 받습니다([규칙 집합 시트](../characters/colors-and-stats.md#ruleset-sheets) 참고). 시트가 없는 멤버는 목록에 **blank sheet**(빈 시트)로 표시되는 빈 시트를 받아 채팅에서 직접 채웁니다. 페르소나가 가장 먼저 옵니다. 채팅에서 바꾼 내용은 채팅에만 남고 캐릭터나 페르소나로 돌아가지 않습니다.

작동하지 않았다면: 가져온 규칙 집합은 **Allow custom Agent imports**(사용자 지정 에이전트 가져오기 허용)가 켜져 있어야 합니다. [규칙 집합 구하기](../game/rulesets.md#get-a-ruleset)를 참고하세요.

### 빈 시트 채우기

1. **Ruleset** 섹션에서 멤버 옆의 **Build sheet**(시트 만들기)를 클릭하세요.
2. 캐릭터 시트가 시트 편집기에서 열립니다. 규칙 집합에 단계별 빌더가 있으면 Game Mode와 캐릭터 편집기에서처럼 먼저 그곳에서 열립니다.
3. 선택을 마치고 **Save sheet**(시트 저장)를 클릭하세요.

### 새 멤버의 시트 추가하기

나중에 캐릭터가 채팅에 들어오면 **Add missing sheets**(빠진 시트 추가)를 클릭하세요. 이미 시트가 있는 멤버는 그대로 유지됩니다.

### 시트 제거하기

내레이터 카드처럼 시트가 없어야 하는 멤버는 시트를 잃게 할 수 있습니다.

1. **Ruleset** 섹션에서 멤버 옆의 휴지통 아이콘을 클릭하세요.
2. **Remove sheet**(시트 제거)를 클릭하세요.

채팅은 이를 기억하므로 **Add missing sheets**와 규칙 집합의 새 버전도 그 멤버를 빼놓습니다. 다시 시트를 주려면 **No sheet:**(시트 없음) 뒤에 있는 그 멤버의 버튼, 예를 들어 **Give Mira a sheet**(Mira에게 시트 주기)를 클릭하세요.

### 규칙 집합 바꾸기 또는 끄기

- **None**(없음)을 고르면 규칙 집합으로 플레이하지 않습니다. 시트는 유지되므로 같은 규칙 집합을 다시 고르면 멈춘 곳에서 이어집니다.
- 다른 규칙 집합을 고르면 모든 시트가 처음부터 시작합니다. 한 규칙 집합에 맞춘 시트는 다른 규칙 집합에서는 의미가 없기 때문입니다.

## 플레이 중의 판정

턴은 평소처럼 씁니다. 결과가 중요한 불확실한 행동을 캐릭터가 시도하면, 내레이터는 결과를 정하는 대신 판정을 씁니다. Marinara가 시트에서 그것을 굴리고, 그다음 내레이터가 굴림이 무엇을 결정했는지 씁니다.

완성된 메시지는 판정이 일어난 자리에 주사위 카드를 보여 주며, 기술, 난이도, 주사위와 **Success**(성공) 또는 **Failure**(실패)가 표시됩니다. 정말로 실패할 수 없는 평범한 행동에는 판정이 붙지 않습니다.

> **팁:** 일부 모델은 판정을 요청하라는 지시를 무시하고 결과를 스스로 정합니다. 판정이 전혀 나오지 않으면 채팅의 **Connection**(연결)에 더 강한 모델을 써 보세요.

**Impersonate**(유저 사칭) 턴에는 판정을 굴리지 않습니다. 멀티플레이어 방은 규칙 집합으로 플레이할 수 없습니다.

## 캐릭터 시트 사용하기

**Ruleset** 섹션에서 멤버 옆의 **Open sheet**(시트 열기)를 클릭하세요. 시트는 Game Mode가 보여 주는 것과 같습니다. Tracker Panel 위쪽의 스크롤 버튼은 페르소나의 시트를 엽니다.

- 체력이나 스트레스 같은 풀이나 트랙 옆의 **−**와 **+**를 클릭하면 값을 바꿀 수 있습니다. 변경은 현재 메시지와 함께 저장되므로 스와이프와 분기를 따라갑니다.
- 점수, 기술 등급, 필드와 목록을 바꾸려면 **Edit ruleset sheet**(규칙 집합 시트 편집)를 클릭한 뒤 **Save sheet**(시트 저장)를 클릭하세요.

내레이터는 매 턴 시트를 읽고 답변 안의 시트 명령으로 시트를 바꾸며, Marinara가 이를 적용하고 메시지에서는 숨깁니다. 휴식하려면 턴에 "우리는 긴 휴식을 취한다"처럼 말하세요. 내레이터가 휴식을 기록하고, 시트는 규칙 집합의 휴식이 회복하는 것을 되찾습니다. 시트에서 **Rest**(휴식)를 클릭할 수도 있습니다.

## 문제 해결

| 증상 | 해결 방법 |
| --- | --- |
| **This chat's ruleset is not installed here, so its checks and sheets are paused.** | 규칙 집합을 다시 설치하거나 다른 것을 고르세요. |
| 내레이터가 판정을 전혀 요청하지 않습니다. | 채팅에 더 강한 모델을 쓰세요. 일부 모델은 판정 지시를 건너뜁니다. |
| 새 캐릭터에 시트가 없습니다. | **Add missing sheets**를 클릭하세요. |
