# Marinara 백업과 복원

이 가이드에서는 Marinara Engine 안의 모든 것을 복사해 두는 두 가지 방법과, 그 사본을 나중에 되돌리는 방법을 설명합니다. 업데이트하기 전, 새 기기로 옮기기 전, 데이터를 초기화하기 전에 활용하세요.

## 데이터를 저장하는 두 가지 방법

Marinara는 두 가지 저장 방법을 제공합니다. 각각 있는 위치도 다르고 하는 일도 다릅니다.

- **Download Backup**(백업 다운로드)은 디스크에 있는 모든 것을 **.zip** 아카이브 하나로 묶습니다. **.zip**은 여러 파일을 안에 담고 있는 압축 파일 하나를 말합니다. 가장 완전한 사본이며, 데이터 손실을 막는 가장 확실한 수단입니다.
- **Export Profile**(프로필 내보내기)은 계정 데이터(캐릭터, 페르소나, 채팅, 로어북, 프리셋, 에이전트, 테마, Personal Extensions)만 담은 더 가벼운 파일을 만듭니다. 프로필은 계정을 들고 다닐 수 있게 만든 Marinara의 사본입니다. 나중에 Marinara 안에서 그대로 복원할 수 있습니다.

모든 것을 안전하게 한 번에 복사해 두고 싶다면 **Download Backup**을 쓰세요. 파일을 더 작게 만들고 싶거나 다른 롤플레이 도구가 읽을 수 있는 형식이 필요할 때는 **Export Profile**을 쓰세요.

두 저장 방법 모두 **Settings**(설정)의 **Advanced**(고급) 탭 안 **Backup & Export**(백업 및 내보내기) 섹션에 있습니다.

## 같은 기기에서, 그리고 다른 기기에서 사용하기

Marinara를 실행 중인 컴퓨터에서는 이 기능이 바로 동작합니다. 같은 컴퓨터에서 `localhost` 또는 `127.0.0.1` 주소로 앱을 연 경우, 즉 루프백 접속에 해당합니다.

휴대폰, 태블릿 등 다른 기기에서 접속했다면 백업과 복원에 **Admin Access**(관리자 접근) 시크릿이 필요합니다. 서버에 시크릿을 설정한 다음, 같은 값을 **Settings**의 **Advanced** 탭 **Admin Access** 항목에 붙여넣으세요. 문서 끝에 링크한 원격 접근 가이드를 참고하세요.

## Download Backup

**Download Backup**은 데이터베이스, 설정, 모든 미디어 폴더(아바타, 스프라이트, 배경, 갤러리 이미지, 글꼴, 직접 넣은 알림 소리 등)를 **.zip** 파일 하나로 만듭니다.

1. **Settings**를 여세요.
2. **Advanced** 탭으로 이동하세요.
3. **Backup & Export** 섹션을 찾으세요.
4. **Download Backup**을 클릭하세요.
5. 작업이 진행되는 동안 버튼에 **Creating backup…**이 표시됩니다.
6. 아카이브가 준비되면 Marinara가 전체 파일을 페이지 메모리에 보관하지 않고 브라우저로 바로 스트리밍합니다.
7. 다운로드 설정에 따라 브라우저의 일반 **Save As** 창이 열리거나 파일이 다운로드 폴더에 저장됩니다.

이 단계는 Android와 iOS에서 특히 중요합니다. 이런 기기에서는 앱 자체의 데이터 폴더에 접근하기 어려운 경우가 많습니다. 그래서 기기 밖으로 사본을 꺼내는 손쉬운 방법은 **Download Backup**뿐입니다. 개인 클라우드 저장소처럼 안전하고 남에게 노출되지 않는 곳에 보관하세요.

**.zip** 안에는 `RESTORE.txt`라는 일반 텍스트 파일도 들어 있습니다. 필요할 때 데이터를 직접 손으로 복구하는 방법이 적혀 있습니다. 백업은 비공개로 다루세요. 저장해 둔 API 키를 푸는 데 쓰이는 비밀 파일이 들어 있을 수 있습니다. 각 폴더에 무엇이 들어 있는지는 아래에 링크한 데이터 저장 위치 가이드를 참고하세요.

## 자동 백업

**Backup & Export** 섹션에서는 Marinara를 실행 중인 기기에 전체 백업을 자동으로 만들고 오래된 것부터 지우도록 설정할 수도 있습니다.
**Automatic Backups**(자동 백업)를 켜고 **Daily**, **Weekly**, **Monthly** 중 하나를 고른 다음, **Automatic backups kept**(보관할 자동 백업 수) 값을
1에서 9999 사이로 정하세요. 켜고 나면 Marinara가 곧바로 첫 백업을 만듭니다. 이후 실행이 성공할 때마다 설정한 개수만큼
최신 자동 아카이브를 남기고, 그보다 오래된 자동 아카이브를 지웁니다. 이 보관 개수 제한은
수동 백업이나 **Download Backup**으로 저장한 백업에는 영향을 주지 않습니다.

자동 백업은 Marinara 데이터 폴더 안의 `backups/`에 저장됩니다. 가장 최신 아카이브는
`marinara-automatic-backup.zip`이고, 함께 보관되는 이전 자동 아카이브에는 시각이 들어간 파일 이름이 붙습니다. 형식은 **Download Backup**과 같아서
그대로 복원할 수 있는 스트리밍 아카이브이며, 업로드한 미디어와 암호화 키 파일이 있으면 그것까지
함께 담깁니다. 디스크 고장, 앱 저장 공간 삭제, 기기 초기화에 대비하려면 Marinara 데이터 폴더 바깥에도
사본을 따로 하나 보관하세요.

## Export Profile

**Export Profile**은 계정 데이터를 담은 더 작은 파일을 만듭니다. 미디어도 포함되므로 아바타, 이미지, 직접 넣은 알림 소리까지 같이 들어갑니다.

1. **Settings**를 여세요.
2. **Advanced** 탭으로 이동하세요.
3. **Backup & Export** 섹션을 찾으세요.
4. **Export Profile**을 클릭하세요.
5. **Export Profile** 창이 열리고 선택지 두 개가 나타납니다.
6. 형식을 고르세요(아래에서 설명합니다).
7. 파일이 기기로 다운로드됩니다.

창에서 고를 수 있는 형식은 두 가지입니다.

| 형식 | 설명 | Marinara에서 복원 가능? |
| --- | --- | --- |
| **Marinara Native** | Marinara 전용 필드, 로어북 폴더, 캐릭터와 페르소나 데이터, 프리셋, 에이전트, 테마, Personal Extension 초안, 본문에 포함된 미디어까지 그대로 유지합니다. | 가능 |
| **Compatible JSON** | 다른 롤플레이 도구에서 쓸 수 있는 일반 캐릭터, 페르소나, 로어북 파일입니다. | 불가능 |

나중에 Marinara에서 복원할 사본을 남기려면 **Marinara Native**를 고르세요. 프로필이 작으면
`marinara-profile.json` 파일로 다운로드되고, 크면 스트리밍 방식의 `marinara-profile.zip`으로 제공됩니다. 이 zip은 데이터를
일정 크기 단위의 테이블 파일로 나눠 담기 때문에, 자료가 많아도 메모리 안의 JSON 문자열 하나에 전부 담을 필요가 없습니다.

Personal Extension의 코드는 네이티브 프로필에 그대로 보존되지만, 활성화 상태와 실행 승인은 보존되지 않습니다. 복원된 확장은 모두 비활성화 상태로 들어오므로 **Settings** > **Addons**(애드온)에서 다시 검토해야 합니다.

**Compatible JSON**은 캐릭터나 로어북을 다른 도구로 옮기려는 경우에만 고르세요. 일반 파일들을 담은 **.zip**으로 다운로드됩니다. 이 파일은 **Import Profile**(프로필 가져오기)로 Marinara에 다시 복원할 수 없습니다.

## Import Profile로 복원하기

저장해 둔 프로필이나 **Download Backup** 아카이브를 되돌리려면 **Import Profile**을 쓰세요. 저장 기능과는 다른 탭에 있습니다.

1. **Settings**를 여세요.
2. **Imports**(가져오기) 탭으로 이동하세요.
3. **Profile & Marinara**(프로필 및 Marinara) 섹션을 찾으세요.
4. **Import Profile (JSON/ZIP)**(프로필 가져오기)을 클릭하세요.
5. 파일을 고르세요. `marinara-profile.json`, `marinara-profile.zip`, 전체 **Download Backup** **.zip** 모두 쓸 수 있습니다.
6. Marinara가 먼저 파일을 검사합니다. 버튼에는 **Scanning Profile...**이 표시됩니다.
7. **Import Profile** 창이 나타납니다. 캐릭터와 페르소나의 개수처럼 찾아낸 내용을 보여 줍니다.
8. 이 창은 가져오기를 되돌릴 수 없다고 경고합니다. 내용을 읽고 계속하려면 **Import**(가져오기)를, 중단하려면 **Cancel**(취소)을 클릭하세요.
9. 가져오기가 실행되고 진행 막대와 함께 **Importing Profile...**이 표시됩니다.

최근 버전의 Marinara 프로필은 이름이 아니라 각 항목의 고유 식별 정보를 기준으로 복원합니다. 그래서 같은 프로필을 두 번 가져와도 사본이 늘어나지 않고 기존 항목을 그 자리에서 업데이트합니다.

아주 오래된 버전에서 만든 프로필 파일은 이렇게 동작하지 않습니다. 그런 파일을 다시 가져오면 캐릭터, 페르소나, 로어북이 중복으로 생길 수 있습니다. 최근에 내보낸 파일만 복원한다면 이런 일은 생기지 않습니다.

파일을 고른 뒤 확인을 누르기 전에 디스크에서 그 파일이 바뀌면 가져오기가 경고와 함께 중단됩니다. 파일을 다시 고르면 됩니다.

**.zip** 안에 미디어 파일이 일부 빠져 있어도 가져오기는 끝까지 진행됩니다. 빠진 파일 목록을 호박색 경고로 보여 주고 나머지는 모두 가져옵니다.

## 복원한 다음: API 키 다시 입력하기

**Export Profile**은 프로필 파일에서 비밀 값을 지웁니다. 저장해 둔 API 키와 웹훅 주소는 파일 안에서 빈 값이 됩니다. 그래서 프로필 파일은 보관하거나 남에게 건네도 안전합니다. API 키는 Marinara를 AI 제공자에 연결해 주는 비밀번호 같은 값입니다.

**Download Backup** 아카이브는 다릅니다. Marinara는 여기서 비밀 값을 지우지 않습니다. 백업 **.zip**은 데이터를 그대로 복사한 것입니다. 저장해 둔 키와 그 키를 풀 수 있는 비밀 파일까지 들어 있습니다. 백업 **.zip**은 절대 남에게 공유하지 마세요. 남이 볼 수 없는 곳에 보관하세요.

**Import Profile**은 백업 **.zip**을 골랐을 때도 프로필 파일을 읽어 복원합니다. 아카이브 안에 프로필 파일의 사본이 들어 있고, 가져오기는 그 사본을 읽습니다. 따라서 가져오기로 만들어진 항목은 키와 웹훅 주소가 비어 있는 상태로 들어옵니다.

프로필을 가져온 다음에는 이렇게 하세요.

1. **Settings**를 여세요.
2. **Connections**(연결) 탭으로 이동하세요.
3. 사용 중인 제공자마다 API 키를 다시 입력하세요.

웹훅 주소를 호출하는 사용자 지정 도구를 쓰고 있다면, 각 도구에도 그 주소를 다시 입력하세요.

가져오기를 해도 이미 설정해 둔 키는 지워지지 않습니다. 오래된 프로필을 다시 가져와도 Marinara는 남아 있는 항목의 현재 키와 웹훅 주소를 그대로 유지합니다. 다시 가져온다고 해서 값이 비워지지 않습니다.

## Existing backups 목록

**Backup & Export** 섹션에는 삭제 버튼이 달린 **Existing backups**(기존 백업) 목록이 표시될 수 있습니다. 평소에는 이 목록이 비어 있습니다. **Download Backup**은 파일을 기기에 바로 저장합니다. 이 목록에 사본을 남기지 않으며, 하나만 유지되는 자동 아카이브는 대신 Automatic Backups 설정이 관리합니다. 백업을 만들고 보관하는 데 이 목록이 꼭 필요하지는 않습니다.
