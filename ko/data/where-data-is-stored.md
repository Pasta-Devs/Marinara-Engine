# Marinara가 데이터를 저장하는 위치

이 가이드에서는 Marinara Engine이 데이터를 컴퓨터의 어느 위치에 보관하는지 설명합니다. 데이터 폴더 본체, 그 안의 `storage` 폴더와 자산 폴더들, 그리고 저장된 API 키를 보호하는 암호화 키 파일을 다룹니다.

Marinara Engine(아래에서는 "Marinara")은 사용 중인 컴퓨터에서 직접 실행됩니다. 저장한 캐릭터, 채팅, 설정은 그 컴퓨터에만 보관합니다. 다만 답변을 생성할 때는 연결해 둔 AI 제공자에게 채팅 내용을 보낸다는 점을 기억하세요.

## 데이터 폴더(DATA_DIR)

Marinara에서 만든 모든 것은 서버가 돌아가는 컴퓨터의 폴더 한 곳에 모입니다. 이 폴더를 데이터 폴더라고 부릅니다. 그 위치를 가리키는 환경 변수의 이름은 `DATA_DIR`입니다. 환경 변수는 앱 바깥, 서버 쪽에서 지정하는 값입니다. 앱의 **Settings**(설정) 패널에서는 찾을 수 없습니다.

기본 상태에서 데이터 폴더는 Marinara가 서버 파일 옆에 만드는 `data` 폴더입니다. 공식 Docker 컨테이너로 Marinara를 실행하면 데이터 폴더는 컨테이너 안의 `/app/data`입니다.

데이터 폴더 위치를 모르겠다면 서버 시작 로그를 확인하세요. Marinara는 시작할 때 `[storage] DATA_DIR=`로 시작하는 줄을 출력하며, 그 뒤에 데이터 폴더의 전체 경로가 붙습니다.

`DATA_DIR`을 직접 지정하면 데이터 폴더를 다른 위치로 옮길 수 있습니다. 지정하는 방법은 [서버 설정 참고 문서](../CONFIGURATION.md)에서 확인하세요. 새 `DATA_DIR` 값은 Marinara를 다시 시작해야 적용됩니다.

## storage 폴더와 자산 폴더

데이터 폴더 안에서 데이터는 `storage` 폴더 하나와 여러 자산 폴더로 나뉘어 저장됩니다.

`storage` 폴더에는 캐릭터, 채팅, 메시지, 로어북, 프리셋, 연결 같은 텍스트 데이터가 들어갑니다. Marinara는 각 테이블을 소유자별로 묶은 작은 파일로 저장합니다. 예를 들어 한 채팅의 메시지나 한 로어북의 항목을 함께 묶으므로 항목 하나를 바꿀 때 계속 커지는 전역 JSON 파일 전체를 다시 쓰지 않습니다. 이전 저장 형식에서 한 번만 진행되는 업그레이드 동안에는 원래 테이블 파일을 새 폴더 옆에 `.pre-shard` 접미사로 보존합니다.

이미지, 음성을 비롯한 미디어 파일은 각각 내용에 맞는 이름의 폴더에 따로 들어갑니다. 주요 자산 폴더는 다음과 같습니다.

| 폴더 | 저장되는 내용 |
| --- | --- |
| `avatars` | 캐릭터와 페르소나의 아바타 |
| `sprites` | 캐릭터 스프라이트 이미지 |
| `backgrounds` | 업로드한 채팅 배경 |
| `gallery` | 갤러리 이미지 |
| `fonts` | 추가한 사용자 지정 글꼴 |
| `knowledge-sources` | 지식 에이전트용으로 업로드한 파일 |
| `game-assets` | Game Mode 자산 |
| `custom-emojis` | 사용자 지정 이모지 이미지 |
| `custom-stickers` | 사용자 지정 스티커 이미지 |

`storage` 폴더가 동작하는 방식을 기술적으로 더 깊이 알고 싶은 개발자는 [파일 네이티브 저장소](../development/file-storage.md)를 읽어 보세요.

## 암호화 키 파일

Marinara는 저장한 API 키를 암호화해서 일반 텍스트로 남지 않게 합니다. 이때 쓰는 키는 데이터 폴더 안의 `.encryption-key` 파일에 저장합니다.

이 파일은 데이터를 옮기거나 복원할 때 중요합니다. 예를 들어 데이터 폴더를 새 컴퓨터로 복사하면서 `.encryption-key` 파일을 두고 왔다고 해 보겠습니다. 그러면 Marinara는 저장된 API 키를 더 이상 복호화하지 못하므로 키를 다시 입력해야 합니다. 이 파일은 항상 나머지 데이터와 함께 보관하세요.

고급 설정에서는 파일 대신 `ENCRYPTION_KEY` 환경 변수로 키를 전달하기도 합니다. 이 변수를 쓴다면 값 자체를 따로 안전하게 보관하세요. 이때는 복사할 `.encryption-key` 파일이 없습니다. 자세한 내용은 [서버 설정 참고 문서](../CONFIGURATION.md)를 참고하세요.

## Android에서 데이터가 있는 위치

Android에서는 서버의 데이터 폴더가 보통 루팅 없이는 접근할 수 없는 앱 저장 영역에 있습니다. 그래서 폴더를 그대로 휴대폰 밖으로 복사할 수 없습니다.

Android에서 데이터 사본을 만들려면 **Download Backup**(백업 다운로드) 버튼을 사용하세요. **Settings**의 **Advanced**(고급) 탭에 있는 **Backup & Export**(백업 및 내보내기) 항목에서 찾을 수 있습니다. 이 버튼을 누르면 데이터가 담긴 zip 파일 하나가 만들어집니다. `.encryption-key` 파일이 있으면 zip에 함께 들어갑니다. 휴대폰에서 데이터를 보관하는 가장 확실한 방법입니다.

같은 항목에서 매일, 매주, 매월 자동 아카이브을 데이터 폴더 안의 `backups/`에 1개에서 9999개까지 돌려 가며 남길 수 있습니다.
가장 최근 것은 `marinara-automatic-backup.zip`이고, 함께 남겨 두는 이전 자동 아카이브에는 시각이 이름에 붙습니다.
이 개수 제한은 자동 백업에만 적용됩니다. 중요한 백업은 앱 저장 영역 바깥에도 복사해 두세요. 앱을 제거하거나 초기화하면
실제 데이터와 기기 안의 자동 백업이 함께 사라질 수 있습니다.

모든 플랫폼의 백업 및 복원 절차 전체는 [Marinara 백업과 복원](backup-and-restore.md)에서 확인하세요.
