# 世界书总览

本指南介绍 Marinara Engine 里的世界书是什么、**Lorebooks**(世界书) 面板怎么用，以及一本世界书如何在聊天中生效，同时手把手带你建好第一本世界书和第一个条目。关键词、时机、语义搜索这些更深入的话题各有专门的指南，文末有链接。

## 世界书是什么

世界书是一个小型知识库，AI 在聊天过程中可以从中取用内容。它也叫 **World Info**，两个名字指的是同一样东西。每本世界书都是一串条目，而一个条目由两部分组成：若干触发关键词，加一段文本。

只要最近的聊天里出现了某个关键词，Marinara Engine 就会把对应条目的文本加进提示词。提示词就是每次生成回复时发给 AI 的那段隐藏指令和历史记录。这样一来，AI 就能用上聊天里从没直接告诉过它的设定。

举个简单的例子。你写了一个世界书条目，关键词是 `Eldoria`，正文是：

```
Eldoria is a rainy port city ruled by a council of nine merchants.
```

之后只要你或者角色提到 Eldoria，AI 就会收到这条设定，回答起来就像它一直知道这座城市一样。没有这个条目，AI 只能靠猜。

世界观设定、角色背景故事、地名、势力、规则，凡是想让 AI 记住的设定，都适合放进世界书，不必在每条消息里重复一遍。世界书只在内容真正相关时才把它送出去，也就省下了提示词的空间。

关键词匹配对任何 AI 连接都有效，不需要额外配置。Marinara 还能按语义而不是字面词匹配条目，这就是可选的语义搜索。它是一项需要单独开启的功能，有专门的指南讲解。

## Lorebooks 面板

**Lorebooks** 面板就是整个世界书库，浏览、搜索、管理都在这里。从应用侧边栏打开它。面板里每本世界书都会显示图片、名称和一句简短描述。

面板顶部有三个图标按钮，只有图标没有文字。把鼠标悬停在按钮上就能看到它的名称。

- **New**(新建，加号图标) 打开 **Create Lorebook**(新建世界书) 窗口，用来创建世界书。
- **Import**(导入，向下箭头) 打开 **Import Lorebook**(导入世界书) 窗口，用来载入世界书文件。
- **Select**(选择，对勾) 开启多选模式，可以一次导出或删除多本世界书。

按钮下方是搜索框，占位文字为 **Search lorebooks**。它按名称、描述、关联的角色或用户角色名称以及标签筛选列表。旁边是 **Sort order**(排序方式) 下拉菜单，选项有 **Manual order**(手动排序)、**A-Z**、**Z-A**、**Newest**、**Oldest** 和 **Token Budget**。选 **Manual order** 时，把世界书拖成你想要的顺序，或者用键盘上的 Alt+Up 和 Alt+Down 移动某一本。你的顺序会保留下来。

每本世界书那一行都有 **Copy**(复制) 按钮和 **Delete**(删除) 按钮，鼠标悬停在该行时出现，手机上则一直可见。**Copy** 会复制出一份副本。已关闭的世界书会带一个小小的 **OFF** 标记。点击图片可以上传或替换图片。

用 **New Folder**(新建文件夹) 按钮还能建立库文件夹。把世界书拖到文件夹上即可归档，库大了也不会乱。在手机上，按住一本世界书片刻，再拖动它。这些库文件夹和单本世界书内部的条目文件夹是两回事。

## 分类

每本世界书都属于一个分类。分类只是一个方便整理的标签，不影响世界书何时生效、怎样生效。

面板里有这些分类选项卡：

- **All** 显示全部世界书，按分类分组。
- **Active** 只显示与当前打开的聊天相关的世界书。
- **World**、**Character**、**NPC**、**Spellbook** 和 **Other** 各自只显示对应分类的世界书。

创建世界书时要从五个分类里选一个：**World**、**Character**、**NPC**、**Spellbook** 或 **Other**，默认是 **Other**。之后可以在世界书的 **Overview**(总览) 选项卡里改。注意 **Overview** 选项卡把这同一个分类写作 **Uncategorized** 而不是 **Other**。怎么用这些标签由你自己定，比如把地点和背景设定放进 **World**，把同伴的过往放进 **Character**。

## 世界书如何生效

只有在当前聊天中处于活动状态时，世界书才会给 AI 供料。让一本世界书生效有三种方式，挑合适的那种即可。

1. **全局。** 全局世界书在每一次聊天里都生效，只要它处于启用状态。在世界书的 **Overview** 选项卡里打开 **Global**(全局) 开关。共享世界观的规则这类到处都用得上的设定，适合走这条路。
2. **关联到角色或用户角色。** 关联世界书会在任何包含该角色、或使用该用户角色的聊天里自动生效。关联可以在 **Overview** 选项卡里设置，也可以在角色编辑器或用户角色编辑器里设置。角色自己的背景故事最常用这种方式。
3. **固定到单次聊天。** 在某次聊天的设置里可以只给这一次聊天添加世界书，它也只在这次聊天里生效。某段设定只服务于一个故事、不适合整个库时，这么做很方便。

同一本世界书不能既是全局又是关联。打开 **Global** 之后保存，角色和用户角色的关联都会被清空。Marinara 把这两个选项视为互斥。

每本生效中的世界书仍然受自己的 **Enabled**(启用) 开关约束。世界书一旦关闭，即使它是全局的或已关联，条目也全都不会生效。想知道当前聊天里有哪些世界书在起作用，打开该聊天的设置，找到里面的 **Lorebooks** 部分。生效列表也可以在那里编辑。这部分内容由另一篇指南介绍。

## 创建第一本世界书和第一个条目

按下面的步骤建一本世界书，并加一个条目。

1. 打开 **Lorebooks** 面板，点击 **New**，**Create Lorebook** 窗口随即打开。
2. 在 **Name**(名称) 输入框里填名称。这一项必填，比如 `Eldoria World Lore` 就很清楚。
3. 想写的话，再加一句简短的 **Description**(描述)。这一项可选，只是方便你以后找到这本世界书。
4. 从下拉菜单里选一个 **Category**(分类)，或者就保持 **Other**。
5. 点击 **Create Lorebook** 按钮。新世界书会出现在面板列表里。

这时世界书里还没有条目，接着加一个。

1. 在面板里点击这本世界书所在的行，整页编辑器打开。
2. 点击 **Entries**(条目) 选项卡，旁边的标记显示条目数量。
3. 点击 **Add Entry**(添加条目)，一个空白的新条目就出现了。
4. 在条目里填一个或多个触发关键词，比如 `Eldoria`。
5. 在条目的 **Content**(内容) 输入框里写下想让 AI 收到的文本。

停止输入后过一小会儿，条目会自动保存，界面上会出现一句 **Saved automatically** 提示。到这里世界书就能用了：最近的聊天命中关键词时，条目内容就会加入提示词。关键词、匹配规则和时机选项详见[世界书条目](entries.md)指南。其中的[编写策略](entries.md#authoring-strategy-choosing-the-right-entry)和[实例演练](entries.md#worked-example-a-small-setting)两节会讲怎样给每个条目选对控件。

## Overview 选项卡的设置

打开一本世界书，点击 **Overview** 选项卡，就能设置整本世界书的行为。最要紧的几项是名称、分类、关联，以及上面讲过的那几个开关。这个选项卡还有下面这些数值设置。

| 设置 | 作用 | 默认值 |
|---|---|---|
| **Scan Depth** | Marinara 检查关键词匹配时往回看多少条消息。设为 0 表示扫描整段聊天。 | 2 |
| **Token Budget** | 这本世界书最多能往一次提示词里加多少 Token。设为 0 表示不限。 | 2048 |
| **Entry Limit** | 这本世界书最多能往一次提示词里加多少条目。取值范围 1 到 1000。 | 100 |
| **Max Depth** | 额外的递归轮数。这一项只在 **Recursive** 开启时出现。取值范围 1 到 10。 | 3 |

Token 是文本的一个小片段，大致相当于几个字符。AI 留给提示词的空间有限，**Token Budget** 的作用就是不让一本世界书把这点空间占满。

这个选项卡还有三个开关：

- **Enabled** 控制整本世界书的开关，默认开启。
- **Recursive**(递归) 让已生效条目的文本在额外的几轮里再触发别的条目，默认关闭。希望设定能一环扣一环带出相关设定时，把它打开。
- **Vectors** 让条目可以使用语义匹配，默认关闭。关着的时候关键词匹配照常工作。

这些设置下方是 **Semantic Search (Embeddings)**(语义搜索与嵌入) 面板，它负责生成按意思匹配所需要的数据。配置方法、嵌入来源以及那几个向量化按钮，都在语义搜索指南里。

预算、**Entry Limit** 和递归的细节同样有专门的指南。先用上面的默认值就好，它们对绝大多数世界书都够用，以后随时可以调。
