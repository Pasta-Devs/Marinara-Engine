# 把世界书关联到角色和用户角色

把世界书关联到角色或用户角色，它就会在对应的聊天里自动生效。你也可以把世界书嵌入角色卡，还可以针对单个聊天控制世界书。第一次接触世界书？先看[世界书总览](overview.md)。

## 关联还是嵌入

| 功能 | 关联（指派） | 嵌入 |
| --- | --- | --- |
| 效果 | 角色或用户角色指向你库里的一本世界书。 | 世界书被写进角色卡。 |
| 何时生效 | 在有这个角色或使用这个用户角色的聊天里。 | 同上，而且它会跟着角色卡走。 |
| 随角色卡导出 | 否 | 是 |
| 适用于 | 角色和用户角色 | 仅角色 |

大多数情况下选关联就行。只有打算把角色卡连同世界书一起分享时，才需要嵌入。

## 编辑器里的 Lorebook 选项卡

角色编辑器和用户角色编辑器都有 **Lorebook**(世界书) 选项卡。

1. 打开一个角色或用户角色进行编辑。
2. 点击 **Lorebook** 选项卡。**Lorebooks**(世界书) 区域里有两个按钮：**New**(新建) 和 **Assign Lorebook**(指派世界书)。

**New** 会新建一本已经关联到这个角色或用户角色的世界书，分类设为 **Character**(角色)。**Assign Lorebook** 用来关联你已有的世界书。

## 指派一本已有的世界书

开始之前：选择器只列出 **Category**(分类) 为 **Character** 的世界书，用户角色也一样。如果找不到某本世界书，就打开它，在 **Overview**(总览) 选项卡上把 **Category** 设为 **Character**，然后再试一次。

1. 在 **Lorebook** 选项卡里点击 **Assign Lorebook**。
2. 在搜索框里输入名称的一部分。
3. 点击这本世界书，会出现一个对勾。
4. 让 **Scope**(生效范围) 保持为 **All chats with**(所有包含……的聊天) 后接名称，或者改成别的（见下文）。
5. 点击 **Assign**(指派)。

这本世界书现在会出现在已指派列表里。用该行的 **Scope** 按钮更改生效范围，用垃圾桶图标解除关联。点击名称可以打开这本世界书。

全局世界书不能同时被关联。见[世界书总览](overview.md)。

### 生效范围

**Scope** 决定哪些聊天可以使用这本关联的世界书。只有包含这个角色、或者使用这个用户角色的聊天才会被考虑。

| 生效范围 | 结果 |
| --- | --- |
| **All chats with** 后接名称 | 默认值。在每个这样的聊天里都生效。 |
| **Disabled for all chats**(全部聊天中禁用) | 关联保留，但世界书永远不生效。想暂停时用它。 |
| **Specific chats**(指定聊天) | 只在你从清单里勾选的聊天中生效。至少要勾选一个才能保存。 |

以后想改生效范围，点击该行的 **Scope**，调整好之后再点一次 **Assign**。

## 把世界书嵌入角色卡

开始之前：先把这本世界书指派给角色（见上文）。

1. 打开这个角色，点击 **Lorebook** 选项卡。
2. 在这本世界书所在的行上，点击 **Embed into card**(嵌入角色卡)。

这一行上会出现 **Embedded**(已嵌入) 角标，条目从此会随角色卡一起导出。

一张角色卡只能有一本嵌入的世界书。如果卡里已经有一本，**Embed into card** 会被禁用，它的提示文字会告诉你先移除当前嵌入的世界书。

编辑了关联的世界书之后，点击该行的 **Refresh**(刷新)，按当前条目重写嵌入副本。

### 管理已嵌入的世界书

角色卡里有嵌入的世界书时，已指派列表下方会出现以下控件，还有一份嵌入条目的只读清单。

- **Import Embedded Lorebook**(导入嵌入的世界书) 会把卡里的条目变成你库里一本正常的世界书，并反过来关联到这个角色。关联副本存在之后，按钮会变成 **Reimport Embedded Lorebook**(重新导入嵌入的世界书)。
- **Edit Embedded Lorebook**(编辑嵌入的世界书) 打开那本关联的世界书。你的修改会同步回卡里的副本。
- **Remove from card**(从角色卡移除) 删除嵌入副本。另外关联的世界书不受影响。

很多从其他工具导入的角色卡都自带嵌入的世界书。点击 **Import Embedded Lorebook**，就能得到一份可编辑的版本。

## Chat Settings 里的 Lorebooks 区域

每个聊天都有自己的世界书控件。

1. 打开一个聊天。
2. 打开 **Chat Settings**(聊天设置)。
3. 找到 **Lorebooks** 区域。角标会显示有多少本世界书正在生效。

每本生效的世界书都带一个角标，说明它为什么生效。

| 角标 | 含义 |
| --- | --- |
| **Chat**(聊天) | 你把它添加到了这个聊天。 |
| **Global**(全局) | 它是一本全局世界书。 |
| **Character** | 它关联到了这个聊天里的某个角色。 |
| **Persona**(用户角色) | 它关联到了这个聊天的用户角色。 |

你可以只针对这个聊天更改生效内容。

- **Add Lorebook**(添加世界书) 把一本世界书添加到这个聊天，它会带 **Chat** 角标。
- 垃圾桶图标（**Remove from chat**(从聊天移除)）移除你添加的世界书。
- 闭眼图标（**Disable in this chat**(在此聊天中禁用)）在这里隐藏一本自动生效的世界书，但不解除关联。之后它的名称会带删除线，并显示 **Disabled**(已禁用) 角标。
- 眼睛图标（**Enable in this chat**(在此聊天中启用)）让它重新生效。

### Lorebook Token Budget

**Lorebook Token Budget**(世界书 Token 预算) 限制这个聊天最多能加入多少世界书文本，单位是 Token(模型切分文本的最小单位)。默认值是 8192，0 表示不限制。它在每本世界书自己的 **Token Budget**(Token 预算) 之上额外生效。见[世界书的 Token 预算与递归扫描](token-budgets.md)。
