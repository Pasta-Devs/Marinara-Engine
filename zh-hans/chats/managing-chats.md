# 管理聊天列表

本指南介绍 Marinara Engine 的聊天列表，说明三个模式选项卡的用法，以及聊天的新建、导入、改名、删除、整理、搜索和批量管理。主页上的最近聊天一栏也在本文范围内。

## 聊天列表与模式选项卡

所有聊天都放在左侧边栏的 **Chats**(聊天) 面板里。面板顶部有三个模式选项卡：

- **CONVO** 对应 Conversation(对话模式)，就是普通的即时通讯式聊天。
- **RP** 对应 Roleplay(角色扮演)，带角色和世界状态追踪的沉浸式场景。
- **GM** 对应 Game，由 AI 主持的单人 RPG。

每个选项卡只显示对应模式的聊天。点击选项卡即可切换列表。

列表中每一行显示聊天名称，以及所属角色的头像。在 Conversation 聊天里，头像上的小彩点表示每个角色的在线状态。某一行出现红色角标时，那是未读消息的数量。

有些行会显示一个带数字的小分支图标，说明这个聊天有不止一个分支，这些分支被合并显示在同一行里。想了解分支是什么，见[聊天分支](branches.md)。

## 新建聊天

1. 选中想要的模式选项卡（**CONVO**、**RP** 或 **GM**）。
2. 点击面板顶部附近的 **+** 按钮。它的提示文字会随当前选项卡显示 **New Conversation**、**New Roleplay** 或 **New Game**。
3. Marinara Engine 会创建并打开这个聊天，同时打开 **Chat Settings**(聊天设置) 面板和一个设置向导，方便你把配置一次做完。

新聊天的名字是 **New Conversation**、**New Roleplay** 或 **New Game**，之后可以改名（见下面的“给聊天改名”）。

聊天能打开的前提是至少有一个连接。连接就是把 Marinara 接到某个 AI 服务商的一套信息。还没有连接时，出现的不是聊天界面，而是一个 **Set Up**(设置) 窗口，要求先选一个连接。如果一个连接都没有，窗口会显示 **No connections found** 和一个 **Open Connections** 按钮。配置方法见[连接 AI 服务商](../connections/connecting-to-a-provider.md)。

如果为该模式保存过一个加星的默认设置方案，Marinara 会自动把它套用到新聊天上。见[聊天设置总览](chat-settings.md)。

## 导入聊天

来自 SillyTavern 或 Marinara 的聊天记录，只要存成 `.jsonl` 文件就能导入。

1. 选中希望导入结果落在哪个模式选项卡。
2. 点击面板顶部附近的 **Import**(导入) 按钮。它的提示文字是 **Import SillyTavern or Marinara chat JSONL**。
3. 选择 `.jsonl` 文件。

Marinara 会按当前选项卡的模式新建一个聊天并打开它，屏幕上应该出现 **Imported N messages** 的提示，其中 N 是消息条数。

导入导出聊天的全部方式，包括批量导入和各种导出格式，见[导出与导入聊天](export-import.md)。

## 给聊天改名

聊天名称只有你自己看得到，不会发给 AI，也不会影响聊天内容。

1. 打开聊天。
2. 用聊天里的按钮打开 **Chat Settings**。
3. 在 **Chat Name** 一栏点击当前名称，它会变成一个输入框。
4. 输入新名称，然后按 Enter 或点击对勾按钮。

关于 Chat Settings 面板的更多内容，见[聊天设置总览](chat-settings.md)。

## 删除聊天

要删除单个聊天，把鼠标移到那一行上，点击垃圾桶按钮。手机上垃圾桶按钮一直显示。接着会弹出标题为 **Delete Chat**(删除聊天) 的窗口，问“Delete this chat?”点击 **Delete**(删除) 确认。

聊天删掉就找不回来了。删除同时也会中止这个聊天里仍在生成的回复。

### 分支选择窗口

如果要删的聊天有不止一个分支，弹出的会是另一个窗口。它同样标题为 **Delete Chat**，说明这个聊天有多个分支，并给出两个选择：

- **Delete This Branch Only** 只删掉刚才点击的那一个分支。
- **Delete All N Branches** 删掉这一组里的全部分支，其中 N 是分支数量。

想在不删整个聊天的前提下管理分支，见[聊天分支](branches.md)。

### 开启或关闭删除确认

这些确认窗口出不出现，由一个全应用范围的设置 **Confirm before deleting**(删除前确认) 控制。它默认开启，位于 **Settings**(设置) 的 **General** 选项卡下。它自带的说明文字也建议保持开启。

## 聊天文件夹

在每个模式选项卡内部，都可以用文件夹给聊天分组。

1. 当前选项卡里至少要有一个聊天，列表上方才会出现 **New Folder**(新建文件夹) 按钮。
2. 点击 **New Folder**。新文件夹的名字是 **unnamed**(这个名字被占用时依次是 **unnamed 2**、**unnamed 3**，以此类推)。

给文件夹改名有三种办法：双击，在触摸屏上点两下，或者选中它再按 F2。改成空名称的操作会被忽略。

要删除文件夹，点击该行上的垃圾桶按钮，标题为 **Delete Folder**(删除文件夹) 的窗口会请你确认。删除文件夹绝不会删掉里面的聊天，这些聊天会回到顶层。

要调整文件夹顺序，抓住拖动手柄上下拖即可。

要把聊天放进文件夹，把它那一行拖到文件夹上。要把聊天从所有文件夹里拿出来，就拖到文件夹下方的空白区域。在触摸屏上，长按聊天大约半秒即可开始拖动。如果已经选中了多个聊天，拖动其中任意一个会带着整批一起移动。

不在任何文件夹里的聊天，会以普通列表的形式排在文件夹下方。

## 搜索、排序和按标签筛选

每个模式选项卡在列表顶部都有自己的搜索框，占位文字随选项卡变化：**Search conversations...**、**Search roleplays...** 或 **Search games...**。搜索匹配的是聊天名称、标签和角色名称，不会搜索消息正文。

搜索框旁边是排序菜单，提示文字为 **Sort chats**，共有四个选项：

- **Newest** 是默认值，最近活跃的聊天排在最前。
- **Oldest** 把最久没动过的排在最前。
- **A-Z** 按名称从 A 到 Z 排序。
- **Z-A** 按名称从 Z 到 A 排序。

只要当前选项卡里有聊天带标签，就会出现一行标签筛选器。点击 **Tags** 小标展开标签列表，再点某个标签，列表就只显示带该标签的聊天。点击 **Clear** 取消筛选。标签很多时，会有一个 **+N more** 小标用来展开其余的。

注意：这个界面只能按聊天已有的标签筛选，这里没有给聊天添加标签的按钮。

列表一次最多显示 100 个聊天。数量超出时，底部会出现 **Load more** 按钮，用来加载下一批。

## 选中多个聊天

多个聊天可以一次性处理。

1. 点击面板顶部附近的 **Select chats**(选择聊天) 按钮（对勾图标）。
2. 逐个点击想要的聊天。这时点击不再打开聊天，而是在该行上切换一个复选框。
3. 底部会出现一个条，显示已选中的聊天数量，以及两个按钮。

**Export**(导出) 按钮把选中的聊天一起打包成一个 `.zip` 文件下载下来。**Delete** 按钮则把它们删掉，删除前会先弹出标题为 **Delete Chats** 的确认窗口。

想什么都不做直接退出选择模式，再点一次选择按钮即可。切换选项卡也会清空选择。

## 主页上的最近聊天

主页会显示一个紧凑的 **Recent Chats**(最近聊天) 一栏，列出最近活跃的三个聊天。每个聊天显示成一个小标，带头像、模式角标和聊天名称。点击小标即可打开对应聊天。一个聊天都还没有时，这一栏显示 **No chats yet**。
