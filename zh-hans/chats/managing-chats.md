# 管理聊天列表

左侧的 **Chats**(聊天) 面板放着你所有的聊天。在这里可以新建、查找、排序、整理和删除聊天。

## 聊天列表与模式选项卡

面板顶部有三个模式选项卡。每个选项卡只列出对应模式的聊天。

| 选项卡 | 模式 |
| --- | --- |
| **CONVO** | Conversation(对话模式)：即时通讯式的聊天。 |
| **RP** | Roleplay(角色扮演)：带角色和世界状态追踪的场景。 |
| **GM** | Game：由 AI 主持的单人 RPG。 |

每一行显示聊天名称和其中角色的头像。在 Conversation 聊天里，头像上的彩色小点表示那个角色的状态。红色角标是未读消息的数量。带一个小分支图标和数字的行，表示这个聊天有好几个分支，它们归在同一行里。见[聊天分支](branches.md)。

## 新建聊天

开始之前：在 **Connections**(连接) 里至少添加一个账号。见[连接 AI 服务商](../connections/connecting-to-a-provider.md)。

1. 点击你想要的模式选项卡。
2. 点一下面板顶部的 **+** 按钮。它的标签会随选项卡显示为 **New Conversation**、**New Roleplay** 或 **New Game**。

Marinara 会创建并打开这个聊天，旁边同时打开 **Chat Settings**(聊天设置) 和一个设置向导。聊天的初始名称是 **New Conversation**、**New Roleplay** 或 **New Game**。如果你为 Conversation 或 Roleplay 保存过一个加了星标的默认设置方案，Marinara 会把它套用到新聊天上。见[设置方案](settings-profiles.md)。

如果没有成功：还没有保存任何账号时，打开的不是聊天，而是 **Add account**(添加账号) 窗口。选一个服务，点击 **Connect**(连接)，然后选择一个模型。完整步骤见[连接 AI 服务商](../connections/connecting-to-a-provider.md)。

## 导入聊天

可以导入来自 SillyTavern 或 Marinara 的 `.jsonl` 聊天记录。

1. 点击聊天要落入的那个模式选项卡。
2. 点一下面板顶部的 **Import**(导入) 按钮。它的标签是 **Import SillyTavern or Marinara chat JSONL**。
3. 选择你的 `.jsonl` 文件。

Marinara 会创建并打开这个聊天，并显示 **Imported N messages**。导出格式和批量导出见[导出与导入聊天](export-import.md)。

如果没有成功：屏幕底部会出现一条简短的消息 **Import failed**，并写明原因。只接受 `.jsonl` 文件。

## 给聊天改名

聊天名称只给你自己看，不会发给模型。

1. 打开聊天，再打开 **Chat Settings**。
2. 在 **Chat Name**(聊天名称) 中点击当前名称。
3. 输入新名称，然后按 <kbd>Enter</kbd> 或点击对勾。

怎么打开这个面板，见[聊天设置总览](chat-settings.md)。

## 删除聊天

1. 点一下聊天那一行上的垃圾桶按钮。在电脑上，把鼠标指向那一行时它才会显示。
2. 在 **Delete Chat**(删除聊天) 对话框里点击 **Delete**(删除)。

删除是永久的。它也会中止这个聊天里仍在生成的回复。

如果这个聊天有好几个分支，对话框会说明有几个，并给出两个选择：

- **Delete This Branch Only**(只删除这个分支) 删掉你点击的那个分支。
- **Delete All N branches**(删除全部 N 个分支) 删掉这一组里的每个分支。

想在不删除聊天的前提下管理分支，见[聊天分支](branches.md)。

这些对话框由全应用范围的设置 **Confirm before deleting**(删除前确认) 控制。它默认开启，在 **Settings → General**(设置 → 常规) 里。

## 聊天文件夹

文件夹用来在一个模式选项卡内给聊天分组。

1. 打开一个至少有一个聊天的选项卡。只有这时，选项卡下方才会出现 **New Folder**(新建文件夹)。
2. 点击 **New Folder**。文件夹会命名为 **unnamed**(之后依次是 **unnamed 2**、**unnamed 3**)。

| 想做什么 | 怎么做 |
| --- | --- |
| 给文件夹改名 | 双击它或在触屏上点两下，或者聚焦它再按 <kbd>F2</kbd>。空名称会被忽略。 |
| 删除文件夹 | 点击文件夹那一行上的垃圾桶按钮。文件夹里有聊天时，会出现 **Delete Folder**(删除文件夹) 对话框。聊天会移到顶层，不会被删除。 |
| 调整文件夹顺序 | 把文件夹上下拖动。排序菜单会切换为 **Custom**(自定义)。 |
| 把聊天放进文件夹 | 把聊天那一行拖到文件夹上。在触摸屏上，要先长按聊天大约半秒。 |
| 把聊天移出文件夹 | 把它拖到文件夹下方的空白区域。 |

选中了多个聊天时，拖动其中一个会带着整批一起移动。不在文件夹里的聊天排在文件夹下方。

## 搜索、排序和筛选

### 按名称查找聊天

每个选项卡都有一个搜索框，占位文字是 **Search conversations**、**Search roleplays** 或 **Search games**。输入一个词即可。它匹配聊天名称、标签和角色名称，不匹配消息正文。

### 在所有聊天中查找消息

1. 点一下排序菜单旁边的 **Search all chats**(搜索所有聊天) 按钮。
2. 输入要找的词。

它会搜索所有聊天，并可以按模式、角色、发送者和日期筛选。

排序菜单（**Sort chats**(聊天排序)）有这些选项：

| 选项 | 顺序 |
| --- | --- |
| **Custom** | 你的文件夹顺序。 |
| **Manual order**(手动排序) | 按你拖动排好的顺序排列聊天。用键盘时，聚焦一个聊天后按 <kbd>Alt</kbd>+<kbd>Up</kbd> 或 <kbd>Alt</kbd>+<kbd>Down</kbd>。 |
| **Recent**(最近) | 最近活跃的排在最前。这是默认值。 |
| **Newest**(最新) | 最近创建的排在最前。 |
| **Oldest**(最早) | 最早创建的排在最前。 |
| **A-Z** 和 **Z-A** | 按名称排序。 |

只要这个选项卡里有聊天带标签，就会出现一个 **Tags (N)**(标签) 小标签。点击它展开标签，再点某个标签，就只显示带这个标签的聊天。点击 **Clear**(清除) 取消筛选。这个面板不能给聊天添加标签。

列表一次显示 100 个聊天。点击 **Load more**(加载更多) 查看下一批。

## 选中多个聊天

1. 点击面板顶部的对勾按钮（**Select chats**(选择聊天)）。
2. 逐个点击你想要的聊天。这时点击不会打开聊天，各行会显示一个复选框。
3. 使用底部的操作栏，它会显示选中了多少个聊天。

**Export**(导出) 会把选中的聊天下载成一个 `.zip` 文件，里面是一个个 `.jsonl` 文件。**Delete** 会先弹出 **Delete Chats**(删除聊天) 对话框请你确认，然后删除它们。再点一次对勾按钮就会退出选择模式。切换选项卡也会清空选择。

## 主页上的最近聊天

主页上有一个 **Recent chats**(最近聊天) 小组件，列出你最近的聊天。每个聊天显示名称、模式角标和最后一条消息。点击某个聊天即可打开它。还没有任何聊天时，它会显示 **Your chats will show here**。见[主页小组件](../home/welcome.md#home-widgets)。
