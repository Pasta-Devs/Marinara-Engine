# Game Mode：使用规则集游玩

规则集告诉 Game Mode 一套桌面系统如何运作：检定掷什么骰子、人物卡上有什么、消耗哪些资源、休息恢复什么，以及某些规则集如何进行整场战斗。用这份指南获取规则集、为游戏选择规则集，并了解游玩时有哪些变化。没有规则集的游戏采用 Marinara 自身规则，其他 Game Mode 指南介绍了这些规则。

## 获取规则集

安装 5e (SRD 5.1) 这类官方规则集：

1. 打开 **Agents**(智能体) 面板（Sparkles 图标）。
2. 选择 **Agent Organizer**(智能体管理器)。
3. 找到这个规则集。规则集标有 **Rules**(规则)。
4. 选择 **Install**(安装)。

然后新建一局游戏并选中它（见下文）。规则集有两个来源：

- **Official**(官方) 规则集按上面的方法安装。
- **Community**(社区) 规则集从文件或作者的 GitHub 仓库导入，并按来源归档，例如 `local/ember-roads` 或 `alice/v20`。

导入使用的开关和导入智能体相同，即 **Allow custom Agent imports**(允许导入自定义智能体)。这个开关关闭时，导入的规则集不会出现在新游戏中，已经在用的游戏照常运行。使用导入规则集的游戏始终按创建时的确切版本来玩。想自己编写，见[编写 Game Mode 规则集](../extending/writing-rulesets.md)。

规则集自身的文本，如技能名称、法术和给游戏主持人（GM）的文本，采用 **Settings**(设置) 中设定的语言。官方规则集只下载该语言的译文，切换语言时再获取新的译文，缺少某种语言时回退到英语。从文件导入的规则集只保留导入时所用语言的译文。要切换语言，需要重新导入文件。

## 为游戏选择规则集

只有安装了至少一个规则集，并且是新游戏时，设置向导的 **World**(世界) 步骤里才会出现 **Rules**。它与 **Combat Preference**(战斗偏好) 分开：**Rules** 决定检定和人物卡如何运作，**Combat Preference** 决定战斗如何呈现。

1. 在设置向导里打开 **World** 步骤。
2. 在 **Rules** 下面，保留 **Marinara's own rules**(Marinara 自身规则)（内置的 d20 检定和六属性人物卡），或者选一个规则集，例如 **5e (SRD 5.1)**。
3. 阅读简述。它会列出规则集覆盖的内容，以及一行关于战斗的说明（见[战斗中会发生什么](#what-happens-in-battles)）。
4. 可选：开启 **layers**(层)（见下文）。
5. 在 **Party**(队伍) 步骤里，查看谁 **Has a sheet**(已有人物卡)、谁 **Starts on a blank sheet**(从空白人物卡开始)。人物卡是角色在这个规则集下的数值，例如属性值和生命值。空白人物卡使用规则集的默认值，你可以以后再填。

规则集在创建游戏时确定。之后不能更换，也不能再添加。

**Layers** 是规则集的具名变体，例如 Low magic 或 Hard winter。它们以开关形式显示在规则集下方，每个都附一行说明其作用。一个层可以：

- 让难度更严苛；
- 缩小人物卡上的某项选择；
- 把一些现成条目从人物卡编辑器的选择器里隐藏；
- 改变商店出售什么、掉落什么宝物；
- 给 GM 额外的指令，包括它构建世界时的指令。

有些层彼此排斥，向导会禁用你不能选的那个。游戏开始后层就固定下来。人物卡上已经在用、但被某个层去掉的内容会保留。

人物卡在角色或用户角色编辑器的 **Stats**(属性) 下添加（见[规则集人物卡](../characters/colors-and-stats.md#ruleset-sheets)）。生成世界时，游戏会复制每张人物卡，你在游戏里做的任何改动都不会写回角色或用户角色。没有人物卡的成员会得到一张空白人物卡，所有数值都是规则集的默认值。世界生成绝不会编造属性值。

共享的设置文件会记住它的规则集。如果你导入的设置文件用的规则集你没有，或者你的版本更旧，向导会告诉你它用的是哪个规则集，游戏会使用 Marinara 自身规则，除非你安装并选中那个规则集。

<a id="what-happens-in-battles"></a>

## 战斗中会发生什么

规则集在战斗中做什么，取决于它的编写方式。设置向导中规则集下方的那行文字会说明属于下表的哪一行。

| 规则集 | 战斗 |
| --- | --- |
| 自行结算战斗，例如 5e (SRD 5.1) | 按规则集自身的规则，在它自己的战斗界面上进行。见[按规则集战斗](fighting-on-a-ruleset.md)。 |
| 为战斗提供人物卡 | 采用 Marinara 自身的战斗系统，使用人物卡的生命值、法术位和能力（见下文）。 |
| 未提及战斗 | 采用 Marinara 自身的战斗系统，与没有规则集时完全相同。见[战斗](combat.md)。 |

规则集提供人物卡时，Marinara 的战斗会这样使用它：

- 每个队伍成员开战时，带着规则集为战斗设定的资源池和法术位，数量与人物卡当前的记录一致。
- 从规则集目录里选的能力，只要 Marinara 的战斗能用，就会变成技能。只描述战斗之外事情的条目、反应，以及战斗无法扣除其消耗的条目都会被略过。
- 生命值按占最大值的比例带入，而不是照搬人物卡上的数字。生命剩一半的角色，开战时就是战斗界面生命条的一半，所以人物卡上只有 9 点生命的角色，不会走进一场一击就打掉 12 点的战斗。
- 战斗结束时，失去或恢复的生命值按同样的方式写回，花掉的法术位和资源则按实际数量写回。

其余部分不变。骰子计算仍然是 Marinara 的（见[战斗数值怎么算](combat.md#how-combat-math-works)），不套用桌面系统的攻击检定、豁免和专注。通过删除发起战斗的那条消息而离开的战斗，不会写回任何东西。

<a id="checks-on-a-ruleset"></a>

## 规则集中的检定

GM 会像在任何游戏中一样要求检定（见[技能检定](dice-and-skill-checks.md#skill-checks)），但如何掷骰由规则集决定。

- GM 只说出技能或豁免的名称并设定难度。它收到的是规则集自己的难度阶梯，而不是内置阶梯。难度可以达到该阶梯的上限，甚至超过 Marinara 自身规则的 1 到 40。只有一条路径仍限制在 1 到 40：为已保存回合补掷尚欠检定的回退路径。
- Marinara 掷规则集的骰子，并加上角色**规则集人物卡**中的调整值：技能或豁免指定了属性时的属性调整值、训练等级的加值（熟练加值的倍数、固定数值或两者都有），以及人物卡上的任何额外加值。不使用内置的技能加值和属性。
- 结果遵循规则集。在 5e (SRD 5.1) 下，天然 20 和天然 1 对检定和豁免没有特殊效果，所以没达到难度的天然 20 也会失败。
- 如果规则集的包缺失，或者比创建游戏时的版本更旧，检定会不带数值保存，继续保持待掷状态。绝不会改用另一个系统的规则掷骰。

Marinara 不信任 GM 自己写的数字。即使标签看起来已经完成，只要它的调整值与人物卡不符、掷的骰子数量或面数与规则集不同、计入的骰子不是掷骰模式应保留的那颗，或者声称了规则集没有的天然结果，就会重新掷骰并替换。

### GM 可以在检定里加什么

| GM 写的内容 | 效果 |
| --- | --- |
| `who="Name"` | 检定使用那位队伍成员的人物卡。不写时检定玩家。没有人物卡的成员用空白人物卡掷骰。名字没有匹配到任何人，或被两名成员共用时，不加任何调整值。如果有成员与你自己的角色同名，这个名字仍然指你。Marinara 绝不会借用别人的人物卡。 |
| `with="Ability"` | 用另一项属性来掷这个技能或豁免。只有规则集声明的属性有效，其他名称一律忽略。 |
| `difficulty="Hard"` | 用难度阶梯上某一级的名称代替数字。Marinara 按那一级的数值掷骰，保存下来的检定显示这个数值。未知的名称会被忽略。 |
| 掷骰占位符 | 可以引用规则集的属性、技能和豁免；规则集有熟练加值时，也可以用 `PROF` 表示它。 |

你在检定前自己掷出的骰子，只在规则集掷单颗 d20 时使用。掷其他骰子（例如 2d6 或骰池）的规则集会忽略它。

### 人物卡对掷骰的影响

- **改变掷骰的护符。** GM 在检定里点名护符，Marinara 扣除它的消耗、应用效果并掷骰。你没选取或付不起的护符既无效果，也不扣消耗。
- **花费资源稳定掷骰。** GM 在检定里注明，Marinara 扣点、加上买到的效果并掷骰。资源池不够时什么都不扣。记录显示的是实际支付的量。一次检定最多能买多少由规则集决定：一个固定数值、你人物卡上的某个数值，或者与检定的骰子数一样多。
- **随掷骰附加的数值。** 如果规则集规定人物卡上的某个数值作用于特定掷骰，例如每次 Brawn 掷骰都要计入的沉重背包，Marinara 会把它加到所有适用的检定上，骰子卡片也会注明人物卡加了什么。
- **未受训练的技能。** 规则集可以让未受训练的检定扣掉骰子或点数、难度提高一级，或者根本无法进行。无法尝试的检定不会掷骰，叙述会说明这一点。在你受训之前，人物卡上不会显示这类技能的数值。
- **伤势。** 如果规则集有伤势轨道，并规定其惩罚作用于掷骰，受伤会让每次检定更难。在骰池规则集下，它会从骰池里减去相应数量的骰子，但不会低于规则集允许的最小骰池（有些允许为零）。在把骰子相加的规则集下，它是一项固定惩罚。检定会说明实际应用了多少。见[规则集人物卡](#the-ruleset-sheet)。

GM 还会在人物卡上随时更新每个角色的资源、状态和休息，Marinara 会拒绝人物卡不允许的改动。

### 使用骰池的规则集

有些系统数骰子，而不是加加值。人物卡上的数值就是你掷的骰子数，再数出点数够高的那些。

- **人物卡数值就是骰子数。** 评级 3 加专业技能 2，就掷五颗骰子。人物卡显示“5 dice”，而不是“+5”。
- **难度是成功次数。** 困难的任务需要三次成功，而不是总和 15。每一级需要多少次成功，由规则集的难度阶梯规定。
- **Marinara 负责掷骰和计数。** 哪些点数算成功、高点数是再掷一颗还是计作两次、低点数是否抵消成功，以及什么算失误或杰出成功，都由规则集决定。骰子卡片展示每一颗骰子，把达到目标值的那些标出来，并对照所需次数读出成功次数。骰池大时会换行显示，卡片绝不会显示一个骰子并没有相加得出的总数。
- **GM 可以调整单次检定**，前提是规则集允许：提高或降低单颗骰子的目标值，按情境增减骰子，以及调低触发重掷或计作两次的点数。每一项都限制在规则集的范围内。难度阶梯的某一级可以自带单颗骰子的目标值。检定用了规则集惯常点数以外的点数时，骰子卡片会注明。
- **骰子可以重掷**，前提是规则集有相应规则。GM 在检定里点名，点数低的骰子就会重掷，重掷一次或一直掷到更高为止。花费资源也能买到同样的效果。一次掷骰只按一种方式重掷；两种都适用时，采用涉及骰子更多的那种。
- **两种属性可以合并掷骰**，前提是规则集这样规定：两个评级合成一个骰池掷出。
- **失误也可能伴随结果。** 在把半数或更多骰子掷出低点算作失误的规则集里，仍然拿到所需成功次数的检定会保留其结果，卡片会另外注明出了差错。一次成功都没有时，就是大失败。
- **GM 从不提供数值。** 叙述中写出的骰池结果会被 Marinara 自己的掷骰替换。优势和预先掷好的骰子不适用。
- **让 GM 看到每种面数的一颗骰子不适用。** GM 看到的骰子是二十面骰。骰池检定会盲掷，并像其他盲掷一样叙述。

### 规则集的其他掷骰方式

掷骰仍由 Marinara 完成，骰子卡片按规则集显示：

- **保留最高的骰子。** 掷一把骰子，读取其中最高的一颗、两颗或三颗。
- **对照人物卡掷骰。** 掷出不高于人物卡上某个数值（例如技能百分比）的结果。
- **自带骰面的骰子。** 骰面代表的可以不是它的数字，例如减号、空白和加号，也可以带有符号，例如成功、优势以及它们的反面。
- **分档结果。** 检定可以落入某个档位，例如大成功或付出代价的成功，而不只是简单的通过或失败。卡片会标出档位，由 GM 叙述。
- **少数检定另用一种掷法。** 规则集可以让大多数检定用一种方式掷骰，并指定少数几种用另一种方式。

<a id="the-ruleset-sheet"></a>

## 规则集人物卡

在使用规则集的游戏里，每张人物卡都以一个 **Ruleset sheet**(规则集人物卡) 区块开头。它的布局来自规则集，所以 5e 的人物卡和其他系统的人物卡看起来不一样。没有规则集的游戏没有这个区块。另见 [Character Profiles](party-and-npcs.md#character-profiles)。

| 部分 | 作用方式 |
| --- | --- |
| **Resources**(资源) | 生命值、法术位或职业资源会显示上限中还剩多少。用减号和加号按钮，或者直接输入数字。带临时缓冲的资源还会显示 **Temp**(临时)。 |
| **Tracks**(轨道) | 例如力竭。在自己的范围内逐级升降。 |
| **Notes**(备注) | 简短的文本框，例如角色正在专注什么。 |
| **Conditions**(状态) | 可以开关的按钮。 |
| **States**(形态) | 一种形态或姿态：一次只能取列表里的一个值。形态可以改变跟随它的数值，例如给掷骰加的骰子，休息也可能把它重置。 |
| **Rest buttons**(休息按钮) | 执行规则集的某一种休息。休息恢复什么由规则集规定。它还可以恢复道具的充能，例如魔杖的充能，按钮下方那一行会写明恢复了什么。在 5e (SRD 5.1) 下，长休会恢复生命值和法术位，并恢复一半的生命骰，至少一颗。 |
| 构建摘要 | 属性调整值、受过训练的技能和豁免，以及规则集挑选的数值，例如护甲等级。 |

**Wound tracks**(伤势轨道) 用一排格子代替数字，适用于标记伤害而不是计数的系统。每个格子都写明这一级伤势的名称，以及它会从你的掷骰里扣掉什么。

1. 如果规则集有不止一种伤害，先选伤害类型。
2. 点击 **Mark**(标记) 或 **Clear one**(清除一个)。你也可以点击下一个空格添加标记，或者点击最后一个已标记的格子清除一个。其他格子不响应点击。

更重的标记会占据更高的格子，把较轻的往下挤。下方那一行会写明当前生效的惩罚，以及放不进轨道的部分。有些规则集给格子编号而不是命名，有时格子数和你自己的评级一样多；有些规则集会把每个标记放在它瞄准的那个格子上。这类轨道上，你可以点击任何一个空格，**Clear one** 清除最高格子上最轻的那个标记，轨道满了以后会拒绝新的标记，而不是让旧标记变重。规则集还可以根据你人物卡上的某个列表添加格子，并让一次休息或治疗只清除某一种伤害。

### GM 如何修改人物卡

GM 在叙述时会同步更新人物卡。角色花费资源、受到伤害、得到治疗、获得或失去状态、改变形态或休息时，它会记录这些改动，Marinara 再对照人物卡检查。不可能发生的改动，例如没有剩余法术位却施法，会被拒绝：什么都不会改变，并有一条通知告诉你。

角色使用从规则集目录里选的东西时，例如一个法术或一项职业特性，GM 会说出它的名字，Marinara 支付全部代价：规则集规定的消耗，加上随它而来的每个计数器各一次使用次数。消耗法术位的法术，从规则集指定的环级支付，GM 也可以要求用更高的环级。Marinara 永远不会自行升到更高的环级。代价中只要有任何一部分付不起，整个操作就会被拒绝，什么都不扣。不花费任何东西的效果，例如戏法，只是叙述出来。

人物卡上有些数值属于规则集：上限随等级变化的职业资源，或随某项属性值变化的使用次数，由规则集设定，你编辑人物卡时它们会保持正确。规则集还可以根据某项资源或轨道的当前状态算出一个数值，为形态的每个取值给出一个数值，把某个列表的一列加总（例如你打包的装备的重量），或者用这样的数值给某项技能设上限，于是资源低时技能也会缩水。游戏的人物卡显示这些数值的当前值，检定或战斗使用的是那一刻的值。角色卡上的人物卡编辑器没有游戏可读，所以显示的是游戏开始时的样子。

实时数值属于它们发生时所在的那条消息。如果你切换到某个回合的另一个版本，或者重新生成它，人物卡会回到那个回合之前的样子，所以任何东西都不会被花掉两次。

### 编辑规则集人物卡

修改配置本身，例如升级之后。

1. 打开角色的人物卡，点击 **Edit ruleset sheet**(编辑规则集人物卡)。
2. 修改属性值、字段、法术之类的列表，以及技能和豁免的训练。计算值会随输入更新。如果规则集有分步构建器，选择 **Guided**(引导) 逐项完成每个选择（属性值、技能、初始装备），或者选择 **All fields**(全部字段) 一次看到全部内容。
3. 点击 **Save sheet**(保存人物卡)。

它和角色卡上的编辑器是同一个。可以从规则集目录添加行，规则集维护的单元格会显示但不能输入，规则集原文有变化的列表会提供 **Review**(审查)。保存只修改这局游戏里的副本。游戏永远不会改动保存在角色或用户角色上的人物卡。

单独的 **Edit card**(编辑人物卡) 按钮（见[手动编辑人物卡](party-and-npcs.md#edit-a-sheet-by-hand)）编辑的是通用人物卡（职业、能力、优势），不会动规则集人物卡。

如果没有成功，并且规则集的包已被移除，或者比创建游戏时的版本更旧，这个区块会改为显示一条通知。在重新安装这个包之前无法掷检定。

## 队伍人物卡和进度时钟

有些规则集会为整支队伍保留一张人物卡，例如一支船员或一个佣兵团。它显示在游戏画面上地图附近，使用规则集自己给它起的名字。点击名字即可打开。GM 会像更新每个角色的人物卡一样更新它，在规则集允许的地方，你也可以编辑它。如果你编辑时有别人保存了队伍人物卡，你会看到对方的版本。**Save**(保存) 用你的版本替换它，**Cancel**(取消) 保留对方的版本。

规则集还可以使用 **Progress clocks**(进度时钟)：分成若干段的圆圈，GM 会随着某件事逐渐累积而填满它，例如警报逐步拉响。它们显示在地图附近，各自写明填了多少段，填满后显示 **Done**(完成)。
