# Game Mode：HUD 小组件

HUD 小组件是贴在游戏画面左右两侧的小面板，用来记录血条、金币数或某个同伴的信任度之类的东西。HUD 是 heads-up display 的缩写。每场游戏都有自己的一套小组件，和 Roleplay 的 HUD 追踪器是两套东西（见 [Roleplay 的 HUD 与追踪器](../roleplay/hud-and-trackers.md)）。

一场游戏总共最多可以有 4 个小组件，左右两侧怎么分配随你。只有为这场游戏开启了 **Custom HUD Widgets**(自定义 HUD 小组件)，小组件才会生效。这个选项在设置向导里默认开启。开启之后，游戏主持人（GM）会在构建世界的同时设计出一套初始小组件。

## 小组件类型

GM 每创建一个小组件都会为它挑一种类型。自己手动搭建小组件时，也可以自行选择类型。

| 小组件类型 | 显示内容 |
| --- | --- |
| **Progress Bar**(进度条) | 横向进度条，显示一个数值及其上限，比如生命值或体力。 |
| **Gauge**(仪表盘) | 半圆形仪表盘，显示一个数值及其上限。 |
| **Relationship Meter**(关系条) | 带里程碑刻度和文字标签的条，适合表现 NPC(玩家之外的角色) 的信任度或羁绊。 |
| **Counter**(计数器) | 一个大数字，比如金币、经过的天数或击杀数。 |
| **Stat Block**(属性块) | 一小格带名称的字段和数值，比如 STR 和 DEX，或者一个状态词。 |
| **List**(列表) | 一份简短的文字项目符号列表，比如当前目标。 |
| **Inventory Grid**(物品栏网格) | 物品格子组成的网格，可以带分类选项卡和物品数量。 |
| **Timer**(计时器) | 以分秒显示的倒计时，可以实时走秒。 |

## 开局前检查小组件

存在自定义小组件时，游戏画面上的 **Start Game**(开始游戏) 下方会有一个 **Review Starting Widgets**(检查初始小组件) 按钮。点击它，就会在开始之前打开 **Review Starting Widgets** 窗口。它会列出全部初始小组件，让你在游戏把它们固定下来之前先做调整。

1. 对某个小组件按 **Edit**(编辑)，修改它的初始数值，或者给 **Stat Block** 的字段改名。
2. 按 **Remove**(移除)，去掉不想要的小组件。
3. 按 **Start Game**，按当前显示的小组件开始游戏。按 **Back**(返回) 则关掉窗口，不开始游戏。

在进行中的游戏里开始新会话时，会出现一个类似的窗口 **Prepare Next Session Widgets**(准备下一场会话的小组件)。它用 **Start Next Session**(开始下一场会话) 代替 **Start Game**，用 **Cancel**(取消) 代替 **Back**。

## 游戏过程中修改小组件

GM 会随剧情推进更新小组件的数值。GM 漏掉某次更新时，可以手动修正。

1. 在画面左边或右边找到那个小组件面板。
2. 点击小组件标题栏里的铅笔（**Edit**）按钮。
3. 在编辑窗口里修改数值，例如条的 **Maximum value**(最大值)。
4. 点击 **Save Changes**(保存更改)。

点击小组件标题栏，可以折叠或展开它的主体部分。

## 移动和锁定面板

小组件面板默认锁定在原位。每个面板的标题栏里都有一个锁图标。

1. 点击锁图标解锁面板。面板会浮现一圈淡淡的轮廓，表示现在可以移动了。
2. 把面板拖到新位置。
3. 再次点击锁图标，把它重新锁定。

想把面板挪回默认位置，双击它的锁图标，或者在图标处于焦点状态时按 <kbd>R</kbd>。每个面板的位置和锁定状态都按游戏分别记住，布局不会带到其他游戏里。

在手机上，小组件显示成小胶囊而不是完整面板。点一下胶囊就能打开对应的小组件，点 X 关闭。

## 自己搭建小组件

小组件不一定要交给 GM 生成，也可以自己设计。手动编辑器有两个入口：

- 在设置向导里：开启 **Custom HUD Widgets**，再开启 **Build Widget Setup**(搭建小组件配置)。编辑器会出现在下方。
- 在已有的游戏里：打开 **Chat Settings**(聊天设置)，再打开 **Widgets**(小组件) 部分。

1. 从下拉菜单选一种小组件类型，然后按 **Add**(添加)。
2. 设置 **Icon**(图标，一个简短符号或 emoji)、**Label**(标签)、**Type**(类型)、**Side**(所在侧，可选 **Left HUD** 或 **Right HUD**) 和 **Accent**(强调色，即颜色)。
3. 填写这种类型的字段：条用 **Value**(值) 和 **Max**(上限)，计数器用 **Count**(计数)，物品栏网格用 **Slots**(格子数) 和 **Contents**(内容)，计时器用 **Seconds**(秒数) 和 **Running**(是否运行)。
4. 在 **Chat Settings** 里，按 **Save Widgets**(保存小组件) 应用改动。**Reset**(重置) 会撤销尚未保存的修改。

编辑器会显示允许的 4 个名额里已经用掉几个。

## 用导入导出分享小组件

小组件布局可以存成文件，再加载到另一场游戏里。设置向导和 **Chat Settings** 的 **Widgets** 部分都有这两个按钮。

1. 按 **Export Widgets**(导出小组件)，把小组件下载成一个 JSON 文件（一种纯文本数据格式）。
2. 在另一场游戏里按 **Import Widgets**(导入小组件)，选中那个文件。
3. 在 **Chat Settings** 里按 **Save Widgets**，让加载进来的小组件生效。
