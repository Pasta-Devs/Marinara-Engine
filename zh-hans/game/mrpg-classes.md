# Game Mode：MRPG 职业

所有新游戏都采用 **MRPG**(Marinara RPG) 职业，包括从 Experience 创建的游戏。每位队伍成员都有一个职业，会通过战斗升级，并在成长过程中解锁新职业。在 MRPG 职业出现之前创建的游戏会保留 **Legacy** 人物卡，直到你选择迁移（见[把 Legacy 游戏迁移到 MRPG](#move-a-legacy-game-to-mrpg)）。

使用规则集游玩的游戏（例如 5e (SRD 5.1)）改用规则集自己的人物卡，不采用 MRPG 职业。

<a id="classes-and-trees"></a>

## 职业与树

共有八棵树：**Blade**、**Guard**、**Scout**、**Marksman**、**Channeler**、**Hexer**、**Mender** 和 **Herald**。每个角色会在其中两棵树里训练：

- **主树。** 从人物卡决定。资料库中的角色卡或用户角色卡可以在 **Game Mode**(游戏模式) 部分选择主树，否则会根据角色的职业和能力判断。
- **副树。** 由角色开始游戏时的性格开启。如果角色的性格指向自己的主树，就只训练这一棵树，并且可以学习只有专精单棵树的角色才能学习的职业。

每棵树都从一个基础职业开始。职业会在职业等级 10 时首次晋升，20 时再次晋升，等级上限为 30。角色最多可以携带 4 项在其他职业中学过的技能。战斗外可以从人物卡切换职业。属性取决于当前职业。

<a id="the-character-sheet"></a>

## 人物卡

从队伍列表打开某位成员的人物卡。人物卡有四个选项卡：**Status**(状态)、**Classes**(职业)、**Skills**(技能) 和 **Gear**(装备)。成长率默认隐藏。开启 **Debug**(调试) 后，会显示确切的成长百分比。

队伍打赢战斗后会升级。战败或逃跑都不会获得经验。开启 **Permadeath**(永久死亡)（一项设置选项）后，队伍成员若在战斗中倒下，且战斗结束前没有获救，就会永远离队。

<a id="skill-checks"></a>

## 技能检定

战斗外的检定读取角色的 MRPG 属性。各项技能使用哪个属性，见[骰子与技能检定](dice-and-skill-checks.md#how-the-result-is-decided)。

<a id="newcomers-to-the-party"></a>

## 新加入的队伍成员

游戏开始后才加入的角色，会以游戏主持人（GM）为其指定的等级入队。大多数新成员等级较低，经验丰富的战士则可能接近队伍等级。GM 还可以赋予新成员：

- 某些属性的**更快成长速度**，适合天赋尚未打磨、但能迅速追上队伍的角色。
- **更好的初始属性**，适合已经具备一定实力的角色。

GM 会在角色加入时决定这些内容。若 GM 没有特别说明，新成员从 1 级开始。

<a id="playing-with-others"></a>

## 与其他玩家一起玩

在共享游戏中，每位访客加入房间时都会构建自己的角色：名称、描述、供 GM 参考的**角色概念**，以及用户角色拥有的同一组 **Game Mode**(游戏模式) 选项（起始树、强项属性和弱项属性）。选择你的某个用户角色会用其中的内容填入这些项目。你可以在概念里告诉 GM 角色是谁，以及希望这个角色如何进入故事。

GM 随后会安排角色融入故事，并选择其姐妹树。

- **新游戏。** 所有人（房主和访客）都从 1 级开始。
- **已经开始的游戏。** GM 还会决定访客的起始等级；和其他[新成员](#newcomers-to-the-party)一样，还可以给予更快的成长速度或更好的属性。
- **回归的访客。** 访客离开时，其角色会连同等级、装备和驯服的野兽一起留在游戏里。玩家不在期间，该角色不会参战，也不获得经验，GM 也不会让其出现在场景中。访客回来后，会继续操控同一个角色，等级与离开时相同。

<a id="move-a-legacy-game-to-mrpg"></a>

## 把 Legacy 游戏迁移到 MRPG

Legacy 游戏可以一直保留 Legacy 人物卡。要迁移，打开 **Journal**(日志)，在 **All**(全部) 选项卡上找到 **MRPG classes**(MRPG 职业) 卡片，然后选择 **Upgrade**(升级)。

卡片会为每位队伍成员显示：

- **Class**(职业)。角色的起始树，会根据其资料库卡片上的选择填入；没有选择时，则根据 Legacy 职业填入。可以更改。
- **Sister tree**(姐妹树)。由角色性格开启的副树。若角色还没有性格，升级时会根据其 Description(描述) 判断。
- **Gear**。角色携带的每件 Legacy 武器和护甲，以及它会转换成的 MRPG 装备。取消勾选即可保留原样。

用 **Upgrade the party**(升级队伍) 确认后：

- 每位队伍成员都从 10 级开始，也就是起始职业的最高等级；每一级的属性都像正常升级一样掷出。
- 角色卡上的职业会变成其 MRPG 职业。Legacy 职业和能力会移入角色卡上的 **Before the upgrade**(升级前) 注释，让故事仍然知晓这些内容。Legacy 属性也会留在角色卡上。
- 每件接受转换的武器或护甲都会变为相应的 MRPG 装备，并保留原名；如果角色的职业能使用，就会穿戴或装备它。

> **警告：** 升级不可逆。迁移到 MRPG 职业后，游戏无法改回 Legacy 人物卡。

战斗期间不会提供升级选项，请先结束战斗。使用规则集游玩的游戏无法升级，它会保留规则集的人物卡。
