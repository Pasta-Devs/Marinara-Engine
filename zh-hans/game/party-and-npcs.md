# Game Mode：队伍与 NPC

本指南介绍 Game Mode(游戏模式) 战役里的人：你的队伍成员，以及游戏主持人引入的 NPC(玩家之外的角色)。你会学到怎么打开队伍成员的人物卡、怎么编辑或重新生成人物卡，以及怎么查看冒险日志，其中也包括 NPC 的好感度标签。此外还会讲清楚两种游戏主持人模式。

Game Mode 是 Marinara Engine 的聊天模式之一。它是一款由 AI 游戏主持人主持的单人 RPG(角色扮演游戏)，游戏主持人常简称 GM。设置方法和基础玩法见 [Game Mode：入门](getting-started.md)。

## Character Profiles

点击或轻触 **Character Profiles**(角色资料) 头像按钮，就能看到与你同行的角色。队伍不止一人时，按钮会轮流显示他们的头像，并带一个数字角标。

无论在电脑还是手机上，都可以把这个按钮拖到聊天里的任意位置。打开它后使用 **Lock window**(锁定窗口)，按钮就会停在原处。电脑上还可以移动窗口、调整窗口大小。**Close**(关闭) 会把它收回成按钮。它的位置随聊天保存，样式跟随 **Settings → Appearance → App**(设置 → 外观 → 应用) 中的聊天组件样式。手机上，它单独显示，不会收进三点 **Chat tools**(聊天工具) 菜单。

在 **Character Profiles** 里可以做这些事：

1. 点击某个头像，打开这名角色的人物卡。
2. 把鼠标移到头像上（电脑端），会露出一个小小的 **X** 按钮。
3. 点击 **X**，把这名角色移出队伍。

GM 招募来的同伴都可以移除，不管是创建游戏时加入的，还是后来在剧情里加入的。你自己的用户角色是你操作的那个角色，它没有 **X** 按钮，所以没法把自己踢出队伍。

## 人物卡

人物卡是某位队伍成员在游戏里的属性摘要，和角色卡是两回事。它由 GM 根据角色本身和当前剧情写出来。

打开 **Character Profiles**，再点击或轻触那名角色的头像，即可打开人物卡。有内容的部分才会显示出来：

- **Attributes**(属性)：跑团式的数值，比如 STR、DEX、CON，每项都带一个调整值。
- **Stats**(状态)：HP、MP 这类资源条。
- **Abilities**(能力)：这名角色会做的事。
- **Strengths**(优势) 和 **Weaknesses**(劣势)：两份简短列表。
- **Details**(详细信息)：Skills、Weapon、Faction 之类的补充信息。
- **Inventory**(物品栏)：角色随身携带的道具。
- **Traits**(特质)：其他自定义字段。

角色刚加入时，可能会看到“Character data will populate as the story progresses.”人物卡会随着游戏推进逐渐补全。

### 用 AI 重新生成人物卡

点击 **Regenerate Sheet**(重新生成人物卡)，让 AI 重写这名角色的人物卡。它会参考角色本身和当前的游戏上下文。剧情让一个角色变化很大之后，用这个功能很合适。

### 手动编辑人物卡

点击 **Edit Sheet**(编辑人物卡)，自己动手改。编辑模式下可以设置这些内容：

- **Sheet Details**(人物卡详情) 下面的 **Class**(职业) 和一段简短描述。
- **RPG Attributes**(RPG 属性)：打开 **Enable**(启用) 开关，就能记录 HP 这类资源池和各项属性。用 **Add Pool**(添加资源条) 添加一条资源条（名称、当前值、最大值和颜色）。用 **Add Attribute**(添加属性) 添加 STR 之类的数值。
- **Abilities**、**Strengths** 和 **Weaknesses**：用 **Add**(添加) 追加一行。
- **Details**：用 **Add Detail**(添加详情) 添加一条带标签的信息。

改完点击 **Save Sheet**(保存人物卡)。点击 **Cancel**(取消) 放弃修改。

### 规则集人物卡

在使用规则集的游戏里（见[使用规则集的游戏](dice-and-skill-checks.md#games-that-use-a-ruleset)），每张人物卡都以一个 **Ruleset sheet**(规则集人物卡) 区块开头。它的布局来自规则集，所以 5e 的人物卡和其他系统的人物卡看起来不一样。没有规则集的游戏没有这个区块。

- **Resources**(资源)，例如生命值、法术位或职业资源，显示剩余量和上限。用减号和加号按钮，或者直接输入数字。带临时缓冲的资源还会显示一个 **Temp**(临时) 框。
- **Tracks**(轨道)，例如力竭，在自己的范围内逐级升降。
- **Wound tracks**(伤势轨道) 用一排格子代替数字，适用于标记伤害而不是计数的系统。每个格子都写明这一级伤势叫什么，以及会从你的掷骰里扣掉多少。规则集有不止一种伤害时，先选伤害类型，再用 **Mark**(标记) 或 **Clear one**(清除一个)。你也可以点击下一个空格添加标记，或者点击最后一个已标记的格子清除一个；其他格子不响应点击。更重的标记会占据更高的格子，把较轻的标记往下挤，下方那一行会写明当前生效的惩罚，以及完全放不进轨道的部分。有些规则集给格子编号而不是命名，有时格子数和角色自己的等级一样多；有些规则集会把每个标记放在它瞄准的那个格子上：这类轨道上你可以点击任何一个空格，**Clear one** 清除的是最高格子上最轻的那个标记，而轨道满了以后会拒绝新的标记，而不是让旧标记变重。规则集还可以根据你人物卡上的某个列表给轨道添加格子，并让一次休息或治疗只清除某一种伤害。如果规则集这样规定，这项惩罚会作用于你的掷骰：从骰池里减去骰子，或加到求和掷骰上，骰子卡片会写明实际应用了多少。
- **Notes**(备注)，例如角色正在专注什么，是简短的文本框。
- **Conditions**(状态) 是可以开关的按钮。
- **States**(形态)，例如变身或姿态，一次只能取列表里的一个值。从列表里选择这个值。形态可以改变它后面的数值，例如某种姿态给你的掷骰加的骰子；休息也可能把它恢复到起始值。
- **Rest buttons**(休息按钮) 执行规则集的某一种休息。休息恢复什么由规则集规定，休息还可以恢复角色携带的道具的充能，例如魔杖的充能；按钮下方那一行会写明恢复了什么。在 5e (SRD 5.1) 下，长休会恢复生命值和法术位，并恢复角色一半的生命骰，至少一颗。
- 下方是配置的简短汇总：属性调整值、受过训练的技能和豁免，以及规则集挑选的几个数值，例如护甲等级。

Game Master 在叙述时会同步更新这张人物卡。角色花费资源、受到伤害、得到治疗、获得或失去状态、改变形态或休息时，它会记录这些改动，引擎再对照人物卡检查。不可能发生的改动，例如没有剩余法术位却施法，会被拒绝：什么都不会改变，并有一条通知告诉你。

角色使用从规则集目录里选的东西时，例如一个法术或一项职业特性，Game Master 会说出它的名字，引擎则支付全部代价：规则集规定的消耗，加上随它而来的每个计数器各一次使用次数。消耗法术位的法术，从规则集为它指定的环级支付，Game Master 也可以要求用更高的环级。引擎永远不会自行升到更高的环级。代价中只要有任何一部分付不起，整个操作就会被拒绝，什么都不扣。不花费任何东西的效果，例如戏法，只是叙述出来。

人物卡上有些数值属于规则集而不属于你。上限随等级变化的职业资源，或随某项属性值变化的使用次数，由规则集设定，你编辑人物卡时它们会保持正确。

有些计算值跟随游戏进程本身：规则集可以根据某项资源或轨道的当前状态算出一个数值，为形态的每个取值给出一个数值，或者把某个列表的一列加总，例如你打包的装备的重量。它还可以用这样的数值给某项技能设上限，于是资源低时技能也会缩水。这些值在游戏的人物卡上显示当前值，检定或战斗使用的是它发生那一刻的值。角色卡上的人物卡编辑器没有游戏可读，会显示它们在游戏开始时的样子。

这些实时数值属于它们发生时所在的那条消息。如果你切换到某个回合的另一个版本，或者重新生成它，人物卡会回到那个回合之前的样子，所以任何东西都不会被花掉两次。

点击 **Edit sheet**(编辑人物卡) 修改配置本身，例如升级之后：属性值、字段、法术之类的列表，以及技能和豁免的训练。计算值会随输入更新。它与角色卡上的编辑器是同一个，所以这里也能从规则集目录添加行，规则集维护的单元格会显示但不能输入，规则集原文有变化的列表会提供 **Review**(审查) 按钮。如果规则集有分步构建器，编辑器会在 **All fields**(全部字段) 旁边提供 **Guided**(引导)。**Guided** 带你逐项完成每个选择，例如属性值、技能和初始装备，并说明每一步还在等待什么。**All fields** 一次显示全部内容。完成后点击 **Save sheet**(保存人物卡)。这只会修改这局游戏里的人物卡副本。游戏永远不会改动保存在角色或用户角色上的人物卡。

上面介绍的那个单独的 **Edit Sheet** 按钮仍然编辑通用人物卡（职业、能力、优势等），不会动规则集人物卡。

如果规则集的包被移除了，或者已安装的版本比创建游戏时用的版本旧，这个区块会改为显示一条通知，在重新安装这个包之前无法掷检定。

### 队伍人物卡和进度时钟

有些规则集会为整支队伍保留一张人物卡，例如一支船员或一个佣兵团。它显示在游戏画面上地图附近，使用规则集自己给它起的名字。点击名字即可打开。Game Master 会像更新每个角色的人物卡一样更新它，在规则集允许的地方，你也可以编辑它。如果你编辑时有别人保存了队伍人物卡，它会显示对方的版本：**Save**(保存) 用你的版本替换它，**Cancel**(取消) 保留对方的版本。

规则集还可以使用 **Progress clocks**(进度时钟)：分成若干段的圆圈，Game Master 会随着某件事逐渐累积而填满它，例如警报逐步升级。它们显示在地图附近，各自写明填了多少段，填满后显示 **Done**(完成)。

## 物品栏

点击叙述上方的 **Inventory**(物品栏) 打开它。每个方格是一叠：一种物品及其数量。点击一叠即可选中。

队伍里每个人都带着自己的东西。物品栏打开时显示 **All**(全部)，所有背包一起显示，每叠物品的角上写着携带者的名字。点击某个队伍成员的标签页，就只看他的背包。在其他人都没带任何东西时，没有标签页，每一叠都是你的。

- **调整数量。**用 **-** 和 **+** 减少或增加一个。要改动更多，在两者之间的数字里输入并按 Enter：输入数字会设定数量（`300`），带符号则增加或减少相应数量（`+100`、`-50`）。把一叠设为 0 会移除它，数量多于一个时会先询问。
- **拆分一叠。**点击 **Split**(拆分)，输入新的一叠要分出多少，再点一次 **Split**。从 300 个苹果里拆出 100 个，会留下一叠 200 个，旁边多出一叠 100 个。
- **交给别人。**点击 **Give**(给予)，选择交给谁、给多少，再点一次 **Give**。要交出一整叠，也可以把它拖到那个人的标签页上。
- **添加。**输入物品名称，点击 **Add**(添加)。它会进入当前打开的标签页对应的背包；在 **All** 下则进入你自己的背包，除非规则集规定了每个人能带多少（见下文）。添加一个背包里已经有的物品，会给它的第一叠加一个。
- **合并或重新排序。**把一叠拖到同一种物品的另一叠上即可合并，不管它们各自叫什么。合并后的这叠归你拖放目标那叠的携带者所有。把一叠拖到另一种物品上，会让两者互换位置。
- **从规则集添加。**在规则集列出自己物品的游戏里，**From the ruleset**(从规则集添加) 会打开这些物品的选择器，带有规则集的搜索和筛选。勾选想要的物品，点击 **Add**：每样一个，放到 **Add** 放物品的地方，即当前打开的标签页对应的背包，或者在 **All** 下放进你自己的背包，除非规则集规定了每个人能带多少。输入的名称如果是规则集的某个物品，也会添加那个物品。规则集可以只接受它自己的物品，这时就没有可以输入名称的地方。
- **初始装备。**规则集提供初始装备时，**Starting gear**(初始装备) 会打开它。选择给谁（**For**(给)），完成套装要求的选择，然后点击它的 **Take**(领取) 按钮，把装备放进那个人的背包。适合该角色人物卡的装备排在前面；其他装备只要 Game Master 同意也可以领取。领取是可选的。提供的东西全部领完后，按钮会显示为 **Starting gear (taken)**。
- **使用。**点击 **Use**(使用) 告诉 Game Master 你使用了这件物品。对于规则集里写明使用效果的物品，例如治疗药膏，引擎会先执行它：掷出它恢复的数值，写到携带者的人物卡上，从这一叠里扣掉一个或消耗一次充能，再把发生的事告诉 Game Master，让故事跟上。它对其他人的作用则交给 Game Master 叙述。用光了的物品会被拒绝使用，必须穿戴的物品只有在穿戴时才能使用。有些物品会先要求一次检定，例如超出你阅读能力的卷轴：引擎会掷这次检定，失败的话物品就白白用掉了。
- **昵称。**为这一叠输入一个新名字，点击 **Save**。这只是你对这一叠的称呼：它仍然是同一种物品，Game Master 仍然可以用它本来的名字称呼它，而且起昵称永远不会把它合并到另一叠里。物品本来的名字会显示在昵称旁边。把本来的名字输回去即可清除昵称。

选中规则集的物品时，会显示它是什么：类型、稀有度、标签、数值和描述。它的一叠最多只能放规则集规定的数量，超出的部分会另起一叠。Game Master 还可以用规则集自己的措辞发明一件物品，例如一把有名字的刀刃。它和规则集自己的物品一样使用，详情里会注明它是发明出来的，以及引擎为了让它符合规则集做了哪些修改，例如把加值限制在它的稀有度允许的范围内。有些规则集会关闭 Game Mode 自带的物品：这时 Game Master 只会给出规则集的物品和它发明的物品，而你仍然可以输入自己的物品，除非规则集只接受它自己的物品。

### 穿戴、绑定和携带

规则集还可以规定它的物品如何穿戴和携带：

- **已装备。**占用槽位的物品，例如穿在身上的盔甲或双手持握的弓，会有一个 **Equipped**(已装备) 按钮。只要这些槽位空着，携带者就能穿戴它；背包的标签页会显示每个正在使用的槽位，例如 **Hands 2/2**。装备一大叠里的其中一件，会把它单独分成一叠，标记为已穿戴。
- **绑定。**必须绑定才能起作用的物品（同调、灌注）会有一个按规则集用词命名的按钮，例如 **Bound**(已绑定)。一个角色能绑定的物品数量以人物卡允许的为限，显示为例如 **Bound 1/3**。被诅咒的物品一旦绑定就会保持绑定：你无法解除绑定、脱下、送人或丢掉它。只有故事本身，通过 Game Master，才能解除诅咒。
- **携带。**规则集规定了每样东西的重量和每个角色能携带多少时，每个背包都会显示负重，例如 **Load 5/6, at most 12**，超过携带者能轻松携带的量时会显示 **Encumbered**(负重过度)。在 **All** 下添加的物品会交给能携带它而不至于负重过度的人：先是你，然后按顺序轮到队伍其他人。如果没有人能把它全部带走，就按每个人剩余的空间分摊，而且绝不会给任何人超过其最大负重的东西。谁都带不了的部分会被留下，并告诉你。交给某人超出其负重能力的东西会被拒绝，无论是用 **Give**，还是把一叠拖到他背包里的另一叠上。

把穿戴着或绑定着的物品交给别人，会先脱下并解除绑定。

队伍成员的人物卡会列出他携带的东西。

Game Master 会随着故事推进添加、移除和转交物品，并说明谁携带它们。它提到的物品如果是规则集的物品，那就是那件物品，它也会得知你持有的每件规则集物品是什么。它使用规则集物品的方式与 **Use** 按钮相同。在规定了物品如何穿戴和携带的规则集里，它还会穿上和脱下物品、绑定和解除绑定，并能看到每个角色的负重、槽位和已绑定的物品；它添加物品而没说给谁时，会和你添加的物品一样分摊。每项改动都在回复保存时生效，对应的通知会在你读到故事的那一部分时出现。Game Master 拿走一件物品而没说从谁那里拿时，会先从你的背包里拿，再从队伍其他人那里拿。不可能发生的改动，例如拿走谁都没有的东西，会被拒绝，并告诉 Game Master。重新生成一条回复时，它的改动会从那个回合开始时的状态重新来过；切换回较早的版本，会显示那个版本留下的结果。删除当前所在的版本，会显示下一个版本留下的结果；聊天的分支也会带上每个版本的物品栏。这一切只在物品栏仍然完全保持回复留下的样子时才会发生：一旦你自己改动了什么，新的回复就会在此基础上叠加它的改动，你做过的事一件都不会被撤销。战斗通过 **Items** 行动使用物品，并会把一种物品的所有叠加在一起计算，不管谁携带、叫什么名字。所有背包，包括拆分和昵称，都会延续到下一次会话。

### 货币

规则集可以有自己的货币：一个或多个币种系列，例如便士、先令和克朗，每种较大的硬币都值若干枚最小的硬币。硬币和其他物品一样按叠存放。它们的重量按规则集规定计算，并计入携带者的负重，也可以像其他东西一样拆分、交给别人和合并。**From the ruleset** 里有一个 **Coins**(硬币) 列表，可以手动添加硬币。

在各叠物品上方，有一行显示当前打开的标签页里每个币种系列的硬币及其合计，例如 **Coin: crowns ×2, pennies ×12 (worth 132 pennies)**。

Game Master 用这些硬币向队伍收费和付款，赢下的战斗或它掷出的宝藏也可能掉落硬币。付款从某一个角色的钱袋里出，没说是谁就从你的钱袋里出，而且只用标价所用的那个币种系列：先用最大的硬币，凑不出准确金额时会拆开一枚较大的硬币，以较小的硬币找零。钱袋付不起的价格会被拒绝，并告诉 Game Master。以一个币种标价的东西永远不会用另一个币种支付，所以用盐标价就用盐付。队伍赚到的钱会像其他物品一样进入背包。每次付款和收入都会显示一条通知。

规则集的某个变体可以去掉一种硬币，例如在一个漫长的夜晚里，没有克朗流到古墓那边。这时谁都不会收到或用这种硬币支付，以它标价的东西会按相同的价值折算成剩下的硬币显示。

规则集还可以有市场，所以你能买到什么取决于你在哪里。Game Master 会说明一个场景所在的地方是哪里、有多大，用规则集自己的话说是小村还是城市；小地方卖的东西更少：稀有的东西可能只有在城镇才找得到，有些商人只在较大的地方开店，或者只为某些买家服务，例如只卖给信徒的礼拜堂。你买东西时，引擎会根据物品的成本和这笔交易是便宜还是贵来算出价格，从买家的钱袋里扣钱，再把物品放进他的背包。住宿、船票和其他服务只需付款。一条通知会显示买了什么、花了多少；这个地方、这个商人或这个钱袋无法完成的购买会被拒绝，并告诉 Game Master 原因。规则集还可以让同一个地方的每一天都不一样：一个地方的某种稀有物品可能只有寥寥几件，某个商人那天可能会拿出一些不寻常的东西，你也可以把东西卖回给经营它的商人，按价格的一定比例出售，直到这个地方的商人花完他们一天能付出的钱为止。在同一个地方的新的一天（队伍留下来时由 Game Master 开始）会重新补满货架和钱袋。

没有规则集的游戏，只要它的设定包有货币和市场，也会有：每个入门设定包都有，例如高奇幻里的铜币、银币和金币，武侠里的铜钱和银两，现代的美元和美分，以及赛博朋克和太空歌剧里的信用点。设定包的商店会列出它的设定里出售的日常物品，每样都有价格和出售它的最小地点，所以村子里有咖啡馆，但只有城镇才有急救包。你可以在设定包的 **Change its words**(修改用词) 里修改货币和商店，或者干脆去掉货币。之后买东西、付款和赚钱都和上面一样，只是使用设定自己的货币。

## 招募和移除队伍成员

队伍里有谁，由 GM 随剧情推进决定，界面上没有手动的“添加同伴”按钮。GM 会根据场景里发生的事，在叙述中加入或移出队伍成员。

GM 加入的 NPC 如果和你的某张角色卡名字完全相同，或者和你的好几张卡同名，就会弹出一个窗口，问你让哪一张卡加入。窗口里会列出每张卡的名字、头衔和头像。选一张卡即可；也可以选 **Keep the game's own**(保留游戏自己的角色) 加 NPC 名字的那一项，比如 **Keep the game's own Emma**，让游戏生成的那个角色加入。直接关闭窗口也是同样的效果。只是名字相近的卡永远不会被加进来，比如 NPC 叫 Sam，而卡叫 **Samantha**。

想自己赶走一位同伴，就按上面说的，用 **Character Profiles** 里该同伴头像旁的 **X**。自己的用户角色不能用这种方式移除。

## 冒险日志

冒险日志是这场战役的流水记录。它由保存下来的游戏事件生成，不是 AI 写的，所以内容一定属实。

打开 **Session**(会话)，见[打开 Session](sessions-and-saves.md#opening-session)，再选择 **Journal**(日志) 选项卡。Journal 有这些选项卡：

- **Timeline**(时间线)：已经发生的事，比如发现的地点、遇到的 NPC、战斗结果、任务和道具事件。
- **NPCs**：你见过的 NPC，带头像和好感度标签（见下文）。
- **Map**(地图)：已探索地点的名称列表，只有名字。
- **Items**(道具)：获得、使用、丢失和移除道具的记录。
- **Library**(藏书)：GM 给你看过的世界内笔记和书籍，保存下来方便随时重读。
- **Notes**(笔记)：你自己的自由记事本。
- **World**(世界)：在有生成世界的游戏里，显示你的队伍所了解的世界。它会显示：
  - 你在哪里，以及队伍有多出名
  - 队伍与打过交道的每个团体的关系
  - 队伍做过的事
  - 队伍听到的消息，传闻会单独标出
  - 队伍听说的正在酝酿的麻烦
  - 任何一个当地人都会讲的往事

  它只显示队伍可能知道的东西。只有 Game Master 知道的秘密会保持隐藏。它会随着故事的备选回复和分支一起变化。

### 玩家笔记

**Notes** 选项卡是你的私人记事本。左边输入，右边同步显示排版后的预览。记事本上方有一行说明，提醒你写的内容 GM 和队伍成员都看得到。也就是说，这里写的任何东西都可能影响剧情。

停止输入片刻后，笔记会自动保存。保存过程中会显示 **Saving...**，保存完成后显示 **Saved**。

## NPC 好感度标签

冒险日志的 **NPCs** 选项卡记录每个 NPC 对你的态度。列表里的每个 NPC 都有头像、名字和一个好感度标签。

好感度标签会随着你在剧情里的行为变化。一共七档，从好到坏依次是：

| 标签 | 含义 |
|---|---|
| **Devoted** | 对你死心塌地 |
| **Allied** | 坚实的盟友 |
| **Friendly** | 态度友好 |
| **Neutral** | 谈不上好恶 |
| **Unfriendly** | 态度不佳 |
| **Hostile** | 已经与你为敌 |
| **Enemy** | 处处与你作对 |

只有当 NPC 的好感度偏离初始值之后，标签才会出现。刚登场、好感度还没变过的 NPC 暂时不显示标签。

GM 描述过某个 NPC、给了它好感度，或者记下了一条关系备注，这个 NPC 就会出现在这个选项卡里。每一行 NPC 还提供这些操作：

- 上传或替换 NPC 的头像。
- 开启图像生成后，用 AI 生成头像。
- 把这个 NPC 从日志里删除。

## 游戏主持人模式

游戏由谁来主持，在设置向导的 **Party**(队伍) 这一步、**Game Master Mode**(游戏主持人模式) 下面选择。两个选项：

- **Standalone GM**：默认选项。Marinara 会替你搭一个 GM。向导里对它的描述是“A snarky narrator running the show”。不需要角色卡。
- **Character GM**：拿自己的一张角色卡当 GM。引擎会让模型一边扮演这个角色，一边主持游戏。想要某种特定的叙述口吻时选它。

第一次玩就用 **Standalone GM**。模式在创建游戏时设定。完整的设置流程见 [Game Mode：入门](getting-started.md)。
