# Game Mode：队伍与 NPC

本指南介绍 Game Mode(游戏模式) 战役里的人：你的队伍成员，以及游戏主持人（GM）引入的非玩家角色（NPC，即玩家之外的角色）。用它来打开和编辑人物卡、管理物品栏、查看冒险日志，以及选择 GM 模式。设置方法和基础玩法见 [Game Mode：入门](getting-started.md)。

## 查看队伍和物品栏

1. 点击 **Character Profiles**(角色资料)，选一个头像，查看这名角色的人物卡。
2. 点击故事文字上方的 **Inventory**(物品栏)，查看每个人携带的东西。

两者的详细说明见下文。

## Character Profiles

**Character Profiles** 是一个头像按钮，显示与你同行的角色。它不在 **Chat tools**(聊天工具) 菜单里（见[游戏控件](getting-started.md#the-games-controls)）。队伍不止一人时，按钮会轮流显示他们的头像，并带一个数字角标。在故事加入其他人之前，队伍里只有你的用户角色。

1. 点击或轻触 **Character Profiles** 按钮。
2. 点击或轻触一个头像，打开这名角色的人物卡。

要移除一位同伴，在电脑上把鼠标移到其头像上，再点击 **X**。GM 招募的同伴都可以这样移除，不管是在设置时还是之后加入的。你自己的用户角色（你扮演的那个角色）没有 **X**。

无论在电脑还是手机上，都可以把这个按钮拖到聊天里的任意位置。打开它后使用 **Lock window**(锁定窗口)，它就会停在原处。电脑上还可以移动窗口、调整窗口大小，**Close**(关闭) 会把它收回成按钮。它的位置随聊天保存，样式跟随 **Settings → Appearance → App**(设置 → 外观 → 应用) 中的聊天组件样式。手机上，它和三点 **Chat tools** 菜单分开显示。

## 人物卡

人物卡是某位队伍成员在游戏里的摘要，和角色卡是两回事。采用 **MRPG** 职业的游戏（也就是所有新游戏）会先显示角色的 MRPG 职业人物卡：其中有 **Status**(状态)、**Classes**(职业)、**Skills**(技能) 和 **Gear**(装备) 选项卡，可用来切换职业、携带技能和装备物品。见[人物卡](mrpg-classes.md#the-character-sheet)。MRPG 属性会取代下文的 **Attributes**(属性)。

在它下面，GM 会根据你的角色和当前剧情来编写人物卡的剧情部分。有内容的部分才会显示出来：

| 部分 | 内容 |
| --- | --- |
| **Attributes** | 仅限 Legacy 游戏：STR、DEX、CON 之类带调整值的数值，以及 HP、MP 这类资源条。 |
| **Stats**(状态) | 其他数值条。 |
| **Abilities**(能力) | 这名角色会做的事。 |
| **Strengths**(优势)、**Weaknesses**(劣势) | 简短列表。 |
| **Details**(详细信息) | Skills、Weapon、Faction 之类的补充信息。 |
| **Inventory** | 角色随身携带的物品。 |
| **Traits**(特质) | 其他自定义字段。 |

新角色可能会显示“Character data will populate as the story progresses.”人物卡会随着游戏推进逐渐补全。

<a id="edit-a-sheet-by-hand"></a>

### 手动编辑人物卡

**Retry**(重试)、**Save Sheet**(保存人物卡) 和 **Cancel**(取消) 只有在你点击 **Edit card**(编辑人物卡) 之后才会出现。

1. 打开这名角色的人物卡，点击 **Edit card**。
2. 修改需要改的内容：
   - **Sheet Details**(人物卡详情) 下的 **Class**(职业) 和一段简短描述。
   - **RPG Attributes**(RPG 属性)（Legacy 游戏）：打开 **Enable**(启用)，就能记录资源池和属性。**Add Pool**(添加资源条) 会添加一条资源条（名称、当前值、最大值、颜色）。**Add Attribute**(添加属性) 会添加 STR 之类的数值。采用 MRPG 职业的游戏不会把它们用于检定或战斗。
   - **Abilities**、**Strengths** 和 **Weaknesses**：**Add**(添加) 会追加一行。
   - **Details**：**Add Detail**(添加详情) 会添加一条带标签的信息。
3. 点击 **Save Sheet**。点击 **Cancel** 则放弃修改。

想让 AI 重新生成人物卡，就在编辑时点击 **Retry**。它会参考角色本身和当前的游戏历史，并向你的模型发送一次请求。它生成的是一份草稿：“new sheet draft is ready. Review it, then save to apply.”检查草稿，然后点击 **Save Sheet**。剧情让一个角色变化很大之后，适合用它。在窄屏上，这个按钮只显示一个图标。

<a id="the-ruleset-sheet"></a>

### 规则集人物卡

在使用规则集的游戏里，每张人物卡都以一个由规则集决定布局的 **Ruleset sheet**(规则集人物卡) 区块开头：其中有资源、轨道、状态、休息和构建摘要，由 GM 在叙述时持续更新。见[规则集人物卡](rulesets.md#the-ruleset-sheet)。

## 招募和移除队伍成员

队伍里有谁，由 GM 通过叙述决定。界面上没有“添加同伴”按钮。

GM 加入的 NPC 如果和你的某张角色卡名字完全相同，或者和好几张卡同名，就会弹出一个窗口，问你让哪一张加入。窗口里列出每张卡的名字、头衔和头像。选一张卡；或者选 **Keep the game's own**(保留游戏自己的角色) 加 NPC 名字的那一项（比如 **Keep the game's own Emma**），让游戏生成的那个角色加入。直接关闭窗口效果相同。只是名字相近的卡永远不会被加入，比如 NPC 叫 Sam，而卡叫 **Samantha**。

Experience 可以自带同伴：来自它的世界、可以加入你的角色，每个都带有现成的人物卡。故事可能让一位同伴加入或离开，而 GM 只能招募这些同伴（你自己角色库里的角色仍然可以加入）。同伴加入时采用队伍的最高等级，之后随队伍一起升级。

## 物品栏

点击故事文字上方的 **Inventory** 按钮，会打开一个方格网格。每个方格是一叠：一种物品，以及它的数量。点击一叠即可选中。

队伍里每个人都有自己的背包。物品栏打开时显示 **All**(全部)，所有背包一起显示，每叠物品上都标着携带者的名字。点击某个队伍成员的标签页，就只看这个人的背包。在其他人都没带任何东西时，没有标签页。

- **调整数量。**用 **-** 和 **+** 减少或增加一个。也可以在两者之间输入一个数字，然后按 <kbd>Enter</kbd>。
  - 输入数字会设定数量：`300`。
  - 带符号则增加或减少相应数量：`+100`、`-50`。
  - 设为 0 会移除这一叠；数量多于一个时会先询问。
- **拆分一叠。**点击 **Split**(拆分)，输入新的一叠要分出多少，再点一次 **Split**。
- **交给别人。**点击 **Give**(给予)，选择交给谁、给多少，再点一次 **Give**。也可以把一整叠拖到那个人的标签页上。
- **添加。**输入物品名称，点击 **Add**。它会进入当前标签页对应的背包；在 **All** 下则进入你自己的背包。添加背包里已经有的物品，会给它的第一叠加一个。
- **合并。**把一叠拖到同一种物品的另一叠上。合并后的这叠归你拖放目标那叠的携带者。
- **互换。**把一叠拖到另一种物品上，两者就会互换位置。
- **使用。**点击 **Use**(使用)，告诉 GM 你使用了这件物品。
- **昵称。**输入一个新名字，点击 **Save**(保存)。物品仍保留它本来的名字，显示在昵称旁边，而且昵称永远不会让几叠合并。把本来的名字输回去即可清除昵称。

### GM 如何改动你的物品栏

GM 会随着故事推进添加、移除和转交物品，并说明由谁携带。

- GM 拿走一件物品而没说从谁那里拿时，会先从你的背包里拿，再从队伍其他人那里拿。
- 不可能发生的改动，例如拿走谁都没有的东西，会被拒绝，并告诉 GM。
- 改动在回复保存时生效。重新生成一条回复，会从那个回合开始时的状态重新来过。切换回较早的备选回复，会显示那个版本留下的结果。分支会保留每个版本的物品栏。
- 如果你自己改动了什么，新的回复会在此基础上叠加它的改动，你做过的事一件都不会被撤销。
- 战斗通过 **Items**(物品) 行动使用物品，并把同一种物品的所有叠加在一起计算。
- 所有背包、拆分和昵称都会延续到下一次会话。

## 冒险日志

冒险日志是这场战役的流水记录。它由保存下来的游戏事件生成，不是 AI 写的，所以内容始终属实。

1. 打开 **Session**(会话)（见[打开 Session](sessions-and-saves.md#opening-session)）。
2. 选择 **Journal**(日志) 选项卡。

| 选项卡 | 显示内容 |
| --- | --- |
| **Timeline**(时间线) | 已经发生的事：发现的地点、遇到的 NPC、战斗结果、任务和物品事件。 |
| **NPCs** | 你见过的 NPC，带头像和好感度标签。 |
| **Map**(地图) | 已发现地点名称的简单列表。 |
| **Items** | 获得、使用、丢失或移除物品的记录。 |
| **Library**(藏书) | GM 给你看过的世界内笔记和书籍，保存下来方便重读。 |
| **Notes**(笔记) | 你自己的记事本。 |
| **World**(世界) | 在有生成世界的游戏里，显示你的队伍所了解的世界。 |

**World** 选项卡会显示你在哪里、队伍有多出名、队伍与每个团体的关系、队伍做过的事、传到队伍耳中的消息（传闻会单独标出）、队伍听说的正在酝酿的麻烦，以及任何一个当地人都会讲的往事。它只显示队伍可能知道的东西。只有 GM 知道的秘密会保持隐藏。它会随着故事的备选回复和分支一起变化。

### 玩家笔记

在 **Notes** 选项卡里，左边输入，右边显示排版后的预览。有一行说明提醒你，笔记 GM 和队伍成员都看得到，所以你写的任何东西都可能影响剧情。停止输入片刻后，笔记就会保存。标签会先显示 **Saving...**，然后显示 **Saved**。

### NPC 好感度标签

**NPCs** 选项卡里的每个 NPC 都显示头像、名字和一个好感度标签，标签会随你的行为变化。GM 描述过某个 NPC、给了它好感度，或者记下了一条关系备注之后，这个 NPC 就会出现。只有好感度偏离初始值之后，标签才会出现，所以刚登场的 NPC 没有标签。

| 标签 | 含义 |
| --- | --- |
| **Devoted** | 对你死心塌地 |
| **Allied** | 坚实的盟友 |
| **Friendly** | 态度友好 |
| **Neutral** | 谈不上好恶 |
| **Unfriendly** | 态度不佳 |
| **Hostile** | 已经与你为敌 |
| **Enemy** | 处处与你作对 |

每一行 NPC 还可以上传或替换头像、用 AI 生成头像（需要开启图像生成），以及把这个 NPC 从日志里移除。

## 游戏主持人模式

游戏由谁来主持，在设置向导的 **Party**(队伍) 这一步、**Game Master Mode**(游戏主持人模式) 下面选择。模式在创建游戏时设定。

- **Standalone GM**：默认选项。Marinara 会替你搭一个 GM。向导里对它的描述是“A snarky narrator running the show”。不需要角色卡。
- **Character GM**：用你自己的一张角色卡当 GM。模型会扮演这个角色，同时主持游戏。想要某种特定的叙述口吻时选它。

如果这是你的第一局游戏，就用 **Standalone GM**。

## 参考：规则集物品栏

这些内容只适用于使用规则集的游戏，或者设定包带有货币的游戏。见[使用规则集游玩](rulesets.md)。

### 规则集物品

这些控件只在游戏使用带物品的规则集时出现。

- **From the ruleset**(从规则集添加) 会打开规则集物品的选择器，带有规则集的搜索和筛选。勾选物品，点击 **Add**：每样一个，放到 **Add** 放物品的地方。输入的名称如果是规则集的某个物品，就会添加那个物品。有些规则集只接受自己的物品，这时就没有可以输入名称的地方。
- **Starting gear**(初始装备) 会打开规则集提供的初始装备。选择给谁（**For**(给)），完成套装要求的选择，然后点击 **Take**(领取)。适合该角色人物卡的装备排在前面。领取是可选的。全部领完后，按钮会显示为 **Starting gear (taken)**。
- 对写明了使用效果的规则集物品（例如治疗药膏）点击 **Use**，Marinara 会先执行它的效果：
  - 掷出这件物品恢复的数值，写到携带者的人物卡上。
  - 从这一叠里扣掉一个或消耗一次充能，并把发生的事告诉 GM。
  - 它对其他人的作用交给 GM 处理。
  - 用光了的物品会被拒绝使用，必须穿戴的物品只有在穿戴时才起作用。
  - 有些物品会先要求一次检定，例如超出你阅读水平的卷轴。Marinara 会掷这次检定，失败的话物品就白白用掉了。
- 选中规则集物品时，会显示它的类型、稀有度、标签、数值和描述。一叠最多只能放规则集规定的数量，多出来的会另起一叠。
- GM 可以用规则集的措辞发明一件物品，例如一把有名字的刀刃。它和规则集物品一样使用，详情里会注明它是发明出来的，以及 Marinara 为了让它符合规则集做了哪些修改，例如把加值限制在它的稀有度允许的范围内。
- 有些规则集会关闭 Game Mode 自带的物品。这时 GM 只会给出规则集的物品和它发明的物品，而你仍然可以输入自己的物品，除非规则集只接受它自己的物品。

### 穿戴、绑定和携带

规则集可以规定它的物品如何穿戴和携带。

- **已装备。**占用槽位的物品，例如穿在身上的盔甲或双手持握的弓，会有一个 **Equipped**(已装备) 按钮。只要这些槽位空着，携带者就能穿戴它。背包的标签页会显示正在使用的槽位，例如 **Hands 2/2**。装备一大叠里的其中一件，会把它单独分成一叠，标记为已穿戴。
- **绑定。**必须绑定才能起作用的物品（同调、灌注）会有一个按规则集用词命名的按钮，例如 **Bound**(已绑定)。一个角色能绑定的数量以人物卡允许的为限，显示为 **Bound 1/3**。被诅咒的物品一旦绑定，就无法解除绑定、脱下、送人或丢掉。只有故事本身，通过 GM，才能解除诅咒。
- **携带。**规则集规定了重量和负重上限时，每个背包都会显示负重，例如 **Load 5/6, at most 12**，超过携带者能轻松携带的量时会显示 **Encumbered**(负重过度)。在 **All** 下添加的物品会交给能携带它而不至于负重过度的人：先是你，然后按顺序轮到队伍其他人。如果没有人能带，就按每个人剩余的空间分摊，而且谁都不会拿到超过自己最大负重的东西。谁都带不了的部分会被留下，并告诉你。用 **Give** 或把一叠拖到背包上时，如果会超出那个背包的上限，就会被拒绝。

把穿戴着或绑定着的物品交给别人，会先脱下并解除绑定。在有这些规则的规则集里，GM 也会穿上和脱下物品、绑定和解除绑定，并能看到每个人的负重、槽位和已绑定的物品。

### 金钱与市场

规则集可以有自己的货币：若干币种系列，例如便士、先令和克朗，每种较大的硬币都值若干枚最小的硬币。硬币和其他物品一样按叠存放。它们的重量按规则集规定计算，计入携带者的负重，也可以拆分、交给别人和合并。**From the ruleset** 里有一个 **Coins**(硬币) 列表，可以手动添加硬币。在各叠物品上方，有一行显示当前标签页里每个币种系列及其合计，例如 **Coin: crowns ×2, pennies ×12 (worth 132 pennies)**。

- GM 用这些硬币向队伍收费和付款，赢下的战斗或掷出的宝藏也可能掉落硬币。付款从某一个角色的钱袋里出，没说是谁就从你的钱袋里出。
- 价格只用标价所用的那个币种系列支付，所以用盐标价就用盐付。先用最大的硬币；凑不出准确金额时，会拆开一枚较大的硬币，用较小的硬币找零。
- 钱袋付不起的价格会被拒绝，并告诉 GM。每次付款和收入都会显示一条通知。
- 规则集的某个变体可以去掉一种硬币。这时谁都不会用这种硬币付款或收款，以它标价的东西会按相同的价值，换算成剩下的硬币显示。

规则集还可以有市场，所以你能买到什么取决于你在哪里。

- GM 会说明一个场景所在的地方是哪里、有多大，用规则集自己的话说是小村还是城市。小地方卖的东西更少：稀有的东西可能只有在城镇才找得到，有些商人只在较大的地方开店，或者只为某些买家服务，例如只卖给信徒的礼拜堂。
- 你买东西时，Marinara 会根据物品的成本和这笔交易是便宜还是贵来算出价格，从买家的钱袋里扣钱，再把物品放进买家的背包。住宿、路费和其他服务只需付款。
- 这个地方、这个商人或这个钱袋无法完成的购买会被拒绝，并告诉 GM 原因。
- 规则集可以让同一个地方的每一天都不一样：一个地方的某种稀有物品可能只有寥寥几件，某个商人可能会拿出一些不寻常的东西，你也可以按价格的一定比例把东西卖回去，直到商人们花完他们一天能付出的钱为止。在同一个地方开始新的一天（队伍留下来时由 GM 开始），会重新补满货架和钱袋。

没有规则集的游戏，只要它的设定包带有货币和市场，同样会有。每个入门设定包都有，例如高奇幻里的铜币、银币和金币，武侠里的铜钱和银两，现代的美元和美分，以及赛博朋克和太空歌剧里的信用点。设定包的商店会列出日常物品，每样都有价格和出售它的最小地点，所以村子里有咖啡馆，但只有城镇才有急救包。你可以在设定包的 **Change its words**(修改用词) 里修改货币和商店，或者去掉货币。见[选择设定包](getting-started.md#choosing-a-setting-kit)。
