# Game Mode：队伍与 NPC

本指南介绍 Game Mode(游戏模式) 战役里的人：你的队伍成员，以及游戏主持人引入的 NPC(玩家之外的角色)。你会学到怎么打开队伍成员的人物卡、怎么编辑或重新生成人物卡，以及怎么查看冒险日志，其中也包括 NPC 的好感度标签。此外还会讲清楚两种游戏主持人模式。

Game Mode 是 Marinara Engine 的聊天模式之一。它是一款由 AI 游戏主持人主持的单人 RPG(角色扮演游戏)，游戏主持人常简称 GM。设置方法和基础玩法见 [Game Mode：入门](getting-started.md)。

## 队伍栏

队伍栏显示与你同行的角色，位置在游戏画面靠上的地方。

电脑上，它是横向排开的一行角色小头像。手机上则收起成单个头像。队伍不止一人时，这个头像会带一个数字角标，点一下就能打开队伍成员列表。队伍里只有一个人时，点头像会直接打开这名角色的人物卡。

队伍栏能做这些事：

1. 点击某个头像，打开这名角色的人物卡。
2. 把鼠标移到头像上（电脑端），会露出一个小小的 **X** 按钮。
3. 点击 **X**，把这名角色移出队伍。

GM 招募来的同伴都可以移除，不管是创建游戏时加入的，还是后来在剧情里加入的。你自己的用户角色是你操作的那个角色，它没有 **X** 按钮，所以没法把自己踢出队伍。

## 人物卡

人物卡是某位队伍成员在游戏里的属性摘要，和角色卡是两回事。它由 GM 根据角色本身和当前剧情写出来。

在队伍栏点击角色头像即可打开人物卡。有内容的部分才会显示出来：

- **Attributes**(属性)：跑团式的数值，比如 STR、DEX、CON，每项都带一个调整值。
- **Stats**(状态)：HP、MP 这类资源条。
- **Abilities**(能力)：这名角色会做的事。
- **Strengths**(优势) 和 **Weaknesses**(劣势)：两份简短列表。
- **Details**(详细信息)：Skills、Weapon、Faction 之类的补充信息。
- **Inventory**(物品栏)：角色随身携带的道具。
- **Traits**(特质)：其他自定义字段。

角色刚加入时，可能会看到“Character data will populate as the story progresses.”人物卡会随着游戏推进逐渐补全。

### 用 AI 重新生成人物卡

点击 **Regenerate Sheet**(重新生成人物卡)，让 AI 重写这名角色的人物卡。它会参考角色本身和当前的游戏上下文。剧情让一个角色变化很大之后，用这个功能很合适。

### 手动编辑人物卡

点击 **Edit Sheet**(编辑人物卡)，自己动手改。编辑模式下可以设置这些内容：

- **Sheet Details**(人物卡详情) 下面的 **Class**(职业) 和一段简短描述。
- **RPG Attributes**(RPG 属性)：打开 **Enable**(启用) 开关，就能记录 HP 这类资源池和各项属性。用 **Add Pool**(添加资源条) 添加一条资源条（名称、当前值、最大值和颜色）。用 **Add Attribute**(添加属性) 添加 STR 之类的数值。
- **Abilities**、**Strengths** 和 **Weaknesses**：用 **Add**(添加) 追加一行。
- **Details**：用 **Add Detail**(添加详情) 添加一条带标签的信息。

改完点击 **Save Sheet**(保存人物卡)。点击 **Cancel**(取消) 放弃修改。

### 规则集角色表

在[使用规则集的游戏](dice-and-skill-checks.md#games-that-use-a-ruleset)中，每个角色的面板以 **Ruleset sheet** 开始，布局由规则集决定。没有规则集时不显示这一块。

- **Resources** 显示生命、法术位或职业资源的当前值和上限。用加减按钮或直接输入数字修改。**Temp** 表示临时缓冲值。
- **Tracks** 是有范围限制的计数器，如力竭。
- **Wound tracks**(伤势轨道)用一排格子代替数值，适用于标记伤害而非计数的系统。每个格子显示该伤势等级的名称及其对掷骰的减值。如果规则集有多种伤害，先选择种类，再使用 **Mark**(标记) 或 **Clear one**(清除一个)。你也可以点击下一个空格添加标记，或点击最后一个已标记的格子清除一个；其他格子不响应点击。更严重的标记占据更高的格子，将较轻的标记向下挤。下方文字显示当前生效的惩罚，以及完全无法容纳到轨道内的部分。如果规则集这样规定，该惩罚会作用于掷骰：从骰池减去骰子，或加到求和掷骰上，骰子卡片会显示实际应用了多少。
- **Notes** 保存简短备注，如专注。
- **Conditions** 用于开关状态。
- 休息恢复规则集指定的内容。5e (SRD 5.1) 的长休恢复生命、法术位和一半生命骰，至少一颗。
- 下方汇总属性、受过训练的技能和豁免，以及护甲等级等选定数值。

GM 可以记录资源消耗、伤害、治疗、状态和休息，引擎会验证操作。没有可用法术位却施法等非法操作会被整体拒绝，并显示提示。

使用目录条目会支付全部费用，以及关联行的每个计数器的一次使用次数。法术位按条目指定的环级消耗；GM 可以要求更高环级，但引擎不会自行升环。缺少任何部分都会拒绝整个操作，不扣资源。戏法等免费行动只进行叙述。随等级变化的资源上限和随属性变化的使用次数在编辑时重新计算。

状态属于消息。切换回复变体或重新生成时，角色表恢复到该回合之前，避免重复扣除。**Edit sheet** 使用与角色卡相同的编辑器和目录修改配置、列表、训练和加值，也包含只读字段及用于新文本的 **Review**。**Save sheet** 只修改本局副本。另一个 **Edit Sheet** 按钮仍编辑通用角色表。包缺失或过旧时会显示警告，并阻止检定，直到恢复包。

## 招募和移除队伍成员

队伍里有谁，由 GM 随剧情推进决定，界面上没有手动的“添加同伴”按钮。GM 会根据场景里发生的事，在叙述中加入或移出队伍成员。

想自己赶走一位同伴，就用上面说的队伍栏 **X** 按钮。自己的用户角色不能用这种方式移除。

## 冒险日志

冒险日志是这场战役的流水记录。它由保存下来的游戏事件生成，不是 AI 写的，所以内容一定属实。

点击顶部工具栏的 **Session**(会话) 按钮，再选 **Journal**(日志) 选项卡，就会打开 Journal 面板，里面有这些选项卡：

- **Timeline**(时间线)：已经发生的事，比如发现的地点、遇到的 NPC、战斗结果、任务和道具事件。
- **NPCs**：你见过的 NPC，带头像和好感度标签（见下文）。
- **Map**(地图)：已探索地点的名称列表，只有名字。
- **Items**(道具)：获得、使用、丢失和移除道具的记录。
- **Library**(藏书)：GM 给你看过的世界内笔记和书籍，保存下来方便随时重读。
- **Notes**(笔记)：你自己的自由记事本。

### 玩家笔记

**Notes** 选项卡是你的私人记事本。左边输入，右边同步显示排版后的预览。记事本上方有一行说明，提醒你写的内容 GM 和队伍成员都看得到。也就是说，这里写的任何东西都可能影响剧情。

停止输入片刻后，笔记会自动保存。保存过程中会显示 **Saving...**，保存完成后显示 **Saved**。

## NPC 好感度标签

冒险日志的 **NPCs** 选项卡记录每个 NPC 对你的态度。列表里的每个 NPC 都有头像、名字和一个好感度标签。

好感度标签会随着你在剧情里的行为变化。一共七档，从好到坏依次是：

| 标签 | 含义 |
|---|---|
| **Devoted** | 对你死心塌地 |
| **Allied** | 坚实的盟友 |
| **Friendly** | 态度友好 |
| **Neutral** | 谈不上好恶 |
| **Unfriendly** | 态度不佳 |
| **Hostile** | 已经与你为敌 |
| **Enemy** | 处处与你作对 |

只有当 NPC 的好感度偏离初始值之后，标签才会出现。刚登场、好感度还没变过的 NPC 暂时不显示标签。

GM 描述过某个 NPC、给了它好感度，或者记下了一条关系备注，这个 NPC 就会出现在这个选项卡里。每一行 NPC 还提供这些操作：

- 上传或替换 NPC 的头像。
- 开启图像生成后，用 AI 生成头像。
- 把这个 NPC 从日志里删除。

## 游戏主持人模式

游戏由谁来主持，在设置向导的 **Party**(队伍) 这一步、**Game Master Mode**(游戏主持人模式) 下面选择。两个选项：

- **Standalone GM**：默认选项。Marinara 会替你搭一个 GM。向导里对它的描述是“A snarky narrator running the show”。不需要角色卡。
- **Character GM**：拿自己的一张角色卡当 GM。引擎会让模型一边扮演这个角色，一边主持游戏。想要某种特定的叙述口吻时选它。

第一次玩就用 **Standalone GM**。模式在创建游戏时设定。完整的设置流程见 [Game Mode：入门](getting-started.md)。
