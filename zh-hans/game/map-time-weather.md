# Game Mode：地图、时间与天气

用地图面板查看队伍在哪里，并移动队伍。本指南还会介绍记录队伍周围世界变化的那几套系统：日期与时间、天气、队伍士气。

## 地图面板

Game Mode(游戏模式) 会在游戏画面上显示一个地图面板，上面有当前地图名称、游戏天数，还有一个表示时段的天空图标。

- **在电脑上**，地图是一块嵌在页面里的面板，一眼就能看清。面板可以拖动，也可以锁定位置。可拖动面板的具体用法见 [Game Mode：HUD 小组件](hud-widgets.md)。
- **在手机上**，点 **Map**(地图) 打开面板。它的按钮一开始在左上角附近，可以在聊天里随意拖动。用 **Lock window**(锁定窗口) 把按钮固定在原位，用 **Close**(关闭) 回到这个按钮。位置会随聊天一起保存。手机上的地图使用你在 **Settings → Appearance → App**(设置 → 外观 → 应用) 里设置的聊天小组件样式，它的按钮也与三点 **Chat tools**(聊天工具) 菜单相互独立。

普通的 Classic(经典) 游戏使用这里介绍的场景地图。大地图、城镇和地下城地图属于 Overworld RPG(大地图 RPG) 游戏，而这类游戏目前还不可用（见 [Classic 还是 Overworld RPG](getting-started.md#classic-or-overworld-rpg)）。

### 网格视图与节点视图

用哪种视图由 Marinara 根据地图所示场所的类型决定，不需要手动切换。

- **grid**(网格) 视图用于地区、城市这类开阔区域。它显示按地形着色的方块：草地、森林、水域、山地、沙漠、雪原、城镇、道路和洞穴。
- **node**(节点) 视图用于地下城、室内这类封闭区域。它把各个地点画成圆圈，用线连起来。还没发现的地点显示一个问号。虚线是还没走过的路径，实线是已经走过的路径。

## 移动队伍

只能选择特定的地点。网格地图上，方块必须紧挨着队伍，而且已经发现过；节点地图上，节点必须与当前所在地点相连，或者已经发现过。点击其他方块和节点不会有任何反应。

1. 点击一个网格方块，或者在节点地图上点击一个节点。
2. 消息框上方会出现一个显示地点名称的 **Map position:**(地图位置) 小标签。
3. 输入消息并发送。Marinara 会在消息开头加上一小段文字，形如 `*moves to <place>*`。

要取消，点击 **Map position:** 小标签上的清除按钮（X）。它的提示文字是 **Clear destination**(清除目的地)。

手机上，先点一下节点选中它，再点底部的 **Set destination**(设为目的地)。标着 **You are here** 的节点就是当前所在位置。

如果没有成功，检查方块是否紧挨着队伍并且已经发现过，或者节点是否与你所在的地点相连。

### 缩放、切换和生成地图

- **缩放。**用右上角的 **Zoom in**(放大，加号) 和 **Zoom out**(缩小，减号)。缩放范围是 75% 到 180%，每次调整 25%。
- **切换地图。**游戏有不止一张地图或一个地区时，面板顶部会出现一个下拉菜单，用它可以查看别的地图。队伍所在的那张地图标着 **(Current)**。
- **生成地图。**点击左上角的魔杖按钮 **Generate another map**(另外生成一张地图)，用一张新地图替换当前地图。还没有地图的游戏会显示 **No map yet** 和一个 **Generate**(生成) 按钮，作用相同。

## 手动设定日期和时间

日期与时间控件在地图面板顶部，显示 **Day**(天数) 和一个数字，再加一个天空图标。

1. 点击 **Day** 控件。
2. 输入 1 到 9999 之间的天数。
3. 选一个时段：**Dawn**、**Morning**、**Afternoon**、**Evening**、**Night** 或 **Midnight**。
4. 点击别处或按 <kbd>Enter</kbd> 保存。

这属于手动覆盖，与自动时钟互不相干。时钟自己也可能显示 **Noon**，但 Noon 不在手动可选项里。

## 时间如何流逝

游戏时钟靠固定的算式推进，不经过 AI。每局新游戏都从第 1 天 08:00 开始。每个行动都会把时钟往前推：

| 行动 | 增加的时间 |
| --- | --- |
| 交谈 | 15 分钟 |
| 探索 | 30 分钟 |
| 一个战斗回合 | 5 分钟 |
| 一次短休息 | 1 小时 |
| 一次长休息 | 8 小时 |
| 赶路 | 2 小时 |

时钟越过午夜时，天数加一。

在有世界的游戏里，时间还会自己流逝：

- 大地图在前台、游戏正在等你行动时，现实中每五秒过去一分钟游戏时间。游戏主持人（GM）正在写回复时、你还没读完它的回复之前、场景视图在前台时，以及应用在后台时，都会暂停。
- 在大地图上行走，会过去这段路线所花的天数。
- GM 说过去了几天（一段旅程、一次长休息、一段等待）时，时钟会前进相应的天数。重新生成的回复不会再次推进时钟。如果新的讲述所花时间不同，就手动设定日期。

## 天气

游戏用固定的算式记录天气，不经过 AI。天气取决于生物群系（队伍所处的环境类型，比如沙漠、极地、海岸或山地）和季节。天气种类包括晴、多云、雨、暴风雨、雪、暴风雪、雾和沙暴。赶路和长休息时天气变化最频繁，探索时偶尔会变，其他情况下很少变。天气会影响 GM 描述每个场景时的气氛。

要在屏幕上看到天气，就在外观设置里开启 **Dynamic weather effects (rain, snow, fog, etc.)**(动态天气效果)。它默认是开启的。开启后，雨、雪、雾粒子会叠加显示在游戏画面上，并与当前天气和时段保持一致。见[外观设置](../appearance/appearance-settings.md)。

## 队伍士气

游戏会在后台记录一个 0 到 100 的队伍士气分数，分为五个等级，从低到高依次是 Broken、Low、Steady、High 和 Inspired。

打赢一场战斗、完成一个任务、找到宝藏都会让士气上升；打输、任务失败、失去同伴则会让它下降。时间一长，士气会慢慢回落到中间水平。士气不会显示成数字。它会影响 GM 描述队伍情绪时的笔调，但不会改变你的掷骰结果。

## 大地图与其他 Overworld RPG 地图

下面几节介绍 **Overworld RPG** 游戏，这类游戏目前还不可用。只有服务器开启了这项功能，这些内容才适用。

<a id="the-overworld"></a>

### 大地图

有生成世界的游戏（见[创建世界](getting-started.md#making-a-world)）会在**大地图**上打开：世界的地面以像素地图的形式画在叙述后面，有森林、丘陵、海岸和海洋，有连接各个聚落的道路和小径，每个聚落按其大小绘制，还有你的队伍。较大的地点会标出名字，你所在的地点也会标出。拖动地图可以四处查看。

1. 点按或点击一个聚落，或者从 **Places**(地点) 里选一个（最近的排在最前，并显示路程时间）。
2. 查看它的规模，以及从你所在位置出发的行程：要花几天或几小时，走哪些路。
3. 点击 **Walk there**(走过去)。队伍会沿着世界的通路、按最快的路线走过去，这段路的天数会立刻计入时钟。

你的下一回合会告诉 GM 你走到了哪里、花了多久、走了哪些路，好让它讲述抵达的情景。在下一回合之前再走一次，会从第一次走到的地方接着出发。

聚落外几步路远的洞穴、矿井、地穴和废墟，会画成**遗址**。新世界的每个地区都有一两处，以旁边的聚落命名（“Hollin Caves”、“Ashby Ruins”）。**Walk there** 会沿着通路走到它所属的聚落，再离开大路步行过去。到了遗址，**Enter**(进入) 会打开它的地图（见[地下城、洞穴和空间站](#dungeons-caves-and-stations)）。对剧情重要的遗址会保持**关闭**（画得较淡，不能前往，也不能进入），直到 GM 打开它。世界制作者也可以让遗址在那之前一直隐藏，或者一开始就开放。

处于废墟状态的地点会画成废墟。天黑后地图会变暗，窗户会亮起灯光。每个设定类别（奇幻、武侠、现代、1920 年代、科幻、废土）都有自己的地块。没有类别的设定包使用普通地块。

要切换视图，就在 **Game controls**(游戏控制) 里选 **Show the scene**(显示场景) 或 **Show the overworld**(显示大地图)；手机上这两项在三点 **Chat tools** 菜单里。游戏会记住你的选择。战斗和会话回放使用各自的界面。

### 地块包

地块包以像素行的形式保存调色板和每一种地块（各类地面、按规模区分的聚落、队伍，以及城镇的街道、屋顶和居民）。每个设定类别都有一个内置地块包。打开 **Agents**(智能体) 面板，找到 **Tile packs**(地块包)，就可以：

- 选择每个设定用哪个地块包绘制（**Built in**(内置) 是它自己的）；
- 用 **Import a tile pack**(导入地块包) 从 `.tilepack.json` 文件导入地块包；
- 用 **Export**(导出) 把地块包分享出去，或者用 **Remove**(移除) 删除它，用它绘制的设定会改回自己的地块。

地块包只需要包含它要改的地块，没包含的部分会画成普通样式。如果地块包里写了 Marinara 不会绘制的地块，其余部分照常保留，并说明哪些被略过了。

<a id="the-town"></a>

### 城镇

到了聚落，在大地图上选中它并选择 **Enter**，就能看到城镇。城镇是按照世界布置的：街道和广场、世界或剧情在其中设定的地点（名字写在各自的建筑上）、较大地方的会堂、这个地方以之闻名的行当的作坊，以及住宅。居民会出现在这个时辰该在的地方：白天在干活，黄昏在广场，夜里在家。

选中一栋建筑或广场，或者从 **Places in town**(城镇里的地点) 里选择，就能看到谁在那里，以及要走多少分钟。**Walk there** 会沿着街道穿过城镇，绕过建筑和手动布局画上的一切，走过它的桥。路上花的分钟数会计入时钟，你的下一回合会告诉 GM 队伍去了哪里、那里有谁。造访一个有名字的地点，例如剧情添加的一家旅店，它就会成为队伍当前所在的地点。**Leave town**(离开城镇) 会回到大地图。游戏会记住你之前在哪个视图。

城镇可以用 Pixelforge 之类的世界编辑器**手动布置**，作为世界手动编辑的一部分。

- 建筑可以移到别的地块上。移到另一栋建筑所在的地块会与它互换位置，而且每栋建筑都仍然面向街道。
- 地面上可以绘制街道、铺路、空地、树木或水井，但绝不会画在建筑下面、门前、广场中央或市场摊位下面。
- 谁住在哪里、在哪里工作永远不会变。走到被移动的建筑，路程从它的新门口开始计算。
- 不适合这座城镇的布局会被编辑器拒绝，并说明原因。剧情在游戏过程中添加的地点仍然能找到地块。
- 布局还可以把建筑放在地块之外，绘制田地、土路、带桥的水面和树篱，并摆放装饰。城镇视图会把它们全部画出来（装饰只有在图像包里有对应素材时才会显示）。

<a id="dungeons-caves-and-stations"></a>

### 地下城、洞穴和空间站

当剧情深入地下或登上飞船时，GM 可以打开一张**场所地图**：地下城、洞穴或空间站，画在场景上方。它是根据游戏和场所的名字布置的，所以同一个地方的房间总是一样，再回来时地图也保持原样。GM 会从十一种外观里挑一种：岩石、冰、水晶和熔岩洞穴；地穴、下水道和神殿；以及空间站的走廊、实验室、引擎甲板和水培舱。有对应这种外观的地块包时，地图就用它的美术；没有的话，就用普通颜色。

城镇里队伍可以下去的地方（按名字判断的洞穴、矿井、地穴、下水道或废墟，在科幻设定里则是废弃飞船或地堡），在队伍到达时会显示 **Go down**(下去)。

- 每次打开的都是同一张地图，离开时队伍会回到城镇里。
- 如果队伍正在另一张地图上，要先离开那一张。
- 一个地方也可以有用 Pixelforge 之类的世界编辑器手动制作的地图。这时 **Go down** 会打开那张地图，不管这个地方叫什么，并使用它指定的地块包绘制。在这样的地图上，出口就是队伍进来的地方，道具永远不会挡路，人物会在地图规定的时辰站在命名的位置上。GM 会得知谁在那里。

在地图上点击一个地方，或者用方向键，就能沿最短的路走过去。花的分钟数会计入时钟（大约每三十步一分钟），你的下一回合会告诉 GM 队伍从哪个区域走到了哪个区域。顶部的标签会显示当前所在的区域。**Game controls** 里的 **Show the scene** 和 **Show the map**(显示地图) 用来在场景和地图之间切换。

要离开，就走回出口（楼梯、梯子或舱口），然后选择 **Leave**(离开)。剧情离开这个地方时，GM 也可以结束地图。重新生成一个打开、走动或离开地图的回合，会把地图恢复到那个回合之前的样子。
