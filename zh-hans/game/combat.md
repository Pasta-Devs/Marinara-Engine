# Game Mode：战斗

本指南介绍 Marinara Engine 的 Game Mode 战斗。在设置向导的 **World**(世界) 步骤中，通过 **Combat Preference**(战斗偏好) 选择 **Classic**(菜单战斗) 或 **Tactical**(网格战斗)。AI Game Master(GM)设定遭遇并叙述结果，具体战斗行动由引擎结算。

<a id="tactical-battles-and-terrain"></a>

## 战术战斗与地形

战术战斗将队伍和敌人放在战场上。选择一个队伍单位，查看移动范围，选择目的地和行动，然后确认。敌方阶段开始前，每个队伍单位都可以行动。攻击预测会在确认前显示预期后果。

创建 Tactical 游戏时，可以选填战场种子、尺寸和给 GM 的地形指引。种子留空时自动生成。种子是 0 到 4294967295 之间的整数，0 也有效。当参战者、地形简述及其他生成输入相同时，它能复现棋盘；它不会强制 GM 生成同样的故事或敌人。

GM 提供场景环境、阵形和简短地形说明，引擎生成精确格子和初始位置。说明可以要求在地图中央或边缘附近设置地形区域和障碍。地形指引是给 GM 的请求，不保证每个词都变成一个格子。接受的战场会保存，因此刷新后恢复的是同一棋盘。

引擎会检查说明和生成布局，在保留请求地形的同时保证遭遇可达。如果约束无法同时满足，战斗会报告问题。**Use generated terrain**(使用生成地形) 会明确地在不采用被拒绝地形要素的情况下开始，而不是悄悄删除这些要素。目前还没有精确手绘地图或战场编辑器。

| 地形 | 步行 | 防御与闪避 |
| --- | --- | --- |
| 平原 | 消耗 1 移动力 | 无加成 |
| 森林 | 消耗 2 移动力 | 防御 +1，闪避 +15 个百分点 |
| 废墟 | 消耗 1 移动力 | 防御 +1，闪避 +10 个百分点 |
| 山地、水域、墙壁 | 阻止步行 | 无加成 |

已设定飞行或传送能力的单位可以采用不同的移动方式：

- **步行**沿可达地面格移动。敌方单位会挡路，不能在已被占用的格子结束移动。
- **飞行**可以跨越途中地形和单位，每格消耗 1 移动力，森林也不例外。飞行单位可以悬停在通常被阻挡的格子上，但不能停在其他单位所在处。
- **传送**忽略途中地形和单位。目的地必须在移动范围内、未被占用且可以步行，不能停在墙内、山地格或没有支撑的水面上。

这两种特殊移动都使用当前移动额度和格子的正交距离，并保留目的地的防御与闪避加成。这是简单的平面网格模型，不模拟高度、天花板、特定法术的消耗或视线要求。

战术战斗使用队伍阶段和敌方阶段，而非桌面规则中的个人先攻。阻挡移动的墙壁目前不会依据视线阻止远程攻击。掩体、桌面规则配置和完整召唤战斗属于各自独立的后续工作。

## 经典战斗

以下行动菜单和骰子计算章节介绍 Classic 战斗。所有队伍成员都会参与，但选定命令控制的是队伍中第一个仍存活的战斗成员，其他同伴自动行动。

## 发起遭遇战

战斗不由你主动发起。剧情需要打起来的时候，GM 就会开战，比如你激怒了敌人，或者一头撞进埋伏。这时叙述上方会弹出完整的战斗界面。队伍成员、敌人、双方属性以及各种特殊规则，都由引擎根据当前剧情自动组建。

战斗界面一侧是你的队伍，另一侧是敌人。每个战斗者都有一条生命条（HP，生命值），会用技能的还会有一条魔力条（MP，魔力值）。出手顺序显示在顶部，**Next:** 后面跟着下一个行动者的名字。回合计数显示为 **Round**(回合) 加当前回合数。

<a id="games-whose-ruleset-resolves-its-own-fights"></a>

### 由规则集自行结算战斗的游戏

规则集可以用自己的规则结算整场战斗，而不仅是向 Marinara 的战斗提供几个数值。这时，战斗界面也属于该规则集：菜单是角色自己的攻击和能力，采用自身的行动分配和状态，日志记录实际算式。所有结果一经生效就会写入人物卡。

这种战斗在一回合内能做什么也由规则集决定。一次打击可以同时附带多种伤害，各部分独立掷骰、抵抗和豁免，但整体仍算一次打击。消耗一次行动可以换来多次攻击；还有剩余次数时，菜单会提供不再消耗行动的攻击并显示余量，让你换一种攻击或在攻击之间移动。能力可以完全不花行动额度，也可以只在本回合再给你一次行动，或让你用回合内较小的行动额度疾走、撤离或躲藏。角色总会触发的效果，例如回合内首次有效命中的额外伤害，会自动添加并写入日志，无须选择。状态还可以让自身的豁免更难或更容易，将所有类型的伤害减半，阻止你攻击或接近施加者，或在施加者倒下的瞬间结束。

这类规则集还可以规定战场每格相当于多少自身距离单位，例如英尺、步数等。若有此声明，且游戏的 **Combat Preference**(战斗偏好) 为 **Tactical**(战术)，战斗就在生成的战场上进行，使用与上述战术战斗相同的棋盘、地形和部署。这些游戏的 **Combat Preference** 因而重新有了意义。未声明距离的规则集，以及设为 **Classic**(经典) 的游戏，仍然照旧作战，任何人都可以选中任何人为目标。

在这个战场上，一切都由规则集自身的数值决定。一回合能走多远取自自身的移动规则或生物的速度；武器的触及范围和射程取自对应行；能力区域成为真正的爆发、锥形或直线；墙会挡住射击；站在遮挡物后会按规则集规定增加防御；如果规则集规定了借机攻击的消耗，走出他人触及范围就会让对方攻击你。移动采用八个方向，每个方向都算一格，遵循这些规则原本面向的桌面网格玩法，与上面 Marinara 自身战术战斗的四方向模型不同。

战场会显示在屏幕上。每格都是独立按钮，因此可以用指针或方向键浏览棋盘，每格都会说明其类型、站着谁以及走到那里要花多少移动量。选择 **Move**(移动) 会点亮可达格子并以规则集的距离单位显示消耗；悬停或聚焦某格时会画出路径，路径上会引来攻击的格子以琥珀色标记，攻击者姓名列在棋盘下方。选择需要目标的行动时，可选目标会点亮，你既可以点击列表，也可以点击棋盘。攻击无法触及任何人时，会显示 **Nobody is in reach. Move closer.**(无人处于触及范围内。请靠近。)，而不会让你挥向空处。具有形状的效果瞄准格子：可瞄准的格子会点亮，指针下方的格子会显示波及对象，包括友军。移动可以拆在行动前后使用，因此菜单会带着剩余额度重新出现，下方 **Movement**(移动量) 面板则使用规则集自己的单位。Escape 会取消尚未完成的选择，把键盘操作返回菜单。

四分之三掩护、高低差、飞越障碍、躲藏、强制移动，以及是否攻击正在离开的对手，都是各自独立的后续工作。

<a id="games-that-use-a-ruleset"></a>

### 使用规则集的游戏

如果规则集允许战斗使用其[角色表](party-and-npcs.md#the-ruleset-sheet)，战斗会从当前资源和法术位开始。目录能力只有在 Marinara Engine 战斗系统能够执行时才转为战斗技能；非战斗条目、反应和不支持的费用会跳过。

生命按最大值比例传递：表中一半生命对应战斗中一半血条。结束后将生命比例写回，其他资源和法术位直接传递。战斗仍使用内置计算，不执行桌面规则的攻击、豁免或专注检定。删除发起战斗的消息不会写回任何结果。规则集没有战斗声明时，本页描述的机制保持不变。

## 行动菜单

轮到你行动时，从菜单里选一个行动。六个行动分别是：

- **Attack**(攻击)：用普通攻击打击一名敌人。
- **Skills**(技能)：使用特殊能力。技能可能消耗 MP。有的治疗队友，有的攻击敌人，有的施加增益或减益。
- **Special**(特殊行动)：用自己的话写一段自由行动，然后按 **Ask GM**(问 GM)。比如“我把沙子踢进遗迹守卫破裂的镜片里”。结果由 GM 判定。
- **Defend**(防御)：本回合剩余时间内提升防御，少受伤害。
- **Items**(道具)：使用包里的道具。选 **Full inventory** 可以直接在这里打开完整的物品栏。
- **Flee**(逃跑)：立刻脱离战斗。逃跑会当场结束战斗。

选定之后，这一回合就会结算。结果以浮动的伤害数字、变化的生命条和战斗日志里的文字呈现。

## 战斗数值怎么算

战斗一旦开始，每回合的结果都由固定的掷骰计算决定，与 AI 无关。GM 只负责把结果讲出来，谁命中、伤害多少都轮不到它决定。所以战斗是公平且稳定的。下文说的“d20”指掷一颗二十面骰，结果是 1 到 20 之间的数字。

### 先攻（出手顺序）

每回合开始时，所有战斗者各掷一次 d20，再加上由速度决定的加值。总值高的先出手。战斗者处于冻结、眩晕或禁锢状态，或者速度降到 0 时，整个回合都会被跳过。

### 攻击与防御

一名战斗者攻击另一名时：

1. 攻击方掷一次 d20，加上攻击属性带来的加值。
2. 防御方掷一次 d20，加上防御属性带来的加值。
3. 攻击方总值低于防御方总值时，攻击落空。
4. 骰面为自然 20，或者攻击方总值高出防御方 10 点以上时，打出暴击。

### 伤害

命中后，基础伤害由攻击方的攻击属性决定，并随等级上升。此外还会追加伤害骰，等级越高，追加的骰子越多。暴击会把总伤害乘以 1.5。最后由防御方的防御属性减伤，最多可以挡下防御数值的 40%。

### 难度缩放

最后一步按游戏的 Difficulty(难度) 缩放伤害，这个值在设置向导里选定。四档设置对最终伤害的倍率如下：

| Difficulty | 伤害倍率 |
|---|---|
| Casual | 0.6 |
| Normal | 1.0 |
| Hard | 1.3 |
| Brutal | 1.6 |

难度越高，双方打得越疼，战斗更短，也更凶险。

## 状态效果与元素反应

状态效果是对战斗者攻击、防御、速度或 HP 的临时改动。增益有利，减益有害。状态会持续固定的回合数，然后自动消失。中毒类效果每回合扣 HP，回复类效果则每回合恢复 HP。其中冻结、眩晕、禁锢这三种效果会让中招的战斗者跳过自己的回合。

有些攻击和技能带元素属性：Fire、Ice、Lightning、Poison、Holy、Shadow。第一个命中目标的元素会留下附着，也就是该元素残留的痕迹。之后另一种元素再打中同一个目标，就会触发元素反应。反应会追加额外伤害，通常还附带一个状态效果。

常见的反应有 Melt、Shatter、Overload、Superconduct、Toxic Blaze、Purification、Eclipse 和 Electrotoxin。这套机制自行运转，不需要开启，也没有配置项。只要合适的元素接连打在同一个目标上，反应就会自动发生。

## Boss 机制与战利品

强敌可以拥有 Boss 机制，也就是 GM 为这场战斗专门写的特殊规则。机制的触发方式可以是按节奏来，比如每隔几回合触发一次，也可以是 Boss 生命降到某个数值以下时触发。机制可以打击整支队伍、强化 Boss，或者施加一个状态效果。触发时效果会写进战斗日志，方便你及时应对。

打赢之后，敌人会掉落战利品。每件物品都有稀有度，从常见到罕见依次为：common、uncommon、rare、epic、legendary。难度越高，掉落越偏向稀有物品，数量也会略多一些。获胜时会出现 **Victory!** 横幅，队伍全灭则出现 **Defeat...** 横幅。

## 打断 GM

GM 还在写回复的时候，可以用 **Interrupt** 按钮插话。在真正发送之前，输入的内容都不会被提交。点击 **Interrupt** 会打开标题为 **Attempt to Interrupt?** 的确认窗口，里面有三个选项：

- **No**：取消，让 GM 继续写。
- **Force Interrupt**：干净利落地插话。GM 不会知道你打断过，输入框会变成绿色边框。
- **Yes**：尝试在剧情内打断，GM 有可能抵抗。输入框变红，应用会提示“using dice recommended”，同时骰子按钮开始闪动。这时掷骰子有助于打断成功。

确认之后，写好消息发送即可。如果改主意了，按 **Resume**(继续) 就能撤掉待处理的打断，让叙述继续。这个控件在紧张桥段特别好用，比如想在开打前的一瞬间抢先反应。

## 快速反应事件

GM 可以触发快速反应事件浮层，也叫 QTE，用于闪避、追逐这类节奏很快的动作场面。浮层上有一条不断缩短的倒计时条、一句 **React quickly!** 提示，以及每个选项对应的一个按钮。按钮都有编号（1、2、3，依此类推）。点击想要执行的那个行动的按钮。

在倒计时结束前选好行动可以拿到加成，反应越快，加成越大。倒计时先走完，则会吃到惩罚。快速反应事件不掷骰子，比的纯粹是速度。

## 手机上的战斗

在手机上，战斗界面会重新排布以适应小屏幕。行动按钮固定在屏幕底部。正文里放不下的内容会收进一个从下方滑出的面板，里面有四个选项卡：

- **Party**(队伍)：队伍成员及其生命值。
- **Boss Mechanics**(Boss 机制)：当前战斗的特殊规则。
- **Dialogue**(对白)：战斗者说出的台词。
- **Combat Log**(战斗日志)：逐回合的战况记录。

点选项卡即可打开对应面板。关闭时点面板外侧，或者点关闭按钮。
