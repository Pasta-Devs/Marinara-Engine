# Game Mode：战斗

Game Mode(游戏模式) 的战斗分两种：**Turn-Based**(回合制) 菜单战斗和 **Tactical**(网格战斗)。在设置向导的 **World**(世界) 步骤里，用 **Combat Preference**(战斗偏好) 在两者之间选择。之后想改，打开 **Chat Settings**(聊天设置)，展开 **Combat Style**(战斗风格)，选择一个 **Battle system**(战斗系统)。自行结算战斗的规则集可能会限制可选项。游戏主持人（GM，也就是主持游戏的 AI）设定遭遇并叙述结果。Marinara 用固定的掷骰计算结算战斗行动，所以谁命中永远不由 AI 决定。

## 发起遭遇战

战斗不由你主动发起。剧情需要打起来的时候，GM 就会开战，比如你激怒了敌人，或者一头撞进埋伏。这时叙述上方会打开完整的战斗界面，内容根据当前剧情组建：你的队伍、敌人、双方属性以及各种特殊规则。

界面一侧是你的队伍，另一侧是敌人。每个战斗者都有一条生命条（HP，生命值），会用技能的还有一条魔力条（MP，魔力值）。顶部显示 **Next:** 和下一个行动者的名字，以及 **Round**(回合) 和当前回合数。

战斗如何结算取决于游戏的角色系统。所有新游戏都采用 **MRPG** 职业：每名战斗者使用所属职业的属性、技能和装备战斗（见 [MRPG 游戏中的战斗](#battles-in-an-mrpg-game)）。在 MRPG 职业推出前创建的 **Legacy** 游戏使用[战斗数值怎么算](#how-combat-math-works)中的旧版攻击与防御规则。下文的界面和按钮对两者都一样。

> **注意：** 如果游戏使用的规则集自行结算战斗，例如 5e (SRD 5.1)，战斗就按规则集进行，而不是按本页。见[按规则集战斗](fighting-on-a-ruleset.md)。只把人物卡借给战斗使用的规则集，战斗仍按本页进行。见[战斗中会发生什么](rulesets.md#what-happens-in-battles)。

## 进行 Turn-Based 战斗

Turn-Based 战斗没有棋盘。所有队伍成员都会参战。你只为一个角色选择行动，也就是队伍中第一个仍存活的成员。其他同伴自行行动。

轮到你时，选择一个行动：

| 行动 | 作用 |
| --- | --- |
| **Attack**(攻击) | 用普通攻击打击一名敌人。 |
| **Skills**(技能) | 使用特殊能力。技能可能消耗 MP。有的治疗队友，有的攻击敌人，有的施加增益或减益。 |
| **Special**(特殊行动) | 用自己的话写一段自由行动，然后按 **Ask GM**(问 GM)，比如“我把沙子踢进遗迹守卫破裂的镜片里”。结果由 GM 判定。 |
| **Defend**(防御) | 在本回合剩余时间内提升防御，少受伤害。 |
| **Items**(道具) | 使用包里的道具。**Full inventory**(完整物品栏) 会打开你的全部道具列表。 |
| **Flee**(逃跑) | 立刻脱离战斗。逃跑总会成功，并当场结束战斗。 |

选定之后，这一回合就会结算。结果以浮动的伤害数字、变化的生命条和 **Combat Log**(战斗日志) 里的文字呈现。获胜时出现 **Victory!** 横幅，队伍全灭则出现 **Defeat...** 横幅。

在使用规则集的游戏里，规则集自己的道具在 **Items** 中按规则集的规定生效：治疗或伤害多少，以及施加哪些状态。带充能的道具在还有使用次数时才会提供。需要先过检定的道具会先掷骰，失败的话道具就白白耗掉。规则集没有给出用途的道具不会提供。其余道具按 GM 在开战时的判定生效，除非规则集关闭了 Game Mode 自带的道具。

## 进行 Tactical 战斗

Tactical 战斗把你的队伍和敌人放到网格战场上。战场由一个个方格组成，每格是一种地块，比如 **Plains**(平原) 或 **Forest**(森林)。

1. 轮到你时（显示 **Player Phase**(玩家阶段)，或者某个单位的名字后面显示“'s turn”），在网格上点击你的一个单位。棋盘上会显示它的移动范围。
2. 点击目的地格，再点击 **Confirm Move**(确认移动)。想重新选，点击 **Reset Move**(重置移动)。
3. 移动之后，棋盘会提示“Already moved — choose an action.”选择 **Attack**、**Defend** 或 **Item**(道具)。**Flee** 也在这里。
4. 选 **Attack** 时，棋盘会显示 **Select an enemy**，点击一个敌人。攻击预测会显示预期结果。点击 **Confirm**(确认) 执行。**← Back**(返回) 会退回上一步。
5. 完成后点击 **End Turn**(结束回合)。在先队伍后敌人的行动顺序下，接着进行 **Enemy Phase**(敌方阶段)。

如果棋盘显示 **Resolving…**，稍等片刻。**Restart**(重新开始) 会在你确认后，在同一个战场上从头重新开始这场战斗。

谁在什么时候行动，取决于 **Turn order**(行动顺序)。见[行动顺序](#turn-order)。手绘棋盘和地形规则见[战术战斗与地形](#tactical-battles-and-terrain)。

## MRPG 游戏中的战斗

采用 MRPG 职业的游戏里，每位队伍成员都使用当前职业战斗，包括它的属性、技能和人物卡上的装备（见 [MRPG 职业](mrpg-classes.md)）。对手按级别战斗：minion、standard、elite 或 boss。战斗旁边的面板会显示接下来由谁行动、每名战斗者的职业、等级、排位和资源，并在结束时显示队伍获得的东西。

<a id="turns-skills-and-resources"></a>

### 回合、技能与资源

- **行动顺序。** 不掷先攻。战斗者在时间轴上行动，每次行动都会把自己的下个回合往后推；速度越高，推后的幅度越小，所以行动越频繁。
- **技能。** **Skills** 会列出当前职业的技能和携带的技能，每项都显示消耗和预计效果。魔法技能消耗 **MP**，战斗期间不会恢复。其余技能消耗 **Stamina**，每回合会恢复少量。
- **Defend**：在战斗者下个回合前把 Defense 提高一半，并恢复更多 Stamina。
- **弹药与元素。** Marksman 可以在战斗旁边的面板里装填一种弹药，Channeler 可以引导一种元素。更换两者都不消耗行动。没有手动选择时，AI 会为目标挑选最佳选项。

<a id="hitting-and-damage"></a>

### 命中与伤害

- **命中率**随攻击方的 Skill 和 Luck 提高，随目标的 Speed 和 Luck 降低，最低不会低于 25%。
- **暴击**由攻击方的 Skill 对抗目标的 Luck 决定，造成双倍伤害。
- **伤害。** 武器攻击造成 Strength 加攻击威力的伤害，再减去目标的 Defense。法术，或使用法杖、魔杖或法器的攻击，则以 Magic 对抗 Resistance。威力会随等级略微增长，相当于装备逐渐变好。
- **伤害类型。** 每次命中都有一种类型：武器是斩击、穿刺或钝击；元素包括火、冰、雷、风、木、土、水或金；此外还有光明或黑暗。敌人可能弱于某种类型（多受一半伤害）、抵抗它（伤害减半）、免疫它或吸收它。一次命中发现某项弱点或抗性后，它就会显示在敌人身上，队伍也会记住该类敌人的这项信息。敌人的元素弱点遵循五行相克循环，每种元素克制下一种：木克土、土克水、水克火、火克金、金克木。

<a id="rows"></a>

### 排位

Turn-Based 战斗中，双方各有前排和后排。近战攻击命中后排时，双方都只造成一半伤害；远程攻击和法术攻击任一排都造成完整伤害。某一方前排无人时，后排就会变成前排。每个职业都有默认排位，也可以在角色人物卡的 **Status**(状态) 选项卡上修改。Tactical 战斗没有排位，能否攻击到对方取决于棋盘上的位置。

<a id="taunts-yielding-and-taming"></a>

### 挑衅、投降与驯服

- **Provoke**：Sentinel 的 Provoke 会让所有敌人在 2 个回合内以 Sentinel 为目标。在棋盘上，无法靠近 Sentinel 的敌人会尽可能接近，并改为做好准备。
- **投降。** 有智慧的敌人在败势中可能投降或逃跑。只剩已经投降的敌人时，战斗会让你选择 **Spare them**(饶了他们) 或 **Finish them**(解决他们)。无论选哪项，队伍都会获得战利品和经验。携带宝物的敌人若逃走，也会带走它的宝物。
- **驯服。** Tracker 可以驯服 HP 低于 30% 的野兽。它会离开战斗并成为同伴，即使随后战败也会保留。

<a id="after-the-fight"></a>

### 战斗结束后

获胜会给所有参战角色经验（见[等级与经验](mrpg-classes.md#levels-and-experience)），结束面板会显示每次升级、提高的属性，以及现在可以进行的晋升。战败或逃跑不提供经验。开启 **Permadeath**(永久死亡) 后，战斗结束时仍倒下的队伍成员会永远离队。

在 MRPG 游戏中，**Difficulty**(难度) 决定敌人的数量和强度，而不是让它们的伤害乘上倍率。在 **Brutal** 难度下，敌人可能比队伍高出好几级。

## 打断 GM

GM 还在写的时候，可以用 **Interrupt**(打断) 按钮插话。在你发送之前，输入的内容都不会提交。

1. 点击 **Interrupt**。会打开一个标题为 **Attempt to Interrupt?** 的窗口。
2. 选择一项：
   - **No**(否) 会取消，让 GM 继续写。
   - **Force Interrupt**(强制打断) 会干净利落地插话。GM 不会得知你打断过。输入框会出现绿色边框。
   - **Yes**(是) 会尝试在剧情内打断，GM 可能会抵抗。输入框变红，应用会提示“using dice recommended”，同时骰子按钮开始闪动。掷骰会有帮助。
3. 写好消息并发送。

如果改了主意，按 **Resume**(继续)。它会撤掉待处理的打断，叙述照常继续。

## 快速反应事件

GM 可以为闪避、追逐这类节奏很快的场面触发快速反应事件（QTE）。浮层上有一条不断缩短的倒计时条、一句 **React quickly!** 提示，以及每个选项对应的一个带编号的按钮。在倒计时结束前点击想要的行动，就能拿到加成。反应越快，加成越大。如果时间耗尽，则会吃到惩罚。QTE 不掷骰子。

如果使用屏幕阅读器，或者想不限时游玩，可以在向导的 **Features**(功能) 步骤里关闭 **Quick Time Events**(快速反应事件)，把 QTE 关掉。

## 手机上的战斗

在手机上，行动按钮固定在屏幕底部。放不下的面板会收进一个从下方滑出的抽屉，里面有四个选项卡：**Party**(队伍，成员和生命值)、**Boss Mechanics**(Boss 机制，本场战斗的特殊规则)、**Dialogue**(对白，战斗者说出的台词) 和 **Combat Log**(逐回合的战况记录)。点选项卡打开对应的抽屉。点抽屉外侧或它的关闭按钮即可关闭。

<a id="how-combat-math-works"></a>

## 战斗数值怎么算

本节规则适用于 **Legacy** 游戏，以及规则集把人物卡借给 Marinara 战斗使用的游戏。采用 **MRPG** 职业的游戏（也就是所有新游戏）改用 [MRPG 游戏中的战斗](#battles-in-an-mrpg-game)中的规则。

每个回合都由固定的掷骰计算决定，而不是由 AI 决定。这让战斗公平且稳定。d20 是一颗二十面骰（1 到 20）。Tactical 战斗还要见[行动顺序](#turn-order)和[视线、掩护和高度](#sight-cover-and-height)。

**先攻。** 每回合开始时，所有战斗者各掷一次 d20，再加上由速度决定的加值（速度除以 5，向下取整）。总值高的先行动。战斗者处于冻结、眩晕或禁锢状态，或者速度降到 0 时，会跳过这一回合。

**攻击与防御。** 一名战斗者攻击另一名时：

1. 攻击方掷一次 d20，加上攻击属性带来的加值。
2. 防御方掷一次 d20，加上防御属性带来的加值。
3. 攻击方总值较低时，攻击落空。
4. 骰面为自然 20，或者攻击方总值高出防御方 10 点或以上时，打出暴击。

**伤害。** 命中后，基础伤害来自攻击方的攻击属性，并随等级增长。另外还会追加若干颗 d6，等级越高的战斗者掷得越多。暴击会把总伤害乘以 1.5。随后防御方的防御属性会从这次伤害中挡下最多相当于自身数值 40% 的部分。

<a id="difficulty-scaling"></a>

### 难度缩放

在 Legacy 游戏中，伤害接下来会按你在设置向导里设定的 **Difficulty** 缩放。天气和状态效果的修正随后才生效。这个倍率只作用于敌人的攻击，所以难度越高，敌人打得越疼，而你的队伍造成的伤害保持不变。

| 难度 | 敌人伤害倍率 |
| --- | --- |
| Casual | 0.6 |
| Normal | 1.0 |
| Hard | 1.3 |
| Brutal | 1.6 |

这些倍率属于 Marinara 自己的规则。规则集会提供自己的难度策略。

## 状态效果与元素反应

本节介绍 Legacy 战斗。MRPG 游戏有自己的伤害类型（见[命中与伤害](#hitting-and-damage)）；其技能造成的 Poisoned、Asleep 或 Slowed 等效果会在各项技能的说明中写明。

状态效果是对战斗者攻击、防御、速度或 HP 的临时改动。增益有利，减益有害。状态会持续固定的回合数，然后消失。中毒类效果每回合扣 HP，再生类效果每回合恢复 HP。冻结、眩晕和禁锢会让战斗者跳过自己的回合。

有些攻击和技能带有元素。第一个命中目标的元素会留下附着，也就是一道残留的痕迹。另一种元素再打中同一个目标，就会触发元素反应，追加额外伤害，通常还附带一个状态效果。反应包括 Melt、Shatter、Overload、Superconduct、Toxic Blaze、Purification、Eclipse 和 Electrotoxin。它们会自动发生，不需要你开启。

### 元素

有哪些元素由设定决定：

- 没有设定包，或设定包没有指定元素：经典的六种（火、冰、雷、毒、圣、暗）。
- 武侠：五行（木、火、土、金、水），依次相克。
- 赛博朋克和太空歌剧：动能、热能、电磁，以及化学或等离子。
- 现代和 1920 年代：没有元素。

开阔地上的雨和风暴会削弱类似火的元素，增强类似雷的元素。在战术战斗中，元素打它克制的元素时伤害更高，打克制它的元素时伤害更低。你可以在 **Change its words**(修改用词) 里修改设定包的元素和反应。见[选择设定包](getting-started.md#choosing-a-setting-kit)。

## Boss 机制与战利品

强敌可以有 Boss 机制，也就是 GM 为这场战斗专门写的特殊规则。机制按节奏触发，比如每隔几回合一次，或者在 Boss 生命降到某个数值以下时触发。它可以打击整支队伍、强化 Boss，或者施加一个状态效果。机制触发时，**Combat Log** 会显示出来，方便你应对。

打赢之后，敌人会掉落战利品，直接进入队伍的背包。物品有稀有度，从 common 到 uncommon、rare、epic 和 legendary。难度越高，掉落越偏向稀有物品，数量也略多一些。一条通知会说明掉了什么，GM 也会得知这些东西已经在你的背包里。

掉什么取决于你的设定。带设定包的游戏掉落设定包自己的战利品（现代游戏会掉礼品卡或急救包，绝不会掉附魔剑），这些用词可以在 **Change its words** 里修改。没有设定包的游戏掉落它的类型常见的东西。没有入门设定包的类型，例如 Steampunk，会掉落不属于任何设定的普通物品。如果游戏的规则集有自己的战利品表，敌人改为掉落规则集的物品；关闭了 Game Mode 自带道具的规则集只掉落它自己的物品。

## 参考：战术战斗

<a id="tactical-battles-and-terrain"></a>

### 战术战斗与地形

创建游戏时，没有需要填写的战场设置。每场战斗都有自己的棋盘，根据一个新的种子和 GM 为该场景提供的简述生成。GM 提供环境、阵形和一段简短的地形简述，简述可以要求在中央或边缘附近设置地形区域和障碍。Marinara 生成精确的地块和初始位置。被接受的战场会保存下来，所以刷新后恢复的还是那张棋盘。

Marinara 会检查简述和布局，在保留所要求地形的同时，保证遭遇可达。

如果这些约束无法同时满足，战斗会报告问题。这时 **Use generated terrain**(使用生成地形) 会在不采用被拒绝地形要素的情况下开始战斗。它绝不会悄悄删掉这些要素。

世界还可以有手绘战场：用 Pixelforge 之类的世界编辑器，为世界中的某个地点一格一格画出来的棋盘。在那个地点或它内部开战时，战斗会使用其中一张棋盘，而不是生成一张。

- 棋盘完全按绘制的样子使用。如果这个地点有好几张，由战斗的种子（一个用来挑选的数字）决定用哪张。
- 这时不使用 GM 的地形简述，但它的阵形仍然决定双方从哪里开始。GM 会得知这张棋盘是为这个地点制作的。
- 手绘棋盘必须遵守三条规则：它是三种棋盘尺寸之一；两侧各两列是平原，双方在那里列阵；战斗者能站立的每一格都与其余部分连通。违反规则的棋盘会被制作工具拒绝，并说明原因。

这些棋盘与世界的手动编辑保存在一起，所以会随世界文件、地图包和世界库一起带走。

| 地形 | 步行 | 防御与闪避 |
| --- | --- | --- |
| 平原 | 消耗 1 点移动力 | 无加成 |
| 森林 | 消耗 2 点移动力 | 防御 +1，闪避 +15 个百分点 |
| 废墟 | 消耗 1 点移动力 | 防御 +1，闪避 +10 个百分点 |
| 山地、水域、墙壁 | 无法步行通过 | 无加成 |

已设定飞行或传送能力的单位，移动方式不同：

- **步行**沿可达的地面格移动。敌方单位会挡路，单位也不能在已被占用的格子结束移动。
- **飞行**可以越过地形和单位，每格消耗 1 点移动力，森林也一样。飞行单位可以悬停在原本无法通行的格子上，但不能停在其他单位所在的格子。
- **传送**无视途中的地形和单位。目的地必须在移动范围内、未被占用且可以步行。传送不能停在墙里、山地上或没有支撑的水面上。

这两种特殊移动都使用当前的移动额度，并按正交（不算斜向）格距计算距离。它们保留目的地地形的防御与闪避加成，并忽略高度。飞行者的飞行高度、天花板、特定法术的消耗和特定法术的视线要求都没有模拟。Marinara 自身的战斗目前还不支持召唤。

<a id="turn-order"></a>

### 行动顺序

Tactical 战斗的回合有两种进行方式：

- **One at a time, by initiative**(按先攻逐个行动)：每个单位在掷出的顺序里都有一个位置，只有轮到的那个单位可以行动。棋盘上会显示行动顺序。新的 Overworld 游戏使用这种方式。
- **Your whole party, then the enemies**(先是你的整支队伍，再轮到敌人)：每个队伍单位都可以行动，然后进行敌方阶段。VN 游戏使用这种方式。

要修改它，打开 **Chat Settings**，展开 **Combat Style**，选择一个 **Turn order**。只要 **Battle system** 是 Tactical，这一项就会出现，除非游戏的规则集自行结算战斗。修改从下一场战斗开始生效。正在进行的战斗保持原来的顺序。

<a id="sight-cover-and-height"></a>

### 视线、掩护和高度

- **视线。** 墙和山会遮挡视线。单位只能对看得见的目标攻击、使用技能或使用道具。
- **掩护。** 攻击者和目标之间有东西时，目标就受到保护。中间隔着森林或废墟格，或者有墙或山挡住部分视线，算半掩护。墙或山挡住大部分视线，算四分之三掩护。半掩护让命中率降低 15 个百分点，四分之三掩护降低 30 个百分点。目标自己所在格的加成和它的掩护不叠加，取较好的那一个。
- **高度。** 在有山的棋盘上，山高两级，山周围的地面高一级。往上走一级多花 1 点移动力，往下走不花移动力。高差两级或以上就是悬崖，谁都走不过去。较高的地面也会挡住两个较低格子之间的视线。从高处往下攻击，命中率加 10；从高处发起的远程攻击射程多 1 格；森林这类低矮掩护无法挡住来自上方的视线。手绘战场可以有自己的悬崖。

### 战场场景

战术棋盘会按照战斗发生的地点来布置：森林里有可以藏身的树木，地下城有墙壁和走廊，城市有街道。带设定包的游戏会用自己的用词命名自己的场景，所以赛博朋克的战斗发生在屋顶或巨型公寓楼的走廊里，武侠的战斗发生在竹林或茶馆里。棋盘的地块也使用设定的用词（掩体和瓦砾，而不是森林和废墟）。你可以在 **Change its words** 里修改设定包的场景和地块用词。
