# Game Mode：按规则集战斗

有些规则集（如 5e (SRD 5.1)）会用自身规则结算整场战斗，而不只是向 Marinara 的战斗系统提供几个数值。本指南介绍这类战斗是什么样子，以及怎么进行你的回合。采用 Marinara 自身规则的游戏，见 [Game Mode：战斗](combat.md)。要选择规则集，见[使用规则集游玩](rulesets.md)。

这类战斗不由你发起。和任何游戏一样，游戏主持人（GM）会在剧情需要时发起战斗。Marinara 根据队伍的人物卡和规则集的生物构建战斗，也可以采用 GM 用规则集术语描述的对手。

## 战斗界面

这个界面属于规则集自身：

- **菜单**列出角色的攻击和能力。每一项都会说明它要消耗规则集的行动分配（每回合能做什么）和资源池（法术位之类的储备）中的哪些部分。
- **下方面板**显示回合顺序、当前是第几轮、按规则集名称标示的每个人的状态，以及各项额度的余量。
- **日志**会打印真实的算式，例如“Juno attacks Rust jackal with Road axe: 8 (5 + 3) + 3 = 11 against Guard 6, a hit.”

每个行动生效时都会写入人物卡。中途关闭标签页不会丢失任何东西，之后 GM 也会得知数值已经结算。

## 进行你的回合

1. 查看日志和面板，了解当前轮次、行动顺序和你的额度。
2. 从菜单里选一个攻击或能力。
3. 如果需要目标，就在列表里选一个。在战场上也可以直接在棋盘上点击目标。
4. 看日志里的那一行，了解发生了什么。
5. 没有可做的事了，或者想跳过时，选择 **Pass**(跳过)。

如果没法行动，可能是某个行动被有意从菜单里去掉了。检查以下几点：

- 它的消耗超过了你的余量。看看面板里的额度（每个资源池和行动还剩多少）。
- 它超出了某种资源的每回合上限。下一回合它会重新出现。
- 它是挣脱的手段，只有在有东西抓住你时才会显示。
- 它需要目标，但触及范围内没有人。菜单会显示 **Nobody is in reach. Move closer.** 见[在战场上](#on-a-battlefield)。

规则集有这些分组时，菜单会把选项归在以下标题下：

| 分组 | 内容 |
| --- | --- |
| **Attacks**(攻击)、**Abilities**(能力)、**Items**(物品) | 你的攻击、能力和物品。 |
| **Standard actions**(标准行动) | 规则集的通用行动。 |
| **Stat block actions**(数据块行动) | 生物数据块里列出的行动。 |
| **Contests**(对抗) | 擒抱、推撞和挣脱（见[对抗](#contests)）。 |
| **Movement**(移动) | 在战场上行走（见[在战场上](#on-a-battlefield)）。 |
| **Spend symbols**(花费符号) | 在符号骰规则集里，剩余符号能换来什么。 |
| **Reload**(装填)、**Switches**(开关) | 装填，以及规则集定义的开关。 |
| **End of turn**(回合结束) | 结束你的回合。 |

## 一个回合能做什么

一个回合能做什么由规则集决定。

- 一次打击可以同时附带多种伤害。各部分独立掷骰、抵抗和豁免，但整体仍算一次打击。
- 消耗一次行动可以换来多次攻击。还有剩余次数时，菜单会免费提供它们并显示还剩几次，让你可以再挥一次、换用别的东西，或在攻击之间移动。
- 能力可以完全不花消耗，可以只在本回合再给你一次行动，也可以让你用回合中较小的一部分来疾走、撤离或躲藏。
- 角色总会触发的效果，例如回合内首次有效命中的额外伤害，会自动加上，并在日志里写明。

## 状态

状态是作用在战斗者身上的持续效果。视规则集而定，它可以让你的豁免（抵抗某种效果的掷骰）更难或更容易，把所有类型的伤害减半，阻止你攻击施加者或向施加者靠近，或在施加者倒下时结束。状态也可以改变数值：提高你的防御，给你的攻击、豁免和对抗加骰或减骰，或者让你变慢。日志会把每一项写在它所改变的那次掷骰旁边，菜单显示的几率也会把它算进去。有些状态持续到你下一个回合开始，或者只持续到与它有关的下一次攻击或豁免为止。规则集还可以在你的人物卡上用一条轨道记录力竭之类的东西，只要它还在，每一级都会让情况更糟一些。

## 使用骰池的规则集

检定时掷一把骰子、统计达到目标值的骰子数的规则集，也以同样的方式战斗。

- **攻击。**攻击会掷出你的骰池，需要一定数量的成功才能命中，最少一个。每多出一个成功，伤害就多一颗骰子。伤害同样用骰子掷出。
- **吸收。**目标可以按伤害类型吸收一部分伤害。吸收是一种防御：要么掷骰，每颗骰子抵消 1 点；要么在掷伤害之前先去掉一些骰子。剩下的就记为对方的伤势。
- **惩罚与状态。**你的伤势惩罚会像减少检定骰一样减少你的骰池，状态则会增加或减少骰子。豁免和对抗也用骰池。
- **日志**会写明投入了多少颗骰子、需要达到多少、得到几个成功，以及吸收抵消了多少。
- **先攻与上限。**这类规则集可以每轮重新掷先攻，也可以限制你一回合内能花掉多少某种资源。

有些骰池规则集把先攻保留为整场战斗通用、会被攻击改变的一个数值。每次攻击都由你决定怎么打：要么从目标的数值里拿走一部分归自己，而不伤害对方；要么把自己的数值当作伤害骰花掉。花掉数值的攻击命中后，你的数值会重置。没命中则按规则集规定扣掉相应的数值。数值跌到规则集崩溃线（规则集为这个数值设的下限）的人就崩溃了，恢复之前不能再花。每轮的顺序跟随这些数值变化，每个人的数值都显示在生命值旁边。

采用叙事符号骰的规则集（如 Genesys 风格系统）也用这类骰子战斗。攻击时，用你的骰子对抗目标的难度骰，符号像检定时一样相互抵消，剩余符号决定是否命中。剩余符号能换来什么由规则集规定，因此无须询问 GM。

## 对抗

规则集可以允许战斗中的任何人发起对抗：一次与对手比拼的掷骰。你可以擒抱某人、把对方推倒或推开，或者挣脱擒抱。双方各自掷骰并加上自己的数值，总值高者胜出，菜单会在你选择之前显示你获胜的几率。

- 擒抱成功会把对手固定在原地，直到对方挣脱或你倒下。失败则什么也不会发生。
- 只有在有东西抓住你时，菜单上才会出现挣脱，而且只针对正在抓住你的那个人。
- 推开只会在战场上移动对方，遇到墙或挡路的人就会停下。

## 应对别人的行动

有些能力不是在你自己的回合里使用，而是回应其他战斗者的举动。在以下时刻，战斗会暂停，菜单会在 **Pass** 旁边提供你的回应：

- 对手即将使用某个东西；
- 有东西瞄准了你；
- 一次攻击刚刚命中你；或者
- 有东西刚刚伤害了你，

前提是你手里有针对这一时刻的回应。命中之后，日志会写明这次攻击掷出了多少、以什么为对抗目标，让你看清像 Shield 这样的回应能不能让它落空。如果你使用回应，会用同一次掷骰再检查一次，日志会写明它是否仍然命中。

对手也可以回应，用他们自己的招架。反制可以在对手的能力生效之前将其阻止，无论那个能力瞄准的是谁，只要对手在反制的触及范围内即可。规则集可以规定它只回应某些类型的能力，例如法术。被阻止的能力所花的消耗仍然会扣除，而反制本身无法被任何东西回应。

## 在战场上

规则集可以规定战场上一格相当于它自身多少距离，单位可以是英尺、步数或它自己的单位。若有此规定，且游戏的 **Combat Preference**(战斗偏好) 为 **Tactical**(网格战斗)，战斗就在战场上进行：使用与 Marinara 自身的[战术战斗](combat.md#tactical-battles-and-terrain)相同的棋盘（为这个地点生成或手工制作的）、地形和部署。没有规定距离的规则集，以及设为 **Classic**(菜单战斗) 的游戏，作战时不使用位置，任何人都可以把任何人选为目标。

在战场上，一切都由规则集自身的数值决定：

- 一回合能走多远，取自规则集的移动规则或生物的速度。
- 武器的触及范围和射程，取自它自己的那几行数据。
- 能力的区域会成为真正的爆发、锥形或直线，墙会挡住射击。
- 站在遮挡物后面，会获得规则集规定的掩护加值。
- 如果规则集规定这种攻击有消耗，走出别人的触及范围就会让对方攻击你。
- 移动有八个方向，每步一格，和桌面游戏的网格一样。这与 Marinara 自身战术战斗的四方向模型不同。

使用棋盘：

1. 每一格都是独立的按钮。用指针或方向键操作。每一格都会说明它是什么、上面站着谁，以及走过去要花多少。
2. 选择 **Move**(移动)。能到达的格子会点亮，并以规则集的单位显示消耗。悬停或聚焦某一格时会画出路线。路线上会招来攻击的格子以琥珀色标记，攻击者的名字列在棋盘下方。
3. 选择需要目标的行动。合法目标会点亮，你可以在棋盘上或列表里点击它们。
4. 区域能力要瞄准一格。可以瞄准的格子会点亮，指针下方的那一格会显示它会波及谁，包括友军。
5. 按 <kbd>Esc</kbd> 取消尚未完成的选择，并把键盘操作交回菜单。

移动可以在行动之前和之后使用。菜单会带着剩余量重新出现，面板则以规则集的单位把它显示为 **Movement**。

规则集还可以更多地利用战场：分等级的掩护，最高为四分之三掩护；会改变攻击和坠落的高地；能飞行、游泳、攀爬或掘地的生物；菜单上的 **Hide**(躲藏) 和 **Search**(搜索)；以及有人脱离对手时暂停战斗，询问对手是否出手攻击。一场战斗用到其中哪些，取决于规则集。规则集还可以允许生物挤过比自身更小的空间、骑乘坐骑，或拖拽自己抓住的人。飞越障碍尚未实现：飞行生物的移动方式与其他生物相同。
