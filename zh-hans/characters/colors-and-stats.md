# 角色颜色与 RPG 属性

**Colors**(颜色) 和 **Stats**(属性) 选项卡在 Character Editor(角色编辑器) 和 Persona Editor(用户角色编辑器) 里都有。Colors 决定角色或用户角色在聊天里的外观，Stats 用来设置可以追踪的数值，例如生命值或饥饿度。

## Colors 选项卡

**Colors** 选项卡设置三种颜色：名字颜色、对话颜色和消息框颜色。哪个输入框留空，对应部分就使用应用主题的颜色。

1. 在编辑器里打开一个角色或用户角色。
2. 点击 **Colors** 选项卡。
3. 实时的 **Preview**(预览) 卡片会显示一个示例名字和一个消息气泡，下面是颜色输入框。改动每种颜色时，预览都会立即更新，保存之前就能看到效果。

### Extract Colors from Avatar

**Extract Colors from Avatar**(从头像提取颜色) 会根据头像图片挑出全部三种颜色。还没有头像时，这个按钮是禁用的，显示为 **Upload an avatar first**。提取之后，任何颜色仍然可以手动修改。

### 三种颜色

用颜色输入框选取，或者直接输入数值：

| 字段 | 作用于 | 示例值 |
| --- | --- | --- |
| **Name Display Color**(名字显示颜色) | 名字。它也支持渐变，见下文。 | `#f59e0b` |
| **Dialogue Highlight Color**(对话高亮颜色) | 对话引号内的文字。 | `#ffd700` |
| **Message Box Color**(消息框颜色) | Roleplay(角色扮演) 消息气泡的背景。 | `#123456` |

**Name Display Color** 还支持 CSS 渐变，也就是几种颜色之间的平滑过渡：

```text
linear-gradient(90deg, #f59e0b, #ef4444)
```

角色的 **Colors** 选项卡里还有 **Name Aliases**(名字别名)。输入额外的名字或昵称，用逗号分隔，例如 `Kate, Kitty, Katherine`。这些名字出现在聊天消息里时，会使用这个角色的名字颜色。主名字始终包含在内。在 **Chat Settings → Characters**(聊天设置 → 角色) 里按聊天开启这项功能。

要调整透明度，使用 **Settings → Appearance → Roleplay Presentation → Roleplay Messages Background Opacity**(设置 → 外观 → Roleplay 呈现方式 → Roleplay 消息背景不透明度)。

这个滑块会取代角色、用户角色和预设的背景色中保存的透明度，从头像提取的颜色也包括在内。你保存的颜色值本身保持不变。名字颜色和对话颜色不受影响。

自定义主题的背景钩子和角色卡 CSS 仍然可以覆盖应用自带的气泡样式。

<a id="where-your-colors-show"></a>

### 这些颜色用在哪里

- 名字颜色用于聊天消息里的显示名。角色的名字颜色还会用在侧边栏选项卡里的名字上。用户角色的名字颜色还会用在用户角色选择器里的名字上。
- 对话颜色用于对话引号内的文字，直引号和其他样式的引号都算。你还可以在 **Settings**(设置) 里把这段文字设为加粗。Conversation(对话模式) 聊天不使用它。
- 消息框颜色决定该角色或用户角色在 Roleplay 聊天里的消息气泡背景。Conversation 和 Game Mode(游戏模式) 聊天不使用它。

## Stats 选项卡

**Stats** 选项卡设置 HP(生命值)、STR(力量) 或饥饿度条这类数值。开启属性后，Marinara 会把这些数值写进提示词，让 AI 知道当前状态。这里设置的数值是新聊天的起始默认值。开始游玩后，智能体可以修改其中一部分（见[智能体如何更新属性](#how-agents-update-your-stats)）。

角色和用户角色的 **Stats** 选项卡布局不同。

### 角色属性

角色只有一个开关：**Enable RPG Stats**(启用 RPG 属性)。关闭时，下面的内容既不显示也不发送。开启后会出现两个区块：

- **Pools**(资源条) 是带名字的条，包含当前值、最大值和颜色。新角色默认带 HP 和 MP，数值都是 100，满值 100。
- **Attributes**(属性值) 是带名字的数值。新角色默认带 STR、DEX、CON、INT、WIS 和 CHA，全部为 10。

点击 **Add**(添加) 新增一条资源条或一项属性值，点击某一行的 X 删除它。

### 用户角色属性

用户角色的 **Stats** 选项卡有两个独立区块，各有各的开关。

- **Persona Status Bars**(用户角色状态条) 用 **Enable Persona Stats**(启用用户角色属性) 开启，用来追踪生理和心理需求。初始的状态条是 Satiety、Energy、Hygiene 和 Mood，数值都是 100，满值 100。在 **Status Bars**(状态条) 下，每条都有名字、当前值、最大值和颜色。点击 **Add** 新增一条，点击 X 删除一条。
- **Enable RPG Attributes**(启用 RPG 属性值) 的机制和角色卡一样，给你的用户角色提供 **Pools**(初始为 HP 和 MP，数值都是 100，满值 100) 和 **Attributes**(初始为 STR、DEX、CON、INT、WIS 和 CHA，全部为 10)。

<a id="mrpg-picks-on-a-card"></a>

### 卡片上的 MRPG 选择

两个 **Stats** 选项卡都有一个 **Game Mode**(游戏模式) 区块，其中的 **MRPG** 区块用于采用 MRPG 职业的游戏（也就是所有新游戏）。每局游戏都会为每个角色重新掷出 MRPG 属性，因此卡片不保存数值，只保存三项选择：

- **Starting tree**(起始树)：角色从哪棵树开始。**Auto**(自动) 会从卡片的描述和性格中判断，并显示由此选出的树。
- **Strong in**(强项)：最多两项角色擅长成长的属性。
- **Weak in**(弱项)：一项角色不擅长成长的属性。

这个区块会预览角色在新游戏里从 1 级开始时的职业，包括所在排位以及初始 HP、MP 和 Stamina。强项和弱项会影响角色在每局游戏中隐藏的成长倾向。姐妹树由角色在游戏中的性格决定，而不是来自卡片。见 [Game Mode：MRPG 职业](../game/mrpg-classes.md#choose-a-characters-trees)。

角色卡上，这个区块下方的 **Story stats for Legacy games**(Legacy 游戏的剧情属性) 会收起上文介绍的 RPG 属性。只有 Legacy 游戏会使用这些属性。

<a id="game-mode-icon"></a>

### Game Mode 图标

两个 **Stats** 选项卡都有 **Game Mode Icon**(游戏模式图标) 区块，用来设置 Game Mode 战斗中，这个角色或用户角色在棋盘上的圆形棋子所用的图片。选项旁边的小棋子会显示棋盘上实际画出来的样子。

- **Avatar**(头像) 是默认选项。它使用头像；没有头像时显示姓名首字母。
- **Custom image**(自定义图片) 使用角色卡自身图库里的图片。可以选一张图库中显示的图片，也可以上传新图片，新图片会加入图库。使用此选项前，要先保存一次角色卡。
- **Initials**(姓名首字母) 始终显示姓名首字母，即使有头像也一样。

在其他战斗风格中，这个角色也会显示同一张图片。如果从图库里删除了选中的图片，区块会提示这一点。选另一张，或切回 **Avatar**。

<a id="ruleset-sheets"></a>

### 规则集人物卡

安装了 Game Mode 规则集（例如 5e (SRD 5.1)）后，两个 **Stats** 选项卡都会在上面几个区块下方多出一个 **Ruleset sheets**(规则集人物卡) 区块。每个已安装的规则集对应一个可折叠条目。如果角色卡里还存着你已经没有的规则集的人物卡，这个区块也会出现。

人物卡是这个角色在该规则集下的初始配置。使用该规则集的新游戏会复制一份。在游戏里做的修改只留在那局游戏中，永远不会写回角色卡。

1. 展开条目，点击 **Add a sheet**(添加人物卡)。你会得到一张空白人物卡，每个值都是规则集的默认值。
2. 填写人物卡。布局来自规则集本身：属性值及其调整值、按分区归组的字段、攻击和法术之类的列表，以及各带一个训练等级和一项额外加值的技能与豁免。熟练加值、被动察觉之类的计算值会随输入实时更新，不能直接编辑。
3. 照常保存角色或用户角色。

也可以让 Professor Mari 填写或修改人物卡，例如“把 Rook 的 Brawn 设为 2，再往 Rook 的装备里加一根撬棍”。她只写入那个规则集的人物卡，所有数值都遵守规则集的限制，并在改动卡片上展示修改。

有些规则集自带现成的法术、攻击和特性。由它们填充的列表有一个 **Add from catalog**(从目录添加) 按钮，会打开可搜索的选择器。添加进来的行都是副本，可以像其他行一样编辑。

- 由规则集替你维护的单元格，例如随某项属性值变化的使用次数，或随等级增长的职业资源，会显示在原位但不能输入。它带有“Set by the ruleset”说明，每次你编辑人物卡时都会重新计算。
- 如果规则集里某一行的原文在你选用之后改过了，列表下方会有一行提示，说明有多少行有更新的文本，并附带一个 **Review**(审查) 按钮。审查时，每一行都会把你的文本和规则集的文本并排显示，每行一个勾选框。**Update selected**(更新所选) 只写入勾选的行。比较的只有文本：数字、开关，以及你在其他列里输入的任何内容都保持原样。

未安装的规则集的人物卡会保留下来。它显示为一行，带一个 **Remove**(移除) 按钮，永远不会发送给 AI，安装那个规则集之后就能再次编辑，导出角色卡时也会一起带走。已安装规则集的人物卡如果当前版本读不了，例如由更新的版本保存的，也会原样保留。它的条目只提供 **Remove this sheet**(移除这张人物卡)，所以新人物卡绝不会意外覆盖它。每张人物卡上限为 64 KB。

规则集人物卡与 **Enable RPG Stats** 和 **Enable RPG Attributes** 互不相干。使用 Marinara 自身规则的游戏会忽略人物卡；使用规则集的游戏则用人物卡代替上面的 Attributes 进行检定。

<a id="how-agents-update-your-stats"></a>

## 智能体如何更新属性

**Stats** 选项卡设置的是聊天的初始状态。智能体只会更新由追踪器管理的数值。

| 数值 | 由谁修改 |
| --- | --- |
| 角色的 **Pools**，例如 HP | **Character Tracker** 智能体，根据战斗、治疗和剧情事件修改。它不追踪玩家的用户角色。 |
| **Persona Status Bars** | **Persona Stats** 智能体，在每条消息之后修改。 |
| **RPG Attributes**(RPG 属性值)，例如 STR 和 DEX | 没有智能体修改。它们会随卡片一起发送，用于战斗和 Game Mode，以及 Roleplay 或 Game Mode 中的可选掷骰。 |

如果不开启对应的智能体，由追踪器管理的数值就一直停在你设定的默认值上。单靠 **Stats** 选项卡，游玩时不会更新任何东西。要开启这些智能体，见[可下载智能体参考](../agents/built-in-agents.md)。

## 属性在 HUD 里怎么显示

开启的属性会在聊天过程中显示在 HUD 里。HUD 就是显示你实时数值的那个小面板。各种条以按颜色区分的渐变显示。移动或隐藏 HUD 的方法见 [HUD 与追踪器](../roleplay/hud-and-trackers.md)。
