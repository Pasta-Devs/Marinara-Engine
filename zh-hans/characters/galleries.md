# 角色与用户角色图库

本指南介绍角色编辑器和用户角色编辑器里的 **Gallery**(图库) 选项卡，讲清楚怎么添加长期跟着角色或用户角色走的图片和视频，也会讲怎么把图库里的一张图标记成自定义 Emoji 或贴纸。

## Gallery 选项卡

每个角色、每个用户角色都有自己的 **Gallery** 选项卡。在 **Character Editor**(角色编辑器) 里打开一个角色，或者在 **Persona Editor**(用户角色编辑器) 里打开一个用户角色，然后点击 **Gallery** 选项卡（相机图标）。

Gallery 下面分两个子选项卡：

- **Images**(图片)：为这个角色或用户角色上传的图片。
- **Videos**(视频)：上传的视频，外加与这个角色相关的场景视频和视频通话片段。

角色的图库标题是 **Character Gallery**，用户角色的图库标题是 **Persona Gallery**。两者用法完全相同。

## Gallery 和聊天图库的区别

Gallery 里的图片属于角色或用户角色，不属于某一次聊天。删掉一次聊天，这些图片照样在。设定参考图、换装差分、导入的角色图包，都适合放进 Gallery。

聊天自己的图库是另一回事，里面装的是那一次聊天专属的场景插图和生成出来的消息附件。临时的场景图放聊天图库，长期要留着的角色图片放角色或用户角色的 Gallery。

## 添加图片

1. 打开角色编辑器或用户角色编辑器。
2. 点击 **Gallery** 选项卡。
3. 确认当前选中的是 **Images** 子选项卡。
4. 把图片文件拖到 **Upload Character Images**(上传角色图片) 区域，或者点击这个区域挑选文件。在用户角色里，这个区域叫 **Upload Persona Images**。
5. 等待上传完成。新图片会出现在下方的网格里。

常见图片格式都能上传，例如 JPG、PNG、GIF、WebP 和 AVIF。点击任意一张图可以放大查看。每个图块上还有下载和删除两个控件。

## 添加视频

1. 点击 **Gallery** 选项卡。
2. 选中 **Videos** 子选项卡。
3. 把视频文件拖到 **Upload Character Videos**(上传角色视频) 区域，或者点击这个区域挑选文件。在用户角色里，这个区域叫 **Upload Persona Videos**。
4. 等待上传完成。

支持的视频格式是 MP4、WebM 和 MOV。**Videos** 子选项卡里还会列出与这个角色聊天时生成的场景视频，以及所有视频通话片段，按时间从新到旧排列。

## 把图库里的图标记为自定义 Emoji 或贴纸

图库里的图片可以变成 **Conversation Mode**(对话模式，即时通讯风格的聊天模式) 用的自定义 Emoji 或贴纸。自定义 Emoji 是一张随文字内嵌的小图，写法是 `:name:`。贴纸是一张单独成块的大图，写法是 `sticker:name:`。这两种写法只在 Conversation Mode 的聊天里有效。

标记方法：

1. 打开 **Gallery** 选项卡，选中 **Images** 子选项卡。
2. 找到目标图片。它左上角有一个小的标记按钮，提示文字是 **Tag as emoji or sticker**。
3. 点击标记按钮，会弹出一个菜单，里面有 **Make emoji** 和 **Make sticker**。
4. 点击 **Make emoji** 或 **Make sticker**。
5. 在 **Custom Emoji** 或 **Custom Sticker** 窗口里输入名称，然后确认。

名称由小写字母、数字和下划线组成，最长 32 个字符。其他字符会自动转换，比如“Big Grin”会变成 `big_grin`。

尺寸上限取决于选哪一种，与图库本身无关。Emoji 图片最大 256 × 256 像素，贴纸图片最大 512 × 512 像素。图片超出上限时会弹出错误提示，标记不会生效。

### 管理已标记的图片

图片标记之后，它上面的浮层按钮会显示所分配的名称。点击这个按钮可以打开菜单，里面还有更多选项：

- **Rename**(重命名)：改名称。
- **Switch to sticker** 或 **Switch to emoji**：切换成另一种类型。切换时会按新类型重新检查尺寸上限，所以超过 256 × 256 像素的贴纸图片没法变成 Emoji。真遇到这种情况会弹出错误提示，类型保持不变。
- **Remove emoji** 或 **Remove sticker**：取消标记。图片本身仍然留在 Gallery 里。

### 这类 Emoji 和贴纸在哪里有效

在图库里标记出来的 Emoji 或贴纸只属于那一个角色或用户角色，也只在包含该角色或用户角色的 Conversation Mode 聊天里有效。它和消息输入框里那套全局 Emoji、贴纸库是两回事。

如果图库里的名称和全局库里的某个名称撞车，那次聊天中以图库版本为准。名称并不做唯一性检查，所以最好给每张图起一个不重样的名称，免得出现意外。

## 在消息和问候语中复用图库图片

角色图库中的任何图片都可以显示在聊天文本里，例如问候语、示例消息或角色发送的消息。把鼠标悬停在图片上并单击 **Copy image reference**（链接图标），即可复制一小段 Markdown，粘贴到角色说话的任何位置：

```text
![sunset selfie](card://self/gallery/k3m2xq7.png)
```

规则只有一条：**`self` 表示正在说这条消息的角色。** 渲染消息时，Marinara 会把 `self` 替换为该角色并显示其图库中的图片。

它适用于角色卡上的 **First Message**、**Alternate Greetings** 和 **Example Dialogue**，也适用于角色在 Roleplay 和 Conversation 中发送的任何消息以及群聊。在包含多个说话者的回复中，`self` 会针对每位说话者分别解析。如果说话者的图库里没有该文件，Marinara 会在聊天中其他角色的图库里查找。

它有意不支持你自己的消息，因为这类消息没有正在说话的角色；系统消息也不会渲染 Markdown 图片。要自行发送角色的图库图片，请使用聊天资源浏览器，它会写入完整的 `card://characters/<id>/...` 形式。Persona 图库则使用 `card://personas/<id>/gallery/<file>`。

如果两个角色拥有相同文件名的图片，始终优先使用说话者的图片。说话者没有该文件时，则使用聊天角色顺序中的第一个匹配项。如果需要指定版本，请使用不同的文件名。

### 为什么使用 `self` 而不是完整链接

完整链接包含角色的内部 id（`card://characters/<id>/gallery/<file>`），而每次导入角色都会重新生成 id，因此分享后完整链接会失效。`self` 形式不包含 id 或服务器地址。它能经受**原生 JSON 导出和导入**：图库图片会随导出一起传递，并保留文件名。

有一项限制：**PNG 角色卡导出不包含图库**。角色使用图库引用时，请分享原生 `.json` 导出。
