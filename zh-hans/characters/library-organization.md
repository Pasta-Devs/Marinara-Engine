# 整理角色库

**Characters**(角色) 面板就是侧边栏里的角色列表，你创建过和导入过的每个角色都在这里。可以用它搜索、排序、把角色归进文件夹、标记收藏、按标签筛选，以及一次性导出或删除多个角色。

## Characters 面板

在面板顶部可以：

- 点击 **Download**(下载) 打开 [Card Browser](bot-browser.md)，在公开网站上查找角色。
- 点击 **Open Library**(打开角色库)，用更大的整页网格查看同一批角色。
- 点击 **New**(新建)（加号图标）打开 **Create Character**(创建角色) 窗口。
- 点击 **Import**(导入)（下载图标）导入角色文件，见[导入和导出角色卡](import-export.md)。
- 点击 **Select**(选择)（对勾图标）开启选择模式，用于批量操作。

打开某个角色去编辑再返回时，完整角色库会保留你选中的卡片、排序方式和滚动位置。

每一行显示头像、名称、可选的标题行、作者和版本、最多 3 个标签，以及大致的 Token(模型切分文本的最小单位) 估算。小星标表示收藏。鼠标悬停在某一行上会出现 **Duplicate**(复制) 和 **Delete**(删除)。角色很多时，点击底部的 **Load more**(加载更多) 加载下一页。

## 搜索

在顶部的搜索框里输入内容。占位文字是 **Search characters/tags**(搜索角色/标签)。普通文字会匹配角色的名称、标题、描述和标签，不区分大小写。输入 `knight`，这几处中任意一处含有“knight”的角色都会列出来。

| 搜索 | 找到什么 |
| --- | --- |
| `male genshin` 或 `male,genshin` | 同时带有这两个精确标签的卡片。 |
| `male "Modern AU"` | 标签里有空格或逗号时，用引号括起来。 |
| `-tag:"slow burn"` | 隐藏所有带这个标签的卡片，即使搜索的其余部分能匹配上。 |
| `-vampire` | 效果相同，用于单个单词的标签。可以省掉引号。 |
| `mage -tag:"villain"` | 匹配“mage”的卡片，去掉带“villain”标签的那些。 |

普通短语搜索仍然有效。整页的 Character Library(角色库) 和用户角色也支持同样的搜索。

## 排序

在搜索框旁边的排序下拉菜单里选择顺序。

| 选项 | 作用 |
| --- | --- |
| **Manual order**(手动排序) | 你自己设定的顺序。 |
| **A-Z** | 名称按 A 到 Z 排列。 |
| **Z-A** | 名称按 Z 到 A 排列。 |
| **Newest** | 最近创建的排在前面。 |
| **Oldest** | 最早创建的排在前面。 |
| **Favorites** | 收藏的排在前面，然后是其余的。 |

要设定手动顺序，把某一行向上或向下拖动，或者在获得焦点的行上按 <kbd>Alt</kbd>+<kbd>Up</kbd> 或 <kbd>Alt</kbd>+<kbd>Down</kbd>。两种方式都会把排序切换为 **Manual order**。

## 文件夹

文件夹把相关的角色归到一起，例如按故事或系列分组，让长列表更容易浏览。文件夹是可选的。

1. 点击 **New Folder**(新建文件夹)。会出现一个名为 **unnamed** 的文件夹。
2. 给它改名：双击、在触屏上点两下，或者选中后按 <kbd>F2</kbd>。输入新名称，按 <kbd>Enter</kbd>。
3. 把角色行拖到文件夹上，就能把它放进去。只要有了文件夹，就会显示一行提示：**Drag and drop characters to folders, double-click or double-tap to rename**。

要把角色移出来，把鼠标悬停在文件夹内的那一行上，点击移出文件夹的按钮，或者直接拖出来。点击文件夹可以展开或折叠。文件夹名称旁边的数字表示里面有多少个角色。

在触屏上，长按某一行把它拿起来，然后拖动。正常滑动仍然会滚动列表。

要一次移动多个，按住一行，同时用另一根手指点其他行，把它们叠成一摞一起带走。然后把这一摞放到文件夹上。

要删除文件夹，把鼠标悬停在文件夹上，点击它的垃圾桶按钮。文件夹里有角色时会要求你确认：**Delete "name"? Its N characters will stay in the library and move out of the folder.** 空文件夹会立即删除。删除文件夹绝不会删掉里面的角色。

### 把文件夹用作群聊名单

每个文件夹同时也是一份保存好的群聊名单。设置有多个角色的聊天时，**Add from Folder**(从文件夹添加) 能一步把某个文件夹里的全部角色都加进来。见[群聊与 Conversation 模式群聊](../chats/group-chats.md)。

## 收藏和标签

### 收藏

打开一个角色，点击它的 **Favorite**(收藏) 星标即可开启或关闭。无法从面板列表里设置。收藏的角色会显示一个小星标。搜索框下方有三个按钮可以筛选列表：

- **All** 显示全部角色。
- **Favs** 只显示收藏的角色。
- **Non-favs** 只显示没有收藏的角色。

也可以在排序下拉菜单里选 **Favorites**，把收藏的角色排到最上面。

### 标签

标签是 `fantasy` 或 `slow burn` 这样的标记，在角色编辑器里添加，见[创建和编辑角色](creating-and-editing-characters.md#metadata-tab)。在面板里，点击任意一行上的标签小标，列表就会筛选成带这个标签的角色。

角色带有标签时，会出现一个带计数的 **Tags**(标签) 按钮，例如 **Tags (12)**。点击它展开完整的标签列表：

- 点击某个标签，把它作为筛选条件加进来。选中多个标签时，带其中任意一个标签的角色都算匹配。
- 点击标签上的 X，会把这个标签从所有带它的角色上删除。删除前会要求你确认：**Remove tag "name" from all characters?**
- 标签筛选生效后会出现 **Clear**(清除)。点击它清空标签筛选。

如果想排除某个标签，就在搜索框里使用 `-tag:`，见[搜索](#search)。

## 批量导出或删除角色

1. 点击面板顶部的 **Select**。每一行上都会出现一个复选框。
2. 点选要处理的角色。面板标题栏会显示已选中的数量。
3. 使用底部的操作栏。

操作栏上有两个按钮：

- **Export**(导出) 会把选中的角色打包成一个名为 `marinara-characters.zip` 的 zip 文件下载，使用 Marinara 的原生格式。
- **Delete** 删除选中的角色。删除前会先问你：**Delete N characters?**

在选择模式下，还可以把选中的角色一起拖进某个文件夹。文件格式见[导入和导出角色卡](import-export.md)。
