# 整理角色库

本指南介绍 **Characters panel**(角色面板)，也就是存放全部角色的侧边栏。读完之后就会用搜索、排序、把角色归进文件夹、标记收藏、按标签筛选，以及一次性导出或删除多个角色。

## Characters 面板

**Characters panel** 就是侧边栏里的角色列表，创建过和导入过的角色都在这里。从面板顶部可以：

- 点击 **Download**(下载) 打开 [Card Browser](bot-browser.md)，在公开网站上查找角色。
- 点击 **Open Library**(打开角色库)，用整页网格视图查看同一批角色。
- 点击 **New**(新建) 按钮（加号图标）打开 **Create Character**(创建角色) 窗口。
- 点击 **Import**(导入) 按钮（下载图标）导入角色文件。
- 点击 **Select**(选择) 按钮（对勾图标）开启多选模式，用于批量操作。

完整角色库会沿用 **Settings**(设置) 里选定的 chroma 文字配色。打开某个角色去编辑再返回时，选中的卡片、排序方式和滚动位置都保持原样。

每一行角色会显示头像、名称、可选的标题行、作者和版本、最多 3 个标签，以及大致的 Token(模型切分文本的最小单位) 用量估算。收藏的角色带一个小星标。鼠标悬停在某一行上时，会出现 **Duplicate**(复制) 按钮和 **Delete**(删除) 按钮。

角色数量较多时，列表底部会出现 **Load more**(加载更多) 按钮，点击即可加载下一页角色。

## 搜索

在面板顶部的搜索框里输入内容即可筛选列表。占位文字是 **Search characters or -tag:"tag name"**。

普通文字会匹配角色的名称、标题、描述和标签。比如输入 `knight`，这几个字段中任意一处含有“knight”的角色都会列出来。

也可以把带某个标签的角色排除掉，在标签前面加一个减号：

```
-tag:"tag name"
```

关于标签排除，有几点要注意：

- 标签里有空格时要加引号，例如 `-tag:"slow burn"`。
- 单个单词的标签可以省掉引号，例如 `-vampire`。
- 排除某个标签后，带这个标签的角色一律不显示，哪怕搜索文字的其余部分能匹配上。

同一个搜索框里可以把普通文字和排除条件混着写。例如 `mage -tag:"villain"` 会找出匹配“mage”的角色，同时隐藏所有带“villain”标签的角色。

## 排序

搜索框旁边是排序下拉菜单，可选的顺序有这几种：

| 选项 | 效果 |
| ------------- | ------------------------------- |
| **Manual order**(手动排序) | 按你自己设定的顺序排列。 |
| **A-Z** | 名称按 A 到 Z 排列。 |
| **Z-A** | 名称按 Z 到 A 排列。 |
| **Newest** | 最近创建的排在前面。 |
| **Oldest** | 最早创建的排在前面。 |
| **Favorites** | 收藏的排在前面，其余的跟在后面。 |

要设定手动顺序，把角色行向上或向下拖动即可。也可以在选中的行上按 Alt+Up 或 Alt+Down。两种方式都会把排序切换为 **Manual order**。

## 文件夹

文件夹用来在面板里把相关的角色归到一起，属于可选功能。喜欢的话，也完全可以让所有角色都待在一个扁平列表里。

创建文件夹的步骤：

1. 点击 **New Folder**(新建文件夹) 按钮。
2. 新文件夹随即出现，默认名为 **unnamed**。
3. 立刻改名，或者以后再改（见下文）。

给文件夹改名的方法：双击、在触屏上点两下，或者选中后按 F2 键。输入新名称，按 Enter 确认。

要把角色放进文件夹，拖动角色行并松手放到文件夹上。只要至少有一个文件夹，就会显示一行提示：**Drag and drop characters to folders, double-click or double-tap to rename**。要把角色移出来，把鼠标悬停在文件夹内的那一行上，点击移出文件夹的按钮，或者直接拖出来。

在触屏上，长按某一行把它拿起来，然后拖动。正常滑动仍然会滚动列表。按住一行的同时，用另一根手指点其他行，就能把它们叠成一摞一起带走，再把这一摞放到文件夹上。

点击文件夹可以展开或折叠。文件夹名称旁边的数字表示里面有多少个角色。

要删除文件夹，把鼠标悬停在文件夹上，点击垃圾桶按钮。文件夹里有角色时会弹出确认提示：**Delete "name"? Its N characters will stay in the library and move out of the folder.** 空文件夹会立即删除，不做确认。删除文件夹绝不会删掉里面的角色，它们只是回到主列表。

## 收藏和标签小标

### 收藏

把角色标为收藏，以后就好找了。收藏星标要在角色内部设置，不能从面板列表里点。打开一个角色，点击它的 **Favorite**(收藏) 星标即可开启或关闭。收藏过的角色，头像上会在面板里显示一个小星标。

搜索区域下方有三个筛选按钮：

- **All** 显示全部角色。
- **Favs** 只显示收藏的角色。
- **Non-favs** 只显示没有收藏的角色。

在排序下拉菜单里选 **Favorites**，也能把所有收藏的角色顶到列表最上面。

### 标签

标签是给角色贴的描述性标记，比如 `fantasy` 或 `slow burn`。角色的标签在角色编辑器里添加和修改。

在面板中，每一行角色最多显示 3 个标签。点击任意一行上的标签小标，列表就会筛选成带这个标签的角色。

角色带有标签时，筛选按钮那一行会出现 **Tags**(标签) 按钮，括号里是标签总数（例如 **Tags (12)**）。点击它展开完整的标签列表：

- 点击展开列表里的某个标签，把它作为筛选条件加进来。选中多个标签时，只要带其中任意一个标签的角色都会列出来。
- 展开列表里每个标签后面都有一个小 X。点击它会把这个标签从所有带它的角色上删除，删除前会弹出确认提示：**Remove tag "name" from all characters?**
- 标签筛选一旦生效，就会出现 **Clear**(清除) 按钮，点击即可清空标签筛选。

如果想排除某个标签而不是包含它，用上面搜索一节讲过的 `-tag:` 搜索语法。

## 批量选择、导出和删除

想一次处理多个角色时，用选择模式。

1. 点击面板顶部的 **Select** 按钮。
2. 每一行角色上都会出现一个复选框。
3. 点选要处理的角色。面板顶栏会显示已选中的数量。
4. 使用面板底部的操作栏。

操作栏上有两个按钮：

- **Export**(导出) 会把选中的所有角色打包成一个 zip 文件下载下来，文件名为 `marinara-characters.zip`。这是 Marinara Engine 自有原生格式的批量导出。
- **Delete** 会删除选中的所有角色，删除前会弹出确认提示：**Delete N characters?**

在选择模式下，还可以把选中的角色一次性拖进某个文件夹，不必一个一个地挪。

导入和导出支持的完整文件格式清单，见下方关于导入导出的指南。

## 文件夹同时也是群聊名单

这里建好的文件夹还有第二个用途：每个文件夹同时是一份保存好的名单，可以直接拉进群聊。

设置多角色聊天时，注意找 **Add from Folder**(从文件夹添加) 这个选项，它能一步把选定文件夹里的全部角色都加进来。想和几个常搭配使用的角色开群聊，这是最快的办法。群聊的具体机制见下方的群聊指南。
