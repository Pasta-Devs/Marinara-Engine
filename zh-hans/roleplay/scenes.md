# 场景：分支出一段角色扮演

本指南介绍 Marinara Engine 里的场景。场景是一段短小、自成一体的角色扮演，从 Conversation(对话模式) 聊天里分支出来。下面讲怎么开一个场景、怎么玩，以及结束、丢弃、复刻或转换它的方法。

## 什么是场景

场景是从 Conversation 聊天里长出来的一段支线角色扮演。Conversation 聊天就是即时通讯、私信风格的模式。有了场景，你和角色可以暂时离开那段聊天，专心演一个片段，可以是一段回忆、一次约会，也可以是一场打斗。主线不会因此丢失。

每个场景都是一段独立的角色扮演聊天，有自己的背景、自己登场的角色、自己的开场消息。场景开始时，铺垫由角色或故事本身写好。

场景天生是临时的。场景开着的时候，原来的 Conversation 聊天里会出现一张小卡片，写着 **A scene is in progress**。卡片上的 **Go to Scene**(前往场景) 按钮可以直接跳进当前场景。

演完之后，由你决定这个场景的去向：把一份摘要写回聊天、直接扔掉，或者把它保留成一段独立的角色扮演。这几种选择下面会分别说明。

## 开始一个场景

场景要在 Conversation 聊天内部用 `/scene` 命令开启。这个命令还有一个别名 `/rp`，效果完全一样。

按下面的步骤操作：

1. 打开一段已经有一些消息的 Conversation 聊天。
2. 在消息输入框里输入场景命令，后面可以补一句简短描述，说明你想演什么。

```
/scene we sneak into the old library at midnight
```

3. 按 Enter。**Scene Prompt Setup**(场景提示词设置) 窗口会打开。
4. 为新场景选择一个**Prompt preset**(提示词预设)，或保留**None**(无)。Marinara会记住这个选择，供下次创建场景使用。场景自身的指令仍会与所选预设一起生效。
5. 在 **POV**(视角) 下选择行文的人称：**First Person**、**Second Person** 或 **Third Person**。
6. 在 **Tense**(时态) 下选择 **Past**、**Present** 或 **Future**。
7. 需要的话，在 **Extra instructions**(额外说明) 输入框里写点提示，引导场景走向。
8. 点击 **Plan Scene**(规划场景)。

Marinara 会规划好场景，并把它作为一段新的角色扮演聊天打开。聊天列表里应该会出现这段新场景并自动打开，开场消息交代好当前情境。如果在设置窗口里改了主意，点击 **Cancel**(取消)，场景就不会创建。

不写描述也能开场景。只要聊天已经积累了足够多的内容可供参考，直接输入命令本身就行。

```
/scene
```

如果聊天里还一条消息都没有，Marinara 会提示先补一句描述，或者先聊几句，才能规划场景。

角色也可以主动提出开一个场景。这时会打开同一个 **Scene Prompt Setup** 窗口，上面写着类似“[Character] wants to start a scene.”的一行字。照样选好 **Prompt preset**、**POV** 和 **Tense** 再点击 **Plan Scene**，或者点击 **Cancel** 拒绝。

## 场景操作条：End Scene、Discard、Convert 和 Back to conversation

在场景里的时候，消息输入框正上方有一条操作条，决定这个场景最终去向的控件都在这里。具体显示哪些按钮，取决于场景有没有关联的聊天。

- **Back to conversation**(返回聊天) 把你送回开启这个场景的 Conversation 聊天。场景仍然开着、仍然有效，之后随时可以回来。只有当场景有来源聊天时，这个按钮才会出现。
- **End Scene**(结束场景) 结束场景并保存一份摘要。点击后，操作条会问 **End and save summary?**，下面是 **Yes** 和 **No** 两个按钮。点击 **Yes** 确认。处理过程中按钮会显示 **Saving...** 状态。Marinara 会把这段场景的简短摘要作为一条记忆写回来源聊天，然后把你带回那段聊天中断的地方。
- **Discard**(丢弃) 直接扔掉场景，什么都不保存。点击后，操作条会问 **Discard scene?**，同样有 **Yes** 和 **No** 两个按钮。点击 **Yes** 就删掉场景并返回聊天，不会写回任何内容。
- **Convert**(转换) 把场景变成一段独立的角色扮演聊天。这个操作会永久改变场景，所以单独用一节说明。

点 **End Scene** 或 **Discard** 之前先想清楚，这两个操作都会把场景从聊天里移除。区别在于 **End Scene** 会留下一条关于经过的记忆，**Discard** 什么都不留。

## 从某条消息复刻场景

在场景聊天里，每条消息都有一个小操作按钮，提示文字是 **Clone from here**(从这里复刻)。它可以把场景内容分支到一段全新的角色扮演聊天里，复制到这条消息为止（含这条）。

用法：

1. 把鼠标悬停在想分支的那条消息上。
2. 点击 **Clone from here** 操作。

Marinara 会基于这个场景新建一段独立的角色扮演，把此前的消息复制过去。原来的场景仍然开着、仍然有效，所以这是一种试探另一条走向的安全做法。屏幕上应该会提示场景已复刻为角色扮演，新聊天随即打开。

复刻会保留原场景，而下面要讲的转换不会。

## 把场景转换成独立的角色扮演

场景操作条上的 **Convert** 按钮会把场景剥离出来，变成一段独立的、永久保留的角色扮演聊天。点击 **Convert** 后会打开一个确认窗口，标题是 **Convert this scene into a standalone roleplay?**

窗口里说明了接下来会发生什么：基于当前场景创建一段新的角色扮演聊天，并把原场景从它所属的聊天里剥离。不会有场景摘要写回原聊天，也不会有角色记忆写回。点击 **Convert** 继续，点击 **Cancel** 则保持现状。

如果一个场景已经演成了你想留下并继续写下去的故事，就用 **Convert**。如果只想要一份副本、同时希望原场景原地保留，那就用 **Clone from here**。

两条分支路径的区别一句话说清：**Clone from here** 分支出场景的支线，原场景照常继续；**Convert** 把场景支线转换成独立的角色扮演，并把原场景从所属聊天里移除。

## 场景为什么不继承已连接聊天的上下文

Conversation 聊天可以和一段角色扮演连接起来，让上下文在两边流动。场景则是有意做成另一套逻辑：场景是自成一体的。

即便父级聊天连着别的聊天，场景也不会自动把那边的来回上下文拉进来。已连接的聊天会悄悄把简短的引导提示传给关联的角色扮演，推动故事走向，但场景会忽略这些提示。这样场景才能专注在自己这个片段上，而不是把整段聊天都拖进来。

正因如此，场景读起来才像一个干净利落的小故事。如果你要的是聊天和角色扮演之间持续的双向联动，那就用已连接聊天，而不是场景。这项功能见下面链接的已连接聊天指南。
