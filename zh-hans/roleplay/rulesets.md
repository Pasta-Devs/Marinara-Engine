# Roleplay：按规则集游玩

Roleplay 聊天可以按桌面规则集游玩，和 Game Mode 用的是同一类。遇到不确定的事情时，旁白会要求检定，Marinara 从人物卡掷骰，回复说明这次掷骰定下了什么。想在角色扮演里用真正的骰子和人物卡、又不想开一局 Game Mode 时，就用它。

你为 Game Mode 装过的任何规则集都能用，例如 5e (SRD 5.1)，你在角色编辑器和用户角色编辑器里已经为它建好的人物卡也能用。

## 为聊天开启规则集

开始之前：先安装一个规则集。见[获取规则集](../game/rulesets.md#get-a-ruleset)。

1. 打开 Roleplay 聊天。
2. 打开 **Chat Settings**(聊天设置)，找到 **Ruleset**(规则集) 分区。
3. 从列表里选一个规则集。列表显示你已安装的规则集。
4. Marinara 给聊天里的每个成员一张人物卡，并说明加了几张。每个成员都列在规则集下面。

每个成员会从角色编辑器或用户角色编辑器得到自己那张人物卡在这个规则集下的副本（见[规则集人物卡](../characters/colors-and-stats.md#ruleset-sheets)）。没有人物卡的成员会得到一张空白人物卡，在列表里标为 **blank sheet**(空白人物卡)，可以在聊天里填写。你的用户角色排在最前面。聊天里的改动只留在聊天里，绝不会写回角色或用户角色。

如果没有成功：导入的规则集需要开启 **Allow custom Agent imports**(允许导入自定义智能体)。见[获取规则集](../game/rulesets.md#get-a-ruleset)。

### 填写空白人物卡

1. 在 **Ruleset** 分区里，点击成员旁边的 **Build sheet**(建立人物卡)。
2. 人物卡在人物卡编辑器里打开。规则集带引导式构建器时，会先在那个构建器里打开，和 Game Mode 及角色编辑器里一样。
3. 做好选择，点击 **Save sheet**(保存人物卡)。

### 为新成员添加人物卡

之后有角色加入聊天时，点击 **Add missing sheets**(补齐缺少的人物卡)。已经有人物卡的成员保持原样。

### 移除人物卡

不该有人物卡的成员，例如旁白角色卡，可以拿掉它的人物卡。

1. 在 **Ruleset** 分区里，点击成员旁边的垃圾桶图标。
2. 点击 **Remove sheet**(移除人物卡)。

聊天会记住这一点，所以 **Add missing sheets** 和更新版本的规则集都会跳过这名成员。想再给他一张人物卡，就点击 **No sheet:**(没有人物卡) 后面那个以他命名的按钮，例如 **Give Mira a sheet**(给 Mira 一张人物卡)。

### 更换或关闭规则集

- 选择 **None**(无) 就不再按规则集游玩。人物卡会保留，所以再次选择同一个规则集时会从上次停下的地方继续。
- 换用别的规则集会让人物卡全部重新开始，因为为某个规则集做的人物卡对另一个规则集没有意义。

## 游玩中的检定

你照常写自己的回合。当角色尝试结果重要的不确定行动时，旁白会写一次检定，而不是直接决定结果。Marinara 从人物卡掷这次检定，然后由旁白写出掷骰定下了什么。

完成的消息会在检定发生的位置显示一张骰子卡片，包含技能、难度、骰子，以及 **Success**(成功) 或 **Failure**(失败)。不会真正失败的普通行动不会有检定。

> **提示：** 有些模型会忽略要求检定的指令，自己决定结果。如果一个检定都不出现，就给聊天的 **Connection**(连接) 换一个更强的模型。

**Impersonate**(代写) 回合不掷检定。多人模式房间不能按规则集游玩。

## 使用人物卡

在 **Ruleset** 分区里点击某个成员旁边的 **Open sheet**(打开人物卡)。这张人物卡和 Game Mode 显示的是同一张。Tracker Panel 顶部的卷轴按钮会打开你用户角色的人物卡。

- 点击资源池或轨道旁边的 **−** 和 **+**，例如生命值或压力，就能改动它。改动随当前这条消息保存，所以会跟着备选回复和分支走。
- 点击 **Edit ruleset sheet**(编辑规则集人物卡)，可以修改数值、技能等级、字段和列表，然后点击 **Save sheet**(保存人物卡)。

旁白在每个回合都会读人物卡，并用回复里的人物卡命令修改它们，Marinara 会执行这些命令，并把它们从消息里隐藏。要休息，就在你的回合里说明，例如“我们长休一次”。旁白会记录休息，人物卡会恢复规则集的休息所恢复的内容。也可以在人物卡上点击 **Rest**(休息)。

## 制作自己的规则集

规则集构建器用一张表单做出一个小型规则集：检定怎么掷骰、人物卡上有什么，以及告诉旁白什么。Marinara 没有的系统，就用它来做。你做的规则集和已安装的规则集用起来一样，Roleplay 和 Game Mode 里都能用。

开始之前：开启 **Allow custom Agent imports**，因为构建器保存规则集的方式和导入一样。见[获取规则集](../game/rulesets.md#get-a-ruleset)。

1. 在 **Chat Settings → Ruleset**(聊天设置 → 规则集) 里，点击 **New ruleset…**(新建规则集)。
2. 输入 **Name**(名称)。
3. 在 **Dice**(骰子) 下面，选择检定怎么掷骰（见下表）。选好后会填入初始的属性、资源池和轨道，你可以再修改。
4. 修改 **Difficulties**(难度)、**Stats**(属性)、**Skills**(技能) 和表单的其余部分。大多数分区的标题下面都有一行说明它的用途。
5. 点击 **Create ruleset**(创建规则集)。

Marinara 会保存这个规则集。在没有规则集的聊天里，它还会开启这个新规则集。已经有规则集的聊天会保留原来的规则集和人物卡；要切换，就在列表里选新规则集。

如果某个已安装的规则集已经按你选的方式掷骰，**Dice** 分区会写出它的名字。每个规则集在每个角色身上都是一张单独的人物卡，所以想让每个角色只有一张人物卡，就用那个规则集游玩或编辑它，而不是另做一个。

| 骰子 | 检定怎么掷 |
| --- | --- |
| **d20 + modifier**(d20 + 调整值) | 一颗 d20 加上属性和技能，对照一个难度数值。 |
| **2d6 bands**(2d6 分档) | 2d6 加上属性：10 或以上是强命中，7 到 9 是弱命中，6 或以下是未命中。 |
| **Dice pool**(骰池) | 属性和技能每有一点就掷一颗骰子。每颗达到目标值的骰子都算数。由你选择 d6 或 d10 以及目标值。 |
| **Highest d6**(最高 d6) | 每一点掷一颗 d6，保留最高的那颗：6 是完全成功，4 或 5 是部分成功，两个 6 是大成功。 |
| **Percentile**(百分骰) | 一颗 d100。掷出不高于技能数值时，检定成功。 |
| **Hope and Fear**(希望与恐惧) | 两颗 d12 加上属性。点数较高的那颗骰子决定结果伴随希望还是恐惧。 |
| **No dice**(不掷骰) | 不掷任何骰子。属性和技能相加后与难度比较。 |

### 修改自己做的规则集

1. 为聊天开启这个规则集。
2. 在 **Chat Settings → Ruleset** 里，点击 **Edit ruleset**(编辑规则集)。
3. 做好修改，点击 **Save new version**(保存新版本)。

聊天会换到新版本，并保留所有人物卡。给属性、技能、资源池或列表列改名时，每个角色在其中的内容都会保留。使用同一规则集的另一个聊天，要在那个聊天里点击 **Add missing sheets**，才会换到新版本。

**Edit ruleset** 会出现在你自己做的或从文件导入的规则集上，前提是表单能容纳它的全部内容：也就是构建器做出的规则集，或者只用到表单所显示内容的手写文件。来自包或仓库的规则集不会出现这个按钮。构建器绝不会打开带有更多内容（例如战斗规则或注释）的规则集，所以不会丢掉它不显示的东西。这个按钮也只出现在使用最新版本的聊天里；在使用旧版本的聊天里，先点击 **Add missing sheets**。

### 人物卡布局

| 在表单里 | 在人物卡上 |
| --- | --- |
| 行的顺序 | 属性、技能、资源池、轨道、字段和列表选项卡按表单里的顺序显示。拖住某一行的拖动手柄就能移动它，也可以让焦点落在手柄上，再按上下方向键。 |
| 属性或技能的 **Group**(分组) | 分组相同的属性或技能显示在同一个标题下。 |
| **Skill ranks**(技能等级) | 你在人物卡上可以为每项技能选的等级，以及每个等级加什么：d20 或 2d6 掷骰加到总数上，骰池加骰子，百分骰加点数。 |
| **Show ranks on the sheet as**(人物卡上的等级显示方式) | 人物卡在每项受过训练的技能和豁免旁显示的内容：**Check value (+2)**(检定值)、**Rank name**(等级名称)、**Dots (●●○)**(圆点)、**Roman numerals (II)**(罗马数字) 或 **Rank number (2)**(等级序号)。检定和旁白收到的那份人物卡都保持不变。 |
| **Practice meter**(练习进度) | 每项受过训练的技能都会显示它升到下一等级的进度，从 0 到 99%。故事里的练习会提高它，升级后从头开始。你可以在人物卡上修正它。在 **No meter for:**(不设练习进度) 下勾选一个分组，就能把它的技能排除在外。 |
| 资源池或轨道上的 **Number**(数字)、**Bar**(进度条) 或 **Dots**(圆点) | 只显示数字、在数字旁加一条进度条，或者显示一排圆点，填到该数值为止，每一点对应一个圆点。超过 20 个圆点时改为显示进度条。 |
| **Lists**(列表) | 每个列表都有自己的选项卡，以列表名命名，除非你另外输入选项卡名称。选项卡名称相同的列表共用一个选项卡。 |
| 列表的列 | 每一行都有一个名称，再加上你的列：**Text**(文本)、**Number** 或 **Checkbox**(复选框)。第一个复选框列会在每个名称旁边显示为一个对勾。 |

### 向旁白说明你的规则

**Prompts**(提示词) 分区存放旁白会收到的、关于你这个规则集的说明。**Checks**(检定) 和 **Keeping the sheets**(维护人物卡) 会显示默认内容；任何一个留空就使用默认内容。换行会变成空格。名称和提示词不能包含方括号或双花括号，因为旁白的标签和宏要用到它们。

| 输入框 | 用途 |
| --- | --- |
| **Checks** | 什么时候要求检定，以及怎样选择技能和难度。 |
| **Keeping the sheets** | 游玩过程中人物卡怎样变化。 |
| **Rules reference**(规则参考) | 房规，以及旁白应该始终放在眼前的其他内容。 |
| **World (Game Mode)**(Game Mode 世界) | 在这个规则集上创建 Game Mode 游戏时读取一次，让游戏世界契合这些规则。 |

## 故障排查

| 症状 | 解决办法 |
| --- | --- |
| **This chat's ruleset is not installed here, so its checks and sheets are paused.** | 重新安装这个规则集，或者换一个。 |
| 旁白从不要求检定。 | 给聊天换一个更强的模型。有些模型会跳过检定的指令。 |
| 新角色没有人物卡。 | 点击 **Add missing sheets**。 |
