# Roleplay：按规则集游玩

Roleplay 聊天可以按桌面规则集游玩，和 Game Mode 用的是同一类。遇到不确定的事情时，旁白会要求检定，Marinara 从人物卡掷骰，回复说明这次掷骰定下了什么。想在角色扮演里用真正的骰子和人物卡、又不想开一局 Game Mode 时，就用它。

你为 Game Mode 装过的任何规则集都能用，例如 5e (SRD 5.1)，你在角色编辑器和用户角色编辑器里已经为它建好的人物卡也能用。

## 为聊天开启规则集

开始之前：先安装一个规则集。见[获取规则集](../game/rulesets.md#get-a-ruleset)。

1. 打开 Roleplay 聊天。
2. 打开 **Chat Settings**(聊天设置)，找到 **Ruleset**(规则集) 分区。
3. 从列表里选一个规则集。列表显示你已安装的规则集。
4. Marinara 给聊天里的每个成员一张人物卡，并说明加了几张。每个成员都列在规则集下面。

每个成员会从角色编辑器或用户角色编辑器得到自己那张人物卡在这个规则集下的副本（见[规则集人物卡](../characters/colors-and-stats.md#ruleset-sheets)）。没有人物卡的成员会得到一张空白人物卡，在列表里标为 **blank sheet**(空白人物卡)，可以在聊天里填写。你的用户角色排在最前面。聊天里的改动只留在聊天里，绝不会写回角色或用户角色。

如果没有成功：导入的规则集需要开启 **Allow custom Agent imports**(允许导入自定义智能体)。见[获取规则集](../game/rulesets.md#get-a-ruleset)。

### 填写空白人物卡

1. 在 **Ruleset** 分区里，点击成员旁边的 **Build sheet**(建立人物卡)。
2. 人物卡在人物卡编辑器里打开。规则集带引导式构建器时，会先在那个构建器里打开，和 Game Mode 及角色编辑器里一样。
3. 做好选择，点击 **Save sheet**(保存人物卡)。

### 为新成员添加人物卡

之后有角色加入聊天时，点击 **Add missing sheets**(补齐缺少的人物卡)。已经有人物卡的成员保持原样。

### 移除人物卡

不该有人物卡的成员，例如旁白角色卡，可以拿掉它的人物卡。

1. 在 **Ruleset** 分区里，点击成员旁边的垃圾桶图标。
2. 点击 **Remove sheet**(移除人物卡)。

聊天会记住这一点，所以 **Add missing sheets** 和更新版本的规则集都会跳过这名成员。想再给他一张人物卡，就点击 **No sheet:**(没有人物卡) 后面那个以他命名的按钮，例如 **Give Mira a sheet**(给 Mira 一张人物卡)。

### 更换或关闭规则集

- 选择 **None**(无) 就不再按规则集游玩。人物卡会保留，所以再次选择同一个规则集时会从上次停下的地方继续。
- 换用别的规则集会让人物卡全部重新开始，因为为某个规则集做的人物卡对另一个规则集没有意义。

## 游玩中的检定

你照常写自己的回合。当角色尝试结果重要的不确定行动时，旁白会写一次检定，而不是直接决定结果。Marinara 从人物卡掷这次检定，然后由旁白写出掷骰定下了什么。

完成的消息会在检定发生的位置显示一张骰子卡片，包含技能、难度、骰子，以及 **Success**(成功) 或 **Failure**(失败)。不会真正失败的普通行动不会有检定。

> **提示：** 有些模型会忽略要求检定的指令，自己决定结果。如果一个检定都不出现，就给聊天的 **Connection**(连接) 换一个更强的模型。

**Impersonate**(代写) 回合不掷检定。多人模式房间不能按规则集游玩。

## 使用人物卡

在 **Ruleset** 分区里点击某个成员旁边的 **Open sheet**(打开人物卡)。这张人物卡和 Game Mode 显示的是同一张。Tracker Panel 顶部的卷轴按钮会打开你用户角色的人物卡。

- 点击资源池或轨道旁边的 **−** 和 **+**，例如生命值或压力，就能改动它。改动随当前这条消息保存，所以会跟着备选回复和分支走。
- 点击 **Edit ruleset sheet**(编辑规则集人物卡)，可以修改数值、技能等级、字段和列表，然后点击 **Save sheet**(保存人物卡)。

旁白在每个回合都会读人物卡，并用回复里的人物卡命令修改它们，Marinara 会执行这些命令，并把它们从消息里隐藏。要休息，就在你的回合里说明，例如“我们长休一次”。旁白会记录休息，人物卡会恢复规则集的休息所恢复的内容。也可以在人物卡上点击 **Rest**(休息)。

## 故障排查

| 症状 | 解决办法 |
| --- | --- |
| **This chat's ruleset is not installed here, so its checks and sheets are paused.** | 重新安装这个规则集，或者换一个。 |
| 旁白从不要求检定。 | 给聊天换一个更强的模型。有些模型会跳过检定的指令。 |
| 新角色没有人物卡。 | 点击 **Add missing sheets**。 |
