# 智能体：聊天里的 AI 帮手

本指南介绍 Marinara Engine 里的智能体是什么、怎么下载、什么时候运行，以及如何在某个聊天里开启它们，内容涵盖 **Agents**(智能体) 面板、官方目录、单个聊天的设置，还有怎么判断智能体是否运行过。完整的官方目录清单见文末的相关指南。

## 智能体是什么

智能体是一批小型 AI 帮手，会在主聊天回复的前后自动运行。你和角色聊天的时候，它们各自负责一件具体的事。比如有的智能体负责追踪时间和天气，或者挑选角色表情。有的会重写回复，把重复的词去掉。还有的会为重要时刻生成一张图像。

智能体按聊天开启，不按角色开启。角色卡上没有智能体开关。同一个角色的两个聊天，可以运行完全不同的智能体。每个聊天要运行哪些智能体，都在这个聊天自己的设置里选。

全新安装的 Marinara Engine 不带任何可选智能体，这样能让基础应用和 Termux 安装包更小。v2.3.0 以后的官方目录收录了 33 个一键安装包：6 个 Writer Agents、9 个 Tracker Agents、18 个 Misc Agents，其中包括 Long-Term Memory、Maps、Calls、Inventory Tracker 以及全部 6 款 Conversation 游戏。它们的源码、清单文件、可下载产物和仓库级目录都公开在 [Pasta-Devs/Marinara-Agents](https://github.com/Pasta-Devs/Marinara-Agents)。每个智能体的详细说明见[可下载智能体参考](built-in-agents.md)。想自己做一个，见[创建自定义智能体](custom-agents.md)。

## 三个阶段

每个智能体都在回复前后的三个时间点之一运行，这个时间点叫作智能体的 **pipeline phase**(流水线阶段)。它在智能体编辑器里设置，每个内置智能体也都有合理的默认值。

- **Pre-Generation**(生成前)：在 AI 写回复之前运行，可以先往提示词里补充有用的上下文。知识查询类智能体就在这个阶段运行。
- **Parallel**(并行)：和回复同时运行。它不等回复，也改不了回复。实时观众反应类智能体在这个阶段运行。
- **Post-Processing**(后处理)：在回复写完之后运行。它能读到回复，重写类智能体还能修改回复。大多数追踪器、文风清理智能体和图像智能体都在这个阶段运行。

## Agents 面板

从右侧面板的选项卡（Sparkles 图标）打开 **Agents** 面板。这里可以浏览、创建和整理智能体，相当于你自己的智能体库，而不是单个聊天的开关。

点击顶部的 **Download Agents**(下载智能体) 打开全屏的官方目录，桌面端和移动端都能用。选中一项，就能看到它的说明、支持的功能类型、下载体积、权限、版本兼容性和文档。点击 **Install**(安装) 即可添加；同一个界面还提供立即手动更新，以及对已安装包的 **Uninstall**(卸载)。Marinara 还会在服务器启动时检查每个已安装的官方包，在它的运行时激活之前升级到目录里最新的兼容版本。主机服务器不在线，或者更新无法验证时，这些包会继续以当前版本工作。

应用内的目录背后是公开的 [Marinara-Agents 仓库](https://github.com/Pasta-Devs/Marinara-Agents)。每个包和产物都可以在那里查看，但一般情况下还是通过 **Download Agents** 安装，这样 Marinara 才能校验兼容性、权限、哈希、压缩包内容和重启要求。

目录里收录了官方聊天智能体、World Maps、Conversation 的音视频通话，以及全部可选的 Conversation 游戏。已安装的智能体会分成 **Writer Agents**(写作智能体)、**Tracker Agents**(追踪器智能体) 和 **Misc Agents**(其他智能体) 三组，自己做的则放在 **Custom Agents**(自定义智能体) 分区。卸载目录里的包，会从 Engine 中删掉它的代码和设置，聊天消息和历史记录仍然保留。删除自定义智能体则是彻底删除。

从内置这些功能的旧版 Engine 升级上来时，Marinara 会把对应的包下载一次，并保留已有的聊天选择、智能体设置、存储的运行时数据和历史记录。如果这次迁移连不上目录，它会在下次启动时重试，不会丢弃任何东西。

启动时的自动更新绝不会安装你没有选择的包。桌面端、Docker 和 Android/Termux 安装会更新本地服务器保存的包。iOS、iPadOS 和其他浏览器客户端使用的，是它们所连接的那台 Marinara 服务器安装并更新的包。

## 为聊天开启智能体

智能体在每个聊天内部开启，位置在 **Chat Settings**(聊天设置) 面板里。

1. 打开想要设置的聊天。
2. 打开 **Chat Settings**(齿轮图标)。
3. 找到 **Agents** 分区。
4. 开启 **Enable Agents**(启用智能体)。这是总开关，关闭之后这个聊天不会运行任何智能体。
5. 从开关下方的列表里添加想用的智能体，或者移除不想要的。

添加过的智能体应该会列为已激活，每个后面带一个小的移除按钮。

**Agents** 分区里还有几个控制项：

- **Review Agent Outputs**(审核智能体输出)：开启后，世界书、摘要和角色卡的改动要经过你批准才会保存。关闭后，世界书和摘要的改动可以自行保存，但角色卡的编辑仍然会先征求你的意见。见[智能体审批与 Agent Suite](approvals-and-agent-suite.md)。
- **Manual Trackers**(手动追踪器)（仅限 Roleplay 聊天）：开启后，追踪器智能体不再每次回复之后都运行，改由你从 HUD 上的按钮手动触发。HUD 指抬头显示，也就是 Roleplay 里屏幕上的状态浮层。
- **Agent Suite**：打开一个查看器，可以读取和编辑智能体为这个聊天存下的全部内容。

### 开销提醒

智能体会额外消耗 Token(模型切分文本的最小单位)，也会额外增加模型调用。每个智能体都要加上自己的指令，往往还要单独调用一次模型。共用同一个连接的智能体，Marinara 会尽量合并成一次调用。智能体列表上方有一处读数，估算当前配置的负担，显示新增的智能体指令大约有多少 Token，以及每一轮大约会多出多少次调用。

负担变重时，这处读数会变成琥珀色，并带上警告图标。实际每轮的开销比显示的数字更高，因为每次调用都会带上聊天历史和角色详情。看到警告的话，可以移除用不上的智能体，或者把一部分挪到更便宜的连接或本地连接上。

## 各个模式一开始有哪些智能体

全新安装不会安装或激活任何可选智能体。每个聊天模式只显示已安装且兼容的包。

- **Roleplay**：先从目录安装 Roleplay 智能体，再在 Chat Settings 里添加。World Maps 也和其他受支持的智能体一样出现在那里。
- **Conversation**：从目录安装 Calls 或单个桌面游戏。游戏会出现在游戏选择器里，并注册各自的斜杠命令；通话则会加上自己的工具栏和 Chat Settings 控制项。
- **Game Mode**：兼容 Game 的已安装智能体可以在创建游戏时选择，也可以之后再加。只有在某局游戏里激活 World Maps，它才会提供地图工作区和世界地图视图。

兼容的智能体随时可以添加或移除。

## 怎么判断智能体运行过

有些智能体的改动一眼就能看到，有些则悄悄干活。可以这样检查。

- 追踪器智能体会写入 HUD 和追踪器面板。时间、地点、心情或数值有更新，就说明有追踪器智能体运行过。
- 智能体工作时，会有一个浮动状态浮层显示简短的思考信息，可以实时看着它们运行。
- **Prose Guardian** 和 **Continuity Checker** 这两个智能体会直接改动回复文本。回复读起来更干净，或者错误得到纠正，就是它们运行过的迹象。
- 想看完整的追踪记录，到 **Settings**(设置) → **Advanced** → **Message Tools** 里开启 **Debug mode**(调试模式)。它会把每个智能体的提示词和响应记到服务器控制台，还会显示一个 **Agent Debug** 浮层，列出每个智能体的调用、Token 和耗时。

有智能体没按预期运行？先看 **Enable Agents** 是不是开着，再看这个智能体在当前聊天里是否激活，最后确认当前聊天模式支持它。
