# 智能体审批与 Agent Suite

本指南介绍如何审核并控制智能体（在回复旁边同时运行的小型 AI 帮手）在聊天中写入的内容，包括 **Review Agent Outputs**(审核智能体输出) 开关、两种审核窗口、**Agent Suite**(智能体套件) 编辑器，以及 **Cached prompt injections**(缓存的提示词注入) 面板。

## Review Agent Outputs

有些智能体会往聊天里写入新数据。世界书智能体可以新增世界书条目，摘要智能体可以保存一份聊天摘要。默认情况下，其中一部分写入会自动保存。开启 **Review Agent Outputs** 开关，就能逐条先行确认。

找到这个开关的方法：

1. 打开想要控制的聊天。
2. 打开 **Chat Settings**(聊天设置)。
3. 滚动到 **Agents**(智能体) 区域。
4. 开启 **Review Agent Outputs**。

**Review Agent Outputs** 开启时，世界书更新、摘要更新，以及其他可审核的写入型智能体输出，都要等你批准才会保存。关闭时，世界书更新和摘要更新可以自动保存。

角色卡的修改是个例外。即使 **Review Agent Outputs** 是关闭的，这类修改也一律先征求你的批准。这道安全检查无法关闭。

## 智能体写入审批窗口

**Review Agent Outputs** 开启时，只要有智能体提出世界书或摘要写入，就会弹出一个审核窗口。窗口标题按写入类型显示为 **Review Lorebook Update** 或 **Review Summary Update**。

窗口中会显示：

- 提出这条建议的智能体名称。
- 一个 **Proposed Text**(建议文本) 框，保存前可以直接改。
- 世界书写入还会附一句提醒：每个条目都要放在 `###` 标题下面。

窗口底部有三个选择：

- **Accept**(接受)：把文本（含你所做的修改）保存进聊天。
- **Regenerate**(重新生成)：只重跑这一个智能体，换一份新建议。
- **Discard**(丢弃)：直接扔掉这条建议，不做保存。

如果还有别的建议在排队，窗口会显示剩下多少条。处理完当前这条，窗口会自动为下一条重新打开。

## 角色卡更新审核

**Card Evolution Auditor** 智能体可以根据 Roleplay(角色扮演) 里发生的事，给角色卡字段提出修改建议。Conversation(对话模式) 内置的 `update_about_me` 工具也能提议修改公开的 About Me。这两条路径都不会自己动角色卡，而是打开 **Review Character Card Updates** 窗口，交给你决定。

窗口会逐条列出建议的修改。每条修改都能看到：

- 涉及的角色卡字段（例如 description、personality 或 appearance）。
- 一句简短的修改理由，前提是智能体给出了理由。
- 一个 **Before**(修改前) 块，显示当前文本。
- 一个 **After**(修改后) 框，显示新文本。批准之前可以先改这段文字。

可以执行这些操作：

- **Approve**(批准)：应用这些修改。按钮上的数字表示会应用多少条。批准后角色的版本号会加一，并保存一条版本历史记录。
- **Regenerate**：重跑这个智能体，换一批建议。
- **Reject**(拒绝)：不采纳这些建议，角色卡保持不变。

有时候智能体写完建议之后，角色卡又发生了变化。这种情况下，应用会把这条修改标记为 **stale**(已过期) 并置灰显示。只要存在过期的修改，就会出现一个带数量的 **Override stale**(强制应用过期修改) 按钮。只有确实还想保留那段文字时才用它。应用会先让你确认，然后把过期文本追加到该字段，而不是去替换已经对不上的内容。

## Agent Suite 编辑器与 AI 辅助改写

**Agent Suite** 可以查看和编辑这个聊天里所有智能体存下来的内容，既包括追踪器数据（例如当前场景、在场角色、用户角色属性），也包括自定义智能体保存的输出。名字写错、数值不对、存下来的文本乱七八糟，都可以手动改，也可以让 AI 帮忙。

打开方式：

1. 打开 **Chat Settings**。
2. 滚动到 **Agents** 区域。
3. 点击 **Agent Suite**。

左侧是这个聊天里活跃的智能体列表，选中一个就能看到它存了什么。右侧是可编辑的区块，分成 **Stored Memory**(存储记忆)、**Tracker Data**(追踪器数据，只有追踪器智能体才有) 和 **Recent Outputs**(最近输出，只有自定义智能体才有) 三组。不追踪数据的智能体只显示 **Stored Memory**。

每个区块都是一个文本或 JSON 编辑器。改完一个区块之后：

- 点击 **Save**(保存) 保留改动。
- 点击 **Reset**(重置) 撤销尚未保存的改动，回到已存储的值。

也可以让 AI 替你改写某个区块：

1. 在要改的区块上点击 **AI Edit**(AI 编辑)。
2. 只想改其中一部分时，先在编辑器里选中那部分。不选任何内容，整个区块都会重写。
3. 输入一条指令，例如“把弄乱的角色名改对，她叫 Mira”。
4. 可选：点击 **Add Context**(添加上下文) 附上角色卡或世界书条目，帮助 AI 理解这些数据的含义。
5. 选择由哪个连接（AI 服务商和模型）来完成改写。
6. 点击 **Rewrite**(改写)。

改写出来的文本会作为未保存的草稿填进区块。看过之后，点击 **Save** 保留，或点击 **Reset** 丢弃。

几点提醒：

- 这个聊天还有智能体在运行时，保存会暂停，要等它们跑完。
- **Stored Memory** 区域有一个 **Clear memory**(清除记忆) 按钮，只在该智能体确实存了数据时才出现。它会一次性删掉这个智能体为当前聊天存下的全部内容，而且无法撤销。应用会先让你确认。
- 对 **Narrative Director** 来说，存储的剧透内容是隐藏的。用 **Reveal spoilers**(显示剧透) 才能查看和编辑。

## Cached prompt injections 面板

生成回复之前，有些写入型智能体会往提示词里追加文字，**Prose Guardian**、**Narrative Director** 和自定义注入智能体尤其常见。**Cached prompt injections** 面板就是用来排查这些追加文字的，在 Roleplay 的 **Agent activity** 中打开 **Injections** 选项卡即可找到，只有开启 **Debug mode** 时才显示，见[智能体活动](../roleplay/getting-started.md#agent-activity)，内容对应最近一次回复。

每条缓存的注入都可以：

- 展开阅读并编辑文本。
- 点击 **Save** 图标保留改动。
- 点击 **Re-run**(重新运行) 图标，让那一个智能体重写一份注入。

**Knowledge Retrieval** 和 **Knowledge Router** 的注入无法在这个面板里重新运行。你的编辑和重新运行，只有在重新生成同一条回复时才会生效。重新运行用的是那个时间点的原始聊天记录，不包含之后的新消息。
