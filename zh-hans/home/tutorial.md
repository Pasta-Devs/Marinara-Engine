# 首次使用的引导教程

引导教程是一段导览，第一次打开 Marinara Engine 时就会开始。内置助手 Professor Mari 会带你把应用的主要部分逛一遍。用这份指南可以跳过教程、重看教程，或者了解每一步讲了什么。

## 重看引导教程

1. 回到主页。
2. 点击 **Tutorial**(教程) 书签，或者点击 **Learn the engine**(了解引擎) 小组件里的 **Replay tutorial**(重看教程)。

教程会从第一步重新开始。在手机上，点击标签页左侧的书签按钮就能看到这些书签。

## 跳过引导教程

每张卡片上都有跳过按钮。第一张卡片上写的是 **Skip Tutorial**(跳过教程)，之后的卡片上写的是 **Skip**(跳过)。点击它就会立刻结束教程。

- **Skip**、**Skip Tutorial** 和 **Get Started**(开始使用) 都会把教程标记为已完成，之后它不会再自动开始。它们还可能解锁 **Diligent Student** 成就。
- 只有 **Get Started** 会保存你在最后一张卡片上选的指南语言（也就是应用内指南使用的语言）。**Skip** 会保持原样。之后可以在 **Settings → General**(设置 → 常规) 里修改。

## 教程是怎么进行的

教程一次只显示一张卡片。每张卡片包含一个标题、一段简短说明和一排进度圆点。在普通的桌面屏幕上，会有一圈脉动的光环高亮出卡片正在讲的那个按钮。

有些步骤还会替你打开对应的面板或选项卡。比如 **Connections**(连接) 这一步会打开 **Connections** 面板。

点击 **Next**(下一步) 进入下一张卡片。到了最后一步，这个按钮会变成 **Get Started**。

在手机或其他窄屏设备上，每张卡片都居中显示在顶栏下方。脉动光环不会出现。面板照样会打开，只是以全屏覆盖层的形式显示。

## 参考：18 个步骤

| # | 卡片标题 | 讲解内容 |
| --- | --- | --- |
| 1 | **Welcome to Marinara Engine!** | 居中的欢迎卡片。Professor Mari 提出带你四处看看。 |
| 2 | **Characters** | **Characters**(角色) 面板按钮，角色都放在这里。 |
| 3 | **Personas** | **Personas**(用户角色) 面板按钮，在这里定义你在聊天里的身份。 |
| 4 | **Lorebooks** | **Lorebooks**(世界书) 面板按钮，里面存放额外的世界设定和角色细节。 |
| 5 | **Presets** | **Presets**(预设) 面板按钮，它决定提示词怎么拼装。 |
| 6 | **Connections** | **Connections** 面板按钮。开始聊天前，第一件要设置的就是连接。 |
| 7 | **Agents** | **Agents**(智能体) 面板按钮。卡片会指引你到 **Agent Organizer**(智能体管理器) 安装智能体。 |
| 8 | **Settings** | **Settings**(设置) 面板按钮。打开 **Settings** 的 **General** 选项卡。 |
| 9 | **Chats** | 侧边栏开关。打开聊天侧边栏。 |
| 10 | **Conversation Mode** | Conversation(对话模式) 选项卡，标签显示为 **CONVO**。 |
| 11 | **Roleplay Mode** | Roleplay(角色扮演) 选项卡，标签显示为 **RP**。 |
| 12 | **Game Mode** | Game Mode(游戏模式) 选项卡，标签显示为 **GM**。 |
| 13 | **Home: Your Story Hub** | 回到主页。主页是你继续聊天、开始新聊天和摆放小组件的地方。 |
| 14 | **Ask Me Where Things Are** | 主页顶部的搜索栏。在手机上，卡片会提示你从应用的顶栏往下拉。 |
| 15 | **Guides and Home Controls** | **Documentation**(文档)、**Tutorial**、**FAQ**(常见问题) 和 **Widgets**(小组件) 书签。 |
| 16 | **Migrating from SillyTavern?** | 又轮到 **Settings** 按钮。打开 **Settings** 的 **Imports**(导入) 选项卡。 |
| 17 | **You're All Set!** | 再一次轮到 **Connections** 面板按钮。 |
| 18 | **One Last Thing: Guide Language** | **Documentation** 书签。**Documentation Language**(文档语言) 列表用来设置应用内指南的语言。还没翻译的指南会以英文显示。 |
