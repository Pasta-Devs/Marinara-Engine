# Professor Mari，你的应用内助手

Professor Mari 是主页上的内置助手。她能讲解这个应用、帮你完成配置，还能替你创建或编辑角色、用户角色、世界书和预设。她做的改动在一段有限的时间内可以从改动卡片上撤销（见[审查她的改动](#reviewing-her-changes)）。

<a id="where-to-find-her"></a>

## 去哪里找她

1. 打开主页。没有打开任何聊天时显示的就是主页。
2. 点击 **Professor Mari** 小组件里的 **Ask Professor Mari**(问问 Professor Mari)，或者点击 **Professor**(教授) 标签页。

她的窗口随即打开。在任何界面也都能找到她：在 Search(搜索栏) 里打字并选择 **Ask Prof. Mari**，按 <kbd>Ctrl</kbd>+<kbd>J</kbd>(Mac 上是 <kbd>⌘</kbd>+<kbd>J</kbd>)，或者在手机上从顶栏往下拉。她空闲时，标题栏显示 **Ready to help**(随时待命)，干活时显示 **Working on it...**。

用日常语言写好消息，按 <kbd>Enter</kbd> 发送。<kbd>Shift</kbd>+<kbd>Enter</kbd> 换行。如果在她的设置里关掉 **Enter sends to Professor Mari**(按 Enter 发送给 Professor Mari)，<kbd>Enter</kbd> 就变成换行，按 <kbd>Ctrl</kbd>+<kbd>Enter</kbd> 才发送。你的第一条消息会解锁 **Hello World** 成就。

她的所有设置都在 **Settings → General → Search and Professor Mari settings → Open**(设置 → 常规 → Search 与 Professor Mari 设置 → 打开) 里，也可以点 Search 里的齿轮图标。在电脑上，**Professor Mari window**(Professor Mari 窗口) 下的 **Height**(高度) 和 **Width**(宽度) 滑块可以调整她窗口的大小。在手机上，她的窗口会占满屏幕。

## 和 Mari 一起做一个角色

开始之前：先添加一个用于文本生成的账号。见[连接 AI 服务商](../connections/connecting-to-a-provider.md)和[为她选择账号](#pick-an-account-for-her)。

1. 打开她的窗口（见上文）。
2. 如果聊天里已经有消息，先点击 **New chat**(新建聊天)。当前聊天会保存在 **Chats**(聊天) 里。
3. 点击 **Create a character**(创建角色) 小标签。它会填好输入框。如果没有显示小标签，就自己输入请求。
4. 在文字里补上你的想法，比如名字和性格，然后按 <kbd>Enter</kbd>。
5. 回答她的问题。选一个选项或自己输入，然后点击 **Submit**(提交)。
6. 她完成后，点击结果上的 **Open**(打开)，查看新角色。
7. 如果不喜欢某处改动，就点击它改动卡片上的 **Undo**(撤销)。

如果没有成功：还没添加账号时，按下发送会打开 **Connections**(连接) 列表。在那里选择或添加一个账号。

## 她能做什么

她在编辑某样东西之前会先读一遍，你的要求不够具体时她会追问。

- 讲解某个设置、某种模式或某个概念。
- 创建或编辑角色、用户角色或世界书。角色卡为 AI 设定名字、性格和说话方式。用户角色是代表你的那张角色卡。世界书是一组世界设定，相关关键词出现时 AI 会读到它们。
- 为角色编写[交互式引导](../characters/interactive-onboarding.md)，并为已安装的 Game Mode(游戏模式) 规则集填写[规则集人物卡](../characters/colors-and-stats.md#ruleset-sheets)。数值不符合规则集时，她的改动会被拒绝，并附上原因。
- 创建或编辑主题、智能体、提示词预设或 Personal Extension(个人扩展) 草稿。在你读过草稿的代码并在 **Settings → Addons**(设置 → 插件) 里批准之前，它一直处于关闭状态。
- 就地编辑预设的某一部分，而不必替换整份预设。
- 对比各个可下载的智能体，告诉你哪些适合你的目标。她会让你去 **Agents → Agent Organizer**(智能体 → 智能体管理器) 安装它们。见[可下载智能体参考](../agents/built-in-agents.md)。
- 生成或指定图像，比如头像、立绘和背景。你需要先有一个图像生成账号，她不会替你创建。
- 你研究某个角色或世界观时，查阅公开的 Fandom wiki 页面。

### 从小标签开始

在空白的 Professor Mari 聊天里，起步小标签帮你开个头：**Create a character**、**Create a lorebook**(创建世界书) 和 **Create a persona**(创建用户角色)。点击一个小标签会填好输入框，发送前可以修改文字。在引导式任务中，小标签会随下一步变化。小标签只在 Professor Mari 聊天里显示。

当你的请求里还有真正需要拿主意的地方，她可以在回复下方的问题卡片上提问：最多四个问题，一次一个，附带选项，她推荐的选项会做上标记。选一个选项或自己输入，然后点击 **Submit**。你的回答会作为你的下一条消息发出。你也可以不理会卡片，直接输入一条消息。她随问题一起提出的内容，在你回答之前都不会执行。

### 从手头的工作直接问她

从下面这些地方打开她时，会带上一份可编辑的草稿和一个 **Context**(上下文) 小标签（输入框上方的一个标签），发送前可以删掉：

- **Character**(角色)、**Persona**(用户角色)、**Lorebook**(世界书) 和 **Preset**(预设) 编辑器。
- **FAQ**(常见问题) 答案：**Ask Prof. Mari about this**(就此问问 Professor Mari)。
- Search：选中一个结果，然后选 **Ask Prof. Mari**。
- **Try again**(再试一次) 这类出错状态：**Ask Professor Mari**。

仅仅打开某个编辑器，并不会让她拿到完整的项目。

<a id="pick-an-account-for-her"></a>

## 为她选择账号

开始之前：先添加一个用于文本生成的账号。见[连接 AI 服务商](../connections/connecting-to-a-provider.md)。

1. 点击回形针旁边的连接按钮。它显示她所用账号的名称，还没选时显示 **Select connection**(选择连接)。
2. 从 **Connections** 列表里选一个文本生成账号。如果你下载了 **Built-in model**(内置模型)，它也会出现在这里。
3. 点击列表里的某个模型来使用它。模型会保存到这个账号上，所以使用这个账号的其他聊天也会一起切换。**Built-in model** 没有模型列表。

在手机上，点按某个账号即可使用它，或者点按那一行末尾的箭头先查看它的模型。还没有任何账号时，列表显示 **Add a connection**(添加连接)。

<a id="reviewing-her-changes"></a>

## 审查她的改动

她改动某样东西时，会立刻保存，并在回答下方给出一张改动卡片。卡片会列出每个改动过的字段。文字编辑会同时显示原来的和新的文字。**Show all**(全部显示) 显示所有字段，**Technical details**(技术细节) 显示原始命令。

卡片上只有一个操作：**Undo**。它会把上一个保存的版本放回去。只要撤销副本还在，无论哪种权限模式，每次改动都可以撤销。权限模式只决定她会不会先征求你的同意。

- 显示 **Not saved**(未保存) 并附上原因，说明改动失败了。**Try again** 会再请她做一次。
- **Undo until**(可撤销至) 只在最后 24 小时里显示。撤销副本最多保留 14 天，而且只保留最新的 50 份。超过之后，卡片显示 **Undo closed**(已无法撤销)，改动会保留下来。
- 她工作列表里以 **· not saved**(未保存) 结尾的步骤只是预览，没有任何改动。
- 不会改变任何内容的编辑不会被保存，也不会生成卡片。
- 角色和用户角色在各自的编辑器里还保留着版本历史，相当于第二条退路。
- 她不能编辑或删除自己的角色卡。Marinara 每次启动都会重置它。

卡片属于她做出改动时所在的那个聊天。删除聊天会保留其中的改动，并移除对应的卡片。

### 等你决定的改动

被暂缓的改动不会保存，而是停下来等你。它显示 **Apply**(应用) 和 **Don't apply**(不应用)。删除操作显示 **Delete**(删除) 和 **Put back**(放回)。在 Manual 模式下，以及涉及敏感文件和依赖时，改动都会被暂缓（见[文件和库的暂缓改动](#held-changes-for-files-and-libraries)）。Search 不会列出她的改动：要应用或撤销它们，请打开 Professor Mari。

她创建或更新角色、用户角色、世界书或预设后，结果上可能显示 **Open**，用它可以打开那个项目。有待处理的审查时，更新的结果上还可能显示 **Review**(审查)。

## 回形针菜单

点击标着 **Attach**(附加) 的回形针按钮。菜单分为三个部分。

| 部分 | 项目 |
| --- | --- |
| **Attach** | **Attach files or photos**(附加文件或照片)、**Add chat history**(添加聊天记录)（分享你过去的一段聊天）、**View attached context**(查看附加的上下文) |
| **Reference**(引用) | **Link with @**(用 @ 链接) |
| **Mari** | **New chat**、**Chat history**(聊天记录)、**Skills**、**Memories**(记忆)、**Model**(模型)、**Permissions**(权限)。有改动在等你处理时，会显示 **Pending approvals**(待批准)。 |

同样的操作也可以用 `/` 输入。见[用 / 输入命令](#commands-with-)。

### 附加文件

选择 **Attach files or photos**，或输入 `/attach`。她接受图片、PDF 文件，以及 `.txt`、`.md`、`.json`、`.csv` 和 `.log` 这类文本文件，单个文件最大 20 MB。你也可以把截图或文件直接粘贴到输入框里。想让她读图片，所选模型必须支持图像输入。

### 用 @ 链接内容

输入 `@`，就能把你资料库里的某样东西指给她。随即会打开一个列表，分为 **Characters**(角色)、**Personas**(用户角色)、**Lorebooks**(世界书)、**Presets**(预设)、**Skills**、**Memories**、**Chats**、**Agents**(智能体) 和 **Docs**(文档) 几组。继续输入可以缩小范围。名字里有空格也不必加引号。

- 用方向键移动，按 <kbd>Enter</kbd> 或 <kbd>Tab</kbd> 选择，按 <kbd>Escape</kbd> 关闭。在世界书上按右方向键会列出它的 **Entries**(条目)，这样就能只链接其中一条。
- 在编辑器旁边时，第一行 **Open beside me**(旁边已打开的内容) 会链接该编辑器当前打开的内容。在角色编辑器旁边时，点这一行的 ›，或者按右方向键，会列出 **Fields**(字段)。选中一个字段会切换她处理的字段，并替换她上下文行里的字段小标签。
- 选中的名字会以小标签的形式显示在输入框上方。删掉名字，链接也会随之消失。小标签上的 **×** 会移除链接，但保留你的文字。
- 在普通文本中，<kbd>Tab</kbd> 会补全她用灰色建议的名字。再按一次 <kbd>Tab</kbd> 即可把它变成链接。在触屏上，点按灰色名字，然后点按 **Tap to link**(点按转为链接)。

| 链接 | 她收到的内容 |
| --- | --- |
| 角色、用户角色、预设 | 完整的项目 |
| 世界书 | 它的设置和条目列表 |
| 世界书条目 | 该条目，以及它所属的世界书 |
| Skill | 你自己的 Skill 的指令。内置 Skill 会在这条消息里作为她的手册打开。 |
| 记忆 | 记忆的完整文字，即使它已关闭 |
| 聊天 | 聊天的详细信息和最新的 30 条消息 |
| 智能体 | 智能体的设置 |
| 文档 | 本文档中的整页内容 |

链接只发送一次，随你添加它的那条消息一起。之后她只会看到一行备注，需要时会重新读取那个项目。一条消息最多带 8 个链接。如果它们加起来超过模型上下文的约四分之一（最多 60,000 个字符），最后的几个就不会发送。她会改为收到一条备注，可以自己去读。被链接的内容只算作信息，绝不会被当作指令。

<a id="commands-with-"></a>

### 用 / 输入命令

在一行的开头输入 `/`，会列出她的命令。继续输入可以筛选，然后按 <kbd>Enter</kbd>。列表里也会显示你的 Skills 和 Memories。选中其中一个，就会像 `@` 一样把它链接进来。

| 命令 | 作用 |
| --- | --- |
| `/new` | 开始新的聊天，并保存当前聊天（也可以用 `/restart`） |
| `/history` | 打开你和她过去的聊天 |
| `/skills` | 打开 **Skills** 面板 |
| `/memories` | 打开 **Memories** 面板 |
| `/context` | 查看这个聊天附加了什么 |
| `/attach` | 选择要发送的文件或照片 |
| `/model` | 选择她使用的账号 |
| `/permissions` | 选择她可以改动什么 |
| `/approvals` | 打开等你处理的改动（仅在有改动待处理时） |

<a id="sending-messages-while-she-works"></a>

## 她干活时发送消息

她干活期间，输入框仍然可用。由你决定消息何时送到她那里。

- **Send now**(立即发送) 会在她的下一步插入，不会打断她。她到目前为止的回复会被保存，你的消息显示在它下面，她会带着你说的话继续。
- **Send after her answer**(等她回答完再发送) 会在输入框上方的列表里等待，标着 **Sends when she finishes**。她顺利完成后，会一次取一条等待中的消息。

- **Enter sends** 开启（默认）：<kbd>Enter</kbd> 立即发送。<kbd>Ctrl</kbd>+<kbd>Enter</kbd> 加入队列。
- **Enter sends** 关闭：<kbd>Ctrl</kbd>+<kbd>Enter</kbd> 立即发送。<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd> 加入队列。

在 Mac 上，用 <kbd>⌘</kbd> 代替 <kbd>Ctrl</kbd>。她干活时，输入框为空就只显示一个 **Stop**(停止) 按钮，点它会取消当前任务。你一打字，**Stop** 就变成发送按钮。点击它可以选择 **Send now** 或 **Send after her answer**，在手机上很方便。

Send now 只适用于纯文字。带文件、`@` 链接或交给她的某个字段的消息，会改为加入队列。谈的是另一个话题的消息，或在你更改权限模式之后发出的消息，也一样。界面会弹出一条简短提示说明。点消息上的 **X** 可以移除它。一个聊天最多能容纳 20 条等待中的消息。

在以下情况，等待中的消息不会自动发送：

- **你按了 Stop。** 它们会回到输入框。
- **她在等你**（等你批准或回答问题），或者**运行失败、应用重启了。** 它们会显示 **Held**，旁边有 **Send**(发送) 按钮。**Send** 只发送那一条。

`/restart` 和 `/title` 在她干活期间不起作用。它们会留在输入框里，直到她忙完。

做较长的工作时，她会在最新消息下方列一份待办清单，带有 **2 of 5** 这样的计数。你不能编辑它。你写了新消息之后，清单会变淡，并显示 **Plan from before your last message**。

## 找到你的 Professor Mari 聊天

她的聊天和你平时的聊天列表是分开的。

1. 点击她标题栏里的 **Chats**。
2. 用 **Search Prof. Mari chats**(搜索 Professor Mari 聊天) 查找某个聊天。点击一个聊天，可以打开、重命名或删除它。

点击 **New chat** 或输入 `/new`，即可重新开始。它会先保存当前聊天，并显示 **Professor Mari's previous chat was saved.**

## Search 中的快速回答

快速回答默认关闭，要在 **Search and Professor Mari settings**(Search 与 Professor Mari 设置) 里打开 **Quick answers in Search**(Search 中的快速回答)。在 Search 里输入一个问题、又没有匹配的结果时，她会在一张 **Quick answer · Read-only**(快速回答，只读) 卡片里写一段简短的只读回答。

- 回答最多三句话，内容来自 Marinara 文档，会注明用到了哪些页面，也不会改动任何东西。五分钟内重复问同一个问题，会直接使用保存下来的副本。
- 回答下方有 **Copy**(复制)、**Answer again**(重新回答) 和 **Continue with Prof. Mari**(和 Professor Mari 接着聊)。最后一个会打开她的窗口，新建一个以你的问题命名的聊天。
- **Wait after typing**(输入后等待) 决定 Search 等多久。**Answer with**(回答使用) 选择由谁来回答：你下载的模型、**Same as Prof. Mari**(与 Professor Mari 相同)，或者另一个账号。每次回答都是一次简短的请求，所以付费账号可能会产生费用。
- 回答失败时，卡片会说明原因。只有缺少密钥或模型时，才会显示 **Choose a model**(选择模型)。服务自己的报错信息在 **Details**(详细信息) 里。

## 参考：设置、Skill 和记忆

### 状态线和顶栏胶囊

她干活时，你可以关掉她的窗口。顶栏底部有一条细线：她干活时线条会波动，完成后变成绿色，有批准在等待时变成金色，上一次运行失败则变成红色。她的窗口关着时，顶栏上的一个胶囊会显示 **Working**(工作中)、**Needs you**(需要你)、**Done**(完成) 或 **Failed**(失败)。点击胶囊即可回到她的聊天。

### 外观

在 **Search and Professor Mari settings → Appearance**(Search 与 Professor Mari 设置 → 外观) 下为她挑一个形象，例如 **Basic**、**Prof. Mari loves Dottore** 或 **Safari Prof. Mari**。这个形象会显示在她的聊天、Search、主页和顶栏里。有些形象要玩够一定时长才会解锁，未解锁的形象会显示你目前已经玩了多少小时。

### Skill

Skill 是一份简短的说明文档，用来改变她处理某一类请求的方式。

1. 点击她标题栏里的 **Skills**。**Professor Mari skills** 面板随即打开。
2. 点击 **New**(新建) 从模板开始写，或者点击 **Upload**(上传) 添加一个 `.md` 或 `.txt` 文件。
3. 选中一个 Skill，编辑它的 **Name**(名称)、**Description**(描述) 和 **Instructions**(说明)，然后点击 **Save**(保存)。点击 **Delete** 可以删掉它。

把 Skill 关掉，它会保留下来，只是不会被用到。一个 Skill 都没有时，面板显示 **No custom skills yet**。

内置 Skill 列在 **Always on**(始终启用) 下，标记为 **Built-in**(内置)。它们是她处理角色、世界书、预设、主题、扩展、主页小组件等事务的手册。它们是只读的，应用更新时会被替换。想改其中一个，就把它的文字复制到一个你自己的新 Skill 里。

### 记忆

记忆是她长期记住的一条偏好，比如你喜欢世界书条目用什么做关键词。可以直接告诉她（“记住，我的条目一律用角色的名字做关键词”），也可以打开她标题栏里的 **Memories**，新建、编辑、开启或关闭、删除记忆，或者 **Upload** 一个文本文件。

- 她保存的记忆初始是关闭的。改动卡片上会提供 **Turn on**(开启)。只有你开口要求时她才会保存记忆，绝不会因为读到的东西这么说就照做。
- 每一轮她只看到一份已启用记忆的简短索引，某条记忆相关时再去读它的完整文字。**Persistent**(常驻) 记忆每一轮都摆在她面前，所以这类记忆要少而精。
- 记忆和她的默认习惯冲突时，以记忆为准。

## 信任与恢复状态

打开她标题栏里的 **Context**，可以看到下一条消息会带上什么、哪些内容会留在这个聊天里，以及她的工作方式：所用的模型、上下文预算，以及她的 shell 是否在沙箱里运行。标题栏还会显示待批准的事项、Skills 和 Memories。**Context** 不会授予额外的访问权限。

请求失败时，聊天会保留失败原因；可以重新发送时，还会显示 **Retry**(重试)。先解决界面上指出的账号、沙箱或访问问题。如果你的问题没有保存下来，它会连同文件一起回到输入框里。之后 **Retry** 和 **Retry with another model**(换个模型重试) 会发送输入框里的内容。

## 阅读 FAQ

点击 **FAQ** 书签，或者 **Learn the engine**(了解引擎) 小组件里的 **Read FAQ**(查看常见问题)，即可打开 **Professor Mari's FAQ**(Professor Mari 的常见问题)。这是一份写好的固定清单，不是 AI 聊天，所以它不了解你的配置。在 **Search FAQ**(搜索常见问题) 里输入文字可以筛选。每个问题都带一个分类标签，比如 **Setup**、**Connections** 或 **Game Mode**。点一下问题就能看答案。

## 限制和安全

- 她没法保证自己内置的知识和你的应用版本对得上。凡是和版本相关的内容，以指南和发行说明为准。
- 创建新内容通常很安全。编辑已有内容就要多留心。把具体是哪个项目、哪个字段说清楚：“把 Luna 的开场白改短一点，性格保持不变”比“把这个角色整个重写一遍”更安全。
- 如果她说做完了，应用里却看不到，以应用为准，到对应的面板里把事情做完。
- 从另一台设备访问 Marinara 时，她的编辑操作需要先配好远程访问。见[远程访问：登录与 IP 允许列表](../REMOTE_ACCESS.md)。

## 故障排查

| 症状 | 解决办法 |
| --- | --- |
| 没有回复 | 看看 **Context** 里显示的账号，或者用连接按钮选一个。一个都没有的话，在 **Connections** 里添加一个。 |
| 按下发送时打开了 **Connections** 列表 | 还没有选账号。选一个，或者点击 **Add a connection**。 |
| 交接带错了项目 | 删掉那个上下文项，切换到正确的 Professor Mari 聊天，再从原来的地方重新发起交接。 |
| 结果没有出现在编辑器里 | 点击结果卡片上的 **Open**。项目列表可能还没刷新。 |
| 请求失败 | 看清失败原因，解决其中指出的问题，然后点击 **Retry**。 |
| 她读不出你的图片 | 换成模型支持图像输入的账号。 |
| Fandom 查询失败 | 这需要能上网。 |
| 操作被权限错误挡住 | 你是通过网络访问 Marinara 的。先配置远程访问。 |

## 进阶用户参考

这几部分写给要改 Marinara 自身文件、或者想调整她工作方式的人。可以跳过。

### 运行时

在 **Runtime**(运行时) 下，可以选择默认的 **Pi (experimental)**(Pi，实验性)，或者 **Classic**。在 Pi 模式下，她动手之前会多想一想，也能处理更长的任务。如果你的账号跑不了 Pi，她会使用 Classic。修改从她的下一个回答开始生效，Undo 在两种模式下的作用相同。如果她在 Pi 下行为异常，就切换到 Classic。

同样在 **Runtime** 下的 **Read the handbook before the first write**(首次写入前阅读手册) 默认开启。她首次修改某个有内置 Skill 的领域时，如果还没读过那个 Skill，这次修改就会被退回。这对较小的模型有帮助。只有你能关掉它。

### 她能接触到你电脑上的什么

她能读取和修改 Marinara 自己的程序文件，还能在沙箱里执行命令，这样她就能修复应用。绝大多数人永远用不到这些。

- 她的文件工具只在 Marinara 的安装文件夹里活动。原始 shell 命令读不到你其他的个人文件，没有网络访问权限，也不会继承服务器密钥。
- `.env`、保护你已保存 API 密钥的密钥文件，以及 Git 的内部文件，她都拿不到。
- 她不能直接往你的数据文件夹里写东西，角色和聊天都存在那里。她走的是上面讲的可审查改动流程。
- 依赖清单、锁文件、启动脚本、安装程序和 CI 工作流的改动会先暂存，等你批准。包的安装脚本始终保持关闭。
- 命令过一小段时间会自行停止。
- 如果 Marinara 提供不了 macOS 或 Linux 的 shell 沙箱，原始 shell 命令和 `mari code check` 都会关闭。她仍然可以使用结构化的文件工具和应用数据工具。

<a id="held-changes-for-files-and-libraries"></a>

### 文件和库的暂缓改动

- **Sensitive files**(敏感文件)（依赖文件、启动脚本、安装程序、CI 工作流）会显示路径和新内容，配 **Apply change**(应用改动) 和 **Discard**(丢弃) 两个按钮。
- **Dependencies**(依赖) 会显示 npm 包、确切版本和仓库完整性校验值，配 **Install**(安装) 和 **Not now**(暂不) 两个按钮。她的 shell 里禁止执行安装命令。批准一个库，就意味着在 Marinara 运行它时信任它的代码。

### 她如何处理 Decision

Decision 模型是一个回答“是”或“否”问题的小模型。处理智能体的 **Activation questions**(激活问题)、世界书的 **Decision** 语句和条件提示词时，她会先检查你选了哪个 Decision 模型。

- 加入 Decision 内容之前，她会先询问。没有 Decision 模型时，除非你要求，她新做的内容都不会用到 Decision。
- 她倾向于少量使用，并配合时机控制：世界书条目用 **Sticky** 或 **Cooldown**，智能体激活用 **Trigger Cadence**，提示词条件用 `sticky`、`cooldown` 或 `every`。
- 要加入会在提示词靠前位置或聊天历史里变化的内容之前，她会先询问，这样提示词的开头能保持稳定，便于服务商的提示词缓存。
- 告诉她“别再提醒我设置 Decision 模型”，就能停止这些提醒。

见 [Decision 模型](../connections/decision-models.md)、[条件提示词](../prompts/conditional-prompts.md)、[自定义智能体](../agents/custom-agents.md#activation-questions)和[世界书条目](../lorebooks/entries.md#decision-activation)。

### mari 命令

在终端里用 `mari` 命令做出的改动不属于任何聊天，所以它的改动卡片会显示在每个 Professor Mari 聊天里。
