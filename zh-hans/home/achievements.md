# 成就

成就是一批纯装饰性的徽章，会在你使用 Marinara Engine 的过程中陆续解锁，比如新建聊天或点开社区链接时。它们不会改变应用的运作方式。本指南介绍在哪里查看成就、完整清单，以及怎么关掉它们。

## 打开 Achievements 窗口

1. 回到主页。
2. 点击 **Achievements**(成就) 书签（奖杯图标）。在手机上，先点击标签页左侧的书签按钮。

**Achievements** 窗口随即打开。顶部是一行汇总，比如 **12 of 24 achievements unlocked in this profile.** 档案就是你保存下来的那一套 Marinara 数据。下面是成就卡片组成的网格。

- 未解锁的卡片显示 **?????** 和一个锁形图标。解锁之前看不到具体内容。
- 已解锁的卡片会显示 **unlocked** 标签。
- 带目标数量的卡片还会显示一行 **Progress**(进度) 和一条进度条。

你也可以把 **Achievements** 小组件加到主页上。点击书签里的 **Widgets**(小组件)，把它打开即可。它会显示 **12 of 24 unlocked** 这样的计数，以及你 **Last obtained**(最近获得) 的成就和 **Closest next**(最接近完成) 的成就。加载时显示 **Checking the collection...**。点击它即可打开窗口。见[主页小组件](welcome.md#home-widgets)。

如果没有成功：只有 **Achievements** 设置开启时，书签、小组件和窗口才会显示。见[开启或关闭成就](#turn-achievements-on-or-off)。

你的进度保存在当前使用的档案里。换一份档案或者全新安装，就会从零开始，什么都没解锁。完整备份会保存解锁记录。

## 24 项成就

一共 24 项，分成四类：**Milestone**(里程碑)、**Community**(社区)、**Creation**(创作) 和 **Collection**(收藏)。**Creation** 和 **Collection** 两类成就有三个等级：**I**、**II** 和 **III**，对应 5、25、100 三个门槛。到了第二级，徽章标题会变成 **Hoarder II** 这样。

| 成就 | 分类 | 解锁条件 |
| --- | --- | --- |
| **Diligent Student** | Milestone | 完成或跳过首次使用教程。 |
| **Hello World** | Milestone | 给 Professor Mari 发出第一条消息。 |
| **Please Handle With Care** | Milestone | 把 Professor Mari 的图片在屏幕上拖来拖去。 |
| **One Of Us** | Community | 点击 **Discord** 书签，或 **Community** 小组件里的 **Discord** 链接。 |
| **Based Backer** | Community | 在书签或 **Community** 小组件里点击 **Support**，它会打开 Ko-fi。 |
| **Backseat Appreciator** | Community | 点击书签或 **Community** 小组件里的 **Credits**。 |
| **Who Needs IRL Friends** | Creation | 创建 Conversation(对话模式) 聊天（5、25、100）。 |
| **They Feel Real To Me** | Creation | 创建 Roleplay(角色扮演) 聊天（5、25、100）。 |
| **I Have No Other Hobbies** | Creation | 创建 Game(游戏模式) 聊天（5、25、100）。 |
| **Hoarder** | Collection | 收集角色（5、25、100）。 |
| **The World's A Stage** | Collection | 收集世界书（5、25、100）。 |
| **I Am A Gamer** | Collection | 收集用户角色（5、25、100）。 |

- 用户角色是在聊天里代表你的那张角色卡。世界书是一组世界设定，相关关键词出现时 AI 会读到它们。
- **Collection** 统计的是你资料库里该类型的全部内容，包括导入和下载来的。对于 **Hoarder**，内置的 Professor Mari 角色永远不计入。
- 社区类成就只要点开链接就算数，不需要在对方网站上注册。

## 智能体的成就

已安装的智能体可以添加自己的成就。它们显示在同一个窗口里，位于内置成就之后，归在 **From Noodle**(来自 Noodle) 这样的标题下。它们遵循相同的规则，智能体还可以显示自己的徽章图片。

移除智能体后，它的区块会消失，你的解锁记录仍会保留。重新安装后，这些成就会再次显示为已解锁。顶部的总数也算上了你已安装的智能体。

## 开启或关闭成就

1. 打开 **Settings → General**(设置 → 常规)。
2. 在 **App Behavior**(应用行为) 部分，打开或关闭 **Achievements** 开关。它默认开启。

- 开启：书签和窗口可用，有成就解锁时会弹出提示。
- 关闭：书签、小组件和弹出提示都会隐藏。应用仍会在后台记录解锁情况，所以重新打开时不会丢失任何东西。

## 解锁是怎么判定的

发生被统计的操作（比如创建聊天或点击书签）时，以及你打开窗口时，Marinara 都会检查你的计数。

- 某个操作解锁了徽章、而且设置是开启的，会弹出一条标题为 **Achievement unlocked** 的提示，写明是哪一枚徽章，比如 **Hoarder II**。
- 打开窗口时，可能会解锁你早已通过别的方式达成的徽章。这类解锁是静默的：卡片直接显示为已解锁，不会弹出提示。
- 徽章一旦解锁就会一直保持，哪怕之后删掉聊天、角色、世界书或用户角色。
- 已解锁卡片上的 **Progress** 进度条显示的是你当前的计数，所以徽章已经拿到了，卡片上却可能写着 **2 / 5**。这是正常的。

没有用来重置成就的按钮。
