# v2.5.3 release catch-up (2026-11-28)

All ten documentation packs were brought up to date with the English guides that changed between Engine commits `3e8a0f56874e` (2026-11-23, the packs' previous source) and `f9fdcdb48d` (staging on 2026-11-28). Each pack's `manifest.json` now records `f9fdcdb48d` as its source.

## Guides covered

`CONFIGURATION.md`, `TROUBLESHOOTING.md`, `UPGRADING.md`, `agents/agents-overview.md`, `agents/built-in-agents.md`, `agents/knowledge-sources.md`, `agents/memory.md`, `appearance/custom-css-themes.md`, `characters/galleries.md`, `chats/chat-settings.md`, the six changed `connections/` guides, `conversation/calls.md`, `conversation/emoji-stickers-gifs.md`, `development/frontend.md`, `development/optional-agent-packages.md`, `extending/ruleset-sheets.md`, `home/professor-mari.md`, `media/illustrator-agent.md`, `media/image-providers.md`, `media/scene-backgrounds.md`, `media/scene-video.md`, `media/tts-setup.md`, `prompts/generation-parameters.md`, `roleplay/hud-and-trackers.md`, `roleplay/rulesets.md` and `settings/settings-overview.md`.

Many hunks (the Jobs page wording, the ntfy settings, the CONFIGURATION.md resident chat rows) were already translated after 2026-11-23 and were left as they were. Each pack updated 13 or 14 guides.

## Not covered here

- `game/combat.md` (Battle narration, #9883): tracked in #9884.
- `extending/ruleset.schema.json`: not part of the packs.

## UI packs

The five keys #9837 removed with Professor Mari's Height and Width sliders are gone from all eleven UI packs (#9839), and `ui/manifest.json` was rebuilt.

## Validation

`node scripts/docs-i18n/validate-pack.mjs <pack>` passes for all ten packs (152 translated docs each), and `node scripts/ui-i18n/validate-packs.mjs` passes for the UI packs. Glossaries record the new terms under a "v2.5.3 catch-up" heading.
