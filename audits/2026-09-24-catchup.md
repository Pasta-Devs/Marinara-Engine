# Documentation translation catchup — 2026-09-24

This audit compares the last Git content-edit dates for all **132 English guides** with the corresponding files in all ten documentation packs. It covers [#6458](https://github.com/Pasta-Devs/Marinara-Engine/issues/6458), [#6532](https://github.com/Pasta-Devs/Marinara-Engine/issues/6532), [#6619](https://github.com/Pasta-Devs/Marinara-Engine/issues/6619), and [#6633](https://github.com/Pasta-Devs/Marinara-Engine/issues/6633). ## Source and method

- English snapshot: [`28e4b5dcc`](https://github.com/Pasta-Devs/Marinara-Engine/commit/28e4b5dcc4523e554593dfe042468e55784f355b), fetched from `staging`.

- Dates are each file’s last Git committer timestamp (`git log -1 --format=%H%x09%cI -- <path>`), compared as timezone-aware instants. They are not checkout modification times.
- Scope matches the pack validator: Markdown under English `docs/`, excluding `evidence`, `pr-evidence`, `screenshots`, `examples`, and `i18n`.
- **38 existing paths** have English edits newer than at least one translation. **Three paths** were absent in every pack: the new Decision guide and two previously untranslated ruleset guides.
- Dates select candidates; they do not prove drift. Candidate source diffs were compared with current translations. Some translations already included a change before its English merge. Conversely, a recent translated-file edit could leave older sections incomplete.
- [Exact per-file, per-language dates and commit IDs](2026-09-24-dates.json) retain the original timestamps for all 132 paths, plus catchup outcomes. Files outside the candidate/issue scope were not independently retranslated.

## Review findings and source follow-ups

The initial German CodeRabbit review completed with six minor findings. Four concerned English-fragment links to translated headings; stable explicit anchors address those without changing the source URLs. The in-app viewer intentionally removes in-document fragments and explicit anchor lines (`DocsViewerModal.tsx`, `prepareDocMarkdown`); the anchors improve navigation when reading the packs as Markdown on GitHub.

Two findings concern wording inherited from English and are retained as source follow-ups, rather than changing one language's described behavior:

- `game/combat.md` still calls choosing an opportunity strike future work, although the same snapshot's API 1.33 section and C5b/C5c status describe reaction windows. The translation mirrors the English scope; reconcile those English sections in a follow-up before changing their meaning across packs.
- `game/dice-and-skill-checks.md` describes invalid notation with the shorthand `NdM` / `dM`. Adjacent examples already show signed modifiers. Expanding that shorthand explicitly would be an English editorial improvement, not a correction specific to German.

A subsequent German finding proposed that lorebook activation ignores the remaining Decision allowance. It was rejected after tracing `createLorebookDecisionResolver` in `packages/server/src/services/decision/prompt-decisions.ts`: activation requests call `admit(key)`, which rejects new keys at zero remaining allowance; dropped keys receive no answer. The entry-content `answerStatements` path uses the same admission function. The translated explanation matches both that implementation and the English source.
