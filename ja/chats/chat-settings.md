# Chat Settingsの概要

**Chat Settings**(チャット設定)は、開いているチャットのオプションをまとめたパネルです。モデル、キャラクター、エージェント、検索、要約、分岐、ギャラリーを扱います。ほとんどの設定は、そのチャットだけに属します。

## Chat Settingsを開く

1. チャットを開きます。
2. **Chat Settings**ボタン(スライダーのアイコン)をタップします。パネルが開きます。スマートフォンでは、**Help**(ヘルプ、**?**)でアイコンを説明するガイドを表示できます。
3. セクションのタイトルをタップすると開きます。タイトルをもう一度タップすると折りたたまれます。

Chat Settingsは、チャットを作成すると自動で開きます。閉じるには、パネルの**X**をタップするか、スライダーボタンをもう一度タップしてください。

コンピューターでは、スライダーボタンは最初はチャットの右上にあります。Tracker Panelを右側に表示している場合は、最初はそのパネルの左にあります。Tracker Panelは、Roleplayのサイドパネルです。エージェント(返信と並行して動く補助機能)が追跡している内容、たとえばシーンにいるキャラクターを表示します。

スライダーボタンは、使いやすい場所へドラッグできます。ドラッグ中は、近くのチャットボタンに位置がそろいます。コンピューターでは<kbd>Alt</kbd>を押したままにすると、自由に配置できます。位置はチャットごとに記憶されます。ボタンの小さな点は、エージェントが動作中であることを示します。Advanced Memory Recallを使うRoleplayチャットで、反対側の角に点滅しない点が表示されている場合は、一部のシーンの記憶に対応が必要です。[記憶の問題を直す](../agents/memory.md#fixing-memory-problems)を参照してください。

初めてチャットを開くと、ボタンとウィンドウの配置方法を紹介する短い動画が表示されます。**Got it**(わかりました)をクリックしてください。ほかのチャットでも、ページを再読み込みした後も、閉じたままになります。1つのチャットでレイアウトのヒントを非表示のままにするには、ヒントの横の**X**(**Hide these tips for this chat**(このチャットのヒントを非表示))をクリックします。

## セクションの一覧

表示されるセクションは、チャットのモードによって変わります。**Impersonate**セクションについては、[ガイド付き生成とImpersonate](guided-and-impersonate.md)で説明しています。

- 設定プロファイルのバー: チャットの設定のまとまりを適用または保存します。[設定プロファイル](settings-profiles.md)を参照してください。(Conversation、Roleplay)
- **Search messages**(メッセージ検索): 語句、または`#`とメッセージ番号でメッセージを探します。**Bookmarks**と**Trash**タブには、ブックマークしたメッセージと削除したメッセージが並びます。(Game以外)
- **Chat Name**(チャット名): チャット一覧に表示される名前です。クリックすると名前を変更できます。モデルには一切送られません。
- **Chat Branches**(チャットの分岐): 分岐の切り替え、名前変更、エクスポート、インポートができます。[チャットの分岐](branches.md)を参照してください。
- **Connection**(接続): このチャットで返信するモデルです。下記を参照してください。
- **Prompt Preset**(プロンプトプリセット): このチャットで使う、保存済みのプロンプト構成です。
- **Advanced Parameters**(詳細パラメーター): temperatureなどの生成設定を、このチャットだけ上書きします。[生成パラメーター](../prompts/generation-parameters.md)を参照してください。
- **Persona**(ペルソナ): 自分が演じる人物です。[チャットで使うペルソナの選択](../characters/choosing-your-persona.md)を参照してください。(Conversation、Roleplay)
- **Characters**(キャラクター): チャットに登場するキャラクターです。(Conversation、Roleplay)
- **Ruleset**(ルールセット): 卓上ルールセットでチャットを遊びます。ダイス判定とキャラクターシートを使います。[Roleplay: ルールセットで遊ぶ](../roleplay/rulesets.md)を参照してください。(Roleplay)
- **Party**(パーティー): **Persona**と**Characters**の代わりに、両方を1か所にまとめたものです。(Game)
- **Group Chat**(グループチャット): グループで誰が発言するかを決めます。[グループチャット](group-chats.md)を参照してください。(キャラクターが2人以上いるチャット)
- **Scoped Regex Scripts**(範囲限定の正規表現スクリプト): キャラクターに属する正規表現スクリプトを、チャットごとに制御します。[正規表現スクリプト](../extending/regex-scripts.md#the-per-chat-scoped-regex-scripts-setting)を参照してください。(チャットのキャラクターが範囲限定のスクリプトを持つ場合にだけ表示)
- **Chat Variables**(チャット変数): `{{name}}`で再利用する、名前付きのテキストです。下記を参照してください。
- **Connected Chats**(接続チャット): チャットを別のチャットにつなぎます。[接続チャット](connected-chats.md)を参照してください。
- **Lorebooks**(ロアブック): 世界の設定を結び付けます。[ロアブックの概要](../lorebooks/overview.md)を参照してください。
- **Chat Summary**(チャットの要約): 要約を確認、作成します。[Memory Recallとチャットの要約](../agents/memory.md#chat-summary-roleplay)を参照してください。(要約を使える場合)
- **Active Context**(有効なコンテキスト): このチャットで有効なロアブックとコンテキストを表示します。[トークン予算と再帰](../lorebooks/token-budgets.md#seeing-skipped-entries-in-active-context)を参照してください。
- **Agents**(エージェント): 補助機能をオンにします。[エージェント: チャットを支えるAIヘルパー](../agents/agents-overview.md)を参照してください。
- **Agent activity**(エージェントの動作): エージェントが行ったことを表示します。トラッカーの再実行、エージェントの再試行や停止、トラッカーの消去ができます。[エージェントの動作](../roleplay/getting-started.md#agent-activity)を参照してください。(Roleplayで、エージェントまたはAdvanced Memoryがオンの場合)
- **Author's Notes**(作者ノート): モデルが毎ターン読むメモです。[Author's Notes](../roleplay/getting-started.md#authors-notes)を参照してください。(Roleplay)
- **Background**(背景): チャットの背景画像です。(Roleplay、Game)
- **Gallery**(ギャラリー): チャットの画像と動画です。[シーン背景とギャラリー](../media/scene-backgrounds.md)を参照してください。
- **Widgets**(ウィジェット): ゲームに表示するHUDウィジェットを選びます。(Game)
- **Impersonate**: `/impersonate`コマンドの設定です。(Roleplay)
- **Memory Recall**(記憶の呼び出し): チャットの以前の部分を思い出します。[Memory Recallとチャットの要約](../agents/memory.md)を参照してください。(Lite版にはありません)
- **Function Calling**(関数呼び出し): このチャットで、モデルがツール(関数)を使えるようにします。
- **Translation**(翻訳): メッセージの自動翻訳です。[メッセージの翻訳](../integrations/message-translation.md)を参照してください。

Conversationのチャットには、Autonomous Messaging(キャラクターから先にメッセージを送る機能)、Commands(キャラクターが自分から行う操作)、メモのセクションもあります。これらは[Conversationモード: はじめに](../conversation/getting-started.md)で説明しています。

## チャットのモデルを選ぶ

**Connection**(接続)セクションでは、このチャットで返信するモデルを選びます。選んだモデルが変わるのは、このチャットだけです。

1. **Chat Settings**を開き、**Connection**セクションを開きます。
2. **Model**(モデル)欄をタップします。現在のモデルが表示されています。
3. チャットが**Main**(メイン)に従っているかどうかを確認します。Mainとは、**Connections**(接続)で設定したデフォルトのモデルです。
4. モデルを選びます。選択画面は、チャット入力欄のモデルボタンと同じです。現在のモデルが一番上に残り、その下に最近使ったモデルと星付きのモデルがアカウントごとに並びます。モデルとアカウントをまとめて検索するか、**Browse**(参照)で1つのアカウントのカタログを開きます。

**Follow Main**(メインに従う)は、チャット独自の選択を解除します。そのため、Mainを変えるとこのチャットのモデルも変わります。**Shuffle**(シャッフル)は、返信ごとにプールから別のモデルを選びます。[Shuffle](../connections/organizing-connections.md#shuffle)を参照してください。アカウントにキーが必要な場合やオフになっている場合は、そのモデルから修復の操作に進めます。アカウントを追加するには、[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。

## チャット変数を使う

チャット変数とは、テキストに付ける名前です。たとえば、`char1`という変数を値`Mary`で追加し、メッセージに`{{char1}} walks in.`と書くと、モデルは「Mary walks in.」と読みます。

1. **Chat Settings**を開き、**Chat Variables**(チャット変数)セクションを開きます。
2. **Add variable**(変数を追加)をタップし、行の**name**(名前)と**value**(値)を入力します。
3. <kbd>Enter</kbd>を押すか、欄の外をクリックすると保存されます。ゴミ箱ボタンで変数を削除できます。

名前には英字、数字、アンダースコアを使えます。先頭は英字かアンダースコアにし、64文字以内にしてください。ちょうど21文字の名前は、キャラクター参照用に予約されています。`char`や`user`など、組み込みマクロの名前は受け付けられません。

- メッセージには、入力したタグがそのまま表示されます。値を見るのはモデルだけです。あとから値を変えると、そのタグを使った過去のすべてのターンも変わります。
- 変数はこのチャットだけに属し、再起動しても保持されます。
- `{{setvar}}`が使うのと同じ保存先です。プロンプトのセクションやロアブックのエントリーが同じ名前を設定すると、入力した値は上書きされます。

変数が多いときは、**Search and edit all in the State Editor**(State Editorですべて検索・編集)をクリックします。すべての変数が一覧で表示され、検索、編集、JSONでのまとめて貼り付け、保存前の変更の確認ができます。[State Editor](../roleplay/hud-and-trackers.md#the-state-editor)を参照してください。ほかの二重波括弧のマクロについては、[プロンプトマクロ](../prompts/macros.md)を参照してください。

<a id="settings-profiles"></a>

## 設定プロファイル

設定プロファイルとは、チャットの設定をまとめて保存し、ほかのチャットに適用できるようにしたものです。プロファイルのバーはパネルの上部にあり、Gameでは表示されません。保存、適用、インポート、エクスポート、デフォルトの選択については、[設定プロファイル](settings-profiles.md)で説明しています。

## ウィンドウの移動、ピン留め、ロック

コンピューターでは、Chat Settingsはチャットの上に重なって表示され、内容はウィンドウの大きさに合わせて並び替わります。ウィンドウは、初めて開くときはボタンの下に、それ以降は保存した位置に開きます。

- 移動: タイトルバーをドラッグします。または、タイトルバーにフォーカスを移して矢印キーを使います。<kbd>Shift</kbd>を押すと、移動幅が大きくなります。
- サイズ変更: 辺または角をドラッグします。または、右下のハンドルにフォーカスを移して矢印キーを使います。
- ピン留め: **Pin**(ピン留め)をクリックします。ピン留めしたウィンドウは、ほかの場所をクリックしても開いたままで、ページを再読み込みすると再び開きます。ピン留めしていないウィンドウは、外側をクリックするか<kbd>Esc</kbd>を押すと閉じます。ただし、入力中や、開いたメニューの操作中は閉じません。
- ロック: **Lock**(ロック)をクリックします。ウィンドウの移動とサイズ変更ができなくなり、ボタンも定位置に固定されます。ウィンドウを開くことはできます。
- 閉じる: **X**をクリックします。

ウィンドウはチャット領域の中に収まります。ウィンドウやボタンをメッセージ入力欄の横に置くことはできますが、入力欄を覆うことはありません。スマートフォンでは、Chat Settingsは画面幅いっぱいのパネルとして開き、キーボードより上に収まります。

## Help、トラッカー、Reset View

これらのボタンはタイトルバーにあります。

- **Help**(ヘルプ、**?**)は、チャットの操作を説明するラベルを表示します。スマートフォンでは、先にChat Settingsを閉じます。非表示にするには、**Settings → General → App Behavior → Hide chat Help button**(設定 → 一般 → アプリの動作 → チャットのHelpボタンを隠す)をオンにします。
- **Reset View**(表示をリセット、円形の矢印)は、確認を求めたうえで、このチャットの初期レイアウトを復元します。切り離したセクションが戻り、ウィンドウのサイズ、位置、ピン留め、ロックがリセットされます。
- **Favorite layout**(お気に入りレイアウト、星)は、この配置を新しいチャット用に保存します。[新しいチャットのレイアウトを選ぶ](#choosing-a-layout-for-new-chats)を参照してください。
- **Tracker Panel**(トラッカーパネル、サイコロ)は、エージェントまたはAdvanced Memoryを使うRoleplayチャットで、パネルのオンとオフを切り替えます。コンピューターでは、チャットの横に開きます。スマートフォンやタブレットでは、移動できるボタンで開きます。**Settings → Appearance**(設定 → 外観)のTracker Panelの設定も変わります。

Tracker Panelを表示していない場合、コンピューターのトラッカーは[Trackersウィンドウ](../roleplay/hud-and-trackers.md#the-trackers-window)を使います。メッセージの横に十分な空きがなければ、小さな**Trackers**ボタンとして始まります。Tracker Panelを再び表示するには、サイコロを使ってください。

<a id="popping-a-section-out-into-its-own-window"></a>

## セクションを独立したウィンドウに切り離す

セクションを切り離すと、専用のウィンドウになります。

1. セクションの**Pop out**(切り離す)ボタン(**?**の横の、矢印が付いた四角)をクリックします。コンピューターでは、セクションのタイトルをChat Settingsの外へドラッグすることもできます。
2. 新しいウィンドウは、Chat Settingsと同じように移動、サイズ変更、ピン留め、ロックができます。最初はピン留めされていないため、ほかの場所をクリックするとボタンに縮みます。
3. 元に戻すには、**Put back in Chat Settings**(Chat Settingsに戻す、**X**の横の曲がった矢印)をクリックするか、ウィンドウをChat Settingsの上へドラッグします。

**X**は、セクションをアイコン付きの小さなボタンに縮めます。ボタンを好きな場所へドラッグし、クリックするとウィンドウが再び開きます。Trackersウィンドウのトラッカーも同じように切り離せます。その戻すボタンは**Put back in Trackers**(Trackersに戻す)です。

スマートフォンでは、切り離すとChat Settingsが閉じ、そのセクションが3点アイコンの**Chat tools**(チャットツール)メニューに追加されます。3点アイコンをタップしてから、セクションの丸いアイコンをタップしてください。戻すには**Put back in Chat Settings**をタップします。

<a id="the-phones-chat-tools-menu"></a>

## スマートフォンのChat toolsメニュー

移動できる3点ボタンには、Chat Settingsから取り出したツールがまとまっています。タップすると丸いアイコンボタンが展開されるので、ツールをタップします。3点ボタンをもう一度タップすると折りたたまれます。トラッカーのボタン、GameのMapボタン、Character Profilesは別に表示されます。

3点ボタンをドラッグすると、メニューを移動できます。メニューを開き、上部のロックを使うと位置を固定できます。ロックしていない間は、ツールを上下にドラッグするか、フォーカスを移して矢印キーを使うと、順番を変えられます。ロックすると、移動と並べ替えの両方ができなくなります。メニューは、チャットウィジェットのスタイルに従います。

<a id="control-windows-and-their-buttons"></a>

## 操作ウィンドウとボタン

一部のツールは、専用の小さなウィンドウを開きます。Gameの**Game controls**、**Session**、**Volume**、**Game Assets**、**Connected chat**、インストールしたパッケージが追加する操作が該当します。

コンピューターでは、これらのボタンは最初はチャットの右上付近にあります。クリックするとウィンドウが開き、ウィンドウを閉じるとボタンが戻ります。スマートフォンでは、これらは**Chat tools**メニューにあり、画面幅いっぱいのパネルとして開きます。

ツールをChat Settingsの中に置くには、ウィンドウを開いて**Put back in Chat Settings**を選んでください。再び切り離すには、セクションの切り離しボタンを使います。**Reset View**は初期の配置を復元します。

ボタンはドラッグして移動できます。ドラッグ中は、近くのボタンに位置がそろいます。<kbd>Alt</kbd>を押したままにすると自由に配置でき、ボタンにフォーカスがある状態では矢印キーも使えます。Conversationの**Calls**は、通常のボタンのままです。Gameでは、**Character Profiles**(キャラクタープロフィール)とスマートフォンの**Map**(マップ)ボタンを移動でき、それぞれのロックでゲームごとの位置が保たれます。

## チャットごとに保存されるウィンドウレイアウト

ウィンドウのサイズと位置、ピン留め、ロック、切り離したセクション、ボタンの位置は、チャットごとに記憶されます。スマートフォンの位置と、Chat toolsの順番およびロックは、コンピューターの位置とは別に保存されます。[設定プロファイル](settings-profiles.md)にレイアウトを保存すると、ほかのチャットでも使えます。

<a id="choosing-a-layout-for-new-chats"></a>

## 新しいチャットのレイアウトを選ぶ

**Reset View**の横の星を使うと、現在の配置を、同じモードの新しいチャットの初期レイアウトにできます。Conversation、Roleplay、Gameは、それぞれ別のお気に入りを持ちます。

1. ウィンドウとボタンを配置します。ツールをChat Settingsの中に置くか、切り離してください。
2. 新しいチャットでもレイアウトのヒントを非表示にしたい場合は、ヒントを非表示にします。
3. 星をクリックします。現在のレイアウト、ヒントの状態、Scoped Regex Scriptsのモードが保存済みのお気に入りと一致すると、星が塗りつぶされます。

お気に入りには、位置、サイズ、ピン留め、ロック、切り離したツールやChat Settings内に置いたツール、レイアウトのヒントの選択、チャットの[Scoped Regex Scripts](../extending/regex-scripts.md#the-per-chat-scoped-regex-scripts-setting)のモードが保存されます。**Use preset default**(プリセットのデフォルトを使用)のチャットではモードが保存されないため、新しいチャットはそれぞれのプロンプトプリセットに従います。キャラクター、モデル、AIの設定、メッセージはチャットに残ります。

お気に入りを置き換えるには、配置を変えて星をもう一度クリックします。使うのをやめるには、塗りつぶされた星をクリックします。これは、その後に作成するチャットにだけ影響します。

保存済みレイアウトを持つ設定プロファイルを適用すると、そのレイアウトがお気に入りより優先されます。レイアウトを持たないプロファイルは、お気に入りの配置をそのまま残します。ただし、レイアウトのヒントの設定とScoped Regex Scriptsのモードについては、プロファイルは引き続き自身の設定を適用します。[設定プロファイル](settings-profiles.md#favorite-window-layouts)を参照してください。

古いバージョンからアップグレードした場合は、以前のツールボタンの配置が、3つのモードすべてで星付きになっています。置き換えるか解除するまで、その状態が続きます。新規インストールでは、ツールはChat Settingsの中にあり、お気に入りはありません。

## チャットウィンドウの外観を変える

**Settings → Appearance → App**(設定 → 外観 → アプリ)を開き、**App Style**(アプリのスタイル)の下部にある**Chat widget style**(チャットウィジェットのスタイル)までスクロールします。**Default**(デフォルト)は、Marinaraの外観を保ちます。**Dottore**は、氷のような青、淡い金属色、切り落とした角を使います。**Prof. Mari**は、宝石のような青、温かみのある金色、アーチ状の枠を使います。どちらもライトモードとダークモードに対応し、3つのチャットモードすべてで、移動できるボタン、ウィンドウ、セクションに適用されます。

- プリセットの下の**Font**(フォント)、**Shape**(形)、3つのカラーピッカーで外観を組み合わせられます。Marinaraにインストールしたフォントも、フォントの一覧に表示されます。プリセットを選び直すと、フォント、形、独自の色がリセットされます。
- **Button size (px)**(ボタンのサイズ、px)は、移動できるチャットボタンのサイズを32から96までの範囲で設定します。欄を空にすると、デフォルトのままになります。
- **Apply preset font**(プリセットのフォントを適用)、**Apply preset shape**(プリセットの形を適用)、**Apply preset colors**(プリセットの色を適用)は、スタイルをメッセージ、入力欄、チャットの操作部品にも広げます。それぞれ独立して動作し、最初はすべてオフです。Conversationのメッセージにはフォントと色が適用されますが、形は元のままです。**Apply preset colors**をオンにしても、引用符で囲まれたセリフはキャラクターやペルソナごとのDialogue Highlight Colorを保ちます。

これらの選択でウィンドウが動くことはありません。アプリの設定と一緒に保存され、同じサーバーに接続したブラウザー間で同期されます。[カスタムCSSテーマ](../appearance/custom-css-themes.md#ready-made-chat-window-styles)を参照してください。
