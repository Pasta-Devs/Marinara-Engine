# チャットのエクスポートとインポート

チャットをファイルに保存したり、読みやすい物語として共有したり、MarinaraやSillyTavern(別のロールプレイチャットアプリ)のチャットファイルを読み込んだりできます。エクスポートは、1件のチャット、チャットの一部、複数のチャットのいずれでも行えます。

<a id="file-formats-you-will-see"></a>

## 扱うファイル形式

| 形式 | 内容 | 再インポート |
| --- | --- | --- |
| **JSONL** | JSON Linesの略で、1行に1メッセージを収めたプレーンテキストのファイルです。デフォルトの形式です。 | できます |
| **Text** | 読みやすい`.txt`形式の記録です。 | できません |
| **Markdown** | 読みやすい`.md`ファイルです。先頭にチャット名と対象の期間の日付が入り、その後に各メッセージが発言者の名前の下に並びます。 | できません |
| **Story** | 各発言者の名前とアバターが付いた、スタイル付きの`.html`のWebページです。ブラウザーで開いて、読んだり、共有したり、印刷したりできます。 | できません |

**Markdown**と**Story**のファイルには、システムメッセージと、自分には非表示のメッセージは含まれません。チャットのインポートが受け付けるのは`.jsonl`だけなので、後でチャットを読み込み直したいときは**JSONL**でエクスポートしてください。

**JSONL**ファイルには、チャットに保存されたいくつかのアドレスが含まれません。対象は、Discordミラーのwebhook、DeepLXのアドレス、DeepLのキー、Intifaceのアドレスです。インポートしても、これらが取り込まれることはありません。使う場合は、インポートしたチャットの**Chat Settings**(チャット設定)で入力し直してください。

## チャットを1件だけエクスポートする

1. チャットを開きます。
2. **Chat Settings**(チャット設定)を開き、**Chat Name**(チャット名)の下にある**Chat Branches**(チャットの分岐)を展開します。チャットに分岐が1つしかなくても、エクスポートのボタンはこのセクションにあります。
3. **JSONL**、**Text**、**Markdown**、**Story**のいずれかをタップします。

ブラウザーがファイルをダウンロードします。ファイルには、表示中の分岐とそのメッセージが入ります。

<a id="export-part-of-a-chat"></a>

## チャットの一部をエクスポートする

一部のメッセージだけを保存するには、**Export a range**(範囲をエクスポート)を使います。Gameのチャットでは使えません。

1. **Chat Branches**(チャットの分岐)で**Export a range**をクリックします。
2. 最初のメッセージをクリックし、続いて最後のメッセージをクリックします。「Select the first and last message to export.」というヒントが表示されます。
3. **Export selected**(選択範囲をエクスポート)をクリックします。
4. **Export messages**(メッセージのエクスポート)ダイアログで、メッセージの件数と最初と最後のメッセージを確認し、**Text**、**Markdown**、**JSONL**、**Story**のいずれかを選びます。

Marinaraは、選んだ最初のメッセージから最後のメッセージまでを、すべてエクスポートします。エクスポートせずにやめるときは、**Cancel**(キャンセル)をクリックします。

## 複数のチャットをまとめてエクスポートする

1. 左サイドバーで、目的のモードのタブ(**CONVO**、**RP**、**GM**のいずれか)をクリックします。各タブは、そのタブのチャットだけをエクスポートします。
2. 一覧の上部にある**Select chats**(チャットを選択)をクリックします。
3. 含めたいチャットを1件ずつクリックします。画面下部のバーに選択数が表示されます(例: 「3 selected」)。
4. バーの**Export**(エクスポート)をクリックします。

ブラウザーが`.zip`ファイルをダウンロードします。中には、チャット1件につき1つのJSONLの記録が入っています。まとめてエクスポートする場合の形式は常に**JSONL**です。[チャット一覧の管理](managing-chats.md#selecting-multiple-chats)を参照してください。

## チャットを新しいチャットとしてインポートする

Marinaraで保存した、またはSillyTavernから書き出した`.jsonl`ファイルから、新しいチャットを作ります。

1. 左サイドバーで、目的のモードのタブをクリックします。インポートしたチャットのモードは、ファイルに記録されたモードではなく、開いているタブのモードになります。
2. **+**ボタンの隣にある**Import**(インポート)ボタンをクリックします。このボタンのラベルは**Import SillyTavern or Marinara chat JSONL**です。
3. `.jsonl`ファイルを選びます。

「Imported N messages」と表示され、Marinaraが新しいチャットを開きます。SillyTavernのファイルについて詳しくは、[SillyTavernからのインポート](../data/importing-from-sillytavern.md)を参照してください。

うまくいかなかった場合: 画面下部に**Import failed**という小さなメッセージが、理由とともに表示されます。ファイル名が`.jsonl`で終わっているか確認してください。

## チャットを新しい分岐としてインポートする

`.jsonl`ファイルを既存のチャットに、新しい分岐として読み込みます。[チャットの分岐](branches.md)を参照してください。

1. 分岐を追加したいチャットを開きます。
2. **Chat Settings**(チャット設定)を開き、**Chat Branches**(チャットの分岐)を展開して**Import**(インポート)をクリックします。
3. `.jsonl`ファイルを選びます。

「Imported N messages as a new branch」と表示されます。この分岐は、開いているチャットのキャラクター、ペルソナ、接続、プロンプトプリセットをそのまま使います。

## エクスポートに思考と非公開メモを含める

隠れたテキストをエクスポートファイルに入れるかどうかは、2つの設定で決まります。どちらも**Settings → Advanced → Message Tools**(設定 → 詳細設定 → メッセージツール)にあるトグルで、デフォルトではどちらもオフです。1件のチャットのエクスポートにも、`.zip`のエクスポートにも適用されます。

| 設定 | オンのとき |
| --- | --- |
| **Include reasoning in exports**(エクスポートに思考を含める) | モデルが保存した思考を、すべての形式に追加します。**Markdown**と**Story**のファイルでは、メッセージの下にある折りたたみ式の**Thinking**(思考)セクションに入ります。 |
| **Include private notes in exports**(エクスポートに非公開メモを含める) | メッセージに付けた自分の非公開メモを、**JSONL**と**Text**のエクスポートに追加します。 |

> **Warning:** 記録を共有する前に、両方ともオフにしておいてください。隠れた思考や非公開メモには、送るつもりのなかった内容が含まれていることがあります。
