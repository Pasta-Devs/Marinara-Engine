# チャットのエクスポートとインポート

このガイドでは、チャットをファイルに保存する方法と、保存したチャットをMarinara Engineに読み込む方法を説明します。エクスポートは1件ずつでも、複数まとめてでも行えます。Marinaraで書き出したチャットファイルのほか、SillyTavern(別のロールプレイチャットアプリ)のファイルもインポートできます。

## 扱うファイル形式

Marinaraのチャットファイルには2つの形式があります。

- **JSONL**: JSONLはJSON Linesの略で、1行に1メッセージを保存するプレーンテキストのファイルです。エクスポート時のデフォルト形式で、後からMarinaraに再インポートできます。
- **Text**: 読みやすいプレーンテキストの`.txt`形式の記録です。そのまま読んだり共有したりするのに向きますが、Marinaraに再インポートすることはできません。人に読ませたいときだけ**Text**を選びます。

チャットのインポートが受け付けるのは`.jsonl`ファイルだけです。後で読み込み直す予定があるなら、**Text**ではなく**JSONL**でエクスポートしてください。

## チャットを1件だけエクスポートする

チャットを1件だけファイルに書き出すときは、**Chat Settings**の**Chat Branches**(チャットの分岐)セクションを使います。1つのチャットの履歴を書き出すいちばん手軽な方法です。

1. エクスポートしたいチャットを開きます。
2. **Chat Settings**を開き、**Chat Name**の下にある**Chat Branches**セクションを展開します。
3. **JSONL**をクリックするとJSONLファイルとして、**Text**をクリックすると読みやすいテキストファイルとして保存できます。
4. ブラウザーがファイルをダウンロードします。

保存されるのは、いま開いているチャットとそのメッセージです。

## 複数のチャットをまとめてエクスポートする

複数のチャットを選んで、1つの`.zip`ファイルにまとめてダウンロードできます。

1. 左サイドバーのチャット一覧を開きます。
2. 目的のモードのタブを選びます。**CONVO**(Conversation)、**RP**(Roleplay)、**GM**(Game)のいずれかです。各タブは、そのタブのチャットだけをエクスポートします。
3. チャット一覧の上部にある**Select chats**(チャットを選択)ボタンをクリックします。
4. 含めたいチャットを1件ずつクリックします。クリックしたチャットにチェックボックスが付きます。
5. 画面下部にバーが表示され、選択数がわかります(例: 「3 selected」)。
6. そのバーの**Export**(エクスポート)をクリックします。
7. ブラウザーがJSONL形式の記録をまとめた`.zip`ファイルをダウンロードします。ファイルはチャット1件につき1つです。

まとめてエクスポートする場合の形式は常に**JSONL**です。同じバーにある**Delete**(削除)は、選んだチャットを削除したいときだけクリックしてください。

## チャットを新しいチャットとしてインポートする

`.jsonl`ファイルから、まったく新しいチャットを作ります。Marinaraで保存したチャットファイルや、SillyTavernから書き出したファイルの読み込みに使います。

1. 左サイドバーのチャット一覧を開きます。
2. 目的のモードのタブを選びます。**CONVO**、**RP**、**GM**のいずれかです。Marinaraは、そのとき開いているタブにインポートしたチャットを作成します。
3. 一覧の上部にある**New**(新規)ボタンの隣のインポートボタンをクリックします。ツールチップには**Import SillyTavern or Marinara chat JSONL**と表示されます。
4. ファイル選択のウィンドウで`.jsonl`ファイルを選びます。
5. 「Imported N messages」というメッセージが表示され、そのまま新しいチャットに切り替わります。

新しいチャットをRoleplayモードで作りたいときは、インポートの前に**RP**タブを開いておきます。モードを決めるのは開いているタブであり、ファイルの中身ではありません。

## チャットを新しい分岐としてインポートする

`.jsonl`ファイルを既存のチャットに読み込み、新しい分岐として追加することもできます。分岐とは、チャットを別々に保存した複製で、それぞれ独立して進められます。詳しくは[チャットの分岐](branches.md)を参照してください。

1. 分岐を追加したいチャットを開きます。
2. **Chat Settings**を開き、**Chat Branches**セクションを展開します。
3. そのセクションで**Import**(インポート)をクリックします。
4. `.jsonl`ファイルを選びます。
5. 「Imported N messages as a new branch」というメッセージが表示されます。

新しい分岐は、開いているチャットに追加されます。キャラクター、ペルソナ、接続、プロンプトプリセットは、開いているチャットのものをそのまま引き継ぎます。

## エクスポートに思考テキストを含める

モデルによっては、返信と一緒に画面に出ない思考テキストを保存します。この隠れたテキストをエクスポートファイルに入れるかどうかは、設定で切り替えられます。

対象の設定は**Include reasoning in exports**(エクスポートに思考を含める)です。**Settings**(設定)の**Advanced**タブにある**Message Tools**セクションにあり、デフォルトでは**off**のトグルです。

- **off**のとき、Marinaraは保存された思考テキストを**JSONL**と**Text**のどちらのエクスポートからも除きます。
- **on**のとき、Marinaraはその隠れた思考テキストを両方の形式に追加します。

この設定は、1件ずつのエクスポートにも`.zip`の一括エクスポートにも同じように効きます。

チャットの記録を誰かに渡すときは、**Include reasoning in exports**をオフのままにしておいてください。隠れた思考テキストには、渡すつもりのなかったメモが含まれていることがあります。オンにするのは、自分用に完全な記録を残したいときだけにします。
