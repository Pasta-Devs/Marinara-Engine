# メッセージの操作: 編集、削除、スワイプ、再生成

このガイドでは、チャット内の1件のメッセージに対してできる操作を説明します。メッセージツールバーの各ボタン、メッセージの編集と削除の手順、スワイプと再生成の仕組みを取り上げます。トークン数やメッセージ番号を表示するトグルについても説明します。

Marinara Engineのメッセージには、自分が書いたものにもAIが書いたものにも、小さなツールバーが付いています。ツールバーは、コンピューターではメッセージにマウスを重ねたとき、スマートフォンやタブレットではメッセージをタップしたときに表示されます。

## メッセージツールバー

メッセージに表示されるボタンは次のとおりです。特定の状況でしか出ないボタンもあり、表の右列に条件を示しています。各ボタンには、ここに示したラベルと同じ内容のツールチップが付きます。

| ボタン | 動作 | 表示される条件 |
| --- | --- | --- |
| **Copy**(コピー) | メッセージの本文をコピーします。アイコンが一時的にチェックマークに変わります。 | 常に表示 |
| **Add reaction**(リアクションを追加) | 絵文字ピッカーを開き、メッセージへのリアクションをオンとオフで切り替えます。 | Conversationモードのみ |
| **Translate**(翻訳) / **Hide translation**(翻訳を隠す) | メッセージを自分の言語に翻訳し、もう一度押すと翻訳を隠します。 | 常に表示 |
| **Edit**(編集) | メッセージを編集できる状態にします。後述します。 | 常に表示 |
| **Regenerate**(再生成) | 別案の返信(スワイプ)を新しく作ります。後述します。 | AIのメッセージ。Roleplayモードでは自分のメッセージにも表示。ConversationモードではImpersonateで作った自分のメッセージにも表示 |
| **Show original before rewrite**(書き直し前の原文を表示) / **Show rewritten version**(書き直し後を表示) | 元の文章と書き直された文章を切り替えます。どちらも残るので、見比べて好きなほうを残せます。 | エージェントがメッセージを書き直した後のみ |
| **Hide from AI**(AIから隠す) / **Unhide from AI**(AIへの表示を戻す) | 以降のターンでこのメッセージをAIに送るのを止めたり、再開したりします。Roleplayのグループチャットではキャラクターの選択画面が開きます。 | 常に表示 |
| **Peek prompt**(プロンプトを確認) | この返信のためにAIが受け取ったプロンプトをそのまま表示します。 | 最新のAIメッセージのみ |
| **Stored guidance**(保存された指示) | この返信を方向づけた指示を表示します。 | 返信がガイド付きの指示を使った場合、またはImpersonateで作られた場合のみ |
| **Branch from here**(ここから分岐) | このメッセージまでのチャットを新しい分岐にコピーします。 | 常に表示 |
| **View model thoughts**(モデルの思考を表示) | モデルの隠れた思考テキストを開きます。 | モデルが思考を返した場合のみ |
| **Delete**(削除) | メッセージを削除します。後述します。 | 常に表示 |
| **Pause speaking**(読み上げを一時停止) / **Resume speaking**(読み上げを再開) / **Restart speaking**(読み上げをやり直す) | メッセージの読み上げ音声を操作します。 | Text to Speechがオンで読み上げ中のときのみ |

**Peek prompt**のビューアーについては[Peek Prompt](peek-prompt.md)を参照してください。**Branch from here**については[チャットの分岐](branches.md)、**Translate**については[メッセージの翻訳](../integrations/message-translation.md)、読み上げの操作については[Text to Speech (TTS)の設定](../media/tts-setup.md)を参照してください。ガイド付きの指示、**Stored guidance**、Impersonateについては[ガイド付き生成とImpersonate](guided-and-impersonate.md)で説明しています。

## メッセージの編集

メッセージの本文は、自分のものもAIのものも編集できます。

1. メッセージの**Edit**をクリックします。本文が編集できる入力欄に変わります。
2. 本文を書き換えます。
3. **Save**(保存)をクリックするか、CtrlとEnterを同時に押します(Macの場合はCmdとEnter)。ボタンのツールチップは**Save (Cmd+Enter)**です。
4. 保存せずにやめるときは、**Cancel**(キャンセル)をクリックするかEscキーを押します。ボタンのツールチップは**Cancel (Esc)**です。

編集をすばやく始める方法が2つ用意されています。どちらも**Settings**(設定)の**General**タブ、**Input & Editing**にあります。

- **Up Arrow edits last message**(デフォルトはオン): 入力欄が空のときにUp Arrowキーを押すと、いちばん新しいメッセージが編集できる状態になります。
- **Double-click edits messages**(デフォルトはオン): Roleplayのメッセージをダブルクリックまたはダブルタップすると、編集できる状態になります。

## メッセージの削除

メッセージを削除すると、**How to proceed?**というウィンドウが開きます。選べる項目は次のとおりです。

- **Delete only this swipe (1/3)**: 今表示している別案の返信だけを削除します。この項目は、メッセージにスワイプが2つ以上あるときだけ表示されます。数字は、どのスワイプを表示しているかと全体の数を示します。
- **Delete this message**: メッセージ全体を、すべてのスワイプごと削除します。
- **Delete more**: このメッセージとそれより下のメッセージをすべて選択し、メッセージの複数選択をオンにします。削除する前に選択範囲を調整できます。
- **Cancel**: ウィンドウを閉じ、何も削除しません。

「joined the chat」のようなシステムメッセージには、ウィンドウを出さない単純な削除ボタンが付いています。

## スワイプ: 別案の返信

スワイプとは、AIの返信の1つの案です。1件のメッセージは複数のスワイプを持てるので、同じターンに対する複数の答えを見比べて、気に入ったものを選べます。

スワイプが2つ以上になると、メッセージにスワイプの操作部分が表示されます。ここには「2/4」のように、表示中のスワイプと全体の数が出ます。操作は次のとおりです。

- **Previous swipe**(前のスワイプ)と**Next swipe**(次のスワイプ): スワイプを1つずつ前後に切り替えます。
- 数字の入力欄: スワイプの番号を入力してEnterを押すと、そのスワイプに直接移動します。ツールチップは**Jump to swipe 1-N**で、Nは全体の数です。
- **Generate next swipe**(次のスワイプを生成): いちばん新しいスワイプを表示しているとき、次へ進むボタンがこれに変わり、押すとまったく新しいスワイプを作ります。

メッセージに残った最後のスワイプは削除できません。削除しようとすると「Cannot delete the last remaining swipe」と表示されます。メッセージごと消したいときは**Delete this message**を使います。

## 再生成、続きの生成、再送信

この3つの操作は似ていますが、動作は異なります。目的に合ったものを選んでください。

**Regenerate**は新しいスワイプを作ります。AIのメッセージで**Regenerate**をクリックすると、その返信の別案が生成されます。元のスワイプはそのまま残ります。タッチ操作の画面では、誤って実行しないように「Regenerate this message as a new swipe?」という確認が先に出ます。ガイド付きの指示を設定してあるときは、ボタンの表示が**Regenerate (guided)**に変わります。

**/continue**コマンドは、同じメッセージの続きを書かせます。入力欄に`/continue`(短縮形は`/cont`)と入力して送信します。AIは新しいスワイプを作らず、直前の返信が途切れたところから続きを書き足します。

Marinaraはデフォルトで、書き足す文章の前に空行を1つ入れます。前の返信の最後の文字にそのままつなげたいときは、**Settings → General → Responses → Add a new line before /continue text**をオフにします。オフにすると、区切りを入れず途切れた位置から正確に続けるようにモデルへ指示します。

```
/continue
```

空送信による再送信は、返信をもう一度作り直します。チャットの最後のメッセージが自分のもので、入力欄が空のときは、同じ**Send**(送信)ボタンが送信ではなく再送信として働きます。見た目は変わりません。クリックするかEnterを押せば、メッセージを打ち直さずに返信を得られます。Roleplayモードでは、空の**Send**でAIに新しいターンを促し、シーンを進めてもらうこともできます。これは**/continue**とは違います。空送信は常に新しい返信を作り、**/continue**は今あるメッセージに書き足します。

## メッセージをAIから隠す

AIのコンテキストとは、ターンごとにアプリがAIへ送るメッセージのまとまりです。**Hide from AI**をクリックすると、以降のターンでそのメッセージがコンテキストから外れます。メッセージは画面には残り、**Hidden from AI**というラベルが付きます。もう一度送るようにするには**Unhide from AI**をクリックします。

キャラクターが複数いるRoleplayのグループチャットでは、**Hide from AI**を押すとアバターを選ぶ小さな画面が開きます。グループのアバターを選ぶと全員から隠し、キャラクターのアバターを1つ以上選ぶとそのキャラクターからだけ隠します。全員を選ぶと個別の選択は解除され、個別のキャラクターを選ぶと全員の選択がオフになります。メッセージに付く目に斜線のマークには、そのメッセージを見られないキャラクターのアバターが並びます。キャラクターが1人のチャットでは、ボタンを押すとそのまま隠す、または隠すのをやめます。

メッセージ内のささやきは、メッセージを受信者のキャラクターからだけ隠した場合でも、そのキャラクターに届きます。受信者はささやきを受け取りますが、メッセージの残りの部分は受け取りません。メッセージを全員から隠すと、そのささやきも届かなくなります。[ささやきと秘密](../roleplay/getting-started.md#whispers-and-secrets)を参照してください。

`/hide [range] [name (optional)]`でもメッセージを隠せます。たとえば`/hide 3-8`です。Roleplayでは、`/hide 3-8 Maukie`はMaukieに対してだけ非表示にし、名前を省略すると全員に対して非表示にします。`/unhide [range]`は全体に対して非表示にしたメッセージを戻します。キャラクターごとの非表示を解除するには、Roleplayのグループチャットではアバター選択を、キャラクターが1人のRoleplayチャットではメッセージの**Unhide from AI**を使ってください。メッセージ番号はチャットの最初のメッセージを1として数えます。書式と例は[スラッシュコマンド一覧](slash-commands.md)を参照してください。

Advanced Memoryの**Decide who sees new messages**(新しいメッセージを見られる相手を決める)がオンの場合、キャラクターが1人ずつ返信するグループチャットでは、新しいメッセージがその場にいないキャラクターから自動的に隠され、同じマークが付きます。メッセージの設定を自分で変更した場合は、常にそちらが優先されます。[新しいメッセージを見られる相手の決定](../agents/memory.md#deciding-who-sees-new-messages)を参照してください。

## メッセージの表示トグル

メッセージに追加情報を表示するトグルが2つあります。どちらも**Settings**の**Advanced**タブ、**Message Tools**の項目にあります。デフォルトはどちらもオフです。

- **Show message numbers**: メッセージごとに番号を表示します。番号はチャットの最初のメッセージを1として始まります。この番号は`/goto`、`/hide`、`/unhide`の各コマンドで使う番号と同じです。メッセージ番号を調べたいときにオンにします。
- **Show token usage on messages**: AIの返信にメッセージごとのトークン数を表示します。トークンとは、AIが読み書きする文章の小さな単位です。表示されるのは、その返信のプロンプトのトークン数と生成分のトークン数です。取得できる場合は、キャッシュのヒット数と返信にかかった時間も表示します。

同じ**Message Tools**の項目には、関連するトグルとして**Show model name on messages**もあります。オンにすると、返信を書いたAIモデルの名前が表示されます。これもデフォルトはオフです。

プロンプトに収めるために古いメッセージを省いた場合は、返信の下に、省いた件数を示す短い注記が表示されます。たとえば「1109 older messages not sent」のように表示されます。返信の下のこの注記を隠すには、同じセクションで**Show "older messages not sent" note**(「送信されなかった古いメッセージ」の注記を表示)をオフにします。それでも、Checkupを開けばそこに表示されることがあります。デフォルトではオンです。返信が途中で切れたことや、空で返ってきたことについての注記は、引き続き表示されます。
