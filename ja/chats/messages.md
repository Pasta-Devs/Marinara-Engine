# メッセージの操作: 編集、削除、スワイプ、再生成

自分のメッセージにもAIのメッセージにも、ツールバーが付いています。ツールバーを使うと、1件のメッセージを編集、削除、再生成したり、AIから隠したり、そのメッセージから分岐したりできます。

ツールバーは、スマートフォンやタブレットではメッセージをタップしたとき、コンピューターではメッセージにマウスを重ねたときに表示されます。

## メッセージツールバー

よく使うボタン:

- **Edit**(編集)は、メッセージの本文を変更します。
- **Regenerate**(再生成)は、AIの返信の新しい版をモデルに作らせます。それぞれの版をスワイプと呼びます。
- **Delete**(削除)は、メッセージを削除します。

ボタンはアイコンで表示されます。各ボタンのラベルは次のとおりです。特定の状況でしか表示されないボタンもあります。

| ボタン | 動作 |
| --- | --- |
| **Copy**(コピー) | メッセージの本文をコピーします。 |
| **Edit** | メッセージを編集できる状態にします。 |
| **Regenerate** | 新しいスワイプ(返信の別の版)を作ります。AIのメッセージのみ。Roleplayでは自分のメッセージにも、ConversationではImpersonateで作った自分のメッセージにも表示されます。 |
| **Delete** | メッセージを削除します。 |
| **Translate**(翻訳) / **Hide translation**(翻訳を隠す) | メッセージを自分の言語に翻訳し、次に押すと翻訳を隠します。 |
| **Add reaction**(リアクションを追加) | 絵文字ピッカーを開きます。Conversationのみ。 |
| **Hide from AI**(AIから隠す) / **Unhide from AI**(AIへの表示を戻す) | このメッセージをモデルに送るのを止めたり、再開したりします。Roleplayのグループチャットでは、キャラクターの選択画面が開きます。 |
| **Bookmark, pin or note**(ブックマーク・固定・メモ) | メッセージをブックマークする、履歴の上限を超えてもプロンプトに残るように固定する(1チャットにつき最大10件)、または**Private note**(非公開メモ)を追加します。**Show the note to the narrator character**(ナレーター役のキャラクターにメモを見せる)をオンにしない限り、モデルがメモを見ることはありません。この設定は、キャラクターが1人のチャットと、キャラクターが個別に返信するグループチャットで使えます。 |
| **Branch from here**(ここから分岐) | このメッセージまでのチャットを新しい分岐にコピーします。シーンのチャットにはありません。 |
| **Clone from here**(ここから複製) | このメッセージまでのシーンのチャットを、新しいRoleplayにコピーします。シーンのチャットのみ。 |
| **Peek prompt**(プロンプトを確認) | この返信に使われたプロンプトをそのまま表示します。最新のAIメッセージのみ。 |
| **Stored guidance**(保存された指示) | この返信を方向づけた指示を表示します。指示を使って作った返信と、Impersonateで作った返信のみ。 |
| **View model thoughts**(モデルの思考を表示) | モデルの隠れた推論を開きます。モデルが推論を返した場合のみ。 |
| **Show original before rewrite**(書き直し前の原文を表示) / **Show rewritten version**(書き直し後を表示) | エージェント(返信と並行して動く補助機能)がメッセージを書き直したときに、元の文章と書き直した文章を切り替えます。 |
| **Mark as new start**(新しい開始点にする) | Roleplayのみ。Advanced Memory(Marinaraの長期記憶機能)がオンのとき、モデルによるチャットの記憶をこのメッセージから始めます。[Advanced Memory](../agents/memory.md)を参照してください。 |
| **Pause speaking**(読み上げを一時停止) / **Resume speaking**(読み上げを再開) / **Restart speaking**(読み上げをやり直す) | Text to Speech(メッセージを音声で読み上げる機能)がオンで読み上げ中のとき、音声を操作します。 |

詳しくは次を参照してください: [Peek Prompt](peek-prompt.md)、[チャットの分岐](branches.md)、[シーン](../roleplay/scenes.md)(シーンのチャットとは、チャットから分岐した短いRoleplayです)、[メッセージの翻訳](../integrations/message-translation.md)、[Text to Speech (TTS)の設定](../media/tts-setup.md)、[ガイド付き生成とImpersonate](guided-and-impersonate.md)、[非公開メモ](../roleplay/getting-started.md#your-private-notes)。

## メッセージの編集

1. メッセージの**Edit**(編集)をクリックします。本文が編集できる入力欄に変わります。
2. 本文を書き換えます。
3. **Save**(保存)をクリックするか、<kbd>Ctrl</kbd>+<kbd>Enter</kbd>(Macでは<kbd>Cmd</kbd>+<kbd>Enter</kbd>)を押します。
4. 保存せずにやめるときは、**Cancel**(キャンセル)をクリックするか、<kbd>Esc</kbd>を押します。

**Settings → General → Input & Editing**(設定 → 一般 → 入力と編集)にある2つの設定を使うと、編集をすばやく始められます。どちらもデフォルトでオンです。

- **Up Arrow edits last message**(上矢印キーで最後のメッセージを編集): 入力欄が空のときに<kbd>Up</kbd>を押します。
- **Double-click edits messages**(ダブルクリックでメッセージを編集): Roleplayのメッセージをダブルクリックまたはダブルタップします。

## メッセージの削除

1. メッセージの**Delete**(削除)をクリックします。**Delete message**(メッセージの削除)ダイアログが開きます。
2. 選択肢を1つ選びます。

| 選択肢 | 動作 |
| --- | --- |
| **Delete only this swipe (1/3)** | 表示中のスワイプを削除します。スワイプが2つ以上あるときだけ表示されます。 |
| **Delete all other swipes** | 表示中のスワイプを残し、ほかのスワイプを削除します。スワイプが2つ以上あるときだけ表示されます。 |
| **Delete this message** | メッセージを、すべてのスワイプごと削除します。 |
| **Delete more** | このメッセージとそれより下のメッセージをすべて選択し、選択バーを開きます。 |
| **Cancel** | ダイアログを閉じます。 |

選択バーが出ているあいだは、メッセージをクリックすると選択に加わります。**Select all messages above**(上のメッセージをすべて選択)と**Select all messages below**(下のメッセージをすべて選択)は選択範囲を広げ、**Unselect all**(すべての選択を解除)は選択を解除します。**Delete selected**(選択したものを削除)で、選択したメッセージを削除します。バーには選択中の件数が表示されます。

「joined the chat」のようなシステムメッセージは、ダイアログを出さずにワンクリックで削除されます。

## スワイプ: 別案の返信

スワイプとは、AIの返信の1つの版です。1件のメッセージは複数のスワイプを持てるので、答えを見比べて気に入ったものを残せます。スワイプが2つ以上になると、メッセージにスワイプの操作部分が表示されます。ここには「2/4」のように、表示中のスワイプと全体の数が表示されます。

- **Previous swipe**(前のスワイプ)と**Next swipe**(次のスワイプ)で、スワイプを1つずつ切り替えます。
- 数字の入力欄で、スワイプに直接移動します。番号を入力して<kbd>Enter</kbd>を押してください。ラベルは**Jump to swipe 1-N**です。
- いちばん新しいスワイプを表示しているときは、次へ進むボタンが**Generate next swipe**(次のスワイプを生成)に変わり、新しいスワイプを作ります。

最後のスワイプは削除できません。削除しようとすると「Cannot delete the last remaining swipe」と表示されます。代わりに**Delete this message**を使ってください。

## 再生成、続きの生成、やり直し

この3つは似ていますが、動作は異なります。

| 操作 | 結果 |
| --- | --- |
| **Regenerate**(再生成) | 新しいスワイプができます。元のスワイプは残ります。タッチ画面では、先に「Regenerate this message as a new swipe?」と確認されます。指示を準備してあるときは、ボタンの表示が**Regenerate (guided)**になります。 |
| `/continue` | 新しいスワイプを作らずに、同じメッセージに文章を書き足します。 |
| 空の**Send**(送信) | 新しい返信を作ります。 |

### 返信の続きを書かせる

入力欄に`/continue`(または`/cont`)と入力して送信します。モデルは、直前の返信が止まったところから続きを書きます。

```text
/continue
```

Marinaraは、新しい文章の前に空行を1つ入れます。最後の文字にそのままつなげるには、**Settings → General → Responses → Add a new line before /continue text**をオフにします。

### 空のSendでやり直す

最後のメッセージが自分のもので入力欄が空のときは、**Send**(送信)は送信ではなくやり直しとして働きます。Roleplayでは、AIがすでに答えたあとでも、空の**Send**で新しいターンを始められます。前の返信に書き足すことはありません。[メッセージの送信とストリーミング](sending-and-streaming.md#retry-without-retyping)を参照してください。

## メッセージをAIから隠す

**Hide from AI**(AIから隠す)をクリックすると、以降のターンでそのメッセージがプロンプトに入らなくなります。メッセージは自分には見えたままで、**Hidden from AI**というラベルが付きます。もう一度送るようにするには、**Unhide from AI**(AIへの表示を戻す)をクリックします。

Roleplayのグループチャットでは、**Hide from AI**を押すとアバターの選択画面が開きます。グループのアバターを選ぶと全員から隠し、キャラクターを1人以上選ぶとそのキャラクターからだけ隠します。メッセージに付く目に斜線のマークで、誰が見られないかがわかります。キャラクターが1人のチャットでは、ボタンを押すとそのまま隠す、または隠すのをやめます。

あるキャラクターからメッセージを隠しても、そのキャラクターはメッセージ内のささやきを受け取ります。ただし、それ以外の部分は受け取りません。全員から隠すと、ささやきも届かなくなります。[ささやきと秘密](../roleplay/getting-started.md#whispers-and-secrets)を参照してください。

範囲を指定して隠すには、`/hide`と`/unhide`を使います。[スラッシュコマンド](slash-commands.md)を参照してください。メッセージ番号は、最初のメッセージを1として数えます。

Advanced Memoryの**Decide who sees new messages**(新しいメッセージを見られる相手を決める)がオンの場合、1人ずつ返信するグループチャットでは、新しいメッセージがその場にいないキャラクターから自動的に隠されます。自分で選んだ設定が常に優先されます。[新しいメッセージを見られる相手の決定](../agents/memory.md#deciding-who-sees-new-messages)を参照してください。

## メッセージの表示トグル

これらのトグルは**Settings → Advanced → Message Tools**(設定 → 詳細設定 → メッセージツール)にあります。

| トグル | デフォルト | 表示される内容 |
| --- | --- | --- |
| **Show message numbers** | オフ | 各メッセージの番号です。`/goto`、`/hide`、`/unhide`で使う番号と同じです。 |
| **Show token usage on messages** | オフ | AIの返信ごとの、プロンプトと生成分のトークン数です(トークンとは、モデルが数える文章の小さな単位です)。取得できる場合は、キャッシュのヒット数と返信にかかった時間も表示します。 |
| **Show model name on messages** | オフ | 各返信を書いたモデルです。 |
| **Show "older messages not sent" note**(「送信されなかった古いメッセージ」の注記を表示) | オン | 古いメッセージがプロンプトに収まらなかったとき、返信の下に「1109 older messages not sent」のような注記を表示します。返信が途中で切れた、または空だったことを伝える注記は常に表示されます。 |
