# グループチャットとグループでの会話

このガイドでは、Marinara Engineのグループチャット、つまり2人以上のキャラクターが同時に参加するチャットを説明します。グループチャットの作り方と、メンバーの追加や削除の方法がわかります。ConversationモードとRoleplayモードで誰が発言するかを決める方法も紹介します。

## グループチャットとは

グループチャットとは、2人以上のキャラクターが入っているチャットのことです。「group chat」専用のボタンはありません。通常のチャットに2人目のキャラクターを追加した時点で、そのチャットがグループチャットになります。

グループチャットが使えるのは**Conversation**と**Roleplay**の2つのモードです。Game Modeにはパーティーの仕組みが別に用意されているため、ここでは扱いません。

Marinaraでは「group」という言葉がいくつかの意味で使われます。グループチャットは、1つのチャットに複数のキャラクターがいることを指します。これは、再利用できるキャラクターの一覧を保存しておく**Folders**(フォルダー)とは別のものです。同じチャットの別バージョンである**Chat Branches**(チャットの分岐)とも異なります。このガイドで扱うのはグループチャットだけです。

## グループチャットの作成

グループチャットは、ほかのチャットと同じNew Chatの設定ウィザードで作ります。キャラクターを2人以上選ぶだけです。

1. サイドバーで、使いたいモードの新規チャットボタンをクリックします。ボタンの表示は**New Conversation**または**New Roleplay**です。
2. ウィザードの**Persona & Characters**ステップに進みます。
3. **Search characters...**欄でキャラクターを探し、アバターか名前をクリックして追加します。
4. 同じ手順で2人目のキャラクターを追加します。人数に決まりはありません。
5. ウィザードを完了するとチャットが開きます。

2人目を追加すると、選択欄の上のラベルが変わります。Conversationモードでは**Group Chat**とメンバー数が、Roleplayモードでは**Characters**と人数が表示されます。

キャラクターの人数に上限はありません。ただし人数が増えるほどプロンプトは長くなり、返信1回あたりの費用も上がります。そのシーンに必要なキャラクターだけを追加してください。

チャットの名前を変更しない場合、Marinaraはキャラクター名をカンマでつないだ名前を付けます。たとえば「Alice, Bob, Carol」のようになります。

### フォルダーでキャラクターをまとめて追加

キャラクターのフォルダーを作ってあれば、フォルダーごと一度に追加できます。フォルダーは**Characters**パネルで作るキャラクターの一覧で、繰り返し使うグループチャットを用意するにはいちばん手軽な方法です。

1. **Persona & Characters**ステップで、**Add from Folder**ドロップダウンを開きます。
2. 一覧からフォルダーを選びます。
3. ドロップダウンの隣にある**Add**をクリックします。

そのフォルダーに入っているキャラクターのうち、まだチャットにいない全員が追加されます。**Add from Folder**は、フォルダーが1つ以上あるときだけ表示されます。フォルダーの作り方と管理方法は、下記の「キャラクターライブラリーの整理」を参照してください。

**Random**の行(表示は**Dice pick**)をクリックすると、まだチャットにいないキャラクターが1人ランダムで追加されます。

## 作成後のメンバー管理

キャラクターの追加、削除、並べ替えは**Chat Settings**(チャット設定)で行います。チャット内の**Chat Settings**ボタンから開きます。

Chat Settingsの中には**Characters**セクションがあります。ここにはメンバー数と、「Characters in this chat. Each character has their own personality that the AI roleplays as.」という説明文が表示されます。各メンバーの行には、アバター、キャラクター名、ドラッグハンドル、目のアイコン、ゴミ箱アイコンが並びます。

- キャラクターを1人追加するには、**Add Character**をクリックして検索します。
- フォルダーごと追加するには、**Add from Folder**をクリックして選びます。
- キャラクターを外すには、ゴミ箱アイコンをクリックします。ツールチップは**Remove from chat**です。
- 並べ替えるには、ドラッグハンドルをつかんでメンバーを上下に動かします。ツールチップは**Drag to reorder**です。

メンバーの順番には意味があります。後述の**Sequential**の応答順では、ここに並んでいる順にキャラクターが返信します。発言の順番を変えたいときはメンバーをドラッグします。

**Characters**セクションはGame Modeには表示されません。Game Modeのパーティーは別の場所で管理します。

### メンバーを外さずにオフにする

しばらく登場させたくないけれど一覧には残しておきたい、というときはメンバー行の目のアイコンを使います。

- 目のアイコンをクリックすると、そのキャラクターが無効になります。ツールチップは**Disable in chat**に変わり、目のアイコンに斜線が入ります。
- もう一度クリックすると元に戻ります。ツールチップは**Enable in chat**です。

無効にしたキャラクターはメンバー一覧に残りますが、どの返信にも加わりません。キャラクターカードはモデルに送られず、発言者として選ばれることもありません。

安全策が1つあります。チャット内のキャラクターを全員無効にすると、Marinaraは全員を有効なものとして扱います。キャラクターが1人もいない返信を防ぐためです。

このオンとオフの状態はチャットごとに保存します。アプリのほかの場所にあるキャラクターには影響しません。MergedモードのRoleplayグループでは、[アクティブなキャラクターの自動化](#automate-active-characters-merged-only)でこの状態を自動で切り替えられます。

## 発言者の決め方: Roleplayモード

Roleplayモードでは、グループチャットの**Chat Settings**に**Group Chat**セクションが表示されます。表示されるのはキャラクターが2人以上いるときだけです。ここでキャラクターの返信のしかたを設定します。

### Merged (Narrator)とIndividual

**Mode**の設定は2択のトグルです。

- **Merged (Narrator)**がデフォルトです。1回の返信で全キャラクターのセリフとナレーションをまとめて生成します。
- **Individual**にすると、キャラクターごとに別々の返信を生成します。

### Color Dialogues(Merged時のみ)

**Mode**が**Merged (Narrator)**のときは、**Color Dialogues**をオンにできます。デフォルトはオフです。オンにすると、各キャラクターのセリフがそのキャラクター専用の色で表示されます。色はCharacter Editorの**Colors**タブで決まります。このタブでは名前の色、セリフの色、メッセージボックスの色を設定します。設定方法はキャラクター編集のガイドを参照してください。

<a id="automate-active-characters-merged-only"></a>

### Automate active characters(Merged時のみ)

Mergedモードでは、アクティブなキャラクター全員のカードが返信のたびにプロンプトへ入ります。そのため、出演者が多いとコンテキストがいっぱいになり、キャラクターの出入りに合わせて目のトグルを手作業で切り替えることになります。**Mode**が**Merged (Narrator)**のときは、**Automate active characters**(アクティブなキャラクターを自動化)がその切り替えを代行できます。選択肢は3つで、デフォルトは**Off**(オフ)です。

- **Off**: 目のトグルで、誰をアクティブにするかを自分で選びます。
- **Decision model**(判定モデル): 返信のたびに、[Decisionモデル](../connections/decision-models.md)に、キャラクターごとに「はい/いいえ」の質問を1つ投げます。そのキャラクターは、返信が続くシーンにいるか、またはこれから登場するか、という質問です。話題に出ただけ、思い出されただけでは対象にならないため、話に出るだけのキャラクターはオフのままです。シーンにいると判断されたキャラクターはオンになり、それ以外はオフになります。
- **Character Tracker**: [Character Tracker](../agents/built-in-agents.md#character-tracker)が直近の返信で記録した登場キャラクターが、誰をアクティブにするかを決めます。追加のモデル呼び出しは不要ですが、1ターン遅れて反映されます。そのターンに登場したキャラクターは、次のターンでオンになります。

設定の下のヒントは、足りないものがあるときにそれを知らせます。Decisionモデルが未選択の場合、このチャットでCharacter Trackerがオフの場合、またはCharacter Trackerが手動で実行される設定で、実行したあとにだけ一覧が変わる場合です。

チャットが問題なく動くように、いくつかのルールがあります。

- **ピン留め。** 自動化がオンの間、**Characters**一覧の各行で、目の左にピンが表示されます。クリックすると、そのキャラクターを現在の状態(オンまたはオフ)のままピン留めし、以後、自動化はそのキャラクターに触れません。目のトグルを手動で切り替えたキャラクターもピン留めされるので、次の返信で選択が元に戻されることはありません。ピン留めされた行のピンはAccent Colorで表示され、もう一度クリックすると解除できます。自動化を**Off**にすると、すべてのピン留めが解除されます。
- **ナレーターは常にアクティブです。** **Roleplay Commands**(Roleplayコマンド)で指定した**Narrator**(ナレーター)がオフになることはありません。
- **回答がなければ一覧は維持されます。** **Decision model**モードで、モデルがすべてのキャラクターについて回答しなかった場合は、あればCharacter Trackerの直近のシーンが代わりに使われます。先に思考するモデルは、**Also gate agents that run before the reply**(返信前に実行するエージェントも判定)がオンでない限り返信の前には回答しないため、トラッカーが代わりを務めます。名前だけでもDecisionモデルの入力に収まらないほど出演者が多い場合も同様で、その場合はモデルにまったく質問しません。どちらにも回答がなければ、一覧はそのままです。
- **全員がオフになる結果は認められません。** 全員をオフにしてしまう結果は無視されます。
- **Character Activityエージェントが優先されます。** 結果の種類に**Character Activity**を使うカスタムエージェントがあるチャットでは、そのエージェントが引き続き管理し、自動化は何もしません。

Character Trackerは、見つけたキャラクターごとに独自の名前を書き込みます。キャラクターとカードの照合は、カードのID、名前、Character Editorの**Colors**タブにあるカードの名前の別名の順に行われるため、オフの間に登場したカードも見つかります。チャットのキャラクターが1人も含まれないトラッカーの一覧、たとえばエキストラだけのシーンの場合は、現在の一覧が維持されます。

自動化は、返信、スワイプ、再生成のたびにその前に実行されます。**Continue**とimpersonateでは実行されません。この設定は設定プロファイルに保存され、ピン留めは1つのチャットに属します。

<a id="response-order-individual-only"></a>

### Response Order(Individual時のみ)

**Mode**が**Individual**のときは、**Response Order**の設定が表示されます。3択のトグルです。

- **Sequential**がデフォルトです。**Characters**一覧に並んでいる順に、全キャラクターが順番に返信します。順番を変えるにはメンバーを並べ替えます。
- **Smart**は、短い内部的なAI呼び出しで次に返信するキャラクターを決めます。直近のメッセージと各キャラクターの情報を読み、たいていは1人を選びます。メッセージに`@Alice`のようなメンションを書くと、そちらが優先されます。

  **Decision model**(判定モデル)を選択済みなら([Decisionモデル](../connections/decision-models.md)を参照)、その下の**Also use it to pick who speaks in Smart response order**(Smart応答順の発言者選択にも使用)をオンにできます。Smart順序は各候補について個別のはい・いいえのスコアを求めます。質問には共通の直近5件のメッセージと、候補の名前、状態、活動、発言頻度、短い性格または説明を含む一覧を使います。ホスト型プロバイダーにはこの一覧も送ります。[モデルが受け取る情報](../connections/decision-models.md#what-the-model-sees)を参照してください。

  これらのスコアはAIの完全な返信より速く得られることがありますが、速度と費用はモデルと候補数に依存します。Roleplayでは最も可能性の高い発言者を選びます。Conversationでは答える理由のある全員が、可能性の高い順に返信します。直前に話したキャラクターは、ほかに答える理由のある人がいれば順番を待ちます。Decisionモデルが答えなければ、通常のAI呼び出しを使います。

- **Manual**は自動返信を止めます。誰が返信するかは、メッセージバーの**Trigger Response**で指定します。

**Smart**では、AIが複数のキャラクターを順番待ちに並べることがあります。すぐに返信するのは最初の1人だけです。次に発言するキャラクターを選ぶには、メッセージバーの**Trigger Response**を使います。空のメッセージを送って、順番待ちの次のキャラクターに生成させることもできます。

Roleplayの**Individual**モードで順序を**Smart**または**Manual**にすると、選択メニューの先頭に**Smart**が表示され、アクセントカラーの人物グループのアイコンが付きます。その返信で次に話すキャラクターをモデルに選ばせます。DecisionモデルのSmart順序オプションがオンなら、そのモデルを使います。保存済みの返信順序は変わらず、キャラクター名の項目から直接選ぶこともできます。

**Individual**モードでは、さらに2つのトグルが表示されます。

- **Add Turn To Prompt**はデフォルトでオンです。そのターンにどのキャラクターが返信するかを示す短い指示を追加します。
- **Name Prefix History**はデフォルトでオフです。過去のメッセージをモデルに送る前に、発言者名をどう付けるかを変えます。誰の発言かをキャラクターが取り違えるとき以外は、オフのままにします。

### Scenario Override

**Scenario Override**欄では、グループ全体で共通のシナリオを指定できます。テキストを入力すると、プロンプトの中で各キャラクター自身のシナリオがそのテキストに置き換わります。空のままにすれば、各キャラクターのシナリオがこれまでどおり使われます。

オンとオフを切り替えるスイッチはありません。テキストを入力すればオン、消せばオフです。大きなウィンドウで編集したいときは、展開アイコン(ツールチップは**Expand editor**)をクリックします。大きい方のエディターの名前は**Group Scenario Override**です。

再利用について1点注意があります。**Scenario Override**のテキストは、このチャット1つだけに紐づきます。設定プロファイルには含まれないため、プロファイルを新しいチャットに適用しても引き継がれません。

### 設定とデフォルト(Roleplay)

| 設定 | 場所 | デフォルト |
|---|---|---|
| **Mode**(**Merged (Narrator)** / **Individual**) | Group Chatセクション | Merged (Narrator) |
| **Color Dialogues** | Group Chatセクション、Mergedモード | Off |
| **Automate active characters**(Off / Decision model / Character Tracker) | Group Chatセクション、Mergedモード | Off |
| **Response Order**(Sequential / Smart / Manual) | Group Chatセクション、Individualモード | Sequential |
| **Add Turn To Prompt** | Group Chatセクション、Individualモード | On |
| **Name Prefix History** | Group Chatセクション、Individualモード | Off |
| **Scenario Override** | Group Chatセクション | 空(オフ) |

これらの設定はほとんどが設定プロファイルに保存されるので、繰り返し使えます。例外は**Scenario Override**だけで、こちらはそのチャットに残ります。自動化のピン留めも、そのチャットに残ります。

## 発言者の決め方: Conversationモード

Conversationモードでも同じグループチャットを使えますが、**Group Chat**セクションは表示されません。代わりに、**Chat Settings**の**Autonomous Messaging**セクションに設定があります。

デフォルトでは、Conversationモードのグループチャットは**Merged**モードと同じように動きます。1回の返信で複数のキャラクターが発言し、セリフは発言者ごとに自動で色分けされます。Conversationモードに色分けのトグルはありません。

### Reply When Mentioned

**Reply When Mentioned**をオンにすると、1人ずつ発言する形に切り替わります。オンのときは、名前を挙げたキャラクターか、手動で指定したキャラクターだけが返信します。トグルの説明は「Characters wait for direct mentions or manual response triggers.」です。

キャラクターを名指しするにはメンションを使います。メッセージ入力欄で`@`に続けてキャラクター名を入力すると、候補の一覧が表示されます。メンションしたキャラクターが返信します。

メンションを入力せずに発言者を選びたいときは、**Trigger Response**を使います。

- デスクトップでは、Sendの隣にあるボタンです。
- モバイルでは、メッセージバーから開くツールトレイの**Trigger Response**の見出しの下にあります。

ボタンのツールチップは「Trigger character response」です。

### Character Exchanges

**Character Exchanges**をオンにすると、キャラクター同士が自分から話し始めます。デフォルトはオフです。説明は「Characters chat with each other in group chats.」です。

オンにすると、キャラクターは自分に向けられたメッセージに答えるだけでなく、離れている間もキャラクター同士で返信し合います。これはMarinaraをブラウザーで開いている間だけ動きます。アプリを閉じるとキャラクター同士の返信も止まります。1日あたりのメッセージ上限も、自動送信メッセージと共通です。

キャラクター同士のやり取りは、キャラクターのスケジュールがオンでもオフでも動作します。**Individual**に設定したグループでは、やり取りやキャラクター同士のメンションへの返信に、グループのその日最後の声かけの1回分を使うことはありません。そのため、あとから声をかけるときにもその1回分を使えます。

## ターンの扱いの早見表

| モードと設定 | 動作 | 操作方法 |
|---|---|---|
| Roleplay、Merged | 1回の返信で全キャラクターが発言 | 常に全キャラクターがまとめて発言 |
| Roleplay、Individual、Sequential | メンバーの並び順に各キャラクターが返信 | メンバーをドラッグして並べ替え |
| Roleplay、Individual、Smart | 次に発言するキャラクターをAIが選ぶ | `@Name`のメンションが選択より優先 |
| Roleplay、Individual、Manual | 自動では誰も返信しない | **Trigger Response**で指定 |
| Conversation、デフォルト | 1回の返信で複数のキャラクターが発言 | `@Name`のメンションで相手を指定 |
| Conversation、Reply When Mentionedがオン | メンションか手動の指定がないと誰も返信しない | `@Name`のメンションか**Trigger Response** |
| Conversation、Character Exchangesがオン | キャラクター同士もメッセージを送り合う | 止めるにはオフにする |
