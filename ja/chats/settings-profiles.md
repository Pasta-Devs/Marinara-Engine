# 設定プロファイル

設定プロファイルとは、繰り返し使うチャットの設定に名前を付けてまとめたものです。接続、プロンプトプリセット、エージェント、ツール、翻訳、記憶機能の呼び出し、詳細パラメーターなどが含まれます。同じオプションをもう一度設定する代わりに、プロファイルをほかのチャットに適用できます。

プロファイルは**Chat Settings**(チャット設定)の上部にあります。ConversationとRoleplayで使えます。Gameのチャットには、プロファイルの操作欄は表示されません。

**プロンプトプリセット**は別のものです。システムプロンプトの構成と生成の値を決めるもので、Presetsパネルで編集します。[Preset Editorとプロンプトの管理](../prompts/presets.md)を参照してください。設定プロファイルはもっと広い範囲をまとめたもので、その1項目としてプロンプトプリセットを含められます。

## プロファイルを適用する

1. 変更したいチャットを開き、**Chat Settings**を開きます。[Chat Settingsの概要](chat-settings.md)を参照してください。
2. **Profile**(プロファイル)ドロップダウン(ラベルは**Apply a settings profile to this chat**)を開きます。
3. プロファイルを名前で選びます。

チャットはすぐに更新されます。プロファイルによって**Hide summarised messages**(要約済みのメッセージを隠す)がオンまたはオフになる場合、チャットの要約済みのメッセージも、同時にモデルから隠されるか、再び見えるようになります。

うまくいかなかった場合: チャットの値が保存済みのどのプロファイルとも一致しないときは、ドロップダウンに**Custom settings profile**と表示されます。適用したプロファイルが削除されている場合は、**Missing profile - choose a profile**と表示されます。別のプロファイルを選んでください。

## プロファイルを作成または編集する

1. ドロップダウンの横にある**New**(新規作成、「New profile from this chat's settings」)をタップします。プロファイルビルダーが開き、このチャットの設定がスロットに入っています。保存済みのプロファイルを変更するには、選択して**Edit**(編集)をクリックします。Defaultプロファイルは編集できません。
2. **Profile name**(プロファイル名)を入力します。
3. スロットを埋めます(下の一覧を参照)。
4. **Save and choose chats…**(保存してチャットを選ぶ)をタップします。
5. 新しいチャットでこのプロファイルを使うには、**Make this the default**(これをデフォルトにする)にチェックを入れます。一覧の先頭は**New conversation chats**または**New roleplay chats**です。
6. 今すぐプロファイルを適用する既存のチャットにチェックを入れます。
7. **Apply to N chats**(N件のチャットに適用)をタップします。何もチェックしていない場合は、**Save**(保存)をタップします。

ビルダーは、スロットを**Chat**(チャット)、**Story**(物語)、**Pictures**(画像)、**Behind the scenes**(裏方の処理)の下にまとめています。スロットは次のとおりです。

- **Connection**(接続)、**Prompt preset**(プロンプトプリセット)、**Parameters**(パラメーター)
- **Agents**(エージェント)、**Tools**(ツール)、**Memory & summary**(記憶と要約)
- **Persona**(ペルソナ)、**Lorebooks**(ロアブック)、**Background**(背景)
- **Image style**(画像のスタイル)、**Translation**(翻訳)

スロットの埋め方は次のとおりです。

- 各スロットの一覧から項目を選びます。**Agents**、**Tools**、**Lorebooks**は複数選べます。**Tools**のチェックボックスで、ツールごとにオンとオフを切り替えます。1つしか選べないスロットを空にするには、**None**(なし)を選びます。
- コンピューターのエージェントとロアブックの一覧では、<kbd>Ctrl</kbd>(macOSでは<kbd>Command</kbd>)を押したまま選ぶと、複数の項目を選べます。スマートフォンでは、選択用のコントロールを使います。**Clear selection**(選択をクリア)で一覧を空にできます。
- コンピューターでは、エディターを開いたままライブラリーのサイドバーを開き、項目を対応するフィールドへドラッグできます。
- **Parameters**、**Memory & summary**、**Translation**には、プロファイルにその設定が含まれるかどうかだけが表示されます。Chat Settingsで変更してから、プロファイルに保存してください。

新規チャットのウィザードでも、**Use a Profile**(プロファイルを使う)ステップの一覧の先頭に**New profile…**(新しいプロファイル)が、保存済みプロファイルの横に**Edit**があります。保存すると、ウィザードはそのプロファイルを選択します。

## チャットの設定をプロファイルに保存する

チャットからプロファイルを更新するには、プロファイルを適用してチャットを変更し、ドロップダウンの下にあるアイコンの列を使います。

| ボタン | ラベル | 結果 |
| --- | --- | --- |
| Save | **Save current chat settings into this profile** | プロファイルの保存済みの値を置き換えます。 |
| Rename | **Rename profile** | 名前を変更します。 |
| Import | **Import settings profile (.json)** | プロファイルのファイルを読み込みます。 |
| Export | **Export settings profile (.json)** | プロファイルをダウンロードします。 |
| Delete | **Delete profile** | プロファイルを完全に削除します。 |

### プロファイルを使うほかのチャットを更新する

各チャットはプロファイルの設定のコピーをそれぞれ持っているため、プロファイルを保存しただけでは、ほかのチャットは変わりません。同じモードのほかのチャットがそのプロファイルを使っている場合は、**Other chats use this profile**(ほかのチャットがこのプロファイルを使用中)というダイアログで確認されます。

- **Save to this profile only**(このプロファイルにのみ保存)は、プロファイルを保存し、ほかのチャットはそのままにします。
- **Save and update N other chats**(保存して、ほかのN件のチャットを更新)は、プロファイルのChat Settingsをそれらのチャットにもコピーします。それらのチャットで独自に変えていた設定は置き換わり、保存元のチャットでデフォルトのままにしていた設定は、それらのチャットでもデフォルトに戻ります。

ほかにプロファイルを使うチャットがない場合、**Save**は確認せずに保存します。マルチプレイヤーのルームが、この方法で更新されることはありません。

<a id="choosing-the-default-profile"></a>

## デフォルトのプロファイルを決める

ドロップダウンの横の星は、そのモードの新しいチャットで自動的に使うプロファイルを示します。デフォルトにできるのは、1つのモードにつき1つのプロファイルだけです。ラベルは**Mark this profile as default for new chats in this mode**、**This profile is the default for new chats in this mode**、**Select a profile to mark it as default**です。ビルダーで**Make this the default**にチェックを入れることもできます。

## プロファイルをインポート、エクスポートする

**Export settings profile (.json)**は、`.marinara-settings-profile.json`ファイルをダウンロードします。バックアップとして保管したり、ほかの人と共有したりできます。**Import settings profile (.json)**は、対応するファイルから新しいプロファイルを作り、既存のプロファイルを上書きすることはありません。古い形式で書き出したファイルも読み込めます。インポートに失敗すると、**Import failed**と表示されます。

プロファイルに保存されるのは設定だけで、プロバイダーの秘密情報は含まれません。エクスポートまたはインポートしたプロファイルには、Discordミラーのwebhook、DeepLXのアドレス、DeepLのキー、Intifaceのアドレスも含まれません。このインストール環境で保存したプロファイルでは、これらは保持されます。エクスポートしたファイルには、このインストール環境にしか存在しないペルソナとロアブックは含まれません。

## Defaultプロファイル

ConversationとRoleplayには、それぞれ組み込みの**Default**(デフォルト)プロファイルがあります。これを適用すると、プロファイルが管理する設定が、そのモードのMarinaraのデフォルトに戻ります。名前の変更、上書き、削除はできません。無効になった操作には、**Cannot save into the Default profile**、**Cannot rename the Default profile**、**Cannot delete the Default profile**と表示されます。

## お気に入りのウィンドウレイアウト

Chat Settingsのタイトルバーで**Reset View**(表示をリセット)の横にある星は、新しいチャット用のお気に入りのウィンドウレイアウトを保存します。**Profile**ドロップダウンの横の星は、それとは別に、デフォルトのプロファイルを選ぶものです。手順は[新しいチャットのレイアウトを選ぶ](chat-settings.md#choosing-a-layout-for-new-chats)を参照してください。

新しいチャットが、保存済みレイアウトを持つデフォルトのプロファイルを使う場合は、そのレイアウトがお気に入りレイアウトより優先されます。レイアウトを保存していないプロファイルは、お気に入りから適用された配置も含め、チャットの配置を維持します。ただし、プロファイルはレイアウトのヒントの設定(この設定を持たない古いプロファイルでは、ヒントが表示されます)と、Scoped Regex Scriptsのモード(モードを持たない場合は、プロンプトプリセットのデフォルト)については、自身の設定を適用します。

## プロファイルに含まれるもの

プロファイルには、チャットがモデルとやり取りする方法が保存されます。

- 接続
- プロンプトプリセット(Conversationではプロンプトの供給元と呼びます)
- エージェントとツール
- 翻訳、Memory Recall、Advanced Parameters
- ウィンドウとボタンのレイアウト: 位置、サイズ、ピン留め、ロック、Chat Settings内に置くツールと切り離すツール、開いている操作ウィンドウ、コンピューターとスマートフォンのボタン位置。**Default**のようにレイアウトを保存していないプロファイルは、チャットのレイアウトをそのままにします。
- レイアウトのヒントを非表示にするかどうか。**Default**や、この選択を持たない古いプロファイルを適用すると、ヒントが再び表示されます。
- そのほかの再利用できるチャットのオプション

プロファイルには**最初の選択**として、ペルソナ、有効にするロアブック、背景も保存できます。

- プロファイルを適用すると、これらの選択がチャットにコピーされます。プロファイルで空になっているものは、チャット自身の選択が残ります。
- プロファイルのほかの設定は、引き続きチャットの設定を置き換えます。
- 選択は連動しません。後からチャットで変えた内容は、そのチャットに残ります。
- **Save current chat settings into this profile**で保存しても、プロファイル自身のペルソナ、ロアブック、背景は保持されます。背景がないプロファイルには、保存したときにチャットの背景が入ります。
- ほかのチャットを更新しても、それらのチャットのペルソナ、ロアブック、背景は変わりません。

キャラクター、スプライト、要約、タグ、シーンのプロンプトといった、チャット自身が持つ内容は、プロファイルでは置き換わりません。チャットの履歴も、マクロ変数、オフにしたキャラクター、マルチプレイヤーのルームといった進行中の状態も含みません。

### Save and updateがコピーするもの

**Save and update**は、次のものをほかのチャットにコピーします。

- 生成とコンテキストのオプション
- グループチャットのオプション
- 機能とコマンドのスイッチ
- エージェントとそのオプション
- 記憶と要約の設定
- 翻訳
- ウィンドウのレイアウト

それ以外は、各チャットの状態のまま残ります。

- 接続、プロンプトプリセット、カスタムプロンプト
- 物語とキャラクター
- ロアブックと背景
- メモと進行状況
- ナレーターだけが使えるRoleplayコマンドの指定
- Noodleがそのチャットのメッセージを使えるかどうか

Advanced Parametersと画像の説明文生成(オンかオフか、どの接続で画像を説明するか)は、プロファイルの接続を使うチャットでだけ変わります。これらはその接続ごとに設定されるためです。キャラクターのスケジュールが変わるのは、保存元のチャットでオンまたはオフを切り替えた場合だけです。Knowledge Retrieval、Knowledge Router、Lorebook Keeper、Expression Engineは、オンかオフか、およびプロンプトテンプレートについて、各チャットの状態のまま残ります。それらのソース、ロアブック、スプライトは、各チャットが自分で選びます。
