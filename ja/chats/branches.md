# チャットの分岐

このガイドでは、Marinara Engineのチャットの分岐について説明します。分岐とは何か、どう作るのか、さらに切り替え、名前の変更、削除、エクスポート、インポートの方法まで扱います。分岐を使えば、元のチャットを残したまま別の展開を試せます。

## 分岐とは

分岐とは、選んだ地点までの履歴を共有するチャットのコピーです。元のチャットをそのまま保ちながら、別の方向へ話を進めたいときに使います。

同じチャットから作られた分岐は、1つのグループにまとまります。チャット一覧では、分岐が複数あるチャットも1行だけ表示され、その横に分岐の数が小さく表示されます。分岐を開いたり切り替えたりする操作は、**Chat Settings**の**Chat Branches**(チャットの分岐)セクションから行います(後述)。

分岐ごとに表示名を付けられるので、「friendly ending」「dark ending」のようにラベル付けできます。この表示名は、元になっているチャット名とは別のものです。

分岐の系譜には、直接の元になったチャットと、分岐した位置のメッセージが記録されます。元のメッセージIDとコピー先のメッセージIDは両方とも保持されます。コピーされたメッセージには新しいIDが割り当てられますが、この記録があるおかげで連携先でも分岐点を特定できます。分岐からさらに分岐させた場合、直接の親として記録されるのはその分岐であり、いちばん最初のチャットではありません。古い分岐や、インポートで追加された同グループの分岐は、表示名は保持しますが系譜の情報を持ちません。

## ここから分岐する

チャット内のどのメッセージからでも分岐を作れます。

1. メッセージにマウスカーソルを重ねます(モバイルではタップします)。メッセージの操作バーが表示されます。
2. **Branch from here**(ここから分岐)ボタンをクリックします。小さな分岐アイコンが目印です。

Marinaraは、そのメッセージまでを含めてチャットをコピーし、新しい分岐を作ります。新しい分岐には次の特徴があります。

- モード、キャラクター、ペルソナ、プロンプトプリセット、接続は元のチャットと同じものを引き継ぎます。
- すべてのメッセージをコピーします。スワイプ(同じ返信の別案)もすべて含まれ、どのスワイプが選ばれていたかも引き継ぎます。スワイプの仕組みは[メッセージの操作: 編集、削除、スワイプ、再生成](messages.md)を参照してください。
- コピーしたメッセージに紐づくトラッカーとゲームの状態のスナップショットもコピーします。そのため、RoleplayとGame Modeのチャットでも状態が保たれます。
- 表示名は最初**New Branch**になります。名前は後から変更できます(後述)。
- 元のチャットと同じチャットフォルダーに入ります。

メッセージのないチャットでは、分岐位置の記録は空になります。親のチャットを削除しても、そこから分かれた分岐の系譜の記録は変わりません。ただし、分岐グループ全体を削除した場合は、そのグループ内のチャットがすべて削除されます。

日次と週次の要約は引き継ぎません。ローリング要約のうち、対象のメッセージ範囲がコピーされた分岐の中に完全に収まっているものは引き継がれ、分岐側の新しいメッセージIDに対応付け直されます。範囲が分岐点をまたぐ要約と、メッセージの情報を持たない古い形式の要約は対象外です。新しい分岐では、これらは最初から作り直しになります。

シーンのチャットは分岐できません。シーンのチャットでは**Branch from here**ボタンが表示されず、代わりに**Clone from here**(ここから複製)という別の操作が用意されています。詳しくは[シーン: Roleplayを枝分かれさせる](../roleplay/scenes.md)を参照してください。

## Chat Branchesセクション

**Chat Settings**を開き、**Chat Name**の下にある**Chat Branches**セクションを展開します。ヘッダーには現在の分岐の数が表示されます。コンピューターでは、独立したウィンドウとして切り離すこともできます([チャット設定の概要](chat-settings.md#popping-a-section-out-into-its-own-window)を参照)。

このセクションには現在のチャットの分岐がすべて一覧表示され、いま開いている分岐が先頭に来ます。各行には分岐の表示名と最終更新日時が表示されます。

### 別の分岐に切り替える

分岐の行をクリックすると、その分岐が開きます。チャットの表示が選んだ分岐に切り替わります。

### 分岐の名前を変更する

1. **Chat Branches**セクションを開きます。
2. 名前を変更したい分岐の行にある鉛筆(名前の変更)ボタンをクリックします。
3. **Rename Branch**というウィンドウが開き、「Set a display name for this chat branch.」と表示されます。
4. 新しい名前を入力し、**Rename**ボタンで確定します。

名前を空にした場合や、変更せずに確定した場合は、何も起こりません。

### 分岐を削除する

1. **Chat Branches**セクションを開きます。
2. 分岐の行にあるゴミ箱(削除)ボタンをクリックします。
3. **Delete Branch**というウィンドウが開き、「Delete this branch? Messages will be lost.」と確認されます。
4. **Delete**ボタンで確定します。

削除されるのは、その分岐とその分岐のメッセージだけです。ほかの分岐はそのまま残ります。

### すべての分岐を削除する

チャットに分岐が2つ以上ある場合は、セクションの下部に**Delete All Branches**(すべての分岐を削除)ボタンが表示されます。「Delete all N branches? This cannot be undone.」と確認されるので、**Delete All**ボタンで確定すると、グループ内のすべての分岐が一度に削除されます。

この操作はチャット一覧からも始められます。分岐のあるチャットを、ゴミ箱アイコンから削除してください。**Delete Chat**というウィンドウが開き、何を削除するかを確認されます。ここには**Delete This Branch Only**ボタンと**Delete All N Branches**ボタンが並びます。一覧からの削除については[チャット一覧の管理](managing-chats.md)を参照してください。

## 分岐をエクスポートする

**Chat Branches**セクションの上部にはエクスポート用のボタンがあります。エクスポートされるのは、いま開いている分岐です。

- **JSONL**: 分岐をJSONLファイルとしてダウンロードします。JSONLとは1行に1メッセージを書く形式で、SillyTavernと互換性があります。
- **Text**: 分岐をプレーンテキストの記録としてダウンロードします。

多数のチャットをまとめてエクスポートしたいときは[チャットのエクスポートとインポート](export-import.md)を参照してください。エクスポートにモデルの思考過程を含める設定についても、そちらで説明しています。

## JSONLファイルを新しい分岐としてインポートする

保存済みのチャットログを、いま開いているチャットの新しい分岐として取り込めます。

1. **Chat Branches**セクションを開きます。
2. **Import**(インポート)ボタンをクリックします。
3. SillyTavernまたはMarinaraからエクスポートしたJSONLファイル(`.jsonl`)を選びます。

Marinaraはそのファイルを、現在のチャットのグループに新しい分岐として追加します。「Imported N messages as a new branch」のようなメッセージが表示され、続けて新しい分岐に切り替わります。
