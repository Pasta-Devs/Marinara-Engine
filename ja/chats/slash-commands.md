# スラッシュコマンド一覧

このガイドでは、Marinara Engineのチャットで入力できるスラッシュコマンドを一覧で説明します。スラッシュコマンドとは、メッセージ入力欄にスラッシュ(/)から始まる短い文字列を打ち込んで、操作をすばやく実行する仕組みです。画面をその場で操作するコマンドもあれば、AIに文章を書かせるコマンドもあります。

## スラッシュコマンドの使い方

スラッシュコマンドは、チャット下部のメッセージ入力欄に入力し、**Send**(送信)を押すと実行できます。チャットモードごとに**Settings**(設定)で**Send on Enter**をオンにしてあれば、Enterでも送信できます。デフォルトでは、ConversationチャットはEnterで送信、Roleplayチャットは改行になります。メッセージ入力欄にはスラッシュコマンドのヒントが表示されます。Roleplayチャットでは**Write your response, / for commands**と表示されます。Conversationチャットではキャラクターの名前が入った「Message @Alice, / for commands」のような表示になります。キャラクターが2人以上いるチャットでは、代わりにチャット名が表示されます。

スラッシュを入力すると、条件に一致するコマンドの小さなメニューが入力欄の上に出ます。各行には引数を含むコマンドの書式と短い説明が並びます。行をクリックまたはタップすると、そのコマンドが入力欄に入るので、必要な文字列を続けて書いて送信します。

`[name]`や`[range]`などの角括弧内のラベルは、実際の値に置き換えてください。角括弧自体は入力しません。`(optional)`と記された引数は省略できます。`|`は選択肢の区切りで、`prompt|reset`のような値の候補や、コマンド書式全体の候補を示します。

多くのコマンドには短い別名があります。たとえば`/continue`と別名の`/cont`は、どちらも同じ動作です。アプリ内でいつでも全一覧を見たいときは、次のコマンドを実行します。

```
/help
```

ブラウザー側だけで動き、チャットをその場で変えるコマンドは、費用がかかりません。一方、AIに文章を生成させるコマンドは、接続したプロバイダーを使うためトークンを消費することがあります。トークンとは、ほとんどのAIプロバイダーが文章の量を測って課金する単位です。以下の表には、各コマンドの動作を記載しています。

スラッシュコマンドは**Conversation**と**Roleplay**のメッセージ入力欄で使えます。**Game**モードでスラッシュコマンドとして動くのは`/illustrate`だけです。それ以外のスラッシュ付きの入力は、通常のテキストとして送信されます。

いくつかのコマンドはメッセージ番号を使います。Marinaraはチャットの最初のメッセージを1、次を2、その次を3というように数えます。`/goto`、`/hide`、`/unhide`などのコマンドはこの番号を使います。

## チャットとメッセージのコマンド

チャットとメッセージを管理するためのコマンドです。**Conversation**チャットと**Roleplay**チャットで使えます。

| コマンド | 別名 | 動作 |
|---|---|---|
| `/help` | | すべてのスラッシュコマンドを一覧表示します。 |
| `/send [message]` | | 生成を開始せずに、自分のペルソナとしてメッセージを投稿します。 |
| `/continue` | `/cont` | 新しいメッセージを送らずに、直前のAIの返信に続きの文章を足します。**Settings → General → Responses**の**Add a new line before /continue text**で、続きの文章を空行のあとから始めるか、途切れた位置に直接つなげるかを切り替えられます。 |
| `/goto [number]` | `/jump`, `/scroll` | 指定した番号のメッセージまでチャットをスクロールします。 |
| `/hide [range] [name (optional)]` | | 1件以上のメッセージを、以降のターンでAIから見えないようにします。 |
| `/unhide [range]` | | 非表示にしたメッセージを、再びAIから見えるようにします。 |
| `/sys [message]` | `/system` | システムメッセージを追加します。この注記はチャットに表示されてAIの動きを誘導しますが、キャラクターの発言にはなりません。 |
| `/macros` | `/macro` | `{{user}}`や`{{char}}`など、使えるプロンプトのマクロを一覧表示します。 |
| `/remind [time] [message]` | `/reminder`, `/timer` | タイマーを設定し、時間になったらチャットにリマインドのメッセージを投稿します。 |

27番のメッセージへ移動するには、次のように入力します。

```
/goto 27
```

`/hide`と`/unhide`には、番号1つ、範囲、その組み合わせを指定できます。たとえば次の例は、3番から8番までのメッセージを非表示にします。

```
/hide 3-8
```

1つのメッセージには`/hide 5`、複数には`/hide 2-5,9,12`とも書けます。キャラクター名を省略すると、すべてのキャラクターから非表示になります。非表示のメッセージはチャットに残りますが、AIは次のターンで読みません。全体に対して非表示にしたメッセージを戻すには、同じ形式の番号リストを`/unhide`に指定してください。

**Roleplay**では、範囲の後ろにキャラクター名を付けると、そのキャラクターに対してだけメッセージを非表示にできます。

```
/hide 3-8 Maukie
/hide 2-5,9 "Powers That Be"
```

ほかのキャラクターの閲覧範囲は変わりません。名前を先に書く場合、空白を含む名前は引用符で囲んでください。従来の`/hide Maukie 3-8`と`/hide "Powers That Be" 2-5,9`も引き続き使えます。複数のキャラクターに一致する場合は、名前を省略せずに入力してください。数字だけのキャラクター名は、`/hide 1 "123"`のように引用符で囲み、メッセージ番号と区別してください。Roleplayのグループチャットでは、メッセージの**Hide from AI**(AIから隠す)のアバター選択で、キャラクターごとの非表示を確認・解除できます。キャラクターが1人のRoleplayチャットでは、代わりにメッセージの**Unhide from AI**(AIに再表示)を使ってください。`/unhide`で解除できるのは全体に対する非表示だけです。

`/remind`コマンドは、時間、メッセージの順に指定します。時間の単位は、時間が`h`、分が`m`、秒が`s`です。次の例では30分後にリマインドします。

```
/remind 30m check the oven
```

リマインダーはブラウザーのセッション内に保持されるため、実行されるまでタブを開いたままにしてください。

## ストーリーとロールプレイのコマンド

物語の方向づけ、キャラクターの演じ分け、イラストの追加に役立つコマンドです。多くは**Roleplay**チャットでの利用に向いています。例外は`/scene`で、これは**Conversation**チャットから実行します。

| コマンド | 別名 | 動作 |
|---|---|---|
| `/guided [direction]` \| `/guided respond for [name] [direction (optional)]` | `/narrator`, `/narrate`, `/nar` | 次のAIの返信を、指定した方向へ誘導します。 |
| `/as [name] [message (optional)]` | `/respond` | キャラクターとしてメッセージを投稿するか、キャラクターに返信させます。 |
| `/emote [expression (optional)]` \| `/emote "[name]" [expression (optional)]` | `/emotion`, `/sprite` | キャラクターのスプライトの表情を一覧表示するか、切り替えます。 |
| `/roll [dice (optional)]` | `/r`, `/dice` | ダイスを振って結果を投稿します。 |
| `/random` | `/rand`, `/event` | 物語に予想外の出来事を加えるようAIに指示します。 |
| `/scene [description (optional)]` | `/rp` | Conversationチャットから実行します。そのチャットから分岐する新しいRoleplayのシーンを開始します。 |
| `/illustrate [range=N\|range=N-M (optional)] [prompt (optional)]` | `/ill` | 現在のチャット向けにギャラリーの画像を生成します。 |
| `/impersonate [direction (optional)]` | `/imp` | 自分のペルソナとして返信を書きます。 |
| `/impersonate_prompt [prompt\|reset]` | `/imp_prompt` | このチャットで`/impersonate`が使う指示を設定します。 |

**Roleplay**では、`/illustrate range=12`でメッセージ12を描き、`/illustrate range=12-18`でメッセージ12から18をIllustratorに渡せます。`/goto`と同じ番号を昇順で指定し、最大200メッセージまで選択できます。非表示のメッセージは除外されます。画像は選択範囲の最後の表示対象メッセージに添付され、プロンプト確認中に新しいメッセージが届いても選択は変わりません。Advanced Memoryを有効にしていても過去のメッセージを使えます。`range=`を省くと、従来どおり現在のシーンを対象にします。任意で入力したプロンプトは、これまでどおり直接使用されます。

次の返信を誘導するには、`/guided`のあとに方向性を書きます。

```
/guided make him confess he is lying
```

Roleplayのグループチャットでは、`/guided respond for [name] [direction (optional)]`で返信するキャラクターを指定できます。たとえば次のように入力します。

```
/guided respond for "Powers That Be" describe the approaching storm
```

`/as [name] [message (optional)]`で、キャラクターとしてテキストを投稿できます。メッセージを省略すると、代わりにモデルがそのキャラクターの次の返信を生成します。

```
/as Dottore "The experiment begins."
/as Dottore
```

`/roll`コマンドはダイス記法を解釈します。次の例では6面ダイスを2個振ります。

```
/roll 2d6
```

`/roll 1d20+5`のように補正値も足せます。`/roll`だけを入力した場合は、Marinaraが`1d20`を振ります。

スプライトとは、表情を表したキャラクターの立ち絵です。`/emote`コマンドは、どのスプライトを表示するかを切り替えます。`/emote`だけを入力すると使える表情の一覧が出て、名前を指定するとその表情に切り替わります。

```
/emote joy
```

キャラクターを1人指定するには、`/emote "[name]" [expression (optional)]`を使います。たとえば`/emote "Powers That Be" joy`です。表情を省略すると、そのキャラクターで使える表情の一覧が表示されます。

スプライトの切り替えには、スプライトをアップロード済みのRoleplayチャットが必要です。追加の手順は[キャラクターのスプライト](../characters/sprites.md)を参照してください。

ペルソナとは、チャットの中で自分自身を表すキャラクターで、プロンプトでは`{{user}}`と書きます。`/impersonate`コマンドは、自分の代わりに返信を書きます。あとに方向性を書き足すこともできます。

```
/impersonate ask about the weather
```

`/impersonate`と`/impersonate_prompt`は**Conversation**チャットでは使えません。ガイド付き生成とImpersonateのくわしい手順は[ガイド付き生成とImpersonate](guided-and-impersonate.md)を参照してください。

## Conversationモードのコマンド

次のコマンドは**Conversation**チャットでのみ使えます。

| コマンド | 動作 |
|---|---|
| `/games` | インストール済みのConversationゲームの選択画面を開きます。`/game`と`/play`も同じ動作です。 |
| `/selfie [name (optional)]` | インストール済みのIllustratorエージェントで自撮りを生成します。名前を付けるとキャラクターを指定できます。 |
| `/uno` | チャットにいるキャラクターとUNOのゲームを始めます。 |
| `/chess` | キャラクターと1対1のチェスを始めます。 |
| `/poker` | キャラクターとテキサスホールデムポーカーを始めます。 |
| `/8ball` | キャラクターと1対1のエイトボール(ビリヤード)を始めます。`/pool`でも同じ動作です。 |
| `/status [online\|idle\|dnd\|offline\|clear] [name (optional)]` | キャラクターの在席ステータスを設定または解除します。 |

`/uno`、`/chess`、`/poker`、`/8ball`の各コマンドは、そのゲームの設定画面を開きます。1つのチャットで同時に遊べるゲームは1つだけです。ルールと設定項目は[テーブルゲーム](../conversation/table-games.md)を参照してください。

`/status`コマンドは、キャラクターの在席状態を上書きします。指定できるステータスは`online`、`idle`、`dnd`(取り込み中)、`offline`です。上書きを解除するには`clear`を使います。次の例では、キャラクターをidleにします。

```
/status idle
```

キャラクターが2人以上いるチャットでは、`/status online Alice`のように末尾にキャラクターの名前を添えます。
