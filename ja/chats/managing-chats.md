# チャット一覧の管理

画面左の**Chats**(チャット)パネルには、すべてのチャットがまとまっています。このパネルで、チャットの作成、検索、並べ替え、整理、削除を行います。

## チャット一覧とモードタブ

パネルの上部には3つのモードタブがあります。各タブには、そのモードのチャットだけが表示されます。

| タブ | モード |
| --- | --- |
| **CONVO** | Conversation: メッセージアプリのようなチャットです。 |
| **RP** | Roleplay: キャラクターが登場し、世界の状態を追いながら進めるシーンです。 |
| **GM** | Game: AIが進行する1人用のRPGです。 |

各行には、チャット名と、登場するキャラクターのアバターが表示されます。Conversationのチャットでは、アバターに付いた色付きの点がそのキャラクターの状態を表します。赤いバッジは未読メッセージの件数です。小さな分岐アイコンと数字が付いた行は、複数の分岐を持つチャットを1行にまとめたものです。[チャットの分岐](branches.md)を参照してください。

## チャットの開始

始める前に: **Connections**(接続)にアカウントを1つ以上追加してください。[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。

1. 使いたいモードのタブをクリックします。
2. パネル上部の**+**ボタンをタップします。ラベルは、タブに合わせて**New Conversation**、**New Roleplay**、**New Game**のいずれかになります。

Marinaraがチャットを作成して開きます。その横に、**Chat Settings**(チャット設定)と設定ウィザードが開きます。チャットの名前は最初、**New Conversation**、**New Roleplay**、**New Game**のいずれかになります。ConversationまたはRoleplay用に、星を付けたデフォルトの設定プロファイルを保存してある場合は、Marinaraがそれを新しいチャットに適用します。[設定プロファイル](settings-profiles.md)を参照してください。

うまくいかなかった場合: アカウントが保存されていないと、チャットの代わりに**Add account**(アカウントの追加)ウィンドウが開きます。サービスを選び、**Connect**(接続)をクリックしてから、モデルを選びます。手順の詳細は[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。

## チャットのインポート

SillyTavernまたはMarinaraの`.jsonl`形式のチャットログをインポートできます。

1. チャットを入れたいモードのタブをクリックします。
2. パネル上部の**Import**(インポート)ボタンをタップします。ラベルは**Import SillyTavern or Marinara chat JSONL**です。
3. `.jsonl`ファイルを選びます。

Marinaraはチャットを作成して開き、**Imported N messages**と表示します。エクスポート形式とまとめてのエクスポートについては、[チャットのエクスポートとインポート](export-import.md)を参照してください。

うまくいかなかった場合: 画面下部に、理由とともに**Import failed**という小さなメッセージが表示されます。受け付けるのは`.jsonl`ファイルだけです。

## チャットの名前の変更

チャット名は自分のためだけのもので、モデルには送られません。

1. チャットを開き、**Chat Settings**を開きます。
2. **Chat Name**(チャット名)で、現在の名前をクリックします。
3. 新しい名前を入力し、<kbd>Enter</kbd>を押すか、チェックマークをクリックします。

パネルの開き方は[Chat Settings](chat-settings.md)を参照してください。

## チャットの削除

1. チャットの行にあるゴミ箱のボタンをタップします。コンピューターでは、行にマウスを重ねると表示されます。
2. **Delete Chat**(チャットの削除)ダイアログで、**Delete**(削除)をクリックします。

削除は取り消せません。そのチャットで書かれている途中の返信も停止します。

チャットに複数の分岐がある場合は、ダイアログに分岐の数が表示され、2つの選択肢が示されます。

- **Delete This Branch Only**は、クリックした分岐だけを削除します。
- **Delete All N branches**は、グループ内のすべての分岐を削除します。

チャットを削除せずに分岐を管理するには、[チャットの分岐](branches.md)を参照してください。

これらのダイアログは、アプリ全体の設定**Confirm before deleting**(削除前に確認する)で制御されます。デフォルトはオンです。**Settings → General**(設定 → 一般)にあります。

## チャットのフォルダー

フォルダーを使うと、1つのモードタブの中でチャットをまとめられます。

1. チャットが1つ以上あるタブを開きます。**New Folder**(新しいフォルダー)は、そのときだけタブの下に表示されます。
2. **New Folder**をクリックします。フォルダーの名前は**unnamed**になります(続けて作ると**unnamed 2**、**unnamed 3**になります)。

| 目的 | 操作 |
| --- | --- |
| フォルダーの名前を変更する | ダブルクリックかダブルタップするか、フォーカスして<kbd>F2</kbd>を押します。空の名前は無視されます。 |
| フォルダーを削除する | フォルダーの行にあるゴミ箱のボタンをクリックします。フォルダーにチャットがある場合は、**Delete Folder**(フォルダーの削除)ダイアログが表示されます。中のチャットは最上位に移り、削除されません。 |
| フォルダーを並べ替える | フォルダーを上下にドラッグします。並べ替えメニューが**Custom**(カスタム)に切り替わります。 |
| チャットをフォルダーに入れる | チャットの行をフォルダーの上にドラッグします。タッチ画面では、先にチャットを0.5秒ほど長押しします。 |
| チャットをフォルダーから出す | フォルダーの下の空いている場所にドラッグします。 |

複数のチャットを選択しているときは、1つをドラッグすると、選択したチャットがまとめて移動します。フォルダーに入っていないチャットは、フォルダーの下に並びます。

## 検索、並べ替え、絞り込み

### 名前でチャットを探す

各タブには検索欄があります。プレースホルダーは**Search conversations**、**Search roleplays**、**Search games**のいずれかです。言葉を入力すると、チャット名、タグ、キャラクターの名前と照合されます。メッセージの本文は対象外です。

### すべてのチャットからメッセージを探す

1. 並べ替えメニューの隣にある**Search all chats**(すべてのチャットを検索)ボタンをタップします。
2. 探したい言葉を入力します。

すべてのチャットを検索し、モード、キャラクター、送信者、日付で絞り込めます。

並べ替えメニュー(**Sort chats**)には次の選択肢があります。

| 選択肢 | 順番 |
| --- | --- |
| **Custom**(カスタム) | 自分で決めたフォルダーの順番です。 |
| **Manual order**(手動の順番) | ドラッグして決めたチャットの順番です。キーボードでは、チャットにフォーカスして<kbd>Alt</kbd>+<kbd>Up</kbd>または<kbd>Alt</kbd>+<kbd>Down</kbd>を押します。 |
| **Recent**(最近) | 最近やり取りしたものが先です。これがデフォルトです。 |
| **Newest** | 最近作成したものが先です。 |
| **Oldest** | 作成日が古いものが先です。 |
| **A-Z**と**Z-A** | 名前順です。 |

タブ内のいずれかのチャットにタグがあると、**Tags (N)**のチップが表示されます。クリックしてタグを展開し、タグをクリックすると、そのタグが付いたチャットだけが表示されます。絞り込みを解除するには**Clear**をクリックします。このパネルでは、チャットにタグを追加できません。

一覧には一度に100件のチャットが表示されます。続きを見るには**Load more**(さらに読み込む)をクリックします。

<a id="selecting-multiple-chats"></a>

## 複数のチャットの選択

1. パネル上部のチェックマークのボタン(**Select chats**)をクリックします。
2. 選びたいチャットをそれぞれクリックします。行はチャットを開く代わりに、チェックボックスを表示します。
3. 下部のバーを使います。バーには選択中のチャットの件数が表示されます。

**Export**(エクスポート)は、選択したチャットを、`.jsonl`ファイルを収めた1つの`.zip`ファイルとしてダウンロードします。**Delete**(削除)は、**Delete Chats**ダイアログで確認してから、選択したチャットを削除します。選択モードを終えるには、チェックマークのボタンをもう一度クリックします。タブを切り替えても選択は解除されます。

## ホーム画面のRecent chats

ホーム画面には、最近のチャットが並ぶ**Recent chats**(最近のチャット)ウィジェットがあります。各チャットには、名前、モードのバッジ、最後のメッセージが表示されます。チャットをクリックすると開きます。チャットが1つもないときは、**Your chats will show here**と表示されます。[ホームのウィジェット](../home/welcome.md#home-widgets)を参照してください。
