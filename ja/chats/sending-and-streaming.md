# メッセージの送信とストリーミング

メッセージを入力して送信すると、返信が表示されていきます。このガイドでは、送信、添付ファイル、ストリーミング、返信の停止、やり直し、エラーの読み方を説明します。

## メッセージを送る

始める前に: チャットにはモデルが必要です。[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。

1. チャット下部の入力バーに入力します。
2. **Send**(送信)をクリックします。そのチャットモードで**Send on Enter**(Enterで送信)がオンなら、<kbd>Enter</kbd>を押しても送信できます。

送ったメッセージが表示され、続いて返信がストリーミングで表示されます。1つのチャットで同時に生成できる返信は1つだけです。返信のストリーミング中は、**Send**が停止ボタンに変わります。

うまくいかなかった場合: チャットにモデルが設定されていないと、返信はすぐに失敗し、接続が設定されていないというメッセージが表示されます。[Chat Settings](chat-settings.md)でモデルを選んでください。

### Send on Enter

**Settings → General → Input & Editing**(設定 → 一般 → 入力と編集)にあります。チャットモードごとに1つずつトグルがあります。

| チャットモード | デフォルト | オフのとき |
| --- | --- | --- |
| Roleplay | オフ | <kbd>Enter</kbd>で改行が入ります。**Send**をクリックして送信します。 |
| Conversations | オン | <kbd>Ctrl</kbd>+<kbd>Enter</kbd>(Macでは<kbd>Cmd</kbd>+<kbd>Enter</kbd>)で送信します。 |
| Game | オン | <kbd>Ctrl</kbd>+<kbd>Enter</kbd>(Macでは<kbd>Cmd</kbd>+<kbd>Enter</kbd>)で送信します。 |

Roleplayのメッセージは長くなりやすく、改行が必要になるため、Roleplayはデフォルトでオフです。Professor Mariには専用のトグル**Enter sends to Professor Mari**(EnterでProfessor Mariに送信)があり、**Settings → General → Search and Professor Mari settings**にあります。

## 画像やファイルを添付する

1. 入力バーのクリップのアイコンをタップします。
2. ファイルを選びます。入力欄の上に小さなチップとして表示されます。
3. いつもどおり送信します。

Marinaraが受け付けるのは、画像、PDFファイル、プレーンテキストのファイル(`.txt`、`.md`、`.markdown`、`.json`、`.jsonl`、`.csv`、`.log`、`.xml`、`.yaml`、`.yml`)です。1ファイルあたり20 MB以下にしてください。これより大きいファイルや、対応していない形式のファイルは、注意とともに拒否されます。

モデルが画像を見られるのは、そのモデルが画像入力(vision)に対応している場合だけです。テキストしか扱えないモデルでは、**Chat Settings → Advanced Parameters**(チャット設定 → 詳細パラメーター)で**Image captioning**(画像の説明文生成)をオンにします。デフォルトはオフです。オンにすると、Marinaraは選んだモデルで各画像の内容を文章で説明し、画像の代わりにその説明を送ります。

## ギャラリー画像をメッセージ内に表示する

添付ファイルは、モデルに見せるためのものです。ギャラリーのリンクは、メッセージ本文の中で自分に画像を見せるためのものです。メッセージはMarkdownの画像構文に対応しており、Marinaraは`card://`リンクをギャラリーのファイルとして解決します。

```text
![a caption](card://characters/<character-id>/gallery/<filename>.png)
```

Roleplayでは、チャットのアセットブラウザーからリンクを挿入できます。メッセージ、挨拶メッセージ、会話例にリンクを貼り付けることもできます。

キャラクター自身のギャラリーには、持ち運べる形式の`card://self/gallery/<filename>`を使ってください。キャラクターをエクスポートしてインポートした後も使えます。ギャラリーの**Copy image reference**(画像の参照をコピー)ボタンで作れます。[キャラクターのギャラリー](../characters/galleries.md#reuse-a-gallery-image-in-messages-and-greetings)を参照してください。

## 返信のストリーミング

ストリーミングでは、返信を一度にではなく、少しずつ順に表示します。設定は**Settings → General → Responses**(設定 → 一般 → 応答)にあります。

| 設定 | デフォルト | 動作 |
| --- | --- | --- |
| **Enable streaming** | オン | 書かれていくそばから返信を表示します。オフにすると、モデルが書き終えたときに返信の全文が表示されます。 |
| **Streaming speed** | 50 | 1から100までのスライダーです。値が小さいほど、ゆっくりしたタイプライター風の表示になります。モデルが書く速さは変わりません。 |
| **Trim incomplete sentences from the response** | オフ | 返信を保存する前に、途中で切れた最後の文を取り除きます。完結した返信や、コマンド形式で終わる返信はそのまま残ります。 |

## 入力中と進捗の表示

最初の言葉が届くまでは、キャラクターの名前と、動く3つの点が表示されます。グループチャットでは、返信するすべてのキャラクターの名前が表示されます。サーバーがプロンプトを準備しているあいだは、進捗の行に次のラベルが順番に表示されます。チャットがその機能を使っているときだけ動く処理もあるため、すべてが表示されるとはかぎりません。

- **Preparing context...**
- **Building prompt...**
- **Scanning lorebooks...**
- **Recalling memories...**
- **Running agents...**
- **Retrieving knowledge...**
- **Generating...**

キャラクターのステータスが取り込み中や離席中の場合は、点の代わりに待機中の表示が出ます。キャラクターが応答できる状態になると、返信が始まります。

## モデルのthinkingを見る

モデルによっては、「thinking」と呼ばれる隠れた推論の記録を返します。返信にthinkingがある場合は、メッセージに脳のアイコンの**View model thoughts**(モデルの思考を表示)が表示されます。クリックすると推論を読めます。

これには、モデルが推論を返す必要があります。推論をプレーンテキストのタグで囲んで返すモデルもあります。その場合は、生成の設定で**Thinking Tags**(思考タグ)を設定すると、Marinaraが推論と返信を切り分けられます。[生成パラメーター](../prompts/generation-parameters.md)を参照してください。

## 返信を止める

停止ボタンをクリックします。返信のストリーミング中は、**Send**ボタンが停止ボタンになっています。すでに表示された文章は、通常はそのまま残ります。自分で止めた場合は、エラーは表示されません。

## 打ち直さずにやり直す

最後のメッセージが自分のもので、AIが返信しなかった場合は、入力欄を空のままにして**Send**をクリックします(または<kbd>Enter</kbd>を押します)。Marinaraは、同じメッセージを重ねて追加せずに新しい返信を始めます。Conversationでは、この状態のときボタンに円を描く矢印が表示されます。入力欄に下書きがある場合は、**Send**はその下書きを送信します。

Roleplayでは、AIがすでに答えたあとでも、空の**Send**でまったく新しい返信を始められます。前の返信に書き足すことはありません。前の返信を続けるには、`/continue`を使います。[メッセージの操作](messages.md)を参照してください。

## 生成エラーが出たとき

返信が失敗すると、画面下部にトースト(短いポップアップのメッセージ)が15秒ほど表示されます。その文章はコピーできます。Marinaraは一部のエラーを、次にすべきことに書き換えて表示します。

| 原因 | トーストが伝える内容 |
| --- | --- |
| モデルが、対応していないパラメーターを拒否した | **Chat Settings → Advanced Parameters**(チャット設定 → 詳細パラメーター)を開き、そのパラメーターの**Send**をオフにします。 |
| モデルが必要とするパラメーターがオフになっている | 同じ場所で**Send**をオンに戻します。 |
| 返信が空で返ってきた | メッセージをもう一度送ります。 |
| すでに返信を生成中 | 待つか、停止ボタンで止めます。 |
| 接続が設定されていない | チャットに接続を設定します。 |

エラーが繰り返し起きる場合は、[トラブルシューティング](../TROUBLESHOOTING.md)を参照してください。

## 回線が遅いときとモバイルのタブ

長い返信には時間がかかることがあります。返信はいつでも止められます。スマートフォンでは、チャットのタブから離れると、ブラウザーがそのタブを一時停止することがあります。返信のストリーミング中だった場合、Marinaraは**Finishing in background...**と表示し、返信がサーバー側で完了したかどうかを確認します。返信が表示されない場合は、少し待ってからチャットを再読み込みしてください。
