# Game Mode: ルールセットでの戦闘

5e (SRD 5.1)など一部のルールセットは、Marinaraの戦闘にいくつかの数値を提供する代わりに、独自のルールで戦闘全体を行います。このガイドでは、そのような戦闘の見た目と、自分のターンの進め方を説明します。Marinara独自のルールを使うゲームについては、[Game Mode: 戦闘](combat.md)を参照してください。ルールセットを選ぶには、[ルールセットで遊ぶ](rulesets.md)を参照してください。

このような戦闘を自分で始めることはありません。ほかのゲームと同じように、物語の流れに応じてゲームマスター(GM)が開始します。Marinaraは、パーティーのシートとルールセットのクリーチャー、またはルールセットの用語でGMが説明した相手から戦闘を組み立てます。

## 戦闘画面

画面はルールセット独自のものです。

- **メニュー**には、キャラクターの攻撃と能力が並びます。それぞれ、ルールセットの行動枠(各ターンにできること)とプール(呪文スロットなどの蓄え)から何を消費するかが表示されます。
- **下のパネル**には、行動順、ラウンド、ルールセットの名称による全員の状態、各予算の残りが表示されます。
- **ログ**には、実際の計算が出力されます。たとえば「Juno attacks Rust jackal with Road axe: 8 (5 + 3) + 3 = 11 against Guard 6, a hit.」です。

各アクションは、適用された時点でキャラクターシートに書き込まれます。戦闘中にタブを閉じても何も失われず、GMにはその後、数値がすでに確定していることが伝えられます。

## 自分のターンを進める

1. ログとパネルで、ラウンド、行動順、自分の予算を確認します。
2. メニューから攻撃か能力を選びます。
3. 対象が必要な場合は、リストから選びます。戦場では、盤面でクリックすることもできます。
4. ログの行を読んで、何が起きたかを確認します。
5. やることがなくなったとき、または見送りたいときは、**Pass**(見送る)を選びます。

行動できない場合、アクションが意図的にメニューから外されていることがあります。次の点を確認してください。

- 残っている量より多くを消費するアクションです。パネルで予算(各プールと行動の残り)を確認してください。
- リソースの1ターンあたりの上限を超えるアクションです。次のターンにまた表示されます。
- 拘束を振りほどくアクションで、何かに拘束されている間だけ表示されます。
- 対象が必要なのに、誰も届く範囲にいません。メニューには**Nobody is in reach. Move closer.**と表示されます。[戦場での戦闘](#on-a-battlefield)を参照してください。

ルールセットに該当するものがある場合、メニューは選択肢を次の見出しにまとめます。

| グループ | 内容 |
| --- | --- |
| **Attacks**、**Abilities**、**Items** | 攻撃、能力、アイテム。 |
| **Standard actions** | ルールセットの一般的なアクション。 |
| **Stat block actions** | クリーチャーのステータスブロックに載っているアクション。 |
| **Contests** | 掴む、押す、振りほどく([対抗判定](#contests)を参照)。 |
| **Movement** | 戦場での移動([戦場での戦闘](#on-a-battlefield)を参照)。 |
| **Spend symbols** | シンボルダイスのルールセットで、残ったシンボルで得られるもの。 |
| **Reload**、**Switches** | 再装填と、ルールセットが定める切り替え。 |
| **End of turn** | ターンの終了。 |

## 1ターンにできること

1ターンにできることは、ルールセットが決めます。

- 一撃が複数の種類のダメージを持つことがあります。各部分は別々にロールされ、抵抗とセーヴが適用されますが、全体としては一撃のままです。
- 1回のアクション消費で、複数回の攻撃を得られることがあります。残りがある間は、メニューに消費なしで表示され、手元に残っている回数も示されます。そのため、もう一度振るうことも、別のものを使うことも、攻撃の合間に歩くこともできます。
- 能力は、何も消費しないこともあれば、このターンだけ2回目のアクションを与えることも、ターンの一部を使うだけでダッシュ、離脱、隠れるといった行動ができるようにすることもあります。
- ターン最初の有効な一撃に追加ダメージを与えるなど、キャラクターが常に行うことは自動的に加わり、ログにもそう記録されます。

## 状態

状態とは、戦闘中の者にかかる持続的な効果です。ルールセットによって、状態はセーヴィングスロー(効果に抵抗するためのロール)を難しくしたり易しくしたり、あらゆる種類のダメージを半減させたり、状態を与えた相手を狙えなくしたり、その相手に近づけなくしたり、相手が倒れたときに終わったりします。数値を変えることもあります。防御に加算する、攻撃、セーヴィングスロー、対抗判定にダイスを足したり引いたりする、移動を遅くする、などです。ログには、変更されたロールの横にそれぞれが表示され、メニューの確率にも反映されます。次の自分のターンの開始時まで続く状態や、対象となる次の攻撃やセーヴまでしか続かない状態もあります。ルールセットは、消耗などをシート上のトラックで数えることもあり、その場合は段階ごとに、それが続く間は少しずつ状況が悪くなります。

## ダイスプールを振るルールセット

ダイスを数個振って目標に届いたものを数える判定方式のルールセットも、同じように戦います。

- **攻撃。** 攻撃では自分のプールを振り、命中には一定数の成功が必要です(1未満になることはありません)。必要数を超えた成功は、1つごとにダメージにダイスを1個加えます。ダメージもダイスで振られます。
- **吸収。** 攻撃を受けた側は、ダメージの種類に応じてその一部を吸収できます。吸収は防御の一種で、1個ごとに1点減らすダイスを振るか、ダメージを振る前にダイスを減らします。残った分が負傷として記録されます。
- **ペナルティと状態。** 負傷ペナルティは、判定と同じようにプールからダイスを減らし、状態はダイスを増やしたり減らしたりします。セーヴィングスローと対抗判定もプールで行います。
- **ログ**には、投入したダイスの数、到達すべき目標、得た成功数、吸収で減った量が表示されます。
- **イニシアチブと上限。** こうしたルールセットでは、毎ラウンドにイニシアチブを振り直したり、1ターンに消費できるリソースの量を制限したりすることがあります。

プール方式のルールセットには、イニシアチブを戦闘全体を通じた1つの数値として保持し、攻撃でそれを動かすものもあります。各攻撃のやり方は自分で選びます。相手を傷つける代わりに相手の数値の一部を自分のものにするか、自分の数値をダメージダイスとして費やします。費やす攻撃が命中すると、自分の数値はリセットされます。外れると、ルールセットが定める分だけ数値を失います。ルールセットのクラッシュライン(その数値に対するルールセット独自の下限)まで落ちた者はクラッシュし、回復するまで費やせません。順番は毎ラウンドの数値に従い、全員の数値が体力の横に表示されます。

Genesys形式のシステムなど、ナラティブシンボルダイスを振るルールセットは、戦闘でもそのダイスを使います。攻撃では標的の難易度ダイスに対して自分のダイスを振り、判定と同じようにシンボルが相殺され、残ったものによって命中するかが決まります。残ったシンボルで何を得られるかはルールセットが定めるため、GMに判断を求めることはありません。

## 対抗判定

ルールセットによっては、戦闘中の誰でも対抗判定を始められます。対抗判定とは、相手に対して行うロールです。相手を掴む、押し倒す、押し出す、拘束を振りほどく、といったことができます。双方がロールして自分の数値を加え、合計が高いほうが勝ちます。選ぶ前に、メニューに勝つ確率が表示されます。

- 掴むことに成功すると、相手が振りほどくか自分が倒れるまで、相手をその場に拘束します。失敗しても何も起こりません。
- 振りほどく行動は、何かに拘束されている間だけ、拘束している相手に対してだけメニューに表示されます。
- 押し出しで相手が動くのは戦場の上だけで、壁や途中にいる者で止まります。

## ほかの者の行動に応じる

自分のターンに使うのではなく、ほかの者の行動に応じて使う能力もあります。次のときに戦闘は一時停止し、メニューに**Pass**(見送る)と並んで応答が表示されます。

- 相手が何かを使おうとしているとき
- 何かが自分に向けられたとき
- 攻撃が自分に命中した直後
- 何かで自分が傷ついた直後

ただし、その瞬間に使える応答を持っている場合に限ります。命中のあとには、攻撃のロール値と、何に対して行われたかがログに表示されるので、Shieldのような応答で外れに変えられるかどうかがわかります。応答を使うと、同じロールがもう一度判定され、まだ命中するかどうかがログに表示されます。

相手も、相手自身の受け流しで応答できます。カウンターは、相手がカウンターの届く範囲にいる間は、誰に向けられたものであっても、相手の能力を発動前に止められます。ルールセットによっては、呪文など一部の種類の能力にしか応答できないと定めている場合もあります。止められた能力のコストは消費されたままで、カウンターに応答することはできません。

## 戦場での戦闘

ルールセットは、戦場の1マスが独自の距離でどれだけに相当するかを、フィート、歩、または独自の単位で指定できます。指定があり、ゲームの**Combat Preference**(戦闘の種類)が**Tactical**(グリッド式戦闘)の場合、戦闘は戦場で行われます。Marinara独自の[Tactical戦闘](combat.md#tactical-battles-and-terrain)と同じ盤面(自動生成されたもの、またはその場所のために手作りされたもの)、地形、配置を使います。距離を指定しないルールセットや、**Classic**(メニュー式戦闘)に設定したゲームでは位置を使わずに戦い、誰でも誰を対象にもできます。

戦場では、すべてルールセット自身の数値で決まります。

- 1ターンに歩ける距離は、ルールセットの移動ルールかクリーチャーの速度から決まります。
- 武器の間合いや射程は、その武器自身の行から決まります。
- 能力の範囲は実際の爆発、円錐、直線になり、壁は射撃を遮ります。
- 物陰に立つと、ルールセットが遮蔽に定める分が加わります。
- 相手の間合いから歩いて出ると、ルールセットがその攻撃にコストがあると定めている場合、相手から攻撃を受けます。
- 移動は卓上ゲームのグリッドと同じく8方向で、いずれも1マスずつ進みます。Marinara独自のTactical戦闘の4方向モデルとは異なります。

盤面の使い方は次のとおりです。

1. 各マスはそれぞれボタンです。ポインターか矢印キーを使います。各マスは、その種類、そこに立っている者、そこへ歩くコストを示します。
2. **Move**(移動)を選びます。到達できるマスが、ルールセットの単位によるコスト付きで光ります。マスにカーソルを合わせるかフォーカスすると、経路が描かれます。誰かに攻撃される経路のマスは琥珀色で示され、その者の名前が盤面の下に表示されます。
3. 対象が必要なものを選びます。選択できる対象が光り、盤面でもリストでもクリックできます。
4. 範囲能力は、マスに照準を合わせます。狙えるマスが光り、ポインターの下のマスには、味方を含めて誰が巻き込まれるかが表示されます。
5. <kbd>Esc</kbd>を押すと、選びかけの行動を取り消し、キーボード操作をメニューに戻します。

移動は、アクションの前後に分けて使えます。メニューは残りを反映して戻り、パネルにはルールセットの単位で**Movement**(移動量)として表示されます。

ルールセットは戦場をさらに活用できます。四分の三遮蔽までの段階的な遮蔽、攻撃や落下に影響する高所、飛ぶ、泳ぐ、登る、穴を掘るクリーチャー、メニューの**Hide**(隠れる)と**Search**(探す)、そして誰かが相手から離脱するときに、攻撃するかどうかを相手に尋ねる一時停止です。戦闘でどれを使うかはルールセットによって決まります。ルールセットによっては、クリーチャーがより小さな空間をすり抜けたり、乗騎に乗ったり、掴んでいる相手を引きずったりすることもできます。障害物の上を飛ぶ移動はまだ実装されていません。飛ぶクリーチャーも、ほかと同じように移動します。
