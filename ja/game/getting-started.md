# Game Mode: はじめに

Game Modeを使うと、Marinara EngineはAIのゲームマスターが進行する1人用のロールプレイングゲームになります。このガイドでは、ゲームを始め、最初のターンを遊び、操作の場所を見つけるまでを説明します。

Game Modeは、3つのチャットモード(Conversation、Roleplay、Game Mode)の1つです。ゲームマスター(GM)とは、世界の様子を語り、出会うキャラクター全員を演じ、次に何が起こるかを決めるAIです。テーブルトークRPGのダンジョンマスターと同じ役割です。Marinaraは、マップ、パーティー、プレイヤー以外のキャラクター(NPC)、アイテム、クエスト、ゲーム内の時刻、天候を記録し続けます。長いゲームは複数の**セッション**に分けられます。1つのキャンペーンを何晩かのゲーム会に分けて遊ぶのと同じです。

すべての仕組みを使う必要はありません。戦闘とダイスを使わずに、物語を楽しむために遊ぶこともできます。

## 始める前に

必要なものは1つだけです。ゲームマスター用のAIのアカウントです。まだ追加していない場合は[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。

これ以外はすべて任意で、デフォルトではオフです。後から追加できます。

- **画像。** **Illustrator**エージェントが、NPCの肖像、場所の背景、シーンの画像を描きます。**Agents → Agent Organizer**(エージェント → エージェント管理)からダウンロードしてください。画像用のアカウントが必要です。なくても物語、状態の追跡、戦闘は使えますが、画像の領域は空のままになります。
- **内蔵モデルによるシーン演出。** Marinaraは自分のコンピューターで小さなモデルを動かし、費用をかけずに背景と音楽を選べます。ダウンロードすると、このモデルがデフォルトの**Scene effects model**(シーン効果のモデル)になります。それまでのデフォルトは**Skip - use inline tags from GM**(スキップしてGMのインラインタグを使う)です。[内蔵モデルのセットアップ](../connections/local-model.md)を参照してください。
- **絵コンテ。** Storyboardエージェントをダウンロードし、そのゲームでオンにします。[Storyboardエージェントガイド](storyboard.md)を参照してください。
- **動画。** 動画用のアカウントは、シーンの動画や動く絵コンテを使う場合にだけ必要です。
- **音楽。** **Music DJ**エージェントが、Spotifyかローカルの音楽フォルダーから音楽を再生します。

## ゲームを始める

1. チャットのサイドバーで**GM**タブを開き、**+**ボタン(**New Game**)をクリックします。または、ホーム画面で**Game**をクリックします。設定ウィザードが開きます。[チャットの管理](../chats/managing-chats.md)を参照してください。
2. 最初のステップで、GMを動かす**Model**(モデル)を選びます。前に追加したアカウントを選んでください。一覧が空なら、先にアカウントを追加します。世界の生成には、性能の高い有料のモデルを選んでください([モデルの選び方](#choosing-a-model)を参照)。
3. 各ステップで**Next**(次へ)をクリックします。ほかの項目にはすべてデフォルトがあるので、そのまま進めてかまいません。
4. 最後のステップで**Create world**(世界を作成)をクリックします。Marinaraが世界を組み立てている間、ボタンには**Generating World…**と表示されます。これはモデルへの1回の大きなリクエストなので、終わるまで待ってください。
5. 世界ができあがると、ゲーム画面に**Start Game**(ゲーム開始)が表示されます。クリックすると、GMが最初のメッセージを書きます。

カスタムHUDウィジェットがオン(デフォルト)の場合、**Start Game**の下に**Review Starting Widgets**(開始時ウィジェットの確認)ボタンがあります。飛ばしてもかまいませんし、これを使って先に開始時のウィジェットを変更することもできます。[Game Mode: HUDウィジェット](hud-widgets.md)を参照してください。

> **Tip:** Game Modeが初めてなら、**Game Master Mode**(ゲームマスターのモード)は**Standalone GM**のままにしてください。Marinaraが皮肉の効いたナレーターを用意します。

うまくいかなかった場合は、[世界の生成がJSONエラーや422エラーで失敗する](#world-generation-fails-with-a-json-or-422-error)を参照してください。

### 設定ウィザード

| ステップ | 設定する内容 |
| --- | --- |
| **Connection** | **Game Name**(ゲーム名)、GMを動かす**Model**(モデル)、任意の**Scene effects model**(シーン効果のモデル)です。**Game Mode**(ゲームモード)のカードには、今のところ**VN**だけが表示されます([VNとOverworld](#vn-or-overworld)を参照)。 |
| **World** | ジャンル、舞台、雰囲気、難易度、コンテンツ区分、言語です。**Combat Preference**(戦闘の種類)は**Turn-Based**(ターン制のメニュー式戦闘)か**Tactical**(グリッド式戦闘)です。新しいゲームはすべて**MRPG**(Marinara RPG)クラスで遊びます([MRPGクラス](mrpg-classes.md)を参照)。ルールセットがインストールされていると、**Rules**(ルール)の選択肢が表示されます([ルールを選ぶ](#choose-rules)を参照)。 |
| **Party** | 自分のペルソナ(自分が演じるキャラクター)、**Game Master Mode**(ゲームマスターのモード)、パーティーメンバー、**GM intro message**(GMの導入メッセージ)です([GMの導入メッセージ](#the-gm-intro-message)を参照)。 |
| **Goals** | 冒険に何を求めるかです。 |
| **Lorebooks** | GMが事実として扱うロアブックです。ロアブックとは、世界の背景設定をまとめたものです。[ロアブック](../lorebooks/overview.md)を参照してください。 |
| **Features** | **Enable Agents**(エージェントを有効にする)と、その下に表示されるダウンロード済みの各エージェントのカード(**Illustrator**、**Music DJ**、**Lorebook Keeper**)、さらに**Custom HUD Widgets**(カスタムHUDウィジェット)、**Quick Time Events**(クイックタイムイベント)、**Start Muted**(ミュートで開始)です。 |
| **GM** | 演出のスタイルと**GM Prompt**(GMプロンプト)です。 |

舞台と目標の下に表示されるアイデアは、ウィザードを開くたびに変わります。Tacticalのゲームでは、GMが戦闘ごとに短い概要を書き、Marinaraがそれをもとに盤面を作ります。[戦闘](combat.md#tactical-battles-and-terrain)を参照してください。

**World**のステップには、ボスに関する戦闘の選択肢もあります。**GM directs bosses**(GMがボスを操作)はデフォルトでオンです。GMの接続を使ってGMがボスのターンを決めるため、少し時間がかかることがあります。通常の敵は自分で行動を決めます。ただし、**GM directs bosses**がオンで、ゲームのルールセットが敵側をGame Masterに任せている場合は別です([Game Master向けの文章](../extending/ruleset-sheets.md#game-master-text)を参照)。**GM directs bosses**がオンの間は、**Game Master also plays named and brilliant opponents**(名前のある敵と非常に賢い敵もGame Masterが演じる、デフォルトでオン)によって、名前のあるキャラクターや非常に賢い敵もGMが演じます。さらに2つの選択肢が常に表示されます。**Companions fight on their own**(仲間が自分で戦う、デフォルトでオン。オフにするとパーティー全体を自分で操作します)と、**Let cruel opponents strike the fallen**(残酷な相手が倒れた者を攻撃できるようにする、デフォルトでオフ)です。[戦闘](combat.md)を参照してください。

**Hierarchical Maps**エージェント(現在の名前はWorld Maps。[World Maps](../agents/hierarchical-maps.md)を参照)をダウンロードし、**Enable Agents**をオンにしていると、**Features**のステップで**Hierarchical world map**の下書きを作ったり、保存したマップのテンプレートを使ったり、共有された世界をリンクしたりもできます。

| Game Presentation | Standard | 下記を参照してください。 |

<a id="choose-rules"></a>

### ルールを選ぶ

**Rules**(ルール)は、新しいゲームで、ルールセットが1つ以上インストールされている場合にだけ表示されます。デフォルトは**Marinara's own rules**(Marinara独自のルール)で、内蔵のd20判定と6つの能力値のシートを使います。**5e (SRD 5.1)**などのルールセットは、それらを卓上ゲームのシステム独自の判定とキャラクターシートに置き換え、戦闘も独自のルールで行う場合があります。ウィザードには、各ルールセットの対応範囲が表示されます。この選択は、ゲームを作成すると固定されます。[ルールセットで遊ぶ](rulesets.md)を参照してください。

<a id="the-gm-intro-message"></a>

### GMの導入メッセージ

**Party**のステップにある**GM intro message**(GMの導入メッセージ)で、ゲームの始まり方を決めます。

- **None**(なし、デフォルト): GMが適切と考える方法でゲームを始めます。
- **Defined**(指定): 最初のメッセージを、表示したい文章のとおりに入力します。ゲームはこの文章で始まり、再生成しても同じ文章になります。
- **Guided**(ガイド付き): どこから始まるか、誰がいるかなど、始まり方を説明します。GMはそれをもとに導入部分を書きます。

文章は8,000文字までです。二重の波かっこは含められず、**Guided**の文章には角かっこも含められません。文章が使えない場合は、欄にその旨が表示されます。世界のストーリーが独自の導入を設定していることもあります。その場合、欄にはその導入がロックされた状態で表示され、変更できません。

### Storyboard Optimized

**GM**のステップでは、**Game Presentation**(Gameの表示)を**Standard**か**Storyboard Optimized**にできます。**Storyboard Optimized**はStoryboard Game Promptを使い、GMのターンを映像化しやすい見せ場として組み立てます。Storyboardエージェントのダウンロードやオン、画像生成や動画生成のオン、アカウントの変更は行いません。それらは、ゲームの作成後に**Chat Settings → Agents → Storyboards**(チャット設定 → エージェント → 絵コンテ)で設定してください。

**GM Prompt**(GMプロンプト)エディターでは、選択中の表示で使われるプロンプトをプレビューできます。文章を変更しなければ、内蔵プリセットが選択されたままです。編集すると、その文章がプリセットより優先されます。

別の選択肢として、アニメ調の1ショット構成も設定の完了後に使えます。Animation Plannerに**Anime Episode Director**を、Storyboard Video Promptに**Anime Game Video**を選んでください。

## 最初のターンを遊ぶ

自分のキャラクターの行動やせりふを入力して送信します。GMが返信して世界を更新し、ダイスロールを求めたり戦闘を始めたりすることもあります。

ファイル添付ボタンの隣にある吹き出しのボタン(ツールチップは**Choose who to address**)で、メッセージの宛先を決めます。

| モード | 働き |
| --- | --- |
| デフォルト | メッセージは、行動やせりふとしてシーンに送られます。GMとパーティーが物語の中で応じます。 |
| **Talk to Party**(パーティーに話す) | `[To the party]`という目印を付け、仲間に話しかけます。パーティーが空でないときだけ表示されます。 |
| **Talk to GM**(GMに話す) | `[To the GM]`という目印を付け、キャラクターの外側からGMに尋ねます。たとえば「自分のキャラクターはその神殿のことを知っていますか?」のような質問です。 |

選択中のモードには、メニューに**On**と表示されます。オフにするには、同じ項目をもう一度クリックします。

<a id="the-games-controls"></a>

## Gameの操作

コンピューターでは、操作はチャットの右上付近にあるボタンから開きます。スマートフォンでは、移動できる3点アイコンの**Chat tools**(チャットツール)メニューの中にあります。

| 操作 | 内容 |
| --- | --- |
| **Game controls**(ゲームの操作、ゲームコントローラー) | **Retry turn**、**Retry scene analysis**、**Retry Music DJ**(Music DJが音楽を流している場合)、**Retry assets image generation**があります。絵コンテが背景のときは、最初から再生、再生と一時停止、ミュートもあります。**Show the scene**(シーンを表示)、**Show the overworld**(オーバーワールドを表示)、**Show the map**(マップを表示)は、それらがあるゲームで表示を切り替えます。**Edit game data**(ゲームデータを編集)では、保存データを手で修正できます([ゲームデータを手で編集する](sessions-and-saves.md#editing-game-data-by-hand)を参照)。**Checkpoints**(チェックポイント)では、以前の時点に戻れます([ゲームの保存の仕組み](sessions-and-saves.md#how-your-game-saves)を参照)。 |
| **Session**(セッション、羽根) | セッション履歴、記録、セッションの操作です。[Game Mode: セッションとセーブデータ](sessions-and-saves.md)を参照してください。 |
| **Volume**(音量、スピーカー) | **Master**、**Music**、**Sound Effects**、**TTS**、**Ambient**の音量です。 |
| **Game Assets**(ゲームアセット、フォルダー) | シーンのメディアとAsset Browserです。[ゲームアセット](game-assets.md)を参照してください。 |
| **Connected chat**(接続したチャット) | ゲームがConversationにリンクされているときに表示されます。[接続したチャット](../chats/connected-chats.md#switching-between-connected-chats)を参照してください。 |

ツールを選ぶと、コンピューターでは移動できるウィンドウ、スマートフォンでは画面幅いっぱいのパネルで開きます。コンピューターでは、ツールのボタンをドラッグして移動できます。スマートフォンでは、3点アイコンのメニューを動かすか、ロックを解除して中のツールを並べ替えます。[操作ウィンドウとボタン](../chats/chat-settings.md#control-windows-and-their-buttons)を参照してください。

操作を**Chat Settings**(チャット設定)の中に置くこともできます。操作のウィンドウを開き、**Put back in Chat Settings**(Chat Settingsに戻す)を選びます。すると、展開できるセクションとしてそこに表示され、その切り離しボタンで再びウィンドウにできます。選択はゲームごとに保存されます。**Reset View**(表示をリセット)で最初の配置に戻ります。

**Character Profiles**(キャラクタープロフィール)は、コンピューターでもスマートフォンでもChat toolsの外にあります。肖像のボタンを好きな場所にドラッグし、開いてパーティーメンバーを選ぶと、そのシートを表示したり編集したりできます。スマートフォンでは、**Map**(マップ)にも専用の移動できるボタンがあります。どちらもチャットウィジェットのスタイルに従い、このゲームでの位置を保存し、開いたウィンドウからロックできます。

<a id="choosing-a-model"></a>

## モデルの選び方

Game Modeでもっとも難しいのは世界の生成です。項目の欠けがない、長く厳密なJSON文書(正確でないとゲームが読み取れないテキスト形式)を1つ、モデルに要求します。ふだんのチャットを上手にこなすモデルでも、このステップで失敗することがあります。

- 世界の生成には、有料のアカウントで使える、性能の高い最新の上位モデルを使ってください。2026年時点では、Anthropic Claude、OpenAI GPT、Google Geminiなど、主要プロバイダーの最上位クラスで良い結果が出たという報告がプレイヤーから寄せられています。モデル名はよく変わるので、固定の一覧ではなく例として受け取ってください。
- おすすめするモデルのうち最も安いのはDeepSeek V4 FlashとClaude Haiku 5.5で、どちらも2026年10月31日時点で実際のプレイでテスト済みです。
- その後のターンには、安いモデルを使える場合もあります。ターンで求められるのは厳密なJSONではなく語りだからです。GMがNPCを忘れたり、前の描写と矛盾したりしたら、強いモデルに戻してください。
- 世界の生成では、無料モデルと自動振り分けのモデルは避けてください。有効なJSONを作れない小さなモデルに振り分けられることがあります。小規模なオープンウェイトのモデルも、たいてい失敗します。

パラメーターの詳しい説明は[生成パラメーター](../prompts/generation-parameters.md)を参照してください。

## ターンにかかる費用

Game Modeは3種類のAIリクエストを行います。

1. **世界の生成。** **Start Game**(ゲーム開始)をクリックしたときに1回だけ行います。世界の概要、開始時のマップ、NPC、パーティーのシート、ウィジェットを返す、1回の大きなリクエストです。
2. **ゲームのターン。** メッセージを送るたびに、現在の状態を含む新しいプロンプトを組み立てます。GMが語り、世界を更新します。戦闘のラウンドの計算はモデルではなくエンジンが行うので、結果は公平です。
3. **セッションの要約。** セッションを終了すると、GMが振り返りと継続用のメモを書きます。次のセッションを始めるときは、短いつなぎのメッセージを書きます。古いセッションは要約に圧縮されるので、長いキャンペーンでもモデルに収まります。

<a id="optional-tool-planning-and-lore-searches"></a>

## 任意のツール計画とロア検索

プレイ中に**Chat Settings → Function Calling**(チャット設定 → 関数呼び出し)を開きます。

- **Let the GM search lore**(GMによるロア検索を許可)を使うと、GMが意味に基づいてロアブックの情報を検索できます。先に対象のロアブックでベクトル化をオンにし、エントリーをベクトル化してください。検索は、有効なブックやフォルダー、チャットごとのエントリーの切り替えに従います。検索には埋め込み用のアカウントを使い、モデルへのリクエストが増えることがあります。Gameチャットでロアブックを検索するには、**Enable Tool Use**(ツールの使用を有効にする)がオンでも、このスイッチが必要です。オフの間は、ツールの選択画面で`search_lorebook`を選べません。
- **Game tool provider**(ゲーム用ツールのプロバイダー)のデフォルトは**Same as narrator**(ナレーターと同じ)で、通常のツールループ(1ターンに最大4回のツールのやり取り)を維持します。別のアカウントを選ぶと、語りの前に独立した計画リクエストを1回行います。そのモデルがツールを選び、ナレーターはその結果をテキストで受け取ります。そのアカウントで、1ターンにつきリクエストが1回増えます。安いモデルなら費用を抑えられますが、選ぶツールが変わることがあります。1回の計画では、その結果を受けて2回目の検索を続けることはできません。
- **Finish rolled turns in one request**(ダイスを使うターンを1リクエストで完了)はデフォルトでオンで、ダイスを振るターンのリクエストを1回減らします。[Game Mode: ダイスとスキル判定](dice-and-skill-checks.md#finishing-a-rolled-turn-in-one-request)を参照してください。

ClaudeとGrokのサブスクリプションのアカウントは、ネイティブのツール呼び出しに対応していません。該当する操作にはその説明が表示され、対応する**Game tool provider**を選ぶまでは無効のままです。テキストコマンドとダイスタグは引き続き使えます。別のアカウントが見つからない場合やそのリクエストが失敗した場合は、ツールの処理を省いて語りを進めるのではなく、そのターンに失敗が表示されます。

ローカルモデルが限られたGPUメモリーを共有している場合は、**Chat Settings → Agents**(チャット設定 → エージェント)を開き、**Run Game tasks one at a time**(Gameタスクを1つずつ実行)をオンにします。すると、そのGameチャットの中で、語り、エージェント、シーンのメディアが互いの完了を待ちます。デフォルトではオフで、ほかのチャットやアプリケーションに対してGPUを確保するものではありません。

## エージェントをオンにする

エージェントは、GMと並行して動く任意のAIの助け手です。追加のリクエストを行うため、費用が増えます。使うには、プレイ中に**Chat Settings → Agents**(チャット設定 → エージェント)を開き、**Enable Agents**(エージェントを有効にする)をオンにします。Game Modeで役立つのは次の2つです。

- **Game Session Keeper**は、セッションをまたいだ話のつながりを保つ手助けをします。
- **Music DJ**は背景の音楽を選びます。

**Review Agent Outputs**(エージェント出力の確認)では、エージェントが何を出力したかを確認できます。[エージェント: チャットを支えるAIヘルパー](../agents/agents-overview.md)を参照してください。

## トラブルシューティング

<a id="world-generation-fails-with-a-json-or-422-error"></a>

### 世界の生成がJSONエラーや422エラーで失敗する

いちばん考えられる原因は、モデルがJSONを最後まで作れなかったことです。次の順に試してください。

1. GMがどのモデルを使っているか確認します。無料モデルや自動振り分けのモデルなら、性能の高い有料のモデルに切り替えます。
2. もう一度試します。一度だけの失敗もあります。
3. 長い舞台設定や希望の欄を短くします。入力が長いと、JSONに使える余地が減ります。

呼び出しがほぼ成功していた場合、Marinaraは**Repair JSON**(JSONの修復)ウィンドウを表示します。モデルの生の出力が、行番号付きのエディターに入っています。状態を示す行に、JSONが正しいかどうか、または解析エラーが表示されます。**Format**(整形)をクリックすると正しいJSONが整い、続いて**Apply Repaired JSON**(修復したJSONを適用)をクリックすると、費用をかけてやり直すことなく、修正した内容を使えます。**Repair JSON**は、セッションの要約など、ほかの構造化された呼び出しでも表示されます。ほかの対処法は[Marinara Engineのトラブルシューティング](../TROUBLESHOOTING.md)を参照してください。

### 暗いトーンを選んだのにGMが明るく語る

明るい調子のままのモデルもあります。ウィザードの希望欄に、「語りは重い調子を保ち、失敗を和らげないこと」のようなはっきりした指示を書き足してください。または、もともとの語り口がそのトーンに合うモデルに切り替えます。

## Overworld

以下のセクションでは、まだ使えない**Overworld**ゲームについて説明します。サーバーでオンになっている場合にだけ読んでください。

<a id="vn-or-overworld"></a>

### VNとOverworld

新しいゲームは、2つのゲームモードのどちらかで遊びます。モードは最初のステップで選び、そのゲームのすべてのセッションで変わりません。

- **Overworld**は、舞台に合わせて作られた世界を、オーバーワールドのマップの上で歩いて旅するモードです。町、探索する場所、ダンジョンがあります。舞台設定キットと世界が必要です。キットを選ぶまでは最初のジャンルのキット(キットのないジャンルではHigh fantasy)が使われ、そのキットで世界が生成されます。
- **VN**は、これまでどおりのGame Modeをビジュアルノベルのように語るモードです。物語はシーンごとに進み、シーンのマップと戦闘があります。舞台設定キット、世界、オーバーワールド、町、ダンジョンのマップはありません。

サーバーの所有者が`MARINARA_OVERWORLD_GAMES`を設定しない限り、Overworldはロックされています。ロック中は、そのカードがグレー表示になり、「Overworld games, with a setting kit and a generated world, are not ready yet. New games start as VN games.」という注記が表示されます。その場合、新しいゲームはすべてVNゲームになり、舞台設定キットと世界の選択肢は表示されません。この選択ができる前に作ったゲームは、これまでどおりに遊べます。世界があればOverworldゲーム、なければVNゲームです。

<a id="choosing-a-setting-kit"></a>

### 舞台設定キットの選択

**Setting kit**(舞台設定キット)は、その種類の世界を書き表すための言葉をGMに渡します。場所の呼び名と集落の大きさ、集団の種類、人々の旅の仕方、1年と1日の呼び名、民族が自分たちにどう名前を付けるか、通貨と品物、属性、戦いの場所、そしてどの系統のアートと音楽を使うか([ゲームアセット](game-assets.md#a-settings-own-art-and-music)を参照)です。また、対立、犯罪、戦争、災害など、その世界でどんな種類の変化が起こりうるか、そしてどれくらいの速さで変わるかも決めます。オフになっている種類が持ち込まれることはないので、口論は口論のままでいられます。

キットは、ハイファンタジー、武侠と仙侠、現代、現代の超常、1920年代、サイバーパンク、スペースオペラ、ポストアポカリプスの8つです。現代はデフォルトで穏やかな設定になっていて、犯罪、紛争、大災害がなく、変化もゆっくりです。

- ジャンルを選ぶ前にキットを選ぶと、キットに合ったジャンルが設定されます。自分で選んだジャンルはそのまま残ります。
- **Write it for my setting**(自分の舞台用に書き直す)を押すと、GMのモデルが、選んだジャンル、舞台、雰囲気に合わせてキットを書き直します。結果の整合性が取れていない場合は、理由を添えてもう一度モデルに依頼します。それでもだめなら、ウィザードが何が問題だったかを知らせ、元のキットを残します。
- **Change its words**(言葉を変更)を押すと、キットのすべての言葉を編集できます。一覧は、カンマで区切って1行に入力します。名前が空、集落が1つもないなど、問題のあるキットには何が問題かが表示され、直すまではゲームを始められません。
- **Download this kit**(このキットをダウンロード)は、共有用に`.worldkit.json`ファイルを保存します。**Import a kit file**(キットのファイルをインポート)で読み込めます。

ゲームは、作成したときのキットを保持します。共有したセットアップファイルにも、キットが含まれます。Experienceは独自のマップパック(キット、既製のマップ、タイル)を同梱できます。そのExperienceがオンのとき、セットアップではキットが設定済みとして表示され、マップを同梱している場合は選択できる**Map**(マップ)が表示されます。Experienceをオフにすると、自分の選択に戻ります。

<a id="making-a-world"></a>

### 世界を作る

キットを選ぶと、ゲームが始まる前に、**Your world**(自分の世界)がキットの言葉で世界を組み立てます。地方、あらゆる大きさの集落、各場所が何で知られているか、そしてそれらを結ぶ道(街道、川、航路、ジャンプ航路)と、それぞれの旅にかかる日数です。

世界は**World seed**(世界のシード)から作られます。シード、キット、概要が同じなら、いつも同じ世界ができます。**Roll**(振り直す)を押すと別の世界になり、数値を入力し直すと元の世界に戻せます。プレビューには、地面と集落の小さなマップ、パーティーの出発地点、地方ごとの集落の一覧が表示されます。

- **Start from this lore**(このロアから始める)は、チェックを入れたロアブックから、そこに書かれた場所と日付のある出来事を読み取り、書かれたとおりに保持します。**Build around the lore**(ロアの周りに世界を作る)はそれらの周りに世界を埋め、**Only the lore's places**(ロアの場所だけ)はそれら以外に何も作りません。
- **Write the world's brief**(世界の概要を書く)は、GMのモデルに次のものを依頼します。現在の状況、主要な場所、現在を動かしている集団(それぞれが何を望み、誰が味方で誰が対立相手か)、そして各民族らしい響きの場所と人々の名前です。モデルが何を書いても、ロアの場所は保持されます。キットに合わないものは除外され、件数が数えられます。**Change the brief**(概要を変更)を押すと、各民族の名と姓を含め、概要の言葉を編集できます。概要がない場合、場所には番号が振られ、人々は職業で呼ばれます。

**世界には過去がある。** ゲームが始まる前に、世界は創設から1年ずつ進みます。集落は成長し、集団は創設され、指導者を得たり失ったりし、互いに手を結んだり仲たがいしたりします。そうしたものがある世界では、盗賊、戦争、飢饉が爪痕を残します。深刻な変化は、しばらく前兆が続いた後にだけ、キットが許す種類でだけ起こります。ロアや概要に書かれた日付のある出来事は、書かれたとおりの時と場所で起こります。シードと概要が同じなら、いつも同じ過去になります。

**GMが知っていること。** GMは、パーティーがどこにいて、どこへ行けて、それぞれの道にどれだけかかるかを常に把握しています。過去の最も注目すべき出来事、今いる場所を誰が率いているか、その場所の歴史も伝えられます。ほかの場所や集団については、GMが尋ねることができ、次のターンで答えを受け取ります。パーティーの行き先は、場所のタグで示します。世界の一覧にある場所は、世界が与えた大きさを保ちます。農家のように世界の一覧にない場所は、GMが付けた名前を保ちます。どの集落にも、パーティーが着いたときにシードから決まる住人がいます。それぞれが、自分の文化の名前、その場所に合った仕事、性格、話し方、見た目を持っています。GMがフルネームで呼んだ人物は、ゲームが追跡するキャラクターに加わります。

**パーティーのしたことは残る。** パーティーが集団を助けたり妨げたり、2つの集団が互いをどう思うかを変えたり、場所を奪ったり荒らしたり、誰かを集団の頭に据えたりすると、GMはそれを返信の中に記録します。それぞれの変化は世界と照らし合わされます。キットでオフになっている種類の変化や、世界にない場所や集団を挙げる変化は拒否されます。それ以降、GMには物語が残したとおりの世界が伝えられます。物語が加えた場所には、パーティーが行けます。スワイプ、再生成、メッセージの削除をすると、変化はその返信とともに取り消されます。

**世界はパーティーがいなくても動き続ける。** GMが時間の経過を語ると、世界は1週間ずつ、キットにある種類の変化だけで進みます。大災害がひとりでに起こることはありません。大災害を語れるのはGMだけで、その種類がオフなら拒否されます。パーティーのいる場所では何も決まりません。知らせは伝わっていきます。GMは、道のりにかかる日数が過ぎてから遠くの変化を知ります。パーティーの行いは、名が知られるほど重みを増します。

**手で加えた編集。** 世界のエディターでは、場所の名前を変えたり動かしたり、地面を塗ったり、場所や人物を加えたり、場所の戦術用の戦場を塗ったり([戦闘](combat.md#tactical-battles-and-terrain)を参照)、町を配置したり([町](map-time-weather.md#the-town)を参照)できます。ゲームのあらゆる部分に、編集がすぐに反映されます。名前を変えた場所も、古い名前で通じます。編集はこれからの世界を変えるもので、過去は決して変えません。町は配置を保つため、追加した場所と人物は、次に空いている区画と住まいに入ります。

**ワールドファイル。** **Your world**の下にある**Download this world**(この世界をダウンロード)は作成中の世界を、ゲームのWorldタブにある**Download the world**(世界をダウンロード)はそのゲームの世界を手で加えた編集も含めて、`.world.json`ファイルとして保存します。舞台設定キットの横にある**Import a world file**(ワールドファイルをインポート)は、新しいゲームのセットアップにワールドファイルを読み込みます。ファイルのキットを選び、その世界を作ります。**Your worlds**(自分の世界一覧)は、ライブラリーにある世界で同じことをします。ファイルには世界のストーリー、つまり作者が書いた出来事とシーンも含められます。ストーリーのシーンは、GMの返信の前に、書かれたとおりに語りの中に現れます。クエストの目標は、記録のWorldタブの**Story**の下に一覧表示されます。ストーリーの書き方は[Game Modeのストーリースクリプトの作成](../extending/writing-story-scripts.md)を参照してください。手で加えた編集とストーリーはそのシードと概要のためのものなので、どちらかを変えると除外されます。読み取れないファイルは拒否され、ウィザードがその理由を示します。内容がキットに合わないファイルは一部が除外され、ウィザードが何を除外したかを示します。

**後から作る世界と保存。** 世界なしで作ったゲームにも、記録の**World**タブにある**Make a world for this game**(このゲームの世界を作る)で、後から世界を与えられます。世界は次のターンから始まり、過去のターン、マップ、人物はそのまま残ります。Overworld RPGがロックされている間、このボタンはグレー表示になります。ゲームは作られたときのままの世界を保持するので、新しいセッション、分岐、エクスポートしたチャットでも同じ世界が保たれます。以前のバージョンの世界ジェネレーターで作った世界は、そのままプレイを続けられますが、編集はできなくなります。

世界のあるゲームは、**overworld**(オーバーワールド)で開きます。オーバーワールドとは、パーティーを集落から集落へ歩かせたり、町に入ったりできるピクセルマップです。[オーバーワールド](map-time-weather.md#the-overworld)を参照してください。
