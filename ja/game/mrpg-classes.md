# Game Mode: MRPGクラス

Experienceから作成したゲームを含め、新しいゲームはすべて**MRPG**(Marinara RPG)クラスで遊びます。各パーティーメンバーにはクラスがあり、戦闘でレベルアップし、成長に応じて新しいクラスが開放されます。MRPGクラスが登場する前に作ったゲームは、[LegacyゲームをMRPGへ移行する](#move-a-legacy-game-to-mrpg)ことを選ぶまで**Legacy**シートを使い続けます。

5e (SRD 5.1)など、ルールセットで遊ぶゲームでは、代わりにそのルールセット独自のシートを使うため、MRPGクラスは適用されません。

<a id="classes-and-trees"></a>

## クラスとツリー

ツリーは**Blade**、**Guard**、**Scout**、**Marksman**、**Channeler**、**Hexer**、**Mender**、**Herald**の8種類です。各キャラクターは、そのうち2つを修めます。

- **Primary tree**(メインツリー)。シートから選びます。ライブラリーのキャラクターカードやペルソナカードにある**Game Mode**セクションで選択できます。選ばなかった場合は、キャラクターのクラスと能力から読み取られます。
- **Secondary tree**(サブツリー)。キャラクターがゲーム開始時に持つ性格によって開放されます。性格が自分のメインツリーを指すキャラクターは、そのツリーだけを修め、1つのツリーにとどまる者だけが到達できるクラスへ進めます。

各ツリーは基礎クラスから始まります。クラスレベル10と20でクラスアップし、レベルは30で上限に達します。キャラクターは、これまで修めた別のクラスから最大4つのスキルを持ち越せます。クラスの切り替えは戦闘外で、キャラクターシートから行います。ステータスは現在のクラスに従います。

<a id="the-character-sheet"></a>

## キャラクターシート

パーティーの一覧からメンバーのシートを開きます。シートには**Status**(状態)、**Classes**(クラス)、**Skills**(スキル)、**Gear**(装備)の4つのタブがあります。成長率は表示されません。**Debug**(デバッグ)をオンにすると、正確な成長率がパーセントで表示されます。

パーティーが勝った戦闘で、パーティーメンバーはレベルアップします。敗北または逃走した戦闘では経験値を得られません。設定項目の**Permadeath**(永久死)がオンの場合、戦闘中に倒れ、戦闘終了までに救出されなかったパーティーメンバーは永久に失われます。

<a id="skill-checks"></a>

## スキル判定

戦闘外の判定では、キャラクターのMRPGステータスを読みます。各スキルがどのステータスを使うかは、[ダイスとスキル判定](dice-and-skill-checks.md#how-the-result-is-decided)を参照してください。

<a id="newcomers-to-the-party"></a>

## パーティーに新しく加わる仲間

ゲーム開始後に加わる者は、Game Masterが指定するレベルで加入します。たいていの新しい仲間は低いレベルから始まり、熟練した戦士ならパーティーに近いレベルから始まることもあります。Game Masterは、新しい仲間に次の特徴を与えることもできます。

- 一部のステータスの**成長が速い**: 素質があり、すぐに追いつくキャラクター向けです。
- **開始時からステータスが高い**: すでにある程度の実力を持つキャラクター向けです。

キャラクターが加入するときに、Game Masterがこれを決めます。特に指定されなかった新しい仲間はレベル1から始まります。

<a id="playing-with-others"></a>

## ほかのプレイヤーとのプレイ

共有ゲームでは、ゲストはそれぞれ、ルームに参加するときに自分のキャラクターを作ります。名前、説明、Game Master向けの**キャラクターのコンセプト**、そしてペルソナと同じ**Game Mode**の選択(開始時のツリー、強いステータス、弱いステータス)です。自分のペルソナを選ぶと、そこからこれらが入力されます。コンセプトでは、キャラクターが何者で、どのように物語へ登場してほしいかをGame Masterに伝えます。

Game Masterは、そのキャラクターを物語に組み込み、姉妹ツリーを選びます。

- **新しいゲーム。** ホストもゲストも全員レベル1から始まります。
- **進行中のゲーム。** Game Masterはさらにゲストの開始レベルを決め、ほかの[新しい仲間](#newcomers-to-the-party)と同じく、成長を速くしたり、ステータスを高くしたりできます。
- **再参加するゲスト。** ゲストが退出しても、そのキャラクターはレベル、装備、手なずけた獣とともにゲームに残ります。プレイヤーが不在の間、そのキャラクターは戦闘に参加せず、経験値も得ません。Game Masterもシーンには登場させません。ゲストが戻ると、退出時と同じレベルのキャラクターを再び操作します。

<a id="move-a-legacy-game-to-mrpg"></a>

## LegacyゲームをMRPGへ移行する

Legacyゲームは、好きなだけLegacyシートを使い続けられます。移行するには**Journal**(記録)を開き、**All**(全員)タブで**MRPG classes**(MRPGクラス)カードを見つけ、**Upgrade**(アップグレード)を選びます。

カードには、パーティーメンバーごとに次の項目が表示されます。

- **Class**(クラス)。開始時のツリーです。ライブラリーカードで選んだもの、なければLegacyクラスから自動入力されます。変更もできます。
- **Sister tree**(姉妹ツリー)。性格によって開放されるサブツリーです。まだ性格がないキャラクターでは、アップグレード時にDescriptionから読み取られます。
- **Gear**(装備)。持っているLegacyの武器と防具、および変換先となるMRPG装備です。変換せずそのまま残すものは、チェックを外してください。

**Upgrade the party**(パーティーをアップグレード)で確定すると、次のようになります。

- 各パーティーメンバーは開始クラスの最高レベルであるレベル10になり、レベルアップと同じ方法で各レベルのステータスが決まります。
- カードのクラスがMRPGクラスになります。Legacyのクラスと能力は、物語で引き続き認識できるように、カードの**Before the upgrade**(アップグレード前)という注記へ移されます。Legacyのステータスもカードに残ります。
- 変換を選んだ武器や防具は、それぞれ対応するMRPG装備になり、名前はそのまま残ります。クラスが装備できるものは身に着けます。

> **Warning:** アップグレードは一方向です。MRPGクラスへ移行したゲームをLegacyシートへ戻すことはできません。

戦闘中はアップグレードできません。まず戦闘を終えてください。ルールセットで遊ぶゲームもアップグレードできず、そのルールセットのシートを使い続けます。
