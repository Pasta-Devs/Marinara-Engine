# Game Mode: MRPGクラス

Experienceから作成したゲームを含め、新しいゲームはすべて**MRPG**(Marinara RPG)クラスで遊びます。各パーティーメンバーにはクラスがあり、パーティーが勝った戦闘でレベルを上げ、成長に応じて新しいクラスを開放します。このページは、クラスの選び方、ステータスの意味、レベルとクラスアップの仕組み、キャラクターシートを説明するプレイヤー向けのガイドです。

2種類のゲームではMRPGクラスを使いません。

- **Legacyゲーム。** MRPGクラスが登場する前に作ったゲームは、移行を選ぶまで**Legacy**シートを使い続けます。[LegacyゲームをMRPGへ移行する](#move-a-legacy-game-to-mrpg)を参照してください。
- **ルールセットのゲーム。** 5e (SRD 5.1)など、ルールセットで遊ぶゲームでは、そのルールセット独自のシートを使います。[ルールセットで遊ぶ](rulesets.md)を参照してください。

MRPGクラスでの戦闘の進み方は、[ゲームでのMRPG戦闘](combat.md#battles-in-an-mrpg-game)を参照してください。

<a id="how-it-works"></a>

## 仕組み

- 各キャラクターは、8つの**ツリー**のうち2つを修めます。選択する**メインツリー**と、そのキャラクターの性格が開放する**姉妹ツリー**です。
- メインツリーの基礎クラスのレベル1でゲームを始めます。
- 戦闘に勝つと経験値を得ます。キャラクターのステータスは**現在のクラス**から得られ、そのクラスのレベルとともに上がります。
- クラスレベル10で上級クラスに、クラスレベル20で最上級クラスにクラスアップできます。レベルは30で上限に達します。
- 戦闘外では、開放済みのどのクラスにも切り替えられ、修めた別のクラスから最大4つのスキルを持ち越せます。

<a id="the-eight-trees"></a>

## 8つのツリー

| ツリー | 列 | 戦い方 | 次の性格で開放される姉妹ツリー |
| --- | --- | --- | --- |
| **Blade** | 前列 | 敵に正面から立ち向かう武器戦士です。 | Reckless |
| **Guard** | 前列 | 味方の代わりに攻撃を受け、敵を自分に引きつける盾使いです。 | Protective、Honourable |
| **Scout** | 前列 | 攻撃、回避、盗みの機会をすばやくつかむ者です。 | Opportunistic、Cowardly |
| **Marksman** | 後列 | 対象に合わせて弾薬を切り替える弓使いです。 | Patient、Cautious |
| **Channeler** | 後列 | 火、氷、雷、風、木、土、水、金を操る魔術師です。 | Arrogant、Methodical |
| **Hexer** | 後列 | 敵を弱体化し、HPを吸い取る呪いの使い手です。 | Cruel |
| **Mender** | 後列 | パーティーが倒れないように支え、異常を治す治療師です。 | Supportive |
| **Herald** | 後列 | 指示を出し、歌でパーティーを強化する戦闘指揮官です。 | Coordinated、Disciplined |

ツリーをバランスよく組み合わせたパーティーが最も強くなります。後列への近接攻撃はダメージが半減するため、後列のツリーは前列に戦線を支えてもらいます([列](combat.md#rows)を参照)。

<a id="classes-in-each-tree"></a>

### 各ツリーのクラス

各ツリーには7つのクラスがあります。基礎クラスはクラスレベル10で2つの上級クラスのどちらかへクラスアップし、それぞれの上級クラスはクラスレベル20で最上級クラスへクラスアップします。最後の列にある3本目の系統は、**Pure**のキャラクターだけに開放されます。その性格が自分のメインツリーを指し、姉妹ツリーを持たず、1つのツリーだけを修めるキャラクターです。

| ツリー | 基礎クラス | 上級(10) → 最上級(20) | Pureのみ |
| --- | --- | --- | --- |
| Blade | Blade | Duelist → Headsman; Bloodsworn → Cleaver | Weaponmaster → Paragon of Arms |
| Guard | Guard | Sentinel → Stonewall; Warden → Elder Warden | Aegis → Bulwark |
| Scout | Scout | Rogue → Phantom; Skirmisher → Harrier | Shade → Shroud |
| Marksman | Marksman | Sharpshooter → Farshot; Tracker → Huntsmaster | Artillerist → Siegebreaker |
| Channeler | Channeler | Elementalist → Stormcaller; Rune Scholar → Runelord | Astral Adept → Starweaver |
| Hexer | Hexer | Witch → Carrion Lord; Dreamcaller → Dreamweaver | Nullifier → Void Sovereign |
| Mender | Mender | Cleric → Saint; Apothecary → Panacean | Lifebinder → Lightbearer |
| Herald | Herald | Cantor → Maestro; Field Captain → Marshal | Standard-Bearer → Lodestar |

キャラクターシートの**Classes**(クラス)タブでは、すべてのクラスが説明され、各スキルが習得されるクラスレベルとともに一覧表示されます。

<a id="choose-a-characters-trees"></a>

## キャラクターのツリーを選ぶ

**メインツリー。** ゲーム開始前に、ライブラリーのキャラクターまたはペルソナの**Stats**(ステータス)タブにある**Game Mode**セクションで選びます([カードでのMRPGの選択](../characters/colors-and-stats.md#mrpg-picks-on-a-card)を参照)。**Auto**(自動)のままにすると、キャラクターのDescriptionから読み取られ、ゲームではクラスと能力からも読み取られます。カードにツリーが書かれていないキャラクターはBladeで始めます。最初の経験値を得るまでは、ゲーム内でも、シートの**Classes**タブにある**Main tree**(メインツリー)から変更できます。

**得意と苦手のステータス。** カードの同じセクションでは、キャラクターが**Strong in**(得意)とするステータスを最大2つ、**Weak in**(苦手)とするステータスを1つ選べます。ゲームごとに各キャラクターの隠し成長率が改めてロールされ、これらの選択がそのロールに傾向を与えます。数値を指定するものではありません。

**姉妹ツリー。** ゲームがキャラクターのゲームカードを作るとき、Game MasterはDescriptionと性格から、そのキャラクターの性格、つまり戦闘にどう取り組むかを読み取ります。その性格が上の表にある姉妹ツリーを開放します。特定の姉妹ツリーにしたい場合は、それを意識してDescriptionを書いてください。シートには、たとえば「from Cautious」のように、姉妹ツリーの横に性格が表示されます。物語の中で性格が後から変わることはありますが、姉妹ツリーは最初のものから変わりません。

RecklessのBladeなど、性格が自分のメインツリーを開放するキャラクターは**Pure**です。1つのツリーだけを修め、Pureだけの系統が開放されます。

<a id="what-the-stats-mean"></a>

## ステータスの意味

| ステータス | 効果 |
| --- | --- |
| **HP** | 体力です。0になったキャラクターは戦闘不能になります。戦闘のHPバーはステータスより大きく、レベルとともに増えます。 |
| **Strength** (Str) | 武器のダメージです。Staminaも増やします。 |
| **Magic** (Mag) | 呪文、杖、ワンド、フォーカスのダメージと、回復の威力です。MPも決めます。 |
| **Skill** (Skl) | 命中率とクリティカルヒットです。 |
| **Speed** (Spd) | キャラクターが行動する頻度と、回避の上手さです。Staminaも増やします。 |
| **Defense** (Def) | 武器などの物理攻撃によるダメージを減らします。 |
| **Resistance** (Res) | 魔法によるダメージを減らします。 |
| **Luck** (Lck) | 命中率と回避率を少し上げ、クリティカルヒットから守ります。 |

2つのリソースをスキルのコストに使います。

- **MP**は魔法に使います。値は8にMagicの2倍を足したもので、戦闘中には回復しません。
- **Stamina** (ST)はそれ以外のすべてに使います。値は10にStrengthとSpeedの半分を足したもので、ターンごとに少し回復します。防御に使ったターンではより多く回復します。

戦闘外のスキル判定でも同じステータスを使います。[スキル判定](#skill-checks)を参照してください。

<a id="levels-and-experience"></a>

## レベルと経験値

**経験値。** 戦闘に勝つと、降伏した敵や逃走した敵を含め、パーティーが倒したすべての敵から経験値を得ます。半分は戦った全員で均等に分け、残りの半分はダメージ、回復、支援といった各自の貢献度で分けます。キャラクターよりレベルの低い敵から得る経験値は少なく、レベルの高い敵からは多くなります。パーティーの平均レベルより低いキャラクターは、さらに半分多く得ます。敗北した戦闘や逃走した戦闘では何も得られません。

**キャラクターレベル。** 100経験値ごとに1レベル上がり、上限は30です。戦闘画面の終了パネルにある**What the party gained**(パーティーが得たもの)には、経験値、上がった各レベル、上昇したステータスが表示されます。

**クラスレベル。** 現在のクラスは、同じ経験値をそのクラスレベルに向けて得ます。キャラクターレベルの半分未満で修めているクラスは2倍の経験値を得るため、後から始めたクラスも追いつけます。キャラクターのステータスは、現在のクラスのクラスレベルから得られます。クラスレベルが上がるたびに、クラスの成長率とキャラクターの隠し適性によって各ステータスの上昇がロールされ、毎回少なくとも2つのステータスが上がります。

これは、新しく始めたクラスでは身体がレベル1になるということです。余裕のあるときに戦闘と戦闘の間で新しいクラスへ切り替え、築いた強さが必要なときは元に戻してください。

**クラスアップ。** クラスがクラスレベル10に達すると上級クラスが、クラスレベル20に達すると最上級クラスが開放されます。終了パネルには**A promotion is open**と表示されます。**Classes**(クラス)タブで**Promote to**(クラスアップ先)とクラス名を選び、クラスアップします。クラスアップしたクラスは、親クラスのクラスレベルで始まり、1回限りのステータスボーナスが加わり、空いている持ち越し枠が、そこへ至るクラスのアクティブスキルで埋まります。

成長率は表示されません。**Debug**(デバッグ)をオンにすると、**Status**(状態)タブに各ステータスが上がる正確な確率が表示されます。

<a id="switch-classes-and-carry-skills"></a>

## クラスの切り替えとスキルの持ち越し

クラスは戦闘外で、**Classes**(クラス)タブから変更します。クラスを選ぶと、そのスキルと、切り替えると失われるものが表示されます。そのあと、まだ修めていないクラスなら**Take up**(始める)、以前に修めたクラスなら**Switch to**(切り替え)を選びます。後者では、そのクラスが達したクラスレベルに戻ります。

キャラクターが使うのは、現在のクラスのスキルと、修めた別のクラスから**持ち越した**最大4つのスキルだけです。**Skills**(スキル)タブの**Carry from other classes**(他のクラスから持ち越す)で選びます。持ち越したスキルは、キャラクター自身のステータスを使います。GuardのCoverなど、ツリー全体に属するスキルもあり、そのツリーのすべてのクラスが枠を使わずに保持します。クラスの切り替えで使っていたスキルが失われる場合は、先にシートが警告し、持ち越せるようにします。

<a id="the-character-sheet"></a>

## キャラクターシート

**Character Profiles**(キャラクタープロフィール)からパーティーメンバーのシートを開きます。シートには4つのタブがあります。

- **Status**(状態): レベル、経験値、現在のクラス、装備を含めたステータス、戦闘開始時のHP、MP、Staminaです。**Row**(列)で、Turn-Based戦闘で前列と後列のどちらに立つかを設定します。各クラスにデフォルトがあります。
- **Classes**(クラス): 2つのツリーとそのすべてのクラスについて、開放されているもの、各クラスの条件、クラスアップを表示します。
- **Skills**(スキル): 現在のクラスのスキルと持ち越したスキルを、それぞれのコストとともに表示します。
- **Gear**(装備): **Weapon**(武器)、**Armour**(防具)、2つの**Accessory**(アクセサリー)枠があり、パーティーの所持品のうち、クラスが使えるものを装備します。各装備には、身に着ける前にステータスが表示されます。武器や防具の枠が空の場合は、そのレベルでのクラス標準の装備で戦います。

攻撃で使うステータスは武器が決めます。杖、ワンド、フォーカスはMagicでResistanceを攻撃し、それ以外の武器はStrengthでDefenseを攻撃します。

**手なずけた仲間。** Trackerは、戦闘で弱った野生の獣を手なずけられます。その獣は仲間となり、**Status**(状態)タブに表示され、最大8体まで保有できます。TrackerまたはHuntsmasterクラスが現在のクラスのとき、アクティブな仲間はその仲間が最も得意とするステータスを上げます。レベルが高い獣やエリート獣ほど効果が大きくなります。厩舎がいっぱいのときは、1体を野に放って新しい仲間を残します。仲間は戦闘外で切り替えます。

**永久死。** **Permadeath**(永久死、設定ウィザードの**World**ステップにある選択肢で、デフォルトでオフ)がオンの場合、戦闘で倒れ、戦闘終了までに救出されなかったパーティーメンバーは永久に失われます。オフの場合、倒れた者は戦闘後に立ち上がります。

<a id="skill-checks"></a>

## スキル判定

戦闘外の判定では、現在のクラスから得られるキャラクターのMRPGステータスを使います。各スキルは、StealthならSpeed、PersuasionならLuckのように、1つのステータスに依存します。完全な一覧と各ステータスのボーナスは、[ダイスとスキル判定](dice-and-skill-checks.md#how-the-result-is-decided)を参照してください。

<a id="new-party-members-and-shared-games"></a>

## 新しいパーティーメンバーと共有ゲーム

**進行中のゲームに加わる者。** ゲーム開始後に加わる仲間は、Game Masterが指定するレベルで加入します。たいていは低いレベルから始まり、熟練した戦士ならパーティーに近いレベルから始まることもあります。Game Masterは、すぐに追いつく素質のあるキャラクターに一部のステータスの成長を速くしたり、すでに実力のあるキャラクターに開始時から高いステータスを与えたりもできます。Game Masterが特に指定しなかった新しい仲間はレベル1から始まります。

**共有ゲームのゲスト。** ゲストはそれぞれ、ルームに参加するときに自分のキャラクターを作ります。名前、説明、Game Master向けの**キャラクターのコンセプト**、カードと同じ**Game Mode**の選択(開始時のツリー、得意なステータス、苦手なステータス)です。自分のペルソナを選ぶと、そこからこれらが入力されます。コンセプトでは、キャラクターが何者で、どのように物語へ登場してほしいかをGame Masterに伝えます。Game Masterはそのキャラクターを物語に組み込み、姉妹ツリーを選びます。

- **新しいゲーム。** ホストもゲストも全員レベル1から始めます。
- **進行中のゲーム。** Game Masterはほかの新しい仲間と同じように、ゲストの開始レベル、成長、ステータスも決めます。
- **再参加するゲスト。** ゲストが退出しても、そのキャラクターはレベル、装備、手なずけた獣とともにゲームに残ります。プレイヤーが不在の間、そのキャラクターは戦闘に参加せず、経験値も得ず、シーンにも登場しません。ゲストが戻ると、退出時と同じレベルのキャラクターを再び操作します。

各プレイヤーのスキル判定は、そのプレイヤー自身のキャラクターのステータスを読みます。

<a id="move-a-legacy-game-to-mrpg"></a>

## LegacyゲームをMRPGへ移行する

Legacyゲームは、好きなだけLegacyシートを使い続けられます。移行するには**Journal**(記録)を開き、**All**(全員)タブで**MRPG classes**(MRPGクラス)カードを見つけ、**Upgrade**(アップグレード)を選びます。

カードには、パーティーメンバーごとに次の項目が表示されます。

- **Class**(クラス)。開始時のツリーです。ライブラリーカードで選んだもの、なければLegacyクラスから自動入力されます。変更もできます。
- **Sister tree**(姉妹ツリー)。性格によって開放されるツリーです。まだ性格がないキャラクターでは、アップグレード時にDescriptionから読み取られます。
- **Gear**(装備)。持っている各Legacy武器と防具、および変換先となるMRPG装備です。変換せずそのまま残すものは、チェックを外してください。

**Upgrade the party**(パーティーをアップグレード)で確定すると、次のようになります。

- 各パーティーメンバーは開始クラスの最高レベルであるレベル10になり、レベルアップと同じ方法で各レベルのステータスが決まります。最初のクラスアップがすぐに開放されます。
- カードのクラスがMRPGクラスになります。Legacyのクラスと能力は、物語で引き続き認識できるように、カードの**Before the upgrade**(アップグレード前)という注記へ移されます。Legacyのステータスもカードに残りますが、判定にも戦闘にも使われなくなります。
- 変換を選んだ武器や防具は、それぞれ対応するMRPG装備になり、名前はそのまま残ります。クラスが装備できるものは身に着けます。

> **Warning:** アップグレードは一方向です。MRPGクラスへ移行したゲームをLegacyシートへ戻すことはできません。

戦闘中はアップグレードできません。まず戦闘を終えてください。ルールセットで遊ぶゲームもアップグレードできず、そのルールセットのシートを使い続けます。
