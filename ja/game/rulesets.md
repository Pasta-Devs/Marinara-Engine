# Game Mode: ルールセットで遊ぶ

ルールセットは卓上ゲームの仕組みをGame Modeに伝えます。判定で振るダイス、キャラクターシートの項目、消費するリソース、休息で回復するものに加え、一部のルールセットでは戦闘全体の進め方も定めます。このガイドでは、ルールセットを入手し、ゲームで使うものとして選び、プレイで何が変わるかを確認する方法を説明します。ルールセットを使わないゲームは、ほかのGame Modeガイドで説明しているMarinara独自のルールで進みます。

## ルールセットを入手する

5e (SRD 5.1)などの公式のルールセットをインストールするには、次のようにします。

1. Sparklesのアイコンから**Agents**(エージェント)パネルを開きます。
2. **Agent Organizer**(エージェント管理)を選びます。
3. ルールセットを探します。ルールセットには**Rules**の印が付いています。
4. **Install**を選びます。

そのあと新しいゲームを始めて、そのルールセットを選びます(下記を参照)。ルールセットの入手先は2つです。

- **Official**(公式)のルールセットは、上の手順でインストールします。
- **Community**(コミュニティ)のルールセットは、ファイルか作者のGitHubリポジトリーからインポートします。`local/ember-roads`や`alice/v20`のように、入手元ごとに分類されます。

インポートには、インポートするエージェントと同じ**Allow custom Agent imports**(カスタムエージェントのインポートを許可)のスイッチを使います。このスイッチがオフのあいだ、インポートしたルールセットは新しいゲームでは選べませんが、すでに使っているゲームは引き続き動きます。インポートしたルールセットを使うゲームは、必ず作成したときとまったく同じバージョンでプレイされます。自分で作るには、[Game Modeのルールセットを作成する](../extending/writing-rulesets.md)を参照してください。

スキル名、呪文、Game Master(GM)向けのテキストなど、ルールセット自身のテキストは**Settings**(設定)で指定した言語に従います。公式のルールセットはその言語の翻訳だけをダウンロードし、言語を切り替えると新しい翻訳を取得します。翻訳のない言語では英語で表示します。ファイルからインポートしたルールセットは、インポート時に設定されていた言語の翻訳だけを保持します。切り替えるには、ファイルを再度インポートしてください。

## ゲームで使うルールセットを選ぶ

**Rules**(ルール)は、ルールセットが1つ以上インストールされている場合に、新しいゲームのときだけ、ウィザードの**World**ステップに表示されます。これは**Combat Preference**とは別の設定です。**Rules**は判定とシートの仕組みを、**Combat Preference**は戦闘の表示方法を決めます。

1. セットアップウィザードで**World**ステップを開きます。
2. **Rules**で、**Marinara's own rules**(Marinara独自のルール。内蔵のd20判定と6つの能力値のシート)のままにするか、**5e (SRD 5.1)**などのルールセットを選びます。
3. 概要を読みます。ルールセットが扱う範囲と、戦闘についての1行が表示されます([戦闘での動作](#what-happens-in-battles)を参照)。
4. 任意: **layers**(レイヤー)をオンにします(下記を参照)。
5. **Party**ステップで、誰が**Has a sheet**(シートあり)で、誰が**Starts on a blank sheet**(空白のシートで開始)かを確認します。シートとは、能力値やHPなど、このルールセットでのキャラクターの数値です。空白のシートはルールセットのデフォルト値を使います。あとから記入できます。

ルールセットはゲームの作成時に決まります。あとから変更したり追加したりすることはできません。

**Layers**(レイヤー)は、Low magicやHard winterのような、ルールセットの名前付きのバリエーションです。ルールセットの下にスイッチとして表示され、それぞれが何をするかを説明する1行が付きます。レイヤーでは、次のことができます。

- 難易度を厳しくする
- シートの選択肢を絞る
- シートエディターの選択画面から、用意された項目の一部を隠す
- 店が売るものや、手に入る宝物を変える
- GMに追加の指示を与える(GMが作る世界についての指示も含む)

互いに両立しないレイヤーもあり、選べないものはウィザードで無効になります。レイヤーは、ゲームが始まると固定されます。レイヤーが取り除くものをすでに使っているシートは、それをそのまま保持します。

シートは、キャラクターエディターかペルソナエディターの**Stats**で追加します([ルールセットのシート](../characters/colors-and-stats.md#ruleset-sheets)を参照)。世界を生成するときに、ゲームは各シートをコピーします。ゲームの中で変えたことが、キャラクターやペルソナに戻ることはありません。シートのないメンバーには、すべての値がルールセットのデフォルトになった空白のシートが渡されます。世界の生成で能力値が作り出されることはありません。

共有したセットアップファイルは、使ったルールセットを覚えています。インポートしたファイルのルールセットを持っていない場合や、古いバージョンしか持っていない場合は、ウィザードがどのルールセットだったかを知らせます。そのルールセットをインストールして選ばない限り、ゲームはMarinara独自のルールを使います。

## 戦闘での動作

ルールセットが戦闘で何をするかは、その書き方によって決まります。どの行に当てはまるかは、ウィザードのルールセットの下の行に表示されます。

| ルールセット | 戦闘 |
| --- | --- |
| 5e (SRD 5.1)など、独自に戦闘を解決するもの | ルールセット独自のルールに従い、専用の戦闘画面で戦います。[ルールセットでの戦闘](fighting-on-a-ruleset.md)を参照してください。 |
| 戦闘にシートを提供するもの | シートの体力、呪文スロット、能力を使ったMarinara独自の戦闘です(下記を参照)。 |
| 戦闘について何も定めていないもの | ルールセットを使わない場合とまったく同じ、Marinara独自の戦闘です。[戦闘](combat.md)を参照してください。 |

ルールセットがシートを提供する場合、Marinaraの戦闘は次のようにシートを使います。

- パーティーの各メンバーは、ルールセットが戦闘用に設定したリソースプールと呪文スロットを、現在のシートの状態のまま持って戦闘を始めます。
- ルールセットのカタログから選んだ能力は、Marinaraの戦闘で使えるものがスキルになります。戦闘外のことだけを説明する項目、リアクション、戦闘で支払えないコストを持つ項目は除外されます。
- HPは、シート上の数値そのままではなく、最大値に対する割合として引き継がれます。体力が半分のキャラクターは、戦闘画面の体力バーの半分の状態で戦闘を始めます。そのため、体力が9のシートのキャラクターが、一撃で12のダメージを受ける戦闘に放り込まれることはありません。
- 戦闘が終わると、失った体力や回復した体力は同じ方法でシートに戻され、消費したスロットとリソースはそのまま書き戻されます。

それ以外は変わりません。ダイスの計算は引き続きMarinaraのもので([戦闘の計算方法](combat.md#how-combat-math-works)を参照)、卓上システムの攻撃ロール、セーヴィングスロー、精神集中は適用されません。戦闘が始まったメッセージを削除して戦闘から抜けた場合は、何も書き戻されません。

## ルールセットでの判定

GMは、ほかのゲームと同じように判定を求めます([スキル判定](dice-and-skill-checks.md#skill-checks)を参照)。ただし、ダイスの振り方はルールセットが決めます。

- GMは、スキルまたはセーヴの名前を挙げて難易度を決めるだけです。GMには、内蔵の難易度表ではなく、そのルールセットの難易度表が伝えられます。難易度はその表の範囲まで指定でき、Marinara独自のルールの1～40を超えることもあります。1～40のままの経路が1つだけあります。保存済みのターンで未実行の判定をロールするフォールバックです。
- Marinaraはルールセットのダイスを振り、キャラクターの**ruleset sheet**(ルールセットのシート)の修正値を加えます。修正値の内訳は、スキルやセーヴが能力値を指定する場合はその能力値修正値、習熟段階のボーナス(習熟ボーナスの倍数、固定値、またはその両方)、シート上の追加ボーナスです。内蔵のスキルボーナスと属性は使いません。
- 結果はルールセットに従います。5e (SRD 5.1)では、判定とセーヴで自然出目の20や1に特別な効果はないため、自然出目の20でも難易度に届かなければ失敗します。
- ルールセットのパッケージがない場合や、ゲーム作成時のものより古い場合、判定は数値なしで保存され、未実行のまま残ります。別のシステムのルールで振られることはありません。

Marinaraは、GMが書いた数値を信用しません。完成済みに見えるタグでも、修正値がシートのものと違う場合、ダイスの数や面数がルールセットと違う場合、数えたダイスがロールモードで採用するダイスと違う場合、ルールセットにない自然出目の結果を主張している場合は、振り直して置き換えます。

### GMが判定に加えられるもの

| GMが書くもの | 効果 |
| --- | --- |
| `who="Name"` | 判定にそのパーティーメンバーのシートを使います。指定がなければ、プレイヤーの判定です。シートのないメンバーは空白のシートでロールします。名前が誰にも一致しない場合や、2人のメンバーに共通する場合は、修正値なしで振ります。自分のキャラクターと同じ名前のメンバーがいても、その名前は自分を指します。Marinaraが別の人のシートを借りることはありません。 |
| `with="Ability"` | スキルやセーヴを別の能力値で振ります。有効なのはルールセットが宣言した能力値だけです。それ以外は無視されます。 |
| `difficulty="Hard"` | 数値の代わりに難易度表の段階名を指定します。Marinaraはその段階の数値に対してロールし、保存された判定には数値が表示されます。不明な名前は無視されます。 |
| ロールプレースホルダー | ルールセットの能力値、スキル、セーヴを指定できます。ルールセットに習熟ボーナスがあれば、`PROF`も使えます。 |

判定の前に自分で振ったダイスが使われるのは、ルールセットがd20を1個振る場合だけです。2d6やダイスプールなど、ほかのダイスを振るルールセットでは無視されます。

### ロールへのシートの効果

- **ロールを変えるチャーム。** GMが判定でチャームの名前を挙げると、Marinaraがそのコストを引き、効果を適用して振ります。選んでいないチャームや、コストを払えないチャームは、効果もなく、何も消費しません。
- **リソースを使ってロールを安定させる。** GMが判定でそのことを指定します。Marinaraがポイントを引き、それで得たものを加えて振ります。プールで払いきれない場合は、何も消費しません。記録には実際に支払った量が表示されます。1回の判定で得られる量はルールセットが決めます。固定の数、シート上の数値、または判定のダイスの数までのいずれかです。
- **常に加わる数値。** すべてのBrawnロールに重い荷物が影響するなど、シート上の数値が特定のロールに適用されるとルールセットが定めている場合、Marinaraは該当するすべての判定にそれを加え、シートが加えた値をダイスカードに表示します。
- **訓練していないスキル。** ルールセットは、訓練していないスキルの判定について、ダイスやポイントを減らす、1段階難しくする、判定できなくする、のいずれかを定められます。試みることのできない判定はロールされず、ナレーションでその旨が語られます。そうしたスキルは、訓練するまでシートに数値が表示されません。
- **負傷。** ルールセットに負傷トラックがあり、そのペナルティがロールに適用されると定めている場合、負傷するとすべての判定が難しくなります。ダイスプールのルールセットでは、その数だけプールからダイスを減らしますが、ルールセットが認める最小のプールを下回ることはありません(ダイスが0個になるのを認めるものもあります)。ダイスを合計するルールセットでは、固定のペナルティになります。判定には適用された量が表示されます。[ルールセットのシート](#the-ruleset-sheet)を参照してください。

GMは、各キャラクターのリソース、状態、休息もシート上で最新に保ちます。Marinaraは、シートが許さない変更を拒否します。

### ダイスプールを振るルールセット

ボーナスを加える代わりにダイスを数えるシステムもあります。シートの数値は振るダイスの数で、十分に高い出目が出たダイスを数えます。

- **シートの数値はダイスの数です。** 評価値3と専門技能2なら、5個のダイスを振ります。シートには「+5」ではなく「5 dice」と表示されます。
- **難易度は成功の数です。** 難しい仕事に必要なのは、合計15ではなく3つの成功です。各段階に必要な成功の数は、ルールセットの難易度表が定めます。
- **Marinaraが振って数えます。** どの出目を数えるか、高い出目でもう1個ダイスを振るか2つと数えるか、低い出目が成功を打ち消すか、何をファンブルや際立った成功とするかは、ルールセットが決めます。ダイスカードにはすべてのダイスが表示され、目標に届いたダイスが強調されます。また、必要な数に対する成功の数が示されます。大きなプールは複数行に折り返され、ダイスを合計していないのに合計が表示されることはありません。
- **GMは1回の判定を調整できます。** ただし、ルールセットが許可する場合に限ります。調整できるのは、ダイスごとの目標を難しくまたは易しくすること、状況に応じたダイスの増減、もう1個振るか2つと数える出目を下げることです。いずれもルールセットの範囲内に収まります。難易度表の段階は、独自のダイスごとの目標を持てます。判定でルールセットの通常とは違う出目を使った場合は、ダイスカードにその旨が表示されます。
- **ダイスを振り直せます。** ルールセットにそのルールがある場合に限ります。GMが判定でそれを指定すると、低い出目のダイスを、1回、または高い出目が出るまで振り直します。リソースを使って同じ効果を得ることもできます。1回のロールで使われる振り直しの方法は1つだけです。2つが当てはまる場合は、より多くのダイスに届く方法が使われます。
- **2つの能力値をまとめて振れます。** ルールセットがそう定めている場合、2つの評価値を1つのプールとして振ります。
- **ファンブルでも結果が出ることがあります。** ダイスの半数以上が低い出目ならファンブルとするルールセットでは、それでも必要な成功を得た判定は結果を保ち、ダイスカードに何かがうまくいかなかったことが追記されます。成功が1つもなければ、クリティカルな失敗です。
- **GMが数値を与えることはありません。** ナレーションに書かれたプールの結果は、Marinara自身のロールで置き換えられます。有利と、事前に振ったダイスは適用されません。
- **各サイズのダイスを1個ずつ見せる仕組みは適用されません。** GMに見せるダイスは20面です。プールの判定は非公開で振られ、ほかの非公開ロールと同じように描写されます。

### ルールセットのその他のロール方法

ダイスを振るのは引き続きMarinaraで、ダイスカードはルールセットに従います。

- **最も高いダイスを採用する。** 数個のダイスを振り、最も高い1個、2個、または3個を読みます。
- **シートの数値に対して振る。** スキルの百分率など、シート上の数値以下を出すように振ります。
- **独自の面を持つダイス。** 面の価値が数字とは異なることがあり、たとえばマイナス、空白、プラスです。また、成功、有利、それらの反対といった記号を持つこともあります。
- **段階で分かれる結果。** 判定は、単なる成功か失敗ではなく、クリティカルな成功や代償を伴う成功などの段階に入ることがあります。ダイスカードにその段階の名前が表示され、GMがそれを描写します。
- **一部の判定だけ別の方法で振る。** ルールセットは、ほとんどの判定を1つの方法で振り、別の方法で振るいくつかの判定を指定できます。

<a id="the-ruleset-sheet"></a>

## ルールセットのシート

ルールセットを使うゲームでは、各キャラクターのシートの先頭に**Ruleset sheet**(ルールセットのシート)のブロックがあります。構成はルールセットによって決まるため、5eのシートとほかのシステムのシートでは見た目が異なります。ルールセットのないゲームには、このブロックはありません。[Character Profiles](party-and-npcs.md#character-profiles)も参照してください。

| 部分 | 仕組み |
| --- | --- |
| **Resources**(リソース) | HP、呪文スロット、クラスリソースなどの、最大値に対する残りを示します。マイナスとプラスのボタンを使うか、数値を入力します。一時的な上乗せがあるリソースには、**Temp**(一時)も表示されます。 |
| **Tracks**(トラック) | 消耗などです。範囲内で段階を上下させます。 |
| **Notes**(メモ) | キャラクターが精神集中している対象などを書く、短いテキスト欄です。 |
| **Conditions**(状態) | オンとオフを切り替えるボタンです。 |
| **States**(ステート) | 形態や構えなど、一覧から一度に1つだけ取る値です。ステートは、ロールに加わるダイスなど、それに連動する数値を変えることがあり、休息で元に戻ることもあります。 |
| **Rest buttons**(休息ボタン) | ルールセットの休息の1つを適用します。休息で何が回復するかはルールセットが定めます。ワンドのチャージなど、アイテムのチャージを戻すこともでき、ボタンの下の行に何が戻ったかが表示されます。5e (SRD 5.1)では、大休憩でHPと呪文スロットが回復し、ヒット・ダイスの半分(最低1個)が戻ります。 |
| ビルドの概要 | 能力値修正値、習熟したスキルとセーヴ、アーマー・クラスなど、ルールセットが選んだ値です。 |

**Wound tracks**(負傷トラック)は、数値の代わりに並ぶマスの列で、ダメージを数えずに印で記録するシステム向けです。各マスには、その負傷段階の名前と、ロールから差し引かれる量が表示されます。

1. ルールセットに複数の種類の負傷がある場合は、先に種類を選びます。
2. **Mark**(印を付ける)か**Clear one**(1つ消す)をクリックします。次の空きマスをクリックして印を追加したり、最後に印の付いたマスをクリックして1つ消したりすることもできます。それ以外のマスはクリックに反応しません。

重い印は上位のマスを取り、軽い印を下に押し下げます。下の行には、適用中のペナルティと、トラックに収まらなかった分が表示されます。ルールセットによっては、マスに名前ではなく番号を付け、ときには自分の評価値と同じ数のマスを持ちます。また、各印を狙ったマスに付けるルールセットもあります。そうしたトラックでは、空いているどのマスでもクリックでき、**Clear one**で消えるのは最も上のマスにある最も軽い印です。また、いっぱいになったトラックは、古い印を重くする代わりに新しい印を拒否します。ルールセットは、シート上の一覧からマスを追加したり、休息や治療で1種類の負傷だけを消したりすることもできます。

### GMによるシートの変更

GMは、語りながらシートを最新の状態に保ちます。キャラクターがリソースを使う、ダメージを受ける、回復する、状態を得るか失う、ステートを変える、休息するといったときに、GMがその変更を記録し、Marinaraがシートと照らし合わせて確認します。空きスロットがないのに呪文を唱えるなど、ありえない変更は拒否されます。何も変わらず、通知でそのことが知らされます。

キャラクターが呪文やクラスの特徴など、ルールセットのカタログから選んだものを使うと、GMがその名前を挙げ、Marinaraが代価をすべて支払います。ルールセットが定めるコストに加えて、それに付随する各カウンターを1回分ずつ消費します。スロットを使う呪文は、ルールセットが指定するレベルのスロットから支払われ、GMはより高いレベルを求めることもできます。Marinaraが自分から高いスロットに上げることはありません。代価の一部でも支払えない場合は全体が拒否され、何も消費されません。初級呪文などコストのないものは、描写されるだけです。

シート上の数値の中には、ルールセットに属するものがあります。最大値がレベルに連動するクラスリソースや、能力値に連動する使用回数は、ルールセットが設定し、シートを編集しても正しい値に保たれます。ルールセットは、リソースやトラックの現在の状態から数値を求めたり、ステートの値ごとに数値を与えたり、一覧の列(荷物に詰めた装備の重さなど)を合計したり、そうした数値でスキルを頭打ちにしたりもできます。そのため、リソースが少ないあいだはスキルが下がることがあります。ゲームのシートにはこれらの現在の値が表示され、判定や戦闘ではその時点の値が使われます。キャラクターカードのシートエディターには読み取るゲームがないため、プレイ開始時の値が表示されます。

こうした変化する値は、それが起きたメッセージに属します。ターンの別のバージョンにスワイプしたり、ターンを再生成したりすると、シートはそのターンの前の状態に戻るので、二重に消費されることはありません。

### ルールセットのシートを編集する

レベルアップのあとなどに、ビルドそのものを変えます。

1. キャラクターのシートを開き、**Edit ruleset sheet**(ルールセットのシートを編集)をクリックします。
2. 能力値、各欄、呪文などの一覧、スキルとセーヴの習熟を変更します。計算される値は入力に合わせて更新されます。ルールセットに段階的なビルダーがある場合は、**Guided**(ガイド付き)を選ぶと各選択(能力値、スキル、初期装備)を順に案内され、**All fields**(すべての項目)を選ぶとすべてを一度に表示します。
3. **Save sheet**(シートを保存)をクリックします。

キャラクターカードと同じエディターです。ルールセットのカタログから行を追加でき、ルールセットが管理するセルは表示されるだけで入力できず、ルールセットの文章が変わった一覧には**Review**(確認)が表示されます。保存で変わるのは、このゲームのコピーだけです。キャラクターやペルソナに保存されたシートが、ゲームによって変更されることはありません。

別の**Edit card**(カードを編集)ボタン([シートの手動編集](party-and-npcs.md#edit-a-sheet-by-hand)を参照)は、汎用のシート(クラス、能力、長所)を編集し、ルールセットのシートには触れません。

うまくいかず、ルールセットのパッケージが削除されているか、ゲーム作成時のものより古い場合は、ブロックの代わりに通知が表示されます。パッケージを再びインストールするまで、判定はロールできません。

## パーティーシートと進行クロック

ルールセットによっては、クルーや一団など、パーティー全体のシートを持つものがあります。ゲーム画面のマップの近くに、ルールセット独自の呼び名で表示されます。名前をクリックすると開きます。GMは各キャラクターのシートと同じようにこのシートも最新の状態に保ち、ルールセットが許可していれば自分でも編集できます。編集中に誰かがパーティーシートを保存した場合は、その人のバージョンが表示されます。**Save**(保存)を押すと自分のバージョンで置き換え、**Cancel**(キャンセル)を押すとその人のバージョンを残します。

ルールセットは**Progress clocks**(進行クロック)も使えます。警報が広まっていく様子など、何かが積み重なるにつれてGMが埋めていく、区切られた円です。マップの近くに、埋まった区切りの数とともに表示され、いっぱいになると**Done**(完了)と表示されます。
