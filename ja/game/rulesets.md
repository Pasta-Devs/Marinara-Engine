# Game Mode: ルールセットで遊ぶ

ルールセットは卓上ゲームの仕組みをGame Modeに伝えます。判定で振るダイス、キャラクターシートの項目、消費するリソース、休息で回復するものに加え、一部のルールセットでは戦闘全体の進め方も定めます。このガイドでは、ルールセットの入手方法、ゲームで使うルールセットの選び方、ルールセットで遊ぶと何が変わるかを説明します。ルールセットを使わないゲームは、ほかのGame Modeガイドで説明しているMarinara独自のルールで進みます。

<a id="getting-a-ruleset"></a>

## ルールセットの入手

ルールセットの入手先は2つです。5e (SRD 5.1)などの公式のルールセットは**Agent Organizer (エージェント管理)**からインストールします。そこでは**Rules**の印が付いています。コミュニティ製のルールセットはファイルか作者のGitHubリポジトリーからインポートし、`local/ember-roads`や`alice/v20`のように入手元ごとに分類されます。インポートには、エージェントのインポートと同じ**Allow custom Agent imports**のスイッチを使います。このスイッチがオフのあいだ、インポートしたルールセットは新しいゲームでは選べませんが、すでに使っているゲームは引き続き動きます。インポートしたルールセットを使うゲームは、必ず作成したときとまったく同じバージョンでプレイされます。自分で作るには[Game Modeのルールセットを作成する](../extending/writing-rulesets.md)を参照してください。

### 言語

スキル名、呪文、Game Master向けのテキストなど、ルールセット自身のテキストは**Settings**(設定)で指定した言語に従います。公式のルールセットはその言語の翻訳だけをダウンロードし、言語を切り替えると新しい言語の翻訳を取得します。翻訳されていない言語では英語で表示します。ファイルからインポートしたルールセットは、インポート時に設定されていた言語の翻訳だけを保持します。切り替えるには、ファイルを再度インポートしてください。

<a id="choosing-a-ruleset-for-a-game"></a>

## ゲームで使うルールセットの選択

**Rules**(ルール)は、ルールセットが1つ以上インストールされている場合に、新しいゲームを作るときだけ表示されます。**Combat Preference**とは別の設定です。一方は判定とキャラクターシートの仕組みを、もう一方は戦闘の表示方法を決めます。

- **Marinara's own rules**(Marinara独自のルール)がデフォルトです。内蔵のd20判定と6つの能力値のシートを使います。
- **5e (SRD 5.1)**などの**ルールセット**では、対応範囲の短い説明と、戦闘の動作を説明する1行が表示されます。独自に戦闘を解決するルールセットでは、その旨が示されます。シートだけを提供するものでは、シート自身の体力、エネルギー、能力を使ってMarinaraの戦闘を行うと説明されます。どちらでもないものでは、Marinaraの戦闘を行うと説明され、選んだ**Combat Preference**も表示されます。

ルールセットはゲームの作成時に決まり、そのゲームで使い続けます。あとから変更したり追加したりすることはできません。

一部のルールセットには**layers**(レイヤー)があります。Low magicやHard winterのような名前付きのバリエーションで、ルールセットの下にスイッチとして表示され、それぞれが何をするかを説明する1行が付きます。レイヤーは、難易度を厳しくしたり、キャラクターシートの選択肢を絞ったり、シートエディターの選択画面から用意された項目の一部を外したり、どの店が何を売るかやどんな宝物が出るかを変えたり、Game Masterに追加の指示を与えたりできます。指示には、セットアップ時に作る世界についてのものも含まれます。互いに両立しないレイヤーもあり、選べないものはウィザードで無効になります。レイヤーはルールセット自体とまったく同じく、ゲームが始まると固定されます。レイヤーが取り除くものをすでに使っているシートは、そのまま保持されます。

ルールセットを選ぶと、**Party**のステップで、選択欄の下にペルソナとパーティーメンバーが並びます。それぞれについて、そのルールセットのシートを持っているなら**Has a sheet**(シートあり)、空のシートで始まるなら**Starts on a blank sheet**(空白のシートで開始)と表示されます。シートは、キャラクターエディターかペルソナエディターの**Stats**で追加します([ルールセットのシート](../characters/colors-and-stats.md#ruleset-sheets)を参照)。世界が生成されるときに、ゲームは各シートのコピーを取ります。ゲームの中で変えたことが、キャラクターやペルソナに戻ることはありません。シートのないメンバーには、すべての値がルールセットのデフォルトになった空のシートが渡されます。世界の生成で数値が作られることはありません。

共有したセットアップファイルは、使ったルールセットを覚えています。インポートしたファイルのルールセットを持っていない場合や、古いバージョンしか持っていない場合は、ウィザードがどのルールセットだったかを知らせます。そのルールセットをインストールして選ばない限り、ゲームはMarinara独自のルールを使います。

<a id="what-happens-in-battles"></a>

## 戦闘での動作

ルールセットが戦闘で何をするかは、その記述によって決まります。どれに該当するかは、セットアップウィザードのルールセットの下の行に表示されます。

| ルールセット | 戦闘 |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 5e (SRD 5.1)など、独自に戦闘を解決するもの | ルールセット独自のルールに従い、専用の戦闘画面で進みます。[ルールセットでの戦闘](fighting-on-a-ruleset.md)を参照してください。 |
| 戦闘にシートを提供するもの | シートの体力、呪文スロット、能力を使ってMarinara独自の戦闘を行います。下記を参照してください。 |
| 戦闘について何も定めていないもの | ルールセットを使わないゲームとまったく同じMarinara独自の戦闘を行います。[戦闘](combat.md)を参照してください。 |

ルールセットが戦闘にシートを提供する場合、パーティーの各メンバーは、ルールセットが戦闘用に設定したリソースプールと呪文スロットを、現在のシートの状態のまま持って戦闘を始めます。ルールセットのカタログから選んだ能力は、Marinaraの戦闘で使えるものだけがスキルになります。戦闘外のことだけを説明する項目、リアクション、戦闘で支払えないコストを持つ項目は除外されます。HPはシート上の数値そのままではなく、最大値に対する割合として引き継がれます。シートで体力が半分のキャラクターは、戦闘画面で与えられる体力バーの半分の状態で戦闘を始めます。戦闘中の数値はMarinaraのものだからです。シートの体力が「9」のキャラクターが、一撃で「12」ダメージを受ける戦闘に放り込まれることはありません。戦闘が終わると、失った体力や回復した体力は同じ方法でシートに戻され、消費したスロットとリソースはそのまま書き戻されます。それ以外の戦闘の仕組みは変わりません。ダイス計算は引き続きMarinaraのもので([戦闘の計算方法](combat.md#how-combat-math-works)を参照)、卓上システムの攻撃ロール、セーヴィングスロー、精神集中は適用されません。戦闘が始まったメッセージを削除して戦闘から抜けた場合は、その戦闘は起こらなかったことになるため、何も書き戻されません。

<a id="checks-on-a-ruleset"></a>

## ルールセットでの判定

ルールセットを使う場合も、Game Masterはほかのゲームと同じように判定を求めます([スキル判定](dice-and-skill-checks.md#skill-checks)を参照)。ただし、ダイスの振り方はルールセットが決めます。

- Game Masterは引き続きスキルまたはセーヴの名前と難易度だけを指定します。組み込みの難易度表の代わりに、そのルールセットの難易度段階が伝えられます。難易度はその段階の範囲まで指定でき、Marinara独自の1～40を超えることもあります。ただし、保存済みターンで未実行の判定をロールするフォールバック経路だけは、ルールセットのゲームでも1～40です。
- Engineはルールセットのダイスを振り、キャラクターの**ルールセットのシート**の修正値を加えます。内訳はルールセットの宣言によって決まり、スキルやセーヴが能力値を指定する場合はその修正値、習熟段階のボーナス(習熟ボーナスの倍数、固定値、または両方)、シートに入力された追加ボーナスを使います。組み込みのスキルボーナスと属性は使いません。
- 仲間の判定もできます。Game Masterがタグに`who="Name"`を加えると、Engineはそのキャラクターのシートを使います。`who`がなければプレイヤーの判定です。シートがまだない仲間は、ルールセットの既定値を持つ空のシートでロールします。名前がパーティーの誰にも一致しない場合や2人に一致する場合は、一切の修正値なしで振ります。例外は自身のキャラクター名で、仲間と同名でも自身のシートを使います。Engineが別人のシートを借りることはありません。
- 自然出目はルールセットに従います。5e (SRD 5.1)では、判定とセーヴで自然出目が「20」や「1」であっても特殊効果はありません。自然出目が「20」でも難易度に届かなければ失敗します。これは意図的にMarinara独自のルールと異なります。
- Game Master自身が書く数値は信頼されません。完成済みに見えるタグでも、修正値がシートと異なる、ダイスの数や面数がルールセットと異なる、採用したダイスがロールモードの指定と異なる、またはルールセットにない自然出目の効果を主張する場合は、振り直して置き換えます。
- 事前に自身で振ったダイスを使えるのは、ルールセットがd20を1個振る場合だけです。2d6やダイスプールなどの場合は無視し、通常どおり振ります。
- Game Masterはタグに`with="Ability"`を加え、通常とは異なる能力値でスキルやセーヴを判定できます。ルールセットで宣言された能力値だけが有効で、それ以外は無視して本来の能力値を使います。
- Game Masterは難易度を数値で書く代わりに、`difficulty="Hard"`のように難易度表の段階名で指定することもできます。Engineはその段階の数値に対してロールし、保存された判定には数値が表示されます。難易度表にない名前は無視されます。
- ロールプレースホルダーではルールセットの能力値、スキル、セーヴを指定でき、習熟ボーナスがあれば`PROF`も使えます。
- ルールセットのパッケージがないか、ゲーム作成時より古い場合、判定は数値なしで保存され、未実行のまま残ります。別のシステムのルールで振ることはありません。
- 失敗したダイスを振り直すチャームなど、シート上の要素がロールを変える場合、Game Masterが判定でその名前を指定し、あとはEngineが処理します。チャームのコストを引き、効果を適用して振ります。未取得のチャームやコストを払えないチャームは効果も消費もありません。
- ロールを安定させるためにリソースを使えるルールセットでは、Game Masterが判定自体にその消費を指定し、Engineがポイントの支払いと得られる効果の加算、ロールをまとめて行います。プールが不足していれば何も消費せず、通常のロールになります。記録には要求量ではなく実際に支払った量が表示されます。1回の判定で得られる量はルールセットが決めます。固定の数、シート上の数値、または判定のダイス数までのいずれかです。
- すべてのBrawnロールに重い荷物が影響するなど、シート上の数値が特定のロールに常に加わるとルールセットが定めている場合、Engineは該当するすべての判定にそれを加え、シートが加えた値をダイスカードに表示します。
- ルールセットは、スキルの訓練がない場合に判定がどうなるかを定められます。ダイスやポイントが減る、1段階難しくなる、そもそも判定できない、のいずれかです。訓練なしでは試みられない判定はロールされず、結果を表示する代わりにナレーションでその旨が語られます。そうしたスキルは、訓練するまでシートに数値が表示されません。
- 負傷トラックのペナルティをロールに適用するルールセットでは、負傷するとすべての判定が難しくなります。ダイスプール方式ではその数だけダイスを減らしますが、ルールセットの最小プールを下回りません。システムによっては最小が0です。合計方式では固定のペナルティとして適用します。いずれも判定に適用量が表示されるため、ダイスが減った理由を確認できます。[ルールセットのシート](#the-ruleset-sheet)を参照してください。
- Game Masterは各キャラクターのリソース、状態、休息もシートに反映し、Engineはシートの許可しない変更を拒否します。[ルールセットのシート](#the-ruleset-sheet)を参照してください。

### ダイスプールを振るルールセット

ロールにボーナスを加える代わりに、シートの数値だけダイスを振り、目標以上の出目を数えるシステムもあります。この方式のルールセットも作成でき、そのゲームは少し異なります。

- **シートの数値はダイス数です。** 評価値3と専門技能2なら5個振ります。編集画面でもGame Masterに渡す内容でも、"+5"ではなく"5 dice"と表示されます。
- **難易度は成功数です。** 難しい仕事に必要なのは合計15ではなく成功3回です。各段階に必要な成功数はルールセットの難易度表が定めます。
- **Engineが振って数えます。** どの出目を成功とするか、高い出目で追加ダイスを振るか2成功とするか、低い出目で成功を相殺するか、ファンブルや突出した成功の条件など、すべてルールセットが定めます。ダイスカードには振ったすべてのダイスが表示され、目標に届いたものと届かなかったものを区別し、必要数に対する成功数を示します。大きなプールは縮小せず複数行に折り返し、加算していないダイスの合計を表示することはありません。
- **Game Masterは個別の判定を調整できます。** ルールセットが許可する場合、各ダイスの目標を難しくも易しくもでき、状況に応じてダイスを増減でき、追加で振るか2成功とする出目を下げることもできます。いずれもルールセットの宣言範囲内に制限されます。難易度表の段階は独自のダイスごとの目標を持つことができ、Game Masterがその段階を選んだときに適用されます。ルールセットの通常とは異なる出目で追加ダイスを振ったり2成功としたりした場合は、ダイスカードにその旨が表示されます。
- **ダイスを振り直せます。** ルールセットにそのルールがある場合、状況に応じてGame Masterが判定でそれを指定し、低い出目のダイスを1回、または高い出目が出るまで振り直します。リソースを消費して同じ効果を得ることもできます。1回のロールで振り直しに使われる方法は1つだけで、2つが当てはまる場合は、より多くのダイスに届く方法が使われます。
- **2つの能力値をまとめて振れます。** ルールセットがそう定めている場合、能力値判定に2つ目の能力値のダイスを加え、2つの評価値を1つのプールとして振れます。
- **結果と同時に何かがうまくいかないルールセットもあります。** ダイスの半数以上が低い出目ならファンブルとするルールセットでは、それでも必要な成功数を得た判定は結果を保ち、ダイスカードに、同時に何かがうまくいかなかったことが追記されます。成功が1つもなければクリティカルな失敗です。
- **Game Masterは数値を与えません。** ナレーションに書かれたプールの結果は必ずEngine自身のロールで置き換えます。有利も、事前に自身で振ったダイスも適用されません。
- **Game Masterに各面数のダイスを1個見せる設定は、これらの判定には適用されません。** 見せるダイスは20面です。プール判定はEngineが事前非公開で振り、ほかの非公開ロールと同じように描写します。

### ルールセットのその他のロール方法

ルールセットは、ほかの方法で判定を振ることもできます。ダイスを振るのは引き続きEngineで、ダイスカードはルールセットに従います。

- **最も高いダイスを採用。** 数個のダイスを振り、ルールセットの指定に従って、最も高い1個、2個、または3個を読みます。
- **シートの数値以下を出す。** ダイスにボーナスを加える代わりに、スキルの百分率などシート上の数値以下を出すように振ります。
- **独自の面を持つダイス。** 面の価値が数字とは異なる場合があり、たとえばマイナス、空白、プラスです。数字の代わりに、成功、有利、それらの反対といった記号を持つダイスもあります。
- **段階で分かれる結果。** 判定は単なる成功か失敗ではなく、クリティカルな成功や代償を伴う成功など、複数の結果のいずれかになることがあります。ダイスカードにその段階の名前が表示され、Game Masterがそれを描写します。
- **一部の判定だけ別の方法で振る。** ルールセットはほとんどの判定を1つの方法で振り、いくつかの判定だけを別の方法で振るよう指定できます。

<a id="the-ruleset-sheet"></a>

## ゲーム中のルールセットシート

ルールセットを使うゲームでは、各キャラクターのシートの先頭に**Ruleset sheet**(ルールセットのシート)のブロックが表示されます。構成はルールセットによって決まるため、5eのシートとほかのシステムのシートでは見た目が異なります。ルールセットのないゲームには、このブロックはありません。

- **Resources**(リソース)は、HP、呪文スロット、クラスリソースなどの残りを最大値とともに示します。マイナスとプラスのボタンを使うか、数値を入力します。一時的な上乗せがあるリソースには、**Temp**(一時)の欄も表示されます。
- **Tracks**(トラック)は、消耗などのように、範囲内で段階が上下します。
- **Wound tracks**(負傷トラック)は、ダメージを数値で数えずに印で記録するシステム向けの、マスの列です。各マスには負傷段階の名前と、ロールにかかるペナルティが表示されます。ルールセットに複数の負傷種別がある場合は先に種別を選び、**Mark**(印を付ける)または**Clear one**(1つ消す)を使います。次の空きマスをクリックして印を追加したり、最後に印の付いたマスをクリックして1つ消したりすることもできます。それ以外のマスはクリックに反応しません。重い負傷の印は上位のマスを取り、軽い印を下に押し下げます。下の行には適用中のペナルティと、トラックに収まらなかった分が表示されます。ルールセットによっては、マスに名前ではなく番号を付け、ときにはキャラクター自身の評価値と同じ数のマスを持ちます。また、各印を狙ったマスに付けるルールセットもあります。そうしたトラックでは、空いているどのマスでもクリックでき、**Clear one**で消えるのは最も上のマスにある最も軽い印です。いっぱいになったトラックは、古い印を重くする代わりに新しい印を受け付けません。ルールセットは、シート上の一覧からトラックにマスを追加したり、休息や治療で1種類の負傷だけを消したりすることもできます。ルールセットで指定されていれば、そのペナルティがロールに適用されます。ダイスプールからダイスを減らすか、合計値のロールに加算し、ダイスカードに適用量が表示されます。
- **Notes**(メモ)は、キャラクターが精神集中している対象などを書く短いテキスト欄です。
- **Conditions**(状態)は、オンとオフを切り替えるボタンです。
- **States**(ステート)は、形態や構えなど、一覧の中から一度に1つだけ取る値です。一覧から値を選びます。ステートは、構えがロールに加えるダイスのように、それに続く数値を変えることがあり、休息で元に戻ることもあります。
- **Rest buttons**(休息ボタン)は、ルールセットの休息の1つを適用します。休息で何が回復するかはルールセットが定めます。休息では、ワンドのチャージなど、キャラクターが持つアイテムのチャージが戻ることもあり、そのときはボタンの下の行に何が戻ったかが表示されます。5e (SRD 5.1)では、大休憩でHPと呪文スロットが回復し、キャラクターのヒット・ダイスの半分(最低1個)が戻ります。
- その下には、能力値修正値、習熟したスキルとセーヴ、アーマー・クラスなどルールセットが選んだいくつかの値をまとめた、ビルドの短い概要があります。

Game Masterは、語りながら同じシートを最新の状態に保ちます。キャラクターがリソースを使う、ダメージを受ける、回復する、状態を得るか失う、ステートを変える、休息するといったときに、その変更を記録し、Engineがシートと照らし合わせて確認します。空きスロットがないのに呪文を唱えるなど、ありえない変更は拒否されます。何も変わらず、通知でそのことが知らされます。

キャラクターが呪文やクラスの特徴など、ルールセットのカタログから選んだものを使うと、Game Masterがその名前を挙げ、Engineが代価をすべて支払います。ルールセットが定めるコストに加えて、それに付随する各カウンターの使用回数を1回分ずつ消費します。スロットを使う呪文は、ルールセットがその呪文に定めるレベルのスロットから支払われ、Game Masterは代わりに高いレベルを求めることもできます。Engineが自分から高いスロットに上げることはありません。代価の一部でも支払えない場合は全体が拒否され、何も消費されません。初級呪文などコストのないものは、描写されるだけです。

シート上の数値の中には、自分ではなくルールセットに属するものがあります。最大値がレベルに連動するクラスリソースや、能力値に連動する使用回数は、ルールセットが設定し、シートを編集しても正しい値に保たれます。

計算される値の中には、プレイの進行に連動するものもあります。ルールセットは、リソースやトラックの現在の状態から数値を求めたり、ステートの値ごとに数値を与えたり、荷物に詰めた装備の重さのように一覧の列を合計したりできます。また、スキルをそうした数値で頭打ちにすることもでき、リソースが少ない間はスキルが下がることがあります。これらはゲームのシートに現在の値を表示し、判定や戦闘ではその時点の値が使われます。キャラクターカードのシートエディターには読み取るゲームがないため、プレイ開始時の値が表示されます。

こうした変化する値は、それが起きたメッセージに属します。ターンの別のバージョンにスワイプしたり再生成したりすると、シートはそのターンの前の状態に戻るので、二重に消費されることはありません。

レベルアップのあとなど、ビルドそのものを変えるには**Edit sheet**(シートを編集)をクリックします。能力値、各欄、呪文などの一覧、スキルとセーヴの習熟を編集できます。計算される値は入力に合わせて更新されます。キャラクターカードと同じエディターなので、ここでもルールセットのカタログから行を追加でき、ルールセットが管理するセルは表示されるだけで入力できず、ルールセットの文章が変わった一覧には**Review**(確認)ボタンが表示されます。ルールセットに段階的なビルダーがある場合、エディターには**All fields**(すべての項目)と並んで**Guided**(ガイド付き)が表示されます。**Guided**は、能力値、スキル、初期装備などの選択を1つずつ案内し、各ステップでまだ何が必要かを示します。**All fields**はすべてを一度に表示します。終わったら**Save sheet**(シートを保存)をクリックします。変更されるのは、このゲームのシートのコピーだけです。キャラクターやペルソナに保存されたシートが、ゲームによって変更されることはありません。

別の**Edit Sheet**ボタン([シートの手動編集](party-and-npcs.md#edit-a-sheet-by-hand)を参照)は、引き続き汎用のシート(クラス、能力、長所など)を編集し、ルールセットのシートには触れません。

ルールセットのパッケージが削除された場合や、インストールされているものがゲーム作成時より古い場合は、ブロックの代わりに通知が表示され、パッケージを再びインストールするまで判定はロールできません。

## パーティーシートと進行クロック

ルールセットによっては、クルーや一団など、パーティー全体のシートを持つものがあります。ゲーム画面のマップの近くに、ルールセット独自の呼び名で表示されます。名前をクリックすると開きます。Game Masterは各キャラクターのシートと同じようにこのシートも最新の状態に保ち、ルールセットが許可していれば自分でも編集できます。編集中に誰かがパーティーシートを保存した場合は、その人のバージョンが表示されます。**Save**(保存)を押すと自分のバージョンで置き換え、**Cancel**(キャンセル)を押すとその人のバージョンを残します。

ルールセットは**Progress clocks**(進行クロック)も使えます。警報が広まっていく様子など、何かが積み重なるにつれてGame Masterが埋めていく、区切られた円です。マップの近くに、埋まった区切りの数とともに表示され、いっぱいになると**Done**(完了)と表示されます。
