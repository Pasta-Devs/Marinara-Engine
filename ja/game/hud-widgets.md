# Game Mode: HUDウィジェット

HUDウィジェットは、ゲーム画面の左右の端に並ぶ小さなパネルです。体力バー、所持金のカウンター、仲間の信頼度などを追跡します。HUDはheads-up displayの略です。ウィジェットはゲームごとにあり、RoleplayのHUDトラッカーとは別のものです([Roleplay HUDとトラッカー](../roleplay/hud-and-trackers.md)を参照)。

1つのゲームで使えるウィジェットは合計4つまでで、左右への振り分けは自由です。ウィジェットが使われるのは、そのゲームで**Custom HUD Widgets**(カスタムHUDウィジェット)がオンのときだけです。設定ウィザードではデフォルトでオンになっています。オンの場合、ゲームマスター(GM)が世界を組み立てながら、最初のウィジェット一式を設計します。

## ウィジェットの種類

GMは、自分が作る各ウィジェットに種類を選びます。手作業でウィジェットを作るときは、種類を自分で選べます。

| ウィジェットの種類 | 表示される内容 |
| --- | --- |
| **Progress Bar**(進捗バー) | 体力やスタミナのように、最大値に対する現在値を横棒で表します。 |
| **Gauge**(ゲージ) | 最大値に対する現在値を半円のメーターで表します。 |
| **Relationship Meter**(関係メーター) | 節目のマーカーとラベルが付いたバーです。NPCの信頼度や絆の表示に向いています。 |
| **Counter**(カウンター) | 所持金、経過日数、撃破数のような数値を大きく1つ表示します。 |
| **Stat Block**(ステータス表) | STRやDEX、状態を表す単語など、名前付きの項目と値を小さな表にまとめます。 |
| **List**(リスト) | 進行中の目標のように、短い箇条書きのテキストを並べます。 |
| **Inventory Grid**(インベントリーグリッド) | アイテム枠を格子状に並べます。カテゴリーのタブと個数の表示も付けられます。 |
| **Timer**(タイマー) | 分と秒のカウントダウン時計です。リアルタイムで減らすこともできます。 |

## ゲーム開始前にウィジェットを確認する

カスタムウィジェットがある場合、ゲーム画面の**Start Game**(ゲーム開始)の下に**Review Starting Widgets**(開始時ウィジェットの確認)ボタンがあります。クリックすると、開始する前に**Review Starting Widgets**ウィンドウが開きます。ここには開始時のウィジェットがすべて並ぶので、ゲームに確定される前に調整できます。

1. ウィジェットの**Edit**(編集)を押して、開始時の値を変えたり、**Stat Block**の項目名を付け直したりします。
2. **Remove**(削除)を押して、不要なウィジェットを取り除きます。
3. **Start Game**を押すと、表示されているウィジェットのままプレイを始めます。開始せずにウィンドウを閉じるには、**Back**(戻る)を押します。

進行中のゲームで新しいセッションを始めるときにも、よく似たウィンドウ**Prepare Next Session Widgets**(次のセッションのウィジェット準備)が開きます。**Start Game**の代わりに**Start Next Session**(次のセッションを開始)が、**Back**の代わりに**Cancel**(キャンセル)があります。

## プレイ中にウィジェットを編集する

GMは物語の進行に合わせてウィジェットの値を更新します。更新を取りこぼしたときは、手作業でウィジェットを直してください。

1. 画面の左端または右端にあるウィジェットのパネルを探します。
2. ウィジェットのヘッダーにある鉛筆(**Edit**)ボタンをクリックします。
3. 編集ウィンドウで値を変更します。たとえばバーなら**Maximum value**(最大値)です。
4. **Save Changes**(変更を保存)をクリックします。

ウィジェットのヘッダーをクリックすると、中身を折りたたんだり展開したりできます。

## パネルを移動して固定する

ウィジェットのパネルは、デフォルトで位置が固定されています。各パネルのヘッダーには鍵アイコンがあります。

1. 鍵アイコンをクリックして固定を解除します。薄い枠線が表示され、移動できることがわかります。
2. パネルを新しい位置までドラッグします。
3. もう一度鍵アイコンをクリックすると固定されます。

パネルをデフォルトの位置に戻すには、鍵アイコンをダブルクリックするか、アイコンにフォーカスがある状態で<kbd>R</kbd>を押します。位置と固定の状態は、ゲームごとにパネル単位で記憶されます。配置はほかのゲームには引き継がれません。

スマートフォンでは、ウィジェットはパネルではなくピル型の小さなボタンとして表示されます。ピルをタップするとそのウィジェットが開き、Xをタップすると閉じます。

## ウィジェットを自分で作る

GMに任せず、ウィジェットを自分で設計することもできます。手動のエディターは、次のどちらかで開きます。

- 設定ウィザード: **Custom HUD Widgets**をオンにし、続けて**Build Widget Setup**(ウィジェット構成の作成)をオンにします。下にエディターが表示されます。
- 進行中のゲーム: **Chat Settings**(チャット設定)を開き、**Widgets**(ウィジェット)セクションを開きます。

1. ドロップダウンからウィジェットの種類を選び、**Add**(追加)を押します。
2. **Icon**(アイコン、短い記号や絵文字)、**Label**(ラベル)、**Type**(種類)、**Side**(表示位置、**Left HUD**または**Right HUD**)、**Accent**(アクセント、色)を設定します。
3. その種類の項目を入力します。バーは**Value**(値)と**Max**(最大)、カウンターは**Count**(カウント)、インベントリーグリッドは**Slots**(枠数)と**Contents**(中身)、タイマーは**Seconds**(秒数)と**Running**(動作中)を使います。
4. **Chat Settings**では、**Save Widgets**(ウィジェットの保存)を押すと変更が反映されます。**Reset**(リセット)を押すと、未保存の編集を取り消せます。

エディターには、使える4つのうち何個のウィジェットを使ったかが表示されます。

## インポートとエクスポートでウィジェットを共有する

ウィジェットの構成はファイルに保存して、別のゲームに読み込めます。設定ウィザードと**Chat Settings**の**Widgets**セクションの両方に、このためのボタンがあります。

1. **Export Widgets**(ウィジェットのエクスポート)を押すと、ウィジェットがJSONファイル(文字だけで書かれたデータ形式)としてダウンロードされます。
2. 別のゲームで**Import Widgets**(ウィジェットのインポート)を押し、そのファイルを選びます。
3. **Chat Settings**では、**Save Widgets**を押して、読み込んだウィジェットを反映します。
