# Game Mode: パーティーとNPC

このガイドでは、Game Modeのキャンペーンに登場する人々、つまりパーティーメンバーと、ゲームマスターが登場させるNPC(プレイヤー以外のキャラクター)を説明します。パーティーメンバーのキャラクターシートを開く方法、編集や再生成のしかた、NPCの好感度ラベルを含むAdventure Journalの読み方がわかります。2つのゲームマスターのモードについても取り上げます。

Game ModeはMarinara Engineのチャットモードの1つです。AIのゲームマスター(GM)が進行する1人用のRPG(ロールプレイングゲーム)を遊べます。準備と基本については[Game Mode: はじめに](getting-started.md)を参照してください。

## パーティーバー

パーティーバーには、一緒に旅をしているキャラクターが並びます。ゲーム画面の上部近くにあります。

デスクトップの画面では、小さなキャラクターの顔画像が横一列に並びます。スマートフォンでは、バーが1つのアバターにまとまります。パーティーメンバーが2人以上いる場合、そのアバターに人数のバッジが付きます。タップするとパーティーメンバーの一覧が開きます。メンバーが1人だけのときは、アバターをタップするとそのキャラクターのシートが直接開きます。

パーティーバーでできる操作は次のとおりです。

1. 顔画像をクリックまたはタップすると、そのキャラクターのキャラクターシートが開きます。
2. デスクトップで顔画像にマウスを重ねると、小さな**X**ボタンが現れます。
3. **X**をクリックすると、そのキャラクターをパーティーから外せます。

ゲームマスターが仲間にしたキャラクターは、設定のときに加わった場合でも物語の途中で加わった場合でも、すべて外せます。自分のペルソナは自分が演じるキャラクターです。**X**ボタンがないため、自分をパーティーから外すことはできません。

## キャラクターシート

キャラクターシートは、パーティーメンバー1人分のゲーム上の情報をまとめたものです。キャラクターカードとは別物です。ゲームマスターが、そのキャラクターと現在の物語をもとに書きます。

シートは、パーティーバーでそのキャラクターの顔画像をクリックすると開きます。シートに表示されるのは、内容のある項目だけです。

- **Attributes**(能力値): STR、DEX、CONのようなテーブルトークRPG風の数値です。それぞれに修正値が付きます。
- **Stats**(ステータス): HPやMPのようなリソースのバーです。
- **Abilities**(能力): そのキャラクターにできることです。
- **Strengths**(長所)と**Weaknesses**(短所): 短い一覧です。
- **Details**(詳細): Skills、Weapon、Factionのような補足情報です。
- **Inventory**(インベントリー): そのキャラクターが持っているアイテムです。
- **Traits**(特性): そのほかの自由な項目です。

加わったばかりのキャラクターでは、「Character data will populate as the story progresses.」と表示されることがあります。シートは遊び進めるにつれて埋まっていきます。

### AIによるシートの再生成

**Regenerate Sheet**(シートの再生成)をクリックすると、そのキャラクターのシートをAIが書き直します。キャラクターの内容と現在のゲームのコンテキストが使われます。物語の中でキャラクターが大きく変わったあとに便利です。

### シートの手動編集

**Edit Sheet**(シートの編集)をクリックすると、自分でシートを書き換えられます。編集モードで設定できるのは次の内容です。

- **Sheet Details**(シートの詳細)にある**Class**(クラス)と短い説明。
- **RPG Attributes**(RPG能力値): **Enable**(有効化)をオンにすると、HPのようなリソースのバーと能力値を管理できます。**Add Pool**(バーの追加)でバーを1つ増やします(名前、現在値、最大値、色)。**Add Attribute**(能力値の追加)でSTRのような数値を増やします。
- **Abilities**、**Strengths**、**Weaknesses**: **Add**(追加)で1行足します。
- **Details**: **Add Detail**(詳細の追加)でラベル付きの情報を足します。

入力が終わったら**Save Sheet**(シートの保存)をクリックします。変更を捨てる場合は**Cancel**(キャンセル)をクリックします。

### ゲーム中のルールセットシート

[ルールセットを使うゲーム](dice-and-skill-checks.md#games-that-use-a-ruleset)では、各キャラクターのシートの先頭に **Ruleset sheet** が表示されます。構成はセット次第で、セットなしのゲームにはありません。

- **Resources** はHP、呪文スロット、クラスリソースなどの現在値と最大値です。プラス・マイナスまたは直接入力で変更します。**Temp** は一時的な余裕値です。
- **Tracks** は消耗などの範囲付きカウンターです。
- **Wound tracks**(負傷トラック)は、ダメージを数値で数えずに印で記録するシステム向けの、マスの列です。各マスには負傷段階の名前と、ロールにかかるペナルティが表示されます。ルールセットに複数の負傷種別がある場合は先に種別を選び、**Mark**(印を付ける)または**Clear one**(1つ消す)を使います。次の空きマスをクリックして印を追加したり、最後に印の付いたマスをクリックして1つ消したりすることもできます。それ以外のマスはクリックに反応しません。重い負傷の印は上位のマスを取り、軽い印を下に押し下げます。下の行には適用中のペナルティと、トラックに収まらなかった分が表示されます。ルールセットで指定されていれば、そのペナルティがロールに適用されます。ダイスプールからダイスを減らすか、合計値のロールに加算し、ダイスカードに適用量が表示されます。
- **Notes** は精神集中などの短いメモです。
- **Conditions** は状態のオン・オフです。
- 休息はセットが指定する値を回復します。5e (SRD 5.1)の大休憩はHP、呪文スロット、ヒット・ダイスの半分（最低1個）を回復します。
- 下には能力値、習熟した技能とセーヴ、アーマー・クラスなどの選ばれた値の概要があります。

GMは消費、ダメージ、回復、状態、休息を記録でき、エンジンが検証します。空きスロットがない呪文など、無効な操作は通知とともに全体が拒否されます。

カタログ項目の使用は、費用全額と関連する各行カウンターの1回分を支払います。呪文スロットは指定レベルを使います。GMは高レベルを指定できますが、エンジンが自動で上げることはありません。費用の一部でも不足すれば何も消費しません。初級呪文など無料の行動は描写だけです。レベル連動の最大値や能力値連動の回数は編集時に再計算します。

状態はメッセージに属します。返信候補の切り替えや再生成ではターン前に戻し、二重消費を防ぎます。**Edit sheet** はカードと同じ編集画面とカタログで、設定、一覧、習熟、ボーナスを編集します。読み取り専用値や新しい文章の **Review** も同じです。**Save sheet** が変えるのはこのゲームのコピーだけです。別の **Edit Sheet** は従来の汎用シートを編集します。パッケージがないか古ければ警告し、復元まで判定を止めます。

## パーティーメンバーの加入と離脱

物語の展開に合わせて、パーティーの顔ぶれを決めるのはゲームマスターです。仲間を手動で追加するボタンはありません。GMがその場面の出来事に応じて、語りの中でパーティーメンバーを増やしたり減らしたりします。

自分から仲間を外したいときは、前述のとおりパーティーバーの**X**ボタンを使います。この方法で自分のペルソナを外すことはできません。

## Adventure Journal(冒険の記録)

Adventure Journalは、キャンペーンの記録が積み重なっていく場所です。AIが書くのではなく、保存されたゲームの出来事から組み立てられるため、内容は事実のままです。

上部のツールバーにある**Session**(セッション)ボタンをクリックし、**Journal**(記録)タブを選びます。Journalパネルが開き、次のタブが並びます。

- **Timeline**(時系列): 発見した場所、NPCとの出会い、戦闘の結果、クエスト、アイテムの出来事など、これまでに起きたことの一覧です。
- **NPCs**: これまでに出会ったNPCが、顔画像と好感度ラベル付きで並びます(後述)。
- **Map**(マップ): 発見した場所の名前を並べただけの一覧です。
- **Items**(アイテム): 入手、使用、紛失、削除したアイテムの記録です。
- **Library**(蔵書): ゲームマスターが見せてくれた世界内の記録や本です。保存されるので読み返せます。
- **Notes**(メモ): 自由に書き込めるメモ帳です。

### プレイヤーのメモ

**Notes**タブは自分専用のメモ帳です。左側に入力すると、右側に整形されたプレビューが表示されます。メモ帳の上のキャプションは、書いた内容がゲームマスターとパーティーメンバーから見えることを知らせています。つまり、ここに書いたことは物語に影響します。

メモは入力の手が止まってしばらくすると自動的に保存されます。保存中は小さく**Saving...**、保存が終わると**Saved**と表示されます。

## NPCの好感度ラベル

Adventure Journalの**NPCs**タブでは、各NPCがこちらをどう思っているかを追跡します。一覧に並ぶNPCには、顔画像、名前、好感度ラベルが表示されます。

好感度ラベルは物語での行動に応じて変わります。良いほうから悪いほうへ、次の7つのいずれかです。

| ラベル | 意味 |
|---|---|
| **Devoted** | 深く忠誠を誓っている |
| **Allied** | 頼れる味方 |
| **Friendly** | 好意的 |
| **Neutral** | 特に感情はない |
| **Unfriendly** | 否定的 |
| **Hostile** | 敵に回った |
| **Enemy** | はっきりと敵対して動く |

ラベルが表示されるのは、NPCの好感度が初期値から動いたあとです。加わったばかりで好感度が変わっていないNPCには、まだラベルが付きません。

NPCがこのタブに現れるのは、ゲームマスターがそのNPCを描写したか、好感度を与えたか、関係についてのメモを記録したときです。各NPCの行では、次の操作もできます。

- NPCの顔画像をアップロードする、または差し替える。
- 画像生成がオンであれば、AIで顔画像を生成する。
- そのNPCをAdventure Journalから削除する。

## ゲームマスターのモード

誰がゲームを進行するかは、設定ウィザードの**Party**(パーティー)ステップにある**Game Master Mode**(ゲームマスターのモード)で選びます。選択肢は2つです。

- **Standalone GM**: デフォルトです。Marinaraがゲームマスターを用意します。設定ウィザードでは「A snarky narrator running the show」と説明されます。キャラクターカードは必要ありません。
- **Character GM**: 自分のキャラクターカードの1つをゲームマスターとして使います。ゲームを進行しつつ、そのキャラクターとして振る舞うようMarinara Engineがモデルに指示します。語り口を特定のキャラクターに任せたいときに選びます。

初めて遊ぶ場合は**Standalone GM**を選んでください。モードはゲームを作成するときに設定できます。設定手順の全体は[Game Mode: はじめに](getting-started.md)を参照してください。
