# Game Mode: パーティーとNPC

このガイドでは、Game Modeのキャンペーンに登場する人々、つまりパーティーメンバーと、ゲームマスターが登場させるNPC(プレイヤー以外のキャラクター)を説明します。パーティーメンバーのキャラクターシートを開く方法、編集や再生成のしかた、NPCの好感度ラベルを含むAdventure Journalの読み方がわかります。2つのゲームマスターのモードについても取り上げます。

Game ModeはMarinara Engineのチャットモードの1つです。AIのゲームマスター(GM)が進行する1人用のRPG(ロールプレイングゲーム)を遊べます。準備と基本については[Game Mode: はじめに](getting-started.md)を参照してください。

## Character Profiles

**Character Profiles**(キャラクタープロフィール)のアバターボタンをクリックまたはタップすると、一緒に旅をしているキャラクターが表示されます。パーティーメンバーが複数いる場合、ボタンにはメンバーの顔画像が順番に表示され、人数のバッジが付きます。

このボタンは、コンピューターでもスマートフォンでも、チャット内でドラッグして動かせます。開いて**Lock window**(ウィンドウを固定)を使うと、その場に固定できます。コンピューターでは、ウィンドウの移動とサイズ変更もできます。**Close**(閉じる)を押すと、ボタンに戻ります。位置はチャットに保存され、**Settings → Appearance → App**(設定 → 外観 → アプリ)のチャットウィジェットのスタイルに従います。スマートフォンでは、3点アイコンの**Chat tools**(チャットツール)メニューとは別に表示されます。

**Character Profiles**の中では、次の操作ができます。

1. 顔画像をクリックまたはタップすると、そのキャラクターのキャラクターシートが開きます。
2. デスクトップで顔画像にマウスを重ねると、小さな**X**ボタンが現れます。
3. **X**をクリックすると、そのキャラクターをパーティーから外せます。

ゲームマスターが仲間にしたキャラクターは、設定のときに加わった場合でも物語の途中で加わった場合でも、すべて外せます。自分のペルソナは自分が演じるキャラクターです。**X**ボタンがないため、自分をパーティーから外すことはできません。

## キャラクターシート

キャラクターシートは、パーティーメンバー1人分のゲーム上の情報をまとめたものです。キャラクターカードとは別物です。ゲームマスターが、そのキャラクターと現在の物語をもとに書きます。

**Character Profiles**を開き、そのキャラクターの顔画像をクリックまたはタップすると、シートが開きます。シートに表示されるのは、内容のある項目だけです。

- **Attributes**(能力値): STR、DEX、CONのようなテーブルトークRPG風の数値です。それぞれに修正値が付きます。
- **Stats**(ステータス): HPやMPのようなリソースのバーです。
- **Abilities**(能力): そのキャラクターにできることです。
- **Strengths**(長所)と**Weaknesses**(短所): 短い一覧です。
- **Details**(詳細): Skills、Weapon、Factionのような補足情報です。
- **Inventory**(インベントリー): そのキャラクターが持っているアイテムです。
- **Traits**(特性): そのほかの自由な項目です。

加わったばかりのキャラクターでは、「Character data will populate as the story progresses.」と表示されることがあります。シートは遊び進めるにつれて埋まっていきます。

### AIによるシートの再生成

**Regenerate Sheet**(シートの再生成)をクリックすると、そのキャラクターのシートをAIが書き直します。キャラクターの内容と現在のゲームのコンテキストが使われます。物語の中でキャラクターが大きく変わったあとに便利です。

### シートの手動編集

**Edit Sheet**(シートの編集)をクリックすると、自分でシートを書き換えられます。編集モードで設定できるのは次の内容です。

- **Sheet Details**(シートの詳細)にある**Class**(クラス)と短い説明。
- **RPG Attributes**(RPG能力値): **Enable**(有効化)をオンにすると、HPのようなリソースのバーと能力値を管理できます。**Add Pool**(バーの追加)でバーを1つ増やします(名前、現在値、最大値、色)。**Add Attribute**(能力値の追加)でSTRのような数値を増やします。
- **Abilities**、**Strengths**、**Weaknesses**: **Add**(追加)で1行足します。
- **Details**: **Add Detail**(詳細の追加)でラベル付きの情報を足します。

入力が終わったら**Save Sheet**(シートの保存)をクリックします。変更を捨てる場合は**Cancel**(キャンセル)をクリックします。

### ゲーム中のルールセットシート

[ルールセットを使うゲーム](dice-and-skill-checks.md#games-that-use-a-ruleset)では、各キャラクターのシートの先頭に**Ruleset sheet**(ルールセットのシート)のブロックが表示されます。構成はルールセットによって決まるため、5eのシートとほかのシステムのシートでは見た目が異なります。ルールセットのないゲームには、このブロックはありません。

- **Resources**(リソース)は、HP、呪文スロット、クラスリソースなどの残りを最大値とともに示します。マイナスとプラスのボタンを使うか、数値を入力します。一時的な上乗せがあるリソースには、**Temp**(一時)の欄も表示されます。
- **Tracks**(トラック)は、消耗などのように、範囲内で段階が上下します。
- **Wound tracks**(負傷トラック)は、ダメージを数値で数えずに印で記録するシステム向けの、マスの列です。各マスには負傷段階の名前と、ロールにかかるペナルティが表示されます。ルールセットに複数の負傷種別がある場合は先に種別を選び、**Mark**(印を付ける)または**Clear one**(1つ消す)を使います。次の空きマスをクリックして印を追加したり、最後に印の付いたマスをクリックして1つ消したりすることもできます。それ以外のマスはクリックに反応しません。重い負傷の印は上位のマスを取り、軽い印を下に押し下げます。下の行には適用中のペナルティと、トラックに収まらなかった分が表示されます。ルールセットによっては、マスに名前ではなく番号を付け、ときにはキャラクター自身の評価値と同じ数のマスを持ちます。また、各印を狙ったマスに付けるルールセットもあります。そうしたトラックでは、空いているどのマスでもクリックでき、**Clear one**で消えるのは最も上のマスにある最も軽い印です。いっぱいになったトラックは、古い印を重くする代わりに新しい印を受け付けません。ルールセットは、シート上の一覧からトラックにマスを追加したり、休息や治療で1種類の負傷だけを消したりすることもできます。ルールセットで指定されていれば、そのペナルティがロールに適用されます。ダイスプールからダイスを減らすか、合計値のロールに加算し、ダイスカードに適用量が表示されます。
- **Notes**(メモ)は、キャラクターが精神集中している対象などを書く短いテキスト欄です。
- **Conditions**(状態)は、オンとオフを切り替えるボタンです。
- **States**(ステート)は、形態や構えなど、一覧の中から一度に1つだけ取る値です。一覧から値を選びます。ステートは、構えがロールに加えるダイスのように、それに続く数値を変えることがあり、休息で元に戻ることもあります。
- **Rest buttons**(休息ボタン)は、ルールセットの休息の1つを適用します。休息で何が回復するかはルールセットが定めます。休息では、ワンドのチャージなど、キャラクターが持つアイテムのチャージが戻ることもあり、そのときはボタンの下の行に何が戻ったかが表示されます。5e (SRD 5.1)では、大休憩でHPと呪文スロットが回復し、キャラクターのヒット・ダイスの半分(最低1個)が戻ります。
- その下には、能力値修正値、習熟したスキルとセーヴ、アーマー・クラスなどルールセットが選んだいくつかの値をまとめた、ビルドの短い概要があります。

Game Masterは、語りながら同じシートを最新の状態に保ちます。キャラクターがリソースを使う、ダメージを受ける、回復する、状態を得るか失う、ステートを変える、休息するといったときに、その変更を記録し、Engineがシートと照らし合わせて確認します。空きスロットがないのに呪文を唱えるなど、ありえない変更は拒否されます。何も変わらず、通知でそのことが知らされます。

キャラクターが呪文やクラスの特徴など、ルールセットのカタログから選んだものを使うと、Game Masterがその名前を挙げ、Engineが代価をすべて支払います。ルールセットが定めるコストに加えて、それに付随する各カウンターの使用回数を1回分ずつ消費します。スロットを使う呪文は、ルールセットがその呪文に定めるレベルのスロットから支払われ、Game Masterは代わりに高いレベルを求めることもできます。Engineが自分から高いスロットに上げることはありません。代価の一部でも支払えない場合は全体が拒否され、何も消費されません。初級呪文などコストのないものは、描写されるだけです。

シート上の数値の中には、自分ではなくルールセットに属するものがあります。最大値がレベルに連動するクラスリソースや、能力値に連動する使用回数は、ルールセットが設定し、シートを編集しても正しい値に保たれます。

計算される値の中には、プレイの進行に連動するものもあります。ルールセットは、リソースやトラックの現在の状態から数値を求めたり、ステートの値ごとに数値を与えたり、荷物に詰めた装備の重さのように一覧の列を合計したりできます。また、スキルをそうした数値で頭打ちにすることもでき、リソースが少ない間はスキルが下がることがあります。これらはゲームのシートに現在の値を表示し、判定や戦闘ではその時点の値が使われます。キャラクターカードのシートエディターには読み取るゲームがないため、プレイ開始時の値が表示されます。

こうした変化する値は、それが起きたメッセージに属します。ターンの別のバージョンにスワイプしたり再生成したりすると、シートはそのターンの前の状態に戻るので、二重に消費されることはありません。

レベルアップのあとなど、ビルドそのものを変えるには**Edit sheet**(シートを編集)をクリックします。能力値、各欄、呪文などの一覧、スキルとセーヴの習熟を編集できます。計算される値は入力に合わせて更新されます。キャラクターカードと同じエディターなので、ここでもルールセットのカタログから行を追加でき、ルールセットが管理するセルは表示されるだけで入力できず、ルールセットの文章が変わった一覧には**Review**(確認)ボタンが表示されます。ルールセットに段階的なビルダーがある場合、エディターには**All fields**(すべての項目)と並んで**Guided**(ガイド付き)が表示されます。**Guided**は、能力値、スキル、初期装備などの選択を1つずつ案内し、各ステップでまだ何が必要かを示します。**All fields**はすべてを一度に表示します。終わったら**Save sheet**(シートを保存)をクリックします。変更されるのは、このゲームのシートのコピーだけです。キャラクターやペルソナに保存されたシートが、ゲームによって変更されることはありません。

前述の別の**Edit Sheet**ボタンは、引き続き汎用のシート(クラス、能力、長所など)を編集し、ルールセットのシートには触れません。

ルールセットのパッケージが削除された場合や、インストールされているものがゲーム作成時より古い場合は、ブロックの代わりに通知が表示され、パッケージを再びインストールするまで判定はロールできません。

### パーティーシートと進行クロック

ルールセットによっては、クルーや一団など、パーティー全体のシートを持つものがあります。ゲーム画面のマップの近くに、ルールセット独自の呼び名で表示されます。名前をクリックすると開きます。Game Masterは各キャラクターのシートと同じようにこのシートも最新の状態に保ち、ルールセットが許可していれば自分でも編集できます。編集中に誰かがパーティーシートを保存した場合は、その人のバージョンが表示されます。**Save**(保存)を押すと自分のバージョンで置き換え、**Cancel**(キャンセル)を押すとその人のバージョンを残します。

ルールセットは**Progress clocks**(進行クロック)も使えます。警報が広まっていく様子など、何かが積み重なるにつれてGame Masterが埋めていく、区切られた円です。マップの近くに、埋まった区切りの数とともに表示され、いっぱいになると**Done**(完了)と表示されます。

## インベントリー

語りの上にある**Inventory**(インベントリー)をクリックすると開きます。各マスはスタックで、アイテムとその数を表します。スタックをクリックすると選択できます。

パーティーの一人ひとりが自分の持ち物を運びます。インベントリーは**All**(全員)の表示で開き、すべてのバッグがまとめて表示されます。各スタックの隅には、それを運んでいる人の名前が表示されます。パーティーメンバーのタブをクリックすると、その人のバッグだけが表示されます。ほかに誰も何も持っていない間はタブがなく、すべてのスタックが自分のものです。

- **量を変える。** **-**と**+**で1つ減らしたり増やしたりします。もっと大きく変えるには、その間の数値に入力してEnterを押します。数値だけなら個数を設定し(`300`)、符号を付けるとその数だけ加えるか減らします(`+100`、`-50`)。スタックを0にすると削除されます。2つ以上あるときは、先に確認されます。
- **スタックを分ける。** **Split**(分割)をクリックし、新しいスタックに移す数を入力して、もう一度**Split**をクリックします。300個のリンゴから100個を分けると、200個のスタックと、その隣に100個の新しいスタックができます。
- **渡す。** **Give**(渡す)をクリックし、渡す相手と数を選んで、もう一度**Give**をクリックします。スタックをまるごと渡すには、その人のタブへドラッグすることもできます。
- **追加する。** アイテムの名前を入力して**Add**(追加)をクリックします。アイテムは開いているタブのバッグに入り、**All**からは自分のバッグに入ります。ただし、ルールセットが各自の運べる量を定めている場合は除きます(下記を参照)。そのバッグにすでにあるアイテムを追加すると、そのアイテムの最初のスタックに1つ加わります。
- **まとめる、並べ替える。** スタックを同じアイテムの別のスタックにドラッグすると、それぞれの呼び名にかかわらず1つにまとまります。まとめたスタックは、ドロップ先のスタックを運んでいた人のものになります。別のアイテムにドラッグすると、2つが入れ替わります。
- **ルールセットから。** ルールセットが独自のアイテムを一覧にしているゲームでは、**From the ruleset**(ルールセットから)で、ルールセットの検索とフィルター付きの選択画面が開きます。欲しいアイテムにチェックを入れて**Add**をクリックすると、それぞれ1つずつが、**Add**でアイテムが入るのと同じ場所に入ります。つまり開いているタブのバッグか、**All**からなら自分のバッグです(ルールセットが各自の運べる量を定めている場合を除きます)。入力した名前がルールセットのアイテムの1つであれば、そのアイテムが追加されます。ルールセットが自分のアイテムしか受け付けない場合は、名前を入力することはできません。
- **初期装備。** ルールセットが初期装備を用意している場合は、**Starting gear**(初期装備)で開きます。**For**(対象)で誰の装備かを選び、キットが求める選択をしてから、その**Take**(受け取る)ボタンをクリックすると、その人のバッグに入ります。そのキャラクターのシートに合う装備が先に並び、それ以外の装備はGame Masterが認めれば受け取れます。受け取るかどうかは任意です。用意されたものをすべて受け取ると、ボタンの表示が**Starting gear (taken)**に変わります。
- **使う。** **Use**(使用)をクリックすると、アイテムを使うことがGame Masterに伝わります。治療用の湿布など、使ったときの効果が定められたルールセットのアイテムでは、まずEngineがそれを処理します。回復量をロールし、それを運んでいる人のシートに書き込み、スタックから1つ減らすかチャージを1つ消費して、何が起きたかをGame Masterに伝えるので、物語もそれに従います。ほかの誰かへの効果は、Game Masterが描写します。何も残っていないアイテムは拒否され、身に着ける必要のあるアイテムは、身に着けている間だけ使えます。読める範囲を超えた巻物など、先に判定が必要なアイテムもあります。その場合はEngineがロールし、失敗するとアイテムは効果なしで使い切られます。
- **愛称。** スタックの新しい名前を入力して**Save**(保存)をクリックします。これはそのスタックの呼び名にすぎません。同じアイテムのままで、Game Masterは元の名前でも呼べ、愛称を付けても別のスタックにまとまることはありません。アイテム本来の名前が愛称の横に表示されます。本来の名前を入力し直すと、愛称は消えます。

ルールセットのアイテムを選ぶと、種類、レアリティー、タグ、数値、説明が表示されます。1つのスタックに入る数はルールセットが定めた数までで、超えた分は新しいスタックになります。Game Masterは、名のある刃など、ルールセットの言葉でアイテムを考案することもできます。考案されたアイテムはルールセットのアイテムと同じように働き、詳細には考案されたものであることと、レアリティーで許される範囲に抑えたボーナスなど、ルールセットに合わせるためにEngineが変更した点が表示されます。Game Mode独自のアイテムをオフにするルールセットもあります。その場合、Game Masterが与えるのはルールセットのアイテムと考案したアイテムだけですが、ルールセットが自分のアイテムしか受け付けない場合を除き、自分でアイテムを入力することはできます。

### 装備、結びつけ、運搬

ルールセットは、アイテムの身に着け方と運び方を定めることもできます。

- **装備。** 体の鎧や両手で持つ弓のようにスロットを使うアイテムには、**Equipped**(装備中)ボタンがあります。持ち主は、そのスロットが空いている間だけ身に着けられます。バッグのタブには、**Hands 2/2**のように使用中の各スロットが表示されます。大きなスタックのアイテムを1つ装備すると、そのアイテムは身に着けた印の付いた専用のスタックに移ります。
- **結びつけ。** 効果を得るために結びつける必要のあるアイテム(同調、授与など)には、**Bound**のように、ルールセットの用語で名付けられたボタンがあります。キャラクターが結びつけられるアイテムの数はシートで許される数までで、たとえば**Bound 1/3**のように表示されます。呪われたアイテムは、一度結びつけると結びつけたままになります。結びつけの解除も、外すことも、譲ることも、捨てることもできません。呪いを解けるのは、Game Masterを通じた物語だけです。
- **運搬。** ルールセットがすべての重さと各キャラクターの運べる量を定めている場合、各バッグに**Load 5/6, at most 12**のように積載量が表示され、持ち主が楽に運べる量を超えると**Encumbered**と表示されます。**All**から追加したアイテムは、重荷にならずに運べる人に渡ります。まず自分、次にパーティーの順です。全部を運べる人がいない場合は、各自の残りの余裕に応じて分けられ、誰も運べる上限を超えて渡されることはありません。誰も運べない分は置いていかれ、そのことが知らされます。運べる量を超えて渡すことは、**Give**でも、相手のバッグのスタックにドラッグしても拒否されます。

身に着けているアイテムや結びつけたアイテムをほかの人に渡すと、外され、結びつけも解除されます。

パーティーメンバーのキャラクターシートには、その人が運んでいる物が一覧表示されます。

Game Masterは、物語に合わせてアイテムを追加、削除、受け渡しし、誰が運ぶかを伝えます。Game Masterが名前を挙げたアイテムがルールセットのアイテムの1つであれば、それはそのアイテムとして扱われ、持っているルールセットのアイテムがそれぞれ何であるかもGame Masterに伝えられます。Game Masterは、**Use**ボタンと同じ方法でルールセットのアイテムを使います。アイテムの身に着け方と運び方を定めるルールセットでは、Game Masterはアイテムを身に着けたり外したり、結びつけたり解除したりし、各キャラクターの積載量、スロット、結びつけたアイテムも把握します。誰に渡すかを指定せずに追加したアイテムは、自分で追加した場合と同じように分けられます。各変更は返信が保存されたときに行われ、その通知は物語のその部分まで進んだときに表示されます。Game Masterが誰から取るかを指定せずにアイテムを取る場合は、まず自分のバッグから、次にパーティーのほかのメンバーから取られます。誰も持っていない物を取るなど、ありえない変更は拒否され、Game Masterに伝えられます。返信を再生成すると、その変更はそのターンの開始時点からやり直され、以前のバージョンにスワイプして戻ると、そのバージョンが残した状態が表示されます。表示中のバージョンを削除すると次のバージョンが残した状態が表示され、チャットの分岐には各バージョンのインベントリーがそのまま引き継がれます。これは、インベントリーが返信の残したとおりのままである間だけです。自分で何かを変更したあとは、新しい返信の変更はその上に加えられ、自分の操作が取り消されることはありません。戦闘では**Items**(アイテム)の行動からアイテムを使い、誰が運んでいても、どう呼ばれていても、同じアイテムのスタックをすべて合わせて数えます。分割や愛称も含め、すべてのバッグは次のセッションに引き継がれます。

### お金

ルールセットは独自のお金を持つことができます。ペニー、シリング、クラウンのように1つ以上の硬貨の系統があり、大きい硬貨はそれぞれ最小の硬貨の何枚分かの価値を持ちます。硬貨はほかのアイテムと同じスタックです。ルールセットが定める重さがあり、運んでいる人の積載量に数えられ、ほかの物と同じように分割、受け渡し、まとめができます。**From the ruleset**には、手動で追加するための**Coins**(硬貨)の一覧があります。

スタックの上の行に、開いているタブにある各系統の硬貨と、その合計の価値が表示されます。たとえば**Coin: crowns ×2, pennies ×12 (worth 132 pennies)**です。

Game Masterはこれらの硬貨でパーティーに請求したり支払ったりし、勝った戦闘やロールした宝物から硬貨が落ちることもあります。支払いは1人のキャラクターの財布から行われ、誰の財布かを指定しなければ自分の財布です。また、価格が示された系統の硬貨だけで支払われます。大きい硬貨から先に使い、ちょうどの額がないときは大きい硬貨をくずして、おつりは小さい硬貨で戻ります。財布で払えない価格は拒否され、Game Masterに伝えられます。ある系統の価格がほかの系統で支払われることはないので、塩で示された価格は塩で支払います。パーティーが得たお金は、ほかのアイテムと同じようにバッグに入ります。支払いと収入は、それぞれ通知で表示されます。

ルールセットのバリアントでは、クラウンが塚まで届かない長い夜のように、ある硬貨をなくすこともできます。その間は、その硬貨で支払いを受ける人も支払う人もいなくなり、その硬貨で示された価格は、同じ価値のまま残りの硬貨で表示されます。

ルールセットは市場を持つこともでき、その場合は買える物が今いる場所によって変わります。Game Masterはシーンがどの場所で、その場所がどれほどの規模か(ルールセットの言葉で、小村や都市など)を伝え、小さな場所ほど売っている物は少なくなります。珍しい物は町でしか見つからないことがあり、売り手によっては大きな場所にしか店を構えなかったり、信者にしか売らない礼拝堂のように一部の買い手にしか売らなかったりします。何かを買うと、Engineはアイテムのコストと取引の安さや高さから価格を計算し、買い手の財布から支払って、アイテムをその人のバッグに入れます。宿泊、渡航などのサービスは支払うだけです。何をいくらで買ったかは通知で表示され、場所、売り手、財布のいずれかの理由でできない購入は拒否され、Game Masterにその理由が伝えられます。ルールセットは、場所での1日ごとに違いを出すこともできます。珍しい物を少ししか置いていない場所や、その日だけ珍しい物を出す売り手があり、その物を扱う売り手には、価格の一部で物を売り戻せます。ただし、その場所の売り手たちが1日に支払える額を使い切るまでです。パーティーが滞在を続けるとGame Masterが同じ場所で新しい1日を始め、棚と財布が再び満たされます。

ルールセットのないゲームでも、舞台設定キットにお金と市場があれば使えます。スターターキットにはすべてあり、ハイファンタジーなら銅貨、銀貨、金貨、武侠なら銅銭と銀の両、現代ならドルとセント、サイバーパンクやスペースオペラならクレジットです。キットの店には、その舞台設定で売られている日用品が、価格と、それを売っている最小の場所とともに並びます。そのため、村にはカフェがありますが、救急箱があるのは町からです。お金と店はキットの**Change its words**(言葉を変更)で変更でき、お金を完全になくすこともできます。購入、支払い、収入は、その舞台設定独自の硬貨で、上記と同じように働きます。

## パーティーメンバーの加入と離脱

物語の展開に合わせて、パーティーの顔ぶれを決めるのはゲームマスターです。仲間を手動で追加するボタンはありません。GMがその場面の出来事に応じて、語りの中でパーティーメンバーを増やしたり減らしたりします。

GMが加えるNPCの名前が、自分のキャラクターカードの1枚とまったく同じ場合や、複数のカードに共通する名前の場合は、どれを加えるかを尋ねるウィンドウが開きます。各カードの名前、タイトル、アバターが表示されます。カードを選ぶか、ゲームが作ったキャラクターを加える場合は**Keep the game's own**(ゲームのキャラクターのままにする)の後にNPCの名前が続く選択肢(たとえば**Keep the game's own Emma**)を選びます。ウィンドウを閉じた場合も同じです。Samという名前のNPCに対する**Samantha**のように、名前が似ているだけのカードが加わることはありません。

自分から仲間を外したいときは、前述のとおり**Character Profiles**でその仲間の顔画像の横にある**X**ボタンを使います。この方法で自分のペルソナを外すことはできません。

## Adventure Journal(冒険の記録)

Adventure Journalは、キャンペーンの記録が積み重なっていく場所です。AIが書くのではなく、保存されたゲームの出来事から組み立てられるため、内容は事実のままです。

**Session**(セッション)を開き([Sessionを開く](sessions-and-saves.md#opening-session)を参照)、**Journal**(記録)タブを選びます。Journalには次のタブがあります。

- **Timeline**(時系列): 発見した場所、NPCとの出会い、戦闘の結果、クエスト、アイテムの出来事など、これまでに起きたことの一覧です。
- **NPCs**: これまでに出会ったNPCが、顔画像と好感度ラベル付きで並びます(後述)。
- **Map**(マップ): 発見した場所の名前を並べただけの一覧です。
- **Items**(アイテム): 入手、使用、紛失、削除したアイテムの記録です。
- **Library**(蔵書): ゲームマスターが見せてくれた世界内の記録や本です。保存されるので読み返せます。
- **Notes**(メモ): 自由に書き込めるメモ帳です。
- **World**(世界): 生成された世界を持つゲームで、パーティーが知っている範囲の世界です。次の内容が表示されます。
  - 今いる場所と、パーティーの知名度
  - パーティーが関わった各集団との関係
  - パーティーが成し遂げたこと
  - パーティーに届いた知らせ(うわさには印が付きます)
  - 耳にした、起こりつつある問題
  - 土地の人なら誰でも語る過去

  パーティーが知りうることだけが表示されます。Game Masterだけが知る秘密は隠されたままです。スワイプや分岐をしても、物語に沿った内容が表示されます。

### プレイヤーのメモ

**Notes**タブは自分専用のメモ帳です。左側に入力すると、右側に整形されたプレビューが表示されます。メモ帳の上のキャプションは、書いた内容がゲームマスターとパーティーメンバーから見えることを知らせています。つまり、ここに書いたことは物語に影響します。

メモは入力の手が止まってしばらくすると自動的に保存されます。保存中は小さく**Saving...**、保存が終わると**Saved**と表示されます。

## NPCの好感度ラベル

Adventure Journalの**NPCs**タブでは、各NPCがこちらをどう思っているかを追跡します。一覧に並ぶNPCには、顔画像、名前、好感度ラベルが表示されます。

好感度ラベルは物語での行動に応じて変わります。良いほうから悪いほうへ、次の7つのいずれかです。

| ラベル | 意味 |
|---|---|
| **Devoted** | 深く忠誠を誓っている |
| **Allied** | 頼れる味方 |
| **Friendly** | 好意的 |
| **Neutral** | 特に感情はない |
| **Unfriendly** | 否定的 |
| **Hostile** | 敵に回った |
| **Enemy** | はっきりと敵対して動く |

ラベルが表示されるのは、NPCの好感度が初期値から動いたあとです。加わったばかりで好感度が変わっていないNPCには、まだラベルが付きません。

NPCがこのタブに現れるのは、ゲームマスターがそのNPCを描写したか、好感度を与えたか、関係についてのメモを記録したときです。各NPCの行では、次の操作もできます。

- NPCの顔画像をアップロードする、または差し替える。
- 画像生成がオンであれば、AIで顔画像を生成する。
- そのNPCをAdventure Journalから削除する。

## ゲームマスターのモード

誰がゲームを進行するかは、設定ウィザードの**Party**(パーティー)ステップにある**Game Master Mode**(ゲームマスターのモード)で選びます。選択肢は2つです。

- **Standalone GM**: デフォルトです。Marinaraがゲームマスターを用意します。設定ウィザードでは「A snarky narrator running the show」と説明されます。キャラクターカードは必要ありません。
- **Character GM**: 自分のキャラクターカードの1つをゲームマスターとして使います。ゲームを進行しつつ、そのキャラクターとして振る舞うようMarinara Engineがモデルに指示します。語り口を特定のキャラクターに任せたいときに選びます。

初めて遊ぶ場合は**Standalone GM**を選んでください。モードはゲームを作成するときに設定できます。設定手順の全体は[Game Mode: はじめに](getting-started.md)を参照してください。
