# Game Mode: パーティーとNPC

このガイドでは、Game Modeのキャンペーンに登場する人々、つまりパーティーメンバーと、ゲームマスター(GM)が登場させるNPC(プレイヤー以外のキャラクター)を説明します。キャラクターシートを開いて編集する方法、インベントリーの管理、Adventure Journalの読み方、GMのモードの選び方がわかります。準備と基本については[Game Mode: はじめに](getting-started.md)を参照してください。

## パーティーとインベントリーを確認する

1. **Character Profiles**(キャラクタープロフィール)をクリックし、顔画像を選ぶと、そのキャラクターのシートが表示されます。
2. 物語の本文の上にある**Inventory**(インベントリー)をクリックすると、全員の持ち物が表示されます。

それぞれの詳細は、このあとで説明します。

## Character Profiles

**Character Profiles**(キャラクタープロフィール)は、一緒に旅をしている仲間を表示する顔画像のボタンです。**Chat tools**(チャットツール)メニューの外に置かれています([Gameの操作](getting-started.md#the-games-controls)を参照)。パーティーメンバーが複数いる場合は、メンバーの顔画像が順番に表示され、人数のバッジが付きます。物語で誰かが加わるまでは、パーティーは自分のペルソナだけです。

1. **Character Profiles**ボタンをクリックまたはタップします。
2. 顔画像をクリックまたはタップすると、そのキャラクターのシートが開きます。

仲間を外すには、コンピューターでその仲間の顔画像にマウスを重ね、**X**をクリックします。GMが仲間にしたキャラクターであれば、設定ウィザードで加わった場合でも、あとから加わった場合でも、この方法で外せます。自分のペルソナ(自分が演じるキャラクター)には**X**がありません。

このボタンは、コンピューターでもスマートフォンでも、チャット内でドラッグして動かせます。開いて**Lock window**(ウィンドウを固定)を使うと、その場に固定できます。コンピューターでは、ウィンドウの移動とサイズ変更もでき、**Close**(閉じる)を押すとボタンに戻ります。位置はチャットに保存され、**Settings → Appearance → App**(設定 → 外観 → アプリ)のチャットウィジェットのスタイルに従います。スマートフォンでは、3点アイコンの**Chat tools**メニューとは別に表示されます。

## キャラクターシート

キャラクターシートは、パーティーメンバー1人分のゲーム上の情報をまとめたもので、キャラクターカードとは別物です。新しいゲームすべてで使われる**MRPG**クラスのゲームでは、最初にキャラクターのMRPGクラスシートが開きます。**Status**(状態)、**Classes**(クラス)、**Skills**(スキル)、**Gear**(装備)のタブでクラスを変更し、スキルを持ち越し、装備を身に着けます。[キャラクターシート](mrpg-classes.md#the-character-sheet)を参照してください。MRPGステータスが、以下の**Attributes**の代わりになります。

その下には、GMがキャラクターと現在の物語をもとに書く、シートの物語面があります。内容のある項目だけが表示されます。

| 項目 | 内容 |
| --- | --- |
| **Attributes**(能力値) | Legacyゲームだけで使います。STR、DEX、CONのような修正値付きの数値と、HPやMPのようなリソースのバーです。 |
| **Stats**(ステータス) | そのほかの数値のバーです。 |
| **Abilities**(能力) | そのキャラクターにできることです。 |
| **Strengths**(長所)、**Weaknesses**(短所) | 短い一覧です。 |
| **Details**(詳細) | Skills、Weapon、Factionのような補足情報です。 |
| **Inventory**(インベントリー) | そのキャラクターが持っているアイテムです。 |
| **Traits**(特性) | そのほかの自由な項目です。 |

加わったばかりのキャラクターでは、「Character data will populate as the story progresses.」と表示されることがあります。シートは遊び進めるにつれて埋まっていきます。

<a id="edit-a-sheet-by-hand"></a>

### シートの手動編集

**Retry**(再試行)、**Save Sheet**(シートの保存)、**Cancel**(キャンセル)は、**Edit card**(カードを編集)をクリックしたあとでだけ表示されます。

1. キャラクターのシートを開き、**Edit card**をクリックします。
2. 必要な内容を変更します。
   - **Sheet Details**(シートの詳細)にある**Class**(クラス)と短い説明。
   - **Roleplay Stats**(ロールプレイ用ステータス、Legacyゲーム): **Enable**(有効化)をオンにすると、リソースのバー(プール)と能力値を管理できます。**Add Pool**(バーの追加)でバーを1つ増やします(名前、現在値、最大値、色)。**Add Attribute**(能力値の追加)でSTRのような数値を増やします。MRPGクラスのゲームでは、判定にも戦闘にも使いません。
   - **Abilities**、**Strengths**、**Weaknesses**: **Add**(追加)で1行足します。
   - **Details**: **Add Detail**(詳細の追加)でラベル付きの情報を足します。
3. **Save Sheet**をクリックします。変更を捨てる場合は**Cancel**をクリックします。

シートをAIに作り直させるには、編集中に**Retry**をクリックします。キャラクターと現在のゲームの履歴が使われ、モデルへのリクエストが発生します。作られるのは下書きで、「new sheet draft is ready. Review it, then save to apply.」と表示されます。下書きを確認してから、**Save Sheet**をクリックしてください。物語の中でキャラクターが大きく変わったあとに使います。幅の狭い画面では、このボタンはアイコンだけで表示されます。

<a id="the-ruleset-sheet"></a>

### ルールセットのシート

ルールセットを使うゲームでは、各シートの先頭に、ルールセットが構成を決める**Ruleset sheet**(ルールセットのシート)のブロックがあります。リソース、トラック、状態、休息、ビルドの概要が並び、GMが語りながら最新の状態に保ちます。[ルールセットのシート](rulesets.md#the-ruleset-sheet)を参照してください。

## パーティーメンバーの加入と離脱

パーティーの顔ぶれは、GMが語りを通じて決めます。「仲間を追加する」ボタンはありません。

GMが加えるNPCの名前が、自分のキャラクターカードの1枚、または複数のカードの名前と完全に一致する場合は、どれを加えるかを尋ねるウィンドウが開きます。各カードの名前、タイトル、アバターが表示されます。カードを選ぶか、ゲームが作ったキャラクターを加える場合は、**Keep the game's own**(ゲームのキャラクターのままにする)の後にNPCの名前が続く選択肢(たとえば**Keep the game's own Emma**)を選びます。ウィンドウを閉じた場合も同じです。Samという名前のNPCに対する**Samantha**のように、名前が似ているだけのカードが加わることはありません。

Experienceは、独自の仲間を用意できます。その世界の住人で、パーティーに加われる人々です。それぞれに完成済みのシートがあります。物語が仲間を加えたり去らせたりすることがあり、GMが仲間にできるのはそれらの仲間だけです(自分のライブラリーのキャラクターは引き続き加入できます)。仲間はパーティーの最高レベルで加わり、パーティーとともにレベルアップします。

## インベントリー

物語の本文の上にある**Inventory**(インベントリー)ボタンをクリックします。マス目が並んだ画面が開きます。各マスはスタックで、アイテムとその数を表します。スタックをクリックすると選択できます。

パーティーの一人ひとりが自分のバッグを持っています。インベントリーは**All**(全員)の表示で開き、すべてのバッグがまとめて表示されます。各スタックには、それを運んでいる人の名前が付きます。パーティーメンバーのタブをクリックすると、その人のバッグだけが表示されます。ほかに誰も何も持っていない間は、タブはありません。

- **量を変える。** **-**と**+**で1つ減らしたり増やしたりします。または、その間に数値を入力して<kbd>Enter</kbd>を押します。
  - 数値だけなら、その個数に設定します: `300`。
  - 符号を付けると、その数だけ加えるか減らします: `+100`、`-50`。
  - 0にするとスタックが削除されます。2つ以上あるときは、先に確認されます。
- **スタックを分ける。** **Split**(分割)をクリックし、新しいスタックに移す数を入力して、もう一度**Split**をクリックします。
- **渡す。** **Give**(渡す)をクリックし、渡す相手と数を選んで、もう一度**Give**をクリックします。または、スタックをまるごとその人のタブへドラッグします。
- **追加する。** アイテムの名前を入力して**Add**(追加)をクリックします。アイテムは開いているタブのバッグに入り、**All**からなら自分のバッグに入ります。そのバッグにすでにあるアイテムを追加すると、そのアイテムの最初のスタックに1つ加わります。
- **まとめる。** スタックを同じアイテムの別のスタックにドラッグします。まとめたスタックは、ドロップ先のスタックを運んでいた人のものになります。
- **入れ替える。** スタックを別のアイテムにドラッグすると、2つが入れ替わります。
- **使う。** **Use**(使用)をクリックすると、アイテムを使うことがGMに伝わります。
- **愛称。** 新しい名前を入力して**Save**(保存)をクリックします。アイテム本来の名前はそのまま残り、愛称の横に表示されます。愛称を付けても、スタックがまとまることはありません。本来の名前を入力し直すと、愛称は消えます。

### GMによるインベントリーの変更

GMは、物語に合わせてアイテムを追加、削除、受け渡しし、誰が運ぶかを伝えます。

- GMが持ち主を指定せずにアイテムを取る場合は、まず自分のバッグから、次にパーティーから取られます。
- 誰も持っていない物を取るなど、ありえない変更は拒否され、そのことがGMに伝えられます。
- 変更は、返信が保存されたときに行われます。返信を再生成すると、そのターンの開始時点からやり直されます。以前のバージョンにスワイプして戻ると、そのバージョンが残した状態が表示されます。分岐には、各バージョンのインベントリーがそのまま引き継がれます。
- 自分で何かを変更した場合、新しい返信の変更はその上に加えられ、自分の操作が取り消されることはありません。
- 戦闘では**Items**(アイテム)の行動からアイテムを使い、同じアイテムのスタックはすべて合わせて数えます。
- すべてのバッグ、分割、愛称は、次のセッションに引き継がれます。

## Adventure Journal(冒険の記録)

Adventure Journalは、キャンペーンの記録が積み重なっていく場所です。AIが書くのではなく、保存されたゲームの出来事から組み立てられるため、内容は事実のままです。

1. **Session**(セッション)を開きます([Sessionを開く](sessions-and-saves.md#opening-session)を参照)。
2. **Journal**(記録)タブを選びます。

| タブ | 表示される内容 |
| --- | --- |
| **Timeline**(時系列) | 発見した場所、NPCとの出会い、戦闘の結果、クエスト、アイテムの出来事など、これまでに起きたことです。 |
| **NPCs** | これまでに出会ったNPCです。顔画像と好感度ラベル付きで並びます。 |
| **Map**(マップ) | 発見した場所の名前を並べただけの一覧です。 |
| **Items**(アイテム) | 入手、使用、紛失、削除したアイテムの記録です。 |
| **Library**(蔵書) | GMが見せてくれた世界内の記録や本です。読み返せるよう保存されます。 |
| **Notes**(メモ) | 自分用のメモ帳です。 |
| **World**(世界) | 生成された世界を持つゲームで、パーティーが知っている範囲の世界です。 |

**World**タブには、今いる場所とパーティーの知名度、各集団との関係、パーティーが成し遂げたこと、パーティーに届いた知らせ(うわさには印が付きます)、耳にした、起こりつつある問題、土地の人なら誰でも語る過去が表示されます。表示されるのは、パーティーが知りうることだけです。GMだけが知る秘密は隠されたままです。スワイプや分岐をしても、物語に沿った内容が表示されます。

### プレイヤーのメモ

**Notes**タブでは、左側に入力すると、右側に整形されたプレビューが表示されます。キャプションには、メモがGMとパーティーメンバーから見えるため、書いた内容が物語に影響しうるという注意が表示されます。メモは、入力の手を止めてしばらくすると保存されます。ラベルには**Saving...**、続いて**Saved**と表示されます。

### NPCの好感度ラベル

**NPCs**タブの各NPCには、顔画像、名前、そして自分の行動に応じて変わる好感度ラベルが表示されます。NPCがこのタブに現れるのは、GMがそのNPCを描写したか、好感度を与えたか、関係についてのメモを記録したときです。ラベルが表示されるのは好感度が初期値から動いたあとなので、登場したばかりのNPCにはラベルがありません。

| ラベル | 意味 |
| --- | --- |
| **Devoted** | 深く忠誠を誓っている |
| **Allied** | 頼れる味方 |
| **Friendly** | 好意的 |
| **Neutral** | 特に感情はない |
| **Unfriendly** | 否定的 |
| **Hostile** | 敵に回った |
| **Enemy** | はっきりと敵対して動く |

各NPCの行では、顔画像をアップロードしたり差し替えたり、AIで顔画像を生成したり(画像生成がオンの場合)、そのNPCをJournalから削除したりすることもできます。

## ゲームマスターのモード

誰がゲームを進行するかは、設定ウィザードの**Party**(パーティー)ステップにある**Game Master Mode**(ゲームマスターのモード)で選びます。モードはゲームを作成するときに決まります。

- **Standalone GM**(デフォルト): MarinaraがGMを用意します。ウィザードでは「A snarky narrator running the show」と説明されています。キャラクターカードは必要ありません。
- **Character GM**: 自分のキャラクターカードの1枚がGMになります。モデルはゲームを進行しながら、そのキャラクターとして振る舞います。特定の語り口が欲しいときに選びます。

初めてのゲームなら、**Standalone GM**を使ってください。

## リファレンス: ルールセットのインベントリー

ここで説明する内容は、ルールセットを使うゲームか、お金のある舞台設定キットを使うゲームにだけ当てはまります。[ルールセットで遊ぶ](rulesets.md)を参照してください。

### ルールセットのアイテム

これらの操作は、アイテムを持つルールセットでゲームを動かしている場合にだけ表示されます。

- **From the ruleset**(ルールセットから)を押すと、ルールセットのアイテムの選択画面が、そのルールセットの検索とフィルター付きで開きます。アイテムにチェックを入れて**Add**(追加)をクリックすると、それぞれ1つずつが、**Add**でアイテムが入るのと同じ場所に入ります。入力した名前がルールセットのアイテムの1つであれば、そのアイテムが追加されます。ルールセットによっては自分のアイテムしか受け付けず、その場合は入力する名前がありません。
- **Starting gear**(初期装備)を押すと、ルールセットが用意している初期装備が開きます。**For**(対象)で誰の装備かを選び、キットが求める選択をしてから、**Take**(受け取る)をクリックします。そのキャラクターのシートに合う装備が先に並びます。受け取るかどうかは任意です。すべて受け取ると、ボタンの表示が**Starting gear (taken)**に変わります。
- 治療用の湿布など、使ったときの効果が定められたルールセットのアイテムで**Use**(使用)を押すと、Marinaraがまずその効果を適用します。
  - アイテムが回復させる量をロールし、それを運んでいる人のシートに書き込みます。
  - スタックから1つ減らすか、チャージを1つ消費して、何が起きたかをGMに伝えます。
  - ほかの誰かへの効果は、GMに任されます。
  - 何も残っていないアイテムは拒否され、身に着ける必要のあるアイテムは、身に着けている間だけ働きます。
  - 読める範囲を超えた巻物など、先に判定が必要なアイテムもあります。Marinaraがその判定をロールし、失敗するとアイテムは効果なしで使い切られます。
- ルールセットのアイテムを選ぶと、種類、レアリティー、タグ、数値、説明が表示されます。1つのスタックに入る数はルールセットが定めた数までで、超えた分は新しいスタックになります。
- GMは、名のある刃など、ルールセットの言葉でアイテムを考案することもできます。考案されたアイテムはルールセットのアイテムと同じように働き、詳細には、考案されたものであることと、レアリティーで許される範囲に抑えたボーナスなど、ルールセットに合わせるためにMarinaraが変更した点が表示されます。
- Game Mode独自のアイテムをオフにするルールセットもあります。その場合、GMが与えるのはルールセットのアイテムと考案したアイテムだけです。ルールセットが自分のアイテムしか受け付けない場合を除き、自分でアイテムを入力することは引き続きできます。

### 装備、結びつけ、運搬

ルールセットは、アイテムの身に着け方と運び方を定めることができます。

- **装備。** 体の鎧や両手で持つ弓のようにスロットを使うアイテムには、**Equipped**(装備中)ボタンがあります。持ち主は、そのスロットが空いている間だけ身に着けられます。バッグのタブには、**Hands 2/2**のように使用中のスロットが表示されます。大きなスタックのアイテムを1つ装備すると、そのアイテムは身に着けた印の付いた専用のスタックに移ります。
- **結びつけ。** 効果を得るために結びつける必要のあるアイテム(同調、授与など)には、**Bound**のように、ルールセットの用語で名付けられたボタンがあります。キャラクターが結びつけられる数はシートで許される数までで、**Bound 1/3**のように表示されます。呪われたアイテムは、一度結びつけると、解除も、外すことも、譲ることも、捨てることもできません。呪いを解けるのは、GMを通じた物語だけです。
- **運搬。** ルールセットが重さと運べる量を定めている場合、各バッグに**Load 5/6, at most 12**のように積載量が表示され、持ち主が楽に運べる量を超えると**Encumbered**と表示されます。**All**から追加したアイテムは、重荷にならずに運べる人に渡ります。まず自分、次にパーティーの順です。誰も運べない場合は、各自の残りの余裕に応じて分けられ、誰も運べる上限を超えて受け取ることはありません。誰も運べない分は置いていかれ、そのことが知らされます。上限を超えてしまうバッグへの**Give**やスタックのドラッグは拒否されます。

身に着けているアイテムや結びつけたアイテムをほかの人に渡すと、外され、結びつけも解除されます。これらのルールがあるルールセットでは、GMもアイテムを身に着けたり外したり、結びつけたり解除したりし、各キャラクターの積載量、スロット、結びつけたアイテムを把握します。

### お金と市場

ルールセットは独自のお金を持つことができます。ペニー、シリング、クラウンのような硬貨の系統があり、大きい硬貨はそれぞれ最小の硬貨の何枚分かの価値を持ちます。硬貨は、ほかのアイテムと同じスタックです。ルールセットが定める重さがあり、運んでいる人の積載量に数えられ、分割、受け渡し、まとめができます。**From the ruleset**(ルールセットから)には、手動で追加するための**Coins**(硬貨)の一覧があります。スタックの上の行には、開いているタブにある各系統の硬貨とその合計が表示されます。たとえば**Coin: crowns ×2, pennies ×12 (worth 132 pennies)**です。

- GMは、これらの硬貨でパーティーに請求したり支払ったりします。勝った戦闘やロールした宝物から硬貨が落ちることもあります。支払いは1人のキャラクターの財布から行われ、誰の財布かを指定しなければ自分の財布から出ます。
- 価格は、示された系統の硬貨だけで支払われます。そのため、塩で示された価格は塩で支払います。大きい硬貨から先に使い、ちょうどの額がないときは大きい硬貨をくずして、おつりは小さい硬貨で戻ります。
- 財布で払えない価格は拒否され、そのことがGMに伝えられます。支払いと収入は、それぞれ通知で表示されます。
- ルールセットのバリアントでは、ある硬貨をなくすこともできます。その場合、その硬貨で支払う人も支払いを受ける人もいなくなり、その硬貨で示された価格は、同じ価値のまま残りの硬貨で表示されます。

ルールセットは市場を持つこともでき、その場合は買える物が今いる場所によって変わります。

- GMは、シーンがどの場所で、その場所がどれほどの規模か(ルールセットの言葉で、小村や都市など)を伝えます。小さな場所ほど売っている物は少なくなります。珍しい物は町でしか見つからないことがあり、売り手によっては大きな場所にしか店を構えなかったり、信者にしか売らない礼拝堂のように一部の買い手にしか売らなかったりします。
- 何かを買うと、Marinaraはアイテムのコストと取引の安さや高さから価格を計算し、買い手の財布から支払って、アイテムをその人のバッグに入れます。宿泊、渡航などのサービスは支払うだけです。
- 場所、売り手、財布のいずれかの理由でできない購入は拒否され、その理由がGMに伝えられます。
- ルールセットは、場所での1日ごとに違いを出すこともできます。珍しい物を少ししか置いていない場所や、珍しい物を出してくる売り手があり、売り手たちがその日に支払える額を使い切るまでは、価格の一部で物を売り戻せます。パーティーが滞在を続けると、GMが同じ場所で新しい1日を始め、棚と財布が再び満たされます。

ルールセットのないゲームでも、舞台設定キットにお金と市場があれば使えます。スターターキットにはすべてあり、たとえばハイファンタジーなら銅貨、銀貨、金貨、武侠なら銅銭と銀の両、現代ならドルとセント、サイバーパンクやスペースオペラならクレジットです。キットの店には日用品が、価格と、それを売っている最小の場所とともに並びます。そのため、村にはカフェがありますが、救急箱があるのは町からです。お金と店はキットの**Change its words**(言葉を変更)で変更でき、お金をなくすこともできます。[舞台設定キットの選択](getting-started.md#choosing-a-setting-kit)を参照してください。
