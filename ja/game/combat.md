# Game Mode: 戦闘

Game Modeの戦闘には、**Classic**(メニュー式戦闘)と**Tactical**(グリッド式戦闘)の2種類があります。どちらにするかは、設定ウィザードの**World**(世界)ステップにある**Combat Preference**(戦闘の種類)で選びます。あとで変更するには、**Chat Settings**(チャット設定)を開き、**Combat Style**(戦闘スタイル)を展開して、**Battle system**(戦闘システム)を選びます。独自に戦闘を行うルールセットでは、選べる項目が限られることがあります。ゲームマスター(GM、ゲームを進行するAI)が遭遇を設定し、結果を語ります。Marinaraは戦闘アクションを決まったダイスの計算で解決するので、誰の攻撃が命中するかをAIが決めることはありません。

## 戦闘の始まり

戦闘は自分から始めるものではありません。敵を挑発したり待ち伏せに踏み込んだりして、物語が戦闘を必要としたときに、GMが戦闘を始めます。すると、語りの上に全画面の戦闘画面が開きます。この画面は、そのとき物語で起きていること、つまりパーティー、敵、それぞれの能力値、特別なルールから組み立てられます。

画面には、片側にパーティー、反対側に敵が並びます。それぞれの戦闘参加者には体力バー(HP、ヒットポイント)があり、スキルを使う場合はマジックバー(MP、マジックポイント)もあります。画面上部には、**Next:**(次)と次に行動する者の名前、そして**Round**(ラウンド)とラウンド番号が表示されます。

> **Note:** 5e (SRD 5.1)など、ルールセットが独自に戦闘を解決するゲームでは、戦闘はこのページではなくルールセットに従います。[ルールセットでの戦闘](fighting-on-a-ruleset.md)を参照してください。戦闘にシートを提供するだけのルールセットでは、このページの戦闘を使います。[戦闘での動作](rulesets.md#what-happens-in-battles)を参照してください。

## Classic戦闘をプレイする

Classic戦闘には盤面がありません。パーティー全員が参加します。行動を選ぶのは1人のキャラクター、つまり生存している最初のパーティーメンバーの分だけです。ほかの仲間は自分で行動します。

自分のターンでは、行動を1つ選びます。

| 行動 | 内容 |
| --- | --- |
| **Attack**(攻撃) | 敵1体に通常攻撃を仕掛けます。 |
| **Skills**(スキル) | 特殊な能力を使います。スキルにはMPを消費するものがあります。味方を回復するもの、敵を攻撃するもの、バフやデバフをかけるものがあります。 |
| **Special**(特殊行動) | 自分の言葉で自由に行動を入力し、**Ask GM**(GMに聞く)を押します。たとえば「Ruin Guardのひび割れたレンズに砂を蹴り込む」のように書きます。何が起こるかはGMが決めます。 |
| **Defend**(防御) | そのラウンドの残りのあいだDefenseを上げ、受けるダメージを減らします。 |
| **Items**(アイテム) | バッグのアイテムを使います。**Full inventory**(インベントリー全体)を押すと、アイテムの一覧全体が開きます。 |
| **Flee**(逃走) | ただちに戦闘から離脱します。逃走は必ず成功し、戦闘はその場で終わります。 |

行動を選ぶと、そのラウンドが進みます。結果は、浮かび上がるダメージの数値、増減する体力バー、**Combat Log**(戦闘ログ)の行として表示されます。勝利すると**Victory!**のバナーが、パーティーが全滅すると**Defeat...**のバナーが表示されます。

ルールセットを使うゲームでは、ルールセット独自のアイテムについて、**Items**はルールセットの定めどおりに働きます。どれだけ回復するか、どれだけ傷つけるか、どの状態を与えるかです。チャージを持つアイテムは、使用回数が残っている間だけ表示されます。先に判定を求めるアイテムは、その判定がロールされ、失敗するとアイテムは効果なしで消費されます。ルールセットが用途を定めていないアイテムは表示されません。それ以外のアイテムは、戦闘開始時にGMが判断したとおりに働きます。ただし、ルールセットがGame Mode独自のアイテムをオフにしている場合は除きます。

## Tactical戦闘をプレイする

Tactical戦闘では、パーティーと敵をグリッド状の戦場に配置します。1マスが1タイルで、**Plains**(平原)や**Forest**(森)などの種類があります。

1. 自分のターンになったら(**Player Phase**と表示されるか、ユニットの名前の後に「's turn」と表示されたら)、グリッド上の味方ユニットを1体クリックします。盤面にそのユニットの移動範囲が表示されます。
2. 移動先のタイルをクリックし、**Confirm Move**(移動を確定)をクリックします。選び直すときは**Reset Move**(移動をリセット)をクリックします。
3. 移動すると、盤面に「Already moved — choose an action.」と表示されます。**Attack**(攻撃)、**Defend**(防御)、**Item**(アイテム)のどれかを選びます。**Flee**(逃走)もここにあります。
4. **Attack**を選ぶと、盤面に**Select an enemy**と表示されます。敵を1体クリックします。攻撃予測に、予想される結果が表示されます。確定するには**Confirm**(確定)をクリックします。**← Back**(戻る)で1つ前の手順に戻ります。
5. 終わったら**End Turn**(ターン終了)をクリックします。パーティーが先に行動するターンの順番では、続いて**Enemy Phase**が進みます。

盤面に**Resolving…**と表示されたら、少し待ってください。**Restart**(やり直す)を押して確認すると、同じ戦場で戦闘を最初からやり直します。

誰がいつ行動するかは**Turn order**(ターンの順番)によって決まります。[ターンの順番](#turn-order)を参照してください。手作りの盤面と地形のルールは、[Tactical戦闘と地形](#tactical-battles-and-terrain)で説明しています。

## GMに割り込む

GMが文章を書いている間は、**Interrupt**(割り込み)ボタンで割り込めます。入力した内容は、送信するまで確定しません。

1. **Interrupt**をクリックします。**Attempt to Interrupt?**(割り込みを試みますか?)というタイトルのウィンドウが開きます。
2. 次のどれかを選びます。
   - **No**は、取り消してGMに書き続けさせます。
   - **Force Interrupt**(強制割り込み)は、そのまま割り込みます。割り込んだことはGMに伝えられません。入力欄の枠が緑色になります。
   - **Yes**は、物語の中での割り込みを試みます。GMはそれに抵抗することがあります。入力欄が赤くなり、アプリが「using dice recommended」とヒントを表示して、ダイスボタンが点滅します。ダイスを振ると有利になることがあります。
3. メッセージを入力して送信します。

気が変わったときは、**Resume**(再開)を押します。保留中の割り込みが取り消され、語りが続きます。

## クイックタイムイベント

回避や追跡のようなテンポの速い場面では、GMがクイックタイムイベント(QTE)を発生させることがあります。オーバーレイには、縮んでいくカウントダウンバー、**React quickly!**という表示、選択肢ごとに1つずつの番号付きボタンが並びます。時間切れになる前に取りたい行動をクリックすると、ボーナスが手に入ります。反応が速いほどボーナスは大きくなります。時間切れになると、代わりにペナルティーを受けます。QTEではダイスを使いません。

スクリーンリーダーを使う場合や時間制限なしで遊ぶ場合など、QTEを使わないときは、ウィザードの**Features**(機能)ステップで**Quick Time Events**(クイックタイムイベント)をオフにします。

## スマートフォンでの戦闘

スマートフォンでは、行動ボタンが画面下部に固定されます。収まらないパネルは、下から引き出すドロワーに移り、4つのタブに分かれます。**Party**(パーティー。メンバーと体力)、**Boss Mechanics**(ボス特有の仕掛け。その戦闘の特別なルール)、**Dialogue**(セリフ。戦闘参加者が話す戦闘中のセリフ)、**Combat Log**(戦闘ログ。ラウンドごとの記録)です。タブをタップすると、そのドロワーが開きます。閉じるときは、ドロワーの外側か閉じるボタンをタップします。

<a id="how-combat-math-works"></a>

## 戦闘の計算方法

各ラウンドの結果を決めるのはAIではなく、決まったダイスの計算です。そのため戦闘は公平で、結果に一貫性があります。d20は20面ダイス(1から20)です。以下のイニシアチブ、攻撃、ダメージのルールは、Classic戦闘の進め方です。これはルールセットのルールではなく、Marinara独自のルールです。Tactical戦闘については、[ターンの順番](#turn-order)と[視界、遮蔽、高さ](#sight-cover-and-height)を参照してください。

**イニシアチブ。** 各ラウンドの開始時に、すべての戦闘参加者がd20を振り、Speedに応じたボーナス(Speedを5で割って切り捨てた値)を足します。合計が高い順に行動します。凍結、スタン、拘束の状態にあるか、Speedが0まで下がっている戦闘参加者は、そのラウンドを飛ばします。

**攻撃と防御。** 戦闘参加者がほかの相手を攻撃したときの処理は次のとおりです。

1. 攻撃側がd20を振り、Attackの能力値に応じたボーナスを足します。
2. 防御側がd20を振り、Defenseの能力値に応じたボーナスを足します。
3. 攻撃側の合計のほうが低ければ、攻撃は外れます。
4. ダイスの出目がそのまま20だったとき、または攻撃側が防御側を10以上上回ったとき、クリティカルヒットになります。

**ダメージ。** 命中すると、基本ダメージは攻撃側のAttackの能力値から決まり、レベルが上がるほど大きくなります。そこに追加のd6ダイスが加わり、レベルが高い戦闘参加者ほど多く振ります。クリティカルヒットでは合計が1.5倍になります。そのあと、防御側のDefenseが、そのダメージから自分のDefenseの値の最大40パーセントぶんを防ぎます。

<a id="difficulty-scaling"></a>

### 難易度による補正

次に、設定ウィザードで設定した**Difficulty**(難易度)に応じてダメージが補正されます。天候と状態異常による補正は、そのあとに適用されます。この倍率は敵の攻撃にだけ適用されるので、難しいゲームほど敵の攻撃は重くなりますが、パーティーのダメージは変わりません。

| Difficulty | 敵のダメージ倍率 |
| --- | --- |
| Casual | 0.6 |
| Normal | 1.0 |
| Hard | 1.3 |
| Brutal | 1.6 |

これらの倍率は、Marinara独自のルールのものです。ルールセットは独自の難易度の方針を持ちます。

## 状態異常と元素反応

状態異常とは、戦闘参加者のAttack、Defense、Speed、HPに対する一時的な変化です。バフは有利に、デバフは不利にはたらきます。状態異常は決まったラウンド数だけ続き、そのあと切れます。毒系の効果は毎ラウンドHPを削り、再生系の効果はHPを回復します。凍結、スタン、拘束は、かかった戦闘参加者のターンを飛ばします。

攻撃やスキルの中には、属性を持つものがあります。対象に最初に命中した属性は、オーラ(しばらく残る痕跡)を残します。そこへ別の属性が同じ対象に当たると元素反応が起こり、追加ダメージが入ります。状態異常をともなうこともよくあります。反応には、Melt、Shatter、Overload、Superconduct、Toxic Blaze、Purification、Eclipse、Electrotoxinがあります。反応は自動で起こり、オンにする操作は必要ありません。

### 属性

どの属性があるかは、舞台設定によって決まります。

- 舞台設定キットがない場合、または属性を指定していないキットの場合: 従来の6属性(火、氷、雷、毒、聖、闇)です。
- 武侠: 五行(木、火、土、金、水)です。それぞれが次の属性に打ち勝ちます。
- サイバーパンクとスペースオペラ: 運動、熱、EM、化学またはプラズマです。
- 現代と1920年代: 属性はありません。

屋外の雨や嵐は、火のような属性を弱め、雷のような属性を強めます。Tactical戦闘では、属性は自分が打ち勝つ属性に対しては強く、自分に打ち勝つ属性に対しては弱くなります。キットの属性と反応は、**Change its words**(言葉を変更)で変更できます。[舞台設定キットの選択](getting-started.md#choosing-a-setting-kit)を参照してください。

## ボス特有の仕掛けと戦利品

強力な敵には、ボス特有の仕掛けがあることがあります。これは、その戦闘のためにGMが書く特別なルールです。仕掛けは、数ラウンドごとのような決まったスケジュールで、またはボスの体力が決められた値を下回ったときに発動します。パーティー全体を攻撃したり、ボスを強化したり、状態異常をかけたりします。発動すると**Combat Log**(戦闘ログ)に表示されるので、それを見て対応できます。

戦闘に勝つと、敵が戦利品を落とし、それはそのままパーティーのバッグに入ります。アイテムにはレアリティーがあり、common、uncommon、rare、epic、legendaryの順に上がります。難易度が高いほど、よりレアなアイテムが出やすくなり、落とす数も少し増えます。何が落ちたかは通知で表示され、それがすでにバッグに入っていることがGMに伝えられます。

何が落ちるかは舞台設定によって決まります。舞台設定キットを使うゲームでは、キット独自の戦利品が落ちます(現代のゲームなら、魔法の剣ではなくギフトカードや救急箱が落ちます)。これらの言葉は**Change its words**(言葉を変更)で変更できます。キットのないゲームでは、そのジャンルによくあるものが落ちます。Steampunkのようにスターターキットのないジャンルでは、どの舞台設定にも属さない一般的なものが落ちます。ルールセットが独自の戦利品表を持つゲームでは、代わりにルールセットのアイテムが落ちます。Game Mode独自のアイテムをオフにしたルールセットでは、ルールセット自身のアイテムだけが落ちます。

## リファレンス: Tactical戦闘

<a id="tactical-battles-and-terrain"></a>

### Tactical戦闘と地形

ゲームの作成時に入力する戦場の設定はありません。戦闘ごとに、新しいシードと、その場面に対するGMの概要から専用の盤面が生成されます。GMは環境、陣形、短い地形の概要を渡します。概要では、中央や端の付近に地形のまとまりや障害物を指定できます。具体的なタイルと初期配置はMarinaraが作ります。採用された戦場は保存されるので、再読み込みしても同じ盤面が復元されます。

Marinaraは概要と配置を検証します。要求された地形を保ちながら、戦闘で到達できる配置を確保します。

制約を両立できない場合、戦闘は問題を表示します。そのとき**Use generated terrain**(生成された地形を使う)を押すと、拒否された地形要素なしで開始します。要素が黙って消されることはありません。

世界には、手作りの戦場を持たせることもできます。これは、Pixelforgeなどのワールドエディターで、世界のある場所のためにタイルを1枚ずつ描いた盤面です。その場所、またはその中で戦闘が始まると、生成された盤面の代わりにそうした盤面のどれかが使われます。

- 盤面は描かれたとおりに使われます。その場所に盤面が複数ある場合は、戦闘のシード(1つを選ぶための数値)で決まります。
- そこではGMの地形の概要は使われませんが、陣形は引き続き各陣営の開始位置を決めます。GMには、この盤面がこの場所のために作られたことが伝えられます。
- 手作りの盤面は、3つのルールに従う必要があります。3種類の盤面サイズのどれかであること、両端の2列ずつが各陣営の並ぶ平原であること、戦闘参加者が立てるすべてのタイルがほかのタイルとつながっていることです。ルールに反する盤面は、作成ツールが理由を示して受け付けません。

これらの盤面は世界に手で加えた編集とともに保存されるので、ワールドファイル、マップパック、ライブラリーを通じて持ち運べます。

| 地形 | 歩行 | 防御と回避 |
| --- | --- | --- |
| 平原 | 移動ポイント1消費 | ボーナスなし |
| 森 | 移動ポイント2消費 | 防御+1、回避+15パーセントポイント |
| 廃墟 | 移動ポイント1消費 | 防御+1、回避+10パーセントポイント |
| 山、水、壁 | 歩行不可 | ボーナスなし |

飛行やテレポートの能力が設定されたユニットは、別の方法で移動します。

- **歩行**は、到達可能な地面のタイルをたどります。敵ユニットは経路をふさぎ、占有されたタイルで移動を終えることはできません。
- **飛行**は、途中の地形やユニットを越え、森も含めて1タイルにつき移動ポイント1を消費します。通常は通れないタイルの上に浮かんで止まれますが、別のユニットの上では移動を終えられません。
- **テレポート**は、途中の地形やユニットを無視します。移動先は移動範囲内で、空いていて、歩行可能である必要があります。壁の中、山の上、足場のない水の上では移動を終えられません。

どちらの特殊な移動方法も、現在の移動可能量と、縦横方向(斜めではない)のタイル距離を使います。移動先の地形の防御・回避ボーナスは維持され、高さは無視されます。飛行するユニットの高度、天井、呪文固有のコストや呪文固有の視認条件は表現されません。召喚は、Marinara独自の戦闘にはまだ含まれていません。

<a id="turn-order"></a>

### ターンの順番

Tactical戦闘では、次の2つのどちらかの方法でターンを進めます。

- **One at a time, by initiative**(イニシアチブ順に1体ずつ): すべてのユニットが振った順番の中に位置を持ち、自分のターンのユニットだけが行動できます。盤面にターンの順番が表示されます。新しいOverworld RPGのゲームはこの方法を使います。
- **Your whole party, then the enemies**(パーティー全員、次に敵): パーティーの各ユニットが行動してから、敵フェーズに進みます。Classicのゲームはこの方法を使います。

変更するには、**Chat Settings**(チャット設定)を開き、**Combat Style**(戦闘スタイル)を展開して、**Turn order**(ターンの順番)を選びます。この項目は、**Battle system**(戦闘システム)がTacticalのときに表示されます。ただし、ゲームのルールセットが独自に戦闘を行う場合は表示されません。変更は次の戦闘から適用され、進行中の戦闘は元の順番のままです。

<a id="sight-cover-and-height"></a>

### 視界、遮蔽、高さ

- **視界。** 壁と山は視界を遮ります。ユニットが攻撃、スキル、アイテムを使えるのは、見えている対象に対してだけです。
- **遮蔽。** 攻撃側と対象の間にあるものが対象を守ります。間にある森や廃墟のタイル、または視界の一部を遮る壁や山は、半遮蔽になります。視界の大部分を遮る壁や山は、4分の3遮蔽になります。半遮蔽は命中率を15パーセントポイント、4分の3遮蔽は30パーセントポイント下げます。対象自身のタイルのボーナスと遮蔽は合算されず、高いほうが適用されます。
- **高さ。** 山のある盤面では、山は2段の高さがあり、その周りの地面は1段の高さです。1段上ると移動ポイントが1多くかかり、下るときはかかりません。2段以上の段差は崖で、誰も歩いて越えられません。高い地形は、それより低い2つのタイルの間の視界も遮ります。高所から下へ攻撃すると命中率に10が加わり、高所からの遠距離攻撃は1タイル遠くまで届きます。また、森のような低い遮蔽は、上からの攻撃に対して対象を隠しません。手作りの戦場には、独自の崖があることもあります。

### 戦場のシーン

Tactical戦闘の盤面は、戦闘が起きる場所の種類に合わせて配置されます。森には身を隠す木があり、ダンジョンには壁と通路が、街には通りがあります。舞台設定キットを使うゲームでは、キットの言葉で独自のシーンが名付けられます。そのため、サイバーパンクの戦闘は屋上やメガブロックの通路で、武侠の戦闘は竹林や茶館で起こります。盤面のタイルも舞台設定の言葉で呼ばれます(森や廃墟ではなく、遮蔽物や瓦礫)。キットのシーンとタイルの言葉は、**Change its words**(言葉を変更)で変更できます。
