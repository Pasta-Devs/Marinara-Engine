# ゲームアセット: 音楽、効果音、スプライト、背景

このガイドでは、Game Modeが音楽、効果音、キャラクターの絵、シーンの背景に使うゲームアセットのライブラリーを説明します。最初から入っているスターターセット、ファイルマネージャーの**Asset Browser**(アセットブラウザー)、自分のファイルのアップロード、ゲームごとに使えるアセットの選び方、Game Modeが生成できる効果音と音楽を扱います。

## ゲームアセットとは

ゲームアセットとは、セッション中にGame Modeが再生したり表示したりするメディアファイルです。Marinara Engineはこれらを5つのカテゴリーに分けて管理します。

- **Music**(音楽): シーンに合わせて切り替わる背景音楽です。
- **Ambient**(環境音): 自然、都市、屋内などの、ループ再生する環境の音です。
- **Sound Effects**(効果音。SFXとも呼びます): メニュー、戦闘、探索で鳴る短い音です。
- **Sprites**(スプライト): 画面に表示するキャラクターや物の絵です。
- **Backgrounds**(背景): 物語の後ろに表示するシーンの画像です。

Game Modeはこのライブラリーを自分で読み込みます。シーンに合わせて音楽、環境音、背景を自動で選ぶので、プレイ中にアセットを手作業で割り当てる必要はありません。

## 同梱のスターターセット

Marinaraはサーバーの初回起動時に、無料のスターターライブラリーをインストールします。同梱のセットが変わった場合は、次回以降の起動時にファイルを入れ替えます。スターターセットの内容は次のとおりです。

- 5つの**Music**トラック。いくつかのシーンの雰囲気に1つずつ対応します。
- 自然、都市、屋内のフォルダーに分けて入った**Ambient**のループ音源一式。
- メニュー、戦闘、探索用の**Sound Effects**。

**Backgrounds**は同梱されていません。背景のフォルダーは空の状態から始まります。画像をアップロードするか、Game Modeがシーンの絵を生成したときに中身が増えます。
キャラクターの**Sprites**も同梱されていません。自分のゲームに合うキャラクターの絵だけを追加してください。

同梱ファイルのライセンスはすべてCC0です。つまりパブリックドメインで、自由に使えます。各ファイルのクレジットは、アセットと一緒にディスク上に置かれる`CREDITS.md`というテキストファイルにまとまっています。アプリの中には表示されません。

同梱のファイルとフォルダーは保護されています。**Asset Browser**からは削除も移動もできないので、スターターライブラリーはそのまま残ります。名前の変更とコピーはできます。

## Asset Browserの開き方

**Asset Browser**は、ゲームアセット用のファイルマネージャーです。開き方は2とおりあります。

**Settings**(設定)から開く場合:

1. **Settings**を開きます。
2. **Imports**(インポート)タブに移動します。
3. **Game Assets**(ゲームアセット)セクションを探します。
4. **Asset Browser**ボタンをクリックします。

ゲームから開く場合:

1. Game Modeのチャットを開きます。
2. **Game Assets**ボタン(フォルダーのアイコン)をクリックまたはタップします。最初はチャットの右上付近にあります。コンピューターでもスマートフォンでも、別の場所へドラッグできます。

このボタンはGame Modeのチャットにだけ表示されます。クリックすると**Asset Browser**を含む**Game Assets**が開きます。コンピューターでは移動できるウィンドウ、スマートフォンでは画面幅いっぱいのパネルになります。

**Put back in Chat Settings**(Chat Settingsに戻す)でこのウィンドウを移した場合は、代わりにChat Settings内の**Game Assets**セクションを開いてください。

上部のツールバーには、**Game Assets**から始まるパンくずリストがあります。その隣に**Grid view**と**List view**を切り替えるトグル、**Upload**(アップロード)ボタン、**New**(新規作成)ボタンが並びます。さらに**Rescan**(再スキャン)ボタン、**Open in system folder**(システムのフォルダーで開く)ボタン、**Search in folder**(フォルダー内を検索)欄もあります。画面の広い環境では、左側のフォルダーツリーからカテゴリー間を移動できます。

## 自分のアセットのアップロード

アセットのアップロード方法は2とおりあります。やりやすいほうを使ってください。

### Asset Browserからのアップロード

1. **Asset Browser**を開きます。
2. 5つのカテゴリーフォルダーのどれか、またはその中のサブフォルダーをクリックして開きます。
3. **Upload**をクリックしてファイルを選ぶか、ファイル一覧の領域にファイルをドラッグします。

先にカテゴリーフォルダーの中に入っておく必要があります。最上位でファイルをドロップすると、アップロードの前にカテゴリーフォルダーを開くようアプリが促します。

### Settingsからのアップロード

1. **Settings**を開き、**Imports**タブに移動します。
2. **Game Assets**セクションを探します。
3. **Type**(種類)メニューからカテゴリーを選びます: **Music**、**Ambient**、**Sound Effects**、**Sprites**、**Backgrounds**。
4. **Folder**(フォルダー)欄に保存先を指定するか、提案されたデフォルトのままにします。
5. **Choose Files**をクリックしてファイルを選びます。
6. **Upload to Server**をクリックします。

**Type**を選ぶと、**Folder**欄に妥当なデフォルトが入ります。デフォルトは次のとおりです。

- **Music**: `exploration/fantasy/calm`
- **Ambient**: `nature`
- **Sound Effects**: `exploration`
- **Sprites**: `generic-fantasy`
- **Backgrounds**: `custom`

### ファイル形式とサイズの制限

サーバーはアップロードされたファイルをすべてこの条件で確認します。条件はどちらのアップロード方法にも当てはまります。

| カテゴリー                    | 対応するファイル形式                 |
| ----------------------------- | ------------------------------------ |
| Music, Ambient, Sound Effects | MP3, OGG, WAV, FLAC, M4A, AAC, WebM  |
| Sprites                       | PNG, JPG, JPEG, GIF, WebP, AVIF, SVG |
| Backgrounds                   | PNG, JPG, JPEG, GIF, WebP, AVIF      |

音声ファイルと画像ファイルは1つあたり50 MBまでです。テキストファイルは10 MBまでです。カテゴリーに合わないファイル形式はサーバーが受け付けません。エラーメッセージに対応する形式が一覧で表示されます。

### 音楽のフォルダーの決まり

音楽にはフォルダー構成の厳密な決まりがあります。音楽のトラックは必ず`state/genre/intensity`という3階層のパスに置きます。たとえば`exploration/fantasy/calm`です。パスがこの形と一致しないとアップロードは失敗します。

使える値は次のとおりです。

- State: `exploration`、`dialogue`、`combat`、`travel_rest`。
- Genre: `fantasy`、`horror`、`romance`、`mystery`、`scifi`、`modern`、`slice_of_life`、`adventure`、`drama`、`custom`、または`wuxia`のような舞台設定の系統(下記を参照)。
- Intensity: `calm`、`tense`、`intense`。

Game Modeはこの構成を手がかりに、どのトラックをいつ再生するかを判断します。環境音、効果音、スプライト、背景のフォルダーにはこの決まりがありません。サブフォルダーの名前は自由に付けられます。

<a id="a-settings-own-art-and-music"></a>

### 舞台設定ごとのアートと音楽

舞台設定キットを使って始めたゲームには、アートの系統があります。系統は、キットの言葉を変更するときに**Art and music**(アートと音楽)の下に表示されます。値は`fantasy`、`scifi`、`modern`、`wuxia`、`jazz_age`、`wasteland`、またはキット独自の系統です。ゲームは、自分の系統の名前が付いたフォルダーと、どの系統の名前も付いていないすべてのフォルダーを使い、ほかの系統のフォルダーは使いません。そのため、サイバーパンクのゲームでファンタジーの戦闘音楽が流れたり、魔法の森が表示されたりすることはありません。自分の系統のフォルダーにも共有のフォルダーにも合うものがないときは、ほかの系統のトラックを流さず、何も再生しません。

- **Music**(音楽): その舞台設定のトラックは`music/<state>/<family>/<intensity>`に置きます。たとえば`combat/wuxia/intense`です。共有のトラックより優先して再生されます。
- **Backgrounds**(背景): `backgrounds/<family>`です。舞台設定キットを使うゲームの途中で生成された背景も、ここに保存されます。
- **Combat sounds**(戦闘の効果音): `sfx/combat/<family>`に、`sword-swing`のような同梱の効果音と同じ名前の音を置くと、その系統のゲームでは同梱の音の代わりに使われます。同梱の戦闘の効果音はファンタジー用なので、ほかの系統の戦闘は、その系統の音を追加するまで静かなままです。

同梱のスターター背景は共有として扱われます。ただし、ファンタジー用の背景(`ancient_library`、`castle_cliff`、`enchanted_forest`)とモダン用の`city_night`は除きます。舞台設定キットのないゲームは、これまでどおりすべてのフォルダーを使います。アートの系統が導入される前に保存された舞台設定キットも、そのまま使えます。スターターキットから作ったキットはそのスターターの系統を使い、それ以外のキットは、**Art and music**で系統を選ぶまですべてのフォルダーを使います。[ゲームごとに使うアセットの選択](#choosing-which-assets-a-game-can-use)で説明している選択バーには、開いているゲームの系統が表示されます。

## アセットの整理

**Asset Browser**を使うとファイルを整理できます。デスクトップではファイルやフォルダーを右クリックするか、その「...」メニューを開くと、実行できる操作が表示されます。

ファイルに対する操作:

- **Rename**(名前の変更): ファイルに新しい名前を付けます。同じフォルダーに同じ名前がすでにあると失敗します。
- **Move**(移動)と**Copy**(コピー): フォルダー選択画面を使って、ファイルを別のフォルダーへ送ります。
- **Delete**(削除): ファイルを削除します。
- **Download**(ダウンロード): ファイルをデバイスに保存します。

フォルダーに対する操作:

- **Create subfolder**(サブフォルダーの作成): その中に新しいフォルダーを作ります。
- **Open in system folder**: コンピューターのファイルマネージャーでそのフォルダーを表示します。
- **Delete folder**(フォルダーの削除): フォルダーを削除します。中にまだファイルがある場合は、先に**Delete everything inside**(中身をすべて削除)にチェックを入れる必要があります。

ツールバーの**New**ボタンからも、今開いているフォルダーに項目を作れます。**New folder**、**New text file**、**New markdown file**を選べます。

複数のファイルをまとめて操作するときは、各ファイルのチェックボックスを使います。選んだファイル数を示すバーが表示され、**Select all**(すべて選択)、**Move**、**Copy**、**Delete**のボタンが並びます。ファイル数の多いフォルダーは中身を一部ずつ表示し、**Load more**(もっと読み込む)ボタンで続きを表示します。

フォルダーごとに短いメモを付けられます。フォルダーの説明文、または**Add description...**のヒントをクリックして入力します。5つのカテゴリーフォルダーの説明は固定で、変更できません。

同梱のスターターファイルが保護されている点にも注意してください。名前の変更とコピーはできますが、移動と削除はできません。

## アプリ外での変更後の再スキャン

MarinaraはGame Modeがアセットを素早く見つけられるように、内部の一覧を保持しています。アプリからアップロードした場合、この一覧は自動で更新されます。

アプリを通さず、コンピューター上でゲームアセットのフォルダーに直接ファイルをコピーした場合、アプリはすぐには気づきません。**Rescan**ボタンをクリックすると、フォルダーを読み直して新しいファイルを取り込みます。**Rescan**は**Asset Browser**のツールバーと、**Settings**の**Game Assets**セクションの両方にあります。

<a id="choosing-which-assets-a-game-can-use"></a>

## ゲームごとに使うアセットの選択

Game Modeのチャットごとに、使うアセットフォルダーを一部だけに絞れます。たとえばホラーのゲームで明るい音楽を鳴らしたくないときに便利です。

設定ウィザードでは、**Features**ステップの**Adjust Game Assets for this Game**を展開します。すでに始めているゲームでは、そのゲームの**Game Assets**ウィンドウを開きます。

続いて、次の操作をします。

1. **Game assets**ボタンをクリックします。有効な間は表示が**Selecting**に変わります。
2. 各フォルダーの小さな状態表示で、対象に含めるか除外するかを切り替えます。

バーには「All folders included」か、除外したフォルダーの数が表示され、すべてを含む状態に戻す**Reset to all**ボタンが並びます。この設定は、そのチャットにだけ保存されます。Game Modeが選べるフォルダーが変わるだけで、ファイルが削除されたり隠されたりすることはありません。そのGame Modeのチャットの外には影響しません。

<a id="generated-sound-effects-and-music"></a>

## 生成される効果音と音楽

Game Modeは、AI音声サービスのElevenLabsを使って、シーンに合った新しい効果音や音楽を作ることもできます。ElevenLabsのAPIキーが必要です。新しい効果音やトラックを1つ作るたびに、自分のアカウントでElevenLabsへのリクエストが1回発生します。

まず、音声の接続を設定します。

1. **Connections**(接続)パネルを開き、**Audio**プロバイダーの接続を作成します。
2. **Audio Source**で**ElevenLabs**を選び、ElevenLabsのAPIキーを貼り付けます。
3. **Game sound effects**、**Game music**、またはその両方をオンにします。これらのスイッチは**ElevenLabs**ソースでのみ表示されます。
4. 接続を保存します。

次に、ゲームを作成するときにオンにします。

1. 設定ウィザードの**Features**ステップで、**Game Audio**カードを探します。
2. **Audio Connection**でElevenLabsの接続を選ぶか、**Use the default audio connection**(デフォルトの音声接続を使う)のままにします。
3. **Sound effects**と**Music**はオンのままにするか、不要なほうをオフにします。

選んだ接続が、該当するスイッチをオンにしたElevenLabsの接続でない限り、**Sound effects**や**Music**はオンにできません。そのような場合は、カードに表示されます。

プレイ中は次のように動きます。

- **Sound effects**: GMのターンのあと、Marinaraはシーンに合った短い効果音をElevenLabsに依頼します。
- **Music**: Marinaraは、パーティーが訪れる場所ごと、そしてボス戦などの戦闘の種類ごとに、約2分のインストゥルメンタルのトラックを1つずつ作曲します。各トラックは一度だけ作られ、その後は再利用されます。新しい場所のトラックは、シーンの途中で音楽が割り込まないよう、その後のシーン切り替えのタイミングで始まります。戦闘のトラックは、準備ができしだいフェードインします。

生成した効果音とトラックはゲームアセットと一緒に保存されるため、同じ音が二度作られることはありません。**Music DJ**がゲームの音楽を再生している場合、Game Modeは音楽を生成しません。

## Music DJ用のカスタム音楽フォルダー

**Music DJ**は、ゲーム中に音楽を再生できるエージェントです。Customモードで動くときは、指定したフォルダーのトラックを再生します。このフォルダーは2か所で設定できます。

チャットで**Music DJ**を有効にすると、設定フォームはMusic DJエージェントに保存された取得元に従います。**Game Assets**には、`music`や`music/combat`のようにゲームアセット内のパスが表示されます。**Folder on this device**には、保存済みのサーバー側のパスと**Choose Folder**ボタンが表示されます。

**Music DJ**の詳細なエディターには、**Custom Music Library**セクションがあります。ここの**Use Game Assets music folder**スイッチで、2つのモードを切り替えます。

- スイッチをオンにした場合: **Game Assets music folder**欄に、`music`や`music/combat`のようなゲームアセット内のフォルダーを指定します。**Open Folder**ボタンを押すと、サーバーのコンピューター上でそのフォルダーが開きます。
- スイッチをオフにした場合: **Music folder on this device**欄を使うと、Customモードはサーバーを動かしているコンピューター上のどのフォルダーからでも音楽を再生できます。**Select Folder**をクリックしてシステムのフォルダー選択画面を開くか、フォルダーのパスを欄に貼り付けます。

アプリの外にあるフォルダーを選ぶには、特別な権限が必要です。サーバーと同じコンピューターで使っている場合は、追加の設定なしで動きます。別のデバイスからの操作やリモートアクセス経由の場合は、先に管理者アクセスを設定してください。有効にする手順は[リモートアクセス](../REMOTE_ACCESS.md)を参照してください。音楽プレイヤーのそのほかの機能については[Music DJ](../media/music.md)を参照してください。

## コンピューターでフォルダーを開く

**Open in system folder**ボタンは、選んだアセットフォルダーをコンピューター標準のファイルマネージャーで開きます。これはサーバーを動かしているコンピューターでアプリを使っているときだけ機能します。スマートフォン、タブレット、別のコンピューターから使っている場合は、システムのフォルダーはMarinaraを動かしているデバイスからしか開けない、というメッセージが表示されます。
