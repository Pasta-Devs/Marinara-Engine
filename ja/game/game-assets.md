# ゲームアセット: 音楽、効果音、スプライト、背景

ゲームアセットとは、Game Modeが再生したり表示したりするメディアファイルです。音楽、音、キャラクターの絵、シーンの背景があります。このガイドでは、スターターセットの使い方、**Asset Browser**(アセットブラウザー)での自分のファイルのアップロード、ゲームで使えるアセットの制限、効果音と音楽の生成について説明します。

Game Modeはライブラリーを自分で読み込みます。シーンに合わせて音楽、環境音、背景を選ぶので、プレイ中にアセットを手作業で割り当てる必要はありません。

| カテゴリー | 内容 |
| --- | --- |
| **Music**(音楽) | シーンに合わせて切り替わる背景音楽です。 |
| **Ambient**(環境音) | 自然、都市、屋内などの、ループ再生する環境の音です。 |
| **Sound Effects**(効果音、SFX) | メニュー、戦闘、探索で鳴る短い音です。 |
| **Sprites**(スプライト) | 画面に表示するキャラクターや物の絵です。 |
| **Backgrounds**(背景) | 物語の後ろに表示するシーンの画像です。 |

## スターターセット

Marinaraは、サーバーの初回起動時に無料のスターターライブラリーをインストールします。同梱のセットが変わった場合は、次回以降の起動時に更新します。内容は次のとおりです。

- 5つの**Music**トラック。シーンのさまざまな雰囲気に合わせたものです。
- `nature`、`urban`、`interior`の各フォルダーに入った**Ambient**のループ音源。
- メニュー、戦闘、探索用の**Sound Effects**。

Asset Browserの**Backgrounds**フォルダーと**Sprites**フォルダーは、空の状態から始まります。キャラクターのスプライトは同梱されていないので、自分のゲームに合う絵を追加してください。背景については、Game Modeはアプリ自身の背景ライブラリーも使います。新しくインストールした場合、このライブラリーには13枚のスターター画像と無地の`Black.jpg`が入っており、ゲームはアップロードなしでそれらを使えます。そのフォルダーにすでに画像があった場合は、`Black.jpg`だけが復元されます。生成されたシーンの絵や自分でアップロードした画像は、それらに追加されます。

同梱の音声のライセンスはすべてCC0(パブリックドメイン、自由に使用可能)です。各ファイルのクレジットは、アセットと一緒にディスク上に置かれる`CREDITS.md`ファイルにあります。アプリの中には表示されません。

同梱のファイルとフォルダーは保護されています。**Asset Browser**では削除も移動もできませんが、名前の変更とコピーはできます。

## Asset Browserを開く

**Asset Browser**は、ゲームアセット用のファイルマネージャーです。**Settings**(設定)から開く手順は次のとおりです。

1. **Settings**を開きます。
2. **Imports**(インポート)タブに移動します。
3. **Game Assets**(ゲームアセット)を探し、**Asset Browser**をクリックします。

ゲームから開くこともできます。

1. Game Modeのチャットを開きます。
2. チャットの右上付近にある**Game Assets**ボタン(フォルダーのアイコン)をクリックまたはタップします。このボタンは、コンピューターでもスマートフォンでも別の場所へドラッグできます。

このボタンはGame Modeのチャットにだけ表示されます。押すと、**Asset Browser**を含む**Game Assets**が開きます。コンピューターでは移動できるウィンドウ、スマートフォンでは画面幅いっぱいのパネルになります。**Put back in Chat Settings**(Chat Settingsに戻す)で移した場合は、代わりにChat Settingsの**Game Assets**セクションを開いてください。

ツールバーには、**Game Assets**から始まるパンくずリスト、**Grid view**(グリッド表示)と**List view**(リスト表示)の切り替え、**Upload**(アップロード)、**New**(新規)、**Rescan**(再スキャン)、**Open in system folder**(システムのフォルダーで開く)、**Search in folder**(フォルダー内を検索)欄があります。画面の広い環境では、左側のフォルダーツリーでカテゴリー間を移動できます。

## 自分のアセットをアップロードする

Marinaraは、すべてのアップロードを[ファイル形式とサイズ](#file-types-and-sizes)のルールに照らして確認します。次のどちらの方法でもアップロードできます。

### Asset Browserからアップロードする

1. **Asset Browser**を開きます。
2. 5つのカテゴリーフォルダーのどれか、またはその中のサブフォルダーを開きます。
3. **Upload**をクリックしてファイルを選ぶか、ファイルの領域にファイルをドラッグします。

カテゴリーフォルダーの中にいる必要があります。最上位でファイルをドロップすると、先にカテゴリーフォルダーを開くようアプリが求めます。

### Settingsからアップロードする

1. **Settings**を開き、**Imports**タブに移動します。
2. **Game Assets**で、**Type**(種類)からカテゴリーを選びます。**Music**、**Ambient**、**Sound Effects**、**Sprites**、**Backgrounds**のどれかです。
3. **Folder**(フォルダー)で保存先を指定するか、デフォルトのままにします。
4. **Choose Files**(ファイルを選択)をクリックしてファイルを選びます。
5. **Upload to Server**(サーバーにアップロード)をクリックします。

うまくいかなかった場合: エラーメッセージに、そのカテゴリーで使えるファイル形式が一覧で表示されます。音楽の場合は、フォルダーのパスを確認してください([音楽のフォルダーの決まり](#the-music-folder-rule)を参照)。

**Folder**のデフォルト値は次のとおりです。

| 種類 | デフォルトのフォルダー |
| --- | --- |
| **Music** | `exploration/fantasy/calm` |
| **Ambient** | `nature` |
| **Sound Effects** | `exploration` |
| **Sprites** | `generic-fantasy` |
| **Backgrounds** | `custom` |

<a id="file-types-and-sizes"></a>

### ファイル形式とサイズ

| カテゴリー | 使えるファイル形式 |
| --- | --- |
| Music, Ambient, Sound Effects | MP3, OGG, WAV, FLAC, M4A, AAC, WebM |
| Sprites | PNG, JPG, JPEG, GIF, WebP, AVIF, SVG |
| Backgrounds | PNG, JPG, JPEG, GIF, WebP, AVIF |

音声ファイルと画像ファイルは1つあたり50 MBまでです。テキストファイルは10 MBまでです。

<a id="the-music-folder-rule"></a>

### 音楽のフォルダーの決まり

音楽のトラックは、必ず`state/genre/intensity`という3階層のパスに置きます。たとえば`exploration/fantasy/calm`です。パスがこの形と一致しないと、アップロードは失敗します。Game Modeはこの構成を手がかりに、どのトラックをいつ再生するかを判断します。

- State: `exploration`、`dialogue`、`combat`、`travel_rest`。
- Genre: `fantasy`、`horror`、`romance`、`mystery`、`scifi`、`modern`、`slice_of_life`、`adventure`、`drama`、`custom`、または`wuxia`のような舞台設定の系統(下記を参照)。
- Intensity: `calm`、`tense`、`intense`。

環境音、効果音、スプライト、背景のフォルダーには、このような決まりはありません。サブフォルダーの名前は自由に付けられます。

## アセットを整理する

コンピューターではファイルやフォルダーを右クリックするか、その「...」メニューを開くと、実行できる操作が表示されます。

| ファイルの操作 | 内容 |
| --- | --- |
| **Rename**(名前を変更) | そのフォルダーに同じ名前がすでにあると失敗します。 |
| **Move**(移動)、**Copy**(コピー) | フォルダーの選択画面で、ファイルを別のフォルダーへ送ります。 |
| **Delete**(削除)、**Download**(ダウンロード) | ファイルを削除するか、デバイスに保存します。 |

| フォルダーの操作 | 内容 |
| --- | --- |
| **Create subfolder**(サブフォルダーを作成) | その中に新しいフォルダーを作ります。 |
| **Open in system folder**(システムのフォルダーで開く) | コンピューターのファイルマネージャーでそのフォルダーを表示します。 |
| **Delete folder**(フォルダーを削除) | 中にファイルがある場合は、先に**Delete everything inside**(中身もすべて削除)にチェックを入れます。 |

ツールバーの**New**(新規)を使うと、今のフォルダーに**New folder**(新しいフォルダー)、**New text file**(新しいテキストファイル)、**New markdown file**(新しいMarkdownファイル)を作れます。複数のファイルをまとめて操作するときは、それぞれのチェックボックスをオンにします。選んだ数を示すバーが表示され、**Select all**(すべて選択)、**Move**、**Copy**、**Delete**が並びます。ファイル数の多いフォルダーは一部ずつ読み込まれ、**Load more**(さらに読み込む)ボタンで続きを表示します。

フォルダーごとに短いメモを付けられます。説明文、または**Add description...**のヒントをクリックして入力します。5つのカテゴリーフォルダーの説明は固定です。

### アプリ外で変更したあとの再スキャン

Marinaraは、Game Modeがアセットを素早く見つけられるように、アセットの内部一覧を保持しています。アプリからアップロードした場合、この一覧は自動で更新されます。アプリを通さずに、コンピューター上でゲームアセットのフォルダーにファイルをコピーした場合は、**Rescan**(再スキャン)をクリックしてフォルダーを読み直してください。**Rescan**は、**Asset Browser**のツールバーと、**Settings**の**Game Assets**にあります。

### コンピューターでフォルダーを開く

**Open in system folder**(システムのフォルダーで開く)は、サーバーを動かしているのと同じコンピューターでアプリを使っているときだけ機能します。スマートフォン、タブレット、別のコンピューターでは、システムのフォルダーはMarinaraを動かしているデバイスからしか開けない、とアプリが表示します。

## ゲームで使えるアセットを選ぶ

Game Modeのチャットでは、アセットフォルダーの一部だけを使うようにできます。たとえば、ホラーのゲームで明るい音楽を流したくないときに使います。

1. セットアップ中は、**Features**(機能)ステップで**Adjust Game Assets for this Game**(このゲームのゲームアセットを調整)を展開します。既存のゲームでは、そのゲームの**Game Assets**ウィンドウを開きます。
2. **Game assets**(ゲームアセット)をクリックします。表示が**Selecting**に変わります。
3. 各フォルダーの小さな状態表示を使って、そのフォルダーを含めるか除外するかを切り替えます。

バーには「All folders included」か、除外したフォルダーの数が表示されます。**Reset to all**(すべてにリセット)を押すと、すべてが再び含まれます。この選択はそのチャットにだけ保存されます。変わるのはGame Modeが選べるフォルダーだけで、ファイルが削除されたり隠されたりすることはありません。

<a id="a-settings-own-art-and-music"></a>

### 舞台設定ごとのアートと音楽

舞台設定キットを使って始めたゲームには、アートの系統があります。系統は、キットの言葉を変更するときに**Art and music**(アートと音楽)の下に表示されます。値は`fantasy`、`scifi`、`modern`、`wuxia`、`jazz_age`、`wasteland`、またはキット独自の系統です。ゲームは、自分の系統の名前が付いたフォルダーと、どの系統の名前も付いていないすべてのフォルダーを使い、ほかの系統のフォルダーは使いません。そのため、サイバーパンクのゲームでファンタジーの戦闘音楽が流れたり、魔法の森が表示されたりすることはありません。自分の系統のフォルダーにも共有のフォルダーにも合うものがないときは、ほかの系統のトラックを流さず、何も再生しません。舞台設定キットのないゲームは、すべてのフォルダーを使います。

- **Music**(音楽): その舞台設定のトラックは`music/<state>/<family>/<intensity>`に置きます。たとえば`combat/wuxia/intense`です。共有のトラックより優先して再生されます。
- **Backgrounds**(背景): `backgrounds/<family>`です。舞台設定キットを使うゲームで生成された背景も、ここに保存されます。
- **Combat sounds**(戦闘の効果音): `sfx/combat/<family>`に、`sword-swing`のような同梱の効果音と同じ名前の音を置くと、その系統のゲームでは同梱の音の代わりに使われます。同梱の戦闘の効果音はファンタジー用なので、ほかの系統の戦闘は、その系統の音を追加するまで静かなままです。

同梱のスターター背景は共有として扱われます。ただし、ファンタジー用の背景(`ancient_library`、`castle_cliff`、`enchanted_forest`)とモダン用の`city_night`は除きます。アートの系統が導入される前に保存された舞台設定キットも、そのまま使えます。スターターキットから作ったキットはそのスターターの系統を使い、それ以外のキットは、**Art and music**で系統を選ぶまですべてのフォルダーを使います。上で説明した選択バーには、開いているゲームの系統が表示されます。

<a id="generated-sound-effects-and-music"></a>

## 生成される効果音と音楽

Game Modeは、**Music & Sound Effects**(音楽と効果音)のアカウントを通して効果音や音楽を生成できます。ElevenLabs、SunoAPI、カスタム互換サーバーから選んでください。新しい音やトラックを作るたびに、そのサービスのアカウントを使います。同梱の音声は、生成なしで引き続き使えます。

**始める前に:** **Music & Sound Effects**のアカウントが必要です。**Add account**(アカウントの追加)ウィンドウには、このアカウント用のタイルはありません。これらのアカウントは、アップグレードかインポート(**Connections**(接続)の**Import a backup**(バックアップをインポート))によって作られます。[プロバイダーの設定と制限](../connections/providers-reference.md#music--sound-effects)を参照してください。

1. **Connections**で、**Edit model**(モデルの編集)からそのアカウントのモデルを開きます。
2. サービスを選び、キーを入力して、音楽と効果音のモデルを選びます。SunoAPIの音楽には、公開HTTPSコールバックURLも必要です。カスタムサーバーには、エンドポイントパスが必要です。
3. **Sound-effect generation**(効果音生成)、**Music generation**(音楽生成)、または両方をオンにします。
4. アカウントを保存します。[プロバイダーの設定と制限](../connections/providers-reference.md#music--sound-effects)を参照してください。

次に、ゲームを作成するときにオンにします。

1. 設定ウィザードの**Features**(機能)ステップで、**Game Audio**(ゲームの音声)カードを探します。
2. アカウントの選択で自分のアカウントを選ぶか、**Use the default Music & Sound Effects account**(デフォルトの音楽と効果音のアカウントを使用)のままにします。
3. **Sound effects**(効果音)と**Music**(音楽)はオンのままにするか、不要なほうをオフにします。

各スイッチを使うには、選んだアカウントで対応する機能がオンになっている必要があります。読み上げ専用のAudioアカウントは、生成には使われません。

プレイ中は次のように動きます。

- **Sound effects。** GMのターンのあと、Marinaraはシーンに合った短い効果音をサービスに依頼します。
- **Music。** Marinaraは、パーティーが訪れる場所ごと、そしてボス戦などの戦闘の種類ごとに、約2分のインストゥルメンタルのトラックを1つずつ作曲します。各トラックは一度だけ作られ、その後は再利用されます。新しい場所のトラックは、シーンの途中で音楽が割り込まないよう、その後のシーン切り替えのタイミングで始まります。戦闘のトラックは、準備ができしだいフェードインします。

生成した効果音とトラックはゲームアセットと一緒に保存されるため、同じ音が二度作られることはありません。**Music DJ**がゲームの音楽を再生している場合、Game Modeは音楽を生成しません。

## Music DJ用のカスタム音楽フォルダー

**Music DJ**は、ゲーム中に音楽を再生できる補助エージェントです。Customモードでは、指定したフォルダーのトラックを再生します。チャットで**Music DJ**を有効にすると、その設定に**Apply to**(適用対象)が表示されます。ここでは、フォルダーをこのチャット用、チャットにいる1人だけのキャラクター用、すべてのチャット用のどれとして保存するかを選びます。**In use:**には、そのチャットで再生するフォルダーが表示されます。**All chats (default)**(すべてのチャット、デフォルト)の場合、**Game Assets**のソースには、`music`や`music/combat`のようなゲームアセット内のパスを指定します。チャットやキャラクターに専用のフォルダーを持たせるには、[チャットやキャラクターごとに別のフォルダーを使う](../media/music.md#use-a-different-folder-for-a-chat-or-character)を参照してください。

**Music DJ**の詳細なエディターには、**Custom Music Library**(カスタム音楽ライブラリー)セクションがあります。**Use Game Assets music folder**(ゲームアセットの音楽フォルダーを使う)で、2つのモードを切り替えます。

- オン: **Game Assets music folder**(ゲームアセットの音楽フォルダー)欄で、ゲームアセット内のフォルダーを読み込みます。**Open Folder**(フォルダーを開く)を押すと、サーバーのコンピューター上でそのフォルダーが開きます。
- オフ: **Default music folder on this device**(この端末のデフォルトの音楽フォルダー)を使うと、サーバーを動かしているコンピューター上のどのフォルダーからでも音楽を再生できます。**Select Folder**(フォルダーを選択)をクリックするか、パスを貼り付けます。

アプリの外にあるフォルダーを選ぶには、特権アクセスが必要です。サーバーと同じコンピューターでは、追加の設定なしで動きます。別のデバイスからの操作やリモートアクセス経由の場合は、先に管理者アクセスを設定してください。[リモートアクセス](../REMOTE_ACCESS.md)を参照してください。音楽プレイヤーのそのほかの機能については、[Music DJ](../media/music.md)を参照してください。
