# Game Mode: マップ、時間、天候

マップパネルでは、パーティーがどこにいるかを確認し、パーティーを移動させます。このガイドでは、パーティーを取り巻く世界を追跡する仕組みも説明します。日付と時刻、天候、パーティーの士気です。

## マップパネル

Game Modeでは、ゲーム画面にマップパネルが表示されます。パネルには現在のマップ名、ゲーム内の日付、時間帯を表す空模様のアイコンが並びます。

- **コンピューターでは**、マップは画面に組み込まれたパネルとして表示され、ひと目で確認できます。パネルはドラッグして移動でき、位置を固定することもできます。ドラッグできるパネルの仕組みについては、[Game Mode: HUDウィジェット](hud-widgets.md)を参照してください。
- **スマートフォンでは**、**Map**(マップ)をタップするとパネルが開きます。このボタンは最初は左上付近にあり、チャット内でドラッグして動かせます。ボタンをその場に固定するには**Lock window**(ウィンドウを固定)を使い、ボタンに戻るには**Close**(閉じる)を使います。位置はチャットに保存されます。スマートフォンのマップは**Settings → Appearance → App**(設定 → 外観 → アプリ)で選んだチャットウィジェットのスタイルを使い、そのボタンは3点アイコンの**Chat tools**(チャットツール)メニューとは別に表示されます。

VNゲームには、ここで説明するシーンのマップがあります。オーバーワールド、町、ダンジョンのマップはOverworldゲームのもので、Overworldはまだ利用できません([VNとOverworld](getting-started.md#vn-or-overworld)を参照)。

### grid表示とnode表示

表示形式は、マップが表す場所の種類に応じてMarinaraが選びます。手動で切り替えることはありません。

- **grid**表示は、地方や街のような開けた場所に使われます。草原、森、水、山、砂漠、雪原、町、道、洞窟の地形ごとに色分けされたマス目で表示されます。
- **node**表示は、ダンジョンや屋内のような閉じた場所に使われます。各地点が円で表示され、線でつながります。まだ発見していない地点には疑問符が表示されます。破線はまだ通っていない経路、実線は通ったことのある経路です。

## パーティーを移動する

選べる場所は限られています。gridマップでは、パーティーの隣にあり、かつすでに発見済みのマスだけを選べます。nodeマップでは、現在地とつながっているノード、またはすでに発見済みのノードだけを選べます。それ以外のマスやノードはクリックしても何も起こりません。

1. gridのマスをクリックするか、nodeマップのノードをクリックします。
2. メッセージ入力欄の上に、場所の名前が入った**Map position:**(マップ上の位置)のチップが表示されます。
3. メッセージを入力して送信します。Marinaraがメッセージの先頭に`*moves to <place>*`のような短い一文を追加します。

取り消すには、**Map position:**のチップにあるクリアボタン(X)をクリックします。そのツールチップには**Clear destination**(目的地をクリア)と表示されます。

スマートフォンでは、ノードを1回タップして選択し、フッターの**Set destination**(目的地を設定)をタップします。**You are here**と表示されているノードが現在地です。

うまくいかなかった場合は、マスがパーティーの隣にあって発見済みか、ノードが現在地とつながっているかを確認してください。

### マップの拡大縮小、切り替え、生成

- **拡大縮小。** 右上の**Zoom in**(拡大、プラスのボタン)と**Zoom out**(縮小、マイナスのボタン)を使います。倍率は75%から180%まで、25%刻みで変わります。
- **マップの切り替え。** ゲームにマップや地方が2つ以上ある場合は、パネルの上部にあるドロップダウンで別のマップを表示できます。今いるマップには**(Current)**が付きます。
- **マップの生成。** 左上にある杖のボタン**Generate another map**(別のマップを生成)をクリックすると、現在のマップが新しいマップに置き換わります。マップのないゲームには**No map yet**と**Generate**(生成)ボタンが表示され、このボタンも同じ動作をします。

## 日付と時刻を手動で設定する

日付と時刻のコントロールは、マップパネルの上部にあります。**Day**(日)という表示と数字、そして空模様のアイコンが並びます。

1. **Day**のコントロールをクリックします。
2. 1から9999までの日付の数字を入力します。
3. 時間帯を選びます。**Dawn**、**Morning**、**Afternoon**、**Evening**、**Night**、**Midnight**のいずれかです。
4. 欄の外をクリックするか、<kbd>Enter</kbd>を押すと保存されます。

これは手動での上書きで、自動の時計とは別のものです。時計は自動で**Noon**を表示することもありますが、Noonは手動の選択肢にはありません。

## 時間の進み方

ゲーム内の時計は、AIではなく決まった計算で動きます。新しいゲームはどれもDay 1の08:00から始まります。行動を取るたびに、時計が進みます。

| 行動 | 進む時間 |
| --- | --- |
| 会話 | 15分 |
| 探索 | 30分 |
| 戦闘1ラウンド | 5分 |
| 短い休息 | 1時間 |
| 長い休息 | 8時間 |
| 移動 | 2時間 |

時計が深夜0時を回ると、日付の数字が1つ増えます。

世界を持つゲームでは、時間はほかにも自動で進みます。

- オーバーワールドが前面に表示され、ゲームが入力を待っている間は、現実の5秒ごとにゲーム内の1分が過ぎます。GMが書いている間、その返信を読む前、シーン表示が前面にある間、アプリがバックグラウンドにある間は止まります。
- オーバーワールドを歩くと、そのルートにかかる日数が過ぎます。
- ゲームマスター(GM)が日数の経過を告げたとき(旅、長い休息、待機)は、時計がその日数だけ進みます。返信を再生成しても、時計がもう一度進むことはありません。新しい語りでかかる時間が違う場合は、日付を手動で設定してください。

## 天候

ゲームは、AIではなく決まった計算で天候を管理します。天候は、バイオーム(砂漠、寒冷地、沿岸、山岳のように、パーティーがいる場所の種類)と季節で決まります。たとえば晴れ、曇り、雨、嵐、雪、吹雪、霧、砂嵐があります。天候は、移動したときと長い休息を取ったときにいちばん変わりやすく、探索したときにも変わることがあり、それ以外ではめったに変わりません。天候は、GMが各シーンを描写するときの雰囲気に反映されます。

天候を画面に表示するには、外観の設定で**Dynamic weather effects (rain, snow, fog, etc.)**(動的な天候エフェクト)をオンにします。デフォルトではオンです。オンにすると、雨、雪、霧の粒子がゲームの上に表示され、天候と時間帯に合わせて変わります。[外観の設定](../appearance/appearance-settings.md)を参照してください。

## パーティーの士気

ゲームは、0から100までのパーティーの士気を画面に出さずに管理しています。士気には低い順にBroken、Low、Steady、High、Inspiredの5段階があります。

士気は、戦闘に勝つ、クエストを達成する、宝物を見つけると上がります。戦闘に負ける、クエストに失敗する、仲間を失うと下がります。時間が経つと、士気は中間へ戻っていきます。士気は数値としては表示されません。GMがパーティーの雰囲気を描写するときの色合いに影響します。ダイスロールの結果は変わりません。

## オーバーワールドとそのほかのOverworldマップ

以下のセクションでは、まだ利用できない**Overworld**ゲームについて説明します。サーバーでこの機能がオンになっている場合にだけ当てはまります。

<a id="the-overworld"></a>

### オーバーワールド

生成された世界を持つゲーム([世界を作る](getting-started.md#making-a-world)を参照)は、**オーバーワールド**で開きます。オーバーワールドとは、語りの後ろにピクセルマップとして描かれた世界の地面です。森、丘、海岸、海、集落を結ぶ道や航路、大きさに応じて描かれた各集落、そしてパーティーが表示されます。大きな場所と今いる場所には名前が付きます。マップをドラッグすると見回せます。

1. 集落をタップまたはクリックするか、**Places**(場所)から選びます(近い順に、旅程の時間付きで並びます)。
2. その集落の大きさと、今いる場所からの旅程を確認します。何日または何時間かかるか、どの道を通るかが示されます。
3. **Walk there**(そこへ歩く)をクリックします。パーティーは世界の道に沿って最短のルートで進み、歩いた日数がすぐに時計に加わります。

次のターンで、どこへ歩いたか、どれだけかかったか、どの道を通ったかがGMに伝わるので、GMは到着の場面を語れます。次のターンの前にもう一度歩くと、最初の移動が終わった場所から続きます。

集落から少し離れた洞窟、鉱山、地下墓所、遺跡は、**サイト**として描かれます。新しい世界では地方ごとに1つか2つあり、隣の集落にちなんだ名前が付きます(「Hollin Caves」、「Ashby Ruins」)。**Walk there**を選ぶと、道に沿ってそのサイトの集落まで行き、そこから道を外れて歩きます。サイトでは、**Enter**(入る)でそのマップが開きます([ダンジョン、洞窟、ステーション](#dungeons-caves-and-stations)を参照)。物語にとって重要なサイトは、GMが開くまで**閉じた**ままです(薄く描かれ、旅も中へ入ることもできません)。世界の作成ツールでは、それまでサイトを隠しておくことも、最初から開いておくこともできます。

廃墟になった場所は廃墟として描かれます。日が暮れるとマップが暗くなり、窓に明かりがともります。舞台設定の系統(ファンタジー、武侠、現代、1920年代、SF、荒廃世界)ごとに専用のタイルがあります。系統のないキットは、無地のタイルで描かれます。

表示を切り替えるには、**Game controls**(ゲームの操作)の**Show the scene**(シーンを表示)と**Show the overworld**(オーバーワールドを表示)を使います(スマートフォンでは、3点アイコンの**Chat tools**(チャットツール)メニューの中にあります)。どちらを選んだかはゲームが覚えています。戦闘とセッションの再生には、それぞれ専用の画面があります。

### タイルパック

タイルパックは、パレットと、すべてのタイル(地面の種類、大きさ別の集落、パーティー、町の通り、屋根、町の人々)をピクセルの行として収めたものです。舞台設定の系統ごとに、組み込みのパックがあります。**Agents**(エージェント)パネルを開いて**Tile packs**(タイルパック)を探すと、次のことができます。

- 各舞台設定をどのパックで描くかを選びます。**Built in**(組み込み)は、その舞台設定自身のパックです。
- `.tilepack.json`ファイルから**Import a tile pack**(タイルパックをインポート)で取り込みます。
- **Export**(エクスポート)でパックを書き出して共有したり、**Remove**(削除)で削除したりします。削除すると、そのパックで描かれていた舞台設定は自身のタイルに戻ります。

パックには、変更するタイルだけを入れれば十分で、入っていないものは無地で描かれます。Marinaraが描かないタイルを指定しているパックは、残りのタイルを使い、何を除外したかを知らせます。

<a id="the-town"></a>

### 町

集落にいるときは、オーバーワールドでその集落を選び、**Enter**(入る)を選ぶと町が表示されます。町は世界の情報をもとに配置されます。通りと広場、世界や物語がその町に持つ場所(建物に名前が付きます)、大きな集落なら集会所、その町で知られた職業の仕事場、そして住まいです。人々は時刻に応じた場所にいます。昼は仕事場、夕暮れは広場、夜は家にいます。

建物か広場を選ぶか、**Places in town**(町の場所)から選ぶと、そこに誰がいるか、何分の距離かが表示されます。**Walk there**(そこへ歩く)を選ぶと、通りに沿い、建物や手で配置したレイアウトが描いたものを回り込み、その橋を渡って町を横切ります。かかった分数は時計に加わり、次のターンで、パーティーがどこへ行き、そこに誰がいるかがGMに伝わります。物語が加えた宿屋など、名前のある場所を訪れると、そこがパーティーの現在の場所になります。**Leave town**(町を出る)を押すとオーバーワールドに戻ります。どの表示にいたかはゲームが覚えています。

町は、世界に手で加えた編集の一部として、Pixelforgeなどの世界のエディターで**手で配置する**こともできます。

- 建物を別の区画へ移せます。別の建物の区画へ移した建物はその建物と入れ替わり、どの建物も必ず通りに面します。
- 地面には通り、舗装、空き地、木、井戸を描けます。ただし、建物の下、扉の前、広場の真ん中、市場の屋台の下には描けません。
- 誰がどこに住み、どこで働くかは変わりません。移した建物まで歩く時間は、新しい扉の位置から計算されます。
- 町に合わない配置は、エディターが理由を示して受け付けません。プレイ中に物語が加えた場所も、ちゃんと区画を見つけられます。
- 配置では、区画の外に建物を置いたり、畑、土の小道、橋の架かった水辺、生け垣を描いたり、飾りを置いたりすることもできます。町の表示はそれらをすべて描きます(飾りは、それを含む画像パックがある場合だけです)。

<a id="dungeons-caves-and-stations"></a>

### ダンジョン、洞窟、ステーション

物語が地下や船内に入ると、GMが**その場所のマップ**を開けます。ダンジョン、洞窟、ステーションのマップが、シーンの上に描かれます。マップはゲームとその場所の名前から配置されるので、同じ場所にはいつも同じ部屋があり、戻ってもマップはそのままです。GMは見た目を11種類から選びます。岩、氷、水晶、溶岩の洞窟、地下墓所、下水道、神殿、そしてステーションの通路、研究室、機関甲板、水耕栽培区画です。その見た目のタイルパックがあればその絵が使われ、なければ単色で描かれます。

町の中で降りていける場所(名前からわかる洞窟、鉱山、地下墓所、下水道、遺跡。SFでは廃船や地下壕)には、パーティーがそこにいるときに**Go down**(降りる)が表示されます。

- 毎回同じマップが開き、マップを出るとパーティーは町に戻ります。
- パーティーが別のマップにいるときは、先にそのマップを出てください。
- Pixelforgeなどの世界のエディターで、場所に専用のマップを手で作ることもできます。その場合、場所の名前にかかわらず、**Go down**でそのマップが開き、マップが指定するパックで描かれます。こうしたマップでは、出口はパーティーが入ってきた場所にあり、小道具が通り道をふさぐことはありません。人々は、マップが決めた時刻に、名前の付いた地点に立ちます。そこに誰がいるかはGMに伝えられます。

マップ上の場所をクリックするか矢印キーを使うと、最短の道でそこへ歩きます。かかった分数は時計に加わり(30歩につき約1分)、次のターンで、パーティーがどのエリアからどのエリアへ歩いたかがGMに伝わります。上部のラベルには、現在のエリアの名前が表示されます。**Game controls**(ゲームの操作)の**Show the scene**(シーンを表示)と**Show the map**(マップを表示)で、シーンとマップを切り替えます。

出るには、出口(階段、はしご、ハッチ)まで歩いて戻り、**Leave**(出る)を選びます。物語がその場所を離れたときに、GMがマップを終わらせることもあります。マップを開いた、マップ内を歩いた、マップを出たターンを再生成すると、マップはそのターンの前の状態に戻ります。
