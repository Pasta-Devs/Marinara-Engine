# Game Mode: セッションとセーブデータ

Game Modeは、卓上ゲームの1晩ごとのゲーム会のように、冒険を番号付きのセッションに区切ります。このガイドでは、セッションの終了と開始、過去のセッションの閲覧、セットアップの共有、保存データの手での修正、以前の時点に戻る方法を説明します。

最初のセッションは**Session 1**です。これを終了してもう一度始めると**Session 2**になり、以降も同じように増えていきます。セッションを終了すると、ゲームマスター(GM、ゲームを進行するAI)が要約を書き、後から読み返せます。

## 保存と再開

保存ボタンはありません。ゲームは遊んでいる間に自動で保存されます。

1. ひとまず中断するには、タブかアプリを閉じます。
2. 続けるには、同じゲームのチャットを開きます。中断したところから再開できます。
3. 1つの章を締めくくるには、セッションを終了します([セッションを終了する](#end-a-session)を参照)。

以前の時点に戻る方法は、[ゲームの保存の仕組み](#how-your-game-saves)を参照してください。

<a id="opening-session"></a>

## Sessionを開く

**Session**(セッション)では、セッションの終了、新しいセッションの開始、履歴の閲覧を行います。

1. Game Modeのチャットを開きます。
2. チャットの右上付近にある**Session**ボタン(羽根のアイコン)をクリックまたはタップします。別の場所へドラッグすることもできます([操作ウィンドウとボタン](../chats/chat-settings.md#control-windows-and-their-buttons)を参照)。
3. **Session**は、コンピューターではウィンドウ、スマートフォンでは画面幅いっぱいのパネルとして開きます。最初の行には、現在のセッション番号と状態が表示されます。
4. **Session History**(セッション履歴)と**Journal**(記録)の2つのタブがあります。セッションの操作は**Session History**で行うので、このタブのままにします。

**Put back in Chat Settings**(Chat Settingsに戻す)でこのウィンドウを移した場合は、代わりにChat Settings内の**Session**セクションを開いてください。

<a id="end-a-session"></a>

## セッションを終了する

1つの章を締めくくり、GMに要約してもらいたいときは、セッションを終了します。

1. **Session**を開き、**Session History**のままにします。
2. 一番上にある現在のセッションを見つけます。**Session N (Current)**と表示されています。
3. その行にある**End Session**(セッションの終了)ボタン(小さな四角のアイコン)をクリックします。行には小さなアイコンのボタンがいくつかあるので、カーソルを合わせてツールチップを確認してください。**End Session**というタイトルのダイアログが開き、確認を求められます。
4. 任意: **What do you want to happen in the next session (optional)?**(次のセッションで起きてほしいこと、任意)にメモを入力します(5,000文字まで)。GMに話を進めてほしいときは、空のままにします。
5. ダイアログの**End Session**をクリックします。取り消すときは**Cancel**(キャンセル)をクリックします。

GMが要約を書いている間、ダイアログのタイトルは**Ending Session**に変わります。終わるまでこの画面のまま待ってください。完了するとそのセッションは終了扱いになり、履歴に表示されます。

うまくいかなかった場合は、GMのモデルにアクセスできるかを確認してください。要約はモデルへのリクエストなので、ほかのリクエストと同じように失敗することがあります。もう一度試し、[Marinara Engineのトラブルシューティング](../TROUBLESHOOTING.md)を参照してください。

## 新しいセッションを始める

セッションが終了扱いになると、その行の同じボタンが**New Session**(新しいセッション)に変わります。

1. **Session**を開き、**Session History**に移動します。
2. 現在のセッションの行で、**New Session**(再生のアイコン)をクリックします。

GMは、最後の要約と、セッションの終了時に書いたメモをもとに物語を再開します。生成された世界を持つゲームでは、世界は前に終わったところから続きます。経過した日数、パーティーの功績と評判、物語で加わった場所や集団、パーティーが向かった先です。

## 過去のセッションを読む

**Session History**には、終了したセッションが新しい順に並びます。まだ1つも終了していないうちは**No completed sessions yet**と表示されます。各行には、セッションの番号、日付、記録された発見の数が表示されます。行をクリックすると展開します。次の項目が表示されることがあります。

| 項目 | 内容 |
| --- | --- |
| **Summary** | 起きたこと。 |
| **Resume Point** | 次のセッションをどう再開するか。 |
| **Party Dynamics** | パーティーのメンバー同士の関係。 |
| **Key Discoveries** | 重要な事実、どんでん返し、判明したこと。 |
| **Character Moments** | 印象的な場面。 |
| **Little Details To Recall** | 細かな癖、約束、細部。 |
| **NPC Updates** | NPC(プレイヤー以外のキャラクター、GMが動かす人物)の変化。 |
| **Next Session Request** | セッションの終了時に書き残したメモ。 |
| **Stats Snapshot**、**Party Status** | 保存された数値とパーティーの状態。 |

### セッションを再生する

再生は読むだけの機能です。GMを呼び出すことも、メッセージを作ることも、インベントリーや能力値を変えることも、Journalを更新することも、チェックポイントを復元することもありません。

1. 終了したセッションを展開します。
2. **Replay Session**(セッションを再生)をクリックします。
3. **Next**(次へ)と**Next turn**(次のターン)で、当時の語りと会話を1つずつ進めます。
4. 選択肢の場面では、最初に選んだ選択肢だけが押せる状態になります。それをクリックすると、記録どおりの道筋を進めます。
5. 見終わったら、上部の閉じるボタンか、**Return to current session**(現在のセッションに戻る)をクリックします。

再生機能が追加される前のセッションも、保存済みのテキスト、演出、選択肢、素材から再生できます。古いターンでは、当時保存されなかったシーンの演出が欠けている場合があります。

### 過去のセッションを編集する

以降のセッションが正しく覚えているように、終了したセッションの記録を編集できます。

1. セッションを展開します。
2. **Edit Details**(詳細を編集)をクリックします。
3. 任意の項目を書き換えてから**Save Details**(詳細を保存)をクリックします。編集内容を捨てるときは**Cancel**をクリックします。

展開したセッションには、さらに2つのボタンが表示されます。

- **Regenerate**(再生成)は、AIによる締めくくりをもう一度実行します。要約とその他のすべての項目が書き換わるので、**Edit Details**で加えた変更は失われます。
- **Update Plot Arcs**(プロットアークを更新)は、そのセッションの出来事をもとに、GMが隠し持っている物語の構想をAIに更新させます。この構想が、**Show Spoilers**の画面の**Story Arc**、**Plot Twists**、**Party Arcs**です。

**Regenerate Lorebook**(ロアブックを再生成)は、いちばん新しく終了したセッションにだけ、しかもLorebook Keeperの機能がオンのときにだけ表示されます。ロアブックとは、AIが思い出せる世界の事実をまとめたものです。

## ゲームを作成したセットアップを共有する

Game Modeは、新しいキャンペーンを作成したときのセットアップをスナップショットとして保存します。まず遊んでみて、うまくいったらその組み合わせを共有してください。

1. キャンペーンを開き、**Session**を開きます。
2. **Session History**で、**Initial Game Setup**(初期のゲーム設定)を展開します。
3. 保存された冒険、登場キャラクター、モデル、プロンプト、生成パラメーター、ビジュアル、絵コンテ、世界ツールの設定を確認します。
4. **Copy setup**(セットアップをコピー)をクリックするとテキストがコピーされ、**Download setup**(セットアップをダウンロード)をクリックするとテキストファイルとして保存されます。

> **Warning:** テキストには、長く書いたプレイヤーの好みやGMへのカスタム指示も含まれます。公開する前に読んでください。認証情報、サーバーのURL、APIキー、ローカルデータベースのIDは一切含まれません。

キャラクターカード、ペルソナ、ロアブック、モデル、アカウントは名前だけが記載され、同梱されません。そのため、受け取った側は自分の手元にある同等のものを用意する必要があります。スナップショットが導入される前に作成されたキャンペーンでは、保存されていない設定は復元できません。そのため**Initial Game Setup**は、信頼できるスナップショットがある場合にだけ表示されます。

## GMの隠された覚え書きを見る

**Show Spoilers**(ネタバレ表示、現在のセッションの行にある目のアイコン)は、現在のセッションについてGMが隠している覚え書きを表示します。読むとどんでん返しが台無しになる場合があります。

1. **Session**を開き、**Session History**に移動します。
2. 現在のセッションの行で、**Show Spoilers**(目のアイコン)をクリックします。

この画面には、**World Overview**、**Story Arc**、**Plot Twists**、**Party Arcs**と、保存された**Maps**、**NPCs**、**Character Cards**が表示されることがあります。もう一度隠すときは、同じボタンをクリックします。このときボタンの表示は**Hide Spoilers**に変わっています。

これらの覚え書きを変更するには、**Edit Spoilers**(ネタバレを編集)をクリックしてテキストを書き換え、**Save Spoilers**(ネタバレを保存)をクリックします。一部の項目はJSONという構造化されたテキスト形式です。形式を理解している場合にだけ編集してください。壊れたJSONは保存できません。

<a id="editing-game-data-by-hand"></a>

## ゲームデータを手で編集する

NPCの評判や、閉じないまま残っているクエストなど、GMが何かを間違えたときは、保存されたデータを自分で直せます。

1. **Game controls**(ゲームの操作)を開き、**Edit game data**(ゲームデータを編集)を選びます。スマートフォンでは、**Game controls**は3点アイコンの**Chat tools**(チャットツール)メニューの中にあります。
2. **Game Data**(ゲームデータ)のウィンドウが開きます。「Hand edits can break a game. Every change is checked before it saves, and names can't change here.」という警告が表示されます。
3. 一覧からセクションを選びます(スマートフォンでは横に並んだチップ)。検索ボックスでは、すべてのセクションから値を一度に探せます。
4. **Fields**(フィールド)で値を変更するか、**JSON**に切り替えて生のデータを編集します。
5. **Review changes**(変更を確認)をクリックして何が変わるのかを正確に確認し、**Save changes**(変更を保存)をクリックします。

> **Warning:** 手での編集はゲームを壊すことがあります。保存のたびに、Marinaraはその前に**Before a State Editor save**と表示されるチェックポイントを取ろうとします([ゲームの保存の仕組み](#how-your-game-saves)を参照)。編集がうまくいかなかったときは、そのチェックポイントを読み込むと元に戻せます。最初のターンがまだ保存されていないほど新しいゲームには、チェックポイントにできるものがまだありません。

うまくいかなかった場合は、エディターが理由を表示し、下書きを残すので、直してから保存し直せます。編集中にゲームが同じデータを変更した場合は、ゲームの変更を打ち消さないよう、保存は拒否されます。**Reload**(再読み込み)を押すとゲーム側の内容が表示され、下書きは破棄されます。

変更できるのは、**Party Cards**(パーティーカード)、**Party Sheet**(パーティーシート)、**NPCs**(NPC)、**Journal**(記録)、**Player Notes**(プレイヤーのメモ)、**Inventory**(インベントリー)、**Story**(物語)、**Session Summaries**(セッションの要約)、**World Edits**(世界の編集)、**Story Script**(物語の台本)、**HUD Widgets**(HUDウィジェット)のセクションです。セクションは、ゲームにそのデータがあるときだけ表示されます。そのため、世界を持たないゲームには**World Edits**がありません。**World**(世界)、**Maps & Position**(マップと現在地)、**Time, Weather & Morale**(時刻、天候、士気)、**Combat**(戦闘)、**Settings**(設定)などのセクションには、**Read-only**(読み取り専用)の印が付きます。読んだり検索したりはできますが、管理するのはゲーム自身です。プロンプト、画像、音楽、ダイスの好みは**Chat Settings**(チャット設定)で変更します。

確認によって適用されるルールは次のとおりです。

- 名前は変更できません。カード、NPC、パーティー、バッグは、名前でお互いを見つけているからです。パーティーのメンバーの追加や削除も、ここではできません。
- NPCの評判は-100から100までです。
- **Inventory**では、アイテムの数量、愛称、持ち主と、装備しているか、同調しているか、オンになっているかを変更できます。スタックを除くとそのアイテムは削除され、IDのないスタックを加えるとアイテムが追加されます。
- **Session Summaries**で変更できるのは、セッションのテキストだけです。
- **World Edits**には、場所の名前の変更や人物の追加など、世界に対して手で加えた編集が入ります。世界そのものが変更されることはありません。

このウィンドウは、RoleplayのState Editorと同じように使えます。[State Editor](../roleplay/hud-and-trackers.md#the-state-editor)を参照してください。

<a id="how-your-game-saves"></a>

## ゲームの保存の仕組み

Game Modeは自動で保存します。世界、パーティー、マップ、インベントリー、ゲーム内の時間、セッションの要約は遊んでいる間に保存され、保存ボタンはありません。

Marinaraは、セッションの開始時、セッションの終了時、戦闘の開始時と終了時、新しい場所に着いたとき、そして一定の間隔ごとに、自動のチェックポイントも記録します。種類ごとに新しい5件を保持し、古いものは整理されます。ゲームデータのエディターも、保存のたびにその前にチェックポイントを取ろうとします。

以前の時点に戻るには、次のようにします。

1. **Game controls → Checkpoints**(ゲームの操作 → チェックポイント)を開きます。新しい順に並んでいます。
2. 戻りたい時点の**Load**(読み込む)をクリックします。

**Load**を押すと、ゲームはその時点に戻ります。トラッカー、マップ、**World Edits**、物語、パーティーのカードとシート、NPC、Journal、自分のメモ、インベントリー、セッションの要約、GMの物語の計画、HUDウィジェット、時刻、天候、士気がすべて元に戻ります。ゲームを巻き戻した位置には、システムメッセージが残ります。設定はそのまま残ります。**Delete**(削除)を押すと、そのチェックポイントは完全に削除されます。

1つのターンだけをやり直すには、**Game controls**の**Retry turn**(ターンの再試行)を使うか、スワイプして返信の別のバージョンに切り替えます。

データを自分の手元にも残しておくには、[バックアップと復元](../data/backup-and-restore.md)を参照してください。
