# エージェント: チャットを支えるAIヘルパー

このガイドでは、Marinara Engineのエージェントとは何か、どうやってダウンロードするのか、いつ動くのか、チャットで有効にする方法を説明します。**Agents**(エージェント)パネル、公式カタログ、チャットごとの設定、エージェントが動いたかどうかの見分け方を扱います。公式エージェントの全一覧は、末尾の関連ガイドを参照してください。

## エージェントとは

エージェントは、チャットの返信の前後で自動的に動く小さなAIヘルパーです。キャラクターと話しているあいだ、決められた役割だけをこなします。たとえば、時刻と天気を追跡したり、キャラクターの表情を選んだりするエージェントがあります。返信を書き直して、繰り返された言い回しを取り除くエージェントもあります。大事な場面の画像を生成するエージェントもあります。

エージェントはキャラクター単位ではなく、チャット単位でオンにします。キャラクターカードにエージェントのトグルはありません。同じキャラクターとの2つのチャットで、まったく違うエージェントを動かせます。どのエージェントを動かすかは、チャットごとの設定で選びます。

Marinara Engineをインストールした直後は、追加のエージェントは1つも入っていません。こうすることで、本体アプリとTermuxのインストールを小さく保てます。**Download Agents**(エージェントのダウンロード)では、ワンクリックで導入できる公式パッケージが**Apps**(アプリ)、**Writer Agents**(執筆エージェント)、**Tracker Agents**(トラッカーエージェント)、**Misc Agents**(その他のエージェント)に分かれています。カタログには、Long-Term Memory、World Maps、Calls、Inventory Tracker、Conversationの6種類のゲームがすべて含まれます。ソースコード、マニフェスト、ダウンロードできる成果物、リポジトリー側のカタログは、[Pasta-Devs/Marinara-Agents](https://github.com/Pasta-Devs/Marinara-Agents)で公開しています。エージェントごとの詳しい解説は[ダウンロードできるエージェント一覧](built-in-agents.md)を、自作する方法は[カスタムエージェントの作成](custom-agents.md)を参照してください。

## 3つのフェーズ

どのエージェントも、返信をはさんだ3つのタイミングのどれか1つで動きます。このタイミングを**pipeline phase**(パイプラインフェーズ)と呼びます。エージェントのエディターで指定でき、公式エージェントには最初から適切なデフォルトが設定されています。

- **Pre-Generation**(生成前): AIが返信を書く前に動きます。先に役立つ情報をプロンプトへ追加できます。知識を調べるエージェントはここで動きます。
- **Parallel**(並行): 返信の生成と同時に動きます。返信を待たず、返信を書き換えることもできません。観客のリアルタイムな反応を出すエージェントはここで動きます。
- **Post-Processing**(後処理): 返信が完成した後に動きます。返信を読み取れるほか、書き直し系のエージェントなら編集もできます。ほとんどのトラッカー、文章を整えるエージェント、画像生成のエージェントはここで動きます。

## Agentsパネル

**Agents**パネルは、右側のパネルタブ(キラキラのアイコン)から開きます。ここでエージェントを見て、作って、整理します。いわばエージェントの保管庫です。個々のチャットでオンとオフを切り替える場所ではありません。

上部の**Download Agents**(エージェントのダウンロード)をクリックすると、公式カタログが全画面で開きます。デスクトップでもモバイルでも使えます。項目を選ぶと、説明、対応する機能の種類、ダウンロードサイズ、必要な権限、バージョンの互換性、ドキュメントを確認できます。**Install**(インストール)をクリックすると追加されます。同じ画面から、導入済みのパッケージを手動ですぐアップデートしたり、**Uninstall**(アンインストール)したりもできます。パッケージがリリースノートを公開している場合は、**Version history**(バージョン履歴)のセクションに各バージョンの変更点が表示されます。

アプリ内のカタログは、公開されている[Marinara-Agentsリポジトリー](https://github.com/Pasta-Devs/Marinara-Agents)を土台にしています。パッケージと成果物はすべてそこで確認できますが、ふだんは**Download Agents**からインストールしてください。そうすればMarinaraが互換性、権限、ハッシュ、アーカイブの中身、再起動の要否を検証します。

カタログには、公式のチャット用エージェント、World Maps、Conversationの音声通話とビデオ通話、Conversationの追加ゲームがすべて並びます。インストールしたエージェントは**Apps**(アプリ)、**Writer Agents**(執筆エージェント)、**Tracker Agents**(トラッカーエージェント)、**Misc Agents**(その他のエージェント)に分類され、自作したものは**Custom Agents**(カスタムエージェント)の区分に入ります。**Apps**は、NoodleやSlurpのように専用のHomeタブを持つパッケージで、チャットに追加せず単独で使います。**Rules**と表示されるパッケージは、5e (SRD 5.1)などのGame Modeルールセットを提供します。エージェントではありません。ゲーム作成時の**Rules**で選択します([ルールの選択](../game/getting-started.md#choosing-rules)を参照)。チャット単位の有効化スイッチはありません。5eパッケージはプレビュー版で、現在は`staging`ブランチのEngineのカタログだけに表示されます。カタログのパッケージをアンインストールすると、そのコードと設定はEngineから削除されますが、チャットのメッセージと履歴は残ります。カスタムエージェントを削除した場合は、元に戻せません。

これらの機能を同梱していたバージョンのEngineからアップデートした場合、Marinaraは対応するパッケージを一度だけダウンロードし、チャットで選択済みのエージェント、エージェントの設定、保存された実行データ、履歴をそのまま引き継ぎます。この移行処理でカタログに接続できなかったときは、何も破棄せず、次回の起動時に再試行します。

### パッケージのアップデート

Marinaraは、パッケージをアップデートする前に確認を求めます。インストール済みのパッケージに互換性のある新しいバージョンが出ると、**Agent updates available**のウィンドウが表示されます。ここには、各アップデートの新しいバージョンと、再起動が必要かどうかが一覧で表示されます。パッケージがリリースノートを公開している場合は、**What changed**(変更点)にその内容が表示されます。アップデートでいくつかのバージョンを飛ばす場合、**What changed**には現在のバージョン以降のすべてのバージョンのノートが新しい順に並び、その件数も表示されます。長いノートは途中で省略されるので、全文を読むには**More**(もっと見る)を選んでください。点の付いた変更は、使っていて気づく変更です。点のないアップデートは、日常的な修正です。

- 一覧のアップデートをすべてインストールするには、**Update all**(すべてアップデート)をクリックします。再起動を求められたら、Marinara Engineを再起動してください。
- 現在のバージョンのまま使い続けるには、**Not now**(今はしない)をクリックします。見送ったバージョンについて、Marinaraが再び確認することはありません。

どのパッケージも、あとから**Download Agents**でアップデートできます。インストール済みのパッケージは、アップデートするまで現在のバージョンのまま動き続けます。カタログに接続できないときも同じです。

アップデートの対象は、インストール済みのパッケージだけです。デスクトップ、Docker、Android/Termuxのインストールでは、パッケージをそれぞれのローカルサーバーに保存します。iOS、iPadOS、そのほかのブラウザーから使う場合は、接続先のMarinaraサーバーにインストールされたパッケージを利用します。

## チャットでのエージェントの有効化

エージェントは、各チャットの**Chat Settings**(チャット設定)パネルでオンにします。

1. 使いたいチャットを開きます。
2. **Chat Settings**を開きます。
3. **Agents**セクションを探します。
4. **Enable Agents**(エージェントを有効にする)をオンにします。これが全体のスイッチです。オフのあいだは、このチャットでエージェントは1つも動きません。
5. スイッチの下にあるリストから使いたいエージェントを追加し、不要なものは削除します。

追加したエージェントは有効な状態で一覧に並び、それぞれに小さな削除ボタンが付きます。

**Agents**セクションには、ほかにもいくつか設定があります。

- **Agent Menus**(エージェントメニュー、Roleplayのチャットのみ): **Enable Agents**のすぐ下にあります。エージェントの名前をクリックすると、そのエージェントの設定へ移動します。
- **Trackers Control**(トラッカーの管理、Roleplayのチャットのみ): 最初は閉じた状態のカードです。クリックして開くと、次の設定が表示されます。
  - **Attach chat summaries**(チャットの要約を添付): 初期状態ではオフです。選択が保存されていない既存のチャットでもオフになります。オンにすると、返信後の処理や手動の再実行を含め、エージェントのリクエストに保存済みの要約を添付します。メインの返信のコンテキストから要約を削除したり、要約の生成を停止したりする設定ではありません。メインプロンプト全体へのアクセスを明示的に許可されたエージェントは、その中の要約を引き続き読めます。
  - **Attach Lorebooks to Trackers**(トラッカーにロアブックを添付): オンにすると、メインの返信に使われたロアブックのエントリーをトラッカーエージェントにも渡します。チャットにトラッカーエージェントがあると表示されます。
  - **Review Agent Outputs**(エージェントの出力を確認する): このリストのあとにある専用の項目で説明します。
  - **Individual tracker schedule**(トラッカーごとのスケジュール): トラッカーをオンにすると、そのトラッカーは返信のたびには動かなくなります。その後は、HUDのボタンから手動で実行します。HUDはheads-up displayの略で、Roleplayの画面に重ねて表示される状態表示のことです。チャットにトラッカーエージェントがあると表示されます。
- **Review Agent Outputs**: オンにすると、ロアブック、要約、キャラクターカードへの変更は、保存前に承認を待ちます。オフにすると、ロアブックと要約の変更はそのまま保存されますが、キャラクターカードの編集は必ず先に確認します。[エージェントの承認とAgent Suite](approvals-and-agent-suite.md)を参照してください。Roleplayのチャットでは、**Trackers Control**の中にあります。
- **Agent Suite**: このチャットでエージェントが保存した内容をすべて閲覧、編集できるビューアーを開きます。

### コストの警告

エージェントを使うと、トークンとモデルの呼び出しが余分にかかります。エージェントはそれぞれ独自の指示を追加し、多くの場合は独自のモデル呼び出しも発生させます。同じ接続を使うエージェントは、可能なかぎり1回の呼び出しにまとめます。エージェントの一覧の上には、現在の構成でどのくらいの負荷になるかの目安が表示されます。追加した指示がおよそ何トークンか、1ターンあたり何回ほど呼び出しが増えるかがわかります。

表示の横にあるヘルプアイコンをクリックまたはタップすると、パソコンでもモバイルでも説明を開けます。負荷が大きくなると、この表示は警告アイコン付きの黄色に変わります。1ターンあたりの実際のコストは、表示された数値より大きくなります。呼び出しのたびに、チャットの履歴とキャラクターの詳細も一緒に送られるためです。警告が出たら、不要なエージェントを外すか、一部をより安い接続やローカルの接続へ移してください。直近のメッセージ数の上限はチャットのメッセージだけに適用されます。エージェントの指示、キャラクターの詳細、添付された要約は追加のコンテキストです。接続に保存された**Reasoning Effort**(推論の強度)は、その接続を使うエージェントにも適用されます。高いレベルにすると、エージェントの呼び出しはそのたびに遅くなり、費用も増えます。[エージェントのパラメーター](../prompts/generation-parameters.md#parameters-for-agents)を参照してください。

## モードごとの初期状態

インストールした直後は、追加のエージェントは1つも導入されておらず、有効にもなっていません。各チャットモードには、インストール済みで、そのモードに対応するパッケージだけが表示されます。

- **Roleplay**: カタログからRoleplay向けのエージェントをインストールし、**Chat Settings**で追加します。World Mapsも、ほかの対応エージェントと同じように一覧に並びます。
- **Conversation**: カタログからCallsや個別のテーブルゲームをインストールします。ゲームはゲームの選択画面に並び、それぞれのスラッシュコマンドを登録します。Callsはツールバーと**Chat Settings**の項目を追加します。
- **Game Mode**: Game Modeに対応するエージェントをインストールしておくと、ゲームの作成時に選べるほか、後から追加することもできます。World Mapsのマップ作業画面とワールドマップ表示は、そのゲームで有効になっているときだけ使えます。

対応するエージェントは、いつでも追加、削除できます。

## エージェントが動いたかどうかの確認

すぐ目に見える変化を起こすエージェントもあれば、静かに動くエージェントもあります。確認する方法は次のとおりです。

- トラッカーエージェントは、HUDとトラッカーのパネルに書き込みます。時刻、場所、気分、能力値が更新されていれば、トラッカーエージェントが動いています。
- **Chat Settings**(チャット設定)の**Agent activity**(エージェントの動作)には、エージェントからの短いメモが並びます。エージェントの作業中はそのアイコンがスピナーに変わり、エージェントが失敗するとアイコンに点が表示されます。[Agent activity](../roleplay/getting-started.md#agent-activity)を参照してください。
- **Prose Guardian**と**Continuity Checker**のエージェントは、返信の文章そのものを書き換えます。文章が整えられていたり、矛盾が直っていたりすれば、これらが動いた証拠です。
- すべての動きを追いたいときは、**Settings** > **Advanced** > **Message Tools**で**Debug mode**(デバッグモード)をオンにします。エージェントごとのプロンプトと応答が、サーバーのコンソールに記録されます。さらに、エージェント別の呼び出し回数、トークン数、所要時間を示す**Agent Debug**オーバーレイも表示されます。

動くはずのエージェントが動かないときはどうすればよいでしょうか。まず**Enable Agents**がオンになっているか確かめます。次に、そのエージェントがこのチャットで有効になっているかを確認します。最後に、使っているチャットモードがそのエージェントに対応しているかを確かめます。
