# エージェント: チャットを支えるAIヘルパー

エージェントは、チャットのメインの返信の前後で動く小さなAIヘルパーです。時刻と天気を追跡するもの、キャラクターの表情を選ぶもの、大事な場面の画像を描くものなどがあります。このガイドでは、エージェントをインストールし、チャットでオンにして、動いたかどうかを確かめる方法を説明します。

## エージェントとは

エージェントはキャラクター単位ではなく、チャット単位でオンにします。同じキャラクターとの2つのチャットで、別々のエージェントを動かせます。

インストールした直後は、追加のエージェントは1つも入っていません。公式パッケージをワンクリックで導入するストア、**Agent Organizer**(エージェント管理)からインストールしてください。ソースコードとカタログは[Pasta-Devs/Marinara-Agents](https://github.com/Pasta-Devs/Marinara-Agents)で公開しています。インストールは**Agent Organizer**から行ってください。そうすれば、Marinaraが互換性、権限、ファイルのハッシュを確認できます。各エージェントの働きは[ダウンロードできるエージェント一覧](built-in-agents.md)を、自作する方法は[カスタムエージェントの作成](custom-agents.md)を参照してください。

## チャットにエージェントを追加する

始める前に: 先にエージェントをインストールしてください。**Agents**(エージェント)パネル(右側のタブにあるSparklesのアイコン)を開き、**Agent Organizer**(エージェント管理)をクリックして、そのエージェントのページを開き、**Get**(入手)をクリックします。[エージェントのインストールとアップデート](#install-and-update-agents)を参照してください。

1. チャットを開きます。
2. **Chat Settings**(チャット設定)を開き、**Agents**セクションを探します。
3. **Enable Agents**(エージェントを有効にする)をオンにします。これは全体のスイッチで、オフのあいだは、このチャットでエージェントは1つも動きません。
4. **Add Agent**(エージェントの追加)をクリックし、エージェントが属するグループを開いて選びます。グループには**Writer Agents**(執筆エージェント)や**Misc Agents**(その他のエージェント)などがあります。

追加したエージェントは有効な状態で一覧に並び、それぞれに小さな削除ボタンが付きます。エージェントはいつでも追加、削除できます。

> **Note:** 各チャットモードには、そのモードで動くエージェントだけが表示されます。Conversationでは、インストールしたゲームがゲームの選択画面に並び、**Calls**がツールバーに操作ボタンを追加します。Game Modeでは、ゲームの作成時にエージェントを選ぶか、後から追加します。

エージェントが動かなかった場合は、**Enable Agents**がオンになっているか、そのエージェントがこのチャットで有効になっているか、エージェントのモードがチャットと合っているかを確かめてください。

### Agentsセクションのほかの設定

次の設定も、同じ**Agents**セクションにあります。

- **Agent Menus**(エージェントメニュー、Roleplayのみ): エージェントの名前をクリックすると、その設定へ移動します。
- **Trackers Control**(トラッカーの管理、Roleplayのみ): 閉じた状態のカードで、下のトラッカーの設定が入っています。
- **Agent Suite**: このチャットでエージェントが保存した内容を閲覧、編集できるビューアーを開きます。
- **Review Agent Outputs**(エージェント出力の確認): ロアブック、要約、キャラクターカードへの変更を、承認するまで保留にします。Roleplayでは**Trackers Control**の中にあります。[エージェントの承認とAgent Suite](approvals-and-agent-suite.md)を参照してください。

**Trackers Control**の中の設定は次のとおりです。

- **Attach chat summaries**(チャットの要約を添付): デフォルトはオフです。再実行を含め、エージェントのリクエストに保存済みのチャットの要約を添付します。メインの返信から要約を外したり、要約の生成を止めたりする設定ではありません。メインプロンプト全体にアクセスできるエージェントは、その中の要約を引き続き読めます。
- **Attach Lorebooks to Trackers**(トラッカーにロアブックを添付): トラッカーエージェントにも、メインの返信に使われたロアブックのエントリーを渡します。チャットにトラッカーエージェントがあると表示されます。
- **Individual tracker schedule**(トラッカーごとのスケジュール): トラッカーが返信のたびに動かないようにします。HUD(Roleplayの画面に重ねて表示される状態表示)から手動で実行します。

### 1つのエージェントに参照ロアブックを渡す

1. **Chat Settings**で**Agents**を開き、そのエージェントの設定を開きます。
2. **Attach lorebook for the specific agent**(このエージェント用のロアブックを添付)をオンにします。最初はオフです。
3. **Reference lorebook**(参照ロアブック)でロアブックを選びます。

この選択は、このチャットのこのエージェントだけのものです。一致するエントリーは通常のロアブックのトリガールールに従い、手動の再試行を含め、このエージェントに渡されます。この設定でメインの返信や無関係なエージェントにロアブックが追加されることはありませんが、一緒に実行されるエージェントにも同じエントリーが見える場合があります。削除されたロアブックや利用できないロアブックからは、何も渡されません。

## エージェントが動くタイミング

どのエージェントも、返信の前後のどこか1つのタイミングで動きます。このタイミングを**pipeline phase**(パイプラインフェーズ)と呼びます。組み込みのエージェントにはそれぞれデフォルトがあり、エージェントのエディターで変更できます。

| フェーズ | 動くタイミング | 例 |
| --- | --- | --- |
| **Pre-Generation**(生成前) | 返信の前。プロンプトにコンテキストを追加できます。 | 知識の検索 |
| **Parallel**(並行) | 返信と同時。返信は変更できません。 | 観客のリアルタイムな反応 |
| **Post-Processing**(後処理) | 返信の後。返信を読み取れ、書き直し系のエージェントは編集もできます。 | ほとんどのトラッカー、文章の手直し、画像 |

<a id="tell-whether-an-agent-ran"></a>

## エージェントが動いたかどうかの確認

- トラッカーエージェントは、HUDとトラッカーのパネルに書き込みます。時刻、場所、気分、能力値が変わっていれば、トラッカーが動いています。
- **Chat Settings**(チャット設定)の**Agent activity**(エージェントの動作)には、エージェントからの短いメモが並びます。作業中はアイコンが回転し、エージェントが失敗するとアイコンに点が表示されます。[Agent activity](../roleplay/getting-started.md#agent-activity)を参照してください。
- **Prose Guardian**と**Continuity Checker**は、返信の文章を書き換えます。文章が整えられていたり、修正されていたりすれば、これらが動いています。
- すべての動きを追うには、**Settings → Advanced → Message Tools**(設定 → 詳細設定 → メッセージツール)で**Debug mode**(デバッグモード)をオンにします。各エージェントのプロンプトと応答がサーバーのコンソールに記録され、エージェントのデバッグ情報はブラウザーのコンソールにも表示されます。キャッシュされたプロンプトの挿入内容は、**Agent activity**の**Injections**タブに表示されます。

## コストに注意する

各エージェントは独自の指示を追加し、多くの場合は独自のモデル呼び出しも発生させます。Marinaraは、同じ接続を使うエージェントを、可能なかぎり1回の呼び出しにまとめます。

エージェントの一覧の上に、1ターンあたりに増えるトークンと呼び出しの回数の目安が表示されます。横にあるヘルプアイコンをタップすると、詳しい説明が開きます。負荷が大きいと、この表示は警告アイコン付きの黄色に変わります。実際のコストはこれより大きくなります。呼び出しのたびに、チャットの履歴とキャラクターの詳細も一緒に送られるためです。

警告が出たら、不要なエージェントを外すか、一部をより安い接続やローカルの接続へ移してください。接続に保存された**Reasoning Effort**(推論の度合い)は、その接続を使うエージェントにも適用されます。[エージェントのパラメーター](../prompts/generation-parameters.md#parameters-for-agents)を参照してください。

## エージェントのインストールとアップデート

**Agents**(エージェント)パネル(右側のタブにあるSparklesのアイコン)を開き、**Agent Organizer**(エージェント管理)をクリックします。デスクトップでもモバイルでも使えます。

- **Home**(ホーム)には、おすすめのエージェントと、各セクションの棚が表示されます。セクションは**Apps**(アプリ)、**Chat games**(チャットゲーム)、**Trackers**(トラッカー)、**Writing help**(執筆支援)です。
- **Updates**(アップデート)には、新しいバージョンがあるインストール済みのエージェントが並びます。**Installed**(インストール済み)には、導入済みのものすべてがバージョンとサイズ付きで並びます。
- 検索とモードフィルターで、どの一覧も絞り込めます。
- エージェントを選ぶと、説明、ダウンロードサイズ、権限、互換性、**Version history**(バージョン履歴)を確認できます。**Get**(入手)をクリックするとインストールされます。**⋯**メニューには**Uninstall**(アンインストール)があります。
- タイトルの横にある**⋯**メニューには、**Update all**(すべてアップデート)、**Install all**(すべてインストール)、**Refresh catalog**(カタログを更新)、**Uninstall all**(すべてアンインストール)があります。

インストールしたエージェントは**Apps**、**Writer Agents**(執筆エージェント)、**Tracker Agents**(トラッカーエージェント)、**Misc Agents**(その他のエージェント)に分類され、自作したものは**Custom Agents**(カスタムエージェント)に入ります。**Apps**は、NoodleやSlurpのように専用のHomeタブを持つパッケージです。チャットに追加せず、単独で使います。

**Rules**と表示されるパッケージはエージェントではありません。5e (SRD 5.1)などのGame Modeのルールセットを追加するもので、ゲームの作成時に**Rules**で選びます。[ルールセットで遊ぶ](../game/rulesets.md)を参照してください。5eパッケージはプレビュー版なので、`staging`ブランチのEngineにしか表示されません。

パッケージをアンインストールすると、そのコードと設定は削除されますが、チャットのメッセージと履歴は残ります。カスタムエージェントを削除すると、元に戻せません。

### エージェントのアップデート

インストール済みのパッケージに互換性のある新しいバージョンが出ると、**Agent updates available**のウィンドウが開きます。各アップデートのバージョンと、再起動が必要かどうかが一覧で表示されます。

1. 見送りたいアップデートのチェックを外します。最初はすべてのアップデートが選択されています。
2. パッケージがノートを公開している場合は、**What's new**(新着情報)を読みます。**More**(もっと見る)で長いノートの全文を表示できます。点の付いた変更は、使っていて気づく変更です。
3. **Update all**(すべてアップデート)をクリックします(一部のチェックを外した場合は**Update 2 of 3**(3件中2件をアップデート))。各行に**Updated**または**Failed**と表示されます。失敗した行には理由と**Retry**(再試行)が表示されます。
4. 再起動が必要なアップデートでは、**Restart now**(今すぐ再起動)をクリックするか、あとでMarinaraを再起動します。

現在のバージョンのまま使うには、**Not now**(今はしない)をクリックします。見送ったバージョンについて、Marinaraが再び確認することはありません。**Agent Organizer**(エージェント管理)からは、いつでもアップデートできます。インストール済みのパッケージは、カタログに接続できないときも、現在のバージョンのまま動き続けます。**See in Agent Organizer**(Agent Organizerで表示)で、そのエージェントのページを開けます。

アップデートの対象は、インストールしたパッケージだけです。パッケージはMarinaraサーバーに保存されるので、ブラウザーから使う場合は、サーバーにインストールされたパッケージを利用します。

これらの機能を同梱していたバージョンのEngineからアップグレードすると、Marinaraは対応するパッケージを一度だけダウンロードし、チャットでの選択、設定、履歴を引き継ぎます。カタログに接続できなかったときは、次回の起動時に再試行します。
