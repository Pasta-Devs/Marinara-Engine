# 2Dアバターと3Dアバター

ダウンロードできる2つのエージェントを使うと、キャラクターとペルソナに、返信のストリーミング中に反応するアニメーションのアバターを付けられます。**2D Avatars**(2Dアバター)はPNGTuber風のスプライトかメッシュアバターを、**3D Avatars**(3Dアバター)はVRMモデルを表示します。表情は返信に合わせて変わり、口はテキストか音声合成に合わせて動きます。

この機能はまだ開発中です。以下のセクションは、各部分が`staging`に入るたびに書き足されます。

Live2Dのモデルには対応していません。Live2Dのライセンスでは、無料のオープンソースアプリであってもLive2D社との個別の契約が必要です。また、そのランタイムをMarinara Engineに同梱することもできません。

## エージェントのダウンロード

どちらのエージェントもテスト中です。現時点では、Marinara Engineを`staging`ブランチで動かしている場合にだけ、**Download Agents**(エージェントのダウンロード)に表示されます。

**2D Avatars**と**3D Avatars**は別々のダウンロードなので、必要なほうだけをインストールできます。どちらも、RoleplayとGameのチャットでキャラクターとペルソナに使えます。

1. **Agents → Download Agents**を開き、**2D Avatars**か**3D Avatars**、または両方をインストールします。どちらも再起動は不要です。
2. **Agents**(エージェント)にあるそのエージェントのページで、アバターを1つずつ設定します。[アバターの設定](#setting-up-an-avatar)を参照してください。
3. RoleplayまたはGameのチャットで**Chat Settings → Agents → Misc Agents**(チャット設定 → エージェント → その他のエージェント)を開き、エージェントを追加します。

これらのエージェントは、チャット中にAIの接続へ追加のリクエストを送りません。Capability API 1.73に対応したEngineが必要で、それより古いEngineではインストールが拒否されます。

<a id="setting-up-an-avatar"></a>

## アバターの設定

アバターは、各エージェント専用のページで設定します。**Agents**(エージェント)を開き、**2D Avatars**か**3D Avatars**を開いて、上部近くにある**Avatars**(アバター)セクションを使います。

1. **Character or persona**(キャラクターまたはペルソナ)で、アバターを付ける相手を選びます。「(has an avatar)」と付いた名前には、すでにアバターが保存されています。
2. **Avatar type**(アバターの種類)で、設定する種類を選びます。2D Avatarsでは**PNGTuber sprites**(PNGTuberのスプライト)と**Mesh avatar**(メッシュアバター)、3D Avatarsでは**VRM model**(VRMモデル)を選べます。
3. スイッチの下にある、その種類専用のセクションで設定します。スプライトを使うかファイルをインポートし、感情ごとの表情を選びます。削除もここで行います。[2Dアバター](#2d-avatars-pngtuber-sprites-and-mesh-avatars)と[3Dアバター](#3d-avatars-vrm-models)を参照してください。
4. **Preview**(プレビュー)で確認します。**Try a face**(表情を試す)で感情を切り替え、**Talk**(話す)で口を動かします。まだ表示するものがない場合、プレビューには見本のアバターが表示されます。

表情スプライトを持つキャラクターやペルソナは、2D AvatarsのページですでにPNGTuberのアバターを持っています。そのため、2D Avatarsがオンのチャットでは、何も保存しなくてもそのアバターが表示されます。

**Show this avatar in chats**(チャットでこのアバターを表示)は、アバターを削除せずにオンとオフを切り替えます。**Movement**(動き)には、すべての種類に共通する3つのスイッチがあります。**Lip sync**(リップシンク)は口を動かし、**Blinking**(まばたき)は数秒ごとにまばたきさせ、**Idle motion**(待機中の動き)は待っている間に呼吸と体の揺れを表現します。キャラクターに複数の種類のアバターがある場合は、**Show this one**(これを表示)でチャットに使う種類を選びます。その種類のエージェントがチャットでオフになっているときは、エージェントがオンになっている別の種類を表示します。種類を削除すると、そのファイルが削除されます。スプライトは残り、オフにしたアバターはオフのままです。

アバターは、Roleplay、ビジュアルノベル、Gameのチャットで、エージェントがオンになっていて対応するエージェントが追加されているときに表示されます。Expression Engineがあってもなくても動きます。アバターは全身スプライトを隠さないので、アバターを代わりに使う場合は全身スプライトを自分でオフにしてください。アバターは全身スプライトが立つ位置に立ち、同じ大きさで表示されます。

アバターを動かしたり大きさを変えたりするには、**Chat Settings**(チャット設定)を開き、**Agents**(エージェント)に移動して**Avatars**(アバター)を開きます。一覧でアバターを選び、そのサイズスライダーで大きくしたり小さくしたりします。アバターを動かすには**Arrange**(配置)を選びます。オンの間は、マウスや指でチャット内の好きな場所へドラッグするか、アバターにフォーカスを合わせて矢印キーを使います(Shiftを押しながらだと大きく動きます)。終わったら**Done**(完了)を選びます。アバターは置いた場所にとどまり、クリックは再びチャットの操作に使われます。**Reset**(リセット)を選ぶと、すべてのアバターが通常の位置に戻ります。

3Dアバターには**Framing**(映す範囲)の選択もあります。**Portrait**(ポートレート)は頭と肩を映し、これがデフォルトです。**Half body**(半身)は腰まで、**Full body**(全身)は頭から足までモデル全体を映します。アバターの大きさは変わらず、縦に長い範囲を選ぶほど、同じ枠の中にモデルのより多くの部分が映ります。2Dアバターには映す範囲の選択はありません。

Roleplay、ビジュアルノベル、Gameでは、Expression Engineがなくても使えます。配置はこのデバイス上でそのチャットごとに保存され、再読み込みしても残りますが、ほかのデバイスとは同期しません。Expression Engine自身の**Arrange**ボタンでもアバターを動かせます。

インポートしたファイルは、保存する前に検査されます。サーバーの通常のアップロード上限より小さい、アバター専用のサイズ上限はありません。アバターのファイルは、データフォルダーの`avatar-models/<character or persona>/<id>/`の下に、設定を記録した`avatar.json`と並んで保存されます。バックアップとプロファイルのエクスポートには、このフォルダーも含まれます。キャラクターやペルソナを削除すると、そのアバターも削除されます。SettingsのDanger Zoneで**Characters**(キャラクター)や**Personas**(ペルソナ)をすべて消去した場合も同じです。そこで**Media & Assets**(メディアとアセット)を消去すると、このフォルダーは空になります。キャラクターカードのエクスポートにアバターが含まれることはありません。

## 2Dアバター: PNGTuberのスプライトとメッシュアバター

**2D Avatars**は、2種類のアバターのどちらかを表示します。1つは**PNGTuber sprites**(PNGTuberのスプライト)で、表情を切り替え、口を開け、まばたきする平面の画像です。もう1つは**mesh avatars**(メッシュアバター)で、頭、目、口がなめらかに動くイラストです。どちらも、キャラクターかペルソナを選んでから、エージェントエディターにあるこのエージェントのページで設定します。

<a id="pngtuber-sprites"></a>

### PNGTuberのスプライト

表情スプライトを持つキャラクターやペルソナには、最初からPNGTuberのアバターがあります。スプライトがそのまま表情になるので、設定は何も要りません。ポートレートのスプライトがあればそれを使い、なければ全身スプライトを使います。そのため、1つのアバターで両者が混ざることはありません。

- **口パク用とまばたき用の画像。** 表情の名前に、口を開けた画像なら`_talk`、目を閉じた画像なら`_blink`を付けたスプライトを追加します。たとえば`happy_talk`や`happy_blink`です。両方なら`happy_blink_talk`です。`_talking`、`_speak`、`_mouth_open`、`_blinking`、`_eyes_closed`も使えます。これらの画像がない表情でも、話している間は跳ねます。
- **感情ごとの表情。** Neutral、Happy、Angry、Sad、Relaxed、Surprisedのそれぞれに表示する表情を選びます。**Resting face**(平常時の表情)にはNeutralの表情が使われます。アバターを保存した後に追加したものも含め、すべてのスプライトが選択肢に並びます(最大64個の表情)。PNGTuber Plusからインポートしたアバターでは、そのアバター自身の表情だけが並びます。Expression Engineやゲームマスターが手持ちのスプライトを選んだ場合は、その表情がそのまま表示されます。
- **その他の感情。** **Face for each feeling**(感情ごとの表情)の下にある**More feelings**(その他の感情)を開くと、より細かい23の感情にも表情を選べます。これらは6つの感情の下に分類されています。NeutralにはCuriosity、HappyにはAdmiration、Amusement、Desire、Embarrassment、Excitement、Gratitude、Optimism、Pride、AngryにはAnnoyance、Disapproval、Disgust、SadにはDisappointment、Grief、Nervousness、Remorse、RelaxedにはApproval、Caring、Love、Relief、SurprisedにはConfusion、Fear、Realizationが属します。どれも任意です。別の表情を選ぶまでは、それぞれが属する主な感情の表情を使います。`fear`や`amusement`のようにこれらの感情の名前を付けたスプライトや、`scared`や`laughing`のようにその感情を表す単語の名前を付けたスプライトは、設定しなくてもその感情に使われます。
- **動き。** **Hop while talking**(話している間に跳ねる)と**Hop height**(跳ねる高さ)で、PNGTuber風の弾む動きを設定します。**Time between blinks**(まばたきの間隔)は平均値です。毎回のまばたきは少し早まったり遅れたりするので、機械的には見えません。端末で動きを減らす設定をオンにしている場合、アバターは跳ねたり呼吸したりしませんが、表情と口は変わります。
- **スプライトはそのまま表示されます。** 背景付きで描かれたスプライトは背景ごと表示され、スプライトのファイルが変更されることはありません。背景のない表情が必要な場合は、[アバターから作る表情](#faces-from-the-avatar)を使ってください。
- **Use my sprites**(自分のスプライトを使う)は、スプライトをアバターの表情として保存します。表情を選んだり動きを変えたりしたときも保存されます。**Update from sprites**(スプライトから更新)は、後から追加したスプライトを取り込み、感情ごとに選んだ表情はそのまま残します。インポートした後に元のスプライトへ戻すには、**Remove**(削除)を選びます。

**Import PNGTuber Plus save**(PNGTuber Plusのセーブをインポート)は、[PNGTuber Plus](https://github.com/kaiakairos/PNGTuber-Plus)で保存したアバター(`.save`ファイル)を読み込みます。各コスチュームが1つの表情になり、その口パクとまばたきのレイヤーが口パク用とまばたき用の画像になります。画像は、背景があれば背景も含めて、そのまま取り込まれます。コスチュームは、表示する画像の名前(`angry eyes.png`など)をもとに感情と対応付けられます。名前で対応付けられなかった感情には、表情を選んでください。引き継がれないものもあります。

- 揺れ、ドラッグ、回転、伸縮はインポートされません。アバターは各レイヤーを静止した状態で表示します。
- アニメーションするレイヤーは、最初のフレームだけを表示します。
- とても古いセーブには、作者のコンピューター上にある画像のパスしか含まれていません。先に新しいPNGTuber Plusで保存し直してください。
- とても大きなアバターは、スマートフォンでもすべての画像を保持できるように、2048ピクセルまで縮小されます。

セーブのインポートには、サーバー側の画像処理が必要です。一部のAndroid環境(Termux)には画像処理がないため、その場合はその旨のメッセージとともにインポートが拒否されます。

### メッシュアバター

メッシュアバターは`.mavatar`ファイルです。Marinara Engineで手持ちのスプライトの1枚から作ることも([スプライトからのアバター作成](#mesh-avatar)を参照)、[Mesh Avatar Studio](https://github.com/shinshin86/mesh-avatar-studio)で作ることもできます([自分でモデルを作る](#mesh-avatar-studio)を参照)。追加するには**Import .mavatar file**(.mavatarファイルをインポート)を、差し替えるには**Replace file**(ファイルを置き換える)を選びます。待機中の動きがオンのとき、アバターは自分で呼吸し、あたりを見回します。まばたきもし、口は返信に合わせて動きます。ファイルに描かれた口の形があればそれを使い、なければ簡単な口の形を描いて補います。

**Look for each feeling**(感情ごとの見た目)で、各感情で表示するものを選びます。6つの感情のどれか、または**Smile**(笑顔)、**Shy**(照れ)、**Half-closed eyes**(半目)、**Wink**(ウインク)から選べます。

ファイルはインポート時にすべて検査され、壊れたファイルは短い理由とともに拒否されます。なめらかに動かすには細かすぎるファイルや、展開するとアップロード上限を超えるファイルも拒否されます。アバターに必要な部分だけを残すため、ファイル内の元のイラストは保存されません。イラストの権利は作者にあります。共有する前にライセンスを確認してください。

メッシュアバターにはWebGL2が必要です。現在のブラウザーは対応しています。WebGL2がない場合や、ブラウザーがメモリーを節約するためにアバターの描画を止めた場合は、代わりにPNGTuberの設定かスプライトが表示されます。

<a id="3d-avatars-vrm-models"></a>

## 3Dアバター: VRMモデル

**3D Avatars**は、VRoid Studio、BlenderのVRMアドオン、Unity向けのUniVRMが書き出す形式であるVRMモデルを表示します。VRM 1.0とVRM 0.xのファイルのどちらも使えます。

モデルがまだない場合は、無料アプリの[VRoid Studioで作って](#get-a-3d-model)インポートしてください。

1. エージェントエディターで**3D Avatars**を開き、キャラクターかペルソナを選びます。
2. **VRM model**(VRMモデル)の下で**Import VRM**(VRMをインポート)をクリックし、`.vrm`ファイルを選びます。
3. **The author's terms**(作者の利用条件)を読みます。これはモデルファイルに含まれる情報で、誰がそのモデルをアバターとして使えるか、商用利用が許されるか、モデルを改変してよいか、性的な表現や過度に暴力的な表現が許されるかを示します。VRM 1.0のモデルでは、作者のクレジット表記が必要か、ファイルを共有してよいかも示します。ファイルにライセンスや作者独自の利用条件へのリンクがある場合は、それも開いてください。Marinara Engineは利用条件を表示しますが、守らせる仕組みはないので、自分で守ってください。
4. **Faces and mouth shapes**(表情と口の形)で、各表情(Neutral、Happy、Angry、Sad、Relaxed、Surprised)、各口の形(A、I、U、E、O)、まばたきに、モデルのどの表情を使うかを確認します。ほとんどは自動で埋まります。**Set by the model**(モデルで設定済み)は、モデルが標準のVRMの表情を持っていることを示します。**Guessed from its name**(名前から推測)は、モデル独自の表情のうち名前が一致するものがあったことを示します。モデルが空のままにした表情は何も変えません。そのため、空の表情が割り当てられるのは、何もしていない状態のモデルであるNeutralだけです。インポートで空の表情を飛ばしたときは、その旨が表示されます。推測が合っていないと思ったら、別の表情か**None**(なし)を選んでください。
5. 必要に応じて、**Idle animation**(待機アニメーション)に、待っている間にモデルが再生する`.vrma`ファイルを追加します。追加しない場合、モデルは呼吸しながらゆっくり揺れます。

**Replace model**(モデルを置き換える)では待機アニメーションが残ります。VRMのアニメーションはどのVRMモデルにも合うからです。**Remove model**(モデルを削除)は、モデルと待機アニメーションを削除します。

チャット中、モデルはこちらを見て、まばたきの表情があれば自分でまばたきし、考えているときや聞いているときは首をかしげます。映す範囲がデフォルトの**Portrait**(ポートレート)のときは、頭は表示枠の上端近くに収まります。幅の広い枠では頭と肩が、狭い枠では体のより多くの部分が映ります。チャットのAvatarsの設定で**Half body**(半身)や**Full body**(全身)を選ぶと、モデルのより多くの部分が映ります。VRM 1.0のモデルには、表情を見せている間は口を動かさないものがあります。そのようなモデルが話している間は、口が動けるように表情を弱めて表示します。動きを減らす設定がオンのときも表情と口は変わりますが、モデルは揺れ、呼吸、待機アニメーションの再生を止めます。

使えないファイルもあります。その場合は、インポート時に理由が表示されます。

- **圧縮されたモデル。** Dracoやmeshoptで圧縮したファイルや、KTX2のテクスチャーを使ったファイルは読み込めません。圧縮をオフにしてモデルをエクスポートし直してください。
- **通常の3Dモデル。** VRMのデータを持たない`.glb`や`.gltf`のモデルには、顔の表情も人型の骨格もありません。先にVRMへ変換してください。たとえばBlenderのVRMアドオンを使えます([自分でモデルを作る](#blender-with-the-vrm-add-on-for-blender)を参照)。
- **不完全なモデル。** 骨格にVRMが必要とするボーンが欠けているモデル、ファイル内にない部分を参照しているモデル、ファイルの外にあるファイルを参照しているモデルは拒否されます。

アプリの通常のアップロード上限のほかにサイズの上限はありませんが、大きなモデルは読み込みに時間がかかります。特にスマートフォンでは時間がかかります。

## Get a 3D model

キャラクターやペルソナにまだVRMモデルがない場合は、VRoid Studioで作ります。VRoid Studioはpixivの無料アプリで、Windows、macOS、iPadで使えます。VRoid Studioで作ったモデルは自由に使えます。ただし、一部の組み込みアイテムや購入したテクスチャーには独自の利用条件があるので、先に確認してください。VRoid Studioのモデルには6つの表情、5つの口の形、まばたきが最初から入っているので、表情とリップシンクがすぐに動きます。

**3D Avatars**のページで、キャラクターかペルソナを選びます。**Get a 3D model**(3Dモデルを手に入れる)の下にある**Read the guide**(ガイドを読む)はこのセクションを開き、**Copy prompt**(プロンプトをコピー)はその見た目の説明をコピーします。

1. [VRoid Studio](https://vroid.com/en/studio)をダウンロードしてインストールします。
2. 必要なら、作業の参考にする絵を作ります。**Copy prompt**を選び、画像生成ツールに貼り付けてください。VRoid Studioにはプロンプトを入力する欄がないので、この絵は作りながら眺めるためだけのものです。
3. VRoid Studioで新しいモデルを作成します。キャラクターに最も近い髪、顔、目、体、服装を選び、形と色を調整して似せていきます。
4. モデルをVRMとしてエクスポートします。VRM 1.0とVRM 0.0のどちらも使えます。VRoid Studioに求められたら、モデルの情報と利用条件を入力します。
5. **Agents**で**3D Avatars**を開き、キャラクターかペルソナを選んで、**VRM model**(VRMモデル)の下にある**Import VRM**(VRMをインポート)を選びます。VRoid Studioのモデルなら、**Faces and mouth shapes**(表情と口の形)の表情、口の形、まばたきはすべて最初から埋まっています。

**プロンプトの用途。** 文章から絵や3Dモデルを作るツール向けに、キャラクターを説明するものです。内容は、無地の背景の前で正面を向いてTポーズで立つアニメ調の全身のキャラクターと、その見た目です。見た目は**Appearance**(外見)欄から取ります。**Image Appearance Override**(画像用の外見指定)のタグがオンの場合は代わりにそのタグを、外見がない場合は説明を使います。プロンプトに含まれるのは名前と見た目だけで、カードのほかの内容やチャットの内容は含まれません。プロンプトは英語です。使う前に自由に書き換えてください。

**動く部分。** モデルに対応する表情があれば、顔は返信に合わせて変わり、口はテキストか声に合わせて動きます。ほかのツールで作ったVRMでは、表情が少ないことも、まったくないこともあります。どの表情があるかは**Faces and mouth shapes**で確認できます。画像や説明から表情付きのVRMを作れるとうたうWebサイトもありますが、このガイドの執筆時点(2026年10月)ではどれも確認できなかったため、このガイドでは推奨していません。

削除されたTripoのジェネレーターで以前に作ったモデルも、読み込めて体は動きますが、顔は動きません。

## 表情と口が返信に合わせて動くしくみ

アバターは自動で反応します。この部分に設定するものはありません。

**Roleplayでの表情。** 返信がストリーミングされている間、Marinara Engineは書き終わった文を1つずつ読み、その気分を推測します。表情がちらつかないように、次のようにしています。

- 新しい気分が今の気分よりはっきり強いときだけ、表情を変えます。
- 1つの表情は少なくとも2秒間続きます。
- 落ち着いた文が2つ続いたときだけ、落ち着いた表情に戻ります。
- 返信が終わってから約4秒後に、表情は落ち着いた状態へ戻ります。

音声合成が返信を読み上げるときは、代わりに声に合わせて表情が変わります。下の**返信が読み上げられるとき**を参照してください。

ストリーミングがオフでも、文ごとの気分は保たれます。返信全体を1つの気分にまとめず、返信を話す時間に合わせて表情が順番に変わります。

[その他の感情](#pngtuber-sprites)の表情を持つPNGTuberアバターは、文から読み取ったより細かい感情も表示できます。たとえば、喜んでいるときのAmusementです。その表情も同じルールに従います。はっきり読み取れたときだけ変わり、少なくとも2秒間続きます。専用の表情がない感情では、それが属する主な感情の表情が表示されます。Expression Engineとゲームマスターの選択も同じように扱われます。選ばれた名前(たとえば`scared`)の表情がアバターにない場合は、その感情の表情、この例ではFearの表情が表示されます。3Dアバターとメッシュアバターが表示するのは6つの感情だけです。

**気分の読み取り方。** チャット用の接続には問い合わせません。チャットの文章は自分のMarinara Engineの中にとどまり、外部のサービスに送られることはありません。

- 組み込みの単語リストは、どの環境でもすぐに答えを出します。いくつかの言語で、気分を表すよく使われる単語を知っています。
- 動かせるコンピューターでは、Marinara Engineは代わりにmood reader(気分リーダー)という小さな感情モデルで文を読みます。mood readerは36言語を理解します。2D Avatarsか3D Avatarsをオンにした状態で初めてRoleplayのチャットを開いたときに、約300 MBを一度だけダウンロードします。両方のエージェントがオフの間はダウンロードしません。ダウンロードの進み具合は、**Agents**(エージェント)にある各アバターエージェントのページに表示されます。ダウンロードに失敗した場合は、約10分後に自動で再試行します。mood readerの準備ができるまでは単語リストが答えます。ダウンロード後はオフラインでも動きます。使用中は約1 GBのメモリーを使い、10分間使われないとメモリーから解放されます。Lite版、Android、メモリーが3 GB未満のコンピューターでは、単語リストを使い続けます。

**Game Modeでの表情。** ゲームマスターが表示する各行には表情が付いていて、話しているキャラクターのアバターがその表情になります。声で行を読み上げているときも、表情を選ぶのはゲームマスターです。キャラクターの心の声は表情を変えますが、口は動かしません。

**Expression Engine。** チャットでオンになっている場合、返信の後にExpression Engineが選んだ表情が、その返信の最終的な表情になります。次のメッセージを送った後に選択が届いた場合、その選択は対象だった返信にだけ使われます。音声合成が返信を読み上げる場合、その選択は声が終わったときに表示されます。Expression Engineがなくてもアバターは動きます。

**口。** テキストに合わせて動く場合、口が動くのはせりふ(引用符で囲まれた言葉、`[Name]:`の行、話者タグ)だけで、地の語りでは動きません。速さはおおよそ話す速さです。誰にも読み上げられないほど速くテキストが表示されると、口の動きは速くなり、さらに先へ飛んで画面上の言葉に追いつきます。ストリーミングがオフの場合、返信のせりふは8秒以内に話し終えます。音声合成がせりふを再生するときは、代わりに声が口を動かします。そのため、キャラクター自身の声で読み上げられた地の語りでも、そのキャラクターの口が動きます。

**返信が読み上げられるとき。** Roleplayで音声合成と**Auto-play**(自動再生)がオンの場合、声はふつう返信が表示されてから数秒後に始まるので、アバターは声を待ちます。

- 返信が表示されている間、アバターはいつもどおりまばたきして動きますが、口は閉じたままで、表情もまだ変わりません。
- 声が始まると、口は声に合わせて動き、声が各文に達するたびに表情が変わります。
- 表情が落ち着いた状態に戻るのは、テキストではなく声が終わってから約4秒後です。行と行の間の短い途切れでは戻りません。
- 声が失敗した場合や、返信から数秒以内に始まらない場合、アバターは返信の表情と口の動きをテキストから1回再生します。それより後で失敗した場合は、返信の最後の気分だけを表示してから落ち着いた状態に戻ります。
- 声がないまま30秒たつと、アバターは待つのをやめます。その後で声が始まった場合も、口は声に合わせて動きます。

**体。** アバターは、メッセージを送ってから最初の言葉が出るまでは考える動きを、口が動いている間は話す動きを、ほかの誰かが話している間や入力中は聞く動きをし、それ以外のときは休んでいます。

**グループチャット。** Individual(個別)のグループでは、返信しているメンバーが話します。メンバーのメッセージをスワイプしたときも同じです。Merged(統合)のグループでは、各段落は、その段落で最初に名前が出たキャラクターのものになります。名前が出なければ、前の段落のキャラクターのものになります。誰の名前も出ていない段落が表示されている途中では、名前が出るか段落が終わって話者が分かるまで、その段落のせりふは待機します。Individualのグループでストリーミングがオフの場合、現時点ではアバターが動くのは最後のメンバーの返信だけです。

<a id="lip-sync-with-text-to-speech"></a>

## 音声合成によるリップシンク

音声合成がRoleplayの返信を読み上げると、話しているキャラクターのアバターが声に合わせて口を動かします。大きな音では口を大きく開け、間では閉じます。口の形も変わります。「oo」のようなこもった音では丸くなり、「s」のような音では歯を見せます。追加で設定するものはありません。[Text to Speech (TTS)の設定](../media/tts-setup.md)のとおりに音声合成をオンにすれば、**Auto-play**(自動再生)でも、メッセージの**Speak**(読み上げ)ボタンでもリップシンクが働きます。ビジュアルノベルのレイアウトでも同じです。

- **話す人:** 口が動くのは、そのせりふを読み上げる声のキャラクターです。**Voice Option**(声の割り当て方)が声を選ぶのと同じキャラクターです。1つの返信に複数の話者がいる場合、各キャラクターの口は自分のせりふの間だけ動きます。語り手の声で読まれる行や、チャットのキャラクターではない話者では、どの口も動きません。**Only read dialogues**(せりふだけを読み上げる)がオフの場合、キャラクター自身の地の語りもそのキャラクターの声で読まれるので、その間も口が動きます。
- **一時停止、停止、チャットの切り替え:** 声を一時停止または停止すると、口も止まります。返信の読み上げ中に別のチャットへ切り替えると、そこのアバターは動きません。声が再生されている間に元のチャットへ戻ると、そのアバターが再び声に合わせて動きます。
- **表情:** **Auto-play**でも**Speak**ボタンでも、声が各文に達するたびに表情が変わります。ただし、Expression Engineがその返信の表情をすでに選んでいる場合は除きます。
- **音量:** **Line volume**(この読み上げの音量)スライダーが変えるのは声の大きさで、口の開き方は変わりません。
- **ペルソナ:** 自分のメッセージでは、音声合成の有無にかかわらず、ペルソナの口は動きません。
- **Game Mode:** 音声合成と**Auto-play**がオンの場合、アバターの口は自分のキャラクターの声を待ち、その声に合わせて動きます。一時停止、停止、チャットの切り替えで口も止まります。声がない行はテキストによる動きを続け、声が失敗したり始まらなかったりした場合は、テキストによる動きに1回だけ切り替わります。語り手とプレイヤーの声では、どのキャラクターの口も動きません。心の声は読み上げられません。

リップシンクによって声の再生が変わることはありません。Marinara Engineは口のタイミングを合わせるために各音声クリップの別のコピーを読むので、SafariやiPhone、iPadを含め、再生はこれまでどおりです。アバターが表示されている間は、クリップが届くたびに口のタイミングを準備します。最初のクリップが準備より先に再生される場合は、音声のタイミングに切り替わるまで、そのテキストで口を動かします。ブラウザーがクリップを読めない場合も声は再生され、口が声に合わなくなるだけです。

<a id="making-an-avatar-from-a-sprite"></a>

## スプライトからのアバター作成

エージェントエディターの**2D Avatars**のページでキャラクターかペルソナを選び、**Make an avatar from a sprite**(スプライトからアバターを作る)を使います。キャラクターやペルソナがすでに持っているスプライトをもとに作ります。結果を保存するまで今のアバターは変わらないので、何度でも試せます。

<a id="faces-from-the-avatar"></a>

### アバターから作る表情

**Make faces from the avatar**(アバターから表情を作る)は、背景のない表情を作ります。スプライトがまだないキャラクターやペルソナにも使えます。キャラクターエディターやペルソナエディターと同じスプライト生成が開き、アバターが参照画像としてチェックされた状態になります。

1. 最初は6つの主な表情(Neutral、Happy、Angry、Sad、Relaxed、Surprised)が並び、Pride、Grief、Realizationなど、さらに23の感情も選べます。追加の感情は、専用の表情ができるまで、その感情が表示する主な表情の行に入ります。29個すべてなら**All faces**(すべての表情)、6つなら**Main faces**(主な表情)を選びます。好きな表情だけを選ぶこともできます。
2. 表情は何回かに分けて、主な表情から先に描かれます。1枚の画像には、グリッドに収まるだけの表情が入ります。古いGPT Imageモデルは、1枚の画像に1つの表情を描きます。失敗した画像は1回だけ再試行されます。それでも失敗した場合は**Retry picture**(画像を再試行)を表示して実行が止まり、**Cancel**(キャンセル)を押しても、それまでに作った表情は残ります。
3. **Expose media prompts before sending**(送信前にメディアのプロンプトを表示)がオンの場合は、最初の画像を送る前に、すべての画像のプロンプトをまとめて確認します。どの表情も目を開けて口を閉じた状態で描かれるので、まばたき用と口パク用の画像で目を閉じたり口を開けたりできます。
4. アバターから新しい表情スプライトを単色の背景の上に描き、その色を取り除いて、キャラクターやペルソナのスプライトとして保存します。新しいスプライトは同じ名前のスプライトを置き換えるので、古いスプライトを残したい場合は、最後の手順で名前を変えてください。アバターをすでに保存している場合は、名前を変えたものも含め、新しい表情はそれぞれ描かれた感情の表情になります。ほかのスプライトは残るので、**Face for each feeling**(感情ごとの表情)でもう一度選べます。作り直した表情には、まばたき用と口パク用の画像がありません。古い画像は新しい表情に合わないためです。[まばたき用と口パク用の画像](#blink-and-talk-pictures)で新しく作ってください。PNGTuber Plusからインポートしたアバターは、自身の表情をそのまま保ちます。アバターと画像生成の接続が必要です。

<a id="blink-and-talk-pictures"></a>

### まばたき用と口パク用の画像

1. アバターが感情に表示する表情ごとに1行があり、その表情を表示する感情の名前が付いています。**Face**(表情)の横には、その**Eyes closed**(目を閉じる)と**Mouth open**(口を開ける)の画像が並びます。保存した画像、追加した`_blink`と`_talk`のスプライト、または新しい画像です。キャラクターやペルソナにポートレートのスプライトがある場合は、それだけが使われます。アバターがポートレートと全身の表情を混ぜることはないからです。PNGTuber Plusからインポートした表情のように、自分のスプライトではない表情も画像は表示されますが、新しい画像を描くことはできません。
2. **Image connection**(画像用の接続)を確認します(デフォルトの画像用の接続が自動で選ばれています)。**Make**(作る)は足りない画像を1枚描き、**Make pictures**(画像を作る)は足りない画像をすべて描きます。画像1枚につき、画像のリクエストが1回発生します。画像を編集できない接続では、1つの表情の2枚の画像を1回のリクエストで描きます(下記参照)。Settingsで**Expose media prompts before sending**(送信前にメディアのプロンプトを表示)をオンにしていると、各プロンプトを先に確認して編集できます。
3. 新しい画像が1枚ずつ表示されます。よさそうなものには**Keep**(残す)を、それ以外には**Try again**(もう一度試す)をクリックします。**Try again**は、すでにある画像の描き直しにも使えます。描き直している画像は、新しい画像が届くまで暗く表示され、スピナーが回ります。**Cancel**(キャンセル)を押すと、作成中の画像がサーバー側でも止まり、まだ作られていない画像は取りやめになります。**Try again**が失敗しても前の画像が残ります。残した画像を作り直すには、先に**Kept**(残した)をクリックして解除します。
4. **Save kept pictures**(残した画像を保存)をクリックします。残した画像は、その表情のPNGTuberアバターのまばたき用と口パク用の画像になり、常に位置がそろうように、もとになったスプライトのコピー、または一緒に描かれた新しい表情と並べて保存されます。アバターがまだスプライトをそのまま表示していた場合は、すべてのスプライトを残したうえで新しい画像が加わります。保存する前にスプライトを差し替えた場合は、その画像を作り直してください。

参照画像を受け付ける画像用の接続では、スプライトが唯一の参照画像として、モデルが受け付けるサイズと形(白い背景の上の切り抜き)で、目か口だけを変えるよう求めるプロンプトとともに送られます。モデルは返す画像を動かしたり、拡大縮小したり、余白を足したりするので、まずスプライトに位置を合わせてから、そこから目(まばたき用)か口(口パク用)だけを取り出します。輪郭、服、下端で途切れた胸元など、それ以外はすべてスプライト自身のピクセルのままなので、まばたきや口パクのたびにアバターが跳ねたように見えることはありません。モデルが目を閉じなかった場合や口を開けなかった場合、または位置を合わせられないほど画像を動かした場合、その画像は失敗し、理由を示すメッセージが表示されます。もう一度試してください。

Pollinations、Together AI、Horde、DALL-E、参照画像の入力枠がないComfyUIワークフローのように、画像を編集できない接続もあります。そうした接続では、**Make**はキャラクターやペルソナの外見から新しい表情を描き、そのまばたき用と口パク用の画像も一緒に描きます。3枚がそろうように1枚の画像にまとめて単色の背景の上に描き、その色を取り除きます。[アバターから作る表情](#faces-from-the-avatar)と同じ方法です。行には**New face**(新しい表情)と表示されます。**Keep**を押すと新しい表情と2枚の画像がまとめて残り、保存すると新しい表情がアバターでのその感情の表情になります。スプライト自体は変わりません。この方法には、キャラクターやペルソナの外見か説明が必要です。

<a id="mesh-avatar"></a>

### メッシュアバターの作成

1. スプライトを1枚選びます。キャラクターにNeutralの全身スプライトがあればそれが、なければNeutralのスプライトが自動で選ばれます。別のスプライトも選べます。正面を向いた全身または胸から上のスプライトが最適です。
2. **Chat connection that can see pictures**(画像を読めるチャット接続)を選びます。**The agent's connection**(エージェントの接続)は、2D Avatarsのページで設定した接続を使い、なければデフォルトのエージェント用の接続を使います。そのモデルは画像を受け付けるものでなければなりません。
3. **Make mesh avatar**(メッシュアバターを作る)をクリックします。チャットモデルが顔の位置を見つけ、Marinara Engineがスプライトをそのまま使ってアバターを組み立てます。**Cancel**で中止できます。
4. プレビューを確認します。輪郭線が目、眉、口に重なっていれば正しくできています。**Save as mesh avatar**(メッシュアバターとして保存)をクリックするか、**Discard**(破棄)をクリックして別のスプライトやモデルで試します。

生成されたメッシュアバターは頭、目、眉、口を動かし、自分のまぶたと口でまばたきし、話します。髪は頭と一緒に動きますが、手、髪の毛の1房、垂れ下がるアクセサリーにはリグが入っていません。小さなスプライトは、口が顔に合うように拡大したコピーから組み立てます。大きなスプライトの大部分を顔が占める場合は、作成が速く済むように、縮小したコピーからアバターを組み立てます。

まばたき用と口パク用の画像では、スプライトは画像用の接続に送られます(失敗したときは、その接続にフォールバックの画像用接続が設定されていて、それが参照画像を受け付ける場合は、そちらにも送られます)。メッシュアバターでは、チャット用の接続に送られます。画像を編集できない接続に送られるのはプロンプトだけで、そこには外見が含まれます。プロンプトは2D Avatarsエージェントに含まれています。**Expose media prompts before sending**をオンにすると、各画像のプロンプトを送信前に読んで変更できます。デバッグモードをオンにすると、すべてのプロンプトがサーバーのログに書き込まれます。

## 自分でモデルを作る

始めるために何かを作る必要はありません。表情スプライトを持つキャラクターやペルソナにはすでにPNGTuberのアバターがあり、[スプライトからのアバター作成](#making-an-avatar-from-a-sprite)で、まばたき用と口パク用の画像を加えたり、メッシュアバターを作ったりできます。代わりに自分でモデルを作るなら、次のツールのどれかを使ってください。スプライトは追加した時点で表示され、ファイルはすべて**Agents**(エージェント)にあるエージェントのページでインポートします。

| 作りたいもの | ツール | できるもの |
| --- | --- | --- |
| PNGTuberのスプライト | 任意のお絵描きアプリで描いてから、キャラクターの**Sprites**タブへ | スプライト |
| レイヤーとコスチュームを持つPNGTuberのスプライト | [PNGTuber Plus](https://github.com/kaiakairos/PNGTuber-Plus) | `.save`ファイル |
| メッシュアバター | [Mesh Avatar Studio](https://github.com/shinshin86/mesh-avatar-studio) | `.mavatar`ファイル |
| 3Dモデル | [VRoid Studio](https://vroid.com/en/studio)、または[VRM Add-on for Blender](https://vrm-addon-for-blender.info/en-us/)を入れたBlender | `.vrm`ファイルと、任意で`.vrma`の待機アニメーション |

### 自作のスプライト

1. 感情ごとに1枚ずつ絵を描きます。すべて同じサイズにし、キャラクターを同じ位置に置いてください。それぞれに感情の名前を付けます。`neutral`、`happy`、`angry`、`sad`、`relaxed`、`surprised`です。`smile`、`cry`、`calm`、`shock`のように、感情を表す単語を含む名前も使えます。任意の[その他の感情](#pngtuber-sprites)にも、`amusement`、`fear`、`gratitude`のように、その感情の名前を付けた絵を追加します。
2. 口を動かすには、口だけを開けた同じ絵を描き、名前に`_talk`を付けます(例: `happy_talk`)。まばたきさせるには目だけを閉じて`_blink`を付けます。両方の場合は`_blink_talk`を付けます。これらの絵がない感情でも、話している間は跳ねます。
3. キャラクターかペルソナの**Sprites**タブで、**Facial Expressions**(表情)に絵を追加します。**Upload Folder**(フォルダーをアップロード)を使うとフォルダーをまとめて追加でき、各スプライトにはファイル名がそのまま付きます。[キャラクターのスプライト](../characters/sprites.md)を参照してください。
4. 2D Avatarsがオンのチャットには、すぐに表示されます。感情ごとの表情や動きを変えるには、[PNGTuberのスプライト](#pngtuber-sprites)を参照してください。

### PNGTuber Plus

1. アバターを別々のレイヤーで組み立てます。開いた口は話している間だけ、閉じた口は黙っている間だけ表示されるように設定します。閉じた目はまばたき中だけ、開いた目はまばたきしていない間だけ表示されるように設定します。
2. 感情ごとに、目か口を差し替えるコスチュームを作り、その画像に感情の名前を付けます(例: `angry eyes.png`、`happy_mouth.png`)。より細かい感情も同じで、たとえば`fear eyes.png`のように名前を付けます。コスチューム1が平常時の表情になります。
3. アバターを保存すると、`.save`ファイルができます。
4. **Agents**で**2D Avatars**を開き、キャラクターかペルソナを選んでから、**PNGTuber sprites**、**Import PNGTuber Plus save**の順に選びます。名前で対応付けられなかった感情には、表情を選んでください。

### Mesh Avatar Studio

1. 背景が透明な、正面を向いた頭と肩の絵から始めます。Mesh Avatar StudioはNode.jsを使って自分のコンピューターで動き、Claude CodeやCodexなどのコーディングエージェントが絵にリグを入れます。手順はREADMEで説明されています。
2. 必要なら、**Drawn variants**で描いた目と口を追加します。Marinara Engineは、その口の形(`mouth_a`、`mouth_i`、`mouth_o`、`mouth_a_half`)と閉じた目(`eyes_closed_0`、`eyes_closed_1`)を自動で使います。どのメッシュアバターにも6つの感情が組み込まれているので、名前を付ける必要はありません。
3. **Export .mavatar**を選びます。プロジェクトのフォルダーを自分でZIPにしないでください。
4. **Agents**で**2D Avatars**を開き、キャラクターかペルソナを選んでから、**Mesh avatar**、**Import .mavatar file**の順に選びます。

### VRoid Studio

1. VRoid Studioでキャラクターを作ります。その表情、口の形、まばたきは標準のVRMの表情なので、自動で認識されます。
2. VRMとしてエクスポートします。VRM 1.0とVRM 0.0のどちらも使えます。VRoid Studioに求められたら、モデルの情報と利用条件を入力します。
3. **Agents**で**3D Avatars**を開き、キャラクターかペルソナを選んで、**Import VRM**をクリックします。

<a id="blender-with-the-vrm-add-on-for-blender"></a>

### BlenderとVRM Add-on for Blender

1. Blenderの**Preferences**にある**Get Extensions**から、VRM Add-on for Blenderをインストールします。4.2より前のBlenderでは、代わりに**Add-ons**でアドオンのZIPファイルをインストールします。
2. モデルに人型のアーマチュアを付け、VRMのボーンを割り当てます。アドオンで自動的に割り当てることもできます。
3. アドオンのVRMパネルで表情を設定します。VRM 1.0では**Expressions**、VRM 0.xでは**VRM 0.x Blend Shape Proxy**を使います。各表情は、シェイプキーかマテリアルを動かすものでなければなりません。空の表情は何も変えないため、インポートではNeutralにしか使われません。`Smile`や`Shock`のように名前が分かりやすいカスタムの表情も対応付けられます。
   - 表情: **Happy**、**Angry**、**Sad**、**Relaxed**、**Surprised**。VRM 0.xでは最初の4つを**Joy**、**Angry**、**Sorrow**、**Fun**と呼びます。驚きのプリセットはないので、`Surprised`という名前のカスタムの表情を追加してください。
   - 口の形: **Aa**、**Ih**、**Ou**、**Ee**、**Oh**(VRM 0.xでは**A**、**I**、**U**、**E**、**O**)。
   - まばたき: **Blink**。
4. **File → Export → VRM (.vrm)**でエクスポートします。待機アニメーションを作るには、アーマチュアにアニメーションを付けて**File → Export → VRM Animation (.vrma)**を使います。アドオンがアニメーションをエクスポートできるのはVRM 1.0に設定したモデルだけなので、アニメーションが必要な場合は手順3でVRM 1.0を選んでください。
5. **Agents**で**3D Avatars**を開き、キャラクターかペルソナを選んで、**Import VRM**をクリックします。アニメーションは、**Idle animation**(待機アニメーション)の**Add animation**(アニメーションを追加)で追加します。

### エクスポートで避けること

- **圧縮。** Dracoやmeshoptによるメッシュの圧縮と、KTX2のテクスチャーは読み込めません。上で紹介したVRMのエクスポートでは使われませんが、Blenderの通常のglTFエクスポートにはDracoの選択肢があり、モデルの最適化ツールは3つとも追加することがあります。圧縮をオフにしてエクスポートし直してください。
- **通常のglTF。** 通常の`.glb`や`.gltf`のファイルには、表情と骨格を名前で示すVRMのデータがありません。代わりに`.vrm`をエクスポートしてください。
- **分かれたファイル。** テクスチャーやデータが別のファイルに分かれているモデルは使えません。1つの`.vrm`ファイルとしてエクスポートしてください。
- **PNGTuber Plusの追加効果。** 揺れ、ドラッグ、アニメーションは引き継がれません。各レイヤーは静止した状態で表示され、アニメーションするレイヤーは最初のフレームを表示します。

## パフォーマンスとデバイス

各種類のアバターの描画コードは、その種類のアバターが初めて表示されたときにだけダウンロードされます。そのため、アバターのないチャットでは余分なものは何も読み込みません。

| | スマートフォン | デスクトップ |
| --- | --- | --- |
| 同時に描画するアバター | 2 | 4 |
| 話している間の毎秒フレーム数 | 30 | 30 |
| 待機中の毎秒フレーム数 | 20(スマートフォンの負荷が高いときは15) | 30 |
| 鮮明さ(ピクセル比) | 最大1.5× | 最大2× |

チャットには、キャラクターの順に、続いて自分のペルソナのアバターが、この上限まで表示されます。タブが非表示のとき、ウィンドウがバックグラウンドにあるとき、Appearanceの設定を開いているとき、チャットが画面外にあるときやパネルやエディターに覆われているときは、アバターの描画を完全に止めます。**Reduce Ambient Animations & Effects**(周囲のアニメーションと効果を減らす)か端末の動きを減らす設定がオンのときも、アバターは表情を変え、口を動かしますが、呼吸、揺れ、待機中のポーズは省きます。
