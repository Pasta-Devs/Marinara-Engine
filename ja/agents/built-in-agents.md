# ダウンロードできるエージェント一覧

このガイドでは、**Agents → Download Agents**(エージェント → エージェントのダウンロード)から入手できる公式パッケージ36個を、カテゴリー別にすべて紹介します。エージェントはMarinara Engineをインストールした直後の状態には含まれていません。パッケージのソース、マニフェスト、成果物、機械可読のカタログは[Pasta-Devs/Marinara-Agents](https://github.com/Pasta-Devs/Marinara-Agents)で公開しています。それぞれについて、何をするエージェントなのか、いつ動くのか(またはどう組み込まれるのか)、どのチャットモードで使えるのか、主な設定は何かを説明します。インストールと有効化の方法は、先に[エージェント: チャットを支えるAIヘルパー](agents-overview.md)を読んでください。

## この一覧の読み方

エージェントとは、チャットの返信と並行して自動で動く小さなAIの補助役です。まずカタログからインストールし、そのうえでキャラクターカードごとではなくチャットごとにオンにして設定します。ダウンロード、アップデート、アンインストール、チャットごとの設定、費用に関する注意は[エージェント: チャットを支えるAIヘルパー](agents-overview.md)を参照してください。

以下の各エージェントには、3つの要点を記載しています。

- **フェーズまたは統合方法**: 通常のパイプライン型エージェントが動くタイミングです。**Pre-Generation**(生成前)は返信の前に動き、プロンプトに文章を追加できます。**Parallel**(並行)は返信と同時に動くため、完成した文章は見えません。**Post-Processing**(後処理)は返信が完成してから動き、その内容を読めます(書き換えられるものもあります)。Maps、Calls、Conversation向けのゲームのような機能パッケージは、パイプラインではなく各画面に直接組み込まれます。
- **使える場所**: そのエージェントを追加できるチャットモードです。ほとんどのエージェントは**Roleplay**チャットで動きます。ほかのモードで動くものもあり、各項目に明記しています。
- **主な設定**: 変更する機会が多い設定です。エージェントを追加するときに指定するほか、後から**Chat Settings**(チャット設定)にあるそのエージェントの設定カードでも変更できます。

Marinaraは**Agents**パネルでエージェントを3つのカテゴリーに分けています。**Writer Agents**、**Tracker Agents**、**Misc Agents**の3つです。この一覧も同じ分類に従います。

実行間隔とは、毎回のメッセージではなく、ユーザーとアシスタントのメッセージ数回に1度だけエージェントを動かす設定です。実行間隔はエージェントの設定で最大100まで変更できます。

## 執筆エージェント

**Writer Agents**は物語や文章そのものを整えます。返信の前に方向づけを加えるか、返信の後に文章を整えるかのどちらかです。

### Prose Guardian

意味を変えずに、最新の返信から禁止語と繰り返しを取り除くように書き換えます。同じ言い回しや同じ単語をモデルが繰り返すのを止めたいときに使います。

- **フェーズ**: Post-Processing。
- **使える場所**: Roleplay。
- **主な設定**: **Banned Words**(デフォルトは`ozone`)、**Prefer In Writing**、**Remove From Writing**の各入力欄です。**Hold Message Until Rewrite**トグル(デフォルトでオン)をオンにすると、書き換えが終わるまで返信を表示しません。オフにすると、先に元の返信が表示され、後から差し替わります。

### Continuity Checker

最新の返信にある具体的な矛盾を直します。たとえば1人のキャラクターが同時に2か所にいる、時系列が破綻しているといった誤りです。問題を見つけるとチェックリストの形で提示するので、どの修正を適用するかを選べます。

- **フェーズ**: Post-Processing。
- **使える場所**: Roleplay。
- **主な設定**: **Hold Message Until Rewrite**トグル。

### Card Evolution Auditor

プレイ中にキャラクターがどう変化したかを見守り、そのキャラクターカードへの修正案を出します。自動で書き換えることはありません。提案は必ず**Review Character Card Updates**ウィンドウに表示され、承認するか却下するかを選べます。

- **フェーズ**: Post-Processing。
- **使える場所**: Roleplay。
- **主な設定**: デフォルトではユーザーとアシスタントのメッセージ8回に1度動きます。[エージェントの承認とAgent Suite](approvals-and-agent-suite.md)を参照してください。

### Narrative Director

指示したときだけ、物語を一度だけ動かすきっかけを作ります。Roleplayチャットでこのエージェントが有効になっていると、メッセージ入力欄の上に**Push Story**ボタンが表示されます。クリックすると次の返信に効果がかかり、話が前に進むか、意外な展開が入ります。

- **フェーズ**: Pre-Generation。
- **使える場所**: Roleplayのみ。
- **主な設定**: **Story Push Mode**(**Natural**は今の筋を進め、**Random Event**はありそうな意外な出来事を加えます)。**Secret Plot**という隠しの長期的な筋書きを持たせることもできます。詳しい手順は[Narrative DirectorとSecret Plot](../roleplay/narrative-director.md)を参照してください。

### Knowledge Retrieval

返信の前に、選んだロアブック(とアップロードしたファイル)を読み取ります。重要な部分を要約し、その要約をプロンプトに加えます。ロアブックとは、世界やキャラクターの背景設定をまとめたものです。動作の軽い検索なので、別途データベースを用意する必要はありません。

- **フェーズ**: Pre-Generation。
- **使える場所**: Roleplay。
- **主な設定**: **Use chat-active lorebooks**トグル、**Fixed Source Lorebooks**の選択欄、対応形式のファイルアップロードです。このエージェントとKnowledge Routerは役割が重なるので、同時に使わないでください。設定方法は[知識ソース](knowledge-sources.md)を参照してください。

### Knowledge Router

Knowledge Retrievalより費用を抑えられる代替手段です。要約する代わりに、ロアブックのエントリーに付けた短い説明文を読みます。そして条件に合ったエントリーをそのまま丸ごと追加します。エントリーの説明文がしっかり書かれているほど効果を発揮します。

- **フェーズ**: Pre-Generation。
- **使える場所**: Roleplay。
- **主な設定**: **Use chat-active lorebooks**トグルと**Fixed Source Lorebooks**の選択欄です。参照元のエントリーのうち何パーセントに説明文があるかは、カバー率のバッジでわかります。設定方法は[知識ソース](knowledge-sources.md)を参照してください。

## トラッカーエージェント

**Tracker Agents**は、シーン、キャラクター、各種の数値を継続的に記録します。最新の出力をプロンプトの一区画として加えられるので、モデルの描写がぶれにくくなります。World State、Quest Tracker、Character Tracker、Persona Stats、Custom Tracker、Inventory Tracker、Beholderは**Add as Prompt Section**がデフォルトでオンです。Expression EngineとBackgroundだけが例外です。

### World State

日付、時刻、天気、場所、その場にいるキャラクターを記録します。シーンの土台が固まるので、物語がいつどこで起きているかをモデルが見失いません。

- **フェーズ**: Post-Processing。
- **使える場所**: Roleplay。
- **主な設定**: **Add as Prompt Section**(デフォルトでオン)。

### Expression Engine

最新の返信から感情を読み取り、キャラクターに合うスプライトや表情を選びます。スプライトとは、シーンに表示するキャラクターの立ち絵です。雰囲気に応じて変化する立ち絵を使いたいときに向いています。

- **フェーズ**: Post-Processing。
- **使える場所**: Roleplay。
- **主な設定**: **Sprite Source**(**Expressions**、**Full-body**、または両方)、**Expression Avatars**トグル、**Sprite Owners**の選択欄、サイズと不透明度のスライダーです。[キャラクターのスプライト(表情と全身)](../characters/sprites.md)を参照してください。

### Quest Tracker

クエストの目標、達成状況、報酬を管理します。やるべきことの一覧を画面に出したい冒険物のプレイに向いています。

- **フェーズ**: Post-Processing。
- **使える場所**: Roleplay。
- **主な設定**: **Add as Prompt Section**(デフォルトでオン)。

### Background

アップロード済みの背景の中から、今のシーンにいちばん合う画像を選びます。画像を生成することはありません。シーンの背景を自動生成したいときはIllustratorを使ってください。

- **フェーズ**: Post-Processing。
- **使える場所**: Roleplay。
- **主な設定**: エージェント共通の接続とコンテキストの設定です。背景の選択には、背景のライブラリーにすでにある画像だけを使います。

### Character Tracker

その場にいるキャラクターに加えて、気分、行動、外見、服装、内心、HPなどキャラクターごとの数値を記録します。画像のない新規キャラクターの顔絵を作ることもできます。

一度シーンから退場した常連のキャラクターが再登場したときは、Character Trackerが保存済みの最新の数値とカスタム項目を引き継いで一貫性を保ちます。キャラクターカードのあるキャラクターには、設定済みのRPGのリソースや能力値も判断材料として渡され、カードのアバターと切り抜きも必ず保持されます。顔絵の自動生成は、対応するキャラクターカードのないNPCだけが対象です。

- **フェーズ**: Post-Processing。
- **使える場所**: Roleplay。
- **主な設定**: **Add as Prompt Section**(デフォルトでオン)と、任意の**Auto-Generate NPC Avatars**設定です。後者には画像生成用の接続を選ぶ欄が付いています。

### Beholder

キャラクターごとに、身体の部位別の現在の服装、手に持った物、負傷、失われた身体部位、明示的に何も着けていない部位、人間以外の種族を記録します。検証済みの最新スナップショットはBeholderのRoleplay Chat Settingsドロワーに表示され、Beholderの次の追跡呼び出しと次のRoleplay主応答の両方に渡されます。

- **フェーズ**: Post-Processing。
- **使える場所**: Roleplayのみ。
- **主な設定**: **Chat Settings → Agents → Tracker Agents**で追加または削除します。同じ場所から**Configure Beholder**を開き、接続、モデル、プロンプト、コンテキスト、出力上限を選びます。**Add as Prompt Section**はデフォルトでオンです。
- **推奨モデル**: 状態全体を確実に追跡するには、OpenAI GPT-5.5+、Claude Opus 4.8+、Kimi K3+などのSOTAモデルを使用してください。
- **由来**: AGPL-3.0-onlyライセンスの[GetBeholder/Beholder-ME](https://github.com/GetBeholder/Beholder-ME)をEngineのネイティブAgentランタイム向けに移植しています。公式パッケージは、従来の拡張機能のDOM、ポーリング、ローカルストレージランタイムを読み込みません。

### Persona Stats

満腹度、体力、清潔さなど、自分のキャラクターのステータスバーを記録します。自分で追加したバーも対象です。サバイバル物や生活シミュレーション風のプレイに向いています。

- **フェーズ**: Post-Processing。
- **使える場所**: Roleplay。
- **主な設定**: **Add as Prompt Section**(デフォルトでオン)。[キャラクターの色とRPGステータス](../characters/colors-and-stats.md)を参照してください。

### Custom Tracker

通貨、カウンター、フラグなど、自分で定義した項目を記録します。組み込みのトラッカーでは足りない要素が物語にあるときに使います。

- **フェーズ**: Post-Processing。
- **使える場所**: Roleplay。
- **主な設定**: **Add as Prompt Section**(デフォルトでオン)。

### Inventory Tracker

お金、装備中の品、持ち歩いているアイテムを3つの構造化リストとして追跡します。Persona Statsのインベントリを再利用したり、データをCustom Trackerの文字列に詰め込んだりはしません。同じ名前は統合され、数量1は見た目をコンパクトに保ち、ロックした行はその後の追跡でも変更されません。

- **フェーズ**: Post-Processing(後処理)。
- **利用できるモード**: Roleplay。
- **主な設定**: **Add as Prompt Section**は初期状態でオンです。HUDとTracker Panelで、すべての名前と数量を編集、ロックできます。

### World Maps

入れ子になった場所と、その位置関係を物語に持ち込み、継続して保持します。地方、エリア、部屋、そのつながりを自分で作成し、場所の間を移動でき、現在地を生成時の空間的なコンテキストとして反映させられます。Game Modeにもこのパッケージのワールドマップ表示が追加されます。

- **統合方法**: 機能パッケージです。通常の生成フェーズで動くエージェントではなく、マップのUIとチャット実行時のコンテキストを提供します。
- **使える場所**: RoleplayとGame。
- **主な設定**: Roleplayチャットで使うには**Chat Settings → Agents**から有効にします。Game Modeではゲームの作成時に選択し、後からそのゲームの設定で管理します。インストールと削除にはMarinaraの再起動が必要です。
- **詳しいガイド**: [World Maps: 設定、作成、移動](hierarchical-maps.md)。

## その他のエージェント

**Misc Agents**は、画像、音楽、観客の反応、カードの更新といった追加要素を担当します。

### Echo Chamber

シーンに反応する観客を再現し、チャット領域に浮かぶ**Echo**ウィジェットに表示します。30秒ごとに新しい反応が1件ずつ現れます。

- **フェーズ**: Parallel。
- **使える場所**: Roleplay。
- **主な設定**: 用意された選択肢から作風を選びます。**AO3 / Wattpad**、**Twitter / Reddit**、**4chan**、**Constructive**、**Hype Squad**、**Harbingers**などです。ウィジェット内の操作には**Re-run Echo Chamber**と**Clear messages**があります。

### Noodle

Noodleの公開タイムラインと、クリエイターとファンのロールプレイ用フィードNoodleRからなる、任意のローカルなソーシャル世界を追加します。通常のチャットエージェントの処理には入らず、Home専用タブで開きます。

- **統合方法**: 機能パッケージ。Homeタブ、ローカルルート、生成とメディアのフロー、バックグラウンドスケジューラーを追加します。
- **利用できる場所**: Home。必要に応じてConversation、Roleplay、Gameのチャットからコンテキストを引き継げます。
- **主な設定**: **Agents → Download Agents**からインストールし、指示が表示されたらMarinara Engineを再起動します。Noodle内では、招待アカウント、テキストと画像の接続、タイムラインの更新、NoodleR Creatorプロフィール、シミュレーション投稿へのアクセス、視聴者の活動を設定できます。
- **データの扱い**: アンインストールするとHomeタブが消え、再起動後にパッケージのルートとスケジューラーが停止します。既存のNoodleとNoodleRのデータは、後で再インストールできるよう保持されます。
- **詳しいガイド**: [Noodle: アプリ内ソーシャルタイムライン](../noodle/overview.md)。

### Long-Term Memory

チャットの要約、キャラクターの記録、ロアブックから長く残る記憶を抽出してパッケージ専用の保管庫に蓄え、返信の前に関係するコンテキストを呼び出します。範囲を絞った保管庫の閲覧、取り込み元のインポート、下書きの承認待ち確認、呼び出したコンテキストを差し込む位置をプリセットのマーカーで指定する機能に対応しています。

- **統合方法**: 機能パッケージです。通常の後処理トラッカーではなく、生成前のコンテキストと記憶管理のUIを提供します。
- **使える場所**: Conversation、Roleplay、Game。
- **主な設定**: 有効化、呼び出しに使うトークンの上限(128-16,384)、呼び出す最大チャンク数(1-100)、スコアのしきい値、直近メッセージのコンテキスト(1-20)、呼び出しの方式と意味的、語彙的、グラフ、キーワードの各重み、解決済みの記憶を含めるかどうか、呼び出しの前置き文、抽出時の推論と詳細度、生成の上限、取り込み元の上限、プロンプトのテンプレート、AIによるキーワード抽出、Game Modeでの抽出です。
- **データの取り扱い**: 保管庫、下書き、設定の書き出しや置き換えには、Memory Settingsのバックアップ操作を使います。全データの削除を実行すると、記憶、下書き、活動履歴、生成された索引が完全に消え、設定だけが残ります。パッケージをアンインストールしても、Long-Term Memoryの保管庫は後で入れ直せるように残ります。インストール、アップデート、削除にはMarinaraの再起動が必要です。
- **対応バージョン**: Engineの`2.3.5`以上`4.0.0`未満です。このパッケージは`agent-runtime`、`chat-read`、`chat-write`、`routes`、`storage`、`ui`の権限を使います。

### Illustrator

画像生成と動画生成を担当します。印象的な場面の絵柄のプロンプトを書き起こし、設定済みのメディアプロバイダーへ送ります。

- **フェーズ**: Post-Processing。
- **使える場所**: Roleplay。
- **主な設定**: デフォルトではユーザーとアシスタントのメッセージ5回に1度動きます。設定には**Prompt Model**、**Image Style**、**Attach Card Appearance**、**Send Avatar References**があります。詳しい設定方法は[Illustratorエージェント](../media/illustrator-agent.md)を参照してください。

### Lorebook Keeper

チャットに出てきた重要な事実からロアブックのエントリーを作成、更新します。遊ぶほどに世界の設定が増えていきます。

- **フェーズ**: Post-Processing。
- **使える場所**: Roleplay。Game Modeでは、セッション終了時に同じ働きをする**Game Session Keeper**という派生版があります。
- **主な設定**: デフォルトではユーザーとアシスタントのメッセージ8回に1度動きます。エントリーの保存先は**Target Lorebook**の選択欄で決めます。自動で選ばせることもできます。

### Combat

行動順、HP、ターンの進行を含めて戦闘を管理します。有効にすると、メッセージ入力欄の上に**Encounter**ボタンが表示されます。

- **フェーズ**: Parallel。
- **使える場所**: Roleplay。
- **主な設定**: ターンの判定に使うダイスロールのツールが同梱されています。

### Immersive HTML

物語の内容は変えずに、装飾された手紙や画面のような、作中世界の視覚要素を最新の返信に加えます。

- **フェーズ**: Post-Processing。
- **使える場所**: Roleplayのみ。
- **主な設定**: **Hold Message Until Rewrite**トグル。

### Music DJ

シーンの雰囲気を読み取り、それに合う音楽を再生します。Spotify、YouTube、ローカルの音声ファイルを利用できます。

- **フェーズ**: Post-Processing。
- **使える場所**: RoleplayとGame。
- **主な設定**: **Music Player**設定でプロバイダーを選びます。プロバイダーごとに個別の設定が必要です。Spotify、YouTube、ローカルの音楽それぞれの詳しい手順は[Music DJ](../media/music.md)を参照してください。

### Haptic Feedback

物語の内容を読み取り、Intiface Central経由で接続した大人向けのおもちゃをリアルタイムに制御します。このエージェントを有効にする前に、Intiface Centralを起動してトイを接続しておく必要があります。

- **フェーズ**: Post-Processing。
- **使える場所**: Conversation、Roleplay、Game。
- **主な設定**: **Touch Sensitivity**の選択(**Subtle**、**Standard**、**Intense**)と**Intiface URL**欄です。強さの設定は、利用できる`0.0-1.0`の強度範囲を制限せずにエージェントの選択を導きます。詳しい設定方法は[Haptic Feedbackの設定](../integrations/haptic-feedback.md)を参照してください。

### CYOA Choices

返信のたびに「What will you do?」というクリックできる選択肢のボタンを追加し、ゲームブックのような感覚を作ります。ボタンにはそれぞれ完全な行動文が入っていて、1クリックで送信できます。

- **フェーズ**: Post-Processing。
- **使える場所**: Roleplay。
- **主な設定**: **Edit**で選択肢を書き換え、**Re-roll**で新しい選択肢を作り直せます。

### Storyboard

完了したRoleplayのメッセージとGameの語りから、静止画または動画の絵コンテを組み立てます。計画とプロバイダーに合わせた整形を分けて処理するため、生成されるキーフレームや動画の全体で、元の時系列、キャラクターの同一性、選んだ絵柄が保たれます。

- **統合方法**: エージェントパッケージです。GameとRoleplayは、EngineのStoryboardホスト連携を通じて、インストールしたパッケージのプロンプトのテンプレートと設定を使います。
- **使える場所**: RoleplayとGame。
- **主な設定**: 静止画と動画のどちらのプランナーを使うか、画像と動画の接続、キーフレーム数、長さ、表示方法、キャラクター参照の扱い、Roleplayのエピソードと作風のテンプレート、Gameのイラストと動画のテンプレートを選べます。
- **対応バージョン**: Engineの`2.3.5`以上`3.0.0`未満です。このパッケージは`agent-runtime`、`chat-read`、`prompt-context`、`storage`、`ui`の権限を使い、再起動は不要です。
- **詳しいガイド**: [Storyboardエージェントガイド](../game/storyboard.md)。

### Calls

Conversationのキャラクターとリアルタイムの音声通話とビデオ通話ができるようになります。自分からかける通話と着信、通話だけの文字起こし、音声合成、マイク入力、キャラクターの動画クリップに対応します。

- **統合方法**: Conversation向けの機能パッケージです。通常の生成フェーズで動くエージェントではなく、ツールバー、チャット画面、Chat Settingsに操作を追加します。
- **使える場所**: Conversation。
- **主な設定**: **Chat Settings → Agents → Calls**を開くと、通話を有効にし、音声、マイク、着信音、動画の挙動を選べます。[Conversationの音声通話とビデオ通話](../conversation/calls.md)を参照してください。インストールと削除にはMarinaraの再起動が必要です。

### UNO

自分とConversationのキャラクターで遊べる、ルール判定付きのUNOのテーブルを追加します。ハウスルールを設定でき、合計2人から10人まで参加できます。

- **統合方法**: Conversation向けのゲームパッケージ。
- **使える場所**: Conversation。
- **主な設定**: ゲームの選択欄から、または`/uno`で開始します。設定画面で参加者とハウスルールを決めます。インストールと削除にはMarinaraの再起動が必要です。

### Chess

1対1のChessの盤面を追加します。合法手の判定、チェックとチェックメイトの検出、取った駒の表示、キャラクターになりきった相手のターンに対応します。

- **統合方法**: Conversation向けのゲームパッケージ。
- **使える場所**: Conversation。
- **主な設定**: ゲームの選択欄から、または`/chess`で開始し、対戦相手と自分が持つ側を選びます。インストールと削除にはMarinaraの再起動が必要です。

### Poker

合計2人から8人で遊べるTexas Hold'emのテーブルを追加します。ブラインド、ベットのラウンド、サイドポット、ショーダウンの判定、キャラクターになりきった対戦相手に対応します。

- **統合方法**: Conversation向けのゲームパッケージ。
- **使える場所**: Conversation。
- **主な設定**: ゲームの選択欄から、または`/poker`で開始し、参加者、初期チップ、ブラインドの額を選びます。インストールと削除にはMarinaraの再起動が必要です。

### 8-Ball Pool

1対1のビリヤードのテーブルを追加します。ソリッドとストライプ、狙いと打つ強さ、ファウル、ボール・イン・ハンド、キャラクターになりきった相手のショットに対応します。

- **統合方法**: Conversation向けのゲームパッケージ。
- **使える場所**: Conversation。
- **主な設定**: ゲームの選択欄から、または`/8ball`で開始し、対戦相手を選びます。インストールと削除にはMarinaraの再起動が必要です。

### Tic-Tac-Toe

1対1のTic-Tac-Toeの盤面を追加します。記号は自分で選ぶこともランダムにすることもでき、ターンの正しい処理と勝敗、引き分けの判定に対応します。

- **統合方法**: Conversation向けのゲームパッケージ。
- **使える場所**: Conversation。
- **主な設定**: ゲームの選択欄から、または`/tictactoe`(別名`/ttt`)で開始し、対戦相手と自分の記号を選びます。インストールと削除にはMarinaraの再起動が必要です。

### Rock-Paper-Scissors

1対1のRock-Paper-Scissorsの対戦を追加します。どちらの手も公開の瞬間まで伏せられます。

- **統合方法**: Conversation向けのゲームパッケージ。
- **使える場所**: Conversation。
- **主な設定**: ゲームの選択欄から、または`/rps`で開始し、対戦相手と、3本勝負、5本勝負、7本勝負のどれで戦うかを選びます。インストールと削除にはMarinaraの再起動が必要です。
