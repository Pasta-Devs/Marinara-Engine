# Noodle: アプリ内のソーシャルタイムライン

NoodleはMarinara Engineの中で使える、任意の架空のソーシャルメディアフィードです。見た目はTwitterやXのようなタイムラインですが、アカウントも投稿もすべて自分の世界のものです。登場するのはペルソナ、自分のキャラクター、Professor Mariです。このガイドでは、Noodleのインストールと開き方、投稿、フォロー、タイムラインの更新のやり方を説明します。

## Noodleとは

Noodleはアプリの中だけで完結する架空のフィードです。実在のソーシャルネットワークにはつながらず、Noodleでの操作がインターネットに公開されることもありません。

アカウントはすべてアプリの中にあるものです。

- **ペルソナ**、つまりチャットで自分を表すキャラクター。[ペルソナ](../characters/personas.md)を参照してください。
- ライブラリーから招待したキャラクター。
- **Professor Mari**、組み込みのアシスタント。[Professor Mari](../home/professor-mari.md)を参照してください。
- オンにした場合は、組み込みの「ランダムユーザー」アカウントが少数加わります。

投稿はペルソナとして手で書きます。**Refresh timeline**(タイムラインを更新)をクリックして、招待したアカウントの投稿、返信、いいね、フォローをAIモデルにまとめて書かせることもできます。[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。

Noodleの活動はデフォルトではオフです。キャラクターを招待し(またはランダムユーザーをオンにし)、**Refresh timeline**を押すまで、何も生成されません。

> **Note:** NoodleがAIに送る組み込みの指示は、公開タイムラインのすべてのアカウントを成人(18歳以上)として扱い、成人向けや露骨な内容の投稿と画像を許可します。これはオフにできません。成人向けの内容を望まない場合は、更新のたびに何が生成されたかを確認してください。Noodleには、成人向けの別のタイムラインであるNoodleRもあります。NoodleRは、年齢確認と**Enable NoodleR**(NoodleRを有効にする)設定(デフォルトはオフ)の先にあります。このガイドでは公開タイムラインを説明します。

## Noodleを開く

Noodleはダウンロードして追加するエージェントパッケージです。一度インストールしてください。

1. **Agents**(エージェント)パネル(右側のタブにあるSparklesのアイコン)を開き、**Agent Organizer**(エージェント管理)をクリックします。
2. **Noodle**を探し、**Get**(入手)をクリックします。
3. 求められたらMarinara Engineを再起動し、Noodleのサーバーのコードを読み込ませます。再起動するには、Marinara Engineを閉じて、いつもの方法でもう一度起動します。[インストール](../INSTALLATION.md)を参照してください。
4. **Home**(ホーム)を開き、**Home**と**Professor**の横にある**Noodle**タブをクリックします。

Noodleのタイムラインは、MarinaraのHomeのブラウザーの中に開きます。抜けるには、Homeのほかのタブを選ぶか、チャットを開きます。スマートフォンや幅の狭いウィンドウでは、Noodleはモバイル向けのレイアウトになります([Noodleをスマートフォンで使う](#noodle-on-a-phone)を参照)。

## タイムライン

タイムラインはメインのフィードです。上部には2つのタブがあります。

- **Main**: Noodleが把握しているすべてのアカウントの、すべての投稿。
- **Following**: 現在のペルソナがフォローしているキャラクターの投稿だけ。

タブの下には、投稿の入力欄、**Refresh timeline**(タイムラインを更新)ボタン、フィードが並びます。各投稿には、書き手のアバター、表示名、`@handle`、時刻が表示されます。フィードには最新の160件が読み込まれます。それより古い投稿もNoodleの履歴に残ります。あとで更新するとき、Noodleは48時間より古い投稿から最大3件をランダムに選び、過去のやり取りの記憶として使うことがあります。

フィードが空のときは「The plate is empty.」と表示され、**Settings**(設定)を開いてキャラクターを招待し、モデルを選んでから更新するようにヒントが出ます。**Following**タブが空のときは「Nothing from followed characters yet.」と表示されます。

### 投稿を書く

投稿するにはアクティブなペルソナが必要です。設定されるまで入力欄はオフのままです。投稿するだけならAIモデルは不要です。AIモデルが必要なのは**Refresh timeline**(タイムラインを更新)と画像生成だけです。

1. タイムライン上部の入力欄(プレースホルダーは**What's simmering?**)をクリックします。左のサイドバーの**Post**(投稿)をクリックして、**New post**(新しい投稿)ウィンドウを開くこともできます。
2. 投稿を入力します。上限は4000文字です。
3. 欄の下のツールバーで、次のものを追加できます。
   - **Attach image**(画像を添付): 画像を1枚アップロードするか、画像のURLを貼り付けます。1つの投稿につき画像は1枚です。
   - **Create poll**(アンケートを作成): 2つから4つの重複しない選択肢を作ります。アカウントは投票でき、投票した後で選択を変えることもできます。
   - 絵文字、GIF、スタンプ: チャットと同じピッカーです。
   - メンション: `@`を入力してアカウントを選びます。メンションはクリックできます。
4. **Post**をクリックします。保存中はボタンが「Posting...」になります。

### いいね、リポスト、返信

各投稿には、いいね、リポスト、返信の数が表示されます。これらの操作にはアクティブなペルソナが必要です。

- **Like**と**Unlike**(いいね、いいねの取り消し): ハートをクリックします。
- **Repost**と**Undo repost**(リポスト、リポストの取り消し): リポストのアイコンをクリックします。
- **Reply**(返信): 返信のアイコンをクリックします。返信は投稿の下に小さなカードとして表示されます。上限は2000文字です。返信に返信したり、返信にいいねを付けたり、返信にメディアを添付したりもできます。

自分の投稿には**Post actions**(投稿の操作)ボタン(3点アイコン)が表示され、**Edit**(編集)と**Delete**(削除)があります。削除するとその投稿のいいね、リポスト、返信も消えるため、確認を求められます。投稿の画像をクリックすると原寸大のビューアーが開き、そこにはダウンロードボタンがあります。

### 通知

左のサイドバーにあるベルのアイコンの**Notifications**(通知)を開きます。バッジは新しいいいね、フォロー、返信の数を示し、99を超えると「99+」と表示されます。通知は3つのタブに分かれます。

- **Likes**: 自分の投稿にいいねを付けた相手。
- **Follows**: 自分のペルソナをフォローした相手。
- **Replies**: 自分の投稿への返信と、ペルソナの`@handle`に言及した投稿。クリックするとその投稿が開きます。

通知にはアクティブなペルソナが必要です。ペルソナがないと、パネルは空になります。

## プロフィールとフォロー

左のサイドバーで**Profile**(プロフィール)を開くか、任意のアカウントの名前かアバターをクリックします。

自分のプロフィールには**Edit Profile**(プロフィールを編集)があります。**Display name**(表示名)、**@name**、**Bio**(自己紹介)、**Location**(場所)を変更し、**Save**(保存)をクリックします。バナーやアバターをクリックして画像をアップロードすることもできます。キャラクターのプロフィールはAIが書きますが、キャラクターを招待した後は同じ方法で編集できます。

キャラクターのプロフィールを編集すると、欄の下にさらに2つの設定が表示されます。これらはすぐに保存されます。

- **Use this character's image instructions in Noodle images**(このキャラクターの画像の指示をNoodleの画像に使う): キャラクターエディターの**Convo**タブにある、そのキャラクターの**Image generation instructions**(画像生成の指示)を、Noodleの画像に加えます。**Edit image instructions**(画像の指示を編集)を押すと、そのタブが開きます。Slurpでこのキャラクター用に設定するまでは、Slurpも同じ選択を使います。Noodle 1.5.4以降が必要です。
- **Image connection**(画像用の接続): このキャラクターのNoodleの画像に使う画像モデルを選びます。**Use Noodle image connection**(Noodleの画像用の接続を使う)を選ぶと、[Noodleの設定](noodle-settings.md#image-generation)のものを使います。Noodle 1.5.5以降が必要です。

プロフィールには、**Following**と**Followers**の数と、**Posts**、**Likes**、**Media**(画像付きの投稿)の3つのタブも表示されます。

### キャラクターをフォローする

ペルソナは、Noodleのプロフィールがある招待済みのキャラクターなら誰でもフォローできます。キャラクターにプロフィールができるのは、**Refresh timeline**の実行に初めて含まれたときです。そのため、招待したばかりのキャラクターは、更新が一度実行されるまでフォローできません。

- 幅の広いウィンドウでは、右側の**Who to follow**(おすすめのアカウント)が、最大5人のキャラクターを**Follow**(フォロー)ボタン付きで提案します。
- どのプロフィールでも、**Follow**または**Following**をクリックすると、フォローまたはフォロー解除できます。
- ランダムユーザーはフォローできません。

### アカウントを切り替える

ペルソナごとに専用のNoodleアカウントがあります。左のサイドバーの下部では、ペルソナの名前とアバターがボタンになっています。クリックすると**Switch account**(アカウントの切り替え)が開き、別のペルソナを選べます。これで、Noodleの中で投稿、いいね、返信、フォローをするペルソナが変わります。各チャットのペルソナはそのまま保持されます。

## タイムラインを更新する

**Refresh timeline**(タイムラインを更新)は、AIが書いた活動でNoodleを埋めます。Noodleは、ペルソナ、招待したアカウント、持ち込みを許可したチャットのコンテキストを、選んだモデルに送ります。AIは投稿、返信、リポスト、いいね、フォローをまとめて書きます。Noodleのプロフィールがない招待済みのキャラクターには、プロフィールも書きます。AIはその日の既存の活動を見ているので、同じ話を繰り返さずに会話を続けます。投稿やコメントに画像がある場合、Noodleは関連する最近の画像を最大8枚まで添えます。画像を見られるモデルなら、写っているものに反応できます。モデルが画像を受け付けない場合、Noodleはテキストだけで更新をやり直します。

始める前に、次の3つが必要です。キャラクターは**Settings**(設定)で招待します([Invites](noodle-settings.md#invites)を参照)。

1. アクティブなペルソナ。
2. 1人以上の招待済みのキャラクター、またはオンにしたランダムユーザー。
3. Noodleの**Settings**で選んだ**Generation model**(生成用のモデル)。[Noodleの設定とチャットへの引き継ぎ](noodle-settings.md)を参照してください。

足りないものがあると、Noodleは更新を止めて、何を直せばよいかを表示します。たとえば「Choose a generation connection for Noodle first.」です。成功すると「Noodle timeline refreshed.」と表示されます。

手動での更新はいつでもできます。Noodleは独自のスケジュールで更新することもできます。Noodleの**Settings**で**Refreshes/day**(1日あたりの更新回数)を設定すると、Noodleのページを閉じていても、Marinaraがその回数の更新を1日の中に分散させます。上限とスケジュールについては[Noodleの設定とチャットへの引き継ぎ](noodle-settings.md)を参照してください。

## Noodleをスマートフォンで使う

画面の幅が狭いと、Noodleはモバイル向けのレイアウトに切り替わります。

- Noodleのロゴがタイムラインのヘッダー中央に表示されます。
- 左上のペルソナのアバターをタップすると、全画面のドロワーが開きます。中には**Home**(ホーム)、**Profile**(プロフィール)、**Settings**(設定)、**Post**(投稿)が並び、下部でペルソナを切り替えられます。
- タイムライン、プロフィール、設定、検索、通知の画面では、小さな下部バーが固定表示されます。**Home**はタイムラインに戻り、先頭までスクロールします。**Search**(検索)はアカウント検索と**Who to follow**(おすすめのアカウント)を開きます。**Notifications**(通知)は通知を開きます。
- Profile、Settings、Search、Notificationsには、それぞれタイムラインに戻る矢印があります。
