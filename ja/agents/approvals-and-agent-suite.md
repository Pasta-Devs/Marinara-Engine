# エージェントの承認とAgent Suite

このガイドでは、チャット中にエージェント(返信の裏側で動く小さなAIのヘルパー)が書き込む内容を確認し、制御する方法を説明します。**Review Agent Outputs**(エージェント出力の確認)トグル、2種類の確認ウィンドウ、**Agent Suite**(エージェントスイート)エディター、**Cached prompt injections**(キャッシュされたプロンプト挿入)パネルを取り上げます。

## Review Agent Outputs

エージェントの中には、チャットに新しいデータを書き込もうとするものがあります。Lorebookエージェントはロアブックのエントリーを追加できますし、要約のエージェントはチャットの要約を保存できます。デフォルトでは、この種の書き込みの一部は自動的に保存されます。**Review Agent Outputs**をオンにすると、保存の前に1件ずつ内容を確認できます。

トグルの場所は次のとおりです。

1. 制御したいチャットを開きます。
2. **Chat Settings**(チャット設定)を開きます。
3. **Agents**(エージェント)セクションまでスクロールします。
4. **Review Agent Outputs**をオンにします。

**Review Agent Outputs**がオンのときは、ロアブックの更新、要約の更新、そのほか確認の対象になる書き込み系エージェントの出力が、保存される前に承認を待ちます。オフのときは、ロアブックと要約の更新が自動的に保存されることがあります。

キャラクターカードの編集だけは扱いが違います。**Review Agent Outputs**がオフでも、必ず承認を求めます。この安全確認はオフにできません。

## エージェントの書き込みを承認するウィンドウ

**Review Agent Outputs**がオンの状態でエージェントがロアブックまたは要約への書き込みを提案すると、確認用のウィンドウが開きます。タイトルは書き込みの種類に応じて**Review Lorebook Update**または**Review Summary Update**になります。

ウィンドウには次の内容が表示されます。

- 提案したエージェントの名前。
- 保存する前に編集できる**Proposed Text**(提案されたテキスト)欄。
- ロアブックへの書き込みの場合は、各エントリーを`###`見出しの下に置くようにという短い注意書き。

ウィンドウの下部では、3つの操作を選べます。

- **Accept**(承認): 編集した内容も含めて、そのテキストをチャットに保存します。
- **Regenerate**(再生成): そのエージェントだけをもう一度動かし、新しい提案を作ります。
- **Discard**(破棄): 提案を保存せずに捨てます。

提案が複数待っている場合は、残りの件数がウィンドウに表示されます。今の提案を処理すると、次の提案のためにウィンドウが開き直します。

## キャラクターカードの更新の確認

**Card Evolution Auditor**エージェントは、ロールプレイ中に起きたできごとをもとに、キャラクターカードの項目への編集を提案できます。Conversationモードに組み込みの`update_about_me`ツールも、公開されるAbout Meの変更を提案できます。どちらの経路もカードを勝手に書き換えることはなく、**Review Character Card Updates**ウィンドウを開いて判断を委ねます。

ウィンドウには提案された編集が一覧で並びます。編集ごとに次の情報を確認できます。

- 対象となるカードの項目(description、personality、appearanceなど)。
- エージェントが理由を付けている場合は、その短い説明。
- 現在のテキストを示す**Before**(変更前)ブロック。
- 新しいテキストを示す**After**(変更後)欄。承認する前にこのテキストを編集できます。

操作は次の3つです。

- **Approve**(適用): 編集を反映します。ボタンの中の数字は、反映される編集の件数です。適用するとキャラクターのバージョン番号が上がり、バージョン履歴のエントリーが保存されます。
- **Regenerate**: エージェントをもう一度動かし、提案をまとめて作り直します。
- **Reject**(却下): カードを変更せずに提案を取り下げます。

エージェントが提案を書いたあとでカードが変わっていることもあります。その場合、アプリはその編集を**stale**(古くなった状態)と表示して薄く灰色にします。古くなった編集が1件でもあると、件数の付いた**Override stale**(古い編集を強制的に適用)ボタンが現れます。それでもそのテキストを残したいときだけ使ってください。アプリはまず確認を求めます。そのうえで、一致しなくなった既存のテキストを置き換えるのではなく、古いテキストを項目に追加します。

## Agent Suiteエディターとその場でのAI書き換え

**Agent Suite**では、このチャットのエージェントが保存している内容をまとめて表示し、編集できます。対象になるのは、トラッカーのデータ(現在のシーン、その場にいるキャラクター、ペルソナの状態値など)と、カスタムエージェントの保存済み出力です。名前の誤り、状態値のずれ、乱れた保存テキストを、手作業でもAIの助けを借りても直せます。

開き方は次のとおりです。

1. **Chat Settings**を開きます。
2. **Agents**セクションまでスクロールします。
3. **Agent Suite**をクリックします。

左側には、このチャットで動いているエージェントの一覧が並びます。1つ選ぶと、そのエージェントが保存している内容を確認できます。右側には編集できるブロックが表示され、**Stored Memory**(保存された記憶)、**Tracker Data**(トラッカーのデータ、トラッカーのエージェントのみ)、**Recent Outputs**(最近の出力、カスタムエージェントのみ)に分かれます。データを追跡しないエージェントでは**Stored Memory**だけが表示されます。

各ブロックはテキストまたはJSONのエディターです。ブロックを変更したあとは、次のように操作します。

- 編集を残すには**Save**(保存)をクリックします。
- 保存していない変更を取り消して保存済みの値に戻すには**Reset**(リセット)をクリックします。

ブロックの書き換えをAIに任せることもできます。

1. 変更したいブロックで**AI Edit**(AIで編集)をクリックします。
2. テキストの一部だけを対象にしたい場合は、先にエディターでその部分を選択します。何も選択しないと、ブロック全体が書き換わります。
3. 指示を入力します。たとえば「文字化けしたキャラクター名を直して。彼女の名前はMiraです」のように書きます。
4. 任意: **Add Context**(コンテキストの追加)をクリックすると、キャラクターカードやロアブックのエントリーを添えられます。データの意味をAIが理解しやすくなります。
5. 書き換えを実行する接続(AIのプロバイダーとモデル)を選びます。
6. **Rewrite**(書き換え)をクリックします。

書き換えられたテキストは、保存されていない下書きとしてブロックに入ります。内容を確認したうえで、残すなら**Save**、捨てるなら**Reset**をクリックします。

いくつか補足があります。

- このチャットのエージェントがまだ動いている間は、保存が一時的に止まります。
- **Stored Memory**セクションには**Clear memory**(記憶の削除)ボタンが1つあります。エージェントが保存したデータがあるときだけ表示されます。そのエージェントがこのチャットで保存した内容をまとめて削除するもので、取り消せません。アプリはまず確認を求めます。
- **Narrative Director**では、保存されたネタバレが隠されています。**Reveal spoilers**(ネタバレの表示)を使うと、表示と編集ができます。

## Cached prompt injectionsパネル

返信が生成される前に、書き込み系のエージェントがプロンプトへテキストを追加することがあります。**Prose Guardian**、**Narrative Director**、独自に追加した挿入用のエージェントでよく起こります。**Cached prompt injections**パネルは、その追加されたテキストを調べるための画面です。Roleplayチャットの**Agent activity**(エージェントの動作)にある**Injections**タブから開けます。このタブは**Debug mode**がオンのときに表示されます。[エージェントの動作](../roleplay/getting-started.md#agent-activity)を参照してください。対象になるのは直近の返信です。

キャッシュされた挿入ごとに、次の操作ができます。

- 展開してテキストを読み、編集する。
- **Save**アイコンをクリックして編集を残す。
- **Re-run**(再実行)アイコンをクリックして、そのエージェントに挿入テキストを作り直させる。

**Knowledge Retrieval**と**Knowledge Router**の挿入は、このパネルからは再実行できません。編集と再実行が効くのは、同じ返信を再生成した場合だけです。再実行では、その時点での元のチャット履歴が使われ、それより新しいメッセージは使われません。
