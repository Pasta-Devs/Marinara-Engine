# ロアブックをキャラクターやペルソナに結び付ける

ロアブックをキャラクターやペルソナにリンクすると、必要なチャットで自動的に有効になります。ロアブックをキャラクターカードに埋め込んだり、1つのチャットでロアブックを管理したりすることもできます。ロアブックをはじめて使う場合は、[ロアブックの概要](overview.md)から読んでください。

## リンクか埋め込みか

| 項目 | リンク(割り当て) | 埋め込み |
| --- | --- | --- |
| 何が起きるか | キャラクターやペルソナが、ライブラリーにあるロアブックを参照します。 | ロアブックがキャラクターカードに書き込まれます。 |
| 有効になる場所 | そのキャラクターが参加するチャット、またはそのペルソナを使うチャット。 | 同じです。さらに、カードと一緒に持ち運ばれます。 |
| カードと一緒にエクスポートされる | いいえ | はい |
| 使える対象 | キャラクターとペルソナ | キャラクターのみ |

ふだんはリンクを使ってください。埋め込みは、ロアブックと一緒にカードを共有するつもりのときだけ使います。

## エディターのLorebookタブ

キャラクターエディターにもペルソナエディターにも、**Lorebook**(ロアブック)タブがあります。

1. キャラクターまたはペルソナを開いて編集します。
2. **Lorebook**タブをクリックします。**Lorebooks**セクションには、**New**(新規作成)と**Assign Lorebook**(ロアブックの割り当て)の2つのボタンがあります。

**New**は、このキャラクターまたはペルソナに最初からリンクされたロアブックを、カテゴリーを**Character**にした状態で作ります。**Assign Lorebook**は、手持ちのロアブックをリンクします。

## 既存のロアブックを割り当てる

始める前に: 選択画面に表示されるのは、**Category**(カテゴリー)が**Character**のロアブックだけです。ペルソナの場合も同じです。目的のロアブックが見当たらない場合は、そのロアブックを開き、**Overview**(概要)タブで**Category**を**Character**にしてから、もう一度試してください。

1. **Lorebook**タブで**Assign Lorebook**をクリックします。
2. 検索欄に名前の一部を入力します。
3. ロアブックをクリックします。チェックマークが付きます。
4. **Scope**(適用範囲)は、**All chats with**の後に名前が付いた選択肢のままにするか、変更します(下記を参照)。
5. **Assign**(割り当て)をクリックします。

これでロアブックが割り当て済みの一覧に表示されます。範囲を変えるにはその行の**Scope**ボタンを、リンクを解除するにはゴミ箱アイコンを使います。名前をクリックすると、ロアブックが開きます。

グローバルなロアブックを、さらにリンクすることはできません。[ロアブックの概要](overview.md)を参照してください。

### Scope

**Scope**(適用範囲)は、リンクしたロアブックをどのチャットで使えるかを決めます。対象になるのは、このキャラクターが参加しているチャットか、このペルソナを使っているチャットだけです。

| Scope | 結果 |
| --- | --- |
| **All chats with**(後ろに名前が付きます) | デフォルトです。該当するすべてのチャットで有効になります。 |
| **Disabled for all chats** | リンクは残りますが、ロアブックは有効になりません。一時的に止めたいときに使います。 |
| **Specific chats** | 一覧でチェックを入れたチャットだけで有効になります。保存するには、1つ以上チェックを入れる必要があります。 |

範囲を後から変えるには、行の**Scope**をクリックして設定を直し、もう一度**Assign**をクリックします。

## ロアブックをキャラクターカードに埋め込む

始める前に: 先にロアブックをキャラクターに割り当ててください(上記を参照)。

1. キャラクターを開き、**Lorebook**タブをクリックします。
2. ロアブックの行で**Embed into card**(カードに埋め込む)をクリックします。

行に**Embedded**バッジが表示され、これ以降はエントリーがカードと一緒にエクスポートされます。

カードが持てる埋め込みロアブックは1つです。すでに1つある場合は**Embed into card**が無効になり、ツールチップに、先にいまの埋め込みロアブックを削除するよう表示されます。

リンクしたロアブックを編集した後は、その行の**Refresh**(更新)をクリックすると、現在のエントリーから埋め込みのコピーが書き直されます。

### 埋め込んだロアブックの管理

カードに埋め込みロアブックがあると、割り当て済みの一覧の下に次の操作が表示されます。エントリーの一覧も読み取り専用で表示されます。

- **Import Embedded Lorebook**(埋め込みロアブックをインポート)は、カードのエントリーを、ライブラリーの通常のロアブックに変換し、そのキャラクターにリンクします。リンクされたコピーができた後は、ボタンの表示が**Reimport Embedded Lorebook**になります。
- **Edit Embedded Lorebook**(埋め込みロアブックを編集)は、リンクされたそのロアブックを開きます。編集内容はカードのコピーに反映されます。
- **Remove from card**(カードから削除)は、埋め込みのコピーを削除します。別にリンクしているロアブックはそのまま残ります。

ほかのツールからインポートしたカードには、埋め込みロアブックが付いていることがよくあります。**Import Embedded Lorebook**をクリックすると、編集できる形にできます。

## Chat SettingsのLorebooksセクション

チャットにはそれぞれ、ロアブック用の操作があります。

1. チャットを開きます。
2. **Chat Settings**(チャット設定)を開きます。
3. **Lorebooks**セクションを探します。バッジに、有効なロアブックの数が表示されます。

有効なロアブックには、有効になっている理由を示すバッジが付きます。

| バッジ | 意味 |
| --- | --- |
| **Chat** | このチャットに追加したロアブックです。 |
| **Global** | グローバルなロアブックです。 |
| **Character** | このチャットのキャラクターにリンクされています。 |
| **Persona** | このチャットのペルソナにリンクされています。 |

このチャットだけを対象に、有効なロアブックを変更できます。

- **Add Lorebook**(ロアブックの追加)は、このチャットにロアブックを追加します。追加したロアブックには**Chat**バッジが付きます。
- ゴミ箱アイコン(**Remove from chat**(チャットから削除))は、追加したロアブックを外します。
- 目を閉じたアイコン(**Disable in this chat**(このチャットで無効にする))は、自動で有効になったロアブックを、リンクを解除せずにこのチャットで隠します。隠したロアブックは、名前に取り消し線が引かれ、**Disabled**バッジが付きます。
- 目のアイコン(**Enable in this chat**(このチャットで有効にする))で、再び有効になります。

### Lorebook Token Budget

**Lorebook Token Budget**(ロアブックのトークン予算)は、このチャットで追加できるロアブックの文章のトークン数に上限を設けます。デフォルトは8192で、0にすると上限はなくなります。この上限は、各ロアブック自身の**Token Budget**(トークン予算)に加えて適用されます。[ロアブックのトークン予算と再帰](token-budgets.md)を参照してください。
