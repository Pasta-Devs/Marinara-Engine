# ロアブックのインポートとエクスポート

ロアブックをインポートすると、ファイルから世界についての事実を取り込めます。エクスポートすると、ロアブックを共有したりバックアップしたりできます。このガイドでは、1つのファイル、複数のファイルの一括処理、4種類のエクスポート形式を取り上げます。ロアブックとは、キーワードで発動するメモをまとめたもので、一致する語が出てきたときにMarinaraがプロンプトに追加します。ほかのツールでは、この機能をWorld Infoと呼びます。

## インポートできるもの

ファイルの種類はMarinaraが自動で判別します。どちらの種類も`.json`ファイルで、アカウントもAPIキーも必要ありません。

- Marinaraからエクスポートしたロアブック。すべての項目とすべてのフォルダーがそのまま残ります。
- ほかのツールのWorld Infoファイル。SillyTavernのWorld InfoやV2キャラクターカードの「character-book」形式などです。Marinaraがその項目を自分の項目に対応付けます。

## ロアブックのインポート

1. **Lorebooks**(ロアブック)パネルを開きます。
2. 上部の列にある下向き矢印のアイコンをクリックします。3つのアイコンの真ん中です。ツールチップは**Import**(インポート)です。プラスのアイコンは**New**(新規)、チェックマークのアイコンは**Select**(選択)です。
3. **Import Lorebook**(ロアブックのインポート)ウィンドウで、**Drop one or more lorebook files here or click to browse**と書かれた枠をタップまたはクリックし、`.json`ファイルを選びます。コンピューターでは、ファイルを枠にドロップすることもできます。複数をまとめて選べ、MarinaraのファイルとWorld Infoファイルを混ぜてもかまいません。
4. 結果が出るまで待ちます。ファイルごとに、緑のチェックと**Imported lorebook**、または赤い印とエラーが表示されます。複数のファイルの場合は、成功した数と失敗した数をまとめた行が表示されます。
5. **Close**(閉じる)をクリックします。新しいロアブックが**Lorebooks**パネルに並びます。

Marinaraは、ファイル自体の日付を作成日としてそのまま使います。

うまくいかなかった場合: ファイルの横に表示されたエラーを読んでください。ロアブックではないファイルや壊れたファイルは、そのファイルだけが失敗し、ほかのファイルはインポートされます。

## インポートしたあとに

インポートしたロアブックは、キーワードならすぐに使えます。セマンティック検索を使う場合は、ベクトルを作り直してください。[ロアブックのセマンティック検索](semantic-search.md)を参照してください。

## ロアブックのエクスポート

1. **Lorebooks**パネルでロアブックをクリックして開きます。
2. エディターのヘッダーの右上付近にあるエクスポートのアイコンをクリックします。ツールチップは**Export lorebook**(ロアブックのエクスポート)です。
3. **Export Lorebook**ウィンドウで形式を選びます。ブラウザーがファイルをダウンロードします。

| 形式 | 得られるもの | 用途 |
| --- | --- | --- |
| **Marinara Native** | エントリーのすべての項目とフォルダー。ファイル名は`.marinara.json`で終わります。 | ロアブックを別のMarinaraのインストールへ移すとき。 |
| **Compatible JSON** | フォルダーのないWorld Infoファイルで、ファイル名は`.json`で終わります。Marinara独自の情報の一部は失われます。 | ほかのロールプレイツール。 |
| **Markdown** | エントリーごとに`## Name`見出しが1つと、`Keys:`の行。 | テキストエディターでの閲覧と編集。 |
| **CSV** | name、keys、content、folder、enabled、constant、probabilityの列を持つ表計算用のファイル。 | 表計算ソフトでの多数のエントリーの編集。 |

## 複数のロアブックをまとめてエクスポート

1. **Lorebooks**パネルで、チェックマークのアイコン(**Select**)をクリックします。
2. エクスポートしたいロアブックにそれぞれチェックを入れます。
3. 下部のバーにある**Export**(エクスポート)をクリックします。

ブラウザーが`marinara-lorebooks.zip`をダウンロードします。一括エクスポートは常に**Marinara Native**を使うので、インポートし直せばすべてが元どおりに戻ります。

## MarkdownやCSVからエントリーをインポートする

MarkdownやCSVのテキストファイルから、ロアブックにエントリーを追加できます。たとえば、エクスポートした後に編集したファイルを使えます。

1. ロアブックを開き、エディターのヘッダーにある**Import entries from Markdown or CSV**(MarkdownまたはCSVからエントリーをインポート)をクリックします。
2. **Import entries**(エントリーのインポート)ウィンドウで**Choose file**(ファイルを選択)をクリックするか、テキストを欄に貼り付けます。
3. **Format**(形式)を確認します。Marinaraがテキストから推測します。
4. プレビューを読みます。Markdownでは、エントリーごとに`## Name`見出しを1つ置き、必要なら`Keys: a, b`の行を続け、その後に本文を書きます。CSVでは、name、keys、contentを含む見出し行を使います。folder、enabled、constant、probabilityの列は任意です。プレビューには、取り込める状態のエントリー数と、行ごとのエラーと警告が表示されます。
5. **Import into**(インポート先)で、**This lorebook**(このロアブック)か**New lorebook**(新しいロアブック)を選びます。新しいロアブックの場合は、**New lorebook name**(新しいロアブックの名前)に名前を入力します。
6. **When an entry name already exists**(同じ名前のエントリーがすでにある場合)で、**Skip the imported entry**(インポートするエントリーを飛ばす)、**Import as a renamed copy**(名前を変えたコピーとしてインポート)、**Overwrite the existing entry**(既存のエントリーを上書き)のいずれかを選びます。
7. エントリー数が表示された**Import**ボタンをクリックします。

追加、上書き、スキップされたエントリーの数が、トーストで通知されます。

うまくいかなかった場合: 必須の列がないなど、ファイル全体に関わるエラーがあるときや、有効なエントリーが1つもないときは、ボタンを押せないままです。プレビューに示された行を直してください。
