# 画像と動画のPrompt Overrides

このガイドでは**Prompt Overrides**(プロンプトの上書き)を説明します。画像生成と動画生成のプロンプトを組み立てるためにMarinara Engineが使うテンプレートを、専用のエディターで書き換える機能です。エディターの場所、編集できる内容、独自のテンプレートを安全に保存する手順を取り上げます。

## Prompt Overridesとは

**Prompt Override**とは、メディア用プロンプトのテンプレートです。Marinaraは画像や動画を生成するとき、まず画像モデルや動画モデルに渡す文章のプロンプトを組み立てます。Prompt Overridesでは、そのテンプレートを編集できます。

この機能が扱うのは画像と動画のプロンプトだけです。チャットやロールプレイの最中にチャットモデルへ送られるプロンプトは変わりません。ここはよく誤解される点です。チャットモデルに送るプロンプトを変えたいときは、プロンプトプリセットと生成パラメーターを使います。[Preset Editorとプロンプトの管理](presets.md)と[生成パラメーター](generation-parameters.md)を参照してください。

以降で使う用語は次のとおりです。

- **スプライト**は、表情やポーズなど、画面に立つキャラクターの立ち絵です。
- **絵コンテ**は、Game Modeの1ターン、または完了したRoleplayのエピソードから生成される連続した挿絵です。

## エディターの場所

エディターはアプリの設定画面にあります。

1. **Settings**(設定)を開きます。
2. **Generations**(生成)タブをクリックします。
3. 画面をスクロールして、「Reusable image and video prompt templates.」と説明された**Prompt Overrides**の領域を表示します。

ここに折りたたみ式のエディターが2つあります。

## 2つのエディター

エディターのタイトルをクリックすると展開します。

**Video Generation Prompt Overrides**は、動画向けのテンプレートを編集します。対象はGameとGalleryのシーン動画、Conversationの動画メッセージ、Conversationの通話中に流れるキャラクターのクリップ、動く表情のポートレートです。動画プロンプトのテンプレートは、それぞれの種類のクリップを動画モデルにどう説明するかを決めます。

**Image Generation Prompt Overrides**は、画像、スプライト、Game、プロンプト組み立ての各機能が使うテンプレートを編集します。対象はConversationの自撮り写真、GameのNPCポートレート、シーンのイラスト、絵コンテのプロンプト、Noodleの投稿に使う**Noodle Post Image**テンプレート、そのほか登録済みの画像ビルダーです。画像プロンプトのテンプレートは、それぞれの種類の絵を画像モデルにどう説明するかを決めます。

つまりこの2つのエディターで、ポートレート、自撮り写真、スプライト、シーンのイラスト、絵コンテ、動画クリップのプロンプトを調整できます。

## テンプレートの編集

どちらのエディターも操作は同じです。次の手順で編集します。

1. 編集したいエディターを開きます。
2. **Registered prompt**(登録済みプロンプト)ドロップダウンからテンプレートを選びます。一覧の中身は開いたエディターによって変わります。
3. ドロップダウンの横にあるステータス表示を確認します。独自のテンプレートを保存していないときは**Default**です。保存したテンプレートが使われているときは**Custom active**、保存済みでもオフにしているときは**Custom paused**になります。
4. ドロップダウンの下にある短い説明を読み、そのテンプレートの役割を確かめます。
5. **Available variables**(使用できる変数)の変数チップをクリックすると、テンプレートに変数を挿入できます。変数は`${charName}`のように`${name}`の形で書きます。
6. **Template**(テンプレート)欄の文章を編集します。
7. その下の**Rendered preview**(表示プレビュー)欄を確認します。プレビューではテンプレートにサンプルの値が入るので、仕上がりを確認できます。
8. プレビューに**Unknown variables**の警告が出たら、綴りの誤った変数を直します。**Available variables**の一覧にない変数名は値が入りません。
9. **Save**(保存)をクリックします。

「Prompt override saved」というメッセージが表示され、ステータス表示が**Custom active**に変われば成功です。

## 保存したまま使わずにおく

プレビューの下に**Apply this override**(この上書きを適用)トグルがあります。ヘルプには「Turn this off to keep the template saved without using it.」と書かれています。これをオフにすると、書きかけのテンプレートを保存しておきながら、機能自体は組み込みのデフォルトを使い続けます。このときステータス表示は**Custom paused**になります。

## 組み込みのテンプレートに戻す

**Reset to Default**(デフォルトに戻す)をクリックすると、独自のテンプレートを破棄して組み込みのテンプレートに戻ります。保存済みの上書きがある場合は、実行前に確認を求められます。ステータス表示は**Default**に戻ります。

## 上書きが効く場面

Prompt Overrideが影響するのは、実際に画像や動画を生成する機能だけです。Gameのアセット、Conversationの自撮り写真や通話、スプライト、Noodleの投稿画像などが該当します。これらの機能を使うには、画像生成または動画生成の接続をあらかじめ用意しておく必要があります。生成用の接続が動いていなければ何も実行されず、テンプレートも使われません。[画像生成プロバイダーと設定](../media/image-providers.md)と[シーン動画の生成](../media/scene-video.md)を参照してください。
