# Preset Editorとプロンプトの管理

このガイドではMarinara Engineのプロンプトプリセットを説明します。プリセットとは何か、**Preset Editor**(プリセットエディター)での組み立て方、チャットへの割り当て方がわかります。プリセットは、MarinaraがAIに送る文章の構造を決めるものです。

## プリセットとは

プリセットは、繰り返し使える設計図です。MarinaraがAIへ何を、どの順番で送るかをプリセットが決めます。対象になるのは、自分で書いたシステム指示、キャラクターカード、ペルソナ、チャット履歴、ロアブックのエントリーなどです。

プリセットがプロンプトを形づくるのは、**Roleplay**チャットと**Game**チャットです。**Conversation**モードは仕組みが違い、1つのプロンプト欄だけを使います。下記の「ConversationモードとGame Modeの違い」を参照してください。

プリセットの作成にAPIキーやアカウントは要りません。プロンプトの組み立て方を書き表すだけだからです。プロンプトを実際に送るには、動作する接続が別に必要です。[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。

## Preset Editorを開く

プロンプトプリセットは、アプリ左側の**Presets**(プリセット)パネルにある**Prompts**セクションに置かれています。このパネルの残りのセクションは**Regexes**と**Functions**です。

パネルの上部には3つのボタンがあります。

- **New**(新規作成、プラスのアイコン): プリセットを新しく作ります。
- **Import**(インポート、下向き矢印のアイコン): `.json`ファイルからプリセットを読み込みます。
- **Select**(選択、チェックのアイコン): 複数のプリセットをまとめてエクスポートまたは削除します。

ボタンの下には**Search presets**欄と、**A-Z**、**Z-A**、**Newest**、**Oldest**を選べる並べ替えメニューがあります。**New Folder**(新しいフォルダー)ボタンを使うと、プリセットをフォルダーにまとめられます。プリセットをフォルダーにドラッグすると移動します。フォルダーの名前は、ダブルクリックまたはダブルタップで変更できます。

各プリセットの行には、名前、囲み形式、セクション数、作成者が並びます。スターを付けてデフォルトにしてあるプリセットには**DEFAULT**バッジが付きます。行をクリックすると、そのプリセットが**Preset Editor**で開きます。

## プリセットの作成と編集

新しいプリセットは次の手順で作ります。

1. **Presets**パネルを開きます。
2. **New**ボタンをクリックします。**Create Preset**ウィンドウが開きます。
3. **Name**(名前)を入力します。この欄は必須です。
4. 必要に応じて**Description**(説明)を書き、何のためのプリセットかがわかるようにします。
5. **Create**(作成)をクリックします。新しいプリセットが**Preset Editor**で開きます。
6. **Sections**(セクション)タブでプロンプトを組み立てます(下記で説明します)。
7. 作業が終わったら、右上の**Save**(保存)をクリックします。

エディターは自動では保存しません。変更が残るのは**Save**をクリックした後だけです。保存していない状態で離れようとすると、**Keep editing**、**Discard**、**Save & close**の3つのボタンが付いた警告が表示されます。

プリセットをエクスポートするには、そのプリセットを開き、上部バーのエクスポートボタン(上向き矢印のアイコン)をクリックします。保存していない編集があるときは、Marinaraが先に保存するか確認します。プリセットを削除するには、上部バーのゴミ箱のアイコンを使います。

## Overview、Sections、Promptsの3つのタブ

**Preset Editor**には3つのタブがあります。

- **Overview**(概要): プリセットの名前、説明、囲み形式、作成者。
- **Sections**: ブロックとマーカーで組み立てる、プロンプトそのものの構造。
- **Prompts**: ConversationチャットとGameチャットで使うモードごとのプロンプト。

### Overviewタブ

**Overview**タブには4つの欄があります。**Name**は**Presets**パネルに表示される名前です。**Description**はプリセットの短い説明です。**Wrap Format**(囲み形式)は各セクションの整形方法を決めます(「囲み形式」を参照)。**Author**(作成者)は任意で入れる制作者名で、プリセットを配布するときに役立ちます。読み取り専用のカードが2つあり、**Sections**と**Groups**の数を表示します。

### Promptsタブ

**Prompts**タブには、モードごとのプロンプトが並びます。

- **Conversation Mode**: このプリセットのConversationプロンプトとして使うテキスト欄です。空のままにすると、Marinara内蔵のConversationプロンプトを使います。
- **Roleplay Mode**: ここでは編集できません。Roleplayは**Sections**から組み立てたプロンプトを使います。
- **Game Mode**: このプリセットのGameプロンプトとして使うテキスト欄です。空のままにすると、Marinara内蔵のGameプロンプトを使います。

## セクションとマーカー

プロンプトを組み立てる場所が**Sections**タブです。すべてのセクションが、AIに送られる最終的な文章の一部になります。セクションは上から下へ順に連結されます。

**Add Section**(セクションの追加)をクリックすると追加メニューが開きます。追加できるセクションは2種類です。

**Prompt Block**は、自分で文章を書く自由入力のセクションです。システム指示、口調のルール、毎回のプロンプトに必ず入れたい文言などに使います。

**マーカー**は、自動で中身が入るセクションです。それ自体は文章を持ちません。送信時にMarinaraが、チャットの最新の内容を入れて埋めます。マーカーの一覧は次の表のとおりです。

| マーカー | 挿入される内容 |
|---|---|
| **Character Info** | 使用中のキャラクターカードの内容。 |
| **Persona** | 使用中のペルソナの内容。 |
| **Chat History** | 進行中のチャットのメッセージ。 |
| **Chat Summary** | このチャット向けにまとめた要約。 |
| **Dialogue Examples** | キャラクターの会話例。 |
| **Lorebook Marker (All)** | 有効なロアブックのエントリーすべて。 |
| **Lorebook Marker (Before)** | 前に挿入する設定のロアブックのエントリー。 |
| **Lorebook Marker (After)** | 後ろに挿入する設定のロアブックのエントリー。 |

マーカーのセクションは、行に**MARKER**バッジが付きます。展開すると、マーカーの種類を示す注記が読めます。ほとんどのマーカーには文章を書き込めません。Marinaraが中身を生成するためです。

有効な**Dialogue Examples**マーカーがないプリセットでは、中身のあるExample Dialogueが**Character Info**のScenarioの後ろに追加されます。整形にはプリセットのXML、Markdown、または囲みなしの設定が使われます。配置を自分で決めたいときは、Dialogue Examplesマーカーを追加してください。Marinaraが同じ内容を二重に入れることはありません。

チャットで有効なロアブックがあるのに、プリセットにロアブックのマーカーがない場合は警告が出ます。文面は「Add a lorebook marker when this preset should receive active lorebook entries.」です。エントリーがAIに届くよう、ロアブックのマーカーを追加してください。[ロアブックの概要](../lorebooks/overview.md)を参照してください。

カスタムのエージェントを作り、「inject as section」のオプションをオンにしてある場合は、追加メニューに**Agent Sections**グループが現れます。エージェントのセクションは、そのエージェントの最新の出力をプロンプトに挿入します。その前後に自分の指示を書き足すこともできます。

各セクションの行には、右側に操作ボタンが並びます。**Duplicate**(複製)はセクションを複製します。目のアイコンはセクションの有効と無効を切り替えます。**Delete**(削除)はセクションを消します。並べ替えるには、ハンドルをドラッグするか、上下の矢印を使うか、タッチ画面では長押しします。

セクションを展開すると(名前かシェブロンをクリックします)編集できます。**Name**と役割(**System**、**User**、**Assistant**)を変更できます。**Prompt Block**なら**Content**(内容)も編集できます。内容の入力欄ではマクロを使えます。[プロンプトマクロ](macros.md)を参照してください。

## グループとセクションの位置

### グループ

グループは、複数のセクションを1つの入れ物にまとめます。関連するセクションを、最終的なプロンプトでも隣り合わせに保てます。

1. **Sections**タブでツールバーの**Groups**ボタンをクリックします。
2. **New Group**をクリックします。「New Group」という名前のグループができます。
3. グループ名をクリックすると名前を変更できます。
4. セクションを展開し、**Group**ドロップダウンでグループを選びます。

囲み形式が**XML**のときは、グループが配下のセクション全体を囲む親タグになります。**Markdown**のときは、グループが1つの見出しになります。グループを削除しても、中のセクションは消えません。グループから外れるだけです。

### 位置と深さ

セクションを展開した編集画面には、それぞれ**Position**(位置)の設定があります。

- **Ordered (in sequence)**: リストに並んでいるとおりの場所に入ります。通常はこちらを選びます。
- **Depth (from end of chat)**: チャットの末尾から数えた指定のメッセージ数だけ手前に入ります。これを選ぶと**Depth**(深さ)の数値欄が現れます。深さ0は、最後のメッセージの後ろに入るという意味です。

最新のメッセージのそばでAIに読ませたい念押し、たとえば短い文体の注意書きには**Depth**が向いています。

## 囲み形式

**Overview**タブの**Wrap Format**は、プロンプトを組み立てるときに各セクションをどう囲むかを決めます。ボタンは3つです。

- **XML**: 各セクションをタグで囲みます。たとえば、内容を名前のタグで包みます。グループは親タグになります。これがデフォルトです。
- **MARKDOWN**: 各セクションを見出しで囲みます。グループは上位の見出しになります。
- **NONE**: 何も付け足しません。セクションの内容がそのまま送られます。

たいていのモデルではXMLが無難なデフォルトです。タグがないほうがモデルの反応が良さそうなときだけ、**MARKDOWN**や**NONE**を試してください。

## プリセットをチャットに割り当てる

プリセットは、チャットに割り当てるまで何もしません。**Roleplay**チャットでの割り当て方は2とおりあります。

**Presets**パネルから割り当てる場合:

1. 変更したいチャットを開きます。
2. **Presets**パネルでプリセットの行にカーソルを合わせます。
3. チェックマークの**Assign to chat**ボタンをクリックします。もう一度クリックすると割り当てを外せます。

**Chat Settings**から割り当てる場合:

1. チャットを開きます。
2. **Chat Settings**(チャット設定、歯車のアイコン)を開きます。
3. **Prompt Preset**セクションを探します。
4. ドロップダウンからプリセットを選びます。

変数を持つプリセットを割り当てると、**Configure Preset Variables**ウィンドウが開きます。そこで選択内容を入力します。[プリセット変数](preset-variables.md)を参照してください。別のプリセットに切り替えると、それまでに決めた変数の選択は消えます。

**Conversation**モードでは、パネルからプロンプトプリセットを割り当てられません。Conversationチャットで割り当てのボタンをクリックすると、「Prompt presets are not available in conversation mode.」というメッセージが出ます。ConversationチャットとGameチャットがプリセットをどう使うかは、次のセクションを参照してください。

## ConversationモードとGame Modeの違い

**Conversation**チャットと**Game**チャットは、Sectionsからプロンプトを組み立てません。モードごとのプロンプトを1つ使い、チャットごとに上書きできます。

これらのモードでは、**Chat Settings**の**Prompt Preset**セクションに**Prompt source**ドロップダウンが表示されます。ドロップダウンには手持ちのプリセットが並びます。デフォルトは「Default conversation prompt」または「Default game prompt」です。プリセットが1つもない場合は「No presets available」と表示されます。

ドロップダウンの下には状態の行があり、次の3つのうちいずれかを示します。

- **Default**: 内蔵のモードプロンプトを使っています。
- **Preset**: 選んだプリセットのプロンプトを使っています。
- **Custom**: このチャットだけの編集を書き込んでいます。

**Edit Prompt**をクリックすると、そのチャット専用のプロンプトを書けます。エディターは**Edit Conversation Prompt**または**Edit Game Prompt**として開きます。編集内容がプリセットやデフォルトと完全に一致する場合、Marinaraはカスタムではないものとして扱います。カスタムの編集が保存されると、それを消すための**Reset to default prompt**ボタンが現れます。

Gameチャットには**Extra instructions**欄もあります。ここに書いた文章はGameプロンプトに追加されます。上限は2000文字です。記入例は「Write in the style of Terry Pratchett.」です。

## 判定ブロックとプロンプトキャッシュ

セクションに`{{#if decision:"..."}}`判定ブロックを含めると、チャットについての文が真になったターンだけ、プリセットのその部分を送信できます。[Decisionモデルへの問い合わせ](conditional-prompts.md#asking-the-decision-model)を参照してください。

**変わりやすい判定ブロックはプロンプトの後方に置いてください。** たとえば履歴後の指示です。分岐が変わると、プロバイダーがその地点以降のプロンプトを再利用できなくなり、前方の変更ではキャッシュによる節約の大部分を失うことがあります。それより前の変わらない接頭部分は対象になる場合があり、必ずしも全体が新規として課金されるわけではありません。答えがほとんど変わらず、その指示を先頭に置く必要がある場合だけ、前方に残してください。プロバイダー別の詳細は[プロンプトキャッシュ](conditional-prompts.md#prompt-caching)を参照してください。

無効なセクションやグループの判定文は問い合わせず、**Decision statements per turn**(1ターンあたりの判定文数)にも数えません。

## AIに何が届いたかを確認する

どのプリセットとセクションが実際にAIへ届いたかを確かめるには、**Peek Prompt**を使います。あるメッセージについて、組み立て終わったプロンプト全体を表示します。おかしな返信の原因を調べるいちばんの近道です。[Peek Prompt: AIが受け取った内容を確認する](../chats/peek-prompt.md)を参照してください。
