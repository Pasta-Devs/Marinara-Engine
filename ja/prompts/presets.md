# Preset Editorとプロンプトの管理

プリセットとは、プロンプト(返信のたびにMarinaraがモデルに送るテキスト)の設計図を保存したものです。何をどの順番で入れるかを決めます。対象は、自分で書いた指示、キャラクターカード、ペルソナ、チャット履歴、ロアブックのエントリーなどです。**Preset Editor**(プリセットエディター)でプリセットを組み立て、チャットに割り当ててください。

プリセットがプロンプトを組み立てるのは**Roleplay**チャットです。**Conversation**チャットと**Game**チャットは、代わりに1つのプロンプト欄を使います([ConversationチャットとGameチャット](#conversation-and-game-chats)を参照)。プリセットにAPIキーは要りませんが、プロンプトを送るには動作するアカウントが必要です。[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。

## プリセットをチャットに割り当てる

プリセットは、チャットで使われるまで何もしません。**Roleplay**チャットでは、次のどちらの方法でも割り当てられます。使いたいプリセットを選ぶには、割り当ててください。自分で作るには、[プリセットを作る](#create-a-preset)を参照してください。

**Presets**(プリセット)パネルから割り当てる場合:

1. チャットを開きます。
2. **Presets**パネルでプリセットの行を探します。コンピューターでは、行にカーソルを合わせるとボタンが表示されます。
3. チェックマークの**Assign to chat**(チャットに割り当て)ボタンをクリックします。チェックマークは、そのプリセットが使用中であることを示します。もう一度クリックすると割り当てを外せます。

**Chat Settings**(チャット設定)から割り当てる場合:

1. チャットを開き、**Chat Settings**を開きます。
2. **Prompt Preset**(プロンプトプリセット)を探し、ドロップダウンからプリセットを選びます。

プリセットに変数がある場合は、**Configure Preset Variables**(プリセット変数の設定)ウィンドウが開きます。[プリセット変数](preset-variables.md)を参照してください。プリセットを切り替えると、それまでの変数の選択は消えます。

<a id="create-a-preset"></a>

## プリセットを作る

1. サイドバーから**Presets**パネルを開きます。
2. **New**(新規作成、プラスのアイコン)をクリックします。**Create Preset**ウィンドウが開きます。
3. **Name**(名前)を入力します。この欄は必須です。必要なら**Description**(説明)も追加します。
4. **Create**(作成)をクリックします。プリセットが**Preset Editor**で開きます。
5. **Sections**(セクション)タブでプロンプトを組み立てます。
6. 右上の**Save**(保存)をクリックします。

エディターは自動では保存しません。変更するたびに**Save**をクリックしてください。保存していない編集があるまま離れようとすると、警告に**Keep editing**、**Discard**、**Save & close**が表示されます。

プリセットをエクスポートするには、上部バーの上向き矢印のアイコン(ツールチップは**Export preset**)をクリックします。保存していない編集があるときは、Marinaraが先に保存するよう求めます。削除するには、ゴミ箱のアイコンをクリックします。

## Presetsパネル

プリセットが置かれているのは**Prompts**セクションです。ほかのセクションは**Regexes**と**Functions**です。上部のボタンは**New**、**Import**(`.json`ファイルを読み込みます)、**Select**(複数をまとめてエクスポートまたは削除します)です。

- **Search presets**(プリセットを検索)は一覧を絞り込みます。
- 並べ替えメニューには、**Manual order**(手動の順番)、**A-Z**、**Z-A**、**Newest**、**Oldest**があります。**Manual order**では、行をドラッグするか、行にフォーカスを合わせて<kbd>Alt</kbd>+<kbd>Up</kbd>または<kbd>Alt</kbd>+<kbd>Down</kbd>を押します。タッチスクリーンでは、行を長押しして持ち上げます。
- **New Folder**(新しいフォルダー)でプリセットをまとめられます。プリセットをフォルダーにドラッグして入れ、フォルダーの名前はダブルクリックまたはダブルタップで変更します。

各行には、名前、囲み形式、セクション数、作成者が表示されます。スターを付けたデフォルトのプリセットには**DEFAULT**バッジが付きます。行をクリックすると開きます。

## Preset Editorのタブ

| タブ | 内容 |
| --- | --- |
| **Overview**(概要) | 名前、説明、囲み形式、作成者。 |
| **Sections** | ブロックとマーカーで組み立てる、プロンプトの構造。 |
| **Prompts** | ConversationチャットとGameチャットで使う、モードごとのプロンプト。 |
| **Parameters**(パラメーター) | 生成設定の初期値。[生成パラメーター](generation-parameters.md)を参照してください。 |
| **Regex**(正規表現) | このプリセットにリンクした正規表現スクリプトと、**Scoped regex default**(範囲限定の正規表現のデフォルト)。[正規表現スクリプト](../extending/regex-scripts.md)を参照してください。 |

### Overviewタブ

- **Name**は、**Presets**パネルに表示される名前です。
- **Description**は短い説明です。
- **Wrap Format**(囲み形式)は、セクションの整形方法を決めます([囲み形式](#wrap-formats)を参照)。
- **Author**(作成者)は任意で入れる制作者名で、プリセットを配布するときに役立ちます。

読み取り専用のカードが2つあり、**Sections**と**Groups**の数を表示します。

### Promptsタブ

- **Conversation Mode**は、このプリセットのConversationプロンプトを入れるテキスト欄です。空のままにすると、内蔵のプロンプトを使います。
- **Roleplay Mode**はここでは編集できません。Roleplayは、**Sections**から組み立てたプロンプトを使います。
- **Game Mode**は、このプリセットのGameプロンプトを入れるテキスト欄です。空のままにすると、内蔵のプロンプトを使います。

組み込みの**Marinara's Universal Preset**(Marinaraの汎用プリセット)は、プロンプトの文章を提供しますが、生成パラメーターは指定しません。このプリセットに以前保存されたサンプリング、推論、書式、トークンの設定は無視され、代わりにアカウントの設定、チャットの上書き、アプリのデフォルトが適用されます。カスタマイズするには、編集できるコピーを作ってください。

## セクションとマーカー

プロンプトを組み立てる場所が**Sections**タブです。セクションは上から下へ順に組み立てられます。

1. **Add Section**(セクションの追加)をクリックします。
2. **Prompt Block**かマーカーを選びます。

**Prompt Block**は自分で書くテキストです。システム指示、口調のルールなど、毎回のプロンプトに入れたいものなら何でも書けます。マーカーは、それ自体の文章を持ちません。プロンプトを送るときに、Marinaraがチャットの最新の内容で埋めます。

| マーカー | 挿入される内容 |
| --- | --- |
| **Character Info** | 使用中のキャラクターカードの内容。 |
| **Persona** | 使用中のペルソナの内容。 |
| **Chat History** | チャットのメッセージ。 |
| **Chat Summary** | まとめたチャットの要約。 |
| **Dialogue Examples** | キャラクターの会話例。 |
| **Lorebook Marker (All)** | 有効なロアブックのエントリーすべて。 |
| **Lorebook Marker (Before)** | 前に入れる設定のロアブックのエントリー。 |
| **Lorebook Marker (After)** | 後ろに入れる設定のロアブックのエントリー。 |

マーカーの行には**MARKER**バッジが付きます。ほとんどのマーカーには文章を書き込めません。ロアブックのエントリーを前と後ろに分けたいのでなければ、**Lorebook Marker (All)**を使ってください。

使う機会の少ないマーカーが3つあります。

- **Current Scene Summary**(現在のシーンの要約)と**Recalled Scenes**(呼び出したシーン)は、Advanced Memory Recallが作る要約を配置します。**Recalled Scenes**マーカーがない場合、要約はチャット履歴の前に入ります。[記憶](../agents/memory.md)を参照してください。
- **ID Macro Cards**(IDマクロのカード)は、キャラクターのカードIDを二重の波かっこで囲んで入力し、プロンプトに取り込んだキャラクターカードを配置します。このマーカーがない場合、カードはデフォルトの場所に入ります。[プロンプトマクロ](macros.md)を参照してください。

有効な**Dialogue Examples**マーカーがない場合、中身のある会話例は、**Character Info**のシナリオの後ろに、プリセットの囲み形式で追加されます。配置を自分で決めたいときは、このマーカーを追加してください。Marinaraが同じ内容を二重に入れることはありません。

チャットで有効なロアブックがあるのに、プリセットにロアブックのマーカーがない場合は、「Add a lorebook marker when this preset should receive active lorebook entries.」という警告が表示されます。エントリーがモデルに届くよう、マーカーを追加してください。[ロアブックの概要](../lorebooks/overview.md)を参照してください。

「inject as section」をオンにしたカスタムエージェントがある場合は、追加メニューに**Agent Sections**(エージェントのセクション)が表示されます。それぞれがそのエージェントの最新の出力を挿入し、その前後に自分の指示を書き足すこともできます。

### セクションを編集する

1. セクションの名前か矢印をクリックして展開します。
2. **Name**か役割(**System**、**User**、**Assistant**)を変更します。
3. **Prompt Block**なら**Content**(内容)を編集します。[マクロ](macros.md)を使えます。
4. 右上の**Save**をクリックします。

行の操作:

- **Duplicate**(複製)はセクションを複製します。
- 目のアイコンは、セクションのオンとオフを切り替えます。
- **Delete**(削除)はセクションを削除します。
- 並べ替えるには、ハンドルをドラッグするか、上下の矢印を使うか、タッチスクリーンでは長押しします。

### グループ

グループは、複数のセクションを1つの入れ物にまとめます。

1. **Sections**タブで**Groups**をクリックし、**New Group**(新しいグループ)をクリックします。
2. グループ名をクリックすると、名前を変更できます。
3. セクションを展開し、**Group**ドロップダウンでグループを選びます。

**XML**では、グループが1つの親タグになります。**MARKDOWN**では、1つの見出しになります。グループを削除しても、中のセクションは消えません。グループから外れるだけです。

### 位置と深さ

各セクションの編集画面には**Position**(位置)があります。

- **Ordered (in sequence)**は、リストに並んでいるとおりの場所にセクションを入れます。通常はこちらを選びます。
- **Depth (from end of chat)**は、**Depth**(深さ)の数値を使い、チャットの末尾から指定のメッセージ数だけ手前にセクションを入れます。深さ0は、最後のメッセージの後ろに入ります。最新のメッセージのそばでモデルに見せたい念押しに使います。

<a id="wrap-formats"></a>

## 囲み形式

**Overview**タブの**Wrap Format**は、各セクションをどう囲むかを決めます。

| 形式 | 結果 |
| --- | --- |
| **XML** | 各セクションをタグで囲みます。グループは親タグになります。これがデフォルトです。 |
| **MARKDOWN** | 各セクションに見出しが付きます。グループは上位の見出しになります。 |
| **NONE** | 何も囲みません。内容は書いたとおりに送られます。 |

たいていのモデルにはXMLが合います。タグがないほうがモデルの反応が良い場合だけ、ほかの形式を試してください。

1つの**Prompt Block**だけをタグや見出しなしで送るには、そのブロックを展開して**Send without wrapper**(囲みなしで送信)をオンにします。グループのタグは引き続きブロックを囲むことがあるため、何も付けずに送りたいときは、ブロックをグループから外してください。マーカーには常に囲みが付きます。また、形式が**NONE**のときは、このスイッチは表示されません。

<a id="conversation-and-game-chats"></a>

## ConversationチャットとGameチャット

これらのチャットは、Sectionsからプロンプトを組み立てません。モードごとのプロンプトを1つ使います。**Chat Settings**(チャット設定)の**Prompt Preset**(プロンプトプリセット)セクションには、手持ちのプリセットが並ぶ**Prompt source**(プロンプトのソース)ドロップダウンがあります。最初は**Default conversation prompt**か**Default game prompt**になっていて、プリセットが1つもない場合は**No presets available**と表示されます。**Presets**パネルでは、割り当てのボタンに「Prompt presets are not available in conversation mode.」と表示されます。

ドロップダウンの下のバッジは、プロンプトがどこから来ているかを示します。

| バッジ | 意味 |
| --- | --- |
| **Default** | 内蔵のプロンプト。 |
| **Preset** | 選んだプリセットのプロンプト。 |
| **Style** | 選んだGMのプロンプトスタイルのプロンプト。Gameチャットだけです。 |
| **Custom** | このチャットだけのローカルな編集。ほかのすべてより優先されます。 |

テキスト欄には、使用中のプロンプトが表示されます。編集すると、このチャットだけのコピーができます。テキストがプリセットやデフォルトと完全に一致する場合、Marinaraはカスタマイズされていないものとして扱います。カスタムの編集があるあいだは、リセットのアイコン(ツールチップは**Reset to default prompt**)が表示されます。

Gameチャットには、さらに2つの設定があります。**GM prompt style**(GMのプロンプトスタイル)はGameプロンプトだけを置き換えますが、チャットだけの編集があればそちらが優先されます。**Extra instructions**(追加の指示)は、Gameプロンプトに文章を追加します。上限は2000文字で、たとえば「Write in the style of Terry Pratchett.」のように書きます。

<a id="decision-blocks-and-prompt-caching"></a>

## 判定ブロックとプロンプトキャッシュ

セクションに判定ブロック`{{#if decision:"..."}}`を含めると、チャットについての文が真のときだけ、その部分が送信されます。[Decisionモデルへの問い合わせ](conditional-prompts.md#asking-the-decision-model)を参照してください。

よく変わる判定ブロックは、履歴後の指示など、プロンプトの後方に置いてください。分岐が変わると、プロバイダーはその地点以降のプロンプトを再利用できなくなるため、前方で変わるとキャッシュによる節約の大部分を失います。それより前の変わらない部分は、引き続き再利用できます。判定を先頭近くに置くのは、答えがほとんど変わらない場合だけにしてください。[プロンプトキャッシュ](conditional-prompts.md#prompt-caching)を参照してください。

無効なセクションやグループの判定文は問い合わせず、**Decision statements per turn**(1ターンあたりの判定文数)にも数えません。

## AIに何が届いたかを確認する

**Peek Prompt**は、あるメッセージについて、組み立て終わったプロンプト全体を表示します。おかしな返信の原因を調べるいちばんの近道です。[Peek Prompt: AIが受け取った内容を確認する](../chats/peek-prompt.md)を参照してください。
