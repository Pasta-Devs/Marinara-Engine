# プロンプトマクロ

このガイドでは、Marinara Engineのプロンプトマクロを説明します。マクロとは、Marinaraがその場の値に置き換える短い`{{tag}}`のことです。値はプロンプトを組み立てるときに埋め込まれ、名前や今日の日付などが入ります。組み込みマクロの一覧、入力できる場所、避けたい失敗がわかります。

## マクロとは何か、どこで使えるか

マクロは`{{user}}`や`{{char}}`のように、二重の波括弧で囲んだテキストです。MarinaraはAIに送るテキストを組み立てるときにこのタグを探し、1つずつ現在の値に置き換えます。マクロをオンにするスイッチはありません。マクロに対応した欄では、常に展開されます。

組み込みタグのマクロ名は大文字と小文字を区別しません。`{{user}}`でも`{{USER}}`でも動きます。

マクロはアプリのさまざまな場所で入力できます。

- **Character Editor**(キャラクターエディター)のキャラクターの各欄: Description、Personality、Backstory、Appearance、Scenario、Example Dialogue、System Prompt、Post-History Instructions、そして**Depth Prompt**。
- **Persona Editor**(ペルソナエディター)のペルソナの各欄(カードの同じ欄)。
- ロアブックのエントリーのDescription欄とContent欄。
- **Preset Editor**(プリセットエディター)のプロンプトプリセットのセクション。
- 正規表現スクリプトのFind欄、Replace欄、Trim欄。
- エージェントのプロンプトテンプレート。
- チャットの入力欄。メッセージに`{{roll:1d20}}`と書くと、送信前に展開されます。

マクロの値の中に別のマクロを含めることもでき、Marinaraはそれも展開します。

## 始める前に

準備は何も要りません。組み込みマクロはそのまま使えます。APIキーも追加の接続も不要です。APIキーはMarinaraがAIのプロバイダーと通信するための秘密の文字列ですが、マクロはMarinaraの内部だけで動きます。

ただし、次の2つの機能はアプリの他の部分に依存します。

- プリセット変数(`{{NAME}}`という何でも受けるタグ)は、それを定義したプロンプトプリセットが必要です。[プリセット変数](preset-variables.md)を参照してください。
- エージェントのマクロ`{{agent::TYPE}}`は、対応するエージェントが動いて出力を作ったあとでなければテキストが出ません。

## 本人、キャラクター、ペルソナのマクロ

これらのマクロは、話しかける側と返事をするキャラクターの名前やカードの内容を差し込みます。userは読者自身(またはアクティブなペルソナ)、characterは返事をするボットです。

| マクロ | 展開結果 |
| --- | --- |
| `{{user}}` / `{{userName}}` | 現在の表示名(またはペルソナ名)。ペルソナが未設定のときは`User`になります。 |
| `{{userNamePhonetic}}` | ペルソナのPhonetic name。空のときは`{{user}}`と同じです。 |
| `{{char}}` / `{{charName}}` | 現在のキャラクターの名前。デフォルトは`Character`です。 |
| `{{<21-character-card-ID>}}` | 別のキャラクターカードの名前を入れるためのプレースホルダーの書き方。山括弧の部分は、そのカードの正確な21文字のIDに置き換えます。 |
| `{{persona-21-character-card-ID}}` | 別のペルソナ名を参照するためのプレースホルダーです。カードのコンテキストを取得するには、`persona-`の後をそのカードの正確な21文字のIDに置き換えます。 |
| `{{charNamePhonetic}}` | キャラクターのPhonetic name。空のときは`{{char}}`と同じです。 |
| `{{characters}}` | チャットにいるすべてのキャラクターをカンマ区切りで並べます。 |
| `{{group}}` | グループチャットで有効なキャラクターのうち、今返事をしているキャラクターを除いた全員。ペルソナはこの一覧に入りません。 |
| `{{persona}}` | ペルソナのDescription、Personality、Backstory、Appearance、Scenarioを改行でつないだもの。 |
| `{{personaDescription}}` | ペルソナのDescription欄。 |
| `{{personaPersonality}}` | ペルソナのPersonality欄。 |
| `{{personaBackstory}}` | ペルソナのBackstory欄。 |
| `{{personaAppearance}}` | ペルソナのAppearance欄。 |
| `{{personaScenario}}` | ペルソナのScenario欄。 |

次のマクロは、現在のキャラクターのカードから内容を読み取ります。

| マクロ | キャラクターカードの項目 |
| --- | --- |
| `{{description}}` | Description |
| `{{personality}}` | Personality |
| `{{backstory}}` | Backstory |
| `{{appearance}}` | Appearance |
| `{{scenario}}` | Scenario |
| `{{example}}` | Example Dialogue |
| `{{charSysInfo}}` | System Prompt |
| `{{charPostHistory}}` | Post-History Instructions |

キャラクターが1人のチャットでは、そのキャラクターの内容が入ります。グループチャットでは、デフォルトで最初のキャラクターの内容が入ります。キャラクターごとに同じテキストを繰り返したいときは、角括弧のグループブロックの中に入れてください。グループブロックについては[条件付きプロンプト](conditional-prompts.md)を参照してください。

`{{group}}`は、今返事をしているキャラクターに追従します。グループの中で1人ずつ生成する場合も同じです。たとえばPowers That Be、Maukie、PantaloneがいるRoleplayのグループで、Pantaloneが返事をしているときは、`{{group}}`は`Powers That Be, Maukie`になります。キャラクターカードの名前がたまたま`{{user}}`と一致していても、その一覧からは外れません。

Phonetic name欄には2つの役割があります。1つは音声合成での名前の読み方を決めることです。もう1つは`{{charNamePhonetic}}`と`{{userNamePhonetic}}`に値を渡すことです。この欄は**Character Editor**と**Persona Editor**の両方にあります。

今のチャットにいないキャラクターを参照したいときは、そのカードのIDをコピーして、二重の波括弧の中にそのまま入れてください。たとえば`{{V1StGXR8_Z5jdHi6B-myT}}`のように書きます。Marinaraはこのマクロをカードの名前に置き換え、参照したカードのキャラクターコンテキストをシステムプロンプトに追加します。参照したカードの挨拶メッセージと会話例は含まれません。そのカードに紐づく有効なロアブックは、これまでどおりキーワード、**Constant**、フィルター、確率、トークン予算のルールに従います。

現在選択されていないペルソナを参照するには、コピーしたIDの先頭に`persona-`を付けます。例: `{{persona-P1StGXR8_Z5jdHi6B-myT}}`。Marinaraはマクロをペルソナ名に置き換え、Description、Personality、Appearance、Backstory、Scenarioの各フィールドをID Macro Cardsに追加します。紐づくロアブックは通常の有効化ルールに従います。

## Conversation Modeのマクロ

次の4つのマクロはConversation Modeでのみ動きます。他のモードでは常に空になります。同じカードやプリセットのテキストを複数のモードで使い回している場合も同じです。

| マクロ | 展開結果 |
| --- | --- |
| `{{convo_display}}` | キャラクターの**Convo Display Name**(Conversationでの表示名)。空のときはカードの名前になります。 |
| `{{char_about}}` | キャラクターの現在の**About Me**(チャットごとの上書きがあればそれ、なければカードのデフォルト)。 |
| `{{persona_about}}` | ペルソナの現在のAbout Me。 |
| `{{convo_behavior}}` | キャラクターの**Convo Behavior**のテキスト。ただし挿入位置の設定がこのマクロの場所になっているときだけです。 |

これらの欄は、**Character Editor**と**Persona Editor**の**Convo**タブで編集します。設定の全体像は[Conversationモードのプロフィール(表示名、About Me、振る舞い)](../conversation/profiles.md)を参照してください。

## Conversationの配置マクロ

Conversation Modeは、いくつかのブロックを自動でプロンプトに挿入します。ここで挙げるマクロを使うと、プリセット側からブロックの位置を**移動**できます。マクロを置いた場所にそのブロックが出力され、自動挿入のほうは**省略**されるので、内容が二重になることはありません。各マクロには別名があり、どの別名でも動作は同じです。

| マクロ(と別名) | 配置されるもの |
| --- | --- |
| `{{context}}`, `{{status}}` | Conversationのコンテキスト/状態のブロック。 |
| `{{commands}}`, `{{commandList}}` | 使えるコマンドの案内。 |
| `{{reactRules}}`, `{{emojiReact}}` | カスタム絵文字の**リアクション**のルール。 |
| `{{replyRules}}` | カスタム絵文字とスタンプの**返信**のルール。 |
| `{{memories}}`, `{{memoryRecall}}` | 記憶機能の呼び出しブロック。 |
| `{{lorebook}}`, `{{lore}}` | ロアブックの挿入内容。 |

これらはConversation Modeでのみ有効です。キャラクターが1人のConversationでは、参加者の紹介文を`{{char_about}}`と`{{persona_about}}`(前述)で自分の好きな位置に置いても同じことが起きます。Marinaraは参加者の「about me」ブロックの自動挿入を省略するので、紹介文が2回入ることはありません。グループのConversationでは自動挿入をそのまま残します。単数形のどちらのマクロも参加者1人分しか出せず、他の全員の紹介文を隠してしまってはいけないからです。

## コンテキストのマクロ

次のマクロは、現在のチャットと今回のリクエストの情報を返します。

| マクロ | 展開結果 |
| --- | --- |
| `{{input}}` | プロンプトから参照できる、直近のユーザーのメッセージ。 |
| `{{model}}` | 選択中のモデル名(選ばれている場合)。 |
| `{{chatId}}` | 現在のチャットのID。 |
| `{{lastGenerationType}}` | この返信を生成している理由を表すラベル。 |
| `{{idle_duration}}` | 最後にチャットが動いてからの経過時間。`8 minutes`や`1 hour 5 minutes`のようなテキストです。 |
| `{{gameStoryboardKeyframeCount}}` | Game Modeの現在の**Keyframes per Turn**(1ターンあたりのキーフレーム数)の目標値。1から6までで、デフォルトは`3`です。 |
| `{{agent::TYPE}}` | 指定した種類のエージェントの保存済み出力。 |

`{{lastGenerationType}}`の値は単純なラベルです。アプリで実際に見られる値には`normal`、`continue`、`regenerate`、`impersonate`、`guided`、`autonomous`、`turn_game`、`preview`、`game_setup`、`lorebook_scan`、`retry_agents`などがあります。今後増える可能性があるので、固定の一覧ではなく例として考えてください。

`{{gameStoryboardKeyframeCount}}`は、組み込みの**Storyboard Game Prompt**を含むGame ModeのGMプロンプトに渡されます。これは物語上の目安であり、その数だけ段落を書けという指示ではありません。ターンの中に視覚的な見せ場が足りないときは、絵コンテのプランナーはこれより少ないカットしか返しません。

`{{agent::TYPE}}`マクロは、エージェント(シーンのトラッカーなどを裏で埋めてくれる補助役)の保存済み出力を差し込みます。いちばん簡単な追加方法は**Preset Editor**を使うことです。**Add Section**(セクションの追加)をクリックし、**Agent Sections**のグループを開いてエージェントを選びます。すると、正しい`{{agent::TYPE}}`タグがすでに入ったセクションがMarinaraによって作られます。このマクロは最後に展開されるので、エージェントのテキストからプロンプトにさらにマクロを挿入することはできません。

## ロアブックのOutletマクロ

`{{outlet::name}}`は、**Position**が**Outlet**で、かつ**Outlet name**が`name`と完全に一致するロアブックのエントリーの内容を差し込みます。Outlet名は大文字と小文字を区別します。たとえば`{{outlet::character_rules}}`は、`Character_Rules`という名前のOutletには一致しません。

Outletのエントリーも、通常どおりロアブックの発動判定を通ります。今回の生成でエントリーが有効になるかどうかは、キーワード、Constantモード、確率、フィルター、タイミング、エントリー数の上限、トークンの予算で決まります。同じOutlet名を持つ有効なエントリーは、**Order**の順に改行で区切ってつなげられます。これらはマクロの位置にだけ挿入され、通常のロアブックの位置には追加されません。

Outletマクロは、Conversation、Roleplay、Game Modeのプロンプトのセクションで使えます。プリセットのロアブックのマーカーより前に置いても動きますし、Outletのエントリーしか使わないプリセットならマーカー自体が不要です。存在しないOutletや有効でないOutletは空になります。Outletのエントリーの中から別のOutletマクロを展開することはできないので、入れ子の再帰は起きません。

## 時刻のマクロ

時刻のマクロは、1回の展開で共通の同じ時点を読み取るため、値が互いにずれることはありません。タイムゾーンはブラウザーから取得します。

| マクロ | 展開結果 |
| --- | --- |
| `{{date}}` | 今日の日付。`YYYY-MM-DD`の形式です。 |
| `{{time}}` | 現在の時刻。24時間制の`HH:MM`の形式です。 |
| `{{datetime}}` / `{{isotime}}` | タイムゾーンのオフセットを含む完全なタイムスタンプ。2つの名前は同じ意味です。 |
| `{{weekday}}` | 曜日の名前。`Monday`など。 |
| `{{timezone}}` | タイムゾーンの名前。`Europe/Warsaw`など。 |

## ランダムとダイスのマクロ

次のマクロはプロンプトに偶然の要素を加えます。数値や選択肢にはランダムのマクロ(`{{random}}`)、ダイスにはロールのマクロ(`{{roll}}`)を使います。

| マクロ | 動作 |
| --- | --- |
| `{{random}}` | 0から100までのランダムな整数。 |
| `{{random:X:Y}}` | XからYまでのランダムな整数。両端を含みます。 |
| `{{random::A::B::C}}` | 選択肢を1つランダムに選び、選ばれたものの中だけマクロを展開します。 |
| `{{random::A@2::B@0.5}}` | 重み付きのランダム選択。重みの規則は下記のとおりです。 |
| `{{roll:XdY}}` | ダイスロールの合計。たとえば`{{roll:2d6}}`は6面ダイスを2個振って合計します。 |

そのままコピーして使える簡単な例です。

```text
{{random::The door creaks open.::A bell rings.::Someone laughs nearby.}}
```

### 重み付きの選択

選択肢の末尾に`@数値`を付けると、選ばれやすさを設定できます。この数値は相対的な重みで、大きいほど選ばれやすくなります。

```text
{{random::Common event@1::Rare event@0.25}}
```

この例では重みの合計が1.25なので、確率は次のようになります。

| 選択肢 | 重み | 確率 |
| --- | --- | --- |
| Common event | 1 | 80% |
| Rare event | 0.25 | 20% |

重みの規則は次のとおりです。

- 重みを書かない選択肢は1として扱います。
- 0.5や0.01のような小数も使えます。
- 重みが0の選択肢は残りますが、選ばれることはありません。
- すべての選択肢の重みが0の場合、マクロは空になります。
- 重みとして扱われるのは末尾の`@数値`だけです。メールアドレスのように途中に出てくる`@`はそのまま残ります。

## 動的な変数

変数を使うと、プロンプトのある部分で値を保存し、あとの部分で読み出せます。

| マクロ | 動作 |
| --- | --- |
| `{{setvar::name::value}}` | 値を保存し、テキストには何も残しません。 |
| `{{getvar::name}}` | 保存した値を読み出します(未設定なら空です)。 |
| `{{addvar::name::value}}` | 両方が数値なら加算し、それ以外はテキストを末尾に追加します。 |
| `{{addnumvar::name::value}}` | 常に数値として加算するMarinara独自拡張です。未設定または無効な値は0として扱い、オーバーフローは無視します。 |
| `{{incvar::name}}` | 数値の変数に1を足し、新しい値を挿入します。 |
| `{{decvar::name}}` | 数値の変数から1を引き、新しい値を挿入します。 |

変数は1回のプロンプト構築の中で左から右へ順に展開され、現在のチャットに保存されます。先に来るロアブックのエントリーなど、早い段階で設定した値は、同じプロンプトのあとのほうで読み出せます。SillyTavernのローカル変数と同様に、後のターンや再起動後も保持されますが、別のチャットには共有されません。

組み込みマクロではない`{{NAME}}`は、すべてプリセット変数として扱われ、名前で検索されます。その名前の変数がなければ、タグは入力したままの形でテキストに残ります。定義の方法は[プリセット変数](preset-variables.md)を参照してください。

## 書式のマクロ

次のマクロは、周囲のテキストの見た目を整えます。

| マクロ | 動作 |
| --- | --- |
| `{{newline}}` / `{{\n}}` | 改行を挿入します。 |
| `{{trim}}` | 自身を消し、その位置の前後の空白を削ります。 |
| `{{trimStart}}` | 周囲のテキストの先頭の空白を削ります。 |
| `{{trimEnd}}` | 周囲のテキストの末尾の空白を削ります。 |
| `{{uppercase}}...{{/uppercase}}` | 囲んだテキストを大文字にします。 |
| `{{lowercase}}...{{/lowercase}}` | 囲んだテキストを小文字にします。 |
| `{{noop}}` | 出力から取り除かれます。編集中の無害なプレースホルダーとして使えます。 |
| `{{// comment}}` | 出力から取り除かれる、書き手向けのメモ。 |
| `{{banned "text"}}` | 出力から取り除かれます。何かをフィルターしたり止めたりはしません。 |

## 二重の波括弧をそのまま表示する

マクロにエスケープ文字はありません。二重の波括弧をテキストに残したいときは、Marinaraが知らない名前を使ってください。同じ名前のプリセット変数がないかぎり、未知の`{{name}}`は入力したままの形で残ります。AIには絶対に届かないメモを書きたいときは、代わりに`{{// like this}}`を使ってください。

## Macro referenceと/macros

マクロが使える欄には、隅に小さなボタンが2つあります。

- **Expand editor**(エディターを広げる)は、その欄を大きな編集ウィンドウで開きます。
- **Macro reference**(マクロ一覧)は、**Macro reference**というウィンドウを開きます。組み込みマクロが分類ごとに並び、正確な書き方も載っています。この一覧はエンジンが使うのと同じ情報から生成されるので、常に最新です。

チャットの入力欄に`/macros`と打つこともできます(短い形の`/macro`でも動きます)。マクロの全一覧がそのままチャットに表示されるので、確認用に便利です。

条件ブロックでは、`||`(OR)、`&&`(AND)、丸括弧を使って複数の比較を組み合わせられます。等値の並びは`{{#if character == "Maukie" || "Pantalone"}}`のように短く書けます。優先順位、グループチャットでの例、演算子の全一覧は[条件付きプロンプト](conditional-prompts.md)を参照してください。

## よくある失敗

- `{{random::...}}`のブロックの中に変数を書かないでください。ランダムの選択肢に入れた`{{setvar}}`は、選択が決まる前にすべての選択肢について実行されます。選ばれたものだけではありません。
- ローカル変数をグローバル変数のように使わないでください。`{{setvar}}`の値は現在のチャットだけに保持され、別のチャットにはそれぞれ独立した値があります。
- `{{prompt}}`はマクロではありません。メッセージ全体が`{{prompt}}`だと、Marinaraはそれを送信せずに**Peek Prompt**の表示画面を開きます。[Peek Prompt](../chats/peek-prompt.md)を参照してください。
- Custom Toolsは`{{macro}}`のテキストを解釈しません。展開されることを期待して`{{roll:1d20}}`をツールの欄に貼り付けないでください。
- **Impersonate**のプロンプトテンプレートが受け付けるのは少数のプレースホルダーだけで、マクロの全一覧ではありません。名前も異なるため、カードで動くマクロがここでは動かないことがあります。
- 非常に大きな出力や深く入れ子になった出力は、何も知らせずに切り捨てられます。エラーは出ないので、マクロの展開結果は無理のない大きさに抑えてください。
