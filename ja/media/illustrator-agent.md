# Illustratorエージェント

**Illustrator**は、チャットの最中にシーンの絵を描くダウンロードできるエージェントです。このガイドでは、オンにする手順、画風と画像モデルの選び方、クリップの作り方を説明します。エージェントとは、1つのチャットのために自動的に動く小さなAIヘルパーです。

## Illustratorの役割

Illustratorは後処理型のエージェントなので、AIが返信を書き終えるたびに動きます。直前の返信を読み、その場面が絵にする価値のある瞬間かどうかを判断します。価値があれば、画像プロンプト(何を描くかを画像モデルに伝える文章)を書き、画像サービスに送ります。作った画像はすべて、チャットの**Gallery**(ギャラリー)に保存されます。

すべてのメッセージを絵にするわけではありません。デフォルトでは、1枚作ったあと、採用されたユーザーとアシスタントのメッセージが5件たまるまで、次の画像を作りません。この件数は、Roleplayのチャットごとに変更できます。返信をスワイプしたり再生成したりしても、件数は進みません。絵にする価値がないと判断した場面は飛ばします。

RoleplayとGame Modeのチャットで使えます。インストールすると、Conversationの自撮り写真と[動画メッセージ](../conversation/selfies.md#video-messages)も使えるようになります。このガイドの設定手順はRoleplay向けです。Game Modeではスイッチを1つ使います([Game Mode](#game-mode-the-game-illustrator-toggle)を参照)。

## 始める前に

Illustratorが書くのはプロンプトで、絵を描くのは別の画像モデルです。画像モデルが1つ必要です。[画像生成プロバイダーと設定](image-providers.md)を参照してください。

Illustratorに画像モデルを渡す方法は2つあります。

1. **Connections**(接続)パネルの**Defaults**(デフォルト)で、**Images**(画像)の役割を設定します。
2. または、Illustratorの**Open Setup**(設定を開く)画面で、Illustrator専用の画像モデルを指定します。

画像モデルが見つからない場合、画像の生成は失敗し、アプリが画像モデルを選ぶよう求めます。

## Illustratorをオンにする

始める前に: **Agent Organizer**から**Illustrator**をインストールしてください。[エージェントの概要](../agents/agents-overview.md)を参照してください。

1. 絵を付けたいRoleplayのチャットを開きます。
2. **Chat Settings**(チャット設定)を開き、**Agents**(エージェント)を探します。
3. **Enable Agents**(エージェントを有効にする)をオンにします。
4. **Misc Agents**(その他のエージェント)グループで**Illustrator**を見つけ、プラスボタンで追加します。

専用の項目を持つ**Illustrator**のカードが表示されます。エージェントはトークンを余分に使い、1ターンあたりのモデル呼び出しが増えることがあります。トークンの概算に含まれるのは、エージェントの指示だけです。

<a id="game-mode-the-game-illustrator-toggle"></a>

### Game Mode: Game Illustratorのトグル

Game Modeには、**Prompt Mode**と**Prompt Model**の項目がありません。ゲームの**Chat Settings**を開き、**Game Illustrator**(ゲームのイラスト生成)をオンにします(説明文は「Auto-generate scene illustrations, NPC portraits, and location backgrounds during gameplay」)。

## 画風を選ぶ

**Prompt Mode**(プロンプトモード)の選択肢(カード上のラベルは**Prompt**)は、Illustratorが書くすべてのプロンプトの画風を決めます。追加したばかりのIllustratorは**Background**から始まります。

| 画風 | 描くもの |
| --- | --- |
| **Illustration**(イラスト) | 仕上げの整った1枚のシーン画です。汎用の画風です。 |
| **Comic Page**(コミックページ) | コマ割り、吹き出し、キャプション、効果音のあるコミックのページです。 |
| **Colored Manga**(カラー漫画) | 様式化された吹き出しと効果音のある、カラーの漫画シーンです。 |
| **B&W Manga**(白黒漫画) | ペン入れの線とスクリーントーンで陰影を付けた、白黒の漫画ページです。 |
| **Background**(背景) | キャラクターのいない、場所や情景を示すカットです。 |
| **Selfie**(自撮り写真) | キャラクターになりきった自撮り写真、または気取らない人物写真です。 |

最終的な絵の雰囲気は、スタイルプロファイルにも左右されます。[画像スタイルプロファイル](style-profiles.md)を参照してください。

## プロンプトモデルを選ぶ

**Prompt Model**(プロンプトモデル)は、画像プロンプトを書くテキストモデルです。絵は描きません。カードの**Prompt Model**の一覧から選びます。デフォルトは**Main chat model**(メインのチャットモデル)で、チャットのモデルをそのまま使います。別のモデルにプロンプトを書かせたいときは、ほかのテキストモデルを選びます。

絵を描く画像モデルは、**始める前に**で設定したものです。

## キャラクターの見た目をそろえる

カードにある2つの設定は、どの絵でもキャラクターが同じ見た目になるように助けます。どちらも最初はオフです。

**Attach Card Appearance**(カードの外見情報を添付)は、画面に登場する各キャラクターの保存済みの外見の記述を、画像プロンプトに追加します。Roleplayのチャットでは、4つの選択肢がある一覧になります。

- **Off**(オフ)
- **Images only**(画像のみ): 通常の動作です。
- **Videos only**(動画のみ): クリップに、そこに映るキャラクターの外見の記述を追加します。特に、画像のない**Prompt only**のクリップで重要です。
- **Images and videos**(画像と動画): 両方です。

オンのとき、**Image Appearance Override**(画像用の外見指定)をオンにしたカードやペルソナは、**Appearance**(外見)のテキストの代わりにその指定を送ります。**Appearance**が語り手向けに書かれていて、画像モデルには伝わりにくいときに使います。詳しい説明は**Appearance**に残し、短いタグ形式の説明を画像用の外見指定に入れてください。指定がオフか空の場合、画像プロンプトには**Appearance**を使います。語り手には常に**Appearance**の全文が送られます。このスイッチは、キャラクターとペルソナのエディターの**Appearance**の下にあります。

**Send Avatar References**(アバターを参照画像として送信)は、キャラクターとペルソナのアバター、またはそのスプライトを参照画像として画像サービスに送り、モデルが顔立ちや衣装を真似できるようにします。参照画像を受け付けないサービスもあります。Roleplayのチャットでは、**Attach Card Appearance**と同じような一覧になります。動画を含めると、**First frame**(開始フレーム)が**Prompt only**のクリップはキャラクターのアバターかスプライトから始まり、選択肢の表示は**Prompt only (avatar from Send Avatar References)**になります。

## 絵を描く頻度を調整する

Illustratorのカードには、全体の設定画面を開く**Open Setup**(設定を開く)ボタンがあります。そこで、実行間隔のデフォルトを設定したり、専用の画像モデルを指定したりします。

Roleplayの各チャットには、**Chat Settings**のカードに、そのチャット専用の**Image Run Interval**(画像の実行間隔)があります(「Messages between automatic images in this chat. 0 means only when you ask.」)。値を設定していないチャットでは、設定画面の値を使います。デフォルトは**5**です。カードには**Using agent default**または**Chat override**と表示されます。元に戻すには、**Use agent default**(エージェントのデフォルトを使う)を押します。Illustratorをチャットに追加するときは、追加用のウィンドウにも同じ欄が表示され、値はそのチャットにだけ保存されます。

手動専用にするには、**Image Run Interval**を**0**に設定します。シーン背景の自動生成を含む自動実行は止まりますが、エージェントはGalleryの操作で引き続き使えます。再開するには、正の値を設定します。

今すぐ絵を作るには、**Chat Settings**を開き、**Gallery**(ギャラリー)を展開して**Illustrate**(イラストを生成)をクリックします。Illustratorがすぐに1回だけ動き、ボタンの表示が**Generating...**に変わります。

## クリップを作る

Roleplayのチャットでは、**Chat Settings → Agents → Illustrator**(チャット設定 → エージェント → Illustrator)に**Illustrator makes**(Illustratorが作るもの)という設定があります。

- **Pictures**(画像、デフォルト): 画像だけを作ります。
- **Pictures and clips**(画像とクリップ): アクション、追跡、物が壊れる場面など、動きが要となる場面では、Illustratorが新しい画像を短いクリップにすることもあります。語り手が`[illustrate]`で求めた画像も含まれます。動きはIllustrator自身が、動画モデルの**Video prompting instructions**に従って記述します。先に画像が表示され、完成したクリップは同じメッセージに加わります。
- **Clips only**(クリップのみ): Illustratorが画像を表示するはずの場面で、代わりに短いクリップを表示します。描いた画像はクリップの開始フレームになり、返信ではなくGalleryに入ります。クリップが失敗した場合は、その画像が表示されます。

クリップは**Scene Videos**(シーン動画)の動画モデルを使い、1本ごとに動画リクエストになります。使える動画モデルがなければ、**Clips only**でもIllustratorは画像を作ります。画像を作るカスタムエージェントも、同じ設定に従います。[シーン動画の生成](scene-video.md)を参照してください。

**Video Run Interval**(動画の実行間隔)は、Illustratorがクリップを作る設定にすると表示されます。1本のクリップのあと、次のクリップまでに必要なユーザーとアシスタントのメッセージ数で、**Image Run Interval**とは別の設定です。

- **Clips only**では、毎回の実行がクリップになり、**Video Run Interval**がIllustratorの実行頻度を決め、**Image Run Interval**は表示されません。
- 値を設定していないチャットでは、**Open Setup**画面の**Video Run Interval**を使い、それもなければ5を使います。
- **0**: 自分からはクリップを作りません。`[illustrate]`で求められた画像も同様で、代わりにその画像が表示されます。
- 1つの返信に付くクリップは、最大で**Videos per reply**の本数までです。この値は**Settings → Generations → Video Generation**(設定 → 生成 → 動画生成)にあります。
- Galleryから画像をアニメーションにすることも、引き続きできます。**Clips only**では、メッセージの**Illustrate**ボタンでクリップが作られます。
- クリップが付いた返信をスワイプすると、新しい返信として数えられ、独自のクリップが付くことがあります。以前のスワイプは、元のクリップを残します。

同じセクションの**First frame**(開始フレーム)は、Roleplayのすべてのクリップが何から始まるかを決めます。対象は、Illustratorのクリップ、`/video`、Galleryの**Video**ボタンです。選択肢は、新しいIllustratorの画像、名前の挙がったキャラクターのアバターかスプライト、画像(使えなければアバター)、画像なしです。Conversationの動画メッセージも、同じ設定を使います。

- アバターまたは画像なしの**Clips only**: 画像は描かれません。クリップは、Illustratorが書いた場面と動きから作られます。
- **Pictures and clips**: 画像は引き続き表示され、クリップだけがアバターまたは画像なしから始まります。
- 開始フレームが未選択: クリップのためだけに画像を描くことはありません。**Pictures and clips**は、Illustratorが作った直後の画像をアニメーションにします。**Clips only**、`/video`、**Video**は、場面だけからクリップを作ります。

独自の画像がないクリップは、ペルソナを含め、名前を挙げた全員を記述します。アバターの開始フレームは、最初に名前が挙がった人物から始まります。

メッセージの**Illustrate**ボタンからIllustratorを再実行するときも、**Illustrator makes**と**First frame**に従います。

## NovelAIで複数のキャラクターを描く

Illustratorの画像モデルがNovelAIのV4、V4.5、V5モデルの場合、プロンプトを書くモデルは、画面に登場するキャラクターごとに1つずつキャラクターの記述を追加します。各記述には、そのキャラクターの外見、表情、ポーズ、画面内のおおよその位置が含まれます。Marinaraは記述をシーンのキャラクター一覧と照合し、対応するキャラクターが見つからないものを除いて、残りをNovelAI標準のキャラクタープロンプトとして、メインプロンプトと一緒にNovelAIへ送ります。これにより、髪や服などの特徴がキャラクター間で混ざるのを防ぎます。**Illustrate**や、キャラクターの`[illustrate]`コマンドで作る画像にも、同じ記述が付きます。

V5は最大22人、V4とV4.5は最大6人まで受け付けます。それ以上のキャラクターが登場する場合は、重要なキャラクターを残し、残りは名前のない背景の人物になります。

変わらない特徴は、**Appearance**(外見)フィールドから取ります。すでにDanbooruタグで書かれていればそのままコピーし、文章ならプロンプトを書くモデルがタグに変換します。服装は、キャラクタートラッカーが動いている場合はその時点の服装から取り、これもタグに変換します。

**Attach Card Appearance**(カードの外見情報を添付)をオンにすると、プロンプトを書くモデルにはチャット内のすべてのカードとペルソナのAppearance全文も渡されるため、長いカードや複数のキャラクターを含むカードが途中で切れません。複数のキャラクターを`[NAME] tags | [NAME] tags`の形式で記述したカードは、キャラクターごとに分けて渡されます。プロンプトを書くモデルは、変わらない特徴を対応するキャラクターの記述にコピーし、カードの服装タグはトラッカーやシーンで上書きされるデフォルトとして扱い、シーンにいないキャラクターは無視します。キャラクターの記述が返ってきた場合、Marinaraはそれ以上何も追加しません。1人だけのシーンのように記述がない場合は、これまでどおり通常の外見の行をメインプロンプトに追加します。

設定は必要ありません。キャラクターの記述が使われるのはNovelAI自身のホストの場合だけなので、プロキシやほかのサービスには影響しません。**Expose media prompts before sending**(送信前にメディアのプロンプトを表示)をオンにすると、確認ウィンドウのメインプロンプトの下に、記述が読み取り専用で表示されます。メインプロンプトは通常どおり編集してください。

## ギャラリーへの保存とプロンプトの確認

**Settings → Generations → Image Generation**(設定 → 生成 → 画像生成)の**Automatically save generated images to character galleries**(生成画像をキャラクターギャラリーに自動保存)は、デフォルトでオンです。オフにすると、チャットのイラストや自撮り写真を、描かれたキャラクターやペルソナのギャラリーに追加しなくなります。画像はチャットの中とチャットのGalleryには引き続き表示され、明示的なギャラリーへの保存も使えます。既存の項目は変わりません。ギャラリーは画像ファイルを共有しているため、この設定はギャラリーへの登録を制御するもので、削除は行いません。

NovelAIで新しく作ったイラストでは、画像インスペクターに、シーンとスタイルのプロンプトに続けて、ポジティブのキャラクターの記述が` | `で区切って表示されます。ギャラリーに保存されるプロンプトも同じです。

返信を再生成せずに、プロンプトを変えてイラストを描き直すには、イラストを開いて**Regenerate image**(画像を再生成)を使います。[画像を再生成する](scene-backgrounds.md#regenerating-an-image)を参照してください。

以前のRoleplayのメッセージや範囲を絵にするには、`/illustrate range=12`または`/illustrate range=12-18`を使います。[スラッシュコマンド](../chats/slash-commands.md)を参照してください。
