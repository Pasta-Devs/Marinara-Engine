# Illustratorエージェント

このガイドでは、チャットの最中にシーンの絵を描いてくれる組み込みのエージェント**Illustrator**を説明します。何をするエージェントなのか、オンにする手順、選べる画風、そして必要になる2つの接続がわかります。

## Illustratorエージェントの役割

エージェントとは、1つのチャットの中で自動的に動く小さなAIヘルパーです。**Illustrator**は後処理型のエージェントで、AIが返信を書き終えたあとに動きます。直前の返信を読み、その場面が絵にする価値のある瞬間かどうかを判断します。価値があると判断したときは、画像プロンプトを書いて画像プロバイダーに送ります。プロンプトとは、何を描くかを画像モデルに伝える文章です。

Illustratorはすべてのメッセージを絵にするわけではありません。デフォルトでは、1枚生成したあと、採用されたメッセージ(自分の入力とAIの返信)が5件たまるまで次の生成を行いません。この件数はRoleplayのチャットごとに変更できます。同じ返信をスワイプしたり再生成したりしても、この間隔は進みません。絵にする場面ではないと判断したときは、その返信を飛ばして画像を作りません。生成した画像はすべてチャットの**Gallery**(ギャラリー)に保存します。

Illustratorは**Roleplay**と**Game Mode**のチャットで使えます。さらに、インストールするとConversationの自撮り写真と[動画メッセージ](../conversation/selfies.md#video-messages)も使えるようになります。アプリ内の短い説明は「Responsible for image and video generations.」です。このガイドで扱う設定手順と項目はRoleplayのチャット向けです。Game Modeでは代わりにスイッチが1つあるだけで、詳しくは後半のGame Modeの節で説明します。

## 始める前に

Illustratorが書くのは画像プロンプトまでです。実際に絵を描くには、別途、画像用の接続が必要です。画像の接続とは、OpenAIやローカルのStable Diffusionサーバーなど、画像プロバイダーへの接続情報をまとめて保存したものです。

まず画像の接続を用意します。Illustratorに接続を渡す方法は2つあります。

1. 画像の接続を1つデフォルトに指定します。**Connections**(接続)パネルを開き、**Defaults**(デフォルト)を展開して、**Images**(画像)の下で選びます。
2. または、Illustrator専用の画像の接続をフル設定画面から指定します(後述の**Open Setup**(設定を開く)を参照)。

画像の接続が1つも見つからない場合、画像の生成は失敗し、アプリが接続の選択を求めます。プロバイダーを追加する手順は[画像生成プロバイダーと設定](image-providers.md)を参照してください。

## Illustratorをオンにする

Illustratorはデフォルトでオフです。**Roleplay**のチャットでは、次の手順で追加します。

1. 絵を付けたいチャットを開きます。
2. **Chat Settings**(チャット設定)を開きます(チャット内の**Chat Settings**ボタンで、移動していなければ右上にあります)。
3. **Agents**(エージェント)セクションを探し、**Enable Agents**(エージェントを有効にする)をオンにします。
4. **Misc Agents**(その他のエージェント)グループで**Illustrator**を見つけ、プラスボタンで追加します。

これで、専用の設定項目を持つ**Illustrator**の設定カードが表示されます。エージェントを追加するとトークン消費が増え、1ターンあたりのAI呼び出しも増える場合があります。トークンの概算に含まれるのはエージェントの指示だけで、利用料金を継続的に見積もる表示ではありません。

### Game Mode: Game Illustratorのトグル

Game Modeでは上記の手順を使わず、**Prompt Mode**や**Prompt Model**の項目も表示されません。代わりに、ゲームの**Chat Settings**を開き、**Game Illustrator**(ゲームのイラスト生成)というトグルを1つオンにします。説明文は「Auto-generate scene illustrations, NPC portraits, and location backgrounds during gameplay.」です。

## プロンプトモード

**Prompt Mode**(プロンプトモード)の選択肢は、Illustratorが書くすべてのプロンプトの画風を決めます。エージェントのカード上では、この選択肢のラベルは**Prompt**です。すぐ下には「Prompt mode controls how Illustrator writes image prompts for this chat.」という短い説明が表示されます。

選べる画風は次のとおりです。

- **Illustration**(イラスト): 仕上げの整った1枚絵です。汎用の画風です。
- **Comic Page**(コミックページ): コマ割り、吹き出し、キャプション、効果音のあるコミックのページです。
- **Colored Manga**(カラー漫画): 様式化された吹き出しと効果音のあるカラーの漫画シーンです。
- **B&W Manga**(白黒漫画): ペン入れの線とスクリーントーンで陰影を付けた白黒の漫画ページです。
- **Background**(背景): キャラクターの写り込まない、場所や情景を示すカットです。
- **Selfie**(自撮り写真): キャラクターになりきった自撮り写真、または気取らない人物写真です。

追加したばかりのIllustratorエージェントは**Background**の画風から始まります。画風はいつでも選び直せます。最終的な絵の雰囲気はスタイルプロファイルにも左右されます。設定方法は[画像スタイルプロファイル](style-profiles.md)を参照してください。

## Prompt Modelと画像の接続

Illustratorは2種類の接続を使います。混同しないように整理しておきます。

**Prompt Model**(プロンプトモデル)は、画像プロンプトを書くテキストモデルです。絵を描くモデルではありません。Illustratorのカードにある**Prompt Model**ドロップダウンから選びます。デフォルトは**Main chat model**で、チャットが使っている接続をそのまま再利用します。別のモデルにプロンプトを書かせたいときは、ほかのテキストの接続を選びます。

画像の接続は、最終的な絵を描く画像プロバイダーです。「始める前に」で説明したとおり、**Defaults → Images**で指定するか、エージェント専用の設定画面から指定します。

## Attach Card AppearanceとSend Avatar References

Illustratorのカードにある2つの設定は、キャラクターの見た目を安定させるためのものです。どちらもデフォルトではオフです。

画像では、**Attach Card Appearance**(カードの外見情報を添付)は、その場に登場しているキャラクターごとに、保存された外見の記述を画像プロンプトへ追加します。動画のプロンプトに追加されるのは、後述のとおり動画を含めた場合だけです。ヘルプの文言は「Append matched character appearance lines to image prompts, using only visible/generated names.」です。キャラクターの設定どおりの姿で描いてほしいときにオンにします。

Roleplayのチャットの**Chat Settings**(チャット設定)では、**Attach Card Appearance**は4つの選択肢を持つドロップダウンです。

- **Off**(オフ)
- **Images only**(画像のみ): 通常の動作です。
- **Videos only**(動画のみ): クリップに映るキャラクターの外見の記述を追加します。特に、その姿を示す画像がない**Prompt only**のクリップで重要です。
- **Images and videos**(画像と動画): 両方を行います。

**Attach Card Appearance**がオンのとき、カードやペルソナの**Image Appearance Override**(画像用の外見指定)もオンで、その欄に内容が入力されていれば、**Appearance**の代わりにそちらの文章を送ります。物語を書くモデル向けの**Appearance**が画像モデルには伝わりにくいときに便利です。詳しい説明は**Appearance**に残し、画像用の欄には短いタグ形式の説明を入力してください。スイッチがオフの場合や欄が空の場合は、画像プロンプトにも引き続き**Appearance**を使います。どちらの場合も、物語を書くモデルには**Appearance**の全文が送られます。このスイッチは、キャラクターとペルソナのエディターの**Appearance**の下にあります。

**Send Avatar References**(アバターを参照画像として送信)は、キャラクターとペルソナのアバター、またはそのスプライトを、参照画像として画像プロバイダーに送ります。ヘルプの文言は「Send matching character and persona avatars or sprites as reference images when the provider supports them.」です。顔立ちや衣装を画像モデルに真似させたいときに役立ちます。参照画像に対応していないプロバイダーもあるため、効果は選んだプロバイダーによって変わります。Roleplayのチャットでは**Attach Card Appearance**と同じドロップダウンになります。動画を含めると、**First frame**が**Prompt only**のクリップは画像なしではなくキャラクターのアバターかスプライトから始まり、選択肢は**Prompt only (avatar from Send Avatar References)**に変わります。プロンプトだけからクリップを作るには動画を対象から外してください。

## 自動動画

Roleplayのチャットでは、**Chat Settings**、**Agents**、**Illustrator**に**Illustrator makes**(Illustratorが作るもの)があります。

- **Pictures**(デフォルト): これまでと同じく画像だけです。
- **Pictures and clips**: アクション、暴力、追跡、物が壊れる場面など、動きが中心になる瞬間には、Illustratorが作成直後の画像に短いクリップを追加することもあります。語り手が`[illustrate]`で求めた画像も含まれます。動画接続の**Video Prompting Instructions**に従い、動きを自ら記述します。先に画像が表示され、完成したクリップは同じメッセージに追加されます。
- **Clips only**: Illustratorが画像を表示するはずの場面で、代わりに短いクリップを表示します。クリップ用の画像を描く場合は、それが開始フレームになり、返信ではなくGalleryに保存されます。その場合、クリップが失敗すると代わりにその画像が表示されます。

クリップは**Scene Videos**の**Video Connection**を使い、1本ごとに動画リクエストになります。使える動画接続がなければ、**Clips only**でもIllustratorは代わりに画像を作ります。画像を作成するカスタムエージェントも同じ設定に従います。

**Video Run Interval**はIllustratorでクリップを作るときに表示され、1本作ってから次までに必要なユーザーとアシスタントのメッセージ数を設定します。画像の作成頻度を決める**Image Run Interval**とは別です。

- **Clips only**: Illustratorの実行は毎回クリップになります。Video Run Intervalが実行頻度を決め、Image Run Intervalは非表示になります。
- **デフォルト**: チャットに独自の値がなければ、Illustratorカードの**Open Setup**画面にある**Video Run Interval**を使います。そこにもなければ5です。
- **0**: Illustratorは自発的にクリップを作りません。語り手が`[illustrate]`で求めた画像のクリップも対象となり、代わりに画像を表示します。
- **上限**: 1返信のクリップ数は**Videos per reply**までです(**Settings**、**Generations**、**Video Generation**)。
- **手動クリップ**: Galleryから画像をアニメーションにすることは引き続き可能です。**Clips only**では、メッセージの**Illustrate**ボタンでクリップを作ります。
- **スワイプ**: クリップ付き返信のスワイプは新しい返信として数えます。新しいスワイプには独自のクリップを付けられ、以前のスワイプは元のクリップを保持します。

同じセクションの**First frame**は、Roleplayのすべてのクリップの開始画像を決めます。Illustrator自身のクリップ、`/video`、Galleryの**Video**ボタンが対象です。新しいIllustrator画像、名前を挙げたキャラクターのアバターかスプライト、画像がなければアバターに切り替える方式、または画像なしを選べます。Conversationチャットの動画メッセージと同じ設定です。

- アバターまたは画像なしの**Clips only**: 画像は一切描かれません。Illustratorが記述した場面と動きからクリップを作ります。
- **Pictures and clips**: 画像は引き続き表示され、クリップだけがアバターまたは画像なしから始まります。
- 開始フレーム未選択: クリップのためだけに画像を描くことはありません。**Pictures and clips**はIllustratorが作った直後の画像をアニメーションにし、**Clips only**、`/video`、Galleryの**Video**ボタンでは場面だけからクリップを作ります。

独自の画像がないクリップでは、ペルソナを含め、名前を挙げる全員を描写します。アバターを開始フレームにする場合は最初に名前を挙げた人物を使います。

メッセージの**Illustrate**ボタンでIllustratorを再実行するときも**Illustrator makes**と**First frame**に従います。**Clips only**では画像の代わりにクリップを作り、**Pictures and clips**では動きが中心になる場面にクリップを追加することがあります。

## NovelAIで複数のキャラクターを描く

Illustratorの画像接続がNovelAIのV4、V4.5、V5モデルを使う場合、プロンプトを書くモデルには、画面に登場するキャラクターごとに追加の記述を作るよう指示されます。各記述には、そのキャラクターの外見、表情、ポーズ、画面内のおおよその位置が含まれます。Marinaraは記述をシーンのキャラクター一覧と照合し、対応するキャラクターが見つからないものを除外して、残りをNovelAI標準のキャラクタープロンプトとしてシーンのメインプロンプトと一緒に送信します。これにより、複数のキャラクターがいるシーンで髪や服などの特徴が混ざるのを防ぎます。**Illustrate**ボタンや、キャラクターの`[illustrate]`コマンドで作る画像にも、同じ記述が付きます。

記述できる人数はモデルによって異なります。V5は最大22人、V4とV4.5は最大6人です。それ以上のキャラクターが登場するシーンでは、重要なキャラクターを優先し、残りは名前のない背景の人物として扱います。

プロンプトを書くモデルには、各記述の詳細をどこから取得するかも指示されます。変わらない特徴は、キャラクターやペルソナの**Appearance**(外見)フィールドから取得します。Danbooruタグで書かれていればそのままコピーし、文章ならタグに変換します。服装は、キャラクタートラッカーが動作している場合、その時点の服装から取得してタグに変換します。

**Attach Card Appearance**(カードの外見情報を添付)をオンにすると、チャット内の各カードとペルソナのAppearance全文も参照用に渡されるため、長いカードや複数のキャラクターを含むカードが途中で切り詰められません。1つのAppearanceフィールドで`[NAME] tags | [NAME] tags`の形式で複数のキャラクターを記述したカードは、キャラクターごとに分けて渡されます。何を使うかはモデルが判断します。変わらない特徴は対応するキャラクターの記述にコピーし、カード内の服装タグはトラッカーやシーンで置き換えられるデフォルトとして扱い、シーンにいないキャラクターは無視します。キャラクターの記述が返された場合、Marinaraはプロンプトに何も追加しません。1人だけのシーンのように記述が返されなかった場合は、従来どおり外見の行をメインプロンプトに追加します。

特別な設定は不要です。この記述はNovelAI自身のホストへの接続でのみ使われるため、プロキシやほかのプロバイダーには影響しません。**Expose media prompts before sending**(送信前にメディアのプロンプトを表示)をオンにすると、確認ダイアログのメインプロンプトの下に記述が表示され、送信内容を確認できます。記述はそこで編集できませんが、メインプロンプトは通常どおり編集できます。

## そのほかの設定と手動での実行

Illustratorのカードには**Open Setup**ボタンがあります。押すとエージェントのフル設定画面が開き、実行の頻度のデフォルトを設定したり、専用の画像の接続を指定したりできます。

Roleplayの各チャットには、**Chat Settings**のIllustratorのカードに、そのチャット専用の**Image Run Interval**(実行間隔)があります。ヘルプの文言は「Messages between automatic images in this chat. 0 means only when you ask.」です。値を設定していないチャットでは、設定画面の**Image Run Interval**を使います。変更しないかぎり、この値は**5**です。カードには**Using agent default**または**Chat override**と表示されます。設定画面の値に戻すには、**Use agent default**(エージェントのデフォルトを使う)を押します。Illustratorをチャットに追加するときは、追加用のウィンドウにも同じ欄が表示され、選んだ値はそのチャットにだけ保存されます。

画像を手動生成専用にするには、**Image Run Interval**を**0**に設定します。シーン背景を含むIllustratorの画像の自動生成が停止します。**Clips only**で自動クリップを停止するには、代わりに**Video Run Interval**を**0**に設定してください。エージェントはインストールされたままGalleryの操作で利用できます。画像の自動生成を再開するには画像の間隔を正の値にしてください。

生成を待たずに、その場で1枚描かせることもできます。**Chat Settings**を開き、**Gallery**セクションを展開して、**Illustrate**(イラストを生成)ボタンを押します。Illustratorがすぐに1回だけ動き、処理中はボタンの表示が**Generating...**に変わります。今この瞬間の絵がほしいのに、エージェントがまだ描いていないときに便利です。

## ギャラリーへの保存とプロンプトの確認

**Settings → Generations → Image Generation**(設定 → 生成 → 画像生成)の**Automatically save generated images to character galleries**(生成画像をキャラクターギャラリーに自動保存)は初期状態で有効です。無効にすると、チャットのイラストやセルフィーを、描かれたキャラクターやペルソナのギャラリーに自動追加しなくなります。画像は会話とチャットのギャラリーに残り、明示的なギャラリー保存も利用できます。既存の項目は変わりません。ギャラリーは画像ファイルを共有しているため、この設定はギャラリーへの登録を制御し、チャットの画像ファイルを削除しません。

IllustratorがNovelAIで新しく生成するイラストでは、画像インスペクターにシーンやスタイルのプロンプトと、それに続くキャラクターごとのポジティブな説明が` | `で区切って表示されます。ギャラリーに保存されるプロンプトも同じです。

返信を再生成せずに、プロンプトを変えてイラストを描き直すには、イラストを開いて**Regenerate image**(画像を再生成)を使います。[画像を再生成する](scene-backgrounds.md#regenerating-an-image)を参照してください。

過去のRoleplayメッセージや範囲を描くには、`/illustrate range=12`または`/illustrate range=12-18`を使ってください。番号と上限は[スラッシュコマンド](../chats/slash-commands.md)を参照してください。
