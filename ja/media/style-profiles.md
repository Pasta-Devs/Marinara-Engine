# 画像スタイルプロファイル

このガイドでは、Marinara Engineの画像スタイルプロファイルを説明します。スタイルプロファイルとは、Marinaraが画像プロバイダーへ送る前にすべての画像プロンプトへ適用する、使い回しのできる「共通のスタイル」です。アバター、ポートレート、自撮り写真、背景、イラスト、スプライトの見た目をそろえたいときに使います。

## スタイルプロファイルとは

Marinara Engineは、さまざまな種類の画像を生成できます。キャラクターとペルソナのアバター、ポートレート、Conversationモードの自撮り写真、シーンの背景、シーン中のイラスト、キャラクターのスプライトです。これらの画像はすべて、テキストのプロンプトから始まります。

スタイルプロファイルは、Marinaraがそのプロンプトに足すルールを保存したものです。含めたい語(ポジティブな語)、避けたい語(ネガティブな語)、そして好みのプロンプト形式を追加できます。これで画像の見た目が全体で一貫し、毎回同じスタイル語を打ち直さずにすみます。

アプリ全体のデフォルトとして1つのプロファイルを選びます。チャット単位、画像接続単位で上書きすることもできます。詳しくは以下で説明します。

エディターを開く手順は次のとおりです。

1. **Settings**(設定)を開きます。
2. **Generations**タブを開きます。
3. **Image Generation**セクションを探します。
4. **Style Profiles**まで画面をスクロールします。

## 組み込みプロファイル

Marinaraには10個の組み込みスタイルプロファイルが付属します。デフォルトは**Auto**です。どれでも編集でき、組み込みプロファイルはいつでも元の値に戻せます。

以下で使う用語を先に説明します。

- SDXLはStable Diffusion XLのことです。自分のコンピューターでも、クラウドサービス経由でも動かせる、広く使われているオープンな画像モデルです。
- チェックポイントとは、学習済みの画像モデルのファイル1つを指します。絵柄に応じて別々のチェックポイントをダウンロードして使い分けます。これらのプロファイルで名前が挙がっているのはIllustrious、Pony、NovelAIです。
- Danbooruは大規模なアニメ画像サイトです。「1girl, long hair, smile」のようにカンマで区切った短いタグが、アニメ系画像モデルへのプロンプトの定番になりました。

組み込みプロファイルは次のとおりです。

- **Off**: 共通のスタイルを何も足しません。プロンプトはほぼ書いたままの形で送られます。
- **Auto**: キャラクター、ゲーム、シーン、選択中の画像モデルから、一貫した見た目を推測します。これがデフォルトのプロファイルです。
- **Anime**: 線のきれいなキャラクターイラスト向けの、一般的なアニメ調タグです。
- **Danbooru / Illustrious**: Illustrious、Pony、NovelAIといったSDXLのアニメ系チェックポイントに向けたDanbooru風タグです。
- **Realistic SDXL**: SDXL系モデル向けの、自然文によるリアル寄りの指定です。
- **Photorealistic**: 肌、光、質感を自然に見せる写真調のプロンプトです。
- **Cinematic**: キービジュアル向けの、劇的な光と強い構図です。
- **Digital Painting**: コンセプトアート風の筆致と、計算された光の表現です。
- **Painterly Fantasy**: 柔らかい絵画調のファンタジーイラストです。
- **Z-Image Turbo Narrative**: 平易な文章をうまく読み取るZ-Image Turbo系モデル向けの、短い散文です。

## アプリ全体のスタイルの変更

グローバルのデフォルトプロファイルは、チャットや接続による上書きがない限り、生成されるすべての画像に適用されます。変更する手順は次のとおりです。

1. **Settings**を開き、**Generations**タブ、**Image Generation**、**Style Profiles**の順に進みます。
2. **Default style**ドロップダウンを開きます。
3. アプリ全体で使いたいプロファイルを選びます。

選択はすぐに保存されます。以降に生成する画像には、選んだプロファイルが適用されます。

## プロファイルの複製とカスタマイズ

組み込みプロファイルをそのまま編集することもできますが、**Clone**ボタンを使えば元のプロファイルを残したまま独自の版を作れます。プロファイルを作成してカスタマイズする手順は次のとおりです。

1. **Editing**ドロップダウンを開き、目的に近いプロファイルを選びます。
2. **Clone**をクリックします。Marinaraは複製を作って編集対象に切り替え、同時にその複製をアプリ全体のデフォルトスタイルにします。
3. **Name**欄を、あとで見分けやすい名前に変えます。
4. **Prompt grammar**を選びます(次のセクションで説明します)。
5. **Style text**に、目指す見た目を普通の文章で書きます。AIが画像プロンプトを書く場合(Illustrator、自撮り写真、Noodleがこれに当たります)、AIはStyle textをそのまま写さずに、その内容に従います。アバターなど、ほかの画像ではStyle textが書いたとおりに追加される場合があります。
6. **Positive tags**(含めたい語)と**Negative tags**(避けたい語)を追加します。
7. **Per-image tags**セクションを開き、画像の種類ごと(アバター、ポートレート、自撮り写真、背景、イラスト、スプライト)に追加のタグを設定します。
8. 手順2で、複製はアプリ全体のデフォルトになっています。この役割を別のプロファイルへ戻すには、**Default style**を開いて使いたいプロファイルを選びます。

プロファイルの管理には2つのボタンが使えます。

- **Reset**は組み込みプロファイルにだけ使えます。その組み込みプロファイルを元の値に戻します。
- **Delete**は自分で作ったプロファイルにだけ使え、プロファイルが2つ以上あるときだけ有効です。

## プロンプト文法のモード

**Prompt grammar**ドロップダウンでは、画像モデルがどんな形のプロンプトを好むかをMarinaraに伝えます。使っている画像モデルに合うモードを選んでください。モードは4つあります。

- **Hybrid**: 文章とタグを混ぜた形です。迷ったときに選べる無難な選択肢です。
- **Danbooru tags**: カンマ区切りの短いDanbooru風タグです。Illustrious、Pony、NovelAIなどアニメ系のSDXLチェックポイントに最適です。
- **Tags**: カンマ区切りの短いキーワードで、Danbooruの流儀には従いません。
- **Natural language**: 普通の文章です。DALL-EやZ-Image Turbo系モデルのように、散文を読み取れるモデルに向いています。

## Test bench

**Test bench**(テストベンチ)セクションでは、実際に画像を生成せずに、Marinaraが送信する内容をそのまま確認できます。Style Profilesエディターの中で開きます。使う手順は次のとおりです。

1. **Image kind**(画像の種類)を選びます(たとえばポートレートや背景)。
2. **Sample input**に、おおまかなプロンプトを入力します。
3. **Final positive prompt**と**Final negative prompt**の欄を読みます。

Test benchには、整理の内容についての短い注記も表示されます。何も変わらなかったときは「No cleanup needed for this sample.」と表示されます。プロンプトに手が入ったときは、重複した断片や置き場所の違う断片をいくつ整理したかが表示されます。

## Marinaraによるプロンプトの整理

画像のリクエストを送信する前に、Marinaraは有効なプロファイルを使ってプロンプトを組み立て直します。このとき、次の処理を行います。

- ほぼ重複しているタグ(同じ品質タグの繰り返しなど)を取り除きます。
- 「avoid text」「no watermark」のような単純な否定表現を、ネガティブプロンプト側へ移します。
- 背景、イラスト、自撮り写真の画像では、書いた言葉づかいをそのまま残します。ポートレート、アバター、スプライトの画像では、認識できる短い視覚タグまで内容を絞り込みます。
- 生成する画像の種類に合わせて、プロファイルの画像種類別タグを追加します。

## 整理の前後の例

**Danbooru / Illustrious**プロファイルを選び、**Image kind**をポートレートにして、**Sample input**に次のように入力したとします。

```
masterpiece, masterpiece, red-haired knight, no watermark
```

すると、Test benchの**Final positive prompt**には次のように表示されます。

```
detailed eyes, solo, upper body, portrait, looking at viewer, anime screencap, masterpiece, best quality, absurdres
```

ここでは3つのことが起きています。

- 「no watermark」がポジティブプロンプトから外れ、**Final negative prompt**へ移りました。整理の注記はこの変更を数えています。
- プロファイル自身のスタイルタグ、ポートレート用の画像種類別タグ、品質タグが追加されました。結果に出ている「masterpiece」は、入力した語ではなくプロファイル側のタグに由来します。
- 入力した語は絞り込まれました。ポートレート画像では、明確な視覚的手がかりとして認識できる断片だけが残ります。「red-haired knight」はそれに当たらないため、削除されました。

ポートレート、アバター、スプライトで被写体を表す語が消えてしまう場合は、画像の種類を**illustration**(イラスト)に変えてみてください。この種類では書いた言葉づかいがそのまま残ります。

## 優先順位: チャット、接続、グローバルの順

Marinaraは3つの場所からスタイルプロファイルを選べます。より限定的な指定が優先されます。順番は次のとおりです。

1. 現在のチャットまたはゲームに対して明示的に選んだプロファイル。
2. 画像接続に設定された**Style Profile**(接続エディターの**Local Image Defaults**の中)。
3. **Settings**で設定したグローバルの**Default style**。

**Local Image Defaults**セクションは、ローカルのStable Diffusion接続(AUTOMATIC1111 / SD Web UI、ComfyUI、NovelAI)でのみ表示されます。それ以外のプロバイダーでは、選択はそのままグローバルの**Default style**に委ねられます。接続ごとにプロファイルを設定するには、接続を開き、**Local Image Defaults**を展開して、**Style Profile**ドロップダウンでプロファイルを選びます。グローバルの選択に従わせたいときは**Use global default**のままにします。接続のモデル名から適切なプロファイルを推測できる場合は、そのプロファイルをワンクリックで適用する「Use ...」ボタンが表示されます。
