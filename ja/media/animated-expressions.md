# アニメーション表情

アニメーション表情とは、キャラクターの立ち絵スプライトとして使う、短くループするアニメーションです。スプライトとは、チャット中にMarinaraが表示するキャラクターの立ち絵です。通常の表情スプライトは、笑顔などの静止画です。アニメーション表情はその静止画の代わりに再生され、GIFとして保存されます。GIFは、短いアニメーションを自動でループ再生する画像ファイルです。

Marinaraはアニメーション表情を2段階で作ります。まず**Video Generation**(動画生成)のアカウントにその表情の短いクリップを依頼し、次にそのクリップを手元のコンピューターでループするGIFに変換します。保存したあとは、ほかのスプライトと同じように動作します。ダウンロードできる**Expression Engine**エージェントが、シーンがその感情を求めるときに表示します。[キャラクターのスプライト(表情と全身)](../characters/sprites.md)と[ダウンロードできるエージェント一覧](../agents/built-in-agents.md)を参照してください。

<a id="before-you-start"></a>

## 始める前に

必要なものは2つです。

1. 動画用のアカウント。追加方法は[シーン動画の生成](scene-video.md)を参照してください。
2. Marinaraを動かしているコンピューターのffmpeg。ffmpegは、クリップをGIFに変換する無料のメディアツールです。

ffmpegがない場合、生成はすぐに失敗し、次のメッセージが表示されます。

```text
Animated expression GIF conversion requires ffmpeg. Install ffmpeg and make it available on PATH, or set FFMPEG_PATH.
```

ffmpegをインストールしてシステムから見つけられるようにするか、環境変数`FFMPEG_PATH`にffmpegのプログラムのフルパスを設定してください。環境変数とは、サーバーの起動前に渡しておく設定のことです。

## アニメーション表情を生成する

静止画のスプライトと同じウィンドウを使います。

1. キャラクターの場合は**Character Editor**(キャラクターエディター)を、ペルソナの場合は**Persona Editor**(ペルソナエディター)を開きます。
2. **Sprites**タブを開き、**Facial Expressions**(表情)カテゴリーを開きます。
3. **Generate Sprite**(スプライトの生成)をクリックします。**Generate Sprites**ウィンドウが開きます。
4. **Generate animated portraits**(アニメーションするポートレートを生成)にチェックを入れます。ウィンドウがアニメーションモードに切り替わります。画像用の選択欄が動画用の選択欄に変わり、スプライトシート用のグリッド設定が消え、Marinaraは表情を1つずつ作るようになります。
5. 動画用のアカウントを選びます。
6. サービスがキャラクターの外見を把握できるように、**Appearance Description**(外見の説明)を入力します。
7. 生成する表情を選びます。
8. 表情が1つなら**Generate Animated Portrait**を、複数なら**Generate Animated Portraits**をクリックします。

生成中は「Generating animated portrait GIFs...」と表示されます。完了したら結果を確認し、保存ボタンをクリックしてキャラクターまたはペルソナに追加します。一部の表情が失敗しても、Marinaraは完成した分を残し、失敗した表情の名前を一覧にするので、それらをやり直せます。

アニメーション表情は1つずつ作られるため、静止画のスプライトより時間がかかります。まずは少数から始めてください。

**Settings → Generations → Overall Generations**(設定 → 生成 → 生成全般)の**Expose media prompts before sending**(送信前にメディアのプロンプトを表示)をオンにしていると、Marinaraがいったん止まり、各プロンプトをサービスへ送る前に読んで編集できます。

## 長さと縦横比

アニメーション表情はすべて9:16の縦長の立ち絵クリップで、これは変更できません。各クリップの長さを変えるには、**Settings → Generations**(設定 → 生成)を開き、**Video Generation**(動画生成)を探して**Animated expression length**を設定します。デフォルトは3秒です。範囲は1秒から8秒です。Marinaraは幅512ピクセルの小さなループGIFを保存します。クリップが短いほど、ファイルは小さくなり、ループも短くまとまります。

<a id="backgrounds-are-not-removed"></a>

## 背景は除去されない

静止画のスプライトは、背景を取り除いて、キャラクターがシーンの上に浮かんでいるように見せられます。アニメーション表情では、この背景の除去を行いません。アニメーションモードでは、**Prefer clean transparent-style background**(透過しやすいすっきりした背景を優先)のチェックボックスは、動画のプロンプトにヒントを1つ追加するだけです。その説明文には「GIF transparency is not guaranteed.」とあります。確認の段階でも、GIFの出力では背景の除去、シートの切り分け、フレームの切り抜きを省略すると示されます。アニメーション表情には、背景が見えたまま残ることがあります。すっきりした見た目にしたいときは、**Appearance Description**(外見の説明)で無地の背景を指定してください。

## トラブルシューティング

- **ffmpegに関するメッセージが出て生成に失敗する**: ffmpegをインストールするか、`FFMPEG_PATH`を設定してください。[始める前に](#before-you-start)を参照してください。
- **動画用のアカウントが見つからないと選択欄に表示される**: 先にアカウントを追加してください。[シーン動画の生成](scene-video.md)を参照してください。
- **Generate Spriteボタンが無効になっている**: 一部のAndroidやTermuxの環境など、デバイスによっては、Marinaraが画像ライブラリーを読み込めません。その場合は、アニメーション表情を含むすべてのスプライト生成がオフになります。
- **保存したGIFに背景が残っている**: これは想定どおりの動作です。[背景は除去されない](#backgrounds-are-not-removed)を参照してください。
