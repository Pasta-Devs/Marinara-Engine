# Marinaraがデータを保存する場所

このガイドでは、Marinara Engineがデータをコンピューターのどこに保存するのかを説明します。中心となるデータフォルダー、その中にある`storage`フォルダーとアセット用のフォルダー、そして保存したAPIキーを守る暗号化キーのファイルを取り上げます。

Marinara Engine(以下Marinara)は手元のコンピューターで動きます。保存したキャラクター、チャット、設定は、コンピューターの中だけに残ります。ただし返信を生成するときは、接続先のAIプロバイダーへチャットの内容が送られます。

## データフォルダー(DATA_DIR)

Marinaraで作ったものは、サーバーが動いているコンピューター上の1つのフォルダーにまとまって入ります。これがデータフォルダーです。その場所を指す環境変数の名前は`DATA_DIR`です。環境変数とは、アプリの外側でサーバーに設定する値のことです。アプリの**Settings**(設定)パネルの中にはありません。

デフォルトのデータフォルダーは、Marinaraがサーバーのファイルの隣に作る`data`という名前のフォルダーです。公式のDockerコンテナーでMarinaraを動かしている場合、データフォルダーはコンテナー内の`/app/data`です。

データフォルダーの場所がわからないときは、サーバーの起動ログを見てください。Marinaraは起動時に`[storage] DATA_DIR=`で始まる行を出力し、その後ろにデータフォルダーの完全なパスが続きます。

`DATA_DIR`を自分で設定すれば、データフォルダーを別の場所へ移せます。設定方法は[サーバー設定リファレンス](../CONFIGURATION.md)を参照してください。新しい`DATA_DIR`の値を反映するには、Marinaraの再起動が必要です。

## storageフォルダーとアセット用のフォルダー

データフォルダーの中で、データは`storage`フォルダーといくつかのアセット用フォルダーに分かれています。

`storage`フォルダーには、キャラクター、チャット、メッセージ、ロアブック、プリセット、接続などのテキストデータが入ります。Marinaraは各テーブルを所有者ごとの小さなファイルに分けて保存します。たとえば、1つのチャットのメッセージや1冊のロアブックのエントリーがそれぞれまとまるため、1項目を変更しても増え続ける共通JSONファイル全体を書き直しません。古いストレージから一度だけ移行するときは、元のテーブルファイルを`.pre-shard`という接尾辞で新しいフォルダーの隣に残します。

画像、音声、その他のメディアファイルは、内容ごとに名前を付けた専用のフォルダーに入ります。主なアセット用フォルダーは次のとおりです。

| フォルダー | 入っているもの |
| --- | --- |
| `avatars` | キャラクターとペルソナのアバター |
| `sprites` | キャラクターのスプライト |
| `backgrounds` | アップロードしたチャットの背景 |
| `gallery` | ギャラリーの画像 |
| `fonts` | 追加したカスタムフォント |
| `knowledge-sources` | 知識エージェント用にアップロードしたファイル |
| `game-assets` | Game Modeのアセット |
| `custom-emojis` | カスタム絵文字の画像 |
| `custom-stickers` | カスタムスタンプの画像 |

`storage`フォルダーの仕組みをより技術的に知りたい開発者は、[ファイルネイティブストレージ](../development/file-storage.md)を参照してください。

## 暗号化キーのファイル

Marinaraは保存したAPIキーを暗号化し、平文のままでは保存しません。この暗号化に使うキーは、データフォルダー内の`.encryption-key`というファイルに保存されます。

このファイルが重要になるのは、データを移動したり復元したりするときです。たとえば、データフォルダーを新しいコンピューターにコピーしたのに`.encryption-key`ファイルだけを置き忘れたとします。するとMarinaraは保存したAPIキーを復号できなくなり、入力し直すことになります。このファイルは必ずほかのデータと一緒に扱ってください。

高度な構成では、ファイルではなく`ENCRYPTION_KEY`環境変数でキーを渡すこともあります。この変数を使う場合は、その値を別途安全に保管してください。この構成ではコピーすべき`.encryption-key`ファイルはありません。詳しくは[サーバー設定リファレンス](../CONFIGURATION.md)を参照してください。

## Androidでのデータの場所

Androidでは、サーバーのデータフォルダーは通常、root権限がないと到達できないアプリ用のストレージに置かれます。そのため、フォルダーをそのままスマートフォンの外へコピーすることはできません。

Androidでデータのコピーを取るには、**Download Backup**(バックアップのダウンロード)ボタンを使います。**Settings**の**Advanced**タブにある**Backup & Export**セクションにあります。押すとデータを1つのzipファイルにまとめます。`.encryption-key`ファイルがあれば、それもzipに含まれます。スマートフォンからデータを保存する方法としては、これがいちばん確実です。

同じセクションでは、日次、週次、月次の自動アーカイブを1個から9999個まで、データフォルダー内の
`backups/`にローテーションしながら残せます。最新のものは`marinara-automatic-backup.zip`で、保持している古い自動アーカイブにはタイムスタンプが付きます。
この上限が効くのは自動バックアップだけです。大事なバックアップは、アプリのストレージの外にもコピーしておいてください。
アプリをアンインストールしたりリセットしたりすると、実データとローカルの自動バックアップの両方が消えることがあります。

各プラットフォームでのバックアップと復元の手順は、[Marinaraのバックアップと復元](backup-and-restore.md)で詳しく説明しています。
