# SillyTavernからのインポート

SillyTavernのデータをMarinara Engineに取り込みます。ファイルを1つずつインポートすることも、SillyTavernのフォルダー全体をスキャンしてまとめて取り込むこともできます。

## 引き継げるもの

| SillyTavernのデータ | Marinaraでの扱い |
| --------------------- | ---------------------------------------------------------------------------------------- |
| キャラクター | キャラクター |
| チャットとグループチャット | チャット |
| Presets | Presets(プロンプトのセクションとプリセットのサンプラー設定) |
| World Info | ロアブック(特定の言葉が出てきたときにAIが読むメモ) |
| 背景 | チャットの背景 |
| ペルソナ | ペルソナ(自分の代わりになるプロフィール) |
| 正規表現スクリプト | 正規表現スクリプト: 各カード専用のものと、`settings.json`にあるグローバルのもの(フォルダーのインポート時) |

## 単一ファイルの簡易インポート

1. **Settings → Imports**(設定 → インポート)を開きます。
2. **SillyTavern Import**で、ファイルの種類に合うボタンをクリックします。
3. ファイルを選びます。**キャラクターをインポート**、**プリセットをインポート**、**ロアブックをインポート**は、それぞれのパネルの**インポート**ボタンと同じウィンドウを開きます。選択肢も、引き継いだものと引き継がなかったものの報告も同じです。

| ボタン | ファイル |
| ------------------------------- | -------------------------------------------------------------------------------------- |
| **Import Character (JSON/PNG)** | `.json`または`.png`のキャラクターカード。 |
| **Import Chat (JSONL)** | `.jsonl`のチャット記録(1行に1件のJSONレコードを書く、SillyTavernがチャットを保存する形式)。 |
| **Import Preset (JSON)** | `.json`のプリセット。 |
| **Import Lorebook (JSON)** | `.json`のWorld Infoファイル。 |

正規表現スクリプトとは、テキストの検索と置換を行うルールです。[キャラクターカードのインポートとエクスポート](../characters/import-export.md)を参照してください。

キャラクターカードにロアブックが含まれている場合、キャラクターをインポートするウィンドウで、その扱いを選びます。**ロアブックをインポート**を選ぶと、再利用できるロアブックとして残します。**Skip lorebook**(ロアブックをスキップ)を選ぶと、キャラクターだけをインポートします。

**チャットをインポート(JSONL)**は、ファイルに別のモードが記録されていない限り、Roleplayのチャットを作成して開きます。作者の注記、ペルソナ、AIに見せないメッセージのうち、何を引き継いだかが短いメッセージで表示されます。

### チャット一覧からのチャットのインポート

チャット一覧の上部にあるインポートボタンも使えます。ツールチップは**Import SillyTavern or Marinara chat JSONL**(SillyTavernまたはMarinaraのチャットJSONLをインポート)です。動作は同じで、ファイルに記録されたモードでチャットを開き、モードの記録がなければRoleplayのチャットとして開きます。[チャットのエクスポートとインポート](../chats/export-import.md)を参照してください。

## SillyTavernフォルダーのインポート

始める前に: ウィザードは、サーバーのコンピューター上のファイルを読み取ります。SillyTavernが別のコンピューターにある場合は、先にそのフォルダー(SillyTavernをインストールしたフォルダー)をMarinaraのコンピューターにコピーしてください。Marinaraのコンピューターでは、ウィザードはそのまま使えます。別のデバイスから使う場合は、管理者用のシークレットを設定し、**Settings → Advanced → Admin Access**に入力してください。[Marinaraのバックアップと復元](backup-and-restore.md)と、[サーバー設定リファレンス](../CONFIGURATION.md)の「Privileged APIs (ADMIN_SECRET)」のセクションを参照してください。

1. **Settings → Imports → SillyTavern Import**を開きます。
2. **Import from SillyTavern Folder**をクリックします。
3. SillyTavernのフォルダーを選びます。メインフォルダーを選んでください。通常は`data/`または`public/`のフォルダーがあるフォルダーです。次のいずれかの方法を使います。
   - **Browse**をクリックして、フォルダーを選びます。
   - フォルダー選択画面がない場合(リモートサーバー)は、アプリ内蔵のフォルダーブラウザーが開きます。ここには、サーバーを動かしているユーザーのホームフォルダー内のフォルダーだけが表示されます。**Select This Folder**をクリックします。
   - **SillyTavernのフォルダーのパス**にパスを入力します。例: `/home/you/SillyTavern`。サーバーを動かしているユーザーのホームフォルダー内であれば、入力したパスを使えます。サーバーの`IMPORT_ALLOWED_ROOTS`設定がある場合は、代わりに、そこで指定されたフォルダーのどれかの中にある必要があります。
4. **Scan Folder**をクリックします。Marinaraが、カテゴリーごとに見つかった件数を表示します。
5. **Choose exactly what to import**で、取り込みたい項目にチェックを入れます。カテゴリーごとに**All**と**None**のボタンがあり、個々の項目には**Show**と**Hide**のトグルがあります。
6. **Import Selected**をクリックします。進行状況バーに、処理中の項目とカテゴリーごとの件数が表示されます。
7. **インポートが完了しました!**と表示されたら、カテゴリーごとの件数を確認し、**完了**をクリックします。件数の下には、作者の注記とペルソナを引き継いだチャットの数、こちらに対応するペルソナがなかったSillyTavernのユーザー名、プリセットでのWorld Infoの配置、引き継がれなかったプリセット設定が短い一覧で表示されます。

**すでにあるものはスキップ**(デフォルトでオン)は、以前にフォルダーからインポートしたものでも、1ファイルずつインポートしたものでも、すでにあるキャラクター、チャット、ペルソナを除外します。SillyTavernのペルソナと同じ名前のペルソナがすでにある場合、コピーは作らず、そのチャットを既存のペルソナに関連付けます。この変更より前に1ファイルずつインポートしたチャットは認識されず、もう一度取り込まれます。

ほとんどの項目は、最初から選択されています。SillyTavern標準のプリセット(`deterministic`、`neutral`、`universal-*`など)は、Marinaraがチェックを外したままにし、バナーでそのことを知らせます。コピーが必要でない限り、チェックは外したままにしてください。

スキャンでキャラクターが見つかると、さらに2つの設定が表示されます。

**Imported character tags**(デフォルトは**All tags**)

- **All tags**は、元のタグを残します。
- **No tags**は、タグを取り込みません。
- **Existing only**は、すでにあるタグだけを残します。

**Imported regex scripts**(デフォルトは**Character only**)

- **Character only**は、スクリプトを各キャラクターに適用します。
- **Global**は**Presets → Regexes**に追加します。そこでは、複数のチャットで動くスクリプトを管理できます。[正規表現スクリプト](../extending/regex-scripts.md#manage-your-scripts)を参照してください。

うまくいかなかった場合:

- 「Could not find SillyTavern data directory.」は、Marinaraがそのフォルダーを読み取れないという意味です。SillyTavernのメインフォルダーを選んでください。
- 「Marinara can only read folders inside your home folder」は、そのフォルダーがサーバーを動かしているユーザーのホームフォルダーの外にあるという意味です。SillyTavernのフォルダーをホームフォルダー内に移すか、サーバーを運用している人に`IMPORT_ALLOWED_ROOTS`設定でその場所を許可してもらってください。この設定がある場合は、選んだフォルダーであっても、指定されたフォルダーのどれかの中にある必要があります。[サーバー設定リファレンス](../CONFIGURATION.md)を参照してください。
- ホームフォルダーの外のパスを入力して**参照**を使うと、代わりにホームフォルダーでフォルダーブラウザーが開きます。
- 項目が1つ失敗した場合、Marinaraはその項目を飛ばして処理を続け、最後のステップの警告に`Character "Foo": error message`のような形で一覧表示します。

## データの扱い

- 1つのキャラクターに属するチャットファイルは、1つのチャットの分岐としてインポートされます。分岐とは、チャットのコピーを別々に続けるものです。個別のインポートと同じく、各チャットにはSillyTavernのファイル名が付きます。ファイル名が「New Chat」のままなら、キャラクターの名前を使います。
- グループチャットは、**個別**モードのRoleplayチャットとしてインポートされます。各キャラクターはSillyTavernでの発言順に返信します。
- SillyTavernでAIに見せない設定だったメッセージは、その設定を保ちます。
- インポートした項目には、インポートした日付ではなく、元のファイルの最終更新日が付きます。各チャットメッセージも、SillyTavernで保存された日付を保持します。
- チャットの**Author's Note**(作者のメモ)は、深さとともに引き継がれます。SillyTavernで別の頻度、位置、ロールを使っていた場合も、Marinaraは毎回の返信でその深さに追加し、インポート結果にその旨を表示します。SillyTavernでオフになっていたメモは、オフのままです。
- チャットはSillyTavernで使っていたペルソナに関連付けられます。固定されていたペルソナがあればそれを使い、なければチャットのユーザーと同名のペルソナを使います。ペルソナも同時にインポートするか、先に同じ名前のペルソナを作成してください。一致するものがない場合、チャットにはペルソナが付かず、インポート結果に見つからなかったペルソナの名前が表示されます。
- プリセットはSillyTavernの2つのWorld Infoの配置を保ちます。**World Info (before)**と**World Info (after)**は別々のセクションになるため、キャラクターの後に設定したエントリーは引き続きその後に入ります。片方をオフにしたプリセットは、SillyTavernと同じく、そのエントリーを含めません。World Infoの配置が1か所だけのプリセットには、両方を送信する**World Info**セクションが1つ作られます。この変更より前にインポートしたプリセットには、**World Info**セクションが1つあります。修正するには、再度インポートするか、セクション内の希望する位置に**Lorebook Marker (Before)**(ロアブックマーカー、前)と**Lorebook Marker (After)**(ロアブックマーカー、後)を追加し、古い**World Info**セクションを削除してください。
- SillyTavernの作者の注記の前後に置かれたWorld Infoエントリーは、作者の注記がある深さ4にsystemとして挿入されます(注記の後のエントリーは、注記の前のエントリーの直後に入ります)。メッセージ例の前後に置かれたエントリーは、キャラクター定義の後に入ります。移動した件数はインポート時に表示されます。
- プリセットは、温度、Top P、Top K、Min P、頻度ペナルティー、存在ペナルティー、推論の強度のサンプラー設定を引き継ぎます。これらはそのプリセットを使うチャットの初期値になり、接続やチャット独自の値があれば、そちらが優先されます。最大応答長とコンテキストサイズは接続の設定のままです。Top Aと反復ペナルティーは対応する設定がないため、取り込まれません。

## 引き継がれないもの

ウィザードが読み取るのは、最初の表にあるカテゴリーだけです。アプリ全体の設定や接続プロファイルなど、ほかのSillyTavernのデータはインポートされません。フォルダーのインポート結果の**引き継がなかったもの**には、対応する機能がこちらにないものとして、Quick Replyセット、instructテンプレート、コンテキストテンプレート、システムプロンプトの検出件数が表示されます。この修正より前にインポートしたチャットには、メッセージの日付としてインポート日時が付いていました。修正するには、そのチャットを削除してファイルを再度インポートしてください(フォルダーのインポートでは**すでにあるものはスキップ**のチェックを外します)。
