# データの消去とリセット

このガイドでは、**Danger Zone**(危険な操作)を使ってMarinara Engineのデータを完全に削除する方法を説明します。一部のカテゴリーだけを消すことも、すべてを消し去ることもできます。取り消しはできないので、先に警告を読んでください。

## Danger Zoneの場所

データを消去する機能は1か所にまとまっています。

1. **Settings**(設定)を開きます。
2. **Advanced**タブに移動します。
3. 一番下にある**Danger Zone**セクションまでスクロールします。

**Danger Zone**の説明には「Permanently clear selected categories of local data. Professor Mari is always preserved.」と書かれています。

アプリを動かしているコンピューター以外のデバイスからMarinaraを使っている場合、データの消去には管理者権限が必要です。設定方法は[リモートアクセス](../REMOTE_ACCESS.md)を参照してください。

## 消去する前にバックアップを取る

データの消去は取り消せません。ごみ箱にも残りません。確定した時点でデータは消えます。

気が変わったときに戻せるよう、先にバックアップを取っておきます。[Marinaraのバックアップと復元](backup-and-restore.md)を参照してください。

## 8つのデータカテゴリー

**Danger Zone**には8つのカテゴリーのチェックリストが並びます。それぞれが独立した範囲で、1つにチェックを入れてもほかのカテゴリーには影響しません。

| カテゴリー | 消去される内容 |
|---|---|
| **Chats & Messages** | チャット、フォルダー、メッセージ、シーンとOOCのデータ、チャットの実行時の状態。 |
| **Characters** | キャラクターとキャラクターグループ。Professor Mariは常に残ります。 |
| **Personas** | ペルソナとペルソナグループ。 |
| **Lorebooks** | ロアブックとロアブックのエントリー。 |
| **Presets** | プロンプトプリセット、グループ、セクション、変数。 |
| **Connections** | APIの接続とモデルのエンドポイント。 |
| **Automation & Addons** | エージェント、ツール、正規表現スクリプト、同期したテーマ、自動化の状態。 |
| **Media & Assets** | 背景、アバター、スプライト、ギャラリーの項目、フォント、知識ソースのファイル。 |

データベースの記録以外まで削除するカテゴリーもあります。**Chats & Messages**は、ディスク上のギャラリーフォルダー全体とシーン動画のファイルもすべて削除します。ここにはキャラクターとペルソナのギャラリー画像も含まれるので、**Characters**や**Personas**にチェックを入れていなくても消えます。**Media & Assets**は、背景、アバター、スプライト、ギャラリー、シーン動画のファイル、フォント、知識ソースのファイルについて、ディスク上のフォルダーを削除します。**Connections**は、保存済みの音声合成(TTS)と音声認識(Speech to Text)の設定も消去します。これは設定が接続に紐づいているためです。

## 選んだカテゴリーだけを消去する

一部のデータだけを消して、残りは保持したいときに使います。

1. 削除したいカテゴリーのチェックボックスにチェックを入れます。
2. すべてのチェックボックスをまとめて切り替えるには、**Select All**(すべて選択)ボタンを使います。すべてにチェックが入ると、同じボタンが**Clear Selection**(選択を解除)に変わり、一括で外せます。
3. **Clear Selected Data**(選択したデータを消去)をクリックします。このボタンは、カテゴリーが1つもチェックされていない間は無効のままです。
4. 警告のウィンドウが表示されます。選んだカテゴリーの数が示され、取り消しができないことが改めて伝えられます。
5. やめるときは**Cancel**、削除するときは**Confirm Delete**をクリックします。**Confirm Delete**をクリックするまで、何も削除されません。

消去に成功すると、確認のメッセージが表示されます。選択したデータを消去し、実行時のキャッシュを直ちにリセットしたことを知らせる内容です。

## すべてを消去する

8つのカテゴリーを一度にすべて消すときに使います。

1. **Clear All Data**(すべてのデータを消去)をクリックします。事前にチェックボックスを選ぶ必要はありません。
2. 警告のウィンドウに「Delete all supported data categories except Professor Mari? There is no undo.」と表示されます。
3. やめるときは**Cancel**、すべて削除するときは**Confirm Delete**をクリックします。

すべてのチェックボックスにチェックを入れてまとめて消去した場合と、結果は同じです。

## Professor Mariは必ず残る

Professor Mariはアプリに組み込まれた案内役のキャラクターです。この機能でProfessor Mariが削除されることはありません。**Characters**カテゴリーを消去しても、**Clear All Data**を使っても、Professor Mariはそのまま残ります。**Danger Zone**から削除することはできません。
