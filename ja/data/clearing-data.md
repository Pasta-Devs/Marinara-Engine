# データの消去とリセット

**Danger Zone**(危険な操作)を使って、データの一部またはすべてを完全に削除します。取り消しはできません。

チャット1つやキャラクター1つだけを削除するには、それぞれの削除ボタンを使ってください。[チャットの管理](../chats/managing-chats.md)と[キャラクターの作成と編集](../characters/creating-and-editing-characters.md)を参照してください。

**始める前に:** バックアップを取ってください。ごみ箱はありません。[Marinaraのバックアップと復元](backup-and-restore.md)を参照してください。別のデバイスからMarinaraを使っている場合は、管理者用のシークレットも必要です。[リモートアクセス](../REMOTE_ACCESS.md)を参照してください。

## 一部のカテゴリーを消去する

1. **Settings → Advanced**(設定 → 詳細設定)を開き、**Danger Zone**までスクロールします。
2. 削除したいカテゴリーにチェックを入れます。**Select All**を使うと、すべてのボックスにチェックが入ります。すべてにチェックが入ると、同じボタンが**Clear Selection**に変わり、チェックを外します。
3. **Clear Selected Data**をクリックします。カテゴリーにチェックを入れるまで、このボタンは無効のままです。
4. 警告を読みます。選んだカテゴリーの数が表示されます。
5. **Confirm Delete**をクリックします。やめるときは**Cancel**をクリックします。確定するまで、何も削除されません。

成功すると、選択したデータを消去したというメッセージが表示されます。リクエストが失敗すると、エラーメッセージ(「Failed to clear selected data.」)が表示されます。一部のデータはすでに消去されている可能性があるので、残っているものを確認してください。管理者アクセスがあるかどうかも確認してください。

## すべてを消去する

1. **Danger Zone**で**Clear All Data**をクリックします。ボックスにチェックを入れる必要はありません。
2. 警告に「Delete all supported data categories except Professor Mari? There is no undo.」と表示されます。
3. **Confirm Delete**をクリックします。やめるときは**Cancel**をクリックします。

8つのボックスすべてにチェックを入れた場合と同じ結果になります。

## 8つのデータカテゴリー

表の下に書いたギャラリーフォルダーの例外を除き、各カテゴリーが削除するのは、その行に書いたものだけです。

| カテゴリー | 削除されるもの |
| --- | --- |
| **Chats & Messages** | すべてのチャットとその内容、`gallery`フォルダー全体、ゲームのシーン動画。 |
| **Characters** | Professor Mariを除くすべてのキャラクターとグループ、およびそのアバター。 |
| **Personas** | すべてのペルソナとグループ、およびそのアバター。 |
| **Lorebooks** | すべてのロアブック、エントリー、フォルダー。 |
| **Presets** | 組み込みの標準プリセットを除く、すべてのプロンプトプリセットとプリセットのフォルダー。 |
| **Connections** | 保存済みのすべてのアカウント、およびそれに紐づくモデルの選択と音声の設定。 |
| **Automation & Addons** | すべてのエージェント設定、カスタムツール、正規表現スクリプト、同期したテーマ。Personal ExtensionsとExternal Extensionsは対象外。 |
| **Media & Assets** | 背景、アバター、スプライト、ギャラリー、シーン動画、フォント、知識ソースのファイル。 |

詳しい内容は次のとおりです。

- **Chats & Messages**は、スワイプ(1つのメッセージに残した複数の回答)、記憶、エージェントの結果、ゲームの状態、チャットの画像も削除します。
- **Characters**と**Personas**は、2Dと3Dのアバターモデルも削除します。
- **Presets**は、そのグループ、セクション、変数も削除します。ほかのプリセットがデフォルトだった場合は、標準プリセットがデフォルトになります。
- **Connections**は、音声合成と音声認識の設定、機能ごとに選んだモデル、**3D Avatars**のページに保存したTripoのAPIキーも消去します。
- **Automation & Addons**は、エージェントの結果、エージェントの記憶、エージェントのフォルダー、エージェントのHomeウィジェットも削除します。
- **Media & Assets**は、アセットの一覧とチャットの画像も削除します。
- 知識ソースのファイルとは、知識エージェント用にアップロードしたファイルです。同期したテーマとは、Marinaraに保存したカスタムテーマです。

カテゴリー名の範囲を超えてファイルに及ぶものもあります。**Chats & Messages**は、**Characters**や**Personas**にチェックを入れていなくても、キャラクターとペルソナのギャラリー画像を含む`gallery`フォルダー全体を削除します。

消去しても、ほかの設定、`backups/`フォルダー、`.encryption-key`ファイルには影響しません。Personal Extensions、Game Modeのアセット、カスタム絵文字とスタンプ、自分で設定した通知音、ロアブック、プリセット、エージェント、アカウントの画像、長期記憶のファイルも残ります。[Marinaraがデータを保存する場所](where-data-is-stored.md)を参照してください。

## Professor Mariは残る

Professor Mariは、Homeの画面にある組み込みのアシスタントです。**Danger Zone**は、**Clear All Data**を使っても、Professor Mariを削除しません。
