# 戦闘エンカウント(Roleplay)

このガイドでは、Roleplayモードの戦闘エンカウントを説明します。**Combat**(戦闘)エージェントをオンにして戦闘を始め、**Encounter**ウィンドウで戦う流れがわかります。Game Modeの戦闘との違いも取り上げます。

戦闘エンカウントはRoleplayの任意機能です。オンにすると、体力バー、敵とパーティーの一覧、戦闘ログを備えたターン制の戦闘画面がシーンに加わります。使わないままでも、ロールプレイのチャットはこれまでどおり動きます。

## Combatエージェントを有効にする

エージェントとは、メッセージの生成中に自動で動く補助機能です。**Combat**エージェントは、Roleplayのチャットに戦闘機能を追加します。デフォルトではオフなので、チャットごとにオンにします。

1. 戦闘を追加したいチャットを開きます。
2. **Chat Settings**(チャット設定)を開きます(チャット内の**Chat Settings**ボタンで、移動していなければ右上にあります)。
3. **Agents**(エージェント)のセクションを開きます。
4. **Enable Agents**(エージェントを有効にする)がオフなら、オンにします。
5. チャットに**Combat**エージェントを追加します。

これでメッセージ入力欄の上にある操作列に、**Encounter**(エンカウント)ボタン(交差した剣のアイコン)が現れます。ツールチップには**Start Combat Encounter**と表示されます。このボタンが見当たらないときは、そのチャットで**Combat**エージェントが動いていません。

**Agents**パネルの詳しい使い方とエージェントの仕組みは、[エージェント: チャットを支えるAIヘルパー](../agents/agents-overview.md)を参照してください。

## エンカウントを始める

**Encounter**ボタンをクリックすると、設定用のウィンドウが開きます。タイトルは**Configure Combat Narrative**です。ここでは、戦闘中と戦闘後にAIが使う文体を決めます。

設定ウィンドウには、2つの文体グループがあります。

- **Combat Narration**: 戦闘の最中に使う文体です。
- **Summary Narration**: 戦闘が終わったときにチャットへ書き込まれる要約の文体です。

どちらのグループにも、同じ4つの設定があります。

- 時制: **Present Tense**(現在形)または**Past Tense**(過去形)。
- 人称: **First Person**(一人称)、**Second Person**(二人称)、**Third Person**(三人称)。
- 語り: **Omniscient**(すべてを知る語り手)または**Limited**(1人のキャラクターが知ることだけを語る)。
- 視点の入力欄: 誰の目を通してシーンを語るかを入力します。空のままにすると、中立的な語り口になります。

文体グループの下には、任意で選べる**Spellbook**(呪文書)ドロップダウンがあります。呪文書とは、その戦闘で使える呪文と能力をまとめた特別なロアブック(世界の設定をまとめたエントリー集)です。これを指定しておくと、キャラクターが何を唱えられるかをAIが把握できます。呪文書を使わないときは**None**のままにします。

準備ができたら、**Begin Combat**をクリックします。戦闘を始めずに閉じるときは**Cancel**をクリックします。

**Begin Combat**をクリックすると、AIが戦闘を組み立てる間、「Initializing combat encounter...」と表示されます。ここで敵、パーティー、それぞれの攻撃手段と持ち物が作られます。数秒かかることがあります。

## エンカウントを進める(Encounterウィンドウ)

戦闘画面全体(**Encounter**ウィンドウ)のタイトルは**Combat Encounter**です。次の要素で構成されています。

- **Enemies**(敵): 敵カードを並べた領域です。各カードには体力バーと、かかっている状態異常が表示されます。
- **Party**(パーティー): 自分の側の面々です。自分のキャラクターには**(You)**が付きます。
- **Combat Log**(戦闘ログ): 各ターンに起きたことの記録です。
- **Your Actions**(自分の行動): 自分のターンに使うボタンです。

**Your Actions**では、次の操作ができます。

- **Attacks**から攻撃を1つ選びます。
- **Items**から持ち物を1つ使います。
- **Custom Action**の欄に自由な行動を入力して送信します。ボタンにない行動はこちらを使います。たとえば「衛兵の目に砂を蹴り込む」といった行動です。

攻撃や持ち物に対象が必要な場合は、**Select Target**のウィンドウが開きます。敵か味方を1体選ぶか、敵全体を同時に攻撃する範囲攻撃なら**All Enemies**を選びます。範囲攻撃しかできない行動では、単体の選択は省かれます。

AIがターンを処理している間は「Processing action...」と表示され、ボタンは操作できません。ターンが終わると、また押せるようになります。

AIがアプリで解釈できないデータを返した場合は、画面が壊れる代わりに**Combat Error**の画面が出ます。その画面の**Close Encounter**をクリックすると、安全に戦闘から抜けられます。

## エンカウントを終える

戦闘を途中で終える方法は2つあり、これに加えてどちらかが勝ったときの自然な終了があります。

- 上部バーの**Conclude**をクリックすると、戦闘を途中で終えます。先に確認のウィンドウが出ます。その後、アプリがチャットに戦闘の要約を書き込みます。
- 上部バーの**X**ボタンをクリックすると、戦闘を破棄して閉じます。先に**End Combat**というタイトルの確認ウィンドウが出ます。この場合、要約は書き込まれません。

戦闘が自然に終わると、結果のバナーとして**VICTORY**、**DEFEAT**、**FLED**、**INTERRUPTED**のいずれかが表示されます。続いてアプリが、選んだ**Summary Narration**の文体で戦闘の要約メッセージをチャットに書き込みます。要約ができたら、**Close Combat Window**をクリックしてシーンに戻ります。

要約の生成に失敗した場合、ボタンの表示は**Close Anyway**に変わります。これをクリックすると、要約なしでシーンに戻ります。

## Game Modeの戦闘との違い

戦闘エンカウントは、Roleplayモード向けの軽量で独立した戦闘の仕組みです。Game Modeには、専用の戦闘システムが最初から組み込まれています。

主な違いは次のとおりです。

- Roleplayのエンカウントは、**Encounter**ボタンで自分から始めます。Game Modeでは、物語の流れに応じてAIのゲームマスター(GM)が戦闘を始めます。
- Roleplayの戦闘には**Combat**エージェントが必要です。Game Modeの戦闘は**Combat**エージェントを使わず、なくても動きます。
- 2つの仕組みは別々の戦闘画面を使い、データを共有しません。

Game Modeの戦闘システムについては、[Game Mode: 戦闘](../game/combat.md)を参照してください。
