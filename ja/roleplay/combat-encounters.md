# 戦闘エンカウント(Roleplay)

戦闘エンカウントは、Roleplayのシーンに、体力バー、敵とパーティーの一覧、戦闘ログを備えたターン制の戦闘画面を加えます。任意の機能です。使わないチャットは、これまでどおり動きます。Game Modeには、これとは別の独自の戦闘があります。[Game Mode: 戦闘](../game/combat.md)を参照してください。

## 戦闘をオンにする

エージェントとは、返信と並行して動く補助機能です。**Combat**(戦闘)エージェントは、戦闘機能を追加します。デフォルトではオフなので、チャットごとにオンにします。

1. チャットを開きます。チャット内のスライダーボタンで**Chat Settings**(チャット設定)を開きます。
2. **Agents**(エージェント)に移動します。
3. **Enable Agents**(エージェントを有効にする)がオフなら、オンにします。
4. スイッチの下にある一覧から**Combat**エージェントを追加します。

これでメッセージ入力欄の上に、**Encounter**(エンカウント)ボタン(交差した剣)が表示されます。ツールチップには**Start Combat Encounter**と表示されます。

うまくいかなかった場合: ボタンがないときは、このチャットで**Combat**エージェントが動いていません。エージェントの仕組みは[エージェント: チャットを支えるAIヘルパー](../agents/agents-overview.md)を参照してください。

## エンカウントを始める

1. **Encounter**をクリックします。**Configure Combat Narrative**のウィンドウが開きます。ここでは、AIが使う文体を決めます。
2. **Combat Narration**(戦闘の最中)と**Summary Narration**(戦闘が終わったときにチャットへ書き込まれる要約)の文体を選びます。どちらのグループにも、同じ4つの設定があります(下記を参照)。デフォルトのままでも使えるので、すぐに**Begin Combat**をクリックしてもかまいません。
3. 任意: **Spellbook**(呪文書)を選びます。呪文書とは、その戦闘で使える呪文と能力をまとめたロアブック(世界についての事実を保存したまとまり)です。使わない場合は**None**のままにします。
4. **Begin Combat**をクリックします。戦闘をせずにウィンドウを閉じるには、**Cancel**をクリックします。

AIが敵、自分のパーティー、それぞれの攻撃手段と持ち物を作る間、「Initializing combat encounter...」と表示されます。数秒かかることがあります。

| 文体の設定 | 選択肢 |
| --- | --- |
| 時制 | **Present Tense**(現在形)、**Past Tense**(過去形) |
| 人称 | **First Person**(一人称)、**Second Person**(二人称)、**Third Person**(三人称) |
| 語り | **Omniscient**(全知): すべてを知っている語りです。**Limited**(限定): 1人のキャラクターが知っていることだけを知っている語りです。 |
| 視点 | 誰の目を通してシーンを語るかを入力する欄です。中立的な語り手にするには、空欄のままにします。 |

## 自分のターンを進める

**Combat Encounter**の画面は、4つの部分でできています。

- **Enemies**(敵): 体力バーと状態異常を表示するカードです。
- **Party**(パーティー): 自分の側です。自分のキャラクターには**(You)**が付きます。
- **Combat Log**(戦闘ログ): 各ターンの記録です。
- **Your Actions**(自分の行動): 自分のボタンです。

自分のターンでは、**Attacks**(攻撃)から攻撃を選ぶか、**Items**(アイテム)から持ち物を使うか、**Custom Action**(自由行動)に自由な行動を入力して送信します。たとえば「衛兵の目に砂を蹴り込む」のような行動です。

行動に対象が必要なときは、**Select Target**(対象の選択)が開きます。敵か味方を1体選ぶか、範囲攻撃なら**All Enemies**(敵全体)を選びます。範囲攻撃だけの行動では、この手順は省かれます。

AIがターンを処理している間は「Processing action...」と表示され、ボタンはロックされます。ターンが終わると、ロックが解除されます。

うまくいかなかった場合: AIがアプリで読み取れないデータを返すと、**Combat Error**の画面が表示されます。**Close Encounter**をクリックして安全に戦闘から抜け、新しいエンカウントを始めてください。

## エンカウントを終える

- 上部バーの**Conclude**で、戦闘を途中で終えます。確認のウィンドウが出たあと、戦闘の要約がチャットに書き込まれます。
- 上部バーの**X**は、**End Combat**というタイトルの確認ウィンドウのあとで、戦闘を破棄して閉じます。要約は書き込まれません。
- どちらかの側が勝つと、バナーに**VICTORY**、**DEFEAT**、**FLED**、**INTERRUPTED**のいずれかが表示されます。選んだ**Summary Narration**の文体で、要約がチャットに書き込まれます。要約ができたら、**Close Combat Window**をクリックします。

要約に失敗した場合、ボタンの表示は**Close Anyway**になります。これをクリックすると、要約なしでシーンに戻ります。

## Game Modeの戦闘との違い

- Roleplayのエンカウントは、**Encounter**で自分から始めます。Game Modeでは、物語の流れに応じてGame Masterが戦闘を始めます。
- Roleplayの戦闘には**Combat**エージェントが必要です。Game Modeの戦闘には必要ありません。
- 2つの仕組みは、別々の戦闘画面を使います。
