# Roleplay HUDとトラッカー

このガイドでは、Roleplay HUDと、そこに並ぶ小さなトラッカーウィジェットを説明します。値を編集して固定する方法と、より大きな**Tracker Panel**(トラッカーパネル)の使い方がわかります。対象はMarinara EngineのRoleplayモードです。

## HUDとは

HUD(heads-up display)は、チャット画面の上部に並ぶ小さなアイコンウィジェットの列です。各ウィジェットは、時刻、ステータス、その場にいるキャラクターなど、物語の現在の状態を1つずつ表示します。物語が進むと、Marinaraがこれらの値を自動で最新の内容に保ちます。

値の供給元はトラッカーエージェントです。エージェントとは、裏側で動く小さなAIの助け手を指します。各トラッカーエージェントは物語を見張り、メッセージのたびにHUDの担当部分を更新します。指示を出す必要はありません。

ウィジェットは、対応するトラッカーエージェントがそのチャットでオンになっているときだけ表示します。エージェントのオンとオフは**Chat Settings**(チャット設定)の**Agents**セクションで切り替えます。トラッカーエージェントが1つもオンでない場合、HUDには**Agents & Actions**(エージェントとアクション)ボタンだけが並び、ウィジェットは表示しません。

## HUDのウィジェット

トラッカーウィジェットは7つあります。表示するには、それぞれ対応するエージェントを有効にする必要があります。

| ウィジェット           | 必要なエージェント | 表示する内容                                                                     |
| ---------------------- | ----------------- | -------------------------------------------------------------------------------- |
| **World State**        | World State       | 場所、日付、時刻、天候、気温、および自分で追加した世界の項目                     |
| **Persona Stats**      | Persona Stats     | ペルソナのステータスバーと、状態を示す1行                                        |
| **Present Characters** | Character Tracker | シーンにいるキャラクターと、その気分、外見、キャラクターごとの独自項目           |
| **Inventory**          | Persona Stats     | 持ち物と、その個数                                                               |
| **Inventory Tracker**  | Inventory Tracker | 通貨、装備中の装具、持ち歩いている品物を分けた一覧                               |
| **Active Quests**      | Quest Tracker     | 現在の目標                                                                       |
| **Custom Tracker**     | Custom Tracker    | カウンターや通貨など、自分で名前を付けた項目                                     |

**Inventory**ウィジェットを動かしているのは、**Persona Stats**ウィジェットと同じ**Persona Stats**エージェントです。**Persona Stats**をオンにすれば、両方がそろいます。

専用の**Inventory Tracker**は、Persona Statsの持ち物とは別のものです。名前と個数だけの簡潔な項目を**Currencies**、**Equipped**、**Inventory**の3つのグループで管理し、装備中の装具が持ち物の側にも重ねて並ぶことを防ぎます。

項目はそれぞれ小さなピル型で表示されます。ピルはパネルの幅に沿って並び、収まらない分は次の行に折り返すので、持ち物が増えても縦に長く伸びず読みやすいままです。個数は2以上のときだけ名前のうしろに`×4`の形で表示され、1つだけの品物は名前のみになります。パネルが狭いときは、ピルが1行に1つずつ縦に並びます。

現在1になっている個数を変えたいときは、追加モードかロックモードをオンにしてください。どちらでも、すべての項目に個数の入力欄が表示されます。

**Present Characters**ウィジェットには、キャラクターの絵文字が最大3つ並び、残りは「+N」という数で表示します。**Inventory**と**Custom Tracker**のウィジェットは、エントリーを1つずつ順番に切り替えて表示します。

## ポップオーバーでの値の編集

ウィジェットをクリックすると、そのポップオーバーが開きます。ポップオーバーとは、浮かんで表示される小さなパネルです。中の項目はすべて編集できるので、AIが取り違えた値をその場で直せます。編集内容はすぐに保存します。

ポップオーバーごとに編集できる内容は次のとおりです。

- **World State**: **Location**、**Date**、**Time**、**Weather**、**Temperature**と、独自に追加した世界の項目の行。
- **Persona Stats**: **Status**の行と、現在値と最大値を持つ名前付きのステータスバー。バーは追加も削除もできます。
- **Present Characters**: キャラクターの追加と削除、および各キャラクターの絵文字、名前、**Mood**、**Look**、**Outfit**、**Thinks**(心の中の思考)、独自項目の値の編集。キャラクターごとにアバターをアップロードできます。**Auto**ボタンを押すと「Auto-generate avatars: ON」と「Auto-generate avatars: OFF」が切り替わります。
- **Inventory**: アイテムの追加と削除、および各アイテムの名前と個数の編集。
- **Inventory Tracker**: **Currencies**、**Equipped**、**Inventory**の各グループで項目を追加・削除し、それぞれの名前や個数を編集できます。品物をグループ間で移す操作はまだ1回では行えないため、一方のグループから削除して、もう一方に追加してください。
- **Active Quests**: クエストの追加と削除。クエストごとに、完了のチェックボックスが付いた名前付きの目標を持ちます。
- **Custom Tracker**: 名前と値の項目の追加、削除、編集。

## ロックモード

トラッカーエージェントは、ターンが進むたびにHUDの値を上書きします。ふだんは便利ですが、ある値が何度も間違った方向にずれてしまい、手作業で固定したいときもあります。そのための機能がロックモードです。

項目をロックすると、次にトラッカーが自動で動いてもその項目には手を触れません。ロックした項目には印が付くので、ひと目で見分けられます。

項目をロックする手順は次のとおりです。

1. ウィジェットのポップオーバーを開きます。
2. ポップオーバー上部にあるロックのトグルをクリックします。ツールチップには**Enter lock mode**と表示します。
3. 編集できる値の横に、小さなロックボタンが表示されます。
4. 固定したい値の横のロックボタンをクリックします。ツールチップには**Lock field**と表示します。

解除するときは同じボタンをもう一度クリックします(ツールチップは**Unlock field**)。ロックモードを抜けるには、上部のトグルをもう一度クリックします(ツールチップは**Exit lock mode**)。ロックモードはHUD全体で共通なので、どれか1つのポップオーバーでオンにすれば、すべての場所にロックボタンが表示されます。

## トラッカーの再実行

次のメッセージを待たずに、トラッカーを今すぐ更新させることもできます。

各ポップオーバーの中には、小さな更新ボタン(円形の矢印)があります。これをクリックすると、そのトラッカーだけを直近のターンに対して実行し直します。ツールチップにはトラッカーの名前が入り、たとえば**Re-run world state tracker only**や**Re-run quest tracker only**と表示します。

**Chat Settings → Agents**の**Manual Trackers**をオンにすると、有効なトラッカーがすべて手動操作に切り替わります。このスイッチはオフのままにして、**Individual tracker schedule**で選んだエージェントだけを手動にすることもできます。手動のトラッカーが1つでもあると、HUDの列に更新ボタンが表示されます。これをクリックすると、手動に設定したトラッカーを現在のターンに対してまとめて実行します。各トラッカーのポップオーバー内にある更新ボタンは、これまでどおりそのトラッカーだけを直接実行します。

HUDの列の先頭にあるきらめきのアイコンをクリックすると、**Agents & Actions**メニューが開きます。ここからは、すべてのトラッカーの再実行、失敗したエージェントの再試行、**Clear Trackers**(トラッカーの消去)によるチャットの世界の状態の全消去ができます。**Clear Trackers**は取り消せないので、慎重に使ってください。

## Tracker Panel

**Tracker Panel**は、コンパクトなHUDウィジェットと同じトラッカーのデータを表示する、大きめのサイドパネルです。トラッカーのカードを広く表示でき、立ち絵と思考の機能も加わります。設定場所は**Settings**(設定)の**Appearance**タブにある**Tracker Panel**セクションです。

パネルのヘッダーにあるボタンからは、トラッカーの構造も変更できます。

- **+**をクリックすると追加モードに入ります。Worldのセクションに**Add world field**が、その場にいるキャラクターのカードそれぞれに**Add custom field**が表示されます。項目の名前は通常モードでも見えたままなので、値の意味がいつでもわかります。
- ゴミ箱のアイコンをクリックすると削除モードに入り、独自に追加した世界の項目やキャラクターの項目を削除できます。項目を削除すると、その項目に保存したロックも一緒に消えます。
- ロックのアイコンをクリックするとロックモードに入ります。独自項目の値も、もともと備わっているトラッカーの値と同じようにロックできます。
- 目に斜線が入ったアイコンをクリックすると非表示モードに入り、キャラクターのカードで**Mood**、**Look**、**Outfit**、**Thoughts**を選べます。非表示にした項目はTracker PanelとRoleplay HUDから消え、値も消去され、ロックされたままになるので、トラッカーエージェントが埋め直すこともありません。もう一度非表示モードに入ると、非表示の項目を空の項目として再表示できます。

独自項目の名前は構造そのものを決めるもので、トラッカーが何度動いても変わりません。物語の中で内容が変われば、トラッカーエージェントがその値を更新します。エージェントの出力に含まれなかった場合でも、自分で作った項目が消えることはありません。

Tracker Panelは次の設定で調整します。

- **Tracker Panel**: パネル全体のオンとオフを切り替えるトグルです。デフォルトはオンです。オンのとき、ラベルには「Shown in the Roleplay HUD」と表示します。
- **Replace tracker HUD icons**: コンパクトなアイコンの列を隠し、代わりにパネルを画面の端に寄せて表示できるようにします。**Agents & Actions**ボタンは表示したままです。
- **Use expression sprites for tracker portraits**: トラッカーの立ち絵に、素のアバターではなくキャラクターの表情スプライト(今の感情を表す立ち絵)を使います。表情スプライトがある場合だけ適用します。表情スプライトについては[キャラクターのスプライト(表情と全身)](../characters/sprites.md)で説明しています。
- **Panel background**: パネルの背景に使う色やグラデーションを選びます。
- **Desktop size**: パネルの幅を選びます。選択肢は**Compact**、**Standard**、**Expanded**です。
- **Thought display mode**: キャラクターの思考の見せ方を選びます。**Docked**はキャラクターのカードの中に開きます。**Floating**は立ち絵の横に吹き出しとして開きます。
- **Always show Docked thoughts**: **Thought display mode**が**Docked**のとき、注目しているキャラクターの思考をボタンの裏に隠さず、つねに表示します。
- **Temperature unit**: 気温の表示を**Celsius**と**Fahrenheit**で切り替えます。デフォルトはCelsiusです。変わるのは表示だけで、保存する世界の状態の値は変わりません。

## HUDを埋めるエージェント

HUDのウィジェットはどれも、ターンのたびに動くトラッカーエージェントが内容を埋めます。どのエージェントがどのウィジェットに対応するかは、このガイドの冒頭の表にまとめてあります。

ペルソナやキャラクターが最初に持つステータスバーとRPGの能力値は、キャラクターエディターやペルソナエディターの**Stats**タブで決めます。トラッカーエージェントは、物語の進行に合わせてその値を調整します。
