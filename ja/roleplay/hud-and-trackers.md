# Roleplay HUDとトラッカー

HUD(ヘッドアップディスプレイ)は、Roleplayチャットで物語の現在の詳細を表示します。時刻、天候、その場にいるキャラクター、自分の能力値、持ち物、クエストです。どの値も手で直せるほか、値をロックしてAIに変更させないようにしたり、必要なときにトラッカーを再実行したりできます。

値の供給元はトラッカーエージェントです。エージェントとは、返信と並行して動く補助役です。トラッカーエージェントは物語を見張り、メッセージのたびにHUDの担当部分を更新します。ウィジェットは、対応するエージェントがそのチャットでオンのときだけ表示されます。

## HUDをオンにする

1. チャット内のスライダーボタンで**Chat Settings**(チャット設定)を開きます。
2. **Agents**に進み、**Enable Agents**(エージェントを有効にする)をオンにします。
3. スイッチの下の一覧からエージェントを追加します。基本のHUDなら、まず**World State**を追加します。さらに増やすには、**Persona Stats**、**Character Tracker**、**Quest Tracker**を追加します。
4. メッセージを送信します。

返信の後、トラッカーが表示されます。スマートフォンでは**World State**ボタンが、コンピューターでは**Tracker Panel**か**Trackers**ウィンドウ(後述)が表示されます。どのエージェントがどのウィジェットに値を送るかは、ウィジェットの表にまとめてあります。

うまくいかなかった場合: トラッカーエージェントが1つもオンでないと、HUDにウィジェットは表示されません。**Enable Agents**がオンになっているか確認してください。

## HUDが表示される場所

スマートフォンでは、トラッカーは移動できる**World State**と**Player & Tracker**のボタンです。ボタンをタップするとパネルが開き、**X**で閉じます。World Stateに情報が入ると、そのボタンには場所、日付、時刻、天候、気温を示す小さなバナーが表示されます。ボタンは好きな位置へドラッグできます。置いた位置はチャットに記憶されます。ボタンの見た目は**Settings → Appearance → App**(設定 → 外観 → アプリ)の**Chat widget style**(チャットウィジェットのスタイル)に従います。

コンピューターでは、同じトラッカーが次の2か所のどちらかに表示されます。

- **Tracker Panel**: メッセージの横に表示されるサイドパネルです。デフォルトでオンです。**Chat Settings**のタイトルバーにあるサイコロのボタンで、オンとオフを切り替えます。
- **Trackers**ウィンドウ: Tracker Panelがオフのときにトラッカーをまとめる、移動できるウィンドウです。

一度に使うのは、どちらか一方だけです。[Tracker Panel](#the-tracker-panel)と[Trackersウィンドウ](#the-trackers-window)を参照してください。

## HUDのウィジェット

| ウィジェット | 必要なエージェント | 表示する内容 |
| --- | --- | --- |
| **World State** | World State | 場所、日付、時刻、天候、気温、および自分で追加した世界の項目 |
| **Persona Stats** | Persona Stats | ペルソナのステータスバーと、状態を示す1行 |
| **Present Characters** | Character Tracker | シーンにいるキャラクターと、その気分、外見、独自項目 |
| **Inventory** | Persona Stats | 持ち物と、その個数 |
| **Inventory Tracker** | Inventory Tracker | 通貨、装備中の装具、持ち歩いている品物を分けた一覧 |
| **Active Quests** | Quest Tracker | 現在の目標 |
| **Custom Tracker** | Custom Tracker | カウンターや通貨など、自分で名前を付けた項目 |

**Inventory**ウィジェットは**Persona Stats**エージェントから来ているので、これをオンにすれば両方がそろいます。**Inventory Tracker**は別のものです。項目を**Currencies**、**Equipped**、**Inventory**の3つのグループで管理し、装備中の装具を二重に並べることはありません。

各項目は小さなピル型で表示されます。個数は2以上のときだけ`×4`の形で表示されます。個数が1の項目を変えるには、追加モードかロックモードをオンにしてください。どちらも、すべての項目に個数の入力欄を表示します。追加モードは、Tracker Panelのヘッダーにある**+**ボタンです。[ロックモード](#lock-mode)については後述します。

**Present Characters**には、キャラクターの絵文字が最大3つと、「+N」という数が表示されます。**Inventory**と**Custom Tracker**は、項目を1つずつ順番に表示します。

## トラッカーの値を編集する

項目はすべて編集できるので、AIが取り違えた値を直せます。編集内容はすぐに保存されます。次の返信は修正した値から始まります。修正した返信を再生成したりスワイプしたりする場合も同じです。

1. トラッカーを開きます。スマートフォンではボタンをタップし、コンピューターではTracker PanelかTrackersウィンドウで、そのセクションを開きます。
2. 値をクリックして、新しい値を入力します。

- **World State**: **Location**、**Date**、**Time**、**Weather**、**Temperature**と、独自に追加した世界の項目。
- **Persona Stats**: **Status**の行と、現在値と最大値を持つ名前付きのバー。バーは追加も削除もできます。
- **Present Characters**: キャラクターの追加と削除。各キャラクターの絵文字、名前、**Mood**、**Look**、**Outfit**、**Thinks**(心の中の思考)、独自項目を編集できます。キャラクターごとにアバターをアップロードできます。**Auto**ボタンで「Auto-generate avatars」のオンとオフを切り替えます。
- **Inventory**: アイテムの追加と削除。名前と個数を編集できます。
- **Inventory Tracker**: **Currencies**、**Equipped**、**Inventory**の下で項目を追加、削除できます。品物を別のグループに移すには、削除してから移動先に追加します。
- **Active Quests**: クエストの追加と削除。クエストごとに、チェックボックス付きの目標があります。
- **Custom Tracker**: 名前と値の項目の追加、削除、編集。

多くの値をまとめて直すには、[State Editor](#the-state-editor)を使います。

<a id="lock-mode"></a>

## ロックモード

トラッカーエージェントは、ターンのたびにHUDの値を上書きします。ロックモードを使うと、値を固定できます。項目をロックすると、次の自動実行ではその項目に手を触れません。値が何度も間違った方向にずれるときに使ってください。

1. トラッカーを開きます。
2. トラッカーの上部付近にあるロックのトグルをクリックします(ツールチップは**Enter lock mode**)。編集できる各値の横に、小さなロックボタンが表示されます。
3. 値の横のロックボタンをクリックします(ツールチップは**Lock field**)。ロックした項目には印が付きます。

解除するには、同じボタンをもう一度クリックします(**Unlock field**)。ロックモードを抜けるには、上部のトグルをもう一度クリックします(**Exit lock mode**)。ロックモードはHUD全体で共通なので、1つのトラッカーでオンにすると、すべての場所にロックボタンが表示されます。

## トラッカーの再実行

次のメッセージを待たずにトラッカーを今すぐ更新するには、トラッカーの中にある円形の矢印のボタンをクリックします。そのトラッカーだけを、直近のターンに対して実行し直します。ツールチップにはトラッカーの名前が入り、たとえば**Re-run world state tracker only**と表示されます。

トラッカーを指示したときだけ動かすには、**Chat Settings → Agents → Trackers Control**(チャット設定 → エージェント → トラッカーの管理)を開き、**Individual tracker schedule**(トラッカーごとのスケジュール)でそのトラッカーをオンにします。手動のトラッカーは、返信のたびには動きません。以前の**Manual Trackers**スイッチをオンにしていたチャットでは、そこですべてのトラッカーがオンになっています。

手動のトラッカーが1つでもあると、更新ボタンが表示されます。スマートフォンではHUDの列に、コンピューターではTrackersウィンドウのタイトルの横に表示されます。クリックすると、手動のトラッカーを現在のターンに対して実行します。

すべてのトラッカーの再実行、失敗したエージェントの再試行、**Clear Trackers**(トラッカーの消去)は、**Agent activity**(エージェントの動作)で行います。[Agent activity](getting-started.md#agent-activity)を参照してください。

> **Warning:** **Clear Trackers**は、チャットで追跡している世界の状態をすべて消去します。元に戻すことはできません。

<a id="the-trackers-window"></a>

## Trackersウィンドウ

コンピューターでは、Tracker Panelがオフのとき、トラッカーは**Trackers**ウィンドウを使います。メッセージの横に空きがあれば左側に開き、なければチャットの左上に小さな**Trackers**ボタンとして表示されます。ボタンをクリックすると開きます。保存済みのレイアウトがあるチャットでは、その配置が保たれます。

ウィンドウはタイトルバーで移動し、辺でサイズを変えます。右上のボタンは次のとおりです。

- **Pin**(ピン留め): ほかの場所をクリックしても開いたままにします。最初はピン留めされています。
- **Lock**(ロック): 移動とサイズ変更を止め、ボタンの位置も固定します。ボタンからウィンドウを開くことはできます。
- **Close**(閉じる): 移動できる**Trackers**ボタンに縮めます。

Chat Settingsの**Reset View**(表示をリセット)は、保存した配置を消去し、空きに合わせて初期状態のウィンドウかボタンを選びます。

各トラッカーには、折りたたみ可能なセクションがあります。ヘッダーをクリックすると小さなプレビューに折りたたまれ、もう一度クリックすると開きます。どれを折りたたんだかは、Marinaraが記憶します。

トラッカーを独立したウィンドウにするには、矢印の横にある切り離しボタンをクリックするか、タイトルをTrackersウィンドウの外へドラッグします。新しいウィンドウは、最初はピン留めされていません。開いたままにするにはピン留めしてください。**X**を押すと、トラッカーのアイコン付きの小さなボタンに縮みます。**World State**は代わりにバナーに縮み、スマートフォンと同じ場所、日付、時刻、天候を表示するので、チャットの上部中央など、好きな位置にドラッグできます。元に戻すには、**Put back in Trackers**(Trackersに戻す、**X**の左にある曲がった矢印)をクリックするか、Trackersウィンドウへドラッグします。どのトラッカーを切り離し、どこに置いたかは、チャットごとに記憶されます。

<a id="the-tracker-panel"></a>

## Tracker Panel

**Tracker Panel**は、同じデータを表示する大きめのサイドパネルです。キャラクターのポートレートと思考も表示します。

1. **Chat Settings**を開きます。
2. タイトルバーのピン留めとロックの隣にある**Tracker Panel**ボタン(サイコロ)をクリックします。パネルがオンの間、ボタンは強調表示されます。
3. もう一度クリックすると、パネルが隠れます。コンピューターでは、その後トラッカーがTrackersウィンドウに表示されます。

コンピューターでは、パネルはメッセージの横に収まり、幅は**Desktop size**(デスクトップでのサイズ)で決めた値までです。チャットサイドバーを開いているときなど、ウィンドウが両方を表示するには狭すぎる場合は、メッセージとメッセージ入力欄が少し狭くなります。スマートフォンやタブレットでオンにすると、ドラッグできるTracker Panelのボタンが加わります。タップするとパネルが開き、もう一度タップすると閉じます。パネルや別の画面がチャットを覆っている間は、チャット上の移動できるボタンが隠れ、その後同じ位置に戻ってきます。

### トラッカーの項目をカスタマイズする

パネルのヘッダーにあるボタンで、トラッカーの構造を変更できます。

- **+**で追加モードに入ります。Worldのセクションに**Add world field**が、その場にいる各キャラクターのカードに**Add custom field**が表示されます。項目の名前は、通常モードでも表示されたままです。
- ゴミ箱のアイコンで削除モードに入り、独自に追加した世界の項目やキャラクターの項目を削除できます。項目を削除すると、そのロックも一緒に消えます。
- ロックのアイコンでロックモードに入ります。独自項目も、もともと備わっている項目と同じようにロックできます。
- 目に斜線が入ったアイコンで非表示モードに入ります。キャラクターのカードで**Mood**、**Look**、**Outfit**、**Thoughts**を選びます。非表示にした項目はTracker PanelとHUDから消え、値も消去され、ロックされたままになるので、エージェントが埋め直すことはありません。もう一度非表示モードに入ると、空の項目として再表示できます。

独自項目の値は、エージェントが更新します。自分で作った項目をエージェントが削除することはありません。

### 新しいポートレートを作る

Character Trackerに画像用の接続が設定されていれば、キャラクターの大きいカードから新しいポートレートを作れます。コンパクトなカードでは、**Feature character card**(キャラクターカードを大きく表示)をクリックすると大きいカードが開きます。Trackersウィンドウでは、カードはつねに大きく表示されます。ポートレートにカーソルを合わせ、目のボタンをクリックすると**Look**から、シャツのボタンをクリックすると**Look**と**Outfit**からポートレートを作ります。シャツのボタンは、キャラクターに服装があるときだけ表示されます。古いポートレートは、新しいものができるまで残ります。作成に失敗した場合も、古いものが残ります。カードのアバターや表情スプライトで表示されているキャラクターには、これらのボタンはありません。

### Tracker Panelの設定

**Settings → Appearance**(設定 → 外観)を開き、**Roleplay**グループを開いて、**Tracker Panel**セクションを探します。

| 設定 | 働き |
| --- | --- |
| **Tracker Panel** | オンとオフのスイッチで、サイコロで切り替えるものと同じです。デフォルトはオンです。オンのとき、ラベルには「Shown in the Roleplay HUD」と表示されます。 |
| **Dock Tracker Panel to edge** | パネルを画面の端に寄せて置き、近くにあるチャットの操作部品がパネルに重ならないようにします。 |
| **Use expression sprites for tracker portraits** | 表情スプライトがある場合、素のアバターの代わりに、キャラクターの現在の表情スプライトを使います。[キャラクターのスプライト(表情と全身)](../characters/sprites.md)を参照してください。 |
| **Panel background** | パネルの色やグラデーションです。 |
| **Desktop size** | パネルの幅です。**Compact**、**Standard**、**Expanded**から選びます。 |
| **Thought display mode** | **Docked**はキャラクターのカードの中に思考を開きます。**Floating**はポートレートの横に吹き出しとして開きます。 |
| **Always show Docked thoughts** | **Docked**のとき、注目しているキャラクター全員の思考をボタンの裏に隠さず、つねに表示します。 |
| **Stat display mode** | 能力値をバーで表示するか、円形のゲージで表示するかを選びます。 |
| **Temperature unit** | **°C**(デフォルト)か**°F**です。変わるのは表示だけで、保存される値は変わりません。 |

<a id="the-state-editor"></a>

## State Editor

**State Editor**は、現在のターンのすべてのトラッカーを1つのウィンドウに表示します。トラッカーを1つずつ開かなくても、値を見つけて直せます。スマートフォンでも使えます。

次のどこからでも開けます。

- Tracker Panelのヘッダーにある歯車(**Tracker panel settings**)、続けて**{ }**ボタン(**Open in State Editor**)
- **Trackers**ウィンドウか、切り離したトラッカーのタイトルバーにある**{ }**ボタン
- スマートフォンでは、**World State**と**Player & Tracker**のパネルにある**{ }**ボタン
- **Agent Suite**の**Tracker Data**の下にある**Open in State Editor**のリンク

エディターは、開いたトラッカーのセクションで開きます。たとえばWorld Stateからなら**Scene**で開きます。

- **ターンの行**: 検索ボックスの下にあります。編集しているメッセージとスワイプを示します。たとえば「Editing message #12 · swipe 2 of 3」です。**Latest**(最新)は最新のターンを示します。スワイプごとに状態は別なので、別のスワイプを編集するには、先にスワイプしてください。
- **セクション**: **Scene**、**Present Characters**、**Persona Stats**、**Inventory Tracker**、**Custom Tracker Fields**、**Active Quests**です。スマートフォンでは、エディターの上にチップとして並びます。変更したセクションには点が付きます。
- **検索**: `mood`のように、キーか値を入力します。結果をクリックすると、その場所へ移動します。
- **Fields**: 各セクションは**Fields**(フィールド)として開き、テキスト、数値、オン/オフの値の入力ボックスが並びます。
- **No value**: 空の項目には、**Text**(テキスト)、**Number**(数値)、**On/off**(オン/オフ)の選択肢が表示されます。
- **Add item**(エントリーを追加): 上のエントリーをコピーして、エントリーを追加します。
- **Add**(追加): セクションや空のカードに、名前付きの項目を追加します。
- **×**: エントリーを削除するか、値を消去します。
- **JSON**: 生のデータを編集します。**Format**(整形)で整えられます。JSONが壊れているセクションは、直すまで保存できません。
- **Revert**(元に戻す): 1つのセクションへの変更を取り消します。

キャラクターとクエストは物語に属するため、ここではそのカードを追加できません。キャラクターの能力値のように、カードの中のリストは編集できます。

保存の手順は次のとおりです。

1. **Review changes**(変更を確認)をクリックして、各変更を1行ずつ確認します。
2. **Save changes**(変更を保存)をクリックします。編集していたターンに、すべてのセクションを一度に書き込みます。

それまで下書きはウィンドウ内に残り、閉じるときは破棄する前に確認が出ます。

うまくいかなかった場合: 編集中に物語が進んだ場合、エディターはそれを上書きしません。新しい返信やスワイプ、または変更したセクションへのトラッカーの更新があると、保存は**Reload**(再読み込み)ボタンとともに拒否されます。**Reload**は最新の状態を表示し、下書きを破棄します。
