# Roleplayモード: はじめに

Roleplayは物語のためのチャットモードです。メッセージの背後にステージ(背景とキャラクターのスプライト)を、さらに物語の詳細を示すヘッドアップディスプレイ(HUD)を加えます。エージェントとは返信と並行して動く補助役で、たとえば天候を追跡するものや、スプライトを選ぶものがあります。

物語のシーンを楽しむならRoleplayを選びます。ふつうのメッセージのやり取りには[Conversation](../conversation/getting-started.md)を、パーティー、戦闘、ダイスを備えた構造化されたゲームには[Game Mode](../game/getting-started.md)を選びます。Roleplayは画像生成なしでも、テキストだけのチャットとして動きます。その場合、スプライトの枠は空のまま、背景は単色になりますが、HUDは引き続き物語を追跡します。

## ロールプレイの始め方

始める前に: アプリの右側にある**Connections**(接続)パネルでアカウントを追加してください。[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。

1. チャットサイドバーで**RP**タブをクリックします。
2. サイドバーの上部付近にある**+**ボタンをクリックします。ツールチップには**New Roleplay**と表示されます。

チャットが開き、**Chat Settings**(チャット設定)と、5つのステップからなる設定ウィザードが表示されます。必須なのはアカウントだけです。すべて後から変更できます。

1. **Name & Connection**(名前と接続)。ロールプレイに名前を付け(任意)、返信を担当する接続を選びます。
2. **Pick a Preset**(プリセットの選択)。プリセットはプロンプトの構成と生成の値を決めます。ほとんどのチャットではデフォルトで十分です。
3. **Persona & Characters**(ペルソナとキャラクター)。自分のペルソナと、シーンに登場するキャラクターを選びます。このステップにある**Create your persona**(自分のペルソナを作る)というボタンを使うと、いくつかの質問からペルソナを作れます。[対話式オンボーディング](../characters/interactive-onboarding.md)を参照してください。
4. **Attach Lorebooks**(ロアブックの添付)。ロアブックとは、キーワードが出てきたときにAIが読み込む世界の設定をまとめたものです。任意です。
5. **Enable Agents**(エージェントを有効にする)。このチャットで動かすエージェントを選びます。後から**Chat Settings → Agents**(チャット設定 → エージェント)で変更できます。

終えると、メッセージ入力欄のあるチャットが表示されます。最初のメッセージを入力して送信してください。

## ステージ: 背景、スプライト、HUD

- **背景**: メッセージの背後に表示されるシーン全体の画像です。切り替わるときはフェードします。**Background**エージェントにターンごとに選ばせることも、チャットごとに1枚に固定することもできます。[Roleplayの背景](backgrounds.md)を参照してください。
- **スプライト**: ステージ上に立つキャラクターの立ち絵です。スプライトが有効なキャラクターは、全員表示できます。キャラクターのカードにスプライトライブラリーがないと、その枠は空のままです。[キャラクターのスプライト(表情と全身)](../characters/sprites.md)を参照してください。
- **HUD**: トラッカー(日付、時刻、天候、場所、その場にいるキャラクター、インベントリー、クエスト、能力値)です。**Chat Settings → Agents**(チャット設定 → エージェント)でオンにします。[Roleplay HUDとトラッカー](hud-and-trackers.md)を参照してください。

### スプライトの表示設定

**Chat Settings**(チャット内のスライダーボタン)を開いて**Agents**に進み、**Expression Engine**カードを探します。これはスプライトの表情を選ぶエージェントです。スプライトを有効にしたキャラクターが1人以上いると、次の設定が表示されます。

| 設定 | 働き |
| --- | --- |
| **Sprite Source**(スプライトの種類) | **Expressions**、**Full-body**、またはその両方を選びます。少なくとも1つはオンのままにする必要があります。 |
| **Expression Size**、**Full-body Size** | それぞれの種類のスプライトの大きさを決めます。 |
| **Expression Opacity**、**Full-body Opacity** | それぞれの種類の透け具合を決めます。 |
| **Default Side**(デフォルトの表示位置) | **Left**か**Right**です。新しいスプライトが最初に表示される側を決めます。 |
| **Expression Avatars**(表情アバター) | オンにすると、メッセージのアバターに、そのキャラクターの現在の表情スプライトが使われます。 |

大きさと透け具合の4つのスライダーは、このブラウザーにだけ保存されます。ほかのデバイスには同期しません。

スプライトを手で動かすには、次の手順に従います。

1. シーン上のボタン**Arrange**(配置)をクリックします。ボタンは**Done**に変わります。
2. スプライトをドラッグし、その上に出る小さなチェックをクリックして確定します。
3. 終わったら**Done**をクリックします。**Reset**を押すと、手で配置した位置がすべて消えます。

入力して表情を指定するには、シーン全体なら`/emote happy`、1人のキャラクターなら`/emote "Aria" angry`を送信します。`/emote`だけを送信すると、各キャラクターの表情の一覧が表示されます。

うまくいかなかった場合: スプライトを表示するには、キャラクターにスプライトライブラリーをアップロードしておく必要があります。ない場合、表情のエージェントは動いても、表示するものがありません。

## チャットのツール

チャットのツール(検索、分岐、要約、有効なコンテキスト、Agent activity、Author's Notes、Gallery)は、**Chat Settings**のセクションです。チャット内のスライダーボタンで開きます。それぞれの働きは[Chat Settingsの概要](../chats/chat-settings.md)を参照してください。[セクションを独立したウィンドウに切り離す](../chats/chat-settings.md#popping-a-section-out-into-its-own-window)もあわせて参照してください。

<a id="authors-notes"></a>

### Author's Notes

**Author's Notes**(作者ノート)は、AIが返信のたびに読むメモです。口調のルールや隠された事実など、常に効かせておきたい指示に使います。

1. **Chat Settings**を開き、**Agents**の下にある**Author's Notes**を展開します。
2. メモを入力します。例:「暗くサスペンスのある雰囲気を保つこと。」
3. よくわからない場合、**Injection Depth**(挿入の深さ)はそのままにしてください。メモをチャットのどの位置に置くかを決める設定です。0は最新のメッセージの後、4は末尾から4つ前のメッセージの位置です。

長いメモを書くときは、コンピューターでは入力欄の下の角をドラッグします。Author's NotesはGame ModeとConversationモードでも同じように使えます。

<a id="agent-activity"></a>

## Agent activity

**Agent activity**(エージェントの動作)は、チャットのエージェントが行った処理を表示します。チャットでエージェントかAdvanced Memoryを使うと表示されます。**Chat Settings**の**Agents**のすぐ下にある独立したセクションのほか、Tracker Panelの下部と、コンピューターではTrackersウィンドウの下部にもあります。

- **Activity**タブ: エージェントが保存した出力で、思考バブルと呼ばれます。1つずつ消すことも、**Clear all**でまとめて消すこともできます。カスタムエージェントの出力もここに表示されます。
- エージェントの作業中は、アイコンがスピナーに変わります。エージェントが失敗すると、開くまでアイコンに点が表示されます。
- 失敗したエージェントは、再試行ボタン付きで一覧表示されます。実行中のエージェントの停止、トラッカーの再実行、**Clear Trackers**(トラッカーの消去)もできます。
- **Injections**タブ: **Debug mode**(デバッグモード)がオンのときだけ表示されます(**Settings → Advanced**(設定 → 詳細設定))。直前の返信の前に、書き手系のエージェントが保存したプロンプトの断片が並びます。書き手系のエージェントには、文体のルールに合わせて返信を書き直す**Prose Guardian**や、話の流れを導く**Narrative Director**があります。断片は表示、編集、再実行ができます。編集で変わるのは、その同じ返信を再生成するときに使われる内容だけなので、再生成の結果は再現できるままです。画面上の返信は変わりません。

エージェント全般は[エージェント: チャットを支えるAIヘルパー](../agents/agents-overview.md)を参照してください。物語を導くエージェントについては[Narrative DirectorとSecret Plot](narrative-director.md)を参照してください。

## 戦闘とシーン

- Roleplayには軽量な戦闘の仕組みがあります。Combatエージェントを追加してから、チャット入力欄の上にある**Encounter**(エンカウント)をクリックします。[戦闘エンカウント(Roleplay)](combat-encounters.md)を参照してください。
- シーンとは、回想や別の場所を描くための脇道の分岐です。[シーン: Roleplayを枝分かれさせる](scenes.md)を参照してください。
- 話の流れを導くには、[Narrative DirectorとSecret Plot](narrative-director.md)を参照してください。

## モデルの選び方

キャラクターの文章を書くのはチャット用の接続です。性能の高いモデルほど、長いシーンでもキャラクターの口調が安定します。エージェント用の接続は、状態を読み取る、表情を選ぶといった小さな定型処理を担当しますが、小さなモデルではこれを誤ることがあります。チャットには高性能なモデル、エージェントには高速で安価なモデルを使う人が多くいます。HUDの値やスプライトが何度も正しくならない場合は、エージェントをより高性能なモデルに移してください。サンプラーの設定は[生成パラメーター](../prompts/generation-parameters.md)を参照してください。

## コマンド

以下は任意の機能です。コマンドとは、キャラクターが自分で行える操作です。`[illustrate: ...]`のような、角かっこで囲んだ短いテキストとして返信の中に書かれます。Marinaraは角かっこを読み取って操作を実行し、メッセージからは角かっこを隠します。

### コマンドをオンにする

1. **Chat Settings → Agents**(チャット設定 → エージェント)を開き、**Commands**(コマンド)を展開します。
2. 上部の**Commands**スイッチをオンにします。中のコマンドは、最初はすべてオフです。
3. 使いたいコマンドをオンにします。グレー表示のコマンドには、まだ足りないものが示されます。

- **Illustrations**(挿絵)、**Video clips**(動画クリップ): このチャットにIllustratorエージェントを追加します。
- **Combat**(戦闘): このチャットにCombatエージェントを追加します。
- **Soundtrack**(サウンドトラック): Music DJエージェントを追加し、エージェントをオンにします。
- **Personal Notes**(個人メモ)、**Reminders**(リマインダー)、**Whisper**(ささやき): 1対1のチャットか、**Individual**(個別)生成のグループチャットを使います。
- **Sound Cues**(効果音の合図): 効果音をオンにしたMusic & Sound Effectsの接続を選びます。
- **Documents**(ドキュメント)、**HTML Artifacts**(HTMLアーティファクト)、**Rolls**(ダイスロール)、**Direct Messages**(ダイレクトメッセージ)、**Interruptions**(割り込み): 追加で必要なものはありません。

**Rolls**、**Combat**、**Documents**、**Whisper**では、誰が使えるかも選びます。**All**(全員)のキャラクターか、**Narrator**(ナレーター)だけです。ナレーターとは、**Narrator character**(ナレーター役のキャラクター)で選んだキャラクターです。ナレーターはナレーター専用のコマンドを使え、全員のメモ、リマインダー、ささやきを読めます。

うまくいかなかった場合: グレー表示のコマンドは、必要なエージェントかチャットの種類が足りていません。スイッチの下の行を読んでください。

### 挿絵

始める前に: チャットにIllustratorエージェントを追加し、**Illustrations**(挿絵)をオンにしてください。

これでキャラクターが`[illustrate: subject="..." characters="..."]`で画像を依頼できます。画像はチャットのIllustratorの設定で作られ、メッセージの下に表示されます。

**Render in-line**(本文中に表示)をオンにすると、各画像がメッセージの中の、キャラクターがコマンドを書いた位置に表示されます。画像を選ぶとプロンプトが表示され、**X**で削除できます。この設定は新しい画像にだけ適用されます。Illustratorエージェントが自分で作る画像と、ビジュアルノベルのレイアウトは変わりません。

`/illustrate`で自分から挿絵を作ることもできます。RoleplayではIllustratorエージェントが必要です。

<a id="artifacts-on-demand"></a>

### オンデマンドのアーティファクト

**HTML Artifacts**(HTMLアーティファクト)をオンにすると、ナレーターが作中世界の物を1つ作れるようになります。たとえば呪文書のページ、看板、手紙に描かれたスケッチ、端末の表示画面などです。コマンドは`[html: prompt="..."]`です。エージェントは不要です。`/html <what you want>`で、自分から依頼することもできます。

アーティファクトは、返信が書き終わった後で、ナレーターがコマンドを置いた位置に表示されます。ビジュアルノベルのレイアウトでは、マーカーだけが表示されます。1回の返信で作れるアーティファクトは最大3つで、それぞれが別のモデルリクエストになります。リクエストには、**Immersive HTML**エージェントに接続があればその接続を、なければデフォルトのエージェント接続を、それもなければチャットの接続を使います。同時にいくつ実行するかは、その接続の**Parallel requests**(同時リクエスト数)設定(アカウントエディター内)で決まります。装飾しただけのシンプルなページなら、組み込みの**Documents**(ドキュメント)の種類が無料で、すぐに使えます。

ナレーターには、アーティファクトのHTMLは見えません。以降のターンでは、短いプレーンテキスト版を見ます。アーティファクトの読める文章と、見た目を説明する1行です。メッセージの下にある「used html command」のマーカーを開くと、その文章を読んだり編集したりできます。アーティファクトを削除することもでき、削除するとナレーターの記憶からも消えます。実行に失敗した場合は、マーカーにその理由が表示されます。

<a id="whispers-and-secrets"></a>

### ささやきと秘密

**Whisper**(ささやき)をオンにすると、返信の中に私的な一言、秘密、幻視を含められます。コマンドは`[whisper: character="name" text="the secret"]`です。チャット内のキャラクターか自分のペルソナを、ちょうど1人指定します。プロンプトでそのテキストを受け取るのは、そのキャラクターとナレーターだけです。不明な名前や曖昧な名前は無視されるので、秘密が漏れることはありません。

- **Reveal a secret**(秘密を表示)を押すと、ささやきが画面に表示されます。変わるのは自分に見える内容だけで、キャラクターが知っている内容は変わりません。自分のペルソナ宛てのささやきは、すぐに見えます。
- **Edit whisper**(ささやきを編集)でテキストを変更し、**Save**(保存)を押します。ささやきを取り消すには、テキストを空にして**Save**を押します。**Cancel**(キャンセル)を押すと元のままです。
- 自分のメッセージにささやきを書いて、キャラクター1人にささやくこともできます。キャラクターやナレーターのメッセージを編集するときも、同じ角かっこが使えます。テキストは複数行にでき、`text=""I love you.""`のように引用符もそのまま残せます。
- ささやきだけでできたメッセージは、ささやきが届かないキャラクターからは隠されます。
- **Hide from AI**(AIから隠す)でメッセージを一部のキャラクターから隠した場合も、ささやきの受信者はささやきを受け取りますが、メッセージの残りの部分は受け取りません。

エージェントもささやきを読めます。

- ささやきを読むエージェントは、Echo Chamber、トラッカー、Lorebook Keeper、Long-Term Memoryです。グループチャットでは**Smart**応答順もささやきを読むため、ささやきがきっかけで、そのキャラクターが次に返信することがあります。
- 各ささやきには非公開であることを示す印が付き、受信者の名前が添えられます。それでも、ロアブックのエントリーやトラッカーのメモなど、エージェントがささやきをもとに書いたものは、ほかのキャラクターに届くことがあります。
- ホストされたマルチプレイヤーのルームでは、エージェントと**Smart**応答順はささやきを受け取りません。
- Relationship TrackerとMemory Nagはチャットを独自に読み込むため、今のところささやきは見えません。

<a id="your-private-notes"></a>

### 自分の非公開メモ

**Personal Notes**(個人メモ)をオンにしてから、自分のメッセージに`[notes: content="your private note"]`と書いてください。このメモを受け取るのはナレーターだけで、ほかのキャラクターや共有エージェントには渡りません。編集や削除は、メッセージのコマンド詳細から行います。キャラクターを無効にしたりグループから削除したりすると、ナレーターにはそのキャラクターのメモが渡らなくなります。キャラクターを再びオンにすると、また渡るようになります。

1つのメッセージにメモを残すこともできます。

1. メッセージの下にある**Bookmark, pin or note**(ブックマーク・固定・メモ)を選びます。
2. **Private note**(非公開メモ)を書きます。デフォルトでは非公開のままで、モデルには送られません。
3. モデルと共有するには、**Show the note to the narrator character**(ナレーター役のキャラクターにメモを見せる)をオンにしてキャラクターを選びます。そのキャラクターだけが、そのメッセージに添えられたメモを受け取ります。共有には1対1のチャットか、**Individual**のグループ生成が必要です。

**Remove note**(メモを削除)でも共有が止まります。

<a id="video-clips"></a>

### 動画クリップ

始める前に: チャットにIllustratorエージェントを追加し、Illustratorの**Scene Videos**(シーン動画)で動画接続を選んでください。

**Video clips**(動画クリップ)をオンにすると、キャラクターが`[video: subject="the moment" motion="what moves and how the camera moves" characters="names"]`で、重要な瞬間の短いクリップを依頼できるようになります。動きが中心になる瞬間には、`[illustrate]`よりこちらを優先するようモデルに指示されます。クリップは、Illustratorの**First frame**(開始フレーム)で決めた画像(新しいIllustratorの画像、キャラクターのアバターやスプライト、または画像なし)から始まります。完成すると返信の中で再生されます。クリップが提示されるのは**Video Run Interval**(動画の実行間隔)が許すときだけで、**Videos per reply**(返信ごとの動画数)に数えられます。

### キャラクターによる割り込み

**Interruptions**(割り込み)をオンにすると、割り込みが自然な場面で、キャラクターが最新のメッセージを途中で遮れるようになります。コマンドは`[interrupt: part="a verbatim phrase of at least three words"]`です。Marinaraは返信の直前のメッセージからその語句を探し、その語句までのテキストを残して、末尾をダッシュで終わらせます。セリフの閉じ引用符は残ります。語句が見つからない場合や2か所で一致する場合、メッセージはそのままです。

元に戻すには、返信のコマンド情報を開き、**Restore original message**(元のメッセージを復元)を選びます。再生成すると先に元のメッセージ全体が復元されるため、新しい返信は改めて選び直せます。既存のスワイプを選ぶと、復元していないかぎり、そのスワイプの割り込みが適用されます。後から行った手動の編集は保持されます。

## Echo Chamber

**Echo Chamber**は、シーンに反応する観客をリアルタイムで加える任意のエージェントです。配信のコメント欄のように、一定の間隔で新しい反応を投稿します。オンにするには、**Chat Settings → Agents**(チャット設定 → エージェント)の**Echo Chamber**カードを使います。

- コンピューターでは、タイトルバーをドラッグして移動し、辺をドラッグしてサイズを変えます。開いたままにするにはピン留めします。**X**を押すと、移動できるボタンに閉じます。
- スマートフォンでは、最初はメッセージの上に小さなウィンドウとして表示されます。タイトルバーをドラッグすると移動でき、辺や角をドラッグするとサイズを変えられます。ピン留めすると、ほかの場所をタップしても開いたままになり、ロックすると誤って動かすのを防げます。
- 見た目は**Settings → Appearance → App**(設定 → 外観 → アプリ)の**Chat widget style**(チャットウィジェットのスタイル)に従います。レイアウトはチャットごとに記憶されます。

## CYOAの選択肢

CYOAはChoose Your Own Adventureの略です。CYOA Choicesエージェントはデフォルトでオフで、Roleplayでのみ動作します。オンにすると、返信の後にクリックできる選択肢のボタンが追加され、クリックするとそれが次のメッセージとして送信されます。選択肢を組み合わせたり、先に編集したりするには、**Settings → General → Input & Editing**(設定 → 一般 → 入力と編集)で**Add CYOA choices to the message box instead of sending them**(CYOAの選択肢を送信せずメッセージ入力欄に追加する)をオンにします。すると、選択肢をクリックしたときに、その文章がメッセージ入力欄に追加されます。

## トラブルシューティング

| 症状 | 対処 |
| --- | --- |
| HUDの値が正しくない。 | 手で編集し、ロックして次の実行で変わらないようにします。[Roleplay HUDとトラッカー](hud-and-trackers.md)を参照してください。値がずれ続ける場合は、より高性能なエージェント用のモデルを使ってください。 |
| スプライトが変わらない。 | キャラクターにスプライトライブラリーがあるか確認してください。`/emote`を使うこともできます。 |
| 背景がまったく変わらない。 | **Background**エージェントはライブラリーから選ぶので、背景を追加してください。[Roleplayの背景](backgrounds.md)を参照してください。 |
| 再生成しても返信の方向が変わらない。 | **Debug mode**(デバッグモード)をオンにし、**Agent activity → Injections**を開いてから、再生成する前に保存された断片を編集するか再実行してください。 |

ほかの対処法は[Marinara Engineのトラブルシューティング](../TROUBLESHOOTING.md)を参照してください。
