# Roleplayの背景

Roleplayのチャットでは、メッセージの後ろにシーン全体の画像が表示されます。この画像は、返信のたびに**Background**(背景)エージェントに選ばせることも、手動で新しく作ることも、1枚の画像を1つのチャットに固定することもできます。画像が変わるときは、Marinaraが古い画像から新しい画像へフェードで切り替えます。

画像生成は必須ではありません。画像生成のアカウントがない場合、背景は単色になり、チャットはテキストとして動きます。

## 特定のチャットに背景を設定する

エージェントに選ばせる代わりに、開いているチャットの後ろに1枚の画像を置いたままにしたいときに使います。変わるのはそのチャットだけです。

1. チャットを開きます。次に**Settings → Appearance**(設定 → 外観)を開き、**Backgrounds**(背景)を探します。
2. **Chat Background**(チャットの背景)で、アップロードした画像かゲームアセットの背景を選びます。

メッセージの後ろにその画像が表示されます。デフォルトに戻すには、**Chat Background**の横にある**Remove**(削除)をクリックします。

画像がまだない場合は、先にアップロードしてください。[チャットの背景](../appearance/chat-backgrounds.md)を参照してください。

## Backgroundエージェントに背景を選ばせる

**Background**(背景)エージェントは、返信と並行して動く補助機能です。返信のたびに現在のシーンを読み取り、すべての背景の中からいちばん場面に合う画像を選びます。選ぶのは既存の画像だけです。新しい画像を自動で作るのは**Illustrator**エージェントです。

1. Roleplayのチャットを開きます。
2. チャット内のスライダーボタンで**Chat Settings**(チャット設定)を開きます。
3. **Agents**(エージェント)を開き、**Enable Agents**(エージェントを有効にする)をオンにします。
4. **Background**エージェントを追加します。

これで、物語の舞台が移るのに合わせて背景が自動で切り替わります。

うまくいかなかった場合: 背景が1枚か2枚しかないと、エージェントはそれを選び続けます。ライブラリーに背景を追加してください。[チャットの背景](../appearance/chat-backgrounds.md)を参照してください。

## 手持ちの画像の再利用

Illustratorが自動で背景を作るとき、物語が新しい場所に移ると、まずその場所にピン留めした背景があるかを確認します([場所に背景をピン留めする](#pin-a-background-to-a-place)を参照)。ピン留めされた場所では、新しい画像を描きません。なければ背景ライブラリーを探します。画像のファイル名か、2語以上のタグのいずれかがWorld Stateの場所に含まれていれば、その画像を使います。たとえば、`john-bedroom.png`は「Smith House, John's bedroom」に対応します。大文字と小文字、アクセント記号、「's」の違いは無視され、単なる`bedroom.png`より具体的な名前が優先されます。

World Stateに場所がない場合は、Illustratorが新しい背景用に書いた場所の名前を同じ方法で照合します。合う画像があれば、それを表示し、新しく描きません。一致する画像のない場所だけに新しい画像を作ります。

場所ごとに同じ画像を使うには、ファイル名を場所に合わせてください(「Kitchen」なら`kitchen.png`)。`smith house kitchen`のような2語以上のタグも使えます。`kitchen`や`night`のような1語のタグは、たいてい画像の見た目を表すため無視されます。

## 手動で背景を生成する

Marinaraがシーンの内容(ジャンル、設定、場所、天候、時刻)から画像プロンプトを組み立て、新しい背景を作ります。

始める前に: **Illustrator**エージェントをインストールしてそのエージェントに画像生成のアカウントを設定するか、画像生成のアカウントを1つデフォルトに指定してください。[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。Illustratorをチャットに追加する必要はありません。

1. チャット内のスライダーボタンで**Chat Settings**(チャット設定)を開き、**Gallery**(ギャラリー)を展開します。
2. **Background**(背景)をクリックします。処理中はボタンに**Generating...**と表示され、Galleryには「Illustrator is generating a background image for this scene.」と表示されます。
3. 完了するまで待ちます。新しい画像は背景ライブラリーに追加され、シーンに適用されます。

手動生成では、まずIllustratorエージェントの画像用のアカウントを使い、次にデフォルトの画像生成のアカウントを使います。使えるのはRoleplayモードとGame Modeで、Conversationでは使えません。

うまくいかなかった場合: 「Choose an image generation connection for the Illustrator agent, or mark one as the default image connection.」というメッセージは、Marinaraが画像用のアカウントを見つけられなかったことを意味します。アカウントを設定してから、もう一度試してください。**Background**ボタンがない場合は、Illustratorがインストールされていません。

## 場所に背景をピン留めする

物語の場所をいつも同じ見た目にしたいときに使います。たとえば、Johnの寝室では常に`john-bedroom`を、自分の寝室では常に`my-bedroom`を表示します。物語がピン留めした場所に着くと、Backgroundエージェントが何を選ぶかにかかわらず、その画像が表示されます。

1. チャット内のスライダーボタンで**チャット設定**を開き、**背景**を開きます。
2. **Pinned places**(ピン留めした場所)で、**Add place**(場所を追加)をクリックします。
3. 空の画像をクリックして背景を選びます。場所は、`John's bedroom`のように、物語で使われる表記で入力します。
4. 任意: その下に、物語で使われそうな別名を、`John's room, the master bedroom`のようにカンマで区切って追加します。

もっと手早く設定するには、物語がその場所にいて、目的の画像が表示されているときに、**Pin this picture to "John's bedroom"**(この画像を「Johnの寝室」にピン留め)をクリックします。

場所を見分ける方法:

- 最も具体的な名前が優先されます。`John's bedroom`と`{{user}}'s bedroom`が混同されることはなく、単に`bedroom`としたピン留めは、誰もピン留めしていない寝室にだけ使われます。
- 途中に1～2語入っていても一致します。「John's guest bedroom」は、その場所の名前に完全一致する別のピン留めがない限り、`John's bedroom`に一致します。
- `{{user}}`は自分のペルソナの名前、`{{char}}`はチャット内のいずれかのキャラクターなので、`{{user}}'s bedroom`は「Alyssa's bedroom」に一致します。
- 「My」と「our」は、メッセージを書いた人を基準にします。Johnの返信で物語が「my bedroom」にいると書かれていれば、それはJohnの寝室です。Johnの返信にある「your bedroom」は自分の寝室を指します。自分のメッセージにある「your bedroom」は、チャットにキャラクターが1人だけいる場合、そのキャラクターの寝室を指します。
- 大文字と小文字、アクセント記号、アポストロフィーの違いは問いません。名前は単語全体で照合するので、`John`が「Johnson」に一致することはありません。
- **World Maps**を使う場合は、代わりに**World Maps place**(World Mapsの場所)の一覧から場所を選びます。建物にピン留めすると、独自のピン留めがない内部の部屋にも適用されます。

動作:

- 画像は到着時に1回表示されます。そこにいる間に手動で別の背景を選ぶと、物語が次の場所へ移るまで、手動で選んだ背景が表示されます。
- ピン留めした場所では、Backgroundエージェントは画像を変更できず、Illustratorもその場所の新しい背景を描きません。
- **World State**エージェントの場所(またはWorld Maps)が必要です。一覧の下には物語の現在地が表示され、使用中のピン留めには**Here**(ここ)と表示されます。ピン留めはRoleplayのチャットで使えます。

うまくいかなかった場合: 一覧の下の**Story is at**(物語の現在地)に場所が表示され、その中にピン留めした名前のいずれかが含まれているか確認してください。

### キャラクターと一緒に使われる背景

キャラクター(またはペルソナ)の**ギャラリー**で背景として指定した画像は、チャットごとにピン留めしなくても、そのキャラクターがいるすべてのチャットに表示されます。

1. キャラクターの**ギャラリー**を開き、画像のタグボタンをクリックして、**背景として使用**を選びます。
2. 描かれている場所を、`{{char}}'s bedroom, {{char}}'s room`のようにカンマで区切って入力します。キャラクターのギャラリーでは`{{char}}`がそのキャラクターを、ペルソナのギャラリーでは`{{user}}`がそのペルソナを指します。特定の場所の画像でなければ、空のままにしてください。

場所の名前を指定した画像は、そのキャラクターがいるすべてのチャットでピン留めした場所と同じように動き、**チャット設定 → 背景**の**Pinned places**(ピン留めした場所)に表示されます。チャット自体で設定したピン留めは、同じ名前のギャラリー画像より優先されます。

## ライブラリーとぼかし

選ぶ画像は、同じ**Backgrounds**(背景)セクションにあります。インポート、タグ、名前の変更、削除、**Background Blur**(背景のぼかし)スライダー、新しいRoleplayチャット用のデフォルト背景については、[チャットの背景](../appearance/chat-backgrounds.md)で説明しています。
