# シーン: Roleplayを枝分かれさせる

このガイドでは、Marinara Engineのシーンについて説明します。シーンとは、Conversationのチャットから枝分かれする、短くて独立したRoleplayです。始め方と進め方、そして終了、破棄、複製、変換の方法がわかります。

## シーンとは

シーンは、Conversationのチャットから派生するサブのRoleplayです。Conversationのチャットは、メッセンジャー風のダイレクトメッセージのモードです。シーンを使うと、そのチャットからいったん抜け出して、キャラクターと一緒に特定の場面に集中したRoleplayを進められます。回想でも、デートでも、戦闘でもかまいません。元の話の流れが失われることはありません。

シーンは1つ1つが独立したRoleplayのチャットです。専用の背景、舞台に立つキャラクター、そして最初のメッセージを持ちます。シーンが始まるとき、状況の説明はキャラクターや物語の側が書いてくれます。

シーンは一時的なものとして設計されています。シーンが開いている間、元になったConversationのチャットには**A scene is in progress**と書かれた小さなカードが表示されます。このカードの**Go to Scene**ボタンを押すと、進行中のシーンに移動できます。

シーンを終えるときは、そのシーンをどう扱うかを選びます。要約をConversationに書き戻す、シーンを丸ごと捨てる、独立したRoleplayとして残す、の3つです。それぞれ後の節で説明します。

## シーンの開始

シーンはConversationのチャットの中で`/scene`コマンドを使って始めます。同じ働きをする別名として`/rp`も使えます。

手順は次のとおりです。

1. すでにメッセージがいくつかあるConversationのチャットを開きます。
2. メッセージ入力欄にシーンのコマンドを入力します。後ろに、どんな場面にしたいかを短く書き添えることもできます。

```
/scene we sneak into the old library at midnight
```

3. Enterを押します。**Scene Prompt Setup**(シーンプロンプトの設定)ウィンドウが開きます。
4. 新しいシーンの**Prompt preset**(プロンプトプリセット)を選ぶか、**None**(なし)のままにします。Marinaraは次のシーンでもこの選択を記憶します。シーン固有の指示は、選んだプリセットと併せて引き続き適用されます。
5. **POV**で文章の視点を選びます。**First Person**、**Second Person**、**Third Person**のいずれかです。
6. **Tense**で時制を選びます。**Past**、**Present**、**Future**のいずれかです。
7. 必要に応じて、**Extra instructions**欄に補足を書いてシーンの方向性を指定します。
8. **Plan Scene**をクリックします。

Marinaraがシーンを組み立て、新しいRoleplayのチャットとして開きます。新しいシーンがチャット一覧に現れ、状況を提示する最初のメッセージとともに自動で開くはずです。設定ウィンドウで気が変わったときは**Cancel**をクリックすれば、シーンは作られません。

説明を書かずにシーンを始めることもできます。Conversationに材料となる履歴が十分にあるなら、コマンドだけを入力します。

```
/scene
```

Conversationにまだメッセージが1つもない場合は、シーンを組み立てられないため、説明を書き足すか先にチャットを進めるようMarinaraが促します。

キャラクターの側からシーンの開始を持ちかけてくることもあります。その場合も同じ**Scene Prompt Setup**ウィンドウが開き、「[Character] wants to start a scene.」のような一文が表示されます。同じように**Prompt preset**、**POV**と**Tense**を選んで**Plan Scene**をクリックするか、断るときは**Cancel**をクリックします。

## シーンバー: End Scene、Discard、Convert、Back to conversation

シーンを進めている間、メッセージ入力欄のすぐ上にバーが表示されます。ここに、シーンの行き先を決めるボタンが並びます。表示されるボタンは、そのシーンにひもづくConversationがあるかどうかで変わります。

- **Back to conversation**は、シーンを始めたConversationのチャットに戻ります。シーンは開いたまま残るので、後から続きを進められます。このボタンは、元になったConversationがあるシーンにだけ表示されます。
- **End Scene**はシーンを終了し、要約を保存します。クリックすると、バーに**End and save summary?**という確認と**Yes**および**No**ボタンが表示されます。**Yes**をクリックすると確定します。処理中はボタンが**Saving...**の状態になります。Marinaraはシーンの短い要約を記憶として元のConversationに書き戻し、そのConversationの続きへ戻します。
- **Discard**は、何も保存せずにシーンを捨てます。クリックすると、バーに**Discard scene?**という確認と**Yes**、**No**ボタンが表示されます。**Yes**をクリックするとシーンが削除され、Conversationに戻ります。何も書き戻されません。
- **Convert**は、シーンを独立したRoleplayのチャットに変えます。シーンの状態を元に戻せない形で変えるため、後の節で個別に説明します。

**End Scene**と**Discard**はどちらもConversationからシーンを取り除くので、クリックする前によく考えてください。**End Scene**は何が起きたかを記憶として残します。**Discard**は何も残しません。

## メッセージからシーンを複製する

シーンのチャットでは、各メッセージに小さな操作ボタンがあり、ツールチップには**Clone from here**と表示されます。これを使うと、そのメッセージまでの内容をコピーして、まったく新しいRoleplayのチャットとして枝分かれさせられます。

使い方は次のとおりです。

1. 分岐させたいメッセージにカーソルを合わせます。
2. **Clone from here**の操作をクリックします。

Marinaraはそのシーンから新しい独立したRoleplayを作り、指定した位置までのメッセージをコピーします。元のシーンは開いたまま進行し続けるので、別の展開を安全に試せます。シーンがRoleplayとして複製されたことを知らせる表示が出て、新しいチャットが開くはずです。

複製では元のシーンが残ります。次に説明する変換では残りません。

## シーンを独立したRoleplayに変換する

シーンバーの**Convert**ボタンは、シーンをConversationから切り離し、それ自体を独立したRoleplayのチャットにします。**Convert**をクリックすると、**Convert this scene into a standalone roleplay?**という見出しの確認ウィンドウが開きます。

ウィンドウには、これから何が起きるかが書かれています。現在のシーンから新しいRoleplayのチャットを作り、元のシーンをConversationから切り離します。シーンの要約もキャラクターの記憶も、元のConversationには書き戻されません。進めるときは**Convert**を、そのままにしておくときは**Cancel**をクリックします。

シーンが1つの物語に育ち、通常のRoleplayとして残して続けたくなったときは**Convert**を使います。コピーがほしいけれど元のシーンもそのまま残したいときは、代わりに**Clone from here**を使います。

2つの枝分かれの違いを整理すると、**Clone from here**は元のシーンを動かしたままシーンの分岐を作ります。**Convert**はシーンの分岐を独立したRoleplayに変え、元のシーンをConversationから取り除きます。

## シーンがつないだチャットのコンテキストを引き継がない理由

ConversationのチャットはRoleplayとつなぐことができ、つないだ相手との間ではコンテキストが行き来します。シーンは意図的にこれと違う動きをします。シーンは独立した存在だからです。

シーンは、たとえ親のチャットが受け取っていても、つないだConversationのやり取りのコンテキストを自動で取り込むことはありません。つないだConversationは、物語を後押しする短い指示を裏でRoleplayに渡せますが、シーンはその指示を無視します。こうすることで、Conversation全体を引きずり込まず、シーンをその場面だけに集中させられます。

だからこそ、シーンは1つの小さな物語としてすっきり読めます。ConversationとRoleplayの間で双方向のつながりを保ちたいときは、シーンではなくつないだチャットを使ってください。この機能については、下にリンクしたつないだチャットのガイドを参照してください。
