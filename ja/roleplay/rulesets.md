# Roleplay: ルールセットで遊ぶ

Roleplayのチャットは、Game Modeで使うのと同じ種類の卓上ルールセットで遊べます。不確かなことが起きるとナレーターが判定を求め、Marinaraがキャラクターのシートからダイスを振り、返信がそのロールで何が決まったかを伝えます。Game Modeのゲームを始めずに、roleplayで本物のダイスとキャラクターシートを使いたいときに使います。

Game Mode用にインストールしたルールセットなら、5e (SRD 5.1)など何でも使えます。キャラクターエディターとペルソナエディターでそのルールセット用にすでに作ったシートも使えます。

## チャットでルールセットをオンにする

始める前に: ルールセットをインストールしてください。[ルールセットを入手する](../game/rulesets.md#get-a-ruleset)を参照してください。

1. Roleplayのチャットを開きます。
2. **Chat Settings**(チャット設定)を開き、**Ruleset**(ルールセット)セクションを探します。
3. 一覧からルールセットを選びます。インストール済みのルールセットが並びます。
4. Marinaraがチャットの各メンバーにシートを渡し、追加した数を伝えます。各メンバーはルールセットの下に表示されます。

各メンバーは、キャラクターエディターまたはペルソナエディターにある、そのルールセット用の自分のシートのコピーを受け取ります([ルールセットのシート](../characters/colors-and-stats.md#ruleset-sheets)を参照)。シートがないメンバーには、一覧で**blank sheet**(空のシート)と表示される空のシートが渡され、チャット内で作ります。ペルソナが最初に来ます。チャット内の変更はチャット内にとどまり、キャラクターやペルソナには決して戻りません。

うまくいかなかった場合: インポートしたルールセットでは**Allow custom Agent imports**(カスタムエージェントのインポートを許可)をオンにする必要があります。[ルールセットを入手する](../game/rulesets.md#get-a-ruleset)を参照してください。

### 空のシートを作る

1. **Ruleset**セクションで、メンバーの横にある**Build sheet**(シートを作成)をクリックします。
2. キャラクターシートがシートエディターで開きます。ルールセットにガイド付きビルダーがある場合は、Game Modeやキャラクターエディターと同じく、まずそこで開きます。
3. 選択を済ませ、**Save sheet**(シートを保存)をクリックします。

### 新しいメンバーのシートを追加する

あとからキャラクターがチャットに加わったら、**Add missing sheets**(足りないシートを追加)をクリックします。すでにシートがあるメンバーはそのままです。

### シートを削除する

ナレーター用のカードなど、シートを持つべきでないメンバーからはシートを外せます。

1. **Ruleset**セクションで、メンバーの横にあるごみ箱のアイコンをクリックします。
2. **Remove sheet**(シートを削除)をクリックします。

チャットはこれを覚えるので、**Add missing sheets**や新しいバージョンのルールセットでも、そのメンバーは対象から外れます。もう一度シートを与えるには、**No sheet:**(シートなし)のあとにあるそのメンバーのボタン(例: **Give Mira a sheet**、Miraにシートを与える)をクリックします。

### ルールセットを切り替える、またはオフにする

- **None**(なし)を選ぶと、ルールセットでのプレイをやめます。シートは残るので、同じルールセットをもう一度選べば、やめたところから続きます。
- 別のルールセットを選ぶと、すべてのシートが最初からになります。あるルールセット用のシートは、別のルールセットでは意味を持たないからです。

## プレイ中の判定

ターンはいつもどおり書きます。結果が重要な不確かな行動をキャラクターが試みると、ナレーターは結果を決める代わりに判定を書きます。Marinaraがシートからそれを振り、そのあとナレーターがロールで何が決まったかを書きます。

完成したメッセージには、判定があった場所にダイスカードが表示され、スキル、難易度、ダイス、そして**Success**(成功)または**Failure**(失敗)が並びます。本当には失敗しない普通の行動には判定が付きません。

> **Tip:** モデルによっては判定を求める指示を無視し、結果を自分で決めてしまいます。判定がまったく出ないときは、チャットの**Connection**(接続)にもっと強いモデルを試してください。

**Impersonate**(なりきり)のターンでは判定を振りません。マルチプレイヤーのルームではルールセットで遊べません。

## キャラクターシートを使う

**Ruleset**セクションでメンバーの横にある**Open sheet**(シートを開く)をクリックします。シートはGame Modeが表示するものと同じです。Tracker Panelの上部にある巻物のボタンで、ペルソナのシートが開きます。

- ヒットポイントやストレスなどのプールやトラックの横にある**−**と**+**をクリックすると、値を変えられます。変更は現在のメッセージとともに保存されるので、スワイプやブランチにもついてきます。
- **Edit ruleset sheet**(ルールセットのシートを編集)をクリックしてスコア、スキルのランク、欄、一覧を変更し、**Save sheet**(シートを保存)をクリックします。

ナレーターは毎ターン、シートを読み、返信の中でシートのコマンドを使ってシートを変えます。コマンドはMarinaraが適用し、メッセージからは隠します。休息を取るときは、ターンで「長休憩を取ります」のように伝えます。ナレーターが休息を記録し、シートはルールセットの休息が回復するものを取り戻します。シートの**Rest**(休息)をクリックすることもできます。

## トラブルシューティング

| 症状 | 対処 |
| --- | --- |
| **This chat's ruleset is not installed here, so its checks and sheets are paused.** | ルールセットを入れ直すか、別のものを選んでください。 |
| ナレーターが判定をまったく求めない。 | チャットにもっと強いモデルを使ってください。判定の指示を飛ばすモデルがあります。 |
| 新しいキャラクターにシートがない。 | **Add missing sheets**をクリックしてください。 |
