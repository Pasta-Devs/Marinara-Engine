# Roleplay: ルールセットで遊ぶ

Roleplayのチャットは、Game Modeで使うのと同じ種類の卓上ルールセットで遊べます。不確かなことが起きるとナレーターが判定を求め、Marinaraがキャラクターのシートからダイスを振り、返信がそのロールで何が決まったかを伝えます。Game Modeのゲームを始めずに、roleplayで本物のダイスとキャラクターシートを使いたいときに使います。

Game Mode用にインストールしたルールセットなら、5e (SRD 5.1)など何でも使えます。キャラクターエディターとペルソナエディターでそのルールセット用にすでに作ったシートも使えます。

## チャットでルールセットをオンにする

始める前に: ルールセットをインストールしてください。[ルールセットを入手する](../game/rulesets.md#get-a-ruleset)を参照してください。

1. Roleplayのチャットを開きます。
2. **Chat Settings**(チャット設定)を開き、**Ruleset**(ルールセット)セクションを探します。
3. 一覧からルールセットを選びます。インストール済みのルールセットが並びます。
4. Marinaraがチャットの各メンバーにシートを渡し、追加した数を伝えます。各メンバーはルールセットの下に表示されます。

各メンバーは、キャラクターエディターまたはペルソナエディターにある、そのルールセット用の自分のシートのコピーを受け取ります([ルールセットのシート](../characters/colors-and-stats.md#ruleset-sheets)を参照)。シートがないメンバーには、一覧で**blank sheet**(空のシート)と表示される空のシートが渡され、チャット内で作ります。ペルソナが最初に来ます。チャット内の変更はチャット内にとどまり、キャラクターやペルソナには決して戻りません。

うまくいかなかった場合: インポートしたルールセットでは**Allow custom Agent imports**(カスタムエージェントのインポートを許可)をオンにする必要があります。[ルールセットを入手する](../game/rulesets.md#get-a-ruleset)を参照してください。

### 空のシートを作る

1. **Ruleset**セクションで、メンバーの横にある**Build sheet**(シートを作成)をクリックします。
2. キャラクターシートがシートエディターで開きます。ルールセットにガイド付きビルダーがある場合は、Game Modeやキャラクターエディターと同じく、まずそこで開きます。
3. 選択を済ませ、**Save sheet**(シートを保存)をクリックします。

### 新しいメンバーのシートを追加する

あとからキャラクターがチャットに加わったら、**Add missing sheets**(足りないシートを追加)をクリックします。すでにシートがあるメンバーはそのままです。

### シートを削除する

ナレーター用のカードなど、シートを持つべきでないメンバーからはシートを外せます。

1. **Ruleset**セクションで、メンバーの横にあるごみ箱のアイコンをクリックします。
2. **Remove sheet**(シートを削除)をクリックします。

チャットはこれを覚えるので、**Add missing sheets**や新しいバージョンのルールセットでも、そのメンバーは対象から外れます。もう一度シートを与えるには、**No sheet:**(シートなし)のあとにあるそのメンバーのボタン(例: **Give Mira a sheet**、Miraにシートを与える)をクリックします。

### ルールセットを切り替える、またはオフにする

- **None**(なし)を選ぶと、ルールセットでのプレイをやめます。シートは残るので、同じルールセットをもう一度選べば、やめたところから続きます。
- 別のルールセットを選ぶと、すべてのシートが最初からになります。あるルールセット用のシートは、別のルールセットでは意味を持たないからです。

## プレイ中の判定

ターンはいつもどおり書きます。結果が重要な不確かな行動をキャラクターが試みると、ナレーターは結果を決める代わりに判定を書きます。Marinaraがシートからそれを振り、そのあとナレーターがロールで何が決まったかを書きます。

完成したメッセージには、判定があった場所にダイスカードが表示され、スキル、難易度、ダイス、そして**Success**(成功)または**Failure**(失敗)が並びます。本当には失敗しない普通の行動には判定が付きません。

> **Tip:** モデルによっては判定を求める指示を無視し、結果を自分で決めてしまいます。判定がまったく出ないときは、チャットの**Connection**(接続)にもっと強いモデルを試してください。

**Impersonate**(なりきり)のターンでは判定を振りません。マルチプレイヤーのルームではルールセットで遊べません。

## キャラクターシートを使う

**Ruleset**セクションでメンバーの横にある**Open sheet**(シートを開く)をクリックします。シートはGame Modeが表示するものと同じです。Tracker Panelの上部にある巻物のボタンで、ペルソナのシートが開きます。

- ヒットポイントやストレスなどのプールやトラックの横にある**−**と**+**をクリックすると、値を変えられます。変更は現在のメッセージとともに保存されるので、スワイプやブランチにもついてきます。
- **Edit ruleset sheet**(ルールセットのシートを編集)をクリックしてスコア、スキルのランク、欄、一覧を変更し、**Save sheet**(シートを保存)をクリックします。

ナレーターは毎ターン、シートを読み、返信の中でシートのコマンドを使ってシートを変えます。コマンドはMarinaraが適用し、メッセージからは隠します。休息を取るときは、ターンで「長休憩を取ります」のように伝えます。ナレーターが休息を記録し、シートはルールセットの休息が回復するものを取り戻します。シートの**Rest**(休息)をクリックすることもできます。

## 自分のルールセットを作る

ルールセットビルダーは、判定の振り方、シートに載せるもの、ナレーターに伝えることをフォームで指定して、小さなルールセットを作ります。Marinaraにないシステムで遊ぶときに使います。作ったルールセットは、RoleplayでもGame Modeでも、インストールしたルールセットと同じように使えます。

始める前に: **Allow custom Agent imports**(カスタムエージェントのインポートを許可)をオンにしてください。ビルダーは、インポートと同じ方法でルールセットを保存するためです。[ルールセットを入手する](../game/rulesets.md#get-a-ruleset)を参照してください。

1. **Chat Settings → Ruleset**(チャット設定 → ルールセット)で、**New ruleset…**(新しいルールセット)をクリックします。
2. **Name**(名前)を入力します。
3. **Dice**(ダイス)で、判定の振り方を選びます(下の表を参照)。選ぶと、出発点となる能力値、プール、トラックが入力されます。これらは変更できます。
4. **Difficulties**(難易度)、**Stats**(能力値)、**Skills**(スキル)と、フォームのほかの部分を変更します。ほとんどのセクションには、タイトルの下に1行の説明があります。
5. **Create ruleset**(ルールセットを作成)をクリックします。

Marinaraがルールセットを保存します。ルールセットのないチャットでは、あわせて新しいルールセットをオンにします。すでにルールセットがあるチャットでは、そのルールセットとシートがそのまま残ります。切り替えるには、一覧で新しいルールセットを選んでください。

選んだ振り方をするルールセットがすでにインストールされている場合は、**Dice**セクションにその名前が表示されます。ルールセットは、どのキャラクターでもそれぞれ別のシートになります。そのため、キャラクター1人につきシートを1枚に保つには、新しく作らずに、そのルールセットで遊ぶか、そのルールセットを編集してください。

| ダイス | 判定の振り方 |
| --- | --- |
| **d20 + modifier**(d20+修正値) | d20に能力値とスキルを加え、難易度の数値と比べます。 |
| **2d6 bands**(2d6の結果帯) | 2d6に能力値を加えます。10以上は強いヒット、7～9は弱いヒット、6以下はミスです。 |
| **Dice pool**(ダイスプール) | 能力値とスキルの1ポイントにつき、ダイスを1個振ります。目標値に届いたダイスをそれぞれ数えます。d6とd10のどちらを使うかと、目標値を選びます。 |
| **Highest d6**(最も高いd6) | 1ポイントにつきd6を1個振り、最も高い出目を採用します。6は完全な成功、4か5は部分的な成功、6が2個ならクリティカルです。 |
| **Percentile**(パーセンタイル) | d100を1個振ります。スキルの数値以下なら判定は成功します。 |
| **Hope and Fear**(希望と恐怖) | d12を2個振り、能力値を加えます。結果が希望を伴うか恐怖を伴うかは、高いほうのダイスが示します。 |
| **No dice**(ダイスなし) | 何も振りません。能力値とスキルを合計し、難易度と比べます。 |

### 自分で作ったルールセットを変更する

1. チャットでそのルールセットをオンにします。
2. **Chat Settings → Ruleset**で、**Edit ruleset**(ルールセットを編集)をクリックします。
3. 変更を加え、**Save new version**(新しいバージョンを保存)をクリックします。

チャットは新しいバージョンに移り、すべてのシートを保ちます。能力値、スキル、プール、一覧の列の名前を変えても、各キャラクターがそこに持っている値はそのまま残ります。同じルールセットを使う別のチャットは、そのチャットで**Add missing sheets**(足りないシートを追加)をクリックすると、新しいバージョンに移ります。

**Edit ruleset**は、自分で作ったルールセットか、ファイルからインポートしたルールセットのうち、フォームがその全体を扱えるものに表示されます。ビルダーで作ったものか、フォームに表示される内容だけを使って手で書いたファイルです。パッケージやリポジトリーから入手したルールセットには表示されません。ビルダーは、戦闘のルールやコメントなど、それ以上のものを含むルールセットを開かないため、表示しないものを取りこぼすことはありません。また、最新のバージョンで遊んでいるチャットにだけ表示されます。古いバージョンのチャットでは、先に**Add missing sheets**をクリックしてください。

### シートのレイアウトを決める

| フォームでの指定 | シートでの表示 |
| --- | --- |
| 行の順序 | 能力値、スキル、プール、トラック、欄、一覧のタブは、フォームと同じ順に表示されます。行を移動するには、ハンドルをつかんでドラッグするか、ハンドルにフォーカスを移して上下の矢印キーを押します。 |
| 能力値やスキルの**Group**(グループ) | 同じグループの能力値やスキルは、1つの見出しの下に表示されます。 |
| **Skill ranks**(スキルのランク) | シートで各スキルに選ぶランクと、それぞれのランクが加えるものです。d20や2d6のロールでは合計に、プールではダイスを、パーセンタイルではポイントを加えます。 |
| **Show ranks on the sheet as**(シートでのランクの表示) | 習熟した各スキルとセーヴの横に、シートが表示するものです。**Check value (+2)**(判定値)、**Rank name**(ランク名)、**Dots (●●○)**(ドット)、**Roman numerals (II)**(ローマ数字)、**Rank number (2)**(ランクの番号)のいずれかを選びます。判定と、ナレーターに渡すシートの内容は変わりません。 |
| **Practice meter**(練習メーター) | 習熟した各スキルに、次のランクまでの進み具合が0～99%で表示されます。物語の中で練習すると上がり、ランクが上がると最初からになります。シート上で修正することもできます。**No meter for:**(メーターなし)でグループのチェックボックスをオンにすると、そのグループのスキルが対象から外れます。 |
| プールやトラックの**Number**(数値)、**Bar**(バー)、**Dots**(ドット) | 数値だけ、数値の横に並ぶ塗りつぶしのバー、または数値まで塗りつぶしたドットの列(1ポイントにつき1ドット)です。20個を超えるドットはバーとして表示されます。 |
| **Lists**(一覧) | 一覧ごとに専用のタブがあり、別のタブ名を入力しない限り、一覧の名前がタブ名になります。同じタブ名の一覧は、1つのタブを共有します。 |
| 一覧の列 | どの行にも名前があり、それに加えて自分で作った列があります。列は**Text**(テキスト)、**Number**、**Checkbox**(チェックボックス)のいずれかです。最初のチェックボックスの列は、各名前の横にチェックマークとして表示されます。 |

### ナレーターにルールを伝える

**Prompts**(プロンプト)セクションには、ルールセットについてナレーターに伝える内容が入ります。**Checks**(判定)と**Keeping the sheets**(シートの管理)にはデフォルトが表示されます。どちらも、空のままにするとそのデフォルトが使われます。改行はスペースになります。名前とプロンプトには、角括弧と二重の波括弧を使えません。ナレーターのタグとマクロがそれらを使うためです。

| 欄 | 用途 |
| --- | --- |
| **Checks** | いつ判定を求めるか、スキルと難易度をどう選ぶかです。 |
| **Keeping the sheets** | プレイ中にシートがどう変わるかです。 |
| **Rules reference**(ルールリファレンス) | ハウスルールなど、ナレーターが常に手元に置いておくべきものです。 |
| **World (Game Mode)**(Game Modeの世界) | そのルールセットでGame Modeのゲームを作成するときに1回だけ読まれ、世界がルールに合うようにします。 |

## トラブルシューティング

| 症状 | 対処 |
| --- | --- |
| **This chat's ruleset is not installed here, so its checks and sheets are paused.** | ルールセットを入れ直すか、別のものを選んでください。 |
| ナレーターが判定をまったく求めない。 | チャットにもっと強いモデルを使ってください。判定の指示を飛ばすモデルがあります。 |
| 新しいキャラクターにシートがない。 | **Add missing sheets**をクリックしてください。 |
