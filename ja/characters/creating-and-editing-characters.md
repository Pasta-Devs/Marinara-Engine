# キャラクターの作成と編集

キャラクターカードとは、AIキャラクターを定義するファイルです。どんな人物か、どんな話し方をするか、どんな見た目か、チャットがどう始まるかを収めています。カードはCharacter Editor(キャラクターエディター)で書きます。AIは返信のたびにカードの各欄を読むため、具体的で分かりやすく書くほどキャラクターの言動が安定します。

## キャラクターを作る

1. 上部のナビゲーションバーで**Characters**(キャラクター)をクリックします。見当たらない場合は、先に**More**(その他)を開きます。
2. **New**(新規)ボタン(プラスのアイコン)をクリックします。**Create Character**(キャラクターの作成)ウィンドウが開きます。
3. **Name \***欄に名前を入力します。名前は必須です。
4. 丸いアバターの円をクリックして画像を追加します。この手順は省略できます。
5. **Create**(作成)をクリックします。

カードは中身が空のまま保存され、Character Editorが開きます。

6. **Card**タブを開き、**Description**(説明)にキャラクターがどんな人物かを書きます。**Dialogue & Greetings**(会話と挨拶メッセージ)の下に**First Message**(最初のメッセージ)を追加します。これがRoleplayのチャットの書き出しになります。
7. ヘッダーの**Save**(保存)をクリックします。

すでにカードのファイルを持っている場合は、代わりに**Import**(インポート)をクリックします。[キャラクターカードのインポートとエクスポート](import-export.md)を参照してください。

### 作ったキャラクターとチャットを始める

チャットを始めるときに、そのキャラクターを選びます。[Roleplayモード: はじめに](../roleplay/getting-started.md)または[Conversationモード: はじめに](../conversation/getting-started.md)を参照してください。

## Character Editorの全体像

Character Editorは、チャット領域を全画面の作業スペースに置き換えます。画面幅が広いときはタブが左側に縦に並び、狭いときは上部で横スクロールする帯になります。タブは順に**Metadata**、**Card**、**Onboarding**、**Convo**、**Lorebook**、**Sprites**、**Gallery**、**Colors**、**Voice**、**Stats**、**Advanced**です。各タブは1つの長いフォームの該当セクションへ移動するためのものなので、スクロールして見ることもできます。

ヘッダーには、よく使う要素がまとまっています。

- **Back**(戻る)の矢印、アバターのタイル、名前の欄、そして`Modern AU version`のような短いラベルを入れるタイトルまたはコメントの欄。その下の行に作成者とバージョンが表示されます。
- **Save**(保存)。何かを変更するまでは無効です。処理中は表示が変わります。**Uploading…**はアバターのアップロード中、**Embedding…**はロアブックをカードに追加している最中、**Saving…**は保存中です。
- **Favorite**(お気に入り)の星。
- **Export character**(キャラクターのエクスポート)。[キャラクターカードのインポートとエクスポート](import-export.md)を参照してください。
- **Import character as persona**(ペルソナとしてインポート)。このカードを新しいペルソナにコピーします。[ペルソナ](personas.md)を参照してください。
- **Duplicate character**(キャラクターの複製)。
- **Delete character**(キャラクターの削除)。

エディターを離れると、先に変更が保存されます。保存に失敗した場合は、下書きを残したままエディターが開いた状態になるので、もう一度試せます。

専用のガイドがあるタブは次のとおりです。

| タブ | ガイド |
| --- | --- |
| **Onboarding** | [対話式オンボーディング](interactive-onboarding.md) |
| **Convo** | [Conversationモードのプロフィール](../conversation/profiles.md) |
| **Lorebook** | [ロアブックをキャラクターに結び付ける](../lorebooks/linking-to-characters.md) |
| **Sprites** | [キャラクターのスプライト](sprites.md) |
| **Gallery** | [キャラクターとペルソナのギャラリー](galleries.md) |
| **Colors**と**Stats** | [キャラクターの色とロールプレイ用ステータス](colors-and-stats.md) |

以下のセクションでは、**Metadata**、**Card**、**Voice**、**Advanced**の各タブと、アバター、バージョン履歴を説明します。

<a id="metadata-tab"></a>

## Metadataタブ

**Metadata**タブには、カードの身元と整理に関わる情報が入ります。カードの並べ替え、共有、変更の把握に役立つ項目で、その多くはAIには送られません。

- **Character ID**。読み取り専用で、カードを保存したあとに表示されます。**Copy**(コピー)をクリックするとコピーできます。
- **Name**(名前)。表示される名前です。プロンプトの中では`{{char}}`になります。これは、Marinaraがキャラクターの名前に置き換えるプレースホルダーです。
- **Creator**(作成者)。カードを作った人で、共有するときのクレジットになります。
- **Version**(バージョン)。`1.0`のように自分で決めるバージョン番号です。隣にある**Automatic versioning**(自動バージョン管理)スイッチは、以前のバージョンを残し、カードが変わるとこの番号を上げます。バージョン履歴にスナップショットが保存されるのは、このスイッチがオンのときだけです。
- **Talkativeness**(発言頻度)。0から100パーセントまでのスライダーです。グループチャットでこのキャラクターがどのくらい発言するかを決めます。デフォルトは50パーセントです。
- **Tags**(タグ)。タグ追加欄にタグを入力し、<kbd>Enter</kbd>を押すか**Add**(追加)をクリックします。複数のタグはカンマで区切ります。この欄には、ライブラリーですでに使われているタグが、よく使われているものから順に候補として表示されます。タグを1つ外すにはそのXを、すべて外すには**Remove All**(すべて削除)を使います。
- **Creator Notes**(作成者メモ)。AIには一切送られない非公開のメモです。

**Split description into fields**(説明を各欄に分割)は、**Version**の下にあるボタンです。ラベルの付いた文章(性格、外見、来歴、シナリオ、ルール、会話例)を、**Description**からそれぞれ専用の欄へ移します。まず短い要約が表示され、適用するとカードが新しいバージョンとして保存されます。**Description**が空のあいだ、このボタンは無効です。

**Version history**(バージョン履歴)パネルもこのタブにあります。[バージョン履歴](#version-history)を参照してください。

<a id="card-tab"></a>

## Cardタブ

**Card**タブは、書き込みの中心になる作業スペースです。上部のジャンプリンクから各セクションへ移動でき、各欄には文字数のカウンターが入力に合わせて表示されます。

| 欄 | 書く内容 | AIへの送信 |
| --- | --- | --- |
| **Summary**(概要) | ライブラリーとカードのプレビューに表示する短い概要。 | なし |
| **Description**(説明) | キャラクターの基本的な人物像と役割。 | すべてのプロンプト |
| **Personality**(性格) | 気質、話し方の癖、行動のパターン。 | あり |
| **Backstory**(背景設定) | 生い立ちや出自、重要な人間関係。 | あり |
| **Appearance**(外見) | 容姿、服装、見た目の細部。AIアバターのプロンプトのもとにもなります。 | あり |
| **Scenario**(シナリオ) | このキャラクターと新しくチャットを始めるときの、デフォルトの状況設定。 | あり |

**Image Appearance Override**(画像用の外見指定)は**Appearance**の下にあり、デフォルトではオフです。オンにすると、短い画像用タグを入れる2つ目の欄が現れます。たとえばLoRAのトリガーワード(独自の画像スタイルをオンにするキーワード)です。オンで内容が入っているあいだは、画像プロンプトにそのタグが書いたとおりに使われ、**Appearance**は背景情報として残ります。AIアバターのプロンプトもここから作られます。ナレーターには、常に**Appearance**の全文が見えます。

**Dialogue & Greetings**(会話と挨拶メッセージ)セクションでは、チャットの始まり方とキャラクターの語り口を決めます。

- **First Message**(最初のメッセージ)。新しいRoleplayのチャットの最初のメッセージです。ConversationとGameのチャットは、挨拶メッセージから始まりません。
- **Alternate Greetings**(別の挨拶メッセージ)。追加の書き出しのメッセージです。Roleplayのチャットを始めるときに、どれを使うか選べます。上下のボタンで並べ替え、Xで削除します。
- **Example Dialogue**(会話例)。キャラクターの語り口を教えるやり取りの見本です。やり取りの区切りには`<START>`を、プレースホルダーには`{{user}}`と`{{char}}`を使います。

```text
<START>
{{user}}: Hello!
{{char}}: *waves excitedly* Hey there!
```

挨拶メッセージと会話例には、キャラクターのGalleryの画像も表示できます。[ギャラリー画像をメッセージや挨拶で再利用する](galleries.md#reuse-a-gallery-image-in-messages-and-greetings)を参照してください。挨拶メッセージにほかのWebサイトの画像がある場合は、**Save images locally**(画像をローカルに保存)でそのコピーをGalleryに残せます。[挨拶メッセージのWeb画像を保存する](galleries.md#save-web-images-from-greetings)を参照してください。

<a id="write-a-card-field-with-the-wand"></a>

### 杖でカードの欄を書く

**Summary**、**Description**、**Personality**、**Backstory**、**Appearance**、**Scenario**、**Example Dialogue**、**First Message**、各**Alternate Greeting**の欄の上には、アイコンだけの杖のボタンがあります。ツールチップに、そのボタンが書く欄の名前が表示されます。

始める前に: 動作するテキスト接続を設定してください。[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。

1. 残したいアイデアを欄に書きます。たとえば`smart, scientist, handsome`のように入力するか、空欄のままにします。
2. AIに参考にしてほしいほかのカードの欄を埋めます。先に保存する必要はありません。
3. その欄の杖をクリックします。Marinaraは、入力済みの文章を出発点にして、その欄を100–300語で書くよう依頼します。Example Dialogueでは、やり取りの見本を依頼します。**First Message**と各**Alternate Greeting**では、こちらの返答を決めつけない書き出しのメッセージを1つ依頼します。
4. 結果を編集してから、**Save**をクリックします。

杖は、デフォルトのエージェント用テキスト接続を使います。それがない場合は、デフォルトのテキスト接続を使います。設定済みのエージェント用フォールバック接続も適用されます。

杖が置き換えるのは、未保存の下書きのうち選んだ欄だけです。生成に失敗しても、入力した文章は残ります。待っているあいだにその欄を編集したり、別のカードに切り替えたりしても、遅れて届いた結果が作業内容を上書きすることはありません。杖を使うのにProfessor Mariは必要ありません。

## アバターを追加する

アバターは、チャットとライブラリーでそのキャラクターとして表示される画像です。

### 画像をアップロードする

1. エディターのヘッダーにあるアバターのタイルをクリックします。
2. 画像ファイルを選びます。新しい画像はすぐに表示されます。

アバターを設定すると、**Metadata**タブにアバターの切り抜きツールが表示されます。円の中で画像を動かしたり拡大縮小したり、アバターを削除したりできます。

### AIでアバターを生成する

始める前に: 画像生成用の接続を追加してください。AIアバターのボタンは、画像生成用の接続があるときにだけ表示されます。[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。

1. アバターのタイルにマウスを重ね、杖のボタンをクリックします。**Generate Character Avatar**ウィンドウが開きます。
2. **Image Generation Connection**(画像生成の接続)を選びます。
3. **Avatar Prompt**(アバターのプロンプト)を確認し、必要なら書き換えます。**Image Appearance Override**がオンで内容が入っている場合は、その文章から始まります。それ以外の場合は、**Appearance**、**Description**、**Personality**の順に見て、最初に文章が入っているものが使われます。
4. カードにすでにアバターがある場合は、**Use current avatar as a reference**(現在のアバターを参照画像として使う)にチェックを入れられます。
5. **Generate**(生成)をクリックします。やり直すときは**Regenerate**(再生成)をクリックします。
6. 気に入った結果が出たら、**Use Avatar**をクリックします。

画像のサイズは、画像生成設定にある**Portraits**の画像サイズに従います。デフォルトは横1024、縦1024です。**Expose media prompts before sending**がオンの場合は、リクエストのたびにプロンプトを確認する手順が入ります。

## Voiceタブ

**Voice**タブでは、Text to Speechで読み上げるときのキャラクターの声を設定します。

- **Voice**(声)。このキャラクターの声です。変更は**Save**を押さなくてもすぐに保存されます。**Connections → Text to Speech**(接続 → 音声合成)にあるこのキャラクターの行と同じ設定です。空欄のままにすると、デフォルトの声を使います。名前が一致するカード(AU版のコピー元など)に声が設定されている場合は、このカードもその声を使うため、空欄にはその声の名前が表示されます。
- **Preview**(試聴)。その声で短い文を読み上げます。文にはキャラクターの名前が入り、**Phonetic name**(読み仮名)を設定している場合はそちらが読まれます。
- **Phonetic name**。発音を直すためだけに使う、任意の表記です。カードの一部なので、残すには**Save**をクリックしてください。

Text to Speechがオフのとき、またはすべてのキャラクターが1つの声を共有しているときは、**Voice**欄の代わりに短い案内が表示されます。1つの声を共有している場合は、案内に**Use a voice per character**(キャラクターごとの声を使う)が表示されます。**Open Text to Speech settings**(音声合成の設定を開く)を押すとConnectionsが開きます。[Text to Speech (TTS)の設定](../media/tts-setup.md)を参照してください。

## Advancedタブ

**Advanced**タブには、プロンプトの設定があります。普通のキャラクターなら、いずれも空欄のままにしてください。これらはConversation、Roleplay、Gameの各モードで適用されます。ConversationやGameのプリセットを使うと周囲のプロンプトは変わりますが、キャラクターのPost-History InstructionsやDepth Promptが無効になることはありません。

- **System Prompt**(システムプロンプト)。有効なプリセットのキャラクターブロック、Conversationのキャラクターコンテキスト、またはGameのキャラクターカードを通じて追加される、キャラクター固有の指示です。チャット本体のシステムプロンプトを置き換えるものではありません。
- **Post-History Instructions**(履歴の後に置く指示)。チャット履歴の後、AIが書き始める直前に置かれる文章です。たとえば「Stay in character」のような文です。
- **Depth Prompt**(深さを指定するプロンプト)。チャット履歴の中に挿入される文章です。**Depth**(深さ)は何メッセージ分さかのぼるかを表し、0は最新のメッセージの直後です。デフォルトは4です。**Role**(役割)は**System**、**User**、**Assistant**のいずれかで、デフォルトはSystemです。

**Regex Scripts**セクションには、このキャラクターだけに適用される検索置換のスクリプトが入ります。[正規表現スクリプト](../extending/regex-scripts.md)を参照してください。

<a id="use-an-alternative-field-in-selected-chats"></a>

## 選択したチャットで代替項目を使う

代替項目を使うと、同じキャラクターでも、選んだチャットでだけ説明、外見、来歴などの内容を変えられます。ほかのチャットでは元の内容のままです。7つのカード項目の下には、それぞれ**Add Alternative Field**(代替項目を追加)があります。

1. 変えたい項目の下で**Add Alternative Field**をクリックします。Marinaraがその欄の文章を新しい代替項目にコピーします。
2. 任意: **Backstory alternative 1**(経歴の代替版1)のような代替項目のタイトルをクリックし、`Young`のような名前を入力します。名前は60文字までです。名前を空のままにすると、番号付きのタイトルのままになります。
3. 代替項目を編集します。代替項目には専用の杖があり、代替項目の文章を出発点に使います。元の欄は変更しません。
4. **Active in 0 chats**(0件のチャットで有効)を開き、この代替項目を使うチャットにチェックを入れます。このキャラクターが参加しているチャットだけが表示されます。
5. **Save**をクリックします。

チャットの中から選ぶこともできます。**Chat Settings**(チャット設定)を開き、**Card Field Alternatives**(カード項目の代替)を展開します。チャットのペルソナと、代替項目を持つチャット内の各キャラクターが一覧表示され、項目ごとにメニューが1つあります。**Original**(元の項目)か、名前で代替項目を選びます。カードはすぐに保存され、選んだ内容は次の返信から使われます。チャットの中に代替項目を持つものがなければ、このセクションは表示されません。

ルールは次のとおりです。

- 1つのチャットで使える代替は、1つの項目につき1つだけです。別の代替でそのチャットにチェックを入れるか、Chat Settingsで別の代替を選ぶと、割り当てがそちらに移ります。
- どのチャットにもチェックを入れなければ、代替項目は後で使うために無効のまま残ります。
- 空の代替項目は、割り当てたチャットでその項目を空にします。
- チャット固有のシナリオと画像用の外見の上書きは、これまでどおり優先されます。
- **Summary**の代替はメタデータのままで、AIには送られません。
- キャラクターがチャットから外れると、その割り当ては休止し、キャラクターを追加し直すと再開します。
- カードのエクスポート、インポート、複製、キャラクターとペルソナの相互変換では、代替の文章は残りますが、チャットのチェックは解除されます。プロファイル全体のバックアップでは、チェックも保持されます。

代替項目を削除するには、そのゴミ箱ボタンをクリックし、**Delete**(削除)で確認してから、**Save**をクリックします。割り当てられていたチャットは元の項目に戻ります。代替項目と一緒に元の項目が削除されることはありません。

<a id="version-history"></a>

## バージョン履歴

**Automatic versioning**がオンのあいだは、保存のたびに**Metadata**タブの**Version history**(バージョン履歴)へスナップショットが追加されることがあります。それまでは、`Previous card states will appear here after the next edit.`と表示されます。保存されているスナップショットの数はカウンターでわかります。

保存済みのバージョンを現在のカードと見比べる手順は次のとおりです。

1. **Metadata**タブを開きます。
2. **Version history**で、保存済みのバージョンをクリックします。比較ウィンドウが開き、カードの各項目が左右に並び、変更があった項目には印が付きます。

古いバージョンに戻す手順は次のとおりです。

1. そのバージョンの比較ウィンドウを開くか、一覧にある復元アイコンをクリックします。
2. **Restore this version**(このバージョンを復元)をクリックし、確認します。

Marinaraはまず現在のカードをバージョン履歴に保存するので(すでにそのバージョンと同じ場合を除く)、あとで元に戻せます。

パネルには、ほかに次の操作があります。

- 鉛筆アイコンは、復元せずにスナップショットのカードバージョン番号を変更します。
- ゴミ箱アイコンはスナップショットを削除します。現在のカードは変わりません。
- **Reset**(リセット)は、保存済みのスナップショットをすべて削除し、カードのバージョンを1.0にします。Marinaraが確認を求めます。この操作は取り消せません。未保存の編集があるあいだ、**Reset**は無効です。

## エージェントが提案するカード更新の確認

Roleplayのチャットでは、任意のエージェントが場面に合わせて、カードの項目に小さな修正を提案することがあります。**Review Character Card Updates**(カード更新の確認)ウィンドウが開くので、何を残すかを自分で決めます。提案された修正ごとに、次の操作を選べます。

- **Approve**(承認)は修正を適用し、バージョン番号を上げ、バージョン履歴に記録を追加します。
- **Regenerate**(再生成)は、エージェントにもう一度やり直させます。
- **Reject**(却下)は提案を破棄します。

提案が作られたあとに文章が変わっていた場合は、強制的に適用する前にアプリが警告します。こうしたエージェントをオンまたはオフにする方法は、[エージェント: チャットを支えるAIヘルパー](../agents/agents-overview.md)を参照してください。

## うまくいかないときは

- **杖が何もしない、または失敗する。** 動作するテキスト接続があるか確認してください。失敗しても、下書きが上書きされることはありません。
- **AIアバターのボタンがない。** 先に画像生成用の接続を追加してください。
- **Professor Mariを削除できない。** Professor Mariは、Marinaraが起動するたびにリセットする組み込みのキャラクターです。[Professor Mari: アプリ内アシスタント](../home/professor-mari.md)を参照してください。
