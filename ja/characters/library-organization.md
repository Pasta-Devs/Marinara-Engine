# キャラクターライブラリーの整理

このガイドでは、作成したキャラクターがすべて並ぶサイドバーの**Characters**(キャラクター)パネルについて説明します。検索と並べ替え、フォルダーへのグループ分け、お気に入りの登録、タグでの絞り込み、そして複数のキャラクターをまとめてエクスポートしたり削除したりする方法がわかります。

## Charactersパネル

**Characters**パネルは、サイドパネルに表示されるキャラクターの一覧です。作成したキャラクターとインポートしたキャラクターがすべてここに入ります。パネル上部からは次の操作ができます。

- **Download**(ダウンロード)をクリックすると[Card Browser](bot-browser.md)が開き、公開サイトでキャラクターを探せます。
- **Open Library**(ライブラリーを開く)をクリックすると、同じキャラクターをページ全体の大きなグリッド表示で開きます。
- **New**(新規作成)ボタン(プラスのアイコン)をクリックすると、**Create Character**(キャラクターの作成)ウィンドウが開きます。
- **Import**(インポート)ボタン(ダウンロードのアイコン)をクリックすると、キャラクターのファイルをインポートできます。
- **Select**(選択)ボタン(チェックのアイコン)をクリックすると、まとめて操作するための複数選択モードがオンになります。

ライブラリー全体の表示には**Settings**(設定)で選んだクロマ文字色が使われます。キャラクターを開いて編集し、戻ってきたときも、選択中のカード、並び順、スクロール位置はそのまま保たれます。

キャラクターの行には、アバター、名前、任意のタイトル行、作成者とバージョン、最大3つのタグ、おおよそのトークン数が表示されます。お気に入りには小さな星のバッジが付きます。行にカーソルを合わせると、**Duplicate**(複製)ボタンと**Delete**(削除)ボタンが現れます。

キャラクターの数が多いときは、一覧の下に**Load more**(さらに読み込む)ボタンが表示されます。クリックすると次のページ分のキャラクターを読み込みます。

## 検索

パネル上部の検索ボックスに文字を入力すると、一覧を絞り込めます。プレースホルダーの文字列は**Search characters or -tag:"tag name"**です。

ふつうの文字列は、キャラクターの名前、タイトル、説明、タグに対して照合されます。たとえば`knight`と入力すると、これらのどれかに「knight」を含むキャラクターがすべて表示されます。

特定のタグが付いたキャラクターを除外することもできます。タグの前にマイナス記号を付けます。

```
-tag:"tag name"
```

タグの除外について知っておきたい点がいくつかあります。

- タグに空白が含まれる場合は`-tag:"slow burn"`のように引用符で囲みます。
- 1語だけのタグなら`-vampire`のように引用符を省略できます。
- タグを除外すると、検索文字列のほうが一致していても、そのタグを持つキャラクターはすべて隠れます。

同じボックスの中で、ふつうの文字列と除外を組み合わせられます。たとえば`mage -tag:"villain"`は、「mage」に一致するキャラクターを表示しつつ、「villain」のタグが付いたものを隠します。

## 並べ替え

検索ボックスの隣にあるのが並べ替えのドロップダウンです。次のいずれかの順序を選びます。

| 選択肢 | 動作 |
| ------------- | ------------------------------- |
| **Manual order** | 自分で決めた順に並べます。 |
| **A-Z** | 名前をAからZの順に並べます。 |
| **Z-A** | 名前をZからAの順に並べます。 |
| **Newest** | 作成日が新しいものから並べます。 |
| **Oldest** | 作成日が古いものから並べます。 |
| **Favorites** | お気に入りを先に、残りをその後に並べます。 |

手動で順番を決めるには、キャラクターの行を上下にドラッグします。行にフォーカスを合わせてAlt+上矢印キーまたはAlt+下矢印キーを押しても動かせます。どちらの操作でも、並べ替えは**Manual order**(手動の順番)に切り替わります。

## フォルダー

フォルダーを使うと、関連するキャラクターをパネルの中でまとめられます。使うかどうかは自由です。すべてのキャラクターを1つの平らな一覧のまま置いておいてもかまいません。

フォルダーを作成する手順は次のとおりです。

1. **New Folder**(新しいフォルダー)ボタンをクリックします。
2. 新しいフォルダーができ、デフォルトでは**unnamed**という名前が付きます。
3. その場で名前を変えるか、後から変更します(下記を参照)。

フォルダーの名前を変えるには、ダブルクリックするか、ダブルタップするか、選択してからF2キーを押します。新しい名前を入力してEnterを押します。

キャラクターをフォルダーに入れるには、キャラクターの行をドラッグしてフォルダーの上でドロップします。フォルダーが1つ以上あると、**Drag and drop characters to folders, double-click or double-tap to rename**という補助テキストが表示されます。フォルダーから出すには、フォルダー内でその行にカーソルを合わせてフォルダーから外すボタンをクリックするか、外へドラッグします。

タッチスクリーンでは、行を長押しして持ち上げてから、ドラッグします。普通にスワイプすれば、一覧はそのままスクロールします。1つの行を押さえたまま、別の指でほかの行をタップすると、それらも重ねていっしょに運べます。そのままフォルダーの上で離してください。

フォルダーをクリックすると開閉できます。フォルダー名の隣の数字は、中に入っているキャラクターの数です。

フォルダーを削除するには、フォルダーにカーソルを合わせてゴミ箱ボタンをクリックします。中にキャラクターが入っている場合は、確認メッセージが表示されます: **Delete "name"? Its N characters will stay in the library and move out of the folder.**空のフォルダーは確認なしですぐに削除されます。フォルダーを削除しても、中のキャラクターが消えることはありません。メインの一覧に戻るだけです。

## お気に入りとタグチップ

### お気に入り

キャラクターをお気に入りにしておくと、後から見つけやすくなります。お気に入りの星は、パネルの一覧からではなくキャラクター自体の画面で設定します。キャラクターを開き、**Favorite**(お気に入り)の星をクリックしてオンとオフを切り替えます。お気に入りにしたキャラクターは、パネルのアバターに小さな星のバッジが付きます。

検索欄の下には3つの絞り込みボタンがあります。

- **All**はすべてのキャラクターを表示します。
- **Favs**はお気に入りだけを表示します。
- **Non-favs**はお気に入り以外のキャラクターだけを表示します。

並べ替えのドロップダウンで**Favorites**を選び、お気に入りを一覧の先頭にまとめることもできます。

### タグ

タグは、キャラクターの特徴を表すためにキャラクターへ付けるラベルです。たとえば`fantasy`や`slow burn`などです。タグの追加と編集はキャラクターエディターで行います。

パネルでは、各キャラクターの行に最大3つのタグが表示されます。どれかの行のタグチップをクリックすると、そのタグを持つキャラクターだけに一覧が絞り込まれます。

キャラクターにタグが付いていると、絞り込みの並びに**Tags**(タグ)ボタンが現れ、タグの総数が丸括弧の中に表示されます(たとえば**Tags (12)**)。クリックするとタグの一覧が展開します。

- 展開した一覧でタグをクリックすると、そのタグが絞り込み条件に加わります。複数のタグをクリックした場合は、選んだタグのいずれかを持つキャラクターが一致します。
- 展開した一覧の各タグには小さなXが付いています。これをクリックすると、そのタグが付いたすべてのキャラクターからタグを削除します。確認を求められます: **Remove tag "name" from all characters?**
- タグの絞り込みが有効になると**Clear**(クリア)ボタンが現れます。クリックするとタグの絞り込みを解除します。

タグを含めるのではなく除外したいときは、上の「検索」で説明した`-tag:`の書き方を使います。

## まとめて選択、エクスポート、削除

複数のキャラクターを一度に操作したいときは、選択モードを使います。

1. パネル上部の**Select**ボタンをクリックします。
2. キャラクターの各行にチェックボックスが表示されます。
3. 対象にしたいキャラクターをクリックします。選択した数はパネルのヘッダーに表示されます。
4. パネル下部の操作バーを使います。

操作バーには2つのボタンがあります。

- **Export**(エクスポート)は、選択したキャラクターをまとめて`marinara-characters.zip`という1つのzipファイルとしてダウンロードします。これはMarinara Engine独自の形式による一括エクスポートです。
- **Delete**は選択したキャラクターをすべて削除します。実行前に確認を求められます: **Delete N characters?**

選択モードの間は、選んだキャラクターを1つずつ動かす代わりに、まとめてフォルダーへドラッグすることもできます。

インポートとエクスポートで扱えるファイル形式の全体像は、下記のインポートとエクスポートのガイドを参照してください。

## フォルダーはグループチャットの名簿にもなる

ここで作ったフォルダーには、もう1つの使い道があります。それぞれのフォルダーは、グループチャットにそのまま投入できる保存済みの名簿でもあります。

複数のキャラクターでチャットを始めるときは、**Add from Folder**(フォルダーから追加)という選択肢を探してください。選んだフォルダーの中のキャラクターを1回の操作ですべて追加します。いつも一緒に使うキャラクターの組み合わせでグループチャットを始めるには、これがいちばん速い方法です。グループチャットの仕組みについては、下記のグループチャットのガイドを参照してください。
