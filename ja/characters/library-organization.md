# キャラクターライブラリーの整理

**Characters**(キャラクター)パネルは、作成またはインポートしたすべてのキャラクターが並ぶサイドバーの一覧です。ここでは、検索と並べ替え、フォルダーへのグループ分け、お気に入りの登録、タグでの絞り込み、そして複数のキャラクターのまとめてのエクスポートや削除ができます。

## Charactersパネル

パネル上部からは次の操作ができます。

- **Download**(ダウンロード)をクリックすると[Card Browser](bot-browser.md)が開き、公開サイトでキャラクターを探せます。
- **Open Library**(ライブラリーを開く)をクリックすると、同じキャラクターをページ全体の大きなグリッドで開きます。
- **New**(新規作成)ボタン(プラスのアイコン)をクリックすると、**Create Character**(キャラクターの作成)ウィンドウが開きます。
- **Import**(インポート)ボタン(ダウンロードのアイコン)をクリックすると、キャラクターのファイルをインポートできます。[キャラクターカードのインポートとエクスポート](import-export.md)を参照してください。
- **Select**(選択)ボタン(チェックのアイコン)をクリックすると、まとめて操作するための選択モードがオンになります。

キャラクターを開いて編集し、戻ってきたときも、ライブラリー全体の表示では選択中のカード、並び順、スクロール位置がそのまま保たれます。

各行には、アバター、名前、任意のタイトル行、作成者とバージョン、最大3つのタグ、おおよそのトークン数が表示されます。お気に入りには小さな星のバッジが付きます。行にカーソルを合わせると、**Duplicate**(複製)と**Delete**(削除)が表示されます。キャラクターが多いときは、下部の**Load more**(さらに読み込む)をクリックすると次のページを読み込みます。

## 検索

上部の検索ボックスに入力します。プレースホルダーは**Search characters/tags**(キャラクター/タグを検索)です。ふつうの文字列は、大文字と小文字を区別せずに、キャラクターの名前、タイトル、説明、タグと照合されます。`knight`と入力すると、これらのどれかに「knight」を含むキャラクターがすべて表示されます。

| 検索 | 見つかるもの |
| --- | --- |
| `male genshin`または`male,genshin` | 両方のタグと完全一致するカード。 |
| `male "Modern AU"` | スペースやカンマを含むタグは引用符で囲みます。 |
| `-tag:"slow burn"` | 検索のほかの部分が一致していても、そのタグを持つカードをすべて隠します。 |
| `-vampire` | 1語のタグの場合も同じです。引用符は省略できます。 |
| `mage -tag:"villain"` | 「mage」に一致するカードのうち、「villain」のタグが付いたものを除いたもの。 |

通常のフレーズ検索もそのまま使えます。同じ検索は、ページ全体のCharacter Libraryでも、ペルソナでも使えます。

## 並べ替え

検索ボックスの隣にある並べ替えのドロップダウンで、順序を選びます。

| 選択肢 | 動作 |
| --- | --- |
| **Manual order** | 自分で決めた順に並べます。 |
| **A-Z** | 名前をAからZの順に並べます。 |
| **Z-A** | 名前をZからAの順に並べます。 |
| **Newest** | 作成日が新しいものから並べます。 |
| **Oldest** | 作成日が古いものから並べます。 |
| **Favorites** | お気に入りを先に、残りをその後に並べます。 |

手動で順番を決めるには、行を上下にドラッグするか、行にフォーカスを合わせて<kbd>Alt</kbd>+<kbd>Up</kbd>または<kbd>Alt</kbd>+<kbd>Down</kbd>を押します。どちらの操作でも、並べ替えは**Manual order**(手動の順番)に切り替わります。

## フォルダー

フォルダーを使うと、物語やシリーズごとなど、関連するキャラクターをまとめられるので、長い一覧を見渡しやすくなります。使うかどうかは自由です。

1. **New Folder**(新しいフォルダー)をクリックします。**unnamed**という名前のフォルダーが表示されます。
2. 名前を変えます。ダブルクリックするか、ダブルタップするか、選択してから<kbd>F2</kbd>を押します。新しい名前を入力して<kbd>Enter</kbd>を押します。
3. キャラクターの行をフォルダーの上へドラッグすると、フォルダーに入ります。フォルダーが1つでもあると、**Drag and drop characters to folders, double-click or double-tap to rename**という補助テキストが表示されます。

キャラクターをフォルダーから出すには、フォルダー内でその行にカーソルを合わせてフォルダーから外すボタンをクリックするか、外へドラッグします。フォルダーをクリックすると開閉できます。名前の隣の数字は、中に入っているキャラクターの数です。

タッチスクリーンでは、行を長押しして持ち上げてから、ドラッグします。普通にスワイプすれば、これまでどおりスクロールします。

複数をまとめて動かすには、1つの行を押さえたまま、別の指でほかの行をタップします。それらが重なっていっしょに運ばれます。そのあと、重ねた行をフォルダーの上で離します。

フォルダーを削除するには、フォルダーにカーソルを合わせてゴミ箱ボタンをクリックします。キャラクターが入っているフォルダーでは、確認を求められます: **Delete "name"? Its N characters will stay in the library and move out of the folder.**空のフォルダーはすぐに削除されます。フォルダーを削除しても、中のキャラクターが削除されることはありません。

### フォルダーをグループチャットの名簿として使う

各フォルダーは、グループチャット用の保存済みの名簿でもあります。複数のキャラクターでチャットを設定するとき、**Add from Folder**(フォルダーから追加)を使うと、フォルダー内のキャラクターを1回の操作ですべて追加できます。[グループチャットとグループでの会話](../chats/group-chats.md)を参照してください。

## お気に入りとタグ

### お気に入り

キャラクターを開き、**Favorite**(お気に入り)の星をクリックしてオンとオフを切り替えます。パネルの一覧からは設定できません。お気に入りには小さな星のバッジが付きます。検索ボックスの下にある3つのボタンで、一覧を絞り込めます。

- **All**はすべてのキャラクターを表示します。
- **Favs**はお気に入りだけを表示します。
- **Non-favs**はお気に入り以外のキャラクターだけを表示します。

並べ替えのドロップダウンで**Favorites**を選び、お気に入りを先頭に並べることもできます。

### タグ

タグは、`fantasy`や`slow burn`のようなラベルです。タグはキャラクターエディターで追加します。[キャラクターの作成と編集](creating-and-editing-characters.md#metadata-tab)を参照してください。パネルでは、どれかの行のタグチップをクリックすると、そのタグを持つキャラクターだけに一覧が絞り込まれます。

キャラクターにタグが付いていると、件数付きの**Tags**(タグ)ボタンが表示されます(例: **Tags (12)**)。クリックすると、タグの一覧全体が展開します。

- タグをクリックすると、絞り込み条件に加わります。複数のタグを選んだ場合は、そのいずれかを持つキャラクターが一致します。
- タグのXをクリックすると、そのタグが付いたすべてのキャラクターからタグを削除します。確認を求められます: **Remove tag "name" from all characters?**
- タグの絞り込みが有効になると、**Clear**(クリア)が表示されます。クリックすると、タグの絞り込みを解除します。

タグを除外したいときは、[検索](#search)で示したように、検索ボックスで`-tag:`を使います。

## 複数のキャラクターのエクスポートと削除

1. パネル上部の**Select**(選択)をクリックします。各行にチェックボックスが表示されます。
2. 対象のキャラクターをクリックします。選択した数はパネルのヘッダーに表示されます。
3. 下部の操作バーを使います。

操作バーには2つのボタンがあります。

- **Export**(エクスポート)は、選択したキャラクターをMarinaraのネイティブ形式で、`marinara-characters.zip`という1つのzipファイルとしてダウンロードします。
- **Delete**(削除)は、選択したキャラクターを削除します。最初に確認を求められます: **Delete N characters?**

選択モードでは、選んだキャラクターをまとめてフォルダーへドラッグすることもできます。ファイル形式については、[キャラクターカードのインポートとエクスポート](import-export.md)を参照してください。
