# キャラクターとペルソナのギャラリー

このガイドでは、キャラクターエディターとペルソナエディターにある**Gallery**(ギャラリー)タブを説明します。キャラクターやペルソナに紐づいたまま残る画像と動画を追加する方法、そしてギャラリーの画像をカスタム絵文字やスタンプとして登録する方法がわかります。

## Galleryタブ

**Gallery**タブは、すべてのキャラクターとすべてのペルソナに用意されています。**Character Editor**(キャラクターエディター)でキャラクターを開くか、**Persona Editor**(ペルソナエディター)でペルソナを開き、カメラのアイコンが付いた**Gallery**タブをクリックします。

Galleryには2つのサブタブがあります。

- **Images**(画像): このキャラクターまたはペルソナ用にアップロードした画像です。
- **Videos**(動画): アップロードした動画に加えて、このキャラクターに紐づくシーン動画と通話の映像も並びます。

キャラクターのギャラリーは**Character Gallery**、ペルソナのギャラリーは**Persona Gallery**という名前で表示されます。どちらも使い方は同じです。

## チャットのギャラリーとの違い

ギャラリーの画像は、特定のチャットではなくキャラクターやペルソナ自体に属します。チャットを削除しても、ギャラリーの画像はそのまま残ります。設定画や衣装違い、インポートしたキャラクター画像集などの置き場所に向いています。

チャット側のギャラリーは役割が異なります。こちらはそのチャット限定のシーン挿絵や、生成したメッセージの添付画像を保持します。一時的なシーンの絵はチャットのギャラリーに、長く使うキャラクターの絵はキャラクターやペルソナのGalleryに置いてください。

## 画像の追加

1. キャラクターまたはペルソナのエディターを開きます。
2. **Gallery**タブをクリックします。
3. **Images**サブタブが選択されているか確かめます。
4. 画像ファイルを**Upload Character Images**(キャラクター画像のアップロード)の枠にドラッグするか、枠をクリックしてファイルを選びます。ペルソナではこの枠の名前が**Upload Persona Images**になります。
5. アップロードが終わるまで待ちます。追加した画像は下のグリッドに表示されます。

JPG、PNG、GIF、WebP、AVIFなど、一般的な画像形式をアップロードできます。画像をクリックすると拡大表示になります。各画像のタイルには、ダウンロード用と削除用のボタンも付いています。

## 動画の追加

1. **Gallery**タブをクリックします。
2. **Videos**サブタブを選びます。
3. 動画ファイルを**Upload Character Videos**(キャラクター動画のアップロード)の枠にドラッグするか、枠をクリックしてファイルを選びます。ペルソナではこの枠の名前が**Upload Persona Videos**になります。
4. アップロードが終わるまで待ちます。

対応する動画形式はMP4、WebM、MOVです。**Videos**サブタブには、このキャラクターとのチャットで生成したシーン動画と、通話の映像も一覧に並びます。並び順は新しいものが先頭です。Conversationの動画メッセージは、その動画に映っているキャラクターのギャラリーにだけ並びます。映っているのは、送ったキャラクターと、本文で名前が挙がった相手です。チャット内にほかに同じ名前の人がいなければ、大文字で始まっていれば名だけでも構いません。本文がグループ写真やグループの自撮りを求めている場合は、チャットの全員が含まれます。引用符の中で話されている名前は数えません。ペルソナのギャラリーにこのクリップが並ぶのは、本文でペルソナの名前が挙がった場合だけです。それより前の動画と、RoleplayやGame Modeのチャットの動画は、そのチャットのすべてのキャラクターとペルソナのギャラリーに並びます。

## ギャラリーの画像をカスタム絵文字やスタンプにする

ギャラリーの画像は、**Conversation Mode**(メッセンジャー風のチャットモード)で使うカスタム絵文字やスタンプにできます。カスタム絵文字は`:name:`と書いて本文に埋め込む小さな画像、スタンプは`sticker:name:`と書いて表示する大きめの画像です。どちらもConversation Modeのチャットでのみ使えます。

登録の手順は次のとおりです。

1. **Gallery**タブを開き、**Images**サブタブを選びます。
2. 目的の画像を探します。左上の角に小さなタグボタンがあり、**Tag as emoji or sticker**というツールチップが表示されます。
3. タグボタンをクリックします。**Make emoji**と**Make sticker**が並ぶメニューが開きます。
4. **Make emoji**または**Make sticker**をクリックします。
5. **Custom Emoji**または**Custom Sticker**ウィンドウで名前を入力し、確定します。

名前に使えるのは半角英小文字、数字、アンダースコアで、長さは32文字までです。それ以外の文字は自動的に変換します。たとえば「Big Grin」は`big_grin`になります。

サイズの上限は、ギャラリーではなく選んだ種類によって決まります。絵文字にする画像は256×256ピクセル以下、スタンプにする画像は512×512ピクセル以下である必要があります。画像が大きすぎるとエラーメッセージが表示され、登録は行われません。

### 登録した画像の管理

登録が済むと、画像に重ねて表示されるボタンに設定した名前が出ます。クリックすると、次の操作を選べるメニューが開きます。

- **Rename**(名前の変更): 名前を変更します。
- **Switch to sticker**または**Switch to emoji**(種類の切り替え): 絵文字とスタンプを入れ替えます。切り替え時には新しい種類のサイズ上限を判定し直します。256×256ピクセルより大きいスタンプの画像は、絵文字にするには大きすぎます。その場合はエラーが表示され、種類は元のままになります。
- **Remove emoji**または**Remove sticker**(登録の解除): 登録を解除します。画像自体がGalleryから削除されることはありません。

### 登録した絵文字とスタンプが使える範囲

ギャラリーから登録した絵文字やスタンプは、そのキャラクターまたはペルソナ専用です。有効になるのは、そのキャラクターやペルソナが参加しているConversation Modeのチャットだけです。メッセージ入力欄にある全体共通の絵文字とスタンプとは別の扱いになります。

ギャラリー側の名前が全体共通の名前と重なった場合は、そのチャットではギャラリー側が優先されます。名前の重複チェックは行われないため、画像ごとに重ならない名前を付けてください。

## ギャラリー画像をメッセージや挨拶で再利用する

キャラクターのギャラリーにある画像は、挨拶、メッセージ例、キャラクターが送るメッセージなど、チャット本文の中に表示できます。画像にカーソルを合わせて**Copy image reference**（リンクアイコン）をクリックすると、キャラクターが話す場所に貼り付けられる短いMarkdownがコピーされます。

```text
![sunset selfie](card://self/gallery/k3m2xq7.png)
```

ルールは1つです。**`self`は、そのメッセージを話しているキャラクターを表します。** 描画時にMarinaraが`self`をそのキャラクターへ置き換え、ギャラリーの画像を表示します。

使える場所:

- キャラクターカードの**First Message**、**Alternate Greetings**、**Example Dialogue**。欄のMarkdownプレビューで、編集中も画像を確認できます。
- **Roleplay**モードでも**Conversation**モードでも、キャラクターが送るすべてのメッセージ。
- **グループチャット**: 複数の話者がいる返信では、`self`は話者ごとに解決されるため、各キャラクターの台詞にはそのキャラクター自身のギャラリー画像が表示されます。話者のギャラリーにそのファイルがない場合、Marinaraはチャットのほかのキャラクターのギャラリーから探します。そのため、返信が1人の話者の下にまとめられた場合でも、正しい画像が表示されます。

仕様上、使えない場所は次のとおりです。

- **自分のメッセージ**。話しているキャラクターがいないため、`self`の参照は壊れた画像として表示されます。キャラクターのギャラリー画像を自分で投稿したい場合は、チャットのアセットブラウザーの挿入機能を使ってください(完全な`card://characters/<id>/...`形式で書き込まれます)。
- **システムメッセージ**。Markdownの画像の書き方をまったく描画しないため、参照はそのまま文字として表示されます。
- **ペルソナのギャラリー**。ペルソナの画像は話者のいない自分のメッセージに表示されます。代わりにペルソナ用の`card://personas/<id>/gallery/<file>`形式を使ってください。

グループチャットでの注意点が1つあります。チャット内の2人のキャラクターが**同じファイル名**のギャラリー画像を持っている場合、話しているキャラクターの画像が必ず優先されます。話者がそのファイルを持っていない場合は**最初に一致したもの**が使われ、ほかのキャラクターはチャットのキャラクター順に確認されます。別のキャラクターの台詞から特定のキャラクターの画像を表示したい場合は、同じ名前の画像に別々のファイル名を付けてください。

### 完全なリンクではなく`self`を使う理由

完全なリンクにはキャラクターの内部ID（`card://characters/<id>/gallery/<file>`）が含まれます。IDはキャラクターをインポートするたびに再生成されるため、共有すると完全なリンクは壊れます。`self`形式にはIDもサーバーアドレスもありません。**ネイティブJSONのエクスポートとインポート**後も利用でき、ギャラリー画像はファイル名を保ったままエクスポートに含まれます。

ただし、**PNGカードのエクスポートにはギャラリーが含まれません**。ギャラリー参照を使うキャラクターは、ネイティブの`.json`エクスポートで共有してください。

### 挨拶メッセージのWeb画像を保存する

多くのカードは挨拶メッセージにほかのWebサイトの画像を表示していますが、そうしたリンクは切れたり変わったりすることがあります。**First Message**(最初のメッセージ)や**Alternate Greetings**(別の挨拶メッセージ)にWeb画像がある場合、**Dialogue & Greetings**(会話と挨拶メッセージ)に**Save images locally**(画像をローカルに保存)ボタンが表示されます。このボタンはそれらの画像をキャラクターのGalleryにダウンロードし、各リンクを`card://self/gallery/...`参照に置き換えます。そのため、Webサイトから画像が削除されたり、オフラインだったりしても画像は表示されます。新しいリンクを残すには、その後でキャラクターを保存してください。

ボタンを押すまで、何もダウンロードされません。保存されるのは、10 MB以下かつ40メガピクセル以下のPNG、JPEG、GIF、WebP画像だけです。自分のコンピューターや家庭内ネットワークを指すリンクは拒否されます。保存できなかった画像はWebリンクのまま残り、その理由が通知に表示されます。

**Restore web links**(Webリンクを復元)を押すと、挨拶メッセージに元のリンクが戻ります。保存したコピーは、削除するまでGalleryに残ります。互換形式のJSONとPNGのエクスポートでは元のWebリンクが使われます。これらのカードにはギャラリーが含まれないためです。ロアブックの画像は対象外です。
