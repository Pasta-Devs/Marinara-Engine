# Card Browser: キャラクターを探してインポートする

このガイドでは、Marinara Engineの**Card Browser**(カードブラウザー)について説明します。公開サイトにあるキャラクターカードを探し、そのままライブラリーに取り込むための機能です。対応する配信元、検索と絞り込みの方法、配信元ごとのアダルトコンテンツの扱いを取り上げます。キャラクターのインポート方法と、ファイルとして保存する方法もあわせて説明します。古いバージョンでは、このタブは**Bot Browser**または**Browser**という名前でした。

キャラクターカードとは、1人のキャラクターの名前、性格、挨拶メッセージなどをまとめたファイルです。通常はWebサイトからカードをダウンロードし、それをMarinaraにアップロードすることになります。**Card Browser**を使えば、この2つの手順を1か所で済ませられます。

## Card Browserとは

**Card Browser**は、複数の公開キャラクターカードサイトをMarinaraの中から検索します。対応する配信元は**ChubAI**、**JannyAI**、**Pygmalion**、**Wyvern**、**DataCat**の5つです。**CharacterTavern**も一覧には残っていますが、現在は閲覧できません([CharacterTavern](#charactertavern)を参照)。配信元を検索し、結果を絞り込み、キャラクターの詳細をひととおり確認できます。気に入ったキャラクターはライブラリーにインポートするか、PNGファイルとして保存できます。デフォルトの設定であれば、閲覧にもインポートにもアカウントやAPIキーは必要ありません。

## Card Browserを開く

**Card Browser**を開く方法は2つあります。

1. 上部バーの**Card Browser**アイコンをクリックします。右側に並んだパネルボタンの中にあります。
2. または、右サイドバーの**Card Browser**パネルを開き、パネル上部の**Download Cards**(カードのダウンロード)ボタンをクリックします。

どちらの方法でも、コンテンツ領域全体が**Card Browser**の全画面表示に切り替わります。この画面はチャット領域と入れ替わる形で表示され、小さなポップアップウィンドウではありません。

閉じるときは、**Card Browser**ヘッダー左上の戻る矢印ボタンをクリックします。元いた画面に戻ります。

**Card Browser**はアプリを開いているあいだ読み込まれたままです。いったん閉じてから開き直しても、直前の検索、絞り込み、選択していたキャラクターはそのまま残ります。アプリ全体を再読み込みするとリセットされます。

## 配信元を選ぶ

ヘッダーにある配信元ボタンをクリックします。現在の配信元名と小さな矢印が表示されています。クリックすると、配信元が**ChubAI**、**JannyAI**、**CharacterTavern**、**Pygmalion**、**Wyvern**、**DataCat**の順に並んだメニューが開きます。**CharacterTavern**には**Unavailable**(利用不可)と表示されます。

**Card Browser**を初めて開いたときは**ChubAI**が選ばれています。配信元を切り替えると、検索文字列、タグ、絞り込みはすべてクリアされます。アダルトコンテンツの設定とログイン状態は配信元ごとに別々に保持されるため、1つの配信元での変更が他に影響することはありません。

名前について1点だけ補足します。メニューには**ChubAI**と表示されますが、キャラクターの詳細画面にある外部リンクは**View on Chub**と表示されます。これはサイト自身の名乗り方によるものです。ほかの配信元は、どちらの場所でも同じ名前です。

## CharacterTavern

CharacterTavernはWebサイトを作り直し、Marinaraがカードの検索とダウンロードに使っていた接続を提供しなくなりました。**CharacterTavern**を選ぶと、**Card Browser**には検索結果の代わりに短い案内が表示されます。CharacterTavernがAPIでのアクセスを提供すれば、閲覧できるようになる可能性があります。

それまでのあいだも、CharacterTavernのキャラクターは手動でMarinaraに取り込めます。

1. 案内にある**Open CharacterTavern**(CharacterTavernを開く)をクリックします。サイトが新しいタブで開きます。
2. character-tavern.comからキャラクターカードのファイルをダウンロードします。
3. 案内にある**Import Character**(キャラクターをインポート)をクリックし、ダウンロードしたファイルを選びます。[キャラクターカードのインポートとエクスポート](import-export.md)を参照してください。

CharacterTavernからインポート済みのキャラクターは、そのままライブラリーに残ります。

## 検索、並べ替え、ページ送り

**Search characters...**欄に入力すると検索できます。Enterを押す必要はありません。入力が止まってから少し(約0.5秒)待って、Marinaraが自動的に検索します。欄を空にしたときや絞り込みを変えたときも、あらためて検索します。

検索欄の隣には並べ替えのドロップダウンがあります。選択肢は配信元ごとに異なり、それぞれ独自のデフォルトの並び順で始まります。

| 配信元 | デフォルトの並び順 |
| --------- | --------------- |
| ChubAI    | Most Downloaded |
| JannyAI   | Newest          |
| Pygmalion | Downloads       |
| Wyvern    | Popular         |
| DataCat   | Relevance       |

**Refresh**(再検索)ボタン(円形の矢印アイコン)をクリックすると、現在の検索条件でもう一度検索します。

結果の下には**Previous**と**Next**のボタンがあり、**Page 2**のようなページ表示が添えられます。配信元が正確な総数を返せない場合は、現在のページ番号だけが表示されます。

**DataCat**について1点注意があります。**Fresh**の並び順で新着の結果が出るのは、タグの絞り込みも検索文字列もない場合だけです。検索文字を入力するかタグを選んだ時点で、**DataCat**は通常の関連度順に戻ります。

## タグで絞り込む

ツールバーの**Tags**(タグ)ボタンをクリックすると、タグパネルが開きます。

- **Search tags...**欄に入力すると、タグの一覧を絞り込めます。
- タグの横にある緑のチェックをクリックすると、そのタグを含める条件になります。赤いマイナスをクリックすると除外する条件になります。1つのタグを両方に指定することはできません。
- 含めるタグは緑、除外するタグは赤のチップで表示されます。チップをクリックすると外せます。
- **Clear**(クリア)ボタンを押すと、有効なタグがすべて外れます。

ほとんどの配信元では、タグの一覧は直近の検索結果に含まれるキャラクターから作られます。最初の検索を実行する前は、パネルに**Tags will appear after searching**と表示されます。目当てのタグが一覧にないときは、その名前を入力します。ボタンが2つ表示されるので、絞り込み条件として追加するか、結果から除外するかを選べます。

**DataCat**だけは動作が異なります。タグの一覧が非常に大きいため、人気の高いタグを最初から読み込みます。もちろん、それ以外のタグ名を手入力することもできます。

## そのほかの絞り込み

配信元によっては、ツールバーに**Filters**(絞り込み)ボタンが追加されます。絞り込み条件を持つ配信元でのみ表示されるため、**DataCat**では表示されません。有効な条件の数は小さなバッジで示されます。

絞り込みパネルには次のような項目があります。

- **Lorebook**や**Alt Greetings**などのコンテンツのチェックボックス。その要素を持つキャラクターだけに結果を絞ります。ロアブックとは、キャラクターが一緒に持ち歩ける追加の設定情報です。
- **Sort Direction**(並び順の方向)。**ChubAI**と**Pygmalion**で**Descending**または**Ascending**を選べます。
- **Min Tokens**と**Max Output Tokens**の数値入力欄。サイズで結果を絞ります。空欄のままにすると、配信元側のデフォルトが使われます。
- **JannyAI**には**Show Low Quality**トグルがあります。デフォルトはオフで、**JannyAI**が低品質と判定したキャラクターを隠します。含めたいときはオンにします。

**Wyvern**についての注意です。**Lorebook**と**Alt Greetings**のチェックボックスも、**Min Tokens**と**Max Output Tokens**の欄も表示されますが、どれも**Wyvern**の結果には反映されません。**Wyvern**で結果を絞り込みたいときは、並べ替えのドロップダウンとタグを使ってください。

## 配信元ごとのアダルトコンテンツ(NSFW)

アプリではアダルトコンテンツを**NSFW**と表記します。ツールバーの**NSFW**チェックボックスは1つだけですが、扱いは配信元ごとに違います。質問がいちばん多い部分なので、よく読んでください。

- **ChubAI**と**JannyAI**: **NSFW**チェックボックスがそのまま機能します。ログインは不要です。デフォルトはオフです。
- **Pygmalion**: ログインするまで**NSFW**チェックボックスはグレーアウトしています。ツールチップに、先にログインするよう案内が出ます。ログイン後は、Pygmalionのアカウント設定に従います。チェックボックスの表示も**NSFW depends on your account settings**に変わります。ログイン後に個別のオン/オフ切り替えはありません。
- **Wyvern**: **NSFW**チェックボックスは常にグレーアウトしています。**Use "🔞 Popular NSFW" sort for NSFW content**という案内が表示されます。**Wyvern**でアダルトコンテンツを見るには、並べ替えのドロップダウンで**🔞 Popular NSFW**を選びます。
- **DataCat**: すべてのキャラクターがアダルト扱いのため、チェックボックスはオンで固定されます。**DataCat**を初めて選んだときは、**DataCat is NSFW only**というウィンドウが開きます。閲覧するなら**Continue to DataCat**、やめるなら**Don't continue to DataCat**をクリックします。

アダルト指定のキャラクターには、サムネイルの隅に赤い**NSFW**バッジが小さく表示されます。

## Pygmalionへのログイン

**Pygmalion**は、アダルトコンテンツをログインの内側に隠しています。通常の公開キャラクターを見るだけならログインは不要です。ログインで解放されるのはアダルトコンテンツだけです。

ログインするには、ツールバーの**Log In**(ログイン)ボタンをクリックします。ログインウィンドウが開いたら、自分のPygmalionアカウントからコピーした値を貼り付けます。Marinaraがパスワードを尋ねることはありません。

**Pygmalion**の場合、ウィンドウの名前は**Pygmalion Authentication**で、**Auth Token**の入力を求められます。

1. pygmalion.chatにアクセスし、アカウントにログインします。
2. ブラウザーの開発者ツールを開きます。多くのブラウザーではF12キーで開きます。開発者ツールは、上級者向けにブラウザーへ最初から組み込まれているパネルです。
3. **Application**タブを開き、続いて**Local Storage**を開きます。
4. `authn`という名前のエントリーを探し、その値をコピーします。
5. コピーした値をMarinaraの**Auth Token**欄に貼り付けます。貼り付けた値は、欄の中では伏せ字で表示されます。
6. **Save & Connect**をクリックします。NSFWコンテンツが有効になったというメッセージが表示されます。

ウィンドウには、以上の手順をあらためて示すヘルプと、pygmalion.chatを開く**Website**リンクが用意されています。

これはPygmalionアカウントのログイン情報です。Marinaraは、再起動するか**Log Out**をクリックするまで、これをメモリー上に保持します。ログアウトするには、もう一度ログインウィンドウを開いて**Log Out**をクリックします。完全にログアウトするには、pygmalion.chatでもログアウトしてください。

Marinaraは、トークンを保持する前にPygmalionに問い合わせて確認します。Pygmalionがトークンを受け付けなかった場合は何も保存されず、その理由がメッセージで表示されます。後からPygmalionがトークンを受け付けなくなった場合は、Marinaraがログアウト状態に戻し、もう一度ログインするよう求めます。

重要: このログイン情報はサーバーのメモリー上にだけ保持されます。ファイルに保存されることはありません。Marinaraのサーバーを再起動するとログアウトされるので、トークンを貼り付け直す必要があります。その場合、Marinaraは再度ログインするよう促すメッセージを表示します。

## インポート前にキャラクターを確認する

結果のカードをクリックすると詳細画面が開きます。**Back to results**で一覧に戻れます。

詳細画面には、キャラクターのアバター、名前、作者、短い紹介文、そして最大20個のタグチップが表示されます。**View on**リンクもあり、クリックするとキャラクターの元のページが新しいタブで開きます。

その下には、配信元が提供している場合に限り、キャラクターの詳しい内容が表示されます。この部分の見出しには**Creator's Notes**、**Personality**、**Scenario**、**First Message**、**Alternate Greetings**などが使われます。キャラクターがロアブックを持っている場合は、**Has embedded lorebook**という琥珀色のバッジが表示されます。

配信元によっては、詳しい内容が常に返ってくるとは限りません。何も読み込まれない場合は、基本情報だけでもインポートできる旨が画面に表示されます。

## キャラクターをインポートまたはダウンロードする

詳細画面には2つのボタンがあります。**Import**(インポート)はキャラクターをMarinaraのライブラリーに追加します。**Download as PNG**(PNGとしてダウンロード)はライブラリーには追加せず、キャラクターをファイルとしてデバイスに保存します。

キャラクターカードをライブラリーにインポートする手順は次のとおりです。

1. キャラクターの詳細画面を開きます。
2. **Imported tags**の選択肢を選びます(下の表を参照)。
3. **Import**をクリックします。処理中はボタンの表示が**Importing...**に変わります。
4. 完了メッセージを待ちます。キャラクターをインポートしたというメッセージが表示されます。
5. チャットを始める前に、**Characters**パネルを開いてインポートしたキャラクターを確認します。

インポートしたキャラクターは、ほかのキャラクターとまったく同じように扱えます。実際にチャットするには、動作するプロバイダーの接続が別途必要です。[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。

### Imported tags

アバターの隣にある**Imported tags**パネルで、キャラクターと一緒に取り込むタグを選べます。デフォルトは**All tags**です。

| 選択肢        | 動作                                 |
| ------------- | -------------------------------------------- |
| All tags      | 配信元のタグをそのまま取り込みます。 |
| No tags       | 配信元のタグを取り込みません。 |
| Existing only | Marinaraですでに使っているタグだけを取り込みます。 |

### 埋め込みロアブックの確認

キャラクターがロアブックを埋め込んでいる場合、インポート時にWebブラウザーの小さな確認ウィンドウが表示されます。そのロアブックを独立したMarinaraのロアブックとしても保存するかどうかを尋ねる内容です。**OK**をクリックすると、キャラクターに付属するコピーに加えて独立したロアブックも作成します。**Cancel**をクリックすると、ロアブックはキャラクターに付属したままになります。

### Download as PNG

**Download as PNG**をクリックすると、標準的なPNG形式のキャラクターカードファイルとして保存できます。処理中はボタンの表示が**Building PNG...**に変わります。これはどの配信元でも利用できます。保存されるファイルの名前はキャラクター名にちなんだもので、たとえば`Some_Character.png`となります。このファイルは他の人に渡すことも、あとで別のアプリにインポートすることもできます。

JSONとPNGは、同じキャラクターデータを表す代表的な2つの形式です。JSONはプレーンテキストの形式です。PNGカードは画像ファイルで、その内部にキャラクターのデータが埋め込まれています。どちらもキャラクターの情報をすべて保持します。

## インポートしたキャラクターの一覧

右サイドバーの**Card Browser**パネルには、**Card Browser**経由でインポートしたキャラクターだけをまとめた一覧があります。自分で作ったキャラクターや、別の方法でインポートしたキャラクターはここには並びません。もちろん、どれもメインの**Characters**ライブラリーには表示されます。

- **Download Cards**ボタンを押すと、**Card Browser**の全画面表示が開きます。
- **Search imported...**欄でこの一覧を絞り込めます。
- 並べ替えのドロップダウンでは**A-Z**、**Z-A**、**Newest**、**Oldest**を選べます。
- 行を右クリックするか行内のボタンを使うと、**Quick Start Roleplay**と**Quick Start Conversation**を利用できます。どちらもそのキャラクターとの新しいチャットを開きます。この場所からキャラクターを削除することもできます。

## トラブルシューティング

**JannyAIの検索や詳細の取得がCloudflareのエラーで失敗します。** サイトによっては自動化されたリクエストを遮断します。同じWebブラウザーでjannyai.comに一度アクセスし、表示される確認画面を通過してから、Marinaraに戻ってもう一度検索してください。

**Pygmalionのログインが効かなくなりました。** Marinaraのサーバーを再起動すると、このログイン情報は消えます。**Log In**ウィンドウをもう一度開き、トークンを貼り付け直してください。

**CharacterTavernでは案内しか表示されません。** これは仕様どおりです。カードをファイルとしてインポートする方法は、[CharacterTavern](#charactertavern)を参照してください。

**検索が失敗する、または配信元が動かなくなりました。** 公開サイトはページの構造を変えたり、アクセスを遮断したりすることがあります。しばらく待ってから試してください。特定の配信元で失敗が続く場合は、そのサイトでキャラクターのページを直接開き、自分でカードをダウンロードします。そのうえで、通常のインポート手順で取り込んでください。[キャラクターカードのインポートとエクスポート](import-export.md)を参照してください。
