# Card Browser: キャラクターを探してインポートする

**Card Browser**(カードブラウザー)は、公開サイトにあるキャラクターカードを探し、Marinaraの中からそのままライブラリーにインポートします。ファイルを手作業でダウンロードしてアップロードする必要はありません。古いバージョンでは**Bot Browser**または**Browser**という名前でした。

キャラクターカードとは、1人のキャラクターの名前、性格、挨拶メッセージなどをまとめたファイルです。デフォルトの設定であれば、閲覧にもインポートにもアカウントやAPIキーは必要ありません。

## Card Browserを開く

1. 上部のナビゲーションバーで**Characters**(キャラクター)または**Personas**(ペルソナ)をクリックします。見当たらない場合は、先に**More**(その他)を開きます。
2. 上部にある**Download**(ダウンロード)ボタンをクリックします。ツールチップには**Download character cards**と表示されます。

Card Browserはコンテンツ領域全体に表示され、タイトルは**Browse character cards online**です。閉じるときは、左上の戻る矢印をクリックします。

いったん閉じてから開き直しても、直前の検索、絞り込み、選択していたキャラクターはそのまま残ります。アプリを再読み込みするとリセットされます。

## 配信元を選ぶ

ヘッダーにある配信元ボタンをクリックします。メニューには**ChubAI**、**JannyAI**、**CharacterTavern**、**Pygmalion**、**Wyvern**、**DataCat**、**PlotLight**、**PlotLight Personas**の順に並びます。最初は**ChubAI**が選ばれています。配信元を切り替えると、検索文字列、タグ、絞り込みはクリアされます。アダルトコンテンツの設定とログインは、配信元ごとに別々に保持されます。

| 配信元 | アダルトコンテンツ(NSFW) |
| --- | --- |
| **ChubAI** | **NSFW**チェックボックスが機能します。デフォルトはオフです。 |
| **JannyAI** | **NSFW**チェックボックスが機能します。デフォルトはオフです。 |
| **Pygmalion** | [ログイン](#log-in-to-pygmalion)するまでグレーアウトしています。ログイン後は、Pygmalionのアカウント設定に従います。 |
| **Wyvern** | 常にグレーアウトしています。代わりに**🔞 Popular NSFW**の並び順を選んでください。 |
| **DataCat** | すべてのカードがアダルト扱いのため、チェックボックスはオンで固定されます。 |
| **PlotLight**と**PlotLight Personas** | 常にグレーアウトしています。PlotLightは独自のルールを適用します。アダルトのタグが付いた結果には**NSFW**バッジが付きます。 |

どこから始めればよいか迷ったら、最初の配信元である**ChubAI**を使ってください。各配信元はそれぞれ独自の並び順で始まり、並べ替えのドロップダウンで変更できます。

アダルト指定のカードには、サムネイルに赤い**NSFW**バッジが小さく表示されます。メニューには**ChubAI**と表示されますが、カードの外部リンクは**View on Chub**と表示されます。これはサイト自身の名前です。

### DataCat

**DataCat**を初めて選ぶと、**DataCat is NSFW only**というダイアログが開きます。閲覧するなら**Continue to DataCat**、戻るなら**Don't continue to DataCat**をクリックします。**Fresh**の並び順で新着の結果が出るのは、タグの絞り込みも検索文字列もない場合だけです。

### CharacterTavern

CharacterTavernはサイトを作り直し、Marinaraが使っていた接続を提供しなくなりました。CharacterTavernを選ぶと、検索結果の代わりに案内が表示されます。CharacterTavernがAPIでのアクセスを提供すれば、閲覧できるようになる可能性があります。それまでは、カードを手作業でインポートしてください。

1. 案内にある**Open CharacterTavern**(CharacterTavernを開く)をクリックします。サイトが新しいタブで開きます。
2. character-tavern.comからカードのファイルをダウンロードします。
3. 案内にある**Import Character**(キャラクターをインポート)をクリックし、ファイルを選びます。[キャラクターカードのインポートとエクスポート](import-export.md)を参照してください。

CharacterTavernからインポート済みのキャラクターは、そのままライブラリーに残ります。

### PlotLight

PlotLightは、公開されているキャラクターとペルソナを共有しています。**PlotLight**にはキャラクターカードが、**PlotLight Personas**にはペルソナ(チャットで自分を表すキャラクター)が並びます。PlotLightのアカウントは必要ありません。詳細画面には、元のページを開く**View on PlotLight**リンクがあります。

Marinaraは、PlotLightが提供しているファイルをダウンロードします。キャラクターカードは通常PNGファイルで、ポートレートと、作者が許可したロアブックが含まれます。ペルソナはテキストファイルで、画像はMarinaraが別にコピーします。どちらの種類も、キャラクターとしてもペルソナとしてもインポートできます。

PlotLightは、アプリからの問い合わせの速さを制限しています。速すぎると、Marinaraは**PlotLight is busy**と待つ秒数を表示し、その時間だけ待ちます。検索とインポートの制限は別々です。

作者が許可していない場合など、ダウンロードできないカードもあります。その場合、Marinaraは**PlotLight doesn't offer this for download.**と表示します。そのカードはインポートできず、詳細も見られませんが、画像、作者、**View on PlotLight**リンクは残ります。

## 検索、並べ替え、ページ送り

**Search characters**(キャラクターを検索)に入力します。<kbd>Enter</kbd>を押す必要はありません。入力が止まって少しするとMarinaraが検索し、欄を空にしたときや絞り込みを変えたときも、あらためて検索します。配信元ごとに専用の並べ替えのドロップダウンがあります。**Refresh**(再検索)ボタン(円形の矢印)をクリックすると、もう一度検索します。

結果の下には**Previous**と**Next**があり、**Page 2**のようなラベルが添えられます。配信元が総数を返せない場合は、現在のページだけが表示されます。**PlotLight**は総数を返さないため、ヘッダーには**Browsing PlotLight**と表示されます。PlotLightのページには、カードが少ししかないことや1枚もないことがありますが、その後にまだページが続く場合があります。**Next**はオンのままなので、続けて進めます。

## タグで絞り込む

1. ツールバーの**Tags**(タグ)をクリックします。
2. **Search tags**(タグを検索)に入力すると、一覧が絞り込まれます。
3. タグの横にある緑のチェックをクリックすると含める条件に、赤いマイナスをクリックすると除外する条件になります。1つのタグを両方に指定することはできません。
4. チップをクリックするとそのタグが外れ、**Clear**(クリア)ですべて外れます。

ほとんどの配信元では、一覧は直近の検索結果に含まれるキャラクターから作られます。最初の検索を実行する前は、パネルに**Tags will appear after searching**と表示されます。目当てのタグが一覧にないときは、その名前を入力します。ボタンが2つ表示され、一方は絞り込み条件として追加し、もう一方はそのタグを除外します。**DataCat**は人気の高いタグを最初から読み込みますが、それ以外のタグも入力できます。**PlotLight**では、Marinaraは入力したタグをPlotLight自身の一覧で照合し、PlotLightにないタグは何にも一致しません。

## そのほかの絞り込み

ほとんどの配信元では、**Filters**(絞り込み)ボタンが追加され、そのバッジに有効な絞り込みの数が表示されます。**DataCat**と**PlotLight**では表示されません。パネルには次のような項目があります。

- **Lorebook**や**Alt Greetings**などのコンテンツのチェックボックス。その要素を持つキャラクターだけを残します。ロアブックとは、キャラクターが持ち歩く追加の背景情報です。
- **Sort Direction**(並び順の方向)。**ChubAI**と**Pygmalion**で、**Descending**または**Ascending**を選べます。
- **Min Tokens**と**Max Output Tokens**の欄。サイズで結果を絞ります。空欄のままにすると、配信元のデフォルトが使われます。
- **JannyAI**の**Show Low Quality**トグル。オフになっていて、JannyAIが低品質と判定したカードを隠します。

**Wyvern**では、**Lorebook**と**Alt Greetings**のチェックボックスとトークンの欄は表示されますが、結果は変わりません。代わりに並べ替えのドロップダウンとタグを使ってください。

## キャラクターを確認する

結果をクリックすると詳細画面が開きます。**Back to results**で一覧に戻ります。

詳細画面には、アバター、名前、作者、短い紹介文、最大20個のタグチップ、元のページを開く**View on**リンクが表示されます。その下には、配信元が提供している場合に限り、**Creator's Notes**、**Personality**、**Scenario**、**First Message**、**Alternate Greetings**などの見出しの下に詳しい内容が表示されます。カードがロアブックを持っている場合は、**Has embedded lorebook**という琥珀色のバッジが表示されます。配信元が詳しい内容を返さない場合は、基本情報だけでもインポートできる旨が表示されます。

## キャラクターをインポートする

始める前に: キャラクターとチャットするには、動作するテキスト接続が必要です。[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。

1. キャラクターの詳細画面を開きます。
2. アバターの隣にある**Imported tags**(取り込むタグ)の選択肢を選びます。デフォルトは**All tags**です。[インポートの設定](import-export.md#import-options)を参照してください。
3. **Import**(インポート)をクリックします。**Import Card**ウィンドウが開き、**Where should this card live?**と尋ねられます。
4. 必要に応じて**Split description into fields**(説明を各欄に分割)にチェックを入れます。[インポートの設定](import-export.md#import-options)を参照してください。
5. **Characters**に追加するなら**Import as Character**(キャラクターとしてインポート)を、**Personas**に追加するなら**Import as Persona**(ペルソナとしてインポート)をクリックします。
6. カードにロアブックが埋め込まれている場合は、**Embedded lorebook found**パネルにエントリーの数が表示されます。独立したロアブックも作るなら**Import Lorebook**(ロアブックをインポート)を、カードの中だけに残すなら**No Import**(インポートしない)をクリックします。**Back**(戻る)を押すと手順5に戻ります。
7. ボタンの表示が**Importing...**のあいだは待ちます。`Imported "Name" successfully!`というメッセージが表示されます。
8. **Characters**(または**Personas**)を開くと、インポートしたキャラクターがあります。

うまくいかなかった場合: トーストのエラーメッセージを読んでください。**JannyAI**では、Cloudflareによるブロックがいちばん多い原因です(下のトラブルシューティングを参照)。

### Download as PNG

詳細画面の**Download as PNG**(PNGとしてダウンロード)をクリックすると、ライブラリーには追加せずに、標準的なPNG形式のキャラクターカードとしてデバイスに保存できます。処理中はボタンの表示が**Building PNG...**に変わります。どの配信元でも使え、ファイルには`Some_Character.png`のようにキャラクター名にちなんだ名前が付きます。PNGカードとは、キャラクターのデータを内部に収めた画像です。共有することも、別のアプリにインポートすることもできます。

## トラブルシューティング

| 問題 | 対処 |
| --- | --- |
| **JannyAI**の検索や詳細の取得が、Cloudflare(自動化されたリクエストを遮断するセキュリティチェック)に触れるエラーで失敗する。または、カードの完全な定義がブロックされる。 | 同じブラウザーでjannyai.comに一度アクセスし、表示される確認を通過してから、もう一度検索してください。それでもカードがブロックされる場合は、JannyAIでそのカードを開いてPNGをダウンロードし、そのファイルをインポートしてください。 |
| Pygmalionのログインが効かなくなった。 | サーバーを再起動するとログインは消えます。新しいトークンでもう一度ログインしてください。 |
| **CharacterTavern**では案内しか表示されない。 | 仕様どおりです。[CharacterTavern](#charactertavern)を参照してください。 |
| **PlotLight is busy.** | メッセージに示された秒数だけ待ってから、もう一度試してください。 |
| **PlotLight doesn't offer this for download.** | 作者がダウンロードを許可していないか、カードがすでに公開されていない可能性があります。**View on PlotLight**で確認してください。 |
| 検索が失敗する、または配信元が動かなくなった。 | 公開サイトは、いつでも変更されたりアクセスを遮断したりすることがあります。時間をおいて試すか、サイトからカードをダウンロードして通常のインポートを使ってください。[キャラクターカードのインポートとエクスポート](import-export.md)を参照してください。 |

## Pygmalionへのログイン

Pygmalionは、アダルトコンテンツをログインの内側に隠しています。公開キャラクターならログインは不要です。Marinaraがパスワードを尋ねることはありません。自分のアカウントからコピーした値を貼り付けます。

1. ツールバーの**Log In**(ログイン)をクリックします。**Pygmalion Authentication**ウィンドウが開きます。
2. ブラウザーでpygmalion.chatにアクセスし、ログインします。
3. ブラウザーの開発者ツールを開きます。開発者ツールは、上級者向けにブラウザーへ最初から組み込まれているパネルです。多くのコンピューター用ブラウザーでは、<kbd>F12</kbd>キーで開きます。スマートフォンのブラウザーには通常ないため、この手順にはコンピューターを使ってください。
4. **Application**タブを開き、続いて**Local Storage**を開きます。
5. `authn`という名前のエントリーを探し、その値をコピーします。
6. Marinaraの**Auth Token**欄に貼り付けます。貼り付けた値は伏せ字で表示されます。
7. **Save & Connect**をクリックします。NSFWコンテンツが有効になったというメッセージが表示されます。

ウィンドウには、以上の手順を示すヘルプと、pygmalion.chatを開く**Website**リンクがあります。

Marinaraは、まずPygmalionにトークンを確認します。Pygmalionが受け付けなかった場合は何も保存されず、その理由がメッセージで表示されます。後からPygmalionがトークンを受け付けなくなった場合は、Marinaraがログアウトし、もう一度ログインするよう求めます。

ログイン情報はサーバーのメモリー上にだけ保持されます。ファイルに保存されることはないため、Marinaraのサーバーを再起動するとログアウトされます。自分でログアウトするには、もう一度ウィンドウを開いて**Log Out**(ログアウト)をクリックします。完全にログアウトするには、pygmalion.chatでもログアウトしてください。
