# キャラクターカードのインポートとエクスポート

キャラクターカードとは、1人のキャラクターを収めた1つのファイルです。名前、説明、性格、挨拶メッセージが入っていて、アバター画像を含むことも多くあります。カードをインポートすると、ほかのアプリやサイトのキャラクターを追加できます。自分のキャラクターをエクスポートすれば、バックアップしたり共有したりできます。

## キャラクターをインポートする

始める前に: キャラクターカードのファイルをデバイスに用意してください。代わりにオンラインでカードを探す場合は、[Card Browser](bot-browser.md)を参照してください。

1. 上部のナビゲーションバーで**Characters**(キャラクター)をクリックします。見当たらない場合は、先に**More**(その他)を開きます。
2. ツールバーの**Import**(インポート)をクリックします(ダウンロードの矢印のアイコンです)。**Import Character**(キャラクターのインポート)ウィンドウが開きます。
3. 下のインポートの設定を決めます。この設定は、この回に取り込むすべてのファイルに適用されます。
4. ファイルをウィンドウにドロップするか、ウィンドウをタップまたはクリックしてデバイスのファイル選択画面を開きます。複数のファイルを選べ、形式が混ざっていてもかまいません。
5. 結果の一覧が出るまで待ちます。ファイルごとに、緑のチェックか、赤い印とエラーが表示されます。表示される文は`Imported "Name"`、`Imported "Name" with its embedded lorebook`、`Imported "Name" without creating the embedded lorebook`のいずれかです。
6. **Characters**で新しいキャラクターを確認します。

Marinaraが受け付けるファイル形式は4種類です。

| ファイル形式 | 内容 |
| --- | --- |
| **.json** | テキストとして保存されたカード。Marinaraのエクスポート(`.marinara.json`)も.jsonファイルです。 |
| **.png** | カードのデータを画像の中に隠したカード画像。 |
| **.charx** | zipファイルとして保存されたカードのパッケージ。 |
| **.marinara** | Marinaraのエクスポートファイル。 |

いちばん多くの情報を保てるのは、Marinaraのエクスポートです。ほかの形式は、SillyTavern、Chub、Risuなどのツールで使われているものです。

うまくいかなかった場合: ファイルの横にある赤いメッセージを読んでください。同じ回のほかのファイルは、そのままインポートされます。

<a id="import-options"></a>

### インポートの設定

| 設定 | 選択肢 |
| --- | --- |
| **Imported card tags**(インポートしたカードのタグ) | **All tags**(デフォルト): すべてのタグを残します。 |
| | **No tags**: タグを取り込みません。 |
| | **Existing only**: ライブラリーにすでにあるタグだけを残します。 |
| **Imported regex scripts**(インポートした正規表現スクリプト) | **Character only**(デフォルト): ルールはこのキャラクターに対して動きます。 |
| | **Global**: ルールは**Presets → Regexes**(プリセット → 正規表現)に追加され、すべてのチャットで動きます。 |
| **Split description into fields**(説明を各欄に分割) | デフォルトではオフです。チェックを入れると、見出しの付いた性格、外見などのテキストが**Description**(説明)からそれぞれの欄へ移ります。 |

正規表現スクリプトとは、文字列を置き換える小さなルールです。ルールをすべてのチャットで使いたい場合を除き、**Character only**のままにしてください。ナレーター、世界観、複数キャラクターのカードは、分割されずにそのまま残ります。

### ロアブックが埋め込まれたカード

ロアブックとは、AIがチャット中に参照する背景情報をまとめたものです。カードにロアブックが埋め込まれていると、インポートがいったん止まり、**Embedded lorebook found**(埋め込みロアブックが見つかりました)と表示されます。ここには、ファイルごとにエントリーの数が並びます。この回に取り込むファイル全体に対して、次のどちらかを選びます。

- **Import Lorebook**(ロアブックをインポート)は、キャラクターに紐づいた独立したMarinaraのロアブックも作ります。
- **No Import**(インポートしない)は、ロアブックをカードの中だけに留めます。

### SillyTavernのフォルダーをまるごとインポートする

SillyTavernの環境をまるごと移すには、**Settings**(設定)の**Imports**(インポート)タブにある一括インポート機能を使います。キャラクター、チャット、プリセット、ロアブックをまとめて移せます。[SillyTavernからのインポート](../data/importing-from-sillytavern.md)を参照してください。

## キャラクターをエクスポートする

1. エディターでキャラクターを開きます。
2. ヘッダーの**Export character**(キャラクターのエクスポート)をクリックします。**Export Character**ウィンドウが開きます。
3. 形式を選びます。Marinaraがファイルをダウンロードします。

| 形式 | 書き出される内容 | 向いている用途 |
| --- | --- | --- |
| **Marinara Native** | Marinara固有の情報、スプライト、ギャラリーの画像、紐づいたロアブックを含む`.marinara.json`ファイル。 | Marinara同士で、情報を欠かさずキャラクターを移すとき。 |
| **Compatible JSON** | ほかのアプリでも読める素のカードファイル。スプライトやギャラリーの画像といったMarinara独自の要素は含まれません。 | JSONカードを読めるほかのアプリ。 |
| **Compatible PNG Card** | データを画像の中に収めたカード画像。スプライトは含まれますが、ギャラリーの画像は含まれません。 | SillyTavern、Chub、RisuなどPNGカードを前提とするアプリやサイト。 |

**Compatible**の2つの形式では、空でない**Backstory**(背景設定)と**Appearance**(外見)の欄が標準の**Description**(説明)に追記されるため、ほかのアプリでもその情報が残ります。保存済みのカードは変わりません。

カードの[対話式オンボーディング](interactive-onboarding.md)は、**Marinara Native**と**Compatible PNG Card**では保持されるため、だれかがMarinaraにインポートしたときもカードは質問をします。**Compatible JSON**では含まれません。

## 複数のキャラクターをまとめてエクスポートする

1. 上部のナビゲーションバーで**Characters**(キャラクター)をクリックします(表示されていない場合は、先に**More**(その他)を開きます)。
2. ツールバーの**Select**(選択)をクリックし(チェックマークのアイコンです)、書き出したいキャラクターにチェックを入れます。
3. 画面下部のバーで**Export**(エクスポート)をクリックします。Marinaraが`marinara-characters.zip`をダウンロードします。

zipの中身は、キャラクターごとの**Marinara Native**ファイルです。まとめてエクスポートする場合、PNGやJSONは選べません。これらの形式が必要なときは、キャラクターを1人ずつエクスポートしてください。キャラクターを選ぶほかの方法は、[キャラクターライブラリーの整理](library-organization.md#export-or-delete-many-characters)を参照してください。
