# キャラクターカードのインポートとエクスポート

このガイドでは、キャラクターカードをMarinara Engineに取り込む方法と、自分で作ったキャラクターを書き出す方法を説明します。Marinaraが受け付けるファイル形式、インポート時に選べる項目、3つのエクスポート形式を取り上げます。

キャラクターカードとは、1人のキャラクターの情報をまとめた1つのファイルです。名前、説明、性格、挨拶メッセージが入っていて、アバター画像を含むことも多くあります。カードを使えば、Marinaraとほかのロールプレイアプリの間でキャラクターを持ち運べます。

## インポートできる形式

**Import Character**(キャラクターのインポート)ウィンドウは4種類のファイルを受け付けます。複数のファイルをまとめてドロップでき、形式が混ざっていてもかまいません。

| ファイル形式 | 内容 |
| --- | --- |
| **.json** | テキスト形式のキャラクターカード(Chara Card V2)。 |
| **.png** | カードのデータを画像の中に埋め込んだキャラクターカード。 |
| **.charx** | Character Card V3のパッケージ(CharX)。RisuAIが使うzipベースの形式。 |
| **.marinara** | Marinara独自のエクスポート形式(`.marinara.json`という名前で見かけることもあります)。 |

**.marinara**はMarinara自身の形式なので、いちばん多くの情報を保てます。ほかの3つはSillyTavern、Chub、Risuなどのツールで使われている形式です。

## キャラクターをインポートする

次の手順で、1枚または複数のカードをライブラリーに取り込みます。

1. **Characters**(キャラクター)パネルを開きます。
2. ツールバーの**Import**(インポート)ボタンをクリックします。下向き矢印のアイコンボタンです。**Import Character**ウィンドウが開きます。
3. ファイルをウィンドウにドラッグするか、ウィンドウをクリックしてファイルを選びます。「Drop one or more files here or click to browse」と表示されます。
4. 2つのインポート設定(下で説明します)を決めます。この設定は、この回に取り込むすべてのファイルに適用されます。
5. 結果の一覧が出るまで待ちます。ファイルごとに、緑のチェックと「Imported」とカード名が並ぶか、赤い印とエラーが表示されます。

### 残すタグを選ぶ

**Imported card tags**(インポートしたカードのタグ)は、取り込むカードに付いているタグをどう扱うかを決める設定です。これをタグインポートモードと呼びます。選択肢は3つあります。

- **All tags**: 元のカードのタグをすべて残します。これがデフォルトです。
- **No tags**: 元のカードのタグを取り込みません。
- **Existing only**: ライブラリーにすでにあるタグだけを残します。

### 正規表現スクリプトの適用範囲を選ぶ

カードによっては、正規表現スクリプトが付属していることがあります。文字列を置き換える小さなルールです。**Imported regex scripts**(インポートした正規表現スクリプト)で、その適用範囲を決めます。

- **Character only**: このキャラクターのチャットでだけ動きます。これがデフォルトです。
- **Global**: **Presets**の**Regexes**セクションに追加され、すべてのチャットで動きます。

すべてのチャットに効かせたいと決めている場合を除き、**Character only**を選んでください。

### ロアブックが埋め込まれたカード

ロアブックとは、AIがチャット中に参照できる背景設定をまとめたものです。インポートするカードにロアブックが埋め込まれていると、処理がいったん止まり、**Embedded lorebook found**(埋め込みロアブックが見つかりました)パネルが表示されます。ここには、ファイルごとにエントリーの数が並びます。この回に取り込むファイル全体に対して、次のどちらかを選びます。

- **Import Lorebook**: キャラクターに紐づいた独立したMarinaraのロアブックも作ります。
- **No Import**: ロアブックをカードの中だけに留めます。

### 複数のカードをまとめてインポートする

同じ**Import Character**ウィンドウで、まとめてインポートもできます。複数のファイルを選ぶと、Marinaraが順番に取り込みます。結果の一覧はファイルごとに1行なので、どのカードが成功してどれが失敗したかがわかります。

## キャラクターをエクスポートする

エディターでキャラクターを開き、上部ツールバーの**Export character**(キャラクターのエクスポート)をクリックします。**Export Character**ウィンドウで3つの形式から選べます。

| 形式 | 書き出される内容 | 向いている用途 |
| --- | --- | --- |
| **Marinara Native** | Marinara固有の情報、スプライト、ギャラリーの画像、紐づいたロアブックを保持する`.marinara.json`ファイル。 | Marinara同士で、情報を欠かさずキャラクターを移すとき。 |
| **Compatible JSON** | Marinara独自の情報を含まない、素のChara Card V2のJSON。 | JSONカードを読めるほかのアプリに渡すとき。 |
| **Compatible PNG Card** | カードのデータを画像に埋め込んだChara Card V2の画像。 | SillyTavern、Chub、RisuなどPNGカードを前提とするアプリやサイト。 |

情報をすべて残したいときは**Marinara Native**を選びます。ファイルをほかのツールに渡すときは**Compatible**のどちらかを選びます。互換形式2つでは、スプライトやギャラリーの画像といったMarinara独自の要素は失われます。空でない**Backstory**(背景設定)と**Appearance**(外見)は標準のDescriptionに追記されるため、ほかのV2対応ツールでもキャラクター情報を保持できます。再インポート時の重複を防ぐため、これらのフィールドはエクスポートする拡張情報から除かれます。保存済みのカードは変わりません。**Marinara Native**では別々のフィールドを維持します。

## 複数のキャラクターをまとめてエクスポートする

複数のキャラクターを1つのzipファイルとして書き出せます。

1. **Characters**パネルを開きます。
2. ツールバーの**Select**(選択)ボタンをクリックして選択モードに入ります。チェックマークのアイコンボタンです。
3. 書き出したいキャラクターにチェックを入れます。
4. 画面下部のアクションバーで**Export**(エクスポート)をクリックします。`marinara-characters.zip`という名前のzipがダウンロードされます。

zipの中身は、キャラクターごとの**Marinara Native**ファイルです。まとめてエクスポートする場合、PNGや互換JSONは選べません。これらの形式が必要なときは、キャラクターを1人ずつエクスポートしてください。

## SillyTavernのフォルダーをまるごとインポートする

ここまでの手順は、自分で選んだカードを取り込む方法です。SillyTavernの環境をまるごと移したいときは、フォルダー一括インポートを使います。キャラクター、チャット、プリセット、ロアブックをまとめて移せます。この機能は**Settings**(設定)の**Imports**タブにあります。詳しい手順は[SillyTavernからのインポート](../data/importing-from-sillytavern.md)を参照してください。
