# キャラクターの色とRPGステータス

**Colors**(色)タブと**Stats**(ステータス)タブは、Character Editor(キャラクターエディター)とPersona Editor(ペルソナエディター)の両方にあります。色は、チャットでのキャラクターやペルソナの見た目を変えます。ステータスでは、体力や空腹度のように追跡できる値を設定します。

## Colorsタブ

**Colors**タブでは、名前の色、セリフの色、メッセージボックスの色の3つを設定します。欄を空のままにすると、その部分にはアプリのテーマの色が使われます。

1. キャラクターまたはペルソナをエディターで開きます。
2. **Colors**タブをクリックします。
3. リアルタイムの**Preview**(プレビュー)カードに、サンプルの名前とメッセージ吹き出しが表示され、その下に色の欄が並びます。色を変えるたびに、保存する前からプレビューが更新されます。

### Extract Colors from Avatar

**Extract Colors from Avatar**(アバターから色を抽出)は、3つの色をすべてアバター画像から選びます。アバターがまだないときはボタンがオフで、表示は**Upload an avatar first**です。抽出したあとでも、どの色も手動で変更できます。

### 3つの色

それぞれ、色の欄で選ぶか、値を入力して設定します。

| 欄 | 色を付ける対象 | 値の例 |
| --- | --- | --- |
| **Name Display Color**(名前の表示色) | 名前です。グラデーションも指定できます(下記を参照)。 | `#f59e0b` |
| **Dialogue Highlight Color**(セリフの強調色) | セリフの引用符の中の文字です。 | `#ffd700` |
| **Message Box Color**(メッセージボックスの色) | Roleplayのメッセージ吹き出しの背景です。 | `#123456` |

**Name Display Color**には、CSSのグラデーションも指定できます。グラデーションとは、色から色へなめらかに変化する塗りです。

```text
linear-gradient(90deg, #f59e0b, #ef4444)
```

キャラクターの**Colors**タブには**Name Aliases**(別名)もあります。`Kate, Kitty, Katherine`のように、ほかの名前や愛称をカンマで区切って入力します。チャットのメッセージにこれらが出てくると、キャラクターの名前の色が付きます。メインの名前は常に含まれます。この機能は、チャットごとに**Chat Settings → Characters**(チャット設定 → キャラクター)でオンにします。

透明度を変えるには、**Settings → Appearance → Roleplay Presentation → Roleplay Messages Background Opacity**(設定 → 外観 → Roleplayの表示 → Roleplayのメッセージの背景の不透明度)を使います。

このスライダーの値は、キャラクター、ペルソナ、プリセットの背景色に保存されている透明度に代わって使われます。抽出した色も対象です。保存されている色の値自体は変わりません。名前やセリフの色には影響しません。

カスタムテーマの背景のフックやカードCSSは、引き続きアプリの吹き出しのスタイルを上書きできます。

<a id="where-your-colors-show"></a>

### 色が反映される場所

- 名前の色は、チャットのメッセージに表示される名前に付きます。キャラクターの場合はサイドバーのタブの名前にも、ペルソナの場合はペルソナのピッカーの名前にも付きます。
- セリフの色は、セリフの引用符の中の文字に付きます。まっすぐな引用符でも、ほかの種類の引用符でも同じです。この文字は**Settings**(設定)で太字にすることもできます。Conversationのチャットでは使われません。
- メッセージボックスの色は、Roleplayのチャットで、そのキャラクターやペルソナのメッセージ吹き出しの背景を設定します。ConversationとGameのチャットでは使われません。

## Statsタブ

**Stats**タブでは、HP(体力)、STR(筋力)、空腹度のバーのような数値を設定します。ステータスをオンにすると、AIが現在の状態を把握できるように、Marinaraがその値をプロンプトに追加します。ここで設定した値は、新しいチャットの開始時のデフォルトです。プレイ中は、その一部をエージェントが変更できます([エージェントがステータスを更新する仕組み](#how-agents-update-your-stats)を参照)。

キャラクターとペルソナの**Stats**タブは、作りが違います。

### キャラクターのステータス

キャラクターにはスイッチが1つあります。**Enable RPG Stats**(RPGステータスを有効化)です。オフのときは、これより下の内容は表示も送信もされません。オンにすると、2つのセクションが現れます。

- **Pools**(プール)は、現在値、最大値、色を持つ名前付きのバーです。新しいキャラクターにはHPとMPがあり、どちらも100/100から始まります。
- **Attributes**(能力値)は、名前の付いた数値です。新しいキャラクターにはSTR、DEX、CON、INT、WIS、CHAがあり、どれも10から始まります。

**Add**(追加)をクリックするとプールや能力値を追加でき、行のXをクリックすると削除できます。

### ペルソナのステータス

ペルソナの**Stats**タブは2つのブロックに分かれていて、それぞれにスイッチがあります。

- **Persona Status Bars**(ペルソナのステータスバー)は**Enable Persona Stats**(ペルソナのステータスを有効化)でオンにし、身体面と精神面の状態を追跡します。最初に用意されるバーはSatiety、Energy、Hygiene、Moodで、どれも100/100から始まります。**Status Bars**の下では、各バーに名前、現在値、最大値、色があります。**Add**(追加)をクリックするとバーを追加でき、Xをクリックすると削除できます。
- **Enable RPG Attributes**(RPG能力値を有効化)は、キャラクターカードと同じように動作します。ペルソナに**Pools**(HPとMPが100/100から始まります)と**Attributes**(STR、DEX、CON、INT、WIS、CHAが10から始まります)が追加されます。

### Game Mode Icon

両方の**Stats**タブに**Game Mode Icon**(Game Modeのアイコン)ブロックがあります。Game Modeの戦闘で、盤面上のこのキャラクターやペルソナの丸いトークンに表示する画像を設定します。選択肢の横にある小さなトークンで、盤面での表示を確認できます。

- **Avatar**(アバター)がデフォルトです。アバターを使い、アバターがない場合はイニシャルを使います。
- **Custom image**(カスタム画像)は、カード自身のギャラリーの画像を使います。そこに表示されている画像を選ぶか、新しい画像をアップロードしてください。アップロードした画像はギャラリーに追加されます。この機能を使う前に、カードを一度保存してください。
- **Initials**(イニシャル)は、アバターがあっても常にイニシャルを表示します。

ほかの戦闘スタイルでも、このキャラクターには同じ画像が表示されます。選んだ画像をギャラリーから削除すると、このブロックにその旨が表示されます。別の画像を選ぶか、**Avatar**に戻してください。

<a id="ruleset-sheets"></a>

### ルールセットのシート

5e (SRD 5.1)などのGame Modeのルールセットがインストールされていると、両方の**Stats**タブで、上のセクションの下に**Ruleset sheets**(ルールセットのシート)のブロックが追加されます。インストールしたルールセットごとに、折りたたみできる項目が1つずつあります。もう持っていないルールセットのシートがカードに残っている場合も、このブロックは表示されます。

シートは、そのルールセットでのキャラクターの開始時の構成です。そのルールセットで新しいゲームを始めると、シートのコピーが使われます。ゲームの中での変更はそのゲームに残り、カードに戻ることはありません。

1. 項目を開き、**Add a sheet**(シートを追加)をクリックします。すべての値がルールセットのデフォルトになった空のシートが作られます。
2. シートに記入します。レイアウトはルールセットが決めます。修正値付きの能力値、セクションごとにまとめられた欄、攻撃や呪文などの一覧、習熟の段階と追加ボーナスが付いた技能とセーヴがあります。習熟ボーナスや受動〈知覚〉などの計算値は、入力に合わせて更新され、編集できません。
3. いつもどおりキャラクターやペルソナを保存します。

Professor Mariにシートへの記入や変更を頼むこともできます。たとえば「RookのBrawnを2にして、Rookの装備にバールを追加して」と伝えます。Professor Mariはそのルールセットのシートだけを書き換え、すべての値をルールセットの制限内に収め、変更カードで変更内容を示します。

用意された呪文、攻撃、特徴を同梱しているルールセットもあります。それらで埋まる一覧には**Add from catalog**(カタログから追加)ボタンがあり、検索できるピッカーが開きます。追加された行は、ほかの行と同じように編集できるコピーです。

- 能力値に連動する使用回数や、レベルとともに増えるクラスのリソースのように、ルールセットが管理するセルは、その場に表示されますが入力はできません。「Set by the ruleset」という注記が付き、シートを編集するたびに計算し直されます。
- そうした行について、選んだ後にルールセット自身の文章が変わった場合は、一覧の下に、新しい文章がある行の数と**Review**(確認)ボタンが表示されます。確認画面では、各行について自分の文章とルールセットの文章が並び、行ごとにチェックがあります。**Update selected**(選択したものを更新)は、チェックした行だけを書き換えます。比べるのは文章だけです。数値、スイッチ、ほかの列に入力した内容は変わりません。

インストールしていないルールセットのシートは保持されます。**Remove**(削除)ボタン付きの1行として表示され、AIに送られることはなく、そのルールセットをインストールすると再び編集できるようになり、カードをエクスポートするときもいっしょに含まれます。インストール済みのルールセットのシートでも、新しいバージョンで保存されたものなど、このバージョンが読み取れないものは、そのまま保持されます。その項目には**Remove this sheet**(このシートを削除)だけが表示されるので、新しいシートで誤って上書きしてしまうことはありません。シート1つの上限は64 KBです。

ルールセットのシートは、**Enable RPG Stats**や**Enable RPG Attributes**とは別のものです。Marinara独自のルールを使うゲームでは、シートは無視されます。ルールセットを使うゲームでは、判定に上のAttributesの代わりにシートが使われます。

<a id="how-agents-update-your-stats"></a>

## エージェントがステータスを更新する仕組み

**Stats**タブで、チャットの開始時の状態が決まります。エージェントが更新するのは、トラッカーが管理する値だけです。

| 値 | 変更するもの |
| --- | --- |
| HPなどのキャラクターの**Pools** | **Character Tracker**エージェントが、戦闘、回復、物語の出来事に合わせて変更します。プレイヤーのペルソナは追跡しません。 |
| **Persona Status Bars** | **Persona Stats**エージェントが、メッセージのたびに変更します。 |
| STRやDEXなどの**RPG Attributes** | どのエージェントも変更しません。戦闘とGame Modeのため、またRoleplayやGame Modeでの任意のダイスロールのために、カードといっしょに送られます。 |

対応するエージェントをオンにしなければ、トラッカーが管理する値は設定したデフォルトのままです。**Stats**タブだけでは、プレイ中に何も更新されません。これらのエージェントをオンにする方法は、[ダウンロードできるエージェント一覧](../agents/built-in-agents.md)を参照してください。

## HUDでのステータスの表示

有効にしたステータスは、チャット中にHUDに表示されます。HUDは、現在の値をリアルタイムに映す小さなパネルです。バーは色分けされたグラデーションで表示されます。HUDを移動する方法や非表示にする方法は、[HUDとトラッカー](../roleplay/hud-and-trackers.md)を参照してください。
