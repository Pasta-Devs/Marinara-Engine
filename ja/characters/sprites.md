# キャラクターのスプライト(表情と全身)

このガイドでは、スプライトと呼ばれるキャラクターの絵を追加する方法と、AIに描かせる方法を説明します。背景をきれいに抜く手順と、画面での見え方を調整する方法も扱います。スプライトはRoleplay ModeとGame Modeで使えます。

## スプライトとは

スプライトとは、画面に立つキャラクターの立ち絵です。Marinara Engineがチャットのシーンの上に重ねて表示します。Marinaraが扱うスプライトは2種類です。

- **Facial Expressions**(表情): うれしい、悲しい、怒っているなど、感情ごとの顔の画像です。
- **Full-body**(全身): 待機、歩行、戦闘中など、ポーズごとの全身の画像です。

スプライトが画面に出るのは**Roleplay Mode**と**Game Mode**だけです。Conversationモードの通常のチャットでは立ち絵は表示しません。ただしアップロード自体はどのモードでも行えます。スプライトはキャラクターに保存され、どのチャットで使っても付いてくるからです。

スプライトはキャラクターごとに追加します。自分が演じるキャラクターであるペルソナにも追加できます。ペルソナの編集画面にも、以下で説明する**Sprites**(スプライト)タブがあります。

## Spritesタブの場所

スプライトの管理は、キャラクター(またはペルソナ)の編集画面で行います。

1. 編集したいキャラクターを開きます。
2. 編集画面の**Sprites**タブをクリックします。
3. タブの上部で、**Facial Expressions**、**Full-body**、**Clips**のいずれかのカテゴリーを選びます。

このガイドが扱うのは**Facial Expressions**と**Full-body**のカテゴリーです。**Clips**カテゴリーは音声通話とビデオ通話のための別の機能です。クリップについては[Conversationの音声通話とビデオ通話](../conversation/calls.md)を参照してください。

## 手持ちのスプライトをアップロードする

すでに用意してある絵をアップロードできます。Marinaraは一般的な画像ファイルに対応しています。いちばんきれいに見えるのは透過PNGです。キャラクターの周りの余白が透けて、シーンとなじみます。

### スプライトを1つずつアップロードする

1. **Sprites**タブを開き、**Facial Expressions**か**Full-body**を選びます。
2. **Add Sprite**(スプライトの追加)欄で、テキスト入力欄に名前を入力します。表情のプレースホルダーは「Expression name (e.g. happy, sad, angry)」、ポーズのプレースホルダーは「Pose name (e.g. idle, walk, battle_stance)」です。
3. **Upload**をクリックして、画像ファイルを1つ選びます。

新しいスプライトが、付けた名前とともに下のグリッドに並びます。

### よく使う表情をまとめて追加する

**Facial Expressions**カテゴリーには**Quick add**(クイック追加)の行があり、まだ使っていない表情名(happyやangryなど)が候補として並びます。候補をクリックすると、その名前が入力済みの状態でファイル選択画面が開きます。名前を自分で入力する手間が省けます。

### フォルダーごとまとめてアップロードする

フォルダーにスプライトがたくさんある場合は、1回の操作でまとめてインポートできます。

1. 画像ファイルの名前を、表情名またはポーズ名にしておきます。たとえば`admiration.png`という名前にすると、admirationという表情になります。
2. **Add Sprite**欄で**Upload Folder**をクリックします。
3. 画像が入っているフォルダーを選びます。

拡張子を除いたファイル名が、そのままスプライトの名前になります。処理中は「Uploading X/Y sprites」という進行状況が表示されます。

同じ表情の別バージョンを作るときは、アンダースコアより前の名前をそろえます。たとえば`happy_01.png`と`happy_blush.png`は、どちらもhappyの別バージョンとして扱われます。

### スプライトを管理する

グリッド上のスプライトカードにマウスを重ねると、操作ボタンが表示されます。

- **Frame**(位置調整): 画像を切り抜いて、キャラクターの位置を整えます。
- **Download**: スプライトのファイルをコンピューターに保存します。
- **Replace**(置き換え): 同じ名前のまま、新しい画像に差し替えます。
- **Delete**(削除): そのスプライトを削除します。

削除するときは「Delete sprite for」と名前を示す確認メッセージが出ます。スプライトが複数表示されている場合は、同じウィンドウに**Delete All Expressions**または**Delete All Full-Body**も表示されます。

## AIにスプライトを生成させる

画像生成の接続を用意してあれば、Marinaraがスプライトを描いてくれます。接続とは、MarinaraとAIサービスをつなぐ設定のことです。スプライトの生成には画像生成の接続が、アニメーションするスプライトには動画生成の接続が必要です。用意の仕方は[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。

まず、**Add Sprite**欄の**Generate Sprite**(スプライトの生成)をクリックします。**Generate Sprites**ウィンドウが開きます。上部で、**Expressions (Portrait)**(ポートレートの表情)か**Full-body**のどちらを作るかを選びます。

ウィンドウの項目を入力します。

1. ドロップダウンから**Image Generation Connection**(画像生成の接続)を選びます。
2. 絵柄をそろえたい場合は、**Reference Images**(参照画像)を最大4枚まで追加します。現在のアバターを参照画像として使うチェックボックスもあります。
3. キャラクターの見た目を**Appearance Description**(外見の説明)に書きます。ここは必須です。
4. 必要に応じて**Transparent sprite background**(スプライトの背景を透過)をオンにします。Marinaraはまず、PNG本来の透過での生成を要求します。プロバイダーがアルファチャンネルを返せない場合は、**Appearance Description**の色と最も重ならない彩度の高いグリーン、マゼンタ、シアンのいずれかを背景色に選び、その色を自動で取り除きます。
5. **Expression Count**(表情の数)、全身の場合は**Pose Count**(ポーズの数)で生成する枚数を決め、どの表情やポーズを埋めるかを選びます。
6. **Generate**ボタンをクリックします。

画像ができあがったら、内容を確認します。1枚ずつオンとオフを切り替えたり、名前を変えたり、保存前に切り抜いたりできます。問題がなければ、選んだ画像をキャラクターのスプライトとして保存します。

**Full-body**を選んでいる場合、そのキャラクターにすでに表情のスプライトがあれば、**Match existing expression sprites**(既存の表情スプライトに合わせる)にチェックを入れられます。手持ちの表情名と同じ名前で、全身のポーズを作ります。

AIによる生成について、2点の注意があります。

- 生成には数分かかることがあります。アプリの画面にはもっと短い時間が表示される場合もあります。AIサービスの反応が遅いとさらに時間がかかります。やり直さずに待ってください。
- 一部のデバイス、たとえばAndroidの一部の環境では、AIによるスプライト生成と背景のクリーンアップを利用できません。その場合はボタンが無効になり、Marinaraが理由を画面に表示します。

### アニメーションするポートレートスプライト

**Expressions (Portrait)**を選ぶと、**Generate animated portraits**(アニメーションするポートレートを生成)というチェックボックスが表示されます。オンにすると、静止画の代わりに短い動画クリップを作り、それぞれをループするGIFスプライトに変換します。GIFは短いアニメーションを再生できる画像ファイルです。アニメーションするポートレートには、画像生成ではなく動画生成の接続を使います。

## スプライトの背景をきれいにする

スプライトはキャラクターだけが写り、背景が透けている状態がいちばんきれいです。生成した静止画のスプライトは、プロバイダーが対応していればPNG本来の透過を使います。対応していない場合、Marinaraは単色の背景色をふちをぼかしながら取り除き、髪や布などの半透明な部分に残った色も落とします。従来の白背景のスプライトも引き続き利用できます。

### スプライトを1枚ずつ手作業できれいにする

グリッド上のスプライトの画像をクリックすると、クリーンアップの編集画面が開きます。ここで背景を消したり、消しすぎた部分を塗り戻したり、暗い背景、明るい背景、市松模様の背景に重ねて結果を確認したりできます。取り消し、元の画像への復元、変更内容の適用も行えます。

### 複数のスプライトをまとめてきれいにする

**Clean Backgrounds**(背景のクリーンアップ)ボタンは、いまグリッドに表示されているすべてのスプライトから背景を取り除きます。

1. **Cleanup strength**(クリーンアップの強さ)スライダーを設定します。値はSoftからAggressiveまで、0から100までの範囲で、初期値は35です。値を大きくすると背景をより多く取り除きますが、キャラクター側まで削れることがあります。
2. **Clean Backgrounds**をクリックして確認します。

まとめてクリーンアップしたあと、Marinaraは安全のために元の画像を保持します。「Last cleanup has a restore point」という行と**Undo Cleanup**(クリーンアップの取り消し)ボタンが表示されます。クリックすると、対象のスプライトがすべて元の状態に戻ります。

背景のクリーンアップに対応している画像形式はPNG、JPG、JPEG、WEBP、AVIFです。GIFとSVGのファイルには使えません。

自動のクリーンアップは、画像を調べてから処理方式を選びます。まず動作の速い内蔵の処理が、単色の背景や従来の白背景を担当します。ふちの色が実際には均一でない場合、AIによる背景除去機能がインストールされていれば、Marinaraはそちらを代わりに使えます。込み入ったシーンや、背景とほとんど同じ色をしたキャラクターには、手作業のクリーンアップ編集画面がいちばん安全です。

## スプライトのエクスポート

キャラクターのスプライトは、zipファイルとしてコンピューターに保存できます。zipは複数のファイルを1つにまとめたファイルです。

1. **Sprites**タブを開きます。
2. **Add Sprite**欄の**Export**をクリックします。
3. 表示中のカテゴリーだけを書き出すなら**Expressions only**または**Full-body only**を、すべて書き出すなら**All sprites**を選びます。

ダウンロードされるのは、キャラクター名の付いたフォルダー1つで、その中にスプライトの画像ファイルが入っています。

## チャットでのスプライトの表示

スプライトをアップロードしただけでは、まだ半分です。チャット中にいつ、どのように表示するかも決めます。これはキャラクターの編集画面ではなく、チャットの設定で行います。

### Roleplay Mode

**Roleplay Mode**では、任意で追加する**Expression Engine**エージェントがスプライトの表示を担当します。**Agents → Agent Organizer (エージェント管理)**からダウンロードし、チャットに追加してください。メッセージごとの雰囲気を読み取り、合う表情のスプライトを選びます。詳しくは[ダウンロードできるエージェント一覧](../agents/built-in-agents.md)を参照してください。

Roleplayのチャットでスプライトを表示するには、次の条件をすべて満たす必要があります。

- チャットで**Expression Engine**エージェントが有効になっていること。
- キャラクターまたは使用中のペルソナが、スプライトの表示対象として1つ以上選ばれていること。
- スプライトの種類が1つ以上オンになっていること。

チャットの設定を開き、**Expression Engine**エージェントのカードを探します。ここでスプライトの表示を調整できます。

- **Sprite Source**(スプライトの種類): **Expressions**、**Full-body**、またはその両方を選びます。デフォルトでは両方オンです。少なくとも1つはオンのままにする必要があります。
- **Expression Avatars**(表情アバター): 立ち絵を重ねて表示する代わりに、メッセージの小さなアバターを対応する表情のスプライトに差し替えます。デフォルトはオフで、Roleplay Modeでのみ使えます。

### Game Mode

**Game Mode**では、話しているキャラクターや戦っているキャラクターの全身スプライトが自動で表示されます。Expression Engineエージェントは必要ありません。そのキャラクターに全身スプライトをアップロードしてあれば十分です。Game Mode全体の準備については[Game Mode: はじめに](../game/getting-started.md)を参照してください。

### スプライトの移動とサイズ変更(Arrangeモード)

スプライトの表示対象を有効にすると、**Expression Engine**エージェントのカードに**Sprite Layout**(スプライトの配置)の項目が表示されます。

- **Arrange**をクリックするとドラッグできる状態になり、各スプライトを好きな位置へ動かせます。終わったら**Done**をクリックします。
- **Reset**は自分で決めた位置を消して、自動配置に戻します。
- **Default Side**(デフォルトの表示位置)は、新しいスプライトを**Left**と**Right**のどちら寄りに置くかを決めます。デフォルトはLeftです。ここを変えると、現在の配置は左右が入れ替わります。
- サイズと透け具合は4つのスライダーで決めます。**Expression Size**と**Full-body Size**は5%から200%まで、**Expression Opacity**と**Full-body Opacity**は15%から100%までです。いずれも初期値は100%です。

## ビデオ通話用のクリップ

**Sprites**タブの**Clips**カテゴリーは別の機能です。Conversationモードの音声通話やビデオ通話で、キャラクターのカメラ映像として使う短いループ動画を作ります。通話機能の一部なので、説明は別のページにまとめてあります。[Conversationの音声通話とビデオ通話](../conversation/calls.md)を参照してください。
