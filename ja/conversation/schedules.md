# キャラクタースケジュールと自律メッセージ

このガイドでは、Conversationモードのキャラクターが自分から先にメッセージを送ってくる仕組みと、そのタイミングを調整する方法を説明します。自律メッセージ、キャラクターのスケジュール、**/status**コマンド、そして自分自身の在席ステータスを取り上げます。これらの機能はConversationモードでのみ動作します。

## 自律メッセージとスケジュールの役割

自律メッセージとは、こちらが何も書かなくてもキャラクターの側から先に送ってくるメッセージです。しばらく発言がないとMarinara Engine(以下Marinara)がこれを送るので、チャットが実際のメッセージのやり取りのように感じられます。

この動作は2つの設定で決まります。

- **Autonomous Messages**(自律メッセージ)は、キャラクターが自分から声をかけてよいかどうかを決めます。
- **Schedules**(スケジュール)は、キャラクターごとに1週間の生活リズムを与えます。時間帯によって、起きている、忙しい、寝ているといった様子が変わります。

スケジュールは任意です。自律メッセージだけをオンにしてスケジュールをオフのままにしても、キャラクターはtalkativeness(発言のしやすさ)とこちらのステータスに応じて声をかけてきます。talkativenessは、キャラクターが自分からどれくらいの頻度でチャットを始めるかを表すキャラクターごとの設定です。

## 自律メッセージをオンにする

これはキャラクターカードではなく、チャット側で設定します。ここで扱う項目はすべて**Chat Settings**(チャット設定)の**Autonomous Messaging**(自律メッセージ)セクションにあります。

1. Conversationのチャットを開きます。
2. **Chat Settings**(歯車アイコン)を開きます。
3. **Autonomous Messaging**セクションを探します。
4. **Autonomous Messages**トグルをオンにします。

新規チャットの設定ウィザードでは、**Autonomous Messages**は最初からオンです。**Chat Settings**からいつでもオフにできます。

### Chat Check-In Cap

トグルの下にある**Chat Check-In Cap**(1日あたりの声かけ上限)は、このチャットでキャラクターが1日に何回まで声をかけてよいかを制限します。

- デフォルトの選択肢は**Default chat ceiling (talkativeness-based)**です。上限は各キャラクターのtalkativenessから決まります。
- **Numeric value**を選ぶと数値入力欄が表示され、正の整数で上限を指定できます。上限を大きくすると、モデルへのリクエストと通知が大量に発生することがあります。

この上限はチャット全体に対する天井です。キャラクター個別の上限はスケジュール側で設定しますが、この数値を下げることはできても、上回らせることはできません。

talkativenessに基づくデフォルトは次のとおりです。

| キャラクターのtalkativeness | 1日あたりのデフォルト声かけ回数 |
|---|---|
| 80以上 | 8 |
| 60から79 | 6 |
| 40から59 | 5 |
| 20から39 | 3 |
| 20未満 | 2 |

### スケジュールをオンにする

**Schedules**（スケジュール）は**Autonomous Messaging**内にあります。保存したルーティンはキャラクターに属し、既存チャットに参加した場合も含めてConversationチャット間で共有します。特定のチャットで明示的に無効にすると、そのチャットでは無効のままで、キャラクターのルーティンは削除しません。

1. **Schedules**トグルをオンにします。
2. 既存のルーティンはすぐに表示されます。有効にするだけでは生成しません。必要なときに**Generate**を選んでください。
3. 生活リズムができると、キャラクターごとに1行が並ぶ**Edit schedules**(スケジュールの編集)リストが表示されます。

週ごとの自動更新は、**Character Schedule Manager**（キャラクタースケジュール管理）でキャラクターごとに有効にするまで無効です。失敗後にチャットを開き直しても繰り返し再試行しません。再試行は生成の操作で行います。

各行には、埋まっている日数が**3 days scheduled**のように表示されます。まだスケジュールがないキャラクターは**Create schedule**と表示されます。**Generate**ボタン(生活リズムができたあとは**Regenerate**)を押すと、いつでも作り直せます。

## Schedulesエディター

**Edit schedules**リストでキャラクターの行をクリックすると、スケジュールエディターが開きます。ウィンドウのタイトルは**Edit**に続いてキャラクター名と**Schedule**が並んだ形になります。

上部の**Routine profile**(生活リズムの概要)には、1週間の様子が読みやすい文章でまとめて表示されます。**Generate summary**ボタンで作成し、**Refresh summary**で内容を更新します。要約を作ったあとにスケジュールを変更すると、**Summary may be stale**という注意書きが表示されます。

### Tuning

主な設定は**Tuning**(調整)セクションにあります。

- **Chat talkativeness**は5段階のスライダーで、**Rare**、**Quiet**、**Balanced**、**Social**、**Very frequent**から選びます。中央の**Balanced**がデフォルトです。この値は、スケジュールが使われる場所でキャラクターのデフォルトのtalkativenessを上書きします。キャラクターが自分からメッセージを送る頻度、追いメッセージを送る頻度、グループの会話に加わる頻度に影響します。キャラクターのデフォルトの1日あたり上限もこの値で決まります。
- **Wait before checking in**は、このキャラクターが声をかけてよくなるまでに必要な無言の時間(分)です。指定できる範囲は15分から360分で、デフォルトは**120**です。
- **Check-in moments**は、キャラクターが声をかけるきっかけです。チップは**Morning**、**Goodnight**、**Meal breaks**、**After busy**、**Long absence**の5種類で、すべて最初はオンです。クリックするとオフになります。

### Advanced timing

**Tuning**の中の**Advanced timing**(詳細なタイミング設定)を開くと、さらに3つの設定があります。

- **Daily safety limit**は、このキャラクター1人に対する絶対的な上限です。**Default**か、1日1回から8回までの数値を選べます。チャットの上限を下げることはできますが、上回らせることはできません。通常は**Default**のままで問題ありません。
- **Delay while you're away**は、キャラクター自身のステータスが**Away**のときに、メッセージを送るまで何分待つかを指定します。空欄のままにするとデフォルトの動作になり、1分から3分のあいだでランダムに待ちます。指定できる範囲は0分から120分です。
- **Delay while you're busy**は、キャラクターのステータスが**Busy**のときの同じ設定です。空欄のままにすると、デフォルトの2分から5分のランダムな待ち時間になります。指定できる範囲は0分から120分です。

### Schedule AI: 1週間を作り直す

**Schedule AI**セクションを開くと、モデルに生活リズムを書き直させることができます。**Week action**を1つ選びます。

- **Rewrite**は1週間分をゼロから作り直します。
- **Adjust**は今の内容をおおむね残したまま、こちらの指示を反映します。
- **Vary**は、無理のない範囲で明らかに違う1週間にします。
- **Repair**は、抜けや明らかな問題を小さな修正で直します。

**Week guidance**の欄には、必要に応じて指示を書けます。たとえば次のように書きます。

```
make weekdays more nocturnal, keep weekends social
```

そのあと、選んだ操作の名前が付いたボタン(**Rewrite week**など)をクリックします。結果はあくまで下書きです。**Save schedule**をクリックするまで何も保存されません。 モデルが無効なJSONを返したら、**Edit generated schedule JSON**（生成したスケジュールJSONを編集）で修正し、**Apply to draft**（下書きに適用）を選びます。検証された修正と生成に成功した日は保存まで下書きに残ります。失敗した呼び出しは自動再試行せず停止します。**Stop**またはエディターを閉じると実行中の要求をキャンセルします。スケジュール管理やチャット設定を閉じた場合も、そこで開始した生成をキャンセルします。

### 曜日ごとのブロック

各セクションの下には、月曜から日曜まで曜日ごとの行が並びます。何も設定していない曜日には**No blocks scheduled for this day**と表示されます。

ブロックは3つの部分でできていて、**Status, time & activity**というラベルが付いています。

- **status**は**Online**、**Away**、**Busy**、**Offline**から選びます。
- 時間帯は`09:00-11:30`のような形式で入力します。
- 短い活動内容のメモです。たとえば`at work`のように書きます。

時間帯を追加するには**Add block**を使います。削除するにはゴミ箱アイコンをクリックします。曜日ごとに指示欄もあり、**Guide Monday**、**Guide Tuesday**のようなラベルが付いています。ここに指示を書いて**Regenerate Monday**のような対応するボタンをクリックすると、その曜日だけを作り直せます。

ブロックのステータスは、声をかける時刻になったときのキャラクターの動きを変えます。**Offline**のブロックが設定された時間帯では、キャラクターは自分からメッセージを送りません。**Busy**のブロックでは、声をかけるまでの待ち時間が通常の3倍になります。

設定が終わったら**Save schedule**をクリックします。**Cancel**を押すと、保存せずにエディターを閉じます。

### スケジュールを別のキャラクターや別の環境へ移す

エディター下部の**Export schedule**(スケジュールのエクスポート)を使うと、編集中の下書きをJSONファイルとしてダウンロードできます。曜日ごとのブロック、生活リズムの要約、talkativenessの設定、声をかけるきっかけ、詳細なタイミングの設定がまとめて書き出されます。

別のキャラクターのスケジュールエディターを開き、**Import schedule**(スケジュールのインポート)を選ぶと、そのファイルを読み込めます。Marinaraはファイルを検証してから編集中の下書きを置き換え、読み込んだ生活リズムを今週の日付に合わせます。インポートしただけでは保存されません。残す場合は**Save schedule**を、キャラクターの元のスケジュールをそのままにする場合は**Cancel**をクリックします。

### Schedule generation preferences

**Chat Settings**に戻ると、**Schedule generation preferences**(スケジュール生成の指示)欄があり、生活リズムの書き方を自由な文章で指示できます。この設定は全体に適用されます。次にスケジュールを生成するときから、手動でも自動でも、すべてのConversationチャットに反映されます。たとえば次のように書きます。

```
Make everyone go to sleep before midnight. I work 9-5 on weekdays.
```

## /statusで一時的なステータスを設定する

**/status**コマンドは、保存済みのスケジュールを変えずに、キャラクターの一時的なステータスを設定したり解除したりします。Conversationモードでのみ動作します。

コマンドの形式は次のとおりです。

```
/status <online|idle|dnd|offline|clear> [character name]
```

Awayにするときは`idle`、Busyにするときは`dnd`と入力します。スケジュールのブロックで使う4種類のステータスと同じものです。Miraという名前のキャラクターを今すぐ忙しい状態にするには、次のように入力します。

```
/status dnd Mira
```

この一時設定を解除してMiraをスケジュールどおりの状態に戻すには、次のように入力します。

```
/status clear Mira
```

チャットにキャラクターが1人しかいない場合は、名前を省略できます。**/status**をオプションなしで実行すると、キャラクターの一覧と使い方が表示されます。

## 自律メッセージの間隔の決まり方

Marinaraは、キャラクターがメッセージを連投しないように間隔を調整します。以下のルールでは、キャラクターごとのスケジュールを使います。

- キャラクターは、こちらが**Wait before checking in**の時間だけ発言しない状態が続くまで待ちます。デフォルトは120分です。
- 現在のステータスが**Offline**のキャラクターは、自分からメッセージを送りません。
- 現在のステータスが**Busy**のキャラクターは、通常の3倍の時間だけ待ちます。
- 最初のメッセージのあと、こちらが黙ったままなら、キャラクターはさらに最大2通まで送れます。1回の無言期間につき合計3通までです。
- 追いメッセージは、回を重ねるほど待ち時間が長くなります。1通目の追いメッセージは基準時間の2倍、2通目は4倍だけ待ちます。
- こちらが返信すると、この回数はリセットされ、次の無言期間はゼロから数え直します。

複数のキャラクターが同時に送れる状態になったときは、talkativenessが高く、タイミングが良いキャラクターが先に送ります。

## 自分の在席ステータス

自分のステータスは、こちらが今そばにいるかどうかをキャラクターに伝えます。ステータスの操作はサイドバーの下部にあり、どのチャットモードでも表示されます。ただし、メッセージ送信への影響が出るのはConversationモードだけです。

ステータスの表示部分をクリックすると、4つの選択肢が表示されます。

- **Active**: オンラインで、対応できる状態です。
- **Idle**: 離席中であることを示します。
- **Do Not Disturb**: 自律メッセージをすべて止めます。
- **Invisible**: ステータスをキャラクターから隠します。

**Idle**はほぼ自動で切り替わります。ステータスが**Active**のまま10分間何も操作しないと、Marinaraが**Idle**に切り替えます。戻ってくると**Active**に戻します。ポップアップから自分で**Idle**を選ぶこともできます。手動でどれかのステータスを選ぶと、再び**Active**を選ぶまで自動切り替えは止まります。

静かに過ごしたいときは**Do Not Disturb**にします。オンのあいだは、どのキャラクターも自分からメッセージを送りません。**Idle**は自律メッセージを止めません。離席中でもキャラクターは声をかけてきます。

ステータス表示の隣には**What are you doing?**欄があります。ここに120文字までの短い活動内容を入力できます。最近入力した内容は**Recent status**リストに並ぶので、そのまま使い回せます。
