# キャラクタースケジュールと自律メッセージ

自律メッセージとは、しばらく反応がないときに、キャラクターから先に送るメッセージです。スケジュールとは、キャラクターの週ごとの計画で、時間帯によって起きている、忙しい、眠っているといった様子を見せます。どちらも、Conversationモードでだけ動きます。

スケジュールは任意です。スケジュールがオフでも、キャラクターは、話好きの度合い(会話を自分から始める頻度)と、自分の在席状況に基づいて連絡します。

スケジュールだけが目的なら、[スケジュールをオンにする](#turn-on-schedules)へ進んでください。

## 自律メッセージをオンにする

始める前に: Conversationのチャットを開きます。新しいチャットは、これがオンの状態で始まります([Conversationモード: はじめに](getting-started.md)を参照)。

1. チャットで**Chat Settings**を開きます。
2. **Autonomous Messaging**セクションを探します。
3. **Autonomous Messages**をオンにします。

うまくいかなかった場合: 在席状況が**Do Not Disturb**のあいだは、キャラクターは沈黙したままです([在席ステータス](getting-started.md#your-presence-status)を参照)。

### チェックインの上限を設定する

**Chat Settings → Autonomous Messaging**の**Chat Check-In Cap**で、このチャットでキャラクターが1日に送れるチェックインの数を制限します。

- **Default chat ceiling (talkativeness-based)**は、各キャラクターの話好きの度合いから上限を決めます(下の表を参照)。
- **Numeric value**は、数値の入力欄を表示します。1以上の整数を入力します。値が大きいと、モデルへのリクエストと通知が多くなることがあります。

キャラクターには、**Daily safety limit**(スケジュールで設定)を持たせることもできます。キャラクターの上限は、次のように決まります。

- チャットの上限が**Numeric value**で、**Daily safety limit**も設定されている場合: 小さいほうの数が優先されます。
- どちらか一方だけの場合: その数が適用されます。話好きの度合いの数より大きくても同じです。
- どちらもない場合: 数は、キャラクターの話好きの度合いから決まります。

| キャラクターの話好きの度合い | 1日のチェックイン数 |
| --- | --- |
| 80以上 | 8 |
| 60～79 | 6 |
| 40～59 | 5 |
| 20～39 | 3 |
| 20未満 | 2 |

## スケジュールをオンにする

始める前に: **Autonomous Messages**をオンにします。

1. **Chat Settings → Autonomous Messaging**で、**Schedules**をオンにします。(新規チャットのウィザードでは、同じオプションが**Generate Schedules**という名前です。)すでにあるスケジュールは、すぐに表示されます。
2. その下の欄で、タイムゾーンを選びます。
3. **Generate**をクリックして、スケジュールがないキャラクターのスケジュールを作ります。スケジュールができた後は、ボタンの表示が**Regenerate**になります。
4. 完了するまで待ちます。すると、**Edit schedules**の一覧が表示され、キャラクターごとに1行が並びます。行には、スケジュールが入っている日数(例: **3 days scheduled**)か、**Create schedule**が表示されます。この一覧は、スケジュールができた後にだけ表示されます。
5. キャラクターの行をクリックして、そのスケジュールエディターを開きます(次のセクション)。

スケジュールはキャラクターのものであり、Conversationのどのチャットでも再利用されます。チャットで**Schedules**をオフにしても、スケジュールはそこに残り、保持されます。

毎週の自動更新は、**Character Schedule Manager**で、そのキャラクターの**Renew weekly**をオンにしない限り、オフです。サイドバーのフッターにある、ステータスの欄の隣のカレンダーボタンで開きます。

Marinaraは、アプリのページを読み込むたびに、キャラクターごとに1回、更新を試みます。失敗した場合は、ページを再読み込みするまで再試行しません。もう一度試すには、**Generate**をクリックします。

**Schedule generation preferences**は、**Chat Settings**の同じ**Schedules**の領域にあり、スケジュールの書き方についての自由記述の指示を入れる欄です。次にスケジュールを生成するとき、すべてのConversationのチャットに適用されます。例:

```text
Make everyone go to sleep before midnight. I work 9-5 on weekdays.
```

## Schedulesエディター

エディターのタイトルバーには、**Edit**、キャラクター名、**Schedule**が表示されます。

上部の**Routine profile**には、その週の内容が平易な言葉で要約されて表示されます。**Generate summary**で作成し、**Refresh summary**で更新します。スケジュールを変更した後は、**Summary may be stale**と表示されます。**Generation model**で、スケジュールを書くモデルを選びます。

### Tuning

**Tuning**を開くと、主な設定があります。

- **Chat talkativeness**: スライダーです。**Rare**、**Quiet**、**Balanced**、**Social**、**Very frequent**があります。デフォルトは**Balanced**です。キャラクターがメッセージを始めたりグループの会話に加わったりする頻度と、1日のデフォルトの上限を決めます。
- **Wait before checking in**: キャラクターがチェックインできるようになるまでの静かな時間(分)です。デフォルトは120です。15から360までを指定できます。
- **Check-in moments**: **Morning**、**Goodnight**、**Meal breaks**、**After busy**、**Long absence**のチップです。すべて最初からオンです。クリックするとオフになります。

**Tuning**の中の**Advanced timing**を開くと、さらに3つの設定があります。

- **Daily safety limit**: このキャラクターの1日あたりのチェックインの最大数です。**Default**のままにするか、1以上の整数を入力します。チャットにも数値の上限がある場合は、小さいほうの数が優先されます。そうでなければ、この数が話好きの度合いの数の代わりになります。
- **Delay while you're away**: ステータスが**Away**のあいだ、キャラクターが返信するまでの追加の時間(分)です。空欄にすると、ランダムに1〜3分になります。0から120までを指定できます。
- **Delay while you're busy**: ステータスが**Busy**のあいだの、同じ設定です。空欄にすると、ランダムに2〜5分になります。0から120までを指定できます。

### Schedule AI: 週の作り直し

**Schedule AI**を開くと、モデルがスケジュールを書き直します。**Week action**を1つ選びます。

| 操作 | 結果 |
| --- | --- |
| **Rewrite** | 週全体を新しく書いた下書き。 |
| **Adjust** | スケジュールの大部分を残して、指示を反映します。 |
| **Vary** | はっきり異なるが、もっともらしい週。 |
| **Repair** | すき間や明らかな問題を、小さな変更で直します。 |

1. **Week action**を選びます。
2. **Weekly generation**で、**Entire week in one request**か**One request per day**を選びます。1日ごとにリクエストを分けると、小さなリクエストが7つになり、トークン(モデルが読むテキストの小さな単位の数)が多くなります。
3. **Week guidance**に、任意のヒントを入力します。例: `make weekdays more nocturnal, keep weekends social`。
4. **Rewrite week**など、選んだ操作の名前のボタンをクリックします。
5. **Save schedule**をクリックして、結果を残します。それまでは下書きにすぎません(**Unsaved draft**)。

うまくいかなかった場合: 下書きは残ります。失敗した呼び出しは再試行されないので、もう一度ボタンをクリックしてください。実行中のリクエストを取り消すには、**Stop**をクリックするか、エディターを閉じます。エディターに**Edit generated schedule JSON**と表示された場合は、モデルが読み取れないテキストを返しています。そこでテキストを直して、**Apply to draft**をクリックしてください。

### 1日ごとのブロック

月曜から日曜まで、日ごとに行があります。空の日には、**No blocks scheduled for this day**と表示されます。各ブロックには、ステータス、`09:00-11:30`のような時間帯、`at work`のような短い活動があります。

1. 日の下で**Add block**をクリックします。
2. ステータスを選びます: **Online**、**Away**、**Busy**、**Offline**。
3. 時間帯と活動を入力します。
4. **Save schedule**をクリックします。**Cancel**は、保存せずにエディターを閉じます。

ブロックを削除するには、ごみ箱アイコンを使います。1日だけ書き直すには、**Guide Monday**(または選んだ曜日)にヒントを入力して、**Regenerate Monday**をクリックします。

**Offline**のブロックのあいだは、キャラクターから先にメッセージを送ることはありません。**Busy**のブロックのあいだは、いつもの3倍の時間待ちます。

### キャラクター間でのスケジュールの移動

**Export schedule**をクリックすると、下書きがJSONファイルとしてダウンロードされます(週ごとのブロック、要約、話好きの度合い、チェックインのタイミングを含みます)。別のキャラクターのエディターで**Import schedule**をクリックして、読み込みます。Marinaraはファイルを確認し、スケジュールを現在の週に移します。**Save schedule**をクリックするまで、何も保存されません。

## /statusでステータスを設定する

`/status`は、キャラクターの保存済みスケジュールを変えずに、一時的なステータスを設定または解除します。Conversationモードでだけ動きます。ステータスはキャラクターに属するため、そのキャラクターがいるすべてのチャットに適用されます。

メッセージ入力欄に、次のいずれかを入力します。

```text
/status dnd Mira
/status clear Mira
```

1つ目は、Miraをビジーにします。2つ目は、スケジュールに戻します。チャットにキャラクターが1人だけなら、名前は省略できます。`/status`だけを入力すると、キャラクターと、その状態の一覧が表示されます。`idle`は**Away**、`dnd`は**Busy**を意味します。完全な形は次のとおりです。角括弧は、名前が省略可能であることを示します。

```text
/status online|idle|dnd|offline|clear [character name]
```

設定したステータスは、解除するまで続き、キャラクターが置き換えることはできません。

## キャラクターが自分のステータスを変えられるようにする

**Chat Settings → Agents → Commands**で**Schedule Updates**がオンのとき、キャラクターは自分で、一時的なステータスと活動を設定できます。たとえば、1時間集中するように頼むと、活動「Studying」で**Busy**に切り替えられます。

- この変更は、キャラクターが言った時間か、言わなかった場合は1時間続きます。最長は7日間です。
- 時間が過ぎると、キャラクターはスケジュールに戻ります。スケジュールがなければ**Online**に戻ります。
- 保存済みのスケジュールを編集することはありません。

## チェックインの間隔の決まり方

| ルール | 詳細 |
| --- | --- |
| 最初のチェックイン | キャラクターは、**Wait before checking in**の時間(デフォルトは120分)だけ、自分が静かになるまで待ちます。 |
| リアクション | 新しいメッセージを伴わない、ユーザーからのリアクションは、待ち時間を短くします。 |
| **Offline**のステータス | チェックインはありません。 |
| **Busy**のステータス | 待ち時間は3倍になります。 |
| 追加のチェックイン | 反応がないあいだ、最大2回まで続けて送ります。合計3回です。1回目は待ち時間の2倍の後、2回目は待ち時間の4倍の後に届きます。 |
| 自分の返信 | 回数がリセットされます。 |
| 複数のキャラクターが対象のとき | 話好きの度合いがいちばん高く、タイミングがいちばん良いキャラクターが先に出ます。**Online**のキャラクターは、順位が上がります。 |

グループチャットで、各キャラクターが自分の返信で答える場合([グループチャットとグループでの会話](../chats/group-chats.md)を参照)、キャラクターは1日の上限と1つのペースを共有します。どのキャラクターがチェックインした後でも、次のだれかのチェックインは、追加のチェックインと同じように待ちます。自分の待ち時間が過ぎたキャラクターが送れます。その日のチェックインの回数がいちばん少ないキャラクターが先です。長い不在の後は、キャラクター1人だけがチェックインします。
