# Conversationモード: はじめに

このガイドでは、Marinara Engineのメッセンジャーアプリのようなチャットモード、Conversationモードを説明します。どんなモードなのか、4ステップの設定ウィザードがどう動くのかがわかります。自動メッセージ、在席ステータス、リアクション、自撮り写真、テーブルゲームといったConversationモード専用の機能も取り上げます。

## Conversationモードとは

ConversationモードはMarinara Engineのチャットモードの1つで、メッセージアプリのように動きます。画面には1人以上のキャラクター、入力バー、スクロールするメッセージ履歴が並びます。

友だちに文字を送る感覚で、ダイレクトメッセージ(DM)をやり取りするイメージです。ゲームマスターも、シーンの絵も、必須のゲーム的な仕組みもありません。いちばん手軽なチャットモードで、ここで過ごす時間がいちばん長いユーザーも多くいます。

Conversationモードには、続いていくメッセンジャーの関係だからこそ意味を持つ機能があります。キャラクターにはオンラインや離席のステータスと週間スケジュールがあります。キャラクターの側から先に話しかけたり、自撮り写真を送ったり、絵文字でリアクションしたり、テーブルゲームで遊んだりできます。キャラクターとペルソナには、表示名と自己紹介を書けるDiscord風の小さなプロフィールも用意されています。プロフィールの項目については[Conversationモードのプロフィール](profiles.md)を参照してください。

こうしたConversationモード専用の機能は、RoleplayやGame Modeでは働きません。同じキャラクターカードを使い回した場合も同じです。

反対に、Conversationモードでは働かないカードの項目もあります。Conversationのチャットは、カードの**First Message**(最初のメッセージ)やほかの挨拶メッセージから始まりません。挨拶メッセージから始まるのはRoleplayのチャットだけです。また、カードの**Dialogue Highlight Color**(セリフの強調色)と**Message Box Color**(メッセージボックスの色)も使いません。**Name Display Color**(名前の表示色)は引き続き、各メッセージの上に表示されるキャラクター名の色になります。[色が反映される場所](../characters/colors-and-stats.md#where-your-colors-show)を参照してください。

### Conversationモードを選ぶ場面

次のどれかに当てはまるときは、Conversationモードを選びます。

- 友だちにDMを送るように、文字だけでキャラクターとチャットしたい。
- 1つのスレッドで複数のキャラクターと同時に話したい。
- メッセージを送る、スケジュールに従う、時間の経過とともにリアクションするなど、キャラクターに自分から動いてほしい。

スプライトや背景といったシーンの絵、あるいはきちんとしたゲームの仕組みが欲しいときは、RoleplayやGame Modeを選びます。

## 4ステップの設定ウィザード

新しいConversationチャットを始めると、4ステップのウィザードが開きます。閉じてしまって、後からチャット設定パネルで設定することもできます。4つのステップは次のとおりです。

1. **Name & Connection**(名前と接続): チャットに名前を付け、キャラクターが使うAI接続を選びます。接続とは、AIプロバイダーへの接続情報をまとめて保存したものです。[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。
2. **Prompt Preset**(プロンプトプリセット): Conversationのプロンプトをどのプリセットから読み込むかを選ぶか、デフォルトのままにします。
3. **Persona & Characters**(ペルソナとキャラクター): ペルソナと1人以上のキャラクターを選びます。
4. **Automation**(自動化): キャラクターがどこまで自分で動けるかを決めます。

ペルソナは自分が演じるキャラクターです。詳しくは[ペルソナの作成と編集](../characters/personas.md)を参照してください。

選んだキャラクターの数でチャットの形が決まります。1人なら1対1のDMになります。2人以上ならグループチャットになり、別のモードをオンにする必要はありません。グループチャットの設定項目は[グループチャット](../chats/group-chats.md)にあります。

接続と1人以上のキャラクターが決まったら、**Start Chatting**(チャットを開始)をクリックするとチャットが開きます。

### Automationステップ

**Automation**ステップには、次の項目が必ず用意されています。

| トグル | デフォルト | 動作 |
|---|---|---|
| **Autonomous Messages**(自動メッセージ) | On | 操作していない間に、キャラクターから先にメッセージを送れます。 |
| **Generate Schedules**(スケジュールの生成) | Off | 週間ルーティンを任意で作ります。Autonomous Messagesがオンのときだけ表示します。 |

Conversationのコマンドを追加するエージェントパッケージをインストールしていると、このステップに**Commands**(コマンド)も表示します。通話、Illustratorの自撮り写真、Music DJ、Haptic Feedback、各テーブルゲームは、対応するパッケージをインストールしている場合だけ現れます。通話については[Conversationの音声通話とビデオ通話](calls.md)を参照してください。

### Commandsの一覧

**Commands**が使える状態でオンになっていると、最大17種類のコマンドグループが一覧で並びます。どれも、キャラクターが自分の判断で実行できる裏方の動作です。パッケージが提供する項目は、そのパッケージをインストールしている場合だけ表示します。表示されているグループは最初からすべてオンです。トグルをオフにすると、そのグループだけが外れます。コマンドはモデルが判断して実行する動作で、自分で入力するものではありません。

コマンドグループの全種類は次のとおりです。

- **Schedule Updates**(スケジュールの変更): キャラクターが自分の現在のステータスを変えられます。
- **Cross-Post**(他チャットへの転送): キャラクターがメッセージを別のチャットに送り直せます。
- **Selfies**(自撮り写真): キャラクターが自撮り写真の生成を求められます。
- **Memories**(記憶): キャラクターが他のキャラクターについての記憶を作れます。
- **Scenes**(シーン): キャラクターが没入感のあるシーンを始められます。
- **Music**(音楽): キャラクターが有効なMusic Playerで曲を再生できます。
- **Haptics**(ハプティックデバイス): キャラクターが接続済みのハプティックデバイスを操作できます。
- **Influence**(影響): キャラクターが連携中のチャットに影響を与えられます。
- **Notes**(メモ): キャラクターが連携中のチャットに残るメモを保存できます。
- **Calls**(通話): キャラクターがConversationの通話を呼び出せます。
- **Reactions**(リアクション): キャラクターが絵文字バッジでメッセージにリアクションできます。
- **UNO**: 遊ぶことに同意すると、キャラクターがテーブルでUNOを始められます。
- **Chess**(チェス): キャラクターが1対1のチェスの挑戦を受けられます。
- **Poker**(ポーカー): キャラクターがテーブルに着いてテキサスホールデムのポーカーを遊べます。
- **8-Ball Pool**(エイトボール): キャラクターがテーブルでエイトボールのビリヤードを始められます。
- **Tic-Tac-Toe**(三目並べ): キャラクターが1対1の三目並べの挑戦を受けられます。
- **Rock-Paper-Scissors**(じゃんけん): キャラクターが1対1のじゃんけん勝負を受けられます。

これらすべてを、**Commands**の親トグル1つがまとめて制御します。親トグルがオフのときは、有効に見えていてもどのコマンドグループも動きません。

## 自動メッセージと在席ステータス

自動メッセージを使うと、キャラクターの側から先に話しかけてきます。**Autonomous Messages**がオンのとき、しばらく発言がないとキャラクターがメッセージを送ってきます。キャラクターは自分のおしゃべりの度合いと、スケジュールがオンならそのときの在席状況も踏まえて判断します。ウィザードを終えた時点では、自動メッセージはオンがデフォルトです。

このトグルは後から変更できます。チャット設定パネルを開き、**Autonomous Messaging**(自動メッセージ機能)セクションを探してください。

### 在席ステータス

在席ステータスは、キャラクターが話しかけてくるタイミングを左右します。サイドバーの下部に、現在のステータスを示す色付きのピルとして表示します。ピルをクリックすると、4つの選択肢から選べます。

- **Active**(対応可能): オンラインで、やり取りできる状態です。
- **Idle**(離席): 離れているときに自動で設定します。
- **Do Not Disturb**(取り込み中): 自動メッセージを止めます。
- **Invisible**(非表示): キャラクターからステータスを隠します。

ピルの隣には**What are you doing?**欄があります。今していることをキャラクターに伝えたいときは、ここに短い一言を書き込みます。在席ステータスは全体で共通なので、どのチャットでも同じ状態になります。

## リアクションと通知

Conversationのメッセージには、どれでも絵文字のリアクションを付けられます。メッセージのリアクションボタンから追加します。Marinaraはリアクションを`[User reacted with ...]`のようなメモとして保存し、以降の返信からも見えるようにします。これでキャラクターはリアクションに気づけます。

**Reactions**のコマンドグループがオンなら、キャラクターもリアクションできます。こちらのメッセージにも、キャラクター同士のメッセージにも反応します。メッセージを丸ごと書かずに軽く反応できるので、グループチャットで便利です。

開いていないチャットにキャラクターがメッセージを送ってくると、画面の端にアバターの吹き出しが浮かびます。吹き出しをクリックするとそのチャットに移動し、Xを押すと閉じます。モバイルでは、たまった吹き出しがタップできる1つのまとまりになります。

## 自撮り写真

キャラクターは自撮り写真、つまりAIが生成したそのキャラクターの写真を送ってきます。自撮り写真は1人のキャラクターに結び付いている点で、RoleplayやGame Modeで使うシーンの絵とは違います。

自撮り写真を使うには、**Agents → Download Agents**から**Illustrator**をインストールします。次にチャット設定パネルを開き、**Agents → Illustrator Settings**へ進んで**Selfie Connection**(自撮り写真用の接続)を設定します。ここで指定するのは画像生成のプロバイダーです。自撮り写真は1枚につき画像生成の呼び出しを1回使います。

画風、解像度、手動でリクエストするボタンを含む設定の全体は[自撮り写真](selfies.md)にあります。

## テーブルゲーム

Conversationモードでは、テーブルゲームのパッケージを6つ、任意で追加できます。**UNO**、**Chess**、**Poker**、**8-Ball Pool**、**Tic-Tac-Toe**、**Rock-Paper-Scissors**の6種類です。遊びたいゲームは**Agents → Download Agents**からインストールします。盤面を配るのもルールを守らせるのもアプリが行い、キャラクターはそれぞれ自分の手をキャラクターらしく語ります。テーブルゲームが動くのはConversationチャットだけです。

ゲームの始め方は3つあります。

1. メッセージ入力欄にスラッシュコマンドを入力し、Enterを押します。
2. 「let's play uno」のような普通のメッセージを送ります。
3. コマンドグループがオンなら、キャラクターからの誘いを待ちます。

スラッシュコマンドは次のとおりです。

```
/uno
```

```
/chess
```

```
/poker
```

```
/8ball
```

```
/tictactoe
```

```
/rps
```

ゲームごとに、選択肢を備えた専用の設定ボックスがあります。ルール、設定ボックス、盤面の詳細は[テーブルゲーム](table-games.md)を参照してください。

## キャラクターのスケジュール

Conversationチャットのキャラクターには、それぞれ週間スケジュールを設定できます。スケジュールでは、7日間24時間のマス目にキャラクターのステータスと行動を割り当てます。これで自動メッセージが生活のリズムを踏まえたものになり、離席にしてある時間帯にキャラクターが話しかけてくることはなくなります。

設定の途中で**Generate Schedules**をオンにすると、スケジュールを作れます。後からチャット設定パネルの**Autonomous Messaging**セクションで作成や編集をすることもできます。スケジュールエディターの全機能、1日あたりの上限、上書き用の`/status`コマンドについては[キャラクタースケジュールと自律メッセージ](schedules.md)で説明します。

## トラブルシューティング

### 自動メッセージが多すぎる

チャット設定パネルを開き、**Autonomous Messaging**セクションで**Autonomous Messages**をオフにします。在席ステータスを**Do Not Disturb**にしても自動メッセージを止められます。スケジュールを使っている場合は、[キャラクタースケジュールと自律メッセージ](schedules.md)を参考に離席の時間帯を増やしてください。

### グループチャットで1人のキャラクターばかりが返信する

グループチャットには、**Reply When Mentioned**(メンションされたときだけ返信)のように発言の順番を調整する設定があります。誰がいつ話すかは[グループチャット](../chats/group-chats.md)で設定します。

### キャラクターが前の話を忘れる

チャットが長くなると、モデルが覚えていられる範囲がいっぱいになります。コンテキストウィンドウの大きいモデルを試すか、大事な情報をロアブックのエントリーに書いてコンテキストに残してください。同じキャラクターとペルソナで新しいチャットを始め直すのも有効です。さらに詳しくは[Marinara Engineのトラブルシューティング](../TROUBLESHOOTING.md)を参照してください。

### 自撮り写真がキャラクターに似ない

**Selfies**の設定を開き、**Attach Card Appearance**(カードの外見情報を添付)を**Images only**(画像のみ)か**Images and videos**(画像と動画)に設定します。使っている画像生成プロバイダーが参照画像に対応しているなら、**Send Avatar References**(アバターの参照画像を送信)も設定してください。詳しくは[自撮り写真](selfies.md)を参照してください。
