# Conversationモードのテーブルゲーム

Conversationのチャットのキャラクターを相手に、UNO、チェス、ポーカー、8-Ball Pool、Tic-Tac-Toe、Rock-Paper-Scissorsで遊びます。Marinaraがカードを配ったり盤面を用意したりし、すべてのルールを適用し、席に着いたキャラクターが、キャラクターらしく手を語ります。遊んでいるあいだ、メッセージ入力欄の上にライブの盤面が表示されます。

ゲームは、それぞれが任意のパッケージです。使いたいものを**Agents → Agent Organizer**からインストールし、カタログが求めたら、Marinaraを再起動してください。インストールしていないゲームには、スラッシュコマンドがなく、ゲームの選択画面にも表示されず、**Commands**スイッチも隠れたままです。

すべてのゲームに共通するルールは次のとおりです。

- テーブルゲームは、Conversationモードでだけ使えます。Roleplayのチャットでは、ゲームはConversationのチャットでしか遊べないというメッセージが表示されます。
- 1つのチャットで、アクティブにできるゲームは1つだけです。新しいゲームを始めると、終了のバナーがまだ表示されている終わったゲームでも、現在のゲームが置き換わります。
- チャットにはキャラクターが1人以上必要で、ボットとして、1人以上を席に着かせる必要があります。ボットの手は、ふだんの返信と同じモデルを使います。追加のアカウントやAPIキーは必要ありません。

## ゲームを始める

始める前に: ゲームをインストールして、キャラクターが1人以上いるConversationのチャットを開いてください。

1. メッセージ入力欄に、ゲームのスラッシュコマンド(`/`で始まる短い指示)を入力して、<kbd>Enter</kbd>を押します。ゲームのセットアップウィンドウが開きます。
2. オプションを選びます(各ゲームの項目を参照)。
3. **Deal**または**Start game**をクリックします。

うまくいかなかった場合: ゲームをインストールしていないか、Conversationのチャットを開いていないと、コマンドが見つからないか、何も起きません。

| ゲーム | コマンド | プレイヤー |
| --- | --- | --- |
| UNO | `/uno` | 自分と、キャラクター1〜9人。 |
| Chess | `/chess` | 自分と、キャラクター1人。 |
| Poker | `/poker` | 自分と、キャラクター1〜7人。 |
| 8-Ball Pool | `/8ball`または`/pool` | 自分と、キャラクター1人。 |
| Tic-Tac-Toe | `/tictactoe`または`/ttt` | 自分と、キャラクター1人。 |
| Rock-Paper-Scissors | `/rps` | 自分と、キャラクター1人。 |

ゲームを始めるほかの方法は次のとおりです。

- `/games`と入力して、インストール済みのゲームから選びます。
- 「let's play uno」「start a game of chess」「deal me into poker」のように、通常のメッセージで伝えます。セットアップウィンドウが開き、メッセージも送信されるので、キャラクターが招待に反応できます。これは、ゲームがまだ進行中でないときに起きます。
- キャラクターが、自分から、ゲームに誘ったり、誘いを受けたりできます。その返信で、デフォルトのルールのまま、セットアップウィンドウなしですぐにゲームが始まります。忙しいか断った場合は、キャラクターらしくそう言います。
- キャラクターがこれをできるのは、そのゲームの**Commands**スイッチがオンのときだけです([キャラクターが自分でゲームを始められるようにする](#let-characters-start-games-on-their-own)を参照)。

## UNO

セットアップウィンドウのタイトルは**Start UNO**です。

- **Players**: ボットとして遊ぶキャラクターにチェックを入れます。デフォルトでは、すべてにチェックが入っています。**You go first**は、デフォルトでチェックが入っています。
- **Starting hand**: 1人あたりのカードの枚数で、1〜10枚です。デフォルトは**7**です。
- **Penalize missed UNO**: チェックが入っています。UNOを宣言せずにいるところを見つかったプレイヤーは、2枚引き、**Catch!**が有効になります。
- **House rules**: すべて、デフォルトでオフです。
  - **Stacking**: +2/+4を、次のプレイヤーに引かせずに重ねます。
  - **Draw to match**: 出せるカードが出るまで引き続けます。
  - **7-0 rule**: 7は選んだプレイヤーと手札を交換し、0はすべての手札を回します。
  - **Jump-in**: 順番を無視して、まったく同じカードを出します。
  - **Force play**: 引いたカードが出せるなら、必ず出します。

**Deal**は、キャラクターを1人以上選ぶまで、無効のままです。プレイヤーの数が、たとえば、自分とキャラクター2人なら**Deal (3p)**のように表示されます。

盤面では、出せるカードが持ち上がり、ほかは暗くなります。カードをクリックして出します。

- ワイルドカードでは、「Pick a color:」が開きます。**7-0 rule**がオンなら、7で「Swap hands with:」が開きます。
- 必要に応じて、**Draw**、**Pass**、**Call UNO!**、**Catch!**のボタンが表示されます。
- 手札の後ろから2枚目のカードを出すと、UNOが自動で宣言されます。
- バナーに「{winner} wins!」または「Game over」と表示されます。

## Chess

セットアップウィンドウのタイトルは**Start Chess**です。**Opponent**を選びます(デフォルトは最初のキャラクター)。グループチャットでは、ほかのキャラクターはおしゃべりを続けます。**Your color**は、**White**、**Random**(デフォルト)、**Black**です。**Start game**をクリックします。

駒を1つクリックして選びます。指せる手は点で、取れる駒はリングで表示されます。黒番で遊ぶと、盤が反転します。最後の段に着いたポーンでは、「Promote to:」(Queen、Rook、Bishop、Knight)が開きます。バナーで、チェックメイトか、理由付きの引き分け、または「Game over」が知らされ、盤面の下の帯に、直近の手が一覧表示されます。

## Poker

セットアップウィンドウのタイトルは**Start Poker**です。テーブルには2〜8人が着席できます。

- **Players**: 席に着くキャラクターにチェックを入れます。7人になると、残りはグレーアウトします。
- **Dealer**: **House dealer (silent)**(デフォルト)は、解説なしでカードを配ります。または、キャラクターを選んで、ハンドとショーダウンを知らせてもらいます。
- **Starting stack**: プレイヤーごとのチップで、100〜1,000,000です。デフォルトは**1000**です。
- **Small blind**: ビッグブラインドは、この2倍です。デフォルトは**10**です。
- **Blinds double every**: ブラインドが上がるまでのハンド数です。デフォルトは**0**で、上がりません。
- **Hand limit**: このハンド数が終わると、セッションが終了し、チップがいちばん多い人が勝ちます。デフォルトは**0**で、1人がチップを持つだけになるまで続きます。

自分の番には、バーに**Fold**、**Check**、**Call**、**All in**が表示されます。ベットやレイズができるときは、ボックスに、**Min**、**½ pot**、**Pot**、**All-in**のボタンが加わります。ハンドが終わるたびに、**Showdown**パネルがポットを配分し、**Next hand**で再び配られます。セッションの最後には、バナーが勝者を知らせ、最終的な全員のスタックを一覧表示します。

## 8-Ball Pool

セットアップウィンドウのタイトルは**Start 8-Ball Pool**です。

- **Opponent**: 対戦するキャラクターです。
- **Announcer**: デフォルトは**Silent (no announcer)**で、またはショットを解説するキャラクターを選べます。
- **Match length**: **Race to 1**、**Race to 3**、**Race to 5**のラック数です(1ラックは1ゲーム全体)。
- **Who breaks first**: **You**、**Random**、**Them**。次のラック以降は、交互にブレイクします。

**Start game**をクリックします。自分の番には、提案されたショットから1つ選ぶと、物理シミュレーションでボールが転がります。テーブルの下の1行に、直近のショットが説明されます。

## Tic-Tac-ToeとRock-Paper-Scissors

**Tic-Tac-Toe**では、対戦相手と、**X**、**O**、またはランダムのマークのどれで遊ぶかを選びます。Xが先に動きます。自分の番に、空のマスをクリックします。無効な手はブロックされ、勝ちと引き分けは自動で判定されます。

**Rock-Paper-Scissors**では、対戦相手と、3回、5回、7回のうち何回先取かを選びます。毎ラウンド、**Rock**、**Paper**、**Scissors**を選びます。選択は、両方が出そろうまで隠れたままで、その後、結果とスコアが更新されます。

## ゲームを途中で終える

どの盤にも、Xボタンがあります。

- **UNO**: **End game**。先に「End this game?」と確認されます。
- **Chess**: **Resign**。先に「Resign and end this game?」と確認されます。
- **Poker**: **End game**。先に「End this poker game?」と確認されます。セッションが終わった後は、**Close**と表示されます。
- **8-Ball Pool**: **End game**。先に「End this pool game?」と確認されます。試合が終わった後は、**Close**と表示されます。
- **Tic-Tac-Toe**と**Rock-Paper-Scissors**: 盤の閉じるボタンまたは終了ボタンで、試合を消します。

ゲームを途中で終えると、その状態が削除され、勝者は記録されません。

## キャラクターが自分でゲームを始められるようにする

**Chat Settings → Agents → Commands**を開くか、チャットを作るときに**Automation**のステップを使います。マスターの**Commands**スイッチは、テーブルゲーム、自撮り写真、通話を含む、キャラクター主導のすべての操作を制御します。オフのときは、キャラクターが自分から何かを始めることはありません。

インストールしたゲームには、それぞれ専用のスイッチがあり、オフにしない限りオンです。**UNO**、**Chess**、**Poker**、**8-Ball Pool**、**Tic-Tac-Toe**、**Rock-Paper-Scissors**です。[キャラクターが使えるCommandsの選択](getting-started.md#choose-which-commands-a-character-can-use)を参照してください。

これらのスイッチが制御するのは、キャラクターができることだけです。ゲームのスラッシュコマンドと、「let's play」という言い方は、スイッチがオフでも動作します。
