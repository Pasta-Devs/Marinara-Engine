# Marinara Engineをはじめる

Marinara Engineへようこそ。このガイドでは、このアプリがどんなものか、ホーム画面に何が並んでいるのか、そして最初のチャットを始めるまでの手順を説明します。初めて使う人に向けて書いてあるので、事前の知識は必要ありません。

## Marinara Engineとは

Marinara Engineは、AIキャラクターとチャットしたりロールプレイしたりするためのローカルアプリです。手元のコンピューターで動き、好きなAIサービスにつないで使います。キャラクターを作るかインポートして、チャットの方法を選び、あとは話しかけるだけです。Marinara自体はAIを動かさないので、最初にやることは接続の追加です。多くの人はオンラインのAIプロバイダーにつなぎます。ダウンロードして使える小さな**Local Model**(ローカルモデル)も内蔵しています。ただしこれは軽い補助作業向けで、メインのチャットには向きません。詳しくは[Local Modelのセットアップ](../connections/local-model.md)を参照してください。最初の設定さえ済めば、あとはすべてアプリの中で完結します。

## ホーム画面の全体像

ホーム画面は、チャットを開いていないときに表示される画面です。見た目はWebブラウザーに少し似ていて、上部にタブとブックマーク、その下にウィジェットを並べた机があります。

上部には次のものがあります。

- **タブ。** **Home**(ホーム)がメインのページです。**Professor**(プロフェッサー)を開くと、アプリの説明や設定の手伝いをしてくれる内蔵アシスタントのProfessor Mariが開きます。インストールしたエージェントの中には、独自のタブを追加するものもあります。
- **検索バー。** コンピューターでは、タブの下のバーをクリックするか、Ctrl+K(MacではCmd+K)を押すと、チャット、キャラクター、設定などを探せます。
- **ブックマーク。** **Discord**、**Support**、**Credits**、**Documentation**、**Tutorial**、**FAQ**、**Achievements**、**Widgets**へのクイックリンクです。**Achievements**は、Achievementsの設定がオンのときだけ表示されます。スマートフォンでは、タブの左にあるブックマークのボタンをタップすると一覧で表示されます。

中央には、アプリのロゴ、**Marinara Engine**の文字、バージョン番号が表示されます。その下にある**Conversation**、**Roleplay**、**Game**の各ボタンで、そのモードの新しいチャットを始められます。

Marinaraを初めて開くと、短いガイドツアーが主要なボタンとチャットモードを案内します。ひととおりの流れは[初回チュートリアル](tutorial.md)を参照してください。

## ホームのウィジェット

ホーム画面の残りの部分は、ウィジェットでできています。ウィジェットとは、表示したり隠したり動かしたりできる小さなカードです。アプリには次のウィジェットが付いています。

| ウィジェット | できること | 最初から表示 |
| --- | --- | --- |
| **Professor Mari** | **Ask Professor Mari**(Professor Mariに質問)をクリックすると、Professor Mariとのチャットが開きます。 | はい |
| **Recent chats**(最近のチャット) | 最近のチャットを、最後のメッセージとともに表示します。クリックすると開き直せます。まだ1件もない場合は**Your chats will show here**と表示されます。 | はい |
| **Learn the engine**(エンジンを学ぶ) | **Documentation**、**Replay tutorial**、**Read FAQ**へのリンクです。 | はい |
| **What's New**(新機能) | **See what's new**を押すと、以前に閉じた場合でも、このバージョンのWhat's Newウィンドウがもう一度開きます。**Read release notes**を押すと、Webで完全なリリースノートが開きます。 | はい |
| **Community**(コミュニティ) | **Discord**、**Support**、**Credits**へのリンクです。 | はい |
| **Character Library**(キャラクターライブラリー) | 毎日新しく選ばれた自分のキャラクターを表示します。 | いいえ |
| **Discovery desk**(発見デスク) | まだインストールしていないエージェントを提案します。矢印でほかの提案を見るか、**Browse agents**でカタログを開きます。 | いいえ |
| **Character of the Day**(今日のキャラクター) | ライブラリーから選んだキャラクター1人を、**Start a chat**と**View character**とともに表示します。 | いいえ |
| **Clock & calendar**(時計とカレンダー) | 今日の日付と時刻です。 | いいえ |
| **Achievements**(実績) | 最近獲得した実績と、獲得に最も近い実績です。Achievementsの設定がオンのときだけ使えます。 | いいえ |

インストールしたエージェントの中にも、ウィジェットを追加するものがあります。Professor Mariに頼めば、自分専用のウィジェットを作ってもらうこともできます。

表示するウィジェットを選ぶには、ブックマークの**Widgets**(ウィジェット)をクリックします。**Home Widgets**(ホームのウィジェット)ウィンドウでは、**Built-in**(組み込み)、**Agents**(エージェント)、**Personal**(個人用)に分けて一覧になっています。ウィジェットの横の目のボタンをクリックすると、表示と非表示を切り替えられます。もう一度表示したウィジェットは、ホームの最初の空いている場所に入ります。個人用のウィジェットには、編集と削除のボタンもあります。

ウィジェットを動かすには、右上の角にあるハンドルをドラッグします。コンピューターでは、ウィジェットにポインターを合わせるとハンドルが現れます。キーボードでは、ハンドルにフォーカスを合わせて矢印キーを使います。ウィジェットの配置は、このブラウザーに保存されます。

**Home Widgets**ウィンドウの下部にある**Browser chrome**(ブラウザーの表示部分)には、3つのスイッチがあります。**Show URL bar**(URLバーを表示)は検索バーの表示と非表示を切り替えます。**Other-tab bookmarks (desktop)**と**Other-tab bookmarks (mobile)**をオンにすると、**Home**以外のタブでもブックマークが表示されたままになります。

## 最初にやること

最初のチャットにたどり着くまでの手順です。順番に進めてください。

1. Marinara Engineをインストールして、ブラウザーで開きます。プラットフォームごとの手順は[Marinara Engineのインストール](../INSTALLATION.md)にあります。
2. アプリがAIサービスに届くように、接続を追加します。接続には、プロバイダー、APIキー、モデルをまとめて保存します。APIキーとは、AIプロバイダーから受け取る、パスワードのような秘密の文字列です。[AIプロバイダーへの接続](../connections/connecting-to-a-provider.md)を参照してください。
3. チャット相手のキャラクターを作るか、インポートします。**Characters**パネルを開いて**New**(新規)をクリックすると**Create Character**ウィンドウが開きます。ファイルからキャラクターカードを取り込むときは**Import**(インポート)をクリックします。[キャラクターの作成と編集](../characters/creating-and-editing-characters.md)を参照してください。
4. チャットを始めます。チャットのサイドバーでモードのタブを選び、**+**ボタンをクリックします。このボタンの名前はタブに合わせて**New Conversation**、**New Roleplay**、**New Game**に変わります。新しいチャットが開くと設定ウィンドウが現れ、残りの手順を案内します。接続をまだ1つも保存していない場合は、先に**Set Up Conversation**、**Set Up Roleplay**、**Set Up Game**のいずれかのウィンドウが表示されます。ここで接続を選び、**Create Chat**をクリックします。

途中でわからなくなったら、内蔵アシスタントに聞いてみてください。できることは[Professor Mari: アプリ内アシスタント](professor-mari.md)で紹介しています。

## 3つのチャットモード

Marinaraには3つのチャットモードがあります。新しいチャットを始めるときに、どれか1つを選びます。

- **Conversation**: ロールプレイなしの、素直なAIチャットです。見た目はメッセージアプリに近い形です。[Conversationモード: はじめに](../conversation/getting-started.md)を参照してください。
- **Roleplay**: キャラクター、シーンの追跡、世界の状態を備えた、没入感のあるロールプレイです。[Roleplayモード: はじめに](../roleplay/getting-started.md)を参照してください。
- **Game**: AIのゲームマスター(GM)が進行する1人用のロールプレイングゲームです。パーティー、ダイス、マップ、クエストが登場します。[Game Mode: はじめに](../game/getting-started.md)を参照してください。

## 困ったときの相談先

アプリから離れずに助けを得る方法がいくつかあります。

- ホーム画面の**Professor Mari**に、設定の相談や操作の質問をする。
- ホーム画面の**FAQ**を読んで、よくある疑問をすぐに解決する。
- ホーム画面の**Documentation**のブックマークから、アプリ内のガイドを開く。
- **Discord**のブックマークをクリックしてコミュニティに参加する。プロジェクトを支援したいときは**Support**をクリックする。

うまく動かないところがあるときは、[Marinara Engineのトラブルシューティング](../TROUBLESHOOTING.md)を参照してください。
