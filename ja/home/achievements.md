# 実績

実績は、Marinara Engineを使ううちに解除される飾りのバッジです。たとえば、チャットを作ったり、コミュニティのリンクを開いたりすると解除されます。アプリの動作が変わることはありません。このガイドでは、実績の表示場所、すべての一覧、オフにする方法を説明します。

## Achievementsウィンドウを開く

1. ホーム画面に移動します。
2. **Achievements**(実績)のブックマーク(トロフィーのアイコン)をクリックします。スマートフォンでは、先にタブの左にあるブックマークのボタンをタップします。

**Achievements**ウィンドウが開きます。上部には、**12 of 24 achievements unlocked in this profile.**のような集計が表示されます。プロファイルとは、保存されたMarinaraのデータひとそろいのことです。その下に、カードが格子状に並びます。

- 未解除のカードには、**?????**と鍵のアイコンが表示されます。解除するまで内容は読めません。
- 解除したカードには、**unlocked**のタグが付きます。
- 目標値のあるカードには、**Progress**の行とバーも表示されます。

ホームに**Achievements**ウィジェットを追加することもできます。ブックマークの**Widgets**(ウィジェット)をクリックして、オンにしてください。ウィジェットには、**12 of 24 unlocked**のような解除数と、**Last obtained**(最後に獲得した実績)、**Closest next**(次に近い実績)が表示されます。読み込み中は**Checking the collection...**と表示されます。クリックするとウィンドウが開きます。[ホームのウィジェット](welcome.md#home-widgets)を参照してください。

うまくいかなかった場合: ブックマーク、ウィジェット、ウィンドウは、**Achievements**の設定がオンのときだけ表示されます。[実績のオンとオフを切り替える](#turn-achievements-on-or-off)を参照してください。

進み具合は、使用中のプロファイルに保存されます。別のプロファイルや新しくインストールした環境では、何も解除されていない状態から始まります。解除の記録は、フルバックアップに含まれます。

## 24種類の実績

実績は全部で24種類あり、**Milestone**、**Community**、**Creation**、**Collection**の4つのカテゴリーに分かれています。**Creation**と**Collection**の実績には**I**、**II**、**III**の3段階があり、5、25、100で解除されます。第2段階に届くと、バッジの名前が**Hoarder II**のように表示されます。

| 実績 | カテゴリー | 解除の条件 |
| --- | --- | --- |
| **Diligent Student** | Milestone | 初回チュートリアルを完了するか、スキップします。 |
| **Hello World** | Milestone | Professor Mariに最初のメッセージを送ります。 |
| **Please Handle With Care** | Milestone | Professor Mariの画像を画面上でドラッグします。 |
| **One Of Us** | Community | **Discord**のブックマークか、**Community**(コミュニティ)ウィジェットの**Discord**のリンクをクリックします。 |
| **Based Backer** | Community | ブックマークか**Community**ウィジェットの**Support**(Ko-fiが開きます)をクリックします。 |
| **Backseat Appreciator** | Community | ブックマークか**Community**ウィジェットの**Credits**をクリックします。 |
| **Who Needs IRL Friends** | Creation | Conversationのチャットを作ります(5、25、100)。 |
| **They Feel Real To Me** | Creation | Roleplayのチャットを作ります(5、25、100)。 |
| **I Have No Other Hobbies** | Creation | Gameのチャットを作ります(5、25、100)。 |
| **Hoarder** | Collection | キャラクターを集めます(5、25、100)。 |
| **The World's A Stage** | Collection | ロアブックを集めます(5、25、100)。 |
| **I Am A Gamer** | Collection | ペルソナを集めます(5、25、100)。 |

- ペルソナは、チャットの中で自分を表すキャラクターカードです。ロアブックは、キーワードが出てきたときにAIが読む、世界の設定の集まりです。
- **Collection**は、ライブラリーにあるその種類のものをすべて数えます。インポートしたものやダウンロードしたものも含みます。**Hoarder**では、組み込みのProfessor Mariのキャラクターは数に入りません。
- コミュニティの実績は、リンクを開くだけで解除されます。リンク先のサイトで登録する必要はありません。

## エージェントの実績

インストールしたエージェントは、独自の実績を追加できます。同じウィンドウの、組み込みの実績の後に、**From Noodle**(Noodleから)のような見出しの下に表示されます。ルールは組み込みの実績と同じで、エージェントは独自のバッジ画像を表示できます。

エージェントを削除すると、そのセクションは表示されなくなりますが、解除の記録は残ります。もう一度インストールすると、再び解除済みとして表示されます。上部の集計には、インストールしているエージェントの実績も含まれます。

<a id="turn-achievements-on-or-off"></a>

## 実績のオンとオフを切り替える

1. **Settings → General**(設定 → 一般)を開きます。
2. **App Behavior**(アプリの動作)セクションで、**Achievements**のトグルをオンまたはオフにします。デフォルトはオンです。

- オン: ブックマークとウィンドウが使えるようになり、何かが解除されるとポップアップが表示されます。
- オフ: ブックマーク、ウィジェット、ポップアップは表示されません。アプリは裏側で解除の記録を続けるので、オンに戻しても何も失われません。

## 解除の仕組み

Marinaraは、チャットの作成やブックマークのクリックなど対象の操作が行われたときと、ウィンドウを開いたときに、個数を確認します。

- 操作によってバッジが解除され、設定がオンになっている場合は、**Achievement unlocked**という見出しのポップアップに、**Hoarder II**のようにバッジの名前が表示されます。
- ウィンドウを開いたときに、ほかの経路ですでに獲得していたバッジが解除されることがあります。この解除は通知なしで行われます。カードが解除済みの表示になるだけで、ポップアップは出ません。
- 一度解除したバッジは、あとからチャット、キャラクター、ロアブック、ペルソナを削除しても、解除されたままです。
- 解除済みのカードでも、**Progress**のバーは現在の個数を表示します。そのため、バッジを獲得済みでも、カードに**2 / 5**のような表示が出ることがあります。これは正常です。

実績をリセットするボタンはありません。
