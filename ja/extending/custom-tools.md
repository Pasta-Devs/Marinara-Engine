# カスタムツールと関数呼び出し

カスタムツール(関数とも呼びます)を使うと、AIがチャットの途中で小さな処理を実行できます。処理の内容は、決まった文章を返す、Webアドレスを呼び出す、サーバー上で短いスクリプトを動かす、のいずれかです。AIに推測させるのではなく、何かを調べさせたり計算させたりしたいときに使います。

関数呼び出しとは、AIがアプリに処理の実行を頼み、その結果を返信に使う仕組みです。Marinaraには、ダイスロール、ロアブック検索、ゲーム状態の更新といった組み込みツールが最初から入っています。カスタムツールは、これらと並んで動きます。カスタムツールはキャラクターカードには紐づきません。チャットでオンにするか、エージェント(チャットと並行して動く補助役)に紐づけて使います。

> **Note:** ツールには、ツールに対応した接続が必要です。ClaudeとGrokのサブスクリプションの接続はツール定義を無視するため、**Chat Settings**(チャット設定)には案内が表示され、それらの接続ではツールの操作が無効になります。テキストコマンドとダイスタグは引き続き使えます。

## ツールを作る

始める前に、上部バーから**Presets**(プリセット)パネルを開いてください。ツールは、その**Functions**(関数)セクション(レンチのアイコン)にあります。別のデバイスからMarinaraを開いている場合は、先に**Settings → Advanced → Admin Access**(設定 → 詳細設定 → 管理者アクセス)で管理者用のシークレットを保存してください。この値はサーバーの`ADMIN_SECRET`と一致している必要があります。[サーバー設定リファレンス](../CONFIGURATION.md)を参照してください。

最初に試すなら、**Static Result**を選んでください。ほかには何も必要ありません。

### ツールの作成

1. **Presets**を開き、**Functions**を探します。
2. **Create function**(関数の作成、プラスのアイコン)をクリックします。空のツールエディターが開きます。
3. `check_weather`のように、小文字のsnake_caseで名前を入力します。これは、AIがツールを呼び出すときにそのまま使う名前です。名前は小文字で始まり、以降は小文字、数字、アンダースコアを使います。
4. **Description**(説明)を入力します。AIはこの文章を読んで、いつツールを呼ぶかを判断するため、AIへの指示として書いてください。例: `Get the current weather for a city the user names.`
5. ツールに必要なパラメーターを追加します([パラメーターの追加](#add-parameters)を参照)。
6. **Execution Type**(実行タイプ)を選びます。**Static Result**、**Webhook**、**Script**のいずれかです。
7. そのタイプの欄を入力します([実行タイプの選択](#choose-an-execution-type)を参照)。
8. **Save**(保存)をクリックします。ボタンの近くに緑色の**Saved**が一瞬表示されます。

名前と説明の決まりは次のとおりです。

- 名前は1文字から100文字までです。説明は1文字から500文字までです。
- 2つのツールが同じ名前を持つことはできません。また、`roll_dice`、`update_game_state`、`set_expression`、`trigger_event`、`search_lorebook`、`web_search`、`update_about_me`などの組み込みの名前も使えません。名前が重なると、`"your_name" is a reserved built-in tool name.`のようなメッセージが表示されます。
- 保存していない変更を残したままエディターを離れると、**Keep editing**、**Discard**、**Save & close**を選べるバナーが表示されます。

**Functions**の見出しには、3つのアイコンボタンがあります。

- **Create function**(プラスのアイコン)
- **Import functions from ZIP or JSON**(ZIPまたはJSONから関数をインポート)
- **Export functions to ZIP**(ZIPへ関数をエクスポート、ツールが1つもないときはグレー表示)

一覧の各ツールには、次のものが表示されます。

- 名前、種類、パラメーターの数、説明
- オン/オフのスイッチ
- **Edit function**(関数の編集)と**Delete Function**(関数の削除)

ハンドルをつかんでドラッグすると、一覧の並び順を変えられます。並び順は表示上のものだけです。ツールが1つもないときは、一覧に**No functions yet**と表示されます。

<a id="add-parameters"></a>

## パラメーターの追加

パラメーターは、AIがツールを呼び出すときに送る入力値です。パラメーターごとに、名前、型、必須かどうか、説明があります。

1. **Parameters**(パラメーター)グループで**Add Parameter**(パラメーターの追加)をクリックします。
2. `city`のように名前を入力します。
3. 型を`string`、`number`、`boolean`、`array`、`object`から選びます。
4. AIが必ずこの値を送る必要がある場合は、**Required**(必須)をオンにします。
5. `The city name to look up, such as Tokyo.`のように、その値が何を意味するのかをAIに伝える説明を書きます。

**Add Parameter**で行を増やすか、行のマイナスボタンで行を削除します。名前が空の行は、保存時に削除されます。

インポートしたツールをAIがまったく呼ばないように見える場合は、パラメーターが不正なのかもしれません。その場合、アプリは何も知らせずにそのツールを飛ばします。パラメーターを削除し、手作業で追加し直してください。

<a id="choose-an-execution-type"></a>

## 実行タイプの選択

### Static Result

**Static Result**ツールは、毎回同じ文章を返します。外部サービスは不要です。カードには**Returns a fixed string when called.**と表示されます。

欄は**Static Result**の1つだけで、複数行の入力欄です。空のままにすると、ツールは`OK`を返します。

例: パラメーターなしの`store_hours`という名前のツールで、**Static Result**に次の文章を入れます。

```text
We are open Monday to Friday, 9am to 5pm. We are closed on weekends.
```

AIは`store_hours`を呼び出すと、ツール名と送った引数とともにこの文章を受け取り、営業時間をユーザーに伝えられます。

### Webhook

**Webhook**ツールは、呼び出しをWebアドレスへ送り、そのサービスからの応答をAIに返します。Webhookとは、データを受け取ってデータを返すアドレスのことです。カードには**Sends a POST request to an external URL.**と表示されます。

欄は**Webhook URL**の1つだけです。アプリはPOSTリクエストを送ります。POSTリクエストとは、Webサービスにデータを送る方法の1つです。本文は、構造化データを表すプレーンテキスト形式のJSONで、次のような形になります。

```json
{ "tool": "your_tool_name", "arguments": { ... } }
```

**Include hidden chat context**(隠しチャットコンテキストを含める)をオンにすると、本文には`context`の値も入ります。サービスはJSONまたはプレーンテキストで応答し、その応答がAIに返ります。

例: `city`という必須のstring型パラメーターを1つ持つ`check_weather`という名前のツールで、**Webhook URL**に次のアドレスを設定します。

```text
https://api.example.com/weather
```

AIが`city`にTokyoを入れて呼び出すと、サービスが天気を調べて応答し、AIはその応答をメッセージに使います。

制限は次のとおりです。

- 応答のサイズは最大512 KBです。
- 1回の呼び出しには制限時間があります。デフォルトは60秒です(`CUSTOM_TOOL_TIMEOUT_MS`)。
- デフォルトでは`https://`のアドレスだけが許可されます。`localhost`や自宅ネットワークのアドレスなど、プライベートアドレスとローカルアドレスは、サーバー管理者が許可するまで遮断されます。[サーバー設定リファレンス](../CONFIGURATION.md)を参照してください。
- 呼び出しが失敗したりタイムアウトしたりした場合、AIにはエラーの結果が返り、チャットはそのまま続きます。

うまくいかなかった場合: アドレスが`https://`で始まり、接続できる状態か確認してください。ローカルアドレスは、管理者が許可しない限り遮断されたままです。応答の遅いサービスは、60秒の制限時間に達することがあります。

### Script

**Script**ツールは、サーバー上で短いJavaScriptを実行し、その結果を返します。JavaScriptは広く使われているプログラミング言語です。カードには**Runs a JavaScript expression server-side.**と表示されます。

スクリプトツールはデフォルトでオフです。サーバーでオンにしていない場合、**Script**のカードはグレー表示になり、琥珀色の**Script disabled**ラベルが表示されます。オンにするには、サーバー管理者がサーバーの`.env`ファイルに次の行を加え、Marinaraを再起動します。

```text
CUSTOM_TOOL_SCRIPT_ENABLED=true
```

欄は**Script Body**の1つだけです。スクリプトは`args`(AIが送った値)を読み取り、結果を必ず`return`します。`JSON`、`Math`、`Date`を使えます。

例: `x`と`y`という必須のnumber型パラメーターを2つ持つ`add_numbers`という名前のツールで、**Script Body**に次のように入力します。

```js
const result = args.x + args.y;
return { sum: result };
```

AIが`x`に2、`y`に3を入れて呼び出すと、ツールは合計の5を返します。スクリプトがエラーを投げた場合、AIにはエラーの結果が返ります。

スクリプトは、サーバー上で実際のコードを実行します。実行はサンドボックス(コードにできることを制限する隔離された領域)の中で行われます。

- ネットワークとファイルにはアクセスできません。
- 環境変数やサーバーの機密情報にはアクセスできません。
- 制限時間があります。デフォルトは60秒です。

サンドボックスは、オペレーティングシステムレベルの完全な隔離ではありません。ツールを作成できる人であれば、CPUやメモリーを浪費するスクリプトを書くことはできます。スクリプトツールをオンにするのは信頼できるサーバーだけにし、他の人が書いたスクリプトには注意してください。

うまくいかなかった場合: **Script**のカードがグレー表示になっているときは、管理者に`CUSTOM_TOOL_SCRIPT_ENABLED=true`を設定して再起動するよう依頼してください。

### 隠しチャットコンテキストを含める

**Webhook**ツールと**Script**ツールは、AIにはツールの入力値として見えない、追加のチャットデータを受け取れます。ツールエディターで**Include hidden chat context**(隠しチャットコンテキストを含める)をオンにしてください(デフォルトはオフです)。すると、ツールは`context`の値を受け取ります。そこには次のものが入ることがあります。

- チャットのモード
- 使用中のペルソナ名とキャラクターの名前
- 保存されたチャット変数
- Game Modeでは、ゲームの状態

これで、AIがすべてのデータを渡さなくても、ツール側で結果を状況に合わせられます。

## チャットでツールをオンにする

ツールを作っただけでは、AIはそれを使いません。チャットでもツールの使用をオンにします。

1. チャットを開き、**Chat Settings**(チャット設定)を開きます。
2. **Function Calling**(関数呼び出し)セクション(レンチのアイコン)を開きます。
3. **Enable Tool Use**(ツールの使用を有効にする)をオンにします。説明には**Allow AI to call functions (dice rolls, game state, etc.)**と表示されます。新しいチャットではデフォルトでオフです。
4. 動作を確認します。`store_hours`の例なら「営業時間は?」のように、ツールが答えられることをAIに尋ねます。返信にはツールの文章が使われるはずです。

**Enable Tool Use**がオンで、その下に何も追加していない場合、そのチャットは、対応している全体で有効なツールをすべて使えます。組み込みツールと、**Functions**でスイッチがオンになっている各カスタムツールです。Gameチャットで`search_lorebook`を使うには、**Let the GM search lore**(GMによるロア検索を許可)も必要です。

チャットで使うツールを限定するには、次の手順に従います。

1. **Add Functions**(関数の追加)をクリックします。検索欄の付いた選択画面が開きます。検索欄が照合するのはツール名だけです。
2. 使いたいツールにチェックを入れます。一覧には組み込みツールとカスタムツールが混在しています。
3. **Add Selected**(選択したものを追加)をクリックします。

ツールを1つでも追加すると、そのチャットでは追加したツールだけが動きます。選択画面の**New Custom Function**(新しいカスタム関数)をクリックすると、ツールエディターへ移動します。

Gameチャットでは、ツール計画用に別の接続を使えます。費用と動作については、[任意のツール計画とロア検索](../game/getting-started.md#optional-tool-planning-and-lore-searches)を参照してください。

うまくいかなかった場合: **Enable Tool Use**がオンになっていること、特定のツールを追加した場合はそのツールがチャットの一覧に入っていること、**Functions**でそのツールのスイッチがオンになっていることを確認してください。**Description**とパラメーターの説明をより明確に書くと、AIがいつツールを呼ぶかを判断しやすくなります。

## エージェントにツールを紐づける

ツールはチャットではなく、エージェントに持たせることもできます。

1. **Agents**(エージェント)パネルを開き、エージェントを1つ開きます。
2. その**Tools / Function Calling**グループを開きます。
3. そのエージェントが使ってよいツールをオンにします。

この場合も、チャットの**Function Calling**(関数呼び出し)セクションで**Enable Tool Use**(ツールの使用を有効にする)をオンにする必要があります。エージェントエディターの下部にも、そのことが書かれています。エージェント全般については、[カスタムエージェントの作成](../agents/custom-agents.md)を参照してください。

## ツールのエクスポートとインポート

- ツールを1つだけエクスポートするには、そのツールを開いて**Export function**(関数のエクスポート)をクリックします。`.json`ファイルとして保存されます。
- すべてのツールをエクスポートするには、**Export functions to ZIP**(ZIPへ関数をエクスポート)をクリックします。
- インポートするには、**Import functions from ZIP or JSON**(ZIPまたはJSONから関数をインポート)をクリックし、`.json`または`.zip`のファイルを選びます。インポートしたツールの数がメッセージで表示されます。

インポートしたWebhookツールとScriptツールは、ファイル側でどちらかを求めていても、常にオフの状態で、**Include hidden chat context**(隠しチャットコンテキストを含める)もオフにして保存されます。そのうえでMarinaraは、種類、Webhookのアドレス、ファイルが求めた権限を表示します。インポートしたツールを1つずつ開いて内容を確認し、信頼できる場合にだけオンにしてください。Staticツールは、インポート元のオン/オフの状態を引き継ぎます。

既存のツールや組み込みツールと名前が重なるツールは、インポート時に飛ばされます。エージェントのパッケージにカスタムツールは含まれません。カスタムツールは別途エクスポートして確認し、エージェントをインポートした後で紐づけてください。
