# クリーチャーパックの作成

**クリーチャーパック**は、Game Modeで戦う相手となるクリーチャーのアートです。パックを選ぶと、パックにアートがある敵は、戦闘の盤面で丸いトークンの代わりにそのアートで描かれます。アートは敵が最後に移動した方向を向き、そのクリーチャー本来のサイズで描かれます。パックにアートがない敵はトークンのままです。実際のプレイでの見え方は[戦術戦闘と地形](../game/combat.md#tactical-battles-and-terrain)を参照してください。

パックは1つのJSONファイル(`.creatures.json`)です。いちばん簡単な作り方は、Pixelforgeの**Creatures**(クリーチャー)タブを使う方法です。このタブは、クリーチャーごとに1枚の画像からファイルを組み立てます。このページでは、別の方法でパックを作る方に向けて、ファイルそのものを説明します。

## ファイル

```json
{
  "creaturePackVersion": 1,
  "id": "my-monsters",
  "name": "My monsters",
  "version": 1,
  "author": "Robin",
  "tileSize": 48,
  "sheets": [{ "id": "s1", "png": "data:image/png;base64,iVBORw0KGgo...", "width": 2048, "height": 1536 }],
  "creatures": [
    {
      "id": "goblin",
      "match": ["5e-2014/creatures/goblin", "Goblin"],
      "size": "small",
      "w": 1,
      "h": 2,
      "frames": 1,
      "variants": [
        { "sheet": "s1", "x": 0, "y": 0 },
        { "sheet": "s1", "x": 1, "y": 0 }
      ]
    }
  ]
}
```

| フィールド | 内容 |
| --- | --- |
| `creaturePackVersion` | 常に`1`です。 |
| `id` | 小文字の英字、数字、`_`、`-`で構成します。インポートしたパックは、ライブラリーに`local/<id>`として登録されます。 |
| `name`, `author` | ライブラリーに表示されます。`author`は任意です。 |
| `version` | 整数です。一度使ったバージョンが書き換えられることはありません。パックを変更するときは、バージョンを上げてください。同じファイルをもう一度インポートしても何も変わりません。 |
| `tileSize` | 1セルの大きさ(ピクセル)で、16から96までの16の倍数です。Game Modeのグリッドは48です。 |
| `sheets` | 最大64枚の画像で、それぞれ1辺8192ピクセルまでです。 |
| `creatures` | 最大2000体のクリーチャーです。 |

## シート

シートの`png`は、PNGの**データURL**でなければなりません。`data:image/png;base64,`の後にbase64が続き、それ以外は何も含みません。別の場所にある画像へのリンクは拒否され、base64の後に何かが続くものも拒否されます。これにより、パックが表示できるのは常にそのパック自身の画像だけになります。`width`と`height`はPNGの実際のサイズと一致する必要があります。Engineは画像のヘッダーからサイズを読み取り、シートの記載と異なるパックを拒否します。

## クリーチャー

| フィールド | 内容 |
| --- | --- |
| `id` | パック内でのクリーチャーのIDです。一意である必要があります。 |
| `match` | アートの対象で、1から16個の項目です。各項目はルールセットのクリーチャーか名前で、両方の種類を並べて書くこともできます。 |
| `size` | `tiny`、`small`、`medium`、`large`、`huge`、`gargantuan`のいずれかです。見た目だけの設定で、どのユニットも1マスを占めることに変わりはありません。 |
| `w`, `h` | 1フレームのサイズをセル数で表したもので、それぞれ1から6です。 |
| `frames` | 静止したクリーチャーは`1`、歩くクリーチャーは`3`(踏み出し、直立、踏み出し)です。 |
| `variants` | クリーチャーの**見た目**で、1から8個です。それぞれ、シート上でブロックが始まる位置を`sheet`と左上のセル`x`、`y`で指定します。 |

### `match`で指定するもの

- **ルールセットのクリーチャー:** `<catalog>/<entry>`(例: `creatures/goblin`)は、どのルールセットでもその図鑑の項目に一致します。`<ruleset>/<catalog>/<entry>`(例: `5e-2014/creatures/goblin`)は、そのルールセットの中でだけ一致します。
- **名前:** 敵の名前で一致します。大文字と小文字、句読点は区別せず、末尾の数字も無視するので、「Goblin 2」もゴブリンとして扱われます。

ルールセットの図鑑から出てきた戦闘参加者は、まず図鑑の項目で、次に名前で照合されます。2体のクリーチャーが同じ対象に一致する場合は、パック内で先に書かれたほうが優先されます。Engineはパックのインポート時にこのことを通知します。

### サイズ

フレームはセル単位で数えます。クリーチャーはマスの下端に立ち、左右の中央に描かれるので、大きなクリーチャーは周りのマスにまたがって立ちます。48ピクセルのグリッドでは、次のサイズが自然に見えます。

| クリーチャー | フレーム(`w`×`h`) |
| --- | --- |
| 超小型、または小型か中型の四足のクリーチャー | 1×1 |
| 小型か中型で、直立するもの | 1×2 |
| 大型 | 2×2。直立するもの(オーガ、ゴーレムなど)は2×3 |
| 超大型 | 3×3。直立するもの(巨人など)は3×4 |
| 巨大 | 4×4 |

### ブロック: 行とフレーム

各見た目は、シート上の1つの**ブロック**です。ブロックは横に`frames`個のフレーム、縦に4行で構成され、各フレームは`w`×`h`セルです。各行は向きを表し、次の順に並びます。

1. 下(見る人の方向)
2. 左
3. 右
4. 上(背後から見た姿)

静止したクリーチャー(`frames: 1`)は、4つの向きを1列に並べたものです。歩くクリーチャー(`frames: 3`)は、RPG Maker(RPGツクール)の歩行キャラクターと同じく、各行に踏み出し、直立、踏み出しを並べます。どのブロックもシートの内側に完全に収まっている必要があります。Engineは端からはみ出すブロックを名指しで示します。

### 見た目

複数の見た目(服、色、武器の違いなど)を持つクリーチャーは、戦闘参加者それぞれにそのうち1つを割り当てます。戦闘参加者は描かれるたびに同じ見た目を保ち、同じ戦闘にいる2体のゴブリンが違う見た目になることもあります。1体のクリーチャーの見た目はすべて同じサイズです。

Pixelforgeの**Creatures**(クリーチャー)タブでは、クリーチャーの横にある**Add looks**(見た目を追加)で、最初の見た目と同じサイズの画像を追加できます。合計8つまでです。

## パックを使う

Pixelforgeの**Creatures**(クリーチャー)タブで**Import a creature pack file**(クリーチャーパックのファイルをインポート)を選びます。そのタブで作ったパックなら、**Save to the library**(ライブラリーに保存)を選びます。続いて**Use for fights**(戦闘に使う)を選びます。すべての戦闘は1つのパックで描かれます。選んだパックを削除するか、**Use tokens instead**(代わりにトークンを使う)を選ぶと、トークンに戻ります。
