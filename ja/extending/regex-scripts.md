# 正規表現スクリプト

このガイドでは、Marinara Engineの正規表現スクリプトについて説明します。正規表現スクリプトとは、チャットの文章を自動で書き換える検索と置換のルールです。ここでは、正規表現スクリプトができること、作り方、動作する場所、そして特定のキャラクターだけに限定する方法を取り上げます。

## 正規表現スクリプトとは

regexは「regular expression」(正規表現)の略です。正規表現は検索のパターンで、ルールに一致する文章を見つけ出します。正規表現スクリプトは、見つかった部分を別の文字列に置き換えます。使うのにプログラミングの知識は要りません。

正規表現スクリプトは、チャットをメッセージが通るたびに自動で動きます。AIの返信を目に触れる前に整えられますし、自分のメッセージを送信前に書き換えることもできます。モデルが受け取る文章そのものを変えることもできます。パターンは一度設定すれば、条件に合うすべてのメッセージで働き続けます。

書き換えの前後を簡単な例で見てみます。モデルによっては、次のように動作をアスタリスクで囲みます:

```
*She smiles* Hello there.
```

パターン`\*([^*]+)\*`を検索して`$1`に置き換えると、アスタリスクが消えて中の文章だけが残ります:

```
She smiles Hello there.
```

置換文字列の`$1`は「パターンの1つ目の丸括弧が捉えた文字列」という意味です。`$1`や`$2`のような書き方はよく使います。

よくある使い道は、アスタリスクの削除、丸括弧で書かれたキャラクター外の注記の削除、特定の語の伏せ字化、あるキャラクターだけが繰り返す書式の癖の修正などです。

## 正規表現スクリプトの場所

全体で使う正規表現スクリプトは**Presets**(プリセット)パネルにあります。上部バーの**Presets**ボタンから開き、**Regexes**という見出しのセクションを探します。セクションの説明には「Find/replace patterns applied to AI output or user input」と書かれています。

リストの各行には次の内容が並びます:

- スクリプトの名前。
- スクリプトが動く場所を示す小さな**AI**または**User**のタグ。
- `/pattern/flags`の形式で表示されるパターン。
- スクリプトをオンオフするトグル。エディターを開かなくても、その場ですぐ反映されます。
- **Edit regex**(正規表現の編集)ボタン(鉛筆アイコン)。
- **Delete regex**(正規表現の削除)ボタン(ゴミ箱アイコン)。

スクリプトが1つもないときは「No regexes yet」と表示されます。行のハンドルをドラッグすると実行順を入れ替えられます。このリストに並ぶのは全体で使うスクリプトだけです。特定のキャラクターに結び付いたスクリプトは別に管理します。後述の「キャラクター単位の正規表現スクリプト」を参照してください。

セクションの見出しには、3つのアイコンボタンもあります:

- **Create regex**(正規表現の作成): 新しい空のスクリプトを開きます。
- **Import regexes from JSON**(JSONから正規表現をインポート): ファイルからスクリプトを読み込みます。
- **Export regexes to JSON**(JSONへ正規表現をエクスポート): 全体で使うスクリプトをまとめて1つのファイルに保存します。

## 正規表現スクリプトの作成

全体で使うスクリプトを新しく作る手順は次のとおりです:

1. **Presets**パネルを開き、**Regexes**セクションを表示します。
2. **Create regex**をクリックします。正規表現スクリプトの編集画面が開きます。
3. 上部の欄に名前を入力します。新規スクリプトの名前は最初「New Regex Script」になっています。
4. 以下で説明する各項目を入力します。
5. **Save**(保存)をクリックします。緑色の**Saved**の表示が少しの間現れます。

編集画面には次の項目があります。

### Find Pattern (Regex)

**Find Pattern (Regex)**(検索パターン)は検索に使うパターンです。前後のスラッシュは付けずに書きます。欄のプレースホルダーには例として`\*([^*]+)\*`が表示されます。パターンが不正な場合や安全でないと判断された場合は、欄の下に赤いエラーが出て保存できなくなります。後述の「安全性とパフォーマンス」を参照してください。

### Replace With

**Replace With**(置換後の文字列)は、一致した箇所と入れ替わる文字列です。空のままにすると、一致した箇所を削除します。`$1`や`$2`などで、捉えた文字列を再利用できます。捉えた文字列の前に変換の記号を置くと、文字の大小を変えられます:

- `\u$1`は捉えた文字列の先頭を大文字にします。
- `\U$1\E`は捉えた文字列全体を大文字にします。
- `\l$1`は捉えた文字列の先頭を小文字にします。
- `\L$1\E`は捉えた文字列全体を小文字にします。

`C:\Users`のようなWindowsのパスなど、バックスラッシュをそのまま含む文字列は書いたとおりに残ります。

### Regex Flags

**Regex Flags**(正規表現のフラグ)は、パターンの一致のしかたを変えるトグルボタンです。新規スクリプトでは`g`と`i`がオンになっています:

- `g` (global): 最初の1件だけでなく、一致したすべての箇所を置き換えます。
- `i` (case-insensitive): 大文字と小文字を区別せずに一致させます。
- `m` (multiline): `^`と`$`が改行位置にも一致するようにします。
- `s` (dotAll): `.`が改行文字にも一致するようにします。
- `u` (unicode)、`y` (sticky)、`d` (match indices)は、特殊な用途向けの上級者向けフラグです。

### Trim Strings

**Trim Strings**(削除する文字列)は、置換のあとに取り除く単純な文字列を並べる、任意の項目です。**Add trim string**をクリックすると行が増え、**X**ボタンで削除できます。パターンで書くより直接入力したほうが早い、決まった文字列を消すのに便利です。

### Live Test

**Live Test**(動作テスト)を使うと、保存する前にパターンを試せます。サンプルの文章を欄に貼り付けると、下の**Result:**に結果が出ます。**Live Test**でわかるのは、検索、置換、そして**Trim Strings**による削除の結果だけです。適用先、オンオフの状態、キャラクターの範囲、深さは確認できません。欄の下の注記にもそのことが書かれています: 「Pattern preview only: placement, enabled state, character scope, and depth are evaluated at runtime」。

パターン、置換後の文字列、削除する文字列には`{{user}}`や`{{char}}`などのマクロを使えます。**Live Test**ではサンプルの値に置き換わり、実際のチャットでは本物の名前や文章に置き換わります。マクロについて詳しくは[マクロ](../prompts/macros.md)を参照してください。

## 適用先: AI OutputとUser Input

**Apply To**(適用先)の項目で、スクリプトがチャットのどちら側を対象にするかを決めます。少なくとも1つは選んだままにする必要があります。両方を選ぶこともできます。

- **AI Output**: AIの返信が表示される前にスクリプトが動きます。
- **User Input**: 自分のメッセージが送信される前にスクリプトが動きます。

モデルが書いた文章を整えたいときは**AI Output**、自分が書いた文章を直したり形を変えたりしたいときは**User Input**を選びます。

**Individual**（個別応答）のグループモードを使う**Roleplay**チャットで**Only Prompt**または**Both**を選ぶと、適用先はプロンプトを受け取るキャラクターを基準に決まります。ユーザーのメッセージと他のキャラクターのメッセージには**User Input**、応答するキャラクター自身の過去の返答には**AI Output**が適用されます。同じグループターン内ですでに生成された返答も対象です。キャラクターの制限は、書き換えたプロンプトを誰に渡すかを引き続き決めます。そのため、思考を隠すスクリプトの対象外にしたナレーターには元の思考が渡されます。保存済みのチャット本文を変えたくない場合は、**Only Prompt**を選んでください。

## 適用範囲: Only Display、Only Prompt、Both

**Apply Mode**(適用範囲)の選択欄は**Advanced Options**(詳細設定)の中にあります。ここでは書き換えがいつ効くかを決めます。適用先とは別の設定です。新規スクリプトでは**Only Display**が選ばれています。

- **Only Display**: チャット画面の見た目だけを変えます。保存されるメッセージと、次のターン以降にモデルが受け取る文章は変わりません。
- **Only Prompt**: モデルが受け取る文章だけを変えます。チャットの表示と保存されるメッセージは変わりません。アプリのプロンプトプレビューに出るのもこちらです。
- **Both**: 表示とプロンプトの両方を変えます。

### どの適用範囲を選べばよいか

選び方の目安は次のとおりです:

- 画面上での返信の見た目だけを整えたい場合は**Only Display**を選びます。見た目の調整にはこれがいちばん安全です。
- モデルが読む文章を変えたい場合、たとえばモデルがまねし続けるタグを取り除きたい場合は**Only Prompt**を選びます。
- 画面上でもモデルのコンテキストでも変更を効かせたい場合は**Both**を選びます。

自分のメッセージについて、1つ知っておきたいことがあります。**User Input**のスクリプトを**Only Display**または**Both**に設定した場合、書き換えはメッセージを送信する直前に行われます。つまり、見た目が変わるだけでなく、実際に保存されて送信されるメッセージそのものが変わります。自分が送信するメッセージには、表示だけを変えるモードはありません。

## 実行順と深さ

どちらの設定も**Advanced Options**の中にあります。

**Execution Order**(実行順)は数値です。小さい数値ほど先に実行されます。同じ文章に複数のスクリプトが一致しうるときに効いてきます。新規スクリプトの初期値は0で、保存時にアプリが空いている次の番号を割り当てるため、新しく作ったスクリプト同士がぶつかることはありません。**Regexes**のリストで行をドラッグして並べ替えることもできます。

**Depth Range**(深さの範囲)は、チャットのどこまでさかのぼってスクリプトを動かすかを、**Min**と**Max**の2つの数値欄で制限します。深さは新しいメッセージから逆向きに数えます。いちばん新しいメッセージが深さ0、その1つ前が深さ1、と続きます。両方の欄を空のままにすると、深さに関係なく動きます。最小値が最大値より大きい場合は保存できません。

## キャラクター単位の正規表現スクリプト

正規表現スクリプトは、どこでも動かすのではなく、特定のキャラクター1人または複数人に結び付けられます。範囲をキャラクターに限定する方法は2つあります。

1つ目は編集画面から設定する方法です。**Apply To**カードの**Specific Characters**(特定のキャラクター)トグルをオンにし、一覧から1人以上のキャラクターを選びます。トグルがオフのときは「Applies to all characters」と表示されます。オンにした場合は、キャラクターを1人以上選ぶ必要があります。

2つ目はキャラクターごとに設定する方法です。キャラクターを開いて**Advanced**タブに移動し、**Regex Scripts**というカードを探します。このカードに並ぶのは、そのキャラクターに結び付いたスクリプトだけで、カード専用の**Create regex**、インポート、エクスポートのボタンが付いています。範囲を限定したスクリプトを追加するには、先にキャラクターを保存しておく必要があります。未保存の場合は、カードにその旨が表示されます。

このカードから編集画面を開くと、Character Editorから離れることになります。キャラクターに未保存の変更があるときは、内容が失われないようにアプリが先に確認します。

### チャットごとのScoped Regex Scripts設定

キャラクター単位のスクリプトは、すべてのチャットで自動的に動くわけではありません。チャットごとの設定で制御します。対象のチャットの**Chat Settings**(チャット設定)パネルを開いてください。**Scoped Regex Scripts**(範囲を限定した正規表現スクリプト)というセクションは、そのチャットに参加するキャラクターの少なくとも1人が範囲を限定したスクリプトを持つときにだけ現れます。モードは3つあります:

- **Disabled**(デフォルト): キャラクター単位のスクリプトはオフになり、全体で使うスクリプトだけが動きます。
- **Exclusive**: 範囲を限定した各スクリプトは、結び付いているキャラクターのメッセージだけを書き換えます。
- **Chat**: 範囲を限定したすべてのスクリプトが、チャット内のすべてのメッセージを書き換えます。

モードのボタンの下には、範囲を限定したスクリプトを持つキャラクターが並び、そのチャットでスクリプトを1つずつオンオフできます。この設定が制御するのは表示側のスクリプトです。プロンプト側のスクリプトは、実際に返信を生成しているキャラクターに常に従います。

## SillyTavernからの正規表現スクリプトのインポート

Marinaraは、SillyTavernのキャラクターカードに同梱された正規表現スクリプトを読み込めます。カードをインポートすると、**Imported regex scripts**(インポートした正規表現スクリプト)というセクションが現れ、2つの選択肢を示します:

- **Character only**(デフォルト): スクリプトはそのキャラクターだけに限定されます。
- **Global**: スクリプトが**Presets**に追加され、すべてのチャットで動きます。

この選択は、キャラクターを1人ずつ取り込むウィンドウでも、**Import from SillyTavern Folder**による一括インポートでも表示されます。パターンが空のスクリプトや、安全性チェックに通らないパターンのスクリプトは、インポート時に読み飛ばされます。スクリプトだけをまとめた単純なJSONファイルは、**Regexes**セクションの**Import regexes from JSON**ボタンから読み込めます。インポート手順の全体は[SillyTavernからのインポート](../data/importing-from-sillytavern.md)を参照してください。

## 安全性とパフォーマンス

すべてのパターンは、保存や実行の前に検査されます。Marinaraは、処理が極端に遅くなってアプリが固まる可能性の高いパターンを拒否します。拒否されたパターンには、「Regex pattern is unsafe: avoid nested quantifiers, ambiguous quantified alternatives, and oversized patterns.」というメッセージが出ます。修正するまで保存できません。

具体的には、次のような形を避けてください:

- 1000文字を超えるパターン。
- `(a+)+`のように、繰り返しのグループを別の繰り返しのグループの中に入れたもの。
- `.*.*`や`\s*\w*`のように、範囲の広いワイルドカードを2つ続けたもの。範囲の広いワイルドカードとは、`.*`、`\s*`、`\w+`のように、いくらでも長い文字列に一致しうる書き方です。
- 1つのパターンの中に範囲の広いワイルドカードが3つ以上あるもの。間に別の文字が挟まっていても同じです。

`a+`や`(a+)`のような単純な繰り返しは問題ありません。`.*`を1つだけ使うように、範囲の広いワイルドカードが1つだけの場合も問題ありません。

安全なパターンであっても、長いメッセージ1件に対して1回の置換にかけられる時間には上限があります。あるスクリプトが1件のメッセージで時間を使いすぎた場合、アプリはそのメッセージについてだけそのスクリプトを飛ばし、処理を続けます。スクリプトがオフになるわけではなく、次のメッセージでは再び実行されます。念のため、新しいパターンはオンにする前に、必ず短いサンプル文章で**Live Test**を試してください。
