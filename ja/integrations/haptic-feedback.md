# Haptic Feedbackの設定

このガイドでは、Marinara EngineでAIキャラクターに接続済みのハプティックデバイスを操作させる方法を説明します。補助アプリのインストール、チャットへの**Haptic Feedback**エージェントの追加、デバイスへの接続、調整できるタッチ設定を扱います。

## ハプティックフィードバックとは

ハプティックフィードバックを使うと、チャットの最中にAIキャラクターが接続済みのハプティックデバイス(大人向けのおもちゃ)へタッチの合図を送れます。Marinara Engineがデバイスと直接やり取りすることはありません。代わりに**Intiface Central**という無料のコンパニオンアプリへコマンドを送り、そのアプリがデバイスを動かします。

**Intiface Central**は**Buttplug.io**というデバイス用のプロトコルを話します。これは多くのおもちゃや他のアプリが対応しているオープン標準です。**Intiface Central**を一度インストールしてデバイスをペアリングしておけば、Marinaraはローカルネットワークのアドレス経由でそこに接続します。

ハプティックフィードバックは、チャットに追加できるAIヘルパーである**Agents**(エージェント)の1つとして作られています。Conversation、Roleplay、Gameの各モードで動作します。

## 始める前に

ハプティックフィードバックをオンにする前に、次の3つを準備します。

1. 公式サイトから**Intiface Central**をインストールします。ブラウザーで次のアドレスを開きます。

```
https://intiface.com/central/
```

2. **Intiface Central**を開き、サーバーを起動します。アプリ内にあるサーバー起動ボタンを探してください。
3. **Intiface Central**の中でデバイスをペアリングまたは接続し、アプリからデバイスが見えるようにします。

**Intiface Central**が起動していない、またはサーバーが起動していない場合、Marinaraはタッチの合図を一切送れません。

## Haptic Feedbackエージェントを追加する

ハプティックフィードバックの追加手順は、他のエージェントと同じで、チャットの設定から行います。

1. Conversation、Roleplay、Gameのいずれかのチャットを開きます。
2. そのチャットの**Chat Settings**(チャット設定)を開きます。
3. **Agents**セクションへ移動します。
4. **Haptic Feedback**エージェントをチャットに追加します。
5. **Agents**の一覧に表示された**Haptic Feedback**のカードを探します。

カード上部の**Haptic Feedback**トグルをオンにします。オフのときは説明文が「Allow this agent to send touch cues during the chat.」、オンのときは「Touch cues are enabled for this chat.」になります。トグルはデフォルトでオフです。

トグルをオンにすると、AIは文章を書きながら見えないタッチの合図を送れるようになります。この合図はチャットにテキストとして表示されません。接続済みのすべてのデバイスへ送られます。

## 接続、検索、デバイスの確認

**Haptic Feedback**のカードを開くと、Marinaraは保存済みのアドレスを使って**Intiface Central**への接続を自動的に試みます。手動で接続することもできます。

カードには色付きの丸が付いた状態表示の行があります。緑は接続済み、赤は未接続を表します。その隣のボタンは、未接続のときは**Connect**(接続)、接続済みのときは**Disconnect**(切断)と表示されます。

手動で接続するには**Connect**をクリックします。成功すると、この行にサーバーアドレスとともに「Connected」と表示されます。

失敗すると、接続できなかったというメッセージが出ます。**Intiface Central**が起動しているか、サーバーが起動しているかを確かめるよう促す内容で、**Intiface Central**のWebサイトへのリンクも含まれます。

接続が済むと、カードに見つかったデバイスの台数が表示されます。1台も接続されていなければ「No devices found」、接続されていればその台数が出ます。もう一度探すには**Scan for devices**(デバイスを検索)をクリックします。検索中、ボタンの表示は「Scanning...」になります。カードには各デバイスの名前と、振動や回転など対応している動作が一覧で並びます。

MarinaraはHaptic Agentに、Intifaceでの正確な名前、機能から判定した玩具の種類、対応する動作も渡します。これにより、すべての玩具をバイブレーターと見なすことなく、正しい機器と動作を選べます。

## 対応する動作とパターン

Marinaraは、接続した機器についてIntifaceが報告するすべての出力形式を使います。振動、回転、往復運動、収縮、膨張、直線位置、温度、噴射、照明に対応します。直線位置はストローク、突き、ポンプ動作を行う機器を、膨張は空気圧でポンプ動作を行う機器を制御します。

エージェントは、停止以外の動作に**Steady**、**Tap**、**Pulse**、**Wave**、**Ramp**、**Impact**のパターンを適用できます。位置パターンは実際の移動先を交互に切り替えるため、ポンプやストロークのパターンは複数の動きを一度に送るのではなく、時間をかけて実行されます。

### Intiface URL欄

**Intiface URL**欄には、**Intiface Central**サーバーのネットワークアドレスを入れます。これはWebSocketのアドレスで、2つのアプリがやり取りするためのローカルなリンクにすぎません。デフォルト値は次のとおりです。

```
ws://127.0.0.1:12345
```

`127.0.0.1`というアドレスは「同じコンピューター」という意味です。欄を空のままにすると、Marinaraはサーバー側のデフォルト値を使います。またMarinaraはアドレスをブラウザーに記憶するので、チャットやデバイスをまたいで再利用されます。

MarinaraをDockerで動かしている場合や、別のデバイスのブラウザーでMarinaraを開いている場合、`127.0.0.1`では**Intiface Central**に届きません。そのときは**Intiface Central**を動かしているコンピューターのアドレスを入力します。次の例のような形で、数字の部分はそのコンピューターの実際のアドレスに置き換えます。

```
ws://192.168.1.50:12345
```

## タッチの強さ

すべてのチャットモードで、**Haptic Feedback**のカードに3つの選択肢を持つ**Touch sensitivity**(タッチの強さ)という設定が表示されます。強さの設定は、エージェントが弱い出力と強い出力のどちらを選びやすくするかを導くもので、厳密な上限ではありません。現在の動作に必要なら、どの選択肢でも機器の`0.0-1.0`の強度範囲全体を使えます。

3つの選択肢は、エージェントの反応スタイルを導きます。

| 選択肢 | 感触 | 備考 |
|---|---|---|
| **Subtle** | 弱めのフィードバックを優先 | 全範囲を利用可能 |
| **Standard** | ほとんどのシーンに合うバランス型 | デフォルト。全範囲を利用可能 |
| **Intense** | 強いフィードバックを選びやすい | 最大出力まで利用可能 |

デフォルトでは**Standard**が選ばれています。シーンに合う反応スタイルを選んでください。Marinaraは、すべてのコマンドをIntifaceの物理的な`0.0-1.0`の範囲に照らして検証します。

## 偶発的な接触

すべてのチャットモードで、強さの設定の下に**Incidental contact**(偶発的な接触)のトグルも表示されます。説明は「Tiny taps for accidental brushes and bumps.」です。このトグルはデフォルトでオフです。

オフのとき、AIは物語の中の小さな不意の接触を無視し、意図的な接触や強い接触にだけ合図を送ります。かすめた程度やぶつかった程度の接触でも軽いタップがほしい場合はオンにします。

## 別のデバイスから使う

デフォルトでは、Marinaraはサーバーを動かしているコンピューターと同じコンピューターからのハプティックコマンドしか受け付けません。デバイスの操作をローカルに閉じ、プライバシーを守るためです。

そのため、スマートフォンや別のデバイスからMarinaraを開いた場合、ハプティックフィードバックは動作しません。これは、そのデバイスが別の場所で動いているMarinaraサーバーに接続する構成に当てはまります。サーバーの設定を変更しないかぎり、接続、検索、コマンド送信のいずれも拒否されます。

別のデバイスからハプティック操作を許可するには、`HAPTICS_ALLOW_REMOTE`というサーバー設定をオンにします。あわせて、Basic Authや管理者シークレットなどのアクセス保護も設定する必要があります。設定項目については[サーバー設定リファレンス](../CONFIGURATION.md)を参照してください。アクセス保護については[リモートアクセス](../REMOTE_ACCESS.md)のガイドを参照してください。管理者アクセスの入力は、**Settings**(設定)の**Advanced**内にある**Admin Access**セクションで行います。

## うまく動かないときは

AIがデバイスをまったく動かせない場合は、次の順に確認します。

1. **Intiface Central**が開いていて、サーバーが起動しているか確かめます。
2. デバイスがペアリングされていて、**Scan for devices**をクリックした後にデバイス一覧へ出るか確かめます。
3. 状態表示の丸が緑になっていて、**Haptic Feedback**のトグルがオンか確かめます。
4. スマートフォンやリモートのデバイスを使っている場合は、上のリモートアクセスの注意事項を読み直します。

**Intiface Central**が未接続のとき、またはデバイスが1台も接続されていないときは、MarinaraはAIのタッチの合図を黙って読み飛ばします。チャットにエラーは表示されません。
