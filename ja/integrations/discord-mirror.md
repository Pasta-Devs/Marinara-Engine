# Discordメッセージミラー

このガイドでは、Marinara EngineのDiscordメッセージミラーを説明します。ミラーは、チャットしている間、メッセージをDiscordのチャンネルへ一方向にコピーします。Conversation、Roleplay、Gameのどのモードでも動作します。

## ミラーの役割

Discordメッセージミラーは一方向の中継です。MarinaraからDiscordのチャンネルへメッセージを送るだけで、Discord側からMarinaraへメッセージを送り返すことはできません。双方向のDiscordボットではありません。

ミラーはDiscordのwebhookを使います。webhookとは、あるアプリがDiscordのチャンネルにメッセージを投稿できるようにする専用のURLです。

ミラーの設定はチャットごとです。チャットはそれぞれ独自のwebhook URLを持ちます。あるチャットでURLを貼り付けると、そのチャットだけでミラーがオンになります。ほかのチャットは、それぞれにURLを貼り付けるまでオフのままです。

## DiscordのwebhookのURLを作る

webhookはMarinaraではなくDiscord側で作成します。使いたいDiscordのチャンネルを管理する権限が必要です。

1. Discordのサーバーを開き、メッセージを表示したいチャンネルを選びます。
2. そのチャンネルの設定を開き、**Integrations**(連携)、**Webhooks**の順に進みます。
3. 新しいwebhookを作成し、そのwebhook URLをコピーします。

DiscordのwebhookのURLは次のような形です。

```
https://discord.com/api/webhooks/123456789012345678/AbCdEf-example-token
```

このURLは他人に見せないでください。URLを知っている人は誰でも、そのDiscordのチャンネルにメッセージを投稿できます。

## ミラーをオンにする

webhookの設定は、チャットごとの設定の中にあります。場所は**Connected Chats**(接続チャット)のセクションです。この入力欄のラベルは**Discord Mirror**で、プレースホルダーの文字列は`https://discord.com/api/webhooks/...`です。

1. ミラーしたいチャットを開きます。
2. **Chat Settings**(チャット設定)を開きます。
3. **Connected Chats**のセクションを探します。
4. そのセクションの下のほうにある入力欄に、webhook URLを貼り付けます。

これでそのチャットのミラーがオンになります。オフにするときは、入力欄を空にします。

URLがDiscordのwebhookとして正しくない場合は、欄の下に「Invalid webhook URL format」という赤い文字が表示されます。URLを直せば、ミラーの設定は保存できます。保存するとき、Marinaraはサーバー側でもURLをもう一度チェックします。

webhookのURLは、このMarinaraのインストールの中にとどまります。チャットのエクスポート、エクスポートした設定プロファイル、**Export Profile**のファイルにはURLが含まれず、それらをインポートしてもミラーがオンになることはありません。別のインストールに移したチャットをミラーするには、移した先でURLを貼り付け直してください。このインストールで保存した設定プロファイルは、適用すれば引き続きミラーを設定します。

## 送られるもの

Marinaraは、生成されたそばからメッセージとAIの返信をミラーします。

- 送信者の名前: 自分のメッセージには、使用中のペルソナの名前が付きます。AIのメッセージにはキャラクターの名前が付きます。
- Game Modeでは、物語の地の文は「Narrator」という名前で送られます。パーティーメンバーやNPC(プレイヤー以外のキャラクター)のターンは「Party」という名前で送られます。**Character GM**(キャラクターがGMを担当)を使っている場合は、ゲームマスターの返信にそのキャラクターの名前が付きます。
- 画像は送られません。Discordには送信者の名前とテキストだけが表示されます。
- 長いメッセージ: Discordは1件あたり2000文字までに制限しています。1997文字を超えるメッセージは短縮され、ミラーされたコピーの末尾が「...」になります。
- 本文に@everyoneや@hereが含まれていても、Discordのチャンネルで誰かに通知が飛ぶことはありません。

## 送られないもの

- 再生成した返信とスワイプは、あらためてミラーされません。Discordへ送られるのは、そのターンの最初の返信だけです。
- Impersonateで書かれたメッセージはミラーされません。Impersonateは、自分の代わりにAIがメッセージを書く機能です。
- Discordへの送信に失敗しても、Marinaraはエラーを表示せず、再送もしません。失敗はサーバーのログに記録されるだけです。

## レート制限

Discordはアプリが投稿できる速度を制限しています。Marinaraが送るのは、1つのwebhookにつきおよそ1.2秒に1件までです。1分あたり約50件になります。あふれたメッセージはキューで待ち、順番に送られます。Discordから速度を落とすよう求められた場合、Marinaraはいったん待ってから送信を続けます。
