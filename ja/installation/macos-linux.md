# macOS / Linuxインストールガイド

このガイドでは、macOSまたはLinuxでMarinara Engineをインストールして動かす方法を説明します。必要なツールを2つインストールし、シェル用の起動スクリプトでアプリを起動し、後からアップデートする手順までを扱います。Marinara Engine(以降はMarinaraと呼びます)は、すべて自分のコンピューターの中で動作します。

## 事前に必要なもの

始める前に、無料のツールを2つインストールします。

- **Node.js**: Marinaraを動かすためのプログラムです。バージョン24、25、26のいずれかをインストールします(推奨はLTS版のバージョン24です)。
- **Git**: Marinaraをダウンロードし、アップデートを取得するためのツールです。

pnpmを自分でインストールする必要はありません。pnpmは、Marinaraが必要な部品を集めるために使うパッケージマネージャーです。適切なバージョンのpnpmは起動スクリプトが用意します。

### macOSでのインストール

いちばん簡単なのはHomebrewを使う方法です。次の1つのコマンドで両方のツールが入ります。

```bash
brew install node git
```

Homebrewを使わない場合は、https://nodejs.org からNode.jsのインストーラーをダウンロードします。そのあと、Xcodeのコマンドラインツールを使ってGitをインストールします。

```bash
xcode-select --install
```

### Linuxでのインストール

使っているディストリビューションのパッケージマネージャーを利用します。UbuntuやDebianでは、標準のNode.jsがバージョン24より古いことがよくあります。その場合は、先に新しいNodeSourceのリリースを追加します。

```bash
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo bash -
```

続いてNode.jsとGitをインストールします。

```bash
sudo apt install -y nodejs git
```

Fedoraの場合は、次のコマンドを実行します。

```bash
sudo dnf install -y nodejs git
```

Archの場合は、次のコマンドを実行します。

```bash
sudo pacman -S nodejs npm git
```

### ツールの動作確認

両方のツールが使える状態か確かめます。次のコマンドを実行します。

```bash
node -v
```

`v24`かそれ以上の番号が表示されれば大丈夫です。続いて次のコマンドを実行します。

```bash
git --version
```

`git version 2.40`かそれ以上のバージョンが表示されれば大丈夫です。どちらかのコマンドが「command not found」と表示する場合は、そのツールが正しくインストールできていません。

## 起動スクリプトで手早く始める

Marinaraを動かすには、起動スクリプト`start.sh`を使う方法をおすすめします。インストールとビルドをまとめて行い、ブラウザーでアプリを開くところまで済ませてくれます。

1. Marinaraをダウンロードします。次のコマンドを実行します。

```bash
git clone https://github.com/Pasta-Devs/Marinara-Engine.git
```

2. できたフォルダーに移動します。次のコマンドを実行します。

```bash
cd Marinara-Engine
```

3. 起動スクリプトを実行できるようにします。次のコマンドを実行します。

```bash
chmod +x start.sh
```

4. Marinaraを起動します。次のコマンドを実行します。

```bash
./start.sh
```

初回はすべてをダウンロードしてビルドするため、数分かかります。完了するとブラウザーでMarinaraが http://127.0.0.1:7860 に開きます。7860はデフォルトのポート番号で、アプリがコンピューター上で使う出入口にあたります。

ブラウザーが自動で開かないときは、自分でブラウザーを開いて同じアドレスにアクセスします。

### 起動スクリプトが毎回行うこと

Gitでダウンロードした状態で`./start.sh`を実行すると、起動スクリプトは毎回次の処理を行います。

1. 新しいバージョンがないか確認し、見つかれば自身をアップデートします。
2. Node.jsと適切なバージョンのpnpmが使える状態か確認します。
3. 足りない部品をインストールします。
4. コードが変わっていればアプリをビルドし直します。
5. データを保存するローカルストレージを準備します。
6. サーバーを起動し、ブラウザーでアプリを開きます。

### ブラウザーの自動起動をオフにする

デフォルトでは、起動スクリプトがブラウザーを開きます。これをやめるには、Marinaraのフォルダーに`.env`という名前のファイルを作り、次の行を書き加えます。

```bash
AUTO_OPEN_BROWSER=false
```

`.env`は設定を1行に1つずつ書いておくテキストファイルです。最小限の`.env`は次のような内容になります。

```bash
PORT=7860
AUTO_OPEN_BROWSER=true
```

`PORT`はアドレスのポート番号を指定します(デフォルトは7860です)。また起動スクリプトは、デフォルトでLAN内のほかのデバイスからもサーバーに届く状態にします。LANとは、家庭や職場の中で使うローカルエリアネットワークのことです。ただしMarinaraは、パスワードなどのアクセス方法を設定するまで、それらのデバイスからの接続をブロックします。設定方法は[リモートアクセス: ログインとIP許可リスト](../REMOTE_ACCESS.md)のガイドで説明しています。

## 手動セットアップ

ほとんどの場合は、上の起動スクリプトを使えば十分です。1つずつ自分で実行したい場合は、代わりに次のコマンドを順に実行します。手動セットアップではpnpmが使える状態にしておく必要があります。Node.js 24にはCorepackが同梱されていますが、Node.js 25には含まれていません。

1. Node.js 24では、Corepack経由でpnpmを有効にします。

```bash
corepack enable pnpm
```

Node.js 25または26では、先にユーザー提供版のCorepackパッケージをインストールしてから、pnpmを有効にします。

```bash
npm install --global corepack
corepack enable pnpm
```

2. Marinaraをダウンロードします。次のコマンドを実行します。

```bash
git clone https://github.com/Pasta-Devs/Marinara-Engine.git
```

3. フォルダーに移動します。次のコマンドを実行します。

```bash
cd Marinara-Engine
```

4. 部品をインストールします。次のコマンドを実行します。

```bash
pnpm install --force
```

5. アプリをビルドします。次のコマンドを実行します。

```bash
pnpm build
```

6. サーバーを起動します。次のコマンドを実行します。

```bash
pnpm start
```

あとはブラウザーで http://127.0.0.1:7860 を開きます。`pnpm start`で起動した場合、サーバーはデフォルトで自分のコンピューターからの接続だけを受け付けます。処理はすべてローカルで行われ、データの保存先は初回起動時に準備されます。

### Linuxでインストールに失敗する場合

Linuxの環境によっては、インストール中に非常に長いファイルパスが拒否されることがあります。`ERR_PNPM_ENAMETOOLONG`を含むエラーが出たときは、途中まで作られたフォルダーを削除し、起動スクリプトからやり直します。次のコマンドを実行します。

```bash
rm -rf node_modules .pnpm .pnpm-store
```

続いて次のコマンドを実行します。

```bash
./start.sh
```

## 任意: 背景除去ツール

Marinaraには、キャラクターのスプライト画像から背景を取り除く機能があります。スプライトとは、RoleplayやGame Modeで画面に立つキャラクターの立ち絵です。透過画像の扱いと内蔵の自動マット処理は、このダウンロードなしでも動作します。追加のAI背景除去ツールが必要なのは、描き込まれた風景や影など、単色でない背景の前で作られたスプライトにも対応したい場合だけです。ダウンロードするファイルはかなり大きくなります。

この追加ツールはPythonのプログラムです。インストールするとPythonのvenv(仮想環境。Pythonのパッケージを入れておく専用のフォルダー)が作られます。あわせて機械学習ライブラリーのPyTorchと、画像の中から被写体を見つけるためのU2Netモデルのファイルもダウンロードします。

インストールは1回だけで済みます。Marinaraのフォルダーで次のコマンドを実行します。

```bash
pnpm backgroundremover:install
```

macOSでは、Pythonのバージョン3.11がもっとも安定して動きます。先にHomebrewでインストールします。

```bash
brew install python@3.11
```

そのうえで、インストールのコマンドをもう一度実行します。

```bash
pnpm backgroundremover:install
```

次回の起動時に起動スクリプトへ自動でインストールさせたい場合は、`.env`ファイルに次の行を書き加えます。

```bash
BACKGROUNDREMOVER_AUTO_INSTALL=true
```

## アップデート

Gitでダウンロードした状態で`./start.sh`からMarinaraを起動すると、起動スクリプトが新しいバージョンを確認します。見つかれば、起動前に自動でアップデートします。チャット、キャラクター、設定はそのまま残ります。

1回だけ確認を省きたいときは`./start.sh --skip-update`を実行します。起動のたびにEngineのバージョンを固定したい場合は、`.env`に`AUTO_UPDATE_ENABLED=false`を追加します。その場合も、**Settings → Advanced → Updates**やGitのコマンドから手動で確認とアップデートができます。

アプリの中から確認することもできます。**Settings**(設定)を開き、**Advanced**(詳細設定)タブに移動して、**Updates**(アップデート)セクションを探します。**Check for Updates**(アップデートの確認)をクリックすると、新しいリリースがあるかどうかがわかります。**Apply Update**(アップデートの適用)ボタンはデフォルトでオフになっています。オンにするには、サーバー側の設定をいくつか行い、そのうえで**Settings**、**Advanced**、**Admin Access**(管理者アクセス)で管理者用のシークレットを保存します。オンにしない場合は、`./start.sh`で起動し直せばアップデートされます。

事前のバックアップの取り方やリリースチャンネルの切り替え方を含む詳しい手順は、下にリンクしたアップデートのガイドを参照してください。

## 主な用語

- **pnpm**: Marinaraが必要な部品をダウンロードして整理するために使うパッケージマネージャーです。
- **Corepack**: Node.jsに同梱されている補助ツールで、pnpmを有効にします。
- **LAN**: ローカルエリアネットワーク。家庭や職場の中で使うプライベートなネットワークです。
- **.env**: Marinaraのフォルダーに置く設定用のテキストファイルです。1行に1つの設定を書きます。
- **venv**: Pythonの仮想環境。Pythonのパッケージを入れておく専用のフォルダーです。
- **PyTorch**: 任意の背景除去ツールが使う機械学習ライブラリーです。
- **U2Net**: 背景除去ツールが画像の中から被写体を見つけるために使うモデルのファイルです。
