# チャットの背景

背景ライブラリーには、自分でアップロードし、手動で選んでチャットの後ろに表示する画像が入っています。毎ターン自動で背景を選ぶ**Background**エージェントについては、[Roleplayの背景](../roleplay/backgrounds.md)を参照してください。ギャラリーから作るAI生成の背景については、[シーン背景とギャラリー](../media/scene-backgrounds.md)を参照してください。

チャットの背景は、すべてのチャットモードで表示されます。Conversationのチャットでは、**Conversation Theme**(Conversationのテーマ)のグラデーションが画像の上に重なったままになり、**Conversation background image opacity**(Conversationの背景画像の不透明度)で画像をどのくらい強く表示するかを決めます。[外観の設定](appearance-settings.md)を参照してください。

## チャットの背景を変える

始める前に: 変更したいチャットを開いてください。選んだ背景はそのチャットに適用されます。

1. **Settings**(設定)を開き、**Appearance**(外観)、**App**(アプリ)ボタンの順に進みます。
2. **Backgrounds**(背景)で**Browse library**(ライブラリーを見る)をタップします。
3. 画像をタップします。その画像がこのチャットの背景になり、ウィンドウが閉じます。

自分の画像を使うには、先にインポートしてください([背景のインポート](#import-a-background)を参照)。

## 背景の場所

1. **Settings**(設定)を開きます。
2. **Appearance**(外観)タブを選び、**App**(アプリ)ボタンを選びます。
3. **Backgrounds**(背景)セクションを探します。

このセクションには、**Chat Background**(チャットの背景)ピッカー、**Background Blur**(背景のぼかし)スライダー、**Conversation background image opacity**と**Chat List Backgrounds**(チャット一覧の背景)の設定があります([外観の設定](appearance-settings.md)を参照)。

ピッカーには現在の背景のプレビューが表示されます。何も選んでいないときは**Default background**と表示されます。その下には**Recent**(最近)の背景が最大3つ並び、1回タップするだけで選べます。**Browse library**(ライブラリーを見る)をクリックすると、**Background Library**(背景ライブラリー)ウィンドウが開きます。

## 背景ライブラリー

ライブラリーには、自分でアップロードした画像と、Marinaraに同梱されている画像が混在します。画像にはそれぞれラベルが付きます。

| ラベル | 意味 |
| --- | --- |
| **My upload** | 自分でアップロードした画像です。名前の変更、タグ付け、削除ができます。 |
| **Game asset** | 同梱の画像です。読み取り専用で、名前の変更、タグ付け、削除はできません。 |

**Filter by source**(提供元で絞り込む)には**All sources**、**My uploads**、**Game assets**のボタンがあり、それぞれに含まれる画像の数が表示されます。

<a id="import-a-background"></a>

### 背景のインポート

1. **Background Library**ウィンドウで、検索欄の隣にある**Import Backgrounds**(背景のインポート)を探します。
2. タップまたはクリックして、画像ファイルを選びます。複数をまとめて選べます。コンピューターでは、ファイルをそこにドロップすることもできます。
3. 待ちます。処理中は**Importing…**と表示されます。

新しい画像は、**My upload**ラベル付きでグリッドに並びます。

ファイルはJPG、PNG、GIF、WebP、AVIFのいずれかで、1ファイルあたり20 MBまでです。Marinaraはファイル名ではなく、ファイルの中身を確認します。画像以外のファイルの名前を`.png`に変えても、拒否されます。

### 開いているチャットの背景を選ぶ

1. **Browse library**を開きます。
2. サムネイルをクリックします。チェックマークが付き、その画像がこのチャットの背景になって、ウィンドウが閉じます。
3. デフォルトに戻すには、選択中のサムネイルをもう一度クリックするか、プレビューのX(**Clear selection**(選択をクリア))をクリックします。

### 検索と絞り込み

- **Search backgrounds**(背景の検索)では、名前、タグ、提供元で絞り込みます。件数の行には、一致した数が「3 of 20 backgrounds」のように表示されます。入力を消すには、欄の中のXをクリックします。
- **Sort backgrounds**(背景の並べ替え)には、**Manual order**(手動の順番)、**A-Z**、**Z-A**、**Newest**、**Oldest**があります。**Manual order**では、ドラッグして並べ替えるか、フォーカスした画像で<kbd>Alt</kbd>+<kbd>Up</kbd>または<kbd>Alt</kbd>+<kbd>Down</kbd>を押します。
- フォルダーのチップ(**All folders**、**Favorites**、**Unfiled**と、フォルダーごとのチップ)で、フォルダー別に絞り込みます。
- タグの欄では、**All**でタグの絞り込みを解除します。**Tags**を展開して、タグを1つ以上選びます。選んだタグのいずれかを持つ画像が一致します。

画像の星をクリックすると、お気に入りに追加されます。デフォルトの背景は変わりません。

### 背景をフォルダーで整理する

フォルダーは、画像ファイルを移動したり隠したりせずにライブラリーを整理します。

1. **New Folder**(新しいフォルダー)をクリックし、名前を入力して**Add**(追加)をクリックします。
2. 画像の**Move to folder**(フォルダーへ移動)ボタンをタップし、フォルダーを選びます。または、画像をフォルダーのチップにドラッグします。スマートフォンやタブレットでは、画像を長押ししてからドラッグします。
3. 画像を戻すには、**Unfiled**(未分類)にドラッグします。
4. フォルダーのチップを選ぶと、鉛筆(**Rename folder**(フォルダー名の変更))とゴミ箱(**Delete folder**(フォルダーを削除))のボタンが表示されます。

フォルダーを削除すると、その中の画像は**Unfiled**に戻ります。画像そのものは削除されません。フォルダーはサーバーに保存され、バックアップにも含まれます。**Background**エージェントからは、フォルダーに入れたものも含めて、すべての背景が見えます。

### 背景の名前を変更する

名前を変更できるのは、**My upload**の画像だけです。

1. 画像の鉛筆(**Rename background**(背景の名前の変更))をクリックします。
2. 新しい名前を入力します。拡張子は入力しなくてかまいません。
3. **Save**(保存)をクリックします。

### 背景にタグを付ける

タグを付けられるのは、**My upload**の画像だけです。

1. 画像のタグアイコン(**Edit tags**(タグの編集))をクリックします。
2. **Add tag…**にタグを入力します。Marinaraが、以前に使ったタグを候補として表示します。
3. <kbd>Enter</kbd>を押すか、**Add**(追加)をクリックします。

タグを外すには、タグの編集中にそのタグをクリックします。

<a id="download-a-background"></a>

### 背景をダウンロードする

画像のダウンロードアイコン(**Download background**(背景をダウンロード))をクリックします。同梱の画像も含め、どの画像でもダウンロードできます。iPhoneやiPadでは共有シートが開きます。開かない場合は、表示されるメッセージで**Save file**(ファイルを保存)をタップしてください。

### 背景を削除する

削除できるのは、**My upload**の画像だけです。

1. 画像のゴミ箱アイコン(**Delete background**(背景の削除))をクリックします。
2. 確定します。

その画像が現在のチャットの背景かRoleplayのデフォルト背景だった場合は、Marinaraが同梱のデフォルトに戻します。

## Roleplayのデフォルト背景を設定する

Roleplayのデフォルト背景とは、新しいRoleplayチャットが最初に使う画像です。

1. **Background Library**(背景ライブラリー)ウィンドウで、画像を探します。
2. その画像のピンアイコン(**Set as default for new Roleplay chats**(新しいRoleplayチャットのデフォルトに設定))をクリックします。

サムネイルに**Default**ラベルが表示されます。元に戻すには、その画像のピンをもう一度クリックするか、グリッドの上にある**Reset Roleplay default**(Roleplayのデフォルトをリセット)をクリックします。このボタンは、デフォルトが同梱のものと違うときにだけ表示されます。

## Background Blur

**Background Blur**(背景のぼかし)は、チャットの後ろにある背景をぼかして、文字を読みやすくします。すべてのチャットモードの背景に適用されます。

1. **Backgrounds**セクションで、**Background Blur**スライダーを探します。
2. 0から24の範囲でドラッグします。数値が大きいほど、ぼかしが強くなります。

0のときは**Off**と表示され、背景はくっきりしたままです。デフォルトは0です。

## 背景の選択内容の保存先

| 設定 | 保存先 |
| --- | --- |
| チャットごとの**Chat Background** | サーバーに、そのチャットと一緒に保存されます。どのデバイスでもチャットに付いてきます。 |
| フォルダーと振り分け | サーバーに、ライブラリーと一緒に保存されます。 |
| Roleplayのデフォルト背景と**Background Blur** | デバイスごとに保存されます。ブラウザーやデバイスの間で同期しません。 |

同期の仕組み全体については、[外観の設定](appearance-settings.md)を参照してください。
