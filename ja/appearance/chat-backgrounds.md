# チャットの背景

このガイドでは、Marinara Engineの背景ライブラリーを説明します。ここで扱うのは、自分でアップロードし、手動で選んでチャットの後ろに表示する画像です。毎ターン自動でシーンの背景を選ぶ**Background**エージェントについては、[Roleplayの背景](../roleplay/backgrounds.md)を参照してください。ギャラリーから作るAI生成のシーン背景については、[シーン背景とギャラリー](../media/scene-backgrounds.md)を参照してください。

## 背景の場所

背景の管理場所は1か所です。**Settings**(設定)を開き、**Appearance**(外観)タブの**Backgrounds**(背景)セクションに進みます。

**Backgrounds**セクションは3つの部分に分かれています。

1. **Chat Background**(チャットの背景)ピッカー。開いているチャットに使う画像を選びます。
2. **Background Blur**(背景のぼかし)スライダー。
3. 背景ライブラリー。画像のインポート、整理、絞り込み、タグ付け、名前の変更、ダウンロード、削除を行います。

チャットの背景が表示されるのは、RoleplayとGame Modeのチャットだけです。Conversationモードでは代わりにグラデーションを使い、**Conversation Theme**(Conversationのテーマ)セクションで設定します。詳しくは[外観の設定](appearance-settings.md)を参照してください。

## 背景ライブラリー

ライブラリーには、選択できる画像がすべて入っています。自分でアップロードした画像と、Marinaraに同梱されている画像が混在します。見分けられるように、画像ごとに小さなラベルが付きます。

- **Library**: 自分でアップロードした画像です。名前の変更、タグ付け、削除ができます。
- **Game asset**: Marinaraに同梱されている画像です。読み取り専用なので、名前の変更、タグ付け、削除はできません。

### 背景のインポート

1. ライブラリーの上部にある**Import Backgrounds**(背景のインポート)ボックスを探します。
2. 画像ファイルを1つ以上ボックスにドラッグするか、ボックスをクリックしてファイルを選びます。
3. アップロードが終わるまで待ちます。処理中はボックスに**Importing...**と表示します。
4. インポートした画像が下のグリッドに**Library**ラベル付きで並びます。

複数のファイルをまとめてインポートできます。ファイルはJPG、PNG、GIF、WebP、AVIFのいずれかの形式の画像で、1ファイルあたり20 MBまでです。

Marinaraはファイル名だけでなく中身も確認します。画像以外のファイルの名前を`.png`で終わるように変えても、アップロードは拒否されます。

### 開いているチャットの背景を選ぶ

1. **Settings**を開き、**Appearance**、**Backgrounds**の順に進みます。
2. グリッドの中から、使いたいサムネイルをクリックします。
3. 選んだ画像にチェックマークが付きます。これが、開いているチャットの背景になります。
4. デフォルトに戻すには、選択中のサムネイルをもう一度クリックするか、**Chat Background**の隣にある**Remove**(削除)ボタンをクリックします。

### ライブラリーの検索

ライブラリーの上にある**Search backgrounds**(背景の検索)ボックスを使うと、名前、タグ、提供元で絞り込めます。件数の行には一致した画像の数を「3 of 20 backgrounds」のように表示します。検索ボックス内の小さなXをクリックすると、入力を消せます。

検索の隣のセレクターでは、背景を**A-Z**、**Z-A**、**Newest**、**Oldest**の順に並べ替えられます。タグの絞り込みを解除するには**All**を選び、タグで絞り込むには**Tags**を展開してタグを1つ以上選びます。複数のタグを選んだ場合は、いずれか1つでも一致する背景が表示されます。

### 背景をフォルダーで整理する

フォルダーは、元の画像ファイルを移動したり隠したりせずにライブラリーを整理します。

1. **New Folder**(新規フォルダー)をクリックします。Marinaraが重複しない名前のフォルダーを作成します。
2. フォルダー名をダブルクリックまたはダブルタップして名前を変更します。フォーカスを合わせてF2を押しても変更できます。
3. デスクトップでは、背景の行をフォルダーへドラッグします。スマートフォンやタブレットでは、行を長押ししてからドラッグします。
4. 背景を未分類の領域へドラッグして戻すと、フォルダーから外れます。

フォルダーと振り分けの情報はサーバーに保存し、バックアップにも含まれます。フォルダーを削除すると、その中の背景は未分類の一覧に戻ります。画像そのものは削除しません。検索とタグの絞り込みでは、フォルダーの中にある一致した項目も自動的に表示します。

**Background**エージェントからは、フォルダーに入れた背景も含めて、利用できる背景がすべて見えます。フォルダーが影響するのは**Settings**での整理だけです。

### 背景の名前を変更する

名前を変更できるのは、**Library**ラベルが付いた画像だけです。

1. 画像の行にカーソルを合わせ、鉛筆アイコン(**Rename**(名前の変更))をクリックします。
2. 新しい名前を入力します。拡張子は入力しなくてかまいません。
3. **Save**(保存)をクリックします。

### 背景にタグを付ける

タグを使うと、アップロードした画像をまとめたり検索したりしやすくなります。タグを付けられるのは、**Library**ラベルが付いた画像だけです。

1. 画像の行にあるタグアイコン(**Edit tags**(タグの編集))をクリックします。
2. **Add tag...**欄にタグを入力します。入力中に、Marinaraが過去に使ったタグを候補として表示します。
3. Enterを押すか、**Add**(追加)をクリックします。
4. タグを外すには、そのタグをクリックします。タグの編集中は、各タグがXの付いたボタンとして表示されます。

### 背景をダウンロードする

同梱の背景も含めて、どの背景でもダウンロードできます。画像の行にカーソルを合わせ、ダウンロードアイコン(**Download background**(背景をダウンロード))をクリックします。画像はそのファイル名で保存されます。iPhoneやiPadでは共有シートが開くので、そこから保存できます。開かない場合は、表示されるメッセージで**Save file**(ファイルを保存)をタップしてください。

### 背景を削除する

削除できるのは、**Library**ラベルが付いた画像だけです。画像の行にカーソルを合わせてゴミ箱アイコンをクリックし、削除を確定します。その画像が現在のチャットの背景やRoleplayのデフォルト背景だった場合は、Marinaraが同梱のデフォルトに自動で戻します。

## Roleplayのデフォルト背景を設定する

Roleplayのデフォルト背景とは、新しいRoleplayチャットが独自の背景を選ぶ前に、最初に使う画像です。一度設定すれば、以降の新しいRoleplayチャットはすべてこの画像から始まります。

1. **Backgrounds**セクションで、使いたい画像をグリッドから探します。
2. その画像の行にあるピンアイコン(**Set as default for new Roleplay chats**)をクリックします。
3. ピンのボタンが強調表示されたままになり、サムネイルに**Default**ラベルが表示されます。これ以降、新しいRoleplayチャットはこの画像から始まります。

画像の左上にある星は、その画像をお気に入りに追加します。デフォルトは変わりません。

元に戻すには、現在のデフォルト画像のピンをクリックします。グリッドの上部にある**Reset Roleplay default**ボタンをクリックしてもかまいません。このボタンは、デフォルト背景が同梱のものと違う場合にだけ表示します。

## Background Blur

**Background Blur**は、チャットの後ろにある背景画像をぼかして、文字を読みやすくします。RoleplayとGame Modeの背景に適用します。

1. **Backgrounds**セクションで、**Background Blur**スライダーを探します。
2. 0から24まででドラッグします。数値が大きいほど、ぼかしが強くなります。
3. 背景をくっきり表示したいときは0にします。0のときは値が**Off**と表示されます。

デフォルトは0(**Off**)です。

## アップロードした画像と同梱の背景の混在

ライブラリーは、アップロードした画像と同梱の**Game asset**画像を1つのグリッドにまとめて表示します。どちらも同じ操作で選べます。違うのは、**Game asset**画像が読み取り専用である点で、名前の変更、タグ付け、削除の操作は表示しません。

ギャラリーで作ったAI生成のシーン背景も、この同じライブラリーに入るので、後から再利用できます。詳しくは[シーン背景とギャラリー](../media/scene-backgrounds.md)を参照してください。

## 背景の選択内容の保存先

チャットに表示する背景は3つの設定で決まり、それぞれ保存のされ方が違います。

- チャットごとに選んだ**Chat Background**は、そのチャットと一緒にサーバーへ保存します。どのデバイスで開いてもチャットに付いてきます。
- 背景のフォルダーと振り分けはサーバーに保存し、ほかのデバイスでも同じライブラリーの構成になります。
- Roleplayのデフォルト背景と**Background Blur**はデバイスごとに保存します。ブラウザーやデバイスの間で同期しません。同期の仕組み全体については、[外観の設定](appearance-settings.md)を参照してください。

## 自動選択とAI生成の背景

このガイドで説明したのは、手動で選ぶライブラリーです。背景を自動で用意する関連機能が2つあります。

- **Background**エージェントは、Roleplayのチャットで、ライブラリーから毎ターン自動でシーンの背景を選べます。詳しくは[Roleplayの背景](../roleplay/backgrounds.md)を参照してください。
- ギャラリーでは、現在のシーンをもとに、AIでまったく新しいシーン背景を生成できます。詳しくは[シーン背景とギャラリー](../media/scene-backgrounds.md)を参照してください。
