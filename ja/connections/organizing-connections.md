# 接続の整理

このガイドでは、**Connections**(接続)パネルでアカウントとモデルを整理する方法を説明します。折りたたみ、星付け、移動、削除、フォルダー、Shuffle、エクスポートを取り上げます。アカウントを追加する方法は、[AIプロバイダーへの接続](connecting-to-a-provider.md)を参照してください。

## アカウントの一覧

**Jobs**(役割)ボックスの下に、自分のアカウントが並びます。各アカウントには、画像、名前、モデルの数、アドレスが表示されます。モデルの行には、モデルの画像、名前、そしてバッジが表示されます。バッジには、担当している役割(**Main**、**Agents**、**Images**)、**Custom settings**、価格、サブスクリプションに含まれるモデルを示す**Plan**などがあります。**Built-in model**(内蔵モデル)のカードは**Jobs**ボックスの下にあります。[内蔵モデルのセットアップ](local-model.md)を参照してください。

アカウントの行をクリックすると、そのモデルを折りたたみます。もう一度クリックすると表示します。どのアカウントを折りたたんだかは、Marinaraが覚えています。パネル上部の**More actions**(その他の操作、3つの点のアイコン)には、次の項目があります。

| 項目 | 内容 |
| --- | --- |
| **Fold all accounts**(すべてのアカウントを折りたたむ)、**Open all accounts**(すべてのアカウントを開く) | すべてのアカウントを折りたたむか、開きます。 |
| **Show only Off or Needs key**(オフまたはキー未設定のものだけを表示) | 対応が必要なアカウントだけを表示します。 |
| **Show cost badges**(料金のバッジを表示) | 各モデルの価格を表示します。 |
| **Group by folder**(フォルダーでグループ化)、**Group by account**(アカウントでグループ化) | モデルのまとめ方を切り替えます。[フォルダー](#folders)を参照してください。 |
| **Import account**(アカウントのインポート)、**Export all accounts**(すべてのアカウントをエクスポート) | [エクスポートとインポート](#export-and-import)を参照してください。 |

パネルの幅が広いときは、並べ替えのドロップダウンが**Search models and accounts**(モデルとアカウントを検索)の横にあります。幅が狭いときは、並べ替えは**More actions**の中にあります。並べ替えの選択肢は、**Custom**(カスタム)、**A–Z**、**Z–A**、**Newest**(新しい順)、**Oldest**(古い順)です。**Search models and accounts**に入力すると、その場で一覧が絞り込まれます。

NanoGPTやプロキシのように、複数の開発元のモデルを使えるアカウントもあります。そうしたアカウントのモデルは、**via NanoGPT**のような見出しの下にまとめられます。

### アカウントの操作

アカウントの行にある**⋯**をクリックします。

| 操作 | 内容 |
| --- | --- |
| **Edit account**(アカウントの編集) | 設定を開きます。**Name**(名前)、**Address**(アドレス)、**API key**(APIキー)、**Use this account**(このアカウントを使う)などがあります。 |
| **Replace key**(キーを置き換える) | 新しいキーを貼り付けます。古いキーがほかのアカウントにも設定されている場合は、それらも更新するかどうかをMarinaraが尋ねます。 |
| **Test**(テスト) | キーを確認して結果を表示します。 |
| **Add model**(モデルを追加) | アカウントのモデル一覧を開きます。画像も作れるサービスでは、**Add image model**(画像モデルを追加)も表示されます。 |
| **Select models**(モデルを選択) | 複数のモデルをまとめて移動または削除できます。 |
| **Duplicate**(複製) | アカウントのコピーを、そのモデルのコピーと一緒に追加します。 |
| **Turn off**(オフにする) / **Turn on**(オンにする) | Marinaraによるアカウントの使用を停止または再開します。 |
| **Delete account**(アカウントを削除) | 下記を参照してください。 |

アカウントを削除するには、**Delete account**をクリックします。Marinaraは確認を求め、そのモデルを使っているもの(チャット、エージェント、モデル、役割)を**Used by**(使用先)の下に一覧で示します。**Delete with its N models**(N個のモデルごと削除)をクリックすると、アカウントとそのモデルを削除します。それらのチャットと役割には、別のモデルが必要になります。削除できないモデルがある場合は、エディターの**This account still has models. Remove these first:**の下に表示されます。1つずつ開いて削除してください。

**Edit account**では、**Test account**(アカウントをテスト)がキーを確認し、**Usage and balance**(使用量と残高)がプランの使用量を表示します。**More options**(その他のオプション)には、**Requests per minute**(1分あたりのリクエスト数)と**Parallel requests**(同時リクエスト数)があります。

### プロバイダーのアイコン

各アカウントには、そのサービスのアイコンが表示されます。アイコンはMarinaraに同梱されており、インターネットから読み込まれることはありません。カスタムのアドレスでは、アドレスや名前に既知のサーバーやゲートウェイが含まれている場合、そのアイコンが表示されます。たとえばOllama、LM Studio、KoboldCpp、Bifrost、LiteLLMです。それ以外の場合は、名前の最初の1文字が表示されます。自分で選ぶには、アカウントの画像をクリックし、サービスのロゴを選ぶか、画像をアップロードするか、文字を使います。

## 星付きのモデル

星は、すぐに見つけたいモデルの印です。星付きのモデルは、どのモデル選択画面でも、上のほうの**Starred**(星付き)の下に並びます。対象は、**Jobs**(役割)ボックスの**Model for**(役割に使うモデル)ウィンドウ、**Model for this chat**(このチャットのモデル)、**Chat Settings**(チャット設定)とエージェントエディターのモデル欄です。

モデルに星を付けるには、アカウントの**Add model**(モデルを追加)の一覧でそのモデルの星をクリックするか、モデルの**⋯**メニューで**Star**(星を付ける)を選びます。モデルに役割を割り当てた場合も、そのモデルは保存されます。

星を外すには、もう一度星をクリックします。Marinaraはそのモデルを削除し、数秒間**Undo**(元に戻す)を表示します。チャットで使われている場合、**Jobs**で役割を持っている場合、独自の設定がある場合、またはアカウントの最後のモデルである場合は、星だけが外れてモデルは残ります。その理由はメッセージに表示されます。

## モデルの操作

モデルの行にある**⋯**をクリックします。

| 操作 | 内容 |
| --- | --- |
| **Make default for…**(…のデフォルトにする) | モデルに役割を割り当てます。**Jobs**(役割)ボックスで選ぶのと同じです。 |
| **Edit model**(モデルの編集) | モデルの設定を開きます。モデルの行をクリックしても同じです。 |
| **Move to account…**(アカウントへ移動…) | モデルを別のアカウントへ移します。移したモデルは、移動先のアカウントのキーを使います。 |
| **Folder**(フォルダー) | モデルをフォルダーに入れます。 |
| **Duplicate**(複製) | 同じ設定のまま丸ごとコピーします。 |
| **Add to Shuffle**(Shuffleに追加) / **Remove from Shuffle**(Shuffleから外す) | [Shuffle](#shuffle)を参照してください。 |
| **Change picture**(画像を変更) | 画像の選択肢を開きます。 |
| **Remove**(削除) | 確認したあとでモデルを削除します。確認画面には、そのモデルを使っているものが表示されます。 |

モデルを移すと、名前、画像、役割、チャットも一緒に移り、サービス固有のオプションはリセットされます。

コンピューターでは、モデルの行をチャットの上にドラッグすると、そのチャットでそのモデルを使えます。

## フォルダー

フォルダーを使うと、たとえば**RP**や**Work**のようにモデルをまとめられます。表示するには、**More actions**(その他の操作)で**Group by folder**(フォルダーでグループ化)を選びます。1つのモデルは1つのフォルダーに入ります。

1. モデルの**⋯**をクリックし、**Folder**(フォルダー)を選びます。
2. フォルダーを選ぶか、**New folder…**(新しいフォルダー…)をクリックして名前を入力し、**Create**(作成)をクリックします。

フォルダーにはアイコンと色を設定できます。フォルダーの名前を変えたり削除したりするには、その**⋯**メニューを開きます。フォルダーを削除しても、中のモデルは**Not in a folder**(フォルダーなし)の下に残ります。

## Shuffle

Shuffle(シャッフル)を使うと、チャットが返信を書くたびに別のモデルを選べます。複数のサービスやモデルにリクエストを分散したいときに使います。

1. プールに入れたい各モデルの**⋯**をクリックし、**Add to Shuffle**(Shuffleに追加)を選びます。
2. チャットで、チャット入力欄から**Model for this chat**(このチャットのモデル)を開くか、**Chat Settings → Connection → Model**(チャット設定 → 接続 → モデル)を開き、**Shuffle**を選びます。

以降は返信ごとに、Shuffleのプールからランダムにモデルを選びます。

返信のために選ばれたモデルが失敗し、**Main**(メイン)に**If it fails**(失敗したとき)のモデルが設定されている場合は、代わりにそのモデルが返信を書きます。通知には、失敗したモデルと、「key rejected」「rate limited」「not found」のような短い理由が表示されます。返信には小さな**Fallback**(フォールバック)ラベルが残ります。タップするかポインターを合わせると、同じ内容をもう一度確認できます。

**Model for this chat**で選んだモデルが変わるのは、そのチャットだけです。新しいチャットのモデルを変えるには、**Jobs**(役割)ボックスで**Main**を設定します。

## エクスポートとインポート

アカウントはファイルにエクスポートできます。バックアップとして保管したり、別のインストール先へ移したりして、あとからインポートできます。

> **Warning:** エクスポートしたファイルにAPIキーは含まれません。インポートしたあとは、アカウントを1つずつ開いてキーを入力し直してください。キーは誰とも共有しないでください。

- **1つのモデルをエクスポートする:** **Edit model**(モデルの編集)で開き、**Export model**(モデルをエクスポート)をクリックします。
- **すべてをエクスポートする:** **More actions**(その他の操作)を開いて**Export all accounts**(すべてのアカウントをエクスポート)を選びます。ファイルにキーが含まれないことをMarinaraが知らせます。**Export**(エクスポート)をクリックします。
- **インポートする:** **More actions**を開いて**Import account**(アカウントのインポート)を選びます。1つ以上のファイル(`.json`、`.jsonl`、`.zip`)をウィンドウにドロップするか、クリックしてファイルを選びます。エクスポートした`marinara-connections.zip`もインポートできます。インポートした各アカウントのキーは、入力するまで空のままです。

モデルが1つのときは`.connection.json`ファイルとしてダウンロードされます。複数のときは`marinara-connections.zip`にまとめてダウンロードされます。星は含まれます。サービスのモデルカタログは含まれないため、アカウントのモデルを初めて開いたときに読み込み直します。
